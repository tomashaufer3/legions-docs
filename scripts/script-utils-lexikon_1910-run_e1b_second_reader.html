How it works

SYMBOL_ACCURACY_PLAN.md keeps Gemini Flash as the reader of record and asks for a second reader that routes and never overwrites (D-38, D-55): a claim the two agree on is accepted, a claim only one makes goes to review. Opus cannot be that reader over a whole volume, on cost. This screen chooses a cheap one, and it does not choose on accuracy alone:

a second reader is worth what it brings to review —
the first reader's errors it disagrees on, less the alarms it raises on
claims the first reader had right (`lexikon_1910_institutions.second_reader`).

Two readers at 0.97 that make the same mistakes are one reader read twice, and the r4 baseline says that is what a second Gemini pass is: its substitutions (castle / poorhouse, ruin / solitary house, myslivna / hájovna) recur in every repeat and in both versions. So the bar a candidate has to clear is on disk before anything is spent — --score prints it.

What is held fixed

Everything the reader is shown. The flags are bakeoff.flags_for for the atlas variant of the gold kind, exactly as E1 and the r4 baseline sent them — 13 pages, both apparatus documents, strips of 500 px, upscaled, atlas on, temperature 0 — and only the transport changes. The crops are therefore the 81 the baseline read.

The candidates

CANDIDATES. The two that run by default need no new account: Claude Haiku 4.5, on the Anthropic key already in .secrets/api_keys.json, and qwen3.8:27b on the local Ollama daemon, which is free. One pass each; a finalist gets three (--repeats 3 --candidates haiku45).

Claude Haiku 5.5 (2026-10-08) is on file twice, on the same key, and off by default: haiku55 with thinking asked off, as the default reader's is, and haiku55t as the model runs unasked, with adaptive thinking. The first table of --score sets either beside gemini38 as a reader in its own right, which is the comparison to make before asking what it adds as a second one. Two further arms, haiku55n and haiku55nh, send the thinking arm the prompt's note for a reader that thinks, at medium and at high effort.

Three more are on file and off by default, because they need an OpenRouter account and its key (OPENROUTER_API_KEY): Qwen3-VL, MiniMax M3 and Kimi K2.5. They are the next thing to try only if neither default clears the bar. Their ids and prices were read off OpenRouter's own model list on 2026-10-06 and are checked against it again before each such pass (the list is public and costs nothing): an id that is gone skips its candidate, a price that moved is printed. --list shows what that endpoint offers today.

Before a hosted pass, one tiny request is sent as the pass would send it — same model, same settings. A model or a parameter the endpoint refuses is then found by one request instead of by eighty-one crops.

def plan(names=DEFAULT, repeats: int = 1) -> list[dict]:
    """One job per candidate and repeat, hosted first so a daemon that is down
    costs the screen only the free pass."""
    jobs = []
    for repeat in range(1, repeats + 1):
        for name in sorted(names, key=lambda n: CANDIDATES[n].route == "ollama"):
            candidate, tag = CANDIDATES[name], label(name, repeat)
            jobs.append({
                "name": name, "candidate": candidate, "repeat": repeat, "label": tag,
                "done": (bo.PASS_DIR / f"inventory_{tag}.csv").exists()
                        and not (bo.PASS_DIR / f"ratelimit_{tag}.json").exists()})
    return jobs

    for job in jobs:
        price = job["candidate"].price

def listed() -> dict:
    """``{model id: ($/M in, $/M out)}`` for every image-reading model OpenRouter
    lists. The list is public: no key, no charge."""
    with urllib.request.urlopen(f"{OPENROUTER_URL}/models", timeout=60) as reply:
        models = json.load(reply)["data"]
    out = {}
    for model in models:
        if "image" not in (model.get("architecture") or {}).get("input_modalities", []):

                            round(float(price.get("completion") or 0) * 1e6, 2))
    return out

def ping(candidate: Candidate) -> tuple[str, str]:
    """One tiny request as the pass would send it: ``("ok" | "closed" | "refused", why)``.

    ``closed`` is the account (429, a spent balance as 402) or the provider having
    a bad minute (5xx): not now. ``refused`` is the request itself (400, 404): the
    endpoint will not take this model with this setting, and no pass should try.
    """
    message = [{"role": "user", "content": "Reply with OK."}]
    if candidate.route == "anthropic":
        import anthropic
        try:
            # gzip only, as the pilot's ClaudeReader asks and for its reason.
            anthropic.Anthropic(
                default_headers={"Accept-Encoding": "gzip, deflate"},
            ).messages.create(model=candidate.model, max_tokens=16,
                              messages=message, **claude_thinking(candidate))
            return "ok", ""
        except anthropic.RateLimitError as exc:
            return "closed", f"rate limited: {exc.message[:160]}"
        except anthropic.APIStatusError as exc:
            return ("closed" if exc.status_code >= 500 else "refused",
                    f"HTTP {exc.status_code}: {exc.message[:160]}")
    from openai import OpenAI
    client = OpenAI(base_url=OPENROUTER_URL, api_key=os.environ.get(OPENROUTER_KEY, ""))
    extra = {"reasoning_effort": candidate.reasoning} if candidate.reasoning else {}
    try:
        client.chat.completions.create(model=candidate.model, max_tokens=16,
                                       messages=message, **extra)
        return "ok", ""
    except Exception as exc:                                    # noqa: BLE001
        status = getattr(exc, "status_code", None)
        why = f"HTTP {status}: {str(exc)[:160]}"
        if status in (402, 429) or (status is not None and status >= 500):
            return "closed", why
        if status in (400, 401, 403, 404, 422):
            return "refused", why
        raise

def ready(job: dict, offered: dict) -> tuple[bool, bool, str]:
    """``(run this pass, keep going with the others, why not)`` for one job.

    A candidate that cannot run is skipped and named, and the others still run;
    only an account or a provider saying "not now" stops the screen.
    """
    candidate = job["candidate"]
    if candidate.route == "ollama":
        if not bo.daemon_up():
            return False, True, "the Ollama daemon is not answering"
        if candidate.model not in bo.pulled_models():
            return False, True, f"{candidate.model} is not pulled (ollama pull {candidate.model})"
        return True, True, ""
    if candidate.route == "openrouter":
        if not os.environ.get(OPENROUTER_KEY):
            return False, True, (f"no {OPENROUTER_KEY}: this candidate needs an "
                                 f"OpenRouter account, the default ones do not")
        if candidate.model not in offered:
            return False, True, f"{candidate.model} is not on the endpoint's list (--list)"
        if offered[candidate.model] != candidate.price:
            print(f"  !! {candidate.model} is listed at ${offered[candidate.model][0]} / "
                  f"${offered[candidate.model][1]} a million tokens; this file has "
                  f"${candidate.price[0]} / ${candidate.price[1]} and books the pass at that")
    state, why = ping(candidate)
    if state == "closed":
        return False, False, f"the account or the provider refused ({why})"
    if state == "refused":
        return False, True, (f"the endpoint refused the request as the pass would "
                             f"send it ({why})")
    return True, True, ""

def run(names=DEFAULT, repeats: int = 1, force: bool = False) -> bool:
    """Run every outstanding pass. False if the account stopped it."""
    bo.ensure_dirs()
    jobs = [job for job in plan(names, repeats) if force or not job["done"]]
    through_openrouter = any(job["candidate"].route == "openrouter" for job in jobs)
    offered = listed() if through_openrouter and os.environ.get(OPENROUTER_KEY) else {}
    timings = bo.load_timings()
    for job in jobs:
        go, carry_on, why = ready(job, offered)
        if not go:
            print(f"\n  {job['label']} not run — {why}")
            if not carry_on:
                print("  stopping E1b; rerun to resume")
                return False
            continue
        marker = bo.PASS_DIR / f"ratelimit_{job['label']}.json"
        if marker.exists():
            marker.replace(bo.PASS_DIR / (f"superseded_ratelimit_{job['label']}_"
                                          f"{time.strftime('%Y%m%d-%H%M%S')}.json"))
        print("\n" + "=" * 78)
        print(f"E1b  {job['label']}   ({job['candidate'].model}, repeat {job['repeat']})")
        print("=" * 78)
        rc, seconds = bo.run_pilot(flags(job), f"{KIND}_{job['label']}")
        timings.setdefault(job["label"], {})[KIND] = {
            "model": job["candidate"].model, "variant": VARIANT,
            "pages": bo.gold_pages(), "seconds": seconds, "rc": rc, "atlas": True,
            "upscale": True, "max_height": bo.MAX_HEIGHT, "sections": bo.SECTIONS,
            "run_tag": bo.RUN_TAG, "host": bo.HOST, "reader": job["candidate"].route,
            "experiment": "E1b", "repeat": job["repeat"],
            "tokens": e1.cache_usage(job["label"]),
            "reasoning_effort": job["candidate"].reasoning,
            "incomplete": marker.exists(),
            "finished": time.strftime("%Y-%m-%d %H:%M:%S")}
        bo.TIMINGS.write_text(json.dumps(timings, indent=2), encoding="utf-8")
        if marker.exists():
            print(f"\n  {job['label']} was refused by the quota — stopping E1b; the "
                  f"pass stays outstanding and reruns on a fresh quota.")
            return False
        if rc != 0:
            print(f"\n  {job['label']} exited rc={rc} — see logs/{KIND}_{job['label']}.log")
    return True

def pairs(passes: dict, human: list[dict]) -> list[dict]:
    """Every pass as second reader to each repeat of the reader of record."""
    firsts = sorted(name for name in passes if family_of(name) == FIRST)
    rows = []
    for first in firsts:
        for second in sorted(passes):
            if second == first:
                continue
            row = lxin.second_reader({"human": human, **passes}, first, second)
            kind = ("the same reader, another repeat" if family_of(second) == FIRST
                    else "the same family, other version"
                    if family_of(second) == SAME_FAMILY else "another family")
            rows.append({**row, "second_reader": family_of(second), "kind": kind})
    return rows

def by_reader(rows: list[dict]) -> list[dict]:
    """The pair rows averaged per second reader — one line each for the ledger."""
    keys = ("first_errors", "caught", "catch_rate", "shared_errors",
            "false_alarms", "f1_first", "f1_after_review")
    out = []
    for reader in dict.fromkeys(row["second_reader"] for row in rows):
        mine = [row for row in rows if row["second_reader"] == reader]
        mean = {key: sum(row[key] or 0 for row in mine) / len(mine) for key in keys}
        out.append({"second_reader": reader, "kind": mine[0]["kind"],
                    "pairs": len(mine), **{k: round(v, 3) for k, v in mean.items()}})
    return out

for a second reader that **routes and never overwrites** (D-38, D-55): a claim

it does not choose on accuracy alone:

    a second reader is worth what it brings to review —
    the first reader's errors it disagrees on, less the alarms it raises on
    claims the first reader had right (``lexikon_1910_institutions.second_reader``).

def label(name: str, repeat: int) -> str:
    """``qwen3vl_r4atlasg1`` / ``minimax3_r4atlasntg1`` (thinking asked off)."""
    tag = VARIANT + ("nt" if CANDIDATES[name].reasoning == "none" else "")
    return bo.label_for(name, tag, KIND) + str(repeat)


def plan(names=DEFAULT, repeats: int = 1) -> list[dict]:
    """One job per candidate and repeat, hosted first so a daemon that is down
    costs the screen only the free pass."""
    jobs = []
    for repeat in range(1, repeats + 1):
        for name in sorted(names, key=lambda n: CANDIDATES[n].route == "ollama"):
            candidate, tag = CANDIDATES[name], label(name, repeat)
            jobs.append({
                "name": name, "candidate": candidate, "repeat": repeat, "label": tag,
                "done": (bo.PASS_DIR / f"inventory_{tag}.csv").exists()
                        and not (bo.PASS_DIR / f"ratelimit_{tag}.json").exists()})
    return jobs


def claude_thinking(candidate: Candidate) -> dict:
    """What a Claude candidate's ``reasoning`` means on the Messages API.

    ``"none"`` asks thinking off, an effort name asks adaptive thinking at that
    effort, and ``""`` sends nothing — right for Haiku 4.5, which does not think
    unasked, and never right for a model that does.
    """
    if candidate.reasoning == "none":
        return {"thinking": {"type": "disabled"}}
    if candidate.reasoning:
        return {"thinking": {"type": "adaptive"},
                "output_config": {"effort": candidate.reasoning}}
    return {}


def claude_flags(candidate: Candidate) -> list[str]:
    """:func:`claude_thinking`, as the pilot's flags."""
    asked = claude_thinking(candidate)
    if not asked:
        return ["--thinking", "default"]
    out = ["--thinking", asked["thinking"]["type"]]
    if "output_config" in asked:
        out += ["--effort", asked["output_config"]["effort"]]
    if candidate.think_note:
        out += ["--notes-think"]        # for this reader, the prompt and nothing else
    return out


def flags(job: dict) -> list[str]:
    """``bakeoff.flags_for`` for the gold atlas pass, pointed at the candidate.

    Edited, not rebuilt — as :func:`run_e1_gemini_version.flags` does — so every
    flag that decides what the model is shown stays whatever the baseline sent.
    """
    candidate = job["candidate"]
    if candidate.route == "ollama":
        return bo.flags_for(candidate.model, job["label"], bo.gold_pages(),
                            bo.VARIANT[VARIANT], bo.load_encoders(), kind=KIND)
    argv = bo.flags_for(candidate.model, job["label"], bo.gold_pages(),
                        bo.VARIANT[VARIANT], {}, kind=KIND)
    reader = (["--notes-reader", "claude", "--model", candidate.model,
               *claude_flags(candidate)]
              if candidate.route == "anthropic" else
              ["--notes-reader", "openai-compatible", "--reader-url", OPENROUTER_URL,
               "--notes-key-env", OPENROUTER_KEY])
    swap = {"--notes-reader": reader,
            "--workers": ["--workers", str(WORKERS)],
            "--notes-num-ctx": []}          # exists for Ollama alone
    out, skip = [], False
    for arg in argv:
        if skip:
            skip = False
        elif arg in swap:
            out += swap[arg]
            skip = True
        else:
            out.append(arg)
    out += ["--notes-price", "{},{}".format(*candidate.price)]
    if candidate.reasoning and candidate.route == "openrouter":
        out += ["--notes-reasoning-effort", candidate.reasoning]
    return out


def estimate(jobs: list[dict]) -> float:
    """USD for the hosted jobs still to read, from :data:`EST_TOKENS`."""
    total = 0.0
    for job in jobs:
        price = job["candidate"].price
        if price and not job["done"]:
            total += CROPS * (EST_TOKENS[0] * price[0] + EST_TOKENS[1] * price[1]) / 1e6
    return total

def listed() -> dict:
    """``{model id: ($/M in, $/M out)}`` for every image-reading model OpenRouter
    lists. The list is public: no key, no charge."""
    with urllib.request.urlopen(f"{OPENROUTER_URL}/models", timeout=60) as reply:
        models = json.load(reply)["data"]
    out = {}
    for model in models:
        if "image" not in (model.get("architecture") or {}).get("input_modalities", []):
            continue
        price = model.get("pricing") or {}
        out[model["id"]] = (round(float(price.get("prompt") or 0) * 1e6, 2),
                            round(float(price.get("completion") or 0) * 1e6, 2))
    return out


def ping(candidate: Candidate) -> tuple[str, str]:
    """One tiny request as the pass would send it: ``("ok" | "closed" | "refused", why)``.

    ``closed`` is the account (429, a spent balance as 402) or the provider having
    a bad minute (5xx): not now. ``refused`` is the request itself (400, 404): the
    endpoint will not take this model with this setting, and no pass should try.
    """
    message = [{"role": "user", "content": "Reply with OK."}]
    if candidate.route == "anthropic":
        import anthropic
        try:
            # gzip only, as the pilot's ClaudeReader asks and for its reason.
            anthropic.Anthropic(
                default_headers={"Accept-Encoding": "gzip, deflate"},
            ).messages.create(model=candidate.model, max_tokens=16,
                              messages=message, **claude_thinking(candidate))
            return "ok", ""
        except anthropic.RateLimitError as exc:
            return "closed", f"rate limited: {exc.message[:160]}"
        except anthropic.APIStatusError as exc:
            return ("closed" if exc.status_code >= 500 else "refused",
                    f"HTTP {exc.status_code}: {exc.message[:160]}")
    from openai import OpenAI
    client = OpenAI(base_url=OPENROUTER_URL, api_key=os.environ.get(OPENROUTER_KEY, ""))
    extra = {"reasoning_effort": candidate.reasoning} if candidate.reasoning else {}
    try:
        client.chat.completions.create(model=candidate.model, max_tokens=16,
                                       messages=message, **extra)
        return "ok", ""
    except Exception as exc:                                    # noqa: BLE001
        status = getattr(exc, "status_code", None)
        why = f"HTTP {status}: {str(exc)[:160]}"
        if status in (402, 429) or (status is not None and status >= 500):
            return "closed", why
        if status in (400, 401, 403, 404, 422):
            return "refused", why
        raise


def ready(job: dict, offered: dict) -> tuple[bool, bool, str]:
    """``(run this pass, keep going with the others, why not)`` for one job.

    A candidate that cannot run is skipped and named, and the others still run;
    only an account or a provider saying "not now" stops the screen.
    """
    candidate = job["candidate"]
    if candidate.route == "ollama":
        if not bo.daemon_up():
            return False, True, "the Ollama daemon is not answering"
        if candidate.model not in bo.pulled_models():
            return False, True, f"{candidate.model} is not pulled (ollama pull {candidate.model})"
        return True, True, ""
    if candidate.route == "openrouter":
        if not os.environ.get(OPENROUTER_KEY):
            return False, True, (f"no {OPENROUTER_KEY}: this candidate needs an "
                                 f"OpenRouter account, the default ones do not")
        if candidate.model not in offered:
            return False, True, f"{candidate.model} is not on the endpoint's list (--list)"
        if offered[candidate.model] != candidate.price:
            print(f"  !! {candidate.model} is listed at ${offered[candidate.model][0]} / "
                  f"${offered[candidate.model][1]} a million tokens; this file has "
                  f"${candidate.price[0]} / ${candidate.price[1]} and books the pass at that")
    state, why = ping(candidate)
    if state == "closed":
        return False, False, f"the account or the provider refused ({why})"
    if state == "refused":
        return False, True, (f"the endpoint refused the request as the pass would "
                             f"send it ({why})")
    return True, True, ""

def run(names=DEFAULT, repeats: int = 1, force: bool = False) -> bool:
    """Run every outstanding pass. False if the account stopped it."""
    bo.ensure_dirs()
    jobs = [job for job in plan(names, repeats) if force or not job["done"]]
    through_openrouter = any(job["candidate"].route == "openrouter" for job in jobs)
    offered = listed() if through_openrouter and os.environ.get(OPENROUTER_KEY) else {}
    timings = bo.load_timings()
    for job in jobs:
        go, carry_on, why = ready(job, offered)
        if not go:
            print(f"\n  {job['label']} not run — {why}")
            if not carry_on:
                print("  stopping E1b; rerun to resume")
                return False
            continue
        marker = bo.PASS_DIR / f"ratelimit_{job['label']}.json"
        if marker.exists():
            marker.replace(bo.PASS_DIR / (f"superseded_ratelimit_{job['label']}_"
                                          f"{time.strftime('%Y%m%d-%H%M%S')}.json"))
        print("\n" + "=" * 78)
        print(f"E1b  {job['label']}   ({job['candidate'].model}, repeat {job['repeat']})")
        print("=" * 78)
        rc, seconds = bo.run_pilot(flags(job), f"{KIND}_{job['label']}")
        timings.setdefault(job["label"], {})[KIND] = {
            "model": job["candidate"].model, "variant": VARIANT,
            "pages": bo.gold_pages(), "seconds": seconds, "rc": rc, "atlas": True,
            "upscale": True, "max_height": bo.MAX_HEIGHT, "sections": bo.SECTIONS,
            "run_tag": bo.RUN_TAG, "host": bo.HOST, "reader": job["candidate"].route,
            "experiment": "E1b", "repeat": job["repeat"],
            "tokens": e1.cache_usage(job["label"]),
            "reasoning_effort": job["candidate"].reasoning,
            "incomplete": marker.exists(),
            "finished": time.strftime("%Y-%m-%d %H:%M:%S")}
        bo.TIMINGS.write_text(json.dumps(timings, indent=2), encoding="utf-8")
        if marker.exists():
            print(f"\n  {job['label']} was refused by the quota — stopping E1b; the "
                  f"pass stays outstanding and reruns on a fresh quota.")
            return False
        if rc != 0:
            print(f"\n  {job['label']} exited rc={rc} — see logs/{KIND}_{job['label']}.log")
    return True

def tokens_of(name: str) -> dict:
    """A pass's stored token counts, from whichever machine's folder holds its cache."""
    for folder in sorted(d for d in bo.BAKEOFF.glob("*") if d.is_dir()):
        usage = e1.cache_usage(name, folder)
        if usage:
            return usage
    return {}


def family_of(name: str) -> str:
    """The reader a pass label belongs to: ``gemini38_r4atlasntg2`` -> ``gemini38``."""
    return name.split(f"_{bo.RUN_TAG}")[0]


def pairs(passes: dict, human: list[dict]) -> list[dict]:
    """Every pass as second reader to each repeat of the reader of record."""
    firsts = sorted(name for name in passes if family_of(name) == FIRST)
    rows = []
    for first in firsts:
        for second in sorted(passes):
            if second == first:
                continue
            row = lxin.second_reader({"human": human, **passes}, first, second)
            kind = ("the same reader, another repeat" if family_of(second) == FIRST
                    else "the same family, other version"
                    if family_of(second) == SAME_FAMILY else "another family")
            rows.append({**row, "second_reader": family_of(second), "kind": kind})
    return rows


def by_reader(rows: list[dict]) -> list[dict]:
    """The pair rows averaged per second reader — one line each for the ledger."""
    keys = ("first_errors", "caught", "catch_rate", "shared_errors",
            "false_alarms", "f1_first", "f1_after_review")
    out = []
    for reader in dict.fromkeys(row["second_reader"] for row in rows):
        mine = [row for row in rows if row["second_reader"] == reader]
        mean = {key: sum(row[key] or 0 for row in mine) / len(mine) for key in keys}
        out.append({"second_reader": reader, "kind": mine[0]["kind"],
                    "pairs": len(mine), **{k: round(v, 3) for k, v in mean.items()}})
    return out


def order_pairs(passes: dict, human: list[dict]) -> list[dict]:
    """The printed-order check (I22) on what each pair with the reader of record disputes.

    One row per second reader, the mean over its pairs with each repeat of
    :data:`FIRST`, which is always the ``first`` of the row. Nothing is sent:
    the flags come from the decoded records already on disk
    (:func:`rescore_passes.order_frames`).
    """
    flags = rescore.order_frames(passes, human)["flags"]
    scored = {"human": human, **passes}
    firsts = sorted(name for name in flags if family_of(name) == FIRST)
    return rescore.dispute_means([
        lxin.order_disputes(scored, flags, first, second)
        for first in firsts for second in sorted(flags) if second != first])


def summary_table(readers: list[dict]) -> list[str]:
    lines = [f"  {'second reader':14s} {'':32s} {'pairs':>5s} {'errors':>6s} "
             f"{'caught':>6s} {'rate':>6s} {'shared':>6s} {'alarms':>6s} "
             f"{'F1':>6s} {'F1 after':>8s}"]
    for row in readers:
        lines.append(
            f"  {row['second_reader']:14s} {row['kind']:32s} {row['pairs']:5d} "
            f"{row['first_errors']:6.1f} {row['caught']:6.1f} {row['catch_rate']:6.3f} "
            f"{row['shared_errors']:6.1f} {row['false_alarms']:6.1f} "
            f"{row['f1_first']:6.3f} {row['f1_after_review']:8.3f}")
    return lines


def score() -> str:
    """Score what is on disk, write the two outputs, return the report."""
    human = bo.load_pass(bo.HUMAN)
    passes = bo.passes_on_disk(hosts="all")
    if not any(family_of(name) == FIRST for name in passes):
        return (f"no {FIRST} pass of run {bo.RUN_TAG} on disk — the baseline "
                f"(notebook 07) comes first")
    scored = {s["pass"]: s for s in lxin.score_against_reference(
        {"human": human, **passes}, reference="human")}
    rows = pairs(passes, human)
    readers = by_reader(rows)
    screened = [name for name in passes if family_of(name) in CANDIDATES]

    lines = [f"run_e1b_second_reader v{__version__} — {time.strftime('%Y-%m-%d %H:%M')}"
             f" — run {bo.RUN_TAG}",
             rescore.gold_line(human), "",
             "  as a reader on its own — settlement level",
             f"  {'pass':26s} {'claims':>6s} {'P':>6s} {'R':>6s} {'F1':>6s} "
             f"{'misfiled':>8s} {'in tok':>10s} {'out tok':>9s}"]
    for name in sorted(passes, key=lambda n: -scored[n]["f1_settlement"]):
        s, tokens = scored[name], tokens_of(name)
        lines.append(f"  {name:26s} {s['claims_settlement']:6d} "
                     f"{s['precision_settlement']:6.3f} {s['recall_settlement']:6.3f} "
                     f"{s['f1_settlement']:6.3f} {s['false_misfiled']:8d} "
                     f"{e1.input_tokens(tokens):10,d} {tokens.get('output', 0):9,d}")
    lines += ["", f"  as a SECOND reader to {FIRST} — mean over the pairs with each "
                  f"of its repeats", ""]
    lines += summary_table(readers)
    lines += ["", "  `errors` are the first reader's; `caught` reach review; `shared` "
                  "are left after a",
              "  perfect review; `alarms` are review load on claims the first "
              "reader had right.",
              "  The first two rows are the bar: what reading again with Gemini "
              "already buys."]
    if not screened:
        lines += ["", "  no candidate pass on disk yet — the rows above are the "
                      "baseline's own passes"]
    lines += ["", "", "  what the printed order of the marks says about the "
                      "claims a pair disputes (I22, D-73) —",
              f"  mean over the pairs with each repeat of {FIRST}", "",
              lxin.lexikon_1910_order_disputes_report(order_pairs(passes, human))]
    lines += ["", "", lxin.lexikon_1910_second_reader_report(
        [row for row in rows if row["second_reader"] != FIRST
         and row["first"].endswith("1")])]
    report = "\n".join(lines)
    bo.BAKEOFF.mkdir(parents=True, exist_ok=True)
    rescore.write_csv(OUT_CSV, rows)
    OUT_REPORT.write_text(report + "\n", encoding="utf-8")
    return report


def main(argv=None) -> int:
    ap = argparse.ArgumentParser(description=__doc__.split("\n\n")[0])
    ap.add_argument("--score", action="store_true", help="score only; spend nothing")
    ap.add_argument("--dry-run", action="store_true", help="print the plan and exit")
    ap.add_argument("--list", action="store_true",
                    help="print the endpoint's ids and prices for the candidates' "
                         "families; no key, no charge")
    ap.add_argument("--candidates", default=",".join(DEFAULT),
                    help=f"comma-separated, from: {', '.join(CANDIDATES)}")
    ap.add_argument("--repeats", type=int, default=1)
    ap.add_argument("--force", action="store_true", help="re-run passes on disk")
    args = ap.parse_args(argv)
    for stream in (sys.stdout, sys.stderr):
        try:
            stream.reconfigure(encoding="utf-8", errors="replace")
        except (AttributeError, ValueError):
            pass
    names = tuple(n for n in args.candidates.split(",") if n)
    unknown = [n for n in names if n not in CANDIDATES]
    if unknown:
        ap.error(f"unknown candidate {unknown}; choose from {', '.join(CANDIDATES)}")

    if args.list:
        families = {c.model.split("/")[0] for c in CANDIDATES.values()
                    if c.route == "openrouter"}
        for model, (price_in, price_out) in sorted(listed().items()):
            if model.split("/")[0] in families:
                print(f"  {model:44s} ${price_in:6.2f} in  ${price_out:6.2f} out")
        return 0
    if args.dry_run:
        jobs = plan(names, args.repeats)
        for job in jobs:
            print(f"  {'done' if job['done'] else 'todo':4s}  {job['label']:24s} "
                  f"{' '.join(flags(job))}")
        print(f"\n  hosted passes still to read: about ${estimate(jobs):.2f} "
              f"(an estimate — {EST_TOKENS[0]:,} in and {EST_TOKENS[1]} out a crop, "
              f"{CROPS} crops)")
        return 0
    if args.score:
        print(score())
        return 0
    from utils.lexikon_1910 import lexikon_1910_pages as lxp
    lxp.load_credentials()
    finished = run(names, args.repeats, force=args.force)
    print("\n" + score())
    return 0 if finished else 2
