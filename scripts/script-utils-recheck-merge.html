How it works

final_inventory_rechecked.csv, final_types_rechecked.csv and (where the run wrote text abbreviations) final_abbreviations_rechecked.csv per edition, beside a changes.csv that gives every row added, removed or relabelled its source and reason. The route's own tables stay the certified record; these are built from them, in this order, a later step overruling an earlier one:

  1. §3, parts lines decoded as offices. A route inventory row that every reader's re-split loses (resplit/lost_&lt;label&gt;.csv): a missed court heading had parts lines decoded as offices. 1b. §3b, the entry keys read with a full stop (entry_keys.run, D-201): a reader's 35. —) opened no entry, so the route dropped the section or filed its lines under the entry before. The stored lines decoded again with the key mended; the claims settled as §4's (disputed: Opus, stage keys_pass), and a claim filed under the entry before removed.
  2. §4, the offices regions read again (reread/consensus.csv): a claim every reader made, or the reader of record's on an entry only it reached, is added; a disputed one only where Opus (§6) rules it printed. A text code (no brackets: the cooperative letters, Notar, Adv., the continuation schools) goes to the abbreviations table, expanded from the volume's own code table, never to the pictogram inventory (0.4.0, D-196: 0.3.0 had filed 492 Böhmen and 155 Mähren text claims as pictograms).
  3. §6, Opus on outlined marks (opus_pass): on the Czech volume, see a ruling on a box below. On a German volume a box answer changes no claim (0.4.0, D-196): judged against the Czech volume, §6's box answers changed 223 German Böhmen claims and 211 of the changes were wrong — the box sat on the neighbouring glyph or the line above (D-118), so Opus read another glyph right and the merge filed it to the wrong municipality and deleted the true claim. Where Opus named something other than the route at a German box, both symbols are asked again of the whole entry (unasked.reask_items) and applied as entry answers, only once the tests that gate German entry answers have passed (unasked.passed). 3b. §6d, Opus on the marks the route never asked about (unasked, D-194): on the Czech volume its answers on outlined marks as rulings on a box; on a claim on the whole entry, printed adds the claim and not printed removes it, unless an outlined mark of the part still holds it — on a German volume, where every question is of the entry (D-196), even then. Applied only where its tests passed (unasked.passed). 3c. §6d's follow-up (unasked, D-195): where Opus found an outlined box empty or could not tell, the claims the readers made there, asked of the whole entry, applied as in 3b but not counting that box as holding the claim. Only where its gold test passed (followup_passed).
  4. The author, last: the hand-check page's look-alike rulings (as boxes), then the Unboxed poorhouses page's rulings on whole entries (apply_unboxed), then the Last Castle Rulings page's (apply_last, 0.4.1: the German Böhmen entries whose castle or poorhouse still disagreed with the Czech volume, and three schools a hand-check box filed under another number), then §6b's carry (author_carry.apply: typed symbols, relabels, codes outside the key, rulings made again).

A ruling on an entry (the Unboxed poorhouses page, 2026-11-07): the poorhouse claims the tables still carry on no outlined mark — the route settled them by asking about the whole entry, and §4's re-read has no boxes — so neither the hand-check page nor Opus could reach them. The author said what the entry prints of the pair: poorhouse, castle, both or neither. That is taken as the whole answer for the pair on that part: the member named is added where missing, the member not named is removed. Cannot find it changes nothing.

A ruling on a box (Opus's or the author's) names what is printed at one outlined mark of a part: its symbol is added to the part's table (the inventory for an offices box, the types for a box in the list of parts) where missing. The value the route had for the box is removed from the part only where nothing else holds it — no other mark of the inventory row, and no other box of the part with that value that no ruling overturned. One exception, for the look-alike pairs (poorhouse/castle, gamekeeper/huntsman), where the German route mostly settled a part by asking about the whole entry and so holds the claim on no box: on a part where a box is ruled one member of a pair and no box the other, the other member is replaced, not kept beside it — unless the route's own table already carried the ruled member on that part, in which case the entry holds both claims and the general rule applies (0.1.2: the swap had removed the poorhouse from 12 Böhmen parts the route read with both, the Czech volume printing it on 11). Cannot tell changes nothing, and nor does no symbol (0.2.1, D-118a): a box can sit off the glyph — on the German pages the locator puts boxes on entry numbers, Roman numerals and letters — so an empty box says nothing about the claim. 0.2.0 had read it as not printed and removed 180 claims (Böhmen 163, Czech 9, Mähren 8; 174 on Opus's answer, 6 on the hand check's), every reader naming the symbol on 141 of them; 8 of 8 Böhmen ones looked at sat on "8.", "12", "&", "R", a letter or a numeral.

Opus's rulings enter only if the §6 test passed (test_passed); otherwise steps 2's disputed claims and 3 are left out and the run says so.

class Tables:
    """The two tables being rebuilt, with every change logged."""

    def __init__(self, edition: str, inventory: list[dict], types: list[dict],
                 abbreviations: list[dict] | None = None, codes: dict | None = None):
        self.edition = edition
        self.rows = {"inventory": [dict(r) for r in inventory], "types": [dict(r) for r in types],
                     "abbreviations": [dict(r) for r in abbreviations or []]}
        self.codes = codes or {}               # the edition's text codes (``run_frozen.abbreviation_table``)
        self.changes: list[dict] = []
        self.route = {(table, _part(r), r["code"]) for table, rows in self.rows.items() for r in rows}
        self.courts = ac._court_of(inventory + types)
        self.readers = ac._readers_of(types)
        # A court label filed under one court only, anywhere in the run (0.5.0): a claim §3 moves to a
        # label the page itself never carried (Mladá Boleslav's parts on Sobotka's pages) finds its court.
        by_label = defaultdict(set)
        for (_page, district), (court, _how) in self.courts.items():
            if court:
                by_label[district].add(court)
        self.court_of_label = {d: next(iter(c)) for d, c in by_label.items() if len(c) == 1}

    def held(self, table: str, part: tuple) -> dict:
        return {r["code"]: r for r in self.rows[table] if _part(r) == part}

    def court(self, page: str, district: str) -> tuple[str, str]:
        """``(court_id, court_source)`` for a section: as the route filed it on the page, else by its
        label where the label names one court in the whole run, else none."""
        court, how = self.courts.get((page, district), ("", ""))
        if not court and district in self.court_of_label:
            return self.court_of_label[district], "court label (merge 0.5.0)"
        return court, how

    def move(self, step, table, part, new, code, why_from, why_to) -> bool:
        """Move the row ``code`` holds on ``part`` to ``new``, its count, marks and fields kept;
        ``False`` where ``part`` holds no such row. Logged as a removal and an addition."""
        row = self.held(table, part).get(code)
        if row is None:
            return False
        self.rows[table] = [r for r in self.rows[table] if not (_part(r) == part and r["code"] == code)]
        self._log(step, table, "remove", part, code, why_from)
        if code in self.held(table, new):
            return True                                   # the new place holds it already
        page, district, muni, seq = new
        court, how = self.court(page, district)
        self.rows[table].append(dict(row, page=page, district=district, court_id=court, court_source=how,
                                     muni_seq=muni, settlement_seq=seq,
                                     entry="/".join((page, court or district, muni, seq))))
        self._log(step, table, "add", new, code, why_to)
        return True

    def _log(self, step, table, action, part, code, reason, mark=""):
        page, district, muni, seq = part
        self.changes.append({"edition": self.edition, "step": step, "table": table, "action": action,
                             "page": page, "district": district, "muni_seq": muni, "settlement_seq": seq,
                             "code": code, "reason": reason, "mark": mark})

    def add(self, step, table, part, code, reason, mark="", extra: dict | None = None):
        if code in NOT_A_SYMBOL or code in self.held(table, part):
            return False
        if table == "inventory" and not code.startswith("["):
            return False                                  # a text code is never a pictogram (0.5.0)
        page, district, muni, seq = part
        court, how = self.court(page, district)
        row = {"entry": "/".join((page, court or district, muni, seq)), "page": page, "district": district,
               "court_id": court, "court_source": how, "muni_seq": muni, "settlement_seq": seq, "code": code}
        if table == "inventory":
            row.update(count="1", count_source=step, rule=f"{step}: {reason}", marks=mark)
        elif table == "abbreviations":
            a = self.codes.get(code)
            if a is None:
                return False
            row.update(count="1", count_source=f"{step} (the count was not read)", expansion=a.expansion,
                       english=a.english, category=a.category, kind=a.kind,
                       establishment=a.kind in rf.ESTABLISHMENT_KINDS, qualifier="", language_suffix="",
                       language_counts="", rule=f"{step}: {reason}", support="")
            row.update(extra or {})
        else:
            row.update(rule=f"{step}: {reason}", support=f"0 of {self.readers}" if self.readers else "")
        self.rows[table].append(row)
        self._log(step, table, "add", part, code, reason, mark)
        return True

    def remove(self, step, table, part, code, reason, mark=""):
        before = len(self.rows[table])
        self.rows[table] = [r for r in self.rows[table] if not (_part(r) == part and r["code"] == code)]
        if len(self.rows[table]) < before:
            self._log(step, table, "remove", part, code, reason, mark)
            return True
        return False

    def sorted(self, table: str) -> list[dict]:
        return sorted(self.rows[table], key=lambda r: (r["page"], r["district"], int(r["muni_seq"]),
                                                        str(r["settlement_seq"]), r["code"]))

def apply_box_rulings(t: Tables, step: str, rulings: list[dict], marks: dict, pairs: list[tuple]) -> None:
    """``rulings`` — ``{mark, value, who}``; ``marks`` — the ledger's marks table by mark (part,
    final). See the module docstring for the rule."""
    boxes_of = defaultdict(list)                      # part -> the part's outlined marks
    for mark, m in marks.items():
        if mark.split("#")[0].endswith(".png"):
            boxes_of[(m["page"], m["district"], str(m["muni"]), str(m["seq"]))].append((mark, m["final"]))
    by_part = defaultdict(list)
    for r in rulings:
        m = marks.get(r["mark"])
        if m is None or r["value"] in (tb.UNSURE, led.UNSURE, ""):
            continue
        value = led.ABSENT if r["value"] == tb.NONE else r["value"]
        if value == led.ABSENT:
            continue                                  # no symbol at the box: no ruling (D-118a, 0.2.1)
        part =(m["page"], m["district"], str(m["muni"]), str(m["seq"]))
        table = "types" if "_parts_" in r["mark"].split("#")[0] else "inventory"
        by_part[(table, part)].append((r["mark"], m["final"], value, r["who"]))
    for (table, part), rs_ in by_part.items():
        ruled = {mark for mark, _f, _v, _w in rs_}
        values = {v for _m, _f, v, _w in rs_}
        # other boxes of the part that still hold a value (no ruling overturned them)
        others = Counter(final for mark, final in boxes_of[part]
                         if mark not in ruled and final not in NOT_A_SYMBOL
                         and (("_parts_" in mark) == (table == "types")))
        for mark, final, value, who in rs_:
            if value not in NOT_A_SYMBOL:
                t.add(step, table, part, value, f"{who} at the outlined mark", mark)
            # The box's old value: the ledger's, and every claim that cites this box — the D-169
            # position rule relabels after the ledger, so a castle can stand on a box the ledger calls
            # a poorhouse (0.5.0; Tannwald 4/0).
            cited = [c for c, r in t.held(table, part).items() if mark in r.get("marks", "").split(" | ")]
            for was in dict.fromkeys([final, *cited]):
                if was in NOT_A_SYMBOL or was == value or was in values or others.get(was):
                    continue
                row = t.held(table, part).get(was)
                if row is None:
                    continue
                support = set(filter(None, row.get("marks", "").split(" | "))) - ruled
                pair = next((p for p in pairs if was in p and value in p), None)
                if pair and (table, part, value) in t.route:
                    pair = None                       # the route read both: two claims, not one misread
                if not support or pair:
                    t.remove(step, table, part, was, f"{who}: {value if value != led.ABSENT else 'no symbol'} at its mark"
                             + (" (look-alike pair)" if pair and support else ""), mark)

def apply_resplit(t: Tables, edition: str, out: Path) -> None:
    """§3: a route row every reader's re-split loses. Where the re-split files the same claim under
    another court on the same page (a missed court heading), it moves there; a place type is dropped
    (parts lines decoded as offices); any other claim is kept, the loss noted."""
    lost = resplit_removals(edition, out)
    path = Path(out) / edition / "resplit" / "consensus.csv"
    consensus = [r for r in (_read(path) if path.exists() else []) if r["status"] in ("agreed", "reader of record")]
    elsewhere = {(r["page"], r["muni_seq"], r["settlement_seq"], r["code"]): r["district"] for r in consensus}
    read_there = {(r["page"], r["district"], str(r["muni_seq"]), str(r["settlement_seq"])) for r in consensus}
    types = settlement_codes()
    # 0.5.0: a part the re-split files under another court, and reads nothing of under the old one,
    # moves whole — every row of the inventory and the abbreviations, its count and marks kept — so a
    # glyph the route read with another code (a D-169 castle) does not stay behind at the old court.
    moved = {}
    for key in lost:
        other = elsewhere.get((key[0], key[2], key[3], key[4]))
        if other and other != key[1] and key[:4] not in read_there:
            moved.setdefault(key[:4], other)
    for part, other in sorted(moved.items()):
        new = (part[0], other, part[2], part[3])
        for table in ("inventory", "abbreviations"):
            for code in sorted(t.held(table, part)):
                t.move("§3", table, part, new, code, f"moved: the re-split files the part under {other}",
                       f"moved from {part[1]} (a missed court heading)")
    for key in sorted(lost):
        part, code = key[:4], key[4]
        if part in moved:
            continue
        other = elsewhere.get((key[0], key[2], key[3], code))
        if other and other != key[1]:
            table = "inventory" if code.startswith("[") else "abbreviations"     # a text code is no pictogram
            if not t.move("§3", table, part, (key[0], other, key[2], key[3]), code,
                          f"moved: the re-split files it under {other}", f"moved from {key[1]} (a missed court heading)"):
                t._log("§3", table, "kept", part, code, f"the re-split files it under {other}, but the route holds no such row here")
        elif code in types:
            t.remove("§3", "inventory", part, code, "a place type: parts lines decoded as offices")
        else:
            t._log("§3", "inventory", "kept", part, code, "every reader's re-split loses it, but no other court holds it")

def apply_keys(t: Tables, edition: str, out: Path, tokens: dict) -> None:
    """§3b (``entry_keys``, D-201): a route claim filed under the entry before the one whose key a
    reader wrote with a full stop is removed; the mended decode's claims are added as §4's are —
    agreed, or the reader of record's where only it reached the entry, or disputed and ruled
    printed by Opus (``tokens``) — a text code to the abbreviations, with its language letter."""
    folder = Path(out) / edition / ek.SUB
    if not (folder / "consensus.csv").exists():
        return
    for r in _read(folder / "removes.csv"):
        table = "inventory" if r["code"].startswith("[") else "abbreviations"
        t.remove("§3b", table, _part(r), r["code"], ek.REMOVE_REASON)

            continue

        table = "inventory" if code.startswith("[") else "abbreviations"
        if table == "abbreviations" and code not in t.codes:
            t._log("§3b", table, "skip", part, code, "a key read with a full stop: not a text code of the volume")

        elif tokens.get((part, code)) == tb.PRINTED:
            t.add("§3b", table, part, code, "a key read with a full stop: disputed, Opus rules it printed", extra=extra)

def opus_answers(edition: str, stage: str, out: Path) -> tuple[list[dict], dict]:
    """``(box rulings, {(part, token): answer})`` from a §6 stage's items and answers."""
    folder = Path(out) / edition / stage
    if not (folder / "items.json").exists() or not (folder / "answers_raw.csv").exists():
        return [], {}
    items = {i["id"]: i for i in json.loads((folder / "items.json").read_text("utf-8"))}
    boxes, tokens = [], {}
    for a in _read(folder / "answers_raw.csv"):
        item = items.get(a["item"])
        if item is None:
            continue
        q = next((q for q in item["questions"] if str(q["n"]) == str(a["question"])), None)
        if q is None:
            continue
        if q["kind"] == "mark":
            boxes.append({"mark": led.box_mark(q["image"], ",".join(map(str, q["box"]))),
                          "value": a["answer"], "who": "Opus"})
        else:
            tokens[(tuple(item["unit"]), q["token"])] = a["answer"]
    return boxes, tokens

def reread_language_letters(folder: Path, edition: str = "") -> dict:
    """``{(page, district, muni, seq, code): letter}``: the language letter §4's readers saw glued to

    """Read the correction pass under ``out``, write the rechecked tables under ``dest`` (``out``)."""
    run = rf.out_dir(edition, PAGES)
    abbreviations = _read(run / "final_abbreviations.csv") if (run / "final_abbreviations.csv").exists() else None
    t = Tables(edition, _read(run / "final_inventory.csv"), _read(run / "final_types.csv"),
               abbreviations, rf.abbreviation_table(edition))
    german = edition in rf.GERMAN
    marks = {m["mark"]: m for m in _read(run / "ledger" / f"marks_{edition}_{PAGES}.csv")}
    pairs = [(g["a"], g["b"]) for g in json.loads((df.CHECKS / "hand_check_groups.json").read_text("utf-8"))
             if g["edition"] == edition]
    opus_ok = bool(test_passed(out))
    # 1. §3
    if edition in rf.GERMAN:
        apply_resplit(t, edition, out)
    # 1b. §3b, the entry keys read with a full stop (0.6.0, D-201); its disputed adds on Opus's word
    if edition in rf.GERMAN:
        apply_keys(t, edition, out, opus_answers(edition, ek.STAGE, out)[1] if opus_ok else {})
    # 2. §4 (+ Opus's token rulings)
    boxes, tokens = opus_answers(edition, "opus_pass", out) if opus_ok else ([], {})
    consensus = Path(out) / edition / orr.SUB / "consensus.csv"
    letters = reread_language_letters(Path(out) / edition / orr.SUB, edition)
    for c in (_read(consensus) if consensus.exists() else []):

        table = "inventory" if c["code"].startswith("[") else "abbreviations"
        if table == "abbreviations" and c["code"] not in t.codes:
            t._log("§4", table, "skip", part, c["code"], "offices read again: not a text code of the volume")
            continue

        if c["status"] in ("agreed", "reader of record"):
            t.add("§4", table, part, c["code"], f"offices read again: {c['status']}", extra=extra)
        elif tokens.get((part, c["code"])) == tb.PRINTED:
            t.add("§4", table, part, c["code"], "offices read again: disputed, Opus rules it printed", extra=extra)
    # 3. §6: on a German volume no box answer changes a claim; its disagreements, asked of the entry

class Tables:
    """The two tables being rebuilt, with every change logged."""

    def __init__(self, edition: str, inventory: list[dict], types: list[dict],
                 abbreviations: list[dict] | None = None, codes: dict | None = None):
        self.edition = edition
        self.rows = {"inventory": [dict(r) for r in inventory], "types": [dict(r) for r in types],
                     "abbreviations": [dict(r) for r in abbreviations or []]}
        self.codes = codes or {}               # the edition's text codes (``run_frozen.abbreviation_table``)
        self.changes: list[dict] = []
        self.route = {(table, _part(r), r["code"]) for table, rows in self.rows.items() for r in rows}
        self.courts = ac._court_of(inventory + types)
        self.readers = ac._readers_of(types)
        # A court label filed under one court only, anywhere in the run (0.5.0): a claim §3 moves to a
        # label the page itself never carried (Mladá Boleslav's parts on Sobotka's pages) finds its court.
        by_label = defaultdict(set)
        for (_page, district), (court, _how) in self.courts.items():
            if court:
                by_label[district].add(court)
        self.court_of_label = {d: next(iter(c)) for d, c in by_label.items() if len(c) == 1}

    def held(self, table: str, part: tuple) -> dict:
        return {r["code"]: r for r in self.rows[table] if _part(r) == part}

    def court(self, page: str, district: str) -> tuple[str, str]:
        """``(court_id, court_source)`` for a section: as the route filed it on the page, else by its
        label where the label names one court in the whole run, else none."""
        court, how = self.courts.get((page, district), ("", ""))
        if not court and district in self.court_of_label:
            return self.court_of_label[district], "court label (merge 0.5.0)"
        return court, how

    def move(self, step, table, part, new, code, why_from, why_to) -> bool:
        """Move the row ``code`` holds on ``part`` to ``new``, its count, marks and fields kept;
        ``False`` where ``part`` holds no such row. Logged as a removal and an addition."""
        row = self.held(table, part).get(code)
        if row is None:
            return False
        self.rows[table] = [r for r in self.rows[table] if not (_part(r) == part and r["code"] == code)]
        self._log(step, table, "remove", part, code, why_from)
        if code in self.held(table, new):
            return True                                   # the new place holds it already
        page, district, muni, seq = new
        court, how = self.court(page, district)
        self.rows[table].append(dict(row, page=page, district=district, court_id=court, court_source=how,
                                     muni_seq=muni, settlement_seq=seq,
                                     entry="/".join((page, court or district, muni, seq))))
        self._log(step, table, "add", new, code, why_to)
        return True

    def _log(self, step, table, action, part, code, reason, mark=""):
        page, district, muni, seq = part
        self.changes.append({"edition": self.edition, "step": step, "table": table, "action": action,
                             "page": page, "district": district, "muni_seq": muni, "settlement_seq": seq,
                             "code": code, "reason": reason, "mark": mark})

    def add(self, step, table, part, code, reason, mark="", extra: dict | None = None):
        if code in NOT_A_SYMBOL or code in self.held(table, part):
            return False
        if table == "inventory" and not code.startswith("["):
            return False                                  # a text code is never a pictogram (0.5.0)
        page, district, muni, seq = part
        court, how = self.court(page, district)
        row = {"entry": "/".join((page, court or district, muni, seq)), "page": page, "district": district,
               "court_id": court, "court_source": how, "muni_seq": muni, "settlement_seq": seq, "code": code}
        if table == "inventory":
            row.update(count="1", count_source=step, rule=f"{step}: {reason}", marks=mark)
        elif table == "abbreviations":
            a = self.codes.get(code)
            if a is None:
                return False
            row.update(count="1", count_source=f"{step} (the count was not read)", expansion=a.expansion,
                       english=a.english, category=a.category, kind=a.kind,
                       establishment=a.kind in rf.ESTABLISHMENT_KINDS, qualifier="", language_suffix="",
                       language_counts="", rule=f"{step}: {reason}", support="")
            row.update(extra or {})
        else:
            row.update(rule=f"{step}: {reason}", support=f"0 of {self.readers}" if self.readers else "")
        self.rows[table].append(row)
        self._log(step, table, "add", part, code, reason, mark)
        return True

    def remove(self, step, table, part, code, reason, mark=""):
        before = len(self.rows[table])
        self.rows[table] = [r for r in self.rows[table] if not (_part(r) == part and r["code"] == code)]
        if len(self.rows[table]) < before:
            self._log(step, table, "remove", part, code, reason, mark)
            return True
        return False

    def sorted(self, table: str) -> list[dict]:
        return sorted(self.rows[table], key=lambda r: (r["page"], r["district"], int(r["muni_seq"]),
                                                        str(r["settlement_seq"]), r["code"]))

def apply_box_rulings(t: Tables, step: str, rulings: list[dict], marks: dict, pairs: list[tuple]) -> None:
    """``rulings`` — ``{mark, value, who}``; ``marks`` — the ledger's marks table by mark (part,
    final). See the module docstring for the rule."""
    boxes_of = defaultdict(list)                      # part -> the part's outlined marks
    for mark, m in marks.items():
        if mark.split("#")[0].endswith(".png"):
            boxes_of[(m["page"], m["district"], str(m["muni"]), str(m["seq"]))].append((mark, m["final"]))
    by_part = defaultdict(list)
    for r in rulings:
        m = marks.get(r["mark"])
        if m is None or r["value"] in (tb.UNSURE, led.UNSURE, ""):
            continue
        value = led.ABSENT if r["value"] == tb.NONE else r["value"]
        if value == led.ABSENT:
            continue                                  # no symbol at the box: no ruling (D-118a, 0.2.1)
        part =(m["page"], m["district"], str(m["muni"]), str(m["seq"]))
        table = "types" if "_parts_" in r["mark"].split("#")[0] else "inventory"
        by_part[(table, part)].append((r["mark"], m["final"], value, r["who"]))
    for (table, part), rs_ in by_part.items():
        ruled = {mark for mark, _f, _v, _w in rs_}
        values = {v for _m, _f, v, _w in rs_}
        # other boxes of the part that still hold a value (no ruling overturned them)
        others = Counter(final for mark, final in boxes_of[part]
                         if mark not in ruled and final not in NOT_A_SYMBOL
                         and (("_parts_" in mark) == (table == "types")))
        for mark, final, value, who in rs_:
            if value not in NOT_A_SYMBOL:
                t.add(step, table, part, value, f"{who} at the outlined mark", mark)
            # The box's old value: the ledger's, and every claim that cites this box — the D-169
            # position rule relabels after the ledger, so a castle can stand on a box the ledger calls
            # a poorhouse (0.5.0; Tannwald 4/0).
            cited = [c for c, r in t.held(table, part).items() if mark in r.get("marks", "").split(" | ")]
            for was in dict.fromkeys([final, *cited]):
                if was in NOT_A_SYMBOL or was == value or was in values or others.get(was):
                    continue
                row = t.held(table, part).get(was)
                if row is None:
                    continue
                support = set(filter(None, row.get("marks", "").split(" | "))) - ruled
                pair = next((p for p in pairs if was in p and value in p), None)
                if pair and (table, part, value) in t.route:
                    pair = None                       # the route read both: two claims, not one misread
                if not support or pair:
                    t.remove(step, table, part, was, f"{who}: {value if value != led.ABSENT else 'no symbol'} at its mark"
                             + (" (look-alike pair)" if pair and support else ""), mark)

def resplit_removals(edition: str, out: Path) -> set:

def apply_resplit(t: Tables, edition: str, out: Path) -> None:
    """§3: a route row every reader's re-split loses. Where the re-split files the same claim under
    another court on the same page (a missed court heading), it moves there; a place type is dropped
    (parts lines decoded as offices); any other claim is kept, the loss noted."""
    lost = resplit_removals(edition, out)
    path = Path(out) / edition / "resplit" / "consensus.csv"
    consensus = [r for r in (_read(path) if path.exists() else []) if r["status"] in ("agreed", "reader of record")]
    elsewhere = {(r["page"], r["muni_seq"], r["settlement_seq"], r["code"]): r["district"] for r in consensus}
    read_there = {(r["page"], r["district"], str(r["muni_seq"]), str(r["settlement_seq"])) for r in consensus}
    types = settlement_codes()
    # 0.5.0: a part the re-split files under another court, and reads nothing of under the old one,
    # moves whole — every row of the inventory and the abbreviations, its count and marks kept — so a
    # glyph the route read with another code (a D-169 castle) does not stay behind at the old court.
    moved = {}
    for key in lost:
        other = elsewhere.get((key[0], key[2], key[3], key[4]))
        if other and other != key[1] and key[:4] not in read_there:
            moved.setdefault(key[:4], other)
    for part, other in sorted(moved.items()):
        new = (part[0], other, part[2], part[3])
        for table in ("inventory", "abbreviations"):
            for code in sorted(t.held(table, part)):
                t.move("§3", table, part, new, code, f"moved: the re-split files the part under {other}",
                       f"moved from {part[1]} (a missed court heading)")
    for key in sorted(lost):
        part, code = key[:4], key[4]
        if part in moved:
            continue
        other = elsewhere.get((key[0], key[2], key[3], code))
        if other and other != key[1]:
            table = "inventory" if code.startswith("[") else "abbreviations"     # a text code is no pictogram
            if not t.move("§3", table, part, (key[0], other, key[2], key[3]), code,
                          f"moved: the re-split files it under {other}", f"moved from {key[1]} (a missed court heading)"):
                t._log("§3", table, "kept", part, code, f"the re-split files it under {other}, but the route holds no such row here")
        elif code in types:
            t.remove("§3", "inventory", part, code, "a place type: parts lines decoded as offices")
        else:
            t._log("§3", "inventory", "kept", part, code, "every reader's re-split loses it, but no other court holds it")

        table = "inventory" if r["code"].startswith("[") else "abbreviations"
        t.remove("§3b", table, _part(r), r["code"], ek.REMOVE_REASON)
    letters = reread_language_letters(folder, edition)
    for c in _read(folder / "consensus.csv"):
        if c["in_route"] == "True":
            continue
        part, code = _part(c), c["code"]
        table = "inventory" if code.startswith("[") else "abbreviations"
        if table == "abbreviations" and code not in t.codes:
            t._log("§3b", table, "skip", part, code, "a key read with a full stop: not a text code of the volume")
            continue
        extra = {"language_suffix": letters[part + (code,)]} if part + (code,) in letters else None
        if c["status"] in ("agreed", "reader of record"):
            t.add("§3b", table, part, code, f"a key read with a full stop: {c['status']}", extra=extra)
        elif tokens.get((part, code)) == tb.PRINTED:
            t.add("§3b", table, part, code, "a key read with a full stop: disputed, Opus rules it printed", extra=extra)


def opus_answers(edition: str, stage: str, out: Path) -> tuple[list[dict], dict]:
    """``(box rulings, {(part, token): answer})`` from a §6 stage's items and answers."""
    folder = Path(out) / edition / stage
    if not (folder / "items.json").exists() or not (folder / "answers_raw.csv").exists():
        return [], {}
    items = {i["id"]: i for i in json.loads((folder / "items.json").read_text("utf-8"))}
    boxes, tokens = [], {}
    for a in _read(folder / "answers_raw.csv"):
        item = items.get(a["item"])
        if item is None:
            continue
        q = next((q for q in item["questions"] if str(q["n"]) == str(a["question"])), None)
        if q is None:
            continue
        if q["kind"] == "mark":
            boxes.append({"mark": led.box_mark(q["image"], ",".join(map(str, q["box"]))),
                          "value": a["answer"], "who": "Opus"})
        else:
            tokens[(tuple(item["unit"]), q["token"])] = a["answer"]
    return boxes, tokens


def hand_box_rulings(edition: str) -> list[dict]:
    return [{"mark": r["mark"], "value": r["author"], "who": "you (hand check)"}
            for r in op.hand_rulings() if r["edition"] == edition]


def apply_entry_answers(t: Tables, step: str, answers: dict, marks: dict, ignore: frozenset = frozenset(),
                        why: str = "the route never asked", boxes_hold: bool = True) -> None:
    """§6d on claims on the whole entry: ``answers`` — ``{(part, token): answer}``. *Printed* adds
    the claim; *not printed* removes it unless an outlined mark of the part holds that value — not
    counting the marks in ``ignore`` (the follow-up's boxes Opus found empty, which hold the very
    claim asked), and none at all where ``boxes_hold`` is off (a German volume, D-196: its boxes
    say nothing reliable about a claim)."""
    types = settlement_codes()
    held = defaultdict(set)
    for mark, m in marks.items():
        if boxes_hold and mark.split("#")[0].endswith(".png") and mark not in ignore:
            held[(m["page"], m["district"], str(m["muni"]), str(m["seq"]))].add(m["final"])
    for (part, token), answer in sorted(answers.items()):
        part = tuple(map(str, part))
        table = "types" if token in types else "inventory"
        if answer == tb.PRINTED:
            t.add(step, table, part, token, f"Opus: printed for the part ({why})")
        elif answer == tb.ABSENT and token not in held[part]:
            t.remove(step, table, part, token, f"Opus: not printed for the part ({why})")


def unboxed_rulings(edition: str, folder: Path = UNBOXED) -> list[dict]:
    """The *Unboxed poorhouses* page's rulings for one edition: ``{part, verdict}``."""
    out = []
    for path in sorted(Path(folder).glob("*.json")):
        d = json.loads(path.read_text("utf-8"))
        if d.get("edition") == SHORT[edition]:
            out.append({"part": (d["page"], d["district"], str(d["muni"]), str(d["seq"])), "verdict": d["v"]})
    return out


def apply_unboxed(t: Tables, rulings: list[dict], who: str = "you") -> None:
    """A ruling on an entry: the pair member named is added, the one not named removed (see above)."""
    for r in rulings:
        printed = PRINTED_AT_ENTRY.get(r["verdict"])
        if printed is None:
            continue
        for code in ENTRY_PAIR:
            if code in printed:
                t.add("author", "inventory", r["part"], code, f"{who}: the entry prints it ({r['verdict']})")
            else:
                t.remove("author", "inventory", r["part"], code, f"{who}: the entry does not print it ({r['verdict']})")


def off_sealed(t: Tables, rulings: list[dict], sealed: set, where, what) -> list[dict]:
    """``rulings`` less those on a sealed page, each one left out logged as a *skip* (D-127).
    ``where(r)`` finds the ruling's place (``None``: unknown, kept), ``what(r, place)`` its
    ``(part, value)`` for the log."""
    kept = []
    for r in rulings:
        place = where(r)
        if place is None:
            kept.append(r)
            continue
        part, value = what(r, place)
        if part[0] in sealed:
            t._log("author", "inventory", "skip", part, value, "a sealed page: scored once, by your own transcription (D-127)")
        else:
            kept.append(r)
    return kept


def last_rulings(edition: str, folder: Path = LAST) -> list[dict]:
    """The *Last Castle Rulings* page's rulings for one edition: ``{part, card_part, verdict, school}``.
    ``part`` is the part the author chose, ``card_part`` the one the card was drawn on."""
    out = []
    for path in sorted(Path(folder).glob("*.json")):
        d = json.loads(path.read_text("utf-8"))
        if d.get("edition") != SHORT[edition]:
            continue
        entry = (d["page"], d["district"], str(d["muni"]))
        out.append({"part": entry + (str(d["seq"]),), "card_part": entry + (str(d.get("card_seq", d["seq"])),),
                    "verdict": d.get("v", ""), "school": d.get("school") or "", "add": d.get("add", ""),
                    "note": d.get("note", "")})
    return out


def apply_last(t: Tables, rulings: list[dict]) -> None:
    """The last page's rulings: the pair on the chosen part as on the *Unboxed poorhouses* page; where
    the author moved the ruling to another part, the card's own part loses the pair (the glyph is not
    its); a school answered *no* is removed from the card's part, *yes* kept."""
    who = "you (last castle page)"
    apply_unboxed(t, rulings, who)
    for r in rulings:
        if r["part"] != r["card_part"] and r["verdict"] in PRINTED_AT_ENTRY:
            for code in ENTRY_PAIR:
                t.remove("author", "inventory", r["card_part"], code, f"{who}: the glyph belongs to part {r['part'][3]}")
        if r["school"] == "no":
            t.remove("author", "inventory", r["card_part"], "[school]", f"{who}: no school printed for the entry")
        elif r["school"] == "yes":
            t.add("author", "inventory", r["card_part"], "[school]", f"{who}: a school printed for the entry")
        if r.get("add"):                                  # a symbol a note placed on a part no card offered
            t.add("author", "inventory", r["part"], r["add"], f"{who}: your note ({r.get('note', '')})")


def chat_rulings(edition: str, folder: Path = CHAT) -> list[dict]:
    """The rulings the author made in chat on an entry shown to him, one row each in ``rulings.csv``
    (``edition, page, district, muni, seq, code, verdict, ruled, note``): ``{part, code, verdict, note}``,
    *printed* or *not printed*."""
    path = Path(folder) / "rulings.csv"
    return [{"part": (r["page"], r["district"], str(r["muni"]), str(r["seq"])), "code": r["code"],
             "verdict": r["verdict"], "note": r.get("note", ""), "ruled": r.get("ruled", "")}
            for r in (_read(path) if path.exists() else []) if r["edition"] == edition]


def apply_chat(t: Tables, rulings: list[dict]) -> None:
    """A chat ruling sets one symbol on one part: *printed* adds it, *not printed* removes it."""
    for r in rulings:
        table = "inventory" if r["code"].startswith("[") else "abbreviations"
        where = r["ruled"] if r["ruled"].startswith("blind") else f"in chat, {r['ruled']}"
        why = f"you ({where}): {r['note']}" if r["note"] else f"you ({where})"
        if r["verdict"] == "printed":
            t.add("author", table, r["part"], r["code"], why)
        elif r["verdict"] == "not printed":
            t.remove("author", table, r["part"], r["code"], why)


def test_passed(out: Path = OUT) -> bool | None:
    """The §6 test's verdict as its cell wrote it (``<TEST_STAGE>_score.json``), or ``None``: the
    test of the call the pass sends (``opus_test_score.json`` is the first, pair-only test)."""
    path = Path(out) / f"{op.TEST_STAGE}_score.json"
    if not path.exists():
        return None
    rows = json.loads(path.read_text("utf-8"))
    return bool(rows) and any(r.get("judged", True) for r in rows) and all(r["passes"] for r in rows)   # 0.5.0


#: The letters a volume glues to a cooperative's code to give its language: the German volumes
#: *b* Czech, *d* German, *p* Polish; the Czech volume *č* Czech, *n* German (its route's
#: ``language_suffix``, ``lexikon_1910_institutions._COOP_SUFFIXES``; 0.6.3).
LANGUAGE_LETTERS = {"cz": "čn"}
GERMAN_LETTERS = "bdp"


def reread_language_letters(folder: Path, edition: str = "") -> dict:
    """``{(page, district, muni, seq, code): letter}``: the language letter §4's readers saw glued to
    a text code (``Rb``, ``Kd``; ``Rn``, ``Hč`` in the Czech volume), from the ``context`` of each
    reader's re-read; kept only where every reader that shows a letter shows the same one (0.5.0).
    The re-read's tables never carried it, so §4's cooperatives were written with none."""
    import re
    letters = LANGUAGE_LETTERS.get(edition, GERMAN_LETTERS)
    seen = defaultdict(set)
    for path in sorted(Path(folder).glob("inventory_*.csv")):
        for r in _read(path):
            code = r.get("code", "")
            if not code or code.startswith("["):
                continue
            found = set(re.findall(rf"(?<![^\W\d_]){re.escape(code)}([{letters}])(?![^\W\d_])", r.get("context", "")))
            if len(found) == 1:
                seen[(r["page"], r["district"], str(r["muni_seq"]), str(r["settlement_seq"]), code)] |= found
    return {k: next(iter(v)) for k, v in seen.items() if len(v) == 1}


def merge(edition: str, out: Path = OUT, dest: Path | None = None) -> dict:
    """Read the correction pass under ``out``, write the rechecked tables under ``dest`` (``out``)."""
    run = rf.out_dir(edition, PAGES)
    abbreviations = _read(run / "final_abbreviations.csv") if (run / "final_abbreviations.csv").exists() else None
    t = Tables(edition, _read(run / "final_inventory.csv"), _read(run / "final_types.csv"),
               abbreviations, rf.abbreviation_table(edition))
    german = edition in rf.GERMAN
    marks = {m["mark"]: m for m in _read(run / "ledger" / f"marks_{edition}_{PAGES}.csv")}
    pairs = [(g["a"], g["b"]) for g in json.loads((df.CHECKS / "hand_check_groups.json").read_text("utf-8"))
             if g["edition"] == edition]
    opus_ok = bool(test_passed(out))
    # 1. §3
    if edition in rf.GERMAN:
        apply_resplit(t, edition, out)
    # 1b. §3b, the entry keys read with a full stop (0.6.0, D-201); its disputed adds on Opus's word
    if edition in rf.GERMAN:
        apply_keys(t, edition, out, opus_answers(edition, ek.STAGE, out)[1] if opus_ok else {})
    # 2. §4 (+ Opus's token rulings)
    boxes, tokens = opus_answers(edition, "opus_pass", out) if opus_ok else ([], {})
    consensus = Path(out) / edition / orr.SUB / "consensus.csv"
    letters = reread_language_letters(Path(out) / edition / orr.SUB, edition)
    for c in (_read(consensus) if consensus.exists() else []):
        part = (c["page"], c["district"], str(c["muni_seq"]), str(c["settlement_seq"]))
        table = "inventory" if c["code"].startswith("[") else "abbreviations"
        if table == "abbreviations" and c["code"] not in t.codes:
            t._log("§4", table, "skip", part, c["code"], "offices read again: not a text code of the volume")
            continue
        extra = {"language_suffix": letters[part + (c["code"],)]} if part + (c["code"],) in letters else None
        if c["status"] in ("agreed", "reader of record"):
            t.add("§4", table, part, c["code"], f"offices read again: {c['status']}", extra=extra)
        elif tokens.get((part, c["code"])) == tb.PRINTED:
            t.add("§4", table, part, c["code"], "offices read again: disputed, Opus rules it printed", extra=extra)
    # 3. §6: on a German volume no box answer changes a claim; its disagreements, asked of the entry
    unasked_ok = ua.passed(out, edition)
    if not german:
        apply_box_rulings(t, "§6", boxes, marks, pairs)
    elif unasked_ok:
        _none, tokens_r = opus_answers(edition, ua.STAGE_REASK, out)
        apply_entry_answers(t, "§6 entry", tokens_r, marks, boxes_hold=False,
                            why="asked of the entry after §6's answer at the box")
    # 3b. §6d, only where its tests passed
    if unasked_ok:
        boxes_u, tokens_u = opus_answers(edition, ua.STAGE_PASS, out)
        if not german:
            apply_box_rulings(t, "§6d", boxes_u, marks, pairs)
        apply_entry_answers(t, "§6d", tokens_u, marks, boxes_hold=not german)
        # 3c. its follow-up: the claims behind the boxes it found empty, asked of the whole entry
        if not german and ua.followup_passed(out):
            _none, tokens_f = opus_answers(edition, ua.STAGE_FOLLOW, out)
            empty = frozenset(b["mark"] for b in boxes_u if b["value"] in ua.EMPTY)
            apply_entry_answers(t, "§6d follow-up", tokens_f, marks, ignore=empty,
                                why="its box held no symbol")
    # 4. the author — never on a sealed page: the sealed half is scored once, by the author's own
    #    transcription (D-127), so his eye there would grade itself in §8b (0.4.2)
    sealed = rf.sealed_pages(edition)
    hand = off_sealed(t, hand_box_rulings(edition), sealed, lambda r: marks.get(r["mark"]),
                      lambda r, m: ((m["page"], m["district"], str(m["muni"]), str(m["seq"])), r["value"]))
    apply_box_rulings(t, "author", hand, marks, pairs)
    apply_unboxed(t, off_sealed(t, unboxed_rulings(edition), sealed, lambda r: r, lambda r, _m: (r["part"], r["verdict"])))
    apply_last(t, off_sealed(t, last_rulings(edition), sealed, lambda r: r, lambda r, _m: (r["part"], r["verdict"])))
    apply_chat(t, off_sealed(t, chat_rulings(edition), sealed, lambda r: r, lambda r, _m: (r["part"], r["code"])))
    from utils.recheck import blind_sample as bs                      # imports this module: loaded here, not at the top
    apply_chat(t, off_sealed(t, bs.as_rulings(edition), sealed, lambda r: r, lambda r, _m: (r["part"], r["code"])))
    carry_path = Path(out) / edition / ac.FILE
    inventory, types = t.sorted("inventory"), t.sorted("types")
    if carry_path.exists():
        carry = _read(carry_path)
        inventory, types = ac.apply(inventory, types, carry)
        for c in carry:
            t._log("author", c["table"], c["action"], (c["page"], c["district"], c["muni_seq"], c["settlement_seq"]),
                   c["code"], c["reason"], c["mark"])
    folder = Path(dest or out) / edition
    folder.mkdir(parents=True, exist_ok=True)
    if abbreviations is not None:
        with open(folder / "final_abbreviations_rechecked.csv", "w", encoding="utf-8", newline="") as fh:
            w = csv.DictWriter(fh, fieldnames=rf.ABBREVIATION_FIELDS, lineterminator="\n", extrasaction="ignore")
            w.writeheader()
            w.writerows(t.sorted("abbreviations"))
    for name, rows in (("final_inventory_rechecked.csv", inventory), ("final_types_rechecked.csv", types)):
        fields = list(rows[0]) if rows else ["page"]
        with open(folder / name, "w", encoding="utf-8", newline="") as fh:
            w = csv.DictWriter(fh, fieldnames=fields, lineterminator="\n", extrasaction="ignore")
            w.writeheader()
            w.writerows(rows)
    with open(folder / "changes.csv", "w", encoding="utf-8", newline="") as fh:
        w = csv.DictWriter(fh, fieldnames=CHANGE_FIELDS, lineterminator="\n")
        w.writeheader()
        w.writerows(t.changes)
    summary = Counter((c["step"], c["table"], c["action"]) for c in t.changes)
    return {"edition": edition, "opus": ("left out on the boxes (a German volume, D-196); its token rulings used in §4"
                                         if german and opus_ok else "applied" if opus_ok
                                         else "left out (the §6 test has not passed)"),
            "reask": ("applied" if german and unasked_ok else "not a German volume" if not german
                      else "left out (the gold and Czech-volume tests have not passed)"),
            "unasked": "applied" if unasked_ok else "left out (its tests have not passed)",
            "unasked_followup": ("applied" if unasked_ok and not german and ua.followup_passed(out)
                                 else "a German volume asks no box" if german
                                 else "left out (its gold test has not passed)"),
            "abbreviations": (len(abbreviations), len(t.rows["abbreviations"])) if abbreviations is not None else None,
            "inventory": (len(_read(run / "final_inventory.csv")), len(inventory)),
            "types": (len(_read(run / "final_types.csv")), len(types)),
            "changes": {" ".join(k): v for k, v in sorted(summary.items())}}


def main(argv=None) -> int:
    ap = argparse.ArgumentParser(description=__doc__, formatter_class=argparse.RawDescriptionHelpFormatter)
    ap.add_argument("--edition", default="all", choices=(*EDITIONS, "all"))
    ap.add_argument("--out", default=str(OUT))
    ap.add_argument("--dest", default="")
    args = ap.parse_args(argv)
    if hasattr(sys.stdout, "reconfigure"):
        sys.stdout.reconfigure(encoding="utf-8")
    for ed in EDITIONS if args.edition == "all" else (args.edition,):
        print(merge(ed, Path(args.out), Path(args.dest) if args.dest else None))
    return 0
