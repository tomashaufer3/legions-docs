How it works

The single largest judgement call in the Czech→HISCO dictionary. rolník is 18 % of the sample and is coded 61110 General Farmer, HISCLASS 8 (the self-employed reading). The live alternative, 62105 Farm Worker, HISCLASS 12, would move a fifth of the Legion between social classes.

Neither of the project's other three checks can settle it. The German bridge confirms only that Landwirt → 61110, not that a Czech rolník is a Landwirt. OccCANINE is fed that same German gloss. CZ-ISCO does not contain the word. And education does not discriminate — rolník and domkář both sit at ~1.0–1.1 on the 0–4 scale, because schooling did not track landholding.

This check uses a primary source instead. The 1910 Volkszählung records, for every politický okres, the agricultural workforce split by Berufsstellung — permanent (Selbständige, working on their own account), tenants (Pächter), employees, workers (Arbeiter), day_laborers (Taglöhner), assisting_family_members. Those columns are already parsed into census_okres_1910.parquet.

The test is ecological and simple. If rolník names the self-employed farmer, then across okresy the number of legionnaires calling themselves rolník should track the okres's count of agricultural Selbständige, and should not track its count of agricultural Arbeiter / Taglöhner. If rolník names a hired hand, the opposite.

nádeník (day-labourer, coded 99920) is carried as a placebo: whatever the correlation structure does for rolník, nádeník must behave like the wage-labour columns, or the design is picking up okres size rather than occupational structure.

Run: python utils/reference_tools/occupations/run_census_berufsstellung_check.py Emits: nothing — prints the result for reference/VALIDATION_OCCUPATIONS.md. This is a validation script, never a pipeline input; it writes no file and touches no code column.

def run() -> pd.DataFrame:
    from utils.parsing.occupations import _norm

    L = pd.read_parquet(FIN / "persons" / "legionnaires_clean.parquet",
                        columns=["occupation", "birth_census_okres_id"])
    L["key"] = L["occupation"].map(_norm)
    L = L.dropna(subset=["birth_census_okres_id"])

    cen = pd.read_parquet(FIN / "census" / "census_okres_1910_pooled.parquet")
    key = "census_okres_id" if "census_okres_id" in cen.columns else "okres_id"
    need = OWNER + LABOUR + FAMILY + [TOTAL]
    missing = [c for c in need if c not in cen.columns]
    if missing:
        raise SystemExit(f"census panel is missing Beruf columns: {missing[:3]}")

    cen = cen[[key] + need].copy()
    cen["owner_n"] = cen[OWNER].sum(axis=1, min_count=1)
    cen["labour_n"] = cen[LABOUR].sum(axis=1, min_count=1)
    cen["family_n"] = cen[FAMILY].sum(axis=1, min_count=1)
    tot = cen[TOTAL].replace(0, np.nan)
    cen["owner_share"] = cen["owner_n"] / tot
    cen["labour_share"] = cen["labour_n"] / tot

    # legionnaire counts per okres
    births = L.groupby("birth_census_okres_id").size().rename("births")
    def cnt(k):
        return (L[L["key"].eq(k)].groupby("birth_census_okres_id").size()
                .rename(f"n_{k.replace(' ', '_')}"))

    d = pd.concat([births, cnt("rolník"), cnt("nádeník"), cnt("dělník")], axis=1).fillna(0)
    d = d[d["births"] >= MIN_BIRTHS]
    d.index.name = key
    d = d.reset_index().merge(cen, on=key, how="inner")

    d["rolnik_share"] = d["n_rolník"] / d["births"]
    d["nadenik_share"] = d["n_nádeník"] / d["births"]
    d["delnik_share"] = d["n_dělník"] / d["births"]

    print(f"  {len(d)} okresy with >= {MIN_BIRTHS} legionnaire births and census Beruf data")
    print(f"  agricultural workforce covered: {d[TOTAL].sum():,.0f} "
          f"({d['owner_n'].sum():,.0f} self-employed + tenants, "
          f"{d['labour_n'].sum():,.0f} workers + day-labourers)\n")

    rows = []
    for lab, col in (("rolník  share of births", "rolnik_share"),
                     ("nádeník share  (placebo)", "nadenik_share"),
                     ("dělník  share  (placebo)", "delnik_share")):
        r_own, n1 = _spearman(d[col], d["owner_share"])
        r_lab, _ = _spearman(d[col], d["labour_share"])
        rows.append({"legionnaire measure": lab,
                     "vs census SELF-EMPLOYED share": round(r_own, 3),
                     "vs census WAGE-LABOUR share": round(r_lab, 3),
                     "n okresy": n1})
    out = pd.DataFrame(rows)
    print(out.to_string(index=False))

    # Raw counts are not run as a test. Both census columns scale with how agricultural an
    # okres is, so `log n_rolník` correlates with both (beta +1.30 vs +1.22, r +0.59 vs
    # +0.53) and discriminates nothing. That is a size effect, not evidence, and it is
    # recorded here so nobody re-derives it and mistakes it for one.

    return d

The clean test: hold agriculture fixed on both sides.

The share-of-all-births measure above still carries a confound — an okres that is more agricultural produces more rolník whatever the word means. So restrict the legionnaire denominator to men already coded into HISCO major group 6 (agricultural, animal husbandry, forestry and fishing) and ask a within-agriculture question:

of this okres's farm-occupation legionnaires, what fraction are coded as
*self-employed farmers* (61110/61115) rather than as *hired agricultural labour*
(62xxx farm workers and servants, plus 99920 day-labourers)?

against the census's own within-agriculture split

Selbständige + Pächter  /  (Selbständige + Pächter + Arbeiter + Taglöhner).

Both sides are now compositions of the same population, so okres size and agricultural intensity cancel. If rolník names an owner the two should move together; if it names a hired hand they should move apart, because rolník dominates the numerator either way (18 % of the whole sample) and would then be sitting on the wrong side.

def run_composition() -> pd.DataFrame:
    """The clean test: hold agriculture fixed on *both* sides.

    The share-of-all-births measure above still carries a confound — an okres that is more
    agricultural produces more `rolník` whatever the word means. So restrict the
    legionnaire denominator to men already coded into **HISCO major group 6** (agricultural,
    animal husbandry, forestry and fishing) and ask a within-agriculture question:

        of this okres's farm-occupation legionnaires, what fraction are coded as
        *self-employed farmers* (61110/61115) rather than as *hired agricultural labour*
        (62xxx farm workers and servants, plus 99920 day-labourers)?

    against the census's own within-agriculture split

        Selbständige + Pächter  /  (Selbständige + Pächter + Arbeiter + Taglöhner).

    Both sides are now compositions of the same population, so okres size and agricultural
    intensity cancel. If `rolník` names an owner the two should move together; if it names
    a hired hand they should move apart, because `rolník` dominates the numerator either
    way (18 % of the whole sample) and would then be sitting on the wrong side.
    """
    from utils.parsing.occupations import _norm

    L = pd.read_parquet(FIN / "persons" / "legionnaires_clean.parquet",
                        columns=["occupation", "occupation_hisco", "occupation_hisco_major",
                                 "birth_census_okres_id"])
    L["key"] = L["occupation"].map(_norm)
    L = L.dropna(subset=["birth_census_okres_id", "occupation_hisco"])

    ag = L[L["occupation_hisco_major"].eq("6") | L["occupation_hisco"].eq("99920")].copy()
    # owner-side vs hired-side codes, by the coding under test
    owner_codes = {"61110", "61115"}
    ag["is_owner"] = ag["occupation_hisco"].isin(owner_codes)
    ag["is_hired"] = ~ag["is_owner"]

    g = ag.groupby("birth_census_okres_id").agg(
        ag_n=("is_owner", "size"), owner_leg=("is_owner", "sum"))
    g = g[g["ag_n"] >= MIN_BIRTHS]
    g["leg_owner_share"] = g["owner_leg"] / g["ag_n"]

    cen = pd.read_parquet(FIN / "census" / "census_okres_1910_pooled.parquet")
    key = "census_okres_id" if "census_okres_id" in cen.columns else "okres_id"
    cen = cen[[key] + OWNER + LABOUR].copy()
    cen["own"] = cen[OWNER].sum(axis=1, min_count=1)
    cen["lab"] = cen[LABOUR].sum(axis=1, min_count=1)
    cen["cen_owner_share"] = cen["own"] / (cen["own"] + cen["lab"]).replace(0, np.nan)

    g.index.name = key
    d = g.reset_index().merge(cen[[key, "cen_owner_share"]], on=key, how="inner")

    r, n = _spearman(d["leg_owner_share"], d["cen_owner_share"])
    pear = float(d["leg_owner_share"].corr(d["cen_owner_share"]))
    print(f"\n  within-agriculture composition test ({n} okresy, "
          f"{int(g['ag_n'].sum()):,} farm-occupation legionnaires)")
    print(f"    legionnaire self-employed share  vs  census Selbständige share")
    print(f"    Spearman r = {r:+.3f}   Pearson r = {pear:+.3f}")
    print(f"    legionnaire mean {d['leg_owner_share'].mean():.3f} "
          f"vs census mean {d['cen_owner_share'].mean():.3f}")

    lo = d.nsmallest(8, "cen_owner_share")[["cen_owner_share", "leg_owner_share"]].mean()
    hi = d.nlargest(8, "cen_owner_share")[["cen_owner_share", "leg_owner_share"]].mean()
    print(f"\n    8 most estate-dominated okresy: census owners {lo['cen_owner_share']:.3f} "
          f"-> legionnaire owners {lo['leg_owner_share']:.3f}")
    print(f"    8 most smallholder okresy:      census owners {hi['cen_owner_share']:.3f} "
          f"-> legionnaire owners {hi['leg_owner_share']:.3f}")

    # ── the level gap, and the one reading that closes it ────────────────────────────
    # 0.907 legionnaire vs 0.463 census is far too large to be coding drift alone, and the
    # obvious suspect is the census's own third category. `mithelfende Familienangehörige`
    # — sons and brothers working the family holding — are 1910's largest single group in
    # agriculture and are exactly who a 22-year-old volunteer saying `rolník` is likely to
    # be. They are neither Selbständige nor wage labour, and were excluded from both sides
    # above. Put them on the own-account side, where they economically belong (they work
    # their family's land, not an employer's, for no wage), and see what the census says.
    cen2 = pd.read_parquet(FIN / "census" / "census_okres_1910_pooled.parquet")
    k2 = "census_okres_id" if "census_okres_id" in cen2.columns else "okres_id"
    cen2 = cen2[[k2] + OWNER + LABOUR + FAMILY].copy()
    cen2["own_fam"] = cen2[OWNER + FAMILY].sum(axis=1, min_count=1)
    cen2["lab2"] = cen2[LABOUR].sum(axis=1, min_count=1)
    cen2["cen_ownfam_share"] = (
        cen2["own_fam"] / (cen2["own_fam"] + cen2["lab2"]).replace(0, np.nan))
    d2 = d.merge(cen2[[k2, "cen_ownfam_share"]], left_on=key, right_on=k2, how="inner")
    r2, n2 = _spearman(d2["leg_owner_share"], d2["cen_ownfam_share"])
    print(f"\n    counting assisting family members as own-account "
          f"(they work family land, not an employer's):")
    print(f"      census mean {d2['cen_ownfam_share'].mean():.3f} "
          f"vs legionnaire {d2['leg_owner_share'].mean():.3f}   "
          f"Spearman r = {r2:+.3f}  (n={n2})")
    print(f"      the level gap closes from "
          f"{d2['leg_owner_share'].mean() - d['cen_owner_share'].mean():+.3f} to "
          f"{d2['leg_owner_share'].mean() - d2['cen_ownfam_share'].mean():+.3f}")
    return d

from pathlib import Path

import numpy as np
import pandas as pd

ROOT = Path(__file__).resolve().parents[3]

A = "occ_occupation_class_a_land_forestry_byproducts_economically_active_"

# Berufsstellung columns, split into the two readings the test discriminates between.

LABOUR = [f"{A}workers", f"{A}day_laborers"]                 # Arbeiter + Taglöhner
FAMILY = [f"{A}assisting_family_members"]

MIN_BIRTHS = 30          # okresy thinner than this are noise, not evidence


def _spearman(x: pd.Series, y: pd.Series) -> tuple[float, int]:
    """Rank correlation, computed on the rows where both are present."""
    ok = x.notna() & y.notna()
    if ok.sum() < 10:
        return float("nan"), int(ok.sum())
    return float(x[ok].rank().corr(y[ok].rank())), int(ok.sum())

    ag = L[L["occupation_hisco_major"].eq("6") | L["occupation_hisco"].eq("99920")].copy()
    # owner-side vs hired-side codes, by the coding under test
    owner_codes = {"61110", "61115"}
    ag["is_owner"] = ag["occupation_hisco"].isin(owner_codes)
    ag["is_hired"] = ~ag["is_owner"]

    g = ag.groupby("birth_census_okres_id").agg(
        ag_n=("is_owner", "size"), owner_leg=("is_owner", "sum"))
    g = g[g["ag_n"] >= MIN_BIRTHS]
    g["leg_owner_share"] = g["owner_leg"] / g["ag_n"]

    cen = pd.read_parquet(FIN / "census" / "census_okres_1910_pooled.parquet")
    key = "census_okres_id" if "census_okres_id" in cen.columns else "okres_id"
    cen = cen[[key] + OWNER + LABOUR].copy()
    cen["own"] = cen[OWNER].sum(axis=1, min_count=1)
    cen["lab"] = cen[LABOUR].sum(axis=1, min_count=1)
    cen["cen_owner_share"] = cen["own"] / (cen["own"] + cen["lab"]).replace(0, np.nan)

    g.index.name = key
    d = g.reset_index().merge(cen[[key, "cen_owner_share"]], on=key, how="inner")

    r, n = _spearman(d["leg_owner_share"], d["cen_owner_share"])
    pear = float(d["leg_owner_share"].corr(d["cen_owner_share"]))
    print(f"\n  within-agriculture composition test ({n} okresy, "
          f"{int(g['ag_n'].sum()):,} farm-occupation legionnaires)")
    print(f"    legionnaire self-employed share  vs  census Selbständige share")
    print(f"    Spearman r = {r:+.3f}   Pearson r = {pear:+.3f}")
    print(f"    legionnaire mean {d['leg_owner_share'].mean():.3f} "
          f"vs census mean {d['cen_owner_share'].mean():.3f}")

    lo = d.nsmallest(8, "cen_owner_share")[["cen_owner_share", "leg_owner_share"]].mean()
    hi = d.nlargest(8, "cen_owner_share")[["cen_owner_share", "leg_owner_share"]].mean()
    print(f"\n    8 most estate-dominated okresy: census owners {lo['cen_owner_share']:.3f} "
          f"-> legionnaire owners {lo['leg_owner_share']:.3f}")
    print(f"    8 most smallholder okresy:      census owners {hi['cen_owner_share']:.3f} "
          f"-> legionnaire owners {hi['leg_owner_share']:.3f}")

    # ── the level gap, and the one reading that closes it ────────────────────────────
    # 0.907 legionnaire vs 0.463 census is far too large to be coding drift alone, and the
    # obvious suspect is the census's own third category. `mithelfende Familienangehörige`
    # — sons and brothers working the family holding — are 1910's largest single group in
    # agriculture and are exactly who a 22-year-old volunteer saying `rolník` is likely to
    # be. They are neither Selbständige nor wage labour, and were excluded from both sides
    # above. Put them on the own-account side, where they economically belong (they work
    # their family's land, not an employer's, for no wage), and see what the census says.
    cen2 = pd.read_parquet(FIN / "census" / "census_okres_1910_pooled.parquet")
    k2 = "census_okres_id" if "census_okres_id" in cen2.columns else "okres_id"
    cen2 = cen2[[k2] + OWNER + LABOUR + FAMILY].copy()
    cen2["own_fam"] = cen2[OWNER + FAMILY].sum(axis=1, min_count=1)
    cen2["lab2"] = cen2[LABOUR].sum(axis=1, min_count=1)
    cen2["cen_ownfam_share"] = (
        cen2["own_fam"] / (cen2["own_fam"] + cen2["lab2"]).replace(0, np.nan))
    d2 = d.merge(cen2[[k2, "cen_ownfam_share"]], left_on=key, right_on=k2, how="inner")
    r2, n2 = _spearman(d2["leg_owner_share"], d2["cen_ownfam_share"])
    print(f"\n    counting assisting family members as own-account "
          f"(they work family land, not an employer's):")
    print(f"      census mean {d2['cen_ownfam_share'].mean():.3f} "
          f"vs legionnaire {d2['leg_owner_share'].mean():.3f}   "
          f"Spearman r = {r2:+.3f}  (n={n2})")
    print(f"      the level gap closes from "
          f"{d2['leg_owner_share'].mean() - d['cen_owner_share'].mean():+.3f} to "
          f"{d2['leg_owner_share'].mean() - d2['cen_ownfam_share'].mean():+.3f}")
    return d
