How it works

The two volumes complete the crown-land set already in library/lexicons/ (UBW_Spezialortsrepertorium-Boehmen-1910_de.pdf and …-Maehren-1910_de.pdf, both German, from the Universitätsbibliothek Wien):

=========== ================================ ========================== Job Volume Host / API =========== ================================ ========================== msvk Special-Orts-Repertorium von kramerius.msvk.cz Schlesien (122 pp., German) Kramerius 7 ndk Podrobný seznam míst zemí ndk.cz rakouských … IX. Čechy Kramerius 5 (756 pp., Czech ed. of Böhmen) =========== ================================ ==========================

Two different Kramerius generations, hence two different downloader modules — scraper_kramerius7.py for MSVK and scraper_kramerius.py for NDK. (The ndk.cz viewer looks modern but its API is v5: /search/api/v5.0/item/{pid} answers, the v7 client path is a 404.)

Both jobs run concurrently — different hosts, so neither sees more load than if it ran alone — and each keeps the modules' own 20-pages-per-batch pacing with a 10 s rest between batches. Their tqdm bars are stacked, one line per volume::

Schlesien-1910_de  ██████████████░░░░░  96/122 [00:41<00:12, 2.1p/s]
Cechy-1910_cz      ████░░░░░░░░░░░░░░░ 179/756 [00:41<21:47, 0.4p/s]

Every page artefact is cached under &lt;name&gt;_pages/, so this is safe to interrupt and re-run: a second pass re-fetches nothing and just assembles the PDF/TXT. MSVK reports ocr.alto=false for its volume, so ALTO is not requested there; NDK has ALTO and keeps it. Neither host's certificate chain can be built from the local certifi bundle (curl and the Windows store are fine with both), so TLS verification is off for both jobs.

Usage::

python utils/scraping/run_lexicon_downloads.py
python utils/scraping/run_lexicon_downloads.py --only ndk
python utils/scraping/run_lexicon_downloads.py --serial --no-progress

def main(argv: list[str] | None = None) -> int:
    p = argparse.ArgumentParser(
        description=__doc__.split("\n\n")[0],
        formatter_class=argparse.ArgumentDefaultsHelpFormatter,
    )
    p.add_argument("--out", default=str(DEFAULT_OUT), help="output directory")
    p.add_argument("--only", choices=[j["key"] for j in JOBS], default=None,
                   help="run just one of the two volumes")
    p.add_argument("--serial", action="store_true",
                   help="run the jobs one after another instead of concurrently")
    p.add_argument("--no-progress", action="store_true",
                   help="no progress bars; log every 25 pages instead")
    p.add_argument("-v", "--verbose", action="store_true", help="debug logging")
    args = p.parse_args(argv)

    logging.basicConfig(level=logging.DEBUG if args.verbose else logging.INFO,
                        format="%(message)s")

    jobs = [j for j in JOBS if args.only is None or j["key"] == args.only]
    out_dir = Path(args.out)
    progress = not args.no_progress
    results: dict[str, dict | Exception] = {}

    if args.serial or len(jobs) == 1:
        for job in jobs:                    # one at a time -> one bar, no stacking
            try:
                results[job["key"]] = run_job(job, out_dir, position=None, progress=progress)
            except Exception as exc:                       # keep going; report at the end
                log.error("FAILED (%s): %s", job["key"], exc)
                results[job["key"]] = exc
    else:
        with ThreadPoolExecutor(max_workers=len(jobs)) as pool:
            futures = {
                job["key"]: pool.submit(run_job, job, out_dir,
                                        position=i, progress=progress)
                for i, job in enumerate(jobs)
            }
            for key, fut in futures.items():
                try:
                    results[key] = fut.result()
                except Exception as exc:
                    log.error("FAILED (%s): %s", key, exc)
                    results[key] = exc

    summarise(results)
    return 1 if any(isinstance(r, Exception) for r in results.values()) else 0

#!/usr/bin/env python3
"""
Download the two outstanding 1910 *Spezialortsrepertorium* volumes into
``library/lexicons/`` — one runner, one screen, one progress bar each.

The two volumes complete the crown-land set already in ``library/lexicons/``
(``UBW_Spezialortsrepertorium-Boehmen-1910_de.pdf`` and
``…-Maehren-1910_de.pdf``, both German, from the Universitätsbibliothek Wien):

===========  ================================  ==========================
Job          Volume                            Host / API
===========  ================================  ==========================
``msvk``     *Special-Orts-Repertorium von     ``kramerius.msvk.cz``
             Schlesien* (122 pp., German)      Kramerius **7**
``ndk``      *Podrobný seznam míst zemí        ``ndk.cz``
             rakouských … IX. Čechy*           Kramerius **5**
             (756 pp., Czech ed. of Böhmen)
===========  ================================  ==========================

Two different Kramerius generations, hence two different downloader modules —
``scraper_kramerius7.py`` for MSVK and ``scraper_kramerius.py`` for NDK.  (The
``ndk.cz`` viewer looks modern but its API is v5: ``/search/api/v5.0/item/{pid}``
answers, the v7 client path is a 404.)

Both jobs run **concurrently** — different hosts, so neither sees more load than
if it ran alone — and each keeps the modules' own 20-pages-per-batch pacing with
a 10 s rest between batches.  Their ``tqdm`` bars are stacked, one line per
volume::

    Schlesien-1910_de  ██████████████░░░░░  96/122 [00:41<00:12, 2.1p/s]
    Cechy-1910_cz      ████░░░░░░░░░░░░░░░ 179/756 [00:41<21:47, 0.4p/s]

Every page artefact is cached under ``<name>_pages/``, so this is safe to
interrupt and re-run: a second pass re-fetches nothing and just assembles the
PDF/TXT.  MSVK reports ``ocr.alto=false`` for its volume, so ALTO is not
requested there; NDK has ALTO and keeps it.  Neither host's certificate chain
can be built from the local ``certifi`` bundle (curl and the Windows store are
fine with both), so TLS verification is off for both jobs.

Usage::

    python utils/scraping/run_lexicon_downloads.py
    python utils/scraping/run_lexicon_downloads.py --only ndk
    python utils/scraping/run_lexicon_downloads.py --serial --no-progress
"""

from __future__ import annotations

import argparse
import logging
import sys
from concurrent.futures import ThreadPoolExecutor
from pathlib import Path

try:  # importable as utils.scraping.run_lexicon_downloads …
    from utils.scraping import scraper_kramerius, scraper_kramerius7
except ImportError:  # … or run as a script from anywhere
    sys.path.insert(0, str(Path(__file__).resolve().parent))
    import scraper_kramerius  # type: ignore[no-redef]
    import scraper_kramerius7  # type: ignore[no-redef]

__version__ = "1.0.0"

log = logging.getLogger("run_lexicon_downloads")

# Repo root is two levels up from utils/scraping/, so the default output path
# holds wherever the script is launched from.
REPO_ROOT = Path(__file__).resolve().parents[2]
DEFAULT_OUT = REPO_ROOT / "library" / "lexicons"

JOBS: list[dict] = [
    {
        "key": "msvk",
        "module": scraper_kramerius7,                       # Kramerius 7
        "url": "https://kramerius.msvk.cz/view/uuid:522ce040-5386-11df-a073-0013d398622b",
        "name": "MSVK_Spezialortsrepertorium-Schlesien-1910_de",
        "desc": "Schlesien-1910_de",
        # host reports ocr.alto=false for this volume — asking would be 122 × 404
        "kwargs": {"save_alto": False},
    },
    {
        "key": "ndk",
        "module": scraper_kramerius,                        # Kramerius 5
        "url": "https://ndk.cz/view/uuid:c2d4a3a0-6fb2-11ec-bc36-005056827e51",
        "name": "NDK_Podrobny-seznam-mist-Cechy-1910_cz",
        "desc": "Cechy-1910_cz",
        # verify_tls=False for the same reason the v7 module defaults to it: the
        # local certifi bundle cannot build a chain for this host ("unable to get
        # local issuer certificate") even though curl and the Windows trust store
        # accept it.  Public-domain scans from a national library, so this only
        # costs authentication of the host, not of the content.
        "kwargs": {"save_alto": True, "per_page_txt": True, "keep_pages": True,
                   "verify_tls": False},
    },
]

_DESC_WIDTH = max(len(j["desc"]) for j in JOBS)


def run_job(job: dict, out_dir: Path, *, position: int, progress: bool) -> dict:
    """Run one download; returns the module's summary dict."""
    return job["module"].download_document(
        job["url"],
        out_dir=out_dir,
        name=job["name"],
        progress=progress,
        progress_position=position,
        progress_desc=job["desc"].ljust(_DESC_WIDTH),
        **job["kwargs"],
    )


def _fmt_size(path: str | None) -> str:
    if not path:
        return "—"
    p = Path(path)
    return f"{p.name} ({p.stat().st_size / 1e6:.0f} MB)" if p.exists() else p.name


def summarise(results: dict[str, dict | Exception]) -> None:
    print()
    print(f"{'job':<6} {'pages':>6} {'scans':>6} {'ocr':>6} {'alto':>6}  output")
    print("-" * 72)
    for key, res in results.items():
        if isinstance(res, Exception):
            print(f"{key:<6} {'FAILED':>6}  {res}")
            continue
        print(f"{key:<6} {res['pages']:>6} {res['images']:>6} {res['ocr_pages']:>6} "
              f"{res.get('alto_pages', 0):>6}  {_fmt_size(res.get('pdf'))}")
        if res.get("txt"):
            print(f"{'':<6} {'':>6} {'':>6} {'':>6} {'':>6}  {_fmt_size(res.get('txt'))}")


def main(argv: list[str] | None = None) -> int:
    p = argparse.ArgumentParser(
        description=__doc__.split("\n\n")[0],
        formatter_class=argparse.ArgumentDefaultsHelpFormatter,
    )
    p.add_argument("--out", default=str(DEFAULT_OUT), help="output directory")
    p.add_argument("--only", choices=[j["key"] for j in JOBS], default=None,
                   help="run just one of the two volumes")
    p.add_argument("--serial", action="store_true",
                   help="run the jobs one after another instead of concurrently")
    p.add_argument("--no-progress", action="store_true",
                   help="no progress bars; log every 25 pages instead")
    p.add_argument("-v", "--verbose", action="store_true", help="debug logging")
    args = p.parse_args(argv)

    logging.basicConfig(level=logging.DEBUG if args.verbose else logging.INFO,
                        format="%(message)s")

    jobs = [j for j in JOBS if args.only is None or j["key"] == args.only]
    out_dir = Path(args.out)
    progress = not args.no_progress
    results: dict[str, dict | Exception] = {}

    if args.serial or len(jobs) == 1:
        for job in jobs:                    # one at a time -> one bar, no stacking
            try:
                results[job["key"]] = run_job(job, out_dir, position=None, progress=progress)
            except Exception as exc:                       # keep going; report at the end
                log.error("FAILED (%s): %s", job["key"], exc)
                results[job["key"]] = exc
    else:
        with ThreadPoolExecutor(max_workers=len(jobs)) as pool:
            futures = {
                job["key"]: pool.submit(run_job, job, out_dir,
                                        position=i, progress=progress)
                for i, job in enumerate(jobs)
            }
            for key, fut in futures.items():
                try:
                    results[key] = fut.result()
                except Exception as exc:
                    log.error("FAILED (%s): %s", key, exc)
                    results[key] = exc

    summarise(results)
    return 1 if any(isinstance(r, Exception) for r in results.values()) else 0


if __name__ == "__main__":
    sys.exit(main())
