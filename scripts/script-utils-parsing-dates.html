TL;DR

Parses Czech date strings across four standalone date columns spanning the legionnaire (csol.cz) and VÚA fallen-soldier (vuapraha.cz) datasets, plus the date part of the legionnaire exit field (via parse_date, called from utils.parsing.exit_codes).

How it works

Each column is clipped to a historically plausible range after parsing; records outside the range become pd.NaT. A century-offset fix handles abbreviated 2-digit year formats (e.g. 6.12.19 → 1919-12-06).

Columns handled

Datum narození → birth_date (+ birth_year_only) Datum zajetí → capture_date (+ capture_date_precision) Datum zařazení do legií → enroll_date (+ enroll_date_precision) Datum úmrtí → death_date (+ death_year_only)

Only columns present in the DataFrame are processed, so the same function serves both datasets without modification.

Valid ranges

birth_date : 1860-01-01 – 1905-12-31 capture_date : 1914-01-01 – 1918-12-31 enroll_date : 1914-01-01 – 1922-12-31 death_date : 1914-01-01 – 1923-12-31 — war-period mortality only. For the VÚA fallen this is every record. For legionnaires it is not: of 12,480 raw Datum úmrtí values, 8,034 are deaths after 1923 (veterans who died in the interwar years and later), which fall outside the range and stay NaT here. The raw string survives as death_date_raw in the legionnaire file so nothing is lost (audit 2026-09-22 §B14). exit_date : 1914-01-01 – 1939-12-31 (see exit_codes)

Parsing pipeline (stops at first success per value)

  1. Try explicit formats DD.MM.YYYY then DD.MM.YY via strptime.
  2. Apply century fix: if parsed year > 1930 and year−100 falls in the column's valid range, subtract 100 (handles 6.12.19 → 1919). For the partial (event) columns the fix is symmetric: a year below the range whose +100 falls in it is a century slip too (8.1.1818 exit → 1918).
  3. If NaT, search for the first DD.MM.YYYY occurrence via regex — fixes double-date birth entries ("23.8.1890 23.9.1891" → 1890-08-23) and reads through a stray keystroke (20.8.18884 → 1888-08-20).
  4. Partial columns only (capture, enrolment, exit): a month-year M.YYYY → the first of that month, precision month (also rescues an impossible day, 29.2.1918 → February 1918).
  5. If NaT and the column allows it, match ^YYYY$ → Jan 1 of that year; precision year (birth/death: the *_year_only flag).
  6. If still NaT, take the first in-range four-digit YYYY anywhere — rescues double-year entries ("1899 (1889)" → 1899) and trailing-annotation years.
  7. Clip: if outside [lo, hi] → pd.NaT.

Until v1.2.0 steps 4–6 existed for birth and death only, so 2,440 capture and 2,463 enrolment strings that state a month or a year (4.1918, 1918) were dropped without a flag — the hazard model's entry time lost exactly where it is coarse, and silently (audit 2026-09-22 §B15). A *_precision column now says which dates are exact to the day.

Note: age strings such as "39 let" (age at death, VÚA birth column) cannot be resolved to a birth date without the death year and intentionally remain pd.NaT.

def parse_date(raw, lo: pd.Timestamp, hi: pd.Timestamp, year_only: bool = False,
               partial: bool = False) -> tuple[pd.Timestamp, str | None]:
    """Parse one raw value → ``(timestamp in [lo, hi] or NaT, precision)``.

    ``precision`` is ``"day"`` / ``"month"`` / ``"year"``, or ``None`` when nothing parsed.
    See the module docstring for the steps; ``partial`` enables the month-year fallback,
    the year fallbacks and the symmetric century fix.
    """
    if raw is None or (not isinstance(raw, str) and pd.isna(raw)):
        return pd.NaT, None
    s = str(raw).strip()
    if s in ("", "?", "-"):
        return pd.NaT, None

    # Step 1: explicit format parse
    ts = _century_fix(_try_formats(s), lo, hi, upward=partial)
    if pd.notna(ts) and lo <= ts <= hi:
        return ts, "day"

    # Step 3: first DD.MM.YYYY substring
    m = _FULL_DATE_RE.search(s)
    if m:
        ts = _century_fix(_try_formats(m.group(0)), lo, hi, upward=partial)
        if pd.notna(ts) and lo <= ts <= hi:
            return ts, "day"
        if partial and pd.isna(ts):
            # a full date whose day does not exist (29.2.1918): the month and year stand
            _d, mon, yr = (int(x) for x in m.group(0).split("."))
            if 1 <= mon <= 12 and 1800 <= yr <= 2100:
                t = _century_fix(pd.Timestamp(year=yr, month=mon, day=1), lo, hi, upward=True)
                if pd.notna(t) and lo <= t <= hi:
                    return t, "month"

    # Step 4: month-year (event dates)
    if partial:
        for mm in _MONTH_YEAR_RE.finditer(s):
            mon, yr = int(mm.group(1)), int(mm.group(2))
            if 1 <= mon <= 12 and 1800 <= yr <= 2100:
                t = _century_fix(pd.Timestamp(year=yr, month=mon, day=1), lo, hi, upward=True)
                if pd.notna(t) and lo <= t <= hi:
                    return t, "month"

    if not (year_only or partial):
        return pd.NaT, None

    # Step 5: bare year-only
    if _YEAR_ONLY_RE.match(s) and 1800 <= int(s) <= 2100:
        t = _century_fix(pd.Timestamp(f"{s}-01-01"), lo, hi, upward=partial)
        if pd.notna(t) and lo <= t <= hi:
            return t, "year"

    # Step 6: first in-range four-digit year anywhere
    for m in _YEAR_SEARCH_RE.finditer(s):
        y = int(m.group(0))
        if lo.year <= y <= hi.year:
            return pd.Timestamp(f"{y}-01-01"), "year"

    return pd.NaT, None

def add_date_columns(
    df: pd.DataFrame,
    source_cols: list[str] | None = None,
) -> pd.DataFrame:
    """Parse date columns and append cleaned timestamp columns.

    Added columns (those whose source column is present)
    ----------------------------------------------------
    birth_date              pd.Timestamp / NaT  — from ``Datum narození``
    birth_year_only         bool                — True when a year-only fallback was used
    capture_date            pd.Timestamp / NaT  — from ``Datum zajetí``
    capture_date_precision  day / month / year  — <NA> where nothing parsed
    enroll_date             pd.Timestamp / NaT  — from ``Datum zařazení do legií``
    enroll_date_precision   day / month / year  — <NA> where nothing parsed
    death_date              pd.Timestamp / NaT  — from ``Datum úmrtí``
    death_year_only         bool                — True when a year-only fallback was used

    Parameters
    ----------
    df:
        Input DataFrame (not modified in place).
    source_cols:
        Restrict parsing to a subset of source columns.  Defaults to all
        four configured columns.

    Returns
    -------
    pd.DataFrame
        Copy of *df* with date columns appended.
    """
    df = df.copy()
    config = _COLUMN_CONFIG
    if source_cols is not None:
        config = {k: v for k, v in config.items() if k in source_cols}

    for src_col, (out_col, lo, hi, year_only, partial) in config.items():
        if src_col not in df.columns:
            continue
        results = df[src_col].apply(
            lambda raw, lo=lo, hi=hi, yo=year_only, pa=partial:
                parse_date(raw, lo, hi, year_only=yo, partial=pa)
        )
        df[out_col] = pd.to_datetime(results.apply(lambda t: t[0]))
        if year_only and src_col in _YEAR_ONLY_FLAG:
            df[_YEAR_ONLY_FLAG[src_col]] = results.apply(lambda t: t[1] == "year")
        if partial:
            df[f"{out_col}_precision"] = results.apply(lambda t: t[1]).astype("string")

    return df

def date_report(df: pd.DataFrame) -> None:
    """Print a coverage table for each parsed date column."""
    print(f"Date column report  (N = {len(df):,})\n")

    for src_col, (out_col, lo, hi, year_only, partial) in _COLUMN_CONFIG.items():
        if out_col not in df.columns:
            continue

        n_raw_miss = df[src_col].isna().sum() if src_col in df.columns else 0
        n_valid    = df[out_col].notna().sum()
        n_failed   = len(df) - n_valid - n_raw_miss
        n          = len(df)

        print(f"  {src_col}  →  {out_col}")
        print(f"    {'Valid (in range)':<26}: {n_valid:>7,}  ({n_valid/n:.1%})")

        flag_col = _YEAR_ONLY_FLAG.get(src_col)
        if year_only and flag_col and flag_col in df.columns:
            n_yo = df[flag_col].sum()
            print(f"    {'  of which year-only':<26}: {n_yo:>7,}  ({n_yo/n:.1%})")
        prec_col = f"{out_col}_precision"
        if partial and prec_col in df.columns:
            vc = df[prec_col].value_counts()
            print(f"    {'  precision':<26}: " + ", ".join(
                f"{p} {int(vc.get(p, 0)):,}" for p in PRECISIONS))

        print(f"    {'Failed / out of range':<26}: {n_failed:>7,}  ({n_failed/n:.1%})")
        print(f"    {'Raw missing':<26}: {n_raw_miss:>7,}  ({n_raw_miss/n:.1%})")
        print()

"""
dates.py — Date column cleaning
================================
Parses Czech date strings across four standalone date columns spanning the
legionnaire (csol.cz) and VÚA fallen-soldier (vuapraha.cz) datasets, plus the
date part of the legionnaire exit field (via :func:`parse_date`, called from
:mod:`utils.parsing.exit_codes`).

Each column is clipped to a historically plausible range after parsing;
records outside the range become ``pd.NaT``.  A century-offset fix handles
abbreviated 2-digit year formats (e.g. ``6.12.19`` → 1919-12-06).

Columns handled
---------------
``Datum narození``          → ``birth_date``    (+ ``birth_year_only``)
``Datum zajetí``            → ``capture_date``  (+ ``capture_date_precision``)
``Datum zařazení do legií`` → ``enroll_date``   (+ ``enroll_date_precision``)
``Datum úmrtí``             → ``death_date``    (+ ``death_year_only``)

Only columns present in the DataFrame are processed, so the same function
serves both datasets without modification.

Valid ranges
------------
birth_date    : 1860-01-01 – 1905-12-31
capture_date  : 1914-01-01 – 1918-12-31
enroll_date   : 1914-01-01 – 1922-12-31
death_date    : 1914-01-01 – 1923-12-31  — **war-period mortality only.** For the VÚA
                fallen this is every record. For legionnaires it is not: of 12,480 raw
                ``Datum úmrtí`` values, 8,034 are deaths after 1923 (veterans who died in
                the interwar years and later), which fall outside the range and stay
                ``NaT`` here. The raw string survives as ``death_date_raw`` in the
                legionnaire file so nothing is lost (audit 2026-09-22 §B14).
exit_date     : 1914-01-01 – 1939-12-31  (see :mod:`exit_codes`)

Parsing pipeline (stops at first success per value)
----------------------------------------------------
1. Try explicit formats ``DD.MM.YYYY`` then ``DD.MM.YY`` via strptime.
2. Apply century fix: if parsed year > 1930 and year−100 falls in the
   column's valid range, subtract 100 (handles ``6.12.19`` → 1919). For the
   *partial* (event) columns the fix is symmetric: a year below the range whose
   +100 falls in it is a century slip too (``8.1.1818`` exit → 1918).
3. If NaT, search for the first ``DD.MM.YYYY`` occurrence via regex — fixes
   double-date birth entries (``"23.8.1890 23.9.1891"`` → 1890-08-23) and
   reads through a stray keystroke (``20.8.18884`` → 1888-08-20).
4. *Partial columns only* (capture, enrolment, exit): a month-year ``M.YYYY``
   → the first of that month, precision ``month`` (also rescues an impossible
   day, ``29.2.1918`` → February 1918).
5. If NaT and the column allows it, match ``^YYYY$`` → Jan 1 of that year;
   precision ``year`` (birth/death: the ``*_year_only`` flag).
6. If still NaT, take the first in-range four-digit ``YYYY`` anywhere — rescues
   double-year entries (``"1899 (1889)"`` → 1899) and trailing-annotation years.
7. Clip: if outside ``[lo, hi]`` → ``pd.NaT``.

Until v1.2.0 steps 4–6 existed for birth and death only, so 2,440 capture and 2,463
enrolment strings that state a month or a year (``4.1918``, ``1918``) were dropped
without a flag — the hazard model's entry time lost exactly where it is coarse, and
silently (audit 2026-09-22 §B15). A ``*_precision`` column now says which dates are
exact to the day.

Note: age strings such as ``"39 let"`` (age at death, VÚA birth column)
cannot be resolved to a birth date without the death year and intentionally
remain ``pd.NaT``.

Usage
-----
    from utils.parsing.dates import add_date_columns, date_report
    df = add_date_columns(df)
    date_report(df)
"""

from __future__ import annotations

import re
from datetime import datetime

import pandas as pd

__version__ = "1.2.0"   # month/year fallbacks + precision for event dates (audit 2026-09-22)

# ── Column configuration ──────────────────────────────────────────────────────
# source_col → (out_col, lo, hi, year_only_fallback, partial)
#   year_only_fallback : accept a bare / embedded year (birth, death: *_year_only flag)
#   partial            : event date — month-year + year fallbacks, symmetric century fix,
#                        and a ``{out_col}_precision`` column
_COLUMN_CONFIG: dict[str, tuple[str, pd.Timestamp, pd.Timestamp, bool, bool]] = {
    "Datum narození": (
        "birth_date", pd.Timestamp("1860-01-01"), pd.Timestamp("1905-12-31"), True, False),
    "Datum zajetí": (
        "capture_date", pd.Timestamp("1914-01-01"), pd.Timestamp("1918-12-31"), False, True),
    "Datum zařazení do legií": (
        "enroll_date", pd.Timestamp("1914-01-01"), pd.Timestamp("1922-12-31"), False, True),
    "Datum úmrtí": (
        "death_date", pd.Timestamp("1914-01-01"), pd.Timestamp("1923-12-31"), True, False),
}

# Out-columns that carry a companion ``*_year_only`` precision flag, keyed by
# the source column.  Driven off ``year_only_fallback`` in the config.
_YEAR_ONLY_FLAG = {
    "Datum narození": "birth_year_only",
    "Datum úmrtí": "death_year_only",
}

PRECISIONS = ("day", "month", "year")

# Explicit strptime formats tried in order; 4-digit year before 2-digit
_FORMATS = ["%d.%m.%Y", "%d.%m.%y"]

# A DD.MM.YYYY substring (double-date entries). Deliberately unanchored: a stray extra
# keystroke is read through — ``20.8.18884`` is 20 Aug 1888, ``217.5.1917`` is 17 May 1917 —
# and anything that lands outside the column's range is dropped by the clip anyway.
_FULL_DATE_RE = re.compile(r"\d{1,2}\.\d{1,2}\.\d{4}")

# M.YYYY — a month and a year with no day (partial columns only).
_MONTH_YEAR_RE = re.compile(r"(?<![\d.])(\d{1,2})\.\s*(\d{4})(?!\d)")

# Regex for a bare 4-digit year string
_YEAR_ONLY_RE = re.compile(r"^\d{4}$")

# The first four-digit year anywhere (double-year / annotated entries).
_YEAR_SEARCH_RE = re.compile(r"\d{4}")


# ── Internal helpers ──────────────────────────────────────────────────────────

def _try_formats(s: str) -> pd.Timestamp:
    """Try each explicit format; return pd.NaT if all fail."""
    for fmt in _FORMATS:
        try:
            return pd.Timestamp(datetime.strptime(s, fmt))
        except ValueError:
            pass
    return pd.NaT


def _century_fix(ts: pd.Timestamp, lo: pd.Timestamp, hi: pd.Timestamp,
                 upward: bool = False) -> pd.Timestamp:
    """Shift a post-1930 timestamp back 100 years if it then falls in range; with *upward*,
    also shift a pre-range year forward 100 years if that lands in range."""
    if pd.isna(ts):
        return ts
    if ts.year > 1930 and lo.year <= ts.year - 100 <= hi.year:
        return ts.replace(year=ts.year - 100)
    if upward and ts.year < lo.year and lo.year <= ts.year + 100 <= hi.year:
        try:
            return ts.replace(year=ts.year + 100)
        except ValueError:                      # 29 Feb in a non-leap target year
            return pd.NaT
    return ts


def parse_date(raw, lo: pd.Timestamp, hi: pd.Timestamp, year_only: bool = False,
               partial: bool = False) -> tuple[pd.Timestamp, str | None]:
    """Parse one raw value → ``(timestamp in [lo, hi] or NaT, precision)``.

    ``precision`` is ``"day"`` / ``"month"`` / ``"year"``, or ``None`` when nothing parsed.
    See the module docstring for the steps; ``partial`` enables the month-year fallback,
    the year fallbacks and the symmetric century fix.
    """
    if raw is None or (not isinstance(raw, str) and pd.isna(raw)):
        return pd.NaT, None
    s = str(raw).strip()
    if s in ("", "?", "-"):
        return pd.NaT, None

    # Step 1: explicit format parse
    ts = _century_fix(_try_formats(s), lo, hi, upward=partial)
    if pd.notna(ts) and lo <= ts <= hi:
        return ts, "day"

    # Step 3: first DD.MM.YYYY substring
    m = _FULL_DATE_RE.search(s)
    if m:
        ts = _century_fix(_try_formats(m.group(0)), lo, hi, upward=partial)
        if pd.notna(ts) and lo <= ts <= hi:
            return ts, "day"
        if partial and pd.isna(ts):
            # a full date whose day does not exist (29.2.1918): the month and year stand
            _d, mon, yr = (int(x) for x in m.group(0).split("."))
            if 1 <= mon <= 12 and 1800 <= yr <= 2100:
                t = _century_fix(pd.Timestamp(year=yr, month=mon, day=1), lo, hi, upward=True)
                if pd.notna(t) and lo <= t <= hi:
                    return t, "month"

    # Step 4: month-year (event dates)
    if partial:
        for mm in _MONTH_YEAR_RE.finditer(s):
            mon, yr = int(mm.group(1)), int(mm.group(2))
            if 1 <= mon <= 12 and 1800 <= yr <= 2100:
                t = _century_fix(pd.Timestamp(year=yr, month=mon, day=1), lo, hi, upward=True)
                if pd.notna(t) and lo <= t <= hi:
                    return t, "month"

    if not (year_only or partial):
        return pd.NaT, None

    # Step 5: bare year-only
    if _YEAR_ONLY_RE.match(s) and 1800 <= int(s) <= 2100:
        t = _century_fix(pd.Timestamp(f"{s}-01-01"), lo, hi, upward=partial)
        if pd.notna(t) and lo <= t <= hi:
            return t, "year"

    # Step 6: first in-range four-digit year anywhere
    for m in _YEAR_SEARCH_RE.finditer(s):
        y = int(m.group(0))
        if lo.year <= y <= hi.year:
            return pd.Timestamp(f"{y}-01-01"), "year"

    return pd.NaT, None


def _parse_one(raw, lo: pd.Timestamp, hi: pd.Timestamp,
               year_only: bool) -> tuple[pd.Timestamp, bool]:
    """Back-compat wrapper: ``(timestamp, is_year_only)`` for the birth/death columns."""
    ts, prec = parse_date(raw, lo, hi, year_only=year_only)
    return ts, prec == "year"

def add_date_columns(
    df: pd.DataFrame,
    source_cols: list[str] | None = None,
) -> pd.DataFrame:
    """Parse date columns and append cleaned timestamp columns.

    Added columns (those whose source column is present)
    ----------------------------------------------------
    birth_date              pd.Timestamp / NaT  — from ``Datum narození``
    birth_year_only         bool                — True when a year-only fallback was used
    capture_date            pd.Timestamp / NaT  — from ``Datum zajetí``
    capture_date_precision  day / month / year  — <NA> where nothing parsed
    enroll_date             pd.Timestamp / NaT  — from ``Datum zařazení do legií``
    enroll_date_precision   day / month / year  — <NA> where nothing parsed
    death_date              pd.Timestamp / NaT  — from ``Datum úmrtí``
    death_year_only         bool                — True when a year-only fallback was used

    Parameters
    ----------
    df:
        Input DataFrame (not modified in place).
    source_cols:
        Restrict parsing to a subset of source columns.  Defaults to all
        four configured columns.

    Returns
    -------
    pd.DataFrame
        Copy of *df* with date columns appended.
    """
    df = df.copy()
    config = _COLUMN_CONFIG
    if source_cols is not None:
        config = {k: v for k, v in config.items() if k in source_cols}

    for src_col, (out_col, lo, hi, year_only, partial) in config.items():
        if src_col not in df.columns:
            continue
        results = df[src_col].apply(
            lambda raw, lo=lo, hi=hi, yo=year_only, pa=partial:
                parse_date(raw, lo, hi, year_only=yo, partial=pa)
        )
        df[out_col] = pd.to_datetime(results.apply(lambda t: t[0]))
        if year_only and src_col in _YEAR_ONLY_FLAG:
            df[_YEAR_ONLY_FLAG[src_col]] = results.apply(lambda t: t[1] == "year")
        if partial:
            df[f"{out_col}_precision"] = results.apply(lambda t: t[1]).astype("string")

    return df


def date_report(df: pd.DataFrame) -> None:
    """Print a coverage table for each parsed date column."""
    print(f"Date column report  (N = {len(df):,})\n")

    for src_col, (out_col, lo, hi, year_only, partial) in _COLUMN_CONFIG.items():
        if out_col not in df.columns:
            continue

        n_raw_miss = df[src_col].isna().sum() if src_col in df.columns else 0
        n_valid    = df[out_col].notna().sum()
        n_failed   = len(df) - n_valid - n_raw_miss
        n          = len(df)

        print(f"  {src_col}  →  {out_col}")
        print(f"    {'Valid (in range)':<26}: {n_valid:>7,}  ({n_valid/n:.1%})")

        flag_col = _YEAR_ONLY_FLAG.get(src_col)
        if year_only and flag_col and flag_col in df.columns:
            n_yo = df[flag_col].sum()
            print(f"    {'  of which year-only':<26}: {n_yo:>7,}  ({n_yo/n:.1%})")
        prec_col = f"{out_col}_precision"
        if partial and prec_col in df.columns:
            vc = df[prec_col].value_counts()
            print(f"    {'  precision':<26}: " + ", ".join(
                f"{p} {int(vc.get(p, 0)):,}" for p in PRECISIONS))

        print(f"    {'Failed / out of range':<26}: {n_failed:>7,}  ({n_failed/n:.1%})")
        print(f"    {'Raw missing':<26}: {n_raw_miss:>7,}  ({n_raw_miss/n:.1%})")
        print()
