How it works

Downloads a whole digital-library document (all its pages) from a Kramerius 5 instance as a single PDF (the page scans) plus a concatenated TXT (the per-page OCR). Written for the Digitální studovna Ministerstva obrany ČR (DSMO) — the Czech Ministry-of-Defence Kramerius that hosts the front diaries (deníky) and the Austro-Hungarian Schematismus volumes — but it works against any public Kramerius 5.x host (National Library, MZK, …); just pass --host.

What a Kramerius document looks like

Every object has a pid (uuid:XX…) and a model. Container models (periodical, periodicalvolume, periodicalitem, monograph, monographunit, convolute…) hold ordered children; leaf pages have model == "page". This downloader walks that tree from any starting pid and collects the page pids in document order, so you can hand it either a whole periodical or a single issue.

A third kind of child is neither: an internal part (picture for a map or plate, internalpart for a chapter heading) labels pages that already hang off the same parent, and its own /children hands those pages back a second time. The walk skips them — the Beilagen volumes of Österreich-Ungarns letzter Krieg list 84 picture maps beside 88 pages, and recursing into the maps nearly doubled the volume.

Per-page datastreams used (confirmed present on DSMO):

IMG_FULL    image/jpeg   full-resolution page scan   -> PDF
TEXT_OCR    text/plain   OCR of that page            -> TXT
ALTO        text/xml     (word coordinates; optional, --alto)

API shape (v5.0), relative to {host}/search/api/v5.0:

/item/{pid}              -> {pid, model, title, root_title, details, …}
/item/{pid}/children     -> [ {pid, model, title/label, …}, … ]  (ordered)
/item/{pid}/streams/IMG_FULL   -> bytes (jpeg)
/item/{pid}/streams/TEXT_OCR   -> text
/item/{pid}/streams/ALTO       -> xml

Scan resolution

IMG_FULL is not the scan. DSMO serves it scaled to 1500 px wide, while the image server behind the viewer holds the page at its native size — 2370 px for a map sheet of Österreich-Ungarns letzter Krieg, about 2000 px for a text page. native_images=True (--native-images) fetches that instead, from the host's IIIF endpoint (outside the v5 API path):

{host}/search/iiif/{pid}/full/full/0/default.jpg   -> bytes (jpeg), native size

Off by default, because not every Kramerius 5 host runs an image server; a page the endpoint will not serve falls back to IMG_FULL with a warning.

Access note

Only pages whose access policy is public can be fetched in full; licensed / DNNT pages return 403 for IMG_FULL. Such pages are logged and (with --fallback-preview) substituted by the lower-res IMG_PREVIEW so the PDF stays complete. The DSMO Schematismus / pre-1920 diaries are public domain.

PDF assembly uses img2pdf when available (lossless — the original JPEGs are embedded as-is); otherwise it falls back to Pillow (re-encodes). Install img2pdf for faithful, smaller output.

Progress is shown as a tqdm bar over the page loop (--no-progress, or progress=False, falls back to a log line every 25 pages). Several documents can share one screen by giving each a progress_position — see run_lexicon_downloads.py.

Jupyter usage

>>> from scraper_kramerius import download_document
>>> # Landwehr Schematismus 1914 (258 pp.) from the viewer URL:
>>> url = ("https://www.digitalniknihovna.cz/dsmo/view/"
...        "uuid:6ea5d3ce-39fc-4916-bcfc-b404786a006c")

class KrameriusClient:
    """Thin, polite wrapper over the Kramerius 5 read API."""

    def __init__(
        self,
        host: str = DEFAULT_HOST,
        *,
        delay: float = 0.4,
        timeout: float = 60.0,
        retries: int = 4,
        verify_tls: bool = True,
    ) -> None:
        self.host = host.rstrip("/")
        self.base = self.host + API_PATH
        self.delay = delay
        self.timeout = timeout
        self.retries = retries
        self.session = requests.Session()
        self.session.headers.update({"User-Agent": USER_AGENT})
        self.session.verify = verify_tls
        if not verify_tls:
            import urllib3
            urllib3.disable_warnings(urllib3.exceptions.InsecureRequestWarning)

    # -- low level ----------------------------------------------------------
    def _get(self, url: str) -> requests.Response:
        """GET with linear backoff on 429/5xx; raise on other 4xx."""
        last_exc: Exception | None = None
        for attempt in range(1, self.retries + 1):
            try:
                r = self.session.get(url, timeout=self.timeout)
                if r.status_code in (429, 500, 502, 503, 504):
                    wait = self.delay * attempt * 3
                    log.warning("  %s on %s — retry %d/%d in %.1fs",
                                r.status_code, url, attempt, self.retries, wait)
                    time.sleep(wait)
                    continue
                r.raise_for_status()
                if self.delay:
                    time.sleep(self.delay)
                return r
            except requests.RequestException as exc:  # network hiccup
                last_exc = exc
                wait = self.delay * attempt * 3
                log.warning("  %s on %s — retry %d/%d in %.1fs",
                            exc.__class__.__name__, url, attempt, self.retries, wait)
                time.sleep(wait)
        raise RuntimeError(f"GET failed after {self.retries} tries: {url}") from last_exc

    # -- metadata -----------------------------------------------------------
    def item(self, pid: str) -> dict:
        return self._get(f"{self.base}/item/{pid}").json()

    def children(self, pid: str) -> list[dict]:
        return self._get(f"{self.base}/item/{pid}/children").json()

    # -- streams ------------------------------------------------------------
    def stream_bytes(self, pid: str, name: str) -> bytes:
        return self._get(f"{self.base}/item/{pid}/streams/{name}").content

    def stream_text(self, pid: str, name: str) -> str:
        # force UTF-8; Kramerius serves OCR as UTF-8 but omits the charset,
        # so requests would otherwise guess ISO-8859-1 and mangle diacritics.
        return self._get(f"{self.base}/item/{pid}/streams/{name}").content.decode(
            "utf-8", errors="replace"
        )

    def try_stream_bytes(self, pid: str, name: str) -> bytes | None:
        try:
            return self.stream_bytes(pid, name)
        except Exception as exc:  # 403 (licensed) / 404 (absent)
            log.debug("    no %s for %s (%s)", name, pid, exc)
            return None

    def try_native_image(self, pid: str) -> bytes | None:
        """The page scan at its native size, from the host's IIIF image server."""
        try:
            return self._get(f"{self.host}/search/iiif/{pid}/full/full/0/default.jpg").content
        except Exception as exc:  # no image server on this host / for this page
            log.debug("    no IIIF image for %s (%s)", pid, exc)
            return None

    def try_stream_text(self, pid: str, name: str) -> str | None:
        try:
            return self.stream_text(pid, name)
        except Exception as exc:
            log.debug("    no %s for %s (%s)", name, pid, exc)
            return None

    # -- tree walk ----------------------------------------------------------
    def iter_pages(self, pid: str) -> Iterator[dict]:
        """Yield page items in document order, recursing through containers."""
        meta = self.item(pid)
        model = meta.get("model", "")
        if model == PAGE_MODEL:
            yield meta
            return
        for child in self.children(pid):
            cmodel = child.get("model", "")
            if cmodel == PAGE_MODEL:
                yield child
            elif cmodel in INTERNAL_PART_MODELS:
                continue  # its page is a sibling, already yielded in its own place
            else:  # container -> recurse (periodical -> volume -> item -> page)
                yield from self.iter_pages(child["pid"])

def parse_pid(url_or_pid: str) -> str:
    """Extract the document ``uuid:…`` from a viewer URL or accept a bare pid.

    Handles ``…/view/uuid:AAA?page=uuid:BBB`` (returns the *document* AAA, not
    the page BBB) and plain ``uuid:AAA`` / ``AAA``.
    """
    s = url_or_pid.strip()
    # the document pid is the one right after '/view/' or '/periodical/' etc.,
    # NOT the '?page=' one.
    m = re.search(r"/(?:view|uuid|periodical|monograph)/(uuid:[0-9a-fA-F-]+)", s)
    if m:
        return m.group(1)
    m = re.search(r"(uuid:[0-9a-fA-F-]+)", s.split("?page=")[0])
    if m:
        return m.group(1)
    if re.fullmatch(r"[0-9a-fA-F-]{36}", s):
        return "uuid:" + s
    raise ValueError(f"could not find a uuid in: {url_or_pid!r}")

def parse_host(url: str) -> str | None:
    """Return the backend Kramerius host for a viewer URL, if derivable.

    ``www.digitalniknihovna.cz/dsmo/…`` is the *portal*; the real API host for
    the ``dsmo`` library is ``digitalnistudovna.army.cz``.  For any other host we
    just reuse the URL's own scheme+host (works for library-native Kramerius
    URLs like ``kramerius.mzk.cz/…``).
    """
    m = re.match(r"https?://([^/]+)(/[^/?#]*)?", url)
    if not m:
        return None
    netloc, first = m.group(1), (m.group(2) or "").strip("/")
    if "digitalniknihovna.cz" in netloc:
        # portal: map known library codes to their backend host
        portal_backends = {"dsmo": "https://digitalnistudovna.army.cz"}
        return portal_backends.get(first)  # None -> caller keeps default/explicit host
    return f"https://{netloc}"

def safe_filename(text: str, *, max_len: int = 120) -> str:
    text = _ILLEGAL.sub("", text)
    text = re.sub(r"\s+", " ", text).strip().rstrip(". ")
    if len(text) > max_len:
        text = text[:max_len].rstrip(". ")
    return text or "kramerius_document"

def download_document(
    url_or_pid: str,
    out_dir: str | Path,
    *,
    host: str | None = None,
    make_pdf: bool = True,
    make_txt: bool = True,
    per_page_txt: bool = False,
    save_alto: bool = False,
    fallback_preview: bool = False,
    native_images: bool = False,
    delay: float = 0.4,
    verify_tls: bool = True,
    keep_pages: bool = False,
    name: str | None = None,
    page_from: int = 1,
    page_to: int | None = None,
    timeout: float = 60.0,
    retries: int = 4,
    batch_size: int = 20,
    batch_pause: float = 10.0,
    progress: bool = True,
    progress_position: int | None = None,
    progress_desc: str | None = None,
) -> dict:
    """Download pages of a Kramerius document to ``out_dir``.

    Returns a small summary dict.  **Every** per-page artefact (scan, OCR text,
    ALTO) is cached under ``out_dir/<slug>_pages/`` and skipped on a re-run, so
    resuming costs only the metadata walk — important when the host is slow or
    rate-limits.

    Downloading is **batched by default**: every ``batch_size`` pages the run
    pauses for ``batch_pause`` seconds, so a long volume is pulled in polite
    bursts rather than one sustained stream.  A batch that hit the cache only
    (no requests) does not pause, so resuming stays fast.  ``batch_size=0``
    disables batching.

    ``page_from``/``page_to`` (1-based, inclusive) restrict the fetch to a slice
    of the document — use these to stop after a fixed slice, not for pacing
    (batching already handles that).  Page numbering is global, so ranges share
    one cache directory.  When a partial range is given the PDF/TXT are **not**
    assembled — re-run once with no range to build them from the completed cache
    (that pass re-fetches nothing).

    ``native_images`` takes each scan at its native size from the host's IIIF
    image server rather than the scaled ``IMG_FULL`` stream (see *Scan
    resolution* in the module docstring).

    A ``tqdm`` progress bar over the page loop is on by default; pass
    ``progress=False`` for the older every-25-pages log line instead.
    ``progress_position`` stacks the bar when several documents run at once
    (see ``run_lexicon_downloads.py``), ``progress_desc`` labels it.
    """
    pid = parse_pid(url_or_pid)
    if host is None and url_or_pid.lower().startswith("http"):
        host = parse_host(url_or_pid)
    client = KrameriusClient(host or DEFAULT_HOST, delay=delay, verify_tls=verify_tls,
                             timeout=timeout, retries=retries)

    meta = client.item(pid)
    # `name` overrides the output *filename stem* only — the title stays whatever
    # the library calls the volume, so it is what the TXT header reports.
    title = meta.get("title") or meta.get("root_title") or pid
    slug = safe_filename(name or title)
    out_dir = Path(out_dir)
    out_dir.mkdir(parents=True, exist_ok=True)
    pages_dir = out_dir / f"{slug}_pages"
    pages_dir.mkdir(exist_ok=True)

    log.info("Document : %s", title)
    log.info("PID      : %s  (model=%s, host=%s)", pid, meta.get("model"), client.base)
    log.info("Collecting page list …")
    pages = list(client.iter_pages(pid))
    n = len(pages)
    log.info("  %d pages", n)
    if n == 0:
        raise RuntimeError("no pages found under this pid")

    lo = max(1, page_from)
    hi = min(n, page_to if page_to is not None else n)
    partial = (lo > 1) or (hi < n)
    if partial:
        log.info("Range    : pages %d–%d of %d (partial — PDF/TXT not assembled)", lo, hi, n)
    if batch_size > 0:
        log.info("Batching : %d pages per batch, %.0fs pause between batches",
                 batch_size, batch_pause)

    image_paths: list[Path] = []
    ocr_parts: list[str] = []
    n_img = n_ocr = n_alto = n_missing_img = n_fetched = n_native_fallback = 0
    batch_pos = batch_mark = 0

    bar = page_bar(n, progress_desc or slug, enabled=progress, position=progress_position)
    bar_live = getattr(bar, "live", False)

    # With a bar drawn, every log line goes through tqdm.write so it does not
    # shred it; without one, the every-25-pages line below is the only progress.
    with bar, redirect_logging():
        for i, pg in enumerate(pages, 1):
            ppid = pg["pid"]
            label = str(pg.get("title") or pg.get("label") or i)
            img_path = pages_dir / f"{i:04d}.jpg"
            txt_path = pages_dir / f"{i:04d}.txt"
            alto_path = pages_dir / f"{i:04d}.alto.xml"
            in_range = lo <= i <= hi

            # -- image (cached / resumable) ------------------------------------
            if make_pdf:
                if img_path.exists() and img_path.stat().st_size > 0:
                    image_paths.append(img_path)
                    n_img += 1
                elif in_range:
                    data = client.try_native_image(ppid) if native_images else None
                    if data is None:
                        if native_images:
                            n_native_fallback += 1
                            log.warning("  p%d/%d %-8s no native image -> IMG_FULL", i, n, label)
                        data = client.try_stream_bytes(ppid, "IMG_FULL")
                    if data is None and fallback_preview:
                        data = client.try_stream_bytes(ppid, "IMG_PREVIEW")
                        if data is not None:
                            log.info("  p%d/%d %-8s IMG_FULL blocked -> preview", i, n, label)
                    if data is None:
                        n_missing_img += 1
                        log.warning("  p%d/%d %-8s no image (skipped in PDF)", i, n, label)
                    else:
                        img_path.write_bytes(data)
                        image_paths.append(img_path)
                        n_img += 1
                        n_fetched += 1

            # -- OCR (per-page file is the cache; skip the request if present) --
            if make_txt or per_page_txt:
                txt: str | None = None
                if txt_path.exists():
                    txt = txt_path.read_text(encoding="utf-8")
                elif in_range:
                    txt = client.try_stream_text(ppid, "TEXT_OCR")
                    if txt is not None:
                        txt_path.write_text(txt, encoding="utf-8")
                        n_fetched += 1
                if txt is not None:
                    n_ocr += 1
                    header = f"\n\n===== p. {i}  ({label})  [{ppid}] =====\n"
                    ocr_parts.append(header + txt.strip())

            # -- ALTO (optional; also cached) ----------------------------------
            if save_alto:
                if alto_path.exists() and alto_path.stat().st_size > 0:
                    n_alto += 1
                elif in_range:
                    alto = client.try_stream_text(ppid, "ALTO")
                    if alto is not None:
                        alto_path.write_text(alto, encoding="utf-8")
                        n_alto += 1
                        n_fetched += 1

            bar.update(1)
            bar.set_postfix(fetched=n_fetched, refresh=False)
            if not bar_live and (i % 25 == 0 or i == n):
                log.info("  … %d/%d pages (%d fetched this run)", i, n, n_fetched)

            # -- polite batching: rest after every `batch_size` in-range pages -----
            # A batch served entirely from cache made no requests, so it does not
            # pause — resuming a part-downloaded volume stays fast.
            if in_range and batch_size > 0:
                batch_pos += 1
                if batch_pos >= batch_size:
                    did = n_fetched - batch_mark
                    if did and i < hi:
                        if bar_live:
                            bar.set_postfix(fetched=n_fetched,
                                            resting=f"{batch_pause:.0f}s")
                        else:
                            log.info("  batch: %d pages, %d requests — pausing %.0fs",
                                     batch_pos, did, batch_pause)
                        time.sleep(batch_pause)
                        bar.set_postfix(fetched=n_fetched)
                    batch_pos = 0
                    batch_mark = n_fetched

    # -- assemble outputs ---------------------------------------------------
    result: dict = {"pid": pid, "title": title, "pages": n,
                    "images": n_img, "ocr_pages": n_ocr, "alto_pages": n_alto,
                    "range": (lo, hi), "fetched_this_run": n_fetched,
                    "native_fallbacks": n_native_fallback,
                    "complete": n_img >= n}

    if partial:
        log.info("Cache: %d/%d scans, %d/%d OCR, %d/%d ALTO (%d requests this run).",
                 n_img, n, n_ocr, n, n_alto, n, n_fetched)
        log.info("Re-run with no --page-from/--page-to once complete to assemble "
                 "the PDF/TXT (that pass fetches nothing).")
        return result

    if make_pdf and image_paths:
        out_pdf = out_dir / f"{slug}.pdf"
        backend = _build_pdf(image_paths, out_pdf)
        size_mb = out_pdf.stat().st_size / 1e6
        log.info("PDF   -> %s  (%d pp, %.1f MB, via %s)", out_pdf.name, n_img, size_mb, backend)
        result["pdf"] = str(out_pdf)
        result["pdf_backend"] = backend
    elif make_pdf:
        log.warning("No page images fetched — PDF not written.")

    if make_txt and ocr_parts:
        out_txt = out_dir / f"{slug}.txt"
        head = (f"OCR text — {title}\nKramerius PID: {pid}\n"
                f"Source host: {client.base}\nPages with OCR: {n_ocr}/{n}\n"
                + "=" * 70)
        out_txt.write_text(head + "".join(ocr_parts) + "\n", encoding="utf-8")
        log.info("TXT   -> %s  (%d/%d pages had OCR)", out_txt.name, n_ocr, n)
        result["txt"] = str(out_txt)

    if not keep_pages and make_pdf and n_missing_img == 0 and not (per_page_txt or save_alto):
        # PDF is complete and the user asked for no per-page artefacts -> tidy up
        # (the per-page .txt files are written unconditionally as resume state,
        # so they go too when they were not requested).
        for p in image_paths:
            try:
                p.unlink()
            except OSError:
                pass
        for p in pages_dir.glob("*.txt"):
            try:
                p.unlink()
            except OSError:
                pass
        try:
            pages_dir.rmdir()
        except OSError:
            pass
        log.info("Cleaned page cache (%s).", pages_dir.name)
    elif not keep_pages:
        log.info("Kept page cache %s (missing images or per-page/ALTO outputs present).",
                 pages_dir.name)

    if n_missing_img:
        log.warning("%d/%d pages had no downloadable IMG_FULL "
                    "(licensed? try --fallback-preview).", n_missing_img, n)
    return result

#!/usr/bin/env python3
"""
Kramerius v5 downloader — importable module + CLI.

Downloads a whole digital-library document (all its pages) from a Kramerius 5
instance as a single **PDF** (the page scans) plus a concatenated **TXT** (the
per-page OCR).  Written for the *Digitální studovna Ministerstva obrany ČR*
(DSMO) — the Czech Ministry-of-Defence Kramerius that hosts the front diaries
(deníky) and the Austro-Hungarian *Schematismus* volumes — but it works against
any public Kramerius 5.x host (National Library, MZK, …); just pass ``--host``.

What a Kramerius document looks like
------------------------------------
Every object has a ``pid`` (``uuid:XX…``) and a ``model``.  Container models
(``periodical``, ``periodicalvolume``, ``periodicalitem``, ``monograph``,
``monographunit``, ``convolute``…) hold ordered children; leaf pages have
``model == "page"``.  This downloader walks that tree from any starting pid and
collects the page pids **in document order**, so you can hand it either a whole
periodical or a single issue.

A third kind of child is neither: an *internal part* (``picture`` for a map or
plate, ``internalpart`` for a chapter heading) labels pages that already hang off
the same parent, and its own ``/children`` hands those pages back a second time.
The walk skips them — the *Beilagen* volumes of *Österreich-Ungarns letzter
Krieg* list 84 ``picture`` maps beside 88 pages, and recursing into the maps
nearly doubled the volume.

Per-page datastreams used (confirmed present on DSMO):

    IMG_FULL    image/jpeg   full-resolution page scan   -> PDF
    TEXT_OCR    text/plain   OCR of that page            -> TXT
    ALTO        text/xml     (word coordinates; optional, --alto)

API shape (v5.0), relative to ``{host}/search/api/v5.0``:

    /item/{pid}              -> {pid, model, title, root_title, details, …}
    /item/{pid}/children     -> [ {pid, model, title/label, …}, … ]  (ordered)
    /item/{pid}/streams/IMG_FULL   -> bytes (jpeg)
    /item/{pid}/streams/TEXT_OCR   -> text
    /item/{pid}/streams/ALTO       -> xml

Scan resolution
---------------
``IMG_FULL`` is not the scan.  DSMO serves it scaled to **1500 px wide**, while
the image server behind the viewer holds the page at its native size — 2370 px
for a map sheet of *Österreich-Ungarns letzter Krieg*, about 2000 px for a text
page.  ``native_images=True`` (``--native-images``) fetches that instead, from
the host's IIIF endpoint (outside the v5 API path):

    {host}/search/iiif/{pid}/full/full/0/default.jpg   -> bytes (jpeg), native size

Off by default, because not every Kramerius 5 host runs an image server; a page
the endpoint will not serve falls back to ``IMG_FULL`` with a warning.

Access note
-----------
Only pages whose access ``policy`` is ``public`` can be fetched in full;
licensed / DNNT pages return 403 for IMG_FULL.  Such pages are logged and (with
``--fallback-preview``) substituted by the lower-res IMG_PREVIEW so the PDF stays
complete.  The DSMO *Schematismus* / pre-1920 diaries are public domain.

PDF assembly uses ``img2pdf`` when available (lossless — the original JPEGs are
embedded as-is); otherwise it falls back to Pillow (re-encodes).  Install
``img2pdf`` for faithful, smaller output.

Progress is shown as a ``tqdm`` bar over the page loop (``--no-progress``, or
``progress=False``, falls back to a log line every 25 pages).  Several documents
can share one screen by giving each a ``progress_position`` — see
``run_lexicon_downloads.py``.

Jupyter usage
-------------
    >>> from scraper_kramerius import download_document
    >>> # Landwehr Schematismus 1914 (258 pp.) from the viewer URL:
    >>> url = ("https://www.digitalniknihovna.cz/dsmo/view/"
    ...        "uuid:6ea5d3ce-39fc-4916-bcfc-b404786a006c")
    >>> download_document(url, out_dir="library/ah-army", delay=0.4)

CLI usage: see ``python scraper_kramerius.py --help``
    python utils/scraping/scraper_kramerius.py \
        --url "https://www.digitalniknihovna.cz/dsmo/view/uuid:6ea5d3ce-39fc-4916-bcfc-b404786a006c" \
        --out library/ah-army
"""

API_PATH = "/search/api/v5.0"
USER_AGENT = (
    "scraper_kramerius/%s" % __version__
)
PAGE_MODEL = "page"
# container models we recurse into (anything not a page, really — this is just
# the documented set for clarity / logging):
CONTAINER_MODELS = {
    "periodical", "periodicalvolume", "periodicalitem",
    "monograph", "monographunit", "convolute", "supplement",
    "collection", "soundrecording", "manuscript", "map", "graphic",
    "archive", "sheetmusic",
}
# internal parts: they label pages of the parent (foster ``isOnPage``) and hold
# none of their own, so the walk must not descend into them.
INTERNAL_PART_MODELS = {"picture", "internalpart"}


# ---------------------------------------------------------------------------
# Client
# ---------------------------------------------------------------------------
class KrameriusClient:
    """Thin, polite wrapper over the Kramerius 5 read API."""

    def __init__(
        self,
        host: str = DEFAULT_HOST,
        *,
        delay: float = 0.4,
        timeout: float = 60.0,
        retries: int = 4,
        verify_tls: bool = True,
    ) -> None:
        self.host = host.rstrip("/")
        self.base = self.host + API_PATH
        self.delay = delay
        self.timeout = timeout
        self.retries = retries
        self.session = requests.Session()
        self.session.headers.update({"User-Agent": USER_AGENT})
        self.session.verify = verify_tls
        if not verify_tls:
            import urllib3
            urllib3.disable_warnings(urllib3.exceptions.InsecureRequestWarning)

    # -- low level ----------------------------------------------------------
    def _get(self, url: str) -> requests.Response:
        """GET with linear backoff on 429/5xx; raise on other 4xx."""
        last_exc: Exception | None = None
        for attempt in range(1, self.retries + 1):
            try:
                r = self.session.get(url, timeout=self.timeout)
                if r.status_code in (429, 500, 502, 503, 504):
                    wait = self.delay * attempt * 3
                    log.warning("  %s on %s — retry %d/%d in %.1fs",
                                r.status_code, url, attempt, self.retries, wait)
                    time.sleep(wait)
                    continue
                r.raise_for_status()
                if self.delay:
                    time.sleep(self.delay)
                return r
            except requests.RequestException as exc:  # network hiccup
                last_exc = exc
                wait = self.delay * attempt * 3
                log.warning("  %s on %s — retry %d/%d in %.1fs",
                            exc.__class__.__name__, url, attempt, self.retries, wait)
                time.sleep(wait)
        raise RuntimeError(f"GET failed after {self.retries} tries: {url}") from last_exc

    # -- metadata -----------------------------------------------------------
    def item(self, pid: str) -> dict:
        return self._get(f"{self.base}/item/{pid}").json()

    def children(self, pid: str) -> list[dict]:
        return self._get(f"{self.base}/item/{pid}/children").json()

    # -- streams ------------------------------------------------------------
    def stream_bytes(self, pid: str, name: str) -> bytes:
        return self._get(f"{self.base}/item/{pid}/streams/{name}").content

    def stream_text(self, pid: str, name: str) -> str:
        # force UTF-8; Kramerius serves OCR as UTF-8 but omits the charset,
        # so requests would otherwise guess ISO-8859-1 and mangle diacritics.
        return self._get(f"{self.base}/item/{pid}/streams/{name}").content.decode(
            "utf-8", errors="replace"
        )

    def try_stream_bytes(self, pid: str, name: str) -> bytes | None:
        try:
            return self.stream_bytes(pid, name)
        except Exception as exc:  # 403 (licensed) / 404 (absent)
            log.debug("    no %s for %s (%s)", name, pid, exc)
            return None

    def try_native_image(self, pid: str) -> bytes | None:
        """The page scan at its native size, from the host's IIIF image server."""
        try:
            return self._get(f"{self.host}/search/iiif/{pid}/full/full/0/default.jpg").content
        except Exception as exc:  # no image server on this host / for this page
            log.debug("    no IIIF image for %s (%s)", pid, exc)
            return None

    def try_stream_text(self, pid: str, name: str) -> str | None:
        try:
            return self.stream_text(pid, name)
        except Exception as exc:
            log.debug("    no %s for %s (%s)", name, pid, exc)
            return None

    # -- tree walk ----------------------------------------------------------
    def iter_pages(self, pid: str) -> Iterator[dict]:
        """Yield page items in document order, recursing through containers."""
        meta = self.item(pid)
        model = meta.get("model", "")
        if model == PAGE_MODEL:
            yield meta
            return
        for child in self.children(pid):
            cmodel = child.get("model", "")
            if cmodel == PAGE_MODEL:
                yield child
            elif cmodel in INTERNAL_PART_MODELS:
                continue  # its page is a sibling, already yielded in its own place
            else:  # container -> recurse (periodical -> volume -> item -> page)
                yield from self.iter_pages(child["pid"])

def parse_pid(url_or_pid: str) -> str:
    """Extract the document ``uuid:…`` from a viewer URL or accept a bare pid.

    Handles ``…/view/uuid:AAA?page=uuid:BBB`` (returns the *document* AAA, not
    the page BBB) and plain ``uuid:AAA`` / ``AAA``.
    """
    s = url_or_pid.strip()
    # the document pid is the one right after '/view/' or '/periodical/' etc.,
    # NOT the '?page=' one.
    m = re.search(r"/(?:view|uuid|periodical|monograph)/(uuid:[0-9a-fA-F-]+)", s)
    if m:
        return m.group(1)
    m = re.search(r"(uuid:[0-9a-fA-F-]+)", s.split("?page=")[0])
    if m:
        return m.group(1)
    if re.fullmatch(r"[0-9a-fA-F-]{36}", s):
        return "uuid:" + s
    raise ValueError(f"could not find a uuid in: {url_or_pid!r}")


def parse_host(url: str) -> str | None:
    """Return the backend Kramerius host for a viewer URL, if derivable.

    ``www.digitalniknihovna.cz/dsmo/…`` is the *portal*; the real API host for
    the ``dsmo`` library is ``digitalnistudovna.army.cz``.  For any other host we
    just reuse the URL's own scheme+host (works for library-native Kramerius
    URLs like ``kramerius.mzk.cz/…``).
    """
    m = re.match(r"https?://([^/]+)(/[^/?#]*)?", url)
    if not m:
        return None
    netloc, first = m.group(1), (m.group(2) or "").strip("/")
    if "digitalniknihovna.cz" in netloc:
        # portal: map known library codes to their backend host
        portal_backends = {"dsmo": "https://digitalnistudovna.army.cz"}
        return portal_backends.get(first)  # None -> caller keeps default/explicit host
    return f"https://{netloc}"


_ILLEGAL = re.compile(r'[<>:"/\\|?*\x00-\x1f]')


def safe_filename(text: str, *, max_len: int = 120) -> str:
    text = _ILLEGAL.sub("", text)
    text = re.sub(r"\s+", " ", text).strip().rstrip(". ")
    if len(text) > max_len:
        text = text[:max_len].rstrip(". ")
    return text or "kramerius_document"


def _build_pdf(image_paths: list[Path], out_pdf: Path) -> str:
    """Assemble a PDF from JPEG page files. Returns the backend used."""
    try:
        import img2pdf  # lossless: embeds the JPEGs unchanged
        with open(out_pdf, "wb") as fh:
            fh.write(img2pdf.convert([str(p) for p in image_paths]))
        return "img2pdf"
    except ImportError:
        from PIL import Image  # fallback: re-encodes
        imgs = [Image.open(p).convert("RGB") for p in image_paths]
        imgs[0].save(out_pdf, "PDF", save_all=True, append_images=imgs[1:])
        for im in imgs:
            im.close()
        return "Pillow"

# Main entry point
# ---------------------------------------------------------------------------
def download_document(
    url_or_pid: str,
    out_dir: str | Path,
    *,
    host: str | None = None,
    make_pdf: bool = True,
    make_txt: bool = True,
    per_page_txt: bool = False,
    save_alto: bool = False,
    fallback_preview: bool = False,
    native_images: bool = False,
    delay: float = 0.4,
    verify_tls: bool = True,
    keep_pages: bool = False,
    name: str | None = None,
    page_from: int = 1,
    page_to: int | None = None,
    timeout: float = 60.0,
    retries: int = 4,
    batch_size: int = 20,
    batch_pause: float = 10.0,
    progress: bool = True,
    progress_position: int | None = None,
    progress_desc: str | None = None,
) -> dict:
    """Download pages of a Kramerius document to ``out_dir``.

    Returns a small summary dict.  **Every** per-page artefact (scan, OCR text,
    ALTO) is cached under ``out_dir/<slug>_pages/`` and skipped on a re-run, so
    resuming costs only the metadata walk — important when the host is slow or
    rate-limits.

    Downloading is **batched by default**: every ``batch_size`` pages the run
    pauses for ``batch_pause`` seconds, so a long volume is pulled in polite
    bursts rather than one sustained stream.  A batch that hit the cache only
    (no requests) does not pause, so resuming stays fast.  ``batch_size=0``
    disables batching.

    ``page_from``/``page_to`` (1-based, inclusive) restrict the fetch to a slice
    of the document — use these to stop after a fixed slice, not for pacing
    (batching already handles that).  Page numbering is global, so ranges share
    one cache directory.  When a partial range is given the PDF/TXT are **not**
    assembled — re-run once with no range to build them from the completed cache
    (that pass re-fetches nothing).

    ``native_images`` takes each scan at its native size from the host's IIIF
    image server rather than the scaled ``IMG_FULL`` stream (see *Scan
    resolution* in the module docstring).

    A ``tqdm`` progress bar over the page loop is on by default; pass
    ``progress=False`` for the older every-25-pages log line instead.
    ``progress_position`` stacks the bar when several documents run at once
    (see ``run_lexicon_downloads.py``), ``progress_desc`` labels it.
    """
    pid = parse_pid(url_or_pid)
    if host is None and url_or_pid.lower().startswith("http"):
        host = parse_host(url_or_pid)
    client = KrameriusClient(host or DEFAULT_HOST, delay=delay, verify_tls=verify_tls,
                             timeout=timeout, retries=retries)

    meta = client.item(pid)
    # `name` overrides the output *filename stem* only — the title stays whatever
    # the library calls the volume, so it is what the TXT header reports.
    title = meta.get("title") or meta.get("root_title") or pid
    slug = safe_filename(name or title)
    out_dir = Path(out_dir)
    out_dir.mkdir(parents=True, exist_ok=True)
    pages_dir = out_dir / f"{slug}_pages"
    pages_dir.mkdir(exist_ok=True)

    log.info("Document : %s", title)
    log.info("PID      : %s  (model=%s, host=%s)", pid, meta.get("model"), client.base)
    log.info("Collecting page list …")
    pages = list(client.iter_pages(pid))
    n = len(pages)
    log.info("  %d pages", n)
    if n == 0:
        raise RuntimeError("no pages found under this pid")

    lo = max(1, page_from)
    hi = min(n, page_to if page_to is not None else n)
    partial = (lo > 1) or (hi < n)
    if partial:
        log.info("Range    : pages %d–%d of %d (partial — PDF/TXT not assembled)", lo, hi, n)
    if batch_size > 0:
        log.info("Batching : %d pages per batch, %.0fs pause between batches",
                 batch_size, batch_pause)

    image_paths: list[Path] = []
    ocr_parts: list[str] = []
    n_img = n_ocr = n_alto = n_missing_img = n_fetched = n_native_fallback = 0
    batch_pos = batch_mark = 0

    bar = page_bar(n, progress_desc or slug, enabled=progress, position=progress_position)
    bar_live = getattr(bar, "live", False)

    # With a bar drawn, every log line goes through tqdm.write so it does not
    # shred it; without one, the every-25-pages line below is the only progress.
    with bar, redirect_logging():
        for i, pg in enumerate(pages, 1):
            ppid = pg["pid"]
            label = str(pg.get("title") or pg.get("label") or i)
            img_path = pages_dir / f"{i:04d}.jpg"
            txt_path = pages_dir / f"{i:04d}.txt"
            alto_path = pages_dir / f"{i:04d}.alto.xml"
            in_range = lo <= i <= hi

            # -- image (cached / resumable) ------------------------------------
            if make_pdf:
                if img_path.exists() and img_path.stat().st_size > 0:
                    image_paths.append(img_path)
                    n_img += 1
                elif in_range:
                    data = client.try_native_image(ppid) if native_images else None
                    if data is None:
                        if native_images:
                            n_native_fallback += 1
                            log.warning("  p%d/%d %-8s no native image -> IMG_FULL", i, n, label)
                        data = client.try_stream_bytes(ppid, "IMG_FULL")
                    if data is None and fallback_preview:
                        data = client.try_stream_bytes(ppid, "IMG_PREVIEW")
                        if data is not None:
                            log.info("  p%d/%d %-8s IMG_FULL blocked -> preview", i, n, label)
                    if data is None:
                        n_missing_img += 1
                        log.warning("  p%d/%d %-8s no image (skipped in PDF)", i, n, label)
                    else:
                        img_path.write_bytes(data)
                        image_paths.append(img_path)
                        n_img += 1
                        n_fetched += 1

            # -- OCR (per-page file is the cache; skip the request if present) --
            if make_txt or per_page_txt:
                txt: str | None = None
                if txt_path.exists():
                    txt = txt_path.read_text(encoding="utf-8")
                elif in_range:
                    txt = client.try_stream_text(ppid, "TEXT_OCR")
                    if txt is not None:
                        txt_path.write_text(txt, encoding="utf-8")
                        n_fetched += 1
                if txt is not None:
                    n_ocr += 1
                    header = f"\n\n===== p. {i}  ({label})  [{ppid}] =====\n"
                    ocr_parts.append(header + txt.strip())

            # -- ALTO (optional; also cached) ----------------------------------
            if save_alto:
                if alto_path.exists() and alto_path.stat().st_size > 0:
                    n_alto += 1
                elif in_range:
                    alto = client.try_stream_text(ppid, "ALTO")
                    if alto is not None:
                        alto_path.write_text(alto, encoding="utf-8")
                        n_alto += 1
                        n_fetched += 1

            bar.update(1)
            bar.set_postfix(fetched=n_fetched, refresh=False)
            if not bar_live and (i % 25 == 0 or i == n):
                log.info("  … %d/%d pages (%d fetched this run)", i, n, n_fetched)

            # -- polite batching: rest after every `batch_size` in-range pages -----
            # A batch served entirely from cache made no requests, so it does not
            # pause — resuming a part-downloaded volume stays fast.
            if in_range and batch_size > 0:
                batch_pos += 1
                if batch_pos >= batch_size:
                    did = n_fetched - batch_mark
                    if did and i < hi:
                        if bar_live:
                            bar.set_postfix(fetched=n_fetched,
                                            resting=f"{batch_pause:.0f}s")
                        else:
                            log.info("  batch: %d pages, %d requests — pausing %.0fs",
                                     batch_pos, did, batch_pause)
                        time.sleep(batch_pause)
                        bar.set_postfix(fetched=n_fetched)
                    batch_pos = 0
                    batch_mark = n_fetched

    # -- assemble outputs ---------------------------------------------------
    result: dict = {"pid": pid, "title": title, "pages": n,
                    "images": n_img, "ocr_pages": n_ocr, "alto_pages": n_alto,
                    "range": (lo, hi), "fetched_this_run": n_fetched,
                    "native_fallbacks": n_native_fallback,
                    "complete": n_img >= n}

    if partial:
        log.info("Cache: %d/%d scans, %d/%d OCR, %d/%d ALTO (%d requests this run).",
                 n_img, n, n_ocr, n, n_alto, n, n_fetched)
        log.info("Re-run with no --page-from/--page-to once complete to assemble "
                 "the PDF/TXT (that pass fetches nothing).")
        return result

    if make_pdf and image_paths:
        out_pdf = out_dir / f"{slug}.pdf"
        backend = _build_pdf(image_paths, out_pdf)
        size_mb = out_pdf.stat().st_size / 1e6
        log.info("PDF   -> %s  (%d pp, %.1f MB, via %s)", out_pdf.name, n_img, size_mb, backend)
        result["pdf"] = str(out_pdf)
        result["pdf_backend"] = backend
    elif make_pdf:
        log.warning("No page images fetched — PDF not written.")

    if make_txt and ocr_parts:
        out_txt = out_dir / f"{slug}.txt"
        head = (f"OCR text — {title}\nKramerius PID: {pid}\n"
                f"Source host: {client.base}\nPages with OCR: {n_ocr}/{n}\n"
                + "=" * 70)
        out_txt.write_text(head + "".join(ocr_parts) + "\n", encoding="utf-8")
        log.info("TXT   -> %s  (%d/%d pages had OCR)", out_txt.name, n_ocr, n)
        result["txt"] = str(out_txt)

    if not keep_pages and make_pdf and n_missing_img == 0 and not (per_page_txt or save_alto):
        # PDF is complete and the user asked for no per-page artefacts -> tidy up
        # (the per-page .txt files are written unconditionally as resume state,
        # so they go too when they were not requested).
        for p in image_paths:
            try:
                p.unlink()
            except OSError:
                pass
        for p in pages_dir.glob("*.txt"):
            try:
                p.unlink()
            except OSError:
                pass
        try:
            pages_dir.rmdir()
        except OSError:
            pass
        log.info("Cleaned page cache (%s).", pages_dir.name)
    elif not keep_pages:
        log.info("Kept page cache %s (missing images or per-page/ALTO outputs present).",
                 pages_dir.name)

    if n_missing_img:
        log.warning("%d/%d pages had no downloadable IMG_FULL "
                    "(licensed? try --fallback-preview).", n_missing_img, n)
    return result

# CLI

def _build_argparser() -> argparse.ArgumentParser:
    p = argparse.ArgumentParser(
        description="Download a Kramerius 5 document (all pages) as PDF + OCR TXT.",
        formatter_class=argparse.ArgumentDefaultsHelpFormatter,
    )
    src = p.add_mutually_exclusive_group(required=True)
    src.add_argument("--url", help="viewer URL, e.g. https://www.digitalniknihovna.cz/dsmo/view/uuid:…")
    src.add_argument("--uuid", help="bare document pid, e.g. uuid:6ea5d3ce-… (or the 36-char id)")
    p.add_argument("--out", default="library/downloads", help="output directory")
    p.add_argument("--host", default=None,
                   help="Kramerius backend host (auto for known portals; default DSMO)")
    p.add_argument("--name", default=None, help="override the output filename stem")
    p.add_argument("--no-pdf", action="store_true", help="skip the PDF (OCR only)")
    p.add_argument("--no-txt", action="store_true", help="skip the OCR TXT (PDF only)")
    p.add_argument("--per-page-txt", action="store_true", help="also write one .txt per page")
    p.add_argument("--alto", action="store_true", help="also save per-page ALTO xml")
    p.add_argument("--fallback-preview", action="store_true",
                   help="use IMG_PREVIEW when IMG_FULL is blocked (licensed pages)")
    p.add_argument("--native-images", action="store_true",
                   help="take scans at native size from the host's IIIF image server "
                        "(IMG_FULL is scaled to 1500 px wide on DSMO)")
    p.add_argument("--keep-pages", action="store_true",
                   help="keep the per-page image cache after building the PDF")
    p.add_argument("--page-from", type=int, default=1,
                   help="first page to fetch (1-based, inclusive)")
    p.add_argument("--page-to", type=int, default=None,
                   help="last page to fetch (1-based, inclusive). A partial range "
                        "fills the cache only; re-run with no range to assemble.")
    p.add_argument("--batch-size", type=int, default=20,
                   help="pages per batch before pausing (0 = no batching)")
    p.add_argument("--batch-pause", type=float, default=10.0,
                   help="seconds to rest between batches")
    p.add_argument("--delay", type=float, default=0.4, help="seconds between requests")
    p.add_argument("--timeout", type=float, default=60.0, help="per-request timeout (s)")
    p.add_argument("--retries", type=int, default=4, help="retries per request")
    p.add_argument("--no-verify-tls", action="store_true", help="disable TLS verification")
    p.add_argument("--no-progress", action="store_true",
                   help="no progress bar; log every 25 pages instead")
    p.add_argument("-v", "--verbose", action="store_true", help="debug logging")
    return p


def main(argv: list[str] | None = None) -> int:
    args = _build_argparser().parse_args(argv)
    logging.basicConfig(
        level=logging.DEBUG if args.verbose else logging.INFO,
        format="%(message)s",
    )
    try:
        download_document(
            args.url or args.uuid,
            out_dir=args.out,
            host=args.host,
            make_pdf=not args.no_pdf,
            make_txt=not args.no_txt,
            per_page_txt=args.per_page_txt,
            save_alto=args.alto,
            fallback_preview=args.fallback_preview,
            native_images=args.native_images,
            delay=args.delay,
            verify_tls=not args.no_verify_tls,
            keep_pages=args.keep_pages,
            name=args.name,
            page_from=args.page_from,
            page_to=args.page_to,
            timeout=args.timeout,
            retries=args.retries,
            batch_size=args.batch_size,
            batch_pause=args.batch_pause,
            progress=not args.no_progress,
        )
    except Exception as exc:
        log.error("FAILED: %s", exc)
        return 1
    return 0


if __name__ == "__main__":
    sys.exit(main())
