How it works

The scheme in utils/parsing/education.py was built from two secondary works — Moore (2020) for the general ladder, Lassnigg (2015) for the vocational branch. Neither is a count of schools: Moore describes the law, and Lassnigg's own quantitative series begins in 1924, in the Republic of Austria, on territory this sample does not cover. So the six rungs, and in particular the decision to keep the pokračovací continuation school off the ordinal, have never been checked against a source that could contradict them.

Nothing else in the project can do it. data_checks.py asks whether the columns are mutually consistent, which they would be if the whole scheme were wrong; the Fidler check reaches units, not schools; and the occupation checks use education as a predictor without ever validating it. VALIDATION.md lists education only under "What none of them reach".

The source here is the administration's own annual census of its schools — Österreichische Statistik XCIII/1, Statistik der Unterrichtsanstalten … für das Jahr 1908/1909 (Wien 1912) — transcribed to unterricht_t{19,20,34}_*.csv and gated by check_unterricht_transcription.py. It is contemporaneous with the years this cohort was at school, it covers Böhmen, Mähren and Schlesien specifically, and it splits every school type by Unterrichtssprache, so the benchmark can be restricted to Czech-language institutions rather than to all of Cisleithania.

What this cannot do

  • Hungary. The volume is "in den im Reichsrate vertretenen Königreichen und Ländern" — Cisleithania by definition. Slovak and Rusyn births are outside it, and D-08 stays open on exactly that. Every test below restricts to Cisleithanian-born records and says so.
  • Flow versus stock. The volume counts pupils enrolled in one year, 1908/09. The legionnaire field records the schooling of men born mostly 1875-1900, i.e. an accumulated stock observed years later. The two are not the same quantity and a share from one is not an estimate of the other. run_composition therefore tests ordering and magnitude, with a placebo, and never equality — a close match would be luck, not corroboration.
  • Institutions versus pupils. Tables 20 and 34 count schools; some columns count pupils. A ratio of school counts is not a ratio of people, and where only school counts exist the test says so rather than pretending otherwise.
  • Nothing here is causal, and nothing here writes.

Run: python utils/reference_tools/education/run_unterricht_check.py Emits: nothing — prints the result for reference/VALIDATION_EDUCATION.md. This is a validation script, never a pipeline input; it writes no file and touches no code column.

def run_taxonomy() -> None:
    """Does every rung name a school the volume actually enumerates, and vice versa?"""
    from utils.parsing.education import INSTITUTIONS

    print("1. TAXONOMY — the ladder against the state's own list of school kinds")
    print()

    # What the volume enumerates, by the section that carries it.
    volume = {
        "Universitäten / technische Hochschulen": ["university", "technical"],
        "theologische Lehranstalten": ["seminary"],
        "Kunstakademien und verwandte Lehranstalten": ["conservatory"],
        "Gymnasien und Realgymnasien": ["gymnasium"],
        "Realschulen": ["realschule"],
        "Lehrer- und Lehrerinnenbildungsanstalten": ["teacher"],
        "höhere Handelsschulen / Handelsakademien": ["commercial_academy"],
        "kommerzielle Tagesschulen (Handelsschulen)": ["commercial"],
        "kaufmännische Fortbildungsschulen": ["continuation"],
        "Staatsgewerbeschulen und verwandte Anstalten": ["industrial", "industrial_higher"],
        "Fachschulen für einzelne gewerbliche Zweige": ["trade"],
        "gewerbliche Fortbildungs- und Zeichenschulen": ["continuation", "continuation_ind"],
        "Schulen für Land- und Forstwirtschaft": ["agricultural"],
        "allgemeine Volksschulen": ["elementary"],
        "Bürgerschulen": ["burgher"],
        # Enumerated by the volume with no token of its own:
        "Handwerkerschulen": [],
        "Notschulen": [],
    }

    covered = {k for keys in volume.values() for k in keys}
    unreached = [k for k in INSTITUTIONS if k not in covered]
    untokened = [name for name, keys in volume.items() if not keys]

    print(f"   rungs in INSTITUTIONS ............ {len(INSTITUTIONS)}")
    print(f"   matched to a school kind ......... {len(covered)}")
    print(f"   rungs the volume does not list ... {len(unreached)}"
          f"{': ' + ', '.join(unreached) if unreached else ''}")
    print(f"   school kinds with no token ....... {len(untokened)}"
          f"{': ' + ', '.join(untokened) if untokened else ''}")
    print()
    print("   Both gaps are real and neither is a defect in the parser:")
    print("     - `cadet`, `illiterate`, `no_school` are not schools the k.k. Ministerium")
    print("       für Kultus und Unterricht counted (the Kadettenschule is a military")
    print("       establishment, and illiteracy is a census category, not an institution).")
    t34 = _load("unterricht_t34_volksschulen.csv")
    t34l = t34[t34["row_kind"] == "land"].set_index("land")
    print("     - `Handwerkerschule` is folded into `trade`; the volume counts 13 in the")
    print("       whole empire, 8 of them in Böhmen, so the merge costs almost nothing.")
    print(f"     - `Notschule` has no token, and does not need one here: "
          f"{int(t34l.loc[CZECH_LANDS, 'notschulen'].sum())} in the Czech lands "
          f"against {int(t34l['notschulen'].sum())} in Cisleithania "
          f"(Tirol alone has {int(t34l.loc['Tirol', 'notschulen'])}).")
    print()

def run_continuation() -> None:
    """The `pok.` decision: does the state file the continuation school apart?"""
    t20 = _load("unterricht_t20_gewerbeschulen.csv")
    t19 = _load("unterricht_t19_handelslehranstalten.csv")
    g = t20[t20["row_kind"] == "land"].set_index("land")
    h = t19[t19["row_kind"] == "land"].set_index("land")

    print("2. CONTINUATION SCHOOL — is `pok.` a rung, or a separate kind of thing?")
    print()
    print("   The volume's own categories, p. XX (gewerblich) and p. XVI (kaufmännisch),")
    print("   keep the Fortbildungsschule apart from the full-time schools. Böhmen:")
    print()
    rows = []
    for land in CZECH_LANDS + ["Im ganzen"]:
        src = g if land != "Im ganzen" else t20[t20["row_kind"] == "total"].set_index("land")
        r = src.loc[land]
        full = int(r["staatsgewerbe_anstalten"] + r["fachschulen_anstalten"]
                   + r["handwerker_anstalten"])
        full_s = int(r["staatsgewerbe_schueler"] + r["fachschulen_schueler"]
                     + r["handwerker_schueler"])
        rows.append({
            "Land": land,
            "full-time Anstalten": full,
            "Fortbild. Anstalten": int(r["fortbildung_anstalten"]),
            "full-time Schüler": full_s,
            "Fortbild. Schüler": int(r["fortbildung_schueler"]),
            "Fortbild. % of pupils":
                round(100 * r["fortbildung_schueler"] / r["zusammen_schueler"], 1),
        })
    print(pd.DataFrame(rows).to_string(index=False))
    print()
    print("   Commercially the same split holds — kaufmännische Fortbildungsschulen are")
    print("   counted apart from the höhere Handelsschulen and the Tagesschulen:")
    print(f"     Böhmen: {int(h.loc['Böhmen', 'hoehere_handelsschulen'])} höhere + "
          f"{int(h.loc['Böhmen', 'tagesschulen_oeffentliche'] + h.loc['Böhmen', 'tagesschulen_vereine_privat'])}"
          f" Tagesschulen vs {int(h.loc['Böhmen', 'kaufm_fortbildungsschulen'])}"
          f" Fortbildungsschulen")
    print()
    print("   VERDICT: the administration files the continuation school as its own")
    print("   category in both branches, and it is the mass institution in each. Keeping")
    print("   `continuation` off the ordinal (INSTITUTIONS ordinal=None) agrees with the")
    print("   source. The v1.0.0 reading — `pok.` as Upper secondary, level with `gym.` —")
    print("   would have put the largest and least selective school kind in the empire at")
    print("   the top of the ladder.")
    print()

def run_klassen() -> None:
    """Table 34 against `education_complete`: classes are not years."""
    t34 = _load("unterricht_t34_volksschulen.csv")
    lands = t34[t34["row_kind"] == "land"].set_index("land")
    total = t34[t34["row_kind"] == "total"].iloc[0]
    kl = [f"klassen_{i}" for i in range(1, 9)]

    print("3. TABLE 34 — the eight-class Volksschule `education_complete` assumes")
    print()
    dist = pd.DataFrame({
        "classes": range(1, 9),
        "Cisleithania": [int(total[c]) for c in kl],
        "Böhmen": [int(lands.loc["Böhmen", c]) for c in kl],
        "Czech lands": [int(lands.loc[CZECH_LANDS, c].sum()) for c in kl],
    })
    print(dist.to_string(index=False))
    print()

    L = _legion(["education_top", "education_years_elementary", "education_complete",
                 LAND_COL])
    e = L[L["education_top"].eq("elementary") & _czech_lands(L)]
    stated = e[e["education_years_elementary"].notna()]
    by_year = (stated.groupby("education_years_elementary")["education_complete"]
               .value_counts().unstack(fill_value=0))

    print(f"   Czech-lands-born records with education_top == 'elementary' and a stated"
          f" year count: {len(stated):,}")
    print()
    print(by_year.to_string())
    print()
    n8 = int(total["klassen_8"])
    n8_cz = int(lands.loc[CZECH_LANDS, "klassen_8"].sum())
    five = int(lands.loc["Böhmen", "klassen_5"])
    n_true = int(stated["education_complete"].eq(True).sum())
    n_ob5 = int(stated[stated["education_years_elementary"].eq(5)]
                ["education_complete"].eq(False).sum())
    print(f"   `education.py` scores completion for a bare Volksschule against **8**")
    print(f"   (Moore p. 30). The volume counts {n8} eight-class Volksschulen in all of")
    print(f"   Cisleithania and {n8_cz} in the Czech lands, against {five:,} five-class")
    print(f"   schools in Böhmen alone.")
    print()
    print(f"   Consequences in data/final:")
    print(f"     {n_true:,} records are scored complete against a school form that")
    print(f"       barely existed;")
    print(f"     {n_ob5:,} records reading `ob. 5` — the modal *full* Bohemian")
    print(f"       Volksschule — are scored incomplete.")
    print()
    print("   VERDICT: FAILS. Moore's eight years are a legal obligation spanning")
    print("   institutions (Volksschule 5 + Bürgerschule 3); Table 34's classes are an")
    print("   institutional form. `Vzdělání`'s bare `ob. N` does not say which it records,")
    print("   and `education_complete` currently resolves that ambiguity by assumption.")
    print("   This is the 'rule narrower than its source' shape (cf. ranks 1.4.0,")
    print("   occupations 1.1.0, education 1.0.0). See D-53.")
    print()

def run_composition() -> None:
    """Continuation : full-time vocational — the records against the enrolment."""
    t20 = _load("unterricht_t20_gewerbeschulen.csv")
    g = t20[t20["row_kind"] == "land"].set_index("land")

    def bench(lands: list[str]) -> float:
        r = g.loc[lands].sum()
        full = (r["staatsgewerbe_schueler"] + r["fachschulen_schueler"]
                + r["handwerker_schueler"])
        return float(r["fortbildung_schueler"] / full)

    # Built from `education_institutions`, not from the ordinal: a record naming both a
    # Gymnasium and a Handelsschule has education_ord 4, so counting full-time vocational
    # as `ord == 3` would silently drop it. The two sets overlap (a man can attend both),
    # so the overlap is reported rather than assumed away.
    FULL_TIME = {"commercial", "industrial", "trade", "agricultural",
                 "commercial_academy", "industrial_higher"}
    L = _legion(["education", "education_institutions", "education_apprentice", LAND_COL])
    sub = L[_czech_lands(L) & L["education"].notna()]
    inst = sub["education_institutions"].fillna("")
    has_full = inst.map(lambda x: bool(FULL_TIME & set(str(x).split("|"))))
    appr = sub["education_apprentice"].fillna(False).astype(bool)
    n_a, n_b = int(appr.sum()), int(has_full.sum())
    both = int((appr & has_full).sum())
    sample = n_a / n_b

    print("4. COMPOSITION — continuation : full-time vocational")
    print()
    print(f"   Sample (Czech-lands-born with a non-empty Vzdělání, n={len(sub):,}):")
    print(f"     names a continuation school (A) ..... {n_a:,}")
    print(f"     names a full-time vocational (B) .... {n_b:,}")
    print(f"     both ................................ {both:,}")
    print(f"     ratio A:B ........................... {sample:.2f}")
    print()
    rows = [{"benchmark": "Czech lands (Böhmen+Mähren+Schlesien)",
             "pupils ratio": round(bench(CZECH_LANDS), 2), "kind": "matched"}]
    for land in PLACEBO_LANDS:
        rows.append({"benchmark": land, "pupils ratio": round(bench([land]), 2),
                     "kind": "placebo"})
    b = pd.DataFrame(rows)
    # Compared in logs because these are ratios: |log(benchmark) - log(sample)| treats
    # "twice as large" and "half as large" as equally far off, as a raw difference
    # would not.
    b["|log gap|"] = b["pupils ratio"].map(
        lambda x: round(abs(math.log(x) - math.log(sample)), 3))
    print(b.to_string(index=False))
    print()
    matched = b.loc[b["kind"] == "matched", "|log gap|"].iloc[0]
    placebos = b.loc[b["kind"] == "placebo", "|log gap|"]
    separates = bool((matched < placebos).all())
    print(f"   Placebo separates: {separates}")
    print()
    print("   VERDICT: INCONCLUSIVE as a placebo test, INFORMATIVE as a level comparison.")
    print()
    print("   The placebo does not separate, and on inspection it cannot: the benchmark")
    print("   ratio varies across crownlands for reasons that have nothing to do with how")
    print("   well a crownland describes this sample — Tirol's low ratio comes from its")
    print("   many Fachschulen, not from any affinity with Czech births. The placebo is")
    print("   not exchangeable with the treatment, so its ordering carries no information")
    print("   and is reported here only so that nobody re-runs it expecting one.")
    print()
    print(f"   What the levels do say is worth keeping. In 1908/09 the Czech lands had")
    print(f"   {bench(CZECH_LANDS):.1f} continuation pupils for every full-time vocational")
    print(f"   pupil; the records name them at {sample:.2f} to one — roughly")
    print(f"   {bench(CZECH_LANDS) / sample:.0f}x fewer, and the gap survives every")
    print("   reasonable reconstruction of the two sets.")
    print()
    print("   The likeliest reading is that `pok.` is **under-recorded**. The continuation")
    print("   school was compulsory, part-time and unremarkable; a man setting down his")
    print("   schooling names the trade school he chose, not the evening classes he was")
    print("   obliged to sit. Some of the gap is also flow-vs-stock (a 2-3 year part-time")
    print("   course turns over faster than a multi-year full-time one) and some is")
    print("   selection into the Legion, and this design cannot apportion it.")
    print()
    print("   Consequence for the paper: `education_apprentice` (6.6% of records) is a")
    print("   **lower bound** on apprenticeship, not a rate. It should not be read as the")
    print("   share of the cohort that served an apprenticeship, and a specification that")
    print("   treats it as an exhaustive category will understate the group.")
    print()

def run_language() -> None:
    """The benchmark restricted to Czech-language institutions."""
    t34 = _load("unterricht_t34_volksschulen.csv")
    lands = t34[t34["row_kind"] == "land"].set_index("land")
    tot = t34[t34["row_kind"] == "total"].iloc[0]

    print("5. LANGUAGE — the Czech-language share of the benchmark")
    print()
    rows = []
    for land in CZECH_LANDS:
        r = lands.loc[land]
        rows.append({
            "Land": land,
            "Bürgerschulen": int(r["buergerschulen_total"]),
            "deutsch": int(r["buergerschulen_deutsch"]),
            "čecho-slavisch": int(r["buergerschulen_cechoslavisch"]),
            "Czech %": round(100 * r["buergerschulen_cechoslavisch"]
                             / r["buergerschulen_total"], 1)
            if r["buergerschulen_total"] else float("nan"),
        })
    print(pd.DataFrame(rows).to_string(index=False))
    print()
    print(f"   Cisleithania: {int(tot['buergerschulen_total']):,} Bürgerschulen, of which"
          f" {int(tot['buergerschulen_cechoslavisch']):,} čecho-slavisch"
          f" ({100 * tot['buergerschulen_cechoslavisch'] / tot['buergerschulen_total']:.1f}%).")
    print()
    print("   The Bürgerschule is a minority institution everywhere:")
    print(f"     {int(tot['buergerschulen_total']):,} of"
          f" {int(tot['buergerschulen_total'] + tot['volksschulen_total']):,}"
          f" public elementary institutions"
          f" ({100 * tot['buergerschulen_total'] / (tot['buergerschulen_total'] + tot['volksschulen_total']):.1f}%),")
    print("   which is the rate the ladder's rung 2 has to be read against — it is a")
    print("   selective step, not the ordinary continuation of rung 1.")
    print()
    # A second internal contradiction in the volume, found by computing a figure it also
    # states in prose. Recorded rather than reconciled: the tabular side wins because two
    # independent places agree with it.
    grand = int(tot["buergerschulen_total"] + tot["volksschulen_total"])
    print(f"   ⚠ Source erratum: the narrative on p. XXXII gives 22.341 public elementary")
    print(f"   schools, but Table 34 sums to {grand:,} (1.266 + 20.975) and the Einleitung's")
    print(f"   own summary table on p. I also prints 22.241. The prose figure is one")
    print(f"   hundred too high; the tabular figure is used here.")
    print()

def main() -> int:
    # The tables carry German place names; a cp1250 console would mangle them and this
    # output is meant to be pasted into VALIDATION_EDUCATION.md verbatim.
    try:
        sys.stdout.reconfigure(encoding="utf-8")
    except (AttributeError, OSError):
        pass
    print("=" * 78)
    print("Österreichische Statistik XCIII/1 (1908/09) vs the education ladder")
    print("=" * 78)
    print()
    run_taxonomy()
    run_continuation()
    run_klassen()
    run_composition()
    run_language()
    return 0

"""Is the education ladder the one the Austrian state actually operated?

The scheme in `utils/parsing/education.py` was built from two secondary works — Moore (2020)
for the general ladder, Lassnigg (2015) for the vocational branch.  Neither is a count of
schools: Moore describes the law, and Lassnigg's own quantitative series begins in **1924**,
in the Republic of Austria, on territory this sample does not cover.  So the six rungs, and
in particular the decision to keep the *pokračovací* continuation school **off** the ordinal,
have never been checked against a source that could contradict them.

Nothing else in the project can do it.  `data_checks.py` asks whether the columns are
mutually consistent, which they would be if the whole scheme were wrong; the Fidler check
reaches units, not schools; and the occupation checks use education as a *predictor* without
ever validating it.  `VALIDATION.md` lists education only under "What none of them reach".

The source here is the administration's own annual census of its schools — *Österreichische
Statistik* XCIII/1, *Statistik der Unterrichtsanstalten … für das Jahr 1908/1909* (Wien 1912)
— transcribed to `unterricht_t{19,20,34}_*.csv` and gated by
`check_unterricht_transcription.py`.  It is contemporaneous with the years this cohort was at
school, it covers Böhmen, Mähren and Schlesien specifically, and it splits every school type
by *Unterrichtssprache*, so the benchmark can be restricted to Czech-language institutions
rather than to all of Cisleithania.

What this cannot do
-------------------
* **Hungary.**  The volume is *"in den im Reichsrate vertretenen Königreichen und Ländern"* —
  Cisleithania by definition.  Slovak and Rusyn births are outside it, and D-08 stays open on
  exactly that.  Every test below restricts to Cisleithanian-born records and says so.
* **Flow versus stock.**  The volume counts pupils enrolled in one year, 1908/09.  The
  legionnaire field records the schooling of men born mostly 1875-1900, i.e. an accumulated
  stock observed years later.  The two are not the same quantity and a share from one is not
  an estimate of the other.  `run_composition` therefore tests *ordering and magnitude*, with
  a placebo, and never equality — a close match would be luck, not corroboration.
* **Institutions versus pupils.**  Tables 20 and 34 count schools; some columns count pupils.
  A ratio of school counts is not a ratio of people, and where only school counts exist the
  test says so rather than pretending otherwise.
* **Nothing here is causal, and nothing here writes.**

Run:   python utils/reference_tools/education/run_unterricht_check.py
Emits: nothing — prints the result for `reference/VALIDATION_EDUCATION.md`.  This is a
       validation script, never a pipeline input; it writes no file and touches no code
       column.
"""
from __future__ import annotations

import math
import sys
from pathlib import Path

import pandas as pd

ROOT = Path(__file__).resolve().parents[3]
sys.path.insert(0, str(ROOT))

__version__ = "1.0.0"

HERE = ROOT / "reference" / "education"
FIN = ROOT / "data" / "final"

# The crownlands this sample was actually schooled in.
CZECH_LANDS = ["Böhmen", "Mähren", "Schlesien"]
# Placebo benchmarks: crownlands the sample was *not* schooled in, whose vocational mix
# differs.  If the Czech lands do not fit Czech-lands births better than these do, the
# design has no power and the check must say so rather than claim a pass.
PLACEBO_LANDS = ["Galizien", "Tirol"]

# The benchmark's territory, named in the sample's own terms. `birth_land` is used rather
# than `birth_okres`, which is populated for Slovak births as well (11,400 records carry
# both it and `birth_jaras_id`) and so does not separate the two census frames.
LAND_COL = "birth_land"
CZECH_LANDS_SAMPLE = "Czech lands"


def _load(name: str) -> pd.DataFrame:
    return pd.read_csv(HERE / name)


def _legion(columns: list[str]) -> pd.DataFrame:
    return pd.read_parquet(FIN / "persons" / "legionnaires_clean.parquet", columns=columns)


def _czech_lands(df: pd.DataFrame) -> pd.Series:
    """Records born in Böhmen, Mähren or Schlesien — the benchmark's own territory.

    Slovak and Rusyn births are deliberately excluded: the volume is Cisleithanian by
    definition and cannot speak to them.  That exclusion is the D-08 gap, not a
    convenience.
    """
    return df[LAND_COL].eq(CZECH_LANDS_SAMPLE)

def run_continuation() -> None:
    """The `pok.` decision: does the state file the continuation school apart?"""
    t20 = _load("unterricht_t20_gewerbeschulen.csv")
    t19 = _load("unterricht_t19_handelslehranstalten.csv")
    g = t20[t20["row_kind"] == "land"].set_index("land")
    h = t19[t19["row_kind"] == "land"].set_index("land")

    print("2. CONTINUATION SCHOOL — is `pok.` a rung, or a separate kind of thing?")
    print()
    print("   The volume's own categories, p. XX (gewerblich) and p. XVI (kaufmännisch),")
    print("   keep the Fortbildungsschule apart from the full-time schools. Böhmen:")
    print()
    rows = []
    for land in CZECH_LANDS + ["Im ganzen"]:
        src = g if land != "Im ganzen" else t20[t20["row_kind"] == "total"].set_index("land")
        r = src.loc[land]
        full = int(r["staatsgewerbe_anstalten"] + r["fachschulen_anstalten"]
                   + r["handwerker_anstalten"])
        full_s = int(r["staatsgewerbe_schueler"] + r["fachschulen_schueler"]
                     + r["handwerker_schueler"])
        rows.append({
            "Land": land,
            "full-time Anstalten": full,
            "Fortbild. Anstalten": int(r["fortbildung_anstalten"]),
            "full-time Schüler": full_s,
            "Fortbild. Schüler": int(r["fortbildung_schueler"]),
            "Fortbild. % of pupils":
                round(100 * r["fortbildung_schueler"] / r["zusammen_schueler"], 1),
        })
    print(pd.DataFrame(rows).to_string(index=False))
    print()
    print("   Commercially the same split holds — kaufmännische Fortbildungsschulen are")
    print("   counted apart from the höhere Handelsschulen and the Tagesschulen:")
    print(f"     Böhmen: {int(h.loc['Böhmen', 'hoehere_handelsschulen'])} höhere + "
          f"{int(h.loc['Böhmen', 'tagesschulen_oeffentliche'] + h.loc['Böhmen', 'tagesschulen_vereine_privat'])}"
          f" Tagesschulen vs {int(h.loc['Böhmen', 'kaufm_fortbildungsschulen'])}"
          f" Fortbildungsschulen")
    print()
    print("   VERDICT: the administration files the continuation school as its own")
    print("   category in both branches, and it is the mass institution in each. Keeping")
    print("   `continuation` off the ordinal (INSTITUTIONS ordinal=None) agrees with the")
    print("   source. The v1.0.0 reading — `pok.` as Upper secondary, level with `gym.` —")
    print("   would have put the largest and least selective school kind in the empire at")
    print("   the top of the ladder.")
    print()

def run_klassen() -> None:
    """Table 34 against `education_complete`: classes are not years."""
    t34 = _load("unterricht_t34_volksschulen.csv")
    lands = t34[t34["row_kind"] == "land"].set_index("land")
    total = t34[t34["row_kind"] == "total"].iloc[0]
    kl = [f"klassen_{i}" for i in range(1, 9)]

    print("3. TABLE 34 — the eight-class Volksschule `education_complete` assumes")
    print()
    dist = pd.DataFrame({
        "classes": range(1, 9),
        "Cisleithania": [int(total[c]) for c in kl],
        "Böhmen": [int(lands.loc["Böhmen", c]) for c in kl],
        "Czech lands": [int(lands.loc[CZECH_LANDS, c].sum()) for c in kl],
    })
    print(dist.to_string(index=False))
    print()

    L = _legion(["education_top", "education_years_elementary", "education_complete",
                 LAND_COL])
    e = L[L["education_top"].eq("elementary") & _czech_lands(L)]
    stated = e[e["education_years_elementary"].notna()]
    by_year = (stated.groupby("education_years_elementary")["education_complete"]
               .value_counts().unstack(fill_value=0))

    print(f"   Czech-lands-born records with education_top == 'elementary' and a stated"
          f" year count: {len(stated):,}")
    print()
    print(by_year.to_string())
    print()
    n8 = int(total["klassen_8"])
    n8_cz = int(lands.loc[CZECH_LANDS, "klassen_8"].sum())
    five = int(lands.loc["Böhmen", "klassen_5"])
    n_true = int(stated["education_complete"].eq(True).sum())
    n_ob5 = int(stated[stated["education_years_elementary"].eq(5)]
                ["education_complete"].eq(False).sum())
    print(f"   `education.py` scores completion for a bare Volksschule against **8**")
    print(f"   (Moore p. 30). The volume counts {n8} eight-class Volksschulen in all of")
    print(f"   Cisleithania and {n8_cz} in the Czech lands, against {five:,} five-class")
    print(f"   schools in Böhmen alone.")
    print()
    print(f"   Consequences in data/final:")
    print(f"     {n_true:,} records are scored complete against a school form that")
    print(f"       barely existed;")
    print(f"     {n_ob5:,} records reading `ob. 5` — the modal *full* Bohemian")
    print(f"       Volksschule — are scored incomplete.")
    print()
    print("   VERDICT: FAILS. Moore's eight years are a legal obligation spanning")
    print("   institutions (Volksschule 5 + Bürgerschule 3); Table 34's classes are an")
    print("   institutional form. `Vzdělání`'s bare `ob. N` does not say which it records,")
    print("   and `education_complete` currently resolves that ambiguity by assumption.")
    print("   This is the 'rule narrower than its source' shape (cf. ranks 1.4.0,")
    print("   occupations 1.1.0, education 1.0.0). See D-53.")
    print()

def run_composition() -> None:
    """Continuation : full-time vocational — the records against the enrolment."""
    t20 = _load("unterricht_t20_gewerbeschulen.csv")
    g = t20[t20["row_kind"] == "land"].set_index("land")

    def bench(lands: list[str]) -> float:
        r = g.loc[lands].sum()
        full = (r["staatsgewerbe_schueler"] + r["fachschulen_schueler"]
                + r["handwerker_schueler"])
        return float(r["fortbildung_schueler"] / full)

    # Built from `education_institutions`, not from the ordinal: a record naming both a
    # Gymnasium and a Handelsschule has education_ord 4, so counting full-time vocational
    # as `ord == 3` would silently drop it. The two sets overlap (a man can attend both),
    # so the overlap is reported rather than assumed away.
    FULL_TIME = {"commercial", "industrial", "trade", "agricultural",
                 "commercial_academy", "industrial_higher"}
    L = _legion(["education", "education_institutions", "education_apprentice", LAND_COL])
    sub = L[_czech_lands(L) & L["education"].notna()]
    inst = sub["education_institutions"].fillna("")
    has_full = inst.map(lambda x: bool(FULL_TIME & set(str(x).split("|"))))
    appr = sub["education_apprentice"].fillna(False).astype(bool)
    n_a, n_b = int(appr.sum()), int(has_full.sum())
    both = int((appr & has_full).sum())
    sample = n_a / n_b

    print("4. COMPOSITION — continuation : full-time vocational")
    print()
    print(f"   Sample (Czech-lands-born with a non-empty Vzdělání, n={len(sub):,}):")
    print(f"     names a continuation school (A) ..... {n_a:,}")
    print(f"     names a full-time vocational (B) .... {n_b:,}")
    print(f"     both ................................ {both:,}")
    print(f"     ratio A:B ........................... {sample:.2f}")
    print()
    rows = [{"benchmark": "Czech lands (Böhmen+Mähren+Schlesien)",
             "pupils ratio": round(bench(CZECH_LANDS), 2), "kind": "matched"}]
    for land in PLACEBO_LANDS:
        rows.append({"benchmark": land, "pupils ratio": round(bench([land]), 2),
                     "kind": "placebo"})
    b = pd.DataFrame(rows)
    # Compared in logs because these are ratios: |log(benchmark) - log(sample)| treats
    # "twice as large" and "half as large" as equally far off, as a raw difference
    # would not.
    b["|log gap|"] = b["pupils ratio"].map(
        lambda x: round(abs(math.log(x) - math.log(sample)), 3))
    print(b.to_string(index=False))
    print()
    matched = b.loc[b["kind"] == "matched", "|log gap|"].iloc[0]
    placebos = b.loc[b["kind"] == "placebo", "|log gap|"]
    separates = bool((matched < placebos).all())
    print(f"   Placebo separates: {separates}")
    print()
    print("   VERDICT: INCONCLUSIVE as a placebo test, INFORMATIVE as a level comparison.")
    print()
    print("   The placebo does not separate, and on inspection it cannot: the benchmark")
    print("   ratio varies across crownlands for reasons that have nothing to do with how")
    print("   well a crownland describes this sample — Tirol's low ratio comes from its")
    print("   many Fachschulen, not from any affinity with Czech births. The placebo is")
    print("   not exchangeable with the treatment, so its ordering carries no information")
    print("   and is reported here only so that nobody re-runs it expecting one.")
    print()
    print(f"   What the levels do say is worth keeping. In 1908/09 the Czech lands had")
    print(f"   {bench(CZECH_LANDS):.1f} continuation pupils for every full-time vocational")
    print(f"   pupil; the records name them at {sample:.2f} to one — roughly")
    print(f"   {bench(CZECH_LANDS) / sample:.0f}x fewer, and the gap survives every")
    print("   reasonable reconstruction of the two sets.")
    print()
    print("   The likeliest reading is that `pok.` is **under-recorded**. The continuation")
    print("   school was compulsory, part-time and unremarkable; a man setting down his")
    print("   schooling names the trade school he chose, not the evening classes he was")
    print("   obliged to sit. Some of the gap is also flow-vs-stock (a 2-3 year part-time")
    print("   course turns over faster than a multi-year full-time one) and some is")
    print("   selection into the Legion, and this design cannot apportion it.")
    print()
    print("   Consequence for the paper: `education_apprentice` (6.6% of records) is a")
    print("   **lower bound** on apprenticeship, not a rate. It should not be read as the")
    print("   share of the cohort that served an apprenticeship, and a specification that")
    print("   treats it as an exhaustive category will understate the group.")
    print()

def run_language() -> None:
    """The benchmark restricted to Czech-language institutions."""
    t34 = _load("unterricht_t34_volksschulen.csv")
    lands = t34[t34["row_kind"] == "land"].set_index("land")
    tot = t34[t34["row_kind"] == "total"].iloc[0]

    print("5. LANGUAGE — the Czech-language share of the benchmark")
    print()
    rows = []
    for land in CZECH_LANDS:
        r = lands.loc[land]
        rows.append({
            "Land": land,
            "Bürgerschulen": int(r["buergerschulen_total"]),
            "deutsch": int(r["buergerschulen_deutsch"]),
            "čecho-slavisch": int(r["buergerschulen_cechoslavisch"]),
            "Czech %": round(100 * r["buergerschulen_cechoslavisch"]
                             / r["buergerschulen_total"], 1)
            if r["buergerschulen_total"] else float("nan"),
        })
    print(pd.DataFrame(rows).to_string(index=False))
    print()
    print(f"   Cisleithania: {int(tot['buergerschulen_total']):,} Bürgerschulen, of which"
          f" {int(tot['buergerschulen_cechoslavisch']):,} čecho-slavisch"
          f" ({100 * tot['buergerschulen_cechoslavisch'] / tot['buergerschulen_total']:.1f}%).")
    print()
    print("   The Bürgerschule is a minority institution everywhere:")
    print(f"     {int(tot['buergerschulen_total']):,} of"
          f" {int(tot['buergerschulen_total'] + tot['volksschulen_total']):,}"
          f" public elementary institutions"
          f" ({100 * tot['buergerschulen_total'] / (tot['buergerschulen_total'] + tot['volksschulen_total']):.1f}%),")
    print("   which is the rate the ladder's rung 2 has to be read against — it is a")
    print("   selective step, not the ordinary continuation of rung 1.")
    print()
    # A second internal contradiction in the volume, found by computing a figure it also
    # states in prose. Recorded rather than reconciled: the tabular side wins because two
    # independent places agree with it.
    grand = int(tot["buergerschulen_total"] + tot["volksschulen_total"])
    print(f"   ⚠ Source erratum: the narrative on p. XXXII gives 22.341 public elementary")
    print(f"   schools, but Table 34 sums to {grand:,} (1.266 + 20.975) and the Einleitung's")
    print(f"   own summary table on p. I also prints 22.241. The prose figure is one")
    print(f"   hundred too high; the tabular figure is used here.")
    print()


# ─────────────────────────────────────────────────────────────────────────────────
def main() -> int:
    # The tables carry German place names; a cp1250 console would mangle them and this
    # output is meant to be pasted into VALIDATION_EDUCATION.md verbatim.
    try:
        sys.stdout.reconfigure(encoding="utf-8")
    except (AttributeError, OSError):
        pass
    print("=" * 78)
    print("Österreichische Statistik XCIII/1 (1908/09) vs the education ladder")
    print("=" * 78)
    print()
    run_taxonomy()
    run_continuation()
    run_klassen()
    run_composition()
    run_language()
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
