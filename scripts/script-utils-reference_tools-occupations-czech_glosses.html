How it works

Rather than assign HISCO codes from memory, each Czech key gets a German gloss. German is the right bridge for this corpus — these are 1910 Bohemian, Moravian and Silesian occupational titles, whose German equivalents the HISCO project has already coded (hisco_occupation_link_combined.csv, 1,199 distinct German labels) — and it is also one of OccCANINE's 13 training languages, so the same gloss feeds the independent check. The English gloss is the fallback lookup against the authority's own label_en.

Only atomic keys are glossed. Compounds are decomposed by utils.parsing.occupations.split_occupations on token boundaries, so rolník zedník, mlynářský dělník and waiter číšník need no entry of their own.

HISCO_OVERRIDE carries codes decided by hand — where the bridge is ambiguous, where the German equivalent does not exist, or where a documented judgement call is needed (see reference/OCCUPATION_CODING.md).

ADJUDICATED is the answer sheet: every key the 2026-08-26 conflict workbook put in front of a human, and what came back. It is the only thing that clears a review flag, so a word that is still flagged is one nobody has settled — not one nobody has read.

Run: python utils/reference_tools/occupations/run_link_bridge.py (applies these glosses) Consumed by utils/reference_tools/occupations/run_link_bridge.py only — not a pipeline input.

def duplicate_keys() -> dict[str, list[int]]:
    """Keys written twice in either dict above, as ``key -> [line, line]``.

    A duplicate literal key cannot be detected at runtime: Python builds the dict by
    assigning in order, so the earlier entry is gone before anyone can look. `finanční
    stráž` was defined twice for months — 58230 *Detective* and then 58220 — and the last
    one silently won. That it happened to be the better reading was luck. So this reads the
    module's own source instead of its value, and `run_link_bridge.py` calls it.
    """
    import ast
    import collections
    from pathlib import Path

    tree = ast.parse(Path(__file__).read_text(encoding="utf-8"))
    dupes: dict[str, list[int]] = {}
    for node in tree.body:
        target = getattr(node, "target", None)
        if getattr(target, "id", None) not in {"CZ_GLOSS", "HISCO_OVERRIDE", "ADJUDICATED"}:
            continue
        seen = collections.Counter(k.value for k in node.value.keys)
        for key, count in seen.items():
            if count > 1:
                dupes[key] = [k.lineno for k in node.value.keys if k.value == key]
    return dupes

"""
czech_glosses.py — Czech occupational key -> German / English gloss
===================================================================
The authored half of the occupation pipeline, and the piece no external source supplies:
neither the History of Work title dictionary nor OccCANINE covers Czech.

Rather than assign HISCO codes from memory, each Czech key gets a **German** gloss. German
is the right bridge for this corpus — these are 1910 Bohemian, Moravian and Silesian
occupational titles, whose German equivalents the HISCO project has already coded
(``hisco_occupation_link_combined.csv``, 1,199 distinct German labels) — and it is also one
of OccCANINE's 13 training languages, so the same gloss feeds the independent check. The
English gloss is the fallback lookup against the authority's own ``label_en``.

Only **atomic** keys are glossed. Compounds are decomposed by
``utils.parsing.occupations.split_occupations`` on token boundaries, so ``rolník zedník``,
``mlynářský dělník`` and ``waiter číšník`` need no entry of their own.

``HISCO_OVERRIDE`` carries codes decided by hand — where the bridge is ambiguous, where the
German equivalent does not exist, or where a documented judgement call is needed (see
``reference/OCCUPATION_CODING.md``).

``ADJUDICATED`` is the answer sheet: every key the 2026-08-26 conflict workbook put in front
of a human, and what came back. It is the only thing that clears a ``review`` flag, so a word
that is still flagged is one nobody has settled — not one nobody has read.

Run:  python utils/reference_tools/occupations/run_link_bridge.py     (applies these glosses)
Consumed by utils/reference_tools/occupations/run_link_bridge.py only — not a pipeline input.
"""

def duplicate_keys() -> dict[str, list[int]]:
    """Keys written twice in either dict above, as ``key -> [line, line]``.

    A duplicate literal key cannot be detected at runtime: Python builds the dict by
    assigning in order, so the earlier entry is gone before anyone can look. `finanční
    stráž` was defined twice for months — 58230 *Detective* and then 58220 — and the last
    one silently won. That it happened to be the better reading was luck. So this reads the
    module's own source instead of its value, and `run_link_bridge.py` calls it.
    """
    import ast
    import collections
    from pathlib import Path

    tree = ast.parse(Path(__file__).read_text(encoding="utf-8"))
    dupes: dict[str, list[int]] = {}
    for node in tree.body:
        target = getattr(node, "target", None)
        if getattr(target, "id", None) not in {"CZ_GLOSS", "HISCO_OVERRIDE", "ADJUDICATED"}:
            continue
        seen = collections.Counter(k.value for k in node.value.keys)
        for key, count in seen.items():
            if count > 1:
                dupes[key] = [k.lineno for k in node.value.keys if k.value == key]
    return dupes
