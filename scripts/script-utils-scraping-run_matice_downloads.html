How it works

Matice česká

I. Jména p.p. zakladatelův Matice české na konci r. … is the society's own yearly list of its founders (zakladatelé, members who paid the one-off founder's contribution). Each entry gives name, occupation, residence, the year the person became a founder (r. 52) and the running membership number (č. 2236). The 1890 issue also lists the deceased founders (number and year of death) and the corporate founders (reading clubs, schools, municipalities; Roman numerals), so on its own it reaches back to 1831. These are the only two issues in MZK; the physical copies are held by the Národní knihovna ČR.

Matice moravská

The Brno society printed its lists inside its own journal, Časopis Matice moravské (MZK periodical uuid:b3dde880-8de5-11e5-b433-5ef3fc9bb22f), so most jobs here are a slice of an issue, given by its first and last printed page label and resolved to page positions at run time. Where a list was found, from the obsah ročníku of every public volume (1869–1882, 1891–1915; checked 2026-10-29): two full rosters — roč. 15 (1891), bound with the report for 1889, and roč. 33 (1909), as of 1 March 1909 with a tabulation by occupation and place — and the partial lists of 1876, 1877 and 1891. The 1878 list is in the Internet Archive copy saved by hand (IA_Casopis-Matice-moravske_1878-1880.pdf), not fetched here.

Matice česká payments, 1885–1914

The founder register stops with the 1891 issue, but every issue of the Časopis Musea království Českého (Národní muzeum, kramerius.nm.cz, periodical uuid:c6e7b030-14d0-11df-9021-000d606f5dc6) closes with a Zpráva o Matici České that lists, month by month, everyone who paid into the society — name, occupation, residence and amount ("Klein Vác., rolník v Hřivici 105 K"), with the month's total (Úhrnem). The founder's contribution could be paid in five instalments, so these lists are the founders joining (D-184). Where they fall in each issue is found, not typed: --discover-payments searches each volume's full text, keeps the pages that carry at least MIN_PAYMENTS amount-terminated entries, widens each run to its neighbours, and writes the slices to PAYMENT_MANIFEST; the jobs mcpYYYY-I (year, issue) are read from that file. The OCR read during discovery is kept in the job's page cache, so the download does not fetch it twice. This host serves no ALTO (info/data: "alto": false), so these pages are read from their OCR text.

Politeness

  • Sequential: one job after the other, one request at a time, DELAY seconds apart, with a BATCH_PAUSE rest every BATCH_SIZE pages (scraper_kramerius7's batching).
  • One attempt per request (retries=1): a failed page is skipped and logged, and a re-run fetches only what is missing, since every page artefact is cached. The exception is kramerius.nm.cz, which now and then drops a TLS handshake (UNEXPECTED_EOF; 2026-11-03, while curl and the next request succeed): there NM_RETRIES attempts, the client waiting 9 s, then 18 s.
  • robots.txt is read first and obeyed (on 2026-10-29 neither host published one: the API answers 404, the viewer answers its single-page app).
  • The User-Agent names scraper_kramerius7 and its version, nothing else. No sign-in, cookie or credential of any kind is sent.
  • TLS is verified (the local certifi bundle accepts this host).

def robots_disallowed(urls: list[str]) -> list[str]:
    """The *urls* their host's robots.txt forbids this script (none where a host publishes
    no file)."""
    agent = scraper_kramerius7.USER_AGENT
    blocked = []
    for host in dict.fromkeys(scraper_kramerius7.parse_host(u) for u in urls):
        try:
            resp = requests.get(f"{host}/robots.txt", headers={"User-Agent": agent}, timeout=30)
        except requests.RequestException:
            continue
        if resp.status_code != 200 or "html" in resp.headers.get("Content-Type", ""):
            continue
        rp = robotparser.RobotFileParser()
        rp.parse(resp.text.splitlines())
        blocked += [u for u in urls if u.startswith(host) and not rp.can_fetch(agent, u)]
    return blocked

def resolve_slice(client: scraper_kramerius7.Kramerius7Client, pid: str,
                  first: str, last: str) -> tuple[int, int, int]:
    """1-based positions (lo, hi) of the printed labels *first*..*last*, and the page count.

    Refuses a label that is missing or printed twice, so a re-paginated item fails loudly
    instead of fetching the wrong pages.
    """
    labels = [str(p["label"]) for p in client.iter_pages(pid)]
    pos = []
    for lab in (first, last):
        hits = [i for i, x in enumerate(labels, 1) if x == lab]
        if len(hits) != 1:
            raise RuntimeError(f"page label {lab!r} occurs {len(hits)} times in {pid}")
        pos.append(hits[0])
    if pos[0] > pos[1]:
        raise RuntimeError(f"slice {first}–{last} runs backwards in {pid}")
    return pos[0], pos[1], len(labels)

def check_positions(client: scraper_kramerius7.Kramerius7Client, job: dict) -> tuple[int, int, int]:
    """The job's page positions, refused if the labels found there are no longer the ones
    discovery recorded (an issue re-paginated since). Used where a label is printed twice
    or not at all, which ``resolve_slice`` cannot take."""
    labels = [str(p["label"]) for p in client.iter_pages(job["pid"])]
    lo, hi = job["positions"]
    if hi > len(labels) or (labels[lo - 1], labels[hi - 1]) != tuple(job["pages"]):
        raise RuntimeError(f"{job['key']}: positions {lo}–{hi} no longer hold "
                           f"{job['pages'][0]}–{job['pages'][1]} in {job['pid']}")
    return lo, hi, len(labels)

def list_runs(judge, hits: list[int], n_pages: int) -> list[list[int]]:
    """The page positions of an issue's payment lists as runs of consecutive pages.
    ``judge(i)`` is the number of payment entries on page *i*. A candidate page opens a
    run if it has at least ``MIN_PAYMENTS``; a run is widened while the next page out
    has any (a list may end, or a short month sit, on a page of one or two), and a gap
    of up to two pages between runs is filled."""
    keep = {i for i in hits if judge(i) >= MIN_PAYMENTS}
    grown = True
    while grown:
        grown = False
        for i in sorted(keep):
            for j in (i - 1, i + 1):
                if 1 <= j <= n_pages and j not in keep and judge(j) >= 1:
                    keep.add(j)
                    grown = True
    ordered = sorted(keep)
    for a, b in zip(ordered, ordered[1:]):
        if 1 < b - a <= 3:
            keep.update(range(a + 1, b))
    runs: list[list[int]] = []
    for i in sorted(keep):
        if runs and i == runs[-1][-1] + 1:
            runs[-1].append(i)
        else:
            runs.append([i])
    return runs

def discover_payments(client: scraper_kramerius7.Kramerius7Client, out_dir: Path,
                      years=PAYMENT_YEARS, manifest: Path = PAYMENT_MANIFEST) -> list[dict]:
    """Find every payment-list slice in the volumes of *years*; keep the OCR read on the
    way in each job's page cache; return the manifest rows. The manifest is rewritten
    after every year, and a year already in it is not searched again."""
    rows = []
    if manifest.exists():
        with manifest.open(encoding="utf-8", newline="") as fh:
            rows = list(csv.DictReader(fh))
    done = {int(r["year"]) for r in rows}
    volumes = {d.get("date.str"): d["pid"] for d in solr(
        client, f'own_parent.pid:"{NM_PERIODICAL}" AND model:periodicalvolume', "pid,date.str")}
    for year in years:
        if year in done:
            continue
        vol = volumes.get(str(year))
        if vol is None:
            log.warning("%d: no volume", year)
            continue
        hits: dict[str, set[str]] = {}
        for term in _PAYMENT_TERMS:
            q = (f'root.pid:"{NM_PERIODICAL}" AND model:page AND date.str:"{year}" '
                 f'AND text_ocr:"{term}"')
            for d in solr(client, q, "pid,own_parent.pid"):
                hits.setdefault(d.get("own_parent.pid"), set()).add(d["pid"])
        issues = solr(client, f'own_parent.pid:"{vol}" AND model:periodicalitem',
                      "pid,part.number.str")
        order = lambda d: int(re.match(r"\d*", issue_label(d.get("part.number.str"))).group() or 0)
        for issue in sorted(issues, key=order):
            if issue["pid"] not in hits:
                continue
            rows += discover_issue(client, out_dir, year, issue, hits[issue["pid"]])
        write_manifest(rows, manifest)
        log.info("%d: %d slices so far", year, len(rows))
    return rows

def discover_issue(client: scraper_kramerius7.Kramerius7Client, out_dir: Path, year: int,
                   issue: dict, candidates: set[str]) -> list[dict]:
    """The payment-list slices of one issue (see :func:`list_runs`)."""
    pages = list(client.iter_pages(issue["pid"]))
    pos = {p["pid"]: i for i, p in enumerate(pages, 1)}
    texts: dict[int, str] = {}

    def judge(i: int) -> int:
        if i not in texts:
            texts[i] = client.ocr_text(pages[i - 1]["pid"]) or ""
        return payment_entries(texts[i])

    runs = list_runs(judge, sorted(pos[c] for c in candidates if c in pos), len(pages))
    out = []
    for n, run in enumerate(runs):
        suffix = "abcdefgh"[n] if len(runs) > 1 else ""
        key = f"mcp{year}-{issue_label(issue.get('part.number.str'))}{suffix}"
        cache = out_dir / f"NM_Casopis-Musea_{key}_Matice-prispevky_pages"
        cache.mkdir(parents=True, exist_ok=True)
        for i in run:
            if texts.get(i):

        out.append({"key": key, "year": year, "issue": issue_label(issue.get("part.number.str")),

def assemble_slice(out_dir: Path, job: dict, res: dict) -> dict:
    """Build the PDF + TXT of a slice from its page cache (``download_document`` leaves a
    partial range unassembled). The cache is the job's own, so it holds only this slice."""
    lo, hi = res["range"]
    pages_dir = out_dir / f"{job['name']}_pages"
    idx = range(lo, hi + 1)
    images = [pages_dir / f"{i:04d}.jpg" for i in idx if (pages_dir / f"{i:04d}.jpg").exists()]
    texts = [(i, pages_dir / f"{i:04d}.txt") for i in idx if (pages_dir / f"{i:04d}.txt").exists()]
    alto = sum((pages_dir / f"{i:04d}.alto.xml").exists() for i in idx)
    out = dict(res, pages=len(idx), images=len(images), ocr_pages=len(texts),
               alto_pages=alto, complete=len(images) == len(idx))
    if not out["complete"]:
        return out
    pdf = out_dir / f"{job['name']}.pdf"
    scraper_kramerius7._build_pdf(images, pdf)
    head = (f"OCR text — {res['title']}, pages {lo}–{hi} of {res['pages']} "
            f"(printed {job['pages'][0]}–{job['pages'][1]})\nKramerius PID: {job['pid']}\n"
            f"Source host: {job.get('host', HOST)}\nPages with OCR: {len(texts)}/{len(idx)}\n"
            + "=" * 70)
    body = "".join(f"\n\n===== p. {i} =====\n" + p.read_text(encoding="utf-8").strip()
                   for i, p in texts)
    (out_dir / f"{job['name']}.txt").write_text(head + body + "\n", encoding="utf-8")
    out["pdf"] = str(pdf)
    log.info("PDF   -> %s  (slice %d–%d, %d pp)", pdf.name, lo, hi, len(images))
    return out

#!/usr/bin/env python3
"""
Download the digitised member lists of two Czech national societies, the *Matice
česká* and the *Matice moravská*, into ``library/associations/`` — page scans (PDF),
OCR (TXT) and ALTO word coordinates.

Matice česká
------------
*I. Jména p.p. zakladatelův Matice české na konci r. …* is the society's own yearly
list of its **founders** (*zakladatelé*, members who paid the one-off founder's
contribution). Each entry gives name, occupation, residence, the year the person
became a founder (``r. 52``) and the running membership number (``č. 2236``).
The 1890 issue also lists the deceased founders (number and year of death) and the
corporate founders (reading clubs, schools, municipalities; Roman numerals), so on
its own it reaches back to 1831. These are the only two issues in MZK; the physical
copies are held by the Národní knihovna ČR.

Matice moravská
---------------
The Brno society printed its lists inside its own journal, *Časopis Matice
moravské* (MZK periodical ``uuid:b3dde880-8de5-11e5-b433-5ef3fc9bb22f``), so most
jobs here are a **slice** of an issue, given by its first and last *printed* page
label and resolved to page positions at run time. Where a list was found, from the
*obsah ročníku* of every public volume (1869–1882, 1891–1915; checked 2026-10-29):
two **full rosters** — roč. 15 (1891), bound with the report for 1889, and roč. 33
(1909), as of 1 March 1909 with a tabulation by occupation and place — and the
partial lists of 1876, 1877 and 1891. The 1878 list is in the Internet Archive copy
saved by hand (``IA_Casopis-Matice-moravske_1878-1880.pdf``), not fetched here.

def payment_jobs(manifest: Path = PAYMENT_MANIFEST) -> list[dict]:
    """The Matice česká payment-list jobs, one per slice of an issue in *manifest*
    (written by ``--discover-payments``); none before discovery has run."""
    if not manifest.exists():
        return []
    with manifest.open(encoding="utf-8", newline="") as fh:
        rows = list(csv.DictReader(fh))
    return [{"key": r["key"], "pid": r["issue_pid"], "host": NM_HOST,
             "positions": (int(r["first_pos"]), int(r["last_pos"])),
             "pages": (r["first_label"], r["last_label"]),
             "name": f"NM_Casopis-Musea_{r['key']}_Matice-prispevky", "source": MCP_SOURCE}
            for r in rows]

def robots_disallowed(urls: list[str]) -> list[str]:
    """The *urls* their host's robots.txt forbids this script (none where a host publishes
    no file)."""
    agent = scraper_kramerius7.USER_AGENT
    blocked = []
    for host in dict.fromkeys(scraper_kramerius7.parse_host(u) for u in urls):
        try:
            resp = requests.get(f"{host}/robots.txt", headers={"User-Agent": agent}, timeout=30)
        except requests.RequestException:
            continue
        if resp.status_code != 200 or "html" in resp.headers.get("Content-Type", ""):
            continue
        rp = robotparser.RobotFileParser()
        rp.parse(resp.text.splitlines())
        blocked += [u for u in urls if u.startswith(host) and not rp.can_fetch(agent, u)]
    return blocked


def _sha256(path: Path) -> str:
    h = hashlib.sha256()
    with path.open("rb") as fh:
        for chunk in iter(lambda: fh.read(1 << 20), b""):
            h.update(chunk)
    return h.hexdigest()


def resolve_slice(client: scraper_kramerius7.Kramerius7Client, pid: str,
                  first: str, last: str) -> tuple[int, int, int]:
    """1-based positions (lo, hi) of the printed labels *first*..*last*, and the page count.

    Refuses a label that is missing or printed twice, so a re-paginated item fails loudly
    instead of fetching the wrong pages.
    """
    labels = [str(p["label"]) for p in client.iter_pages(pid)]
    pos = []
    for lab in (first, last):
        hits = [i for i, x in enumerate(labels, 1) if x == lab]
        if len(hits) != 1:
            raise RuntimeError(f"page label {lab!r} occurs {len(hits)} times in {pid}")
        pos.append(hits[0])
    if pos[0] > pos[1]:
        raise RuntimeError(f"slice {first}–{last} runs backwards in {pid}")
    return pos[0], pos[1], len(labels)


def check_positions(client: scraper_kramerius7.Kramerius7Client, job: dict) -> tuple[int, int, int]:
    """The job's page positions, refused if the labels found there are no longer the ones
    discovery recorded (an issue re-paginated since). Used where a label is printed twice
    or not at all, which ``resolve_slice`` cannot take."""
    labels = [str(p["label"]) for p in client.iter_pages(job["pid"])]
    lo, hi = job["positions"]
    if hi > len(labels) or (labels[lo - 1], labels[hi - 1]) != tuple(job["pages"]):
        raise RuntimeError(f"{job['key']}: positions {lo}–{hi} no longer hold "
                           f"{job['pages'][0]}–{job['pages'][1]} in {job['pid']}")
    return lo, hi, len(labels)

def solr(client: scraper_kramerius7.Kramerius7Client, q: str, fl: str,
         rows: int = 2000) -> list[dict]:
    url = f"{client.base}/search?" + urlencode({"q": q, "fl": fl, "rows": rows})
    return client._get(url).json().get("response", {}).get("docs", [])


def payment_entries(text: str) -> int:
    """How many entries on a page end in an amount and a dash."""
    return len(_PAYMENT_END.findall(text or ""))


def list_runs(judge, hits: list[int], n_pages: int) -> list[list[int]]:
    """The page positions of an issue's payment lists as runs of consecutive pages.
    ``judge(i)`` is the number of payment entries on page *i*. A candidate page opens a
    run if it has at least ``MIN_PAYMENTS``; a run is widened while the next page out
    has any (a list may end, or a short month sit, on a page of one or two), and a gap
    of up to two pages between runs is filled."""
    keep = {i for i in hits if judge(i) >= MIN_PAYMENTS}
    grown = True
    while grown:
        grown = False
        for i in sorted(keep):
            for j in (i - 1, i + 1):
                if 1 <= j <= n_pages and j not in keep and judge(j) >= 1:
                    keep.add(j)
                    grown = True
    ordered = sorted(keep)
    for a, b in zip(ordered, ordered[1:]):
        if 1 < b - a <= 3:
            keep.update(range(a + 1, b))
    runs: list[list[int]] = []
    for i in sorted(keep):
        if runs and i == runs[-1][-1] + 1:
            runs[-1].append(i)
        else:
            runs.append([i])
    return runs


def issue_label(part: str) -> str:
    """An issue's number as a key: ``2 - 3`` (a double issue) → ``2-3``."""
    return re.sub(r"\s*[-–]\s*", "-", (part or "0").strip())


def discover_payments(client: scraper_kramerius7.Kramerius7Client, out_dir: Path,
                      years=PAYMENT_YEARS, manifest: Path = PAYMENT_MANIFEST) -> list[dict]:
    """Find every payment-list slice in the volumes of *years*; keep the OCR read on the
    way in each job's page cache; return the manifest rows. The manifest is rewritten
    after every year, and a year already in it is not searched again."""
    rows = []
    if manifest.exists():
        with manifest.open(encoding="utf-8", newline="") as fh:
            rows = list(csv.DictReader(fh))
    done = {int(r["year"]) for r in rows}
    volumes = {d.get("date.str"): d["pid"] for d in solr(
        client, f'own_parent.pid:"{NM_PERIODICAL}" AND model:periodicalvolume', "pid,date.str")}
    for year in years:
        if year in done:
            continue
        vol = volumes.get(str(year))
        if vol is None:
            log.warning("%d: no volume", year)
            continue
        hits: dict[str, set[str]] = {}
        for term in _PAYMENT_TERMS:
            q = (f'root.pid:"{NM_PERIODICAL}" AND model:page AND date.str:"{year}" '
                 f'AND text_ocr:"{term}"')
            for d in solr(client, q, "pid,own_parent.pid"):
                hits.setdefault(d.get("own_parent.pid"), set()).add(d["pid"])
        issues = solr(client, f'own_parent.pid:"{vol}" AND model:periodicalitem',
                      "pid,part.number.str")
        order = lambda d: int(re.match(r"\d*", issue_label(d.get("part.number.str"))).group() or 0)
        for issue in sorted(issues, key=order):
            if issue["pid"] not in hits:
                continue
            rows += discover_issue(client, out_dir, year, issue, hits[issue["pid"]])
        write_manifest(rows, manifest)
        log.info("%d: %d slices so far", year, len(rows))
    return rows


def discover_issue(client: scraper_kramerius7.Kramerius7Client, out_dir: Path, year: int,
                   issue: dict, candidates: set[str]) -> list[dict]:
    """The payment-list slices of one issue (see :func:`list_runs`)."""
    pages = list(client.iter_pages(issue["pid"]))
    pos = {p["pid"]: i for i, p in enumerate(pages, 1)}
    texts: dict[int, str] = {}

    def judge(i: int) -> int:
        if i not in texts:
            texts[i] = client.ocr_text(pages[i - 1]["pid"]) or ""
        return payment_entries(texts[i])

    runs = list_runs(judge, sorted(pos[c] for c in candidates if c in pos), len(pages))
    out = []
    for n, run in enumerate(runs):
        suffix = "abcdefgh"[n] if len(runs) > 1 else ""
        key = f"mcp{year}-{issue_label(issue.get('part.number.str'))}{suffix}"
        cache = out_dir / f"NM_Casopis-Musea_{key}_Matice-prispevky_pages"
        cache.mkdir(parents=True, exist_ok=True)
        for i in run:
            if texts.get(i):
                (cache / f"{i:04d}.txt").write_text(texts[i], encoding="utf-8")
        out.append({"key": key, "year": year, "issue": issue_label(issue.get("part.number.str")),
                    "issue_pid": issue["pid"], "first_pos": run[0], "last_pos": run[-1],
                    "first_label": str(pages[run[0] - 1]["label"]),
                    "last_label": str(pages[run[-1] - 1]["label"]), "pages": len(run),
                    "payment_entries": sum(payment_entries(texts.get(i, "")) for i in run)})
    return out


def write_manifest(rows: list[dict], path: Path = PAYMENT_MANIFEST) -> Path:
    cols = ["key", "year", "issue", "issue_pid", "first_pos", "last_pos", "first_label",
            "last_label", "pages", "payment_entries"]
    path.parent.mkdir(parents=True, exist_ok=True)
    with path.open("w", encoding="utf-8", newline="") as fh:
        w = csv.DictWriter(fh, fieldnames=cols)
        w.writeheader()
        w.writerows(rows)
    return path


def assemble_slice(out_dir: Path, job: dict, res: dict) -> dict:
    """Build the PDF + TXT of a slice from its page cache (``download_document`` leaves a
    partial range unassembled). The cache is the job's own, so it holds only this slice."""
    lo, hi = res["range"]
    pages_dir = out_dir / f"{job['name']}_pages"
    idx = range(lo, hi + 1)
    images = [pages_dir / f"{i:04d}.jpg" for i in idx if (pages_dir / f"{i:04d}.jpg").exists()]
    texts = [(i, pages_dir / f"{i:04d}.txt") for i in idx if (pages_dir / f"{i:04d}.txt").exists()]
    alto = sum((pages_dir / f"{i:04d}.alto.xml").exists() for i in idx)
    out = dict(res, pages=len(idx), images=len(images), ocr_pages=len(texts),
               alto_pages=alto, complete=len(images) == len(idx))
    if not out["complete"]:
        return out
    pdf = out_dir / f"{job['name']}.pdf"
    scraper_kramerius7._build_pdf(images, pdf)
    head = (f"OCR text — {res['title']}, pages {lo}–{hi} of {res['pages']} "
            f"(printed {job['pages'][0]}–{job['pages'][1]})\nKramerius PID: {job['pid']}\n"
            f"Source host: {job.get('host', HOST)}\nPages with OCR: {len(texts)}/{len(idx)}\n"
            + "=" * 70)
    body = "".join(f"\n\n===== p. {i} =====\n" + p.read_text(encoding="utf-8").strip()
                   for i, p in texts)
    (out_dir / f"{job['name']}.txt").write_text(head + body + "\n", encoding="utf-8")
    out["pdf"] = str(pdf)
    log.info("PDF   -> %s  (slice %d–%d, %d pp)", pdf.name, lo, hi, len(images))
    return out


def run_job(job: dict, out_dir: Path, client: scraper_kramerius7.Kramerius7Client,
            *, progress: bool) -> dict:
    """Fetch one job (a whole item or a slice of one) and return its summary."""
    lo, hi = 1, None
    if "pages" in job:
        lo, hi, n = (check_positions(client, job) if "positions" in job
                     else resolve_slice(client, job["pid"], *job["pages"]))
        log.info("%s: printed pp. %s–%s = positions %d–%d of %d",
                 job["key"], *job["pages"], lo, hi, n)
    res = scraper_kramerius7.download_document(
        job["pid"], out_dir, host=job.get("host", HOST), name=job["name"],
        save_alto=True, per_page_txt=True, verify_tls=True,
        delay=DELAY, retries=client.retries, page_from=lo, page_to=hi,
        batch_size=BATCH_SIZE, batch_pause=BATCH_PAUSE,
        progress=progress, progress_desc=job["key"])
    return assemble_slice(out_dir, job, res) if "pages" in job else res


def write_source_note(out_dir: Path, results: dict[str, dict]) -> Path:
    """Write ``SOURCE.txt``: what each file is, where it came from, when, and its hash.

    A job not run this time keeps its line from the PDF already on disk, so ``--only``
    does not mark the others incomplete.
    """
    stamp = datetime.now(timezone.utc).strftime("%Y-%m-%d %H:%M UTC")
    jobs = all_jobs()
    lines = ["Sources", "-------"]
    for src in dict.fromkeys(j["source"] for j in jobs):
        lines.append(src)
    lines += ["Digitised by the Moravská zemská knihovna (the founder registers and Časopis "
              "Matice moravské) and the Národní muzeum (Časopis Musea), both Kramerius 7. "
              "Licence: public.", "", "Files", "-----"]
    for job in jobs:
        res = results.get(job["key"])
        pdf = out_dir / f"{job['name']}.pdf"
        lines.append(f"{job['name']}.pdf / .txt / _pages/")
        lines.append(f"  {VIEWERS[job.get('host', HOST)]}/{job['pid']}")
        if "pages" in job:
            lines.append(f"  printed pages {job['pages'][0]}–{job['pages'][1]} of the item")
        if res and res.get("pdf"):
            lines.append(f"  {res['pages']} pages, {res['images']} scans, "
                         f"{res['ocr_pages']} OCR, {res['alto_pages']} ALTO")
        if pdf.exists() and (res is None or res.get("pdf")):
            lines.append(f"  PDF {pdf.stat().st_size:,} bytes, sha256 {_sha256(pdf)}")
        else:
            lines.append("  NOT COMPLETE")
        lines.append("")
    lines += [
        "Retrieval", "---------",
        f"{stamp} by utils/scraping/run_matice_downloads.py v{__version__}",
        f"(scraper_kramerius7 v{scraper_kramerius7.__version__}) via {HOST} and {NM_HOST}:",
        f"sequential, {DELAY:.0f} s between requests, {BATCH_PAUSE:.0f} s rest every "
        f"{BATCH_SIZE} pages, one attempt per request, no credentials.",
        "",
    ]
    path = out_dir / "SOURCE.txt"
    path.write_text("\n".join(lines), encoding="utf-8")
    return path


def dry_run(jobs: list[dict], clients: dict[str, scraper_kramerius7.Kramerius7Client]) -> int:
    """Print each job's title and resolved page range; fetch no page."""
    ok = True
    for job in jobs:
        client = clients[job.get("host", HOST)]
        doc = client.solr_doc(job["pid"])
        try:
            if "pages" in job:
                lo, hi, n = (check_positions(client, job) if "positions" in job
                             else resolve_slice(client, job["pid"], *job["pages"]))
                span = f"pp. {job['pages'][0]}–{job['pages'][1]} = {lo}–{hi} of {n}"
            else:
                span = f"all {sum(1 for _ in client.iter_pages(job['pid']))} pages"
        except RuntimeError as exc:
            span, ok = f"FAILED: {exc}", False
        log.info("%-11s %s | %s | %s", job["key"], doc.get("date.str", "?"),
                 doc.get("title.search", "?"), span)
    return 0 if ok else 1


def main(argv: list[str] | None = None) -> int:
    p = argparse.ArgumentParser(description=__doc__.split("\n\n")[0])
    p.add_argument("--out", default=str(DEFAULT_OUT), help="output directory")
    p.add_argument("--only", choices=[j["key"] for j in all_jobs()], default=None)
    p.add_argument("--set", choices=["all", "registers", "payments"], default="all",
                   help="the registers (MZK), the Matice česká payment lists (NM), or both")
    p.add_argument("--discover-payments", action="store_true",
                   help=f"find the payment-list pages and write {PAYMENT_MANIFEST.name}")
    p.add_argument("--dry-run", action="store_true",
                   help="resolve titles and page slices, fetch no pages")
    p.add_argument("--no-progress", action="store_true")
    args = p.parse_args(argv)
    logging.basicConfig(level=logging.INFO, format="%(message)s")

    clients = {h: scraper_kramerius7.Kramerius7Client(h, delay=DELAY, retries=n,
                                                      verify_tls=True)
               for h, n in ((HOST, 1), (NM_HOST, NM_RETRIES))}
    out_dir = Path(args.out)
    if args.discover_payments:
        if robots_disallowed([f"{NM_HOST}/search/api/client/v7.0/search"]):
            log.error("robots.txt disallows the search on %s", NM_HOST)
            return 1
        rows = discover_payments(clients[NM_HOST], out_dir)
        log.info("wrote %s: %d slices, %d pages", write_manifest(rows), len(rows),
                 sum(r["pages"] for r in rows))
        return 0

    pool = {"all": all_jobs(), "registers": JOBS, "payments": payment_jobs()}[args.set]
    jobs = [j for j in pool if args.only is None or j["key"] == args.only]
    blocked = robots_disallowed([f"{j.get('host', HOST)}/search/api/client/v7.0/items/{j['pid']}"
                                 for j in jobs])
    if blocked:
        log.error("robots.txt disallows: %s", blocked)
        return 1

    if args.dry_run:
        return dry_run(jobs, clients)

    results: dict[str, dict] = {}
    for job in jobs:
        try:
            results[job["key"]] = run_job(job, out_dir, clients[job.get("host", HOST)],
                                          progress=not args.no_progress)
        except Exception as exc:                 # report and go on to the next job
            log.error("FAILED (%s): %s", job["key"], exc)
    write_source_note(out_dir, results)

    complete = all(results.get(j["key"], {}).get("complete") for j in jobs)
    for key, res in results.items():
        log.info("%s: %d pages, %d scans, %d OCR, %d ALTO", key, res["pages"],
                 res["images"], res["ocr_pages"], res["alto_pages"])
    return 0 if complete else 1


if __name__ == "__main__":
