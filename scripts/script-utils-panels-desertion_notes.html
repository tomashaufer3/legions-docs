TL;DR

A record coded D beside a demobilisation (D;DM, D;V) is often dated by the other event: D;DM exits run 1919–22, while the note says when the man deserted (Zběhl 29.5.1918., 25.3.1918 zběhl, dezertoval 7.2.1918, 4.1918 dezertoval). The author's ruling (D-260, reference/SPELL_FILE_DESIGN.md (c)): a deserter is a deserter, and where the note gives the desertion date that date is the exit date. This module reads it.

How it works

The rule, kept small on purpose:

  1. the note is cut into clauses at ; and , and at a sentence end (a full stop followed by a capital letter); a date in another clause is never taken (Slib 14.5.1918. Zběhl a zastřelen gives no date: the 14 May is the oath);
  2. a clause counts only if it holds desertion vocabulary (DESERTION_WORDS: zběh, zběhl, sběhl, zběhnutí, dezertoval, dezerce, samovolně se vzdálil), no negation of it (NEGATED: není veden jako zběh), and does not mark its date as an alternative (ALTERNATIVE: jiné datum sběhnutí: 2.3.1918, na kartě datum dezertace je také 29.11.1917: a second date beside the recorded one, not a correction of it);
  3. in such a clause the date nearest the word is taken, at the precision written: d.m.yyyy / d. měsíce yyyy (day), m.yyyy / v dubnu 1918 (month), v roce 1917 / v r. 1917 (year). A bare year is not read (zákona čís. 462/1919 Sb.);
  4. the first clause, in note order, that yields a date wins.

uprchl (fled) is not desertion vocabulary: in these notes it is mostly an escape from captivity. Whether the date is then used is the spell builder's call (spells.build_spells, desertion_date_from_note), not this module's.

Two more readings of a note, for the spell builder:

  • says_deserter — the note says the man deserted: a clause with desertion vocabulary, not negated and not in doubt (UNCERTAIN: ZBĚH?, podezřelý ze sběhnutí), and nothing in the note says he re-entered the Legion afterwards (REENTRY: znovu vstoupil, přihlásil se podruhé), when the desertion was before the spell. Read on records with no D code; &lt;NA&gt; where there is no note;
  • marks_last_record — the note says the recorded date is only the last record of him (LAST_RECORD: Poslední údaj ke dni 5.7.1917; zběhl 3.1.1918), so a later desertion date in the note is the desertion, not a write-off.

def desertion_note_date(note) -> tuple[pd.Timestamp | None, str | None]:
    """The desertion date one note states, as ``(date, precision)``; ``(None, None)`` if none.

    A partial date is stored at its first day (as ``utils/parsing/dates.py`` does)."""
    if note is None or (not isinstance(note, str) and pd.isna(note)):
        return None, None
    for clause in CLAUSE_SPLIT.split(str(note)):
        if NEGATED.search(clause) or ALTERNATIVE.search(clause):
            continue
        words = [w.start() for w in DESERTION_WORDS.finditer(clause)]
        if not words:
            continue
        dates = _dates_in(clause)
        if dates:
            pos, date, prec = min(dates, key=lambda t: min(abs(t[0] - w) for w in words))
            return date, prec
    return None, None

"""
desertion_notes.py — the desertion date a csol.cz note states (``Zběhl 29.5.1918``)
===================================================================================
A record coded D beside a demobilisation (``D;DM``, ``D;V``) is often dated by the *other*
event: ``D;DM`` exits run 1919–22, while the note says when the man deserted
(``Zběhl 29.5.1918.``, ``25.3.1918 zběhl``, ``dezertoval 7.2.1918``, ``4.1918 dezertoval``). The
author's ruling (D-260, reference/SPELL_FILE_DESIGN.md (c)): a deserter is a deserter, and where
the note gives the desertion date that date is the exit date. This module reads it.

The rule, kept small on purpose:

1. the note is cut into **clauses** at ``;`` and ``,`` and at a sentence end (a full stop
   followed by a capital letter); a date in another clause is never taken (``Slib 14.5.1918.
   Zběhl a zastřelen`` gives no date: the 14 May is the oath);
2. a clause counts only if it holds **desertion vocabulary** (:data:`DESERTION_WORDS`: *zběh*,
   *zběhl*, *sběhl*, *zběhnutí*, *dezertoval*, *dezerce*, *samovolně se vzdálil*), no negation
   of it (:data:`NEGATED`: *není veden jako zběh*), and does not mark its date as an
   alternative (:data:`ALTERNATIVE`: *jiné datum sběhnutí: 2.3.1918*, *na kartě datum dezertace je
   také 29.11.1917*: a second date beside the recorded one, not a correction of it);
3. in such a clause the date **nearest the word** is taken, at the precision written:
   ``d.m.yyyy`` / ``d. měsíce yyyy`` (day), ``m.yyyy`` / ``v dubnu 1918`` (month),
   ``v roce 1917`` / ``v r. 1917`` (year). A bare year is not read (``zákona čís. 462/1919 Sb.``);
4. the first clause, in note order, that yields a date wins.

*uprchl* (fled) is not desertion vocabulary: in these notes it is mostly an escape from captivity.
Whether the date is then used is the spell builder's call (``spells.build_spells``,
``desertion_date_from_note``), not this module's.

Two more readings of a note, for the spell builder:

* :func:`says_deserter` — the note says the man deserted: a clause with desertion vocabulary, not
  negated and not in doubt (:data:`UNCERTAIN`: *ZBĚH?*, *podezřelý ze sběhnutí*), and nothing in
  the note says he re-entered the Legion afterwards (:data:`REENTRY`: *znovu vstoupil*,
  *přihlásil se podruhé*), when the desertion was before the spell. Read on records with no D code;
  ``<NA>`` where there is no note;
* :func:`marks_last_record` — the note says the recorded date is only the last record of him
  (:data:`LAST_RECORD`: *Poslední údaj ke dni 5.7.1917; zběhl 3.1.1918*), so a later desertion
  date in the note is the desertion, not a write-off.

Usage
-----
    from utils.panels.desertion_notes import desertion_note_dates
    nd = desertion_note_dates(persons["notes"])   # columns date, precision (NaT / <NA> where none)
"""
from __future__ import annotations

import re

import pandas as pd

__version__ = "1.1.0"
# 1.1.0 (2026-11-18, the check of D-260): ALTERNATIVE clauses are not read (jiné datum, také);
#       says_deserter / marks_last_record for the spell builder. 1.0.0 (D-260): first build.

#: Desertion vocabulary, matched at a word start (case-insensitive). zběh* covers zběh, zběhl,
#: zběhem, zběha, zběhnul, zběhnutí; sběhl is the record's own variant spelling.
DESERTION_WORDS = re.compile(
    r"(?<!\w)(?:[zs]b[ěe]h\w*|dezert\w*|samovoln\w*\s+(?:se\s+)?vzdálil)", re.IGNORECASE)
#: A clause that denies the desertion ("není veden jako zběh") is never read.
NEGATED = re.compile(r"(?<!\w)(?:není|nebyl)\s+(?:veden\w*\s+)?(?:jako|za)\s+zběh", re.IGNORECASE)
#: A clause that names its date as a second one beside the recorded date ("jiné datum sběhnutí",
#: "datum dezertace je také ...") is not read for a date.
ALTERNATIVE = re.compile(r"(?<!\w)(?:jin[éáý]\w*\s+datum|také)(?!\w)", re.IGNORECASE)
#: A clause in doubt ("ZBĚH?", "podezřelý ze sběhnutí") does not say he deserted.
UNCERTAIN = re.compile(r"\?|(?<!\w)podezř", re.IGNORECASE)
#: The note says he came back into the Legion after deserting: the desertion preceded this spell.
REENTRY = re.compile(r"(?<!\w)(?:znovu\s+(?:vstoupil|přijat|zařazen)|podruhé|druh\w*\s+(?:vstup|zařazen))",
                     re.IGNORECASE)
#: The recorded date is only the last record of him ("Poslední údaj ke dni 5.7.1917").
LAST_RECORD = re.compile(r"(?<!\w)posledn\w*\s+(?:údaj|záznam)", re.IGNORECASE)
#: Clause boundaries: ';' and ',', and a full stop followed by a capital (a new sentence).
CLAUSE_SPLIT = re.compile(r"[;,]|\.\s+(?=[A-ZÁČĎÉĚÍŇÓŘŠŤÚŮÝŽ])")
#: A law citation (462/1919 Sb.) carries a year that is no date.
LAW_CITATION = re.compile(r"\d+\s*/\s*\d{4}")

#: Czech month names: genitive (``3. března 1918``) and locative (``v dubnu 1918``).
MONTHS_GENITIVE = ("ledna", "února", "března", "dubna", "května", "června", "července",
                   "srpna", "září", "října", "listopadu", "prosince")
MONTHS_LOCATIVE = ("lednu", "únoru", "březnu", "dubnu", "květnu", "červnu", "červenci",
                   "srpnu", "září", "říjnu", "listopadu", "prosinci")
_MONTH_NO = {**{m: i + 1 for i, m in enumerate(MONTHS_GENITIVE)},
             **{m: i + 1 for i, m in enumerate(MONTHS_LOCATIVE)}}
_MONTH_ALT = "|".join(sorted(_MONTH_NO, key=len, reverse=True))

#: The date shapes, finest first; each yields (precision, year, month, day).
DATE_PATTERNS: tuple[tuple[str, re.Pattern], ...] = (
    ("day", re.compile(r"(?<!\d)(\d{1,2})\s*\.\s*(\d{1,2})\s*\.\s*(\d{4})(?!\d)")),
    ("day_name", re.compile(rf"(?<!\d)(\d{{1,2}})\s*\.\s*({_MONTH_ALT})\s+(\d{{4}})(?!\d)",
                            re.IGNORECASE)),
    ("month", re.compile(r"(?<![\d.])(\d{1,2})\s*\.\s*(\d{4})(?!\d)")),
    ("month_name", re.compile(rf"(?<!\w)v\s+({_MONTH_ALT})\s+(\d{{4}})(?!\d)", re.IGNORECASE)),
    ("year", re.compile(r"(?<!\w)v\s*(?:roce|r\.)\s*(\d{4})(?!\d)", re.IGNORECASE)),
)
#: A year outside this range is a typing error, not a Legion desertion date.
YEAR_RANGE = (1914, 1922)


def _to_date(kind: str, groups: tuple[str, ...]):
    """``(timestamp, precision)`` of one regex match, or None if it is no real date."""
    try:
        if kind == "day":
            d, m, y = (int(g) for g in groups)
            prec = "day"
        elif kind == "day_name":
            d, m, y = int(groups[0]), _MONTH_NO[groups[1].lower()], int(groups[2])
            prec = "day"
        elif kind == "month":
            d, m, y = 1, int(groups[0]), int(groups[1])
            prec = "month"
        elif kind == "month_name":
            d, m, y = 1, _MONTH_NO[groups[0].lower()], int(groups[1])
            prec = "month"
        else:
            d, m, y = 1, 1, int(groups[0])
            prec = "year"
        if not YEAR_RANGE[0] <= y <= YEAR_RANGE[1]:
            return None
        return pd.Timestamp(year=y, month=m, day=d), prec
    except (ValueError, KeyError):
        return None


def _dates_in(clause: str) -> list[tuple[int, pd.Timestamp, str]]:
    """Every date in a clause as ``(position, date, precision)``; a span read at a finer
    precision is not read again at a coarser one (``1.2.1918`` is not also ``2.1918``)."""
    text = LAW_CITATION.sub(lambda m: " " * len(m.group(0)), clause)
    taken: list[tuple[int, int]] = []
    out = []
    for kind, pat in DATE_PATTERNS:
        for m in pat.finditer(text):
            if any(a < m.end() and m.start() < b for a, b in taken):
                continue
            got = _to_date(kind, m.groups())
            if got is not None:
                taken.append((m.start(), m.end()))
                out.append((m.start(), got[0], got[1]))
    return out


def desertion_note_date(note) -> tuple[pd.Timestamp | None, str | None]:
    """The desertion date one note states, as ``(date, precision)``; ``(None, None)`` if none.

    A partial date is stored at its first day (as ``utils/parsing/dates.py`` does)."""
    if note is None or (not isinstance(note, str) and pd.isna(note)):
        return None, None
    for clause in CLAUSE_SPLIT.split(str(note)):
        if NEGATED.search(clause) or ALTERNATIVE.search(clause):
            continue
        words = [w.start() for w in DESERTION_WORDS.finditer(clause)]
        if not words:
            continue
        dates = _dates_in(clause)
        if dates:
            pos, date, prec = min(dates, key=lambda t: min(abs(t[0] - w) for w in words))
            return date, prec
    return None, None


def desertion_note_dates(notes: pd.Series) -> pd.DataFrame:
    """:func:`desertion_note_date` over a column: ``date`` (NaT) and ``precision`` (<NA>)."""
    parsed = notes.map(desertion_note_date)
    return pd.DataFrame({
        "date": pd.to_datetime(parsed.map(lambda t: t[0])),
        "precision": parsed.map(lambda t: t[1]).astype("string"),
    }, index=notes.index)


def _missing(note) -> bool:
    return note is None or (not isinstance(note, str) and pd.isna(note)) or not str(note).strip()


def says_deserter(note):
    """True if the note says the man deserted (a clause with desertion vocabulary, not negated,
    not in doubt) and not that he re-entered afterwards; False otherwise; ``<NA>`` with no note."""
    if _missing(note):
        return pd.NA
    note = str(note)
    if REENTRY.search(note):
        return False
    return any(DESERTION_WORDS.search(c) and not NEGATED.search(c) and not UNCERTAIN.search(c)
               for c in CLAUSE_SPLIT.split(note))


def marks_last_record(note) -> bool:
    """True if the note says the recorded date is only the last record of him."""
    return False if _missing(note) else bool(LAST_RECORD.search(str(note)))


def note_readings(notes: pd.Series) -> pd.DataFrame:
    """:func:`says_deserter` (boolean, <NA> with no note) and :func:`marks_last_record` over a
    column, index kept."""
    return pd.DataFrame({"says_deserter": notes.map(says_deserter).astype("boolean"),
                         "last_record": notes.map(marks_last_record).astype(bool)}, index=notes.index)
