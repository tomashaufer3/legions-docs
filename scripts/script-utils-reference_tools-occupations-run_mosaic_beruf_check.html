How it works

Check 6 settled rolník → 61110 General Farmer (HISCLASS 8) against the 1910 Volkszählung, and declared its own limit in the same breath: the test is ecological. Okres-level composition cannot clear any individual record, and it separates own-account from wage-earning but not the holder from the farmer's son. This check goes at exactly that limit.

The Vienna Database on European Family History (unharmonized Austrian numeric file, distributed by MOSAIC) records 163,400 individuals in 44 localities, 1632–1947, from census data and libri status animarum. Every person carries an occupation drawn from a closed list of 521 German nominal titles and, independently, a household position — Haushaltsvorstand, Hausfrau, Sohn, Gesindeperson. That pairing is what no other source in this project has: it shows, person by person, what the German occupational vocabulary the project's own glosses are written in actually denoted. The coding was done 1974–1984 at the University of Vienna, so it is independent of this project in the strong sense: it predates it.

Cite as: Vienna Database on European Family History. Numeric data file, Version 0.1 [SPSS file]. Vienna: University of Vienna, 2003. (reference/DATA_SOURCES.md #14.)

Three things follow, and the script tests them in that order:

  1. The vocabulary is split at source. BAUER and LANDARBEITER/KNECHT are different entries on the same closed list, in different berufs systematic classes. A recording tradition that kept a separate word for the hired hand was not using BAUER to mean one.
  2. The split shows up in household position — the individual-level fact Check 6 lacks.
  3. Restricted to males 18–30, the Legion age band, it also answers the farmer's-son half: a farmer's son appears on these listings as SOHN, not as BAUER.

What this cannot do, and the write-up must keep saying so. It validates the German term, not the Czech reading — the same gap Checks 1 and 2 carry. rolník's gloss in czech_glosses.py is Landwirt; the term present here is Bauer (this project's gloss for sedlák), and a bare LANDWIRT is not on the 521-term list at all, so the bridge runs through a Landwirt ≈ Bauer synonymy this check assumes rather than demonstrates. It is also the wrong territory (44 Austrian localities, no Czech lands) and largely the wrong period (bulk 1857). Most important: household position and occupational title are not independent in a Seelenbeschreibung — one clerk assigned both — so this corroborates Check 6, it does not independently prove it.

dělník → 99900 is deliberately out of scope. The Arbeiter family (HANDARBEITER, FABRIKARBEITER, HILFSARBEITER) is present in the source, but that is a different question and this check does not open it.

Run: python utils/reference_tools/occupations/run_mosaic_beruf_check.py Emits: nothing — prints the result for reference/VALIDATION_OCCUPATIONS.md. This is a validation script, never a pipeline input; it writes no file and touches no code column.

    print(f"  a bare LANDWIRT is on that list: "
          f"{'yes' if 'LANDWIRT' in set(lab['berufn'].values()) else 'NO — see the docstring'}")
    print(f"  survey years {int(df['erjahr'].min())}–{int(df['erjahr'].max())}, "

    sub = df[df["term"].isin(TERMS)]

    ct = ct.loc[:, ct.sum(axis=0) > 0]
    print("  nominal title x systematic class (counts)")
    _show(ct)
    print("\n  The hired hand has his own word and his own class. That is the point of the "
          "test:\n  the tradition did not lack a term for wage labour and reach for BAUER.\n")

def run_position(df: pd.DataFrame) -> pd.DataFrame:
    """Test 2 — household position, the individual-level split Check 6 cannot make."""
    print("\nTest 2 — household position, person by person\n")
    sub = df[df["term"].isin(TERMS)]
    ct = pd.crosstab(sub["term"], sub["position"])
    ct = ct.loc[_order(ct.index)]

    keep = [c for c in ("GESINDEPERSON", "HAUSHALTSVORSTAND", "HAUSFRAU", "SOHN",

    pct = _row_pct(ct)[keep]

        print(f"\n  read past (n < {MIN_N}): "
              + ", ".join(f"{t} {int(n)}" for t, n in thin.items()))

def run_age_band(df: pd.DataFrame) -> pd.DataFrame:
    """Test 3 — males 18–30, which is where the farmer's-son objection lives."""
    print(f"\nTest 3 — males {AGE_LO}–{AGE_HI}, the Legion age band\n")
    sub = df[df["term"].isin(TERMS)
             & df["sex"].eq(0)
             & df["alter"].between(AGE_LO, AGE_HI)]
    ct = pd.crosstab(sub["term"], sub["position"])
    ct = ct.loc[_order(ct.index)]

    keep = [c for c in ("GESINDEPERSON", "HAUSHALTSVORSTAND", "SOHN", "MITBEWOHNER",
                        "VERWANDTE") if c in ct.columns]
    pct = _row_pct(ct)[keep]
    pct.insert(0, "N", ct.sum(axis=1))
    print("  row %, by nominal title")
    _show(pct)

    tot = ct.sum(axis=1)
    if "BAUER" in ct.index and "SOHN" in ct.columns and tot.get("BAUER", 0) >= MIN_N:
        son = ct.loc["BAUER", "SOHN"] / tot["BAUER"] * 100
        print(f"\n  Of {int(tot['BAUER']):,} men aged {AGE_LO}–{AGE_HI} recorded BAUER, "
              f"{son:.1f} % are listed as a son.")
        print("  A farmer's son on these listings is written down as SOHN, not as BAUER —")
        print("  which is the half of Check 6's blind spot the census could not reach.\n")
    return ct

def run_keys() -> pd.DataFrame:
    """Test 4 — tie the German evidence to the curation keys it actually bears on."""
    from utils.parsing.occupations import _norm
    from utils.reference_tools.occupations.czech_glosses import CZ_GLOSS

    print("\nTest 4 — the curation keys this reaches, and how much of the sample they carry\n")
    if not FINAL.exists():
        raise SystemExit(f"{_rel(FINAL)} not found — run notebook 02 first.")
    L = pd.read_parquet(FINAL, columns=["occupation"])
    counts = L["occupation"].map(_norm).value_counts()
    n_coded = int(counts.sum())

    rows = []
    for key, term, hisco, label in KEYS:
        gloss = CZ_GLOSS.get(key, ("—", "—"))[0]
        n = int(counts.get(key, 0))
        rows.append({"curation key": key,
                     "German gloss": gloss,
                     "Vienna Database term": term,
                     "hisco": hisco,
                     "label": label,
                     "records": n,
                     "% of coded": round(n / n_coded * 100, 2) if n_coded else 0.0})
    out = pd.DataFrame(rows)
    _show(out, index=False)
    print(f"\n  {out['records'].sum():,} legionnaire records "
          f"({out['% of coded'].sum():.1f} % of non-empty occupations) sit on keys this "
          f"check speaks to.")
    print("  `rolník` is glossed *Landwirt*, not *Bauer* — the synonymy is assumed here, "
          "not shown.\n")
    return out

def run_stability(df: pd.DataFrame) -> pd.DataFrame:
    """Is this one clerk's habit, one place, or one census? Split it and see."""
    print("\nStability — is the split an artefact of the 1857 Vienna bulk?\n")
    sub = df[df["term"].isin(["BAUER", "LANDARBEITER/KNECHT"])].copy()

    bins = [(-1, 1799, "pre-1800"), (1800, 1856, "1800–1856"),
            (1857, 1857, "1857 census"), (1858, 9999, "post-1857")]
    def period(y):
        for lo, hi, name in bins:
            if lo <= y <= hi:
                return name
        return "?"
    sub["period"] = sub["erjahr"].fillna(-1).map(period)

    rows = []
    for term in ("BAUER", "LANDARBEITER/KNECHT"):
        t = sub[sub["term"].eq(term)]
        for name in [b[2] for b in bins]:
            p = t[t["period"].eq(name)]
            if len(p) < MIN_N:
                continue
            rows.append({"term": term, "period": name, "N": len(p),
                         "% Gesinde": round(p["position"].eq("GESINDEPERSON").mean() * 100, 1),
                         "% head": round(p["position"].eq("HAUSHALTSVORSTAND").mean() * 100, 1),
                         "localities": p["gmde"].nunique()})
    out = pd.DataFrame(rows)
    _show(out, index=False)

    b = sub[sub["term"].eq("BAUER")]
    k = sub[sub["term"].eq("LANDARBEITER/KNECHT")]
    n1857 = int(sub["period"].eq("1857 census").sum())
    print(f"\n  BAUER appears in {b['gmde'].nunique()} localities across "
          f"{b['erjahr'].nunique()} survey years; "
          f"LANDARBEITER/KNECHT in {k['gmde'].nunique()} across {k['erjahr'].nunique()}.")
    print(f"  The split holds in every period with enough records to read. The 1857 census "
          f"row is\n  absent because it contributes only {n1857} of these records — it is "
          f"the Vienna bulk, and\n  farm terms are rural. So the answer to the heading is "
          f"no: the evidence is not 1857's.\n")
    return out

from __future__ import annotations

import sys
import textwrap
from pathlib import Path

import pandas as pd

ROOT = Path(__file__).resolve().parents[3]
sys.path.insert(0, str(ROOT))

__version__ = "1.0.0"

SAV = (ROOT / "data" / "raw" / "mosaic_unharmonized_austria_numeric"
       / "Austrian numeric data.sav")
FINAL = ROOT / "data" / "final" / "persons" / "legionnaires_clean.parquet"

# The agricultural terms on the closed 521-title list, split by the reading under test.
OWNER_TERMS = ["BAUER", "VIERTELBAUER", "HAEUSLER,HALBBAUER", "GRUNDBESITZER"]
HIRED_TERMS = ["LANDARBEITER/KNECHT", "MAGD", "LAENDL. TAGLOEHNER",
               "TAGLOEHNER IN DER STADT"]
TERMS = OWNER_TERMS + HIRED_TERMS

# Curation keys this check reaches, with the German gloss each is coded through and the
# Vienna-Database term that gloss corresponds to. `hisco` here is what the dictionary says —
# it is printed for the reader, never written anywhere.
KEYS = [
    ("rolník", "BAUER", "61110", "General Farmer"),
    ("sedlák", "BAUER", "61110", "General Farmer"),
    ("domkář", "HAEUSLER,HALBBAUER", "61115", "Small Subsistence Farmer"),
    ("statkář", "GRUNDBESITZER", "61110", "General Farmer (estate owner)"),
    ("čeledín", "LANDARBEITER/KNECHT", "62120", "Farm Servant"),
    ("zemědělský dělník", "LANDARBEITER/KNECHT", "62105", "Farm Worker, General"),
    ("nádeník", "TAGLOEHNER IN DER STADT", "99920", "Day-Labourer"),
]

AGE_LO, AGE_HI = 18, 30          # the Legion age band at enlistment
MIN_N = 30                       # terms thinner than this are noise, not evidence


def _rel(p: Path) -> str:
    """Repo-relative path for messages, never raising — an error handler must not fail."""
    try:
        return str(p.resolve().relative_to(ROOT))
    except ValueError:
        return str(p)


def _load() -> tuple[pd.DataFrame, dict]:
    """The Vienna Database as labelled columns. Both failure modes are the reader's fault."""
    try:
        import pyreadstat
    except ModuleNotFoundError:
        raise SystemExit(
            "pyreadstat is not installed — needed to read the SPSS file.\n"
            "  pip install pyreadstat")
    if not SAV.exists():
        raise SystemExit(
            f"{_rel(SAV)} not found.\n"
            "This is a validation-only source and `data/` is gitignored, so the file does "
            "not ship with the repo. See `reference/DATA_SOURCES.md` #14 for where it comes "
            "from.")

    df, meta = pyreadstat.read_sav(
        str(SAV),
        usecols=["berufn", "berufs", "alstel", "sex", "alter", "erjahr", "gmde"])
    lab = meta.variable_value_labels
    df["term"] = df["berufn"].map(lab["berufn"])
    df["systematic"] = df["berufs"].map(lab["berufs"])
    df["position"] = df["alstel"].map(lab["alstel"])
    return df, lab


def _row_pct(ct: pd.DataFrame) -> pd.DataFrame:
    return (ct.div(ct.sum(axis=1), axis=0) * 100).round(1)

    keep = [c for c in ("GESINDEPERSON", "HAUSHALTSVORSTAND", "SOHN", "MITBEWOHNER",
                        "VERWANDTE") if c in ct.columns]
    pct = _row_pct(ct)[keep]
    pct.insert(0, "N", ct.sum(axis=1))
    print("  row %, by nominal title")
    _show(pct)

    tot = ct.sum(axis=1)
    if "BAUER" in ct.index and "SOHN" in ct.columns and tot.get("BAUER", 0) >= MIN_N:
        son = ct.loc["BAUER", "SOHN"] / tot["BAUER"] * 100
        print(f"\n  Of {int(tot['BAUER']):,} men aged {AGE_LO}–{AGE_HI} recorded BAUER, "
              f"{son:.1f} % are listed as a son.")
        print("  A farmer's son on these listings is written down as SOHN, not as BAUER —")
        print("  which is the half of Check 6's blind spot the census could not reach.\n")
    return ct

def run_stability(df: pd.DataFrame) -> pd.DataFrame:
    """Is this one clerk's habit, one place, or one census? Split it and see."""
    print("\nStability — is the split an artefact of the 1857 Vienna bulk?\n")
    sub = df[df["term"].isin(["BAUER", "LANDARBEITER/KNECHT"])].copy()

    bins = [(-1, 1799, "pre-1800"), (1800, 1856, "1800–1856"),
            (1857, 1857, "1857 census"), (1858, 9999, "post-1857")]
    def period(y):
        for lo, hi, name in bins:
            if lo <= y <= hi:
                return name
        return "?"
    sub["period"] = sub["erjahr"].fillna(-1).map(period)

    rows = []
    for term in ("BAUER", "LANDARBEITER/KNECHT"):
        t = sub[sub["term"].eq(term)]
        for name in [b[2] for b in bins]:
            p = t[t["period"].eq(name)]
            if len(p) < MIN_N:
                continue
            rows.append({"term": term, "period": name, "N": len(p),
                         "% Gesinde": round(p["position"].eq("GESINDEPERSON").mean() * 100, 1),
                         "% head": round(p["position"].eq("HAUSHALTSVORSTAND").mean() * 100, 1),
                         "localities": p["gmde"].nunique()})
    out = pd.DataFrame(rows)
    _show(out, index=False)

    b = sub[sub["term"].eq("BAUER")]
    k = sub[sub["term"].eq("LANDARBEITER/KNECHT")]
    n1857 = int(sub["period"].eq("1857 census").sum())
    print(f"\n  BAUER appears in {b['gmde'].nunique()} localities across "
          f"{b['erjahr'].nunique()} survey years; "
          f"LANDARBEITER/KNECHT in {k['gmde'].nunique()} across {k['erjahr'].nunique()}.")
    print(f"  The split holds in every period with enough records to read. The 1857 census "
          f"row is\n  absent because it contributes only {n1857} of these records — it is "
          f"the Vienna bulk, and\n  farm terms are rural. So the answer to the heading is "
          f"no: the evidence is not 1857's.\n")
    return out
