TL;DR

Parses the free-text Politická příslušnost field into per-party boolean dummies. v1.x built the party genealogy from Wikipedia; v2.0.0 rebuilds it on the Akademický atlas českých dějin, plate IV.37 (Systém politických stran v českých zemích, p. 318) — a register of 55 parties of the Czech lands 1861–1918, each with its founding year, area of operation and a notes column recording every merger, renaming and dissolution. Transcribed and checked in reference/parties/ (atlas_iv37_parties.csv, 12/12 invariants).

How it works

Every token below carries the atlas code(s) that justify it, so a reader can go from a string in the data to a row in the printed register.

What the atlas changed

  1. The "progressive" family is not a family. v1.x kept pokr as a separate Liberal bin. The register says three of the four pokrokové parties co-founded Č23 Česká státoprávní demokracie — Č13 (1918 spoluzakladatelka Č 23), Č15 (idem), Č17 (idem) — and Č23 was "1919 přejmenována na Národní demokracii". The fourth, Č7 radikálně pokroková, merged in 1908 into Č15, which also went to Č23. Masaryk's realists are the same line: Č12 Česká strana lidová ("realisté") "1905 transformace v Č 13". So a progressive token is evidence for nar_dem, not for a liberal party standing apart from it. pokr is gone as a canonical.
  2. lid.pokr. → nar_dem is confirmed, not merely inherited: Č17 Lidová strana pokroková (1909, Moravia) is a co-founder of Č23.
  3. real. → nar_dem is confirmed by the Č12 → Č13 → Č23 chain.
  4. Free Thought is not a party. volnomyšlenkář / volná myšlenka was folded into pokr; it is a freethinker association and appears nowhere in the register. It is its own civic-org dummy now.

What the atlas refuses to settle (see REFUSED)

  • A bare "lidová". Eight parties in the register carry it — Č3 (Moravian liberal-national), Č11 (Catholic), Č12 (Masaryk's realists), Č17, Č20, Č21, Č25, plus N4 and P6 — spanning Catholic, liberal-national and Masarykite. v1.x had no bare lid token; that silence was right, and it is now a documented refusal rather than a gap. Only the unambiguous Catholic spellings (křesť.soc., kat.nár.) set lid.
  • A bare "demokrat" / "dem." (39 records). Social democrat, national democrat and státoprávní demokracie all reduce to it.
  • "SL" (108 records, the largest unmatched token) and every Slovak party. Plate IV.37 is v českých zemích — it contains no Slovak party at all, so it can neither confirm nor deny Slovenská liga or Hlinka's Slovenská ľudová strana. Needs a Slovak source; until then, unresolved.

The three gymnastic organisations stay as dummies of their own

sokol, orel and dtj are mobilisation proxies, not parties, and are never folded into an aligned party. Sokol is the mass Czech nationalist movement, Orel its Catholic counterpart, DTJ (Dělnická tělovýchovná jednota) the social-democratic one. Membership is a pre-war, revealed measure of which current a man had already joined — which is why it is worth a regressor of its own in a study of loyalty, and why it must not be read as a party statement.

v1.x additionally asserted party alignments for them — Sokol → nar_dem, DTJ → soc_dem, Orel → lid — on the same Wikipedia reading as the party genealogy. Those claims are dropped, and the field itself is why. Of the 1,323 Sokol members who also name a party: 59 % national socialist (784), 18 % national democrat (236), 13 % social democrat (167), 9 % agrarian (115). The alignment was three times off. But the spread is not a defect in the proxy — it is what makes it one: Sokol ran across the Czech national parties rather than inside any of them, so the dummy measures nationalist mobilisation precisely because it does not resolve to a party.

⚠ Read the scale before using it. pol_sokol is 10,367 records — 26.1 % of every non-empty affiliation cell, the largest single value in the field — and on 87 % of them it is the only thing recorded. For most of those men the cell says "gymnast", not "voter". Any specification that treats pol_* as party affiliation must exclude the civic organisations; PARTY_IDEOLOGY marks them Civic org but nothing structurally stops a regression from mixing them in. DTJ is the same shape at a twentieth of the size (314 records, 77 % org-only); Orel is 8 records and carries nothing.

Also dropped: rolník → agr. That mapped an occupation into a party dummy on the theory that a farmer self-describing is an Agrarian, while dělník in the same field mapped to nothing — an asymmetry with no source behind it, and the same error shape as D-43.

def parse_affiliation(s: str) -> dict:
    """Parse one raw affiliation string into a ``{canonical: True}`` dict.

    Returns an empty dict for null / placeholder values.  See :data:`REFUSED`
    for strings the atlas register deliberately does not resolve.
    """
    if pd.isna(s) or str(s).strip() in _PLACEHOLDERS:
        return {}
    raw = _normalise(s)
    hits: dict[str, set[str]] = {}
    for token in _matched_tokens(raw):
        canonical, _codes = TOKEN_MAP[token]
        hits.setdefault(canonical, set()).add(token)
    for canonical, (trigger, preempted_by) in _GENERIC_SUPPRESS.items():
        if hits.get(canonical) == {trigger} and preempted_by & hits.keys():
            del hits[canonical]
    return {canonical: True for canonical in hits}

def atlas_codes(s: str) -> str:
    """The IV.37 register codes a string is evidence for, pipe-joined.

    An audit column: it lets any coded record be taken back to a row of the
    printed table.  Empty where the affiliation is a civic organisation, a
    nationality marker or a Slovak formation, none of which the register covers.
    """
    if pd.isna(s) or str(s).strip() in _PLACEHOLDERS:
        return ""
    raw = _normalise(s)
    codes: set[str] = set()
    for token in _matched_tokens(raw):
        codes.update(TOKEN_MAP[token][1])
    return "|".join(sorted(codes, key=lambda c: (c[0], int(c[1:]))))

def affiliation_selftest() -> list[str]:
    """Return a list of behaviours that regressed; empty means all hold."""
    failures: list[str] = []
    for raw, expected in _SELFTEST_PARSE:
        got = parse_affiliation(raw)
        if got != expected:
            failures.append(f"{raw!r}: parsed {got}, expected {expected}")
    for raw, expected in _SELFTEST_CODES:
        got = atlas_codes(raw)
        if got != expected:
            failures.append(f"atlas_codes({raw!r}) = {got!r}, expected {expected!r}")
    # a refusal must be counted as a word, never as a bare substring
    if re.search(_refusal_pattern("sl", "word"), "slov.líga"):
        failures.append("refusal token 'sl' still matches inside 'slov.líga'")
    if not re.search(_refusal_pattern("lidov", "stem"), "lidová"):
        failures.append("refusal stem 'lidov' no longer matches 'lidová'")
    return failures

Append one boolean dummy per canonical affiliation, plus the audit column.

Column names follow pol_&lt;canonical&gt;, one for every entry of PARTY_ORDER whether or not it occurs in this frame; pol_atlas_codes carries the IV.37 register codes.

An unrecorded affiliation is &lt;NA&gt;, not False. 70.2 % of legionnaire records leave Politická příslušnost blank, and writing False there asserts "not a Sokol" on 93,377 men the source says nothing about — the shape that fabricated exit_N on 26.4k empty cells (audit A3), and the rule provenance.py states for its own flags. A record that is filled in but matches no token keeps False: the source spoke, and the register did not recognise what it said. pol_recorded separates the two, and any specification using these dummies should condition on it.

def add_affiliation_columns(df: pd.DataFrame,
                            source_col: str = "Politická příslušnost",
                            ) -> pd.DataFrame:
    """Append one boolean dummy per canonical affiliation, plus the audit column.

    Column names follow ``pol_<canonical>``, one for every entry of
    :data:`PARTY_ORDER` whether or not it occurs in this frame;
    ``pol_atlas_codes`` carries the IV.37 register codes.

    **An unrecorded affiliation is ``<NA>``, not ``False``.**  70.2 % of
    legionnaire records leave ``Politická příslušnost`` blank, and writing
    ``False`` there asserts "not a Sokol" on 93,377 men the source says nothing
    about — the shape that fabricated ``exit_N`` on 26.4k empty cells (audit
    A3), and the rule ``provenance.py`` states for its own flags.  A record that
    *is* filled in but matches no token keeps ``False``: the source spoke, and
    the register did not recognise what it said.  ``pol_recorded`` separates the
    two, and any specification using these dummies should condition on it.
    """
    df = df.copy()
    recorded = _is_recorded(df[source_col])
    parsed = df[source_col].apply(parse_affiliation)

    df[f"{COL_PREFIX}recorded"] = recorded
    for canonical in PARTY_ORDER:
        hits = parsed.apply(lambda d, c=canonical: d.get(c, False))
        df[f"{COL_PREFIX}{canonical}"] = hits.where(recorded, pd.NA).astype("boolean")
    df["pol_atlas_codes"] = df[source_col].apply(atlas_codes).where(recorded, pd.NA)
    return df

def affiliation_report(df: pd.DataFrame,
                       source_col: str = "Politická příslušnost",
                       ) -> None:
    """Print coverage for all ``pol_`` dummies, then the refusals and the tail.

    Counts are shares of the **recorded** base, not of the frame: the field is
    blank on most records and a percentage of 132,993 would understate every
    party by a factor of three.
    """
    pol_cols = [c for c in df.columns
                if c.startswith(COL_PREFIX)
                and c not in ("pol_atlas_codes", f"{COL_PREFIX}recorded")]
    if not pol_cols:
        print("No affiliation columns found. Run add_affiliation_columns() first.")
        return

    total = len(df)
    if f"{COL_PREFIX}recorded" in df.columns:
        recorded = df[f"{COL_PREFIX}recorded"].fillna(False).astype(bool)
    else:
        recorded = _is_recorded(df[source_col])

    summary = (
        df[pol_cols].sum()
        .rename(index=lambda c: c.removeprefix(COL_PREFIX))
        .reindex([p for p in PARTY_ORDER if f"{COL_PREFIX}{p}" in pol_cols])
        .fillna(0).astype(int)
    )
    n_rec = int(recorded.sum())
    print(f"Affiliation coverage — genealogy: Akademický atlas IV.37")
    print(f"  {total:,} records; field recorded on {n_rec:,} "
          f"({n_rec / total:.1%}), <NA> on the rest")
    print(summary.to_string())

    # A dummy is True/False only where the field was recorded, so "no hit"
    # means recorded-and-unmatched, never blank.
    hits = df[pol_cols].sum(axis=1, skipna=True)
    unresolved_mask = recorded & (hits == 0)

    raw = df[source_col].fillna("").map(_normalise)
    unmatched = df.loc[unresolved_mask, source_col]

    # Counted only among records that got no dummy at all: `dem.` occurs inside
    # `soc.dem.` on 17k coded records, and reporting those as "refused" would be
    # a false alarm about a field that coded correctly.
    unresolved = raw[unresolved_mask]
    print("\nRefused — present, and the register cannot resolve them:")
    for token, (kind, why) in REFUSED.items():
        n = int(unresolved.str.contains(_refusal_pattern(token, kind),
                                        regex=True, na=False).sum())
        if n:
            print(f"  {token:<10} {n:>5}   {why}")

    print(f"\nUnmatched recorded entries: {len(unmatched):,}")
    if len(unmatched):
        print(unmatched.value_counts().head(15).to_string())

"""
affiliations.py — political affiliation, on the atlas's own genealogy
=====================================================================
Parses the free-text ``Politická příslušnost`` field into per-party boolean
dummies.  v1.x built the party genealogy from Wikipedia; v2.0.0 rebuilds it on
the **Akademický atlas českých dějin**, plate **IV.37** (*Systém politických
stran v českých zemích*, p. 318) — a register of 55 parties of the Czech lands
1861–1918, each with its founding year, area of operation and a notes column
recording every merger, renaming and dissolution.  Transcribed and checked in
``reference/parties/`` (``atlas_iv37_parties.csv``, 12/12 invariants).

Every token below carries the atlas code(s) that justify it, so a reader can go
from a string in the data to a row in the printed register.

What the atlas changed
----------------------
1. **The "progressive" family is not a family.**  v1.x kept ``pokr`` as a
   separate *Liberal* bin.  The register says three of the four *pokrokové*
   parties co-founded Č23 *Česká státoprávní demokracie* — Č13 (1918
   spoluzakladatelka Č 23), Č15 (idem), Č17 (idem) — and Č23 was "1919
   přejmenována na Národní demokracii".  The fourth, Č7 *radikálně pokroková*,
   merged in 1908 into Č15, which also went to Č23.  Masaryk's realists are the
   same line: Č12 *Česká strana lidová* ("realisté") "1905 transformace v Č 13".
   So a progressive token is evidence for **nar_dem**, not for a liberal party
   standing apart from it.  ``pokr`` is gone as a canonical.
2. ``lid.pokr.`` **→ nar_dem is confirmed**, not merely inherited: Č17 *Lidová
   strana pokroková* (1909, Moravia) is a co-founder of Č23.
3. ``real.`` **→ nar_dem is confirmed** by the Č12 → Č13 → Č23 chain.
4. **Free Thought is not a party.**  ``volnomyšlenkář`` / ``volná myšlenka``
   was folded into ``pokr``; it is a freethinker association and appears
   nowhere in the register.  It is its own civic-org dummy now.

What the atlas refuses to settle (see :data:`REFUSED`)
------------------------------------------------------
* **A bare "lidová".**  Eight parties in the register carry it — Č3 (Moravian
  liberal-national), Č11 (Catholic), Č12 (Masaryk's realists), Č17, Č20, Č21,
  Č25, plus N4 and P6 — spanning Catholic, liberal-national and Masarykite.
  v1.x had no bare ``lid`` token; that silence was right, and it is now a
  documented refusal rather than a gap.  Only the unambiguous Catholic
  spellings (``křesť.soc.``, ``kat.nár.``) set ``lid``.
* **A bare "demokrat" / "dem."** (39 records).  Social democrat, national
  democrat and *státoprávní demokracie* all reduce to it.
* **"SL"** (108 records, the largest unmatched token) **and every Slovak
  party.**  Plate IV.37 is *v českých zemích* — it contains no Slovak party at
  all, so it can neither confirm nor deny *Slovenská liga* or Hlinka's
  *Slovenská ľudová strana*.  Needs a Slovak source; until then, unresolved.

The three gymnastic organisations stay as dummies of their own
------------------------------------------------------------
``sokol``, ``orel`` and ``dtj`` are **mobilisation proxies, not parties**, and are
never folded into an aligned party.  Sokol is the mass **Czech nationalist**
movement, Orel its Catholic counterpart, DTJ (*Dělnická tělovýchovná jednota*)
the social-democratic one.  Membership is a pre-war, revealed measure of which
current a man had already joined — which is why it is worth a regressor of its
own in a study of loyalty, and why it must not be read as a party statement.

v1.x additionally asserted party *alignments* for them — Sokol → ``nar_dem``,
DTJ → ``soc_dem``, Orel → ``lid`` — on the same Wikipedia reading as the party
genealogy.  Those claims are dropped, and the field itself is why.  Of the
**1,323** Sokol members who also name a party: **59 %** national socialist (784),
18 % national democrat (236), 13 % social democrat (167), 9 % agrarian (115).
The alignment was three times off.  But the *spread* is not a defect in the
proxy — it is what makes it one: Sokol ran **across** the Czech national parties
rather than inside any of them, so the dummy measures nationalist mobilisation
precisely because it does not resolve to a party.

⚠ **Read the scale before using it.**  ``pol_sokol`` is 10,367 records —
**26.1 % of every non-empty affiliation cell**, the largest single value in the
field — and on **87 %** of them it is the *only* thing recorded.  For most of
those men the cell says "gymnast", not "voter".  Any specification that treats
``pol_*`` as party affiliation must exclude the civic organisations;
:data:`PARTY_IDEOLOGY` marks them ``Civic org`` but nothing structurally stops a
regression from mixing them in.  DTJ is the same shape at a twentieth of the
size (314 records, 77 % org-only); Orel is 8 records and carries nothing.

Also dropped: ``rolník`` → ``agr``.  That mapped an **occupation** into a party
dummy on the theory that a farmer self-describing is an Agrarian, while
``dělník`` in the same field mapped to nothing — an asymmetry with no source
behind it, and the same error shape as D-43.

Usage
-----
    from utils.parsing.affiliations import add_affiliation_columns
    df = add_affiliation_columns(df)      # pol_soc_dem, pol_sokol, …
    affiliation_report(df)
"""

# A refusal is counted where the token stands as its own word, never as a bare
# substring.  Same anchoring discipline as `ranks` 1.4.0 and `education` 2.1.0.
_WORD_START = r"(?<![^\W\d_])"
_WORD_END = r"(?![^\W\d_])"


def _refusal_pattern(token: str, kind: str) -> str:
    pattern = _WORD_START + re.escape(token)
    return pattern if kind == "stem" else pattern + _WORD_END

# Generic tokens suppressed when a more specific affiliation already matched.
#   suppressed canonical → (its generic trigger token, {canonicals that pre-empt it})

    "russian": ("rus", {"rusyn"}),
}

COL_PREFIX = "pol_"

# Values that mean "the field was left blank", not "no affiliation".
_PLACEHOLDERS = frozenset({"", "?", "-"})

assert set(PARTY_ORDER) == {c for c, _ in TOKEN_MAP.values()}, (
    "PARTY_ORDER must name every canonical in TOKEN_MAP — the dummy columns "
    "are built from it, so a canonical missing here would never get a column")


def _is_recorded(source: pd.Series) -> pd.Series:
    """True where the affiliation field actually says something."""
    return source.notna() & ~source.astype(str).str.strip().isin(_PLACEHOLDERS)


def _normalise(s: str) -> str:
    raw = str(s).lower().strip()
    raw = re.sub(r"[,/]", " ", raw)
    return re.sub(r"\s+", " ", raw)


_TOKEN_RES = {t: re.compile(_WORD_START + re.escape(t)) for t in TOKEN_MAP}


def _matched_tokens(raw: str) -> set[str]:
    """Tokens present in a normalised string, with shadowed ones removed.

    A token must **start a word** (v2.2.0) — the anchor the refusal matcher already had.
    As a bare substring ``rus`` coded *organis. karpatorus* (a Carpatho-Rusyn) as Russian;
    the suffix stays free, so ``sokolský`` and ``odborář`` still count.

    A shorter token contained in a longer matched one is dropped: ``stát.pokr.``
    also contains ``pokr.``, and counting both would credit the record to Č13
    and Č17 as well as its own Č15.  Both tokens happen to map to the same
    canonical, so the dummies were right either way — but the atlas audit
    column was not, and a future token pair that disagrees would be a silent
    mis-coding.  This is the same longest-match discipline `occupations.py`
    applies, and the guard `education.py` needed for `pok.` vs `pok.prům.`
    """
    hits = {t for t, rx in _TOKEN_RES.items() if rx.search(raw)}
    return {t for t in hits
            if not any(t != other and t in other for other in hits)}


def parse_affiliation(s: str) -> dict:
    """Parse one raw affiliation string into a ``{canonical: True}`` dict.

    Returns an empty dict for null / placeholder values.  See :data:`REFUSED`
    for strings the atlas register deliberately does not resolve.
    """
    if pd.isna(s) or str(s).strip() in _PLACEHOLDERS:
        return {}
    raw = _normalise(s)
    hits: dict[str, set[str]] = {}
    for token in _matched_tokens(raw):
        canonical, _codes = TOKEN_MAP[token]
        hits.setdefault(canonical, set()).add(token)
    for canonical, (trigger, preempted_by) in _GENERIC_SUPPRESS.items():
        if hits.get(canonical) == {trigger} and preempted_by & hits.keys():
            del hits[canonical]
    return {canonical: True for canonical in hits}


def atlas_codes(s: str) -> str:
    """The IV.37 register codes a string is evidence for, pipe-joined.

    An audit column: it lets any coded record be taken back to a row of the
    printed table.  Empty where the affiliation is a civic organisation, a
    nationality marker or a Slovak formation, none of which the register covers.
    """
    if pd.isna(s) or str(s).strip() in _PLACEHOLDERS:
        return ""
    raw = _normalise(s)
    codes: set[str] = set()
    for token in _matched_tokens(raw):
        codes.update(TOKEN_MAP[token][1])
    return "|".join(sorted(codes, key=lambda c: (c[0], int(c[1:]))))


# ── Self-test ─────────────────────────────────────────────────────────────
# One case per behaviour, run by the QA gate.  Same pattern as
# ``provenance.provenance_selftest`` and ``education.education_selftest``.
_SELFTEST_PARSE: tuple[tuple[str, dict], ...] = (
    ("soc.dem.", {"soc_dem": True}),
    ("nár.soc., sokol", {"nar_soc": True, "sokol": True}),
    # the shadowed shorter token must not fire as well
    ("stát.pokr.", {"nar_dem": True}),
    ("pokr", {"nar_dem": True}),          # written without the stop
    ("pokrokový", {"nar_dem": True}),
    # Rusyn is not Russian
    ("rusín", {"rusyn": True}),
    # a token must start a word: a Carpatho-Rusyn is not a Russian (audit 2026-09-22)
    ("organis. karpatorus", {}),
    # "socialista" alone is refused like "demokrat"; the national socialists are not
    # social democrats
    ("socialista", {}),
    ("národní socialista", {"nar_soc": True}),
    ("agr. nár.socialista", {"agr": True, "nar_soc": True}),
    # the register's three refusals code nothing at all
    ("lidová", {}),
    ("demokrat", {}),
    ("SL", {}),
    # placeholders are not affiliations
    ("?", {}),
    ("-", {}),
)

_SELFTEST_CODES: tuple[tuple[str, str], ...] = (
    ("stát.pokr.", "Č15"),      # not Č13|Č15|Č17 — `pokr.` is shadowed by it
    ("mladočech", "Č2"),
    ("sokol", ""),              # a civic org is in no register row
)


def affiliation_selftest() -> list[str]:
    """Return a list of behaviours that regressed; empty means all hold."""
    failures: list[str] = []
    for raw, expected in _SELFTEST_PARSE:
        got = parse_affiliation(raw)
        if got != expected:
            failures.append(f"{raw!r}: parsed {got}, expected {expected}")
    for raw, expected in _SELFTEST_CODES:
        got = atlas_codes(raw)
        if got != expected:
            failures.append(f"atlas_codes({raw!r}) = {got!r}, expected {expected!r}")
    # a refusal must be counted as a word, never as a bare substring
    if re.search(_refusal_pattern("sl", "word"), "slov.líga"):
        failures.append("refusal token 'sl' still matches inside 'slov.líga'")
    if not re.search(_refusal_pattern("lidov", "stem"), "lidová"):
        failures.append("refusal stem 'lidov' no longer matches 'lidová'")
    return failures


def add_affiliation_columns(df: pd.DataFrame,
                            source_col: str = "Politická příslušnost",
                            ) -> pd.DataFrame:
    """Append one boolean dummy per canonical affiliation, plus the audit column.

    Column names follow ``pol_<canonical>``, one for every entry of
    :data:`PARTY_ORDER` whether or not it occurs in this frame;
    ``pol_atlas_codes`` carries the IV.37 register codes.

    **An unrecorded affiliation is ``<NA>``, not ``False``.**  70.2 % of
    legionnaire records leave ``Politická příslušnost`` blank, and writing
    ``False`` there asserts "not a Sokol" on 93,377 men the source says nothing
    about — the shape that fabricated ``exit_N`` on 26.4k empty cells (audit
    A3), and the rule ``provenance.py`` states for its own flags.  A record that
    *is* filled in but matches no token keeps ``False``: the source spoke, and
    the register did not recognise what it said.  ``pol_recorded`` separates the
    two, and any specification using these dummies should condition on it.
    """
    df = df.copy()
    recorded = _is_recorded(df[source_col])
    parsed = df[source_col].apply(parse_affiliation)

    df[f"{COL_PREFIX}recorded"] = recorded
    for canonical in PARTY_ORDER:
        hits = parsed.apply(lambda d, c=canonical: d.get(c, False))
        df[f"{COL_PREFIX}{canonical}"] = hits.where(recorded, pd.NA).astype("boolean")
    df["pol_atlas_codes"] = df[source_col].apply(atlas_codes).where(recorded, pd.NA)
    return df


def affiliation_report(df: pd.DataFrame,
                       source_col: str = "Politická příslušnost",
                       ) -> None:
    """Print coverage for all ``pol_`` dummies, then the refusals and the tail.

    Counts are shares of the **recorded** base, not of the frame: the field is
    blank on most records and a percentage of 132,993 would understate every
    party by a factor of three.
    """
    pol_cols = [c for c in df.columns
                if c.startswith(COL_PREFIX)
                and c not in ("pol_atlas_codes", f"{COL_PREFIX}recorded")]
    if not pol_cols:
        print("No affiliation columns found. Run add_affiliation_columns() first.")
        return

    total = len(df)
    if f"{COL_PREFIX}recorded" in df.columns:
        recorded = df[f"{COL_PREFIX}recorded"].fillna(False).astype(bool)
    else:
        recorded = _is_recorded(df[source_col])

    summary = (
        df[pol_cols].sum()
        .rename(index=lambda c: c.removeprefix(COL_PREFIX))
        .reindex([p for p in PARTY_ORDER if f"{COL_PREFIX}{p}" in pol_cols])
        .fillna(0).astype(int)
    )
    n_rec = int(recorded.sum())
    print(f"Affiliation coverage — genealogy: Akademický atlas IV.37")
    print(f"  {total:,} records; field recorded on {n_rec:,} "
          f"({n_rec / total:.1%}), <NA> on the rest")
    print(summary.to_string())

    # A dummy is True/False only where the field was recorded, so "no hit"
    # means recorded-and-unmatched, never blank.
    hits = df[pol_cols].sum(axis=1, skipna=True)
    unresolved_mask = recorded & (hits == 0)

    raw = df[source_col].fillna("").map(_normalise)
    unmatched = df.loc[unresolved_mask, source_col]

    # Counted only among records that got no dummy at all: `dem.` occurs inside
    # `soc.dem.` on 17k coded records, and reporting those as "refused" would be
    # a false alarm about a field that coded correctly.
    unresolved = raw[unresolved_mask]
    print("\nRefused — present, and the register cannot resolve them:")
    for token, (kind, why) in REFUSED.items():
        n = int(unresolved.str.contains(_refusal_pattern(token, kind),
                                        regex=True, na=False).sum())
        if n:
            print(f"  {token:<10} {n:>5}   {why}")

    print(f"\nUnmatched recorded entries: {len(unmatched):,}")
    if len(unmatched):
        print(unmatched.value_counts().head(15).to_string())
