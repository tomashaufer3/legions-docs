How it works

The frozen route anchors every place the 1910 register prints to a settlements_1910 row (utils.lexikon_1910.lexikon_1910_register.anchor_places): a fuzzy match of the printed name cell against the settlements of the place's own okres, refused below 84 and on a tie. It is frozen (digest-held, D-119), and three of its choices leave places unanchored that a reader can anchor:

  • short names are dropped. lexikon_1910_names.parse_name_cell and Obec.keys keep only forms of 3+ letters (names module, l. 207 / 236 / 573), a guard against chance matches. Aš folds to as: both the register (Aš, Asch) and the lexicon (AŠ) print it right, and the town of 21,880 was never anchored. The required exception (author, 2026-11-16).
  • the lexicon's text-layer defects. Kosmanosy o bec (settlements_1910.name_1910, its status empty) cannot equal the register's Kosmanosy; utils.parsing.place_names heals it.
  • an alias ties a headword. CHRASTAVA viz Dolní Chrastava puts Chrastava on two more obce of okres Liberec, so the town ties at 100 three ways and is refused.

This module re-searches each unanchored place with healed names and short forms allowed, and writes only the certain answers to reference/places/anchor_overrides.csv:

a unique candidate inside the place's own okres (or, failing that, its own court) — at the best
tier, a name before an alias — *and* status `obec` for a municipality, *and* the settlement not
already anchored by another place of the edition, *and* a second, independent signal: the
lexicon's 1910 population (ČSÚ lexicon 1869–2005, díl I) within 10 % of the register's, or the
settlement's point inside the MPIDR polygon of the register's court.

Everything else goes to output/places/anchor_candidates.csv for the author, with the reason it is not certain. apply fills settlement_id from the overrides (pure, never overwrites an anchor, never applies to a row whose printed name has changed) — to be hooked into register_rechecked by the main session; this module edits nothing frozen and nothing in data/final.

Generated vs ruled (1.1.0). anchor_overrides.csv is generated: build rewrites it on every run. Rulings by the author or on evidence live in reference/places/anchor_rulings.csv, which this module never writes: evidence rulings are added by hand, each with its basis, and the only code that writes the table is the author's ruling page readback (utils.recheck.anchor_rulings_page.as_author_rulings, --write), which sets ruled_by = author on the rows of a confirmed card and moves a rejected card's rows to reference/places/anchor_rulings_rejected.csv (D-244). Each ruling names a place (KEY + the printed_name it was ruled on) and an action:

  • anchor — fill an empty anchor with settlement_id;
  • replace — swap a frozen anchor old_settlement_id for settlement_id (a wrong fuzzy choice: Kostomlátky had taken kostomlaty-nad-labem:1);
  • unanchor — remove old_settlement_id from a place that should hold none (a spurious row: the Vejprty municipality total read a second time as a part of Schmiedeberg).

Every ruling carries a basis (evidence: … or the author's words) and ruled_by (evidence until the author confirms it, then author; no other value is accepted). A ruling wins over a generated row for the same place. Its precondition is checked against the frozen anchor, not against other rulings: a ruling whose printed name, or whose old_settlement_id, no longer matches is refused (skipped, warned, listed in attrs["anchor_rulings_refused"]), never forced.

The confirmation gate (1.2.0). A ruling the author has not confirmed must not silently drive the analysis, so apply applies by default only rulings with ruled_by = "author"; an evidence ruling applies only with include_unconfirmed=True and is otherwise listed in attrs["anchor_rulings_unconfirmed"] (unconfirmed_rulings lists them from the table). The generated overrides are not rulings — they are the certain rule's output — and apply either way. Only a ruling that is applied settles its place: a refused or unconfirmed one neither blocks the place's generated row nor takes the place out of the build search, which runs with the confirmed rulings only. With include_unconfirmed=True an unconfirmed ruling still wins on its own place; build lists every unapplied ruling (ruling_refused / ruling_unconfirmed) beside the generated row the place got, if any.

The validation (validate_anchoring → output/places/anchor_validation.json). The register–lexikon okres agreement is 100 % by construction — anchoring searches inside the okres — so it proves nothing. Three checks that are not circular:

(a) geometry — the anchored settlement's point (settlements_1910_geo) located in the MPIDR court polygons by plain containment (no snap), against the court the register files the place under; by edition, anchor status and point source. The crosswalk's RÚIAN points were searched inside the 1910 okres, so okres containment is partly built in for them; the court (finer than the okres) is not, and the Wikidata point is independent of both. matched_court used the spatial court as a tie-break and is circular for (a); it is reported, not counted. (b) population — the register prints 1910 population per place; the ČSÚ lexicon 1869–2005 díl I prints it per 2005 obec and part recomputed onto 2005 territory (its foreword). The text-layer reader is utils.validation.lexikon_population (shifted-font decode); here it runs over all 77 okresy. A settlement reaches a díl I row through its RÚIAN obec/part names, not the register. (c) boundaries — every unanchored name searched in all okresy: found in its own okres (an anchoring miss), only in an adjacent okres (a true boundary disagreement), only further away, or nowhere. Okres adjacency is read off the MPIDR polygons (vertices within 250 m). (d) twins — the Czech and the German Bohemian volume print the same places, so a place's anchor in cz and in de-bohemia must agree. The twin is the register's own link (cz_muni_seq/cz_settlement_seq) when the two rows share a printed name form and a population; otherwise the one cz row of the same court and level that does. A link that fails that test is reported (the Kostomlaty pair is linked crosswise), never trusted.

class Courts:
    """The MPIDR Czech-lands court polygons, vectorised containment and distance."""

    def __init__(self, base: Path = MPIDR):
        from utils.parsing import spatial as sp
        loc = sp.CourtLocator(f"{base}.dbf", f"{base}.shp")
        self._laea = sp.laea_forward
        self.courts = {cid: (rings, bbox) for cid, _code, rings, bbox in loc.courts}

    def project(self, lon, lat):
        return self._laea(np.asarray(lon, float), np.asarray(lat, float))

    @staticmethod
    def _crossings(px, py, ring) -> np.ndarray:
        x0, y0 = ring[:, 0], ring[:, 1]
        x1, y1 = np.roll(x0, -1), np.roll(y0, -1)
        straddle = (y0[None, :] > py[:, None]) != (y1[None, :] > py[:, None])
        with np.errstate(divide="ignore", invalid="ignore"):
            xint = x0[None, :] + (py[:, None] - y0[None, :]) * (x1 - x0)[None, :] / (y1 - y0)[None, :]
        return (straddle & (px[:, None] < xint)).sum(axis=1)

    def contains(self, court_id: int, px, py) -> np.ndarray:
        """Even-odd containment of projected points in one court (holes are extra rings)."""
        rings, (x0, y0, x1, y1) = self.courts[court_id]
        px, py = np.atleast_1d(px), np.atleast_1d(py)
        out = np.zeros(len(px), bool)
        box = (px >= x0) & (px <= x1) & (py >= y0) & (py <= y1)
        if box.any():
            n = sum(self._crossings(px[box], py[box], r) for r in rings)
            out[box] = n % 2 == 1
        return out

    def locate(self, lon, lat) -> np.ndarray:
        """Court id containing each WGS84 point (raw containment, no snap); 0 where none."""
        px, py = self.project(lon, lat)
        px, py = np.atleast_1d(px), np.atleast_1d(py)
        out = np.zeros(len(px), np.int64)
        ok = np.isfinite(px) & np.isfinite(py)
        for cid in self.courts:
            todo = ok & (out == 0)
            if not todo.any():
                break
            hit = self.contains(cid, px[todo], py[todo])
            idx = np.flatnonzero(todo)[hit]
            out[idx] = cid
        return out

    def distance_m(self, court_id: int, lon: float, lat: float) -> float:
        """Metres from a point to a court's outline (0 inside)."""
        px, py = self.project(lon, lat)
        px, py = float(np.atleast_1d(px)[0]), float(np.atleast_1d(py)[0])
        if self.contains(court_id, np.array([px]), np.array([py]))[0]:
            return 0.0
        best = np.inf
        for ring in self.courts[court_id][0]:
            a, b = ring, np.roll(ring, -1, axis=0)
            d = b - a
            t = np.clip(((px - a[:, 0]) * d[:, 0] + (py - a[:, 1]) * d[:, 1])
                        / np.maximum((d ** 2).sum(1), 1e-9), 0, 1)
            best = min(best, float(np.hypot(a[:, 0] + t * d[:, 0] - px,
                                            a[:, 1] + t * d[:, 1] - py).min()))
        return best

    def okres_adjacency(self, tol_m: float = ADJACENT_M) -> dict[int, set[int]]:
        """``{okres_id: {adjacent okres_id}}`` — outlines within ``tol_m`` of each other."""
        from scipy.spatial import cKDTree
        pts: dict[int, np.ndarray] = {}
        for cid, (rings, _) in self.courts.items():
            pts.setdefault(cid // 1000, []).append(np.vstack(rings))
        pts = {o: np.vstack(v) for o, v in pts.items()}
        trees = {o: cKDTree(v) for o, v in pts.items()}
        box = {o: (v[:, 0].min(), v[:, 1].min(), v[:, 0].max(), v[:, 1].max()) for o, v in pts.items()}
        adj: dict[int, set[int]] = {o: set() for o in pts}
        okresy = sorted(pts)
        for i, a in enumerate(okresy):
            for b in okresy[i + 1:]:
                (ax0, ay0, ax1, ay1), (bx0, by0, bx1, by1) = box[a], box[b]
                if ax0 > bx1 + tol_m or bx0 > ax1 + tol_m or ay0 > by1 + tol_m or by0 > ay1 + tol_m:
                    continue
                d, _ = trees[b].query(pts[a], k=1, distance_upper_bound=tol_m)
                if np.isfinite(d).any():
                    adj[a].add(b)
                    adj[b].add(a)
        return adj

def read_dil1(cache: Path | None = OUT / "lexikon_dil1_pop_1910.parquet") -> pd.DataFrame:
    """Every data row of the ČSÚ lexicon 1869–2005 díl I: ``okres, obec, level, name, pop_1910``.

    Names stay in the volume's shifted alphabet (compare through :func:`dil1_key`). The header
    ``Okres X`` names the 2005 okres; Prague's pages carry none and are filed ``praha``. ~22 s.
    """
    if cache is not None and Path(cache).exists():
        return pd.read_parquet(cache)
    import pymupdf
    from utils.validation import lexikon_population as lp
    doc = pymupdf.open(str(lp.PDF))
    rows, obec_name = [], None
    for pg in range(len(doc)):
        spans = lp._spans(doc[pg])
        if not lp._years(spans):
            continue
        found = lp.data_rows(doc[pg])
        head = [t for y, _x0, _x1, t in spans if y < 60 and t.startswith("Okres ")]
        okres = head[0][len("Okres "):] if head else "praha"
        for r in found:
            if r["name"] == "Okres celkem" or re.match(r"\d", r["name"]):
                continue
            if r["level"] == "obec":
                obec_name = r["name"]
            rows.append({"page": pg, "okres": okres, "obec": obec_name, "level": r["level"],
                         "name": r["name"], "pop_1910": r["pop_1910"]})
    out = pd.DataFrame(rows)
    out["pop_1910"] = out["pop_1910"].astype("Int64")
    if cache is not None:
        Path(cache).parent.mkdir(parents=True, exist_ok=True)
        out.to_parquet(cache, index=False)
    return out

def settlement_population(geo: pd.DataFrame, dil1: pd.DataFrame) -> pd.DataFrame:
    """``settlement_id, dil1_part_pop, dil1_obec_pop, dil1_parts`` through RÚIAN names.

    The settlement's modern okres and obec (``settlements_1910_geo.okres_name/obec_name``) find the
    díl I obec; the part is its RÚIAN part name (``place_name`` when matched to a part) or else its
    own headword. A name two díl I rows share inside one okres is dropped, never guessed.
    """
    d = dil1.copy()
    d["okres_k"] = d["okres"].map(_dil1_raw_key)
    d["obec_k"] = d["obec"].map(_dil1_raw_key)
    d["name_k"] = d["name"].map(_dil1_raw_key)
    obce = d[d["level"] == "obec"].drop_duplicates(["okres_k", "obec_k"], keep=False)
    obec_pop = dict(zip(zip(obce["okres_k"], obce["obec_k"]), obce["pop_1910"]))
    n_parts = d[d["level"] == "part"].groupby(["okres_k", "obec_k"]).size().to_dict()
    parts = d[d["level"] == "part"].drop_duplicates(["okres_k", "obec_k", "name_k"], keep=False)
    part_pop = dict(zip(zip(parts["okres_k"], parts["obec_k"], parts["name_k"]), parts["pop_1910"]))

    rows = []
    for g in geo.itertuples(index=False):
        if not isinstance(g.obec_name, str):
            continue
        okres = "praha" if g.okres_name == "Hlavní město Praha" else dil1_key(g.okres_name)
        obec = dil1_key("Praha" if okres == "praha" else g.obec_name)
        part_name = g.place_name if g.match_source == "ruian_part" else g.cs_name.title()
        ob = obec_pop.get((okres, obec))
        pt = part_pop.get((okres, obec, dil1_key(part_name)))
        if pt is None and n_parts.get((okres, obec), 0) == 0 and dil1_key(part_name) == obec:
            pt = ob                                       # an obec with no parts is its own part
        rows.append({"settlement_id": g.settlement_id, "dil1_obec_pop": ob, "dil1_part_pop": pt,
                     "dil1_parts": n_parts.get((okres, obec), 0)})
    out = pd.DataFrame(rows, columns=["settlement_id", "dil1_obec_pop", "dil1_part_pop", "dil1_parts"])
    for c in ("dil1_obec_pop", "dil1_part_pop"):
        out[c] = out[c].astype("Int64")
    return out

def pop_agrees(a, b, tol: float = POP_TOLERANCE, slack: int = POP_SLACK) -> bool | None:
    """Two populations within ``tol`` of the larger, or ``slack`` people; None if either missing."""
    if a is None or b is None or pd.isna(a) or pd.isna(b):
        return None
    a, b = int(a), int(b)
    return abs(a - b) <= max(tol * max(a, b), slack)

def decide(cands: pd.DataFrame) -> pd.DataFrame:
    """``certain`` and ``why_not`` on every candidate row; certain = the rule in the module docstring."""
    out = cands.copy()
    why = []
    for r in out.itertuples(index=False):
        if r.reason:
            why.append(r.reason)
            continue
        reasons = []
        if not r.best:
            reasons.append("lower_tier")
        if r.kind != "name":
            reasons.append("word_match_only")
        unique_okres = r.n_okres == 1
        unique_court = not unique_okres and r.n_court == 1 and r.in_court is True
        if not (unique_okres or unique_court):
            reasons.append(f"not_unique({r.n_okres} in okres, {r.n_court} in court)")
        if r.place_level == "municipality" and r.status_1910 != "obec":
            reasons.append(f"status_{r.status_1910 if isinstance(r.status_1910, str) else 'missing'}")
        if r.claimed:
            reasons.append("settlement_already_anchored")
        if r.pop_agrees is False and r.pop_level == "settlement":
            reasons.append(f"population_disagrees({int(r.pop_total)} vs {int(r.lexikon_pop)})")
        # The court cannot be both what made the candidate unique and the second signal.
        elif not (r.pop_agrees is True or (r.in_court is True and unique_okres)):
            reasons.append("no_second_signal")
        why.append("; ".join(reasons))
    out["why_not"] = why
    out["certain"] = out["why_not"] == ""
    # Two places of one edition and level certain of one settlement: neither is (refused, D-22).
    cert = out[out["certain"]]
    owners = cert.groupby(["edition", "settlement_id"])[["court_key", "muni_seq"]].nunique().max(axis=1)
    levels = cert.groupby(["edition", "settlement_id", "place_level"]).size()
    bad = set(owners[owners > 1].index) | {k[:2] for k, n in levels.items() if n > 1}
    contested = [(e, sid) in bad for e, sid in zip(cert["edition"], cert["settlement_id"])]
    out.loc[cert.index[contested], "why_not"] = "contested_by_another_place"
    # A place certain of two settlements (one per form) is not certain either.
    cert = out[out["certain"] & (out["why_not"] == "")]
    twice = cert.duplicated(KEY, keep=False)
    out.loc[cert.index[twice], "why_not"] = "two_certain_settlements"
    out["certain"] = out["why_not"] == ""
    return out

            "unconfirmed": int((~conf).sum()), "by_action": by}

          rulings_path: Path = RULINGS) -> dict:

    The rulings (``rulings_path``) are read, never written. The search runs on the places with the
    **confirmed** rulings applied — their anchors count as claims, the places they settle are not
    searched — so a generated row can neither repeat nor contradict an applied ruling. A refused or
    unconfirmed ruling settles nothing: its place is searched like any other, and

    :func:`apply` are measured (``include_unconfirmed`` False / True).

    unhealed = pn.unhealed_splits(settlements, heals)
    _write_csv(heals, out_dir / "healed_names.csv")
    _write_csv(unhealed, out_dir / "healed_names_left_alone.csv")
    _write_csv(pn.name_index(settlements, heals), out_dir / "healed_name_index.csv")
    heal_summary = pn.heal_report(heals, unhealed)

        "rulings_table": rulings_summary(rulings),

        "rulings_refused": applied.attrs.get("anchor_rulings_refused", []),
        "unconfirmed_with_generated_row": not_applied[not_applied["generated_settlement_id"].notna()]
        .astype(str).to_dict("records"),
        "unanchored_frozen": _unanchored(places),
        "unanchored_default": _unanchored(applied),
        "unanchored_with_unconfirmed": _unanchored(applied_all) if applied_all is not None else None,
        "include_unconfirmed_error": all_error,
        "twins_frozen": {k: twins["frozen"][k] for k in ("verdicts", "links_failed")},
        "twins_default": {k: twins["applied"][k] for k in ("verdicts", "links_failed")},
        "twins_with_unconfirmed": ({k: twins["applied_with_unconfirmed"][k] for k in ("verdicts", "links_failed")}

        "owner_changes_by_confirmed_rulings": owner_rows_rulings.astype(str).to_dict("records"),

    # candidates and where else in the Czech lands its name is found (check (c)); ranked by 1910
    # population, births. A place whose ruling was not applied stays here, marked with the reason.

    cand["ruling_reason"] = [m[0] for m in marks]
    cand["ruling_action"] = [m[1] for m in marks]
    cand["ruling_settlement_id"] = [m[2] for m in marks]
    cand = cand.sort_values(["pop_total", "births"], ascending=False)
    _write_csv(cand, out_dir / "anchor_candidates.csv")
    rt = summary["rulings_table"]
    print(f"  anchor_overrides {__version__}: {len(overrides)} certain overrides "
          f"({summary['generated_rules']}); {rt['rulings']} rulings ({rt['confirmed']} confirmed, "
          f"{rt['unconfirmed']} unconfirmed; {rt['by_action']}); applied by default "
          f"{summary['rulings_applied_default']}, with unconfirmed "

# ── geometry ──────────────────────────────────────────────────────────────────
class Courts:
    """The MPIDR Czech-lands court polygons, vectorised containment and distance."""

    def __init__(self, base: Path = MPIDR):
        from utils.parsing import spatial as sp
        loc = sp.CourtLocator(f"{base}.dbf", f"{base}.shp")
        self._laea = sp.laea_forward
        self.courts = {cid: (rings, bbox) for cid, _code, rings, bbox in loc.courts}

    def project(self, lon, lat):
        return self._laea(np.asarray(lon, float), np.asarray(lat, float))

    @staticmethod
    def _crossings(px, py, ring) -> np.ndarray:
        x0, y0 = ring[:, 0], ring[:, 1]
        x1, y1 = np.roll(x0, -1), np.roll(y0, -1)
        straddle = (y0[None, :] > py[:, None]) != (y1[None, :] > py[:, None])
        with np.errstate(divide="ignore", invalid="ignore"):
            xint = x0[None, :] + (py[:, None] - y0[None, :]) * (x1 - x0)[None, :] / (y1 - y0)[None, :]
        return (straddle & (px[:, None] < xint)).sum(axis=1)

    def contains(self, court_id: int, px, py) -> np.ndarray:
        """Even-odd containment of projected points in one court (holes are extra rings)."""
        rings, (x0, y0, x1, y1) = self.courts[court_id]
        px, py = np.atleast_1d(px), np.atleast_1d(py)
        out = np.zeros(len(px), bool)
        box = (px >= x0) & (px <= x1) & (py >= y0) & (py <= y1)
        if box.any():
            n = sum(self._crossings(px[box], py[box], r) for r in rings)
            out[box] = n % 2 == 1
        return out

    def locate(self, lon, lat) -> np.ndarray:
        """Court id containing each WGS84 point (raw containment, no snap); 0 where none."""
        px, py = self.project(lon, lat)
        px, py = np.atleast_1d(px), np.atleast_1d(py)
        out = np.zeros(len(px), np.int64)
        ok = np.isfinite(px) & np.isfinite(py)
        for cid in self.courts:
            todo = ok & (out == 0)
            if not todo.any():
                break
            hit = self.contains(cid, px[todo], py[todo])
            idx = np.flatnonzero(todo)[hit]
            out[idx] = cid
        return out

    def distance_m(self, court_id: int, lon: float, lat: float) -> float:
        """Metres from a point to a court's outline (0 inside)."""
        px, py = self.project(lon, lat)
        px, py = float(np.atleast_1d(px)[0]), float(np.atleast_1d(py)[0])
        if self.contains(court_id, np.array([px]), np.array([py]))[0]:
            return 0.0
        best = np.inf
        for ring in self.courts[court_id][0]:
            a, b = ring, np.roll(ring, -1, axis=0)
            d = b - a
            t = np.clip(((px - a[:, 0]) * d[:, 0] + (py - a[:, 1]) * d[:, 1])
                        / np.maximum((d ** 2).sum(1), 1e-9), 0, 1)
            best = min(best, float(np.hypot(a[:, 0] + t * d[:, 0] - px,
                                            a[:, 1] + t * d[:, 1] - py).min()))
        return best

    def okres_adjacency(self, tol_m: float = ADJACENT_M) -> dict[int, set[int]]:
        """``{okres_id: {adjacent okres_id}}`` — outlines within ``tol_m`` of each other."""
        from scipy.spatial import cKDTree
        pts: dict[int, np.ndarray] = {}
        for cid, (rings, _) in self.courts.items():
            pts.setdefault(cid // 1000, []).append(np.vstack(rings))
        pts = {o: np.vstack(v) for o, v in pts.items()}
        trees = {o: cKDTree(v) for o, v in pts.items()}
        box = {o: (v[:, 0].min(), v[:, 1].min(), v[:, 0].max(), v[:, 1].max()) for o, v in pts.items()}
        adj: dict[int, set[int]] = {o: set() for o in pts}
        okresy = sorted(pts)
        for i, a in enumerate(okresy):
            for b in okresy[i + 1:]:
                (ax0, ay0, ax1, ay1), (bx0, by0, bx1, by1) = box[a], box[b]
                if ax0 > bx1 + tol_m or bx0 > ax1 + tol_m or ay0 > by1 + tol_m or by0 > ay1 + tol_m:
                    continue
                d, _ = trees[b].query(pts[a], k=1, distance_upper_bound=tol_m)
                if np.isfinite(d).any():
                    adj[a].add(b)
                    adj[b].add(a)
        return adj


# ── the lexicon's 1910 population (díl I) ─────────────────────────────────────
def read_dil1(cache: Path | None = OUT / "lexikon_dil1_pop_1910.parquet") -> pd.DataFrame:
    """Every data row of the ČSÚ lexicon 1869–2005 díl I: ``okres, obec, level, name, pop_1910``.

    Names stay in the volume's shifted alphabet (compare through :func:`dil1_key`). The header
    ``Okres X`` names the 2005 okres; Prague's pages carry none and are filed ``praha``. ~22 s.
    """
    if cache is not None and Path(cache).exists():
        return pd.read_parquet(cache)
    import pymupdf
    from utils.validation import lexikon_population as lp
    doc = pymupdf.open(str(lp.PDF))
    rows, obec_name = [], None
    for pg in range(len(doc)):
        spans = lp._spans(doc[pg])
        if not lp._years(spans):
            continue
        found = lp.data_rows(doc[pg])
        head = [t for y, _x0, _x1, t in spans if y < 60 and t.startswith("Okres ")]
        okres = head[0][len("Okres "):] if head else "praha"
        for r in found:
            if r["name"] == "Okres celkem" or re.match(r"\d", r["name"]):
                continue
            if r["level"] == "obec":
                obec_name = r["name"]
            rows.append({"page": pg, "okres": okres, "obec": obec_name, "level": r["level"],
                         "name": r["name"], "pop_1910": r["pop_1910"]})
    out = pd.DataFrame(rows)
    out["pop_1910"] = out["pop_1910"].astype("Int64")
    if cache is not None:
        Path(cache).parent.mkdir(parents=True, exist_ok=True)
        out.to_parquet(cache, index=False)
    return out


def dil1_key(name) -> str:
    """A name as díl I spells it: modern spelling folded into its alphabet, spaces dropped."""

    obec_pop = dict(zip(zip(obce["okres_k"], obce["obec_k"]), obce["pop_1910"]))
    n_parts = d[d["level"] == "part"].groupby(["okres_k", "obec_k"]).size().to_dict()
    parts = d[d["level"] == "part"].drop_duplicates(["okres_k", "obec_k", "name_k"], keep=False)
    part_pop = dict(zip(zip(parts["okres_k"], parts["obec_k"], parts["name_k"]), parts["pop_1910"]))

    rows = []
    for g in geo.itertuples(index=False):
        if not isinstance(g.obec_name, str):
            continue
        okres = "praha" if g.okres_name == "Hlavní město Praha" else dil1_key(g.okres_name)
        obec = dil1_key("Praha" if okres == "praha" else g.obec_name)
        part_name = g.place_name if g.match_source == "ruian_part" else g.cs_name.title()
        ob = obec_pop.get((okres, obec))
        pt = part_pop.get((okres, obec, dil1_key(part_name)))
        if pt is None and n_parts.get((okres, obec), 0) == 0 and dil1_key(part_name) == obec:
            pt = ob                                       # an obec with no parts is its own part
        rows.append({"settlement_id": g.settlement_id, "dil1_obec_pop": ob, "dil1_part_pop": pt,
                     "dil1_parts": n_parts.get((okres, obec), 0)})
    out = pd.DataFrame(rows, columns=["settlement_id", "dil1_obec_pop", "dil1_part_pop", "dil1_parts"])
    for c in ("dil1_obec_pop", "dil1_part_pop"):
        out[c] = out[c].astype("Int64")
    return out


def pop_agrees(a, b, tol: float = POP_TOLERANCE, slack: int = POP_SLACK) -> bool | None:
    """Two populations within ``tol`` of the larger, or ``slack`` people; None if either missing."""
    if a is None or b is None or pd.isna(a) or pd.isna(b):
        return None
    a, b = int(a), int(b)
    return abs(a - b) <= max(tol * max(a, b), slack)


# ── the authority, healed ─────────────────────────────────────────────────────
def authority(settlements: pd.DataFrame, heals: pd.DataFrame, aliases: pd.DataFrame | None) -> pd.DataFrame:
    """Long frame ``settlement_id, okres_id, court_id, status, key, tier, healed`` — every match key.

    ``tier`` 1 = the settlement's own name (headword, 1910 name, German name; healed forms and
    ``t.`` alternates included), 2 = a ČSÚ ``viz`` alias pointing at its headword. ``okres_id`` falls
    back to the court's okres as :func:`lexikon_1910_register.load_authority` does; ``status`` is the
    healed status (a leaked ``o bec`` restored). ``healed`` is True only for a key that no unhealed
    form of the settlement also yields — the key exists *because of* the heal.
    """
    healed = pn.healed_attributes(settlements, heals)
    okres = healed["okres_id"].astype("Int64").copy()
    court = healed["court_id"].astype("Int64")
    fill = okres.isna() & court.notna()
    okres[fill] = court[fill] // 1000
    base = pd.DataFrame({"settlement_id": healed["settlement_id"], "okres_id": okres,
                         "court_id": court, "status": healed["status_1910"],
                         "cs_name": healed["cs_name"]})
    idx = pn.name_index(settlements, heals)
    names = idx[["settlement_id", "form", "healed"]].assign(tier=1)
    names["healed"] = names["healed"].astype(bool)
    parts = [names]
    if aliases is not None and len(aliases):
        head = pd.DataFrame({"settlement_id": healed["settlement_id"],
                             "tk": healed["cs_name"].map(normalise)})
        al = aliases.dropna(subset=["cs_name", "viz_target"]).assign(tk=lambda a: a["viz_target"].map(normalise))
        parts.append(al.merge(head, on="tk")[["settlement_id", "cs_name"]]
                     .rename(columns={"cs_name": "form"}).assign(tier=2, healed=False))
    long = pd.concat(parts, ignore_index=True)
    long["key"] = long["form"].map(normalise)
    long = long[long["key"].str.len() >= 2]
    # The best tier first, and within it an unhealed form before a healed one: a key any unhealed
    # form yields is not owed to the heal (name_index dedups on a casefold key, this on normalise).
    long = (long.sort_values(["tier", "healed"], kind="stable")
            .drop_duplicates(["settlement_id", "key"]))
    return long.merge(base, on="settlement_id", how="left")


def place_forms(cell) -> list[tuple[str, str]]:
    """``(key, kind)`` for one printed name cell: ``name`` per printed form (short ones kept — *Aš*),
    ``word`` per word or word pair of a form printing two names without a comma
    (``Rapotín Rejpotín``)."""
    out: list[tuple[str, str]] = []
    for form in pn.cell_forms(cell):
        key = normalise(form)
        if len(key) >= 2:
            out.append((key, "name"))
        words = [w for w in re.split(r"\s+", form) if w]
        if len(words) >= 2:
            grams = words + [f"{a} {b}" for a, b in zip(words, words[1:])]
            for g in grams:
                k = normalise(g)
                if len(k) >= 3 and k not in _WORD_STOP and k != key:
                    out.append((k, "word"))
    seen, uniq = set(), []
    for k, kind in out:
        if k not in seen:
            seen.add(k)
            uniq.append((k, kind))
    return uniq


# ── the soldiers ──────────────────────────────────────────────────────────────
def birth_keys(final_dir: Path = FINAL) -> pd.Series:
    """Births per ``(birth_okres_id, key)``, legionnaires + VÚA fallen, Czech-lands okresy.

    The key is the whole ``birth_municipality``; a VÚA ``parent-part`` string also counts under each
    hyphen piece (``Bratrouchov-Brno`` under ``bratrouchov`` and ``brno``).
    """
    frames = []
    for name in ("legionnaires_clean", "habsburg_clean"):
        path = Path(final_dir) / "persons" / f"{name}.parquet"
        if path.exists():
            frames.append(pd.read_parquet(path, columns=["birth_municipality", "birth_okres_id"]))
    if not frames:
        return pd.Series(dtype="int64")
    b = pd.concat(frames, ignore_index=True).dropna()
    keys = []
    for muni, okres in zip(b["birth_municipality"], b["birth_okres_id"]):
        pieces = {normalise(muni)} | {normalise(p) for p in str(muni).split("-")}
        keys += [(int(okres), k) for k in pieces if k]
    return pd.Series(keys).value_counts()


# ── candidates and the certain few ────────────────────────────────────────────
def _claims(places: pd.DataFrame) -> dict[tuple, set[tuple]]:
    """``{(edition, settlement_id): {(court_key, muni_seq, level)}}`` for every anchored place."""
    a = places[places["settlement_id"].notna()]
    out: dict[tuple, set[tuple]] = {}
    for e, sid, ck, ms, lvl in zip(a["edition"], a["settlement_id"].astype(str), a["court_key"],
                                   a["muni_seq"], a["place_level"]):
        out.setdefault((e, sid), set()).add((ck, ms, lvl))
    return out


def claimed_elsewhere(claims: dict, edition: str, sid: str, court_key, muni_seq, level: str) -> bool:
    """Whether another place of the edition already holds ``sid``: any place of the same level, or a
    place of the other level outside this municipality (a municipality and its own eponymous part
    share a settlement legitimately)."""
    for ck, ms, lvl in claims.get((edition, sid), ()):
        if lvl == level or (ck, ms) != (court_key, muni_seq):
            return True
    return False


def _compare_pop(p, popd: pd.DataFrame, sid: str, n_parts: pd.Series) -> tuple:
    """``(lexikon_pop, agrees, level)`` for one place and candidate.

    ``settlement``: a part, or a municipality printed without parts, against the díl I part (a
    disagreement contradicts the candidate). ``obec_2005``: a municipality with parts against the
    díl I obec — 2005 obce merge 1910 ones, so agreement is a signal and disagreement is not.
    """
    if sid not in popd.index or pd.isna(p.pop_total):
        return None, None, None
    pp = popd.loc[sid]
    parts = int(n_parts.get((p.edition, p.court_key, p.muni_seq), 0))
    if p.place_level == "part" or parts == 0:
        col, level = "dil1_part_pop", "settlement"
    else:
        col, level = "dil1_obec_pop", "obec_2005"
    value = pp[col]
    if pd.isna(value):
        return None, None, None
    return int(value), pop_agrees(p.pop_total, value), level


def find_candidates(places: pd.DataFrame, auth: pd.DataFrame, geo_court: dict, pop: pd.DataFrame,
                    births: pd.Series | None = None, skip_keys: set | None = None) -> pd.DataFrame:
    """One row per unanchored place × candidate settlement in its own okres (or none).

    Columns carry the evidence :func:`decide` reads: ``tier``, ``kind`` (name / word),
    ``n_okres`` and ``n_court`` (candidates at the best tier), ``status``, ``in_court`` (the
    settlement's point in the register's court polygon), ``pop_agrees`` and ``claimed``;
    ``healed_form`` says the matched key exists only through a heal. ``skip_keys``: places a
    ruling settles (searched never, though their anchors count as claims).
    """
    skip_keys = skip_keys or set()
    by_key = auth.groupby("key")
    keyset = set(auth["key"])
    claims = _claims(places)
    popd = pop.set_index("settlement_id") if len(pop) else pd.DataFrame()
    births = births if births is not None else pd.Series(dtype="int64")
    n_parts = places[places["place_level"] == "part"].groupby(["edition", "court_key", "muni_seq"]).size()
    rows = []
    for p in places[places["settlement_id"].isna()].itertuples(index=False):
        if (p.edition, str(p.court_key), int(p.muni_seq), int(p.settlement_seq)) in skip_keys:
            continue
        base = {k: getattr(p, k) for k in KEY + ["place_level", "okres_id", "court_id",
                                                 "printed_name", "pop_total", "anchor_status"]}
        forms = place_forms(p.printed_name)
        base["births"] = int(sum(births.get((int(p.okres_id), k), 0) for k, kind in forms
                                 if kind == "name")) if pd.notna(p.okres_id) else 0
        if _NO_SETTLEMENT_RE.search(str(p.printed_name)):
            rows.append({**base, "reason": "no_settlement_body"})
            continue
        if pd.isna(p.okres_id):
            rows.append({**base, "reason": "no_okres"})
            continue
        hits = []
        for key, kind in forms:
            if key not in keyset:
                continue
            grp = by_key.get_group(key)
            grp = grp[grp["okres_id"] == int(p.okres_id)]
            for c in grp.itertuples(index=False):
                hits.append((c, key, kind))
        if p.place_level == "municipality":
            hits = [h for h in hits if h[0].status == "obec"] or [h for h in hits if pd.isna(h[0].status)]
        if not hits:
            rows.append({**base, "reason": "no_candidate_in_okres"})
            continue
        rank = {(kind, tier): i for i, (kind, tier) in
                enumerate([("name", 1), ("name", 2), ("word", 1), ("word", 2)])}
        best = min(rank[(kind, c.tier)] for c, _, kind in hits)
        best_ids = {c.settlement_id for c, _, kind in hits if rank[(kind, c.tier)] == best}
        in_court_ids = {s for s in best_ids if geo_court.get(s) == int(p.court_id)}
        seen = set()
        # Per settlement its best hit, an unhealed key before a healed one at the same rank.
        for c, key, kind in sorted(hits, key=lambda h: (rank[(h[2], h[0].tier)],
                                                         bool(getattr(h[0], "healed", False)))):
            if c.settlement_id in seen:
                continue
            seen.add(c.settlement_id)
            lex_pop, agree, level = _compare_pop(p, popd, c.settlement_id, n_parts)
            rows.append({**base, "settlement_id": c.settlement_id, "cs_name": c.cs_name,
                         "status_1910": c.status, "form": key, "kind": kind, "tier": c.tier,
                         "healed_form": bool(getattr(c, "healed", False)),
                         "best": rank[(kind, c.tier)] == best, "n_okres": len(best_ids),
                         "n_court": len(in_court_ids),
                         "in_court": geo_court.get(c.settlement_id) == int(p.court_id)
                         if c.settlement_id in geo_court else None,
                         "lexikon_pop": lex_pop, "pop_agrees": agree, "pop_level": level,
                         "claimed": claimed_elsewhere(claims, p.edition, c.settlement_id,
                                                      p.court_key, p.muni_seq, p.place_level),
                         "reason": ""})
    return pd.DataFrame(rows)


def decide(cands: pd.DataFrame) -> pd.DataFrame:
    """``certain`` and ``why_not`` on every candidate row; certain = the rule in the module docstring."""
    out = cands.copy()
    why = []
    for r in out.itertuples(index=False):
        if r.reason:
            why.append(r.reason)
            continue
        reasons = []
        if not r.best:
            reasons.append("lower_tier")
        if r.kind != "name":
            reasons.append("word_match_only")
        unique_okres = r.n_okres == 1
        unique_court = not unique_okres and r.n_court == 1 and r.in_court is True
        if not (unique_okres or unique_court):
            reasons.append(f"not_unique({r.n_okres} in okres, {r.n_court} in court)")
        if r.place_level == "municipality" and r.status_1910 != "obec":
            reasons.append(f"status_{r.status_1910 if isinstance(r.status_1910, str) else 'missing'}")
        if r.claimed:
            reasons.append("settlement_already_anchored")
        if r.pop_agrees is False and r.pop_level == "settlement":
            reasons.append(f"population_disagrees({int(r.pop_total)} vs {int(r.lexikon_pop)})")
        # The court cannot be both what made the candidate unique and the second signal.
        elif not (r.pop_agrees is True or (r.in_court is True and unique_okres)):
            reasons.append("no_second_signal")
        why.append("; ".join(reasons))
    out["why_not"] = why
    out["certain"] = out["why_not"] == ""
    # Two places of one edition and level certain of one settlement: neither is (refused, D-22).
    cert = out[out["certain"]]
    owners = cert.groupby(["edition", "settlement_id"])[["court_key", "muni_seq"]].nunique().max(axis=1)
    levels = cert.groupby(["edition", "settlement_id", "place_level"]).size()
    bad = set(owners[owners > 1].index) | {k[:2] for k, n in levels.items() if n > 1}
    contested = [(e, sid) in bad for e, sid in zip(cert["edition"], cert["settlement_id"])]
    out.loc[cert.index[contested], "why_not"] = "contested_by_another_place"
    # A place certain of two settlements (one per form) is not certain either.
    cert = out[out["certain"] & (out["why_not"] == "")]
    twice = cert.duplicated(KEY, keep=False)
    out.loc[cert.index[twice], "why_not"] = "two_certain_settlements"
    out["certain"] = out["why_not"] == ""
    return out


def _evidence(r) -> tuple[str, str]:
    bits = [f"form '{r.form}' tier {'name' if r.tier == 1 else 'alias'}",
            f"{'unique in okres' if r.n_okres == 1 else 'unique in court'}"]
    if r.pop_agrees is True:
        bits.append(f"pop register {int(r.pop_total)} vs lexicon díl I {r.pop_level} {int(r.lexikon_pop)}")
    if r.in_court is True:
        bits.append("point in register court polygon")
    if r.pop_agrees is False:
        bits.append(f"2005-obec pop differs ({int(r.pop_total)} vs {int(r.lexikon_pop)}), not counted")
    healed = bool(getattr(r, "healed_form", False))
    if healed:
        bits.append("key only through a healed lexicon form")
    rule = ("short_name" if len(r.form) < 3 else "alias_tier" if r.tier == 2
            else "healed_name" if healed else "exact_name")
    return "; ".join(bits), rule


def overrides_frame(decided: pd.DataFrame, heals: pd.DataFrame | None = None) -> pd.DataFrame:
    """The certain rows as ``anchor_overrides.csv`` (``rule`` names which exception carried it).

    ``healed_name`` only when the matched key comes from a healed form (``healed_form``); 1.0.0
    gave it to any settlement that had *some* healed cell, 24 of its 39 wrongly. ``heals`` is
    kept in the signature for callers of 1.0.0 and no longer read.
    """
    cert = decided[decided["certain"]].copy()
    if not len(cert):
        return pd.DataFrame(columns=OVERRIDE_COLUMNS)
    ev = [_evidence(r) for r in cert.itertuples(index=False)]
    cert["evidence"] = [e for e, _ in ev]
    cert["rule"] = [rule for _, rule in ev]
    cert["tier"] = cert["tier"].astype("int64")
    cert["births"] = cert["births"].astype("int64")
    return cert[OVERRIDE_COLUMNS].sort_values(KEY).reset_index(drop=True)

def _blank(value) -> bool:
    return value is None or (not isinstance(value, str) and pd.isna(value)) or str(value).strip() == ""

    return "" if _blank(value) else str(value).strip().casefold()


def is_confirmed(ruled_by) -> bool:
    """Whether a ruling's ``ruled_by`` marks the author's confirmation (``author``)."""
    return _ruled_by(ruled_by) in AUTHOR_RULED_BY


def unconfirmed_rulings(rulings: pd.DataFrame | None = None) -> pd.DataFrame:

def ruling_pages(rulings: pd.DataFrame, places: pd.DataFrame) -> list[set]:
    """The register pages (``pages``: ``0449`` or ``0095;0096``) of each ruling's place, in rulings
    order; an empty set where *places* holds no such place."""

             for e, c, m, s, p in zip(places["edition"], places["court_key"].astype(str), places["muni_seq"],
                                      places["settlement_seq"], places["pages"]) if pd.notna(p)}
    return [pages.get((str(r.edition), str(r.court_key), int(r.muni_seq), int(r.settlement_seq)), set())
            for r in rulings.itertuples(index=False)]


def check_rulings(rulings: pd.DataFrame, places: pd.DataFrame | None = None, sealed=None, *,
                  pages: bool = True) -> None:
    """Raise on a malformed rulings table: a missing column, an unknown action, the ids an action
    needs absent (or present where it needs none), no ``basis`` / ``ruled_by``, a ``ruled_by`` other
    than ``author`` / ``evidence``, a place ruled twice.

    1.3.0: and a ruling whose register page is **sealed** (:func:`sealed_pages`; *sealed* may pass
    another ``edition -> pages`` function): no ruling may rest on a certification or reserve page. The
    pages come from *places* (``pages`` column; skipped when it has none) or, by default, from
    ``data/final/register_rechecked/register_places`` (skipped when it is absent). Gold and
    calibration pages are allowed (the author's own anchor rulings on cz 0449, a gold page, stand).

    1.4.0 — **the contract** (the author's answer A5, 2026-11-16): an anchor ruling may rest on any
    register page the author has seen, gold and calibration pages included; it may not rest on a
    **sealed** page (:func:`sealed_pages`: the certification and reserve scans the frozen route holds
    back). This is narrower than :func:`utils.recheck.savings_bank_census.skipped_pages`, which is
    sealed **plus** ``in_sample_pages`` (gold and calibration): that function draws the savings-bank
    census's error sample, a different use whose frame must avoid every page the route was tuned on —
    an anchor ruling corrects a settlement id and may use any page the author has read. The guard no
    longer passes silently: with *pages* (the default) it raises when ``register_places`` is absent
    (*places* not given), when *places* has no ``pages`` column, and when a ruling's place key has no
    pages there (a ruling that names no register place cannot be checked). ``pages=False`` checks the
    table's form only (a toy frame, a rulings file of another register)."""
    missing = [c for c in RULING_COLUMNS if c not in rulings.columns]
    if missing:
        raise ValueError(f"anchor rulings lack columns {missing}")
    bad = []
    if len(rulings) and pages:
        places = _register_pages() if places is None else places
        if places is None:
            raise ValueError("anchor rulings: cannot check their register pages — "
                             "data/final/register_rechecked/register_places is absent (pages=False checks the "
                             "table's form only)")
        if "pages" not in places.columns:
            raise ValueError("anchor rulings: cannot check their register pages — the places frame has no "
                             "'pages' column (pages=False checks the table's form only)")
        sealed = sealed or sealed_pages
        for r, on in zip(rulings.itertuples(index=False), ruling_pages(rulings, places)):
            where = f"{r.edition}/{r.court_key}/{r.muni_seq}/{r.settlement_seq} {r.printed_name!r}"
            if not on:
                bad.append(f"{where}: no register pages (the place key is not in register_places, or its "
                           "pages are empty): the sealed-page guard cannot check it")
                continue
            hit = sorted(on & set(sealed(str(r.edition))))
            if hit:
                bad.append(f"{where}: on sealed page(s) {hit}")
    for r in rulings.itertuples(index=False):
        where = f"{r.edition}/{r.court_key}/{r.muni_seq}/{r.settlement_seq} {r.printed_name!r}"
        new, old = not _blank(r.settlement_id), not _blank(r.old_settlement_id)
        if r.action not in RULING_ACTIONS:
            bad.append(f"{where}: action {r.action!r}")
        elif r.action == "anchor" and not (new and not old):
            bad.append(f"{where}: 'anchor' needs settlement_id and no old_settlement_id")
        elif r.action == "replace" and not (new and old and str(r.settlement_id) != str(r.old_settlement_id)):
            bad.append(f"{where}: 'replace' needs two different ids")
        elif r.action == "unanchor" and not (old and not new):
            bad.append(f"{where}: 'unanchor' needs old_settlement_id and no settlement_id")
        if _blank(r.basis) or _blank(r.ruled_by):
            bad.append(f"{where}: no basis or ruled_by")
        elif _ruled_by(r.ruled_by) not in RULED_BY_VALUES:
            bad.append(f"{where}: ruled_by {r.ruled_by!r} not one of {sorted(RULED_BY_VALUES)}")
    dup = rulings.duplicated(KEY, keep=False)
    if dup.any():
        bad.append(f"places ruled twice: {rulings.loc[dup, KEY].values.tolist()[:5]}")
    if bad:
        raise ValueError("malformed anchor rulings:\n  " + "\n  ".join(bad))


def load_rulings(path: Path = RULINGS, pages: bool = True) -> pd.DataFrame:
    """The hand-kept rulings (``anchor_rulings.csv``), checked; an empty frame if there is none. 1.4.0:
    *pages* is :func:`check_rulings`'s (``False`` for a table whose places are not the register's)."""
    if not Path(path).exists():
        return pd.DataFrame(columns=RULING_COLUMNS)
    r = pd.read_csv(path, dtype={c: str for c in ("edition", "court_key", "printed_name", "action",
                                                  "old_settlement_id", "settlement_id", "basis",
                                                  "ruled_by", "place_level")},
                    keep_default_na=False, na_values=[""], encoding="utf-8")
    check_rulings(r, pages=pages)
    return r


def _keyed(frame: pd.DataFrame) -> pd.DataFrame:
    f = frame.copy()
    f["court_key"] = f["court_key"].astype(str)
    f["muni_seq"] = f["muni_seq"].astype("int64")
    f["settlement_seq"] = f["settlement_seq"].astype("int64")
    return f


def ruling_keys(rulings: pd.DataFrame) -> set[tuple]:
    if rulings is None or not len(rulings):
        return set()
    r = _keyed(rulings)
    return set(zip(r["edition"], r["court_key"], r["muni_seq"], r["settlement_seq"]))


def _ruling_verdict(r, frozen) -> str:
    """'' if a ruling may apply to a place whose frozen anchor is ``frozen``, else why not."""
    cur = None if pd.isna(frozen) else str(frozen)
    if r.action == "anchor" and cur is not None:
        return f"already_anchored({cur})"
    if r.action in ("replace", "unanchor") and cur != str(r.old_settlement_id):
        return f"anchor_is_{cur}_not_{r.old_settlement_id}"
    return ""


def _sort_rulings(rulings: pd.DataFrame, include_unconfirmed: bool, pos: dict, names: list,
                  frozen: pd.Series) -> tuple[list, list, list]:
    """``(to_apply, refused, unconfirmed)`` — each ruling's verdict against the input anchor.

    Refused (stale name, stale anchor, no such place) whatever its confirmation, so a stale evidence
    ruling is reported even when it would not have applied; otherwise an unconfirmed ruling waits
    unless ``include_unconfirmed``. ``to_apply`` holds ``(row position, ruling)``."""
    to_apply, refused, unconfirmed = [], [], []
    for r in (_keyed(rulings).itertuples(index=False) if len(rulings) else ()):
        k = (r.edition, r.court_key, r.muni_seq, r.settlement_seq)
        i = pos.get(k)
        why = ("no_such_place" if i is None else
               "printed_name_changed" if names[i] != str(r.printed_name) else
               _ruling_verdict(r, frozen.iat[i]))
        entry = {"edition": k[0], "court_key": k[1], "muni_seq": k[2], "settlement_seq": k[3],
                 "printed_name": r.printed_name, "action": r.action,
                 "old_settlement_id": None if _blank(r.old_settlement_id) else str(r.old_settlement_id),
                 "settlement_id": None if _blank(r.settlement_id) else str(r.settlement_id),
                 "ruled_by": r.ruled_by}
        if why:
            refused.append({**entry, "refused": why})
        elif not (include_unconfirmed or is_confirmed(r.ruled_by)):
            unconfirmed.append({**entry, "refused": "unconfirmed"})
        else:
            to_apply.append((i, r))
    return to_apply, refused, unconfirmed


def apply(places: pd.DataFrame, overrides: pd.DataFrame | None = None,
          rulings: pd.DataFrame | None = None, include_unconfirmed: bool = False) -> pd.DataFrame:
    """``places`` with the generated overrides and the rulings applied; a new frame, inputs untouched.

    *Generated* (``overrides``, default ``anchor_overrides.csv``): fills only an empty anchor of a place
    printing the name it was found on; ``anchor_status = "override"``. *Rulings* (``rulings``, default
    ``anchor_rulings.csv``): ``anchor`` / ``replace`` / ``unanchor`` (module docstring). By default only
    the rulings the author confirmed (``ruled_by = "author"``) apply; ``include_unconfirmed=True`` adds
    the ``evidence`` ones. An *applied* ruling wins over a generated row for its place; a refused or
    unconfirmed one leaves the place to its generated row. The precondition is checked against the
    input anchor, so rulings do not depend on their order. ``anchor_override_rule`` names the rule or
    ``ruling_<action>``; ``anchor_replaced_from`` keeps the frozen id a ruling removed;
    ``anchor_ruled_by`` the applied ruling's ``ruled_by``. ``attrs``: ``anchor_rulings_refused`` (stale
    name, stale anchor, no such place — all but ``no_such_place`` also warn),
    ``anchor_rulings_unconfirmed`` (valid, not applied for want of confirmation),
    ``anchor_rulings_applied`` (the keys applied) and ``anchor_include_unconfirmed``. Raises if the
    result anchors two municipalities of one edition to one settlement.
    """
    overrides = load_overrides() if overrides is None else overrides
    rulings = load_rulings() if rulings is None else rulings
    if len(rulings):
        # 1.4.0: the pages are checked where the frame carries them (the register); a page-less frame
        # (a test's toy places) is checked for form only — load_rulings() checks the register's pages
        check_rulings(rulings, places=places, pages="pages" in places.columns)
    out = places.copy()
    for col in ("anchor_override_rule", "anchor_replaced_from", "anchor_ruled_by"):
        if col not in out.columns:
            out[col] = pd.Series(pd.NA, index=out.index, dtype="string")
    pos = {tuple(k): i for i, k in enumerate(zip(out["edition"], out["court_key"].astype(str),
                                                 out["muni_seq"].astype("int64"),
                                                 out["settlement_seq"].astype("int64")))}
    frozen = out["settlement_id"].astype("string")
    sid = frozen.copy()
    status = out["anchor_status"].astype(object).copy()
    rule = out["anchor_override_rule"].astype("string").copy()
    replaced = out["anchor_replaced_from"].astype("string").copy()
    ruled_by = out["anchor_ruled_by"].astype("string").copy()
    names = out["printed_name"].astype(str).tolist()
    to_apply, refused, unconfirmed = _sort_rulings(rulings, include_unconfirmed, pos, names, frozen)
    # Only an applied ruling settles its place (1.2.0): the others leave it to its generated row.
    ruled = {(r.edition, r.court_key, r.muni_seq, r.settlement_seq) for _, r in to_apply}

    if len(overrides):
        o = _keyed(overrides[KEY + ["printed_name", "settlement_id", "rule"]])
        for r in o.itertuples(index=False):
            k = (r.edition, r.court_key, r.muni_seq, r.settlement_seq)
            i = pos.get(k)
            if i is None or k in ruled or pd.notna(sid.iat[i]) or names[i] != str(r.printed_name):
                continue
            sid.iat[i] = r.settlement_id
            status.iat[i] = "override"
            rule.iat[i] = r.rule

    for i, r in to_apply:
        sid.iat[i] = pd.NA if r.action == "unanchor" else r.settlement_id
        status.iat[i] = RULED_STATUS[r.action]
        rule.iat[i] = f"ruling_{r.action}"
        ruled_by.iat[i] = _ruled_by(r.ruled_by)
        if r.action != "anchor":
            replaced.iat[i] = r.old_settlement_id
    stale = [x for x in refused if x["refused"] != "no_such_place"]
    if stale:
        warnings.warn(f"{len(stale)} anchor ruling(s) refused: {stale[:5]}", stacklevel=2)

    out["settlement_id"] = sid
    out["anchor_status"] = status
    out["anchor_override_rule"] = rule
    out["anchor_replaced_from"] = replaced
    out["anchor_ruled_by"] = ruled_by
    out.attrs["anchor_rulings_refused"] = refused
    out.attrs["anchor_rulings_unconfirmed"] = unconfirmed
    out.attrs["anchor_rulings_applied"] = sorted(ruled)
    out.attrs["anchor_include_unconfirmed"] = bool(include_unconfirmed)
    munis = out[(out["place_level"] == "municipality") & out["settlement_id"].notna()]
    dup = munis.duplicated(["edition", "settlement_id"], keep=False)
    if dup.any():
        raise ValueError("overrides/rulings anchor two municipalities to one settlement: "
                         f"{munis.loc[dup, ['edition', 'printed_name', 'settlement_id']].values.tolist()[:5]}")
    return out


# ── validation ────────────────────────────────────────────────────────────────
def _rate(mask: pd.Series) -> dict:
    n = int(mask.notna().sum())
    k = int(mask.fillna(False).astype(bool).sum())
    return {"n": n, "agree": k, "rate": round(k / n, 4) if n else None}


def geometry_check(places: pd.DataFrame, geo: pd.DataFrame, courts: Courts) -> tuple[dict, pd.DataFrame]:
    """(a): the anchored settlement's point vs the register's court, plain containment."""
    pts = geo[["settlement_id", "lat", "lon", "wd_lat", "wd_lon", "coord_source", "match_scope"]].copy()
    has = pts["lat"].notna()
    pts["point_court"] = 0
    pts.loc[has, "point_court"] = courts.locate(pts.loc[has, "lon"], pts.loc[has, "lat"])
    has_wd = pts["wd_lat"].notna()
    pts["wd_court"] = 0
    pts.loc[has_wd, "wd_court"] = courts.locate(pts.loc[has_wd, "wd_lon"], pts.loc[has_wd, "wd_lat"])
    a = places[places["anchor_status"].isin(ANCHORED) & places["settlement_id"].notna()].copy()
    a["settlement_id"] = a["settlement_id"].astype(str)
    a = a.merge(pts, on="settlement_id", how="left", validate="m:1")
    a = a[a["court_id"].notna()]
    a["court_id"] = a["court_id"].astype("int64")
    a["has_point"] = a["point_court"].fillna(0) > 0
    a["court_agrees"] = np.where(a["has_point"], a["point_court"] == a["court_id"], np.nan)
    a["okres_agrees"] = np.where(a["has_point"], a["point_court"] // 1000 == a["court_id"] // 1000, np.nan)
    a["wd_court_agrees"] = np.where(a["wd_court"].fillna(0) > 0, a["wd_court"] == a["court_id"], np.nan)
    a["court_agrees"] = a["court_agrees"].astype("float").map(lambda v: pd.NA if pd.isna(v) else bool(v))
    a["okres_agrees"] = a["okres_agrees"].astype("float").map(lambda v: pd.NA if pd.isna(v) else bool(v))
    a["wd_court_agrees"] = a["wd_court_agrees"].astype("float").map(lambda v: pd.NA if pd.isna(v) else bool(v))

    def table(frame, by):
        return {str(k): {"court": _rate(g["court_agrees"]), "okres": _rate(g["okres_agrees"]),
                         "wikidata_court": _rate(g["wd_court_agrees"])}
                for k, g in frame.groupby(by)}

    indep = a[a["anchor_status"] != "matched_court"]
    bad = indep[indep["court_agrees"] == False].copy()                                   # noqa: E712
    bad["dist_m"] = [courts.distance_m(int(c), lo, la) if c in courts.courts else np.nan
                     for c, lo, la in zip(bad["court_id"], bad["lon"], bad["lat"])]
    near = bad["dist_m"] <= 1000
    result = {
        "anchored_places": int(len(a)), "with_point": int(a["has_point"].sum()),
        "overall_excluding_matched_court": {"court": _rate(indep["court_agrees"]),
                                            "okres": _rate(indep["okres_agrees"]),
                                            "wikidata_court": _rate(indep["wd_court_agrees"])},
        "by_edition": table(indep, "edition"),
        "by_anchor_status": table(a, "anchor_status"),
        "by_coord_source": table(indep, "coord_source"),
        "by_match_scope": table(indep, "match_scope"),
        "court_disagreements": int(len(bad)),
        "court_disagreements_within_1km": int(near.sum()),
        "court_disagreements_over_5km": int((bad["dist_m"] > 5000).sum()),
        "court_disagreements_over_20km": int((bad["dist_m"] > 20000).sum()),
        "note": ("matched_court used the spatial court as its tie-break, so it is circular for this "
                 "check and excluded from the overall rates; RÚIAN points were searched inside the "
                 "1910 okres (okres containment partly built in), the Wikidata point is independent."),
    }
    worst = bad.sort_values("dist_m", ascending=False)
    cols = KEY + ["printed_name", "court_cs", "settlement_id", "anchor_status", "coord_source",
                  "point_court", "dist_m"]
    result["worst"] = worst[cols].head(25).assign(dist_m=lambda f: f["dist_m"].round(0)).astype(str).to_dict("records")
    return result, worst[cols]


def population_check(places: pd.DataFrame, pop: pd.DataFrame,
                     auth: pd.DataFrame | None = None) -> tuple[dict, pd.DataFrame]:
    """(b): register 1910 population vs the ČSÚ lexicon díl I (2005 territory), per anchored place.

    A part is compared with its díl I part; a municipality printed without parts with its díl I
    part (or obec, where the 2005 obec has no parts). A municipality *with* parts is compared with
    the díl I obec only as a loose, separately reported check — 2005 obce merge 1910 ones.
    """
    a = places[places["anchor_status"].isin(ANCHORED) & places["settlement_id"].notna()
               & places["pop_total"].notna()].copy()
    a["settlement_id"] = a["settlement_id"].astype(str)
    n_parts = (places[places["place_level"] == "part"]
               .groupby(["edition", "court_key", "muni_seq"]).size())
    a["n_parts"] = [int(n_parts.get((e, c, m), 0)) for e, c, m in
                    zip(a["edition"], a["court_key"], a["muni_seq"])]
    a = a.merge(pop, on="settlement_id", how="left", validate="m:1")
    single = (a["place_level"] == "part") | (a["n_parts"] == 0)
    a["lexikon_pop"] = np.where(single, a["dil1_part_pop"], a["dil1_obec_pop"])
    a["compared_as"] = np.where(single, "settlement", "municipality_vs_2005_obec")
    a = a[a["lexikon_pop"].notna()].copy()
    a["lexikon_pop"] = a["lexikon_pop"].astype("int64")
    a["pop_total"] = a["pop_total"].astype("int64")
    a["ratio"] = a["pop_total"] / a["lexikon_pop"].replace(0, np.nan)
    a["agree10"] = [pop_agrees(x, y) for x, y in zip(a["pop_total"], a["lexikon_pop"])]
    a["agree25"] = [pop_agrees(x, y, tol=0.25) for x, y in zip(a["pop_total"], a["lexikon_pop"])]
    a["exact"] = a["pop_total"] == a["lexikon_pop"]

    def summary(frame):
        return {"n": int(len(frame)), "exact": int(frame["exact"].sum()),
                "within_10pct": int(frame["agree10"].sum()), "within_25pct": int(frame["agree25"].sum()),
                "rate_10pct": round(float(frame["agree10"].mean()), 4) if len(frame) else None,
                "median_ratio": round(float(frame["ratio"].median()), 4) if len(frame) else None}

    res = {"anchored_with_register_pop": int((places["anchor_status"].isin(ANCHORED)
                                              & places["pop_total"].notna()).sum()),
           "reached_dil1": int(len(a)),
           "settlement_level": summary(a[a["compared_as"] == "settlement"]),
           "municipality_vs_2005_obec": summary(a[a["compared_as"] != "settlement"]),
           "by_edition": {e: summary(g[g["compared_as"] == "settlement"]) for e, g in a.groupby("edition")},
           "by_anchor_status": {s: summary(g[g["compared_as"] == "settlement"])
                                for s, g in a.groupby("anchor_status")},
           "source": ("ČSÚ Historický lexikon obcí ČR 1869–2005, díl I (library/lexicons/), 1910 column, "
                      "read by utils.validation.lexikon_population over all 77 okresy; figures are "
                      "recomputed onto 2005 territory, so a disagreement can be a boundary change, "
                      "not a wrong anchor. settlements_1910 itself carries no population."),
           }
    s = a[a["compared_as"] == "settlement"].copy()
    s["log_gap"] = np.abs(np.log((s["pop_total"] + 1) / (s["lexikon_pop"] + 1)))
    s["better_candidate"] = ""
    if auth is not None:
        s["better_candidate"] = _better_candidates(s, auth, pop)
    worst = s.sort_values(["log_gap", "pop_total"], ascending=False)
    cols = KEY + ["place_level", "printed_name", "settlement_id", "anchor_status", "pop_total",
                  "lexikon_pop", "better_candidate"]
    disagree = s[~s["agree10"].astype(bool)]
    res["disagreeing_with_better_candidate"] = int((disagree["better_candidate"] != "").sum())
    res["better_candidate_note"] = ("a disagreeing place whose printed name also names another "
                                    "settlement of its okres whose díl I population agrees: a likely "
                                    "wrong anchor (Osek -> the castle HRAD OSEK, not the town)")
    res["worst"] = worst[worst["pop_total"] >= 200][cols].head(25).astype(str).to_dict("records")
    res["worst_with_better_candidate"] = (worst[worst["better_candidate"] != ""][cols].head(25)
                                          .astype(str).to_dict("records"))
    return res, worst[cols + ["log_gap"]]


def _better_candidates(rows: pd.DataFrame, auth: pd.DataFrame, pop: pd.DataFrame) -> list[str]:
    """Per disagreeing row: other settlements of its okres its printed name names whose díl I
    settlement population agrees with the register's (``"|"``-joined; ``""`` if none)."""
    part_pop = dict(zip(pop["settlement_id"], pop["dil1_part_pop"]))
    by = auth[auth["tier"] == 1].groupby(["okres_id", "key"])["settlement_id"].apply(set).to_dict()
    out = []
    for r in rows.itertuples(index=False):
        if r.agree10 or pd.isna(r.okres_id):
            out.append("")
            continue
        sids = set()
        for k, kind in place_forms(r.printed_name):
            if kind == "name":
                sids |= by.get((int(r.okres_id), k), set())
        better = sorted(x for x in sids - {r.settlement_id} if pop_agrees(r.pop_total, part_pop.get(x)))
        out.append("|".join(better))
    return out


def boundary_check(places: pd.DataFrame, auth: pd.DataFrame, adjacency: dict) -> tuple[dict, pd.DataFrame]:
    """(c): every unanchored name in **all** okresy — own / adjacent only / elsewhere / nowhere."""
    by_key = auth.groupby("key")
    keyset = set(auth["key"])
    rows = []
    for p in places[places["settlement_id"].isna()].itertuples(index=False):
        forms = [k for k, kind in place_forms(p.printed_name) if kind == "name"]
        okresy, sids = set(), set()
        for k in forms:
            if k in keyset:
                g = by_key.get_group(k)
                if p.place_level == "municipality":
                    g = g[(g["status"] == "obec") | g["status"].isna()]
                okresy |= {int(o) for o in g["okres_id"].dropna()}
                sids |= set(g["settlement_id"])
        own = int(p.okres_id) if pd.notna(p.okres_id) else None
        neigh = adjacency.get(own, set()) if own is not None else set()
        if not okresy:
            where = "nowhere"
        elif own in okresy:
            where = "own_okres"
        elif okresy & neigh:
            where = "adjacent_only" if okresy <= neigh else "adjacent_and_further"
        else:
            where = "further_only"
        rows.append({**{k: getattr(p, k) for k in KEY}, "place_level": p.place_level,
                     "printed_name": p.printed_name, "okres_id": own, "pop_total": p.pop_total,
                     "anchor_status": p.anchor_status, "found_in": where,
                     "found_okresy": "|".join(map(str, sorted(okresy))),
                     "adjacent_okresy": "|".join(map(str, sorted(okresy & neigh))),
                     "settlement_ids": "|".join(sorted(sids)[:6])})
    f = pd.DataFrame(rows)
    counts = f["found_in"].value_counts().to_dict()
    res = {"unanchored_places": int(len(f)),
           "found_in": {k: int(v) for k, v in counts.items()},
           "rates": {k: round(v / len(f), 4) for k, v in counts.items()} if len(f) else {},
           "by_edition": {e: {k: int(v) for k, v in g["found_in"].value_counts().items()}
                          for e, g in f.groupby("edition")},
           "adjacency": f"MPIDR outlines within {ADJACENT_M:.0f} m",
           "worst_adjacent_only": f[f["found_in"] == "adjacent_only"]
           .sort_values("pop_total", ascending=False).head(25).astype(str).to_dict("records")}
    return res, f


@lru_cache(maxsize=None)
def _name_keys_cached(cell: str) -> frozenset:
    return frozenset(k for k, kind in place_forms(cell) if kind == "name")


def _name_keys(cell) -> frozenset:
    return _name_keys_cached("" if cell is None or (not isinstance(cell, str) and pd.isna(cell)) else str(cell))


def _same_place(a, b) -> bool:
    """Two register rows print the same place: a shared name form, and equal populations where both
    print one."""
    if not (_name_keys(a.printed_name) & _name_keys(b.printed_name)):
        return False
    return pd.isna(a.pop_total) or pd.isna(b.pop_total) or int(a.pop_total) == int(b.pop_total)


def twin_pairs(places: pd.DataFrame, de: str = "de-bohemia", cz: str = "cz") -> pd.DataFrame:
    """Every ``de`` row with its ``cz`` twin: ``pair_source`` = ``link`` (the register's own
    ``cz_muni_seq``/``cz_settlement_seq``, accepted only if :func:`_same_place`), ``name_pop`` (the one
    ``cz`` row of the same court and level that is the same place, where the link is absent or
    fails), or ``none``. ``link_failed`` marks a link the test refused."""
    c = places[places["edition"] == cz]
    c_idx = {(str(k), int(m), int(s)): r for k, m, s, r in
             zip(c["court_key"], c["muni_seq"], c["settlement_seq"], c.itertuples(index=False))}
    by_court = {k: list(g.itertuples(index=False)) for k, g in c.groupby(["court_key", "place_level"])}
    rows = []
    for d in places[places["edition"] == de].itertuples(index=False):
        twin, source, failed = None, "none", False
        if pd.notna(getattr(d, "cz_muni_seq", pd.NA)) and pd.notna(getattr(d, "cz_settlement_seq", pd.NA)):
            linked = c_idx.get((str(d.court_key), int(d.cz_muni_seq), int(d.cz_settlement_seq)))
            if linked is not None and _same_place(d, linked):
                twin, source = linked, "link"
            else:
                failed = True
        if twin is None:
            same = [r for r in by_court.get((d.court_key, d.place_level), []) if _same_place(d, r)]
            if len(same) == 1:
                twin, source = same[0], "name_pop"
        rows.append({"court_key": d.court_key, "place_level": d.place_level,
                     "de_muni_seq": d.muni_seq, "de_settlement_seq": d.settlement_seq,
                     "de_printed_name": d.printed_name, "de_pop": d.pop_total,
                     "de_settlement_id": d.settlement_id, "de_anchor_status": d.anchor_status,
                     "link_failed": failed, "pair_source": source,
                     "cz_muni_seq": twin.muni_seq if twin is not None else pd.NA,
                     "cz_settlement_seq": twin.settlement_seq if twin is not None else pd.NA,
                     "cz_printed_name": twin.printed_name if twin is not None else pd.NA,
                     "cz_pop": twin.pop_total if twin is not None else pd.NA,
                     "cz_settlement_id": twin.settlement_id if twin is not None else pd.NA,
                     "cz_anchor_status": twin.anchor_status if twin is not None else pd.NA})
    return pd.DataFrame(rows)


def twin_consistency(places: pd.DataFrame) -> tuple[dict, pd.DataFrame]:
    """(d): the ``cz`` and ``de-bohemia`` anchors of one place must agree.

    ``verdict`` per pair: ``agree``, ``conflict`` (two different settlements), ``one_sided`` (one
    edition anchored), ``neither``, ``unpaired`` (no twin found)."""
    f = twin_pairs(places)
    if not len(f):
        return {"pairs": 0}, f
    de_sid, cz_sid = f["de_settlement_id"].astype("string"), f["cz_settlement_id"].astype("string")
    conds = [f["pair_source"] == "none", de_sid.isna() & cz_sid.isna(), de_sid.isna() | cz_sid.isna(),
             de_sid == cz_sid]
    f["verdict"] = np.select([pd.Series(c).fillna(False).to_numpy(bool) for c in conds],
                             ["unpaired", "neither", "one_sided", "agree"], default="conflict")
    paired = f[f["pair_source"] != "none"]
    cols = ["court_key", "place_level", "de_muni_seq", "de_settlement_seq", "de_printed_name", "de_pop",
            "de_settlement_id", "cz_muni_seq", "cz_settlement_seq", "cz_printed_name", "cz_pop",
            "cz_settlement_id", "pair_source"]
    res = {"de_rows": int(len(f)), "pairs": int(len(paired)),
           "by_source": {k: int(v) for k, v in f["pair_source"].value_counts().items()},
           "links_failed": int(f["link_failed"].sum()),
           "links_failed_repaired": int((f["link_failed"] & (f["pair_source"] == "name_pop")).sum()),
           "verdicts": {k: int(v) for k, v in f["verdict"].value_counts().items()},
           "conflicts": f[f["verdict"] == "conflict"][cols].astype(str).to_dict("records"),
           "failed_links": f[f["link_failed"]][cols + ["verdict"]].head(40).astype(str).to_dict("records"),
           "note": ("a register link is trusted only when the two rows share a printed name form and "
                    "a population; otherwise the one cz row of the same court and level that does")}
    return res, f


def owner_changes(before: pd.DataFrame, after: pd.DataFrame) -> tuple[dict, pd.DataFrame]:
    """Which ``register_municipalities`` rows would change if ``after`` replaced ``before``.

    The owner is the frozen :func:`lexikon_1910_register.municipality_owner` (read, not edited): per
    settlement the register municipality (edition, court, muni) it is built from. ``changed``: the
    settlement keeps a row but another municipality owns it; ``added`` / ``dropped``: it gains /
    loses its row."""
    from utils.lexikon_1910.lexikon_1910_register import municipality_owner
    cols = ["edition", "court_key", "muni_seq", "printed_name", "pop_total"]
    b = municipality_owner(before)[cols].add_prefix("before_")
    a = municipality_owner(after)[cols].add_prefix("after_")
    j = b.join(a, how="outer")
    has_b, has_a = j["before_edition"].notna(), j["after_edition"].notna()
    same = ((j["before_edition"] == j["after_edition"]) & (j["before_court_key"] == j["after_court_key"])
            & (j["before_muni_seq"] == j["after_muni_seq"]))
    same = pd.Series(same).fillna(False).to_numpy(bool)
    has_b, has_a = has_b.to_numpy(bool), has_a.to_numpy(bool)
    j["change"] = np.select([has_b & ~has_a, ~has_b & has_a, has_b & has_a & ~same],
                            ["dropped", "added", "changed"], default="same")
    j = j.reset_index().rename(columns={"index": "settlement_id"})
    counts = j["change"].value_counts().to_dict()
    res = {"rows_before": int(has_b.sum()), "rows_after": int(has_a.sum()),
           "note": "owner = lexikon_1910_register.municipality_owner (cz first), as register_municipalities",
           **{k: int(counts.get(k, 0)) for k in ("changed", "added", "dropped", "same")}}
    return res, j[j["change"] != "same"]


def _write_csv(frame: pd.DataFrame, path: Path) -> None:
    """Every csv this module writes: UTF-8, LF line ends (``to_csv`` defaults to ``os.linesep``)."""
    frame.to_csv(path, index=False, encoding="utf-8", lineterminator="\n")


def _write_json(obj, path: Path) -> None:
    Path(path).write_text(json.dumps(obj, indent=2, ensure_ascii=False, default=str),
                          encoding="utf-8", newline="\n")


def _place_key(edition, court_key, muni_seq, settlement_seq) -> tuple:
    return (str(edition), str(court_key), int(muni_seq), int(settlement_seq))


def _mark_rulings(frame: pd.DataFrame, rulings: pd.DataFrame, applied_keys: set) -> pd.DataFrame:
    """``frame`` with ``ruling`` (action), ``ruling_ruled_by`` and ``ruling_applied`` per row a
    ruling names (``""`` / ``""`` / ``<NA>`` elsewhere)."""
    r = _keyed(rulings)
    by_key = {_place_key(e, c, m, s): (a, _ruled_by(b)) for e, c, m, s, a, b in
              zip(r["edition"], r["court_key"], r["muni_seq"], r["settlement_seq"], r["action"],
                  r["ruled_by"])}
    keys = [_place_key(e, c, m, s) for e, c, m, s in
            zip(frame["edition"], frame["court_key"], frame["muni_seq"], frame["settlement_seq"])]
    out = frame.copy()
    out["ruling"] = [by_key.get(k, ("", ""))[0] for k in keys]
    out["ruling_ruled_by"] = [by_key.get(k, ("", ""))[1] for k in keys]
    out["ruling_applied"] = pd.array([(k in applied_keys) if k in by_key else pd.NA for k in keys],
                                     dtype="boolean")
    return out


def validate_anchoring(places: pd.DataFrame, geo: pd.DataFrame, pop: pd.DataFrame,
                       auth: pd.DataFrame, courts: Courts, out_dir: Path = OUT,
                       applied: pd.DataFrame | None = None,
                       rulings: pd.DataFrame | None = None,
                       applied_all: pd.DataFrame | None = None) -> dict:
    """Run (a), (b), (c) on the frozen anchoring and (d) on it, on ``applied`` (overrides + confirmed
    rulings) and on ``applied_all`` (+ the unconfirmed ones); write ``anchor_validation.json`` plus the
    worst-case CSVs. The population CSV marks the rows a ruling names (``ruling``, ``ruling_ruled_by``,
    ``ruling_applied`` — applied in ``applied``, i.e. by default)."""
    out_dir = Path(out_dir)
    out_dir.mkdir(parents=True, exist_ok=True)
    geom, geom_bad = geometry_check(places, geo, courts)
    popu, pop_bad = population_check(places, pop, auth)
    bound, bound_rows = boundary_check(places, auth, courts.okres_adjacency())
    twins, twin_rows = twin_consistency(places)
    result = {"version": __version__, "geometry": geom, "population": popu, "boundaries": bound,
              "twins": {"frozen": twins}}
    if applied is not None:
        twins_applied, twin_rows = twin_consistency(applied)
        result["twins"]["applied"] = twins_applied
    if applied_all is not None:
        result["twins"]["applied_with_unconfirmed"], _ = twin_consistency(applied_all)
    if rulings is not None and len(rulings):
        applied_keys = set(applied.attrs.get("anchor_rulings_applied", [])) if applied is not None else set()
        pop_bad = _mark_rulings(pop_bad, rulings, applied_keys)
    _write_json(result, out_dir / "anchor_validation.json")
    _write_csv(geom_bad, out_dir / "anchor_validation_court_disagreements.csv")
    _write_csv(pop_bad, out_dir / "anchor_validation_population.csv")
    _write_csv(bound_rows, out_dir / "anchor_validation_unanchored_search.csv")
    _write_csv(twin_rows[twin_rows["verdict"].isin(["conflict", "one_sided"]) | twin_rows["link_failed"]],
               out_dir / "anchor_validation_twins.csv")
    return result


def rulings_not_applied(applied: pd.DataFrame, overrides: pd.DataFrame) -> pd.DataFrame:
    """Every ruling :func:`apply` left out of ``applied``: ``reason`` ``ruling_refused`` (stale; the
    detail in ``refused``) or ``ruling_unconfirmed``, with the place's current anchor in ``applied``
    and the generated row it got instead, if any (``generated_settlement_id``,
    ``generated_agrees`` = the same settlement the ruling names)."""
    rows = ([{**x, "reason": NOT_APPLIED_REFUSED} for x in applied.attrs.get("anchor_rulings_refused", [])]
            + [{**x, "reason": NOT_APPLIED_UNCONFIRMED}
               for x in applied.attrs.get("anchor_rulings_unconfirmed", [])])
    cols = KEY + ["printed_name", "action", "old_settlement_id", "settlement_id", "ruled_by", "reason",
                  "refused", "anchor_now", "anchor_status_now", "generated_settlement_id",
                  "generated_agrees"]
    if not rows:
        return pd.DataFrame(columns=cols)
    gen = {}
    if len(overrides):
        gen = {_place_key(e, c, m, s): sid for e, c, m, s, sid in
               zip(overrides["edition"], overrides["court_key"], overrides["muni_seq"],
                   overrides["settlement_seq"], overrides["settlement_id"])}
    now = {_place_key(e, c, m, s): (sid, st) for e, c, m, s, sid, st in
           zip(applied["edition"], applied["court_key"], applied["muni_seq"], applied["settlement_seq"],
               applied["settlement_id"], applied["anchor_status"])}
    for x in rows:
        k = _place_key(x["edition"], x["court_key"], x["muni_seq"], x["settlement_seq"])
        sid, st = now.get(k, (pd.NA, pd.NA))
        x["anchor_now"], x["anchor_status_now"] = sid, st
        g = gen.get(k)
        x["generated_settlement_id"] = g
        x["generated_agrees"] = None if g is None else (str(g) == str(x.get("settlement_id")))
    return pd.DataFrame(rows).reindex(columns=cols)


def _unanchored(frame: pd.DataFrame) -> dict:
    u = frame[frame["settlement_id"].isna()]
    return {"rows": int(len(u)), "municipalities": int((u["place_level"] == "municipality").sum()),
            "by_edition": {e: {"rows": int(len(g)),
                               "municipalities": int((g["place_level"] == "municipality").sum())}
                           for e, g in u.groupby("edition")}}


def rulings_summary(rulings: pd.DataFrame) -> dict:
    """Counts by action × confirmation (``confirmed`` = ``ruled_by`` ``author``)."""
    if not len(rulings):
        return {"rulings": 0, "confirmed": 0, "unconfirmed": 0, "by_action": {}}
    conf = rulings["ruled_by"].map(is_confirmed).astype(bool)
    by = {a: {"confirmed": int((conf & (rulings["action"] == a)).sum()),
              "unconfirmed": int((~conf & (rulings["action"] == a)).sum())}
          for a in RULING_ACTIONS if (rulings["action"] == a).any()}
    return {"rulings": int(len(rulings)), "confirmed": int(conf.sum()),
            "unconfirmed": int((~conf).sum()), "by_action": by}

def load_inputs(final_dir: Path = FINAL) -> dict:
    final_dir = Path(final_dir)
    return {"places": pd.read_parquet(final_dir / "register_rechecked" / "register_places.parquet"),
            "settlements": pd.read_parquet(final_dir / "geo" / "settlements_1910.parquet"),
            "geo": pd.read_parquet(final_dir / "geo" / "settlements_1910_geo.parquet"),
            "aliases": pd.read_csv(final_dir / "geo" / "settlement_aliases_1910.csv")}


def _applied_both_ways(places, overrides, rulings) -> tuple[pd.DataFrame, pd.DataFrame | None, str | None]:
    """``(default, with_unconfirmed, error)``: the second is None, with the error, when the
    unconfirmed rulings collide with a generated row (two municipalities on one settlement)."""
    applied = apply(places, overrides, rulings)
    try:
        return applied, apply(places, overrides, rulings, include_unconfirmed=True), None
    except ValueError as err:
        return applied, None, str(err)


def build(final_dir: Path = FINAL, out_dir: Path = OUT, overrides_path: Path | None = OVERRIDES,
          rulings_path: Path = RULINGS) -> dict:
    """Heal, search, decide, validate; write the overrides (reference), candidates and validation.

    The rulings (``rulings_path``) are read, never written. The search runs on the places with the
    **confirmed** rulings applied — their anchors count as claims, the places they settle are not
    searched — so a generated row can neither repeat nor contradict an applied ruling. A refused or
    unconfirmed ruling settles nothing: its place is searched like any other, and
    ``anchor_rulings_not_applied.csv`` lists it with the generated row it got, if any. Both modes of
    :func:`apply` are measured (``include_unconfirmed`` False / True).
    """
    inp = load_inputs(final_dir)
    places, settlements, geo = inp["places"], inp["settlements"], inp["geo"]
    out_dir = Path(out_dir)
    out_dir.mkdir(parents=True, exist_ok=True)
    rulings = load_rulings(rulings_path)
    ruled = apply(places, pd.DataFrame(columns=OVERRIDE_COLUMNS), rulings)
    skip = set(ruled.attrs["anchor_rulings_applied"])

    official = pn.official_names(Path(final_dir) / "geo")
    heals = pn.heal_frame(settlements, official, pn.register_names(places))
    unhealed = pn.unhealed_splits(settlements, heals)
    _write_csv(heals, out_dir / "healed_names.csv")
    _write_csv(unhealed, out_dir / "healed_names_left_alone.csv")
    _write_csv(pn.name_index(settlements, heals), out_dir / "healed_name_index.csv")
    heal_summary = pn.heal_report(heals, unhealed)

    auth = authority(settlements, heals, inp["aliases"])
    courts = Courts()
    has = geo["lat"].notna()
    located = courts.locate(geo.loc[has, "lon"], geo.loc[has, "lat"])
    geo_court = {s: int(c) for s, c in zip(geo.loc[has, "settlement_id"], located) if c}
    pop = settlement_population(geo, read_dil1())
    births = birth_keys(final_dir)

    decided = decide(find_candidates(ruled, auth, geo_court, pop, births, skip_keys=skip))
    overrides = overrides_frame(decided)
    if overrides_path is not None:
        _write_csv(overrides, overrides_path)
    generated_only = apply(places, overrides, rulings.iloc[0:0])
    applied, applied_all, all_error = _applied_both_ways(places, overrides, rulings)
    validation = validate_anchoring(places, geo, pop, auth, courts, out_dir, applied=applied,
                                    rulings=rulings, applied_all=applied_all)
    owners, owner_rows = owner_changes(places, applied)
    owners_rulings, owner_rows_rulings = owner_changes(generated_only, applied)
    _write_csv(owner_rows, out_dir / "anchor_owner_changes.csv")
    not_applied = rulings_not_applied(applied, overrides)
    _write_csv(not_applied, out_dir / "anchor_rulings_not_applied.csv")
    twins = validation["twins"]
    summary = {
        "generated": int(len(overrides)),
        "generated_rules": {k: int(v) for k, v in overrides["rule"].value_counts().items()},
        "rulings_table": rulings_summary(rulings),
        "rulings_applied_default": len(applied.attrs["anchor_rulings_applied"]),
        "rulings_applied_with_unconfirmed": (len(applied_all.attrs["anchor_rulings_applied"])
                                             if applied_all is not None else None),
        "rulings_not_applied_default": {k: int(v) for k, v in not_applied["reason"].value_counts().items()},
        "rulings_refused": applied.attrs.get("anchor_rulings_refused", []),
        "unconfirmed_with_generated_row": not_applied[not_applied["generated_settlement_id"].notna()]
        .astype(str).to_dict("records"),
        "unanchored_frozen": _unanchored(places),
        "unanchored_default": _unanchored(applied),
        "unanchored_with_unconfirmed": _unanchored(applied_all) if applied_all is not None else None,
        "include_unconfirmed_error": all_error,
        "twins_frozen": {k: twins["frozen"][k] for k in ("verdicts", "links_failed")},
        "twins_default": {k: twins["applied"][k] for k in ("verdicts", "links_failed")},
        "twins_with_unconfirmed": ({k: twins["applied_with_unconfirmed"][k] for k in ("verdicts", "links_failed")}
                                   if applied_all is not None else None),
        "twin_conflicts_default": twins["applied"]["conflicts"],
        "twin_conflicts_with_unconfirmed": (twins["applied_with_unconfirmed"]["conflicts"]
                                            if applied_all is not None else None),
        "register_municipalities_owner_changes_vs_frozen": owners,
        "register_municipalities_owner_changes_by_confirmed_rulings": owners_rulings,
        "owner_changes_by_confirmed_rulings": owner_rows_rulings.astype(str).to_dict("records"),
    }
    if applied_all is not None:
        owners_unconf, owner_rows_unconf = owner_changes(applied, applied_all)
        summary["register_municipalities_owner_changes_by_unconfirmed_rulings"] = owners_unconf
        summary["owner_changes_by_unconfirmed_rulings"] = owner_rows_unconf.astype(str).to_dict("records")
    validation["build"] = summary
    _write_json(validation, out_dir / "anchor_validation.json")

    # The rest, for the author: every place no override or applied ruling settles, its best
    # candidates and where else in the Czech lands its name is found (check (c)); ranked by 1910
    # population, births. A place whose ruling was not applied stays here, marked with the reason.
    done = {_place_key(*k) for k in overrides[KEY].values}
    cand = decided[[_place_key(*k) not in done for k in decided[KEY].values]]
    search = pd.read_csv(out_dir / "anchor_validation_unanchored_search.csv",
                         dtype={"court_key": str, "edition": str})
    cand = cand.merge(search[KEY + ["found_in", "found_okresy", "adjacent_okresy", "settlement_ids"]]
                      .rename(columns={"settlement_ids": "found_settlement_ids"}),
                      on=KEY, how="left", validate="m:1")
    waiting = {_place_key(e, c, m, s): (why, a, sid) for e, c, m, s, why, a, sid in
               zip(not_applied["edition"], not_applied["court_key"], not_applied["muni_seq"],
                   not_applied["settlement_seq"], not_applied["reason"], not_applied["action"],
                   not_applied["settlement_id"])}
    marks = [waiting.get(_place_key(*k), ("", "", None)) for k in cand[KEY].values]
    cand["ruling_reason"] = [m[0] for m in marks]
    cand["ruling_action"] = [m[1] for m in marks]
    cand["ruling_settlement_id"] = [m[2] for m in marks]
    cand = cand.sort_values(["pop_total", "births"], ascending=False)
    _write_csv(cand, out_dir / "anchor_candidates.csv")
    rt = summary["rulings_table"]
    print(f"  anchor_overrides {__version__}: {len(overrides)} certain overrides "
          f"({summary['generated_rules']}); {rt['rulings']} rulings ({rt['confirmed']} confirmed, "
          f"{rt['unconfirmed']} unconfirmed; {rt['by_action']}); applied by default "
          f"{summary['rulings_applied_default']}, with unconfirmed "
          f"{summary['rulings_applied_with_unconfirmed']}; not applied {summary['rulings_not_applied_default']}; "
          f"{cand[KEY].drop_duplicates().shape[0]} places left to the author; unanchored rows "
          f"{summary['unanchored_frozen']['rows']} -> {summary['unanchored_default']['rows']} (default) / "
          f"{(summary['unanchored_with_unconfirmed'] or {}).get('rows')} (with unconfirmed); twins "
          f"{summary['twins_default']['verdicts']} / {(summary['twins_with_unconfirmed'] or {}).get('verdicts')}"
          + (f"; include_unconfirmed failed: {all_error}" if all_error else ""))
    return {"heals": heals, "heal_summary": heal_summary, "auth": auth, "decided": decided,
            "overrides": overrides, "rulings": rulings, "applied": applied,
            "applied_with_unconfirmed": applied_all, "not_applied": not_applied,
            "validation": validation, "summary": summary, "pop": pop}
