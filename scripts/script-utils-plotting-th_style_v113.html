How it works

Colour palette

The palette is organised into seven chromatic families — blues, reds, yellows, greens, oranges, purples — plus a range of neutrals and fill greys. All named constants (e.g. CU_NAVY, CU_RED) are importable directly and may be used wherever a Matplotlib colour argument is accepted.

N-aware colour selection

The core design principle is that the right colours for a figure depend on how many series are being plotted. get_palette(n) returns a curated list of exactly n colours following a consistent sequencing logic:

  • n = 2 primary blue + primary red
  • n = 3 + soft grey (neutral third)
  • n = 4 full blue pair then full red pair
  • n = 5-6 bb rr + grey shades as fillers
  • n = 7+ grey drops out; chromatic families expand in order
  • n = 13-20 curated n=12 sequence extended with neutrals and darks
  • n > 20 full palette cycled

The intent is that similar colours cluster together: a stacked area chart with four series will show two blues and two reds, which read as two distinct groups rather than four unrelated hues.

Legend placement

style_legend(ax, n=n) applies consistent legend formatting and automatically places the legend outside the axes for n >= 4, where an in-axes legend would typically occlude data. Both behaviours can be overridden explicitly. Always call fig.tight_layout() afterwards when placing outside.

Colormaps

Two named Matplotlib colormaps are provided for continuous data:

CU_DIVERGING navy -> white -> red; for variables with a meaningful zero (correlations, residuals, z-scores). CU_SEQUENTIAL white -> navy; for one-directional variables such as counts, densities, or probabilities.

Both are registered with Matplotlib on import and can be passed directly to any cmap= argument.

Axis utilities

set_yaxis_thousands(ax) and set_xaxis_thousands(ax) format tick labels with comma separators (e.g. 1500000 -> 1,500,000).

annotate_bars(ax) adds value labels to bar charts automatically, handling both vertical and horizontal orientations.

despine(ax) removes the top and right spines for a cleaner look, suitable for presentations or blog posts.

Time series utilities

add_vspans(ax, periods) shades a list of (start, end) periods as semi-transparent vertical bands — useful for marking recessions, wars, or other historical episodes on time series plots.

add_vlines(ax, events) draws vertical lines at point-in-time events such as elections, crashes, or policy announcements. Supports optional text labels and partial vertical extent via ymin/ymax.

Saving for LaTeX

save_for_latex(fig, name) writes PDF and PNG to a figures/ directory. By default it strips Matplotlib titles before saving so that LaTeX can supply captions via \caption{} with proper typography and \label{} cross-reference support; titles are restored in memory afterwards. Pass split_panels=True to additionally save each subplot individually, suitable for the LaTeX subcaption environment.

def get_palette(n: int) -> list[str]:
    """Return the recommended colour list for *n* series.

    For n <= 12 returns a curated subset; for n > 12 extends the n=12
    sequence with the remaining PALETTE entries in order (neutrals, darks,
    fill greys). The returned list always has exactly *n* entries.

    Args:
        n: number of distinct series (lines, bars, areas, ...)

    Returns:
        List of hex colour strings, length n.

    Example:
        colours = get_palette(4)
        for i, (label, data) in enumerate(series.items()):
            ax.plot(x, data, color=colours[i], label=label)
    """
    if n <= 0:
        raise ValueError("n must be a positive integer")
    if n in _N_SEQUENCES:
        return _N_SEQUENCES[n]
    if n <= len(PALETTE):
        # extend the n=12 curated sequence with remaining PALETTE entries
        base = _N_SEQUENCES[12]
        extras = [c for c in PALETTE if c not in base]
        return (base + extras)[:n]
    # cycle for very large n (n > 20)
    reps = (n // len(PALETTE)) + 1
    return (PALETTE * reps)[:n]

def annotate_bars(
    ax,
    fmt: str = "{:.0f}",
    padding: float = 0.01,
    fontsize: float | None = None,
    color: str = "black",
    min_value: float | None = None,
    ha: str | None = None,
    va: str | None = None,
):
    """Add value labels to all bars in a bar chart.

    Detects orientation (vertical or horizontal) automatically from the
    first bar found. Labels are placed just outside the end of each bar.

    Args:
        ax:         matplotlib Axes containing the bar chart
        fmt:        Python format string for the label text.
                    Default ``"{:.0f}"`` gives integer labels.
                    Use ``"{:.1f}"`` for one decimal place,
                    ``"{:,.0f}"`` for comma-separated thousands, etc.
        padding:    Gap between the bar tip and the label, expressed as a
                    fraction of the current axis range. Default 0.01.
        fontsize:   Font size for labels. Defaults to the current rcParam
                    ``axes.labelsize`` if not specified.
        color:      Label text colour. Default ``"black"``.
        min_value:  Skip labelling bars whose absolute value is below this
                    threshold — avoids cluttering charts with many tiny bars.
        ha:         Horizontal alignment override. Auto-detected if None.
        va:         Vertical alignment override. Auto-detected if None.

    Returns:
        List of Text objects added to the axes.

    Examples:
        annotate_bars(ax)
        annotate_bars(ax, fmt="{:,.0f}", color=CU_NAVY)
        annotate_bars(ax, fmt="{:.1f}\\\\%", min_value=1.0)
    """
    bars = [p for p in ax.patches if hasattr(p, 'get_width')]
    if not bars:
        return []

    # ── orientation detection ────────────────────────────────────────
    # Compare bar dimension as a fraction of the respective axis span.
    # A horizontal bar's width is a meaningful fraction of the x range;
    # a vertical bar's height is a meaningful fraction of the y range.
    x0, x1 = ax.get_xlim()
    y0, y1 = ax.get_ylim()
    x_span = x1 - x0
    y_span = y1 - y0

    first = bars[0]
    w_frac = abs(first.get_width())  / x_span if x_span else 0
    h_frac = abs(first.get_height()) / y_span if y_span else 0
    horizontal = w_frac > h_frac

    # ── padding in data units (computed from live axis limits) ───────
    pad = padding * (x_span if horizontal else y_span)

    fs = fontsize or mpl.rcParams.get("axes.labelsize", 10)
    texts = []

    for bar in bars:
        value = bar.get_width() if horizontal else bar.get_height()

        if min_value is not None and abs(value) < min_value:
            continue

        label = fmt.format(value)

        if horizontal:
            x = value + pad if value >= 0 else value - pad
            y = bar.get_y() + bar.get_height() / 2
            _ha = ha or ("left" if value >= 0 else "right")
            _va = va or "center"
        else:
            x = bar.get_x() + bar.get_width() / 2
            y = value + pad if value >= 0 else value - pad
            _ha = ha or "center"
            _va = va or ("bottom" if value >= 0 else "top")

        t = ax.text(x, y, label, ha=_ha, va=_va,
                    fontsize=fs, color=color)
        texts.append(t)

    return texts

def add_vspans(
    ax,
    periods: list,
    color: str = CU_GREY_LIGHT,
    alpha: float = 0.35,
    label: str | None = None,
    zorder: int = 0,
):
    """Shade vertical bands on a time series plot.

    Draws semi-transparent rectangles spanning the full vertical extent of
    the axes for each (start, end) period supplied. Useful for marking
    recessions, wars, policy regimes, or any episodic event on a time
    series.

    The bands are drawn at ``zorder=0`` by default, placing them behind
    all data. If you pass ``label``, only the first band receives it so
    that the legend shows a single entry for the whole set of periods.

    Args:
        ax:      matplotlib Axes
        periods: List of (start, end) pairs. Values may be numeric,
                 datetime objects, or anything accepted by ``ax.axvspan()``.
                 Examples:
                   [(1914, 1918), (1939, 1945)]
                   [('2008-09', '2009-06')]
                   [(pd.Timestamp('1929-08'), pd.Timestamp('1933-03'))]
        color:   Fill colour for the bands. Defaults to ``CU_GREY_LIGHT``.
        alpha:   Opacity of the bands. Default 0.35.
        label:   Legend label for the shaded periods. Applied to the first
                 band only; subsequent bands have ``label=None`` so they do
                 not create duplicate legend entries.
        zorder:  Drawing order. Default 0 places bands behind data.

    Returns:
        List of Polygon objects added to the axes.

    Examples:
        add_vspans(ax, [(1914, 1918), (1939, 1945)], label='World Wars')
        add_vspans(ax, recession_dates, color=CU_RED, alpha=0.15)
        add_vspans(ax, [('2008-09', '2009-06')], label='GFC')
    """
    patches = []
    for i, (start, end) in enumerate(periods):
        lbl = label if (i == 0 and label is not None) else None
        p = ax.axvspan(start, end, color=color, alpha=alpha,
                       zorder=zorder, label=lbl)
        patches.append(p)
    return patches

def add_vlines(
    ax,
    events: list,
    color: str = CU_RED,
    alpha: float = 0.8,
    linewidth: float = 1.2,
    linestyle: str = "--",
    labels: list | None = None,
    ymin: float = 0.0,
    ymax: float = 1.0,
    zorder: int = 2,
    label_offset: float = 0.0,
):
    """Draw vertical lines marking point-in-time historical events.

    Complements ``add_vspans`` for episodes that have a single date rather
    than a duration — elections, crashes, policy announcements, assassinations,
    treaty signings, etc.

    Lines span the full (or partial) vertical extent of the axes and are
    drawn in axes-fraction coordinates so they stay pinned regardless of
    subsequent changes to the y-axis scale.

    Args:
        ax:         matplotlib Axes
        events:     List of x-positions (numeric, datetime, or anything
                    accepted by ``ax.axvline()``).
                    Example: [1848, 1914, 1929, 1945, 1989]
        color:      Line colour. Defaults to ``CU_RED``.
        alpha:      Line opacity. Default 0.8.
        linewidth:  Line width. Default 1.2.
        linestyle:  Line style. Default ``"--"`` (dashed).
                    Use ``"-"`` for solid, ``":"`` for dotted.
        labels:     Optional list of text labels, one per event, drawn just
                    above the top of each line. Pass ``None`` (default) for
                    no labels. Length must match ``events`` if provided.
        ymin:       Bottom of the line in axes-fraction units (0 = bottom).
                    Default 0.0.
        ymax:       Top of the line in axes-fraction units (1 = top).
                    Default 1.0.
        zorder:     Drawing order. Default 2 places lines in front of spans
                    but behind most data markers.
        label_offset: Vertical offset for labels in axes-fraction units.

    Returns:
        List of Line2D objects (and Text objects if labels provided).

    Examples:
        add_vlines(ax, [1914, 1929, 1939, 1973, 2008])
        add_vlines(ax, [1848, 1968], color=CU_NAVY, linestyle=':')
        add_vlines(ax, [1989], labels=['Fall of Berlin Wall'], color=CU_OCHRE)
        add_vlines(ax, shocks, color=CU_RED, linewidth=1.5, ymax=0.85)
    """
    if labels is not None and len(labels) != len(events):
        raise ValueError(
            f"labels has {len(labels)} entries but events has {len(events)}"
        )

    artists = []
    for i, x in enumerate(events):
        line = ax.axvline(
            x, ymin=ymin, ymax=ymax,
            color=color, alpha=alpha,
            linewidth=linewidth, linestyle=linestyle,
            zorder=zorder,
        )
        artists.append(line)

        if labels is not None:
            # place label just inside the top of the line in data coords
            y_data = ax.get_ylim()[0] + ymax * (ax.get_ylim()[1] - ax.get_ylim()[0])
            t = ax.text(
                x + label_offset, y_data, f" {labels[i]}",
                va="top", ha="left",
                fontsize=mpl.rcParams.get("legend.fontsize", 8),
                color=color, alpha=min(alpha + 0.2, 1.0),
                rotation=90, zorder=zorder,
            )
            artists.append(t)

    return artists

Any keyword accepted by ax.legend(); overrides all defaults set here (e.g. ncols, title, loc).

The Legend object.

):
    """Apply opinionated legend defaults with n-aware automatic placement.

    For n < 4 the legend sits inside the axes (top-right corner, chosen
    by Matplotlib).  For n >= 4 it moves outside to the right, freeing
    the plot area.  Both behaviours can be overridden via ``outside``.

    When placing outside, call ``fig.tight_layout()`` afterwards so
    Matplotlib resizes the axes to accommodate the legend width.

    Args:
        ax:       matplotlib Axes
        outside:  Force outside (True) or inside (False).  When None
                  (default), placement is automatic: outside if n >= 4,
                  inside otherwise.  If n is also None, defaults to inside.
        n:        Number of series being plotted.  Used only to decide
                  automatic placement when ``outside`` is None.
        **kwargs: Any keyword accepted by ``ax.legend()``; overrides all
                  defaults set here (e.g. ncols, title, loc).

    Returns:
        The Legend object.

    Examples:
        style_legend(ax, n=n)                        # recommended — auto
        style_legend(ax, n=5, title='Country')
        style_legend(ax, n=6, ncols=2)
        style_legend(ax, outside=False)              # force inside
        style_legend(ax, outside=True, ncols=1)      # force outside
    """
    if outside is None:
        outside = (n is not None and n >= 4)

    defaults = dict(
        handlelength=1.2,
        handleheight=0.8,
        handletextpad=0.5,
        labelspacing=0.3,
        columnspacing=1.0,
        frameon=False,
    )
    if outside:
        defaults.update(
            loc='upper left',
            bbox_to_anchor=(1, 1),
            borderaxespad=0,
        )
    defaults.update(kwargs)
    return ax.legend(**defaults)

def set_academic_style(
    target_width_px: int = 1920,
    target_height_px: int = 1080,
    target_dpi: int = 300,
    n: int | None = None,
):
    """Apply minimal, academic LaTeX-style aesthetic for Matplotlib.

    Sets rcParams globally for the current session.  Call once at the
    top of a notebook or script before any plotting.

    Args:
        target_width_px:  output width in pixels (default 1920)
        target_height_px: output height in pixels (default 1080)
        target_dpi:       output DPI (default 300)
        n:                if provided, the prop_cycle is pre-set to
                          get_palette(n).  Omit to use the full 20-colour
                          PALETTE as the default cycle.

    Returns:
        The colour list used for the prop_cycle.
    """
    target_width_in  = target_width_px  / target_dpi
    target_height_in = target_height_px / target_dpi

    base_width, base_height = 5.5, 3.5
    scale = ((target_width_in / base_width) + (target_height_in / base_height)) / 2

    active_palette = get_palette(n) if n is not None else PALETTE

    mpl.rcParams.update({
        # Font
        "text.usetex":          True,
        "font.family":          "serif",
        "text.latex.preamble":  _LIBERTINUS_SERIF_PREAMBLE,
        "font.size":            11 * scale,
        "axes.unicode_minus":   False,

        # Grid — horizontal only, behind data
        "axes.grid":            True,
        "axes.grid.axis":       "y",
        "axes.grid.which":      "major",
        "grid.color":           "0.85",
        "grid.linestyle":       "--",
        "grid.linewidth":       0.5,
        "axes.axisbelow":       True,

        # Axes
        "axes.edgecolor":       "black",
        "axes.linewidth":       0.8,
        "axes.spines.top":      True,
        "axes.spines.right":    True,
        "axes.labelsize":       11 * scale,
        "axes.titlesize":       11 * scale,

        # Ticks
        "xtick.direction":      "out",
        "ytick.direction":      "out",
        "xtick.major.size":     3,
        "ytick.major.size":     3,
        "xtick.minor.size":     1.5,
        "ytick.minor.size":     1.5,
        "xtick.color":          "black",
        "ytick.color":          "black",
        "xtick.labelsize":      10 * scale,
        "ytick.labelsize":      10 * scale,

        # Legend
        "legend.frameon":       False,
        "legend.fontsize":      9 * scale,

        # Figure
        "figure.figsize":       (target_width_in, target_height_in),
        "figure.dpi":           target_dpi,
        "savefig.dpi":          target_dpi,
        "savefig.bbox":         "tight",
    })

    mpl.rcParams["axes.prop_cycle"] = mpl.cycler(color=active_palette)

    return active_palette

def save_for_latex(
    fig,
    name: str,
    figures_dir: str = "figures",
    formats: tuple = ("pdf", "png"),
    dpi: int = 300,
    strip_title: bool = True,
    split_panels: bool = False,
    panel_suffixes: list[str] | None = None,
    beamer: bool = True,
    beamer_suffix: str = "_beamer",
):
    """Save a figure for LaTeX inclusion in both serif and Beamer variants.

    Saves under ``{figures_dir}/{name}.{ext}`` for each requested format.
    PDF is vector and is what you pass to ``\\includegraphics{}``; PNG is
    a raster preview at the specified DPI.

    By default, axis titles and the suptitle are hidden before saving and
    restored afterwards, so that LaTeX can supply the caption via
    ``\\caption{}`` with proper typography and ``\\label{}`` support.
    Pass ``strip_title=False`` to bake the title into the file.

    Beamer variant
    --------------
    When ``beamer=True`` (default), a second set of files is written with
    ``{beamer_suffix}`` appended to the base name (e.g. ``gdp_beamer.pdf``).
    These are rendered with Latin Modern Sans — the default Beamer font —
    so that tick labels, axis labels, and legend text match slide body text
    when the figure is embedded via ``\\includegraphics{}``.  The original
    rcParams are fully restored after saving.

    Use the serif version (``gdp_by_country.pdf``) in papers and the Beamer
    version (``gdp_by_country_beamer.pdf``) in presentations::

        \\includegraphics{figures/gdp_by_country}        % paper
        \\includegraphics{figures/gdp_by_country_beamer} % slides

    If your Beamer theme uses ``\\usefonttheme{serif}`` or a custom fontspec
    font, set ``beamer=False`` and use the serif version for both.

    Args:
        fig:            matplotlib Figure
        name:           base filename — no extension, no spaces
        figures_dir:    output directory; created if it does not exist
        formats:        file extensions to write (default: pdf + png)
        dpi:            raster resolution; ignored for PDF (default: 300)
        strip_title:    hide titles before saving, restore after
        split_panels:   also save each subplot individually as
                        ``{name}_a.pdf``, ``{name}_b.pdf``, ... — useful
                        with the LaTeX ``subcaption`` package
        panel_suffixes: override default a/b/c/... labels for split panels;
                        length must equal the number of subplots
        beamer:         also write a sans-serif Beamer variant (default True)
        beamer_suffix:  suffix appended to ``name`` for Beamer files
                        (default ``"_beamer"``)

    Returns:
        List of file paths written (serif files first, then Beamer files).

    Example:
        save_for_latex(fig, "gdp_by_country", figures_dir="figures")
        # -> figures/gdp_by_country.pdf         (serif — for papers)
        # -> figures/gdp_by_country.png
        # -> figures/gdp_by_country_beamer.pdf  (sans — for slides)
        # -> figures/gdp_by_country_beamer.png

        save_for_latex(fig, "panel_fig", split_panels=True)
        # -> figures/panel_fig.pdf
        # -> figures/panel_fig_a.pdf
        # -> figures/panel_fig_b.pdf
        # -> figures/panel_fig_beamer.pdf
        # -> figures/panel_fig_beamer_a.pdf
        # -> figures/panel_fig_beamer_b.pdf

        save_for_latex(fig, "draft", beamer=False)
        # -> figures/draft.pdf   (serif only)
        # -> figures/draft.png
    """
    os.makedirs(figures_dir, exist_ok=True)

    # ── stash and strip titles ───────────────────────────────────────
    stashed = []
    if strip_title:
        if fig._suptitle is not None and fig._suptitle.get_text():
            stashed.append(("suptitle", fig._suptitle.get_text()))
            fig.suptitle("")
        for ax in fig.axes:
            t = ax.get_title()
            if t:
                stashed.append((ax, t))
                ax.set_title("")

    paths = []

    # ── serif save (paper) ───────────────────────────────────────────
    # Explicitly mark all text artists as serif so any previous beamer
    # call in the same session doesn't bleed through.
    _set_figure_fontfamily(fig, "serif")
    print(f"  [serif]")
    paths += _save_figure(fig, name, figures_dir, formats, dpi,
                          split_panels, panel_suffixes)

    # ── beamer save (sans-serif) ─────────────────────────────────────
    if beamer:
        # Snapshot only the keys we are about to change
        _saved_rc = {k: mpl.rcParams[k] for k in _BEAMER_SNAPSHOT_KEYS
                     if k in mpl.rcParams}
        try:
            mpl.rcParams.update(_BEAMER_FONT_OVERRIDES)
            # Invalidate the on-disk DVI cache and in-memory text-metrics
            # cache.  Matplotlib's TexManager hashes the TeX source to a
            # cache filename; if an earlier session compiled a string with
            # a different (or broken) preamble that happens to share inputs
            # with the current one, the stale .dvi can survive and trigger
            # `ValueError: state precondition failed` deep in dviread.
            # Wiping the cache here forces a fresh compile under the new
            # sans-serif preamble.  Cheap: a handful of LaTeX runs (~100ms
            # each) per save.
            _clear_tex_cache()
            # Mark every text artist — tick labels, axis labels, legend,
            # annotations — as sans-serif so the LaTeX backend re-compiles
            # them with the updated preamble (\sfdefault) on this save.
            _set_figure_fontfamily(fig, "sans-serif")
            print(f"  [beamer / sans-serif]")
            paths += _save_figure(fig, f"{name}{beamer_suffix}", figures_dir,
                                  formats, dpi, split_panels, panel_suffixes)
        finally:
            # Restore rcParams and reset all text artists to serif so the
            # figure is back to its original state in the caller's session.
            mpl.rcParams.update(_saved_rc)
            _set_figure_fontfamily(fig, "serif")

    # ── restore titles ───────────────────────────────────────────────
    if strip_title:
        for item in stashed:
            if item[0] == "suptitle":
                fig.suptitle(item[1])
            else:
                ax, title = item
                ax.set_title(title)

    return paths

"""
th_style — Academic Matplotlib Style
======================================
A personal, reusable Matplotlib configuration module built around the
Charles University (Karlova Univerzita) official colour palette, extended
with complementary colour families for multi-series academic figures.

Colour palette
--------------
The palette is organised into seven chromatic families — blues, reds,
yellows, greens, oranges, purples — plus a range of neutrals and fill
greys. All named constants (e.g. CU_NAVY, CU_RED) are importable
directly and may be used wherever a Matplotlib colour argument is accepted.

N-aware colour selection
------------------------
The core design principle is that the right colours for a figure depend on
how many series are being plotted. ``get_palette(n)`` returns a curated
list of exactly ``n`` colours following a consistent sequencing logic:

  - n = 2        primary blue + primary red
  - n = 3        + soft grey (neutral third)
  - n = 4        full blue pair then full red pair
  - n = 5-6      bb rr + grey shades as fillers
  - n = 7+       grey drops out; chromatic families expand in order
  - n = 13-20    curated n=12 sequence extended with neutrals and darks
  - n > 20       full palette cycled

The intent is that similar colours cluster together: a stacked area chart
with four series will show two blues and two reds, which read as two
distinct groups rather than four unrelated hues.

Legend placement
----------------
``style_legend(ax, n=n)`` applies consistent legend formatting and
automatically places the legend outside the axes for n >= 4, where an
in-axes legend would typically occlude data. Both behaviours can be
overridden explicitly. Always call ``fig.tight_layout()`` afterwards when
placing outside.

Colormaps
---------
Two named Matplotlib colormaps are provided for continuous data:

  ``CU_DIVERGING``   navy -> white -> red; for variables with a meaningful
                     zero (correlations, residuals, z-scores).
  ``CU_SEQUENTIAL``  white -> navy; for one-directional variables such as
                     counts, densities, or probabilities.

Both are registered with Matplotlib on import and can be passed directly
to any ``cmap=`` argument.

Axis utilities
--------------
``set_yaxis_thousands(ax)`` and ``set_xaxis_thousands(ax)`` format tick
labels with comma separators (e.g. 1500000 -> 1,500,000).

``annotate_bars(ax)`` adds value labels to bar charts automatically,
handling both vertical and horizontal orientations.

``despine(ax)`` removes the top and right spines for a cleaner look,
suitable for presentations or blog posts.

Time series utilities
---------------------
``add_vspans(ax, periods)`` shades a list of (start, end) periods as
semi-transparent vertical bands — useful for marking recessions, wars,
or other historical episodes on time series plots.

``add_vlines(ax, events)`` draws vertical lines at point-in-time events
such as elections, crashes, or policy announcements. Supports optional
text labels and partial vertical extent via ``ymin``/``ymax``.

Saving for LaTeX
----------------
``save_for_latex(fig, name)`` writes PDF and PNG to a ``figures/``
directory. By default it strips Matplotlib titles before saving so that
LaTeX can supply captions via ``\\caption{}`` with proper typography and
``\\label{}`` cross-reference support; titles are restored in memory
afterwards. Pass ``split_panels=True`` to additionally save each subplot
individually, suitable for the LaTeX ``subcaption`` environment.

Quick start
-----------
    from th_style import set_academic_style, get_palette, style_legend
    from th_style import set_yaxis_thousands, set_xaxis_thousands
    from th_style import annotate_bars, despine, add_vspans, add_vlines
    from th_style import save_for_latex
    from th_style import CU_DIVERGING, CU_SEQUENTIAL

    set_academic_style()           # apply global rcParams
    colours = get_palette(n)       # n-aware colour list
    style_legend(ax, n=n)          # consistent legend, auto placement
    set_yaxis_thousands(ax)        # comma-separated y-axis tick labels
    annotate_bars(ax)              # value labels on bar charts
    despine(ax)                    # remove top and right spines
    add_vspans(ax, [('1914','1918'), ('1939','1945')])
    add_vlines(ax, [1848, 1929, 1989], labels=['Revolution', 'Crash', 'Wall'])
    save_for_latex(fig, "name")    # serif PDF+PNG (paper) + sans PDF+PNG (beamer)
    save_for_latex(fig, "name", beamer=False)   # serif only

Original CU brand guidelines:
    https://pr.cuni.cz/PR-77-version1-jpvs_uk_graficky_manual_fin.pdf
"""

# Sequencing logic:
#   n=2       primary blue + primary red
#   n=3       + grey-light as lone neutral

def get_palette(n: int) -> list[str]:
    """Return the recommended colour list for *n* series.

    For n <= 12 returns a curated subset; for n > 12 extends the n=12
    sequence with the remaining PALETTE entries in order (neutrals, darks,
    fill greys). The returned list always has exactly *n* entries.

    Args:
        n: number of distinct series (lines, bars, areas, ...)

    Returns:
        List of hex colour strings, length n.

    Example:
        colours = get_palette(4)
        for i, (label, data) in enumerate(series.items()):
            ax.plot(x, data, color=colours[i], label=label)
    """
    if n <= 0:
        raise ValueError("n must be a positive integer")
    if n in _N_SEQUENCES:
        return _N_SEQUENCES[n]
    if n <= len(PALETTE):
        # extend the n=12 curated sequence with remaining PALETTE entries
        base = _N_SEQUENCES[12]
        extras = [c for c in PALETTE if c not in base]
        return (base + extras)[:n]
    # cycle for very large n (n > 20)
    reps = (n // len(PALETTE)) + 1
    return (PALETTE * reps)[:n]

def annotate_bars(
    ax,
    fmt: str = "{:.0f}",
    padding: float = 0.01,
    fontsize: float | None = None,
    color: str = "black",
    min_value: float | None = None,
    ha: str | None = None,
    va: str | None = None,
):
    """Add value labels to all bars in a bar chart.

    Detects orientation (vertical or horizontal) automatically from the
    first bar found. Labels are placed just outside the end of each bar.

    Args:
        ax:         matplotlib Axes containing the bar chart
        fmt:        Python format string for the label text.
                    Default ``"{:.0f}"`` gives integer labels.
                    Use ``"{:.1f}"`` for one decimal place,
                    ``"{:,.0f}"`` for comma-separated thousands, etc.
        padding:    Gap between the bar tip and the label, expressed as a
                    fraction of the current axis range. Default 0.01.
        fontsize:   Font size for labels. Defaults to the current rcParam
                    ``axes.labelsize`` if not specified.
        color:      Label text colour. Default ``"black"``.
        min_value:  Skip labelling bars whose absolute value is below this
                    threshold — avoids cluttering charts with many tiny bars.
        ha:         Horizontal alignment override. Auto-detected if None.
        va:         Vertical alignment override. Auto-detected if None.

    Returns:
        List of Text objects added to the axes.

    Examples:
        annotate_bars(ax)
        annotate_bars(ax, fmt="{:,.0f}", color=CU_NAVY)
        annotate_bars(ax, fmt="{:.1f}\\\\%", min_value=1.0)
    """
    bars = [p for p in ax.patches if hasattr(p, 'get_width')]
    if not bars:
        return []

    # ── orientation detection ────────────────────────────────────────
    # Compare bar dimension as a fraction of the respective axis span.
    # A horizontal bar's width is a meaningful fraction of the x range;
    # a vertical bar's height is a meaningful fraction of the y range.
    x0, x1 = ax.get_xlim()
    y0, y1 = ax.get_ylim()
    x_span = x1 - x0
    y_span = y1 - y0

    first = bars[0]
    w_frac = abs(first.get_width())  / x_span if x_span else 0
    h_frac = abs(first.get_height()) / y_span if y_span else 0
    horizontal = w_frac > h_frac

    # ── padding in data units (computed from live axis limits) ───────
    pad = padding * (x_span if horizontal else y_span)

    fs = fontsize or mpl.rcParams.get("axes.labelsize", 10)
    texts = []

    for bar in bars:
        value = bar.get_width() if horizontal else bar.get_height()

        if min_value is not None and abs(value) < min_value:
            continue

        label = fmt.format(value)

        if horizontal:
            x = value + pad if value >= 0 else value - pad
            y = bar.get_y() + bar.get_height() / 2
            _ha = ha or ("left" if value >= 0 else "right")
            _va = va or "center"
        else:
            x = bar.get_x() + bar.get_width() / 2
            y = value + pad if value >= 0 else value - pad
            _ha = ha or "center"
            _va = va or ("bottom" if value >= 0 else "top")

        t = ax.text(x, y, label, ha=_ha, va=_va,
                    fontsize=fs, color=color)
        texts.append(t)

    return texts


def despine(ax, which: tuple = ("top", "right")):
    """Remove axis spines for a cleaner appearance.

    The default academic style keeps all four spines. This helper removes
    the specified spines — typically the top and right — for a lighter
    look suited to presentations, blog posts, or figures where the full
    box feels too heavy.

    Args:
        ax:    matplotlib Axes
        which: Tuple of spine names to remove.
               Default ``("top", "right")``.
               Pass ``("top", "right", "left", "bottom")`` to remove all.

    Example:
        despine(ax)                          # remove top and right only
        despine(ax, which=("top",))          # remove top only
        despine(ax, which=("top", "right", "left", "bottom"))  # all
    """
    for spine in which:
        ax.spines[spine].set_visible(False)


def add_vspans(
    ax,
    periods: list,
    color: str = CU_GREY_LIGHT,
    alpha: float = 0.35,
    label: str | None = None,
    zorder: int = 0,
):
    """Shade vertical bands on a time series plot.

    Draws semi-transparent rectangles spanning the full vertical extent of
    the axes for each (start, end) period supplied. Useful for marking
    recessions, wars, policy regimes, or any episodic event on a time
    series.

    The bands are drawn at ``zorder=0`` by default, placing them behind
    all data. If you pass ``label``, only the first band receives it so
    that the legend shows a single entry for the whole set of periods.

    Args:
        ax:      matplotlib Axes
        periods: List of (start, end) pairs. Values may be numeric,
                 datetime objects, or anything accepted by ``ax.axvspan()``.
                 Examples:
                   [(1914, 1918), (1939, 1945)]
                   [('2008-09', '2009-06')]
                   [(pd.Timestamp('1929-08'), pd.Timestamp('1933-03'))]
        color:   Fill colour for the bands. Defaults to ``CU_GREY_LIGHT``.
        alpha:   Opacity of the bands. Default 0.35.
        label:   Legend label for the shaded periods. Applied to the first
                 band only; subsequent bands have ``label=None`` so they do
                 not create duplicate legend entries.
        zorder:  Drawing order. Default 0 places bands behind data.

    Returns:
        List of Polygon objects added to the axes.

    Examples:
        add_vspans(ax, [(1914, 1918), (1939, 1945)], label='World Wars')
        add_vspans(ax, recession_dates, color=CU_RED, alpha=0.15)
        add_vspans(ax, [('2008-09', '2009-06')], label='GFC')
    """
    patches = []
    for i, (start, end) in enumerate(periods):
        lbl = label if (i == 0 and label is not None) else None
        p = ax.axvspan(start, end, color=color, alpha=alpha,
                       zorder=zorder, label=lbl)
        patches.append(p)
    return patches



def add_vlines(
    ax,
    events: list,
    color: str = CU_RED,
    alpha: float = 0.8,
    linewidth: float = 1.2,
    linestyle: str = "--",
    labels: list | None = None,
    ymin: float = 0.0,
    ymax: float = 1.0,
    zorder: int = 2,
    label_offset: float = 0.0,
):
    """Draw vertical lines marking point-in-time historical events.

    Complements ``add_vspans`` for episodes that have a single date rather
    than a duration — elections, crashes, policy announcements, assassinations,
    treaty signings, etc.

    Lines span the full (or partial) vertical extent of the axes and are
    drawn in axes-fraction coordinates so they stay pinned regardless of
    subsequent changes to the y-axis scale.

    Args:
        ax:         matplotlib Axes
        events:     List of x-positions (numeric, datetime, or anything
                    accepted by ``ax.axvline()``).
                    Example: [1848, 1914, 1929, 1945, 1989]
        color:      Line colour. Defaults to ``CU_RED``.
        alpha:      Line opacity. Default 0.8.
        linewidth:  Line width. Default 1.2.
        linestyle:  Line style. Default ``"--"`` (dashed).
                    Use ``"-"`` for solid, ``":"`` for dotted.
        labels:     Optional list of text labels, one per event, drawn just
                    above the top of each line. Pass ``None`` (default) for
                    no labels. Length must match ``events`` if provided.
        ymin:       Bottom of the line in axes-fraction units (0 = bottom).
                    Default 0.0.
        ymax:       Top of the line in axes-fraction units (1 = top).
                    Default 1.0.
        zorder:     Drawing order. Default 2 places lines in front of spans
                    but behind most data markers.
        label_offset: Vertical offset for labels in axes-fraction units.

    Returns:
        List of Line2D objects (and Text objects if labels provided).

    Examples:
        add_vlines(ax, [1914, 1929, 1939, 1973, 2008])
        add_vlines(ax, [1848, 1968], color=CU_NAVY, linestyle=':')
        add_vlines(ax, [1989], labels=['Fall of Berlin Wall'], color=CU_OCHRE)
        add_vlines(ax, shocks, color=CU_RED, linewidth=1.5, ymax=0.85)
    """
    if labels is not None and len(labels) != len(events):
        raise ValueError(
            f"labels has {len(labels)} entries but events has {len(events)}"
        )

    artists = []
    for i, x in enumerate(events):
        line = ax.axvline(
            x, ymin=ymin, ymax=ymax,
            color=color, alpha=alpha,
            linewidth=linewidth, linestyle=linestyle,
            zorder=zorder,
        )
        artists.append(line)

        if labels is not None:
            # place label just inside the top of the line in data coords
            y_data = ax.get_ylim()[0] + ymax * (ax.get_ylim()[1] - ax.get_ylim()[0])
            t = ax.text(
                x + label_offset, y_data, f" {labels[i]}",
                va="top", ha="left",
                fontsize=mpl.rcParams.get("legend.fontsize", 8),
                color=color, alpha=min(alpha + 0.2, 1.0),
                rotation=90, zorder=zorder,
            )
            artists.append(t)

    return artists

def style_legend(
    ax,
    outside: bool | None = None,
    n: int | None = None,
    **kwargs,
):
    """Apply opinionated legend defaults with n-aware automatic placement.

    For n < 4 the legend sits inside the axes (top-right corner, chosen
    by Matplotlib).  For n >= 4 it moves outside to the right, freeing
    the plot area.  Both behaviours can be overridden via ``outside``.

    When placing outside, call ``fig.tight_layout()`` afterwards so
    Matplotlib resizes the axes to accommodate the legend width.

    Args:
        ax:       matplotlib Axes
        outside:  Force outside (True) or inside (False).  When None
                  (default), placement is automatic: outside if n >= 4,
                  inside otherwise.  If n is also None, defaults to inside.
        n:        Number of series being plotted.  Used only to decide
                  automatic placement when ``outside`` is None.
        **kwargs: Any keyword accepted by ``ax.legend()``; overrides all
                  defaults set here (e.g. ncols, title, loc).

    Returns:
        The Legend object.

    Examples:
        style_legend(ax, n=n)                        # recommended — auto
        style_legend(ax, n=5, title='Country')
        style_legend(ax, n=6, ncols=2)
        style_legend(ax, outside=False)              # force inside
        style_legend(ax, outside=True, ncols=1)      # force outside
    """
    if outside is None:
        outside = (n is not None and n >= 4)

    defaults = dict(
        handlelength=1.2,
        handleheight=0.8,
        handletextpad=0.5,
        labelspacing=0.3,
        columnspacing=1.0,
        frameon=False,
    )
    if outside:
        defaults.update(
            loc='upper left',
            bbox_to_anchor=(1, 1),
            borderaxespad=0,
        )
    defaults.update(kwargs)
    return ax.legend(**defaults)

def set_academic_style(
    target_width_px: int = 1920,
    target_height_px: int = 1080,
    target_dpi: int = 300,
    n: int | None = None,
):
    """Apply minimal, academic LaTeX-style aesthetic for Matplotlib.

    Sets rcParams globally for the current session.  Call once at the
    top of a notebook or script before any plotting.

    Args:
        target_width_px:  output width in pixels (default 1920)
        target_height_px: output height in pixels (default 1080)
        target_dpi:       output DPI (default 300)
        n:                if provided, the prop_cycle is pre-set to
                          get_palette(n).  Omit to use the full 20-colour
                          PALETTE as the default cycle.

    Returns:
        The colour list used for the prop_cycle.
    """
    target_width_in  = target_width_px  / target_dpi
    target_height_in = target_height_px / target_dpi

    base_width, base_height = 5.5, 3.5
    scale = ((target_width_in / base_width) + (target_height_in / base_height)) / 2

    active_palette = get_palette(n) if n is not None else PALETTE

    mpl.rcParams.update({
        # Font
        "text.usetex":          True,
        "font.family":          "serif",
        "text.latex.preamble":  _LIBERTINUS_SERIF_PREAMBLE,
        "font.size":            11 * scale,
        "axes.unicode_minus":   False,

        # Grid — horizontal only, behind data
        "axes.grid":            True,
        "axes.grid.axis":       "y",
        "axes.grid.which":      "major",
        "grid.color":           "0.85",
        "grid.linestyle":       "--",
        "grid.linewidth":       0.5,
        "axes.axisbelow":       True,

        # Axes
        "axes.edgecolor":       "black",
        "axes.linewidth":       0.8,
        "axes.spines.top":      True,
        "axes.spines.right":    True,
        "axes.labelsize":       11 * scale,
        "axes.titlesize":       11 * scale,

        # Ticks
        "xtick.direction":      "out",
        "ytick.direction":      "out",
        "xtick.major.size":     3,
        "ytick.major.size":     3,
        "xtick.minor.size":     1.5,
        "ytick.minor.size":     1.5,
        "xtick.color":          "black",
        "ytick.color":          "black",
        "xtick.labelsize":      10 * scale,
        "ytick.labelsize":      10 * scale,

        # Legend
        "legend.frameon":       False,
        "legend.fontsize":      9 * scale,

        # Figure
        "figure.figsize":       (target_width_in, target_height_in),
        "figure.dpi":           target_dpi,
        "savefig.dpi":          target_dpi,
        "savefig.bbox":         "tight",
    })

    mpl.rcParams["axes.prop_cycle"] = mpl.cycler(color=active_palette)

    return active_palette

# ── Typeface of paper figures: Libertinus ───────────────────────────────
# Paper figures are set in Libertinus Serif, the typeface of the paper
# template (Template/Paper).  Slide figures stay in Computer Modern Sans,
# the Beamer default (see the overrides below).  With text.usetex=True
# Matplotlib compiles every label with LaTeX, so the typeface is chosen in
# ``text.latex.preamble``.
#
# libertinust1math is needed as well as libertinus: Matplotlib wraps tick
# labels as $\mathdefault{0.5}$, i.e. in math mode, and without a matching
# math font the tick numbers would stay in Computer Modern.
#
# Requires the LaTeX packages libertinus, libertinus-type1 and
# libertinust1math (in TeX Live's full scheme; MiKTeX installs them on
# first use).
_LIBERTINUS_SERIF_PREAMBLE = (
    r"\usepackage[T1]{fontenc}"
    r"\usepackage{libertinus}"
    r"\usepackage{libertinust1math}"
)

# ── Beamer sans-serif font overrides ────────────────────────────────────
# Latin Modern Sans is the default Beamer font family (used by most themes
# unless the author selects \usefonttheme{serif} or loads a custom font).
# These rcParams switch Matplotlib's text rendering to match it, so that
# tick labels, axis labels, and legend text are visually consistent with
# slide body text when the figure is embedded via \includegraphics{}.
_BEAMER_FONT_OVERRIDES = {
    "font.family":          "sans-serif",
    # Resolving font.sans-serif[0] to "Computer Modern Sans Serif" tells
    # Matplotlib's TexManager to emit just `\usepackage{type1ec}` and use
    # \sffamily — no helvet, no lmodern, no font-definition files outside
    # the base TeX Live install.  This is also what Beamer uses by default
    # (\usefonttheme{default} ⇒ CM Sans), so figures match slides natively.
    "font.sans-serif":      ["Computer Modern Sans Serif"],
    "text.usetex":          True,
    # Critical fix: Matplotlib wraps tick label text as $\mathdefault{0.5}$
    # — i.e. math mode.  Plain \sffamily does *not* affect math mode, so
    # without this override the tick numbers (and the minus sign) would
    # render in CM Roman / CM Math Italic even though the rest of the
    # figure is sans.  Forcing \mathdefault to emit \textsf{...} routes
    # the digits and minus signs through the sans family.
    "text.latex.preamble":  r"\renewcommand{\mathdefault}[1]{\textsf{#1}}",
}

# Keys snapshotted when switching to beamer font (restored afterwards)
_BEAMER_SNAPSHOT_KEYS = list(_BEAMER_FONT_OVERRIDES.keys())


def _collect_text_artists(fig):
    """Return every Text artist in *fig*, including tick labels.

    Matplotlib with ``text.usetex=True`` compiles each Text object
    independently using the active preamble *at render time*, but only if
    the object's font properties have actually changed since the last draw.
    Explicitly setting ``fontfamily`` marks each Text as stale so the LaTeX
    backend re-compiles it with the updated preamble when the figure is saved.
    """
    artists = list(fig.texts)  # suptitle, figure-level annotations
    for ax in fig.axes:
        artists += [ax.title, ax.xaxis.label, ax.yaxis.label]
        artists += ax.texts                       # ax.text() annotations
        artists += ax.xaxis.get_ticklabels(which="both")
        artists += ax.yaxis.get_ticklabels(which="both")
        if ax.get_legend() is not None:
            artists += ax.get_legend().get_texts()
    return [a for a in artists if a is not None]


def _set_figure_fontfamily(fig, family: str):
    """Set ``fontfamily`` on every Text artist in *fig*.

    Passing ``family='serif'`` or ``family='sans-serif'`` marks all text
    objects as stale so Matplotlib re-renders them with the current rcParams
    on the next save.  Call this *after* updating rcParams so the new
    ``text.latex.preamble`` is picked up.
    """
    for artist in _collect_text_artists(fig):
        artist.set_fontfamily(family)


def _clear_tex_cache():
    """Invalidate Matplotlib's TexManager caches (on-disk DVI + in-memory).

    Matplotlib hashes the rendered TeX source to a basename and reuses the
    resulting ``.dvi`` if the file already exists on disk.  If a prior run
    compiled a string with a faulty preamble (or wrote a truncated DVI
    after a crash), subsequent runs with a *valid* preamble can still hit
    the stale file and crash deep inside ``dviread`` with
    ``ValueError: state precondition failed``.

    We also clear the ``_get_text_metrics_with_cache_impl`` LRU cache so
    that width/height/descent queries are recomputed against the new
    preamble.

    Both are no-ops if the caches are already empty or unavailable.
    """
    # ── on-disk DVI cache ────────────────────────────────────────────
    try:
        from matplotlib.texmanager import TexManager
        cache_dir = TexManager._texcache
        if os.path.isdir(cache_dir):
            for fname in os.listdir(cache_dir):
                fpath = os.path.join(cache_dir, fname)
                try:
                    if os.path.isfile(fpath):
                        os.unlink(fpath)
                except OSError:
                    pass  # locked file on Windows etc. — skip
    except Exception:
        pass

    # ── in-memory text-metrics LRU cache ─────────────────────────────
    try:
        from matplotlib.text import _get_text_metrics_with_cache_impl
        _get_text_metrics_with_cache_impl.cache_clear()
    except Exception:
        pass


def _save_figure(
    fig,
    name: str,
    figures_dir: str,
    formats: tuple,
    dpi: int,
    split_panels: bool,
    panel_suffixes: list[str] | None,
):
    """Internal helper: write ``fig`` to disk under ``figures_dir/name.*``.

    Does not handle title-stripping or font switching — those are managed
    by the caller (``save_for_latex``).  Returns the list of paths written.
    """
    paths = []

    # ── whole-figure save ────────────────────────────────────────────
    for ext in formats:
        path = os.path.join(figures_dir, f"{name}.{ext}")
        fig.savefig(path, format=ext, bbox_inches="tight",
                    dpi=dpi, pad_inches=0.05)
        paths.append(path)
        print(f"  -> {path}")

    # ── per-panel save (optional) ────────────────────────────────────
    if split_panels:
        main_axes = [ax for ax in fig.axes
                     if ax.get_subplotspec() is not None]

        if len(main_axes) <= 1:
            print(f"  (split_panels=True but figure has {len(main_axes)} "
                  f"main axis — skipping split)")
        else:
            _suffixes = panel_suffixes
            if _suffixes is None:
                _suffixes = [chr(ord("a") + i) for i in range(len(main_axes))]
            elif len(_suffixes) != len(main_axes):
                raise ValueError(
                    f"panel_suffixes has {len(_suffixes)} entries "
                    f"but figure has {len(main_axes)} axes")

            for ax, suffix in zip(main_axes, _suffixes):
                renderer = fig.canvas.get_renderer()
                bbox = ax.get_tightbbox(renderer=renderer)
                if ax.get_legend() is not None:
                    leg_bbox = ax.get_legend().get_window_extent(renderer)
                    bbox = bbox.union([bbox, leg_bbox])
                bbox_in = bbox.transformed(fig.dpi_scale_trans.inverted())
                bbox_in = bbox_in.expanded(1.02, 1.02)

                for ext in formats:
                    path = os.path.join(figures_dir, f"{name}_{suffix}.{ext}")
                    fig.savefig(path, format=ext, bbox_inches=bbox_in,
                                dpi=dpi, pad_inches=0.05)
                    paths.append(path)
                    print(f"  -> {path}")

    return paths


def save_for_latex(
    fig,
    name: str,
    figures_dir: str = "figures",
    formats: tuple = ("pdf", "png"),
    dpi: int = 300,
    strip_title: bool = True,
    split_panels: bool = False,
    panel_suffixes: list[str] | None = None,
    beamer: bool = True,
    beamer_suffix: str = "_beamer",
):
    """Save a figure for LaTeX inclusion in both serif and Beamer variants.

    Saves under ``{figures_dir}/{name}.{ext}`` for each requested format.
    PDF is vector and is what you pass to ``\\includegraphics{}``; PNG is
    a raster preview at the specified DPI.

    By default, axis titles and the suptitle are hidden before saving and
    restored afterwards, so that LaTeX can supply the caption via
    ``\\caption{}`` with proper typography and ``\\label{}`` support.
    Pass ``strip_title=False`` to bake the title into the file.

    Beamer variant
    --------------
    When ``beamer=True`` (default), a second set of files is written with
    ``{beamer_suffix}`` appended to the base name (e.g. ``gdp_beamer.pdf``).
    These are rendered with Latin Modern Sans — the default Beamer font —
    so that tick labels, axis labels, and legend text match slide body text
    when the figure is embedded via ``\\includegraphics{}``.  The original
    rcParams are fully restored after saving.

    Use the serif version (``gdp_by_country.pdf``) in papers and the Beamer
    version (``gdp_by_country_beamer.pdf``) in presentations::

        \\includegraphics{figures/gdp_by_country}        % paper
        \\includegraphics{figures/gdp_by_country_beamer} % slides

    If your Beamer theme uses ``\\usefonttheme{serif}`` or a custom fontspec
    font, set ``beamer=False`` and use the serif version for both.

    Args:
        fig:            matplotlib Figure
        name:           base filename — no extension, no spaces
        figures_dir:    output directory; created if it does not exist
        formats:        file extensions to write (default: pdf + png)
        dpi:            raster resolution; ignored for PDF (default: 300)
        strip_title:    hide titles before saving, restore after
        split_panels:   also save each subplot individually as
                        ``{name}_a.pdf``, ``{name}_b.pdf``, ... — useful
                        with the LaTeX ``subcaption`` package
        panel_suffixes: override default a/b/c/... labels for split panels;
                        length must equal the number of subplots
        beamer:         also write a sans-serif Beamer variant (default True)
        beamer_suffix:  suffix appended to ``name`` for Beamer files
                        (default ``"_beamer"``)

    Returns:
        List of file paths written (serif files first, then Beamer files).

    Example:
        save_for_latex(fig, "gdp_by_country", figures_dir="figures")
        # -> figures/gdp_by_country.pdf         (serif — for papers)
        # -> figures/gdp_by_country.png
        # -> figures/gdp_by_country_beamer.pdf  (sans — for slides)
        # -> figures/gdp_by_country_beamer.png

        save_for_latex(fig, "panel_fig", split_panels=True)
        # -> figures/panel_fig.pdf
        # -> figures/panel_fig_a.pdf
        # -> figures/panel_fig_b.pdf
        # -> figures/panel_fig_beamer.pdf
        # -> figures/panel_fig_beamer_a.pdf
        # -> figures/panel_fig_beamer_b.pdf

        save_for_latex(fig, "draft", beamer=False)
        # -> figures/draft.pdf   (serif only)
        # -> figures/draft.png
    """
    os.makedirs(figures_dir, exist_ok=True)

    # ── stash and strip titles ───────────────────────────────────────
    stashed = []
    if strip_title:
        if fig._suptitle is not None and fig._suptitle.get_text():
            stashed.append(("suptitle", fig._suptitle.get_text()))
            fig.suptitle("")
        for ax in fig.axes:
            t = ax.get_title()
            if t:
                stashed.append((ax, t))
                ax.set_title("")

    paths = []

    # ── serif save (paper) ───────────────────────────────────────────
    # Explicitly mark all text artists as serif so any previous beamer
    # call in the same session doesn't bleed through.
    _set_figure_fontfamily(fig, "serif")
    print(f"  [serif]")
    paths += _save_figure(fig, name, figures_dir, formats, dpi,
                          split_panels, panel_suffixes)

    # ── beamer save (sans-serif) ─────────────────────────────────────
    if beamer:
        # Snapshot only the keys we are about to change
        _saved_rc = {k: mpl.rcParams[k] for k in _BEAMER_SNAPSHOT_KEYS
                     if k in mpl.rcParams}
        try:
            mpl.rcParams.update(_BEAMER_FONT_OVERRIDES)
            # Invalidate the on-disk DVI cache and in-memory text-metrics
            # cache.  Matplotlib's TexManager hashes the TeX source to a
            # cache filename; if an earlier session compiled a string with
            # a different (or broken) preamble that happens to share inputs
            # with the current one, the stale .dvi can survive and trigger
            # `ValueError: state precondition failed` deep in dviread.
            # Wiping the cache here forces a fresh compile under the new
            # sans-serif preamble.  Cheap: a handful of LaTeX runs (~100ms
            # each) per save.
            _clear_tex_cache()
            # Mark every text artist — tick labels, axis labels, legend,
            # annotations — as sans-serif so the LaTeX backend re-compiles
            # them with the updated preamble (\sfdefault) on this save.
            _set_figure_fontfamily(fig, "sans-serif")
            print(f"  [beamer / sans-serif]")
            paths += _save_figure(fig, f"{name}{beamer_suffix}", figures_dir,
                                  formats, dpi, split_panels, panel_suffixes)
        finally:
            # Restore rcParams and reset all text artists to serif so the
            # figure is back to its original state in the caller's session.
            mpl.rcParams.update(_saved_rc)
            _set_figure_fontfamily(fig, "serif")

    # ── restore titles ───────────────────────────────────────────────
    if strip_title:
        for item in stashed:
            if item[0] == "suptitle":
                fig.suptitle(item[1])
            else:
                ax, title = item
                ax.set_title(title)

    return paths
