How it works

locate_glyphs.py puts a box on every mark an entry is said to print. This script cuts each box from the gold section image, embeds it, and names it by the glyphs it is nearest to in a bank of labelled glyphs — a check that shares neither architecture nor training signal with the language-model readers. It routes a claim and never overwrites one (D-38, D-55, D-69): its output is a second opinion per mark, and a disagreement is a reason for a second look.

The bank is the gold-placed glyphs of the calibration pages only (D-69), cut at printed size from entries, never from the legend plate. Each glyph is classified leave-page-out: a calibration page against the bank of the other seven, a purposive page against all eight. Reported for every encoder, cut and feature, 1-NN and 3-NN, per glyph type:

  • accuracy over every gold mark the locator placed;
  • a "not in the bank" answer: when the nearest neighbour is less similar than the threshold, the glyph is not named. The threshold for a page is the 5th percentile of the nearest-neighbour similarity of correctly named glyphs on the other calibration pages, so no page sets its own. A mark whose type the bank does not hold (a rare type printed on no other calibration page) should get it; a mark the bank does hold should not.

A mark is named in parts (1.1.0). The first run named whole tokens on a window round the box, and the box held the base alone: [school-exp] came back [school], [colony] [cottage-group]. Now the base is named on the base cut (the window with the brackets and letter the locator found beside it painted out) against a bank of bases — the bank's tokens taken apart, so a colony's block of four pools with [house-group]'s — the brackets by rule (both found: bracketed), the letter by 1-NN among the calibration pages' A / H crops, and only after a base the plate sets a letter after; then the token is composed from the plate's table. A combination the plate does not print, or a letter the bank cannot decide, is [not-in-legend]: routed, never forced. Reported beside the whole-token answer, per token, as before and after.

Encoders. DINOv3 ViT-B/16 is the encoder of record (D-91); ViT-S/16 runs beside it; plain 32 x 32 pixels are the floor, and run anywhere. Weights load from the local Hugging Face cache only unless --download is given — this laptop has none, Heavyhorse6 has them (notebooks/10_glyph_e3.ipynb). Embeddings are saved (embeddings_&lt;encoder&gt;_&lt;cut&gt;.npz), so a later analysis need not re-run the encoder.

Against the readers (--tag, default r5). For every reader pass on disk under output/lexikon_1910_pilot/bakeoff/&lt;host&gt;/ (Czech passes only; rate-limited passes skipped), the reader's own claims — the offices symbols and the parts' topographic marks — are placed by the same locator on the same images, each placed box is named by the encoder, and the reader's token is set beside the encoder's and beside the gold mark whose box it falls on. Per pass, in the terms of D-71: the reader's errors the encoder disagrees with (caught), those it agrees with (shared), true claims it disagrees with (alarms), and how often the encoder is right when the two disagree. Blind to: a mark the reader did not claim (it is never placed), and to a claim the locator could not place.

def cut(glyph: Glyph, image, variant: str):
    """One view of a placed glyph.

    ``tight``  the base's box, padded as the bank of test A was;
    ``window`` a square of WINDOW_LINES line heights on its centre — which takes
               the brackets of ``(Q)`` with it, and whatever else is near;
    ``base``   that window with every bracket and letter found beside the base
               painted paper white, so the base alone is named (D-93);
    ``letter`` the letter-shaped cluster after the base, padded (blank if none).
    """
    from PIL import ImageDraw
    from build_glyph_bank import PAD, WINDOW_LINES

    x0, y0, x1, y1 = glyph.box
    if variant == "tight":
        return crop_white(image, (x0 - PAD, y0 - PAD, x1 + PAD, y1 + PAD))
    if variant == "letter":
        if glyph.letter_box is None:
            return crop_white(image, (0, 0, 1, 1)).point(lambda _v: 255)
        a, b, c, d = glyph.letter_box
        return crop_white(image, (a - PAD, b - PAD, c + PAD, d + PAD))
    cx, cy = (x0 + x1) / 2, (y0 + y1) / 2
    half = int(WINDOW_LINES * glyph.lh / 2)
    left, top = int(cx) - half, int(cy) - half
    window = crop_white(image, (left, top, int(cx) + half, int(cy) + half))
    if variant == "base":
        pen = ImageDraw.Draw(window)
        for a, b, c, d in glyph.modifier_boxes:
            pen.rectangle((a - left - 1, b - top - 1, c - left + 1, d - top + 1), fill=255)
    return window

def crop_white(image, box):
    """``image.crop(box)``, but what falls outside the image is paper white, not
    the black PIL fills in — a glyph at the edge of a crop is not a glyph in a
    black frame."""
    from PIL import Image

    x0, y0, x1, y1 = (int(v) for v in box)
    out = Image.new("L", (max(1, x1 - x0), max(1, y1 - y0)), 255)
    inner = (max(0, x0), max(0, y0), min(image.width, x1), min(image.height, y1))
    if inner[2] > inner[0] and inner[3] > inner[1]:
        out.paste(image.crop(inner), (inner[0] - x0, inner[1] - y0))
    return out

def knn_vote(sims, tokens: list[str], k: int) -> tuple[str, float]:
    """The majority of the ``k`` most similar bank glyphs (a tie goes to the
    single nearest), and the similarity of the nearest."""
    import numpy as np

    if not len(sims):
        return NOT_IN_BANK, -1.0
    nearest = np.argsort(-sims)[:k]
    votes = Counter(tokens[b] for b in nearest)
    top = max(votes.values())
    winner = next(tokens[b] for b in nearest if votes[tokens[b]] == top)
    return winner, float(sims[nearest[0]])

def classify(query, query_pages: list[str], bank, bank_tokens: list[str],
             bank_pages: list[str], k: int) -> list[tuple[str, float]]:
    """``[(token, nearest similarity)]`` per query, each against the bank glyphs
    of every page but its own. Cosine similarity."""
    import numpy as np

    q, b = unit(query), unit(bank)
    sim = q @ b.T
    pages = np.array(bank_pages)
    out = []
    for i, page in enumerate(query_pages):
        keep = np.flatnonzero(pages != page)
        out.append(knn_vote(sim[i, keep], [bank_tokens[j] for j in keep], k))
    return out

def page_thresholds(results, truths: list[str], pages: list[str], roles: list[str],
                    quantile: float = ABSTAIN_QUANTILE) -> dict[str, float]:
    """For each page, the ``quantile`` of the nearest-neighbour similarity of the
    correctly named glyphs on the *other* calibration pages."""
    import numpy as np

    right = defaultdict(list)
    for (pred, s), t, p, r in zip(results, truths, pages, roles):
        if r == "calibration" and pred == t:
            right[p].append(s)
    out = {}
    for page in set(pages):
        pool = [s for q, ss in right.items() if q != page for s in ss]
        out[page] = float(np.quantile(pool, quantile)) if pool else -1.0
    return out

def evaluate(glyphs: list[Glyph], feats: dict, k_values=(1, 3)) -> tuple[list[dict], list[dict], dict]:
    """Per-glyph-type rows, per-query rows and the summary for one feature set."""
    bank_idx = [i for i, g in enumerate(glyphs) if g.role == "calibration"]
    truths = [g.token for g in glyphs]
    pages = [g.scan for g in glyphs]
    roles = [g.role for g in glyphs]
    bank_tokens = [truths[i] for i in bank_idx]
    bank_pages = [pages[i] for i in bank_idx]
    holds = bank_holds(truths, pages, bank_tokens, bank_pages)
    per_type, per_query, summary = [], [], {}
    for feature, x in feats.items():
        for k in k_values:
            raw = classify(x, pages, x[bank_idx], bank_tokens, bank_pages, k)
            thresholds = page_thresholds(raw, truths, pages, roles)
            named = with_abstain(raw, pages, thresholds)
            for g, (pred, s), (final, _s), h in zip(glyphs, raw, named, holds):
                per_query.append({"feature": feature, "k": k, "scan": g.scan, "role": g.role,
                                  "section": g.kind, "muni": g.muni, "order": g.order,
                                  "token": g.token, "in_bank": h, "nearest": pred,

            per_type += type_rows(feature, k, glyphs, raw, named, holds)
            summary[(feature, k)] = summarise_run(raw, named, truths, holds, roles)
    return per_type, per_query, summary

    rows = []
    by = defaultdict(list)
    for g, r, n, h in zip(glyphs, raw, named, holds):

def summarise_run(raw, named, truths, holds, roles) -> dict:
    def share(rows, test):
        return sum(1 for r in rows if test(r)) / len(rows) if rows else float("nan")

    rows = list(zip(raw, named, truths, holds, roles))
    held = [r for r in rows if r[3]]
    absent = [r for r in rows if not r[3]]
    return {
        "n": len(rows), "in_bank": len(held), "not_in_bank": len(absent),
        "accuracy_in_bank": share(held, lambda r: r[0][0] == r[2]),
        "accuracy_in_bank_calibration": share([r for r in held if r[4] == "calibration"],
                                              lambda r: r[0][0] == r[2]),
        "accuracy_in_bank_purposive": share([r for r in held if r[4] == "purposive"],
                                            lambda r: r[0][0] == r[2]),
        "abstain_in_bank": share(held, lambda r: r[1][0] == NOT_IN_BANK),
        "wrong_named_in_bank": share(held, lambda r: r[1][0] not in (r[2], NOT_IN_BANK)),
        "abstain_not_in_bank": share(absent, lambda r: r[1][0] == NOT_IN_BANK),
    }

def iou(a, b) -> float:
    x0, y0 = max(a[0], b[0]), max(a[1], b[1])
    x1, y1 = min(a[2], b[2]), min(a[3], b[3])
    inter = max(0, x1 - x0) * max(0, y1 - y0)
    union = (a[2] - a[0]) * (a[3] - a[1]) + (b[2] - b[0]) * (b[3] - b[1]) - inter
    return inter / union if union > 0 else 0.0

def composed_report(summary: dict, rows: list[dict], config: tuple, letters_by_encoder: dict,
                    glyphs: list[Glyph]) -> str:
    """Before (the whole token on test A's window) against after (named in parts)."""
    lines = ["the mark in parts (D-93): base on the `base` cut x brackets by rule x letter "
             f"on {LETTER_ENCODER}; before = the whole token on the `window` cut",
             f"  {'encoder':14s} {'feat':6s} k  {'all before':>10s} {'after':>6s} | composite "
             f"{'n':>3s} {'before':>6s} {'after':>6s} | not-in-legend"]
    for (name, feature, k), s in summary.items():
        lines.append(f"  {name:14s} {feature:6s} {k}  {s['before']:10.1%} {s['after']:6.1%} |"
                     f"           {s['n_composite']:3d} {s['before_composite']:6.1%} "
                     f"{s['after_composite']:6.1%} | {s['not_in_legend']}")
    name, _cut, feature, k = config
    lines.append(f"\n  composite tokens, {name} {feature} {k}-NN "
                 "(after = composed; base = base named right)")

            lines.append(f"    {r['token']:22s} {r['n']:3d} {r['before']:7.1%} {r['base_right']:6.1%} "
                         f"{r['after']:6.1%} {r['not_in_legend']:7d}")
    forms = lettered_forms()
    asked = [i for i, g in enumerate(glyphs) if g.letter_box is not None and g.base in forms]
    lettered = [i for i in asked if letter_label(glyphs[i]) != NO_LETTER]
    plain = [i for i in asked if letter_label(glyphs[i]) == NO_LETTER]
    lines.append(f"\n  letters (asked only after a base the plate letters; gold bases): "
                 f"{len(asked)} such marks with a letter-shaped cluster, {len(lettered)} "
                 f"lettered by the gold, {len(plain)} not")
    for enc, letters in letters_by_encoder.items():
        right = sum(letters[i] == letter_label(glyphs[i]) for i in lettered)
        false = sum(letters[i] not in ("", NO_LETTER) for i in plain)
        lines.append(f"    {enc:14s} letter right {right}/{len(lettered)}   "
                     f"a letter read where the gold has none {false}/{len(plain)}")
    return "\n".join(lines)

``locate_glyphs.py`` puts a box on every mark an entry is said to print. This
script cuts each box from the gold section image, embeds it, and names it by the
glyphs it is nearest to in a bank of labelled glyphs — a check that shares neither
architecture nor training signal with the language-model readers. It **routes a
claim and never overwrites one** (D-38, D-55, D-69): its output is a second
opinion per mark, and a disagreement is a reason for a second look.

**The bank** is the gold-placed glyphs of the **calibration** pages only (D-69),
cut at printed size from entries, never from the legend plate. Each glyph is
classified **leave-page-out**: a calibration page against the bank of the other
seven, a purposive page against all eight. Reported for every encoder, cut and
feature, 1-NN and 3-NN, per glyph type:

* accuracy over every gold mark the locator placed;
* a **"not in the bank" answer**: when the nearest neighbour is less similar than
  the threshold, the glyph is not named. The threshold for a page is the 5th
  percentile of the nearest-neighbour similarity of correctly named glyphs on the
  *other* calibration pages, so no page sets its own. A mark whose type the bank
  does not hold (a rare type printed on no other calibration page) should get it;
  a mark the bank does hold should not.

**A mark is named in parts** (1.1.0). The first run named whole tokens on a
window round the box, and the box held the base alone: ``[school-exp]`` came back

colony's block of four pools with ``[house-group]``'s — the brackets by rule

crops, and only after a base the plate sets a letter after; then the token is
composed from the plate's table. A combination the plate does not print, or a
letter the bank cannot decide, is ``[not-in-legend]``: routed, never forced.
Reported beside the whole-token answer, per token, as before and after.

@dataclass
class Glyph:
    """One placed claim: where it is and what the source says it is."""
    scan: str
    role: str
    kind: str
    district: str
    muni: int
    seq: str
    order: int
    token: str
    image: str
    box: tuple[int, int, int, int]
    lh: float
    sheet_dir: Path
    source: str = "gold"
    brackets: str = ""                       # both brackets found beside the base: their kind
    modifier_boxes: tuple = ()               # every bracket or letter box found beside it
    letter_box: tuple | None = None          # the letter-shaped cluster after it, if any

    @property
    def key(self) -> tuple:
        return (self.image, self.box)

    @property
    def base(self) -> str:
        return lg.base_of(self.token)


def glyph_at(section, cands, i: int, claim, lines, source: str = "gold") -> Glyph:
    """The claim placed on candidate ``i``, with what the token-blind search
    (:func:`locate_glyphs.modifiers`) found beside it."""
    c = cands[i]
    m = lg.modifiers(cands, i, lines)
    found = tuple(cands[j].box for j in (m.left, m.right, m.letter) if j is not None)
    return Glyph(section.scan, section.role, section.kind, section.district, claim.muni,
                 claim.seq, claim.order, claim.token, c.image, c.box, c.lh, section.sheet_dir,
                 source, m.brackets(cands), found,
                 cands[m.letter].box if m.letter is not None else None)


def placed_glyphs(located: dict, source: str = "gold") -> list[Glyph]:
    """Every placed claim of ``{key: (section, cands, placed)}`` as a :class:`Glyph`."""
    out = []
    for section, cands, placed in located.values():
        lines = lg.line_neighbours(cands)
        for cl in section.claims:
            i = placed[cl.order]
            if i is not None:
                out.append(glyph_at(section, cands, i, cl, lines, source))
    return out


def cut(glyph: Glyph, image, variant: str):
    """One view of a placed glyph.

    ``tight``  the base's box, padded as the bank of test A was;
    ``window`` a square of WINDOW_LINES line heights on its centre — which takes
               the brackets of ``(Q)`` with it, and whatever else is near;
    ``base``   that window with every bracket and letter found beside the base
               painted paper white, so the base alone is named (D-93);
    ``letter`` the letter-shaped cluster after the base, padded (blank if none).
    """
    from PIL import ImageDraw
    from build_glyph_bank import PAD, WINDOW_LINES

    x0, y0, x1, y1 = glyph.box
    if variant == "tight":
        return crop_white(image, (x0 - PAD, y0 - PAD, x1 + PAD, y1 + PAD))
    if variant == "letter":
        if glyph.letter_box is None:
            return crop_white(image, (0, 0, 1, 1)).point(lambda _v: 255)
        a, b, c, d = glyph.letter_box
        return crop_white(image, (a - PAD, b - PAD, c + PAD, d + PAD))
    cx, cy = (x0 + x1) / 2, (y0 + y1) / 2
    half = int(WINDOW_LINES * glyph.lh / 2)
    left, top = int(cx) - half, int(cy) - half
    window = crop_white(image, (left, top, int(cx) + half, int(cy) + half))
    if variant == "base":
        pen = ImageDraw.Draw(window)
        for a, b, c, d in glyph.modifier_boxes:
            pen.rectangle((a - left - 1, b - top - 1, c - left + 1, d - top + 1), fill=255)
    return window


def crop_white(image, box):
    """``image.crop(box)``, but what falls outside the image is paper white, not
    the black PIL fills in — a glyph at the edge of a crop is not a glyph in a
    black frame."""
    from PIL import Image

    x0, y0, x1, y1 = (int(v) for v in box)
    out = Image.new("L", (max(1, x1 - x0), max(1, y1 - y0)), 255)
    inner = (max(0, x0), max(0, y0), min(image.width, x1), min(image.height, y1))
    if inner[2] > inner[0] and inner[3] > inner[1]:
        out.paste(image.crop(inner), (inner[0] - x0, inner[1] - y0))
    return out


def cut_all(glyphs: list[Glyph], variant: str) -> list:
    """Squared cuts of every glyph, ready for an encoder (test A's ``square``)."""
    from PIL import Image
    from run_glyph_test_a import square

    cache: dict[Path, object] = {}
    out = []
    for g in glyphs:
        path = g.sheet_dir / g.image
        if path not in cache:
            cache[path] = Image.open(path).convert("L")
        out.append(square(cut(g, cache[path], variant)))
    return out


def embed(glyphs: list[Glyph], encoders: list[str], download: bool, cuts=CUTS) -> dict:
    """``{(encoder, cut): {feature: array}}`` for every encoder whose weights load."""
    from run_glyph_test_a import ENCODERS, encoder_features, pixel_features

    out = {}
    if not glyphs:
        return out
    for variant in cuts:
        images = cut_all(glyphs, variant)
        for name in encoders:
            model_id = ENCODERS[name]
            feats = (pixel_features(images) if model_id is None
                     else encoder_features(model_id, images, download))
            if feats:
                out[(name, variant)] = feats
    return out

# Nearest neighbours, leave-page-out
# --------------------------------------------------------------------------- #

def unit(x):
    import numpy as np

    x = np.asarray(x, dtype=np.float64)
    return x / np.linalg.norm(x, axis=1, keepdims=True).clip(1e-9)


def knn_vote(sims, tokens: list[str], k: int) -> tuple[str, float]:
    """The majority of the ``k`` most similar bank glyphs (a tie goes to the
    single nearest), and the similarity of the nearest."""
    import numpy as np

    if not len(sims):
        return NOT_IN_BANK, -1.0
    nearest = np.argsort(-sims)[:k]
    votes = Counter(tokens[b] for b in nearest)
    top = max(votes.values())
    winner = next(tokens[b] for b in nearest if votes[tokens[b]] == top)
    return winner, float(sims[nearest[0]])


def classify(query, query_pages: list[str], bank, bank_tokens: list[str],
             bank_pages: list[str], k: int) -> list[tuple[str, float]]:
    """``[(token, nearest similarity)]`` per query, each against the bank glyphs
    of every page but its own. Cosine similarity."""
    import numpy as np

    q, b = unit(query), unit(bank)
    sim = q @ b.T
    pages = np.array(bank_pages)
    out = []
    for i, page in enumerate(query_pages):
        keep = np.flatnonzero(pages != page)
        out.append(knn_vote(sim[i, keep], [bank_tokens[j] for j in keep], k))
    return out


def page_thresholds(results, truths: list[str], pages: list[str], roles: list[str],
                    quantile: float = ABSTAIN_QUANTILE) -> dict[str, float]:
    """For each page, the ``quantile`` of the nearest-neighbour similarity of the
    correctly named glyphs on the *other* calibration pages."""
    import numpy as np

    right = defaultdict(list)
    for (pred, s), t, p, r in zip(results, truths, pages, roles):
        if r == "calibration" and pred == t:
            right[p].append(s)
    out = {}
    for page in set(pages):
        pool = [s for q, ss in right.items() if q != page for s in ss]
        out[page] = float(np.quantile(pool, quantile)) if pool else -1.0
    return out


def with_abstain(results, pages: list[str], thresholds: dict[str, float]) -> list[tuple[str, float]]:
    """Below its page's threshold a glyph is not named: ``[not-in-bank]``."""
    return [(pred if s >= thresholds.get(p, -1.0) else NOT_IN_BANK, s)
            for (pred, s), p in zip(results, pages)]


def bank_holds(truths: list[str], pages: list[str], bank_tokens: list[str],
               bank_pages: list[str]) -> list[bool]:
    """Does the bank a query is classified against hold its true token at all?"""
    have = defaultdict(set)
    for t, p in zip(bank_tokens, bank_pages):
        have[t].add(p)
    return [bool(have.get(t, set()) - {p}) for t, p in zip(truths, pages)]


def evaluate(glyphs: list[Glyph], feats: dict, k_values=(1, 3)) -> tuple[list[dict], list[dict], dict]:
    """Per-glyph-type rows, per-query rows and the summary for one feature set."""
    bank_idx = [i for i, g in enumerate(glyphs) if g.role == "calibration"]
    truths = [g.token for g in glyphs]
    pages = [g.scan for g in glyphs]
    roles = [g.role for g in glyphs]
    bank_tokens = [truths[i] for i in bank_idx]
    bank_pages = [pages[i] for i in bank_idx]
    holds = bank_holds(truths, pages, bank_tokens, bank_pages)
    per_type, per_query, summary = [], [], {}
    for feature, x in feats.items():
        for k in k_values:
            raw = classify(x, pages, x[bank_idx], bank_tokens, bank_pages, k)
            thresholds = page_thresholds(raw, truths, pages, roles)
            named = with_abstain(raw, pages, thresholds)
            for g, (pred, s), (final, _s), h in zip(glyphs, raw, named, holds):
                per_query.append({"feature": feature, "k": k, "scan": g.scan, "role": g.role,
                                  "section": g.kind, "muni": g.muni, "order": g.order,
                                  "token": g.token, "in_bank": h, "nearest": pred,
                                  "similarity": round(s, 4), "named": final})
            per_type += type_rows(feature, k, glyphs, raw, named, holds)
            summary[(feature, k)] = summarise_run(raw, named, truths, holds, roles)
    return per_type, per_query, summary


def type_rows(feature: str, k: int, glyphs, raw, named, holds) -> list[dict]:
    rows = []
    by = defaultdict(list)
    for g, r, n, h in zip(glyphs, raw, named, holds):
        by[g.token].append((g, r, n, h))
    for token, group in sorted(by.items(), key=lambda kv: -len(kv[1])):
        n = len(group)
        right = sum(r[0] == g.token for g, r, _n, _h in group)
        abstain = sum(nn[0] == NOT_IN_BANK for _g, _r, nn, _h in group)
        right_named = sum(nn[0] == g.token for g, _r, nn, _h in group)
        rows.append({"feature": feature, "k": k, "token": token, "n": n,
                     "pages": len({g.scan for g, *_ in group}),
                     "in_bank": sum(h for *_x, h in group),
                     "accuracy": round(right / n, 4),
                     "abstain": round(abstain / n, 4),
                     "accuracy_when_named": round(right_named / max(n - abstain, 1), 4)})
    return rows


def summarise_run(raw, named, truths, holds, roles) -> dict:
    def share(rows, test):
        return sum(1 for r in rows if test(r)) / len(rows) if rows else float("nan")

    rows = list(zip(raw, named, truths, holds, roles))
    held = [r for r in rows if r[3]]
    absent = [r for r in rows if not r[3]]
    return {
        "n": len(rows), "in_bank": len(held), "not_in_bank": len(absent),
        "accuracy_in_bank": share(held, lambda r: r[0][0] == r[2]),
        "accuracy_in_bank_calibration": share([r for r in held if r[4] == "calibration"],
                                              lambda r: r[0][0] == r[2]),
        "accuracy_in_bank_purposive": share([r for r in held if r[4] == "purposive"],
                                            lambda r: r[0][0] == r[2]),
        "abstain_in_bank": share(held, lambda r: r[1][0] == NOT_IN_BANK),
        "wrong_named_in_bank": share(held, lambda r: r[1][0] not in (r[2], NOT_IN_BANK)),
        "abstain_not_in_bank": share(absent, lambda r: r[1][0] == NOT_IN_BANK),
    }

def name_bases(x, glyphs: list[Glyph], bank_x, bank: list[Glyph], k: int,
               thresholds: dict | None = None) -> list[tuple[str, float]]:
    """The base of each glyph by its neighbours among the bank's bases, leave-page-
    out, ``[not-in-bank]`` below the page's threshold. The bank's bases come from
    its tokens taken apart (``[colony]`` gives a ``[house-group]`` block)."""
    raw = classify(x, [g.scan for g in glyphs], bank_x, [g.base for g in bank],
                   [g.scan for g in bank], k)
    if thresholds is None:
        return raw
    return with_abstain(raw, [g.scan for g in glyphs], thresholds)


def letter_label(glyph: Glyph) -> str:
    """What the plate puts after this token's base: A, H, V — or none."""
    return lg.parts_of(glyph.token).letter or NO_LETTER


def lettered_forms(table: dict | None = None) -> dict[str, set]:
    """``base -> the letters the plate sets after it``: ``[rc-parish]`` A and H,
    ``[rc-vicariate]`` A and H, ``[doctor]`` V."""
    out: dict[str, set] = defaultdict(set)
    for parts in (lg.composites() if table is None else table).values():
        if parts.letter:
            out[parts.base].add(parts.letter)
    return dict(out)


def name_letters(x, glyphs: list[Glyph], bank_x, bank: list[Glyph],
                 bases: list[str] | None = None) -> list[str]:
    """The letter after each glyph's base: ``""`` where none is read.

    A letter is asked for only where it can change the token: the base named by
    the encoder (``bases``; the gold base when not given) is one the plate sets a
    letter after, and a letter-shaped cluster was found beside it. The answer is
    then one of that base's letters — the only one for ``[doctor]`` (V), the
    nearer of A and H by 1-NN among the calibration pages' A/H crops, leave-page-
    out, for the two crosses. A capital after any other base (``[school] II``,
    ``[cooperative]: R``) is not a letter of the mark. The choice rests on the
    encoder's base, never on the claim.
    """
    import numpy as np

    forms = lettered_forms()
    bases = [g.base for g in glyphs] if bases is None else bases
    keep = [i for i, g in enumerate(bank) if letter_label(g) != NO_LETTER]
    out = [""] * len(glyphs)
    for i, (g, base) in enumerate(zip(glyphs, bases)):
        allowed = forms.get(base, set())
        if g.letter_box is None or not allowed:
            continue
        if len(allowed) == 1:
            out[i] = next(iter(allowed))
            continue
        pool = [j for j in keep if letter_label(bank[j]) in allowed and bank[j].scan != g.scan]
        if {letter_label(bank[j]) for j in pool} != allowed:
            # the bank cannot tell these letters apart for this page (A is printed on
            # one calibration page, H on one): unread, which composes to no token
            out[i] = UNREAD_LETTER
            continue
        sims = (unit(np.asarray(x)[[i]]) @ unit(np.asarray(bank_x)[pool]).T)[0]
        out[i] = letter_label(bank[pool[int(np.argmax(sims))]])
    return out


def compose_names(glyphs: list[Glyph], bases: list[tuple[str, float]],
                  letters: list[str]) -> list[tuple[str, float]]:
    """Base x brackets x letter -> the plate's token, through
    :func:`locate_glyphs.compose`; an unknown base stays ``[not-in-bank]`` and a
    combination the plate does not print is ``[not-in-legend]``."""
    out = []
    for g, (base, s), letter in zip(glyphs, bases, letters):
        if base == NOT_IN_BANK:
            out.append((NOT_IN_BANK, s))
            continue
        out.append((lg.compose(base, g.brackets, "" if letter in ("", NO_LETTER) else letter), s))
    return out


def composed_rows(name: str, feature: str, k: int, glyphs: list[Glyph], before, after,
                  bases) -> list[dict]:
    """Per token: the whole-token answer (before) against the composed one (after)."""
    rows = []
    by = defaultdict(list)
    for g, b, a, bs in zip(glyphs, before, after, bases):
        by[g.token].append((g, b, a, bs))
    for token, group in sorted(by.items(), key=lambda kv: -len(kv[1])):
        n = len(group)
        parts = lg.parts_of(token)
        named = sum(a[0] != NOT_IN_BANK for _g, _b, a, _bs in group)
        rows.append({"encoder": name, "feature": feature, "k": k, "token": token, "n": n,
                     "pages": len({g.scan for g, *_ in group}),
                     "composite": parts != lg.Parts(token),
                     "before": round(sum(b[0] == token for _g, b, _a, _bs in group) / n, 4),
                     "base_right": round(sum(bs[0] == g.base for g, _b, _a, bs in group) / n, 4),
                     "after": round(sum(a[0] == token for _g, _b, a, _bs in group) / n, 4),
                     "after_named": round(sum(a[0] == token for _g, _b, a, _bs in group)
                                          / max(1, named), 4),
                     "not_in_legend": sum(a[0] == lg.NOT_IN_LEGEND for _g, _b, a, _bs in group)})
    return rows


def letter_rows(glyphs: list[Glyph], letters_by_encoder: dict) -> list[dict]:
    """How well each encoder names the letters after a lettered base, leave-page-out."""
    rows = []
    forms = lettered_forms()
    have = [i for i, g in enumerate(glyphs) if g.letter_box is not None and g.base in forms]
    for name, letters in letters_by_encoder.items():
        for label in ("A", "H", "V", NO_LETTER):
            group = [i for i in have if letter_label(glyphs[i]) == label]
            rows.append({"encoder": name, "letter": label, "n": len(group),
                         "right": sum(letters[i] == label for i in group)})
    return rows

def reader_passes(tag: str, hosts: str = "all") -> dict[str, Path]:
    """``label -> institutions_<label>.csv`` for every Czech pass of ``tag`` on
    disk (``hosts="all"``: every machine's directory; else a comma list).
    A rate-limited pass is skipped, as in ``bakeoff.passes_on_disk``."""
    if not BAKEOFF.exists():
        return {}
    dirs = sorted(d for d in BAKEOFF.iterdir() if d.is_dir())
    if hosts != "all":
        dirs = [d for d in dirs if d.name in set(hosts.split(","))]
    out: dict[str, Path] = {}
    for d in dirs:
        for path in sorted(d.glob("institutions_*.csv")):
            label = path.stem[len("institutions_"):]
            if f"_{tag}" not in label or label in out:
                continue
            if (d / f"ratelimit_{label}.json").exists():
                continue
            out[label] = path
    return out


def read_reader_claims(institutions: Path) -> dict[tuple, list[tuple]]:
    """``(page, district, kind) -> [(muni, seq, position, token)]`` in printed order:
    the pass's offices symbols (``institutions_<label>.csv``, bracketed codes
    only — one mark however large its count) and its parts' topographic marks
    (``parts_<label>.csv``, beside it)."""
    from utils.lexikon_1910 import lexikon_1910_notes as lxnt

    out: dict[tuple, list[tuple]] = defaultdict(list)
    with institutions.open(encoding="utf-8", newline="") as fh:
        for r in csv.DictReader(fh):
            code = (r.get("code") or "").strip()
            if not code.startswith("[") or code in lg.NOT_A_GLYPH:
                continue
            out[(r["page"].zfill(4), lxnt.normalise(r["district"]), "offices")].append(
                (int(r["muni_seq"]), str(r["settlement_seq"]), _int(r.get("position")), code))
    parts = institutions.with_name(institutions.name.replace("institutions_", "parts_", 1))
    if parts.exists():
        with parts.open(encoding="utf-8", newline="") as fh:
            for r in csv.DictReader(fh):
                code = (r.get("topographic") or "").strip()
                if not code.startswith("[") or code in lg.NOT_A_GLYPH:
                    continue
                out[(r["page"].zfill(4), lxnt.normalise(r["district"]), "parts")].append(
                    (int(r["muni_seq"]), str(r["settlement_seq"]), _int(r.get("position")), code))
    for key in out:
        out[key].sort(key=lambda c: (c[0], _int(c[1]), c[2]))
    return out


def _int(value) -> int:
    try:
        return int(float(value))
    except (TypeError, ValueError):
        return 0


def reader_sections(data, claims: dict) -> list[tuple]:
    """``[(section, cands, reader_claims)]``: each gold section with the pass's
    claims for its page, court and kind, in printed order. A muni the gold
    section does not print is dropped (it has no lines here)."""
    out = []
    for section, cands in data:
        mine = claims.get((section.scan, section.district, section.kind), [])
        listed = [lg.Claim(token, muni, seq, 0, "reader")
                  for muni, seq, _pos, token in mine if muni in section.printed]
        for n, cl in enumerate(listed):
            cl.order = n
        out.append((section, cands, listed))
    return out


def iou(a, b) -> float:
    x0, y0 = max(a[0], b[0]), max(a[1], b[1])
    x1, y1 = min(a[2], b[2]), min(a[3], b[3])
    inter = max(0, x1 - x0) * max(0, y1 - y0)
    union = (a[2] - a[0]) * (a[3] - a[1]) + (b[2] - b[0]) * (b[3] - b[1]) - inter
    return inter / union if union > 0 else 0.0


def gold_at(glyph: Glyph, gold: dict) -> str | None:
    """The gold token whose placed box is this box (IoU >= SAME_MARK_IOU), else
    ``None`` — the reader claims a mark where the gold places none."""
    best, token = 0.0, None
    for g in gold.get(glyph.image, []):
        o = iou(g.box, glyph.box)
        if o > best:
            best, token = o, g.token
    return token if best >= SAME_MARK_IOU else None


def dispute_rows(label: str, readers: list[Glyph], named: list[tuple], gold: dict) -> list[dict]:
    rows = []
    for g, (enc, s) in zip(readers, named):
        truth = gold_at(g, gold)
        rows.append({"pass": label, "scan": g.scan, "section": g.kind, "district": g.district,
                     "muni": g.muni, "seq": g.seq, "reader": g.token, "encoder": enc,
                     "similarity": round(s, 4), "gold": truth or "",
                     "image": g.image, "box": ",".join(map(str, g.box))})
    return rows


def score_pass(rows: list[dict]) -> dict:
    """D-71's terms, over the reader claims whose box carries a gold mark."""
    judged = [r for r in rows if r["gold"]]
    wrong = [r for r in judged if r["reader"] != r["gold"]]
    right = [r for r in judged if r["reader"] == r["gold"]]
    disputes = [r for r in judged if r["encoder"] not in (r["reader"], NOT_IN_BANK)]
    return {
        "claims": len(rows), "judged": len(judged),
        "no_gold_mark_there": len(rows) - len(judged),
        "reader_errors": len(wrong),
        "caught": sum(r["encoder"] not in (r["reader"], NOT_IN_BANK) for r in wrong),
        "shared": sum(r["encoder"] == r["reader"] for r in wrong),
        "errors_unnamed": sum(r["encoder"] == NOT_IN_BANK for r in wrong),
        "alarms": sum(r["encoder"] not in (r["reader"], NOT_IN_BANK) for r in right),
        "true_unnamed": sum(r["encoder"] == NOT_IN_BANK for r in right),
        "disputes": len(disputes),
        "encoder_right_in_dispute": sum(r["encoder"] == r["gold"] for r in disputes),
    }


UNCLAIMED = "[unclaimed]"
#: A detected mark overlapping a placed claim's box by this much is that claim's.
CLAIMED_OVERLAP = 0.3


def unclaimed_marks(cands: list, placed: list, detection, key: str) -> list[int]:
    """The clusters the token-blind detector calls marks that no claim was placed
    on, nor on anything beside a placed base (its brackets, its letter)."""
    lines = lg.line_neighbours(cands)
    taken = [i for i in placed if i is not None]
    covered = []
    for i in taken:
        m = lg.modifiers(cands, i, lines)
        covered.append(m.box(cands, i))
        if m.letter is not None:
            covered.append(cands[m.letter].box)
    out = []
    for i in detection.marks(key):
        if i in taken:
            continue
        if any(iou(cands[i].box, b) >= CLAIMED_OVERLAP or _inside(cands[i].box, b) for b in covered):
            continue
        out.append(i)
    return out


def _inside(a, b) -> bool:
    return a[0] >= b[0] and a[1] >= b[1] and a[2] <= b[2] and a[3] <= b[3]


def file_under(section, cands: list, placed: list, claims: list, i: int) -> tuple[int, str] | None:
    """The entry an unclaimed mark belongs to, from the reader's own structure:
    that of the nearest placed claim before it in reading order, else after it."""
    rank = {name: n for n, name in enumerate(section.images)}
    where = lambda c: (rank.get(c.image, 0), c.line, c.box[0])          # noqa: E731
    marks = sorted((where(cands[placed[cl.order]]), cl.muni, cl.seq)
                   for cl in claims if placed[cl.order] is not None)
    if not marks:
        return None
    me = where(cands[i])
    before = [m for m in marks if m[0] <= me]
    pick = before[-1] if before else marks[0]
    return pick[1], pick[2]


def verdict_of(claim: str, name: str) -> str:
    if name == NOT_IN_BANK:
        return "not-in-bank"
    if name == lg.NOT_IN_LEGEND:
        return "not-in-legend"
    return "agree" if name == claim else "disagree"


def section_glyphs(section, cands, claims, placed, detection, source: str) -> tuple[list, list, list]:
    """``(placed claims, unplaced claims, unclaimed marks)`` of one section as
    :class:`Glyph` (the unplaced ones as claims only)."""
    lines = lg.line_neighbours(cands)
    on = [glyph_at(section, cands, placed[cl.order], cl, lines, source)
          for cl in claims if placed[cl.order] is not None]
    off = [cl for cl in claims if placed[cl.order] is None]
    extra = []
    if detection is not None:
        for n, i in enumerate(unclaimed_marks(cands, placed, detection, section.key)):
            entry = file_under(section, cands, placed, claims, i)
            muni, seq = entry if entry else (0, "")
            extra.append(glyph_at(section, cands, i, lg.Claim(UNCLAIMED, muni, seq, -1 - n, source),
                                  lines, source))
    return on, off, extra


def verdict_rows(label: str, section_of: dict, on: list, named_on: list, off: list,
                 extra: list, named_extra: list, gold: dict) -> list[dict]:
    """One row for every mark: each claim (agree / disagree / not-in-bank /
    not-in-legend / unplaced) and each unclaimed mark (``unclaimed``)."""
    def row(g, claim, name, s, verdict):
        return {"pass": label, "scan": g.scan, "section": g.kind, "district": g.district,
                "muni": g.muni, "seq": g.seq, "claim": claim, "dino": name,
                "similarity": round(s, 4), "verdict": verdict,
                "gold": (gold_at(g, gold) or "") if g.image else "",
                "image": g.image, "box": ",".join(map(str, g.box)) if g.image else ""}
    rows = [row(g, g.token, name, s, verdict_of(g.token, name)) for g, (name, s) in zip(on, named_on)]
    for section, cl in off:
        rows.append({"pass": label, "scan": section.scan, "section": section.kind,
                     "district": section.district, "muni": cl.muni, "seq": cl.seq,
                     "claim": cl.token, "dino": "", "similarity": "", "verdict": "unplaced",
                     "gold": "", "image": "", "box": ""})
    rows += [row(g, "", name, s, "unclaimed") for g, (name, s) in zip(extra, named_extra)]
    return rows


def score_unclaimed(rows: list[dict]) -> dict:
    """The unclaimed flags: a gold mark under one is a mark the reader missed or
    placed elsewhere (caught); none is an alarm."""
    flags = [r for r in rows if r["verdict"] == "unclaimed"]
    real = [r for r in flags if r["gold"]]
    return {"unclaimed_flags": len(flags), "unclaimed_real": len(real),
            "unclaimed_named_right": sum(r["dino"] == r["gold"] for r in real),
            "unclaimed_alarms": len(flags) - len(real),
            "agree": sum(r["verdict"] == "agree" for r in rows),
            "disagree": sum(r["verdict"] == "disagree" for r in rows),
            "unnamed": sum(r["verdict"] in ("not-in-bank", "not-in-legend") for r in rows)}


def score_readers(data, locators: dict, tag: str, hosts: str, gold_glyphs: list[Glyph],
                  config: tuple, encoders_feats_fn, detection=None) -> tuple[list[dict], list[dict], list[dict]]:
    """Every pass of ``tag``: place its claims, find the marks it did not claim,
    name every box, and give every mark a verdict scored against the gold."""
    passes = reader_passes(tag, hosts)
    if not passes:
        return [], [], []
    gold: dict[str, list[Glyph]] = defaultdict(list)
    for g in gold_glyphs:
        gold[g.image].append(g)
    summary, disputes, verdicts = [], [], []
    for label, path in passes.items():
        claims = read_reader_claims(path)
        on, off, extra, in_sections = [], [], [], 0
        for section, cands, listed in reader_sections(data, claims):
            if not listed or not cands:
                continue
            in_sections += len(listed)
            # token-aware: a fill-pair error keeps its box (locator_stability.csv);
            # the claim looks for its base, and what stands beside it is found blind
            placed = locators[section.scan].place(cands, listed)
            a, b, c = section_glyphs(section, cands, listed, placed, detection, label)
            on += a
            off += [(section, cl) for cl in b]
            extra += c
        n_claims = sum(len(v) for v in claims.values())
        named = encoders_feats_fn(on + extra, config)
        named_on, named_extra = named[:len(on)], named[len(on):]
        rows = dispute_rows(label, on, named_on, gold)
        disputes += [r for r in rows if r["encoder"] != r["reader"]]
        mine = verdict_rows(label, {}, on, named_on, off, extra, named_extra, gold)
        verdicts += mine
        # a claim nothing in its entry looks like is left unplaced — itself a
        # reason for a second look, though not one this encoder can name
        summary.append({"pass": label, "config": "/".join(map(str, config)),
                        "claims_on_disk": n_claims, "in_gold_sections": in_sections,
                        "placed": len(on), "unplaced": len(off),
                        **score_pass(rows), **score_unclaimed(mine)})
    return summary, disputes, verdicts

def report(summary: dict, per_type: list[dict]) -> str:
    lines = [f"{'encoder':14s} {'cut':6s} {'feat':6s} k  {'n':>5s} {'acc':>6s} "

    for (name, variant, feature, k), s in summary.items():
        lines.append(f"{name:14s} {variant:6s} {feature:6s} {k}  {s['in_bank']:5d} "
                     f"{s['accuracy_in_bank']:6.1%} {s['accuracy_in_bank_calibration']:6.1%} "
                     f"{s['accuracy_in_bank_purposive']:6.1%} {s['abstain_in_bank']:6.1%} "
                     f"{s['wrong_named_in_bank']:6.1%} |             {s['not_in_bank']:4d} "
                     f"{s['abstain_not_in_bank']:6.1%}")
    return "\n".join(lines)
