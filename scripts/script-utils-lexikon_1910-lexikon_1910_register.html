How it works

register_places one row per register municipality (settlement_seq 0) or part, with its printed names, court, okres and the settlement_id of settlements_1910 it anchors to (nullable), with score and status; register_institutions place × mark: count, source (pictogram / text), the claim's rule, who settled it, and each mark's common category (D-147); register_cooperatives place × cooperative letter × language letter, the bare letter its own value, "not stated" — never Czech (D-146); register_municipalities one row per anchored 1910 municipality (settlement_id): counts by category, by mark, cooperatives by kind and language, and how many claims were disputed or author-ruled. Built from the three long tables by build_municipalities, nothing else.

Beside them, register_columns.csv names the value each of the municipal table's spread columns counts (spread_columns): a name is the value's ASCII stem, plus a short hash where two values share a stem (Gymn. and gymn.), so every name is unique (B1).

Where the names are

The run folder holds claims only. The names are in the readers' pass files (bake-off folders, bakeoff.find_pass_file): the table reader's rows (channel A, row 0 = the municipality, row k = part k; every edition since the German table reader, 1.2.0, D-160, whose district totals name no place and whose carried-over parts continue the municipality of the page before) and the reader of record's parts list (every edition; the named components of each part, each with its type). Every place takes its table name where there is one; else (a German run read before D-160, and any row the table reader missed) every component printed as a village, town or market town, else a hamlet-like one (NAME_TYPE_TIERS; the list is alphabetical, so the first line is not the place). A municipality with numbered parts and no table read prints no name on any list a reader wrote; it is anchored through its parts (via_parts).

How a place is anchored

Through lexikon_1910_names — build_authority with every status (a part is mostly an osada) and anchor_blocks — against the settlements of the okres of the section's 1910 court (courts.csv, D-122): similarity ≥ 84, the best beating the runner-up by 5, ties refused, one settlement per place per okres (municipalities and parts each). A tie at okres level is retried among the settlements whose coordinate lies in the section's own court: the court is evidence the entry carries, so the retry breaks the tie on the record, not on lookup order (D-22). The Polish part of Těšín Silesia is not in the ČSÚ lexikon: okres Bílsko has no settlement at all (outside_authority), and in the split okresy Těšín and Fryštát an unanchored place is counted apart, since it may be Polish or misread.

def row_figures(row: dict | None) -> dict:
    """One table row's figures (``FIGURES``) and ``figures_check``.

    A row is read when its ``pop_total`` is a number above 0; then an empty cell is a printed
    zero, and the area of a part (never printed) is ``<NA>``. A row not read, a cell not a number
    and a column the volume does not print are all ``<NA>``. ``figures_check`` names the identities
    that fail (``sex``, ``confession``, ``language``), ``""`` where all hold, ``unchecked`` where a
    figure in one is ``<NA>``, ``not read`` with no population."""
    row = row or {}
    total = cell_number(row["pop_total"]) if "pop_total" in row else None
    read = bool(total)
    out = {}
    for col in FIGURES:
        value = cell_number(row[col]) if col in row else None
        out[col] = value if value is not None and read and (value or col != "area_ha") else pd.NA
    if not read:
        return {**out, "figures_check": "not read"}
    failed, unchecked = [], False
    for name, parts in IDENTITIES:
        present = [p for p in parts if p in row]
        if any(pd.isna(out[p]) for p in present):
            unchecked = True
        elif sum(out[p] for p in present) != total:
            failed.append(name)
    return {**out, "figures_check": ", ".join(failed) or ("unchecked" if unchecked else "")}

def walking_hours(text) -> float | None:
    """``"1 3/4"`` → 1.75, ``"2"`` → 2.0, ``"¾"`` → 0.75, ``"1¹/₄"`` → 1.25; ``None`` where no
    distance is printed."""
    import unicodedata

    total, seen = 0.0, False
    text = re.sub(r"(?<=\d)(?=[⁰¹²³⁴⁵⁶⁷⁸⁹])", " ", str(text or ""))           # 1¹/₄ → 1 ¹/₄
    text = unicodedata.normalize("NFKC", text).replace("⁄", "/")                # ¹/₄ → 1/4
    for tok in re.findall(r"\d+/\d+|\d+|[¼½¾⅓⅔⅛]", text):
        if "/" in tok:
            num, den = (int(x) for x in tok.split("/"))
            if not den:
                return None
            total += num / den
        else:
            total += FRACTIONS[tok] if tok in FRACTIONS else int(tok)
        seen = True
    return round(total, 3) if seen else None

def legend_items(text) -> list[tuple[str, float | None]]:
    """A legend entry as ``[(place, hours)]``: ``"Steindlhammer 1¹/₄, Rosen- berg an der Moldau

def anchor_places(places: pd.DataFrame, authority: lxn.Authority,
                  parents: dict | None = None) -> pd.DataFrame:
    """Add ``settlement_id``, ``anchor_score``, ``anchor_runner_up`` and ``anchor_status``.

    ``parents`` maps a settlement_id to its 1910 parent commune (``settlements_1910.parent_1910``)
    for the ``via_parts`` step. Statuses: matched · matched_court · via_parts (anchored) and
    ambiguous · unmatched · parts_disagree · no_name · no_court · outside_authority (not).
    """
    out = places.copy().reset_index(drop=True)
    res: dict[int, tuple] = {}
    for okres, grp in out.groupby("okres_id", dropna=False):
        cands = authority.okres(int(okres)) if pd.notna(okres) else []
        for level, sub in grp.groupby("place_level"):
            named = sub[sub["printed_name"] != ""]
            for i in sub.index.difference(named.index):
                res[i] = (None, 0, 0, "no_name")
            if pd.isna(okres):
                res.update({i: (None, 0, 0, "no_court") for i in named.index})
                continue
            pool = [o for o in cands if level == "part" or o.status == "obec"]
            if not pool:

def spread_names(values, prefix: str, universe=()) -> dict[str, str]:
    """``{value: column}`` for the values one spread column takes (B1): ``prefix`` + the value's
    stem (:func:`_slug`), and where two different values share a stem — ``Gymn.`` and

    """The register's population against the 1910 census, per pooled okres (``census_okres_id``,
    D-18). ``coverage`` is the share of the okres's municipalities (``settlements_1910``, status
    obec) the register anchored; ``graded`` only where it is 1 and every one has a population read,
    since a partial okres under-sums by construction. Both sides descend from one enumeration, so
    agreement validates the reading, never the census (``lexikon_1910_census``)."""
    final_dir = Path(final_dir)
    settle = pd.read_parquet(final_dir / "geo" / "settlements_1910.parquet")
    cw = pd.read_csv(final_dir / "geo" / "okres_census_crosswalk.csv")
    census = pd.read_parquet(final_dir / "census" / "census_okres_1910_pooled.parquet")

    obce = settle[settle["status_1910"] == "obec"].assign(
        census_okres_id=lambda d: d["okres_id"].map(pooled))
    known = obce.groupby("census_okres_id")["settlement_id"].nunique()
    muni = tables["register_municipalities"]
    mine = muni[muni["settlement_id"].isin(obce["settlement_id"])].merge(
        obce[["settlement_id", "census_okres_id"]], on="settlement_id", how="left", validate="1:1")
    got = mine.groupby("census_okres_id").agg(anchored=("settlement_id", "nunique"),
                                              pop_read=("pop_total", lambda s: int(s.notna().sum())),
                                              register_pop=("pop_total", lambda s: s.sum(min_count=1)))
    out = got.join(known.rename("known")).join(
        census.set_index("census_okres_id")[["okres_cs", "pop_total"]].rename(columns={"pop_total": "census_pop"}))
    out["coverage"] = (out["anchored"] / out["known"]).round(3)
    out["graded"] = (out["anchored"] == out["known"]) & (out["pop_read"] == out["anchored"])
    out["diff"] = (out["register_pop"] - out["census_pop"]).where(out["graded"])
    return out.reset_index()

"""lexikon_1910_register — the 1910 register's frozen-run output as analysis-ready municipal data
==============================================================================================
A frozen run (``output/frozen/<edition>_<pages>/``, notebook 15) settles what the register
prints for each part of each municipality — the institution pictograms (``final_inventory.csv``),
and, where the run wrote one, the text abbreviations and cooperative letters
(``final_abbreviations.csv``) — keyed ``(page, district/court_id, muni_seq, settlement_seq)``.
It carries no place name and no link to anything outside the book. This module adds both and
writes four normalised tables to ``data/final/register/`` (D-148):

``register_places``          one row per register municipality (``settlement_seq`` 0) or part,
                             with its printed names, court, okres and the ``settlement_id`` of
                             ``settlements_1910`` it anchors to (nullable), with score and status;
``register_institutions``    place × mark: count, source (pictogram / text), the claim's rule,
                             who settled it, and each mark's common category (D-147);
``register_cooperatives``    place × cooperative letter × language letter, the bare letter its
                             own value, "not stated" — never Czech (D-146);
``register_municipalities``  one row per anchored 1910 municipality (``settlement_id``): counts by
                             category, by mark, cooperatives by kind and language, and how many
                             claims were disputed or author-ruled. Built from the three long
                             tables by :func:`build_municipalities`, nothing else.

Beside them, ``register_columns.csv`` names the value each of the municipal table's spread
columns counts (:func:`spread_columns`): a name is the value's ASCII stem, plus a short hash
where two values share a stem (``Gymn.`` and ``gymn.``), so every name is unique (B1).

Where the names are
-------------------
The run folder holds claims only. The names are in the readers' pass files (bake-off folders,
:func:`bakeoff.find_pass_file`): the **table reader**'s rows (channel A, row 0 = the
municipality, row *k* = part *k*; every edition since the German table reader, 1.2.0, D-160,
whose district totals name no place and whose carried-over parts continue the municipality of
the page before) and the **reader of record**'s parts list (every edition; the named components
of each part, each with its type). Every place takes its table name where there is one; else (a
German run read before D-160, and any row the table reader missed) every component printed as a
village, town or market town, else a hamlet-like one (:data:`NAME_TYPE_TIERS`; the list is
alphabetical, so the first line is not the place). A municipality with numbered parts and no
table read prints no name on any list a reader wrote; it is anchored through its parts
(``via_parts``).

How a place is anchored
-----------------------
Through :mod:`lexikon_1910_names` — :func:`build_authority` with every status (a part is mostly

def parse_run_name(run_dir) -> tuple[str, str]:
    """``(edition, pages)`` off a run folder name: ``de-bohemia_gold`` → ``("de-bohemia", "gold")``."""
    name = Path(run_dir).name
    for edition in sorted(EDITION_LAND, key=len, reverse=True):
        if name.startswith(edition + "_"):
            return edition, name[len(edition) + 1:]
    raise ValueError(f"{name!r} is not an <edition>_<pages> run folder ({sorted(EDITION_LAND)})")


def _read(path: Path) -> pd.DataFrame:
    return pd.read_csv(path, dtype=str, keep_default_na=False, encoding="utf-8")


def name_source_paths(edition: str, pages: str) -> tuple[Path | None, Path | None]:
    """``(parts list, table rows)`` of the run's reader of record, wherever the pass files are."""
    import bakeoff as bo
    import run_frozen as rf

    labels = rf.labels(pages, edition)
    table_label = next(iter(labels["table"]), None)
    return (bo.find_pass_file("parts", labels["gemini"]),
            bo.find_pass_file("table_rows", table_label) if table_label else None)


def load_run(run_dir, parts: pd.DataFrame | None = None,
             table: pd.DataFrame | None = None) -> RunInput:
    """Read a run folder; the name lists are found from its label unless passed in."""
    run_dir = Path(run_dir)
    edition, pages = parse_run_name(run_dir)
    if parts is None or table is None:
        parts_path, table_path = name_source_paths(edition, pages)
        parts = _read(parts_path) if parts is None and parts_path else parts
        table = _read(table_path) if table is None and table_path else table
    abbrev = run_dir / "final_abbreviations.csv"
    courts = run_dir / "courts.csv"
    legend_path, attributes_path = record_extra_paths(edition, pages)
    return RunInput(run=run_dir.name, edition=edition, pages=pages,
                    inventory=_read(run_dir / "final_inventory.csv"),
                    abbreviations=_read(abbrev) if abbrev.exists() else None,
                    courts=_read(courts) if courts.exists() else pd.DataFrame(
                        columns=["page", "district", "court_id", "court_cs"]),
                    parts=parts if parts is not None else pd.DataFrame(),
                    table=table if table is not None else pd.DataFrame(),
                    legend=_read(legend_path) if legend_path else None,
                    attributes=_read(attributes_path) if attributes_path else None)


def record_extra_paths(edition: str, pages: str) -> tuple[Path | None, Path | None]:
    """``(legend, attributes)`` of the run's reader of record: the post and station legend the

def _label(district) -> str:
    """A section's label as ``courts.csv`` writes it (``lexikon_1910_notes.normalise``)."""
    from utils.lexikon_1910 import lexikon_1910_notes as lxnt
    return lxnt.normalise(district)


def court_key(court_id, district) -> str:
    """The section key: its 1910 court id, else ``unresolved:<label>`` (pairs only with itself)."""
    court = str(court_id or "").strip()
    return court if court.isdigit() else f"unresolved:{_label(district)}"


def clean_display(name) -> str:
    """A printed name cell without its leaders, symbols, footnote marks, a cross-reference to the
    section that prints the part (``Bor . odd. viz``) and stray single letters at its end."""
    text = re.sub(r"\s*\.?\s*odd\.\s*viz\b.*$", "", str(name or ""))
    text = re.sub(r"\.{2,}|(?<=\s)\.(?=\s|$)|\*\)|\d+\)", " ", text)
    text = "".join(c if c.isalpha() or c in " ,.-'’" else " " for c in text)
    text = re.sub(r"(\s\w)+\s*$", "", re.sub(r"\s+", " ", text).strip(" ,.-"))
    return text.strip(" ,.-")


class _Units:
    """The places of one run, keyed ``(court_key, muni_seq, settlement_seq)``."""

    def __init__(self, run: RunInput):
        self.run = run
        self.court_of = {(str(r["page"]).zfill(4), r["district"]): r["court_id"]
                         for _, r in run.courts.iterrows()}
        self.court_cs = {r["court_id"]: r.get("court_cs", "") for _, r in run.courts.iterrows()}
        self.places: dict[tuple, dict] = {}

    def key(self, page, district, court_id="") -> str:
        page = str(page).zfill(4)
        court = court_id or self.court_of.get((page, _label(district)), "")
        return court_key(court, district)

    def add(self, ck: str, muni, seq, page, district) -> dict | None:
        if not str(muni).isdigit() or not str(seq or "0").isdigit():
            return None
        place = self.places.setdefault((ck, int(muni), int(seq or 0)), {
            "pages": set(), "district": district, "table_name": "", "components": [], "row": None})
        place["pages"].add(str(page).zfill(4))
        return place


def _add_claim_units(units: _Units, frame: pd.DataFrame | None) -> None:
    for _, r in (frame if frame is not None else pd.DataFrame()).iterrows():
        ck = units.key(r["page"], r["district"], r.get("court_id", ""))
        units.add(ck, r["muni_seq"], r["settlement_seq"], r["page"], r["district"])
        units.add(ck, r["muni_seq"], 0, r["page"], r["district"])


def _add_parts_list(units: _Units, parts: pd.DataFrame) -> None:
    for _, r in parts.iterrows():
        ck = units.key(r["page"], r["district"])
        place = units.add(ck, r["muni_seq"], r["settlement_seq"], r["page"], r["district"])
        units.add(ck, r["muni_seq"], 0, r["page"], r["district"])
        if place is not None:
            pos = int(r["position"]) if str(r.get("position", "")).isdigit() else 99
            place["components"].append((pos, r["part_name"], r.get("topographic", "")))


def _table_court(units: _Units, page: str, muni: int, label: str) -> str | None:
    """The section a table row belongs to: its own label where ``courts.csv`` knows it, else the
    page's only court (the label may be misread: ``Cliabarovice``), else the page's one court
    whose municipalities include this number. ``None``: ambiguous, skipped."""
    if label and (page, _label(label)) in units.court_of:
        return units.key(page, label)
    on_page = {c for (p, _d), c in units.court_of.items() if p == page}
    if len(on_page) == 1:
        return court_key(next(iter(on_page)), "")
    holding = {ck for (ck, m, _s), pl in units.places.items() if m == muni and page in pl["pages"]}
    return next(iter(holding)) if len(holding) == 1 else None


def _page_number(page) -> int | None:
    text = str(page).strip()
    return int(text) if text.isdigit() else None


def _add_table_rows(units: _Units, table: pd.DataFrame) -> int:
    """Channel A of the table reader: row 0 names the municipality, rows 1… its parts. A row
    whose number is not the next part's but a later municipality's starts that municipality
    (the reader merged two blocks). Returns how many rows could not be placed.

    The German reader (D-160) also reads blocks that open no municipality (``block_kind``): a
    district total, which names no place and is skipped, and the parts a page carries over,
    which continue the municipality the previous block opened — only where that block is on
    the page before (A12). After a gap in the pages read (a drawn sample: Schlesien 0043 follows
    0033) the municipality they continue was never read, and their rows count as unplaced."""
    if table.empty or "channel" not in table:
        return 0
    skipped = 0
    rows = table[table["channel"] == "A"]
    muni, expected, last_page = None, 1, None
    for _block, block in rows.groupby("block_id", sort=False):
        kind = str(block["block_kind"].iloc[0]) if "block_kind" in block else "municipality"
        page = _page_number(block["page"].iloc[0])
        follows = None not in (page, last_page) and page == last_page + 1
        last_page = page
        if kind == "summary":
            continue
        if kind != "continued" or not follows:
            muni, expected = None, 1
        for _, r in block.iterrows():
            seq = str(r["seq"]).strip()
            if not seq.isdigit():
                skipped += 1
                continue
            n, page = int(seq), str(r["page"]).zfill(4)
            opens = str(r["row"]) == "0" and kind != "continued"
            if opens or (muni is not None and n != expected and n > muni):
                muni, expected, part = n, 1, 0
            elif muni is not None and n == expected:
                part, expected = n, expected + 1
            else:
                skipped += 1
                continue
            ck = _table_court(units, page, muni, r.get("court_label", ""))
            place = units.add(ck, muni, part, page, r.get("court_label", "")) if ck else None
            if place is None:
                skipped += 1
                continue
            units.add(ck, muni, 0, page, r.get("court_label", ""))
            place["table_name"] = place["table_name"] or clean_display(r["name"])
            if place["row"] is None:                   # its figures: the first row that names it
                place["row"] = {**r.to_dict(), "page": page}
    return skipped


def _printed_name(seq: int, place: dict) -> tuple[str, str]:
    """``(name cell, source)`` for one place (see the module docstring)."""
    if place["table_name"]:
        return place["table_name"], "table"
    typed = [c for c in sorted(place["components"])           # a line with no type is a misread
             if str(c[2]).startswith("[") and c[1] != "&"]     # (offices text in the name cell)
    if not typed:
        return "", "none"
    for tier in NAME_TYPE_TIERS:
        named = [clean_display(c[1]) for c in typed if c[2] in tier]
        if named:
            return ", ".join(named), "parts"
    return clean_display(typed[0][1]), "parts"

def cell_number(cell) -> int | None:
    """A printed figure: an int, ``0`` for a cell printed empty (nothing, a dot, a dash), ``None``
    for a cell that is not a number (a misread)."""
    text = re.sub(r"[\s  ']", "", "" if cell is None else str(cell))
    if text.lower() in BLANK_CELLS:
        return 0
    return int(text) if text.isdigit() else None


def row_figures(row: dict | None) -> dict:
    """One table row's figures (``FIGURES``) and ``figures_check``.

    A row is read when its ``pop_total`` is a number above 0; then an empty cell is a printed
    zero, and the area of a part (never printed) is ``<NA>``. A row not read, a cell not a number
    and a column the volume does not print are all ``<NA>``. ``figures_check`` names the identities
    that fail (``sex``, ``confession``, ``language``), ``""`` where all hold, ``unchecked`` where a
    figure in one is ``<NA>``, ``not read`` with no population."""
    row = row or {}
    total = cell_number(row["pop_total"]) if "pop_total" in row else None
    read = bool(total)
    out = {}
    for col in FIGURES:
        value = cell_number(row[col]) if col in row else None
        out[col] = value if value is not None and read and (value or col != "area_ha") else pd.NA
    if not read:
        return {**out, "figures_check": "not read"}
    failed, unchecked = [], False
    for name, parts in IDENTITIES:
        present = [p for p in parts if p in row]
        if any(pd.isna(out[p]) for p in present):
            unchecked = True
        elif sum(out[p] for p in present) != total:
            failed.append(name)
    return {**out, "figures_check": ", ".join(failed) or ("unchecked" if unchecked else "")}


def walking_hours(text) -> float | None:
    """``"1 3/4"`` → 1.75, ``"2"`` → 2.0, ``"¾"`` → 0.75, ``"1¹/₄"`` → 1.25; ``None`` where no
    distance is printed."""
    import unicodedata

    total, seen = 0.0, False
    text = re.sub(r"(?<=\d)(?=[⁰¹²³⁴⁵⁶⁷⁸⁹])", " ", str(text or ""))           # 1¹/₄ → 1 ¹/₄
    text = unicodedata.normalize("NFKC", text).replace("⁄", "/")                # ¹/₄ → 1/4
    for tok in re.findall(r"\d+/\d+|\d+|[¼½¾⅓⅔⅛]", text):
        if "/" in tok:
            num, den = (int(x) for x in tok.split("/"))
            if not den:
                return None
            total += num / den
        else:
            total += FRACTIONS[tok] if tok in FRACTIONS else int(tok)
        seen = True
    return round(total, 3) if seen else None


def keyed_references(note) -> list[tuple[int, float | None]]:
    """A table cell of legend keys, each with its walking distance: ``"11) 1 3/4, 6) 2 1/2"`` →
    ``[(11, 1.75), (6, 2.5)]``; a key printed with no distance has ``None``."""
    return [(int(k), walking_hours(h)) for k, h in re.findall(r"(\d+)\s*\)\s*([^,;)]*)", str(note or ""))]


def legend_items(text) -> list[tuple[str, float | None]]:
    """A legend entry as ``[(place, hours)]``: ``"Steindlhammer 1¹/₄, Rosen- berg an der Moldau
    1³/₄"`` → ``[("Steindlhammer", 1.25), ("Rosenberg an der Moldau", 1.75)]``. A pictogram token
    and a parenthesised note are dropped; a word broken at a line end is joined."""
    import unicodedata

    text = re.sub(r"(?<=\d)(?=[⁰¹²³⁴⁵⁶⁷⁸⁹])", " ", str(text or ""))           # 1¹/₄ → 1 ¹/₄
    text = unicodedata.normalize("NFKC", text).replace("⁄", "/")
    text = re.sub(r"\[[^\]]*\]|\([^)]*\)|\([^)]*$|\*\)", " ", text)     # a note, closed or cut off
    text = re.sub(r"(\w)- (\w)", r"\1\2", text)
    out = []
    for item in text.split(","):
        m = re.match(r"^\s*(.*?[^\d\s/¼½¾⅓⅔⅛])\s*([\d\s/¼½¾⅓⅔⅛]*)\s*\.?\s*$", item)
        if m and re.search(r"[^\W\d_]", m.group(1)):
            out.append((m.group(1).strip(" .;:"), walking_hours(m.group(2))))
    return out

    """The court a legend belongs to: its own label where ``courts.csv`` knows it, else the
    closest label among the courts of its page (an OCR'd label: ``novapaka`` / ``novaraka``)
    at 0.6 or better, else the page's only court; ``""`` where none qualifies."""
    import difflib

    if (page, _label(label)) in units.court_of:
        return units.key(page, label)
    on_page = [(d, c) for (p, d), c in units.court_of.items() if p == page]
    if len(on_page) == 1:
        return court_key(on_page[0][1], "")
    scored = sorted(((difflib.SequenceMatcher(None, _label(label), d).ratio(), c) for d, c in on_page),
                    reverse=True)
    return court_key(scored[0][1], "") if scored and scored[0][0] >= 0.6 else ""


def _legend_map(units: _Units, legend: pd.DataFrame | None) -> tuple[dict, dict]:
    """``({(court_key, key): items}, {(page, key): items})`` off the reader of record's legend,
    ``items`` as :func:`legend_items`; the page index is the fallback where no court is found."""
    by_court, by_page = {}, {}
    for _, r in (legend if legend is not None else pd.DataFrame()).iterrows():
        key, items = str(r.get("key", "")).strip(), legend_items(r.get("place", ""))
        if not key.isdigit() or not items:
            continue
        page = str(r.get("page", "")).zfill(4)
        ck = _legend_court(units, page, r.get("district", ""))
        if ck:
            by_court.setdefault((ck, int(key)), items)
        by_page.setdefault((page, int(key)), items)
    return by_court, by_page


def place_references(row: dict | None, ck: str, legend: tuple[dict, dict]) -> dict:
    """``post_office``, ``stations`` (``Name 1.75; Name 2.5``), ``station_nearest`` and
    ``station_hours`` (the least distance printed) for one table row, through the legend. A
    distance is the table cell's where it prints one, else the legend entry's (the German
    volumes print it there). A key the legend does not resolve is written ``key N``."""
    row, (by_court, by_page) = row or {}, legend
    page = str(row.get("page", "")).zfill(4)

    def entries(key: int, hours) -> list[tuple[str, float | None]]:
        items = by_court.get((ck, key)) or by_page.get((page, key))
        if not items:
            return [(f"key {key}", hours)]
        return [(n, hours if hours is not None else h) for n, h in items]

    post = keyed_references(row.get("post_key"))
    stations = [e for k, h in keyed_references(row.get("station_note")) for e in entries(k, h)]
    timed = [(h, n) for n, h in stations if h is not None]
    return {"post_office": entries(post[0][0], None)[0][0] if post else "",
            "stations": "; ".join(f"{n} {h:g}" if h is not None else n for n, h in stations),
            "station_nearest": min(timed)[1] if timed else (stations[0][0] if stations else ""),
            "station_hours": min(timed)[0] if timed else pd.NA}


def _school_classes(units: _Units, attributes: pd.DataFrame | None) -> dict:
    """``{(court_key, muni, seq): {"school": classes, "burgher_school": classes}}``, summed over a
    place's schools, off the reader of record's attributes (``[school] III`` → 3)."""
    out: dict = {}
    for _, r in (attributes if attributes is not None else pd.DataFrame()).iterrows():
        kind, classes = r.get("attribute", ""), str(r.get("classes", "")).strip()
        if kind not in ("school", "burgher_school") or not classes.isdigit():
            continue
        if not str(r.get("muni_seq", "")).isdigit():
            continue
        key = (units.key(r["page"], r["district"]), int(r["muni_seq"]), int(r.get("settlement_seq") or 0))
        entry = out.setdefault(key, {"school": 0, "burgher_school": 0})
        entry[kind] += int(classes)
    return out

def _block(i: int, cell: str) -> SimpleNamespace:
    return SimpleNamespace(block_id=str(i), name=cell, municipality={"name": cell})


def _anchor_group(idx: list[int], cells: list[str], courts: list[int],
                  candidates: list[lxn.Obec]) -> dict[int, tuple]:
    """``{row: (obec, score, runner_up, status)}`` for one okres's places of one level."""
    anchors = lxn.anchor_blocks([_block(i, c) for i, c in zip(idx, cells)], candidates)
    used = {id(a.obec) for a in anchors if a.verdict == "matched"}
    court_of = dict(zip(idx, courts))
    cell_of = dict(zip(idx, cells))
    out = {}
    for a in anchors:
        i = int(a.block_id)
        if a.verdict == "ambiguous":            # the court as evidence: retry inside it (D-22)
            own = [o for o in candidates if o.court_id == court_of[i] and id(o) not in used]
            retry = lxn.anchor_block(_block(i, cell_of[i]), own) if own else None
            if retry is not None and retry.verdict == "matched":
                used.add(id(retry.obec))
                out[i] = (retry.obec, retry.score, a.runner_up, "matched_court")
                continue
        out[i] = (a.obec, a.score, a.runner_up, a.verdict)
    return out


def _parent_obec(obec: lxn.Obec, candidates: list[lxn.Obec], parents: dict) -> lxn.Obec | None:
    """The obec an anchored part belongs to: itself if an obec, else its 1910 parent, if unique."""
    if obec.status == "obec":
        return obec
    parent = lxn.normalise(parents.get(obec.settlement_id) or "")
    hits = [o for o in candidates if o.status == "obec"
            and parent and parent in {lxn.normalise(v) for v in o.variants}]
    return hits[0] if len(hits) == 1 else None


def anchor_places(places: pd.DataFrame, authority: lxn.Authority,
                  parents: dict | None = None) -> pd.DataFrame:
    """Add ``settlement_id``, ``anchor_score``, ``anchor_runner_up`` and ``anchor_status``.

    ``parents`` maps a settlement_id to its 1910 parent commune (``settlements_1910.parent_1910``)
    for the ``via_parts`` step. Statuses: matched · matched_court · via_parts (anchored) and
    ambiguous · unmatched · parts_disagree · no_name · no_court · outside_authority (not).
    """
    out = places.copy().reset_index(drop=True)
    res: dict[int, tuple] = {}
    for okres, grp in out.groupby("okres_id", dropna=False):
        cands = authority.okres(int(okres)) if pd.notna(okres) else []
        for level, sub in grp.groupby("place_level"):
            named = sub[sub["printed_name"] != ""]
            for i in sub.index.difference(named.index):
                res[i] = (None, 0, 0, "no_name")
            if pd.isna(okres):
                res.update({i: (None, 0, 0, "no_court") for i in named.index})
                continue
            pool = [o for o in cands if level == "part" or o.status == "obec"]
            if not pool:
                res.update({i: (None, 0, 0, "outside_authority") for i in named.index})
                continue
            res.update(_anchor_group(list(named.index), list(named["printed_name"]),
                                     list(named["court_id"]), pool))
    _anchor_via_parts(out, res, authority, parents or {})
    out["settlement_id"] = [res[i][0].settlement_id if res[i][0] is not None else None
                            for i in out.index]
    out["anchor_score"] = [int(res[i][1]) for i in out.index]
    out["anchor_runner_up"] = [int(res[i][2]) for i in out.index]
    out["anchor_status"] = [res[i][3] for i in out.index]
    out["settlement_id"] = out["settlement_id"].astype("string")
    return out


def _anchor_via_parts(out: pd.DataFrame, res: dict, authority: lxn.Authority,
                      parents: dict) -> None:
    """A municipality its own name did not anchor takes the obec all its anchored parts belong to."""
    anchored = {res[i][0].settlement_id for i in res if res[i][0] is not None
                and out.at[i, "place_level"] == "municipality"}
    for i in out.index[out["place_level"] == "municipality"]:
        if res[i][0] is not None or res[i][3] in ("no_court", "outside_authority"):
            continue
        same = (out["court_key"] == out.at[i, "court_key"]) & (out["muni_seq"] == out.at[i, "muni_seq"])
        parts = [res[j][0] for j in out.index[same & (out["place_level"] == "part")]
                 if res[j][0] is not None]
        if not parts:
            continue
        pool = authority.okres(int(out.at[i, "okres_id"]))
        owners = {id(p): p for p in (_parent_obec(o, pool, parents) for o in parts) if p is not None}
        if len(owners) == 1 and len([o for o in parts if _parent_obec(o, pool, parents)]) == len(parts):
            obec = next(iter(owners.values()))
            if obec.settlement_id not in anchored:
                anchored.add(obec.settlement_id)
                res[i] = (obec, 0, 0, "via_parts")
                continue
        res[i] = (None, res[i][1], res[i][2], "parts_disagree")

def settled_by(rule) -> str:
    """The strongest hand on a claim's rule string (:data:`SETTLED_ORDER`)."""
    r = str(rule or "").lower()
    hands = set()
    if "author" in r:
        hands.add("author")
    if "opus" in r.replace("opus settled nothing", ""):
        hands.add("opus")
    if "not asked" in r:
        hands.add("reader_of_record")
    if "readers agree" in r:
        hands.add("readers")
    if re.search(r"(^|\+ )agreed", r):
        hands.add("agreed")
    return next((h for h in SETTLED_ORDER if h in hands), "other")


def _claim_frame(run: RunInput, units: _Units, frame: pd.DataFrame, code_col: str,
                 carry: tuple[str, ...] = ()) -> pd.DataFrame:
    """Claims keyed as places, with the count, rule and the hand that settled each; ``carry``
    names further columns of ``frame`` kept beside them."""
    frame = frame.reset_index(drop=True)
    out = pd.DataFrame({
        "edition": run.edition,
        "court_key": [court_key(c or units.court_of.get((str(p).zfill(4), _label(d)), ""), d)
                      for c, p, d in zip(frame.get("court_id", [""] * len(frame)),
                                         frame["page"], frame["district"])],
        "muni_seq": pd.to_numeric(frame["muni_seq"], errors="coerce"),
        "settlement_seq": pd.to_numeric(frame["settlement_seq"].replace("", "0"), errors="coerce"),
        "code": frame[code_col].values,
        "count": pd.to_numeric(frame["count"], errors="coerce"),
        "count_source": frame.get("count_source", pd.Series([""] * len(frame))).values,
        "rule": frame["rule"].values,
        # the way back (1.7.0): the run's claim key, and the claim's marks, each a key of
        # ledger/ledger_<run>.csv — a box (``crop.png#x0,y0,x1,y1``) or an unplaced claim's mark
        "entry": frame.get("entry", pd.Series([""] * len(frame))).fillna("").values,
        "marks": frame.get("marks", pd.Series([""] * len(frame))).fillna("").values,
        **{c: frame[c].values for c in carry},
    })
    out = out.dropna(subset=["muni_seq", "settlement_seq"])
    out[["muni_seq", "settlement_seq"]] = out[["muni_seq", "settlement_seq"]].astype(int)
    missing = out["count"].isna()
    out.loc[missing, "count_source"] = "none written: 1"
    out["count"] = out["count"].fillna(1).astype("Int64")
    out["settled_by"] = out["rule"].map(settled_by)
    out["author_ruled"] = out["settled_by"].eq("author")
    out["disputed"] = out["settled_by"].ne("agreed")
    return out

def _pointers(cells) -> str:
    """Every pointer of the rows folded into one, once each, in the route's own separator."""
    return " | ".join(dict.fromkeys(p.strip() for cell in cells for p in str(cell).split(" | ")
                                    if p.strip()))


def _collapse(claims: pd.DataFrame, key: list[str]) -> pd.DataFrame:
    """One row per key: a claim read on two pages of one place adds its counts; the strongest
    hand and every rule are kept, and ``n_pages`` says how many rows were folded."""
    order = {h: k for k, h in enumerate(SETTLED_ORDER)}
    claims = claims.assign(_rank=claims["settled_by"].map(order).fillna(len(order)))
    agg = claims.sort_values("_rank").groupby(key, as_index=False, sort=True).agg(
        count=("count", "sum"), count_source=("count_source", lambda s: " + ".join(dict.fromkeys(s))),
        rule=("rule", lambda s: " + ".join(dict.fromkeys(s))), settled_by=("settled_by", "first"),
        n_pages=("rule", "size"), entry=("entry", _pointers), marks=("marks", _pointers))
    agg["author_ruled"] = agg["settled_by"].eq("author")
    agg["disputed"] = agg["settled_by"].ne("agreed")
    agg["count"] = agg["count"].astype("Int64")
    return agg


def build_institutions(run: RunInput, units: _Units | None = None) -> pd.DataFrame:
    """Place × mark: the pictograms of the final inventory and the text institutions and courses
    of the final abbreviations (cooperative letters go to :func:`build_cooperatives`)."""

    pic = _claim_frame(run, units, run.inventory, "code").assign(source="pictogram")
    frames = [pic.assign(english="", establishment=True, qualifier="")]
    ab = run.abbreviations
    if ab is not None and not ab.empty:
        ab = ab[ab["kind"] != "cooperative"]
        txt = _claim_frame(run, units, ab, "code", carry=("english", "establishment", "qualifier"))
        txt["establishment"] = txt["establishment"].astype(str).str.lower().eq("true")
        frames.append(txt.assign(source="text"))
    claims = pd.concat(frames, ignore_index=True).rename(columns={"code": "mark"})
    key = PLACE_KEY + ["mark", "source"]
    out = _collapse(claims, key)
    extra = claims.drop_duplicates(key).set_index(key)[["english", "establishment", "qualifier"]]
    out = out.join(extra, on=key)
    rel = _religion_table()
    is_text = out["source"].eq("text")

    out["rc_parish_strict"] = out["mark"].map(rel["rc_parish_strict"].to_dict()).eq(True)
    return out


#: How the route's ``language_counts`` names a cooperative printed with no language letter (A9).
#: It and the empty letter are one value: not stated (D-146).
NO_LETTER = "none"


def _language_counts(cell) -> dict[str, int] | None:
    """``{letter: count}`` off a ``language_counts`` cell (``"none:1|d:1"``), ``none`` read as the
    empty letter; ``None`` for an empty cell (a route before the column, A9)."""
    out: dict[str, int] = {}
    for item in str(cell or "").split("|"):
        letter, sep, n = item.strip().rpartition(":")
        if sep and n.strip().isdigit() and int(n):
            letter = letter.strip().lower()
            letter = "" if letter == NO_LETTER else letter
            out[letter] = out.get(letter, 0) + int(n)
    return out or None


def _coop_letters(suffixes, count: int, language_counts=None) -> list[tuple[str, int, bool]]:
    """``[(letter, count, split)]`` for one cooperative claim; the empty letter is not stated
    (D-146), and ``split`` marks a claim whose count is divided among several letters (A9).

    With the route's ``language_counts`` — a count for each printed letter, ``none`` for the
    items printed bare, summing to the claim's count — each letter takes its own count, and any
    shortfall against the claim's count is not stated. Without it (a run before the column)
    ``suffixes`` is the readings' majority list of letters, which the route writes once per
    distinct letter: it says neither how many items carried a letter nor whether one stood
    bare, so ``R, Rd`` and ``2 Rd`` read the same (``d``, count 2). A letter is then never given
    to an item whose language is not stated: one letter takes the whole count only where every
    item is known to carry it (as many entries as the count — in practice a claim of one);
    otherwise every distinct letter takes 1 and the rest are not stated. (Before A9 one letter
    took any count — ``R, Rd`` two German cooperatives — and two letters one each with the rest
    lost — ``Rb, 2 Rd`` two cooperatives, not three.)"""
    count = int(count)
    shares = _language_counts(language_counts)
    if shares is not None:
        if count > sum(shares.values()):
            shares[""] = shares.get("", 0) + count - sum(shares.values())
    else:
        given = [s.strip().lower() for s in str(suffixes or "").split(";") if s.strip()]
        letters = list(dict.fromkeys(given))
        if not given:
            return [("", count, False)]
        if len(letters) == 1 and len(given) >= count:          # every item carries it
            return [(letters[0], count, False)]
        shares = {letter: 1 for letter in letters[:count]}
        if count > len(shares):
            shares[""] = count - len(shares)
    return [(letter, n, len(shares) > 1) for letter, n in shares.items()]


def build_cooperatives(run: RunInput, units: _Units | None = None) -> pd.DataFrame | None:
    """Place × cooperative letter × language letter. ``None`` when the run wrote no abbreviations:
    the letters were not read, which is not the same as none printed. Each claim's count is
    divided among its language letters by :func:`_coop_letters` (A9)."""
    ab = run.abbreviations
    if ab is None:
        return None
    ab = ab[ab["kind"] == "cooperative"]
    for col in ("language_suffix", "language_counts"):       # absent from older runs
        if col not in ab:
            ab = ab.assign(**{col: ""})
    claims = _claim_frame(run, units or _Units(run), ab, "code",
                          carry=("english", "language_suffix", "language_counts"))
    rows = []
    for c in claims.to_dict("records"):
        for letter, n, split in _coop_letters(c["language_suffix"], c["count"], c["language_counts"]):
            rows.append({**c, "coop_code": c["code"], "coop_kind": c["english"],
                         "language_letter": letter, "count": n, "count_split": split})
    cols = PLACE_KEY + ["coop_code", "language_letter", "count", "count_source", "rule",
                        "settled_by", "coop_kind", "count_split", "entry", "marks"]
    claims = pd.DataFrame(rows, columns=cols)
    key = PLACE_KEY + ["coop_code", "language_letter"]
    out = _collapse(claims, key)
    extra = claims.groupby(key, sort=True).agg(coop_kind=("coop_kind", "first"),
                                               count_split=("count_split", "any"))
    out = out.join(extra, on=key)                 # split if any claim folded into the row was
    out["language"] = out["language_letter"].map(LANGUAGE_OF_LETTER).fillna("unknown")
    return out

def _slug(text) -> str:
    """A column-name stem: ASCII, lower case, any other run of characters one ``_``
    (``txt:měšť. šk.`` → ``txt_mest_sk``). Not unique: :func:`spread_names` makes it so."""
    import unicodedata

    folded = unicodedata.normalize("NFKD", str(text).replace("ß", "ss"))
    folded = folded.encode("ascii", "ignore").decode("ascii")
    return re.sub(r"[^a-z0-9]+", "_", folded.lower().replace("txt:", "txt_")).strip("_")

           ("register_institutions", "mark", "n_mark_"),

           ("register_cooperatives", "language", "n_coop_lang_"))
#: The columns map written beside the register (B1): every spread column and the value it counts.
COLUMNS_MAP = "register_columns.csv"


def spread_names(values, prefix: str, universe=()) -> dict[str, str]:
    """``{value: column}`` for the values one spread column takes (B1): ``prefix`` + the value's
    stem (:func:`_slug`), and where two different values share a stem — ``Gymn.`` and
    ``gymn.``, ``měst.`` and ``měšť.`` — each of them gets ``_`` + six hex of its own SHA-1 as
    well. A stem counts as shared over ``universe`` too, every value the code table can give
    (:func:`_spread_universe`), so whether a name carries its hash never depends on which values
    one build happens to hold. Raises if two values would still share a name."""
    import hashlib

    stems: dict[str, set[str]] = {}
    for value in {*map(str, universe), *map(str, values)}:
        stems.setdefault(_slug(value), set()).add(value)
    names = {}
    for value in map(str, values):
        stem = _slug(value)
        names[value] = f"{prefix}{stem}" + (
            f"_{hashlib.sha1(value.encode('utf-8')).hexdigest()[:6]}"
            if len(stems[stem]) > 1 or not stem else "")
    if len(set(names.values())) != len(names):
        raise ValueError(f"spread columns of {prefix!r} not unique: {names}")
    return names


def _spread_universe(path: Path = ABBREVIATIONS, religion: Path = RELIGION_CATEGORIES) -> dict:
    """``{long-table column: every value it can take}`` off the code table and the religious
    categories, which :func:`spread_names` judges a shared stem against (B1)."""
    table = pd.read_csv(path, dtype=str, keep_default_na=False)
    pictogram, coop = table["code"].str.startswith("["), table["kind"].eq("cooperative")
    text = ~pictogram & ~coop
    categories = set(pd.read_csv(religion, dtype=str, keep_default_na=False)["category"]) - {""}
    return {"mark": set(table.loc[pictogram, "code"]) | {"txt:" + c for c in table.loc[text, "code"]},
            "common_category": (set(table.loc[pictogram, "code"]) | categories
                                | {"txt:" + e for e in table.loc[text, "english"]}),
            "coop_kind": set(table.loc[coop, "english"]),
            "language": set(LANGUAGE_OF_LETTER.values()) | {"unknown"}}


def spread_columns(institutions: pd.DataFrame, cooperatives: pd.DataFrame | None,
                   universe: dict | None = None) -> pd.DataFrame:
    """The columns map (B1): ``column``, ``source_table``, ``source_column``, ``value`` for every
    value the long tables hold in a spread column, the name :func:`spread_names` gives it. Key
    ``column``; it is what makes a hashed name readable back."""
    universe = _spread_universe() if universe is None else universe
    frames = {"register_institutions": institutions, "register_cooperatives": cooperatives}
    rows = []
    for table, col, prefix in SPREADS:
        frame = frames[table]
        if frame is None or frame.empty or col not in frame:
            continue
        values = sorted(set(frame[col].dropna().astype(str)))
        rows += [{"column": name, "source_table": table, "source_column": col, "value": value}
                 for value, name in spread_names(values, prefix, universe.get(col, ())).items()]
    out = pd.DataFrame(rows, columns=["column", "source_table", "source_column", "value"])
    assert not out["column"].duplicated().any(), "two spread columns share a name"
    return out


def _wide(frame: pd.DataFrame, col: str, owner: pd.Series, names: dict[str, str]) -> pd.DataFrame:
    """Counts of ``frame`` summed per municipality and spread over the values of ``col``,
    each value's column named by ``names`` (:func:`spread_columns`)."""
    f = frame.assign(_owner=owner.reindex(frame.index)).dropna(subset=[col, "_owner"])
    if f.empty:
        return pd.DataFrame()
    w = f.pivot_table(index="_owner", columns=col, values="count", aggfunc="sum", fill_value=0)
    w.columns = [names[str(c)] for c in w.columns]
    return w.astype("Int64")


def municipality_owner(places: pd.DataFrame, editions: tuple = EDITION_PRIORITY) -> pd.DataFrame:
    """The register municipality each anchored ``settlement_id`` comes from.

    Where two editions read it, the first in ``editions`` (the certified Czech volume first);
    where one edition anchored two municipalities to it, neither (counted in ``attrs``)."""
    m = places[(places["place_level"] == "municipality") & places["settlement_id"].notna()].copy()
    m["_rank"] = m["edition"].map({e: k for k, e in enumerate(editions)}).fillna(len(editions))
    dup = m.duplicated(["edition", "settlement_id"], keep=False)
    m = m[~dup].sort_values(["_rank", "court_key", "muni_seq"])
    seen = m.groupby("settlement_id")["edition"].agg(lambda s: ";".join(dict.fromkeys(s)))
    m = m.drop_duplicates("settlement_id", keep="first").set_index("settlement_id")
    m["editions_seen"] = seen
    m.attrs["duplicates"] = int(dup.sum())
    return m


def _owner_of(frame: pd.DataFrame, unit: pd.DataFrame) -> pd.Series:
    """The owning municipality's settlement_id for every row of a place-keyed frame."""
    key = ["edition", "court_key", "muni_seq"]
    joined = frame[key].merge(unit, on=key, how="left", validate="m:1")
    assert len(joined) == len(frame), "the owner join changed the row count"
    return pd.Series(joined["settlement_id"].values, index=frame.index)


def _claim_columns(out: pd.DataFrame, claims: pd.DataFrame) -> None:
    """How many claims each municipality has, and by whose hand they were settled."""
    g = claims.groupby("_owner")
    for col, s in (("n_claims", g.size()), ("n_claims_disputed", g["disputed"].sum()),
                   ("n_claims_author", g["author_ruled"].sum()),
                   ("n_claims_opus", g["settled_by"].agg(lambda x: int((x == "opus").sum()))),
                   ("n_claims_reader_of_record",
                    g["settled_by"].agg(lambda x: int((x == "reader_of_record").sum())))):
        out[col] = s.reindex(out.index).fillna(0).astype("Int64")


def build_municipalities(places: pd.DataFrame, institutions: pd.DataFrame,
                         cooperatives: pd.DataFrame | None,
                         abbreviations_read: set[str] | None = None,
                         universe: dict | None = None) -> pd.DataFrame:
    """One row per anchored 1910 municipality, from the three long tables only.

    ``abbreviations_read``: the editions whose run wrote ``final_abbreviations.csv``. For any
    other edition the text-institution and cooperative counts are ``<NA>`` — not read, which is
    not zero (D-52's rule for an unrecorded field). The spread columns are named by
    :func:`spread_columns` (``universe``: the code table's values, by default), one per value."""
    names: dict[str, dict[str, str]] = {}
    for r in spread_columns(institutions, cooperatives, universe).itertuples():
        names.setdefault(r.source_column, {})[r.value] = r.column
    owners = municipality_owner(places)
    unit = owners.reset_index()[["settlement_id", "edition", "court_key", "muni_seq"]]
    inst_owner = _owner_of(institutions, unit)
    parts = places[places["place_level"] == "part"]
    part_owner = _owner_of(parts, unit)
    own_cols = [c for c in (*FIGURES, "figures_check", "post_office", "stations", "station_nearest",
                            "station_hours") if c in owners]
    out = owners[["edition", "editions_seen", "run", "court_id", "court_cs", "okres_id",
                  "muni_seq", "printed_name", "anchor_status", "anchor_score", *own_cols]].copy()
    for col in ("school_classes", "burgher_school_classes"):      # the municipality and its parts
        if col in owners:
            from_parts = (parts.assign(_o=part_owner).dropna(subset=["_o"]).groupby("_o")[col]
                          .sum(min_count=1).reindex(out.index).fillna(0))
            out[col] = (owners[col] + from_parts).astype("Int64")
    out["n_parts"] = part_owner.value_counts().reindex(out.index).fillna(0).astype("Int64")
    out["n_parts_anchored"] = (part_owner[parts["settlement_id"].notna()].value_counts()
                               .reindex(out.index).fillna(0).astype("Int64"))
    out["abbreviations_read"] = out["edition"].isin(abbreviations_read or set())
    coops = cooperatives if cooperatives is not None else pd.DataFrame()
    coop_owner = _owner_of(coops, unit) if not coops.empty else pd.Series(dtype=object)
    claims = [institutions.assign(_owner=inst_owner)]
    if not coops.empty:
        claims.append(coops.assign(_owner=coop_owner))
    _claim_columns(out, pd.concat(claims, ignore_index=True).dropna(subset=["_owner"]))
    rc = institutions[institutions["rc_cure_seat"]].assign(_o=inst_owner).dropna(subset=["_o"])
    out["rc_cure_seat"] = out.index.isin(rc["_o"])
    strict = institutions[institutions["rc_parish_strict"]].assign(_o=inst_owner)
    out["rc_parish_strict"] = out.index.isin(strict["_o"].dropna())
    out["n_rc_cure_seat"] = rc.groupby("_o")["count"].sum().reindex(out.index).fillna(0).astype("Int64")
    blocks = [_wide(institutions, "common_category", inst_owner, names.get("common_category", {})),
              _wide(institutions, "mark", inst_owner, names.get("mark", {}))]
    out["n_coop"] = (coops.assign(_o=coop_owner).groupby("_o")["count"].sum()
                     .reindex(out.index).fillna(0).astype("Int64") if not coops.empty
                     else pd.Series(0, index=out.index, dtype="Int64"))
    if not coops.empty:
        blocks += [_wide(coops, "coop_kind", coop_owner, names.get("coop_kind", {})),
                   _wide(coops, "language", coop_owner, names.get("language", {}))]
    for b in blocks:
        if not b.empty:
            out = out.join(b, how="left")
            out[b.columns] = out[b.columns].fillna(0).astype("Int64")
    out = out.join(school_columns(institutions, inst_owner, out.index, out["abbreviations_read"]))
    text_cols = [c for c in out.columns if c.startswith(("n_coop", "n_cat_txt_", "n_mark_txt_"))]
    out.loc[~out["abbreviations_read"], text_cols] = pd.NA
    out = out.rename_axis("settlement_id").reset_index()
    assert not out.columns.duplicated().any(), "register_municipalities: a column name twice (B1)"
    return out


def school_type(mark, english) -> str | None:
    """A claim's school type (``SCHOOL_TYPES``): a text mark by its English name, a pictogram by
    its token; ``None`` for what is not a school."""
    key = english if str(mark).startswith("txt:") else mark
    return SCHOOL_TYPES.get(str(key if key is not None else "").strip())


def school_rung(kind) -> int | None:
    """The type's rung on the education ladder (``education.INSTITUTIONS``), ``None`` off it."""
    from utils.parsing import education as edu

    if kind == "elementary_branch":
        return 1
    entry = edu.INSTITUTIONS.get(kind)
    return entry[2] if entry else None


#: The school types a plate prints as a pictogram; every other type is a text abbreviation.
PICTOGRAM_SCHOOLS = {"elementary", "elementary_branch", "preschool"}


def school_columns(institutions: pd.DataFrame, owner: pd.Series, index, read: pd.Series) -> pd.DataFrame:
    """``n_school_<type>`` for every type of ``SCHOOL_TYPES`` and ``school_top_rung``, the highest
    rung a school of the municipality or its parts stands on (0: none printed), per municipality.
    Where the edition's abbreviations were not read, every type they carry and the top rung are
    ``<NA>``: a burgher school or a gymnasium would have been there (1.6.0)."""
    english = institutions["english"] if "english" in institutions else pd.Series("", index=institutions.index)
    kinds = [school_type(m, e) for m, e in zip(institutions["mark"], english)]
    frame = institutions.assign(_o=owner, _kind=kinds).dropna(subset=["_o", "_kind"])
    counts = (frame.groupby(["_o", "_kind"])["count"].sum().unstack(fill_value=0)
              if not frame.empty else pd.DataFrame())
    out = pd.DataFrame(index=index)
    for kind in sorted(set(SCHOOL_TYPES.values())):
        col = counts[kind].reindex(index) if kind in counts else pd.Series(0, index=index)
        out[f"n_school_{kind}"] = col.fillna(0).astype("Int64")
    rungs = frame.assign(_r=pd.to_numeric(frame["_kind"].map(school_rung), errors="coerce")).dropna(subset=["_r"])
    out["school_top_rung"] = rungs.groupby("_o")["_r"].max().reindex(index).fillna(0).astype("Int64")
    not_read = ~read.reindex(index).fillna(False).astype(bool)
    text_kinds = [f"n_school_{k}" for k in sorted(set(SCHOOL_TYPES.values())) if k not in PICTOGRAM_SCHOOLS]
    out.loc[not_read, text_kinds + ["school_top_rung"]] = pd.NA
    return out

def _text_marks(institutions: pd.DataFrame) -> pd.DataFrame:
    """Text marks get a ``txt:`` prefix, so a printed code never merges with a pictogram."""
    inst = institutions.copy()
    inst["mark"] = inst["mark"].where(inst["source"].eq("pictogram"), "txt:" + inst["mark"].astype(str))
    return inst


def build_run(run: RunInput, authority: lxn.Authority, parents: dict) -> dict:

def _assert_key(name: str, frame: pd.DataFrame) -> None:
    key = TABLE_KEYS[name]

    dup = int(frame.duplicated(key).sum())
    assert dup == 0, f"{name}: {dup} duplicate key(s) on {key}"


def _claims_have_places(name: str, claims: pd.DataFrame, places: pd.DataFrame) -> None:
    """Every claim's place is a row of ``register_places`` (the foreign key holds)."""

    assert orphans == 0, f"{name}: {orphans} claim(s) with no place row"

STATUTORY_COLUMNS = ("edition", "city", "row", "okres_id", "quote", "count", "languages",
                     "category", "code", "school_type", "is_total")


def build_statutory(path: Path = STATUTORY_ROWS) -> pd.DataFrame:
    """The statutory cities' institutions read from their prose (D-178, stage 2): one row per
    printed mention both readers gave alike, or the blind judge settled where they did not, and
    every rule passed (``status`` ``agree`` or ``adjudicated``, no ``problems``), or the author ruled
    (``author``, ``statutory_institution_rulings.csv``), keyed by edition,
    city and the mention's order. Joined on ``okres_id``, the
    city's own okres (``STATUTORY_OKRES``). Empty where stage 2 has not run (1.5.0)."""
    empty = pd.DataFrame(columns=list(STATUTORY_COLUMNS)).astype(
        {"row": "int64", "okres_id": "Int64", "count": "Int64"})
    if not Path(path).exists():
        return empty
    rows = _read(Path(path))
    settled = rows[rows["status"].isin(("agree", "adjudicated", "author")) & (rows["problems"] == "")].copy()
    if settled.empty:
        return empty
    settled["row"] = settled.groupby(["edition", "city"]).cumcount() + 1
    settled["okres_id"] = settled["city"].map(STATUTORY_OKRES).astype("Int64")
    settled["count"] = pd.to_numeric(settled["count"]).astype("Int64")
    english = {r["code"]: r["english"] for r in csv.DictReader(ABBREVIATIONS.open(encoding="utf-8"))}
    settled["school_type"] = [school_type(c if c.startswith("[") else "txt:" + c, english.get(c, "")) or ""
                              for c in settled["code"]]
    settled["is_total"] = (settled["is_total"].eq("True") if "is_total" in settled
                           else pd.Series(False, index=settled.index))
    return settled[list(STATUTORY_COLUMNS)].reset_index(drop=True)


def build_register(run_dirs=(), final_dir: Path = FINAL, out_dir: Path | None = None,
                   write: bool = True, runs: list[RunInput] | None = None,
                   statutory: Path = STATUTORY_ROWS) -> dict:
    """Build the five tables from one or more run folders; write them to ``data/final/register``.

    ``runs`` passes loaded runs instead (tests); ``statutory`` the prose institutions' file.
    Never writes into ``output/frozen`` (D-148)."""
    final_dir = Path(final_dir)
    out_dir = Path(out_dir) if out_dir else final_dir / "register"
    if write and FROZEN.resolve() in [out_dir.resolve(), *out_dir.resolve().parents]:
        raise ValueError(f"refusing to write into {FROZEN}: the frozen runs are read-only")
    runs = runs if runs is not None else [load_run(d) for d in run_dirs]
    settlements = pd.read_parquet(final_dir / "geo" / "settlements_1910.parquet")
    if "settlement_id" not in settlements:
        raise KeyError("settlements_1910 has no settlement_id — re-run notebook 02 (lexikon 1.7.0)")
    parents = dict(zip(settlements["settlement_id"], settlements["parent_1910"]))
    authority = load_authority(final_dir)
    built = [build_run(r, authority, parents) for r in runs]
    places = pd.concat([b["places"] for b in built], ignore_index=True)
    # German Böhmen through the Czech volume; a court's ends close only on a full run (D-150)
    complete = bool(runs) and all(r.pages == "full" for r in runs)
    places, order_status = lxcw.crosswalk_editions(places, OWN_ANCHORS, complete)
    inst = _text_marks(pd.concat([b["institutions"] for b in built], ignore_index=True))
    coops = [b["cooperatives"] for b in built if b["cooperatives"] is not None]
    coop = pd.concat(coops, ignore_index=True) if coops else _empty_cooperatives()
    read = {r.edition for r in runs if r.abbreviations is not None}
    universe = _spread_universe()
    tables = {"register_places": places, "register_institutions": inst,
              "register_cooperatives": coop,
              "register_municipalities": build_municipalities(places, inst, coop, read, universe),
              "register_statutory": build_statutory(statutory)}
    for name, frame in tables.items():
        _assert_key(name, frame)
    _claims_have_places("register_institutions", inst, places)
    _claims_have_places("register_cooperatives", coop, places)
    columns = spread_columns(inst, coop, universe)
    columns = columns[columns["column"].isin(tables["register_municipalities"].columns)]
    tables["register_columns"] = columns.reset_index(drop=True)      # B1: not a table of TABLE_KEYS
    tables["_meta"] = {"runs": [r.run for r in runs], "abbreviations_read": sorted(read),
                       "skipped_table_rows": {r.run: b["skipped_table_rows"]
                                              for r, b in zip(runs, built)},
                       "duplicates": municipality_owner(places).attrs.get("duplicates", 0),
                       "order_status": order_status, "crosswalk_stale": ""}
    if write:
        out_dir.mkdir(parents=True, exist_ok=True)
        for name in TABLE_KEYS:
            tables[name].to_parquet(out_dir / f"{name}.parquet", index=False)
            tables[name].to_csv(out_dir / f"{name}.csv", index=False, encoding="utf-8")
        tables["register_columns"].to_csv(out_dir / COLUMNS_MAP, index=False, encoding="utf-8")
        tables["_meta"]["crosswalk_stale"] = stale = crosswalk_stale(final_dir, out_dir)
        if stale:
            print(stale)
    return tables

def crosswalk_stale(final_dir: Path = FINAL, register_dir: Path | None = None) -> str:
    """A warning when the map crosswalk (``geo/settlements_1910_geo``) is older than the register
    it reads (C17), else ``""``; nothing when either is not built."""
    register_dir = Path(register_dir) if register_dir else Path(final_dir) / "register"
    crosswalk = Path(final_dir) / CROSSWALK
    built = [p.stat().st_mtime for p in register_dir.glob("register_*.parquet")]
    if not crosswalk.exists() or not built or crosswalk.stat().st_mtime >= max(built):
        return ""
    return ("  !! data/final/geo/settlements_1910_geo is older than the register it breaks ties "
            "with: re-run notebook 02 §3e (the order is notebook 02's settlements, then notebook "
            "15 §18, then §3e — REGISTER_VARIABLES.md, 'Build order')")


# ── the report ────────────────────────────────────────────────────────────────
def anchor_summary(places: pd.DataFrame) -> pd.DataFrame:
    """Anchoring by run and level: how many places, how many anchored, and every refusal."""
    p = places.assign(anchored=places["anchor_status"].isin(ANCHORED),
                      partitioned=places["okres_id"].isin(list(PARTITIONED_OKRESY)))
    counts = p.pivot_table(index=["run", "place_level"], columns="anchor_status",
                           values="court_key", aggfunc="size", fill_value=0)
    counts.insert(0, "places", counts.sum(axis=1))
    counts.insert(1, "anchored", p.groupby(["run", "place_level"])["anchored"].sum())
    counts.insert(2, "rate", (counts["anchored"] / counts["places"]).round(3))
    counts["unanchored_partitioned"] = (p[~p["anchored"] & p["partitioned"]]
                                        .groupby(["run", "place_level"]).size()
                                        .reindex(counts.index).fillna(0).astype(int))
    return counts

# ── checks against sources outside the book (1.5.0) ───────────────────────────
def okres_check(tables: dict, final_dir: Path = FINAL) -> pd.DataFrame:
    """The register's population against the 1910 census, per pooled okres (``census_okres_id``,
    D-18). ``coverage`` is the share of the okres's municipalities (``settlements_1910``, status
    obec) the register anchored; ``graded`` only where it is 1 and every one has a population read,
    since a partial okres under-sums by construction. Both sides descend from one enumeration, so
    agreement validates the reading, never the census (``lexikon_1910_census``)."""
    final_dir = Path(final_dir)
    settle = pd.read_parquet(final_dir / "geo" / "settlements_1910.parquet")
    cw = pd.read_csv(final_dir / "geo" / "okres_census_crosswalk.csv")
    census = pd.read_parquet(final_dir / "census" / "census_okres_1910_pooled.parquet")
    pooled = dict(zip(cw["okres_id"], cw["census_okres_id"]))
    obce = settle[settle["status_1910"] == "obec"].assign(
        census_okres_id=lambda d: d["okres_id"].map(pooled))
    known = obce.groupby("census_okres_id")["settlement_id"].nunique()
    muni = tables["register_municipalities"]
    mine = muni[muni["settlement_id"].isin(obce["settlement_id"])].merge(
        obce[["settlement_id", "census_okres_id"]], on="settlement_id", how="left", validate="1:1")
    got = mine.groupby("census_okres_id").agg(anchored=("settlement_id", "nunique"),
                                              pop_read=("pop_total", lambda s: int(s.notna().sum())),
                                              register_pop=("pop_total", lambda s: s.sum(min_count=1)))
    out = got.join(known.rename("known")).join(
        census.set_index("census_okres_id")[["okres_cs", "pop_total"]].rename(columns={"pop_total": "census_pop"}))
    out["coverage"] = (out["anchored"] / out["known"]).round(3)
    out["graded"] = (out["anchored"] == out["known"]) & (out["pop_read"] == out["anchored"])
    out["diff"] = (out["register_pop"] - out["census_pop"]).where(out["graded"])
    return out.reset_index()


def birthplace_join(tables: dict, final_dir: Path = FINAL) -> dict:
    """How the legionnaires' birthplaces reach the register: of the births with a Cisleithanian
    okres, how many name a settlement of that okres uniquely (Czech or German name, casefolded),
    how many of those the register holds (as a municipality or a part), and how many were born in
    a statutory city (``register_statutory``). A measure, not the link: the person table should
    carry ``birth_settlement_id`` from notebook 02's own resolution (records_geo)."""
    final_dir = Path(final_dir)
    persons = pd.read_parquet(final_dir / "persons" / "legionnaires_clean.parquet",
                              columns=["birth_okres_id", "birth_municipality_cs", "birth_municipality_de"])
    settle = pd.read_parquet(final_dir / "geo" / "settlements_1910.parquet",
                             columns=["settlement_id", "cs_name", "okres_id"])
    names = settle.assign(name=settle["cs_name"].str.casefold())
    unique = names.drop_duplicates(["okres_id", "name"], keep=False)
    births = persons[persons["birth_okres_id"].notna()].copy()
    births["okres_id"] = births["birth_okres_id"].astype("Int64")
    for col in ("birth_municipality_cs", "birth_municipality_de"):
        births[col + "_key"] = births[col].astype("string").str.casefold()
    hit = births.merge(unique.rename(columns={"name": "birth_municipality_cs_key"}),
                       on=["okres_id", "birth_municipality_cs_key"], how="left", validate="m:1")
    places = tables["register_places"]
    held = set(places["settlement_id"].dropna())
    statutory = births["okres_id"].isin(set(STATUTORY_OKRES.values()))
    return {"births_with_okres": len(births), "named_settlement": int(hit["settlement_id"].notna().sum()),
            "in_register": int(hit["settlement_id"].isin(held).sum()),
            "statutory_city": int(statutory.sum())}

def run_folders(root: Path = FROZEN) -> list[Path]:
    """Every finished run folder under ``output/frozen`` whose name is ``<edition>_<pages>``. A
    re-run's ``…_superseded_round<n>`` folder is not a page set and is left out."""
    import run_frozen as rf

    out = []
    for d in sorted(Path(root).iterdir()) if Path(root).exists() else []:
        try:
            _, pages = parse_run_name(d)
        except ValueError:

        if pages in rf.SUFFIX and (d / "final_inventory.csv").exists():
            out.append(d)
    return out


def measure_anchoring(run_dirs, final_dir: Path = FINAL) -> pd.DataFrame:
    """The anchoring summary of every run, each page set built together (nothing written): German
    Böhmen is crosswalked to the Czech run of its own page set (D-150)."""
    by_pages: dict[str, list[Path]] = {}
    for d in run_dirs:
        by_pages.setdefault(parse_run_name(d)[1], []).append(Path(d))
    frames, notes = [], {}
    for pages, dirs in by_pages.items():
        t = build_register(dirs, final_dir, write=False)
        frames.append(anchor_summary(t["register_places"]))
        if (t["register_places"]["edition"] == lxcw.GERMAN).any():
            notes[pages] = lxcw.crosswalk_report(t["register_places"], t["_meta"]["order_status"])
    out = pd.concat(frames).fillna(0).sort_index() if frames else pd.DataFrame()
    out.attrs["crosswalk"] = notes            # the crosswalk's own report, per page set (D-150)
    return out


def undocumented_columns(tables: dict, readme: str) -> dict[str, list[str]]:
    """``{table: [column, …]}`` — columns the README never names in backticks (spread columns
    count as documented through their prefix)."""
    named = set(re.findall(r"`([a-z0-9_]+)`", readme))
    return {name: [c for c in tables[name].columns
                   if c not in named and not c.startswith(WIDE_PREFIXES + PATTERN_PREFIXES)]
            for name in TABLE_KEYS if name in tables}


def _md_table(frame: pd.DataFrame) -> str:
    frame = frame.reset_index()
    head = "| " + " | ".join(map(str, frame.columns)) + " |"
    rule = "|" + "|".join("---" for _ in frame.columns) + "|"
    rows = ["| " + " | ".join(str(v) for v in r) + " |" for r in frame.itertuples(index=False)]
    return "\n".join([head, rule, *rows])


def build_block(tables: dict, measured: pd.DataFrame, today: str) -> str:
    """The README's generated section: what ``data/final/register`` holds and how well it anchors."""
    places, inst = tables["register_places"], tables["register_institutions"]
    muni, coop = tables["register_municipalities"], tables["register_cooperatives"]
    meta = tables["_meta"]
    notes = measured.attrs.get("crosswalk", {})
    status = measured.drop(columns=["places", "anchored", "rate", "unanchored_partitioned"],
                           errors="ignore")
    keep = ["places", "anchored", "rate", *[c for c in status.columns if (status[c] != 0).any()],
            "unanchored_partitioned"]                          # always shown: the README cites it
    measured = measured[[c for c in keep if c in measured.columns]].astype(
        {c: int for c in keep if c not in ("rate",) and c in measured.columns})
    measured.attrs["crosswalk"] = notes
    hands = inst["settled_by"].value_counts().reindex(list(SETTLED_ORDER) + ["other"]).dropna()
    lines = [
        BLOCK_BEGIN,
        f"*Generated by `lexikon_1910_register.write_build_block` ({__version__}) on {today} — do not edit by hand.*",
        "",
        f"**`data/final/register/` holds:** {', '.join(f'`{r}`' for r in meta['runs'])}. "
        f"Text abbreviations read for: {', '.join(meta['abbreviations_read']) or 'no run on disk'}.",
        "",
        "| table | rows | columns | key |", "|---|---|---|---|",
        *[f"| `{n}` | {len(tables[n]):,} | {tables[n].shape[1]} | {', '.join(f'`{k}`' for k in TABLE_KEYS[n])} |"
          for n in TABLE_KEYS],
        "",
        f"Claims by the hand that settled them: "
        + ", ".join(f"{h} {int(n):,}" for h, n in hands.items())
        + f" (author-ruled {int(inst['author_ruled'].sum()):,}; disputed {int(inst['disputed'].sum()):,} "
          f"of {len(inst):,}). Places with no claim: "
          f"{int((~places.set_index(PLACE_KEY).index.isin(inst.set_index(PLACE_KEY).index)).sum()):,}. "
          f"Municipalities with a cure seat (`rc_cure_seat`): {int(muni['rc_cure_seat'].sum()):,} of {len(muni):,}; "
          f"with a parish in the strict sense: {int(muni['rc_parish_strict'].sum()):,}. "
          f"Cooperative rows: {len(coop):,}.",
        "",
        f"Table rows the anchor could not place in a section: {meta['skipped_table_rows']}; "
        f"municipalities refused for sharing a `settlement_id` within one edition: {meta['duplicates']}.",
        "",
        "**Not read: the statutory cities** "
        + "; ".join(", ".join(c) for c in STATUTORY_CITIES.values())
        + ". Each prints its institutions as prose with no pictogram (D-40, D-82) and the full run "
          "skips its pages, so it has no row here: aggregated to its okres, its counts are missing, never zero.",
        "",
        "**Anchoring, every run on disk (each page set built together, so German Böhmen is "
        "crosswalked to the Czech run of its own pages):**",
        "",
        _md_table(measured),
        "",
        *[line for pages, text in measured.attrs.get("crosswalk", {}).items()
          for line in (f"**Crosswalk to the Czech volume, {pages}:**", "", "```text",
                       text.strip(), "```", "")],
        BLOCK_END,
    ]
    return "\n".join(lines)


def write_build_block(tables: dict, measured: pd.DataFrame, path: Path = README,
                      today: str | None = None) -> None:
    """Replace the README's generated section (between the markers) with :func:`build_block`."""
    import datetime as dt

    text = Path(path).read_text(encoding="utf-8")
    begin, end = text.index(BLOCK_BEGIN), text.index(BLOCK_END) + len(BLOCK_END)
    block = build_block(tables, measured, today or dt.date.today().isoformat())
    Path(path).write_text(text[:begin] + block + text[end:], encoding="utf-8", newline="\n")
