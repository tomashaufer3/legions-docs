How it works

The Czech volume is certified at claim F1 0.996 and prints the same municipalities, so it is the one check on German Böhmen that no step of the correction pass was tuned on: the gold pages are in sample (the full run scores 0.992–0.998 there), and an answer about an outlined box says nothing about a claim when the box sits on the neighbouring glyph (D-118, D-195). Municipalities are paired one to one through the register's crosswalk (cz_muni_seq), as check_offices_coverage.bohemia_editions pairs them, and compared as sets of pictograms.

  • truth — what the Czech volume says of one German claim (printed, not printed, or no partner);
  • scorecard — every change a merge made to German Böhmen's inventory, right or wrong by the Czech volume, by step and reason;
  • agreement — the two editions symbol by symbol, as bohemia_editions counts them.

The Czech volume is not the truth itself: its own errors (0.4 %) and the few places the editions genuinely differ set a ceiling below 1, so read a score as agreement, not accuracy.

class Judge:
    """What the Czech volume says of German Böhmen claims. ``types``: the Czech place types count as
    printed too (an entry question may ask a part's type); off for the scorecard, which judges changes
    to the inventory, where a place type dropped from it is right whatever the Czech types say."""

    def __init__(self, recheck: Path = RECHECK, czech: Path | None = None, types: bool = True):
        self.pairs = pairs()
        self.czech = czech_sets(czech, types=types)
        self.read = set(czech_sets(czech, types=False))   # partners with an inventory: the rest the Czech volume never read (0.1.4)
        self.courts = court_of(rf.out_dir(EDITION, "full") / "final_inventory.csv",
                               Path(recheck) / EDITION / "final_inventory_rechecked.csv")

    def partner(self, page: str, district: str, muni: str):
        court = self.courts.get((str(page), str(district), str(muni)))
        if court is None or not str(muni).isdigit():
            return UNPAIRED
        cz = self.pairs.get((court, int(muni)))
        return UNPAIRED if cz is None else (court, cz)

    def truth(self, part: tuple, token: str):
        """``token`` where the paired Czech municipality prints it, :data:`led.ABSENT` where it does
        not, :data:`UNPAIRED` where there is no one-to-one partner. Judged by municipality: the two
        editions number a municipality's parts differently."""
        partner = self.partner(*part[:3])
        if partner is UNPAIRED or partner not in self.read:
            return UNPAIRED                              # no partner, or one whose offices the Czech volume never read
        return token if token in self.czech.get(partner, set()) else led.ABSENT

def scorecard(changes: list[dict], judge: Judge, after: dict | None = None) -> list[dict]:
    """Per step, action and reason: how many of the merge's inventory changes to German Böhmen the
    Czech volume bears out. An add is right where the Czech volume prints the symbol, a removal
    where it does not; text abbreviations (no brackets) are not pictograms and are left out.
    ``after`` (:func:`parts_by_municipality` of the rechecked inventory, 0.1.3): a change on a part
    whose municipality holds the symbol on another part leaves the municipality as it was, so the
    Czech volume, which is judged by municipality, says nothing of it — unjudged."""
    tally = defaultdict(Counter)
    for c in changes:
        if c.get("edition") != EDITION or c["table"] != "inventory" or not c["code"].startswith("["):
            continue
        key = (c["step"], c["action"], _reason(c["reason"]))
        said = judge.truth((c["page"], c["district"], c["muni_seq"], c["settlement_seq"]), c["code"])
        moved = c["reason"].startswith("moved")          # its court changes: the pairing cannot judge it
        elsewhere = after is not None and bool(
            after.get((c["page"], c["district"], str(c["muni_seq"])), {}).get(c["code"], set()) - {str(c["settlement_seq"])})
        if said is UNPAIRED or moved or elsewhere or c["action"] not in ("add", "remove"):
            tally[key]["unjudged"] += 1
            continue
        right = (said == c["code"]) if c["action"] == "add" else (said == led.ABSENT)
        tally[key]["right" if right else "wrong"] += 1
    rows = []
    for (step, action, reason), n in tally.items():
        judged = n["right"] + n["wrong"]
        rows.append({"step": step, "action": action, "reason": reason, "right": n["right"], "wrong": n["wrong"],
                     "unjudged": n["unjudged"], "share_right": round(n["right"] / judged, 3) if judged else None})
    return sorted(rows, key=lambda r: (r["step"], -(r["right"] + r["wrong"])))
