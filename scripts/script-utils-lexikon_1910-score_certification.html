How it works

This is the one-shot scorer D-55 and the 2026-10-24 audit (§D) ask for. Everything it reports is fixed here, before any sealed page was scored (written 2026-10-25, with the Czech certification run on disk and nothing yet scored against it). The point of the sealed half is that nothing was tuned on it; a metric chosen after seeing how the route did on it would spend that seal as surely as tuning a prompt would.

What it reports, and why each one

  1. Claim level P / R / F1 on the settlement key (page, district, municipality, part, token) — the unit the analysis consumes, and the unit the gold run is scored on.
  2. A 95 % interval by page-clustered bootstrap: the pages are resampled with replacement (10,000 draws, seed 1910 — the project's own), the percentile interval reported. Eight pages are eight clusters, so this interval, not the point estimate, is the result. An interval from treating ~500 claims as independent would be about half as wide and would be wrong.
  3. entry_exact — the share of entries whose claim set matches the gold's exactly, which is what a settlement-level regressor actually needs.
  4. Count accuracy — among claims the route got right, the share whose printed count matches (the gold run reports 875 of 879; this is the sealed equivalent).
  5. Per symbol: sensitivity and specificity. Sensitivity is recall for that token. Specificity is over the entries where the gold does not print it: 1 − false claims / entries without it. Reported with the gold's count beside it, because most tokens will have too few instances here to carry a rate (the estimate from the gold's own mix is that 33 of 46 Czech symbols have fewer than ten).

Two populations, both reported

  • as printed — every entry the sealed sheets print. This is the headline: it is the route as it will read the volume, misses included.
  • shared entries — entries both the gold and the route reached, which is the rule run_frozen.score_claims uses on the gold. Reported so the two numbers are comparable; it is not the headline, because dropping an entry the route never reached would hide exactly the failure the sealed half exists to measure.

The author's own rulings are reported apart

On a sealed page the author's ruling and the gold transcription are one person reading one print, so a claim settled that way is not independent of the truth it is scored against. Every headline is given twice: with those claims and without them. On the Czech run that is 3 of ~503 claims, so it moves the headline by at most a few tenths of a point — but the number is stated rather than assumed.

What it refuses

  • An edition whose sealed sheets are not all status: complete (the German four are cut and blank as this is written) — there is nothing to score against, and a partial sheet would read as the route inventing claims.
  • A second run over the same edition: the result file is written once. --force overwrites it and the record says so, so a re-score can never be passed off as the first.
  • It never writes the gold's own reference files: the sealed sheets are read into memory here, never into output/lexikon_1910_pilot/inventory_human.csv, which run_frozen.gold_rows loads and the 0.999 rests on.

Written 2026-10-27, before any German sealed page was scored.     """A printed district name → its 1910 court id (D-122), or the name itself.

    The two sides key an entry differently and must be reconciled before anything is
    counted: the route carries the slug the **text layer** gave it, damaged and all — the
    sealed pages file Nechanice as ``mechanice`` and Nová Paka as ``novaraka`` — while a

    505 sealed claims look missing when every one of them was read. The court is the key

    from utils.lexikon_1910 import lexikon_1910_courts as lxc

    key = lxc.CourtKey(edition=edition)
    cache: dict[str, str] = {}

    def resolve(name: str) -> str:
        if name not in cache:
            found, _how = key.resolve(name)
            cache[name] = found or name
        return cache[name]

    return resolve

def route_claims(edition: str, inventory: str = "final_inventory.csv") -> tuple[dict, dict, set]:
    """The run's own output: ``{claim: count}``, ``{claim: rule}`` and the entries it reached."""
    import csv

    path = FROZEN / f"{edition}_certification" / inventory
    counts, rules, entries = {}, {}, set()
    with path.open(encoding="utf-8") as fh:
        for row in csv.DictReader(fh):
            # The inventory's own `entry` key where the run wrote one (`run_frozen` 0.10.0),
            # else the court, else the printed slug: the same key the gold side is put on, so
            # a damaged slug cannot read as a missing entry.
            place = (row.get("court_id") or "").strip() or row["district"]
            claim = (row["page"], place, row["muni_seq"],
                     row["settlement_seq"], row["code"])
            counts[claim] = (row.get("count") or "").strip()
            rules[claim] = (row.get("rule") or "").strip()
            entries.add(claim[:3])
    return counts, rules, entries

def prf(hit: int, false: int, missed: int) -> tuple[float, float, float]:
    p = hit / (hit + false) if hit + false else 0.0
    r = hit / (hit + missed) if hit + missed else 0.0
    f = 2 * p * r / (p + r) if p + r else 0.0
    return p, r, f

def page_clustered_interval(truth: set, got: set) -> dict:
    """Percentile interval over pages resampled with replacement — the clusters are pages."""
    pages = sorted({c[0] for c in truth | got})
    by_page_truth, by_page_got = defaultdict(set), defaultdict(set)
    for c in truth:
        by_page_truth[c[0]].add(c)
    for c in got:
        by_page_got[c[0]].add(c)
    rng = random.Random(BOOTSTRAP_SEED)
    f1s, precisions, recalls = [], [], []
    for _ in range(BOOTSTRAP_DRAWS):
        draw = [rng.choice(pages) for _ in pages]
        hit = false = missed = 0
        for page in draw:
            t, g = by_page_truth[page], by_page_got[page]
            hit += len(g & t)
            false += len(g - t)
            missed += len(t - g)
        p, r, f = prf(hit, false, missed)
        f1s.append(f)
        precisions.append(p)
        recalls.append(r)
    lo, hi = (100 - INTERVAL) / 2, 100 - (100 - INTERVAL) / 2

    def band(values: list[float]) -> list[float]:
        values = sorted(values)
        pick = lambda q: values[min(len(values) - 1, int(q / 100 * len(values)))]  # noqa: E731
        return [pick(lo), pick(hi)]

    return {"pages": len(pages), "draws": BOOTSTRAP_DRAWS, "seed": BOOTSTRAP_SEED,
            "f1": band(f1s), "precision": band(precisions), "recall": band(recalls)}

def entry_exact(truth: set, got: set, entries: set) -> dict:
    """The share of entries whose claim set the route reproduces exactly."""
    t, g = defaultdict(set), defaultdict(set)
    for c in truth:
        t[c[:3]].add(c)
    for c in got:
        g[c[:3]].add(c)
    exact = sum(1 for e in entries if t[e] == g[e])
    return {"entries": len(entries), "exact": exact,
            "share": exact / len(entries) if entries else 0.0}

def per_symbol(truth: set, got: set, entries: set) -> list[dict]:
    """Sensitivity, and specificity over the entries where the gold does not print it."""
    tokens = sorted({c[4] for c in truth | got})
    t_by, g_by = defaultdict(set), defaultdict(set)
    for c in truth:
        t_by[c[4]].add(c[:4])
    for c in got:
        g_by[c[4]].add(c[:4])
    rows = []
    for token in tokens:
        positives, claimed = t_by[token], g_by[token]
        hit = len(positives & claimed)
        false = len(claimed - positives)
        negatives = len(entries) - len(positives)
        rows.append({"token": token, "gold": len(positives), "hit": hit,
                     "missed": len(positives) - hit, "false": false,
                     "sensitivity": hit / len(positives) if positives else None,
                     "specificity": (1 - false / negatives) if negatives > 0 else None})
    return sorted(rows, key=lambda r: (-r["gold"], r["token"]))

def by_category(s: dict, categories: dict) -> dict:
    """The sides with each mark put on its common category (D-147).

    ``categories`` is ``{mark: category}`` (:func:`lxin.load_religion_categories`); a mark
    not in it is its own category, one mapped to ``""`` enters none. Counts on one part
    are summed, the gold's as ints and the route's as text, as each side writes them; a
    category claim's rule joins its marks' rules, so it is the author's if any mark was.
    """
    def fold(counts: dict, as_text: bool) -> tuple[dict, dict]:
        out, members = {}, defaultdict(list)
        for claim, n in counts.items():
            category = categories.get(claim[4], claim[4])
            if not category:
                continue
            key = (*claim[:4], category)
            out[key] = out.get(key, 0) + _printed_count(n)
            members[key].append(claim)
        return ({k: str(v) if as_text else v for k, v in out.items()}, members)

    gold_counts, _gold_members = fold(s["gold_counts"], as_text=False)
    route_counts, route_members = fold(s["route_counts"], as_text=True)
    rules = {key: "; ".join(r for r in (s["rules"].get(c, "") for c in claims) if r)
             for key, claims in route_members.items()}
    return {"gold_entries": s["gold_entries"], "route_entries": s["route_entries"],
            "gold_counts": gold_counts, "route_counts": route_counts, "rules": rules}

"""Score the sealed certification pages — once, against metrics written down first.

This is the one-shot scorer D-55 and the 2026-10-24 audit (§D) ask for. **Everything it
reports is fixed here, before any sealed page was scored** (written 2026-10-25, with the
Czech certification run on disk and nothing yet scored against it). The point of the sealed
half is that nothing was tuned on it; a metric chosen after seeing how the route did on it
would spend that seal as surely as tuning a prompt would.

What it reports, and why each one
---------------------------------
1. **Claim level P / R / F1** on the settlement key ``(page, district, municipality, part,
   token)`` — the unit the analysis consumes, and the unit the gold run is scored on.
2. **A 95 % interval by page-clustered bootstrap**: the pages are resampled with
   replacement (10,000 draws, seed 1910 — the project's own), the percentile interval
   reported. Eight pages are eight clusters, so this interval, not the point estimate, is
   the result. An interval from treating ~500 claims as independent would be about half as
   wide and would be wrong.
3. **``entry_exact``** — the share of entries whose claim set matches the gold's exactly,
   which is what a settlement-level regressor actually needs.
4. **Count accuracy** — among claims the route got right, the share whose printed count
   matches (the gold run reports 875 of 879; this is the sealed equivalent).
5. **Per symbol: sensitivity and specificity.** Sensitivity is recall for that token.
   Specificity is over the entries where the gold does *not* print it:
   ``1 − false claims / entries without it``. Reported with the gold's count beside it,
   because most tokens will have too few instances here to carry a rate (the estimate from
   the gold's own mix is that 33 of 46 Czech symbols have fewer than ten).

Two populations, both reported
------------------------------
* **as printed** — every entry the sealed sheets print. This is the headline: it is the
  route as it will read the volume, misses included.
* **shared entries** — entries both the gold and the route reached, which is the rule
  ``run_frozen.score_claims`` uses on the gold. Reported so the two numbers are comparable;
  it is *not* the headline, because dropping an entry the route never reached would hide
  exactly the failure the sealed half exists to measure.

The author's own rulings are reported apart
-------------------------------------------
On a sealed page the author's ruling and the gold transcription are one person reading one
print, so a claim settled that way is not independent of the truth it is scored against.
Every headline is given twice: with those claims and without them. On the Czech run that is
3 of ~503 claims, so it moves the headline by at most a few tenths of a point — but the
number is stated rather than assumed.

What it refuses
---------------
* An edition whose sealed sheets are not all ``status: complete`` (the German four are cut
  and blank as this is written) — there is nothing to score against, and a partial sheet
  would read as the route inventing claims.

def sealed_paths(edition: str) -> list[Path]:

def sheet_status(path: Path) -> str:
    for line in path.read_text(encoding="utf-8").splitlines()[:20]:

            return line.split(":", 1)[1].split("#")[0].strip()
    return ""

def court_of(edition: str) -> callable:
    """A printed district name → its 1910 court id (D-122), or the name itself.

    The two sides key an entry differently and must be reconciled before anything is
    counted: the route carries the slug the **text layer** gave it, damaged and all — the
    sealed pages file Nechanice as ``mechanice`` and Nová Paka as ``novaraka`` — while a
    gold sheet carries the name the transcriber wrote. Keyed on the printed slug, 170 of
    505 sealed claims look missing when every one of them was read. The court is the key
    D-122 built for exactly this, and the run's own ``courts.csv`` already holds the route's
    side of it.
    """
    from utils.lexikon_1910 import lexikon_1910_courts as lxc

    key = lxc.CourtKey(edition=edition)
    cache: dict[str, str] = {}

    def resolve(name: str) -> str:
        if name not in cache:
            found, _how = key.resolve(name)
            cache[name] = found or name
        return cache[name]

    return resolve


def claims_of(rows: list[dict], court=None) -> tuple[set, dict]:
    """``(entries, {claim: printed count})`` on the settlement key, **every part as text**.

    A sheet read here gives ``muni_seq`` as an int where the gold's CSV gives ``"10"``, and
    the route's inventory is read from a CSV too. An entry keyed one way and a claim keyed
    the other silently matches nothing — a zero score that looks like a total failure — so
    both come back as text.
    """
    entries, _unused, claims = lxin._claim_counts(rows, "settlement")
    as_text = lambda t: tuple(map(str, t))                                    # noqa: E731
    if court is not None:
        as_text = lambda t: (str(t[0]), court(str(t[1])), *map(str, t[2:]))   # noqa: E731
    return ({as_text(entry) for entry in entries},
            {as_text(claim): n for claim, n in claims.items()})


def route_claims(edition: str, inventory: str = "final_inventory.csv") -> tuple[dict, dict, set]:
    """The run's own output: ``{claim: count}``, ``{claim: rule}`` and the entries it reached."""
    import csv

    path = FROZEN / f"{edition}_certification" / inventory
    counts, rules, entries = {}, {}, set()
    with path.open(encoding="utf-8") as fh:
        for row in csv.DictReader(fh):
            # The inventory's own `entry` key where the run wrote one (`run_frozen` 0.10.0),
            # else the court, else the printed slug: the same key the gold side is put on, so
            # a damaged slug cannot read as a missing entry.
            place = (row.get("court_id") or "").strip() or row["district"]
            claim = (row["page"], place, row["muni_seq"],
                     row["settlement_seq"], row["code"])
            counts[claim] = (row.get("count") or "").strip()
            rules[claim] = (row.get("rule") or "").strip()
            entries.add(claim[:3])
    return counts, rules, entries

def prf(hit: int, false: int, missed: int) -> tuple[float, float, float]:
    p = hit / (hit + false) if hit + false else 0.0
    r = hit / (hit + missed) if hit + missed else 0.0
    f = 2 * p * r / (p + r) if p + r else 0.0
    return p, r, f


def score_sets(truth: set, got: set) -> dict:
    hit, false, missed = len(got & truth), len(got - truth), len(truth - got)
    p, r, f = prf(hit, false, missed)
    return {"claims_gold": len(truth), "claims_route": len(got), "hit": hit,
            "false": false, "missed": missed, "precision": p, "recall": r, "f1": f}


def page_clustered_interval(truth: set, got: set) -> dict:
    """Percentile interval over pages resampled with replacement — the clusters are pages."""
    pages = sorted({c[0] for c in truth | got})
    by_page_truth, by_page_got = defaultdict(set), defaultdict(set)
    for c in truth:
        by_page_truth[c[0]].add(c)
    for c in got:
        by_page_got[c[0]].add(c)
    rng = random.Random(BOOTSTRAP_SEED)
    f1s, precisions, recalls = [], [], []
    for _ in range(BOOTSTRAP_DRAWS):
        draw = [rng.choice(pages) for _ in pages]
        hit = false = missed = 0
        for page in draw:
            t, g = by_page_truth[page], by_page_got[page]
            hit += len(g & t)
            false += len(g - t)
            missed += len(t - g)
        p, r, f = prf(hit, false, missed)
        f1s.append(f)
        precisions.append(p)
        recalls.append(r)
    lo, hi = (100 - INTERVAL) / 2, 100 - (100 - INTERVAL) / 2

    def band(values: list[float]) -> list[float]:
        values = sorted(values)
        pick = lambda q: values[min(len(values) - 1, int(q / 100 * len(values)))]  # noqa: E731
        return [pick(lo), pick(hi)]

    return {"pages": len(pages), "draws": BOOTSTRAP_DRAWS, "seed": BOOTSTRAP_SEED,
            "f1": band(f1s), "precision": band(precisions), "recall": band(recalls)}


def entry_exact(truth: set, got: set, entries: set) -> dict:
    """The share of entries whose claim set the route reproduces exactly."""
    t, g = defaultdict(set), defaultdict(set)
    for c in truth:
        t[c[:3]].add(c)
    for c in got:
        g[c[:3]].add(c)
    exact = sum(1 for e in entries if t[e] == g[e])
    return {"entries": len(entries), "exact": exact,
            "share": exact / len(entries) if entries else 0.0}


def count_accuracy(truth_counts: dict, route_counts: dict, shared: set) -> dict:
    """Among claims the route got right, how often the printed count matches."""
    right = sum(1 for c in shared if str(truth_counts[c]) == (route_counts.get(c) or "1"))
    return {"claims": len(shared), "count_right": right,
            "share": right / len(shared) if shared else 0.0}


def per_symbol(truth: set, got: set, entries: set) -> list[dict]:
    """Sensitivity, and specificity over the entries where the gold does not print it."""
    tokens = sorted({c[4] for c in truth | got})
    t_by, g_by = defaultdict(set), defaultdict(set)
    for c in truth:
        t_by[c[4]].add(c[:4])
    for c in got:
        g_by[c[4]].add(c[:4])
    rows = []
    for token in tokens:
        positives, claimed = t_by[token], g_by[token]
        hit = len(positives & claimed)
        false = len(claimed - positives)
        negatives = len(entries) - len(positives)
        rows.append({"token": token, "gold": len(positives), "hit": hit,
                     "missed": len(positives) - hit, "false": false,
                     "sensitivity": hit / len(positives) if positives else None,
                     "specificity": (1 - false / negatives) if negatives > 0 else None})
    return sorted(rows, key=lambda r: (-r["gold"], r["token"]))


def author_dependent(rules: dict) -> set:
    """Claims the author settled: on a sealed page the ruling and the gold transcription are
    one person reading one print, so these are not independent of the truth they are scored
    against. Read off the inventory's own ``rule``, which names every step that settled a
    claim; the marks still in ``rulings_queue.csv`` are counted beside it by the caller,
    since a mark the author has not yet ruled has not entered a claim."""
    return {claim for claim, rule in rules.items() if "author" in rule.lower()}

def score(edition: str, force: bool = False, dry_run: bool = False) -> dict | None:
    out_dir = FROZEN / f"{edition}_certification"
    target = out_dir / "certification_score.json"
    paths = sealed_paths(edition)
    drafts = [p.name for p in paths if sheet_status(p) != "complete"]

    print(f"\n=== {edition}: {len(paths)} sealed sheets, "
          f"{len(paths) - len(drafts)} complete")
    if not paths:
        print("  no sealed sheets — nothing to score")
        return None
    if drafts:
        print(f"  refused: still to transcribe — {', '.join(drafts)}")
        return None
    if not (out_dir / "final_inventory.csv").is_file():
        print(f"  refused: no certification run under {out_dir.relative_to(ROOT)}")
        return None
    if edition in GERMAN_LETTERS and not (out_dir / ABBREVIATIONS).is_file():
        print(f"  refused: no {ABBREVIATIONS} — the cooperatives would be scored as missing (D-139)")
        return None
    if target.exists() and not force:
        print(f"  refused: {target.name} exists — the sealed half is scored once (D-55). "
              "Pass --force to overwrite, and the record will say it was forced.")
        return None
    if dry_run:
        print("  would score: the sheets above against "
              f"{(out_dir / 'final_inventory.csv').relative_to(ROOT)}")
        return None

    both = sides(edition)
    result = {"edition": edition, "scorer": __version__,
              "scored": time.strftime("%Y-%m-%d %H:%M:%S"),
              "forced": bool(force and target.exists()), "sheets": [p.name for p in paths],
              **measure(both), "marks_awaiting_a_ruling": waiting_marks(edition),
              "by_category": measure(by_category(both, _categories()))}
    if edition in GERMAN_LETTERS:
        result["cooperatives"] = COOPERATIVES_NOTE
    if edition == "de-bohemia" and (out_dir / POOLED_PARTS[0][1]).is_file():
        result["without_anchor"] = measure(sides(edition, POOLED_PARTS[0][1]))
    out_dir.mkdir(parents=True, exist_ok=True)
    target.write_text(json.dumps(result, indent=1, ensure_ascii=False), encoding="utf-8")
    (out_dir / "certification_score.txt").write_text(report(result), encoding="utf-8")
    print(report(result))
    print(f"  written: {target.relative_to(ROOT)} and certification_score.txt")
    return result


def gold_cooperatives(edition: str, court) -> tuple[set, dict]:
    """``(entries, {claim: 1})``: a German sealed sheet's cooperative letters as the Czech
    heading, one ``[cooperative]`` on every part that prints at least one (D-139). Decoded
    from the 2b lines by the decoder the readings go through, under the route's own rules
    (``run_frozen.sheet_abbreviations``), so the score measures reading, not decoding."""
    import run_frozen as rf

    _entries, claims = rf.sheet_abbreviations(sealed_paths(edition), edition)
    table = rf.abbreviation_table(edition)
    place = lambda t: (str(t[0]), court(str(t[1])), *map(str, t[2:]))          # noqa: E731
    coops = {place(c[:4]) + (COOPERATIVE,): 1 for c in claims if table[c[4]].kind == "cooperative"}
    return {c[:3] for c in coops}, coops


def route_cooperatives(edition: str) -> tuple[dict, dict, set]:
    """The route's side of :func:`gold_cooperatives`, from its ``final_abbreviations.csv``:
    ``{claim: "1"}``, ``{claim: rule}`` and the entries they are on. The derived claim is the
    author's only if every letter under it was ruled by the author. The anchor asks about
    pictograms only (D-129), so one file serves Böhmen with it and without it."""
    import csv

    counts, rules = {}, defaultdict(list)
    with (FROZEN / f"{edition}_certification" / ABBREVIATIONS).open(encoding="utf-8") as fh:
        for row in csv.DictReader(fh):
            if row["kind"] != "cooperative":
                continue
            place = (row.get("court_id") or "").strip() or row["district"]
            claim = (row["page"], place, row["muni_seq"], row["settlement_seq"], COOPERATIVE)
            counts[claim] = "1"
            rules[claim].append((row.get("rule") or "").strip())
    return counts, {c: ("author" if all("author" in r.lower() for r in rs) else "; ".join(rs))
                    for c, rs in rules.items()}, {c[:3] for c in counts}


def sides(edition: str, inventory: str = "final_inventory.csv", tag: str = "") -> dict:
    """The gold's and the route's claims on one edition's sealed pages. ``tag`` prefixes the
    page, so that editions pooled together never share a page key. A German edition's
    cooperative letters enter as the Czech ``[cooperative]`` heading (D-139)."""
    gold_entries, gold_counts = claims_of(sealed_rows(edition), court_of(edition))
    route_counts, rules, route_entries = route_claims(edition, inventory)
    if edition in GERMAN_LETTERS:
        coop_entries, coops = gold_cooperatives(edition, court_of(edition))
        route_coops, coop_rules, coop_route_entries = route_cooperatives(edition)
        gold_entries, route_entries = gold_entries | coop_entries, route_entries | coop_route_entries
        gold_counts, route_counts = {**gold_counts, **coops}, {**route_counts, **route_coops}
        rules = {**rules, **coop_rules}
    if tag:
        key = lambda c: (f"{tag}:{c[0]}", *c[1:])                                # noqa: E731
        gold_entries, route_entries = {key(e) for e in gold_entries}, {key(e) for e in route_entries}
        gold_counts = {key(c): n for c, n in gold_counts.items()}
        route_counts = {key(c): n for c, n in route_counts.items()}
        rules = {key(c): r for c, r in rules.items()}
    return {"gold_entries": gold_entries, "gold_counts": gold_counts,
            "route_counts": route_counts, "rules": rules, "route_entries": route_entries}


def merge(parts: list[dict]) -> dict:
    """Several editions' sides as one population (their pages already tagged apart)."""
    out = {"gold_entries": set(), "route_entries": set(),
           "gold_counts": {}, "route_counts": {}, "rules": {}}
    for part in parts:
        for key, value in out.items():
            value.update(part[key])
    return out


def _printed_count(value) -> int:
    """A count as the two sides write it: an int on the gold, text on the route, blank = 1."""
    text = str(value).strip()
    return int(text) if text.isdigit() else 1


def by_category(s: dict, categories: dict) -> dict:
    """The sides with each mark put on its common category (D-147).

    ``categories`` is ``{mark: category}`` (:func:`lxin.load_religion_categories`); a mark
    not in it is its own category, one mapped to ``""`` enters none. Counts on one part
    are summed, the gold's as ints and the route's as text, as each side writes them; a
    category claim's rule joins its marks' rules, so it is the author's if any mark was.
    """
    def fold(counts: dict, as_text: bool) -> tuple[dict, dict]:
        out, members = {}, defaultdict(list)
        for claim, n in counts.items():
            category = categories.get(claim[4], claim[4])
            if not category:
                continue
            key = (*claim[:4], category)
            out[key] = out.get(key, 0) + _printed_count(n)
            members[key].append(claim)
        return ({k: str(v) if as_text else v for k, v in out.items()}, members)

    gold_counts, _gold_members = fold(s["gold_counts"], as_text=False)
    route_counts, route_members = fold(s["route_counts"], as_text=True)
    rules = {key: "; ".join(r for r in (s["rules"].get(c, "") for c in claims) if r)
             for key, claims in route_members.items()}
    return {"gold_entries": s["gold_entries"], "route_entries": s["route_entries"],
            "gold_counts": gold_counts, "route_counts": route_counts, "rules": rules}


def _categories() -> dict:
    return lxin.load_religion_categories(RELIGION_CATEGORIES)


def waiting_marks(edition: str) -> int:
    """Marks of the run still waiting for the author (``rulings_queue.csv``)."""
    queue = FROZEN / f"{edition}_certification" / "rulings_queue.csv"
    return max(sum(1 for _ in queue.open(encoding="utf-8")) - 1, 0) if queue.exists() else 0


def measure(s: dict) -> dict:
    """The metrics written above, on both populations, for one set of sides."""
    truth, got = set(s["gold_counts"]), set(s["route_counts"])
    ruled = author_dependent(s["rules"])

    def population(name: str, entries: set) -> dict:
        t = {c for c in truth if c[:3] in entries}
        g = {c for c in got if c[:3] in entries}
        block = score_sets(t, g)
        block["interval"] = page_clustered_interval(t, g)
        block["entry_exact"] = entry_exact(t, g, entries)
        block["count"] = count_accuracy(s["gold_counts"], s["route_counts"], g & t)
        block["without_author_rulings"] = score_sets(t - ruled, g - ruled)
        block["symbols"] = per_symbol(t, g, entries)
        block["population"] = name
        return block

    return {"author_ruled_claims": len(ruled),
            "as_printed": population("as printed — every entry the sealed sheets print",
                                     s["gold_entries"]),
            "shared_entries": population("shared entries — both the gold and the route reached them",
                                         s["gold_entries"] & s["route_entries"])}

    if dry_run:
        print("  would score the sealed pages above as one population")
        return None

    parts = {e: sides(e, inv, tag=e) for e, inv in POOLED_PARTS}
    categories = _categories()
    folded = {e: by_category(s, categories) for e, s in parts.items()}
    result = {"edition": POOLED, "scorer": __version__,
              "scored": time.strftime("%Y-%m-%d %H:%M:%S"),
              "forced": bool(force and target.exists()),
              "sheets": [f"{e}/{p.name}" for e, _inv in POOLED_PARTS for p in sealed_paths(e)],
              "inventories": dict(POOLED_PARTS),
              **measure(merge(list(parts.values()))),
              "marks_awaiting_a_ruling": sum(waiting_marks(e) for e, _inv in POOLED_PARTS),
              "cooperatives": COOPERATIVES_NOTE,
              "per_volume": {e: score_sets(set(s["gold_counts"]), set(s["route_counts"]))
                             for e, s in parts.items()},
              "by_category": measure(merge(list(folded.values()))),
              "per_volume_by_category": {e: score_sets(set(s["gold_counts"]), set(s["route_counts"]))
                                         for e, s in folded.items()}}
    out_dir.mkdir(parents=True, exist_ok=True)
    target.write_text(json.dumps(result, indent=1, ensure_ascii=False), encoding="utf-8")
    (out_dir / "certification_score.txt").write_text(report(result), encoding="utf-8")
    print(report(result))
    print(f"  written: {target.relative_to(ROOT)} and certification_score.txt")
    return result


def _population_lines(b: dict, ruled: int) -> list[str]:

        f"{b['count']['claims']} true claims",
        f"    without the author's own rulings: F1 "
        f"{b['without_author_rulings']['f1']:.3f} ({ruled} claims set aside)",
    ]


def _category_lines(result: dict) -> list[str]:
    """The ``by_category`` block (D-147): both populations, then the folded categories."""
    block = result["by_category"]
    lines = ["", "  BY COMMON CATEGORY — the religious marks on the function every plate "
                 "can express (D-147)"]
    for key in ("as_printed", "shared_entries"):
        lines += _population_lines(block[key], block["author_ruled_claims"])
    for edition, b in result.get("per_volume_by_category", {}).items():
        lines.append(f"    {edition:12} {b['claims_gold']:4} printed  {b['hit']:4} hit  "
                     f"{b['false']:3} false  {b['missed']:3} missed  F1 {b['f1']:.3f}")
    folded = set(_categories().values()) - set(_categories())
    for row in block["as_printed"]["symbols"]:
        if row["token"] in folded:
            sens = f"{row['sensitivity']:.3f}" if row["sensitivity"] is not None else "—"
            lines.append(f"    {row['token']:22} gold {row['gold']:4}  hit {row['hit']:4}  "
                         f"false {row['false']:3}  sensitivity {sens}")
    return lines


def report(result: dict) -> str:
    lines = [f"Certification — {result['edition']}, scored {result['scored']}"
             f"{' (FORCED re-score)' if result['forced'] else ''}",
             f"  sheets: {', '.join(result['sheets'])}"]
    for key in ("as_printed", "shared_entries"):
        lines += _population_lines(result[key], result["author_ruled_claims"])
    if "without_anchor" in result:
        bare = result["without_anchor"]
        lines += ["", "  WITHOUT THE CZECH ANCHOR — the route Mähren and Schlesien get (D-136)"]
        for key in ("as_printed", "shared_entries"):
            lines += _population_lines(bare[key], bare["author_ruled_claims"])
    if "per_volume" in result:
        lines += ["", "  per volume (descriptive: two pages each for Mähren and Schlesien)"]
        for edition, b in result["per_volume"].items():
            lines.append(f"    {edition:12} {b['claims_gold']:4} printed  {b['hit']:4} hit  "
                         f"{b['false']:3} false  {b['missed']:3} missed  F1 {b['f1']:.3f}")
    if "cooperatives" in result:
        lines += ["", f"  {result['cooperatives']}"]
    if "by_category" in result:
        lines += _category_lines(result)
    top = result["as_printed"]["symbols"]
    lines += ["", "  per symbol (as printed; a rate on under ten instances is not a rate)",
              f"    {'token':22} {'gold':>5} {'hit':>4} {'miss':>5} {'false':>6} "
              f"{'sens':>6} {'spec':>7}"]
    for row in top:
        sens = f"{row['sensitivity']:.3f}" if row["sensitivity"] is not None else "—"
        spec = f"{row['specificity']:.4f}" if row["specificity"] is not None else "—"
        lines.append(f"    {row['token'][:22]:22} {row['gold']:5} {row['hit']:4} "
                     f"{row['missed']:5} {row['false']:6} {sens:>6} {spec:>7}")
    return "\n".join(lines)


def main() -> int:
    ap = argparse.ArgumentParser(description=__doc__,
                                 formatter_class=argparse.RawDescriptionHelpFormatter)
    ap.add_argument("--edition", default="cz", choices=(*EDITIONS, POOLED, "all"))
    ap.add_argument("--force", action="store_true",
                    help="overwrite a score already written; the record says it was forced")
    ap.add_argument("--dry-run", action="store_true",
                    help="say what would be scored, write nothing")
    args = ap.parse_args()

    editions = (*EDITIONS, POOLED) if args.edition == "all" else (args.edition,)
    done = [score_pooled(force=args.force, dry_run=args.dry_run) if e == POOLED
            else score(e, force=args.force, dry_run=args.dry_run) for e in editions]
    return 0 if any(d is not None for d in done) or args.dry_run else 1
