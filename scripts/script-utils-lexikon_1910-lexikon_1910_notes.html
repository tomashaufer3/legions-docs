How it works

Columns 16 and 17 of the table print keys — 13), 10) 2 1/4 — that point into a block beneath the table body. Until now that block was outside the extraction entirely: utils.lexikon_1910.lexikon_1910.body_band deliberately ends where the shortest column rule stops, so the pipeline transcribed pointers into a legend it never read.

The block is found the same way the table is — from the printed rules, not from the text. A short vertical rule starts where the body rules stop and splits the footnote into two columns; its own extent gives the band and its x position gives the split.

It is a column flow, not a two-part layout. The text runs down the left column and continues at the top of the right, newspaper-fashion, and within that flow two kinds of section alternate, each introduced by its own heading:

Části osad v soudním okresu X the parts each settlement is made of, each with a house–population pair Úřady, ústavy a t. d. v soudním okresu X post office, telegraph, parish, school, railway station and altitude, keyed by the numbers the table references

So a section is not a column: one page carries the tail of one district's offices and the head of the next district's parts, and both may straddle the divider. Sections are therefore cut on their headings in reading order, which also recovers the thing that makes the key check work — the district each key set belongs to. The numbering restarts in every soudní okres, so a key set pooled across districts would resolve almost any reference and check nothing.

What is recoverable here is much less than what is printed, and the difference is the point. The offices sections are mostly pictograms — a post horn, a bell, a telegraph key — which carry the meaning and which the OCR renders as Щ1, gg§!, ф, ľ. No amount of parsing recovers a symbol the engine never saw. This module extracts the three things that survive as text — the key numbers, the altitudes in metres, and the house–population pairs — and reports the rest as unrecovered rather than guessing at it.

What the key numbers are good for is a closed-set check. Within one soudní okres they run 1..N, so a key referenced from the table that is not in the set is an OCR error with a short candidate list. That is how ,3) is recoverable as 13): 13 is in the set and ,3 is not.

def legend_key_marks(text: str) -> list:
    """The ``n)`` marks in a legend block that actually open an entry.

    **The one place that decides what a legend key is**, for the machine reading
    and the gold transcription alike — `read_transcription_md` calls this rather
    than carrying its own copy, because the two are compared entry by entry and a
    second regex would drift on exactly the entries that disagree.

    Two things are not keys. An asterisk footnote marker is one, handled above.
    The other is the closing bracket of a parenthetical inside a PLACE NAME:
    `_LEGEND_KEY_RE` allows up to three arbitrary characters before the `)` so it
    can still admit an OCR-mangled key (``ß)``, ``t)``, ``э)``, ``M')``), and that
    licence also matches the `sko)` at the end of `Kupferhammer-Grünthal (Sasko)`.
    The volume prints those constantly — the postal place for a border village is
    across the frontier, `(Sasko)`, `(Prusko)`.

    Left in, it does not merely add a junk entry. Entries here are numbered by
    POSITION, so a phantom mark **shifts every key after it by one** for the rest
    of the district: on scan 0118 the entry printed `15) Strupčice` came back as
    key 17, and a table row pointing at `15)` then resolved to Reitzenhain — with
    the verdict `resolved`, and nothing but `key_repaired` to show for it.
    """

            if not (_ASTERISK_ONLY_RE.match(m.group(1))
                    and not any(c.isdigit()
                                for c in text[max(0, m.start() - _KEY_LOOKBACK):
                                              m.start()]))
            and not _closes_parenthetical(text, m.end() - 1)]

def normalise(name: str) -> str:
    """Match key for a district name: unaccented, lowercase, letters only."""
    decomposed = unicodedata.normalize("NFKD", str(name or ""))
    stripped = "".join(c for c in decomposed if not unicodedata.combining(c))
    return re.sub(r"[^a-z]", "", stripped.lower())

def find_heading(line: str) -> tuple[str, str, int] | None:
    """``(kind, district, end)`` if this line opens a section, else None.

    ``end`` is where the heading stops, so the caller keeps whatever the same
    printed line carries after it — an entry often starts on the heading's own
    line. Anything *before* the heading belongs to the previous section and is
    dropped by the caller, which is what the old regex did too.

    Every tail on the line is tried in turn, because an entry body can print a
    colon (``Kč: ígt£ 240 m``) and the first colon is not always the heading's.
    """
    for match in HEADING_TAIL_RE.finditer(line):
        prefix = normalise(line[:match.start()])[-_MARK_WINDOW:]
        parts = any(mark in prefix for mark in PARTS_MARKS)
        offices = any(mark in prefix for mark in OFFICES_MARKS)
        if parts == offices:        # neither, or both — refuse rather than pick
            continue
        return ("parts" if parts else "offices",
                match.group("district").strip(" .,;-—–"), match.end())
    return None

class Notes:
    """The footnote apparatus of one page."""

    page: str
    top: int
    bottom: int
    split_x: int
    left_lines: list[str] = field(default_factory=list)
    right_lines: list[str] = field(default_factory=list)
    #: Where the *text* of the apparatus starts — the foot of the table body, which
    #: is above where the divider rule begins, because the section headings are
    #: printed over the full width before the two columns open. ``top`` is the
    #: rule's own start and is not the band; cropping an image at ``top`` cuts every
    #: heading off, and a heading is what tells a section which district it belongs
    #: to. Defaults to 0 so a Notes assembled by hand (the vision channel) is legal.
    band_top: int = 0
    #: Everything below the divider rule's foot, clustered full width. The two
    #: columns stop at the divider; the postal/railway legend runs the whole width
    #: beneath it, so it is neither a left nor a right column line.
    footer_lines: list[str] = field(default_factory=list)
    #: ``(top, bottom)`` in ALTO pixels for each line of the two columns, parallel
    #: to ``left_lines`` / ``right_lines``. This is what lets a *section* be cut out
    #: of the page as an image rather than only out of the text: the heading is a
    #: line, and a line the clusterer already knows the extent of.
    #:
    #: Empty on a :class:`Notes` assembled by hand from a model's reply, because
    #: that reader is handed an image and never sees a coordinate. Consumers check
    #: the length rather than assuming it — see :func:`section_segments`.
    left_bounds: list[tuple[int, int]] = field(default_factory=list)
    right_bounds: list[tuple[int, int]] = field(default_factory=list)

    @property
    def reading_order(self) -> list[str]:
        """Left column top-to-bottom, then right column — how the block is read."""
        return [*self.left_lines, *self.right_lines]

    def sections(self) -> list[Section]:
        """Cut the flow into sections on their headings.

        Lines before the first heading belong to a section that began on an earlier
        page. They are dropped rather than attached to the first heading found here,
        which would file one district's entries under the next district's name and
        quietly corrupt the very scoping this exists to provide.
        """
        found: list[Section] = []
        for line in self.reading_order:
            heading = find_heading(line)
            if heading:
                kind, district, end = heading
                found.append(Section(kind=kind, district=district, page=self.page,
                                     lines=[line[end:]]))
            elif found:
                found[-1].lines.append(line)
        return found

def divider_rule(page, body_bottom: int) -> dict | None:
    """The short vertical rule separating the two footnote columns.

    Returns the tallest rule starting at or below the table body and sitting well
    inside the frame, or None when the engine found none — in which case the page
    has no recoverable footnote geometry and is reported as such rather than split
    at a guessed midpoint.
    """
    left = page.print_left
    width = page.print_width or page.width
    candidates = []
    for rule in page.verticals:
        centre = rule["HPOS"] + rule["WIDTH"] // 2
        position = (centre - left) / width if width else 0.5
        if not _INNER_MIN <= position <= _INNER_MAX:
            continue
        if rule["VPOS"] < body_bottom - _DIVIDER_SLACK:
            continue
        candidates.append(rule)
    return max(candidates, key=lambda r: r["HEIGHT"]) if candidates else None

def fallback_divider(page) -> dict | None:
    """The divider found without the table's body band.

    :func:`divider_rule` rejects a rule that starts far above the table's foot
    as ``lexikon_1910.body_band`` reports it. On 22 table scans that foot is wrong
    — the band runs on into the apparatus, to 4,007 px on scan 0026 against a
    divider starting at 3,375 — so a printed divider was rejected and the whole
    apparatus of the page was never read (audit of 2026-10-14). This takes the
    rule the page actually prints: the one near the middle of the frame whose
    foot is lowest on the sheet, if it reaches the lower part of the page at all.
    Used only where :func:`divider_rule` found nothing, so no page that worked
    before is cut differently by it.
    """
    width = page.print_width or page.width
    if not width:
        return None
    central = [r for r in page.verticals
               if r["HEIGHT"] >= _FALLBACK_MIN_HEIGHT
               and _CENTRE_MIN <= (r["HPOS"] + r["WIDTH"] // 2 - page.print_left)
               / width <= _CENTRE_MAX]
    if not central:
        return None
    rule = max(central, key=lambda r: r["VPOS"] + r["HEIGHT"])
    if rule["VPOS"] + rule["HEIGHT"] < _FALLBACK_MIN_FOOT * page.height:
        return None
    return rule

def table_foot(page, divider_top: int) -> int | None:
    """Where the table's column rules end, above the apparatus.

    ``lexikon_1910.body_band`` ends the table body at a low percentile of its
    rules' feet, which is right for clustering rows and wrong as the top of the
    apparatus: on 227 table scans the last one to three table rows lie below it,
    so they were read as a section carried over from the previous page and sent
    to the reader as one (scan 0196, Hrnčíře and Šeberov, filed under the offices
    of Královské Vinohrady). The rules themselves say where the table stops: the
    lowest foot among the column rules that start well up in the table, inside the
    frame, and end above the divider.
    """
    width = page.print_width or page.width
    if not width:
        return None
    feet = [r["VPOS"] + r["HEIGHT"] for r in page.verticals
            if r["HEIGHT"] >= 150
            and r["VPOS"] < divider_top - _TABLE_RULE_LEAD
            and r["VPOS"] + r["HEIGHT"] <= divider_top + 8
            and 0.05 <= (r["HPOS"] + r["WIDTH"] // 2 - page.print_left) / width <= 0.95]
    return max(feet) if feet else None

        same words that drift apart put a section's crop over the wrong lines.

                for row in rows]

    right = cluster([s for s in band if s[1] + s[2] // 2 >= split_x])

        page=page.stem, top=rule["VPOS"], bottom=bottom, split_x=split_x,
        band_top=band_top,

        right_lines=[text for text, _t, _b in right],
        left_bounds=[(t, b) for _text, t, b in left],
        right_bounds=[(t, b) for _text, t, b in right],

def line_cuts(page, box: tuple[int, int, int, int], slices: int) -> list[int]:
    """Where to cut a region into ``slices`` strips **between printed lines**.

    Returns the interior cut positions in ALTO pixels, so a caller gets
    ``slices`` strips from ``slices - 1`` cuts.

    A local vision model has far less usable resolution than a hosted one, and a
    1,350 x 1,330 column of six-point type is where that shows. Strips fix it —
    but only if no strip begins or ends mid-line. Cutting at an even fraction of
    the height slices through the middle of a line of print roughly as often as
    not, and the two halves are then either both misread or, worse, one half is
    read as a plausible short entry.

    The ALTO already knows where every word sits, so the gaps between lines are
    measurable rather than estimated: the strips are cut at the real whitespace
    nearest each even division. Overlap is therefore unnecessary, which matters
    because overlap has to be de-duplicated afterwards, and de-duplicating OCR
    output means deciding which of two disagreeing readings of the same line to
    keep — a judgement this pipeline has no basis to make.

    Falls back to even division only when no such whitespace exists, which is
    reported by the caller rather than hidden — see :func:`crop_notes`.

    **Line boundaries are not enough here, which is why this works on coverage.**
    Clustering the words into lines and cutting between them puts the cut through
    a glyph about as often as not: the raised key figures sit half a line above
    their own text, so consecutive lines *overlap* vertically and the midpoint of
    the gap between two line centres is frequently inside a superscript. What is
    needed is a y with no word box over it at all, and that is a sweep over the
    word extents rather than an average of them.
    """
    left, top, right, bottom = box
    if slices <= 1 or bottom - top < 40:
        return []
    spans = [(s[0], s[0] + s[3]) for s in page.strings
             if top <= s[0] + s[3] // 2 <= bottom
             and left <= s[1] + s[2] // 2 <= right]

    # Sweep the word extents into the maximal y ranges covered by no glyph.
    free: list[tuple[int, int]] = []
    if spans:
        events = sorted([(a, 1) for a, _b in spans] + [(b, -1) for _a, b in spans])
        depth, last_end = 0, top
        for position, delta in events:
            if depth == 0 and position > last_end:
                free.append((last_end, position))
            depth += delta
            if depth == 0:
                last_end = position
        if last_end < bottom:
            free.append((last_end, bottom))
    free = [(a, b) for a, b in free if b - a >= 4 and top < (a + b) // 2 < bottom]

    step = (bottom - top) / slices
    cuts: list[int] = []
    available = list(free)
    for i in range(1, slices):
        target = int(top + step * i)
        if available:
            # Each band is spent once. Without this, two adjacent targets in a
            # column with little whitespace both snap to the same gap and the run
            # emits a 70-pixel strip beside a full-height one — the tiling is still
            # exact, but the point of slicing is lost.
            band = min(available, key=lambda g: abs((g[0] + g[1]) // 2 - target))
            available.remove(band)
            target = (band[0] + band[1]) // 2
        if target not in cuts and top < target < bottom:
            cuts.append(target)
    return sorted(cuts)

    ``[{name, topographic, topographic_raw, houses, population, position}]``.

    **The canonical splitter for this document, used by the model side and by the
    gold transcription alike.** Two copies of it would drift on exactly the
    entries where drift matters — the ones with a bilingual name, a mark, or the
    ``&`` residual — so :mod:`utils.lexikon_1910.read_transcription_md` imports this
    rather than carrying its own.

    Splitting is by accumulation, not by ``split(",")``: a fragment is closed only
    once it ends in a house–population pair, so ``Hazlov, Haslau 217—2266`` stays
    one part instead of becoming ``Hazlov`` and ``Haslau 217—2266``.

    **Only a bracketed mark is returned as `topographic`.** A vision pass runs
    behind :func:`~utils.lexikon_1910.lexikon_1910_vision.guard_tokens` and returns
    ``[ves]``; the gold sheet asks for the same token; those two are comparable.
    The ALTO text layer returns whatever the engine made of the pictogram — ``Q``,
    ``©``, ``(«“■)``, ``»`` — and naming that is precisely what D-39 established
    the text layer cannot do. It is kept verbatim in ``topographic_raw``, for the
    eye and for counting how many marks were printed, and it is **never** offered
    as a code.

    out: list[dict] = []
    fragments: list[str] = []
    carry = ""
    for piece in _part_pieces(str(text or "")):
        carry = f"{carry},{piece}" if carry else piece
        if _PART_RE.match(carry):
            fragments.append(carry)
            carry = ""
    if carry.strip():
        fragments.append(carry)

    for position, fragment in enumerate(fragments):
        match = _PART_RE.match(fragment)
        if not match:
            out.append({"name": fragment.strip(), "topographic": "",
                        "topographic_raw": "", "houses": "", "population": "",
                        "position": position, "unparsed": fragment.strip()})
            continue
        body = match.group("body").strip()
        wrapped = _TOKEN_PARENS_RE.search(body)
        bracket = _BRACKET_RE.search(body)
        parens = _GLYPH_PARENS_RE.search(body)
        if wrapped:
            token = wrapped.group(1)
            name, raw = body[:wrapped.start()].strip(), wrapped.group(0).strip()
        elif bracket:
            token = bracket.group(1)
            name, raw = body[:bracket.start()].strip(), ""
        elif parens:
            # The engine wraps a pictogram in parentheses often enough to be a
            # rule of its own — `(«“■)`, `(»'*)`, `(■“•)`, `(Jj;)`. Taking it
            # before the word cut below is what keeps `(Jj` out of the NAME: the
            # `j` reads as lower case, so the word test counted it as part of the
            # name and left the name ending mid-glyph.
            token = ""
            name, raw = body[:parens.start()].strip(), parens.group(0).strip()
        elif body.endswith(")") and "(" in body:
            # A parenthesis that survived the glyph test above is prose, and the
            # register puts the linkage there: `Červená, Čerwena 3. odd. (viz
            # Milevsko 14 a 52)` says which division of a settlement this is. The
            # word cut below stops at the last lower-case word — `a` — and would
            # take `52)` for a mark, truncating the cross-reference the protocol
            # explicitly asks a transcriber to honour.
            token, name, raw = "", body, ""
        else:
            token = ""
            words = list(_WORDISH_RE.finditer(body))
            if words:
                cut = words[-1].end()
                name, raw = body[:cut].strip(), body[cut:].strip(" .")
            else:
                # No word at all: the `&` residual, which the register prints as
                # an entry in its own right and which carries a mark of its own
                # (`& ■ 1 —3`). Cutting after the first token keeps the two apart
                # instead of reading `& ■` as the name of a place.
                head, _, tail = body.partition(" ")
                name, raw = head.strip(), tail.strip(" .")

            "houses": match.group("houses").replace(" ", ""),
            "population": match.group("pop").replace(" ", ""),
            "position": position, "unparsed": "",
        })
    return out

def parts_check(blocks, sections) -> list[dict]:
    """Grade each ``Části osad`` entry's part-sums against its settlement's row.

    An entry is matched to a row by *name*, not by the printed sequence number:
    column 1 is the most heavily damaged in the table (``o``, ``в``, ``Г) o``), so
    joining on it would lose most entries to OCR rather than to disagreement. Where
    an entry's names hit more than one row the match is refused, not resolved on
    ordering — the same tie discipline the rest of the pipeline uses.
    """
    from utils.lexikon_1910 import lexikon_1910 as lx

    index = _row_index(blocks)
    findings: list[dict] = []
    for section in sections:
        if section.kind != "parts":
            continue
        page_index = index.get(section.page, {})
        for line in _entries(section):
            pairs = [(int(h), int(p)) for h, p in PART_RE.findall(line)]
            if not pairs:
                continue
            houses, population = sum(h for h, _ in pairs), sum(p for _, p in pairs)
            candidates = {normalise(n) for n in _NAME_RE.findall(line)}
            matched = {id(r): r for key in candidates for r in page_index.get(key, [])}
            rows = list(matched.values())
            base = {"check": "I8_parts", "district": section.district,
                    "page": section.page, "n_parts": len(pairs),
                    "parts_houses": houses, "parts_pop": population}
            if not rows:
                findings.append({**base, "row_name": "", "verdict": "unmatched",
                                 "detail": f"no table row named in: {line[:60]!r}"})
                continue
            if len(rows) > 1:
                findings.append({
                    **base, "row_name": "", "verdict": "ambiguous",
                    "detail": f"{len(rows)} rows match the names in this entry"})
                continue
            row = rows[0]
            for column, total in (("houses", houses), ("pop_total", population)):
                value, status = lx.parse_int_cell(row.get(column))
                if status == "bad":
                    verdict, detail = "recoverable", (
                        f"table {column} unreadable ({row.get(column)!r}); "
                        f"footnote parts give {total}")
                elif status == "blank":
                    verdict, detail = "na", ""
                elif value == total:
                    verdict, detail = "pass", ""
                else:
                    verdict, detail = "fail", (
                        f"table {column}={value} vs parts sum {total}")
                findings.append({**base, "column": column,
                                 "row_name": row.get("name")[:40],
                                 "verdict": verdict, "detail": detail})
    return findings

def lexikon_1910_notes_report(notes_list, sections, findings) -> str:
    """Ledger for the footnote apparatus."""
    lines = [f"lexikon_1910_notes v{__version__} — footnote apparatus", ""]
    if not notes_list:
        return "\n".join(lines + ["  no page yielded a footnote divider rule"])

    defined = keys_by_district(sections)
    parts = parts_by_district(sections)
    heights = altitudes(sections)
    n_parts = sum(len(v) for v in parts.values())
    kinds = {"parts": 0, "offices": 0}
    for s in sections:
        kinds[s.kind] = kinds.get(s.kind, 0) + 1

    lines.append(f"  band located on {len(notes_list)} pages")
    lines.append(f"  sections cut:      {kinds['parts']} parts, "
                 f"{kinds['offices']} offices, over "
                 f"{len({s.key for s in sections})} soudní okresy")
    lines.append(f"  keys defined:      {sum(len(v) for v in defined.values())} "
                 f"across {len(defined)} districts")
    lines.append(f"  altitudes read:    {len(heights)}"
                 + (f"  median {sorted(heights)[len(heights) // 2]} m"
                    if heights else ""))
    lines.append(f"  part house–pop pairs read: {n_parts}")
    lines.append("")

    counts: dict[str, int] = {}
    for f in findings:
        counts[f["verdict"]] = counts.get(f["verdict"], 0) + 1
    graded = counts.get("pass", 0) + counts.get("fail", 0)

    # A disagreement has two very different shapes and pooling them hides both.
    # When the parts fall far short of the table the entry was almost certainly
    # cut off by a page break — the apparatus continues overleaf — and that is a
    # coverage limit, not a reading conflict. When the two are the same size but
    # differ, one of them genuinely misread a digit, which is the whole point of
    # having a second channel.
    conflicts = [f for f in findings if f["verdict"] == "fail"
                 and f["parts_" + ("houses" if f.get("column") == "houses"
                                   else "pop")] > 0.9 * _table_value(f)]
    truncated = counts.get("fail", 0) - len(conflicts)

    lines.append("  I8 — footnote part-sums against the table row they belong to")
    if graded:
        lines.append(f"    agree                              {counts.get('pass', 0):5d}"
                     f"   {counts.get('pass', 0) / graded:6.1%}")
        lines.append(f"    conflict — same size, digits differ  {len(conflicts):5d}")
        lines.append(f"    parts fall short — entry continues overleaf "
                     f"{truncated:5d}")
    lines.append(f"    recovers a cell the table could not read  "
                 f"{counts.get('recoverable', 0):5d}")
    lines.append(f"    entry matched no table row                "
                 f"{counts.get('unmatched', 0):5d}")
    lines.append(f"    entry matched several rows — refused      "
                 f"{counts.get('ambiguous', 0):5d}")
    if conflicts:
        lines.append("")
        lines.append("    conflicts — the two channels read the same figure "
                     "differently:")
        for f in conflicts:
            lines.append(f"      {f.get('row_name', '')}: {f['detail']}")

    lines.append("")
    lines.append("  This is a fourth reading channel, not a legend: the parts are the")
    lines.append("  same figures set a second time elsewhere on the page, so an error")
    lines.append("  in one is uncorrelated with the other.")
    lines.append("")
    lines.append("  Not recovered: what the office keys *mean*. Those sections are")
    lines.append("  pictographic — post horn, bell, telegraph, school — and the OCR")
    lines.append("  renders the glyphs as noise. Their numbering also restarts inside")
    lines.append("  each municipality, so there is no district-wide key set to check")
    lines.append("  a reference against. Both need the page image, not this text layer.")
    return "\n".join(lines)

"""The footnote apparatus printed below the 1910 register table.

Columns 16 and 17 of the table print *keys* — ``13)``, ``10) 2 1/4`` — that point
into a block beneath the table body. Until now that block was outside the
extraction entirely: :func:`~utils.lexikon_1910.lexikon_1910.body_band` deliberately
ends where the shortest column rule stops, so the pipeline transcribed pointers
into a legend it never read.

The block is found the same way the table is — from the printed rules, not from the
text. A short vertical rule starts where the body rules stop and splits the
footnote into two columns; its own extent gives the band and its x position gives
the split.

**It is a column flow, not a two-part layout.** The text runs down the left column
and continues at the top of the right, newspaper-fashion, and within that flow two
kinds of section alternate, each introduced by its own heading:

  ``Části osad v soudním okresu X``      the parts each settlement is made of,
                                         each with a house–population pair
  ``Úřady, ústavy a t. d. v soudním okresu X``   post office, telegraph, parish,
                                         school, railway station and altitude,
                                         keyed by the numbers the table references

So a section is *not* a column: one page carries the tail of one district's offices
and the head of the next district's parts, and both may straddle the divider.
Sections are therefore cut on their headings in reading order, which also recovers
the thing that makes the key check work — **the district each key set belongs to.**
The numbering restarts in every soudní okres, so a key set pooled across districts
would resolve almost any reference and check nothing.

**What is recoverable here is much less than what is printed, and the difference is
the point.** The offices sections are mostly *pictograms* — a post horn, a bell, a
telegraph key — which carry the meaning and which the OCR renders as ``Щ1``,
``gg§!``, ``ф``, ``ľ``. No amount of parsing recovers a symbol the engine never
saw. This module extracts the three things that survive as text — the key numbers,
the altitudes in metres, and the house–population pairs — and reports the rest as
unrecovered rather than guessing at it.

What the key numbers are good for is a closed-set check. Within one soudní okres
they run 1..N, so a key referenced from the table that is not in the set is an OCR
error with a short candidate list. That is how ``,3)`` is recoverable as ``13)``:
13 is in the set and ``,3`` is not.
"""

from __future__ import annotations

import re
import unicodedata
from dataclasses import dataclass, field

__version__ = "0.11.0"

#: The divider must start no higher than this far above the body band's bottom.
_DIVIDER_SLACK = 120

#: The divider sits between the two footnote columns, so a rule near either page
#: edge is the frame, not the divider.
_INNER_MIN, _INNER_MAX = 0.20, 0.80

#: A footnote key: one or two digits followed by a closing parenthesis. The OCR
#: routinely inserts a space (``13 )``) and mangles the digit, so the pattern is
#: deliberately loose and the closed-set check is what separates key from noise.
KEY_RE = re.compile(r"(\d{1,2})\s*\)")

#: ``425 m`` — altitude above sea level. Bounded because a five-digit metre
#: reading in Bohemia is OCR damage, not a mountain.
ALTITUDE_RE = re.compile(r"\b(\d{2,4})\s*m\b")

#: ``58—386`` — houses and population of one part of a settlement. The dash is an
#: em-dash in print and anything at all after OCR.
PART_RE = re.compile(r"(\d{1,4})\s*[—–-]\s*(\d{1,5})")

#: The **tail** of a section heading: the soudní okres it names, closed by the
#: colon that ends every heading.
#:
#: Anchored on ``okres`` rather than on the heading's first word, and that is the
#: whole point. The first word is the single most damaged text in the apparatus,
#: because it is set in a larger face the engine handles worst: ``Úřady`` comes
#: back as ``Hřady``, ``tířady``, ``TJřady``, ``brady``, ``Ĺ ř a d v .``,
#: ``I řady``; ``Části`` as ``Ciísti``, ``Gusti``, ``t asti``, ``(J àsti``,
#: ``Óíi,4ti``. A rule that matched on it lost **137 of 1,146 headings (12%)**
#: across the volume.
#:
#: **A lost heading is worse than a lost line.** :meth:`Notes.sections` attaches
#: every line it cannot open a section with to the *previous* section — so a missed
#: heading did not drop that district's entries, it filed them under its
#: neighbour, which is exactly the corruption the section cutting exists to
#: prevent. The 137 include page 270's ``Hřady, ústavy a t. d. v soudním okresu
#: Česká Skalice:``, whose institution entries were being read as Most's.
#:
#: Even the preposition is not safe (``y``, ``л-``, ``т``, ``\``, ``v.``), nor is
#: ``soudním`` (``souduím``, ``soudiím``, ``s.oudním``, ``$pudním``), so neither is
#: required. What survives everywhere is ``okres`` followed by a name and a colon.
#:
#: **Not quite everywhere** (2026-10-05). ``okresu`` itself is damaged on 30 of the
#: volume's 1,234 headings — ``otřesu`` 20 times, and ``oki-esu``, ``okre'su``,
#: ``okr,esu``, ``©křesu``, ``skresu``, ``otrasu`` — and each of those sections was
#: carried into the one before it. Scan 0451 is the case that showed it: *Části
#: osad v soudním otřesu Trutnov* was read as the tail of Trutnov's offices section
#: from scan 0450, so thirteen place-type symbols were filed as institutions. What
#: every one of the thirty keeps is the word's **ending**, so the tail also accepts
#: any short word that ends in ``su``. The marks rule below is unchanged and is
#: what keeps that from claiming a line of an entry.
HEADING_TAIL_RE = re.compile(
    r"(?:okres\w{0,2}|(?<!\S)\S{3,6}su)\s*[.,;]?\s*(?P<district>[^:]{2,40}):",
    re.IGNORECASE)

#: What the words *before* the tail must contain for the line to be a heading, and
#: which of the two kinds it is. Fragments rather than words, chosen to survive the
#: damage above: ``sti`` sits inside every reading of *Části* seen in the volume,
#: ``rady``/``stav`` inside every reading of *Úřady, ústavy*.
#:
#: **The two marks are also the guard.** A line is claimed as a heading only when
#: exactly one side matches: a prefix carrying both, or neither, is left alone
#: rather than assigned to the likelier kind. Over the whole volume that rule
#: reproduces the old regex on all 1,009 headings it found — same kind, same
#: district, no losses — recovers the 137 it missed, and claims **nothing else**:
#: no line in 20,726 matched a tail and classified without being a printed heading.
PARTS_MARKS = ("sti", "osad")
OFFICES_MARKS = ("rady", "stav")

#: How far back from the tail the marks are looked for, in letters. The heading is
#: short; a whole line's worth of lookback would let an entry body that happens to
#: contain ``stav`` open a section.
_MARK_WINDOW = 40

#: The **third** footnote block, and the one that resolves columns 16 and 17. It is
#: printed across the full page width *below* the two-column apparatus, introduced
#: by the post and railway symbols and the phrase "for the judicial district X":
#:
#:     ✉ a 🚂 k s. o. Aš:  ¹) Aš.  ²) Aš Hoferstraße.  ³) Aš připojení. …
#:     ✉ und 🚂 zum GB. Asch:  ¹) Asch 1.  ²) Asch Hoferstraße. …
#:
#: This is the legend the table's ``post_key`` and ``station_note`` point into, and
#: its numbering **is** district-wide — which is the opposite of what this module
#: concluded when it could only see the offices sections, whose numbering restarts
#: inside each municipality. The block sits below the divider rule, so the band was
#: cutting it off and it was never read at all.
#:
#: The leading symbols are OCR noise (``*£y a ggfc``, ``O' a``), so the anchor is
#: the phrase, not the symbols.
POSTAL_INTRO_RE = re.compile(
    r"\bk\s+s\s*\.\s*[oO0]\s*\.\s*(?P<district>[^:]{2,40}):"     # Czech
    r"|\bzum\s+GB\s*\.\s*(?P<district_de>[^:]{2,40}):",          # German
    re.IGNORECASE)

#: One legend entry: a key, then the place name up to the next key.
_LEGEND_KEY_RE = re.compile(r"([^\s)]{1,3})\s*\)")

#: ``*)`` and ``**)`` are the *other* footnote markers — "town X is divided
#: into…", "see appendix" — and counting one as a legend entry shifts every key
#: after it by one. But a bare asterisk is also what the OCR makes of a digit in a
#: superscript key (``1*)`` is 14 with the 4 lost), so the token alone cannot
#: decide it. A digit in the few characters before the marker does: that is the
#: rest of the key figure.
_ASTERISK_ONLY_RE = re.compile(r"^\*+$")
_KEY_LOOKBACK = 4

#: How far back to look for the bracket that decides whether a `)` is a key.
#:
#: Bounded, and deliberately. Balancing the whole block instead would let ONE
#: unmatched `(` — and the footer is where the OCR puts its worst noise — swallow
#: every key after it. Within this window the nearest bracket is the answer; past
#: it, the `)` is treated as a key, which is the failure that loses one entry
#: rather than a district.
_PAREN_LOOKBACK = 60


def _closes_parenthetical(text: str, pos: int) -> bool:
    """Is the ``)`` at ``pos`` closing a ``(``, rather than opening an entry?"""
    for i in range(pos - 1, max(-1, pos - 1 - _PAREN_LOOKBACK), -1):
        if text[i] == ")":
            return False
        if text[i] == "(":
            return True
    return False


def legend_key_marks(text: str) -> list:
    """The ``n)`` marks in a legend block that actually open an entry.

    **The one place that decides what a legend key is**, for the machine reading
    and the gold transcription alike — `read_transcription_md` calls this rather
    than carrying its own copy, because the two are compared entry by entry and a
    second regex would drift on exactly the entries that disagree.

    Two things are not keys. An asterisk footnote marker is one, handled above.
    The other is the closing bracket of a parenthetical inside a PLACE NAME:
    `_LEGEND_KEY_RE` allows up to three arbitrary characters before the `)` so it
    can still admit an OCR-mangled key (``ß)``, ``t)``, ``э)``, ``M')``), and that
    licence also matches the `sko)` at the end of `Kupferhammer-Grünthal (Sasko)`.
    The volume prints those constantly — the postal place for a border village is
    across the frontier, `(Sasko)`, `(Prusko)`.

    Left in, it does not merely add a junk entry. Entries here are numbered by
    POSITION, so a phantom mark **shifts every key after it by one** for the rest
    of the district: on scan 0118 the entry printed `15) Strupčice` came back as
    key 17, and a table row pointing at `15)` then resolved to Reitzenhain — with
    the verdict `resolved`, and nothing but `key_repaired` to show for it.
    """
    return [m for m in _LEGEND_KEY_RE.finditer(text)
            if not (_ASTERISK_ONLY_RE.match(m.group(1))
                    and not any(c.isdigit()
                                for c in text[max(0, m.start() - _KEY_LOOKBACK):
                                              m.start()]))
            and not _closes_parenthetical(text, m.end() - 1)]

#: A footer token shorter than this share of the line's median height is a
#: **superscript** — the raised key figures, and the abbreviation points of
#: ``k s. o.``. They sit about 20 px above the text they belong to, exactly half a
#: line, so plain centre-clustering either splits them onto their own line or
#: chains every band into one blob. Both scramble entry order.
_SUPERSCRIPT_SHARE = 0.75

#: A railway **stop** (*zastávka*) rather than a full station (*stanice*).
#:
#: This was recorded as "a rail symbol was printed here", on the reasoning that the
#: OCR renders both glyphs as the same blockish garbage (``Bfigi``, ``gági``,
#: ``ggg]``, ``Вйй``) and cannot tell them apart. The Návod (p. VII) says the
#: distinction never depended on telling them apart: *"Ve třetí, jednosloupcové
#: části stran (pod čarou) jest u jmen místních značka pro železniční stanice vždy
#: vypuštěna a jen k železničním zastávkám značka připojena."* In this part of the
#: page the station symbol is **always omitted** and only stops carry one — so the
#: mere presence of a mark is the answer, and the glyph never had to be resolved.
#: Confirmed by the worked example on p. VIII: Bílina hlavní nádraží (a station,
#: printed bare) against Bílina Město and Kyselka (two stops, both marked).
_RAIL_GLYPH_RE = re.compile(r"[BgGВвЙйf]{3,}[\]ji]?|\bSSg\b|\bfgg\w*")

#: ``2 1/4`` — walking hours. Fractions are printed as vulgar fractions and come
#: back as anything at all (``1V4``, ``l'/s``, ``i-7 4``), so only the whole number
#: and a clean ``a/b`` are trusted; everything else is left unparsed rather than
#: guessed, because a fabricated distance is worse than a missing one.
_DISTANCE_RE = re.compile(r"(\d{1,2})?\s*(?:(\d)\s*/\s*(\d))?\s*$")


def normalise(name: str) -> str:
    """Match key for a district name: unaccented, lowercase, letters only."""
    decomposed = unicodedata.normalize("NFKD", str(name or ""))
    stripped = "".join(c for c in decomposed if not unicodedata.combining(c))
    return re.sub(r"[^a-z]", "", stripped.lower())

    """``(kind, district, end)`` if this line opens a section, else None.

    ``end`` is where the heading stops, so the caller keeps whatever the same
    printed line carries after it — an entry often starts on the heading's own
    line. Anything *before* the heading belongs to the previous section and is
    dropped by the caller, which is what the old regex did too.

    Every tail on the line is tried in turn, because an entry body can print a
    colon (``Kč: ígt£ 240 m``) and the first colon is not always the heading's.
    """
    for match in HEADING_TAIL_RE.finditer(line):
        prefix = normalise(line[:match.start()])[-_MARK_WINDOW:]
        parts = any(mark in prefix for mark in PARTS_MARKS)
        offices = any(mark in prefix for mark in OFFICES_MARKS)
        if parts == offices:        # neither, or both — refuse rather than pick
            continue
        return ("parts" if parts else "offices",
                match.group("district").strip(" .,;-—–"), match.end())
    return None


@dataclass
class Section:
    """One heading and the lines beneath it, in reading order."""

    kind: str                       # "parts" | "offices"
    district: str
    page: str
    lines: list[str] = field(default_factory=list)

    @property
    def text(self) -> str:
        return " ".join(self.lines)

    @property
    def key(self) -> str:
        return normalise(self.district)


@dataclass
class Notes:
    """The footnote apparatus of one page."""

    page: str
    top: int
    bottom: int
    split_x: int
    left_lines: list[str] = field(default_factory=list)
    right_lines: list[str] = field(default_factory=list)
    #: Where the *text* of the apparatus starts — the foot of the table body, which
    #: is above where the divider rule begins, because the section headings are
    #: printed over the full width before the two columns open. ``top`` is the
    #: rule's own start and is not the band; cropping an image at ``top`` cuts every
    #: heading off, and a heading is what tells a section which district it belongs
    #: to. Defaults to 0 so a Notes assembled by hand (the vision channel) is legal.
    band_top: int = 0
    #: Everything below the divider rule's foot, clustered full width. The two
    #: columns stop at the divider; the postal/railway legend runs the whole width
    #: beneath it, so it is neither a left nor a right column line.
    footer_lines: list[str] = field(default_factory=list)
    #: ``(top, bottom)`` in ALTO pixels for each line of the two columns, parallel
    #: to ``left_lines`` / ``right_lines``. This is what lets a *section* be cut out
    #: of the page as an image rather than only out of the text: the heading is a
    #: line, and a line the clusterer already knows the extent of.
    #:
    #: Empty on a :class:`Notes` assembled by hand from a model's reply, because
    #: that reader is handed an image and never sees a coordinate. Consumers check
    #: the length rather than assuming it — see :func:`section_segments`.
    left_bounds: list[tuple[int, int]] = field(default_factory=list)
    right_bounds: list[tuple[int, int]] = field(default_factory=list)

    @property
    def reading_order(self) -> list[str]:
        """Left column top-to-bottom, then right column — how the block is read."""
        return [*self.left_lines, *self.right_lines]

    def sections(self) -> list[Section]:
        """Cut the flow into sections on their headings.

        Lines before the first heading belong to a section that began on an earlier
        page. They are dropped rather than attached to the first heading found here,
        which would file one district's entries under the next district's name and
        quietly corrupt the very scoping this exists to provide.
        """
        found: list[Section] = []
        for line in self.reading_order:
            heading = find_heading(line)
            if heading:
                kind, district, end = heading
                found.append(Section(kind=kind, district=district, page=self.page,
                                     lines=[line[end:]]))
            elif found:
                found[-1].lines.append(line)
        return found

def _cluster_footer(words, line_gap: int) -> list[str]:
    """Rebuild the footer's printed lines, superscripts included.

    Done in two passes because the raised key figures make one pass impossible.
    The baseline tokens alone sit on cleanly separated bands, so they define the
    lines; every remaining token — superscript figures, the points of ``k s. o.``
    — is then assigned to the band **at or below** it, which is the line a raised
    character actually belongs to.

    Clustering everything together instead fails whichever gap is chosen: the bands
    are evenly spaced about 20 px apart, so a gap tight enough to keep lines apart
    puts the superscripts on a line of their own, and a gap loose enough to catch
    them chains every band on the page into a single blob. Both reorder the entries,
    and entry order is the only thing the numbering has to go on.
    """
    if not words:
        return []
    import statistics

    cutoff = statistics.median(w[3] for w in words) * _SUPERSCRIPT_SHARE
    baseline = [w for w in words if w[3] >= cutoff]
    if not baseline:
        baseline = words

    bands: list[list[tuple]] = []
    for word in sorted(baseline, key=lambda s: s[0] + s[3] // 2):
        centre = word[0] + word[3] // 2
        if bands and centre - (bands[-1][-1][0] + bands[-1][-1][3] // 2) <= line_gap:
            bands[-1].append(word)
        else:
            bands.append([word])
    centres = [sum(w[0] + w[3] // 2 for w in b) / len(b) for b in bands]

    for word in words:
        if word[3] >= cutoff:
            continue
        centre = word[0] + word[3] // 2
        below = [i for i, c in enumerate(centres) if c >= centre - 8]
        bands[below[0] if below else len(bands) - 1].append(word)

    return [" ".join(w[4] for w in sorted(b, key=lambda w: w[1])).strip()
            for b in bands]


def divider_rule(page, body_bottom: int) -> dict | None:
    """The short vertical rule separating the two footnote columns.

    Returns the tallest rule starting at or below the table body and sitting well
    inside the frame, or None when the engine found none — in which case the page
    has no recoverable footnote geometry and is reported as such rather than split
    at a guessed midpoint.
    """
    left = page.print_left
    width = page.print_width or page.width
    candidates = []
    for rule in page.verticals:
        centre = rule["HPOS"] + rule["WIDTH"] // 2
        position = (centre - left) / width if width else 0.5
        if not _INNER_MIN <= position <= _INNER_MAX:
            continue
        if rule["VPOS"] < body_bottom - _DIVIDER_SLACK:
            continue
        candidates.append(rule)
    return max(candidates, key=lambda r: r["HEIGHT"]) if candidates else None


#: Where the divider sits across the frame, as a share of its width, for the
#: fallback in :func:`fallback_divider`. Narrower than ``_INNER_MIN``/``_MAX``
#: because the fallback does not have the table's foot to rule out column rules.
_CENTRE_MIN, _CENTRE_MAX = 0.42, 0.58

#: The shortest rule taken for the divider by the fallback, and how low on the
#: sheet its foot must reach. Column rules in this band stop at the table's foot,
#: well above 70 % of the page on every page that has an apparatus.
_FALLBACK_MIN_HEIGHT = 250
_FALLBACK_MIN_FOOT = 0.70


def fallback_divider(page) -> dict | None:
    """The divider found without the table's body band.

    :func:`divider_rule` rejects a rule that starts far above the table's foot
    as ``lexikon_1910.body_band`` reports it. On 22 table scans that foot is wrong
    — the band runs on into the apparatus, to 4,007 px on scan 0026 against a
    divider starting at 3,375 — so a printed divider was rejected and the whole
    apparatus of the page was never read (audit of 2026-10-14). This takes the
    rule the page actually prints: the one near the middle of the frame whose
    foot is lowest on the sheet, if it reaches the lower part of the page at all.
    Used only where :func:`divider_rule` found nothing, so no page that worked
    before is cut differently by it.
    """
    width = page.print_width or page.width
    if not width:
        return None
    central = [r for r in page.verticals
               if r["HEIGHT"] >= _FALLBACK_MIN_HEIGHT
               and _CENTRE_MIN <= (r["HPOS"] + r["WIDTH"] // 2 - page.print_left)
               / width <= _CENTRE_MAX]
    if not central:
        return None
    rule = max(central, key=lambda r: r["VPOS"] + r["HEIGHT"])
    if rule["VPOS"] + rule["HEIGHT"] < _FALLBACK_MIN_FOOT * page.height:
        return None
    return rule


#: A column rule has to start at least this far above the divider to count as
#: one of the table's: the apparatus prints no rule of its own except the divider,
#: and pieces of a broken divider start just above it.
_TABLE_RULE_LEAD = 600


def table_foot(page, divider_top: int) -> int | None:
    """Where the table's column rules end, above the apparatus.

    ``lexikon_1910.body_band`` ends the table body at a low percentile of its
    rules' feet, which is right for clustering rows and wrong as the top of the
    apparatus: on 227 table scans the last one to three table rows lie below it,
    so they were read as a section carried over from the previous page and sent
    to the reader as one (scan 0196, Hrnčíře and Šeberov, filed under the offices
    of Královské Vinohrady). The rules themselves say where the table stops: the
    lowest foot among the column rules that start well up in the table, inside the
    frame, and end above the divider.
    """
    width = page.print_width or page.width
    if not width:
        return None
    feet = [r["VPOS"] + r["HEIGHT"] for r in page.verticals
            if r["HEIGHT"] >= 150
            and r["VPOS"] < divider_top - _TABLE_RULE_LEAD
            and r["VPOS"] + r["HEIGHT"] <= divider_top + 8
            and 0.05 <= (r["HPOS"] + r["WIDTH"] // 2 - page.print_left) / width <= 0.95]
    return max(feet) if feet else None


def apparatus_band(page, band_from_table: bool = True,
                   fallback: bool = True) -> tuple[dict, int] | None:
    """``(divider rule, band top)`` of one page, or None when it has no divider.

    The band opens at the foot of the table's column rules (:func:`table_foot`),
    so a table row is never read as apparatus and an apparatus line never as a
    table row. Until 0.9.1 it opened at the *lower* of that foot and the body
    band's, on the reasoning that the rules could only end too early; on scans
    0369 and 0472 the body band overshoots instead (2,657 and 2,401 px against
    rule feet of 2,451 and 2,057, which the image's own reading of the table foot
    confirms to the pixel), and a section heading and its first entries were read
    into the table. Those are the only two scans where the two feet disagree that
    way (2026-10-14). ``band_from_table=False`` keeps the band of 0.7.0 — the body band's
    foot — for replaying a pass cached under it. A page whose divider only the
    fallback finds (:func:`fallback_divider`) has a body band known to be wrong,
    so its band opens at the table's foot whatever the flag says.
    ``fallback=False`` leaves those pages out, as 0.7.0 did.

    Its own function because the table needs the same line:
    ``lexikon_1910.table_bottom`` ends the table's rows where this band opens, so
    every text-layer word above the divider belongs to exactly one of the two.
    """
    from utils.lexikon_1910 import lexikon_1910 as lx

    try:
        _top, body_bottom = lx.body_band(page)
    except ValueError:
        body_bottom = None
    rule = divider_rule(page, body_bottom) if body_bottom is not None else None
    found_by_fallback = rule is None
    if found_by_fallback:
        if not fallback:
            return None
        rule = fallback_divider(page)
        if rule is None:
            return None

    foot = table_foot(page, rule["VPOS"])
    if found_by_fallback:
        if foot is None:
            return None
        return rule, foot
    if band_from_table and foot is not None:
        return rule, foot
    return rule, body_bottom


def extract_notes(page, line_gap: int = 15,
                  band_from_table: bool = True,
                  fallback: bool = True) -> Notes | None:
    """Read the footnote block of one page, or None when it has no divider.

    The band and the two flags are :func:`apparatus_band`'s.
    """
    found = apparatus_band(page, band_from_table=band_from_table,
                           fallback=fallback)
    if found is None:
        return None
    rule, band_top = found

    bottom = rule["VPOS"] + rule["HEIGHT"]
    split_x = rule["HPOS"] + rule["WIDTH"] // 2
    # Opened back to the table rather than to the rule's own top: the section
    # headings are printed above where the divider starts.
    band = [s for s in page.strings if band_top <= s[0] <= bottom]
    # And everything past the divider's foot, which is where the postal/railway
    # legend lives. Cutting the band at the divider dropped it silently.
    footer = [s for s in page.strings if s[0] > bottom]

    def cluster(words, gap: int = line_gap) -> list[tuple[str, int, int]]:
        """``(text, top, bottom)`` per printed line.

        The extent comes back with the text because the only other way to get it
        is to cluster a second time somewhere else, and two clusterings of the
        same words that drift apart put a section's crop over the wrong lines.
        """
        rows: list[list[tuple]] = []
        for word in sorted(words, key=lambda s: (s[0] + s[3] // 2, s[1])):
            centre = word[0] + word[3] // 2
            if rows and centre - (rows[-1][-1][0] + rows[-1][-1][3] // 2) <= gap:
                rows[-1].append(word)
            else:
                rows.append([word])
        return [(" ".join(w[4] for w in sorted(row, key=lambda w: w[1])).strip(),
                 min(w[0] for w in row), max(w[0] + w[3] for w in row))
                for row in rows]

    left = cluster([s for s in band if s[1] + s[2] // 2 < split_x])
    right = cluster([s for s in band if s[1] + s[2] // 2 >= split_x])
    return Notes(
        page=page.stem, top=rule["VPOS"], bottom=bottom, split_x=split_x,
        band_top=band_top,
        left_lines=[text for text, _t, _b in left],
        right_lines=[text for text, _t, _b in right],
        left_bounds=[(t, b) for _text, t, b in left],
        right_bounds=[(t, b) for _text, t, b in right],
        footer_lines=_cluster_footer(footer, line_gap),
    )

#: Regions of the apparatus, in reading order. The two columns are one text flow
#: (left column, then right), and the footer below the divider is a third.
NOTES_REGIONS = ("left", "right", "footer")


def notes_boxes(notes: Notes, page) -> dict[str, tuple[int, int, int, int]]:
    """``(left, top, right, bottom)`` in ALTO pixels for each region of the band.

    Taken from the printed rules the ALTO already gave us, not from a guessed
    fraction of the page: the apparatus starts at the foot of the table body,
    the divider both splits the two columns and ends where the footer begins,
    and the frame gives the outer edges. A page whose divider was not found has
    no :class:`Notes` at all, so there is no case here where the geometry is
    invented.

    The footer's bottom is the last **line of print** inside the footer band, not
    the last word on the page and not the page edge. The legend is a few lines
    under a divider that sits well above the foot of the sheet, so both of the
    other bounds hand a reader a crop that is mostly blank paper — 435 px of image
    for 160 px of print on page 118. That is paid for in tokens on a hosted
    endpoint and in seconds on a local one.

    "Line of print" rather than "word" because of what is down there: page 118
    carries a lone ``Ф`` 200 px below the last legend line, which is a speck on the
    scan the engine took for a glyph, and bounding on it restores the blank paper
    the band cut out. A line is required to carry a few characters before it counts
    — but it *is* consulted, because pages 119 and 125 print genuine ``*) Viz
    dodatek`` and ``*) Bubákov …`` notes that far down, and a fixed offset would
    cut them off.
    """
    left_edge = page.print_left
    right_edge = page.print_left + (page.print_width or page.width)
    below = sorted((s for s in page.strings if s[0] > notes.bottom),
                   key=lambda s: s[0] + s[3] // 2)
    lines: list[list[tuple]] = []
    for word in below:
        centre = word[0] + word[3] // 2
        if lines and centre - (lines[-1][-1][0] + lines[-1][-1][3] // 2) <= 15:
            lines[-1].append(word)
        else:
            lines.append([word])
    printed = [line for line in lines
               if len("".join(w[4] for w in line).strip()) >= 4]
    last_word = max((max(w[0] + w[3] for w in line) for line in printed),
                    default=notes.bottom)
    return {
        "left":   (left_edge, notes.band_top, notes.split_x, notes.bottom),
        "right":  (notes.split_x, notes.band_top, right_edge, notes.bottom),
        "footer": (left_edge, notes.bottom, right_edge, min(page.height, last_word)),
    }


def line_cuts(page, box: tuple[int, int, int, int], slices: int) -> list[int]:
    """Where to cut a region into ``slices`` strips **between printed lines**.

    Returns the interior cut positions in ALTO pixels, so a caller gets
    ``slices`` strips from ``slices - 1`` cuts.

    A local vision model has far less usable resolution than a hosted one, and a
    1,350 x 1,330 column of six-point type is where that shows. Strips fix it —
    but only if no strip begins or ends mid-line. Cutting at an even fraction of
    the height slices through the middle of a line of print roughly as often as
    not, and the two halves are then either both misread or, worse, one half is
    read as a plausible short entry.

    The ALTO already knows where every word sits, so the gaps between lines are
    measurable rather than estimated: the strips are cut at the real whitespace
    nearest each even division. Overlap is therefore unnecessary, which matters
    because overlap has to be de-duplicated afterwards, and de-duplicating OCR
    output means deciding which of two disagreeing readings of the same line to
    keep — a judgement this pipeline has no basis to make.

    Falls back to even division only when no such whitespace exists, which is
    reported by the caller rather than hidden — see :func:`crop_notes`.

    **Line boundaries are not enough here, which is why this works on coverage.**
    Clustering the words into lines and cutting between them puts the cut through
    a glyph about as often as not: the raised key figures sit half a line above
    their own text, so consecutive lines *overlap* vertically and the midpoint of
    the gap between two line centres is frequently inside a superscript. What is
    needed is a y with no word box over it at all, and that is a sweep over the
    word extents rather than an average of them.
    """
    left, top, right, bottom = box
    if slices <= 1 or bottom - top < 40:
        return []
    spans = [(s[0], s[0] + s[3]) for s in page.strings
             if top <= s[0] + s[3] // 2 <= bottom
             and left <= s[1] + s[2] // 2 <= right]

    # Sweep the word extents into the maximal y ranges covered by no glyph.
    free: list[tuple[int, int]] = []
    if spans:
        events = sorted([(a, 1) for a, _b in spans] + [(b, -1) for _a, b in spans])
        depth, last_end = 0, top
        for position, delta in events:
            if depth == 0 and position > last_end:
                free.append((last_end, position))
            depth += delta
            if depth == 0:
                last_end = position
        if last_end < bottom:
            free.append((last_end, bottom))
    free = [(a, b) for a, b in free if b - a >= 4 and top < (a + b) // 2 < bottom]

    step = (bottom - top) / slices
    cuts: list[int] = []
    available = list(free)
    for i in range(1, slices):
        target = int(top + step * i)
        if available:
            # Each band is spent once. Without this, two adjacent targets in a
            # column with little whitespace both snap to the same gap and the run
            # emits a 70-pixel strip beside a full-height one — the tiling is still
            # exact, but the point of slicing is lost.
            band = min(available, key=lambda g: abs((g[0] + g[1]) // 2 - target))
            available.remove(band)
            target = (band[0] + band[1]) // 2
        if target not in cuts and top < target < bottom:
            cuts.append(target)
    return sorted(cuts)


def _crop_strips(image, page, box: tuple[int, int, int, int], pad: int,
                 ceiling: int, upscale: bool, slices: int,
                 max_height: int = 0, ink=None) -> list:
    """One box -> the strips of image to send, padded, cut and scaled.

    Shared by the region crops and the section crops so the two cannot drift: a
    section read at a different scale, or sliced by a different rule, than the
    column it came out of would not be comparable with it, and comparing them is
    the point of having both.

    ``max_height`` cuts by *size* rather than by count. A fixed ``slices`` is the
    wrong control for a section, because sections are not a fixed size — one
    district's offices run 25 lines and the next district's run two — so the same
    number either leaves the long one too big for a small reader or dices the
    short one into single lines. A ceiling in pixels asks the only question that
    matters to the reader: is this crop taller than it can hold?

    ``ink`` (a boolean mask of the page, rules removed) cuts the strips through
    rows with no ink at all (``lexikon_1910_image.blank_cuts``) instead of
    through the gaps between the text layer's word boxes, which is what a crop
    cut from the image needs: a line the text layer dropped has no word box, and
    a cut placed by word boxes can pass straight through it.
    """
    from utils.lexikon_1910 import lexikon_1910 as lx

    left, top, right, bottom = box
    left, top = max(0, left - pad), max(0, top - pad)
    right = min(image.width, right + pad)
    bottom = min(image.height, bottom + pad)
    if bottom - top < 20 or right - left < 20:
        return []
    height = bottom - top
    if max_height > 0 and height > max_height:
        slices = max(slices, (height + max_height - 1) // max_height)
    if ink is not None:
        from utils.lexikon_1910 import lexikon_1910_image as lximg

        cuts = lximg.blank_cuts(ink, (left, top, right, bottom), slices)
    else:
        cuts = line_cuts(page, (left, top, right, bottom), slices)
    edges = [top, *cuts, bottom]
    strips = []
    for start, end in zip(edges, edges[1:]):
        if end - start < 20:
            continue
        crop = image.crop((left, start, right, end))
        if upscale or crop.width > ceiling:
            crop = lx.scale_to_width(crop, ceiling)
        strips.append(crop)
    return strips


def crop_notes(image, notes: Notes, page, regions=NOTES_REGIONS,
               pad: int = 12, target_width: int | None = None,
               upscale: bool = False, slices: int = 1,
               max_height: int = 0) -> list[tuple]:
    """Cut the footnote apparatus out of a rendered page, one image per region.

    Returns ``[(image, region), …]`` in reading order, skipping any region with no
    height — a page can end mid-apparatus with no footer at all.

    **One image per region rather than one for the whole band**, for the same
    reason :func:`~utils.lexikon_1910.lexikon_1910.tile_block` tiles a wide block: the
    two columns are a *flow*, and a single image of both invites a reader to
    transcribe across the divider line by line, which interleaves two districts'
    entries into one stream. Cutting on the printed divider makes the reading order
    a property of the crop instead of an instruction the model has to be trusted
    to follow.

    **Downscaled if it must be, never upscaled by default** — the opposite of
    :func:`~utils.lexikon_1910.lexikon_1910.tile_block`, and for a reason that only
    applies here. A block is a thin strip, so blowing it up to the ceiling costs
    little and buys patches per digit. A footnote column is nearly square and
    already ~1,350 px wide: upscaling it to the same ceiling quadruples the pixel
    count, roughly doubles the image tokens, and adds no detail the 399-DPI scan
    did not have. Pass ``upscale=True`` to spend that deliberately.
    """
    from utils.lexikon_1910 import lexikon_1910 as lx

    ceiling = target_width or lx.VISION_LONG_EDGE
    boxes = notes_boxes(notes, page)
    out: list[tuple] = []
    for region in regions:
        # Strips are emitted under the region's own name, in reading order, so the
        # caller concatenates them back into one flow and nothing downstream needs
        # to know the region was cut at all.
        for crop in _crop_strips(image, page, boxes[region], pad, ceiling,
                                 upscale, slices, max_height):
            out.append((crop, region))
    return out


# --------------------------------------------------------------------------- #
# Sections as geometry — the targeted crop
# --------------------------------------------------------------------------- #
#
# A column crop is the wrong unit for a small local model and the wrong unit for
# the question. A footnote column is ~1,350 x 1,000 px of six-point type holding
# the tail of one district's parts and the head of the next district's offices,
# and a 4B–9B reader given the whole of it truncates: it reads the top, stops, and
# returns a well-formed reply that is missing the bottom half. On page 270 that is
# exactly where Brzice's institution entry sits.
#
# The section is the unit the *source* is organised in — one heading, one district,
# one kind — and the ALTO already knows where each heading sits, so the crop can be
# cut at the print rather than at the paper. That makes the offices sections
# addressable on their own: roughly half a column each, a closed list of symbols
# that only they print, and a prompt that describes one kind of entry instead of
# five.


@dataclass
class Segment:
    """One section's run of lines *within one column*, as a box on the page.

    Not the same thing as a :class:`Section`. A section is a text flow that
    routinely straddles the divider and the page break; an image crop cannot. So a
    section becomes one segment per column it occupies, in reading order, and the
    caller concatenates the replies back into the section.

    ``carried`` marks a segment with no heading in it — the continuation of a
    section that opened in the previous column or on the previous page. Its
    ``kind`` and ``district`` come from there, not from anything inside the crop,
    which is why they are carried explicitly rather than re-read.
    """

    kind: str                       # "parts" | "offices"
    district: str
    page: str
    region: str                     # "left" | "right"
    box: tuple[int, int, int, int]  # left, top, right, bottom in ALTO pixels
    order: int = 0                  # position in this page's reading order
    carried: bool = False
    lines: list[str] = field(default_factory=list)   # the text layer's own read

    @property
    def key(self) -> str:
        return normalise(self.district)

    @property
    def height(self) -> int:
        return self.box[3] - self.box[1]

    @property
    def label(self) -> str:
        return f"{self.page}/{self.region}/{self.order}"


def trailing_section(notes: Notes, carry=None):
    """``(kind, district)`` of the section still open at the foot of this page.

    Cheap enough to run on every page whether or not it is being cropped, which is
    what keeps the carry chain unbroken when a run skips a page. Without it the
    first segment after any gap loses its identity and — since a segment with no
    kind is not in the requested set — would be dropped silently.

    It cannot disagree with :func:`section_segments`, which carries the same thing
    from its left column into its right: both take *the last heading in reading
    order*, and a page with no heading on it leaves the carry untouched in both.
    """
    for line in notes.reading_order:
        heading = find_heading(line)
        if heading:
            carry = (heading[0], heading[1])
    return carry


def section_segments(notes: Notes, page, carry=None,
                     regions=("left", "right"),
                     extend_to_foot: bool = True,
                     tile: bool = True) -> list[Segment]:
    """Cut this page's apparatus into per-column section segments.

    ``carry`` is what :func:`trailing_section` returned for the previous page, and
    it is what gives the lines above the first heading an identity. Without it they
    are dropped — the same rule :meth:`Notes.sections` follows, and for the same
    reason: attaching them to the *next* heading would file one district's entries
    under the following district's name.

    The footer is not a region here. It carries the postal legend, which is a
    different block with its own numbering and no section heading at all.

    **The last segment of a column runs to the foot of the column, not to the last
    line the text layer recognised.** A segment's box is built from the lines the
    ALTO clustered, and a short line that is nothing but a key and a pictogram is
    exactly the line the engine drops: scan 0076 prints ``22, 3) [fire-brigade].``
    39 px below the last recognised line of its right column, and scan 0316 prints
    the offices lines for keys 35 and 36 in the 106 px under its own. Ending the
    box at the text layer cut them out of the reader's crop and out of the gold
    crop alike, so neither channel could report them and the two agreed on their
    absence (2026-10-13). The column's foot is the divider rule's foot, which
    :func:`notes_boxes` already takes from the printed rule; the footer band opens
    there, so the postal legend stays out. Only the *last* segment moves — an
    earlier one ends where the next heading begins, and that boundary is a
    recognised line by construction.

    ``extend_to_foot=False`` is the geometry before 0.7.0, kept so the defect can
    be measured against it and so a reader pass cached under the old crops can
    still be replayed from its cache.

    **And every segment runs to where the next one begins** (``tile=True``, 0.8.0).
    The sentence above — that an earlier segment ends at a recognised line by
    construction — was wrong: it ends at *its own* last recognised line, and the
    lines the engine dropped between that and the next heading fell outside every
    crop. Scan 0386 lost Votice's ``13, 3)`` and ``13, 4)`` that way (audit of
    2026-10-14). With ``tile`` the first segment of a column also opens at the top
    of the column, so a heading the text layer missed entirely (scan 0456, *Části
    osad … Veselí nad Lužnicí*) is at least inside a crop. The crops of a column
    now tile it: nothing printed between the band's top and the divider's foot is
    outside all of them. ``tile=False`` is the 0.7.0 geometry.
    """
    boxes = notes_boxes(notes, page)
    segments: list[Segment] = []
    order = 0
    for region in regions:
        lines = getattr(notes, f"{region}_lines")
        bounds = getattr(notes, f"{region}_bounds")
        if not lines or len(bounds) != len(lines):
            # No geometry (a hand-assembled Notes) means no crop can be cut. Say
            # nothing rather than cut a box from coordinates that were never read.
            continue
        left, column_top, right, foot = boxes[region]
        runs: list[dict] = []
        current = ({"kind": carry[0], "district": carry[1], "carried": True,
                    "rows": []} if carry else None)
        for i, line in enumerate(lines):
            heading = find_heading(line)
            if heading:
                if current and current["rows"]:
                    runs.append(current)
                current = {"kind": heading[0], "district": heading[1],
                           "carried": False, "rows": [i]}
            elif current is not None:
                current["rows"].append(i)
        if current and current["rows"]:
            runs.append(current)

        tops = [min(bounds[i][0] for i in run["rows"]) for run in runs]
        for n, run in enumerate(runs):
            rows = run["rows"]
            top = tops[n]
            bottom = max(bounds[i][1] for i in rows)
            if tile and n == 0:
                top = min(top, column_top)
            if tile and n + 1 < len(runs):
                bottom = max(bottom, tops[n + 1])
            if extend_to_foot and n == len(runs) - 1:
                # `max`, not the foot outright: a line whose top is above the
                # rule's foot can still end a few pixels below it.
                bottom = max(bottom, foot)
            segments.append(Segment(
                kind=run["kind"], district=run["district"], page=notes.page,
                region=region, box=(left, top, right, bottom), order=order,
                carried=run["carried"],
                lines=[lines[i] for i in rows]))
            order += 1
        if runs:
            carry = (runs[-1]["kind"], runs[-1]["district"])
    return segments


def crop_segments(image, segments, page, pad: int = 12,
                  target_width: int | None = None, upscale: bool = False,
                  slices: int = 1, max_height: int = 0, ink=None) -> list[tuple]:
    """``[(crop, segment, strip, n_strips), …]`` for the segments asked for.

    A segment too tall for the reader is cut into strips at real whitespace by the
    same :func:`line_cuts` sweep the region crops use, and the strips are emitted
    in reading order under their own segment, so the caller concatenates the
    replies back into one section without needing to know it was cut.
    """
    from utils.lexikon_1910 import lexikon_1910 as lx

    ceiling = target_width or lx.VISION_LONG_EDGE
    out: list[tuple] = []
    for segment in segments:
        strips = _crop_strips(image, page, segment.box, pad, ceiling, upscale,
                              slices, max_height, ink=ink)
        for i, crop in enumerate(strips):
            out.append((crop, segment, i, len(strips)))
    return out

#: How far apart, in Czech-render pixels, the centres of an image heading and a
#: text-layer heading may lie and still be one printed heading. A heading line
#: is ~35 px tall and the two channels measure the same line within a few px.
HEADING_MATCH = 25

#: The white kept round a heading when it is cut out to be read on its own.
HEADING_PAD = 10


@dataclass
class ImageCut:
    """What :func:`image_section_segments` did on one page, for the run's report."""

    page: str
    geometry: str                   # "image" or "alto" (the image found no divider)
    segments: int = 0
    headings_both: int = 0          # found by the image and the text layer
    headings_text_only: int = 0     # the text layer's, the image missed it
    headings_image_read: int = 0    # the image's alone, labelled by a read of it
    headings_image_unread: list = field(default_factory=list)   # (region, top, text)
    legend: tuple[int, int, int, int] | None = None
    ink: object = None              # the page's ink mask, rules removed


def page_ink(image, geo):
    """The page's ink, rules removed — what strip cuts and ink accounting use."""
    from utils.lexikon_1910 import lexikon_1910_image as lximg

    grey = lximg.to_grey(image)
    mask = grey < geo.threshold
    return mask & ~lximg.rule_mask(mask.shape, geo.rules,
                                   max(2, int(3 * geo.scale)))


def text_headings(notes: Notes) -> list[tuple]:
    """``(region, top, bottom, kind, district)`` for every heading the text layer found."""
    out = []
    for region in ("left", "right"):
        lines = getattr(notes, f"{region}_lines")
        bounds = getattr(notes, f"{region}_bounds")
        for text, (top, bottom) in zip(lines, bounds):
            heading = find_heading(text)
            if heading:
                out.append((region, top, bottom, heading[0], heading[1]))
    return out


def image_section_segments(notes: Notes, page, image, carry=None,
                           read_heading=None, find=None, full_width_headings: bool = False
                           ) -> tuple[list[Segment], ImageCut]:
    """The apparatus cut into section segments on the **image's** geometry.

    The image says where the columns, their foot and the headings are
    (``lexikon_1910_image``); a heading's *words* are what say which kind of
    section opens and which district it names, and a crop is labelled with them:

    * an image heading the text layer also found takes the text layer's label;
    * a text-layer heading the image missed is kept as a boundary with its label,
      so a section is never merged into the one before it because one channel
      missed its heading;
    * an image heading the text layer lost (scans 0090 0141 0190 0241 0304 0384
      0456: the whole line is absent from the ALTO) is cut out and given to
      ``read_heading(crop) -> str``, a vision read of that one line; the label
      comes from :func:`find_heading` on what was read. With no reader, or a read
      that is not a heading, the boundary is **not** made — the section runs on
      under the label before it — and the heading is reported as unread. A label
      is never invented by rule (D-38).

    ``find`` is the heading matcher, :func:`find_heading` by default. A volume
    in another language passes its profile's
    (``lexikon_1910_volume.VolumeProfile.find_heading``), which applies the same
    rule to that volume's words (0.10.0, the German notes arm, D-92). A
    ``Notes`` with no lines — a volume with no text layer — then cuts on the
    image alone and every heading is labelled by its read.

    The segments tile each column from the table's foot to the column's foot, as
    :func:`section_segments` does with ``tile=True``. Each keeps the text layer's
    lines that fall inside it, so channel B still decodes from the same boxes.
    The ink mask the strips are cut on comes back in the report.

    A page whose image shows no divider falls back to :func:`section_segments`.
    ``full_width_headings`` also takes a heading that fills its line (0.11.0; the German
    editions, ``lexikon_1910_image.HEADING_FULL_MARGIN``, D-132).
    """
    from utils.lexikon_1910 import lexikon_1910_image as lximg

    geo = lximg.detect(image, full_width_headings=full_width_headings)
    columns = geo.apparatus()
    report = ImageCut(page=notes.page, geometry="image")
    if not columns:
        report.geometry = "alto"
        segments = section_segments(notes, page, carry=carry)
        report.segments = len(segments)
        return segments, report
    report.ink = page_ink(image, geo)
    if geo.footer:
        report.legend = geo.footer
    tolerance = HEADING_MATCH * geo.scale
    texts = text_headings(notes)
    used: set[int] = set()
    segments: list[Segment] = []
    order = 0
    for region in ("left", "right"):
        left, top, right, foot = columns[region]
        # (top, kind, district) for every boundary in this column.
        bounds: list[tuple[int, str, str]] = []
        for heading in sorted((h for h in geo.headings if h.region == region),
                              key=lambda h: h.top):
            centre = (heading.top + heading.bottom) / 2
            match = next((i for i, h in enumerate(texts) if i not in used
                          and h[0] == region
                          and abs((h[1] + h[2]) / 2 - centre) <= tolerance), None)
            if match is not None:
                used.add(match)
                bounds.append((heading.top, texts[match][3], texts[match][4]))
                report.headings_both += 1
                continue
            read = ""
            if read_heading is not None:
                box = (max(left, heading.left - HEADING_PAD),
                       max(0, heading.top - HEADING_PAD),
                       min(right, heading.right + HEADING_PAD),
                       min(image.height, heading.bottom + HEADING_PAD))
                read = read_heading(image.crop(box)) or ""
            found = (find or find_heading)(read) if read else None
            if found:
                bounds.append((heading.top, found[0], found[1]))
                report.headings_image_read += 1
            else:
                report.headings_image_unread.append((region, heading.top, read))
        for i, h in enumerate(texts):
            if i not in used and h[0] == region:
                used.add(i)
                bounds.append((h[1], h[3], h[4]))
                report.headings_text_only += 1
        bounds.sort()
        lines = getattr(notes, f"{region}_lines")
        lbounds = getattr(notes, f"{region}_bounds")
        edges = [(top, *carry)] if carry else [(top, None, None)]
        edges += [b for b in bounds if b[0] > top + 2]
        if bounds and bounds[0][0] <= top + 2:
            edges[0] = (top, bounds[0][1], bounds[0][2])
        for n, (start, kind, district) in enumerate(edges):
            end = edges[n + 1][0] if n + 1 < len(edges) else foot
            inside = [text for text, (a, b) in zip(lines, lbounds)
                      if start <= (a + b) / 2 < end]
            # An opening run with nothing printed in it (the white between the
            # table's foot and the first heading) is not a section: the next
            # one opens at the column's top instead, so the crops still tile.
            ink_rows = int(report.ink[start:end, left + 4:right - 4].any(axis=1).sum())
            if n == 0 and len(edges) > 1 and not inside and ink_rows < 12:
                edges[1] = (start, edges[1][1], edges[1][2])
                continue
            # Print above the first heading with no section carried in has no
            # identity; it is left out, as section_segments leaves it out.
            if end - start < 4 or kind is None:
                continue
            segments.append(Segment(
                kind=kind, district=district, page=notes.page, region=region,
                box=(left, start, right, end), order=order,
                carried=(n == 0 and start == top and carry is not None
                         and (kind, district) == tuple(carry)),
                lines=inside))
            order += 1
        last = [s for s in segments if s.region == region]
        if last:
            carry = (last[-1].kind, last[-1].district)
    report.segments = len(segments)
    return segments, report


def trailing_from_segments(segments: list[Segment], carry=None):
    """``(kind, district)`` of the last section on the page, or ``carry``.

    The image path's counterpart of :func:`trailing_section`: a heading only
    the image found, and read, has to carry onto the next page as well.
    """
    for segment in segments:
        if segment.kind in ("parts", "offices"):
            carry = (segment.kind, segment.district)
    return carry

@dataclass
class LegendEntry:
    """One numbered place in the postal/railway legend of a soudní okres."""

    key: int
    place: str
    page: str
    #: A mark was printed with the name, which in this part of the page means the
    #: place is a **stop**, not a station (Návod p. VII). Read it as
    #: ``is_stop``; the name is kept for the columns already written.
    rail_symbol: bool = False
    key_printed: str = ""           # the key as it was OCR'd, before repair
    key_repaired: bool = False


#: Leading noise on an entry body: the stray superscript figures of *other*
#: entries, which sit on their own raised baseline and land in the wrong place
#: when the words are put back into reading order.
_LEADING_NOISE_RE = re.compile(r"^[\s.,;)\d'’»«^*]+")


def _legend_entries(text: str, page: str, start_key: int) -> list[LegendEntry]:
    """Split one legend block into entries, numbering them by **position**.

    The printed keys are superscript figures set on their own raised baseline, so
    the OCR both mangles them (``ß)``, ``t)``, ``э)``, ``M')``) and files them on a
    different text line from the ``)`` and the name they belong to. Reading them is
    therefore not merely unreliable, it is structurally wrong.

    So they are not read. The entries are printed in ascending order with no gaps —
    the same property column 1 has — so position plus a per-district running count
    reconstructs the numbering exactly, and the printed figure is kept only as
    evidence. This is why ``postal_legend`` must see pages in order.
    """
    marks = legend_key_marks(text)
    if not marks:
        return []
    entries: list[LegendEntry] = []
    for i, mark in enumerate(marks):
        end = marks[i + 1].start() if i + 1 < len(marks) else len(text)
        body = _LEADING_NOISE_RE.sub("", text[mark.end():end]).strip(" .,;")
        entries.append(LegendEntry(
            key=start_key + i,
            place=body[:60],
            page=page,
            rail_symbol=bool(_RAIL_GLYPH_RE.search(body)),
            key_printed=mark.group(1),
            key_repaired=re.sub(r"\D", "", mark.group(1)) != str(start_key + i),
        ))
    return entries


def postal_legend(notes_list) -> dict[str, dict[int, LegendEntry]]:
    """``district -> key -> entry`` for the postal/railway legend.

    Scoped per soudní okres because the numbering restarts there, and **order
    dependent**: a legend routinely spills across a page break (Chotěboř's runs 1–5
    on one page and 6–16 on the next), so the running count continues where the
    previous page left off. Pass ``notes_list`` in page order.
    """
    legend: dict[str, dict[int, LegendEntry]] = {}
    for notes in notes_list:
        text = " ".join(notes.footer_lines)
        for match in POSTAL_INTRO_RE.finditer(text):
            name = match.group("district") or match.group("district_de") or ""
            key = normalise(name)
            bucket = legend.setdefault(key, {})
            stop = len(text)
            for later in POSTAL_INTRO_RE.finditer(text, match.end()):
                stop = later.start()
                break
            for entry in _legend_entries(text[match.end():stop], notes.page,
                                         start_key=max(bucket, default=0) + 1):
                bucket.setdefault(entry.key, entry)
    return legend


#: A reference in column 16 or 17: the key, then an optional walking distance.
_REFERENCE_RE = re.compile(r"(\d{1,2})\s*\)\s*([^,;)]*)")


def parse_reference(cell: str) -> list[tuple[int, str]]:
    """``"10) 2 1/4, 7) 1"`` -> ``[(10, "2 1/4"), (7, "1")]``."""
    return [(int(k), tail.strip()) for k, tail in _REFERENCE_RE.findall(cell or "")]


#: A walk to the nearest station is a few hours at most; the column exists because
#: the distances are short. A parsed figure above this is the OCR having glued two
#: numbers together ("13" out of "1 3/4"), and a fabricated distance in a covariate
#: is worse than a missing one — so it is refused rather than clipped.
_MAX_WALK_HOURS = 8.0


def parse_distance(text: str) -> float | None:
    """Walking hours, or None when the printed figure is not cleanly legible."""
    match = _DISTANCE_RE.match((text or "").strip())
    if not match or not any(match.groups()):
        return None
    whole = int(match.group(1)) if match.group(1) else 0
    if match.group(2) and match.group(3) and int(match.group(3)):
        value = whole + int(match.group(2)) / int(match.group(3))
    elif match.group(1):
        value = float(whole)
    else:
        return None
    return value if 0 < value <= _MAX_WALK_HOURS else None


#: Both sides of the district join are OCR of the same printed name, from two
#: different places on the page — the table's summary row and the legend's
#: introducer — so they disagree on a character often enough to matter. Okres
#: Chotěboř came through as ``Chotéhoř`` in one and ``Chotěboř`` in the other, and
#: that single ``b``/``h`` orphaned 51 blocks, the largest court in the pilot run.
#: Same thresholds as the obec anchoring, and the same discipline: a near-tie is
#: refused rather than broken on ordering.
DISTRICT_MIN_SIMILARITY = 84
DISTRICT_TIE_MARGIN = 5


def match_district(label: str, candidates,
                   min_similarity: int = DISTRICT_MIN_SIMILARITY,
                   tie_margin: int = DISTRICT_TIE_MARGIN) -> tuple[str | None, str]:
    """Join a court label to a legend district. Returns ``(key, how)``."""
    if not label or not candidates:
        return None, "none"
    if label in candidates:
        return label, "exact"

    from rapidfuzz import fuzz

    scored = sorted(((fuzz.ratio(label, c), c) for c in candidates), reverse=True)
    best, name = scored[0]
    runner_up = scored[1][0] if len(scored) > 1 else 0
    if best < min_similarity:
        return None, "unmatched"
    if best - runner_up < tie_margin:
        return None, "ambiguous"
    return name, "fuzzy"


def resolve_places(blocks_by_district: dict[str, list],
                   legend: dict[str, dict[int, LegendEntry]]) -> list[dict]:
    """Resolve every column 16/17 reference against its own district's legend.

    Emits one record per reference, carrying the resolved place name and — for
    column 17 — the walking distance. Unresolved keys are reported rather than
    dropped: a reference to a key the legend does not define is either OCR damage
    in the key or a legend block this run never saw, and the two are told apart by
    whether the key is inside the district's printed range.
    """
    records: list[dict] = []
    for district, blocks in sorted(blocks_by_district.items()):
        matched, how = match_district(district, legend)
        known = legend.get(matched, {}) if matched else {}
        span = (min(known), max(known)) if known else None
        for block in blocks:
            for row in block.rows:
                for column, kind in (("post_key", "post"),
                                     ("station_note", "station")):
                    for key, tail in parse_reference(row.get(column)):
                        entry = known.get(key)
                        if entry is not None:
                            verdict = "resolved"
                        elif not known:
                            verdict = "no legend"
                        elif span and span[0] <= key <= span[1]:
                            verdict = "gap in legend"
                        elif span and key > span[1]:
                            # The legend runs past the last page in this window —
                            # a district at the edge of any page range has its
                            # legend cut off. Coverage, not a misread.
                            verdict = "legend truncated"
                        else:
                            verdict = "out of range"
                        records.append({
                            "check": "I9_place_key", "district": district,
                            "legend_district": matched or "",
                            "district_match": how,
                            "block_id": block.block_id,
                            "row_name": (row.get("name") or "")[:40],
                            "column": column, "kind": kind, "key": key,
                            "verdict": verdict,
                            "place": entry.place if entry else "",
                            "rail_symbol": entry.rail_symbol if entry else "",
                            "distance_hours": (parse_distance(tail)
                                               if kind == "station" else None),
                            "distance_printed": tail if kind == "station" else "",
                            "detail": "" if entry else
                                      f"{key}) not in this district's legend"
                                      + (f" (printed range {span[0]}–{span[1]})"
                                         if span else ""),
                        })
    return records


def lexikon_1910_places_report(legend, records) -> str:
    """Ledger for columns 16 and 17."""
    lines = [f"lexikon_1910_notes v{__version__} — columns 16/17 "
             f"(postal district, nearest station)", ""]
    n_entries = sum(len(v) for v in legend.values())
    repaired = sum(1 for v in legend.values() for e in v.values() if e.key_repaired)
    lines.append(f"  legend blocks found for {len(legend)} soudní okresy, "
                 f"{n_entries} numbered places")
    if n_entries:
        lines.append(f"    keys reconstructed from order (printed figure "
                     f"unreadable): {repaired} ({repaired / n_entries:.0%})")
    if not records:
        return "\n".join(lines + ["  no references in columns 16/17"])

    joins = {}
    for r in records:
        joins.setdefault(r["district"], (r["district_match"],
                                         r.get("legend_district", "")))
    fuzzy = {d: v for d, v in joins.items() if v[0] == "fuzzy"}
    refused = {d: v for d, v in joins.items() if v[0] in ("ambiguous", "unmatched")}
    lines.append(f"  court -> legend join: "
                 + ", ".join(f"{sum(1 for v in joins.values() if v[0] == k)} {k}"
                             for k in ("exact", "fuzzy", "unmatched", "ambiguous")
                             if any(v[0] == k for v in joins.values())))
    for district, (_how, target) in sorted(fuzzy.items()):
        lines.append(f"    fuzzy: {district!r} -> {target!r}")
    for district in sorted(refused):
        lines.append(f"    refused: {district!r} — no legend district close enough")

    counts: dict[str, int] = {}
    for r in records:
        counts[r["verdict"]] = counts.get(r["verdict"], 0) + 1
    total = len(records)
    lines.append(f"  references: {total}")
    for verdict in ("resolved", "legend truncated", "gap in legend",
                    "out of range", "no legend"):
        if counts.get(verdict):
            lines.append(f"    {verdict:18s} {counts[verdict]:5d}  "
                         f"{counts[verdict] / total:5.1%}")
    if counts.get("legend truncated"):
        lines.append("    (truncated = the district's legend continues past the "
                     "last page in this run;")
        lines.append("     a boundary effect of the page window, not a misread)")

    stations = [r for r in records if r["kind"] == "station"]
    with_d = [r for r in stations if r["distance_hours"] is not None]
    lines.append("")
    lines.append(f"  nearest-station references: {len(stations)}, "
                 f"walking distance parsed on {len(with_d)} "
                 f"({len(with_d) / len(stations):.0%})" if stations else
                 "  no station references")
    if with_d:
        vals = sorted(r["distance_hours"] for r in with_d)
        lines.append(f"    distance hours: median {vals[len(vals) // 2]:.2f}, "
                     f"range {vals[0]:.2f}–{vals[-1]:.2f}")
    return "\n".join(lines)

#: Where the running head stops naming districts and starts reciting the column
#: captions ("Pořadné číslo", "Politický okres", …). The captions are picked up by
#: :func:`~utils.lexikon_1910.lexikon_1910.running_head` along with the head itself.
_CAPTION_START = ("poradne", "politicky", "pporadne")


def court_of(head: str, known: set[str] | None = None) -> str:
    """The soudní okres named in a running head.

    The head prints ``Politický okres: Soudní okres`` and the *second* is what the
    footnote headings name — so splitting on the colon is not enough even before
    the OCR loses the colon, which it usually does. Two things make this reliable
    anyway: the column captions that follow are cut off first, and the remainder is
    matched against the districts the footnotes actually named, taking the
    **latest-starting** match because the soudní okres follows the politický one
    (``Chomutov: Jirkov`` -> ``jirkov``, ``Chrudim: Nasavrky`` -> ``nasevrky``).

    Without ``known`` there is nothing to match against and the whole prefix is
    returned, which will only equal a district key when the two okresy share a name.
    """
    text = normalise(head)
    cut = min((text.find(c) for c in _CAPTION_START if text.find(c) > 0),
              default=len(text))
    prefix = text[:cut]
    if not known:
        return prefix
    hits = [(prefix.find(k), len(k), k) for k in known if k in prefix]
    if not hits:
        # The head may be too damaged to carry the name; fall back to the whole
        # head rather than the prefix, in case the cut landed badly.
        hits = [(text.find(k), len(k), k) for k in known if k in text]
    return max(hits)[2] if hits else prefix


# --------------------------------------------------------------------------- #
# I8 — the parts check
# --------------------------------------------------------------------------- #
#
# The ``Části osad`` sections are not a legend. They are the *same figures printed
# a second time*: every settlement is broken into its named parts, each with its own
# house–population pair, and those pairs sum to the settlement's own row in the
# table above. Different type, different column, different part of the page — so an
# OCR error in one is uncorrelated with the other, which makes this a fourth
# reading channel rather than another view of the same characters. It already
# recovers table cells the grid misread: ``Čachotín`` reads ``07`` houses in the
# table and 63+4 = 67 in the footnote.
#
# There is no district-wide footnote key space to check against, incidentally. The
# numbering in the offices sections (``22, 2) … — 3) …``) restarts inside each
# municipality, so a "is this key defined" check would be grading references
# against a set that was never meant to contain them.

#: A run of letters long enough to be a place name rather than an OCR fragment.
_NAME_RE = re.compile(r"[^\W\d_]{3,}", re.UNICODE)

#: An entry opens with its sequence numbers and a closing parenthesis — ``1, 1)``,
#: ``4 , -)``, ``в, -)``, or a bare ``2)`` continuing the same municipality. Every
#: shape puts a ``)`` in the first few characters, and no continuation line does,
#: because those open mid-name or mid-figure. Matching on the *position* of the
#: parenthesis rather than on the digits sidesteps the fact that column-1 sequence
#: numbers are the most OCR-damaged text on the page (``в``, ``s``, ``Г) o``).
_ENTRY_PAREN_WITHIN = 8


def entry_chunks(lines) -> list[str]:
    """Merge printed lines into whole entries, on the print's own structure.

    An entry routinely wraps — ``Spieler-`` / ``jpühle ф 2—16.`` — and its
    house–population pairs wrap with it. Treating each printed line as an entry
    would sum a fragment against a whole settlement and report the difference as a
    disagreement, which is a parser bug wearing the costume of a finding.

    **The line break is the boundary, not the full stop.** Every entry starts on a
    new printed line, so where one ends is a fact about the page rather than about
    the punctuation — and the punctuation is not reliable: the terminal period is
    small, it sits under the glyph noise, and the OCR loses it often enough that a
    rule keyed on it merged 36% of the offices entries into their predecessor.
    That is why this is shared with :mod:`~utils.lexikon_1910.lexikon_1910_institutions`
    rather than reimplemented there.
    """
    merged: list[str] = []
    for line in lines:
        stripped = line.strip()
        if not stripped:
            continue
        opens = 0 <= stripped.find(")") < _ENTRY_PAREN_WITHIN
        if opens or not merged:
            merged.append(stripped)
        else:
            merged[-1] += " " + stripped
    return merged


def _entries(section) -> list[str]:
    return entry_chunks(section.lines)


def _row_index(blocks) -> dict[str, dict[str, list]]:
    """``page -> normalised name -> rows``.

    Indexed per page rather than over the whole run: a page's footnote describes
    that page's settlements, and Bohemia has enough repeated village names
    (``Brand``, ``Lhota``) that a global index matches one entry to a row in
    another district and grades it against the wrong numbers.
    """
    index: dict[str, dict[str, list]] = {}
    for block in blocks:
        page = index.setdefault(block.page, {})
        for row in block.rows:
            for part in (row.get("name") or "").split(","):
                key = normalise(part)
                if len(key) >= 3:
                    page.setdefault(key, []).append(row)
    return index


#: One named part: everything up to its house–population pair, then the pair.
#:
#: The pair is the terminator the print actually guarantees, and that is what
#: makes the entry splittable at all — a plain split on the comma cuts every
#: bilingual name in half (``Hazlov, Haslau 217—2266``). The figures tolerate
#: internal spaces because the press and the OCR both put them there: the volume
#: prints ``& 6 — 20 .`` and ``& ■ 1 —3.``.
_PART_FIGURES = (r"(?P<houses>\[\?\]|\d[\d ]{0,5})\s*[—–-]+\s*"
                 r"(?P<pop>\[\?\]|\d[\d ]{0,6})")
_PART_RE = re.compile(r"^\s*(?P<body>.*?)\s*" + _PART_FIGURES + r"\s*[.;,]?\s*$")

#: A token of the closed vocabulary, e.g. ``[ves]``, ``[mill]``.
#:
#: A stray stop after it is the print's, not the reader's: scan 0451 has
#: ``Kleinschwadowitz ○.124—998``, a reader that copies the speck writes
#: ``[ves].124—998``, and until 0.6.1 the token then ended up cut in half inside
#: the NAME (``Kleinschwadowitz [ves``) — a part read correctly and counted missed.
_BRACKET_RE = re.compile(r"(\[[^\]]+\])\s*[.;]?\s*$")

#: The register's residual entry — "and besides these" — as the print has it, and
#: as the legend plate names it (``& mimo to``). A reader that writes the atlas
#: token has read the ampersand; both spellings are one part, named ``&``.
RESIDUAL = "&"
RESIDUAL_TOKEN = "[besides]"

#: The same token with the glyph's OWN parentheses transcribed around it:
#: ``Hammerwerkflur ([cottage-group]) 10—84``. The legend plate prints *skupina
#: chalup* and *kolonie* inside parentheses — they are part of the pictogram, and
#: what tells a colony from a house-group — so a reader that writes them has named
#: the glyph, not qualified it. Until 0.6.0 the parentheses sent the whole body
#: down the cross-reference branch below and the token ended up inside the NAME.
#: That, and a full stop standing where a comma should (:func:`_part_pieces`),
#: were 22 of the 23 parts the default reader seemed to miss on the development
#: pages (2026-10-06): 152 of 175 found before, 174 after. A named token only:
#: ``([?])`` is a mark the reader could not name, and stays with the unnamed glyphs.
_TOKEN_PARENS_RE = re.compile(r"\(\s*(\[[a-z][a-z-]*\])\s*\)\s*[.;]?\s*$")

#: A pictogram the engine wrapped in parentheses, at the end of a part's body.
#:
#: **Short and space-free, and both halves of that are load-bearing.** The volume
#: prints cross-references in parentheses too — ``Červená (viz Milevsko 14 a 52)``
#: — and those are part of the NAME and must survive. Every parenthesised glyph
#: measured on the Úpice sections is three characters and has no space in it
#: (``(«“■)``, ``(»'*)``, ``(■“•)``, ``(Jj;)``); every cross-reference has spaces.
_GLYPH_PARENS_RE = re.compile(r"\([^\s)]{1,6}\)\s*$")

#: A word: at least two characters, one of them lower case. Used to find where a
#: part's NAME stops and its topographic mark starts, by taking everything after
#: the last word-like token. Uppercase-only runs (``Q``, ``Ш``, ``©``, ``«*.``,
#: ``(«“■)``) are exactly what the engine returns for a pictogram.
_WORDISH_RE = re.compile(r"[^\W\d_]*[a-zíáéěščřžýůúďťňöüäß][^\W\d_]*", re.UNICODE)


#: A full stop or semicolon standing where the list's comma should be.
_PART_STOP_RE = re.compile(r"[.;]\s+(?=\S)")
#: A house–population pair at the very end of what has been read so far.
_PAIR_END_RE = re.compile(_PART_FIGURES + r"\s*$")


def _part_pieces(text: str) -> list[str]:
    """The comma-separated pieces of an entry, also cut where a full stop or a
    semicolon stands in a comma's place.

    ``Johannihof [manor-farm] 1—9. Stachelmühle [mill] 1—4`` is two parts: the
    stop closes a house–population pair, which is the one thing that ends a part.
    A stop that does not — ``Červená 3. odd. (viz Milevsko 14 a 52)`` — is left
    where it is, because there it belongs to the name.
    """
    chunks, start = [], 0
    for stop in _PART_STOP_RE.finditer(text):
        if _PAIR_END_RE.search(text[start:stop.start()]):
            chunks.append(text[start:stop.start()])
            start = stop.end()
    chunks.append(text[start:])
    return [piece for chunk in chunks for piece in chunk.split(",")]


def split_parts(text: str) -> list[dict]:
    """One record per named part in a ``Části osad`` entry's body.

    ``[{name, topographic, topographic_raw, houses, population, position}]``.

    **The canonical splitter for this document, used by the model side and by the
    gold transcription alike.** Two copies of it would drift on exactly the
    entries where drift matters — the ones with a bilingual name, a mark, or the
    ``&`` residual — so :mod:`utils.lexikon_1910.read_transcription_md` imports this
    rather than carrying its own.

    Splitting is by accumulation, not by ``split(",")``: a fragment is closed only
    once it ends in a house–population pair, so ``Hazlov, Haslau 217—2266`` stays
    one part instead of becoming ``Hazlov`` and ``Haslau 217—2266``.

    **Only a bracketed mark is returned as `topographic`.** A vision pass runs
    behind :func:`~utils.lexikon_1910.lexikon_1910_vision.guard_tokens` and returns
    ``[ves]``; the gold sheet asks for the same token; those two are comparable.
    The ALTO text layer returns whatever the engine made of the pictogram — ``Q``,
    ``©``, ``(«“■)``, ``»`` — and naming that is precisely what D-39 established
    the text layer cannot do. It is kept verbatim in ``topographic_raw``, for the
    eye and for counting how many marks were printed, and it is **never** offered
    as a code.
    """
    out: list[dict] = []
    fragments: list[str] = []
    carry = ""
    for piece in _part_pieces(str(text or "")):
        carry = f"{carry},{piece}" if carry else piece
        if _PART_RE.match(carry):
            fragments.append(carry)
            carry = ""
    if carry.strip():
        fragments.append(carry)

    for position, fragment in enumerate(fragments):
        match = _PART_RE.match(fragment)
        if not match:
            out.append({"name": fragment.strip(), "topographic": "",
                        "topographic_raw": "", "houses": "", "population": "",
                        "position": position, "unparsed": fragment.strip()})
            continue
        body = match.group("body").strip()
        wrapped = _TOKEN_PARENS_RE.search(body)
        bracket = _BRACKET_RE.search(body)
        parens = _GLYPH_PARENS_RE.search(body)
        if wrapped:
            token = wrapped.group(1)
            name, raw = body[:wrapped.start()].strip(), wrapped.group(0).strip()
        elif bracket:
            token = bracket.group(1)
            name, raw = body[:bracket.start()].strip(), ""
        elif parens:
            # The engine wraps a pictogram in parentheses often enough to be a
            # rule of its own — `(«“■)`, `(»'*)`, `(■“•)`, `(Jj;)`. Taking it
            # before the word cut below is what keeps `(Jj` out of the NAME: the
            # `j` reads as lower case, so the word test counted it as part of the
            # name and left the name ending mid-glyph.
            token = ""
            name, raw = body[:parens.start()].strip(), parens.group(0).strip()
        elif body.endswith(")") and "(" in body:
            # A parenthesis that survived the glyph test above is prose, and the
            # register puts the linkage there: `Červená, Čerwena 3. odd. (viz
            # Milevsko 14 a 52)` says which division of a settlement this is. The
            # word cut below stops at the last lower-case word — `a` — and would
            # take `52)` for a mark, truncating the cross-reference the protocol
            # explicitly asks a transcriber to honour.
            token, name, raw = "", body, ""
        else:
            token = ""
            words = list(_WORDISH_RE.finditer(body))
            if words:
                cut = words[-1].end()
                name, raw = body[:cut].strip(), body[cut:].strip(" .")
            else:
                # No word at all: the `&` residual, which the register prints as
                # an entry in its own right and which carries a mark of its own
                # (`& ■ 1 —3`). Cutting after the first token keeps the two apart
                # instead of reading `& ■` as the name of a place.
                head, _, tail = body.partition(" ")
                name, raw = head.strip(), tail.strip(" .")
        if name == RESIDUAL_TOKEN:
            name = RESIDUAL
        out.append({
            "name": name, "topographic": token, "topographic_raw": raw,
            "houses": match.group("houses").replace(" ", ""),
            "population": match.group("pop").replace(" ", ""),
            "position": position, "unparsed": "",
        })
    return out


def parts_records(sections, source: str = "model") -> list[dict]:
    """Every named part the ``Části osad`` sections print, one row each.

    Keyed by the entry's own ``municipality, part)`` numbers so it can be joined
    to the gold transcription, which is keyed the same way. That is a **different
    join from** :func:`parts_check`, deliberately: `parts_check` grades an entry's
    figures against the table and matches by *name*, because against the table the
    sequence number is the most damaged column on the page and joining on it would
    lose entries to the OCR rather than to disagreement. Here both sides are
    readings of the *same* apparatus line, so the key is shared damage rather than
    a second source of it — and the number is itself one of the things a gold
    reading exists to grade.
    """
    from utils.lexikon_1910 import lexikon_1910_institutions as lxin

    rows: list[dict] = []
    for section in sections:
        if section.kind != "parts":
            continue
        for entry in lxin.parse_entries(section):
            for part in split_parts(entry.text):
                rows.append({
                    "check": "I8_parts", "page": section.page,
                    "district": section.district,
                    "muni_seq": entry.muni_seq,
                    "settlement_seq": entry.settlement_seq or "0",
                    "part_name": part["name"],
                    "topographic": part["topographic"],
                    "topographic_raw": part["topographic_raw"],
                    "houses": part["houses"],
                    "population": part["population"],
                    "position": part["position"],
                    "unparsed": part["unparsed"], "source": source,
                })
    return rows

def score_parts(reference: list[dict], rows: list[dict],
                pages: set | None = None) -> tuple[dict, list[dict]]:
    """The named parts of one reading against a reference: ``(summary, pairs)``.

    A part is matched **by name** inside its own ``(page, district, municipality,
    part)`` key — the name is what the print addresses a part by, and the order
    two readings list them in is not evidence. On the matched parts three things
    are compared separately, because they fail separately: the place-type symbol,
    the houses and the population. ``pairs`` holds one row per matched part whose
    symbol differs, which is the list a person looks at.

    ``pages`` restricts both sides, so a page the reference covers and the scored
    gold does not is left out of every count. A reference part with no symbol
    (the print gave it none, or the sheet left it blank) is matched and counted in
    the figures, and left out of the symbol rate — nothing was printed to get right.
    """
    def keyed(frame):
        out = {}
        for row in frame:
            if pages is not None and str(row["page"]) not in pages:
                continue
            key = (str(row["page"]), normalise(row["district"]),
                   str(row["muni_seq"]), str(row["settlement_seq"] or "0"),
                   normalise(row["part_name"]) or str(row["part_name"]).strip())
            out.setdefault(key, row)
        return out

    ref, mine = keyed(reference), keyed(rows)
    both = sorted(ref.keys() & mine.keys())
    same = lambda key, column: (str(ref[key][column]).strip()      # noqa: E731
                                == str(mine[key][column]).strip())
    marked = [key for key in both if str(ref[key]["topographic"]).strip()]
    pairs = [{"check": "I20_parts_symbols", "page": key[0], "district": key[1],
              "muni_seq": key[2], "settlement_seq": key[3],
              "part_name": ref[key]["part_name"],
              "reference": ref[key]["topographic"],
              "read": mine[key]["topographic"]}
             for key in marked if not same(key, "topographic")]
    summary = {
        "check": "I20_parts_symbols", "reference_parts": len(ref),
        "read_parts": len(mine), "matched": len(both),
        "missed": len(ref.keys() - mine.keys()),
        "extra": len(mine.keys() - ref.keys()),
        "with_symbol": len(marked), "symbol_agree": len(marked) - len(pairs),
        "houses_agree": sum(1 for key in both if same(key, "houses")),
        "population_agree": sum(1 for key in both if same(key, "population")),
    }
    return summary, pairs


def lexikon_1910_parts_score_report(summary: dict, pairs: list[dict],
                                    label: str = "", top: int = 12) -> str:
    """Ledger for :func:`score_parts`."""
    if not summary.get("reference_parts"):
        return "  no named part in the reference on these pages"
    share = lambda n, d: f"{n}/{d}" + (f" = {n / d:.1%}" if d else "")  # noqa: E731
    lines = [f"  {label + ': ' if label else ''}the named parts (Části osad) "
             f"against the reference", ""]
    lines.append(f"  parts in the reference        {summary['reference_parts']:5d}")
    lines.append(f"  found under the same key      "
                 f"{share(summary['matched'], summary['reference_parts'])}")
    lines.append(f"  not found / read but not in the reference   "
                 f"{summary['missed']} / {summary['extra']}")
    lines.append(f"  place-type symbol agrees      "
                 f"{share(summary['symbol_agree'], summary['with_symbol'])}")
    lines.append(f"  houses agree                  "
                 f"{share(summary['houses_agree'], summary['matched'])}")
    lines.append(f"  population agrees             "
                 f"{share(summary['population_agree'], summary['matched'])}")
    if pairs:
        confusions: dict[str, int] = {}
        for pair in pairs:
            pattern = f"{pair['reference']} read as {pair['read'] or '(nothing)'}"
            confusions[pattern] = confusions.get(pattern, 0) + 1
        lines.append("")
        lines.append("  symbols that differ:")
        for pattern, n in sorted(confusions.items(), key=lambda kv: -kv[1])[:top]:
            lines.append(f"    {n:3d}x  {pattern}")
    return "\n".join(lines)


def parts_check(blocks, sections) -> list[dict]:
    """Grade each ``Části osad`` entry's part-sums against its settlement's row.

    An entry is matched to a row by *name*, not by the printed sequence number:
    column 1 is the most heavily damaged in the table (``o``, ``в``, ``Г) o``), so
    joining on it would lose most entries to OCR rather than to disagreement. Where
    an entry's names hit more than one row the match is refused, not resolved on
    ordering — the same tie discipline the rest of the pipeline uses.
    """
    from utils.lexikon_1910 import lexikon_1910 as lx

    index = _row_index(blocks)
    findings: list[dict] = []
    for section in sections:
        if section.kind != "parts":
            continue
        page_index = index.get(section.page, {})
        for line in _entries(section):
            pairs = [(int(h), int(p)) for h, p in PART_RE.findall(line)]
            if not pairs:
                continue
            houses, population = sum(h for h, _ in pairs), sum(p for _, p in pairs)
            candidates = {normalise(n) for n in _NAME_RE.findall(line)}
            matched = {id(r): r for key in candidates for r in page_index.get(key, [])}
            rows = list(matched.values())
            base = {"check": "I8_parts", "district": section.district,
                    "page": section.page, "n_parts": len(pairs),
                    "parts_houses": houses, "parts_pop": population}
            if not rows:
                findings.append({**base, "row_name": "", "verdict": "unmatched",
                                 "detail": f"no table row named in: {line[:60]!r}"})
                continue
            if len(rows) > 1:
                findings.append({
                    **base, "row_name": "", "verdict": "ambiguous",
                    "detail": f"{len(rows)} rows match the names in this entry"})
                continue
            row = rows[0]
            for column, total in (("houses", houses), ("pop_total", population)):
                value, status = lx.parse_int_cell(row.get(column))
                if status == "bad":
                    verdict, detail = "recoverable", (
                        f"table {column} unreadable ({row.get(column)!r}); "
                        f"footnote parts give {total}")
                elif status == "blank":
                    verdict, detail = "na", ""
                elif value == total:
                    verdict, detail = "pass", ""
                else:
                    verdict, detail = "fail", (
                        f"table {column}={value} vs parts sum {total}")
                findings.append({**base, "column": column,
                                 "row_name": row.get("name")[:40],
                                 "verdict": verdict, "detail": detail})
    return findings


def _table_value(finding: dict) -> float:
    """The table figure quoted in a disagreement's detail line."""
    match = re.search(r"=(\d+)", finding.get("detail", ""))
    return float(match.group(1)) if match else 0.0


def lexikon_1910_notes_report(notes_list, sections, findings) -> str:
    """Ledger for the footnote apparatus."""
    lines = [f"lexikon_1910_notes v{__version__} — footnote apparatus", ""]
    if not notes_list:
        return "\n".join(lines + ["  no page yielded a footnote divider rule"])

    defined = keys_by_district(sections)
    parts = parts_by_district(sections)
    heights = altitudes(sections)
    n_parts = sum(len(v) for v in parts.values())
    kinds = {"parts": 0, "offices": 0}
    for s in sections:
        kinds[s.kind] = kinds.get(s.kind, 0) + 1

    lines.append(f"  band located on {len(notes_list)} pages")
    lines.append(f"  sections cut:      {kinds['parts']} parts, "
                 f"{kinds['offices']} offices, over "
                 f"{len({s.key for s in sections})} soudní okresy")
    lines.append(f"  keys defined:      {sum(len(v) for v in defined.values())} "
                 f"across {len(defined)} districts")
    lines.append(f"  altitudes read:    {len(heights)}"
                 + (f"  median {sorted(heights)[len(heights) // 2]} m"
                    if heights else ""))
    lines.append(f"  part house–pop pairs read: {n_parts}")
    lines.append("")

    counts: dict[str, int] = {}
    for f in findings:
        counts[f["verdict"]] = counts.get(f["verdict"], 0) + 1
    graded = counts.get("pass", 0) + counts.get("fail", 0)

    # A disagreement has two very different shapes and pooling them hides both.
    # When the parts fall far short of the table the entry was almost certainly
    # cut off by a page break — the apparatus continues overleaf — and that is a
    # coverage limit, not a reading conflict. When the two are the same size but
    # differ, one of them genuinely misread a digit, which is the whole point of
    # having a second channel.
    conflicts = [f for f in findings if f["verdict"] == "fail"
                 and f["parts_" + ("houses" if f.get("column") == "houses"
                                   else "pop")] > 0.9 * _table_value(f)]
    truncated = counts.get("fail", 0) - len(conflicts)

    lines.append("  I8 — footnote part-sums against the table row they belong to")
    if graded:
        lines.append(f"    agree                              {counts.get('pass', 0):5d}"
                     f"   {counts.get('pass', 0) / graded:6.1%}")
        lines.append(f"    conflict — same size, digits differ  {len(conflicts):5d}")
        lines.append(f"    parts fall short — entry continues overleaf "
                     f"{truncated:5d}")
    lines.append(f"    recovers a cell the table could not read  "
                 f"{counts.get('recoverable', 0):5d}")
    lines.append(f"    entry matched no table row                "
                 f"{counts.get('unmatched', 0):5d}")
    lines.append(f"    entry matched several rows — refused      "
                 f"{counts.get('ambiguous', 0):5d}")
    if conflicts:
        lines.append("")
        lines.append("    conflicts — the two channels read the same figure "
                     "differently:")
        for f in conflicts:
            lines.append(f"      {f.get('row_name', '')}: {f['detail']}")

    lines.append("")
    lines.append("  This is a fourth reading channel, not a legend: the parts are the")
    lines.append("  same figures set a second time elsewhere on the page, so an error")
    lines.append("  in one is uncorrelated with the other.")
    lines.append("")
    lines.append("  Not recovered: what the office keys *mean*. Those sections are")
    lines.append("  pictographic — post horn, bell, telegraph, school — and the OCR")
    lines.append("  renders the glyphs as noise. Their numbering also restarts inside")
    lines.append("  each municipality, so there is no district-wide key set to check")
    lines.append("  a reference against. Both need the page image, not this text layer.")
    return "\n".join(lines)
