TL;DR

Detects individuals appearing in both final datasets so the double-desertion comparison design is not silently double-counting the same person across the legionnaire population and the fallen-soldier comparison population.

How it works

Records are matched on the fields shared by both sources (no common id exists):

surname, given_name, birth_year, full date of birth, birth_okres

A full 133k × 186k cross-product is avoided by blocking: candidate pairs are only scored within the same (birth_year, phonetic surname initial) block.

The name test (v1.3.0)

Surname and given name are scored separately, each on a phonetic key that folds the Czech/German orthography the two archives mix (sch→s, tsch/cz/tz/z→c, w→v, ph→f, th→t, y/ie→i, doubled letters): the surname must reach a token_set_ratio of SURNAME_MIN (SURNAME_MIN_CORROBORATED when the birth okres agrees too) and the given name GIVEN_MIN.

Until v1.2.x one token_sort_ratio over the concatenated "surname given" string had to reach 80, and a long common given name carried the pair on its own: STANĚK František ↔ Soja František scored exactly 80. On the 2026-09-03 build, 263 DOB-confirmed and 126 note-confirmed pairs had surnames less than 60 % alike (BERAN↔Bureš, ČERNÝ↔Cvrk), and 111 VÚA records were claimed by two to four different legionnaires — one Zdice-born František by Šůra, Škvára, Schoř and Šinágl (audit 2026-09-22 §A1).

Precision-first confirmed-overlap rule. A pair counts as a confirmed overlap only when it clears one of two gold standards; everything weaker is dropped:

high   : identical full day+month+year of birth  +  compatible names
medium : VÚA `note_legion` is True  +  same birth okres  +  same birth year
         +  compatible names — the Poznámka **explicitly** records Legion
         service and the demographics pin which legionnaire.

Four refusals sit on top (v1.3.0):

  • a pair whose full dates of birth both exist and disagree is refused — it is direct evidence against identity, and 31 note-confirmed pairs used to carry one;
  • a surname scoring 85-90 counts only when the birth okres agrees too;
  • one-to-one: each legion id keeps its best candidate and each VÚA id its best claimant; a tie at the top is refused rather than broken by lookup order;
  • criterion B only fires on the corrected note_legion (habsburg 1.2.0), which no longer mistakes the interwar army's register references for Legion service.

Known recall limitations (deliberate — state in the paper's linkage appendix): both criteria require an exact birth year; a person can only DOB-confirm when both sides carry a full (not year-only) birth date; exact ties are refused, so a man recorded twice in csol (see add_duplicate_groups) cannot link at all.

def phonetic_key(v) -> str:
    """Phonetic comparison key for a name (see :data:`_PHON`); ``""`` if missing."""
    s = _norm_name(v)
    for a, b in _PHON:
        s = s.replace(a, b)
    return re.sub(r"(.)\1+", r"\1", s)

def names_compatible(sur_a, giv_a, sur_b, giv_b,
                     corroborated: bool = False) -> tuple[bool, float, float]:
    """``(ok, surname_score, given_score)`` — both scores on the phonetic keys.

    *corroborated* (the birth okres also agrees) lowers the surname bar to
    :data:`SURNAME_MIN_CORROBORATED`.
    """
    s = fuzz.token_set_ratio(phonetic_key(sur_a), phonetic_key(sur_b))
    g = fuzz.token_set_ratio(phonetic_key(giv_a), phonetic_key(giv_b))
    bar = SURNAME_MIN_CORROBORATED if corroborated else SURNAME_MIN
    return (s >= bar and g >= GIVEN_MIN), s, g

def find_overlap(
    legion_df: pd.DataFrame,
    habsburg_df: pd.DataFrame,
    *,
    year_window: int = 0,
    report: bool = True,
) -> pd.DataFrame:
    """Find confirmed overlaps between the datasets, one-to-one.

    Returns only pairs clearing a gold standard in :func:`_tier`, with compatible names
    (:func:`names_compatible`) and no disagreeing full dates of birth; ambiguous ties are
    refused on both sides. ``year_window`` is left as a parameter for experimentation only
    (both criteria need an exact year).

    Returns
    -------
    pd.DataFrame
        One row per confirmed pair: ``legion_id, vua_id, name_score, surname_score,
        given_score, birth_year_legion, birth_year_vua, date_exact, okres_match,
        note_legion, confidence, surname_legion, given_legion, surname_vua, given_vua``.
        ``attrs["refused"]`` counts the pairs dropped by each refusal rule.
    """
    L = _prepare(legion_df, "legion_id")
    H = _prepare(habsburg_df, "vua_id")

    blocks: dict[tuple[int, str], list[int]] = {}
    for pos, (yr, ini) in enumerate(zip(H["year"], H["initial"])):
        blocks.setdefault((yr, ini), []).append(pos)

    h_sur, h_giv = H["sur_k"].tolist(), H["giv_k"].tolist()
    h_id, h_year = H["id"].tolist(), H["year"].tolist()
    h_okres, h_bdate, h_note = H["okres_n"].tolist(), H["bdate"].tolist(), H["note_legion"].tolist()

    year_offsets = [0] + ([-1, 1] if year_window else [])
    cands: list[dict] = []
    n_dob_conflict = 0
    for l_id, l_sur, l_giv, l_year, l_okres, l_bdate, l_ini in zip(
        L["id"], L["sur_k"], L["giv_k"], L["year"], L["okres_n"], L["bdate"], L["initial"]
    ):
        for off in year_offsets:
            positions = blocks.get((l_year + off, l_ini))
            if not positions:
                continue
            choices = {p: h_sur[p] for p in positions}
            for _, s_score, pos in process.extract(
                l_sur, choices, scorer=fuzz.token_set_ratio,
                score_cutoff=SURNAME_MIN_CORROBORATED, limit=None,
            ):
                g_score = fuzz.token_set_ratio(l_giv, h_giv[pos])
                if g_score < GIVEN_MIN:
                    continue
                okres_match = bool(l_okres) and l_okres == h_okres[pos]
                if s_score < SURNAME_MIN and not okres_match:
                    continue                             # 85-90 needs the okres as well
                date_exact = bool(l_bdate) and l_bdate == h_bdate[pos]
                note = bool(h_note[pos])
                tier = _tier(date_exact, okres_match, off == 0, note)
                if tier is None:
                    continue
                if l_bdate and h_bdate[pos] and not date_exact:
                    n_dob_conflict += 1                  # would pass B, but the DOBs disagree
                    continue
                cands.append({
                    "legion_id": l_id, "vua_id": h_id[pos],
                    "surname_score": round(s_score, 1), "given_score": round(g_score, 1),
                    "birth_year_legion": l_year, "birth_year_vua": h_year[pos],
                    "date_exact": date_exact, "okres_match": okres_match,
                    "note_legion": note, "confidence": tier,
                    "_rank": (_TIER_RANK[tier], int(date_exact), int(note),
                              round(s_score, 1), round(g_score, 1)),
                })

    cols = ["legion_id", "vua_id", "name_score", "surname_score", "given_score",
            "birth_year_legion", "birth_year_vua", "date_exact", "okres_match",
            "note_legion", "confidence", "surname_legion", "given_legion",
            "surname_vua", "given_vua"]
    refused = {"dob_conflict": n_dob_conflict, "tie_legion_side": 0, "tie_vua_side": 0}
    if not cands:
        out = pd.DataFrame(columns=cols)
        out.attrs["refused"] = refused
        return out

    C = pd.DataFrame(cands)

    # One-to-one. A legion record keeps its best candidate; if two VÚA records tie at the
    # top it names neither of them. Then each VÚA record keeps its best claimant, again
    # refusing a tie. Nothing is decided by row order.
    def _best(frame: pd.DataFrame, key: str, tie_name: str) -> pd.DataFrame:
        top = frame.groupby(key)["_rank"].transform("max")
        best = frame[frame["_rank"] == top]
        n_at_top = best.groupby(key)[key].transform("size")
        refused[tie_name] += int(best.loc[n_at_top > 1, key].nunique())
        return best[n_at_top == 1]

    C = _best(C, "legion_id", "tie_legion_side")
    C = _best(C, "vua_id", "tie_vua_side")

    matches = C.drop(columns="_rank").copy()
    matches["name_score"] = matches[["surname_score", "given_score"]].min(axis=1)
    leg_names = legion_df.set_index("legion_id")[["surname", "given_name"]]
    vua_names = habsburg_df.set_index("vua_id")[["surname", "given_name"]]
    matches = matches.join(leg_names.rename(
        columns={"surname": "surname_legion", "given_name": "given_legion"}), on="legion_id")
    matches = matches.join(vua_names.rename(
        columns={"surname": "surname_vua", "given_name": "given_vua"}), on="vua_id")

    order = pd.Categorical(matches["confidence"], categories=["high", "medium", "low"],
                           ordered=True)
    matches = (matches.assign(_o=order).sort_values(["_o", "name_score"], ascending=[True, False])
               .drop(columns="_o").reset_index(drop=True)[cols])
    matches.attrs["refused"] = refused
    if report:
        print(f"linkage refusals: {refused['dob_conflict']:,} note-confirmed pairs with "
              f"disagreeing full DOBs; {refused['tie_legion_side']:,} legion ids and "
              f"{refused['tie_vua_side']:,} VÚA ids with a tie at the top")
    return matches

def add_overlap_flags(
    df: pd.DataFrame,
    matches: pd.DataFrame,
    *,
    id_col: str,
    other_id_col: str,
) -> pd.DataFrame:
    """Append ``in_other_dataset`` / ``match_id`` / ``match_confidence`` to *df*.

    Matches are one-to-one since v1.3.0, so both sides carry the same links.
    """
    df = df.copy()
    if matches.empty:
        df["in_other_dataset"] = False
        df["match_id"] = pd.NA
        df["match_confidence"] = pd.NA
        return df

    lookup = matches.drop_duplicates(subset=id_col).set_index(id_col)
    df["match_id"] = df[id_col].map(lookup[other_id_col])
    df["match_confidence"] = df[id_col].map(lookup["confidence"])
    df["in_other_dataset"] = df["match_id"].notna()
    return df

def add_duplicate_groups(df: pd.DataFrame, id_col: str,
                         muni_col: str = "birth_municipality",
                         out: str = "dup_group") -> pd.DataFrame:
    """Flag probable duplicate records of the **same person inside one dataset**.

    Records sharing normalised surname + given name + a *full* date of birth + birth
    municipality get ``{out}`` = the smallest id in the group; everyone else ``<NA>``.
    csol.cz holds such pairs (ADÁMEK Karel, 11917 and 130959: same birth date, birthplace
    and enrolment date, one with a unit and one without — audit 2026-09-22 §B13). Nothing is
    dropped: which record is the better one is an analytical call, and the flag lets a
    hazard model count the man once.
    """
    key = pd.DataFrame({
        "s": df["surname"].map(_norm_name),
        "g": df["given_name"].map(_norm_name),
        "d": _full_dob(df),
        "m": df[muni_col].map(_norm_name) if muni_col in df else "",
    }, index=df.index)
    ok = (key["s"] != "") & (key["g"] != "") & (key["d"] != "")
    grp = df[id_col].where(ok).groupby([key["s"], key["g"], key["d"], key["m"]]).transform("min")
    size = df[id_col].where(ok).groupby([key["s"], key["g"], key["d"], key["m"]]).transform("count")
    res = df.copy()
    res[out] = pd.array(grp.where(ok & (size > 1)), dtype="Int64")
    return res

def linkage_selftest() -> list[str]:
    """Behaviours that shipped wrong once; empty list means all hold."""
    fails: list[str] = []
    cases = [
        # the given name must not carry a different surname (audit 2026-09-22 §A1)
        (("STANĚK", "František", "Soja", "František"), False),
        (("BERAN", "František", "Bureš", "František"), False),
        (("PROCHÁZKA", "Antonín", "Procházka", "Jan"), False),
        # orthographic variants of one surname still meet
        (("Švarc", "Josef", "Schwarz", "Josef"), True),
        (("NOVÁK", "Jan", "Nowak", "Jan"), True),
        (("RIGR RIEGER", "Bedřich", "Riegr", "Bedřich"), True),
        (("HÜBNER", "Alois", "Huebner", "Alois"), True),
    ]
    for (sa, ga, sb, gb), want in cases:
        got = names_compatible(sa, ga, sb, gb)[0]
        if got != want:
            fails.append(f"names_compatible{(sa, ga, sb, gb)} = {got}, expected {want}")
    return fails

def linkage_report(matches: pd.DataFrame, habsburg_df: pd.DataFrame) -> None:
    """Print confirmed-overlap counts split by evidence type."""
    n = len(matches)
    print(f"Linkage report  (confirmed overlaps = {n:,})\n")
    if n == 0:
        print("  No overlaps found.")
        return

    _label = {"high": "DOB-confirmed (exact full DOB)",
              "medium": "note-confirmed (legion note + okres + year)"}
    print("  By evidence type:")
    for tier in ("high", "medium"):
        c = int((matches["confidence"] == tier).sum())
        print(f"    {_label[tier]:<42}: {c:>7,}  ({c/n:.1%})")

    n_date = int(matches["date_exact"].sum())
    n_note = int(matches["note_legion"].sum())
    n_both = int((matches["date_exact"] & matches["note_legion"]).sum())
    print("\n  Evidence carried (a match may satisfy both criteria):")
    print(f"    exact full DOB        : {n_date:,}  ({n_date/n:.1%})")
    print(f"    VÚA note_legion=True  : {n_note:,}  ({n_note/n:.1%})")
    print(f"    both                  : {n_both:,}  ({n_both/n:.1%})")
    print(f"  vua_ids matched >1×     : {n - matches['vua_id'].nunique():,} (must be 0)")
    ref = matches.attrs.get("refused")
    if ref:
        print(f"  refused: {ref}")

    if "note_legion" in habsburg_df.columns:
        hv = habsburg_df.set_index("vua_id")["note_legion"].fillna(False)
        total_flagged = int(hv.sum())
        recovered = int(hv.reindex(matches["vua_id"].unique()).fillna(False).sum())
        print(f"\n  Of all VÚA note_legion=True ({total_flagged:,}), confirmed as an "
              f"overlap: {recovered:,}  ({recovered/max(total_flagged,1):.1%})")

linkage.py — Cross-dataset person linkage (legionnaires ↔ Habsburg fallen)
==========================================================================
Detects individuals appearing in **both** final datasets so the
double-desertion comparison design is not silently double-counting the same
person across the legionnaire population and the fallen-soldier comparison
population.

Records are matched on the fields shared by both sources (no common id exists):

    surname, given_name, birth_year, full date of birth, birth_okres

A full 133k × 186k cross-product is avoided by **blocking**: candidate pairs are
only scored within the same ``(birth_year, phonetic surname initial)`` block.

The name test (v1.3.0)
----------------------
**Surname and given name are scored separately**, each on a phonetic key that folds
the Czech/German orthography the two archives mix (``sch``→s, ``tsch``/``cz``/``tz``/``z``→c,
``w``→v, ``ph``→f, ``th``→t, ``y``/``ie``→i, doubled letters): the surname must reach a
``token_set_ratio`` of :data:`SURNAME_MIN` (:data:`SURNAME_MIN_CORROBORATED` when the birth
okres agrees too) and the given name :data:`GIVEN_MIN`.

Until v1.2.x one ``token_sort_ratio`` over the concatenated "surname given" string
had to reach 80, and a long common given name carried the pair on its own:
``STANĚK František`` ↔ ``Soja František`` scored exactly 80. On the 2026-09-03 build,
263 DOB-confirmed and 126 note-confirmed pairs had surnames less than 60 % alike
(BERAN↔Bureš, ČERNÝ↔Cvrk), and 111 VÚA records were claimed by two to four different
legionnaires — one Zdice-born František by Šůra, Škvára, Schoř *and* Šinágl
(audit 2026-09-22 §A1).

**Precision-first confirmed-overlap rule.**  A pair counts as a *confirmed* overlap
only when it clears one of two gold standards; everything weaker is dropped:

    high   : identical full day+month+year of birth  +  compatible names
    medium : VÚA ``note_legion`` is True  +  same birth okres  +  same birth year
             +  compatible names — the Poznámka **explicitly** records Legion
             service and the demographics pin which legionnaire.

Four refusals sit on top (v1.3.0):

* a pair whose **full** dates of birth both exist and **disagree** is refused — it is
  direct evidence against identity, and 31 note-confirmed pairs used to carry one;
* a surname scoring 85-90 counts only when the birth okres agrees too;
* **one-to-one**: each legion id keeps its best candidate and each VÚA id its best
  claimant; a tie at the top is refused rather than broken by lookup order;
* criterion B only fires on the corrected ``note_legion`` (``habsburg`` 1.2.0), which
  no longer mistakes the interwar army's register references for Legion service.

Known recall limitations (deliberate — state in the paper's linkage appendix): both
criteria require an exact birth year; a person can only DOB-confirm when both sides
carry a full (not year-only) birth date; exact ties are refused, so a man recorded
twice in csol (see :func:`add_duplicate_groups`) cannot link at all.

Usage
-----
    from utils.linkage import find_overlap, add_overlap_flags, linkage_report
    matches = find_overlap(legion_df, habsburg_df)
    legion_df   = add_overlap_flags(legion_df,   matches, id_col="legion_id", other_id_col="vua_id")
    habsburg_df = add_overlap_flags(habsburg_df, matches, id_col="vua_id",    other_id_col="legion_id")
    linkage_report(matches, habsburg_df)
"""

from __future__ import annotations

import re
import unicodedata

import pandas as pd

try:
    from rapidfuzz import fuzz, process
except ImportError as exc:  # pragma: no cover
    raise ImportError(
        "linkage.py requires rapidfuzz — add it to requirements.txt and "
        "`pip install rapidfuzz`."
    ) from exc

__version__ = "1.3.0"   # surname/given scored separately, DOB conflicts refused, one-to-one

# Confidence tiers, ordered strongest → weakest (used to rank candidates).
_TIER_RANK = {"high": 3, "medium": 2, "low": 1}

# Name thresholds on the phonetic keys (token_set_ratio, 0-100). Read off the data rather
# than chosen: over every exact-DOB, same-given-name pair in the two files, pairs whose
# surnames start with *different* letters (chance coincidences by construction) still reach
# the 80-90 band, so a surname between 85 and 90 is accepted only when the birth okres
# agrees as well; from 90 up it stands on the name (audit 2026-09-22 §A1).
SURNAME_MIN = 90
SURNAME_MIN_CORROBORATED = 85
GIVEN_MIN = 80


# ── Normalisation ─────────────────────────────────────────────────────────────

def _strip_diacritics(s: str) -> str:
    """Fold Czech diacritics to ASCII (Čermák → Cermak)."""
    nfkd = unicodedata.normalize("NFKD", s)
    return "".join(c for c in nfkd if not unicodedata.combining(c))


def _norm_name(v) -> str:
    """Lowercase, de-accent, keep letters/spaces only, collapse whitespace."""
    if v is None or (not isinstance(v, str) and pd.isna(v)):
        return ""
    s = _strip_diacritics(str(v)).lower()
    s = "".join(c if c.isalpha() or c.isspace() else " " for c in s)
    return " ".join(s.split())


# Czech/German orthography folds, longest first. Both archives spell the same man both
# ways (Švarc/Schwarz, Černý/Tscherny, Novák/Nowak); the fold makes those equal without
# letting two different surnames meet.
_PHON: tuple[tuple[str, str], ...] = (
    ("tsch", "c"), ("sch", "s"), ("tz", "c"), ("cz", "c"), ("ck", "k"),
    ("ph", "f"), ("th", "t"), ("w", "v"), ("y", "i"), ("ie", "i"), ("z", "c"),
    ("ue", "u"), ("oe", "o"), ("ae", "a"),                 # German umlaut digraphs
)


def phonetic_key(v) -> str:
    """Phonetic comparison key for a name (see :data:`_PHON`); ``""`` if missing."""
    s = _norm_name(v)
    for a, b in _PHON:
        s = s.replace(a, b)
    return re.sub(r"(.)\1+", r"\1", s)


def names_compatible(sur_a, giv_a, sur_b, giv_b,
                     corroborated: bool = False) -> tuple[bool, float, float]:
    """``(ok, surname_score, given_score)`` — both scores on the phonetic keys.

    *corroborated* (the birth okres also agrees) lowers the surname bar to
    :data:`SURNAME_MIN_CORROBORATED`.
    """
    s = fuzz.token_set_ratio(phonetic_key(sur_a), phonetic_key(sur_b))
    g = fuzz.token_set_ratio(phonetic_key(giv_a), phonetic_key(giv_b))
    bar = SURNAME_MIN_CORROBORATED if corroborated else SURNAME_MIN
    return (s >= bar and g >= GIVEN_MIN), s, g


def _norm_okres(v) -> str:
    """Normalise an okres string for equality comparison (de-accented, lower)."""
    if v is None or (not isinstance(v, str) and pd.isna(v)):
        return ""
    return " ".join(_strip_diacritics(str(v)).lower().split())


# ── Preparation ───────────────────────────────────────────────────────────────

def _full_dob(df: pd.DataFrame) -> pd.Series:
    """``YYYYMMDD`` where a *full* birth date exists (not a year-only fallback), else ``""``."""
    if "birth_date" not in df:
        return pd.Series("", index=df.index)
    bd = pd.to_datetime(df["birth_date"], errors="coerce")
    yo = (df["birth_year_only"].astype("boolean").fillna(False)
          if "birth_year_only" in df else pd.Series(False, index=df.index))
    full = bd.notna() & ~yo.to_numpy()
    return pd.Series(bd.dt.strftime("%Y%m%d").values, index=df.index).where(full, "")


def _prepare(df: pd.DataFrame, id_col: str) -> pd.DataFrame:
    """Compact frame: id, names + phonetic keys, year, full DOB, okres, note flag."""
    out = pd.DataFrame({
        "id": df[id_col].values,
        "surname": df["surname"].values,
        "given": df["given_name"].values,
        "sur_k": df["surname"].map(phonetic_key).values,
        "giv_k": df["given_name"].map(phonetic_key).values,
        "okres_n": (df["birth_okres"].map(_norm_okres).values
                    if "birth_okres" in df else ""),
        "bdate": _full_dob(df).values,
    })
    out["year"] = pd.to_numeric(df["birth_year"], errors="coerce").values
    out["initial"] = out["sur_k"].str[:1]
    # VÚA's own Legion signal, parsed from the Poznámka; present only on the Habsburg side.
    out["note_legion"] = (
        df["note_legion"].fillna(False).astype(bool).values
        if "note_legion" in df.columns else False
    )
    out = out[(out["sur_k"] != "") & (out["giv_k"] != "") & out["year"].notna()]
    out["year"] = out["year"].astype(int)
    return out.reset_index(drop=True)


def _tier(date_exact: bool, okres_match: bool, year_exact: bool,
          note_legion: bool) -> str | None:
    """Classify a candidate pair whose names already passed, or ``None`` to drop it.

    * ``high``   — ``date_exact``: identical full day+month+year of birth.
    * ``medium`` — ``note_legion`` and ``okres_match`` and ``year_exact``.
    """
    if date_exact:                                       # gold standard A (DOB)
        return "high"
    if note_legion and okres_match and year_exact:       # gold standard B (note)
        return "medium"
    return None                                          # everything else → drop


# ── Core matcher ──────────────────────────────────────────────────────────────

def find_overlap(
    legion_df: pd.DataFrame,
    habsburg_df: pd.DataFrame,
    *,
    year_window: int = 0,
    report: bool = True,
) -> pd.DataFrame:
    """Find confirmed overlaps between the datasets, one-to-one.

    Returns only pairs clearing a gold standard in :func:`_tier`, with compatible names
    (:func:`names_compatible`) and no disagreeing full dates of birth; ambiguous ties are
    refused on both sides. ``year_window`` is left as a parameter for experimentation only
    (both criteria need an exact year).

    Returns
    -------
    pd.DataFrame
        One row per confirmed pair: ``legion_id, vua_id, name_score, surname_score,
        given_score, birth_year_legion, birth_year_vua, date_exact, okres_match,
        note_legion, confidence, surname_legion, given_legion, surname_vua, given_vua``.
        ``attrs["refused"]`` counts the pairs dropped by each refusal rule.
    """
    L = _prepare(legion_df, "legion_id")
    H = _prepare(habsburg_df, "vua_id")

    blocks: dict[tuple[int, str], list[int]] = {}
    for pos, (yr, ini) in enumerate(zip(H["year"], H["initial"])):
        blocks.setdefault((yr, ini), []).append(pos)

    h_sur, h_giv = H["sur_k"].tolist(), H["giv_k"].tolist()
    h_id, h_year = H["id"].tolist(), H["year"].tolist()
    h_okres, h_bdate, h_note = H["okres_n"].tolist(), H["bdate"].tolist(), H["note_legion"].tolist()

    year_offsets = [0] + ([-1, 1] if year_window else [])
    cands: list[dict] = []
    n_dob_conflict = 0
    for l_id, l_sur, l_giv, l_year, l_okres, l_bdate, l_ini in zip(
        L["id"], L["sur_k"], L["giv_k"], L["year"], L["okres_n"], L["bdate"], L["initial"]
    ):
        for off in year_offsets:
            positions = blocks.get((l_year + off, l_ini))
            if not positions:
                continue
            choices = {p: h_sur[p] for p in positions}
            for _, s_score, pos in process.extract(
                l_sur, choices, scorer=fuzz.token_set_ratio,
                score_cutoff=SURNAME_MIN_CORROBORATED, limit=None,
            ):
                g_score = fuzz.token_set_ratio(l_giv, h_giv[pos])
                if g_score < GIVEN_MIN:
                    continue
                okres_match = bool(l_okres) and l_okres == h_okres[pos]
                if s_score < SURNAME_MIN and not okres_match:
                    continue                             # 85-90 needs the okres as well
                date_exact = bool(l_bdate) and l_bdate == h_bdate[pos]
                note = bool(h_note[pos])
                tier = _tier(date_exact, okres_match, off == 0, note)
                if tier is None:
                    continue
                if l_bdate and h_bdate[pos] and not date_exact:
                    n_dob_conflict += 1                  # would pass B, but the DOBs disagree
                    continue
                cands.append({
                    "legion_id": l_id, "vua_id": h_id[pos],
                    "surname_score": round(s_score, 1), "given_score": round(g_score, 1),
                    "birth_year_legion": l_year, "birth_year_vua": h_year[pos],
                    "date_exact": date_exact, "okres_match": okres_match,
                    "note_legion": note, "confidence": tier,
                    "_rank": (_TIER_RANK[tier], int(date_exact), int(note),
                              round(s_score, 1), round(g_score, 1)),
                })

    cols = ["legion_id", "vua_id", "name_score", "surname_score", "given_score",
            "birth_year_legion", "birth_year_vua", "date_exact", "okres_match",
            "note_legion", "confidence", "surname_legion", "given_legion",
            "surname_vua", "given_vua"]
    refused = {"dob_conflict": n_dob_conflict, "tie_legion_side": 0, "tie_vua_side": 0}
    if not cands:
        out = pd.DataFrame(columns=cols)
        out.attrs["refused"] = refused
        return out

    C = pd.DataFrame(cands)

    # One-to-one. A legion record keeps its best candidate; if two VÚA records tie at the
    # top it names neither of them. Then each VÚA record keeps its best claimant, again
    # refusing a tie. Nothing is decided by row order.
    def _best(frame: pd.DataFrame, key: str, tie_name: str) -> pd.DataFrame:
        top = frame.groupby(key)["_rank"].transform("max")
        best = frame[frame["_rank"] == top]
        n_at_top = best.groupby(key)[key].transform("size")
        refused[tie_name] += int(best.loc[n_at_top > 1, key].nunique())
        return best[n_at_top == 1]

    C = _best(C, "legion_id", "tie_legion_side")
    C = _best(C, "vua_id", "tie_vua_side")

    matches = C.drop(columns="_rank").copy()
    matches["name_score"] = matches[["surname_score", "given_score"]].min(axis=1)
    leg_names = legion_df.set_index("legion_id")[["surname", "given_name"]]
    vua_names = habsburg_df.set_index("vua_id")[["surname", "given_name"]]
    matches = matches.join(leg_names.rename(
        columns={"surname": "surname_legion", "given_name": "given_legion"}), on="legion_id")
    matches = matches.join(vua_names.rename(
        columns={"surname": "surname_vua", "given_name": "given_vua"}), on="vua_id")

    order = pd.Categorical(matches["confidence"], categories=["high", "medium", "low"],
                           ordered=True)
    matches = (matches.assign(_o=order).sort_values(["_o", "name_score"], ascending=[True, False])
               .drop(columns="_o").reset_index(drop=True)[cols])
    matches.attrs["refused"] = refused
    if report:
        print(f"linkage refusals: {refused['dob_conflict']:,} note-confirmed pairs with "
              f"disagreeing full DOBs; {refused['tie_legion_side']:,} legion ids and "
              f"{refused['tie_vua_side']:,} VÚA ids with a tie at the top")
    return matches


# ── Flagging ──────────────────────────────────────────────────────────────────

def add_overlap_flags(
    df: pd.DataFrame,
    matches: pd.DataFrame,
    *,
    id_col: str,
    other_id_col: str,
) -> pd.DataFrame:
    """Append ``in_other_dataset`` / ``match_id`` / ``match_confidence`` to *df*.

    Matches are one-to-one since v1.3.0, so both sides carry the same links.
    """
    df = df.copy()
    if matches.empty:
        df["in_other_dataset"] = False
        df["match_id"] = pd.NA
        df["match_confidence"] = pd.NA
        return df

    lookup = matches.drop_duplicates(subset=id_col).set_index(id_col)
    df["match_id"] = df[id_col].map(lookup[other_id_col])
    df["match_confidence"] = df[id_col].map(lookup["confidence"])
    df["in_other_dataset"] = df["match_id"].notna()
    return df


# ── Duplicate persons inside one dataset ──────────────────────────────────────

def add_duplicate_groups(df: pd.DataFrame, id_col: str,
                         muni_col: str = "birth_municipality",
                         out: str = "dup_group") -> pd.DataFrame:
    """Flag probable duplicate records of the **same person inside one dataset**.

    Records sharing normalised surname + given name + a *full* date of birth + birth
    municipality get ``{out}`` = the smallest id in the group; everyone else ``<NA>``.
    csol.cz holds such pairs (ADÁMEK Karel, 11917 and 130959: same birth date, birthplace
    and enrolment date, one with a unit and one without — audit 2026-09-22 §B13). Nothing is
    dropped: which record is the better one is an analytical call, and the flag lets a
    hazard model count the man once.
    """
    key = pd.DataFrame({
        "s": df["surname"].map(_norm_name),
        "g": df["given_name"].map(_norm_name),
        "d": _full_dob(df),
        "m": df[muni_col].map(_norm_name) if muni_col in df else "",
    }, index=df.index)
    ok = (key["s"] != "") & (key["g"] != "") & (key["d"] != "")
    grp = df[id_col].where(ok).groupby([key["s"], key["g"], key["d"], key["m"]]).transform("min")
    size = df[id_col].where(ok).groupby([key["s"], key["g"], key["d"], key["m"]]).transform("count")
    res = df.copy()
    res[out] = pd.array(grp.where(ok & (size > 1)), dtype="Int64")
    return res


# ── Self-test ─────────────────────────────────────────────────────────────────

def linkage_selftest() -> list[str]:
    """Behaviours that shipped wrong once; empty list means all hold."""
    fails: list[str] = []
    cases = [
        # the given name must not carry a different surname (audit 2026-09-22 §A1)
        (("STANĚK", "František", "Soja", "František"), False),
        (("BERAN", "František", "Bureš", "František"), False),
        (("PROCHÁZKA", "Antonín", "Procházka", "Jan"), False),
        # orthographic variants of one surname still meet
        (("Švarc", "Josef", "Schwarz", "Josef"), True),
        (("NOVÁK", "Jan", "Nowak", "Jan"), True),
        (("RIGR RIEGER", "Bedřich", "Riegr", "Bedřich"), True),
        (("HÜBNER", "Alois", "Huebner", "Alois"), True),
    ]
    for (sa, ga, sb, gb), want in cases:
        got = names_compatible(sa, ga, sb, gb)[0]
        if got != want:
            fails.append(f"names_compatible{(sa, ga, sb, gb)} = {got}, expected {want}")
    return fails


# ── Reporting / validation ────────────────────────────────────────────────────

def linkage_report(matches: pd.DataFrame, habsburg_df: pd.DataFrame) -> None:
    """Print confirmed-overlap counts split by evidence type."""
    n = len(matches)
    print(f"Linkage report  (confirmed overlaps = {n:,})\n")
    if n == 0:
        print("  No overlaps found.")
        return

    _label = {"high": "DOB-confirmed (exact full DOB)",
              "medium": "note-confirmed (legion note + okres + year)"}
    print("  By evidence type:")
    for tier in ("high", "medium"):
        c = int((matches["confidence"] == tier).sum())
        print(f"    {_label[tier]:<42}: {c:>7,}  ({c/n:.1%})")

    n_date = int(matches["date_exact"].sum())
    n_note = int(matches["note_legion"].sum())
    n_both = int((matches["date_exact"] & matches["note_legion"]).sum())
    print("\n  Evidence carried (a match may satisfy both criteria):")
    print(f"    exact full DOB        : {n_date:,}  ({n_date/n:.1%})")
    print(f"    VÚA note_legion=True  : {n_note:,}  ({n_note/n:.1%})")
    print(f"    both                  : {n_both:,}  ({n_both/n:.1%})")
    print(f"  vua_ids matched >1×     : {n - matches['vua_id'].nunique():,} (must be 0)")
    ref = matches.attrs.get("refused")
    if ref:
        print(f"  refused: {ref}")

    if "note_legion" in habsburg_df.columns:
        hv = habsburg_df.set_index("vua_id")["note_legion"].fillna(False)
        total_flagged = int(hv.sum())
        recovered = int(hv.reindex(matches["vua_id"].unique()).fillna(False).sum())
        print(f"\n  Of all VÚA note_legion=True ({total_flagged:,}), confirmed as an "
              f"overlap: {recovered:,}  ({recovered/max(total_flagged,1):.1%})")
