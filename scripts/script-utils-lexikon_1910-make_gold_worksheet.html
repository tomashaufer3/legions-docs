How it works

Companion to make_transcription_worksheet, which built the first four pages and is left alone — its output is hours of a person's attention and this writes somewhere else entirely.

The sheet is a named-part ledger. One line per key, and every line carries obec › část:

18,1    Kbelnice, Kbelnitz    › Kbelnice, Kbelnitz    >
18,2    Kbelnice, Kbelnitz    › Soudná, Soudna        >

The municipality used to live in a block heading and the part in the row, so a transcriber twenty rows into Jičín's twenty-two municipalities had to scroll up to find out which block they were in. Both names on every line removes that entirely, and the redundancy is cheap: the names are pre-filled from the printed table and nobody types a place name.

Because the register itself addresses parts by name. Inside one printed key it prints a part's name and then that part's institutions, in order::

17, —) Kartouzy: † 314 m, věznice pro muže s nemocenským odděl., ♀.
       Valdice:  ▤ III, ⚕, 🪜, ∾ (Kartouzy-Valdice), 🚂 301 m.
18,  1) 🪜.
       Zebín: † 400 m.

Zebín is the case that decides the design: it is printed, it has a church, and the table gives it no number anywhere. A sheet keyed only on m,n has nowhere to put it and the reading is lost. Hence the __,+ escape, written once per section as a blank template rather than as two dead rows on every municipality.

And the number column fails in both documents at once. The old rule dropped a table block whose sequence number the OCR destroyed, on the reasoning that parse_entries would carry it instead and flag it !roster. But the apparatus keys are the same column one document lower, so when it goes, it goes in both. Scan 0136 reads Jičín's municipalities 4, 6 and 9 as i, <> and í); all three are printed in the apparatus with symbols (4, 1) ⚕, 🪜) and all three had no row on the sheet at all. _repair_run reconstructs a number from reading order where the arithmetic is unique — 3, ?, 5 can only be 4 — leaves it unaddressed where it is not, and marks a number that parses but goes backwards (15, 10, 17, the 16 read as a 10) as suspect rather than trusting it.

A symbol can be attached to more than one part. The register prints an institution once and lets it serve several parts of the same municipality — the cadastral community [cadastral] (3,5) is the visible case. A symbol may carry @ and the parts it covers: [school] II @1+3.

Why this matters more than it did: the analysis will use the register at settlement level, and lexikon_1910_institutions._entry_key deliberately pools a municipality's sub-entries because settlement_seq is a single character in the most damaged column on the page. A person reading the print is the only channel that can say whether that character is recoverable at all, and this sheet is the instrument that asks.

def build(pages: list[int], role: str, out_dir: Path, enlarge: int,
          fmt: str = "md", sections: str = "all") -> int:
    out_dir.mkdir(parents=True, exist_ok=True)
    wanted = (("parts", "offices") if sections == "all" else (sections,))
    sheet = out_dir / "worksheet.txt"

    existing = ([sheet] if fmt == "ledger" and sheet.exists()
                else sorted(out_dir.glob("[0-9][0-9][0-9][0-9].md")))
    for path in existing:
        filled = _filled(path)
        if filled:
            print(f"!! {path} already has {filled} filled cells. Refusing to "
                  f"overwrite.\n   Move it aside first if you really mean to "
                  f"rebuild.")
            return 1

    window = sorted({p + d for p in pages
                     for d in range(-WINDOW_BACK, WINDOW_FORWARD + 1)
                     if 15 <= p + d <= 494})
    paths = [CZ_PAGES / f"{n:04d}.alto.xml" for n in window]
    print(f"grid + table over {len(window)} pages "
          f"({window[0]}-{window[-1]}) ...")
    template = _grid_template([p for p in paths if p.exists()])
    by_page_court, heads = _read_window(window, template)
    roster = _roster(by_page_court)
    print(f"  {sum(len(v) for v in by_page_court.values())} table blocks, "
          f"{len(roster)} court(s)")

    printed_pages = _printed_pages()
    lines = [HEADER.format(role=role,
                           pages=",".join(str(p) for p in pages))]
    index_rows: list[dict] = []
    n_keys = n_missing = 0

    for number in pages:
        path = CZ_PAGES / f"{number:04d}.alto.xml"
        if not path.exists():
            print(f"  {number}: no ALTO — SKIPPED")
            continue
        page = lx.read_alto(path)
        notes = lxnt.extract_notes(page)
        if notes is None:
            print(f"  {number}: no footnote divider — SKIPPED, replace this page")
            continue
        # THE SKIP TEST STAYS KEYED ON `offices`, WHATEVER IS BEING EMITTED.
        # The draw frame and the `replaced` column of gold_sample_pages.csv were
        # both defined against the presence of an offices section — scans 15-18
        # print no apparatus at all and were excluded from the frame on exactly
        # that test. Widening it to "any section" would quietly admit pages the
        # drawn sample excluded, and a sample that shifts under an instrument it
        # has already been drawn for cannot be reasoned about afterwards.
        if not [s for s in lxnt.section_segments(notes, page)
                if s.kind == "offices"]:
            print(f"  {number}: no offices section — SKIPPED, replace this page")
            continue

        image = lx.render_page(CZ_PDF, number, page.width)
        courts = _gather(number, page, notes, image, out_dir, enlarge, wanted,
                         roster, by_page_court)

        for _court, info in courts.items():
            got = sum(len(v) for v in info["images"].values())
            flagged = ("" if info["entries"]
                       else "   [!! no parseable key - keys damaged]")
            print(f"  {number} {info['district'][:22]:22s} "
                  f"{len(info['order']):3d} muni "
                  f"({len(info['on_page']):2d} on-page table, "
                  f"{len(info['filled_in']):2d} from span, "
                  f"{len(info['printed_keys']):2d} parsed)  -> "
                  f"{got} image(s){flagged}")

        if fmt == "ledger":
            keys, missing = _emit_ledger(number, courts, roster, heads, lines,
                                         index_rows)
        else:
            boxes = lxnt.notes_boxes(notes, page)
            right = page.print_left + (page.print_width or page.width)
            # THE TABLE IS NOT ENLARGED, AND THE APPARATUS IS. `ENLARGE` exists
            # for six-point type set under the rule; between the printed rules
            # the register sets a much larger face, which is why the ALTO reads
            # digits there at ~88% and reads almost nothing below. Doubling a
            # whole page costs 17 MB against 5 MB and buys resolution the eye
            # does not need. Cropped from y=0 so the COLUMN HEADINGS come with
            # it — without them a blank 17-column grid cannot be filled at all.
            table_image = _crop(image, (page.print_left, 0, right,
                                        notes.band_top),
                                out_dir, f"{number:04d}_table.png", 1)
            footer = boxes.get("footer")
            footer_image = ""
            # A footer box of a few pixels is a band with no print in it, not a
            # legend — `notes_boxes` bounds on the last printed LINE and falls
            # back to `notes.bottom` when it finds none.
            if footer and footer[3] > footer[1] + 4:
                # Same face as the table, so the same reasoning: not enlarged.
                footer_image = _crop(image, footer, out_dir,
                                     f"{number:04d}_legend.png", 1)
            keys, missing = _emit_md(
                number, courts, roster, heads, by_page_court, role,
                printed_pages.get(number, ""), table_image, footer_image,
                out_dir, index_rows)
        n_keys += keys
        n_missing += missing

    if fmt == "ledger":
        sheet.write_text("\n".join(lines) + "\n", encoding="utf-8")
    if not index_rows:
        print("\n  nothing emitted")
        return 1
    with (out_dir / "worksheet_keys.csv").open("w", encoding="utf-8",
                                               newline="") as fh:
        writer = csv.DictWriter(fh, fieldnames=list(index_rows[0]))
        writer.writeheader()
        writer.writerows(index_rows)

    print(f"\n  {n_keys} keys to read"
          + (f"  ({n_missing} printed in the apparatus but absent from the "
             f"table window)" if n_missing else ""))
    print(f"  sheets      {sheet if fmt == 'ledger' else str(out_dir) + '/<scan>.md'}")
    print(f"  key index   {out_dir / 'worksheet_keys.csv'}")
    print("  atlas       reference/places/symbols/atlas.png")
    return 0

def main() -> int:
    ap = argparse.ArgumentParser(
        description=__doc__,
        formatter_class=argparse.RawDescriptionHelpFormatter)
    ap.add_argument("--role", default="calibration",
                    choices=("calibration", "certification", "purposive"),
                    help="which half of the gold sample (default: calibration). "
                         "`purposive` is the four pages held OUTSIDE both halves")
    ap.add_argument("--pages", default="",
                    help="override the sample, e.g. 16,76")
    ap.add_argument("--out", default="", help="override the output directory")
    ap.add_argument("--enlarge", type=int, default=ENLARGE)
    # The same vocabulary run_lexikon_1910_pilot.py already uses for
    # --notes-sections, so the human sheet and the model pass are asked for the
    # same thing in the same words.
    ap.add_argument("--sections", default="all",
                    choices=("offices", "parts", "all"),
                    help="which apparatus sections to cut (default: all)")
    ap.add_argument("--format", dest="fmt", default="md",
                    choices=("md", "ledger"),
                    help="md: one whole-page Markdown sheet per scan (default). "
                         "ledger: the original fixed-width offices-only sheet")
    args = ap.parse_args()

    pages = ([int(p) for p in args.pages.split(",") if p.strip()]
             if args.pages else _pages_for_role(args.role))
    out_dir = Path(args.out) if args.out else OUT_ROOT / args.role
    print(f"role {args.role}   pages {', '.join(str(p) for p in pages)}")
    print(f"into {out_dir}\n")
    return build(pages, args.role, out_dir, args.enlarge,
                 args.fmt, args.sections)

"""Cut the gold-sample pages into a worksheet laid out the way the page reads.

Companion to :mod:`make_transcription_worksheet`, which built the first four pages
and is left alone — its output is hours of a person's attention and this writes
somewhere else entirely.

**The sheet is a named-part ledger.** One line per key, and every line carries
``obec › část``:

    18,1    Kbelnice, Kbelnitz    › Kbelnice, Kbelnitz    >
    18,2    Kbelnice, Kbelnitz    › Soudná, Soudna        >

The municipality used to live in a block heading and the part in the row, so a
transcriber twenty rows into Jičín's twenty-two municipalities had to scroll up to
find out which block they were in. Both names on every line removes that entirely,
and the redundancy is cheap: the names are pre-filled from the printed table and
nobody types a place name.

**Because the register itself addresses parts by name.** Inside one printed key it
prints a part's name and then that part's institutions, in order::

    17, —) Kartouzy: † 314 m, věznice pro muže s nemocenským odděl., ♀.
           Valdice:  ▤ III, ⚕, 🪜, ∾ (Kartouzy-Valdice), 🚂 301 m.
    18,  1) 🪜.
           Zebín: † 400 m.

``Zebín`` is the case that decides the design: it is printed, it has a church, and
the table gives it no number anywhere. A sheet keyed only on ``m,n`` has nowhere to
put it and the reading is lost. Hence the ``__,+`` escape, written once per section
as a blank template rather than as two dead rows on every municipality.

**And the number column fails in both documents at once.** The old rule dropped a
table block whose sequence number the OCR destroyed, on the reasoning that
``parse_entries`` would carry it instead and flag it ``!roster``. But the apparatus
keys are the *same* column one document lower, so when it goes, it goes in both.
Scan 0136 reads Jičín's municipalities 4, 6 and 9 as ``i``, ``<>`` and ``í)``; all
three are printed in the apparatus with symbols (``4, 1) ⚕, 🪜``) and all three had
no row on the sheet at all. :func:`_repair_run` reconstructs a number from reading
order where the arithmetic is unique — ``3, ?, 5`` can only be 4 — leaves it
unaddressed where it is not, and marks a number that parses but goes backwards
(``15, 10, 17``, the 16 read as a 10) as suspect rather than trusting it.

**A symbol can be attached to more than one part.** The register prints an
institution once and lets it serve several parts of the same municipality — the
cadastral community ``[cadastral] (3,5)`` is the visible case. A symbol may carry
``@`` and the parts it covers: ``[school] II @1+3``.

Why this matters more than it did: the analysis will use the register at
**settlement level**, and ``lexikon_1910_institutions._entry_key`` deliberately
pools a municipality's sub-entries because ``settlement_seq`` is a single character
in the most damaged column on the page. A person reading the print is the only
channel that can say whether that character is recoverable at all, and this sheet is
the instrument that asks.

def _read_window(numbers: list[int], template) -> tuple[dict, dict]:
    """Blocks by (page, court) in reading order, and the running head per page.

    The district labels carry across page boundaries — a page opening mid-okres
    prints no summary row of its own — so the window is walked in ascending order
    and the last-seen labels are handed forward, exactly as the pilot does it.

    The per-page grouping is what makes the sheet independent of the parser. The
    *Návod* is explicit that the three documents on a page belong together — the
    apparatus below the rule is keyed to the table above it — so the
    municipalities a page's offices section can possibly name are the
    municipalities that page's table prints.
    """
    by_page_court: dict[tuple, list] = {}
    heads: dict[str, str] = {}
    okres_label = court_label = ""
    for number in sorted(numbers):
        path = CZ_PAGES / f"{number:04d}.alto.xml"
        if not path.exists():
            continue
        try:
            page = lx.read_alto(path)
            rows = lx.extract_rows(page, template)
            blocks, _orphans = lx.segment_blocks(rows, okres_label, court_label)
        except Exception as exc:                        # noqa: BLE001
            print(f"    {number:04d}: table unreadable — {type(exc).__name__}")
            continue
        if blocks:
            okres_label = blocks[-1].okres_label
            court_label = blocks[-1].court_label
        heads[f"{number:04d}"] = lx.running_head(page)
        for block in blocks:
            key = lxnt.normalise(block.court_label)
            if key:
                by_page_court.setdefault(
                    (f"{number:04d}", key), []).append(block)
    return by_page_court, heads


def _repair_run(blocks: list) -> list[tuple]:
    """``[(muni_seq | None, status, block)]`` for one court's run on one page.

    **The number column and the apparatus fail together, so a block that loses its
    number has nothing to fall back on.** Scan 0136's table prints Jičín 3 to 24
    and the OCR reads municipalities 4, 6 and 9 as ``i``, ``<>`` and ``í)``. The
    old rule dropped them and relied on ``parse_entries`` to carry them instead —
    but the apparatus keys are the *same* damaged column one document lower, and
    it lost them too. All three are printed with symbols (``4, 1) [pharmacy],
    [fire-brigade]``) and all three had no row on the sheet at all.

    Reading order is the numbering. Municipality numbers run 1..n densely inside a
    soudní okres, so an unreadable number that sits between two legible ones is
    pinned by arithmetic rather than guessed: ``3, ?, 5`` can only be 4. The
    repair fires only where the arithmetic is **unique** — where the gap in the
    numbers equals the gap in the blocks — and anything else stays ``lost`` and is
    addressed by position rather than by number.

    A number that *parses* but goes backwards (``15, 10, 17`` — the 16 read as 10)
    is the third case, and it is worse than an unreadable one because it looks
    fine. It is marked ``suspect``, kept where it was printed, and never used to
    anchor a repair.

    **The anchors are the LONGEST consistent chain, not the first one greedily
    taken** — which is the fourth case, and the only one that made this function
    corrupt numbers it had read correctly. Scan 0451 reads Trutnov's last four
    municipalities as ``80, 31, 32, 33``: the truth is 30–33 (450 ends at 29) and
    the 3 came back as an 8. Taking the first legible number as an anchor made
    ``80`` the run, so ``31, 32, 33`` all "descended" and were discarded as
    suspect — and then the after-the-last-anchor pass **overwrote them with 81,
    82, 83**. One misread character silently rewrote three correct ones, and the
    result was internally consistent and entirely wrong. Choosing the chain that
    explains the most blocks picks 31–33 over 80 by three to one, and 30 falls out
    of the arithmetic. The old rule is the special case where the first legible
    number happens to sit in the longest chain, so the documented behaviour on
    scan 0136 (``3, ?, 5`` → 4) and on ``15, 10, 17`` is unchanged; a tie keeps
    the earliest chain, which is the old answer.

    Consistency has two halves, and the second is new. A chain may not descend —
    numbering does not run backwards — and it may not **skip**: the numbers
    between two anchors cannot outrun the blocks between them, because the run is
    dense. That is what catches scan 0449's ``…11, 12, 18`` for 13 blocks, where
    the 13 came back as an 18. It parses, it ascends, and only density says it
    cannot be right.
    """
    read: list = []
    for block in blocks:
        muni, status = lx.parse_int_cell(block.municipality.get("seq"))
        read.append([muni if status == "ok" else None, block])

    legible = [(index, muni) for index, (muni, _b) in enumerate(read)
               if muni is not None]

    def _compatible(earlier: tuple, later: tuple) -> bool:
        """Can both of these be true at once, in a dense ascending run?"""
        gap_blocks = later[0] - earlier[0]
        gap_numbers = later[1] - earlier[1]
        # Ascending, and never further than the blocks allow. `gap_numbers <
        # gap_blocks` is left legal: it means one municipality was segmented into
        # two blocks, which happens and is not the number's fault.
        return 1 <= gap_numbers <= gap_blocks

    # Longest chain of mutually compatible legible numbers. O(n^2) over the
    # municipalities of one court on one page — a couple of dozen at most.
    best: list[list[int]] = []
    for position in range(len(legible)):
        chain = [position]
        for earlier in range(position):
            if (len(best[earlier]) + 1 > len(chain)
                    and _compatible(legible[earlier], legible[position])):
                chain = best[earlier] + [position]
        best.append(chain)
    keep = set(max(best, key=len, default=[]))

    anchors: list[tuple] = []
    for position, (index, muni) in enumerate(legible):
        if position not in keep:
            read[index][0] = None                       # suspect: not an anchor
            read[index].append("suspect")
            continue
        anchors.append((index, muni))

    out: list[tuple] = []
    status_by_index: dict[int, str] = {}
    for position, (index, muni) in enumerate(anchors):
        status_by_index[index] = "ok"
        previous = anchors[position - 1] if position else None
        if previous is None:                            # run before the first anchor
            for back in range(1, index + 1):
                if muni - back >= 1:
                    read[index - back][0] = muni - back
                    status_by_index[index - back] = "reconstructed"
        else:
            gap_blocks = index - previous[0]
            gap_numbers = muni - previous[1]
            if gap_blocks == gap_numbers:               # unique reconstruction
                for step in range(1, gap_blocks):
                    read[previous[0] + step][0] = previous[1] + step
                    status_by_index[previous[0] + step] = "reconstructed"
    if anchors:                                         # run after the last anchor
        index, muni = anchors[-1]
        for forward in range(1, len(read) - index):
            read[index + forward][0] = muni + forward
            status_by_index[index + forward] = "reconstructed"

    for index, entry in enumerate(read):
        muni, block = entry[0], entry[1]
        suspect = len(entry) > 2
        status = status_by_index.get(index, "suspect" if suspect else "lost")
        out.append((muni, status, block))
    return out


def _roster(by_page_court: dict) -> dict:
    """``court -> muni_seq -> [(settlement_seq, printed name)]``, from the table.

    The municipality's own line is ``"0"``. Settlement numbers are read where
    legible and otherwise fall back to printed order, which for settlements *is*
    the numbering — they run 1..n with no gaps inside a municipality.

    Built from the per-page runs rather than the pooled court list, because
    :func:`_repair_run` needs reading order on one page to reconstruct a number,
    and pooling a whole twelve-page window destroys exactly that.
    """
    out: dict = {}
    for (_page, court), blocks in sorted(by_page_court.items()):
        for muni, status, block in _repair_run(blocks):
            if muni is None or status == "lost":
                continue
            rows = out.setdefault(court, {}).setdefault(muni, [])
            if rows:                                    # a block already claimed it
                continue
            rows.append(("0", _name(block.municipality)))
            # POSITION BEATS THE PRINTED FIGURE FOR A PART, and only for a part.
            # Parts run 1..n densely inside a municipality — the module's own
            # stated fact — so printed order *is* the numbering and it does not
            # depend on the single most damaged character on the page. Trusting
            # the OCR where it "parsed" put Tíhotka at `2,9` under Hodkovičky,
            # a number that municipality does not have. Where the two disagree
            # the row is flagged `!seq` so the figure gets a second look; it is
            # never silently preferred.
            for position, row in enumerate(block.settlements, start=1):
                seq, seq_status = lx.parse_int_cell(row.get("seq"))
                name = _name(row)
                if seq_status == "ok" and seq != position:
                    name = f"{name}  !seq({seq})"
                rows.append((str(position), name))
    return out


def _munis_on_page(blocks: list) -> dict:
    """``muni_seq -> how its number was obtained``, for one court on one page."""
    return {muni: status for muni, status, _block in _repair_run(blocks)
            if muni is not None and status != "lost"}


def _name(row) -> str:
    """The printed name, German twin kept — it is what the eye matches on."""
    # Not truncated tightly. The tail of a name is where the register puts the
    # linkage — `Červená, Čerwena 2. odd. (viz 14 a Písek 23)` says this
    # settlement is divided between three municipalities in two courts, and a
    # 44-character cut removed exactly that.
    #
    # `>` is stripped because it is this sheet's answer marker and the OCR emits
    # it inside names (`Pekelec, Pekeletz >-`). One such name was enough to make
    # the overwrite guard below read an untouched sheet as a filled one; no Czech
    # or German place name contains the character, so dropping it costs nothing
    # and removes the ambiguity for good.
    return " ".join((row.get("name") or "").replace(">", "").split())[:64]


def _strip_heading(segment) -> list[str]:
    """The segment's lines with its heading removed, as the parser expects."""
    out: list[str] = []
    for line in segment.lines:
        heading = lxnt.find_heading(line)
        tail = line[heading[2]:] if heading else line
        if tail.strip():
            out.append(tail)
    return out

#: How close a damaged heading has to be to a court the table actually prints
#: before the two are taken to name the same okres.
#:
#: **0.85, and the number is read off the two cases rather than chosen.** The
#: defect to repair is a single substituted character in a printed heading:
#: `mechanice`/`nechanice` scores **0.889** on `difflib`'s ratio. The nearest
#: thing that must NOT be repaired is a different okres with a similar name:
#: `nemcice`/`nechanice` — Němčice and Nechanice are 90 km apart — scores
#: **0.750**. A cutoff of 0.75 sits exactly on that second value and would have
#: merged them; 0.85 sits in the gap. Two corrupted characters in a nine-letter
#: name fall below it and stay refused, which is the safe direction: an
#: unrepaired heading shows up as `[not in the table window]` rows, a wrongly
#: repaired one silently files a district's institutions under its neighbour.
_COURT_CUTOFF = 0.85


def _court_resolver(number: int, by_page_court: dict):
    """Map an apparatus heading's key onto a court the TABLE prints, or keep it.

    The heading and the table name the same okres twice, in two faces, and the
    sheet joined them by requiring the two OCR readings to be **byte-identical**.
    One character defeats that. Scan 0106's heading came back `Mechanice` against
    the table's `Nechanice` and all 46 of its keys were stranded with no name and
    no row to check against; scan 0286's *parts* heading came back
    `Nová Рака` — in Cyrillic — and `lexikon_1910_notes.normalise` keeps only
    ``[a-z]``, so the Cyrillic was **deleted** rather than transliterated and the
    key collapsed to `nova` while the offices heading gave `novaraka`. One
    district became two courts and the parts half got no table rows at all.

    That truncation is the more dangerous half: `nova` is a live prefix of every
    `Nová …` okres in the volume, so the failure mode is not only a miss but a
    collision. Measured before this: certification carried **19.4 %** of its keys
    with no table row against calibration's 2.2 %, which would have made the
    sealed half a materially worse instrument than the half the thresholds are
    set on.

    Candidates are the courts whose table blocks sit on this page or the one
    either side — the apparatus belongs to the table above it, and widening the
    net past that is how a heading gets matched to an okres forty pages away.
    **A tie is refused**, the same rule the place matcher follows (D-22, D-23):
    the key is left as printed and the block keeps its `[not in the table
    window]` rows, which is the honest outcome and the one that shows.
    """
    candidates = sorted({court for (page_id, court) in by_page_court
                         if abs(int(page_id) - number) <= 1 and court})

    def resolve(key: str) -> str:
        if not key or key in candidates:
            return key
        # A key the OCR truncated is a prefix of the real one, not a near-miss of
        # it, and edit-distance ratio punishes a short string for being short.
        # **Either side can be the truncated one**, because both are OCR of the
        # same printed words in two different faces. Scan 0286 has it in both
        # directions at once: the table label came back `nova` and the offices
        # heading `novaraka`, and it is the *heading* that read Nová Paka better.
        # Matching only heading-is-truncated would have left the offices half
        # orphaned while the parts half joined, which is how one district became
        # two courts on the sheet.
        prefixed = [c for c in candidates
                    if (c.startswith(key) and len(key) >= 4)
                    or (key.startswith(c) and len(c) >= 4)]
        import difflib
        if len(prefixed) == 1:
            # A shared prefix is weak evidence on its own — `nova` is a prefix of
            # every `Nová …` okres in the volume — so it only settles the match
            # when nothing else on the page reads closer. Without this, a table
            # label truncated to `nova` beside a heading reading `novaraka` would
            # capture a neighbouring `Nová Ves` and file one district's
            # institutions under another, which is the failure the cutoff below
            # exists to prevent.
            best = max(candidates,
                       key=lambda c: difflib.SequenceMatcher(None, key, c).ratio())
            if best == prefixed[0] or best in prefixed:
                return prefixed[0]
            return key
        if prefixed:
            return key                                  # ambiguous — refuse
        close = difflib.get_close_matches(key, candidates, n=2,
                                          cutoff=_COURT_CUTOFF)
        if len(close) == 1:
            return close[0]
        if len(close) > 1:
            first = difflib.SequenceMatcher(None, key, close[0]).ratio()
            second = difflib.SequenceMatcher(None, key, close[1]).ratio()
            if first > second:                          # a clear best, not a tie
                return close[0]
        return key

    return resolve


def _gather(number: int, page, notes, image, out_dir: Path, enlarge: int,
            wanted: tuple, roster: dict, by_page_court: dict) -> dict:
    """Cut this page's crops and return ``court -> info``, in reading order.

    ONE ROSTER PER (PAGE, COURT), NOT PER IMAGE. A section is a text flow that
    straddles the column divider, so an image is one *column* of it — emitting
    the municipality list under each column printed all eighteen of Jičín's
    municipalities twice and left the transcriber to work out which image a key
    was supposed to be on. It is one list, read across however many images the
    section occupies — and now across however many *documents* as well, because
    the parts section and the offices section of one court share a key space and
    therefore have to share a roster.
    """
    courts: dict[str, dict] = {}
    resolve = _court_resolver(number, by_page_court)
    for segment in lxnt.section_segments(notes, page):
        if segment.kind not in wanted:
            continue
        segment_key = resolve(segment.key)
        # The kind goes in the filename. Two documents are cropped now and
        # `order` alone does not say which is which, so a crop that lands in the
        # wrong section of the sheet would be invisible in the filename.
        name = _crop(image, segment.box, out_dir,
                     f"{number:04d}_{segment_key or 'unknown'}_"
                     f"{segment.kind}_{segment.order}.png", enlarge)
        entries = lxin.parse_entries(
            lxnt.Section(kind=segment.kind, district=segment.district,
                         page=segment.page, lines=_strip_heading(segment)))
        info = courts.setdefault(segment_key, {
            "district": segment.district, "images": {}, "text": [],
            "printed_keys": {}, "entries": 0})
        # Two sections resolved to one court print the district name twice, and
        # the first one to arrive is not necessarily the legible one. On scan
        # 0286 the parts heading reads `Nová Рака` — Cyrillic Р, а, к — and the
        # offices heading reads `Nová Raka`; the transcriber sees this string at
        # the top of the block, so take whichever reading kept more Latin letters.
        if (sum(c.isascii() and c.isalpha() for c in segment.district)
                > sum(c.isascii() and c.isalpha() for c in info["district"])):
            info["district"] = segment.district
        info["images"].setdefault(segment.kind, []).append(name)
        # The parsed-key hint stays an OFFICES fact. The parts section keys the
        # same municipalities but says nothing about which of them printed an
        # institution, and pooling the two would inflate a hint the transcriber
        # is told to distrust into one they might believe.
        if segment.kind == "offices":
            info["text"] += _strip_heading(segment)
            info["entries"] += len(entries)
            for entry in entries:
                info["printed_keys"].setdefault(entry.muni_seq, set()).add(
                    entry.settlement_seq or "0")

    for court, info in courts.items():
        # THE LIST COMES FROM THE TABLE, NOT FROM THE PARSER. Page 0316's offices
        # section has every municipality number destroyed by the OCR (`t- - 2)`,
        # `- 6)`), so `parse_entries` returns nothing and a parser-driven sheet
        # would have printed an empty page for it — the transcriber bounded by
        # the channel they are meant to grade.
        #
        # BUT THE TABLE ON THE PAGE IS NOT THE APPARATUS ON THE PAGE. The
        # register runs straight on, so a page's apparatus routinely covers
        # municipalities whose table rows are printed one scan back. Scan 0136's
        # apparatus prints keys 3 to 24 of okres Jičín; that scan's own table
        # starts at 3 but skips 4, 6, 9 and 16, and all four are printed WITH
        # symbols. Under a per-page roster they had no row at all.
        on_page = _munis_on_page(
            by_page_court.get((f"{number:04d}", court), []))
        seen = set(on_page) | set(info["printed_keys"])
        in_span: set = set()
        continues = None
        if seen:
            low, high = min(seen), max(seen)
            in_span = {m for m in roster.get(court, {}) if low <= m <= high}
            # A SECTION WHOSE KEYS ALL DIED MAY HAVE STARTED ON THE PREVIOUS
            # PAGE, and the span above cannot reach back for it because the span
            # is bounded below by this page's first municipality.
            #
            # Scan 0451 is the case. Its Trutnov apparatus is the tail of the
            # okresní seat's entry — `o. hjtm.`, `o. s.`, `notář`, `8 adv.`,
            # unmistakably municipality 29, whose table row is on scan 0450 —
            # and its one printed key came back as `2«, 3)`. The sheet offered
            # 30 to 33, so every symbol the district capital prints had nowhere
            # to go and would have been recorded against Vlčice or dropped.
            #
            # The inference is structural, not about content: the register runs
            # straight on, so a section that opens mid-entry belongs to the
            # municipality before it. It fires ONLY where the apparatus gives no
            # evidence of its own about where it starts — one parsed key, however
            # low, settles the question and this stays out of the way. The extra
            # municipality is marked `[continues from the previous page]` on the
            # sheet, so the transcriber deletes it if the image disagrees.
            if not info["entries"] and low - 1 in roster.get(court, {}):
                continues = low - 1
                in_span.add(continues)
        info["order"] = sorted(seen | in_span)
        info["on_page"] = on_page
        info["filled_in"] = sorted(in_span - seen)
        info["continues"] = continues
    return courts


def _key_rows(court: str, info: dict, roster: dict) -> list[tuple]:
    """``(muni, title, known, printed, rows)`` for one court, in reading order.

    Shared by the offices block and the parts block, because the register keys
    both documents the same way — ``municipality, part)``, with a dash for the
    municipality taken as a whole. Building the rows twice from two code paths is
    how the two blocks would drift apart on the pages where the roster had to be
    repaired, which are precisely the pages where drift would matter.
    """
    out: list[tuple] = []
    for muni in info["order"]:
        known = roster.get(court, {}).get(muni, [])
        known_seqs = [s for s, _n in known]
        title = _muni_title(known, muni)
        printed = sorted(info["printed_keys"].get(muni, set()),
                         key=lambda s: (s != "0", s))
        seqs = list(dict.fromkeys(
            known_seqs + sorted(set(printed) - set(known_seqs))))
        if "0" not in seqs:
            seqs.insert(0, "0")
        rows = []
        for seq in seqs:
            part = (PART_WHOLE if seq == "0"
                    else next((n for s, n in known if s == seq), ""))
            rows.append((muni, seq, title, part,
                         "" if seq in known_seqs else "!roster"))
        # `?` ONLY WHERE A PART FIGURE EXISTS TO BE UNREADABLE — that is, where
        # the table gives this municipality numbered parts. On an undivided obec
        # the register prints `m, —)` and there is no figure to fail, so the row
        # would collect nothing and a blank in it would mean two different things.
        if len(seqs) > 1:
            rows.append((muni, PART_UNREADABLE_KEY, title, PART_UNREADABLE, ""))
        out.append((muni, title, known, printed, rows))
    return out


def _index_row(number: int, court: str, kind: str, muni: int, seq: str,
               title: str, part: str, flag: str, printed: list, image: str):
    return {
        "page": f"{number:04d}", "district": court, "section_kind": kind,
        "muni_seq": muni, "settlement_seq": seq,
        "municipality_name": title,
        "place_name": "" if seq == "0" else part,
        "key_kind": "municipality" if seq == "0" else "part",
        "in_table": "" if flag else "yes",
        "printed_in_offices": "yes" if seq in printed else "",
        "image": image,
    }


def _hint_block(info: dict) -> list[str]:
    """The text layer's own read of the offices section, marked as orientation."""
    parsed = " ".join(
        f"{m},{'—' if s == '0' else s}"
        for m in sorted(info["printed_keys"])
        for s in sorted(info["printed_keys"][m], key=lambda x: (x != "0", x)))
    none = "(none — the number column is destroyed on this page)"
    return [
        "#   the text layer's own read of this section, for ORIENTATION ONLY - "
        "it is\n#   garbage where the symbols are, and copying from it defeats "
        "the point:",
        *[f"#     {line[:150]}" for line in info["text"][:14]],
        f"#\n#   keys the text layer parsed here: {parsed or none}\n"
        f"#   That is a HINT and a floor. It undercounts badly and it is silent "
        f"about the\n#   rest; the image decides which keys are printed.",
    ]


def _emit_ledger(number: int, courts: dict, roster: dict, heads: dict,
                 lines: list, index_rows: list) -> tuple[int, int]:
    """The original fixed-width ledger, unchanged in shape."""
    n_keys = n_missing = 0
    lines.append(f"\n\n# ==== page {number:04d} "
                 f"{'=' * 54}\n# running head: {heads.get(f'{number:04d}', '')}")
    for court, info in courts.items():
        name = "; ".join(sum(info["images"].values(), []))
        lines.append(f"\n#   soudní okres {info['district']}   "
                     f"({len(info['order'])} municipalities)"
                     f"\n#   image(s), in reading order: {name}")
        lines += _hint_block(info)
        lines.append(ESCAPE_BLOCK.format(sep=PART_SEP).rstrip("\n"))

        for muni, title, known, printed, rows in _key_rows(court, info, roster):
            lines.append(f"\n== {muni}  {title}"
                         + ("" if known else "   [not in the table window]")
                         + _continues(info, muni)
                         + _apparatus_note(printed, muni))
            for _m, seq, _t, part, flag in rows:
                lines.append(_row(muni, seq, title, part, flag))
                if seq == PART_UNREADABLE_KEY:
                    continue
                n_keys += 1
                n_missing += 1 if flag else 0
                index_rows.append(_index_row(number, court, "offices", muni,
                                             seq, title, part, flag, printed,
                                             name))
    return n_keys, n_missing


def _table_row_count(number: int, court: str, by_page_court: dict) -> int:
    """How many blank table rows this court prints on this scan.

    A municipality row plus its settlement rows, counted off the blocks the table
    itself yielded — so the sheet has the right number of rows to fill without
    saying anything about what is in any of them.
    """
    blocks = by_page_court.get((f"{number:04d}", court), [])
    return sum(1 + len(block.settlements) for block in blocks)


def _emit_md(number: int, courts: dict, roster: dict, heads: dict,
             by_page_court: dict, role: str, printed_page: str,
             table_image: str, footer_image: str, out_dir: Path,
             index_rows: list) -> tuple[int, int]:
    """One Markdown file per scan: four sections, every data cell blank."""
    n_keys = n_missing = 0
    images = [f"  table: {table_image}\n"]
    for kind in ("parts", "offices"):
        got = [n for info in courts.values() for n in info["images"].get(kind, [])]
        images.append(f"  {kind}: [{', '.join(got)}]\n")
    images.append(f"  legend: {footer_image or '~'}\n")

    out = [MD_HEADER.format(
        scan=f"{number:04d}", printed_page=printed_page, role=role,
        districts=", ".join(sorted(info["district"] for info in courts.values())),
        images="".join(images))]
    out.append(f"\n<!-- running head: {heads.get(f'{number:04d}', '')} -->\n")

    # ---- 1. the table
    out.append(f"\n# 1 — Tabelární část\n\nimage: `{table_image}`\n")
    header = "| r | " + " | ".join(TABLE_COLS) + " |"
    rule = "|---" * (len(TABLE_COLS) + 1) + "|"
    for court, info in courts.items():
        count = _table_row_count(number, court, by_page_court)
        out.append(f"\n## 1 — soudní okres {info['district']}\n")
        if not count:
            out.append("\n_No table rows for this court on this scan: its "
                       "apparatus is keyed to a table printed earlier. Add rows "
                       "if the print says otherwise._\n")
            continue
        out.append("\n" + header + "\n" + rule + "\n")
        for i in range(1, count + 1):
            out.append(f"| r{i} |" + " |" * len(TABLE_COLS) + "\n")

    # ---- 2. the two-column apparatus
    out.append("\n\n# 2 — Dvousloupcová část\n")
    for label, kind in (("2a", "parts"), ("2b", "offices")):
        for court, info in courts.items():
            got = info["images"].get(kind, [])
            heading = ("Části osad" if kind == "parts"
                       else "Úřady, ústavy a t. d.")
            out.append(f"\n## {label} — {heading} v soudním okresu "
                       f"{info['district']}\n")
            if not got:
                out.append(f"\n_No {kind} section printed for this court on this "
                           f"scan._\n")
                continue
            out.append(f"\nimage(s), in reading order: "
                       f"{', '.join('`' + n + '`' for n in got)}\n")
            if kind == "parts":
                out.append("\n" + PARTS_NOTE.rstrip("\n") + "\n")
            else:
                out.append("\n<!--\n" + "\n".join(_hint_block(info)) + "\n-->\n")
            out.append("\n```ledger\n")
            out.append(ESCAPE_BLOCK.format(sep=PART_SEP).strip("\n") + "\n")
            for muni, title, known, printed, rows in _key_rows(court, info,
                                                               roster):
                out.append(f"\n== {muni}  {title}"
                           + ("" if known else "   [not in the table window]")
                           + _continues(info, muni)
                           + (_apparatus_note(printed, muni)
                              if kind == "offices" else "") + "\n")
                for _m, seq, _t, part, flag in rows:
                    out.append(_row(muni, seq, title, part, flag) + "\n")
                    if seq == PART_UNREADABLE_KEY:
                        continue
                    n_keys += 1
                    n_missing += 1 if flag else 0
                    index_rows.append(_index_row(
                        number, court, kind, muni, seq, title, part, flag,
                        printed, "; ".join(got)))
            out.append("```\n")

    # ---- 3. the legend below the rule
    out.append("\n\n# 3 — Jednosloupcová část pod čarou\n")
    out.append(f"\nimage: `{footer_image or '(no footer band on this scan)'}`\n")
    out.append(LEGEND_NOTE)
    for _court, info in courts.items():
        out.append(f"\n## 3 — s. o. {info['district']}\n\n```legend\n\n```\n")

    # ---- 4. the asterisk notes
    out.append("\n\n# 4 — Poznámky pod čarou\n")
    out.append(FOOTNOTE_NOTE)

    (out_dir / f"{number:04d}.md").write_text("".join(out), encoding="utf-8")
    return n_keys, n_missing


#: A filled-in table row, as against the header row that also opens ``| r |``.
_TABLE_ROW_RE = re.compile(r"^\|\s*r\d+\s*\|")


def _filled(path: Path) -> int:
    """How many answers a sheet already holds, in either format.

    A gold worksheet is the one artefact in this project that cannot be
    regenerated: the pages are a probability sample and the reading is hours of
    attention. The generator refuses rather than backs up — a backup nobody
    notices is how the work gets done twice.
    """
    filled = 0
    for line in path.read_text(encoding="utf-8").splitlines():
        stripped = line.strip()
        if _TABLE_ROW_RE.match(stripped):
            # `r1`, `r2` … is the pre-filled POSITION key and is not an answer,
            # so column 1 is skipped. The row key has to carry a NUMBER: the
            # header row also opens `| r |`, and its cells are the seventeen
            # column names, which the guard read as seventeen answers and used
            # to refuse every freshly generated sheet.
            filled += sum(1 for cell in stripped.split("|")[2:-1] if cell.strip())
        elif PART_SEP in line and ">" in line:
            # AN ANSWER LINE IS `obec › část … >`, NOT MERELY A LINE WITH A `>`.
            # The looser test read the instructions as work: the Markdown sheet
            # carries prose, HTML comments and a `name <symbol> houses—population`
            # example, and every one of those put text after a `>` and made the
            # guard refuse to rebuild a sheet nobody had touched. `›` appears
            # only in a generated ledger row — no Czech or German place name
            # contains it, which is why it was chosen as the separator.
            filled += 1 if line.rsplit(">", 1)[1].strip() else 0
    return filled


def build(pages: list[int], role: str, out_dir: Path, enlarge: int,
          fmt: str = "md", sections: str = "all") -> int:
    out_dir.mkdir(parents=True, exist_ok=True)
    wanted = (("parts", "offices") if sections == "all" else (sections,))
    sheet = out_dir / "worksheet.txt"

    existing = ([sheet] if fmt == "ledger" and sheet.exists()
                else sorted(out_dir.glob("[0-9][0-9][0-9][0-9].md")))
    for path in existing:
        filled = _filled(path)
        if filled:
            print(f"!! {path} already has {filled} filled cells. Refusing to "
                  f"overwrite.\n   Move it aside first if you really mean to "
                  f"rebuild.")
            return 1

    window = sorted({p + d for p in pages
                     for d in range(-WINDOW_BACK, WINDOW_FORWARD + 1)
                     if 15 <= p + d <= 494})
    paths = [CZ_PAGES / f"{n:04d}.alto.xml" for n in window]
    print(f"grid + table over {len(window)} pages "
          f"({window[0]}-{window[-1]}) ...")
    template = _grid_template([p for p in paths if p.exists()])
    by_page_court, heads = _read_window(window, template)
    roster = _roster(by_page_court)
    print(f"  {sum(len(v) for v in by_page_court.values())} table blocks, "
          f"{len(roster)} court(s)")

    printed_pages = _printed_pages()
    lines = [HEADER.format(role=role,
                           pages=",".join(str(p) for p in pages))]
    index_rows: list[dict] = []
    n_keys = n_missing = 0

    for number in pages:
        path = CZ_PAGES / f"{number:04d}.alto.xml"
        if not path.exists():
            print(f"  {number}: no ALTO — SKIPPED")
            continue
        page = lx.read_alto(path)
        notes = lxnt.extract_notes(page)
        if notes is None:
            print(f"  {number}: no footnote divider — SKIPPED, replace this page")
            continue
        # THE SKIP TEST STAYS KEYED ON `offices`, WHATEVER IS BEING EMITTED.
        # The draw frame and the `replaced` column of gold_sample_pages.csv were
        # both defined against the presence of an offices section — scans 15-18
        # print no apparatus at all and were excluded from the frame on exactly
        # that test. Widening it to "any section" would quietly admit pages the
        # drawn sample excluded, and a sample that shifts under an instrument it
        # has already been drawn for cannot be reasoned about afterwards.
        if not [s for s in lxnt.section_segments(notes, page)
                if s.kind == "offices"]:
            print(f"  {number}: no offices section — SKIPPED, replace this page")
            continue

        image = lx.render_page(CZ_PDF, number, page.width)
        courts = _gather(number, page, notes, image, out_dir, enlarge, wanted,
                         roster, by_page_court)

        for _court, info in courts.items():
            got = sum(len(v) for v in info["images"].values())
            flagged = ("" if info["entries"]
                       else "   [!! no parseable key - keys damaged]")
            print(f"  {number} {info['district'][:22]:22s} "
                  f"{len(info['order']):3d} muni "
                  f"({len(info['on_page']):2d} on-page table, "
                  f"{len(info['filled_in']):2d} from span, "
                  f"{len(info['printed_keys']):2d} parsed)  -> "
                  f"{got} image(s){flagged}")

        if fmt == "ledger":
            keys, missing = _emit_ledger(number, courts, roster, heads, lines,
                                         index_rows)
        else:
            boxes = lxnt.notes_boxes(notes, page)
            right = page.print_left + (page.print_width or page.width)
            # THE TABLE IS NOT ENLARGED, AND THE APPARATUS IS. `ENLARGE` exists
            # for six-point type set under the rule; between the printed rules
            # the register sets a much larger face, which is why the ALTO reads
            # digits there at ~88% and reads almost nothing below. Doubling a
            # whole page costs 17 MB against 5 MB and buys resolution the eye
            # does not need. Cropped from y=0 so the COLUMN HEADINGS come with
            # it — without them a blank 17-column grid cannot be filled at all.
            table_image = _crop(image, (page.print_left, 0, right,
                                        notes.band_top),
                                out_dir, f"{number:04d}_table.png", 1)
            footer = boxes.get("footer")
            footer_image = ""
            # A footer box of a few pixels is a band with no print in it, not a
            # legend — `notes_boxes` bounds on the last printed LINE and falls
            # back to `notes.bottom` when it finds none.
            if footer and footer[3] > footer[1] + 4:
                # Same face as the table, so the same reasoning: not enlarged.
                footer_image = _crop(image, footer, out_dir,
                                     f"{number:04d}_legend.png", 1)
            keys, missing = _emit_md(
                number, courts, roster, heads, by_page_court, role,
                printed_pages.get(number, ""), table_image, footer_image,
                out_dir, index_rows)
        n_keys += keys
        n_missing += missing

    if fmt == "ledger":
        sheet.write_text("\n".join(lines) + "\n", encoding="utf-8")
    if not index_rows:
        print("\n  nothing emitted")
        return 1
    with (out_dir / "worksheet_keys.csv").open("w", encoding="utf-8",
                                               newline="") as fh:
        writer = csv.DictWriter(fh, fieldnames=list(index_rows[0]))
        writer.writeheader()
        writer.writerows(index_rows)

    print(f"\n  {n_keys} keys to read"
          + (f"  ({n_missing} printed in the apparatus but absent from the "
             f"table window)" if n_missing else ""))
    print(f"  sheets      {sheet if fmt == 'ledger' else str(out_dir) + '/<scan>.md'}")
    print(f"  key index   {out_dir / 'worksheet_keys.csv'}")
    print("  atlas       reference/places/symbols/atlas.png")
    return 0


def _printed_pages() -> dict[int, str]:
    """``scan -> printed page``, from the drawn sample; empty if it is absent."""
    if not SAMPLE_CSV.exists():
        return {}
    with SAMPLE_CSV.open(encoding="utf-8", newline="") as fh:
        return {int(r["scan"]): r.get("printed_page", "")
                for r in csv.DictReader(fh)}


def _pages_for_role(role: str) -> list[int]:
    if not SAMPLE_CSV.exists():
        raise SystemExit(f"no {SAMPLE_CSV} — run draw_gold_sample.py first")
    with SAMPLE_CSV.open(encoding="utf-8", newline="") as fh:
        return [int(r["scan"]) for r in csv.DictReader(fh)
                if r["role"] == role]


def main() -> int:
    ap = argparse.ArgumentParser(
        description=__doc__,
        formatter_class=argparse.RawDescriptionHelpFormatter)
    ap.add_argument("--role", default="calibration",
                    choices=("calibration", "certification", "purposive"),
                    help="which half of the gold sample (default: calibration). "
                         "`purposive` is the four pages held OUTSIDE both halves")
    ap.add_argument("--pages", default="",
                    help="override the sample, e.g. 16,76")
    ap.add_argument("--out", default="", help="override the output directory")
    ap.add_argument("--enlarge", type=int, default=ENLARGE)
    # The same vocabulary run_lexikon_1910_pilot.py already uses for
    # --notes-sections, so the human sheet and the model pass are asked for the
    # same thing in the same words.
    ap.add_argument("--sections", default="all",
                    choices=("offices", "parts", "all"),
                    help="which apparatus sections to cut (default: all)")
    ap.add_argument("--format", dest="fmt", default="md",
                    choices=("md", "ledger"),
                    help="md: one whole-page Markdown sheet per scan (default). "
                         "ledger: the original fixed-width offices-only sheet")
    args = ap.parse_args()

    pages = ([int(p) for p in args.pages.split(",") if p.strip()]
             if args.pages else _pages_for_role(args.role))
    out_dir = Path(args.out) if args.out else OUT_ROOT / args.role
    print(f"role {args.role}   pages {', '.join(str(p) for p in pages)}")
    print(f"into {out_dir}\n")
    return build(pages, args.role, out_dir, args.enlarge,
                 args.fmt, args.sections)
