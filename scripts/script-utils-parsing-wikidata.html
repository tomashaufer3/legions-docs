TL;DR

Fetches Czech settlements (obec Q5153359 + část obce Q15978299) with coordinates, Czech + German labels, and their modern okres (P131) from the Wikidata Query Service, then attaches lat/lon/QID to the utils.parsing.lexikon settlement crosswalk and to individual birth records. Enables point-level mapping and Kelly-2019 spatial standard errors.

How it works

The SPARQL result is cached to disk (data/raw/wikidata/…) so the pipeline is reproducible without re-querying every run; delete the cache (or pass refresh=True) to re-fetch.

Matching

Wikidata is queried CZ-only (the class instances are Czech settlements), so the cross-empire German-name collision (Trautenau → Trutnowo) cannot occur here. Homonyms are disambiguated by modern okres: the lexikon okres_all timeline ends at the present-day okres, matched to Wikidata's P131 okres. Records are disambiguated by their already-resolved birth_okres_id (exact), falling back to a unique-name match.

Coverage note: Wikidata carries coordinates for ~6.3k current municipalities (+~0.6k parts), so settlement coverage of the ~18k historical lexikon entries is ~40%, and birth-coordinate coverage is ~40–50% of records (births cluster in municipalities). Okres-level analysis does not need these.

Usage

from utils.parsing import wikidata as wd
points = wd.fetch_cz_settlements(CACHE)              # SPARQL (or load cache)
settlements = wd.add_settlement_coords(settlements, points)
legion = wd.add_birth_coords(legion, settlements)

def fetch_cz_settlements(cache_path, refresh: bool = False) -> pd.DataFrame:
    """Return Wikidata Czech settlements (``qid, cs, de, lat, lon, okres_modern, wd_class``).

    Loads *cache_path* if present (unless ``refresh``); otherwise queries the Wikidata Query
    Service per class, keeps only rows whose P131 is an ``okres …`` (drops the ORP duplicates),
    dedupes per QID, and writes the cache.
    """
    cache_path = Path(cache_path)
    if cache_path.exists() and not refresh:
        return pd.read_csv(cache_path)

    rows = []
    for class_qid, tag in _CLASSES.items():
        for _try in range(3):
            try:
                bindings = _query_class(class_qid)
                break
            except Exception:                       # noqa: BLE001 — transient WDQS timeout
                time.sleep(5)
        else:
            bindings = []
        for x in bindings:
            okres = x.get("okresLabel", {}).get("value", "")
            if not okres.startswith("okres "):      # keep the okres P131, drop ORP / others
                continue
            lat, lon = _wkt_lonlat(x["coord"]["value"])
            rows.append({"qid": x["item"]["value"].rsplit("/", 1)[-1],
                         "cs": x["csLabel"]["value"],
                         "de": x.get("de", {}).get("value", ""),
                         "lat": lat, "lon": lon,
                         "okres_modern": okres[len("okres "):], "wd_class": tag})
    out = pd.DataFrame(rows).drop_duplicates("qid").reset_index(drop=True)
    cache_path.parent.mkdir(parents=True, exist_ok=True)
    out.to_csv(cache_path, index=False, encoding="utf-8")
    return out

def add_settlement_coords(settlements: pd.DataFrame, points: pd.DataFrame) -> pd.DataFrame

Attach wd_qid / lat / lon to the lexikon settlement crosswalk.

Match on Czech name, then corroborate: the candidate's Wikidata (modern) okres must equal the settlement's own modern okres — the last entry of its okres_all timeline.

The bare unique-name fallback this replaced ("only one Wikidata point carries this name, so take it") was the single largest source of bad geography in the build: Wikidata lists ~6.2k present-day municipalities, whereas the lexikon holds ~18k historical settlements incl. osady and absorbed hamlets, so 2,250 lexikon names are shared by several settlements while only one survives as a modern obec. Every one of those same-named settlements silently inherited that single obec's coordinates — landing a median 75 km from its own okres. Measured (audit 2026-07-16): coordinates that pass the okres corroboration land inside their name-based okres 87.4 % of the time; those taken by the old fallback, only 30.8 %.

A name that is unambiguous on both sides (one lexikon settlement, one Wikidata point) is still accepted without the okres check — there is no other settlement it could be, and this is what keeps coverage up where it is safe. Everything else is left blank: wrong coordinates scatter people across the country and would silently corrupt any spatial analysis (Kelly-2019 SEs, point maps), whereas missing coordinates merely reduce n.

_CURATED_COORDS is consulted first, for the handful of settlements the SPARQL result cannot contain at all (Praha, and the towns partitioned away or merged since 1910).

def add_settlement_coords(settlements: pd.DataFrame, points: pd.DataFrame) -> pd.DataFrame:
    """Attach ``wd_qid`` / ``lat`` / ``lon`` to the lexikon settlement crosswalk.

    Match on Czech name, then **corroborate**: the candidate's Wikidata (modern) okres must
    equal the settlement's own modern okres — the last entry of its ``okres_all`` timeline.

    The bare unique-name fallback this replaced (*"only one Wikidata point carries this name,
    so take it"*) was the single largest source of bad geography in the build: Wikidata lists
    ~6.2k **present-day municipalities**, whereas the lexikon holds ~18k historical
    settlements incl. *osady* and absorbed hamlets, so 2,250 lexikon names are shared by
    several settlements while only one survives as a modern obec. Every one of those
    same-named settlements silently inherited that single obec's coordinates — landing a
    median **75 km** from its own okres. Measured (audit 2026-07-16): coordinates that pass
    the okres corroboration land inside their name-based okres **87.4 %** of the time; those
    taken by the old fallback, only **30.8 %**.

    A name that is unambiguous on **both** sides (one lexikon settlement, one Wikidata point)
    is still accepted without the okres check — there is no other settlement it could be, and
    this is what keeps coverage up where it is safe. Everything else is left blank: wrong
    coordinates scatter people across the country and would silently corrupt any spatial
    analysis (Kelly-2019 SEs, point maps), whereas missing coordinates merely reduce n.

    :data:`_CURATED_COORDS` is consulted first, for the handful of settlements the SPARQL result
    cannot contain at all (Praha, and the towns partitioned away or merged since 1910).
    """
    idx = _coord_index(points)
    okres_modern = settlements["okres_all"].fillna("").map(lambda s: s.split("|")[-1] if s else "")
    # how many lexikon settlements share each (normalised) name — the side the old code ignored
    lex_n = settlements["cs_name"].map(rg._norm).value_counts()

    def match(cs_name, om, oid):
        k = rg._norm(cs_name)
        if pd.notna(oid) and (k, int(oid)) in _CURATED_COORDS:    # absent from Wikidata's reach
            return _CURATED_COORDS[(k, int(oid))]
        cands = idx.get(k)
        if not cands:
            return (None, None, None)
        hit = [c for c in cands if c[0] == rg._norm(om)]          # okres-corroborated
        if len(hit) == 1:
            return (hit[0][1], hit[0][2], hit[0][3])
        if len(cands) == 1 and lex_n.get(k, 0) == 1:              # unique on BOTH sides
            return (cands[0][1], cands[0][2], cands[0][3])
        return (None, None, None)

    out = settlements.copy()
    res = [match(n, o, i)
           for n, o, i in zip(out["cs_name"], okres_modern, out["okres_id"])]

    # One Wikidata point, one place. Corroborating on the *modern* okres lets two different
    # 1910 settlements that today share an okres both claim the same point — BĚLÁ in okres
    # Semily and BĚLÁ in okres Turnov, HRADIŠTĚ in Blatná and in Plzeň: 117 settlements over
    # 57 points, at least one of each pair on the wrong coordinate and hence the wrong court
    # (audit 2026-09-22 §B8). A point claimed from more than one 1910 okres is refused for
    # every claimant, the same corroborate-or-refuse rule as the rest of this function.
    claims: dict[str, set] = defaultdict(set)
    for (q, _la, _lo), oid in zip(res, out["okres_id"]):
        if q is not None:
            claims[q].add(int(oid) if pd.notna(oid) else None)
    shared = {q for q, oids in claims.items() if len(oids) > 1}
    res = [(None, None, None) if r[0] in shared else r for r in res]

    out["wd_qid"] = [r[0] for r in res]
    out["lat"] = [r[1] for r in res]
    out["lon"] = [r[2] for r in res]
    return out

def add_settlement_de_name(settlements: pd.DataFrame, points: pd.DataFrame) -> pd.DataFrame:
    """Attach ``de_name`` (standardised 1910/modern German name) to the settlement crosswalk.

    Primary source is the Wikidata German label (``de``), joined on the already-attached
    ``wd_qid`` — clean for major places (Liberec→Reichenberg, Budweis). Where Wikidata has no
    German label, fall back to the lexikon's ``name_1910`` **only when it is genuinely German**
    (differs from the Czech name and carries no Czech diacritics — the Sudeten exonyms). The long
    tail of Czech-only villages keeps ``de_name`` = ``<NA>`` (no historical German form; no
    translation is invented). Requires :func:`add_settlement_coords` to have run (for ``wd_qid``).
    """
    # Keep only genuine German exonyms — Wikidata's ``de`` label is frequently just the Czech name
    # (Podivín, Želiv), which is noise, not a German variant.
    de_by_qid = {r.qid: r.de for r in points.itertuples(index=False)
                 if isinstance(r.de, str) and r.de.strip()
                 and rg._norm(r.de) != rg._norm(r.cs)}

    def _looks_german(nm, cs) -> bool:
        if not isinstance(nm, str) or not nm.strip():
            return False
        if rg._norm(nm) == rg._norm(cs):
            return False
        return not any(c in nm for c in "áčďéěíňóřšťúůýžÁČĎÉĚÍŇÓŘŠŤÚŮÝŽ")

    out = settlements.copy()
    qid = out["wd_qid"] if "wd_qid" in out.columns else pd.Series(pd.NA, index=out.index)
    de: list[object] = []
    for q, n1910, cs in zip(qid, out.get("name_1910", pd.Series([None] * len(out))), out["cs_name"]):
        val = de_by_qid.get(q) if pd.notna(q) else None
        if not val and _looks_german(n1910, cs):
            val = n1910
        de.append(val if val else pd.NA)
    out["de_name"] = de
    return out

def add_birth_coords(df: pd.DataFrame, settlements: pd.DataFrame,
                     muni_col: str = "birth_municipality") -> pd.DataFrame:
    """Attach ``birth_lat`` / ``birth_lon`` / ``birth_qid`` to person records.

    .. note:: **Superseded in the pipeline** by :func:`records_geo.add_settlement_attrs`
       (via ``add_place_standardization``, notebook 02 §4), which attaches the same
       coordinates *plus* standardised names and courts and — unlike this function —
       vetoes the unique-name fallback for positively-foreign births. Kept as a
       standalone utility; if revived, prefer the records_geo path.

    A record is placed by ``(birth_municipality, birth_okres_id)`` against the coord-bearing
    settlements — the resolved okres_id disambiguates homonyms exactly — with a unique-name
    fallback where the settlement name is unambiguous.
    """
    if "wd_qid" not in settlements.columns:          # coords step (add_settlement_coords) not run
        out = df.copy()
        out["birth_lat"] = out["birth_lon"] = out["birth_qid"] = None
        return out
    coord = settlements[settlements["wd_qid"].notna()]
    keyed: dict[tuple[str, int], tuple[float, float, str]] = {}
    name_ids: dict[str, set[str]] = defaultdict(set)
    qid_xy: dict[str, tuple[float, float]] = {}
    for r in coord.itertuples(index=False):
        qid_xy[r.wd_qid] = (r.lat, r.lon)
        for nm in (r.cs_name, r.name_1910):
            k = rg._norm(nm)
            if not k:
                continue
            name_ids[k].add(r.wd_qid)
            if pd.notna(r.okres_id):
                keyed[(k, int(r.okres_id))] = (r.lat, r.lon, r.wd_qid)
    uniq = {k: next(iter(v)) for k, v in name_ids.items() if len(v) == 1}

    lat = [None] * len(df)
    lon = [None] * len(df)
    qid = [None] * len(df)
    munis = df[muni_col].to_numpy()
    oids = df["birth_okres_id"].to_numpy() if "birth_okres_id" in df else [pd.NA] * len(df)
    for i, (mu, oid) in enumerate(zip(munis, oids)):
        if pd.isna(mu):
            continue
        k = rg._norm(mu)
        if pd.notna(oid) and (k, int(oid)) in keyed:
            lat[i], lon[i], qid[i] = keyed[(k, int(oid))]
        elif k in uniq:
            q = uniq[k]
            lat[i], lon[i], qid[i] = qid_xy[q][0], qid_xy[q][1], q
    out = df.copy()
    out["birth_lat"], out["birth_lon"], out["birth_qid"] = lat, lon, qid
    return out

def okres_centroids(settlements: pd.DataFrame) -> pd.DataFrame:
    """1910-okres centroid (mean of its coord-bearing settlements) → ``okres_id, lat, lon``."""
    c = settlements[settlements["wd_qid"].notna() & settlements["okres_id"].notna()]
    return (c.groupby("okres_id")[["lat", "lon"]].mean()
            .rename(columns={"lat": "okres_lat", "lon": "okres_lon"}).reset_index())

"""
wikidata.py — coordinates + QIDs for Czech settlements (enriches the lexikon crosswalk)
=======================================================================================
Fetches Czech settlements (obec Q5153359 + část obce Q15978299) with **coordinates**, Czech +
German labels, and their **modern okres** (P131) from the Wikidata Query Service, then attaches
lat/lon/QID to the :mod:`utils.parsing.lexikon` settlement crosswalk and to individual birth
records. Enables point-level mapping and Kelly-2019 spatial standard errors.

The SPARQL result is **cached to disk** (``data/raw/wikidata/…``) so the pipeline is reproducible
without re-querying every run; delete the cache (or pass ``refresh=True``) to re-fetch.

Matching
--------
Wikidata is queried CZ-only (the class instances are Czech settlements), so the cross-empire
German-name collision (``Trautenau → Trutnowo``) cannot occur here. Homonyms are disambiguated by
**modern okres**: the lexikon ``okres_all`` timeline ends at the present-day okres, matched to
Wikidata's P131 okres. Records are disambiguated by their already-resolved ``birth_okres_id``
(exact), falling back to a unique-name match.

Coverage note: Wikidata carries coordinates for ~6.3k current municipalities (+~0.6k parts), so
settlement coverage of the ~18k historical lexikon entries is ~40%, and birth-coordinate coverage
is ~40–50% of records (births cluster in municipalities). Okres-level analysis does not need these.

Usage
-----
    from utils.parsing import wikidata as wd
    points = wd.fetch_cz_settlements(CACHE)              # SPARQL (or load cache)
    settlements = wd.add_settlement_coords(settlements, points)
    legion = wd.add_birth_coords(legion, settlements)
"""

from __future__ import annotations

import re
import time
from collections import defaultdict
from pathlib import Path

import pandas as pd

from utils.parsing import records_geo as rg

try:
    import requests
except ImportError as exc:  # pragma: no cover
    raise ImportError("wikidata.py requires requests (`pip install requests`).") from exc

__version__ = "1.4.0"   # a point claimed from >1 1910 okres is refused (audit 2026-09-22)

_SPARQL = "https://query.wikidata.org/sparql"

# Settlements the SPARQL result **cannot** contain, so no amount of matching will reach them.
# The query asks for present-day Czech municipalities whose P131 is an ``okres …``; these four
# fail that filter for two different reasons, and between them they account for the largest
# remaining blocks of missing birth coordinates (~2,700 legion + ~1,900 VÚA for Praha alone).
#
#   * **Praha** — the capital is not *in* an okres, so the P131 filter drops it outright.
#   * **Frýdek**, **Těšín**, **Bílsko** — the 1910 town no longer exists under that name:
#     Frýdek merged into Frýdek-Místek, and Teschen/Bielitz were partitioned to Poland in 1920.
#
# Keyed ``(norm(cs_name), okres_id)`` — the okres pins *which* like-named settlement is meant, so
# the three Czech hamlets called BÍLSKO and the Jilemnice osada called BRNO are never captured.
# Coordinates are Wikidata P625, taken by QID (queried 2026-08-01), same CC0 source as the cache.
# Frýdek and Těšín use their **successor** municipality's point: Frýdek-Místek's centre sits
# ~1 km east of the Frýdek square, and Český Těšín ~700 m west of the old town across the Olza.
# Both are inside the tolerance the boundary file itself carries (PLACE_MATCHING: a line is good
# to a kilometre, not to a field boundary), and both fall in the right 1910 court polygon.
_CURATED_COORDS: dict[tuple[str, int], tuple[str, float, float]] = {
    ("praha", 301072):  ("Q1085",   50.087500, 14.421389),   # Prague
    ("frydek", 303007): ("Q48194",  49.688056, 18.353611),   # Frýdek-Místek
    ("tesin", 303009):  ("Q278877", 49.746111, 18.626170),   # Český Těšín
    ("bilsko", 303002): ("Q106583", 49.822500, 19.044444),   # Bielsko-Biała, PL
}
_UA = {"User-Agent": "LegionsThesis/1.0 (economic-history research; contact via repo)"}
# Wikidata classes of Czech settlements that carry coordinates.
_CLASSES = {"Q5153359": "obec", "Q15978299": "cast_obce"}


def _wkt_lonlat(s: str) -> tuple[float | None, float | None]:
    m = re.match(r"Point\(([-\d.]+) ([-\d.]+)\)", s or "")
    return (float(m.group(2)), float(m.group(1))) if m else (None, None)


def _query_class(class_qid: str, timeout: int = 180) -> list[dict]:
    q = f"""
    SELECT ?item ?csLabel ?de ?coord ?okresLabel WHERE {{
      ?item wdt:P31 wd:{class_qid} ; wdt:P625 ?coord .
      OPTIONAL {{ ?item wdt:P131 ?okres . }}
      OPTIONAL {{ ?item rdfs:label ?de FILTER(lang(?de)="de") }}
      SERVICE wikibase:label {{ bd:serviceParam wikibase:language "cs".
                                ?item rdfs:label ?csLabel . ?okres rdfs:label ?okresLabel . }}
    }}"""
    r = requests.post(_SPARQL, data={"query": q, "format": "json"}, headers=_UA, timeout=timeout)
    r.raise_for_status()
    return r.json()["results"]["bindings"]


def fetch_cz_settlements(cache_path, refresh: bool = False) -> pd.DataFrame:
    """Return Wikidata Czech settlements (``qid, cs, de, lat, lon, okres_modern, wd_class``).

    Loads *cache_path* if present (unless ``refresh``); otherwise queries the Wikidata Query
    Service per class, keeps only rows whose P131 is an ``okres …`` (drops the ORP duplicates),
    dedupes per QID, and writes the cache.
    """
    cache_path = Path(cache_path)
    if cache_path.exists() and not refresh:
        return pd.read_csv(cache_path)

    rows = []
    for class_qid, tag in _CLASSES.items():
        for _try in range(3):
            try:
                bindings = _query_class(class_qid)
                break
            except Exception:                       # noqa: BLE001 — transient WDQS timeout
                time.sleep(5)
        else:
            bindings = []
        for x in bindings:
            okres = x.get("okresLabel", {}).get("value", "")
            if not okres.startswith("okres "):      # keep the okres P131, drop ORP / others
                continue
            lat, lon = _wkt_lonlat(x["coord"]["value"])
            rows.append({"qid": x["item"]["value"].rsplit("/", 1)[-1],
                         "cs": x["csLabel"]["value"],
                         "de": x.get("de", {}).get("value", ""),
                         "lat": lat, "lon": lon,
                         "okres_modern": okres[len("okres "):], "wd_class": tag})
    out = pd.DataFrame(rows).drop_duplicates("qid").reset_index(drop=True)
    cache_path.parent.mkdir(parents=True, exist_ok=True)
    out.to_csv(cache_path, index=False, encoding="utf-8")
    return out


def _coord_index(points: pd.DataFrame) -> dict[str, list[tuple[str, str, float, float]]]:
    """norm(cs name) → list of (norm okres_modern, qid, lat, lon)."""
    idx: dict[str, list] = defaultdict(list)
    for r in points.itertuples(index=False):
        if pd.notna(r.lat):
            idx[rg._norm(r.cs)].append((rg._norm(r.okres_modern), r.qid, r.lat, r.lon))
    return idx


def add_settlement_coords(settlements: pd.DataFrame, points: pd.DataFrame) -> pd.DataFrame:
    """Attach ``wd_qid`` / ``lat`` / ``lon`` to the lexikon settlement crosswalk.

    Match on Czech name, then **corroborate**: the candidate's Wikidata (modern) okres must
    equal the settlement's own modern okres — the last entry of its ``okres_all`` timeline.

    The bare unique-name fallback this replaced (*"only one Wikidata point carries this name,
    so take it"*) was the single largest source of bad geography in the build: Wikidata lists
    ~6.2k **present-day municipalities**, whereas the lexikon holds ~18k historical
    settlements incl. *osady* and absorbed hamlets, so 2,250 lexikon names are shared by
    several settlements while only one survives as a modern obec. Every one of those
    same-named settlements silently inherited that single obec's coordinates — landing a
    median **75 km** from its own okres. Measured (audit 2026-07-16): coordinates that pass
    the okres corroboration land inside their name-based okres **87.4 %** of the time; those
    taken by the old fallback, only **30.8 %**.

    A name that is unambiguous on **both** sides (one lexikon settlement, one Wikidata point)
    is still accepted without the okres check — there is no other settlement it could be, and
    this is what keeps coverage up where it is safe. Everything else is left blank: wrong
    coordinates scatter people across the country and would silently corrupt any spatial
    analysis (Kelly-2019 SEs, point maps), whereas missing coordinates merely reduce n.

    :data:`_CURATED_COORDS` is consulted first, for the handful of settlements the SPARQL result
    cannot contain at all (Praha, and the towns partitioned away or merged since 1910).
    """
    idx = _coord_index(points)
    okres_modern = settlements["okres_all"].fillna("").map(lambda s: s.split("|")[-1] if s else "")
    # how many lexikon settlements share each (normalised) name — the side the old code ignored
    lex_n = settlements["cs_name"].map(rg._norm).value_counts()

    def match(cs_name, om, oid):
        k = rg._norm(cs_name)
        if pd.notna(oid) and (k, int(oid)) in _CURATED_COORDS:    # absent from Wikidata's reach
            return _CURATED_COORDS[(k, int(oid))]
        cands = idx.get(k)
        if not cands:
            return (None, None, None)
        hit = [c for c in cands if c[0] == rg._norm(om)]          # okres-corroborated
        if len(hit) == 1:
            return (hit[0][1], hit[0][2], hit[0][3])
        if len(cands) == 1 and lex_n.get(k, 0) == 1:              # unique on BOTH sides
            return (cands[0][1], cands[0][2], cands[0][3])
        return (None, None, None)

    out = settlements.copy()
    res = [match(n, o, i)
           for n, o, i in zip(out["cs_name"], okres_modern, out["okres_id"])]

    # One Wikidata point, one place. Corroborating on the *modern* okres lets two different
    # 1910 settlements that today share an okres both claim the same point — BĚLÁ in okres
    # Semily and BĚLÁ in okres Turnov, HRADIŠTĚ in Blatná and in Plzeň: 117 settlements over
    # 57 points, at least one of each pair on the wrong coordinate and hence the wrong court
    # (audit 2026-09-22 §B8). A point claimed from more than one 1910 okres is refused for
    # every claimant, the same corroborate-or-refuse rule as the rest of this function.
    claims: dict[str, set] = defaultdict(set)
    for (q, _la, _lo), oid in zip(res, out["okres_id"]):
        if q is not None:
            claims[q].add(int(oid) if pd.notna(oid) else None)
    shared = {q for q, oids in claims.items() if len(oids) > 1}
    res = [(None, None, None) if r[0] in shared else r for r in res]

    out["wd_qid"] = [r[0] for r in res]
    out["lat"] = [r[1] for r in res]
    out["lon"] = [r[2] for r in res]
    return out


def add_settlement_de_name(settlements: pd.DataFrame, points: pd.DataFrame) -> pd.DataFrame:
    """Attach ``de_name`` (standardised 1910/modern German name) to the settlement crosswalk.

    Primary source is the Wikidata German label (``de``), joined on the already-attached
    ``wd_qid`` — clean for major places (Liberec→Reichenberg, Budweis). Where Wikidata has no
    German label, fall back to the lexikon's ``name_1910`` **only when it is genuinely German**
    (differs from the Czech name and carries no Czech diacritics — the Sudeten exonyms). The long
    tail of Czech-only villages keeps ``de_name`` = ``<NA>`` (no historical German form; no
    translation is invented). Requires :func:`add_settlement_coords` to have run (for ``wd_qid``).
    """
    # Keep only genuine German exonyms — Wikidata's ``de`` label is frequently just the Czech name
    # (Podivín, Želiv), which is noise, not a German variant.
    de_by_qid = {r.qid: r.de for r in points.itertuples(index=False)
                 if isinstance(r.de, str) and r.de.strip()
                 and rg._norm(r.de) != rg._norm(r.cs)}

    def _looks_german(nm, cs) -> bool:
        if not isinstance(nm, str) or not nm.strip():
            return False
        if rg._norm(nm) == rg._norm(cs):
            return False
        return not any(c in nm for c in "áčďéěíňóřšťúůýžÁČĎÉĚÍŇÓŘŠŤÚŮÝŽ")

    out = settlements.copy()
    qid = out["wd_qid"] if "wd_qid" in out.columns else pd.Series(pd.NA, index=out.index)
    de: list[object] = []
    for q, n1910, cs in zip(qid, out.get("name_1910", pd.Series([None] * len(out))), out["cs_name"]):
        val = de_by_qid.get(q) if pd.notna(q) else None
        if not val and _looks_german(n1910, cs):
            val = n1910
        de.append(val if val else pd.NA)
    out["de_name"] = de
    return out


def add_birth_coords(df: pd.DataFrame, settlements: pd.DataFrame,
                     muni_col: str = "birth_municipality") -> pd.DataFrame:
    """Attach ``birth_lat`` / ``birth_lon`` / ``birth_qid`` to person records.

    .. note:: **Superseded in the pipeline** by :func:`records_geo.add_settlement_attrs`
       (via ``add_place_standardization``, notebook 02 §4), which attaches the same
       coordinates *plus* standardised names and courts and — unlike this function —
       vetoes the unique-name fallback for positively-foreign births. Kept as a
       standalone utility; if revived, prefer the records_geo path.

    A record is placed by ``(birth_municipality, birth_okres_id)`` against the coord-bearing
    settlements — the resolved okres_id disambiguates homonyms exactly — with a unique-name
    fallback where the settlement name is unambiguous.
    """
    if "wd_qid" not in settlements.columns:          # coords step (add_settlement_coords) not run
        out = df.copy()
        out["birth_lat"] = out["birth_lon"] = out["birth_qid"] = None
        return out
    coord = settlements[settlements["wd_qid"].notna()]
    keyed: dict[tuple[str, int], tuple[float, float, str]] = {}
    name_ids: dict[str, set[str]] = defaultdict(set)
    qid_xy: dict[str, tuple[float, float]] = {}
    for r in coord.itertuples(index=False):
        qid_xy[r.wd_qid] = (r.lat, r.lon)
        for nm in (r.cs_name, r.name_1910):
            k = rg._norm(nm)
            if not k:
                continue
            name_ids[k].add(r.wd_qid)
            if pd.notna(r.okres_id):
                keyed[(k, int(r.okres_id))] = (r.lat, r.lon, r.wd_qid)
    uniq = {k: next(iter(v)) for k, v in name_ids.items() if len(v) == 1}

    lat = [None] * len(df)
    lon = [None] * len(df)
    qid = [None] * len(df)
    munis = df[muni_col].to_numpy()
    oids = df["birth_okres_id"].to_numpy() if "birth_okres_id" in df else [pd.NA] * len(df)
    for i, (mu, oid) in enumerate(zip(munis, oids)):
        if pd.isna(mu):
            continue
        k = rg._norm(mu)
        if pd.notna(oid) and (k, int(oid)) in keyed:
            lat[i], lon[i], qid[i] = keyed[(k, int(oid))]
        elif k in uniq:
            q = uniq[k]
            lat[i], lon[i], qid[i] = qid_xy[q][0], qid_xy[q][1], q
    out = df.copy()
    out["birth_lat"], out["birth_lon"], out["birth_qid"] = lat, lon, qid
    return out


def okres_centroids(settlements: pd.DataFrame) -> pd.DataFrame:
    """1910-okres centroid (mean of its coord-bearing settlements) → ``okres_id, lat, lon``."""
    c = settlements[settlements["wd_qid"].notna() & settlements["okres_id"].notna()]
    return (c.groupby("okres_id")[["lat", "lon"]].mean()
            .rename(columns={"lat": "okres_lat", "lon": "okres_lon"}).reset_index())


def wikidata_report(settlements: pd.DataFrame, points: pd.DataFrame) -> None:
    """Print geocoding coverage of the settlement crosswalk.

    The last line is the one that matters: settlements carrying **both** a 1910
    ``okres_id`` and coordinates are the only ones that can support okres-level spatial
    work. Coverage is capped by Wikidata holding only present-day municipalities, and is
    deliberately traded down for correctness by the okres corroboration in
    :func:`add_settlement_coords`.
    """
    n = len(settlements)
    with_xy = settlements["wd_qid"].notna().sum()
    print(f"Wikidata coordinates  (points fetched = {len(points)})")
    print(f"  settlements geocoded: {with_xy} / {n}  ({with_xy/n*100:.1f}%)")
    print(f"  with both 1910 okres_id and coords: "
          f"{(settlements['okres_id'].notna() & settlements['wd_qid'].notna()).sum()}")
