How it works

SYMBOL_ACCURACY_PLAN.md (revision of 2026-09-17) records a ladder: Gemini 3.7 Flash on the bake-off's section crops reads the 280-claim gold at F1 0.964, and Gemini 3.8 Flash on whole pages (notebook 06) at 0.845 at best. The last step of that ladder changes three things at once — the model version, the size of what one call is shown, and the job the call is given — so it cannot say which one paid. This experiment holds the crops, the prompt, the atlas and every flag fixed and changes only the model:

arm A   gemini-3.7-flash   on the bake-off crops     3 repeats
arm B   gemini-3.8-flash   on the bake-off crops     3 repeats
arm C   gemini-3.8-flash   whole-page halfbands      the 5 repeats of 2026-09-10

arm D   gemini-3.7-flash   on the bake-off crops     3 repeats, thinking OFF
arm E   gemini-3.8-flash   on the bake-off crops     3 repeats, thinking OFF

A − B is the version effect; B − C is what the view and the task cost. Arms D and E (added 2026-09-22) switch Gemini's thinking off with reasoning_effort="none": A − D and B − E are what thinking buys on the crops, and E − C compares crops with whole pages with thinking off on both sides — the cleaner version of B − C. Repeats are not optional here: Gemini is not deterministic (five halfbands repeats span F1 0.804–0.878), so one run per arm would compare two draws, not two readers.

What is held fixed, and how that is known

The flags are bakeoff.flags_for for the atlas variant of the gold kind — 13 pages, both apparatus documents, strips of 500 px, upscaled, atlas on, temperature 0 — with the reader switched from the Ollama daemon to the hosted endpoint. That this reproduces the 2026-08-30 pass exactly was checked, not assumed: re-running gemini37_r3atlasg with these flags against a copy of its crop cache served 81 of 81 crops from cache, and the cache key hashes the crop bytes, the caption, the model, the system prompt, the temperature and the atlas.

Arm A's first repeat is that 2026-08-30 reading, re-decoded by today's code: its cache is copied under the new label, so no request is made and the answers are the model's own. Re-decoding matters — the stored inventory scores F1 0.964 and the same answers decoded today score 0.975, because the decoder changed after the pass was written. Every pass in this experiment is decoded by the same code.

Arms A and B send no thinking setting, so each runs on its provider default — which on Gemini 3.x Flash is thousands of thinking tokens a crop, billed as output and, before 2026-09-22, never booked by the pilot (see SYMBOL_ACCURACY_PLAN.md, Correction). Arm C was run with thinking explicitly off, and so are D and E.

Scoring

score_against_reference against inventory_human.csv (4 purposive pages; 47 entries and 280 claims when E1 ran, 61 and 372 since D-65 — the report prints what the file holds): P / R / F1 / entry_exact per repeat, the mean and range per arm, a ≥ 2-of-3 majority per arm, the claims each arm gets wrong by glyph, and a bootstrap over entries for the two differences. The bootstrap treats the 47 entries as independent; they sit on four pages, so its intervals are too narrow and are reported as a lower bound on the uncertainty.

Usage

python utils/lexikon_1910/run_e1_gemini_version.py               # run what is missing, then score
python utils/lexikon_1910/run_e1_gemini_version.py --arm off     # only the thinking-off arms
python utils/lexikon_1910/run_e1_gemini_version.py --wait 120    # first poll up to 120 min for quota
python utils/lexikon_1910/run_e1_gemini_version.py --score       # score only, spend nothing
python utils/lexikon_1910/run_e1_gemini_version.py --dry-run     # print the plan and the flags

A pass whose inventory exists is skipped. The quota is asked before every pass that needs the network, and a refused request (HTTP 429) mid-pass parks it exactly as bakeoff does. Either way the runner does not push on — the quota belongs to the account, so every later pass would be refused too. Without --wait it stops; with it, it goes back to waiting for whatever time is left, and it counts the quota as open only after two consecutive requests are answered.

def flags(job: dict) -> list[str]:
    """``bakeoff.flags_for`` for the gold atlas pass, pointed at the hosted reader.

    Edited, not rebuilt, so every flag that decides what the model is shown stays
    whatever the bake-off sends. Only the transport changes: the reader, the
    worker count, and ``--notes-num-ctx``, which exists for Ollama alone.
    """
    argv = bo.flags_for(job["model"], job["label"], bo.gold_pages(),
                        bo.VARIANT[VARIANT], {}, kind=KIND)
    out: list[str] = []
    skip = False
    for i, arg in enumerate(argv):
        if skip:
            skip = False
            continue
        if arg == "--notes-num-ctx":
            skip = True
            continue
        if arg == "--notes-reader":
            out += [arg, "gemini"]
            skip = True
            continue
        if arg == "--workers":
            out += [arg, str(WORKERS)]
            skip = True
            continue
        out.append(arg)
    _model, price_in, price_out = MODELS[job["model_label"]]
    if price_in is not None:
        out += ["--notes-price", f"{price_in},{price_out}"]
    if not job.get("thinking", True):
        out += ["--notes-reasoning-effort", "none"]
    if job.get("geometry", "image") != "image":
        out += ["--geometry", job["geometry"]]
    return out

def quota_open(model: str) -> tuple[bool, str]:
    """One tiny request. ``(True, "")`` if the account can be billed right now."""
    import os
    from openai import OpenAI
    client = OpenAI(base_url=GEMINI_URL, api_key=os.environ.get("GEMINI_API_KEY", ""))
    try:
        client.chat.completions.create(
            model=model, max_tokens=16,
            messages=[{"role": "user", "content": "Reply with OK."}])
        return True, ""
    except Exception as exc:                                    # noqa: BLE001
        status = getattr(exc, "status_code", None)
        # 429 is the account (spent prepay, or a per-minute window); 5xx is the
        # provider having a bad minute. Both are "not now", neither is a bug.
        if status == 429 or (status is not None and status >= 500):
            return False, f"HTTP {status}: {str(exc)[:140]}"
        raise

def wait_for_quota(minutes: float) -> bool:
    deadline = time.time() + minutes * 60
    while True:
        ok, why = quota_open("gemini-3.8-flash")
        if ok:
            # TWICE, because once is not evidence. On 2026-09-17 a spent prepay
            # account answered one ping at 09:32 and refused every request after
            # it, and a runner that believed the single success stopped for good
            # one call later. A top-up that has landed answers both.
            time.sleep(15)
            ok, why = quota_open("gemini-3.8-flash")
        if ok:
            print("  quota open (two consecutive requests answered)")
            return True
        if time.time() >= deadline:
            print(f"  quota still closed after {minutes:g} min: {why}")
            return False
        print(f"  {time.strftime('%H:%M')} quota closed — {why[:90]}… "
              f"retrying in 60 s", flush=True)
        time.sleep(60)

def cache_usage(name: str, pass_dir: Path | None = None) -> dict:
    """Tokens stored with every cached crop of one pass (whenever it was read).

    ``pass_dir`` is the machine folder to look in; this machine's by default.
    """
    total = Counter()
    for path in ((pass_dir or bo.PASS_DIR) / "crop_cache" / name).glob("*.json"):
        try:
            usage = json.loads(path.read_text(encoding="utf-8")).get("usage") or {}
        except (ValueError, OSError):
            continue
        total["crops"] += 1
        total["input"] += int(usage.get("input") or 0)
        total["output"] += int(usage.get("output") or 0)
        total["thinking"] += int(usage.get("thinking") or 0)
        total["cache_write"] += int(usage.get("cache_write") or 0)
        total["cache_read"] += int(usage.get("cache_read") or 0)
    return dict(total)

def run(force: bool = False, arm: str = "both") -> bool:
    """Run every outstanding pass. False if a quota refusal stopped it."""
    bo.ensure_dirs()
    seed_first_repeat()
    timings = bo.load_timings()
    for job in plan(arm):
        if job["done"] and not force:
            print(f"  {job['label']:22s} on disk — skipped")
            continue
        # Asked BEFORE the pass, so a closed quota costs one refused ping instead
        # of a parked pass with a short inventory on disk. The seeded repeat is
        # read entirely from cache and needs no quota at all.
        if job["label"] != label(SEED[0], 1, True):
            ok, why = quota_open(job["model"])
            if not ok:
                print(f"\n  quota closed before {job['label']} ({why[:90]}) — "
                      f"stopping E1; rerun to resume")
                return False
        marker = bo.PASS_DIR / f"ratelimit_{job['label']}.json"
        if marker.exists():
            kept = bo.PASS_DIR / (f"superseded_ratelimit_{job['label']}_"
                                  f"{time.strftime('%Y%m%d-%H%M%S')}.json")
            marker.replace(kept)
        argv = flags(job)
        print("\n" + "=" * 78)
        print(f"E1  {job['label']}   ({job['model']}, repeat {job['repeat']}, "
              f"thinking {'on' if job['thinking'] else 'OFF'})")
        print("=" * 78)
        rc, seconds = bo.run_pilot(argv, f"{KIND}_{job['label']}")
        usage = cache_usage(job["label"])
        timings.setdefault(job["label"], {})[KIND] = {
            "model": job["model"], "variant": VARIANT, "pages": bo.gold_pages(),
            "seconds": seconds, "rc": rc, "atlas": True, "upscale": True,
            "max_height": bo.MAX_HEIGHT, "num_ctx": None, "sections": bo.SECTIONS,
            "run_tag": bo.RUN_TAG, "host": bo.HOST, "reader": "gemini",
            "experiment": "E1", "repeat": job["repeat"], "tokens": usage,
            "thinking": job["thinking"],
            "incomplete": marker.exists(),
            "finished": time.strftime("%Y-%m-%d %H:%M:%S"),
        }
        bo.TIMINGS.write_text(json.dumps(timings, indent=2), encoding="utf-8")
        if marker.exists():
            print(f"\n  {job['label']} was refused by the quota — stopping E1; "
                  f"the pass stays outstanding and reruns on a fresh quota.")
            return False
        if rc != 0:
            print(f"\n  {job['label']} exited rc={rc} — see "
                  f"logs/{KIND}_{job['label']}.log")
    return True

def per_entry(reference: list[dict], rows: list[dict]) -> dict:
    """``entry -> (hit, false, missed, exact)`` with the scorer's own matching."""
    ref_entries, ref_claims = lxin._claims(reference)
    entries, claims = lxin._claims(rows)
    out = {}
    for entry in ref_entries & entries:
        mine = {c[3] for c in claims if c[:3] == entry}
        theirs = {c[3] for c in ref_claims if c[:3] == entry}
        out[entry] = (len(mine & theirs), len(mine - theirs),
                      len(theirs - mine), int(mine == theirs))
    return out

def pooled(tables: list[dict], weights: dict) -> dict:
    """P / R / F1 / exact summed over repeats and (weighted) entries."""
    hit = false = missed = exact = n = 0
    for table in tables:
        for entry, w in weights.items():
            if entry not in table or not w:
                continue
            h, f, m, e = table[entry]
            hit += w * h
            false += w * f
            missed += w * m
            exact += w * e
            n += w
    p = hit / (hit + false) if hit + false else 0.0
    r = hit / (hit + missed) if hit + missed else 0.0
    return {"precision": p, "recall": r,
            "f1": 2 * p * r / (p + r) if p + r else 0.0,
            "entry_exact": exact / n if n else 0.0}

def majority(runs: list[list[dict]], at_least: int) -> list[dict]:
    key = lambda r: (r.get("page"), r.get("district"), r.get("muni_seq"), r.get("code"))
    votes: Counter = Counter()
    first: dict = {}
    for rows in runs:
        for k in {key(r) for r in rows}:
            votes[k] += 1
        for r in rows:
            first.setdefault(key(r), r)
    # Entries a run read but claimed nothing on must stay "read" for the scorer.
    kept = [first[k] for k, n in votes.items() if n >= at_least]
    seen = {(r.get("page"), r.get("district"), r.get("muni_seq")) for r in kept}
    for rows in runs:
        for r in rows:
            entry = (r.get("page"), r.get("district"), r.get("muni_seq"))
            if entry not in seen:
                kept.append({**r, "code": ""})
                seen.add(entry)
    return kept

def glyph_errors(reference: list[dict], runs: list[list[dict]]) -> dict:
    """Mean false and missed claims per glyph, per repeat."""
    _ref_entries, ref_claims = lxin._claims(reference)
    false, missed = Counter(), Counter()
    for rows in runs:
        entries, claims = lxin._claims(rows)
        shared = _ref_entries & entries
        mine = {c for c in claims if c[:3] in shared}
        theirs = {c for c in ref_claims if c[:3] in shared}
        false.update(c[3] for c in mine - theirs)
        missed.update(c[3] for c in theirs - mine)
    k = max(len(runs), 1)
    return {code: (false[code] / k, missed[code] / k)
            for code in set(false) | set(missed)}

             "E": "gemini-3.8-flash, section crops, thinking off",
             "G": "gemini-3.8-flash, section crops, thinking off, text-layer geometry"}

             f"(development gold; certifies nothing)", ""]

            # lexikon_1910_institutions 0.6.0 — same key as the local helper
            # this replaced, so the column is unchanged.
            f1_sett = s["f1_settlement"]
            lines.append(f"  {arm:3s} {name:24s} {s['claims']:6d} "
                         f"{s['precision']:6.3f} {s['recall']:6.3f} {s['f1']:6.3f} "
                         f"{s['entry_exact']:6.3f} {f1_sett:7.3f} "
                         f"{tokens.get('input', 0):9,d} {tokens.get('output', 0):8,d}")
            csv_rows.append({"arm": arm, "arm_name": names[arm], "pass": name,
                             **{k: s[k] for k in ("entries_shared", "entries_missed",
                                                  "claims", "hit", "false", "missed",
                                                  "precision", "recall", "f1",
                                                  "entry_exact")},

                             "input_tokens": tokens.get("input", ""),
                             "output_tokens": tokens.get("output", ""),
                             "thinking_tokens": tokens.get("thinking", "")})
        lines.append("")

    lines.append("  per arm — mean [min, max] over repeats, and the majority vote")

    for arm, passes in arms.items():
        if not passes:

        fs = [r["f1_settlement"] for r in rows]

"""E1 — is the gap between the two cloud pipelines the model, or the view?

``SYMBOL_ACCURACY_PLAN.md`` (revision of 2026-09-17) records a ladder: Gemini 3.7
Flash on the bake-off's section crops reads the 280-claim gold at F1 0.964, and
Gemini 3.8 Flash on whole pages (notebook 06) at 0.845 at best. The last step of
that ladder changes three things at once — the model version, the size of what
one call is shown, and the job the call is given — so it cannot say which one
paid. This experiment holds the crops, the prompt, the atlas and every flag fixed
and changes **only the model**:

    arm A   gemini-3.7-flash   on the bake-off crops     3 repeats
    arm B   gemini-3.8-flash   on the bake-off crops     3 repeats
    arm C   gemini-3.8-flash   whole-page halfbands      the 5 repeats of 2026-09-10

    arm D   gemini-3.7-flash   on the bake-off crops     3 repeats, thinking OFF
    arm E   gemini-3.8-flash   on the bake-off crops     3 repeats, thinking OFF

A − B is the version effect; B − C is what the view and the task cost. Arms D and E
(added 2026-09-22) switch Gemini's thinking off with ``reasoning_effort="none"``:
A − D and B − E are what thinking buys on the crops, and E − C compares crops with
whole pages with thinking off on *both* sides — the cleaner version of B − C. Repeats are
not optional here: Gemini is not deterministic (five `halfbands` repeats span F1
0.804–0.878), so one run per arm would compare two draws, not two readers.

What is held fixed, and how that is known
------------------------------------------
The flags are :func:`bakeoff.flags_for` for the `atlas` variant of the `gold`
kind — 13 pages, both apparatus documents, strips of 500 px, upscaled, atlas on,
temperature 0 — with the reader switched from the Ollama daemon to the hosted
endpoint. That this reproduces the 2026-08-30 pass exactly was **checked, not
assumed**: re-running `gemini37_r3atlasg` with these flags against a copy of its
crop cache served **81 of 81** crops from cache, and the cache key hashes the crop
bytes, the caption, the model, the system prompt, the temperature and the atlas.

Arm A's first repeat is that 2026-08-30 reading, **re-decoded by today's code**:
its cache is copied under the new label, so no request is made and the answers are
the model's own. Re-decoding matters — the stored inventory scores F1 0.964 and
the same answers decoded today score 0.975, because the decoder changed after the
pass was written. Every pass in this experiment is decoded by the same code.

Arms A and B send no thinking setting, so each runs on its provider default — which
on Gemini 3.x Flash is thousands of thinking tokens a crop, billed as output and,
before 2026-09-22, never booked by the pilot (see ``SYMBOL_ACCURACY_PLAN.md``,
*Correction*). Arm C was run with thinking explicitly off, and so are D and E.

Scoring
-------
``score_against_reference`` against ``inventory_human.csv`` (4 purposive pages;
47 entries and 280 claims when E1 ran, 61 and 372 since D-65 — the report prints
what the file holds): P / R / F1 / ``entry_exact`` per repeat, the mean and
range per arm, a ≥ 2-of-3 majority per arm, the claims each arm gets wrong by
glyph, and a bootstrap over **entries** for the two differences. The bootstrap
treats the 47 entries as independent; they sit on four pages, so its intervals
are too narrow and are reported as a lower bound on the uncertainty.

Usage
-----
    python utils/lexikon_1910/run_e1_gemini_version.py               # run what is missing, then score
    python utils/lexikon_1910/run_e1_gemini_version.py --arm off     # only the thinking-off arms
    python utils/lexikon_1910/run_e1_gemini_version.py --wait 120    # first poll up to 120 min for quota
    python utils/lexikon_1910/run_e1_gemini_version.py --score       # score only, spend nothing
    python utils/lexikon_1910/run_e1_gemini_version.py --dry-run     # print the plan and the flags

A pass whose inventory exists is skipped. The quota is asked before every pass
that needs the network, and a refused request (HTTP 429) mid-pass parks it exactly
as :mod:`bakeoff` does. Either way the runner does not push on — the quota belongs
to the account, so every later pass would be refused too. Without ``--wait`` it
stops; with it, it goes back to waiting for whatever time is left, and it counts
the quota as open only after two consecutive requests are answered.

#: The arm letter for each (model, thinking) pair.
ARM = {("gemini37", True): "A", ("gemini38", True): "B",
       ("gemini37", False): "D", ("gemini38", False): "E"}

#: Arm G (r5, 2026-10-14): the default reader on the text-layer geometry of
#: ``lexikon_1910_notes`` 0.8.x (``--geometry alto``), beside arm E on the
#: image geometry that is the pilot's default since 0.9.0. The only thing that

GEOMETRY_ARM = ("gemini38", "G")


def label(model_label: str, repeat: int, thinking: bool = True,
          geometry: str = "image") -> str:
    """``gemini38_r3atlasg2`` (thinking on) / ``gemini38_r3atlasntg2`` (off).

    The thinking-off arms carry their own variant tag, so their crop cache, their
    inventory and their row in every table are separate by name. The pilot's cache
    key keeps them apart anyway, but a label that looks the same for two different
    requests is how the 2026-08-14 mislabelling happened.
    """
    variant = VARIANT if thinking else VARIANT + "nt"
    if geometry != "image":
        variant += geometry
    return bo.label_for(model_label, variant, KIND) + str(repeat)


def plan(arm: str = "both") -> list[dict]:
    """Interleaved, so a run cut short still leaves both models comparable.

    ``arm`` is ``on`` (A, B), ``off`` (D, E) or ``both``.
    """
    settings = {"on": (True,), "off": (False,), "both": (True, False)}[arm]
    jobs = []
    for thinking in settings:
        for repeat in range(1, REPEATS + 1):
            for model_label in ("gemini37", "gemini38"):
                model, *_ = MODELS[model_label]
                name = label(model_label, repeat, thinking)
                jobs.append({
                    "model": model, "model_label": model_label, "repeat": repeat,
                    "label": name, "thinking": thinking,
                    "arm": ARM[(model_label, thinking)], "geometry": "image",
                    "done": (bo.PASS_DIR / f"inventory_{name}.csv").exists()
                            and not (bo.PASS_DIR / f"ratelimit_{name}.json").exists(),
                })
            if not thinking and bo.RUN_TAG != E1_RUN_TAG and bo.RUN_TAG != "r4":
                model_label, arm_letter = GEOMETRY_ARM
                model, *_ = MODELS[model_label]
                name = label(model_label, repeat, False, geometry="alto")
                jobs.append({
                    "model": model, "model_label": model_label, "repeat": repeat,
                    "label": name, "thinking": False, "arm": arm_letter,
                    "geometry": "alto",
                    "done": (bo.PASS_DIR / f"inventory_{name}.csv").exists()
                            and not (bo.PASS_DIR / f"ratelimit_{name}.json").exists(),
                })
    return jobs


def flags(job: dict) -> list[str]:
    """``bakeoff.flags_for`` for the gold atlas pass, pointed at the hosted reader.

    Edited, not rebuilt, so every flag that decides what the model is shown stays
    whatever the bake-off sends. Only the transport changes: the reader, the
    worker count, and ``--notes-num-ctx``, which exists for Ollama alone.
    """
    argv = bo.flags_for(job["model"], job["label"], bo.gold_pages(),
                        bo.VARIANT[VARIANT], {}, kind=KIND)
    out: list[str] = []
    skip = False
    for i, arg in enumerate(argv):
        if skip:
            skip = False
            continue
        if arg == "--notes-num-ctx":
            skip = True
            continue
        if arg == "--notes-reader":
            out += [arg, "gemini"]
            skip = True
            continue
        if arg == "--workers":
            out += [arg, str(WORKERS)]
            skip = True
            continue
        out.append(arg)
    _model, price_in, price_out = MODELS[job["model_label"]]
    if price_in is not None:
        out += ["--notes-price", f"{price_in},{price_out}"]
    if not job.get("thinking", True):
        out += ["--notes-reasoning-effort", "none"]
    if job.get("geometry", "image") != "image":
        out += ["--geometry", job["geometry"]]
    return out

def quota_open(model: str) -> tuple[bool, str]:
    """One tiny request. ``(True, "")`` if the account can be billed right now."""
    import os
    from openai import OpenAI
    client = OpenAI(base_url=GEMINI_URL, api_key=os.environ.get("GEMINI_API_KEY", ""))
    try:
        client.chat.completions.create(
            model=model, max_tokens=16,
            messages=[{"role": "user", "content": "Reply with OK."}])
        return True, ""
    except Exception as exc:                                    # noqa: BLE001
        status = getattr(exc, "status_code", None)
        # 429 is the account (spent prepay, or a per-minute window); 5xx is the
        # provider having a bad minute. Both are "not now", neither is a bug.
        if status == 429 or (status is not None and status >= 500):
            return False, f"HTTP {status}: {str(exc)[:140]}"
        raise


def wait_for_quota(minutes: float) -> bool:
    deadline = time.time() + minutes * 60
    while True:
        ok, why = quota_open("gemini-3.8-flash")
        if ok:
            # TWICE, because once is not evidence. On 2026-09-17 a spent prepay
            # account answered one ping at 09:32 and refused every request after
            # it, and a runner that believed the single success stopped for good
            # one call later. A top-up that has landed answers both.
            time.sleep(15)
            ok, why = quota_open("gemini-3.8-flash")
        if ok:
            print("  quota open (two consecutive requests answered)")
            return True
        if time.time() >= deadline:
            print(f"  quota still closed after {minutes:g} min: {why}")
            return False
        print(f"  {time.strftime('%H:%M')} quota closed — {why[:90]}… "
              f"retrying in 60 s", flush=True)
        time.sleep(60)

def cache_usage(name: str, pass_dir: Path | None = None) -> dict:
    """Tokens stored with every cached crop of one pass (whenever it was read).

    ``pass_dir`` is the machine folder to look in; this machine's by default.
    """
    total = Counter()
    for path in ((pass_dir or bo.PASS_DIR) / "crop_cache" / name).glob("*.json"):
        try:
            usage = json.loads(path.read_text(encoding="utf-8")).get("usage") or {}
        except (ValueError, OSError):
            continue
        total["crops"] += 1
        total["input"] += int(usage.get("input") or 0)
        total["output"] += int(usage.get("output") or 0)
        total["thinking"] += int(usage.get("thinking") or 0)
        total["cache_write"] += int(usage.get("cache_write") or 0)
        total["cache_read"] += int(usage.get("cache_read") or 0)
    return dict(total)


def input_tokens(usage: dict) -> int:
    """Every token a pass sent, cached or not.

    The Claude API reports cached input beside ``input`` rather than inside it,
    so on its own that field is only the uncached remainder and cannot be set
    beside a reader that has no prompt cache.
    """
    return sum(int(usage.get(key) or 0)
               for key in ("input", "cache_write", "cache_read"))


def run(force: bool = False, arm: str = "both") -> bool:
    """Run every outstanding pass. False if a quota refusal stopped it."""
    bo.ensure_dirs()
    seed_first_repeat()
    timings = bo.load_timings()
    for job in plan(arm):
        if job["done"] and not force:
            print(f"  {job['label']:22s} on disk — skipped")
            continue
        # Asked BEFORE the pass, so a closed quota costs one refused ping instead
        # of a parked pass with a short inventory on disk. The seeded repeat is
        # read entirely from cache and needs no quota at all.
        if job["label"] != label(SEED[0], 1, True):
            ok, why = quota_open(job["model"])
            if not ok:
                print(f"\n  quota closed before {job['label']} ({why[:90]}) — "
                      f"stopping E1; rerun to resume")
                return False
        marker = bo.PASS_DIR / f"ratelimit_{job['label']}.json"
        if marker.exists():
            kept = bo.PASS_DIR / (f"superseded_ratelimit_{job['label']}_"
                                  f"{time.strftime('%Y%m%d-%H%M%S')}.json")
            marker.replace(kept)
        argv = flags(job)
        print("\n" + "=" * 78)
        print(f"E1  {job['label']}   ({job['model']}, repeat {job['repeat']}, "
              f"thinking {'on' if job['thinking'] else 'OFF'})")
        print("=" * 78)
        rc, seconds = bo.run_pilot(argv, f"{KIND}_{job['label']}")
        usage = cache_usage(job["label"])
        timings.setdefault(job["label"], {})[KIND] = {
            "model": job["model"], "variant": VARIANT, "pages": bo.gold_pages(),
            "seconds": seconds, "rc": rc, "atlas": True, "upscale": True,
            "max_height": bo.MAX_HEIGHT, "num_ctx": None, "sections": bo.SECTIONS,
            "run_tag": bo.RUN_TAG, "host": bo.HOST, "reader": "gemini",
            "experiment": "E1", "repeat": job["repeat"], "tokens": usage,
            "thinking": job["thinking"],
            "incomplete": marker.exists(),
            "finished": time.strftime("%Y-%m-%d %H:%M:%S"),
        }
        bo.TIMINGS.write_text(json.dumps(timings, indent=2), encoding="utf-8")
        if marker.exists():
            print(f"\n  {job['label']} was refused by the quota — stopping E1; "
                  f"the pass stays outstanding and reruns on a fresh quota.")
            return False
        if rc != 0:
            print(f"\n  {job['label']} exited rc={rc} — see "
                  f"logs/{KIND}_{job['label']}.log")
    return True

def load_csv(path: Path) -> list[dict]:
    with path.open(encoding="utf-8", newline="") as fh:
        return list(csv.DictReader(fh))


def v2_claims(run_id: str) -> list[dict]:
    """Arm C's claims, rebuilt from the stored payloads with notebook 06's code."""
    from utils.lexikon_1910 import lexikon_1910_pages as lxp
    abbreviations = lxp.load_abbreviations()
    rows: list[dict] = []
    for path in sorted((V2_RAW / run_id).glob("*.json")):
        blob = json.loads(path.read_text(encoding="utf-8"))
        edition, scan, geometry, model = blob["custom_id"].split(":")
        got, _ = lxp.claims_from_payload(blob.get("payload") or {}, edition,
                                         int(scan), model, geometry, run_id,
                                         abbreviations)
        rows.extend(got)
    return rows


def per_entry(reference: list[dict], rows: list[dict]) -> dict:
    """``entry -> (hit, false, missed, exact)`` with the scorer's own matching."""
    ref_entries, ref_claims = lxin._claims(reference)
    entries, claims = lxin._claims(rows)
    out = {}
    for entry in ref_entries & entries:
        mine = {c[3] for c in claims if c[:3] == entry}
        theirs = {c[3] for c in ref_claims if c[:3] == entry}
        out[entry] = (len(mine & theirs), len(mine - theirs),
                      len(theirs - mine), int(mine == theirs))
    return out


def pooled(tables: list[dict], weights: dict) -> dict:
    """P / R / F1 / exact summed over repeats and (weighted) entries."""
    hit = false = missed = exact = n = 0
    for table in tables:
        for entry, w in weights.items():
            if entry not in table or not w:
                continue
            h, f, m, e = table[entry]
            hit += w * h
            false += w * f
            missed += w * m
            exact += w * e
            n += w
    p = hit / (hit + false) if hit + false else 0.0
    r = hit / (hit + missed) if hit + missed else 0.0
    return {"precision": p, "recall": r,
            "f1": 2 * p * r / (p + r) if p + r else 0.0,
            "entry_exact": exact / n if n else 0.0}


def majority(runs: list[list[dict]], at_least: int) -> list[dict]:
    key = lambda r: (r.get("page"), r.get("district"), r.get("muni_seq"), r.get("code"))
    votes: Counter = Counter()
    first: dict = {}
    for rows in runs:
        for k in {key(r) for r in rows}:
            votes[k] += 1
        for r in rows:
            first.setdefault(key(r), r)
    # Entries a run read but claimed nothing on must stay "read" for the scorer.
    kept = [first[k] for k, n in votes.items() if n >= at_least]
    seen = {(r.get("page"), r.get("district"), r.get("muni_seq")) for r in kept}
    for rows in runs:
        for r in rows:
            entry = (r.get("page"), r.get("district"), r.get("muni_seq"))
            if entry not in seen:
                kept.append({**r, "code": ""})
                seen.add(entry)
    return kept


def glyph_errors(reference: list[dict], runs: list[list[dict]]) -> dict:
    """Mean false and missed claims per glyph, per repeat."""
    _ref_entries, ref_claims = lxin._claims(reference)
    false, missed = Counter(), Counter()
    for rows in runs:
        entries, claims = lxin._claims(rows)
        shared = _ref_entries & entries
        mine = {c for c in claims if c[:3] in shared}
        theirs = {c for c in ref_claims if c[:3] in shared}
        false.update(c[3] for c in mine - theirs)
        missed.update(c[3] for c in theirs - mine)
    k = max(len(runs), 1)
    return {code: (false[code] / k, missed[code] / k)
            for code in set(false) | set(missed)}


def score(bootstrap: int = 2000) -> str:
    human = load_csv(bo.HUMAN)
    arms: dict[str, dict[str, list[dict]]] = {k: {} for k in "ABCDEG"}
    for job in plan("both"):
        path = bo.PASS_DIR / f"inventory_{job['label']}.csv"
        if job["done"] and path.exists():
            arms[job["arm"]][job["label"]] = load_csv(path)
    for run_id in V2_RUNS:
        if (V2_RAW / run_id).exists():
            arms["C"][run_id] = v2_claims(run_id)

    names = {"A": "gemini-3.7-flash, section crops",
             "B": "gemini-3.8-flash, section crops",
             "C": "gemini-3.8-flash, whole page (halfbands, v2)",
             "D": "gemini-3.7-flash, section crops, thinking off",
             "E": "gemini-3.8-flash, section crops, thinking off",
             "G": "gemini-3.8-flash, section crops, thinking off, text-layer geometry"}
    lines = [f"run_e1_gemini_version v{__version__} — {time.strftime('%Y-%m-%d %H:%M')}",
             f"gold: {bo.HUMAN.name} — {lxin.describe_reference(human)} "
             f"(development gold; certifies nothing)", ""]
    csv_rows = []
    lines.append(f"  {'arm':3s} {'pass':24s} {'claims':>6s} {'P':>6s} {'R':>6s} "
                 f"{'F1':>6s} {'exact':>6s} {'F1 sett':>7s} {'in tok':>9s} {'out tok':>8s}")
    for arm, passes in arms.items():
        if not passes:
            continue
        scored = {s["pass"]: s for s in lxin.score_against_reference(
            {"human": human, **passes}, reference="human")}
        for name in passes:
            s = scored[name]
            tokens = cache_usage(name) if arm != "C" else {}
            # The (entry, settlement, code) figure is the scorer's own since
            # lexikon_1910_institutions 0.6.0 — same key as the local helper
            # this replaced, so the column is unchanged.
            f1_sett = s["f1_settlement"]
            lines.append(f"  {arm:3s} {name:24s} {s['claims']:6d} "
                         f"{s['precision']:6.3f} {s['recall']:6.3f} {s['f1']:6.3f} "
                         f"{s['entry_exact']:6.3f} {f1_sett:7.3f} "
                         f"{tokens.get('input', 0):9,d} {tokens.get('output', 0):8,d}")
            csv_rows.append({"arm": arm, "arm_name": names[arm], "pass": name,
                             **{k: s[k] for k in ("entries_shared", "entries_missed",
                                                  "claims", "hit", "false", "missed",
                                                  "precision", "recall", "f1",
                                                  "entry_exact")},
                             "f1_settlement": round(f1_sett, 3),
                             "input_tokens": tokens.get("input", ""),
                             "output_tokens": tokens.get("output", ""),
                             "thinking_tokens": tokens.get("thinking", "")})
        lines.append("")

    lines.append("  per arm — mean [min, max] over repeats, and the majority vote")
    tables: dict[str, list[dict]] = {}
    for arm, passes in arms.items():
        if not passes:
            continue
        rows = [r for r in csv_rows if r["arm"] == arm]
        f1 = [r["f1"] for r in rows]
        ex = [r["entry_exact"] for r in rows]
        fs = [r["f1_settlement"] for r in rows]
        k = len(rows)
        vote_at = k // 2 + 1
        maj = lxin.score_against_reference(
            {"human": human, "maj": majority(list(passes.values()), vote_at)},
            reference="human")[0]
        lines.append(f"  {arm}  {names[arm]:44s} n={k}  "
                     f"F1 {sum(f1)/k:.3f} [{min(f1):.3f}, {max(f1):.3f}]   "
                     f"exact {sum(ex)/k:.3f} [{min(ex):.3f}, {max(ex):.3f}]   "
                     f"F1 sett {sum(fs)/k:.3f}   "
                     f"≥{vote_at}-of-{k}: P {maj['precision']:.3f} R {maj['recall']:.3f} "
                     f"F1 {maj['f1']:.3f} exact {maj['entry_exact']:.3f}")
        tables[arm] = [per_entry(human, rows_) for rows_ in passes.values()]

    # The scorer and the per-entry tables must agree before any interval is drawn.
    for arm, passes in arms.items():
        for (name, rows_), table in zip(passes.items(), tables.get(arm, [])):
            want = next(r for r in csv_rows if r["pass"] == name)
            got = (sum(v[0] for v in table.values()), sum(v[1] for v in table.values()),
                   sum(v[2] for v in table.values()))
            assert got == (want["hit"], want["false"], want["missed"]), (name, got, want)

    entries = sorted({e for arm in tables.values() for t in arm for e in t})
    diffs = [("A − B", "A", "B", "the version effect (3.7 against 3.8, same crops)"),
             ("B − C", "B", "C", "what the whole page costs 3.8 (view + task + thinking)"),
             ("A − D", "A", "D", "what thinking buys 3.7 on the crops"),
             ("B − E", "B", "E", "what thinking buys 3.8 on the crops"),
             ("D − E", "D", "E", "the version effect with thinking off"),
             ("E − C", "E", "C", "crops against whole page, thinking off on both sides"),
             ("E − G", "E", "G", "image geometry against the text layer's (r5)")]
    if entries and bootstrap:
        rng = random.Random(1910)
        lines.append("")
        lines.append(f"  differences — pooled over repeats; 95 % bootstrap over "
                     f"{len(entries)} entries, {bootstrap} draws")
        lines.append("  (entries on 4 pages are not independent: read these "
                     "intervals as a LOWER bound on the uncertainty)")
        unit = {e: 1 for e in entries}
        for label_, a, b, what in diffs:
            if a not in tables or b not in tables:
                lines.append(f"  {label_}  not yet — arm {a if a not in tables else b} "
                             f"has no passes")
                continue
            base = {m: pooled(tables[a], unit)[m] - pooled(tables[b], unit)[m]
                    for m in ("f1", "entry_exact")}
            draws = {"f1": [], "entry_exact": []}
            for _ in range(bootstrap):
                w = Counter(rng.choice(entries) for _ in entries)
                pa, pb = pooled(tables[a], w), pooled(tables[b], w)
                for m in draws:
                    draws[m].append(pa[m] - pb[m])
            parts = []
            for m in ("f1", "entry_exact"):
                d = sorted(draws[m])
                lo, hi = d[int(0.025 * len(d))], d[int(0.975 * len(d)) - 1]
                parts.append(f"{m} {base[m]:+.3f} [{lo:+.3f}, {hi:+.3f}]")
            lines.append(f"  {label_}  {'   '.join(parts)}   — {what}")

    lines.append("")
    lines.append("  where each arm errs — false / missed claims per repeat, by glyph "
                 "(top 12 by total)")
    errs = {arm: glyph_errors(human, list(p.values())) for arm, p in arms.items() if p}
    codes = Counter()
    for table in errs.values():
        for code, (f, m) in table.items():
            codes[code] += f + m
    header = "  " + f"{'glyph':22s}" + "".join(f"{arm + ' false/miss':>16s}" for arm in errs)
    lines.append(header)
    for code, _n in codes.most_common(12):
        cells = "".join(f"{errs[arm].get(code, (0, 0))[0]:8.1f}/"
                        f"{errs[arm].get(code, (0, 0))[1]:<7.1f}" for arm in errs)
        lines.append(f"  {code:22s}{cells}")

    report = "\n".join(lines)
    with OUT_CSV.open("w", encoding="utf-8", newline="") as fh:
        writer = csv.DictWriter(fh, fieldnames=list(csv_rows[0]))
        writer.writeheader()
        writer.writerows(csv_rows)
    OUT_REPORT.write_text(report + "\n", encoding="utf-8")
    return report


def main(argv=None) -> int:
    ap = argparse.ArgumentParser(description=__doc__.split("\n\n")[0])
    ap.add_argument("--score", action="store_true", help="score only; spend nothing")
    ap.add_argument("--dry-run", action="store_true", help="print the plan and exit")
    ap.add_argument("--wait", type=float, default=0,
                    help="minutes to poll for an open quota before running")
    ap.add_argument("--force", action="store_true", help="re-run passes on disk")
    ap.add_argument("--bootstrap", type=int, default=2000)
    ap.add_argument("--arm", choices=["on", "off", "both"], default="both",
                    help="which thinking setting to run: on (arms A, B), off (D, E)")
    args = ap.parse_args(argv)

    if args.dry_run:
        for job in plan(args.arm):
            print(f"  {'done' if job['done'] else 'todo':4s}  {job['label']:22s} "
                  f"{' '.join(flags(job))}")
        return 0
    if not args.score:
        from utils.lexikon_1910 import lexikon_1910_pages as lxp
        lxp.load_credentials()
        # With --wait, a quota that closes again mid-experiment sends the runner
        # back to waiting for whatever time is left, rather than ending the night.
        deadline = time.time() + args.wait * 60
        finished = False
        while True:
            remaining = (deadline - time.time()) / 60
            if args.wait and not wait_for_quota(max(remaining, 0)):
                break
            finished = run(force=args.force, arm=args.arm)
            if finished or not args.wait or time.time() >= deadline:
                break
            print("  back to waiting for the quota", flush=True)
        print("\n" + score(args.bootstrap))
        return 0 if finished else 2
    print(score(args.bootstrap))
    return 0
