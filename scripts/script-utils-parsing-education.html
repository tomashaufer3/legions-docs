TL;DR

Vzdělání is not a level. It is an itinerary: a sequence of school types, each optionally followed by the number of years completed (ob. 5 mě. 3 pok. 3 = five years Volksschule, three Bürgerschule, three years of the apprentices' continuation school). v1.0.0 collapsed the string with first-match substring rules and got the ladder wrong in three places; this module tokenises the itinerary instead and reports the highest rung reached, the years spent at each, and the track.

How it works

The ladder below is the settlement of the Reichsvolksschulgesetz of 14 May 1869, still standing in 1914 — the law under which every man in the sample was schooled (birth cohorts ≈ 1875–1900). Sources and page citations live in reference/EDUCATION_LADDER.md:

  • Moore (2020) Teaching the Empire — the general ladder. Compulsory schooling is ages 6–14, reached as ob. 5 + mě. 3; Gymnasium (8 yrs) and Realschule (7 yrs) are entered at age ten, in parallel with the Bürgerschule, not after it; the Lehrerbildungsanstalt is entered from the Bürgerschule at fifteen and is deliberately not an academic track.
  • Lassnigg (2015) IHS WP 108 — the vocational branch. The pokračovací (gewerbliche Fortbildungsschule) was legally part of compulsory mass schooling, governed communally alongside the Volksschule, and it selected on nothing: apprenticeship required no educational credential, and the school obligation followed the contract. The full-time vocational schools (obch., prům., odb., hosp.) required Bürgerschule grades plus an entrance exam, so they do sit above it.

Three consequences, and they are the whole point of the rewrite:

  1. pok. does not raise the ordinal. It is recorded as a track flag (educ_apprentice, 8,815 records) and a year count. Under v1.0.0 it scored Upper secondary, putting 8,117 records — the classic apprentice itinerary — in the same bucket as gym.
  2. uč.ústav sits one rung below the Matura tracks, not level with them.
  3. The ordinal is highest institution attended, not "level achieved". Completion is a separate, explicitly missing-able column, because a bare reálka does not say whether the man finished.

Two limits, both inherited from the sources and both documented in EDUCATION_LADDER.md §5:

  • Duration is unknown for the vocational rungs. Fortbildungsschule hours and Fachschule course lengths varied by Land and trade (regional laws 1907–1931), so educ_complete is pd.NA for them rather than guessed, and no educ_years_total is emitted. Do not sum the year columns.
  • Cisleithania only. Both sources are silent on Hungary, whose schools the Ausgleich handed to Budapest (Eötvös 1868, Apponyi 1907). Slovak and Rusyn births are parsed on the same tokens because the strings are Czech, but the ordinal is not established for them — interact it with a Cisleithanian/Transleithanian indicator, the way birth_okres and birth_jaras are kept apart.

What 2.1.0 changed

  • Every institution must start at a word start. The scan was an unanchored substring test, so technik matched inside hydrotechnika and ob inside pob. — the shape ranks 1.4.0 had to remove after Fidler caught generálmajor scoring as major. The number group stays unanchored so "reálka4" still yields 4.
  • Ties on the top rung are broken by a written rule, TIE_BREAK (D-51). 1,512 records name two schools on one rung, and max alone resolved them by which one the clerk wrote first — the same pair landing both ways.
  • Semesters are not years. sem./semestr and its number are lifted out into educ_semesters (722 records) before the itinerary is scanned; they used to be written into educ_years_secondary as if they were years.
  • střední yields to a named school. It states the level, not the school, so "stř. hosp. škola" is an agricultural Fachschule (83 records).
  • The imputed rung is flagged. Where only a continuation school is named the ordinal is floored at Elementary; those 1,112 records now carry educ_top_imputed and the track continuation, because educ_top there names a school educ_institutions does not list.

def parse_education(s: object) -> dict[str, object] | None:
    """Tokenise one ``Vzdělání`` string into its itinerary.

    Returns ``None`` for null / placeholder values and for strings in which no
    institution is recognised (the ~1 % tail of abbreviations and stray
    occupation text).  Otherwise a dict with the columns listed in the module
    docstring.

    Year numbers attach **backwards** to the institution they follow
    (``ob. 5``), and forwards when the string opens with a number (``8 ob.``,
    ``3mě``).  The first year seen for an institution wins.
    """
    if s is None or (isinstance(s, float) and pd.isna(s)) or pd.isna(s):
        return None
    raw = str(s).strip()
    if raw.lower() in _PLACEHOLDERS:
        return None

    semesters: int | None = None

    def _take_semesters(m: "re.Match[str]") -> str:
        nonlocal semesters
        val = m.group(1) or m.group(2)
        if val is not None and semesters is None:
            n = int(val)
            if 1 <= n <= _MAX_SEMESTERS:
                semesters = n
        return " "

    raw = _SEM_RE.sub(_take_semesters, raw)

    found: dict[str, int | None] = {}      # key → years (None = not stated)
    order: list[str] = []                  # keys in order of appearance
    last: str | None = None                # last institution seen
    pending: int | None = None             # a number seen before any institution

    for m in _SCANNER.finditer(raw.lower()):
        key = m.lastgroup
        if key == "num":
            year = int(m.group())
            if not 1 <= year <= _MAX_YEARS:
                continue
            if last is None:
                pending = year
            elif found.get(last) is None:
                found[last] = year
            continue
        key = _ALIASES.get(key, key)
        if key not in found:
            found[key] = None
            order.append(key)
        last = key
        if pending is not None:
            if found[key] is None:
                found[key] = pending
            pending = None

    if not found:
        return None

    # ── the ordinal: highest institution attended ─────────────────────────
    scored = [k for k in found if INSTITUTIONS[k][2] is not None]

    # ``střední`` names the *level* when the record does not name the school.
    # It yields to any school actually named on rung 3 or above, so
    # "střední hosp. škola" is an agricultural Fachschule rather than an
    # unspecified academic one — the head-noun-swallows-the-qualifier shape
    # D-29 removed from `occupations.py`.  With nothing else post-compulsory in
    # the record ("ob., střední") it stands on its own.
    if "secondary" in scored and any(
            INSTITUTIONS[k][2] >= 3 for k in scored if k != "secondary"):
        scored = [k for k in scored if k != "secondary"]

    apprentice = any(INSTITUTIONS[k][3] == "continuation" for k in found)
    top_imputed = False

    if scored:
        top = max(scored, key=lambda k: (INSTITUTIONS[k][2], _TIE_RANK[k]))
        ordinal = INSTITUTIONS[top][2]
    elif apprentice:
        # A continuation school followed the eight compulsory years, so the
        # record implies elementary schooling even when it names none.  A
        # floor, never a promotion — and flagged, because `educ_top` then names
        # a school `educ_institutions` does not list.
        top, ordinal, top_imputed = "elementary", 1, True
    else:
        return None

    name, _, _, track, standard = INSTITUTIONS[top]
    if top_imputed:
        # The only school this man is recorded as attending is the
        # Fortbildungsschule.  The rung is imputed; the track is not.
        track = "continuation"

    # ── years ─────────────────────────────────────────────────────────────
    years = {"elementary": None, "burgher": None,
             "continuation": None, "secondary": None}
    for key, val in found.items():
        slot = _YEAR_SLOT.get(key)
        if slot is not None:
            if years[slot] is None:
                years[slot] = val
        elif key == top and INSTITUTIONS[key][2] is not None and (
                INSTITUTIONS[key][2] >= 3):
            years["secondary"] = val
    # ── completion of the top rung ────────────────────────────────────────
    # ``top == "elementary"`` implies the record names no Bürgerschule — it
    # outranks the Volksschule and would have become `top` itself, so the
    # five-year variant was unreachable (measured: 0 records).  The standard
    # here is always the full eight years (Moore p. 30); Volksschule 5 +
    # Bürgerschule 3 is scored under ``top == "burgher"`` against its own 3.
    if top == "elementary":
        standard = 8
    slot = _YEAR_SLOT.get(top, "secondary")
    stated = years.get(slot)
    if standard is None or stated is None:
        complete: object = pd.NA
    else:
        complete = bool(stated >= standard)

    return {
        "educ_clean":              EDUC_ORDER[ordinal],
        "educ_ord":                ordinal,
        "educ_track":              track if ordinal > 0 else "none",
        "educ_apprentice":         apprentice,
        "educ_top":                top,
        "educ_institutions":       "|".join(
            sorted(order, key=lambda k: (INSTITUTIONS[k][2] is None,
                                         INSTITUTIONS[k][2] or 0))),
        "educ_years_elementary":   years["elementary"],
        "educ_years_burgher":      years["burgher"],
        "educ_years_continuation": years["continuation"],
        "educ_years_secondary":    years["secondary"],
        "educ_semesters":          semesters,
        "educ_complete":           complete,
        "educ_top_imputed":        top_imputed,
    }

def add_education_column(df: pd.DataFrame,
                         source_col: str = "Vzdělání",
                         ) -> pd.DataFrame:
    """Append the parsed education columns (see the module docstring).

    Args:
        df:         input DataFrame (not modified in place)
        source_col: raw education column name

    Returns:
        DataFrame with the education columns appended.
    """
    df = df.copy()
    parsed = df[source_col].apply(parse_education)
    blank = {c: None for c in _COLUMNS}
    frame = pd.DataFrame(
        [p if p is not None else blank for p in parsed],
        index=df.index,
    )
    for col in _INT_COLUMNS:
        frame[col] = frame[col].astype("Int8")
    for col in _BOOL_COLUMNS:
        frame[col] = frame[col].astype("boolean")
    for col in _COLUMNS:
        df[col] = frame[col]
    return df

def education_selftest() -> list[str]:
    """Return a list of behaviours that regressed; empty means all hold."""
    failures: list[str] = []
    for raw, field, expected in _SELFTEST:
        got = parse_education(raw)
        if field is None:
            if got is not None:
                failures.append(f"{raw!r} should not parse, got {got['educ_top']}")
            continue
        if got is None:
            failures.append(f"{raw!r} did not parse at all")
        elif got[field] != expected:
            failures.append(f"{raw!r}: {field} = {got[field]!r}, expected {expected!r}")
    return failures

def ladder_report() -> None:
    """Print the ladder and every institution that sits on each rung."""
    print("The Austrian school ladder, 1869–1918 "
          "(Reichsvolksschulgesetz 14 May 1869)")
    print("Sources: Moore 2020 (general), Lassnigg 2015 (vocational), and — since "
          "2026-09-07 —\n"
          "         Österreichische Statistik XCIII/1 (1908/09), the administration's own "
          "school\n"
          "         census, which confirms this taxonomy and the exclusion below.\n"
          "         reference/EDUCATION_LADDER.md · reference/VALIDATION_EDUCATION.md\n")
    for level, label in enumerate(EDUC_ORDER):
        members = [k for k, v in INSTITUTIONS.items() if v[2] == level]
        print(f"  {level}  {label}")
        for key in members:
            name, native, _, track, standard = INSTITUTIONS[key]
            std = f"{standard} yrs" if standard else "length not established"
            print(f"        {name:<28} {native:<44} {track:<12} {std}")
    print("\n  –  Off the ordinal (compulsory, part-time, selects on nothing)")
    for key, v in INSTITUTIONS.items():
        if v[2] is None:
            print(f"        {v[0]:<28} {v[1]:<44} {v[3]:<12} "
                  "length not established")
    print("\n  Recorded as `educ_apprentice`, never as a rung: raising the "
          "ordinal for a\n  continuation school is the v1.0.0 defect this "
          "rewrite exists to remove.")

def education_report(df: pd.DataFrame) -> None:
    """Print the distribution of the parsed education variables."""
    if "educ_clean" not in df.columns:
        print("No educ_clean column. Run add_education_column() first.")
        return
    total = len(df)
    print(f"Education ({total:,} records)")

    counts = (df["educ_clean"].value_counts()
              .reindex(EDUC_ORDER).fillna(0).astype(int))
    print("\n  Ladder (highest institution attended)")
    for label, n in counts.items():
        print(f"    {label:<24} {n:>7,}  ({n / total:.1%})")
    null_n = int(df["educ_clean"].isna().sum())
    print(f"    {'Missing/unparsed':<24} {null_n:>7,}  ({null_n / total:.1%})")

    print("\n  Track")
    for label, n in df["educ_track"].value_counts().items():
        print(f"    {label:<24} {n:>7,}  ({n / total:.1%})")

    app = int(df["educ_apprentice"].fillna(False).sum())
    print(f"\n  Apprentice continuation school   {app:>7,}  "
          f"({app / total:.1%})   ← never raises educ_ord")
    imp = int(df["educ_top_imputed"].fillna(False).sum())
    print(f"  educ_top imputed (floor only)    {imp:>7,}  "
          f"({imp / total:.1%})   <- absent from educ_institutions")

    print("\n  Years (median where stated)")
    for col, name in (("educ_years_elementary", "elementary"),
                      ("educ_years_burgher", "burgher"),
                      ("educ_years_continuation", "continuation"),
                      ("educ_years_secondary", "secondary")):
        s = df[col].dropna()
        med = f"{s.median():.0f}" if len(s) else "—"
        print(f"    {name:<24} n={len(s):>6,}  median {med}")

    sem = df["educ_semesters"].dropna()
    n_sem = len(sem)
    med = f"{sem.median():.0f}" if n_sem else "-"
    print(f"\n  Semesters stated                 {n_sem:>7,}  "
          f"median {med}   <- kept out of the year columns")

    comp = df["educ_complete"]
    print(f"\n  Top rung completed   True {int((comp == True).sum()):,}   "
          f"False {int((comp == False).sum()):,}   "
          f"not established {int(comp.isna().sum()):,}")

"""
education.py — the Austrian school ladder, parsed rather than classified
========================================================================
``Vzdělání`` is **not a level**.  It is an *itinerary*: a sequence of school
types, each optionally followed by the number of years completed
(``ob. 5 mě. 3 pok. 3`` = five years Volksschule, three Bürgerschule, three
years of the apprentices' continuation school).  v1.0.0 collapsed the string
with first-match substring rules and got the ladder wrong in three places; this
module tokenises the itinerary instead and reports the highest rung reached,
the years spent at each, and the track.

The ladder below is the settlement of the **Reichsvolksschulgesetz** of 14 May
1869, still standing in 1914 — the law under which every man in the sample was
schooled (birth cohorts ≈ 1875–1900).  Sources and page citations live in
``reference/EDUCATION_LADDER.md``:

* Moore (2020) *Teaching the Empire* — the general ladder.  Compulsory
  schooling is ages 6–14, reached as ``ob. 5`` + ``mě. 3``; Gymnasium (8 yrs)
  and Realschule (7 yrs) are entered at **age ten, in parallel with** the
  Bürgerschule, not after it; the Lehrerbildungsanstalt is entered *from* the
  Bürgerschule at fifteen and is deliberately not an academic track.
* Lassnigg (2015) IHS WP 108 — the vocational branch.  The *pokračovací*
  (gewerbliche **Fortbildungsschule**) was legally **part of compulsory mass
  schooling**, governed communally alongside the Volksschule, and it selected
  on *nothing*: apprenticeship required no educational credential, and the
  school obligation followed the contract.  The full-time vocational schools
  (``obch.``, ``prům.``, ``odb.``, ``hosp.``) required Bürgerschule grades plus
  an entrance exam, so they do sit above it.

Three consequences, and they are the whole point of the rewrite:

1. ``pok.`` **does not raise the ordinal.**  It is recorded as a track flag
   (``educ_apprentice``, 8,815 records) and a year count.  Under v1.0.0 it
   scored *Upper secondary*, putting 8,117 records — the classic apprentice
   itinerary — in the same bucket as ``gym.``
2. ``uč.ústav`` sits one rung below the Matura tracks, not level with them.
3. The ordinal is **highest institution attended**, not "level achieved".
   Completion is a separate, explicitly missing-able column, because a bare
   ``reálka`` does not say whether the man finished.

Two limits, both inherited from the sources and both documented in
``EDUCATION_LADDER.md`` §5:

* **Duration is unknown for the vocational rungs.**  Fortbildungsschule hours
  and Fachschule course lengths varied by Land and trade (regional laws
  1907–1931), so ``educ_complete`` is ``pd.NA`` for them rather than guessed,
  and no ``educ_years_total`` is emitted.  Do not sum the year columns.
* **Cisleithania only.**  Both sources are silent on Hungary, whose schools the
  Ausgleich handed to Budapest (Eötvös 1868, Apponyi 1907).  Slovak and Rusyn
  births are parsed on the same tokens because the *strings* are Czech, but the
  ordinal is not established for them — interact it with a
  Cisleithanian/Transleithanian indicator, the way ``birth_okres`` and
  ``birth_jaras`` are kept apart.

What 2.1.0 changed
------------------
* **Every institution must start at a word start.**  The scan was an unanchored
  substring test, so ``technik`` matched inside *hydrotechnika* and ``ob``
  inside *pob.* — the shape `ranks` 1.4.0 had to remove after Fidler caught
  ``generálmajor`` scoring as ``major``.  The number group stays unanchored so
  "reálka4" still yields 4.
* **Ties on the top rung are broken by a written rule**, :data:`TIE_BREAK`
  (D-51).  1,512 records name two schools on one rung, and ``max`` alone
  resolved them by which one the clerk wrote first — the same pair landing both
  ways.
* **Semesters are not years.**  ``sem.``/``semestr`` and its number are lifted
  out into ``educ_semesters`` (722 records) before the itinerary is scanned;
  they used to be written into ``educ_years_secondary`` as if they were years.
* **``střední`` yields to a named school.**  It states the *level*, not the
  school, so "stř. hosp. škola" is an agricultural Fachschule (83 records).
* **The imputed rung is flagged.**  Where only a continuation school is named
  the ordinal is floored at Elementary; those 1,112 records now carry
  ``educ_top_imputed`` and the track ``continuation``, because ``educ_top``
  there names a school ``educ_institutions`` does not list.

Usage
-----
    from utils.parsing.education import add_education_column, education_report
    df = add_education_column(df)
    education_report(df)
    ladder_report()          # prints the ladder and what sits on each rung

Columns added
-------------
``educ_clean``            ordinal label (back-compat name; → ``education``)
``educ_ord``              0–5, highest institution **attended**
``educ_track``            compulsory / vocational / academic / teacher / …
``educ_apprentice``       attended a continuation school (Fortbildungsschule)
``educ_top``              canonical key of the highest institution
``educ_top_imputed``      True where the rung is the apprentice floor, not a
                          school the record names
``educ_institutions``     every institution found, in ladder order (audit)
``educ_years_elementary`` years at ``ob.``
``educ_years_burgher``    years at ``mě.``
``educ_years_continuation`` years at ``pok.``
``educ_years_secondary``  years at the highest post-compulsory institution
``educ_semesters``        semesters stated (tertiary records); never a year
``educ_complete``         finished the top rung's standard course (NA if the
                          standard length is not established — see above)
"""

# key → (English name, German/Czech institution, ordinal, track, standard years)

# ── The within-rung tie-break ─────────────────────────────────────────────
# 1,512 records name two institutions on the same rung.  ``max`` alone breaks
# that tie by order of appearance in the string, so the same pair resolved both
# ways — `obch.` + `odb.` gave *trade* on 164 records and *commercial* on 20.
# The order below is the stated rule (D-51); it is a judgement, not a fact, and
# the repo's convention (D-22, D-23) is that a tie is broken by a written rule
# or refused.  Two principles, in this order:
#
#   1. **A generic term yields to a specific one.**  ``odb.`` (*odborná* =
#      "specialised") and ``střední`` ("secondary") are the words the source
#      uses when it does not name the school — "odborná hospodářská škola" is
#      one school, not two.  They lose to any school the record actually names.
#   2. **The terminal professional school outranks the general school that
#      feeds it.**  A man who wrote "reálka, uč.ústav" finished as a teacher;
#      the Lehrerbildungsanstalt is his endpoint and the thing that fixes his
#      track.  Same for the cadet school, the commercial academy and the
#      conservatory.  This agrees with reading the field as an itinerary, which
#      92.4 % of multi-rung records support (ordinals never fall along the
#      string).
#
# Within rung 3's specific schools, and within rung 5, no principle separates
# the members and no record in the data ties them; the order there is a
# convention, recorded so it is at least deterministic.
TIE_BREAK: tuple[str, ...] = (
    "no_school", "illiterate",                                    # rung 0
    "elementary",                                                 # rung 1
    "burgher",                                                    # rung 2
    "trade",                                                      # rung 3 — generic
    "agricultural", "industrial", "commercial",                   # rung 3 — named
    "secondary",                                                  # rung 4 — generic
    "realschule", "gymnasium",                                    # rung 4 — general
    "conservatory", "industrial_higher", "commercial_academy",    # rung 4 — terminal
    "cadet", "teacher",
    "seminary", "technical", "university",                        # rung 5
    "continuation", "continuation_ind",                           # off the ordinal
)
_TIE_RANK = {key: i for i, key in enumerate(TIE_BREAK)}
assert set(_TIE_RANK) == set(INSTITUTIONS), (
    "TIE_BREAK must name every institution exactly once")

# Which year column each institution feeds.
_YEAR_SLOT = {
    "elementary": "elementary",
    "burgher": "burgher",
    "continuation": "continuation",
    "continuation_ind": "continuation",
}


# ═══════════════════════════════════════════════════════════════════════════
# Tokeniser
# ═══════════════════════════════════════════════════════════════════════════
# Letters only — never ``\w``, which would swallow the year digits in
# "reálka4" and let "ob" match the "obch" of *obchodní*.
_L = r"[^\W\d_]"

# Ordered most-specific-first.  Python alternation is leftmost-then-first-listed,
# so "pok.prům." beats "pok.", "obch.ak." beats "obch.", and "vyšší prům."
# beats "prům." — while the scan still runs left to right across the string.
_PATTERNS: list[tuple[str, str]] = [
    ("continuation_ind",   rf"pok{_L}*\.?\s*(?:prům|průmyslov){_L}*"),
    ("commercial_academy", rf"obch{_L}*\.?\s*ak{_L}*|ak{_L}*\.?\s*obch{_L}*"
                           rf"|obchod{_L}*\.?\s*akad{_L}*"),
    ("industrial_higher",  rf"(?:vyšší|vyš\.)\s*\.?\s*(?:prům|průmyslov){_L}*"),
    ("teacher",            rf"uč{_L}*\.?\s*úst{_L}*|učitelsk{_L}*\s*ústav{_L}*"),
    # ``fak{_L}*`` covers the abbreviation the source actually uses — "lék.fak.",
    # "fil.fak.", "práv.fak." — which the three narrow alternatives it replaces
    # all missed.  The acronyms are the university by name (UK, FF UK).
    ("university",         rf"univ{_L}*|vysok{_L}*\s*škol{_L}*|vš(?!{_L})"
                           rf"|fak{_L}*|filozofick{_L}*"
                           rf"|ffuk|uk(?!{_L})|ff(?!{_L})"),
    # Every word order the register uses for the Technische Hochschule.  Without
    # the "vysoká"-first alternatives, "vysoká technická" and "vys.šk.technická"
    # matched no institution at all and the record went unparsed.
    ("technical",          rf"technik{_L}*|pol[yi]techni{_L}*|čvut|vut(?!{_L})"
                           rf"|technick{_L}*\s*(?:vysok{_L}*|vš)"
                           rf"|(?:vysok{_L}*|vyšší|vys\.|vš\.?)\s*(?:(?:škol|šk\.|učen){_L}*\s*)?"
                           rf"technick{_L}*"),
    ("seminary",           rf"bohoslov{_L}*|seminá{_L}*|kněžsk{_L}*"),
    ("conservatory",       rf"konzerv{_L}*|umprum|akadem{_L}*\s*výtvarn{_L}*"),
    ("cadet",              rf"kadet{_L}*|vojensk{_L}*\s*(?:škol|akadem){_L}*"
                           rf"|důstojnick{_L}*"),
    ("continuation",       rf"pok{_L}*"),
    ("commercial_academy2", rf"obchodní\s*akadem{_L}*"),
    ("commercial",         rf"obch{_L}*|obchod{_L}*"),
    ("industrial",         rf"prům{_L}*|průmyslov{_L}*"),
    ("trade",              rf"odb{_L}*|učiliště|lesnick{_L}*"),
    ("agricultural",       rf"hosp{_L}*|zeměděl{_L}*|rolnick{_L}*\s*škol{_L}*|selsk{_L}*"),
    ("gymnasium",          rf"gym{_L}*"),
    ("realschule",         rf"reál{_L}*"),
    ("secondary",          rf"středn{_L}*|stř\.\s*šk{_L}*|stř\."),
    ("burgher",            rf"mě[šs][ťt]{_L}*|mě(?!{_L})"),
    ("elementary",         rf"ob(?!{_L})|obecn{_L}*|nár{_L}*\.?\s*šk{_L}*"
                           rf"|národní\s*škol{_L}*"),
    ("illiterate",         rf"analfab{_L}*|negram{_L}*"),
    ("no_school",          rf"žádn{_L}*|bez\s*vzděl{_L}*"),
]

# ``commercial_academy2`` exists only so the two-word spelling can sit *after*
# the greedy ``obch`` alternatives without shadowing them; it is folded back.
_ALIASES = {"commercial_academy2": "commercial_academy"}

# Every institution must begin at a word start.  Without the lookbehind,
# ``technik{_L}*`` matched inside *polytechnika* and ``fak{_L}*`` would match
# inside any word ending in "…fak…" — the unanchored-substring shape that
# `ranks` 1.4.0 had to fix after Fidler caught `generálmajor` scoring as
# `major`.  The number group is deliberately NOT anchored: "reálka4" must
# still yield 4.
_WORD_START = r"(?<![^\W\d_])"

_SCANNER = re.compile(
    "|".join(f"(?P<{key}>{_WORD_START}(?:{pat}))" for key, pat in _PATTERNS)
    + r"|(?P<num>\d{1,2})",
    re.IGNORECASE,
)

# Semesters are not years.  "technika 4 sem." is four *semesters* at the
# Technische Hochschule; the bare digit attached backwards to the institution
# and was written into `educ_years_secondary` as if it were years, on 719
# records.  The count is pulled out and the whole span removed before the
# itinerary is scanned, so no year column can inherit it.
_SEM_RE = re.compile(
    rf"(?:(\d{{1,2}})\s*\.?\s*(?:semestr{_L}*|sem)(?!{_L})"
    rf"|(?:semestr{_L}*|sem)(?!{_L})\.?\s*(\d{{1,2}}))",
    re.IGNORECASE,
)

_MAX_SEMESTERS = 20

_PLACEHOLDERS = {"", "?", "-", "–", "—", ".", "neuvedeno", "nezjištěno"}

_MAX_YEARS = 12   # anything larger is a stray number, not a course length


def parse_education(s: object) -> dict[str, object] | None:
    """Tokenise one ``Vzdělání`` string into its itinerary.

    Returns ``None`` for null / placeholder values and for strings in which no
    institution is recognised (the ~1 % tail of abbreviations and stray
    occupation text).  Otherwise a dict with the columns listed in the module
    docstring.

    Year numbers attach **backwards** to the institution they follow
    (``ob. 5``), and forwards when the string opens with a number (``8 ob.``,
    ``3mě``).  The first year seen for an institution wins.
    """
    if s is None or (isinstance(s, float) and pd.isna(s)) or pd.isna(s):
        return None
    raw = str(s).strip()
    if raw.lower() in _PLACEHOLDERS:
        return None

    semesters: int | None = None

    def _take_semesters(m: "re.Match[str]") -> str:
        nonlocal semesters
        val = m.group(1) or m.group(2)
        if val is not None and semesters is None:
            n = int(val)
            if 1 <= n <= _MAX_SEMESTERS:
                semesters = n
        return " "

    raw = _SEM_RE.sub(_take_semesters, raw)

    found: dict[str, int | None] = {}      # key → years (None = not stated)
    order: list[str] = []                  # keys in order of appearance
    last: str | None = None                # last institution seen
    pending: int | None = None             # a number seen before any institution

    for m in _SCANNER.finditer(raw.lower()):
        key = m.lastgroup
        if key == "num":
            year = int(m.group())
            if not 1 <= year <= _MAX_YEARS:
                continue
            if last is None:
                pending = year
            elif found.get(last) is None:
                found[last] = year
            continue
        key = _ALIASES.get(key, key)
        if key not in found:
            found[key] = None
            order.append(key)
        last = key
        if pending is not None:
            if found[key] is None:
                found[key] = pending
            pending = None

    if not found:
        return None

    # ── the ordinal: highest institution attended ─────────────────────────
    scored = [k for k in found if INSTITUTIONS[k][2] is not None]

    # ``střední`` names the *level* when the record does not name the school.
    # It yields to any school actually named on rung 3 or above, so
    # "střední hosp. škola" is an agricultural Fachschule rather than an
    # unspecified academic one — the head-noun-swallows-the-qualifier shape
    # D-29 removed from `occupations.py`.  With nothing else post-compulsory in
    # the record ("ob., střední") it stands on its own.
    if "secondary" in scored and any(
            INSTITUTIONS[k][2] >= 3 for k in scored if k != "secondary"):
        scored = [k for k in scored if k != "secondary"]

    apprentice = any(INSTITUTIONS[k][3] == "continuation" for k in found)
    top_imputed = False

    if scored:
        top = max(scored, key=lambda k: (INSTITUTIONS[k][2], _TIE_RANK[k]))
        ordinal = INSTITUTIONS[top][2]
    elif apprentice:
        # A continuation school followed the eight compulsory years, so the
        # record implies elementary schooling even when it names none.  A
        # floor, never a promotion — and flagged, because `educ_top` then names
        # a school `educ_institutions` does not list.
        top, ordinal, top_imputed = "elementary", 1, True
    else:
        return None

    name, _, _, track, standard = INSTITUTIONS[top]
    if top_imputed:
        # The only school this man is recorded as attending is the
        # Fortbildungsschule.  The rung is imputed; the track is not.
        track = "continuation"

    # ── years ─────────────────────────────────────────────────────────────
    years = {"elementary": None, "burgher": None,
             "continuation": None, "secondary": None}
    for key, val in found.items():
        slot = _YEAR_SLOT.get(key)
        if slot is not None:
            if years[slot] is None:
                years[slot] = val
        elif key == top and INSTITUTIONS[key][2] is not None and (
                INSTITUTIONS[key][2] >= 3):
            years["secondary"] = val
    # ── completion of the top rung ────────────────────────────────────────
    # ``top == "elementary"`` implies the record names no Bürgerschule — it
    # outranks the Volksschule and would have become `top` itself, so the
    # five-year variant was unreachable (measured: 0 records).  The standard
    # here is always the full eight years (Moore p. 30); Volksschule 5 +
    # Bürgerschule 3 is scored under ``top == "burgher"`` against its own 3.
    if top == "elementary":
        standard = 8
    slot = _YEAR_SLOT.get(top, "secondary")
    stated = years.get(slot)
    if standard is None or stated is None:
        complete: object = pd.NA
    else:
        complete = bool(stated >= standard)

    return {
        "educ_clean":              EDUC_ORDER[ordinal],
        "educ_ord":                ordinal,
        "educ_track":              track if ordinal > 0 else "none",
        "educ_apprentice":         apprentice,
        "educ_top":                top,
        "educ_institutions":       "|".join(
            sorted(order, key=lambda k: (INSTITUTIONS[k][2] is None,
                                         INSTITUTIONS[k][2] or 0))),
        "educ_years_elementary":   years["elementary"],
        "educ_years_burgher":      years["burgher"],
        "educ_years_continuation": years["continuation"],
        "educ_years_secondary":    years["secondary"],
        "educ_semesters":          semesters,
        "educ_complete":           complete,
        "educ_top_imputed":        top_imputed,
    }


def clean_education(s: object) -> str | None:
    """Map one raw education string to its ordinal label (back-compat)."""
    parsed = parse_education(s)
    return None if parsed is None else str(parsed["educ_clean"])


_COLUMNS = ("educ_clean", "educ_ord", "educ_track", "educ_apprentice",
            "educ_top", "educ_top_imputed", "educ_institutions",
            "educ_years_elementary", "educ_years_burgher",
            "educ_years_continuation", "educ_years_secondary",
            "educ_semesters", "educ_complete")

_INT_COLUMNS = ("educ_ord", "educ_years_elementary", "educ_years_burgher",
                "educ_years_continuation", "educ_years_secondary",
                "educ_semesters")

_BOOL_COLUMNS = ("educ_apprentice", "educ_top_imputed", "educ_complete")


def add_education_column(df: pd.DataFrame,
                         source_col: str = "Vzdělání",
                         ) -> pd.DataFrame:
    """Append the parsed education columns (see the module docstring).

    Args:
        df:         input DataFrame (not modified in place)
        source_col: raw education column name

    Returns:
        DataFrame with the education columns appended.
    """
    df = df.copy()
    parsed = df[source_col].apply(parse_education)
    blank = {c: None for c in _COLUMNS}
    frame = pd.DataFrame(
        [p if p is not None else blank for p in parsed],
        index=df.index,
    )
    for col in _INT_COLUMNS:
        frame[col] = frame[col].astype("Int8")
    for col in _BOOL_COLUMNS:
        frame[col] = frame[col].astype("boolean")
    for col in _COLUMNS:
        df[col] = frame[col]
    return df

# Self-test
# ═══════════════════════════════════════════════════════════════════════════
# One case per behaviour this module exists to get right, checked in code
# rather than in a docstring, and run by the QA gate.  Same pattern as
# ``provenance.provenance_selftest``.
_SELFTEST: tuple[tuple[str, str, object], ...] = (
    # the v1.0.0 defect: the continuation school is not a rung
    ("ob. 5 mě. 3 pok. 3", "educ_top", "burgher"),
    ("ob. 5 mě. 3 pok. 3", "educ_apprentice", True),
    ("ob. 5 mě. 3 pok. 3", "educ_years_continuation", 3),
    # only a continuation school: the rung is floored and the floor is flagged
    ("pok. 3", "educ_ord", 1),
    ("pok. 3", "educ_top_imputed", True),
    ("pok. 3", "educ_track", "continuation"),
    # semesters are not years
    ("technika 4 sem.", "educ_semesters", 4),
    ("technika 4 sem.", "educ_years_secondary", None),
    ("gym. FFUK sem. 2", "educ_top", "university"),
    # the tie-break, both ways round in the string
    ("reálka obch.akademie", "educ_top", "commercial_academy"),
    ("obch.akademie reálka", "educ_top", "commercial_academy"),
    ("reálka uč.ústav", "educ_track", "teacher"),
    # a generic word yields to the school the record names
    ("stř. hosp. škola", "educ_top", "agricultural"),
    ("ob., střední", "educ_top", "secondary"),
    ("hosp. odb. škola", "educ_top", "agricultural"),
    # word-anchored: these matched mid-word before 2.1.0
    ("pob.", None, None),
    ("odb.elektrotechnická", "educ_ord", 3),
    # the abbreviations the source actually uses
    ("univ.", "educ_top", "university"),
    ("lék.fak.", "educ_ord", 5),
    ("vyš.prům.", "educ_ord", 4),
    # a year still attaches with no space
    ("reálka4", "educ_years_secondary", 4),
)


def education_selftest() -> list[str]:
    """Return a list of behaviours that regressed; empty means all hold."""
    failures: list[str] = []
    for raw, field, expected in _SELFTEST:
        got = parse_education(raw)
        if field is None:
            if got is not None:
                failures.append(f"{raw!r} should not parse, got {got['educ_top']}")
            continue
        if got is None:
            failures.append(f"{raw!r} did not parse at all")
        elif got[field] != expected:
            failures.append(f"{raw!r}: {field} = {got[field]!r}, expected {expected!r}")
    return failures

def ladder_report() -> None:
    """Print the ladder and every institution that sits on each rung."""
    print("The Austrian school ladder, 1869–1918 "
          "(Reichsvolksschulgesetz 14 May 1869)")
    print("Sources: Moore 2020 (general), Lassnigg 2015 (vocational), and — since "
          "2026-09-07 —\n"
          "         Österreichische Statistik XCIII/1 (1908/09), the administration's own "
          "school\n"
          "         census, which confirms this taxonomy and the exclusion below.\n"
          "         reference/EDUCATION_LADDER.md · reference/VALIDATION_EDUCATION.md\n")
    for level, label in enumerate(EDUC_ORDER):
        members = [k for k, v in INSTITUTIONS.items() if v[2] == level]
        print(f"  {level}  {label}")
        for key in members:
            name, native, _, track, standard = INSTITUTIONS[key]
            std = f"{standard} yrs" if standard else "length not established"
            print(f"        {name:<28} {native:<44} {track:<12} {std}")
    print("\n  –  Off the ordinal (compulsory, part-time, selects on nothing)")
    for key, v in INSTITUTIONS.items():
        if v[2] is None:
            print(f"        {v[0]:<28} {v[1]:<44} {v[3]:<12} "
                  "length not established")
    print("\n  Recorded as `educ_apprentice`, never as a rung: raising the "
          "ordinal for a\n  continuation school is the v1.0.0 defect this "
          "rewrite exists to remove.")


def education_report(df: pd.DataFrame) -> None:
    """Print the distribution of the parsed education variables."""
    if "educ_clean" not in df.columns:
        print("No educ_clean column. Run add_education_column() first.")
        return
    total = len(df)
    print(f"Education ({total:,} records)")

    counts = (df["educ_clean"].value_counts()
              .reindex(EDUC_ORDER).fillna(0).astype(int))
    print("\n  Ladder (highest institution attended)")
    for label, n in counts.items():
        print(f"    {label:<24} {n:>7,}  ({n / total:.1%})")
    null_n = int(df["educ_clean"].isna().sum())
    print(f"    {'Missing/unparsed':<24} {null_n:>7,}  ({null_n / total:.1%})")

    print("\n  Track")
    for label, n in df["educ_track"].value_counts().items():
        print(f"    {label:<24} {n:>7,}  ({n / total:.1%})")

    app = int(df["educ_apprentice"].fillna(False).sum())
    print(f"\n  Apprentice continuation school   {app:>7,}  "
          f"({app / total:.1%})   ← never raises educ_ord")
    imp = int(df["educ_top_imputed"].fillna(False).sum())
    print(f"  educ_top imputed (floor only)    {imp:>7,}  "
          f"({imp / total:.1%})   <- absent from educ_institutions")

    print("\n  Years (median where stated)")
    for col, name in (("educ_years_elementary", "elementary"),
                      ("educ_years_burgher", "burgher"),
                      ("educ_years_continuation", "continuation"),
                      ("educ_years_secondary", "secondary")):
        s = df[col].dropna()
        med = f"{s.median():.0f}" if len(s) else "—"
        print(f"    {name:<24} n={len(s):>6,}  median {med}")

    sem = df["educ_semesters"].dropna()
    n_sem = len(sem)
    med = f"{sem.median():.0f}" if n_sem else "-"
    print(f"\n  Semesters stated                 {n_sem:>7,}  "
          f"median {med}   <- kept out of the year columns")

    comp = df["educ_complete"]
    print(f"\n  Top rung completed   True {int((comp == True).sum()):,}   "
          f"False {int((comp == False).sum()):,}   "
          f"not established {int(comp.isna().sum()):,}")
