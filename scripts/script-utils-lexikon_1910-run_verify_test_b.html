How it works

The route of D-72 reads every apparatus crop twice, with Gemini 3.8 Flash (the reader of record) and Claude Haiku 5.5, and sends a claim only one of them makes to a verify call; DINOv3 (E3) names every boxed glyph beside them. D-97 measured what that call would face on the twelve gold pages: ≈ 115 disputed claims a pair, with Gemini right in ≈ 59 % of them. So the free alternative to the call is always side with Gemini, and D-98 wrote the bar Opus has to clear against it before anything was sent.

What is asked

The pair is the reader of record against the second reader, gemini38_r5atlasntg1 × haiku55nh_r5atlasg1, at settlement level on the entries both and the gold read (claim_sets). A part is sent when it holds

  • a disputed claim — one of the two makes it, the other does not (the 106 claims the D-98 bar is measured on), or
  • an agreed claim DINOv3 disagrees with on the reader of record's box (reported beside the bar; D-98 as amended).

One call per part. Each outlined mark is one question, which token is printed here?, among its options (options_for): the tokens the readers placed on it, DINOv3's, the same base with other brackets or letters (glyph_composites.csv) and the confusion partners measured on the other gold pages, plus none of these and cannot tell. The marks asked are those of the disputed claims, of the flagged agreed ones, and — at no extra call — the agreed marks DINOv3 leaves unconfirmed in a part that is sent anyway. A disputed claim the locator put no box on keeps a presence question: printed / not printed / cannot tell.

The call shows the symbol key the readers saw (cached with the instructions), the municipality's whole entry (1.3.0, entry_bands) — every line of it, in both sections and across a section break — with the asked marks outlined and numbered, each mark enlarged, and for every token on offer a reference card: the plate's glyph and up to two cuts of it from other gold pages. It is never told which reader made which claim.

claim_verdicts turns the answers back into presence per claim, so the D-98 measures are computed exactly as written. Effort low, Batch API (half price), prompt cache; three repeats, one batch each (each request carries the key as ≈ 0.9 MB of base64, and three repeats in one batch near the 256 MB cap).

The part arm (1.2.0, D-101)

--arm part asks one thing more of each outlined mark: whose mark is it? — an institution of the municipality as a whole (0), of a numbered part (its number), or the type mark of a part (type:&lt;name&gt;: the one mark after a part's name that says what kind of place it is — a mill, a manor farm, a hamlet), which is no institution at all. A mark Opus files under another part moves there; a type mark leaves the inventory. The parts and their type marks come from the readers' own parts lists, as they would in the volume run. Its answers, usage and report go to output/verify_test_b_part, beside the base arm's, never over them.

def disputes(human: list[dict], first: list[dict], second: list[dict],

def place_names(*passes: list[dict]) -> dict:
    """``{part: (municipality, part name)}`` from the gold first, then the readers."""
    names: dict = {}
    for rows in passes:
        for r in rows:

                              else ("", r["place_name"]))
            if muni or part:
                names[unit] = (muni, part)
    return names

def load_parts(labels=(FIRST, SECOND)) -> dict:
    """``{(page, district, muni): {"numbered": {seq: name}, "types": {token: [names]}}}``.

    From the readers' own parts lists (``parts_<label>.csv``), so the options are

    out: dict = {}
    for label in labels:
        hits = sorted(bo.BAKEOFF.glob(f"*/parts_{label}.csv"))
        for r in (_read_csv(hits[0]) if hits else []):
            key = (r["page"], _slug(r["district"]), str(r["muni_seq"]))

                entry["types"].setdefault(token, []).append(name)
    return out

def confusions(verdicts: list[dict]) -> dict:

    out: dict = defaultdict(Counter)
    for r in verdicts:
        claim, gold = r.get("claim", ""), r.get("gold", "")
        if claim.startswith("[") and gold.startswith("[") and claim != gold:
            out[r["scan"]][frozenset((claim, gold))] += 1
    return dict(out)

def options_for(placed: list[str], dino: list[str], scan: str, bases: dict,
                swaps: dict, vocabulary: set) -> list[str]:
    """The tokens one mark is offered, readers' first; never more than ``MAX_OPTIONS``.

    Same base: every vocabulary token built on the base of an offered token
    (``(school)`` beside ``[school]``, ``♁ H`` beside ``♁ A``).
    """
    seeds = [t for t in [*placed, *dino] if t in vocabulary]
    out: list[str] = []
    for token in seeds:
        if token not in out:
            out.append(token)
    for token in list(seeds):
        base = bases.get(token, token)
        out += [t for t in sorted(vocabulary)
                if bases.get(t, t) == base and t not in out]
    for token in list(seeds):
        out += [t for t in partners(token, scan, swaps) if t in vocabulary and t not in out]
    return out[:MAX_OPTIONS]

def key_starts(name: str) -> tuple[tuple[int, ...], int]:
    """``(tops of the lines that open an entry, image height)`` for one section image.

    A line opens a municipality when its first ink is a number in the key column —
    the rule ``build_token_review.municipality_bands`` uses (several inked columns
    there, so a sliver of the frame beside a heading does not count).
    """
    from PIL import Image

    import build_token_review as btr

    image = Image.open(image_path(name))
    lines = btr.text_lines(image)
    if not lines:
        return (), image.height
    ink = btr._text_ink(image)
    cut = min(x for _t, _b, x in lines) + btr.KEY_COLUMN_SHARE * image.width
    span = int(btr.KEY_INK_SHARE * image.width)

                   and (ink[top:bottom + 1, x:x + span].sum(axis=0) > 0).sum()
                   >= btr.KEY_MIN_COLUMNS)
    return starts, image.height

def entry_bands(unit: tuple, geo: dict) -> list[tuple[str, int, int]]:
    """``[(image, top, foot)]``: the municipality's whole entry, every line and image of it.

    Anchored on every box the two readers placed for the municipality, any part,
    so both sections are found, and bounded on each image by :func:`_limits`. An
    entry that reaches the top of an image with nothing above it began on the
    previous image of its section; one that reaches the foot carries on at the
    top of the next.
    """
    page, district, muni, _seq = unit
    placed = _reader_boxes(geo, page, district)
    bands: dict = {}

    def add(name: str, top: int, foot: int) -> None:
        old = bands.get(name)
        bands[name] = (min(top, old[0]), max(foot, old[1])) if old else (top, foot)

    def others(name: str) -> list:
        return [b for (img, mu), bs in placed.items() if img == name and mu != muni for b in bs]

    for (name, mu), boxes in placed.items():
        if mu != muni:
            continue
        top, foot = _limits(name, boxes, others(name))
        add(name, top, foot)
        m = _IMAGE_RE.match(name)
        chain = _section_images(m["page"], m["district"], m["section"])
        i = chain.index(name) if name in chain else -1
        height = key_starts(name)[1]
        if top == 0 and i > 0:                      # began on the previous image
            prev = chain[i - 1]
            prev_starts, prev_height = key_starts(prev)
            lowest = max((b[3] + 2 for b in others(prev)), default=0)
            add(prev, max([lowest, *prev_starts]), prev_height)
        if foot == height and 0 <= i < len(chain) - 1:   # carries on at the next
            nxt = chain[i + 1]
            next_starts, next_height = key_starts(nxt)
            highest = min((b[1] - 2 for b in others(nxt)), default=next_height)
            add(nxt, 0, min([highest, *next_starts]))
    # A margin each side: a glyph's foot pokes a few pixels past the next line's
    # top (3 of the 65 test-B entries lost one mark to it without this).
    # A continuation that found nothing on the next image leaves a sliver: dropped.
    return [(name, max(0, top - 8), min(key_starts(name)[1], foot + 10)) for name, (top, foot) in
            sorted(bands.items(), key=lambda kv: ("_parts_" not in kv[0],
                                                  int(_IMAGE_RE.match(kv[0])["k"])))
            if foot - top >= MIN_BAND]

        per_rep.append({
            "settled": settled / n if n else 0.0,
            "accuracy_settled": right / settled if settled else 0.0,

def gain_interval(claims: list[dict], answers: list[dict], draws: int = BOOTSTRAP,
                  seed: int = SEED) -> tuple[float, float]:
    """Page-clustered bootstrap of the gain over always-Gemini, 95 %."""
    by_page = defaultdict(list)
    for c in claims:
        by_page[c["page"]].append(c)
    pages, rng, gains = sorted(by_page), random.Random(seed), []
    for _ in range(draws):
        sample = [c for p in rng.choices(pages, k=len(pages)) for c in by_page[p]]
        gains.append(measures(sample, answers)["gain"])
    gains.sort()
    return gains[int(0.025 * draws)], gains[int(0.975 * draws) - 1]

"""Test B — does one Opus verify call settle what Gemini and Haiku dispute? (D-72, D-89, D-98)

The route of D-72 reads every apparatus crop twice, with Gemini 3.8 Flash (the
reader of record) and Claude Haiku 5.5, and sends a claim only one of them makes
to a verify call; DINOv3 (E3) names every boxed glyph beside them. D-97 measured
what that call would face on the twelve gold pages: ≈ 115 disputed claims a
pair, with Gemini right in ≈ 59 % of them. So the free alternative to the call is
**always side with Gemini**, and D-98 wrote the bar Opus has to clear against it
before anything was sent.

What is asked
-------------
The pair is the reader of record against the second reader,
``gemini38_r5atlasntg1`` × ``haiku55nh_r5atlasg1``, at settlement level on the
entries both and the gold read (:func:`claim_sets`). A part is sent when it holds

* a **disputed** claim — one of the two makes it, the other does not (the 106
  claims the D-98 bar is measured on), or
* an **agreed** claim DINOv3 **disagrees** with on the reader of record's box
  (reported beside the bar; D-98 as amended).

One call per part. Each **outlined mark** is one question, *which token is
printed here?*, among its options (:func:`options_for`): the tokens the readers
placed on it, DINOv3's, the same base with other brackets or letters
(``glyph_composites.csv``) and the confusion partners measured on the **other**
gold pages, plus ``none of these`` and ``cannot tell``. The marks asked are those
of the disputed claims, of the flagged agreed ones, and — at no extra call — the
agreed marks DINOv3 leaves unconfirmed in a part that is sent anyway. A disputed
claim the locator put no box on keeps a presence question: ``printed`` / ``not
printed`` / ``cannot tell``.

The call shows the symbol key the readers saw (cached with the instructions),
the municipality's **whole entry** (1.3.0, :func:`entry_bands`) — every line of
it, in both sections and across a section break — with the asked marks outlined
and numbered, each mark enlarged, and for every token on offer a reference card: the
plate's glyph and up to two cuts of it from other gold pages. It is never told
which reader made which claim.

:func:`claim_verdicts` turns the answers back into presence per claim, so the
D-98 measures are computed exactly as written. Effort ``low``, Batch API (half
price), prompt cache; three repeats, one batch each (each request carries the
key as ≈ 0.9 MB of base64, and three repeats in one batch near the 256 MB cap).

The ``part`` arm (1.2.0, D-101)
-------------------------------
``--arm part`` asks one thing more of each outlined mark: **whose mark is it?** —
an institution of the municipality as a whole (``0``), of a numbered part (its
number), or the *type mark* of a part (``type:<name>``: the one mark after a
part's name that says what kind of place it is — a mill, a manor farm, a
hamlet), which is no institution at all. A mark Opus files under another part
moves there; a type mark leaves the inventory. The parts and their type marks
come from the readers' own parts lists, as they would in the volume run. Its
answers, usage and report go to ``output/verify_test_b_part``, beside the base
arm's, never over them.

Usage
-----
    python utils/lexikon_1910/run_verify_test_b.py --dry-run    # build the items, price them; send nothing
    python utils/lexikon_1910/run_verify_test_b.py --submit     # one batch per repeat still missing

    python utils/lexikon_1910/run_verify_test_b.py --score      # the D-98 bar and the side tables
    python utils/lexikon_1910/run_verify_test_b.py --arm part --dry-run   # the same for the part arm

``--dry-run`` writes every item's images and prompt to ``output/verify_test_b/items``.
Paid calls belong on Heavyhorse6 (D-68); the notebook enforces that, this script

def claim_sets(human: list[dict], first: list[dict], second: list[dict],
               level: str = LEVEL) -> dict:
    """The gold and the two readers' claims on the entries all three read.

    A claim is ``(page, district, muni, part, token)``; ``claim[:4]`` is the part.
    """
    read = [lxin._claim_counts(rows, level) for rows in (human, first, second)]
    shared = read[0][0] & read[1][0] & read[2][0]
    truth, one, two = ({tuple(map(str, c)) for c in claims if c[:3] in shared}
                       for _entries, _units, claims in read)
    return {"truth": truth, "one": one, "two": two}


def disputes(human: list[dict], first: list[dict], second: list[dict],
             level: str = LEVEL) -> tuple[list[dict], dict]:
    """``(disputed claims, {part: agreed tokens})``.

    ``maker`` is ``first`` or ``second``; ``truth`` whether the gold has the claim.
    Presence only, as in ``second_reader``: on a disputed claim exactly one of the
    two is right.
    """
    s = claim_sets(human, first, second, level)
    out = [_claim_dict(c, "first" if c in s["one"] else "second", c in s["truth"])
           for c in sorted(s["one"] ^ s["two"])]
    agreed: dict = defaultdict(list)
    for c in sorted(s["one"] & s["two"]):
        agreed[c[:4]].append(c[4])
    return out, dict(agreed)


def _claim_dict(c: tuple, maker: str, truth: bool) -> dict:

def place_names(*passes: list[dict]) -> dict:

    names: dict = {}
    for rows in passes:
        for r in rows:
            unit = (r.get("page", ""), r.get("district", ""), str(r.get("muni_seq", "")),
                    str(r.get("settlement_seq") or lxin.WHOLE))

    return names


def load_parts(labels=(FIRST, SECOND)) -> dict:
    """``{(page, district, muni): {"numbered": {seq: name}, "types": {token: [names]}}}``.

    From the readers' own parts lists (``parts_<label>.csv``), so the options are
    what the volume run would have; the reader of record's name wins a clash.
    """
    from utils.lexikon_1910.lexikon_1910_pages import _slug

    out: dict = {}
    for label in labels:
        hits = sorted(bo.BAKEOFF.glob(f"*/parts_{label}.csv"))
        for r in (_read_csv(hits[0]) if hits else []):
            key = (r["page"], _slug(r["district"]), str(r["muni_seq"]))
            entry = out.setdefault(key, {"numbered": {}, "types": {}})
            name = (r.get("part_name") or "").strip()
            seq = str(r.get("settlement_seq") or lxin.WHOLE)
            if seq != lxin.WHOLE and name:
                entry["numbered"].setdefault(seq, name)
            token = (r.get("topographic") or "").strip()
            if token.startswith("[") and name and name not in entry["types"].get(token, []):
                entry["types"].setdefault(token, []).append(name)
    return out


def whose_options(unit: tuple, options: list[str], parts: dict) -> list[list[str]]:

                for name in entry["types"].get(token, [])]

def load_bases() -> dict:

def confusions(verdicts: list[dict]) -> dict:
    """``{scan: Counter({frozenset(pair): n})}``: the readers' swaps against the gold."""
    out: dict = defaultdict(Counter)
    for r in verdicts:
        claim, gold = r.get("claim", ""), r.get("gold", "")
        if claim.startswith("[") and gold.startswith("[") and claim != gold:
            out[r["scan"]][frozenset((claim, gold))] += 1
    return dict(out)


def partners(token: str, scan: str, swaps: dict) -> list[str]:
    """Tokens the readers took ``token`` for, or it for them, on the OTHER pages."""
    total: Counter = Counter()
    for other, pairs in swaps.items():
        if other != scan:
            total.update(pairs)
    hits = [(n, sorted(pair - {token})[0]) for pair, n in total.items()
            if token in pair and n >= PARTNER_MIN]
    return [t for _n, t in sorted(hits, key=lambda h: (-h[0], h[1]))]


def options_for(placed: list[str], dino: list[str], scan: str, bases: dict,
                swaps: dict, vocabulary: set) -> list[str]:
    """The tokens one mark is offered, readers' first; never more than ``MAX_OPTIONS``.

    Same base: every vocabulary token built on the base of an offered token
    (``(school)`` beside ``[school]``, ``♁ H`` beside ``♁ A``).
    """
    seeds = [t for t in [*placed, *dino] if t in vocabulary]
    out: list[str] = []
    for token in seeds:
        if token not in out:
            out.append(token)
    for token in list(seeds):
        base = bases.get(token, token)
        out += [t for t in sorted(vocabulary)
                if bases.get(t, t) == base and t not in out]
    for token in list(seeds):
        out += [t for t in partners(token, scan, swaps) if t in vocabulary and t not in out]
    return out[:MAX_OPTIONS]

def _box(text: str) -> tuple[int, int, int, int] | None:
    try:
        x0, y0, x1, y1 = (int(float(v)) for v in str(text).split(","))
        return x0, y0, x1, y1
    except ValueError:

def image_path(name: str) -> Path | None:
    for directory in _image_dirs():                    # never certification gold (D-55)

            return path

def band_of(image: str, muni: str, boxes: list, lines: dict) -> tuple[int, int]:
    """The rows of ``image`` that hold municipality ``muni`` and every box."""
    spans = lines.get((image, muni), [])
    tops = [y0 for y0, _y1, _lh in spans] + [b[1] for b in boxes]
    feet = [y1 for _y0, y1, _lh in spans] + [b[3] for b in boxes]
    lh = max([lh for *_s, lh in spans] or [60])
    return max(0, min(tops) - lh // 2), max(feet) + lh // 2


#: A section image of the gold: ``0076_duba_offices_2.png`` — the index runs on across
#: a page's sections, so a section that breaks over two images has consecutive ones.
_IMAGE_RE = re.compile(r"^(?P<page>\d{4})_(?P<district>.+)_(?P<section>parts|offices)_(?P<k>\d+)\.png$")


@functools.lru_cache(maxsize=None)
def key_starts(name: str) -> tuple[tuple[int, ...], int]:
    """``(tops of the lines that open an entry, image height)`` for one section image.

    A line opens a municipality when its first ink is a number in the key column —
    the rule ``build_token_review.municipality_bands`` uses (several inked columns
    there, so a sliver of the frame beside a heading does not count).
    """
    from PIL import Image

    import build_token_review as btr

    image = Image.open(image_path(name))
    lines = btr.text_lines(image)
    if not lines:
        return (), image.height
    ink = btr._text_ink(image)
    cut = min(x for _t, _b, x in lines) + btr.KEY_COLUMN_SHARE * image.width
    span = int(btr.KEY_INK_SHARE * image.width)
    starts = tuple(top for top, bottom, x in lines if x <= cut
                   and (ink[top:bottom + 1, x:x + span].sum(axis=0) > 0).sum()
                   >= btr.KEY_MIN_COLUMNS)
    return starts, image.height


def _section_images(page: str, district: str, section: str) -> list[str]:
    for directory in _image_dirs():                    # the first that holds any
        names = [p.name for p in directory.glob(f"{page}_{district}_{section}_*.png")]
        if names:
            return sorted(names, key=lambda n: int(_IMAGE_RE.match(n)["k"]))
    return []


def _reader_boxes(geo: dict, page: str, district: str) -> dict:
    """``{(image, muni): [boxes]}`` the two production readers placed on one page and district."""
    out: dict = defaultdict(list)
    for (label, u), rows in geo["rows"].items():
        if label in READER_LABELS and tuple(u[:2]) == (page, district):
            for r in rows:
                box = _box(r.get("box", ""))
                if box and _IMAGE_RE.match(r.get("image", "")):
                    out[(r["image"], str(u[2]))].append(box)
    return out


def _limits(name: str, boxes: list, others: list) -> tuple[int, int]:
    """``(top, foot)`` of one entry on one image, from both sides.

    The entry numbers say where entries open (:func:`key_starts`); the other
    municipalities' marks say where this one cannot be. The tighter of the two
    wins on each side, so an image whose numbers are not found (8 of the 42 gold
    images) is still bounded by its neighbours, and a neighbour with no marks is
    still bounded by its number.
    """
    starts, height = key_starts(name)
    first, last = min(b[1] for b in boxes), max(b[3] for b in boxes)
    key_top = max((t for t in starts if t <= first + 5), default=0)
    key_foot = min((t for t in starts if t > last), default=height)
    centre = lambda b: (b[1] + b[3]) / 2                              # noqa: E731
    near_top = max((b[3] + 2 for b in others if centre(b) < first), default=0)
    near_foot = min((b[1] - 2 for b in others if centre(b) > last), default=height)
    return max(key_top, near_top), min(key_foot, near_foot)


def entry_bands(unit: tuple, geo: dict) -> list[tuple[str, int, int]]:
    """``[(image, top, foot)]``: the municipality's whole entry, every line and image of it.

    Anchored on every box the two readers placed for the municipality, any part,
    so both sections are found, and bounded on each image by :func:`_limits`. An
    entry that reaches the top of an image with nothing above it began on the
    previous image of its section; one that reaches the foot carries on at the
    top of the next.
    """
    page, district, muni, _seq = unit
    placed = _reader_boxes(geo, page, district)
    bands: dict = {}

    def add(name: str, top: int, foot: int) -> None:
        old = bands.get(name)
        bands[name] = (min(top, old[0]), max(foot, old[1])) if old else (top, foot)

    def others(name: str) -> list:
        return [b for (img, mu), bs in placed.items() if img == name and mu != muni for b in bs]

    for (name, mu), boxes in placed.items():
        if mu != muni:
            continue
        top, foot = _limits(name, boxes, others(name))
        add(name, top, foot)
        m = _IMAGE_RE.match(name)
        chain = _section_images(m["page"], m["district"], m["section"])
        i = chain.index(name) if name in chain else -1
        height = key_starts(name)[1]
        if top == 0 and i > 0:                      # began on the previous image
            prev = chain[i - 1]
            prev_starts, prev_height = key_starts(prev)
            lowest = max((b[3] + 2 for b in others(prev)), default=0)
            add(prev, max([lowest, *prev_starts]), prev_height)
        if foot == height and 0 <= i < len(chain) - 1:   # carries on at the next
            nxt = chain[i + 1]
            next_starts, next_height = key_starts(nxt)
            highest = min((b[1] - 2 for b in others(nxt)), default=next_height)
            add(nxt, 0, min([highest, *next_starts]))
    # A margin each side: a glyph's foot pokes a few pixels past the next line's
    # top (3 of the 65 test-B entries lost one mark to it without this).
    # A continuation that found nothing on the next image leaves a sliver: dropped.
    return [(name, max(0, top - 8), min(key_starts(name)[1], foot + 10)) for name, (top, foot) in
            sorted(bands.items(), key=lambda kv: ("_parts_" not in kv[0],
                                                  int(_IMAGE_RE.match(kv[0])["k"])))
            if foot - top >= MIN_BAND]


def marks_of(unit: tuple, geo: dict, disputed: set, flagged_tokens: set) -> tuple[list, dict]:
    """``(marks to ask, {token: where the readers put it})`` for one part.

    A mark is asked when a disputed claim sits on it, when DINOv3 disagrees with
    the reader of record's agreed token there, or when DINOv3 leaves an agreed
    token on it unconfirmed (the part is sent anyway, so the question is free).
    """
    marks: dict = {}
    where: dict = defaultdict(lambda: {"boxes": set(), "unplaced": set()})
    for label in READER_LABELS:
        who = label
        for r in geo["rows"].get((label, unit), []):
            token, box = r["claim"], _box(r.get("box", ""))
            if not token.startswith("["):
                continue
            if box is None:
                where[token]["unplaced"].add(who)
                continue
            key = (r["image"], box)
            where[token]["boxes"].add(key)
            m = marks.setdefault(key, {"image": r["image"], "box": box, "placed": [],
                                       "dino": [], "ask": False})
            if token not in m["placed"]:
                m["placed"].append(token)
            if r["dino"].startswith("[") and r["dino"] not in m["dino"]:
                m["dino"].append(r["dino"])
            m["ask"] |= (token in disputed
                         or (token in flagged_tokens and label == READER_LABELS[0]
                             and r["verdict"] == "disagree")
                         or r["verdict"] in UNCONFIRMED)
    asked = sorted((m for m in marks.values() if m["ask"]),
                   key=lambda m: (m["image"], m["box"][1] // 40, m["box"][0]))
    return asked, {t: {"boxes": sorted(v["boxes"]), "unplaced": sorted(v["unplaced"])}
                   for t, v in where.items()}

def _fit(image, long_edge: int):
    scale = min(1.0, long_edge / max(image.size))
    if scale < 1.0:
        image = image.resize((round(image.width * scale), round(image.height * scale)))
    return image


def _to_height(image, height: int):
    return image.resize((max(1, round(image.width * height / image.height)), height))


def _row(images, gap: int = 24):
    """Images side by side on white, bottoms aligned."""
    from PIL import Image

    out = Image.new("RGB", (sum(i.width for i in images) + gap * (len(images) - 1),
                            max(i.height for i in images)), "white")
    x = 0
    for image in images:
        out.paste(image.convert("RGB"), (x, out.height - image.height))
        x += image.width + gap
    return out


def _font(size: int):
    from PIL import ImageFont

    try:
        return ImageFont.load_default(size=size)
    except TypeError:                                   # Pillow < 10.1
        return ImageFont.load_default()


def reference_card(token: str, page: str, gold: dict) -> tuple[object | None, int]:
    """The plate's glyph and up to two cuts from other pages; ``(image, cuts)``."""
    from PIL import Image

    pieces = []
    plate = SYMBOLS / f"{token.strip('[]')}.png"
    if plate.exists():
        pieces.append(_to_height(Image.open(plate).convert("RGB"), CARD_HEIGHT))
    seen = set()
    for r in sorted(gold.get(token, []), key=lambda r: (r["scan"], int(r["muni"]),
                                                       int(r["order"]))):
        if r["scan"] == page or r["scan"] in seen or len(seen) >= EXEMPLARS:
            continue
        path = image_path(r["image"])
        if path is None:
            continue
        x0, y0, x1, y1 = _box(r["composite_box"])
        pad = max(4, int(float(r["line_height"])) // 4)
        cut = Image.open(path).convert("RGB").crop((x0 - pad, y0 - pad, x1 + pad, y1 + pad))
        pieces.append(_to_height(cut, CARD_HEIGHT))
        seen.add(r["scan"])
    return (_row(pieces) if pieces else None), len(seen)


def _section_list(page: str, district: str, seq: str) -> list[str]:
    """The part's section images from the run's own sections first (D-120): the list of
    parts and the offices, **for every part** (1.9.0, D-130). A numbered part's
    institutions are printed in the offices section under its own ``n)``; shown the list
    of parts alone, Opus answered *not printed* or *cannot tell* on 19 of the German gold's
    true claims — "institution marks for part 1 are not in this parts listing"."""
    return _section_images(page, district, "parts") + _section_images(page, district, "offices")


def _band_images(unit: tuple, asked: list, geo: dict) -> tuple[list, str]:
    """The entry band of each image the asked marks sit on, marks outlined and numbered.

    Where the boxes are not trusted (:data:`BOXES` off: a German edition whose E3 failed
    its gate) no band is built from them — a band anchored on misplaced boxes can cut
    the entry — and the whole section is shown (D-120). The view is ``"none"`` when no
    image of the page is found at all: such a call must not be sent.
    """
    from PIL import Image, ImageDraw

    page, district, muni, seq = unit
    by_image = defaultdict(list)
    for k, m in enumerate(asked, 1):
        by_image[m["image"]].append((k, m["box"]))
    if BOXES:
        entry = entry_bands(unit, geo)
        if entry:
            return _entry_images(entry, by_image, muni), "entry"
        view, images = "band", list(by_image)
        if not images:
            images = sorted({img for (img, m) in geo["lines"] if m == muni
                             and img.startswith(f"{page}_{district}_")
                             and (seq == lxin.WHOLE or "_parts_" in img)})
    else:
        view, images = "section", []
    if not images:
        # The locator put no line of this entry anywhere: the whole section,
        # downscaled, and the question names the municipality.
        view, images = "section", _section_list(page, district, seq)
    parts, font = [], _font(44)
    for name in images:
        path = image_path(name)
        if path is None:
            continue
        scan = Image.open(path).convert("RGB")
        boxes = [b for _k, b in by_image.get(name, [])]
        top, foot = ((0, scan.height) if view == "section"
                     else band_of(name, muni, boxes, geo["lines"]))
        band = scan.crop((0, top, scan.width, foot))
        draw = ImageDraw.Draw(band)
        for k, (x0, y0, x1, y1) in by_image.get(name, []):
            draw.rectangle((x0 - 6, y0 - top - 6, x1 + 6, y1 - top + 6),
                           outline=OUTLINE, width=4)
            draw.text((x0 - 6, max(0, y0 - top - 50)), str(k), fill=OUTLINE, font=font)
        parts.append((_fit(band, LONG_EDGE),
                      f"The entry, from section image {name}; asked marks outlined and "
                      f"numbered." if view == "band" else
                      f"Section image {name}, whole: find municipality no. {muni}."))
    return parts, (view if parts else "none")


def _entry_images(entry: list, by_image: dict, muni: str) -> list:
    """One image a band of the whole entry, asked marks outlined and numbered."""
    from PIL import Image, ImageDraw

    parts, font = [], _font(44)
    for name, top, foot in entry:
        scan = Image.open(image_path(name)).convert("RGB")
        band = scan.crop((0, top, scan.width, foot))
        draw = ImageDraw.Draw(band)
        for k, (x0, y0, x1, y1) in by_image.get(name, []):
            draw.rectangle((x0 - 6, y0 - top - 6, x1 + 6, y1 - top + 6),
                           outline=OUTLINE, width=4)
            draw.text((x0 - 6, max(0, y0 - top - 50)), str(k), fill=OUTLINE, font=font)
        section = "list of parts" if "_parts_" in name else "offices and institutions"
        parts.append((_fit(band, LONG_EDGE),
                      f"Municipality no. {muni}, its whole entry in the {section} "
                      f"(section image {name})"
                      + ("; asked marks outlined and numbered." if by_image.get(name) else ".")))
    return parts


def _zoom(asked: list) -> list:
    from PIL import Image, ImageDraw

    parts = []
    for k, m in enumerate(asked, 1):
        path = image_path(m["image"])
        if path is None:
            continue
        scan = Image.open(path).convert("RGB")
        x0, y0, x1, y1 = m["box"]
        pad = max(20, (y1 - y0))
        left, top = max(0, x0 - 2 * pad), max(0, y0 - pad * 2 // 3)
        zoom = scan.crop((left, top, x1 + 2 * pad, y1 + pad * 2 // 3))
        ImageDraw.Draw(zoom).rectangle(
            (x0 - left - 5, y0 - top - 5, x1 - left + 5, y1 - top + 5),
            outline=OUTLINE, width=2)
        parts.append((_to_height(zoom, ZOOM_HEIGHT), f"Mark {k}, enlarged."))
    return parts


def build_item(unit: tuple, ctx: dict) -> dict:
    """Everything one call sends, apart from the cached key and instructions."""
    page, district, muni, seq = unit
    disputed = {c["code"] for c in ctx["disputed"].get(unit, [])}
    flagged_tokens = {c["code"] for c in ctx["flagged"].get(unit, [])}
    asked, where = marks_of(unit, ctx["geo"], disputed, flagged_tokens)
    if not BOXES:
        asked = []
    questions = []
    for k, m in enumerate(asked, 1):
        m["options"] = options_for(m["placed"], m["dino"], page, ctx["bases"],
                                   ctx["swaps"], ctx["vocabulary"])
        questions.append({"n": k, "kind": "mark", "image": m["image"],
                          "box": list(m["box"]), "placed": m["placed"],
                          "options": m["options"]})
        if ARM == "part":
            whose = whose_options(unit, m["options"], ctx["parts"])
            if whose:
                questions[-1]["whose"] = whose
    on_asked = {(m["image"], tuple(m["box"])) for m in asked}
    # A flagged token no outlined mark carries — the order rule's flag, with DINOv3
    # agreeing — is asked as a token question too (D-120): routed and never asked, it
    # cost a call and settled nothing.
    for token in sorted(disputed | flagged_tokens):
        spots = where.get(token, {"boxes": [], "unplaced": []})
        if spots["unplaced"] or not any(b in on_asked for b in spots["boxes"]):
            questions.append({"n": len(questions) + 1, "kind": "token", "token": token})
    parts, view = _band_images(unit, asked, ctx["geo"])
    parts += _zoom(asked)
    offered = sorted({t for q in questions for t in q.get("options", [q.get("token")])})
    for code in offered:
        card, cuts = reference_card(code, page, ctx["geo"]["gold"])
        if card is not None:
            parts.append((card, f"Reference for {code} ({ctx['english'].get(code, '')}): "
                                f"the key's glyph" + (f", then {cuts} cut(s) of it from "
                                                      f"other pages" if cuts else "") + "."))
    agreed = [t for t in ctx["agreed"].get(unit, []) if t not in flagged_tokens]
    return {"id": unit_id(unit), "unit": list(unit), "view": view,
            "questions": questions, "where": {t: {"boxes": [[img, list(b)] for img, b in v["boxes"]],
                                                  "unplaced": v["unplaced"]}
                                              for t, v in where.items()},
            "parts": parts,
            "question": _question_text(unit, questions, agreed, ctx)}


def _question_text(unit: tuple, questions: list, agreed: list, ctx: dict) -> str:
    page, district, muni, seq = unit
    muni_name, part_name = ctx["names"].get(unit, ("", ""))
    where = ("the municipality as a whole (part 0)" if seq == lxin.WHOLE
             else f"part {seq}" + (f", {part_name}" if part_name else ""))
    english = ctx["english"]
    lines = [f"Page {page}, district {district}, municipality no. {muni}"
             + (f" ({muni_name})" if muni_name else "") + f"; the marks of {where}.",
             "Marks not in question here: " + (", ".join(agreed) if agreed else "none") + ".",
             ""]
    for q in questions:
        if q["kind"] == "mark":
            opts = "; ".join(f"{t} ({english.get(t, '')})" for t in q["options"])
            lines.append(f"{q['n']}. Mark {q['n']}: which is printed there? "
                         f"{opts}; {NONE}; {UNSURE}."
                         + (" Whose mark is it? " + "; ".join(f'"{k}" = {label}'
                                                              for k, label in q["whose"])
                            + f'; "{UNSURE}".' if q.get("whose") else ""))
        else:
            lines.append(f"{q['n']}. Not outlined: is {q['token']} ({english.get(q['token'], '')}) "
                         f"printed for this part? {PRINTED}; {ABSENT}; {UNSURE}.")
    return "\n".join(lines)

def schema_for(vocabulary: set, whose: bool = False) -> dict:
    choices = sorted(vocabulary) + [NONE, UNSURE, PRINTED, ABSENT]
    fields = {"question": {"type": "integer"},
              "answer": {"type": "string", "enum": choices},
              "note": {"type": "string"}}
    if whose:
        fields["whose"] = {"type": "string"}
    return {
        "type": "object",
        "properties": {"answers": {"type": "array", "items": {
            "type": "object",
            "properties": fields,
            "required": list(fields),
            "additionalProperties": False}}},
        "required": ["answers"],
        "additionalProperties": False,
    }


def _png(image) -> str:
    buffer = io.BytesIO()
    image.save(buffer, format="PNG")
    return base64.standard_b64encode(buffer.getvalue()).decode("ascii")


def system_text(english: dict) -> str:
    head = SYSTEM_HEAD.replace("The tokens:\n", WHOSE_NOTE + "The tokens:\n") if ARM == "part" \
        else SYSTEM_HEAD
    return head + "\n".join(f"{code} — {text}" for code, text in sorted(english.items()))


def params_for(item: dict, system: str, atlas_b64: str, schema: dict) -> dict:
    """One request. Instructions and key are byte-identical in every call: cached."""
    content = [{"type": "image", "source": {"type": "base64", "media_type": "image/png",
                                            "data": atlas_b64}},
               {"type": "text", "text": "The key: every pictogram with its token.",
                "cache_control": {"type": "ephemeral"}}]
    for image, caption in item["parts"]:
        content.append({"type": "image", "source": {"type": "base64",
                                                    "media_type": "image/png",
                                                    "data": _png(image)}})
        content.append({"type": "text", "text": caption})
    content.append({"type": "text", "text": item["question"]})
    return {
        "model": MODEL, "max_tokens": MAX_TOKENS,
        "system": [{"type": "text", "text": system,
                    "cache_control": {"type": "ephemeral"}}],
        "output_config": {"effort": EFFORT,
                          "format": {"type": "json_schema", "schema": schema}},
        "messages": [{"role": "user", "content": content}],
    }


def image_tokens(image) -> int:
    """Claude's vision estimate: about one token per 750 px² after resizing."""
    w, h = image.size
    scale = min(1.0, 1568 / max(w, h))
    return round(w * scale * h * scale / 750)

def write_items(items: list[dict]) -> None:
    """Each item's images and questions on disk, and the manifest ``collect`` reads."""
    root = OUT / "items"
    root.mkdir(parents=True, exist_ok=True)
    manifest = []
    for item in items:
        folder = root / item["id"]
        folder.mkdir(exist_ok=True)
        for stale in folder.glob("*.png"):
            stale.unlink()
        for n, (image, _caption) in enumerate(item["parts"], 1):
            image.save(folder / f"{n:02d}.png")
        (folder / "prompt.txt").write_text(
            "\n".join(f"[{n:02d}.png] {c}" for n, (_i, c) in enumerate(item["parts"], 1))
            + "\n\n" + item["question"] + "\n", encoding="utf-8")
        # `shown`: what the call puts in front of Opus, by caption — an answer given to
        # other images is an answer to another question (run_frozen._retire_stale_answers)
        manifest.append({**{k: item[k] for k in ("id", "unit", "view", "questions", "where")},
                         "shown": [c for _i, c in item["parts"]]})
    (OUT / "items.json").write_text(json.dumps(manifest, indent=1), encoding="utf-8")
    print(f"  wrote {len(items)} items to {root.relative_to(ROOT)}")

    return anthropic.Anthropic(default_headers={"Accept-Encoding": "gzip, deflate"})


def _batches() -> list[dict]:
    return json.loads(BATCHES.read_text(encoding="utf-8")) if BATCHES.exists() else []

    return {r["custom_id"] for r in _read_csv(RAW)} if RAW.exists() else set()


def submit(repeats: int = REPEATS) -> list[str]:
    """One batch per repeat with anything unanswered and not already in flight."""
    built = build_all()
    write_items(built["items"])              # ``collect`` reads the manifest
    atlas_b64 = base64.standard_b64encode(ATLAS.read_bytes()).decode("ascii")
    done = _answered()
    in_flight = {cid for b in _batches() if not b.get("collected") for cid in b["ids"]}
    client, log, sent = _client(), _batches(), []
    for rep in range(1, repeats + 1):
        todo = [i for i in built["items"] if f"r{rep}-{i['id']}" not in done | in_flight]
        if not todo:
            continue
        requests = [{"custom_id": f"r{rep}-{i['id']}",
                     "params": params_for(i, built["system"], atlas_b64, built["schema"])}
                    for i in todo]
        batch = client.messages.batches.create(requests=requests)
        log.append({"id": batch.id, "repeat": rep, "ids": [r["custom_id"] for r in requests],
                    "model": MODEL, "effort": EFFORT, "host": bo.HOST,
                    "version": __version__, "collected": False})
        BATCHES.parent.mkdir(parents=True, exist_ok=True)
        BATCHES.write_text(json.dumps(log, indent=1), encoding="utf-8")
        sent.append(batch.id)
        print(f"  repeat {rep}: batch {batch.id}, {len(requests)} calls")
    if not sent:
        print("  nothing to send: every call is answered or in flight")
    return sent


def _append(path: Path, rows: list[dict]) -> None:
    if not rows:
        return
    new = not path.exists()
    with path.open("a", encoding="utf-8", newline="") as fh:
        writer = csv.DictWriter(fh, fieldnames=list(rows[0]))
        if new:
            writer.writeheader()
        writer.writerows(rows)


def _read_reply(message, item: dict) -> list[dict] | None:
    """One row per question; ``None`` when the reply is not the JSON asked for."""
    text = next((b.text for b in message.content if b.type == "text"), "")
    try:
        replies = {a["question"]: a for a in json.loads(text)["answers"]}
    except (ValueError, KeyError, TypeError):
        return None
    out = []
    for q in item["questions"]:
        reply = replies.get(q["n"], {"answer": UNSURE, "note": "no answer"})
        allowed = (q["options"] + [NONE, UNSURE] if q["kind"] == "mark"
                   else [PRINTED, ABSENT, UNSURE])
        answer = reply["answer"] if reply["answer"] in allowed else UNSURE
        whose = ""
        if q.get("whose"):
            keys = [k for k, _label in q["whose"]] + [UNSURE]
            whose = reply.get("whose", "") if reply.get("whose", "") in keys else UNSURE
        out.append({"question": q["n"], "answer": answer, "whose": whose,
                    "off_list": reply["answer"] not in allowed,
                    "note": reply.get("note", "")})
    return out


def collect() -> bool:
    """Fetch every ended batch not yet collected. ``True`` when none is pending."""
    manifest = {m["id"]: m for m in json.loads((OUT / "items.json").read_text(encoding="utf-8"))}
    client, log, pending = _client(), _batches(), False
    for entry in log:
        if entry.get("collected"):
            continue
        batch = client.messages.batches.retrieve(entry["id"])
        if batch.processing_status != "ended":
            counts = batch.request_counts
            print(f"  {entry['id']} (repeat {entry['repeat']}): {batch.processing_status}, "
                  f"{counts.processing} processing, {counts.succeeded} done")
            pending = True
            continue
        answers, usage, failed = [], [], []
        for result in client.messages.batches.results(entry["id"]):
            cid = result.custom_id
            if result.result.type != "succeeded":
                failed.append(f"{cid}: {result.result.type}")
                continue
            message = result.result.message
            u = message.usage
            usage.append({"custom_id": cid, "input": u.input_tokens, "output": u.output_tokens,
                          "cache_write": u.cache_creation_input_tokens or 0,
                          "cache_read": u.cache_read_input_tokens or 0,
                          "stop": message.stop_reason})
            item_id = cid.split("-", 1)[1]
            rows = _read_reply(message, manifest[item_id])
            if rows is None:
                failed.append(f"{cid}: unreadable reply ({message.stop_reason})")
                continue
            answers += [{"custom_id": cid, "repeat": entry["repeat"], "item": item_id, **r}
                        for r in rows]
        _append(RAW, answers)
        _append(USAGE, usage)
        entry["collected"] = True
        BATCHES.write_text(json.dumps(log, indent=1), encoding="utf-8")
        print(f"  {entry['id']} (repeat {entry['repeat']}): {len(usage)} answered"
              + (f", {len(failed)} failed — run --submit again to resend" if failed else ""))
        for line in failed[:10]:
            print("    ", line)
    return not pending

def claim_verdicts(manifest: list[dict], raw: list[dict]) -> list[dict]:
    """Presence per (repeat, part, token), from the answers to the part's questions.

    A token is ``printed`` when Opus names it at any mark of the part, or answers
    ``printed`` to its presence question. A token the readers placed is ``not
    printed`` when every box they put it on was asked and answered with something
    else — and ``printed`` (kept) when some box of it was not asked or it also
    sits unplaced, since the route only overturns what it asks about. A
    ``cannot tell`` on any of its boxes leaves it ``cannot tell``.

    The part arm (D-101): a mark Opus says belongs to another numbered part is
    ``printed`` there — a row keyed to that part — and counts here as answered
    otherwise; a mark it calls a part's *type mark* is no institution, here or
    anywhere. ``whose`` blank or ``cannot tell`` leaves the mark where it is.
    """
    by_q = defaultdict(dict)                     # (repeat, item) -> {n: (answer, whose)}
    for r in raw:
        by_q[(str(r["repeat"]), r["item"])][int(r["question"])] = (r["answer"],
                                                                   r.get("whose") or "")
    out, moved_rows = [], []
    items = {m["id"]: m for m in manifest}
    for (rep, item_id), replies in sorted(by_q.items()):
        item = items[item_id]
        seq = str(item["unit"][3])
        answers = {}                             # n -> what the mark is, for THIS part
        for n, (answer, whose) in replies.items():
            if whose.startswith("type:") or (whose not in ("", UNSURE, seq)):
                answers[n] = "elsewhere"
                if whose and not whose.startswith("type:") and answer.startswith("["):
                    moved_rows.append({"repeat": rep, "code": answer, "verdict": PRINTED,
                                       "item": unit_id(tuple(item["unit"][:3]) + (whose,))})
            else:
                answers[n] = answer
        marks = {(q["image"], tuple(q["box"])): q for q in item["questions"]
                 if q["kind"] == "mark"}
        chosen = {answers.get(q["n"]) for q in marks.values()}
        presence = {q["token"]: answers.get(q["n"], UNSURE) for q in item["questions"]
                    if q["kind"] == "token"}
        tokens = set(item["where"]) | {t for t in chosen if t and t.startswith("[")}
        for token in sorted(tokens):
            if token in chosen:
                verdict = PRINTED
            elif token in presence:
                verdict = presence[token]
            elif token not in item["where"]:
                continue
            else:
                spots = item["where"][token]
                boxes = [(img, tuple(b)) for img, b in spots["boxes"]]
                if spots["unplaced"] or any(b not in marks for b in boxes):
                    verdict = PRINTED                         # kept: not all asked
                elif any(answers.get(marks[b]["n"]) == UNSURE for b in boxes):
                    verdict = UNSURE
                else:
                    verdict = ABSENT
            out.append({"repeat": rep, "item": item_id, "code": token, "verdict": verdict})
    return out + moved_rows

def _says(verdict: str):
    return {PRINTED: True, ABSENT: False}.get(verdict)


def measures(claims: list[dict], answers: list[dict], repeats: int = REPEATS) -> dict:
    """The D-98 measures. ``answers`` rows carry ``repeat``, ``item``, ``code``, ``verdict``."""
    said = {(str(a["repeat"]), a["item"], a["code"]): _says(a["verdict"]) for a in answers}
    reps = sorted({str(a["repeat"]) for a in answers})[:repeats] or ["1"]
    per_rep = []
    for rep in reps:
        settled = right = route = 0
        err = {"first": [0, 0], "second": [0, 0]}         # [settled, decided the wrong way]
        for c in claims:
            opus = said.get((rep, unit_id(unit_of(c)), c["code"]))
            gemini = c["maker"] == "first"
            if opus is None:
                route += gemini == c["truth"]
                continue
            settled += 1
            right += opus == c["truth"]
            route += opus == c["truth"]
            right_side = "first" if gemini == c["truth"] else "second"
            err[right_side][0] += 1
            err[right_side][1] += opus != c["truth"]
        n = len(claims)
        per_rep.append({
            "settled": settled / n if n else 0.0,
            "accuracy_settled": right / settled if settled else 0.0,
            "route_gemini": route / n if n else 0.0,
            # Error where Gemini was right (Opus went Haiku's way) minus error
            # where Haiku was right (Opus went Gemini's way).
            "lean": ((err["first"][1] / err["first"][0] if err["first"][0] else 0.0)
                     - (err["second"][1] / err["second"][0] if err["second"][0] else 0.0)),
        })
    always = sum((c["maker"] == "first") == c["truth"] for c in claims) / len(claims)
    mean = {k: sum(r[k] for r in per_rep) / len(per_rep) for k in per_rep[0]}
    stable = sum(len({said.get((rep, unit_id(unit_of(c)), c["code"]), "missing")
                      for rep in reps}) == 1 for c in claims) / len(claims)
    return {**mean, "always_gemini": always, "gain": mean["route_gemini"] - always,
            "stable": stable, "repeats": len(reps), "claims": len(claims)}


def flagged_measures(flags: list[dict], answers: list[dict]) -> dict:
    """The agreed claims DINOv3 disagrees with: baseline *accept the agreement*."""
    said = {(str(a["repeat"]), a["item"], a["code"]): _says(a["verdict"]) for a in answers}
    reps = sorted({str(a["repeat"]) for a in answers}) or ["1"]
    rows = []
    for rep in reps:
        opus = [said.get((rep, unit_id(unit_of(c)), c["code"])) for c in flags]
        rows.append({
            "route": sum((o if o is not None else True) == c["truth"]
                         for o, c in zip(opus, flags)) / len(flags),
            "false_removed": sum(o is False and not c["truth"] for o, c in zip(opus, flags)),
            "true_removed": sum(o is False and c["truth"] for o, c in zip(opus, flags)),
            "unsure": sum(o is None for o in opus)})
    mean = {k: sum(r[k] for r in rows) / len(rows) for k in rows[0]}
    return {**mean, "claims": len(flags), "false": sum(not c["truth"] for c in flags),
            "accept": sum(c["truth"] for c in flags) / len(flags)}


def recovered(sets: dict, manifest: list[dict], raw: list[dict]) -> dict:
    """Tokens Opus names that neither reader made: in the gold (recovered) or not (invented).

    Only what Opus **chose** — a token picked at a mark, or ``printed`` to a
    presence question — counts as named. A token :func:`claim_verdicts` keeps
    because some box of it was not asked is the readers' claim, not Opus's; and
    E3 files a few marks under a part the inventories do not, so counting kept
    tokens would credit Opus with claims it never made (1.1.0 did: 157 a repeat).

    *Invented* is a token no reader placed at the part at all — in the
    inventories or in E3's rows. A part-type mark of the parts section (a part
    printed as a mill, a factory, a house group) is placed by the readers and
    boxed by E3 but is not an inventory claim, so confirming it is not an
    invention (1.1.1 counted those: 16 a repeat).
    """
    sent = {tuple(m["unit"]) for m in manifest}
    readers = sets["one"] | sets["two"]
    missed = {c for c in sets["truth"] - readers if c[:4] in sent}
    reps = sorted({str(r["repeat"]) for r in raw}) or ["1"]
    items = {m["id"]: m for m in manifest}
    got, made = [], []
    for rep in reps:
        named, unplaced = set(), set()       # chosen; chosen where no reader placed it
        for r in raw:
            if str(r["repeat"]) != rep:
                continue
            item = items[r["item"]]
            q = next(q for q in item["questions"] if q["n"] == int(r["question"]))
            token = (r["answer"] if q["kind"] == "mark" and r["answer"].startswith("[")
                     else q.get("token") if r["answer"] == PRINTED else None)
            if token:
                named.add(tuple(item["unit"]) + (token,))
                if token not in item["where"]:
                    unplaced.add(tuple(item["unit"]) + (token,))
        got.append(len(named & missed))
        made.append(len({c for c in unplaced - readers if c not in sets["truth"]}))
    return {"missed_in_sent_parts": len(missed), "recovered": sum(got) / len(got),
            "invented": sum(made) / len(made)}


def whose_rulings(sets: dict, manifest: list[dict], raw: list[dict]) -> dict:
    """The part arm's moves and type rulings, right or wrong against the gold, a repeat.

    A move of ``T`` from part ``u`` to ``u'`` is right when the gold has ``T`` at
    ``u'`` and not at ``u``, wrong when the gold has it at ``u``; a type ruling is
    right when the gold has no ``T`` at ``u``, wrong when it has.
    """
    items = {m["id"]: m for m in manifest}
    reps = sorted({str(r["repeat"]) for r in raw}) or ["1"]
    tally = {k: 0 for k in ("moves", "moves_right", "moves_wrong",
                            "types", "types_right", "types_wrong")}
    for r in raw:
        whose, answer = r.get("whose") or "", r["answer"]
        item = items[r["item"]]
        unit = tuple(item["unit"])
        if not answer.startswith("[") or whose in ("", UNSURE, unit[3]):
            continue
        here = unit + (answer,) in sets["truth"]
        if whose.startswith("type:"):
            tally["types"] += 1
            tally["types_right" if not here else "types_wrong"] += 1
        else:
            there = unit[:3] + (whose, answer) in sets["truth"]
            tally["moves"] += 1
            tally["moves_right"] += there and not here
            tally["moves_wrong"] += here
    return {k: v / len(reps) for k, v in tally.items()}


def gain_interval(claims: list[dict], answers: list[dict], draws: int = BOOTSTRAP,
                  seed: int = SEED) -> tuple[float, float]:
    """Page-clustered bootstrap of the gain over always-Gemini, 95 %."""
    by_page = defaultdict(list)
    for c in claims:
        by_page[c["page"]].append(c)
    pages, rng, gains = sorted(by_page), random.Random(seed), []
    for _ in range(draws):
        sample = [c for p in rng.choices(pages, k=len(pages)) for c in by_page[p]]
        gains.append(measures(sample, answers)["gain"])
    gains.sort()
    return gains[int(0.025 * draws)], gains[int(0.975 * draws) - 1]


def bill() -> dict:
    """What the calls cost, from the usage the API returned."""
    rows = _read_csv(USAGE) if USAGE.exists() else []
    tokens = {k: sum(int(r[k]) for r in rows) for k in ("input", "output", "cache_write", "cache_read")}
    cost = (tokens["input"] * PRICE_IN + tokens["cache_write"] * PRICE_IN * CACHE_WRITE_RATE
            + tokens["cache_read"] * PRICE_IN * CACHE_READ_RATE
            + tokens["output"] * PRICE_OUT) / 1e6 * BATCH_RATE
    return {"calls": len(rows), **tokens, "cost": cost}


def score() -> str:
    human = bo.load_pass(bo.HUMAN)
    first, second = pass_rows(FIRST), pass_rows(SECOND)
    sets = claim_sets(human, first, second)
    claims, _agreed = disputes(human, first, second)
    flags = flagged(sets, _read_csv(VERDICTS))
    lines = [f"test B {__version__}, arm {ARM} — Opus verify ({MODEL}, effort {EFFORT}) on",
             f"  {FIRST} x {SECOND}, {LEVEL} level: {len(claims)} disputed claims "
             f"(the D-98 set), {len(flags)} agreed claims DINOv3 disagrees with", ""]
    if not RAW.exists():
        return "\n".join(lines + ["  no answers on disk yet (--submit, then --collect)"])
    manifest = json.loads((OUT / "items.json").read_text(encoding="utf-8"))
    raw = _read_csv(RAW)
    answers = claim_verdicts(manifest, raw)
    m = measures(claims, answers)
    low, high = gain_interval(claims, answers)
    checks = [("accuracy_settled", m["accuracy_settled"] >= BAR["accuracy_settled"]),
              ("settled", m["settled"] >= BAR["settled"]),
              ("gain", m["gain"] >= BAR["gain"] and low > BAR["gain_low"]),
              ("lean", m["lean"] <= BAR["lean"]),
              ("stable", m["stable"] >= BAR["stable"])]
    lines += [f"  repeats scored     {m['repeats']}",
              f"  always-Gemini      {m['always_gemini']:.3f}   (the free baseline)",
              f"  settled            {m['settled']:.3f}   bar ≥ {BAR['settled']}",
              f"  accuracy, settled  {m['accuracy_settled']:.3f}   bar ≥ {BAR['accuracy_settled']}",
              f"  Opus, else Gemini  {m['route_gemini']:.3f}",
              f"  gain               {m['gain']:+.3f} [{low:+.3f}, {high:+.3f}]   "
              f"bar ≥ +{BAR['gain']}, lower bound > 0",
              f"  lean to Haiku      {m['lean']:+.3f}   bar ≤ {BAR['lean']}",
              f"  stable             {m['stable']:.3f}   bar ≥ {BAR['stable']}", ""]
    passed = all(ok for _k, ok in checks)
    lines.append("  D-98: " + ("PASSES — Opus enters the route" if passed else
                               "fails on " + ", ".join(k for k, ok in checks if not ok)))
    if flags:
        f = flagged_measures(flags, answers)
        lines += ["", "  beside the bar — agreed claims DINOv3 disagrees with "
                      f"({f['claims']}, {f['false']} false):",
                  f"    accept the agreement {f['accept']:.3f};  Opus, else accept {f['route']:.3f}",
                  f"    a repeat removes {f['false_removed']:.1f} false and {f['true_removed']:.1f} "
                  f"true claims; cannot tell on {f['unsure']:.1f}"]
    if ARM == "part":
        w = whose_rulings(sets, manifest, raw)
        wrong, right = (w["moves_wrong"] + w["types_wrong"],
                        w["moves_right"] + w["types_right"])
        ok = (passed and m["accuracy_settled"] >= BASE_ACCURACY - WHOSE_BAR["accuracy_drop"]
              and wrong <= WHOSE_BAR["wrong_max"] and right >= wrong)
        lines += ["", "  the whose question (D-101), a repeat:",
                  f"    moves {w['moves']:.1f} (right {w['moves_right']:.1f}, wrong "
                  f"{w['moves_wrong']:.1f});  type rulings {w['types']:.1f} (right "
                  f"{w['types_right']:.1f}, wrong {w['types_wrong']:.1f})",
                  f"    accuracy on settled disputes {m['accuracy_settled']:.3f} against the base "
                  f"arm's {BASE_ACCURACY} (may fall {WHOSE_BAR['accuracy_drop']})",
                  "  D-101: " + ("PASSES — the verify call asks whose a mark is" if ok else
                                 "fails — the verify call stays as in D-100")]
    r = recovered(sets, manifest, raw)
    off = sum(str(x.get("off_list")) == "True" for x in raw)
    lines += ["", f"  gold claims neither reader made, in parts sent: {r['missed_in_sent_parts']};"
                  f" Opus names {r['recovered']:.1f} a repeat (recovered)",
              f"  tokens Opus names that no reader and no gold has: {r['invented']:.1f} a repeat "
              f"(invented); answers off the offered list: {off}"]
    b = bill()
    if b["calls"]:
        per_call = b["cost"] / b["calls"]
        items = len(manifest)
        lines += ["", f"  bill: {b['calls']} calls, ${b['cost']:.2f} (${per_call:.4f} a call; "
                      f"in {b['input']:,}, cache write {b['cache_write']:,}, "
                      f"cache read {b['cache_read']:,}, out {b['output']:,})",
                  f"  scaled: ≈ {VOLUME_DISPUTES:,} volume disputes ≈ "
                  f"${per_call * VOLUME_DISPUTES * items / len(claims):.0f} a reading "
                  f"(calls in proportion to this pair's {items} parts for {len(claims)} disputes)"]
    return "\n".join(lines)


def main(argv=None) -> int:
    for stream in (sys.stdout, sys.stderr):
        try:
            stream.reconfigure(encoding="utf-8", errors="replace")
        except (AttributeError, ValueError):
            pass
    ap = argparse.ArgumentParser(description=__doc__,
                                 formatter_class=argparse.RawDescriptionHelpFormatter)
    group = ap.add_mutually_exclusive_group(required=True)
    for flag in ("--dry-run", "--submit", "--collect", "--score"):
        group.add_argument(flag, action="store_true")
    ap.add_argument("--arm", default="base", choices=sorted(ARMS),
                    help="base: D-98 as amended; part: also ask whose each mark is (D-101)")
    args = ap.parse_args(argv)
    set_arm(args.arm)
    OUT.mkdir(parents=True, exist_ok=True)
    if args.dry_run:
        dry_run()
    elif args.submit:
        submit()
    elif args.collect:
        collect()
    else:
        report = score()
        REPORT.write_text(report + "\n", encoding="utf-8")
        print(report)
    return 0
