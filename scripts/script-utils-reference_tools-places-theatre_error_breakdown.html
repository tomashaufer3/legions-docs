How it works

The measure as built — the rules where they code a clause, the models' page consensus where they leave it (theatre_rule_audit.measure_flags) — scored against the author's blind ruling (theatre_blind_check.blind_verdict_rows), overall and within groups of source page, land, 1910 settlement size and Czech-speaking share, with a test that the miss rate is the same in every group (theatre_rule_audit.miss_rate_test).

Two views:

  • certification — the held-out half, scored once after the freeze: the result to report;
  • pooled — certification and calibration together, descriptive only, since the rules and the codebook were fitted on calibration.

and each again on the lines from places tied to a 1910 settlement only (tied): a place the settlement tie does not reach (mostly city districts) has no land, size or Czech share.

Nothing is sent: the readings come from the request cache, so a reading not yet cached scores NaN.

Usage::

python utils/reference_tools/places/theatre_error_breakdown.py

writes data/interim/theatre/model_pass/tables/error_breakdown/: overall.csv (every reader, both views), groups.csv (the measure, per group) and miss_tests.csv.

def view(halves: tuple[str, ...], clauses: pd.DataFrame, consensus: pd.DataFrame,
         covariates: pd.DataFrame, tied: bool = False) -> tuple[pd.DataFrame, dict[str, pd.DataFrame]]:
    """The blind rows of ``halves`` with their groups, and three readers' flags on them."""
    truths, flagsets = [], {"measure": [], "consensus": [], "rules": []}
    for half in halves:
        truth = ra.with_groups(bc.blind_verdict_rows(half), covariates)
        rules = ra.reader_flags(truth, "rules", clauses)
        model = ra.reader_flags(truth, "consensus", clauses, consensus)
        truths.append(truth)
        for name, f in (("measure", ra.measure_flags(rules, model)), ("consensus", model), ("rules", rules)):
            flagsets[name].append(f)
    unanswered = {}
    for t in truths:
        for k, v in (t.attrs.get("unanswered") or {}).items():
            unanswered[k] = unanswered.get(k, 0) + v
    truth = pd.concat(truths, ignore_index=True)
    flags = {k: pd.concat(v, ignore_index=True) for k, v in flagsets.items()}
    if tied:
        keep = truth["land"].ne("unknown").to_numpy()
        truth = truth[keep].reset_index(drop=True)
        flags = {k: v[keep].reset_index(drop=True) for k, v in flags.items()}
        unanswered = {}          # the undrawn places are not split by settlement tie
    truth.attrs["unanswered"] = unanswered
    return truth, flags

def group_rows(truth: pd.DataFrame, flags: pd.DataFrame, by: str, flag: str, draws: int) -> list[dict]:
    out = []
    for value, idx in truth.groupby(by).groups.items():
