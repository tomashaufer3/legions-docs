How it works

The Czech step has to be authored. Neither the History of Work title dictionary (whose lang_code covers FR/NL/DE/EN/SV and others) nor OccCANINE (13 languages) has Czech. What the external sources do supply, and this module uses, is everything downstream of the code: reference/occupations/hisco_authority.csv turns a HISCO code plus its status / relation / product modifiers into an English label, HISCLASS, HISCLASS_5, HISCAM and SOCPO.

Matching is exact on the normalised key, never substring. That is deliberate: the two defects the 2026-07 audit found in this repo were an unanchored substring match (generálmajor scoring as major) and missing values fabricating content. Compounds are handled by splitting on token boundaries into curated keys — never by testing whether one key occurs inside another string.

Compounds get one of three token-boundary treatments, and which one fired is recorded in occupation_match so any analysis can restrict to whatever it trusts:

exact   the whole normalised string is a curated key                (~93.9 %)
dual    it splits cleanly into two curated keys — `rolník zámečník`,
        `rolník a obuvník`. Both are coded: the first into the primary
        columns (the HISCO convention, and what HSN's DOUBLE table does),
        the second into the `*_2` columns. A man who farms his fields and
        does a trade for extra money is both, and which one matters is an
        analytical choice made downstream, not here.
head    an adjective and a curated head noun — `mlynářský dělník`,
        `tovární dozorce`. The head noun carries the code.
prefix  a curated key followed by something uncurated — the key carries it.
none    unmatched; every output column stays &lt;NA&gt;

Two guards keep the compound rules from inventing a class. ADJECTIVE_KEYS (below) stops a curated key that is really a qualifier from hijacking the compound as its primary. And where the qualifier changes the trade rather than its object — akademický malíř is a fine artist, not a house painter — the whole string is curated in occupation_hisco_curation.csv so it matches exact and never reaches these rules at all. Decomposition is the default, not the answer to everything.

The qualifier is kept, not discarded (v1.2.0). strojní zámečník and zámečník are different jobs and desert at different rates (Russia: 3.38 % vs 6.06 % on the 2026-08-27 build; OCCUPATION_CODING.md §4 carries the live figures), so the modifier is extracted into its own column by extract_qualifier — deliberately independently of the match kind, by locating the curated head noun inside the string. Keying it off the match kind instead would have thrown the qualifier away again the moment a compound was promoted to a curated exact key, which is exactly what this release does to the high-volume ones. dual is the one kind excluded: in rolník zámečník the leading token is a second occupation, not a modifier, and it is already coded in the *_2 columns.

CAREER_STAGE extracts the other axis the strings carry — mistr, učeň, adjunkt, příručí, majitel. HISCO's own status modifier is populated on only ~2.7 % of coded records because csol.cz simply does not record employment status; the token scan reaches ~3.7 k. It is descriptive: it never touches hisco or the class.

HISCAM was removed in v1.2.0 — see reference/DECISIONS.md D-30. It is non-monotonic on this sample, and the one thing it was still buying (separating zámečník 60 from strojní zámečník 66) is now carried explicitly by the qualifier column instead.

def split_occupations(key: str) -> tuple[str | None, str | None, str]:
    """Split a normalised key into (primary, secondary, match kind).

    Token-boundary only — a candidate is accepted solely because a *whole run of tokens*
    is itself a curated key. No substring test is ever performed, so ``zámečník`` cannot
    be found inside a longer word and ``major`` cannot be found inside ``generálmajor``.
    """
    hit = _resolve(key)
    if hit is not None:
        return hit, None, "exact"

    toks = key.split()
    if len(toks) < 2:
        return None, None, "none"

    # Two occupations written together: every token belongs to one curated key or the
    # other. Prefer the earliest split, which keeps the longest tail intact.
    # A key in ADJECTIVE_KEYS may not be the primary here — inside a longer string it is
    # the qualifier, not the job, and taking it would hand the record the wrong class.
    for i in range(1, len(toks)):
        left = _resolve(" ".join(toks[:i]))
        right = _resolve(" ".join(toks[i:]))
        if left is not None and right is not None and left not in ADJECTIVE_KEYS:
            return left, right, "dual"

    # Adjective(s) + curated head noun. Longest matching suffix wins, so
    # "obchodní příručí" is preferred over the bare "příručí". An ADJECTIVE_KEYS member
    # cannot be the head either — "hajný lesní" is a gamekeeper, not a forest master.
    for i in range(1, len(toks)):
        head = _resolve(" ".join(toks[i:]))
        if head is not None and head not in ADJECTIVE_KEYS:
            return head, None, "head"

    # A curated key followed by something uncurated. Longest matching prefix wins.
    # ADJECTIVE_KEYS are excluded here too: "lesní hosp." is not the forest master, and
    # leaving it uncoded is the honest answer where the head noun is not in the dictionary.
    for i in range(len(toks) - 1, 0, -1):
        pre = _resolve(" ".join(toks[:i]))
        if pre is not None and pre not in ADJECTIVE_KEYS:
            return pre, None, "prefix"

    return None, None, "none"

def extract_qualifier(key: str, kind: str) -> str | None:
    """The modifier attached to a curated head noun — ``strojní`` in ``strojní zámečník``.

    Run **independently of how the string matched**. The obvious implementation is to take
    whatever ``head``/``prefix`` matching dropped on the floor, and it is wrong: the moment
    a high-volume compound is promoted to a curated ``exact`` key — which is what this
    release did to ``strojní zámečník``, ``bankovní úředník`` and fifteen others — the
    qualifier would silently stop being recorded for exactly the records that motivated
    recording it. So the head noun is located structurally instead:

        longest *proper* suffix that is a curated key -> qualifier is the tokens before it
        else longest *proper* prefix that is a curated key -> qualifier is the tokens after
        else no qualifier

    ``ADJECTIVE_KEYS`` are not eligible as the head, for the same reason they are not
    eligible in ``split_occupations``: ``lesní`` is the adjective here, not the noun.

    ``dual`` is excluded. In ``rolník zámečník`` the leading run is a second occupation,
    already coded into the ``*_2`` columns — calling it a qualifier would turn a man's
    farm into an adjective describing his workshop.
    """
    if not key or kind in ("dual", "none"):
        return None
    toks = key.split()
    if len(toks) < 2:
        return None

    for i in range(1, len(toks)):                       # longest proper suffix first
        head = _resolve(" ".join(toks[i:]))
        if head is not None and head not in ADJECTIVE_KEYS:
            return " ".join(toks[:i])

    for i in range(len(toks) - 1, 0, -1):               # longest proper prefix
        pre = _resolve(" ".join(toks[:i]))
        if pre is not None and pre not in ADJECTIVE_KEYS:
            return " ".join(toks[i:])

    return None

def extract_career_stage(key: str) -> str | None:
    """Position in the trade — ``master``, ``apprentice``, ``owner`` — or ``None``.

    Whole-token scan of the normalised key, never a substring test: ``mistr`` must not be
    found inside ``ministr``. Where a string carries more than one stage token the highest
    rung wins, which is the reading the title intends (``vrchní mistr`` is a master).
    Unlike everything else in this module the stage is read off the *whole* string, head
    noun included, so a bare ``příručí`` and an ``obchodní příručí`` both score.
    """
    if not key:
        return None
    stages = [CAREER_STAGE[t] for t in key.split() if t in CAREER_STAGE]
    if not stages:
        return None
    return max(stages, key=lambda s: CAREER_STAGE_ORD[s])

def code_occupation(raw) -> dict | None:
    """HISCO coding of one raw ``Zaměstnání`` value, or ``None`` if it cannot be coded.

    ``None`` for missing, empty and unmatched input alike — nothing is guessed.
    """
    key = _norm(raw)
    if key is None:
        return None
    primary, secondary, kind = split_occupations(key)
    if kind in ("head", "prefix", "none"):
        listed = _split_list(raw)
        if listed is not None:
            primary, secondary, kind = listed
    if primary is None:
        return None
    out = {"key": key, "match": kind,
           "qualifier": extract_qualifier(key, kind),
           "career_stage": extract_career_stage(key)} | _scales(primary)
    if secondary is not None:
        sec = _scales(secondary)
        out |= {f"{k}_2": v for k, v in sec.items()}
    return out

def add_occupation_columns(df: pd.DataFrame, source_col: str = "Zaměstnání",
                           prefix: str = "occupation",

    """Append the HISCO/HISCLASS columns for ``source_col`` (not in place).

    get ``<NA>`` in every appended column — asserted by the notebook's QA gate.

    if source_col not in df.columns:
        return df

    coded = df[source_col].map(code_occupation)

    def pick(field: str):
        return coded.map(lambda d: d.get(field) if isinstance(d, dict) else None)

    df[f"{prefix}_hisco"] = pick("hisco").astype("string")
    df[f"{prefix}_hisco_major"] = pick("major").astype("string")

    df[f"{prefix}_hisclass_5"] = pd.to_numeric(pick("hisclass_5"), errors="coerce").astype("Int64")
    df[f"{prefix}_hisclass_label"] = pick("hisclass_label").astype("string")
    df[f"{prefix}_socpo"] = pd.to_numeric(pick("socpo"), errors="coerce").astype("Int64")

def matcher_selftest() -> list[str]:
    """Behaviours of the matcher that must not regress. Returns the failures, empty if OK.

    Needs no data — it exercises ``_norm`` and ``split_occupations`` alone, so the QA gate
    can call it before the frames are built. Every case here is a bug that was actually
    shipped once, in this module or its siblings; the comments say which.
    """
    cases: list[tuple[str, tuple]] = [
        # Abbreviations expand only behind a trailing period, inside a longer phrase —
        # otherwise `cihlář` becomes `cihlářský` and a real trade is destroyed.
        ("obch.příručí", ("obchodní příručí", None, "exact")),
        ("obchodní příručí", ("obchodní příručí", None, "exact")),
        ("cihlář", ("cihlář", None, "exact")),
        ("stavitel", ("stavitel", None, "exact")),
        # No substring test anywhere: `major` is not inside `generálmajor` (audit 2026-07).
        ("generálmajor", (None, None, "none")),
        # Qualifier changes the trade -> curated whole, never decomposed (audit 2026-08).
        ("akademický malíř", ("akademický malíř", None, "exact")),
        ("ak.malíř", ("akademický malíř", None, "exact")),
        ("zubní lékař", ("zubní lékař", None, "exact")),
        # `dekor.` is the adjective `dekorační`, not the noun `dekoratér`.
        ("dekor.malíř", ("malíř", None, "head")),
        # ADJECTIVE_KEYS: eligible only as an exact whole-string match.
        ("lesní", ("lesní", None, "exact")),
        ("lesní adjunkt", ("lesní adjunkt", None, "exact")),
        # `lesní úředník` used to live here. It is a curated whole string as of v1.2.0
        # (a forest official, following `lesní adjunkt` / `lesník`), so it no longer
        # exercises the adjective rule; `lesní zřízenec` — an attendant, deliberately left
        # to fall through to its head — does.
        ("lesní zřízenec", ("zřízenec", None, "head")),
        ("lesní hajný", ("hajný", None, "head")),
        ("mlynářský dělník", ("dělník", None, "head")),
        # ... but `hostinský` is a genuine noun and its duals must survive.
        ("hostinský, řezník", ("hostinský", "řezník", "dual")),
        ("rolník zámečník", ("rolník", "zámečník", "dual")),
        # Promoted to a curated whole string in v1.2.0 — the qualifier names a different
        # trade (machine fitter, not locksmith), so it must not decompose to the head.
        ("strojní zámečník", ("strojní zámečník", None, "exact")),
        ("bankovní úředník", ("bankovní úředník", None, "exact")),
        # `zem.` before `dělník` is zemědělský, not zemský (audit 2026-09-22)
        ("zem.dělník", ("zemědělský dělník", None, "exact")),
    ]
    failures = []
    for raw, expected in cases:
        key = _norm(raw)
        got = split_occupations(key) if key else (None, None, "none")
        if got != expected:
            failures.append(f"{raw!r}: expected {expected}, got {got}")

    # The qualifier survives promotion to an `exact` key — the whole point of reading it
    # off the head noun rather than off whatever head/prefix matching discarded.
    qual_cases = [
        ("strojní zámečník", "strojní"),      # exact (curated compound)
        ("tovární dělník", "tovární"),        # head
        ("soustružník železa", "železa"),     # prefix, post-modifier
        ("akademický malíř", "akademický"),   # exact, curated because it changes the trade
        ("zámečník", None),                   # single token
        ("rolník zámečník", None),            # dual: the other run is an occupation
    ]
    for raw, expected in qual_cases:
        key = _norm(raw)
        _, _, kind = split_occupations(key) if key else (None, None, "none")
        got = extract_qualifier(key, kind) if key else None
        if got != expected:
            failures.append(f"qualifier {raw!r}: expected {expected!r}, got {got!r}")

    stage_cases = [
        ("tkalcovský mistr", "master"),
        ("hospodářský adjunkt", "assistant"),
        ("obchodní příručí", "assistant"),
        ("poštovní aspirant", "apprentice"),
        ("vrchní číšník", "senior"),
        ("stavební podnikatel", "owner"),
        ("vrchní mistr", "master"),           # highest rung wins
        ("ministr", None),                    # whole tokens only: `mistr` is not inside it
        ("nádeník", None),                    # a status and a job, not a rung
        ("zámečník", None),
    ]
    for raw, expected in stage_cases:
        key = _norm(raw)
        got = extract_career_stage(key) if key else None
        if got != expected:
            failures.append(f"stage {raw!r}: expected {expected!r}, got {got!r}")

    if code_occupation(pd.NA) is not None or code_occupation("") is not None:
        failures.append("missing/empty input does not return None")

    # A comma list keeps its first occupation as the primary (audit 2026-09-22 §B4).
    for raw, want_primary_key, want_kind in (("rolník, tovární dělník", "rolník", "dual"),
                                             ("rolník, zem. dělník", "rolník", "dual")):

"""
occupations.py — HISCO / HISCLASS coding of the free-text ``Zaměstnání`` field
==============================================================================
The raw field is Czech free text: 119,046 non-empty values over 8,004 distinct strings,
7,169 after normalisation. It is heavily concentrated — ``rolník`` alone is 21,457 records,
the top 200 normalised keys are 88.1 % and the top 1,000 are 93.9 % — so a curated
dictionary is tractable where a general Czech occupational parser would not be.

**The Czech step has to be authored.** Neither the History of Work title dictionary (whose
``lang_code`` covers FR/NL/DE/EN/SV and others) nor OccCANINE (13 languages) has Czech.
What the external sources do supply, and this module uses, is everything downstream of the
code: ``reference/occupations/hisco_authority.csv`` turns a HISCO code plus its status /
relation / product modifiers into an English label, HISCLASS, HISCLASS_5, HISCAM and SOCPO.

Matching is **exact on the normalised key**, never substring. That is deliberate: the two
defects the 2026-07 audit found in this repo were an unanchored substring match
(``generálmajor`` scoring as ``major``) and missing values fabricating content. Compounds
are handled by splitting on token boundaries into curated keys — never by testing whether
one key occurs inside another string.

Compounds get one of three token-boundary treatments, and which one fired is recorded in
``occupation_match`` so any analysis can restrict to whatever it trusts:

    exact   the whole normalised string is a curated key                (~93.9 %)
    dual    it splits cleanly into two curated keys — ``rolník zámečník``,
            ``rolník a obuvník``. Both are coded: the first into the primary
            columns (the HISCO convention, and what HSN's DOUBLE table does),
            the second into the ``*_2`` columns. A man who farms his fields and
            does a trade for extra money is both, and which one matters is an
            analytical choice made downstream, not here.
    head    an adjective and a curated head noun — ``mlynářský dělník``,
            ``tovární dozorce``. The head noun carries the code.
    prefix  a curated key followed by something uncurated — the key carries it.
    none    unmatched; every output column stays <NA>

Two guards keep the compound rules from inventing a class. ``ADJECTIVE_KEYS`` (below)
stops a curated key that is really a qualifier from hijacking the compound as its primary.
And where the qualifier changes the *trade* rather than its object — ``akademický malíř``
is a fine artist, not a house painter — the whole string is curated in
``occupation_hisco_curation.csv`` so it matches ``exact`` and never reaches these rules at
all. Decomposition is the default, not the answer to everything.

**The qualifier is kept, not discarded** (v1.2.0). ``strojní zámečník`` and ``zámečník``
are different jobs and desert at different rates (Russia: 3.38 % vs 6.06 % on the
2026-08-27 build; ``OCCUPATION_CODING.md`` §4 carries the live figures), so the modifier is
extracted into its own column by ``extract_qualifier`` — deliberately *independently of
the match kind*, by locating the curated head noun inside the string. Keying it off the
match kind instead would have thrown the qualifier away again the moment a compound was
promoted to a curated ``exact`` key, which is exactly what this release does to the
high-volume ones. ``dual`` is the one kind excluded: in ``rolník zámečník`` the leading
token is a second occupation, not a modifier, and it is already coded in the ``*_2``
columns.

``CAREER_STAGE`` extracts the other axis the strings carry — ``mistr``, ``učeň``,
``adjunkt``, ``příručí``, ``majitel``. HISCO's own status modifier is populated on only
~2.7 % of coded records because csol.cz simply does not record employment status; the
token scan reaches ~3.7 k. It is descriptive: it never touches ``hisco`` or the class.

HISCAM was removed in v1.2.0 — see ``reference/DECISIONS.md`` D-30. It is non-monotonic
on this sample, and the one thing it was still buying (separating ``zámečník`` 60 from
``strojní zámečník`` 66) is now carried explicitly by the qualifier column instead.

-----

    # the adjective reading is the right one.
    "dekor": "dekorační", "dek": "dekorační",
    "uměl": "umělecký",
    "chem": "chemický",
    "advok": "advokátní",
    "telegr": "telegrafní",
    "nem": "nemocenský",
    "abs": "absolvent",
    "cihlář": "cihlářský",
    "pivovar": "pivovarský",
    "zed": "zednický",
    "okr": "okresní",
}

# Abbreviations whose expansion depends on the word they qualify. `zem.` is `zemský`
# (provincial) in `zem.výboru`, `zem.úředník`, `zem.fin.ředitelství` — but `zem.dělník` (18
# records) is a *zemědělský* dělník, a farm labourer: expanded as `zemský`, it matched the bare
# head `dělník` and took 99900 / HISCLASS 13 instead of 62105 / 12, and `rolník, zem. dělník`
# lost the farmer altogether (audit 2026-09-22 §B3). Keyed abbreviation -> {next token: expansion}.
ABBREV_CONTEXT: dict[str, dict[str, str]] = {
    "zem": {"dělník": "zemědělský", "dělnice": "zemědělský", "dělníci": "zemědělský"},
}


def _norm(raw) -> str | None:
    """Normalised lookup key: lowercase, abbreviations expanded, punctuation stripped.

    Returns ``None`` for anything missing or empty — the caller must not turn that into a
    code. (The 2026-07 audit's worst defect was ~26k empty cells being fabricated into a
    real value; the same mistake here would invent an occupation for 13,947 soldiers.)
    """
    if raw is None or (not isinstance(raw, str) and pd.isna(raw)):
        return None
    v = str(raw).strip().lower()
    if not v:
        return None
    v = re.sub(r"[,;/]+", " ", v)             # rolník,dělník -> two tokens
    v = re.sub(r"(?<=\w)-(?=\w)", " ", v)     # řezník-uzenář -> two tokens
    v = re.sub(r"\.(?=\S)", ". ", v)          # obch.příručí -> obch. příručí
    raw_tokens = v.split()
    stripped = [t.strip(" .,;:!?()[]\"'-") for t in raw_tokens]
    tokens: list[str] = []
    for i, tok in enumerate(raw_tokens):
        abbreviated = tok.endswith(".")
        tok = stripped[i]
        if not tok or tok in _CONNECTORS:
            continue
        # Expand only tokens that are *marked* as abbreviations by a trailing period,
        # and only inside a longer phrase. Several ABBREV stems are themselves complete
        # occupations — `cihlář` (brickmaker, 164 records), `stavitel` (master builder,
        # 111) — so expanding on the bare stem would silently rewrite a real job into an
        # adjective. That is the unanchored-matching failure the 2026-07 audit found
        # twice elsewhere in this repo; the period is the anchor here.
        if abbreviated and len(raw_tokens) > 1:
            nxt = stripped[i + 1] if i + 1 < len(stripped) else ""
            tok = ABBREV_CONTEXT.get(tok, {}).get(nxt) or ABBREV.get(tok, tok)
        tokens.append(tok)
    v = re.sub(r"\s+", " ", " ".join(tokens)).strip()
    return v or None


def _fold(s: str) -> str:
    """Diacritic-folded form, for the fallback lookup — csol.cz spells the same job both
    with and without accents (``rolník`` / ``rolnik``)."""
    return "".join(c for c in unicodedata.normalize("NFD", s)
                   if unicodedata.category(c) != "Mn")

@lru_cache(maxsize=1)
def load_occupation_curation(path: str | None = None) -> pd.DataFrame:
    """Curated Czech key -> HISCO + modifiers. Only rows carrying a HISCO code are kept:
    an uncoded skeleton row must behave exactly like an absent one."""
    p = Path(path) if path else CURATION_CSV
    if not p.exists():
        raise FileNotFoundError(
            f"{p} not found — run: "
            f"python utils/reference_tools/occupations/build_occupation_curation.py")
    df = pd.read_csv(p, dtype=str).fillna("")
    df = df[df["hisco"].str.strip() != ""].copy()
    for c in ("status", "relation", "product"):
        df[c] = df[c].replace("", "-9")
    df["hisco"] = df["hisco"].str.strip()
    return df.drop_duplicates("key").set_index("key")


@lru_cache(maxsize=1)
def _key_index() -> tuple[frozenset, dict]:
    """(set of curated keys, diacritic-folded key -> curated key)."""
    keys = load_occupation_curation().index
    folded = {}
    for k in keys:
        folded.setdefault(_fold(k), k)
    return frozenset(keys), folded


def _resolve(key: str) -> str | None:
    """A curated key for ``key`` — exact, else diacritic-folded."""
    exact, folded = _key_index()
    if key in exact:
        return key
    return folded.get(_fold(key))


# ── compound splitting ──────────────────────────────────────────────────────────────

def split_occupations(key: str) -> tuple[str | None, str | None, str]:
    """Split a normalised key into (primary, secondary, match kind).

    Token-boundary only — a candidate is accepted solely because a *whole run of tokens*
    is itself a curated key. No substring test is ever performed, so ``zámečník`` cannot
    be found inside a longer word and ``major`` cannot be found inside ``generálmajor``.
    """
    hit = _resolve(key)
    if hit is not None:
        return hit, None, "exact"

    toks = key.split()
    if len(toks) < 2:
        return None, None, "none"

    # Two occupations written together: every token belongs to one curated key or the
    # other. Prefer the earliest split, which keeps the longest tail intact.
    # A key in ADJECTIVE_KEYS may not be the primary here — inside a longer string it is
    # the qualifier, not the job, and taking it would hand the record the wrong class.
    for i in range(1, len(toks)):
        left = _resolve(" ".join(toks[:i]))
        right = _resolve(" ".join(toks[i:]))
        if left is not None and right is not None and left not in ADJECTIVE_KEYS:
            return left, right, "dual"

    # Adjective(s) + curated head noun. Longest matching suffix wins, so
    # "obchodní příručí" is preferred over the bare "příručí". An ADJECTIVE_KEYS member
    # cannot be the head either — "hajný lesní" is a gamekeeper, not a forest master.
    for i in range(1, len(toks)):
        head = _resolve(" ".join(toks[i:]))
        if head is not None and head not in ADJECTIVE_KEYS:
            return head, None, "head"

    # A curated key followed by something uncurated. Longest matching prefix wins.
    # ADJECTIVE_KEYS are excluded here too: "lesní hosp." is not the forest master, and
    # leaving it uncoded is the honest answer where the head noun is not in the dictionary.
    for i in range(len(toks) - 1, 0, -1):
        pre = _resolve(" ".join(toks[:i]))
        if pre is not None and pre not in ADJECTIVE_KEYS:
            return pre, None, "prefix"

    return None, None, "none"


def extract_qualifier(key: str, kind: str) -> str | None:
    """The modifier attached to a curated head noun — ``strojní`` in ``strojní zámečník``.

    Run **independently of how the string matched**. The obvious implementation is to take
    whatever ``head``/``prefix`` matching dropped on the floor, and it is wrong: the moment
    a high-volume compound is promoted to a curated ``exact`` key — which is what this
    release did to ``strojní zámečník``, ``bankovní úředník`` and fifteen others — the
    qualifier would silently stop being recorded for exactly the records that motivated
    recording it. So the head noun is located structurally instead:

        longest *proper* suffix that is a curated key -> qualifier is the tokens before it
        else longest *proper* prefix that is a curated key -> qualifier is the tokens after
        else no qualifier

    ``ADJECTIVE_KEYS`` are not eligible as the head, for the same reason they are not
    eligible in ``split_occupations``: ``lesní`` is the adjective here, not the noun.

    ``dual`` is excluded. In ``rolník zámečník`` the leading run is a second occupation,
    already coded into the ``*_2`` columns — calling it a qualifier would turn a man's
    farm into an adjective describing his workshop.
    """
    if not key or kind in ("dual", "none"):
        return None
    toks = key.split()
    if len(toks) < 2:
        return None

    for i in range(1, len(toks)):                       # longest proper suffix first
        head = _resolve(" ".join(toks[i:]))
        if head is not None and head not in ADJECTIVE_KEYS:
            return " ".join(toks[:i])

    for i in range(len(toks) - 1, 0, -1):               # longest proper prefix
        pre = _resolve(" ".join(toks[:i]))
        if pre is not None and pre not in ADJECTIVE_KEYS:
            return " ".join(toks[i:])

    return None


def extract_career_stage(key: str) -> str | None:
    """Position in the trade — ``master``, ``apprentice``, ``owner`` — or ``None``.

    Whole-token scan of the normalised key, never a substring test: ``mistr`` must not be
    found inside ``ministr``. Where a string carries more than one stage token the highest
    rung wins, which is the reading the title intends (``vrchní mistr`` is a master).
    Unlike everything else in this module the stage is read off the *whole* string, head
    noun included, so a bare ``příručí`` and an ``obchodní příručí`` both score.
    """
    if not key:
        return None
    stages = [CAREER_STAGE[t] for t in key.split() if t in CAREER_STAGE]
    if not stages:
        return None
    return max(stages, key=lambda s: CAREER_STAGE_ORD[s])


# ── coding ──────────────────────────────────────────────────────────────────────────

# ``hiscam_u1`` is deliberately absent — HISCAM was dropped in v1.2.0 (DECISIONS D-30).
_SCALE_COLS = ["label_en", "hisclass", "hisclass_label", "hisclass_5",
               "hisclass_5_label", "socpo", "socpo_label", "major"]

# HISCO's sentinels: -1 no occupation, -2 an employer or institution named instead of a job,
# -3 nothing recorded. Every stratification scale is withheld from all three (v1.3.0, D-42).
_SENTINEL_CODES = {"-1", "-2", "-3"}
_STRATIFICATION_COLS = ["hisclass", "hisclass_label", "hisclass_5", "hisclass_5_label",
                        "socpo", "socpo_label"]

# What describes the code rather than ranking the man. Constant across every authority row
# a code appears on, so it survives a modifier the authority never saw (v1.3.1).
_DESCRIPTIVE_COLS = ["label_en", "major"]


def _scales(curated_key: str) -> dict:
    """HISCO code + modifiers + derived scales for one curated key.

    The authority is keyed on ``(hisco, status, relation, product)`` and is built only from
    the combinations HSN actually observed, so a curated entry may name a modifier HSN
    never saw with that code — ``hospodářský adjunkt`` is 21230 with status 33
    (Subordinate), a pairing absent from the Dutch data. Those rows fall back to the
    **base code's** scales, keeping the modifier in its own column: the modifier refines
    the class where there is evidence, and where there is none the unmodified code is the
    best available answer.

    The one case where the fallback must *not* fire is a non-empty ``relation``. HISCO
    excludes any occupation carrying a relation value from HISCLASS entirely (HSN release
    doc §3.2.4) — "widow of a miner" is not a miner — so reaching past a missing key to
    the base code would manufacture a class the scheme deliberately withholds.
    """
    cur = load_occupation_curation()
    auth = load_hisco_authority()
    row = cur.loc[curated_key]
    hisco = row["hisco"]
    status, relation, product = row["status"], row["relation"], row["product"]
    out: dict = {"hisco": hisco, "status": status,
                 "relation": relation, "product": product}

    idx = (hisco, status, relation, product)
    if idx not in auth.index and relation == "-9":
        idx = (hisco, "-9", "-9", "-9")        # base code, modifier kept in its column

    if idx in auth.index:
        a = auth.loc[idx]
        if isinstance(a, pd.DataFrame):        # defensive: authority key must be unique
            a = a.iloc[0]
        out |= {c: a.get(c) for c in _SCALE_COLS}
    else:
        out |= {c: pd.NA for c in _SCALE_COLS}
        # 32 of the authority's 1,696 codes were only ever observed *under* a modifier and
        # so have no base row at all: 95240 *Cement Finisher* exists solely as status 32 and
        # 33. A curated key sitting on such a code — `cementář` since D-41 — matches neither
        # its own key nor the base fallback, and loses its **English label and major group**
        # along with its class: a HISCO code delivered with nothing behind it, which the QA
        # gate reads as a hole (`Every coded ... carries a HISCO major group`). The scales
        # stay absent, deliberately: HSN's class for a *subordinate* cement finisher is not
        # this man's class, and that is the price D-41 accepted for the sharper code. The
        # description is a property of the code itself and is identical on every row the
        # code appears on, so it is taken from whichever row is at hand.
        same_code = auth.index.get_level_values("hisco") == hisco
        if same_code.any():
            a = auth.loc[same_code].iloc[0]
            out |= {c: a.get(c) for c in _DESCRIPTIVE_COLS}
        else:
            out["_unknown_authority_key"] = True

    # A sentinel is the statement "this is not an occupation", so no occupation-based scale
    # may speak for it. This was believed to hold already and did not: for HISCO -1 there is
    # no occupation, so the *status modifier alone* carries the scales, and HSN's crosswalk
    # reads a modifier as a social position where this project reads it as a refusal to code.
    # The two never agreed. `student` (-1, status 41) had no HISCLASS — which is why the
    # exclusion looked enforced — but carried **SOCPO 42**, "middle class, supervisors of
    # skilled workers", on 3,098 records, 19 % of that cell. `absolvent` / `abiturient`
    # (-1, status 42) was worse and in the headline variable: **HISCLASS 2, Higher
    # professionals** and **SOCPO 5, Elite** for 160 men holding a leaving certificate,
    # 3.3 % of HISCLASS 2 and 5.3 % of the elite. HSN's values are real — 378 and 9
    # observations behind them — and they are answers to a different question.
    #
    # `label_en` and `major` are untouched: they describe the code, they do not rank a man.
    if str(hisco) in _SENTINEL_CODES:
        out |= {c: pd.NA for c in _STRATIFICATION_COLS}
    return out


_LIST_SEP = re.compile(r"[,;/]")


def _split_list(raw) -> tuple[str, str, str] | None:
    """A comma/semicolon list of occupations, coded segment by segment — or ``None``.

    ``_norm`` turns the commas into spaces, so ``rolník, tovární dělník`` reached the
    ``head`` rule as one phrase: the *last* segment's head noun became the primary
    occupation (99900, HISCLASS 13) and the farmer was filed as the "qualifier" ``rolník
    tovární`` — 464 records, against the HISCO convention the ``dual`` rule states (first
    occupation primary, the second in ``*_2``; audit 2026-09-22 §B4). The comma is the
    evidence of a list, so it is read before it is thrown away: when the first segment codes
    and a later one does too, the pair is a ``dual``. Anything else keeps the whole-string
    answer.
    """
    segs = [s for s in (_norm(x) for x in _LIST_SEP.split(str(raw))) if s]
    if len(segs) < 2:
        return None
    first = split_occupations(segs[0])[0]
    if first is None:
        return None
    for seg in segs[1:]:
        nxt = split_occupations(seg)[0]
        if nxt is not None:
            return first, nxt, "dual"
    return None


@lru_cache(maxsize=20000)
def code_occupation(raw) -> dict | None:
    """HISCO coding of one raw ``Zaměstnání`` value, or ``None`` if it cannot be coded.

    ``None`` for missing, empty and unmatched input alike — nothing is guessed.
    """
    key = _norm(raw)
    if key is None:
        return None
    primary, secondary, kind = split_occupations(key)
    if kind in ("head", "prefix", "none"):
        listed = _split_list(raw)
        if listed is not None:
            primary, secondary, kind = listed
    if primary is None:
        return None
    out = {"key": key, "match": kind,
           "qualifier": extract_qualifier(key, kind),
           "career_stage": extract_career_stage(key)} | _scales(primary)
    if secondary is not None:
        sec = _scales(secondary)
        out |= {f"{k}_2": v for k, v in sec.items()}
    return out


# ── frame API ───────────────────────────────────────────────────────────────────────

def add_occupation_columns(df: pd.DataFrame, source_col: str = "Zaměstnání",
                           prefix: str = "occupation",
                           secondary: bool = True) -> pd.DataFrame:
    """Append the HISCO/HISCLASS columns for ``source_col`` (not in place).

    The raw column is left untouched. Rows where ``source_col`` is missing or unmatched
    get ``<NA>`` in every appended column — asserted by the notebook's QA gate.
    """
    df = df.copy()
    if source_col not in df.columns:
        return df

    coded = df[source_col].map(code_occupation)

    def pick(field: str):
        return coded.map(lambda d: d.get(field) if isinstance(d, dict) else None)

    df[f"{prefix}_hisco"] = pick("hisco").astype("string")
    df[f"{prefix}_hisco_major"] = pick("major").astype("string")
    df[f"{prefix}_en"] = pick("label_en").astype("string")
    df[f"{prefix}_hisclass"] = pd.to_numeric(pick("hisclass"), errors="coerce").astype("Int64")
    df[f"{prefix}_hisclass_5"] = pd.to_numeric(pick("hisclass_5"), errors="coerce").astype("Int64")
    df[f"{prefix}_hisclass_label"] = pick("hisclass_label").astype("string")
    df[f"{prefix}_socpo"] = pd.to_numeric(pick("socpo"), errors="coerce").astype("Int64")
    df[f"{prefix}_status"] = pick("status").astype("string")
    df[f"{prefix}_relation"] = pick("relation").astype("string")
    df[f"{prefix}_match"] = pick("match").astype("string")
    # The two axes the string carries beyond the code (v1.2.0). Both are descriptive and
    # neither feeds HISCO or HISCLASS — see ``extract_qualifier`` / ``extract_career_stage``.
    df[f"{prefix}_qualifier"] = pick("qualifier").astype("string")
    df[f"{prefix}_career_stage"] = pick("career_stage").astype("string")
    df[f"{prefix}_career_stage_ord"] = (
        df[f"{prefix}_career_stage"].map(CAREER_STAGE_ORD).astype("Int64")
    )

    if secondary:
        df[f"{prefix}_hisco_2"] = pick("hisco_2").astype("string")
        df[f"{prefix}_en_2"] = pick("label_en_2").astype("string")
        df[f"{prefix}_hisclass_2"] = pd.to_numeric(pick("hisclass_2"), errors="coerce").astype("Int64")
        # Convenience for the dual-occupation cases the user asked to keep codeable both
        # ways: the higher-status of the two (HISCLASS counts down, 1 = higher managers).
        df[f"{prefix}_hisclass_high"] = (
            df[[f"{prefix}_hisclass", f"{prefix}_hisclass_2"]].min(axis=1).astype("Int64")
        )
    return df


def matcher_selftest() -> list[str]:
    """Behaviours of the matcher that must not regress. Returns the failures, empty if OK.

    Needs no data — it exercises ``_norm`` and ``split_occupations`` alone, so the QA gate
    can call it before the frames are built. Every case here is a bug that was actually
    shipped once, in this module or its siblings; the comments say which.
    """
    cases: list[tuple[str, tuple]] = [
        # Abbreviations expand only behind a trailing period, inside a longer phrase —
        # otherwise `cihlář` becomes `cihlářský` and a real trade is destroyed.
        ("obch.příručí", ("obchodní příručí", None, "exact")),
        ("obchodní příručí", ("obchodní příručí", None, "exact")),
        ("cihlář", ("cihlář", None, "exact")),
        ("stavitel", ("stavitel", None, "exact")),
        # No substring test anywhere: `major` is not inside `generálmajor` (audit 2026-07).
        ("generálmajor", (None, None, "none")),
        # Qualifier changes the trade -> curated whole, never decomposed (audit 2026-08).
        ("akademický malíř", ("akademický malíř", None, "exact")),
        ("ak.malíř", ("akademický malíř", None, "exact")),
        ("zubní lékař", ("zubní lékař", None, "exact")),
        # `dekor.` is the adjective `dekorační`, not the noun `dekoratér`.
        ("dekor.malíř", ("malíř", None, "head")),
        # ADJECTIVE_KEYS: eligible only as an exact whole-string match.
        ("lesní", ("lesní", None, "exact")),
        ("lesní adjunkt", ("lesní adjunkt", None, "exact")),
        # `lesní úředník` used to live here. It is a curated whole string as of v1.2.0
        # (a forest official, following `lesní adjunkt` / `lesník`), so it no longer
        # exercises the adjective rule; `lesní zřízenec` — an attendant, deliberately left
        # to fall through to its head — does.
        ("lesní zřízenec", ("zřízenec", None, "head")),
        ("lesní hajný", ("hajný", None, "head")),
        ("mlynářský dělník", ("dělník", None, "head")),
        # ... but `hostinský` is a genuine noun and its duals must survive.
        ("hostinský, řezník", ("hostinský", "řezník", "dual")),
        ("rolník zámečník", ("rolník", "zámečník", "dual")),
        # Promoted to a curated whole string in v1.2.0 — the qualifier names a different
        # trade (machine fitter, not locksmith), so it must not decompose to the head.
        ("strojní zámečník", ("strojní zámečník", None, "exact")),
        ("bankovní úředník", ("bankovní úředník", None, "exact")),
        # `zem.` before `dělník` is zemědělský, not zemský (audit 2026-09-22)
        ("zem.dělník", ("zemědělský dělník", None, "exact")),
    ]
    failures = []
    for raw, expected in cases:
        key = _norm(raw)
        got = split_occupations(key) if key else (None, None, "none")
        if got != expected:
            failures.append(f"{raw!r}: expected {expected}, got {got}")

    # The qualifier survives promotion to an `exact` key — the whole point of reading it
    # off the head noun rather than off whatever head/prefix matching discarded.
    qual_cases = [
        ("strojní zámečník", "strojní"),      # exact (curated compound)
        ("tovární dělník", "tovární"),        # head
        ("soustružník železa", "železa"),     # prefix, post-modifier
        ("akademický malíř", "akademický"),   # exact, curated because it changes the trade
        ("zámečník", None),                   # single token
        ("rolník zámečník", None),            # dual: the other run is an occupation
    ]
    for raw, expected in qual_cases:
        key = _norm(raw)
        _, _, kind = split_occupations(key) if key else (None, None, "none")
        got = extract_qualifier(key, kind) if key else None
        if got != expected:
            failures.append(f"qualifier {raw!r}: expected {expected!r}, got {got!r}")

    stage_cases = [
        ("tkalcovský mistr", "master"),
        ("hospodářský adjunkt", "assistant"),
        ("obchodní příručí", "assistant"),
        ("poštovní aspirant", "apprentice"),
        ("vrchní číšník", "senior"),
        ("stavební podnikatel", "owner"),
        ("vrchní mistr", "master"),           # highest rung wins
        ("ministr", None),                    # whole tokens only: `mistr` is not inside it
        ("nádeník", None),                    # a status and a job, not a rung
        ("zámečník", None),
    ]
    for raw, expected in stage_cases:
        key = _norm(raw)
        got = extract_career_stage(key) if key else None
        if got != expected:
            failures.append(f"stage {raw!r}: expected {expected!r}, got {got!r}")

    if code_occupation(pd.NA) is not None or code_occupation("") is not None:
        failures.append("missing/empty input does not return None")

    # A comma list keeps its first occupation as the primary (audit 2026-09-22 §B4).
    for raw, want_primary_key, want_kind in (("rolník, tovární dělník", "rolník", "dual"),
                                             ("rolník, zem. dělník", "rolník", "dual")):
        got = code_occupation(raw)
        want = load_occupation_curation().loc[want_primary_key, "hisco"]
        if got is None or got["hisco"] != want or got["match"] != want_kind:
            failures.append(f"list {raw!r}: got {None if got is None else (got['hisco'], got['match'])}"
                            f", expected ({want!r}, {want_kind!r})")
    return failures


def occupation_report(df: pd.DataFrame, source_col: str = "Zaměstnání",
                      prefix: str = "occupation", top: int = 20) -> None:
    """Print coverage by match kind, the HISCLASS distribution, and what is still unmapped."""
    if source_col not in df.columns:
        print(f"No {source_col} column.")
        return
    s = df[source_col]
    n = int(s.notna().sum())
    hisco_col = f"{prefix}_hisco"
    if hisco_col not in df.columns:
        print(f"No {hisco_col} — run add_occupation_columns first.")
        return

    cov = int(df[hisco_col].notna().sum())
    print(f"{prefix}: {cov:,}/{n:,} non-empty values coded ({cov / n:.1%}) "
          f"— {len(df) - n:,} rows empty, left <NA>")

    # Count match kinds over the non-empty rows only: an empty source cell is not an
    # "unmatched" occupation, it is the absence of one.
    kinds = df.loc[s.notna(), f"{prefix}_match"].value_counts(dropna=False)
    for k, v in kinds.items():
        label = "unmatched" if pd.isna(k) else k
        print(f"    {label:<9} {v:>7,}  ({v / n:.1%} of non-empty)")

    hc = df[f"{prefix}_hisclass"]
    print(f"\n  HISCLASS assigned to {int(hc.notna().sum()):,} "
          f"({hc.notna().sum() / n:.1%} of non-empty)")
    for k, v in hc.value_counts().sort_index().items():
        lab = df.loc[hc.eq(k), f"{prefix}_hisclass_label"].iloc[0]
        print(f"    {int(k):>3}  {v:>7,}  {lab}")

    unmapped = s[s.notna() & df[hisco_col].isna()]
    if len(unmapped):
        print(f"\n  top unmapped ({unmapped.nunique():,} distinct, "
              f"{len(unmapped):,} records):")
        for val, c in unmapped.value_counts().head(top).items():
            print(f"    {c:>5}  {val!r}")
