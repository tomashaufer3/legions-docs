How it works

Downloads a whole digital-library document (all its pages) from a Kramerius 7 instance as a single PDF (the page scans), a concatenated TXT (the per-page OCR) and, where present, per-page ALTO XML (word coordinates). Written for the Moravskoslezská vědecká knihovna (MSVK, kramerius.msvk.cz) but should work against any Kramerius 7.x "client v7.0" REST API; just pass --host.

Why this is a separate module from scraper_kramerius.py

That module targets Kramerius v5 (/search/api/v5.0/item/{pid}/..., streams/IMG_FULL datastream names). Kramerius v7 renamed almost everything: a different base path, JSON-only responses shaped differently, no children endpoint (404), and per-page datastreams that hang off /items/{pid}/image and /items/{pid}/ocr/... instead of a generic streams/{NAME}. The two APIs are incompatible enough that patching one module to handle both would obscure more than it saved, so this is a fresh, parallel implementation that mirrors the v5 module's conventions (docstring shape, __version__, client class, download_document() entry point, argparse CLI, resumable page cache, PDF assembly) so the two scrapers stay interchangeable from the caller's point of view.

What a Kramerius 7 document looks like

Every object has a pid (uuid:XX…) and a model. A monograph (or periodical / periodicalvolume / periodicalitem / monographunit) holds page children directly; leaf pages have model == "page". Kramerius 7 also has an internalpart model (chapter/section headings such as "Vorwort") that hangs off the same parent via hasIntCompPart but does not introduce further pages of its own — it just labels a range of the same pages via a foster isOnPage relation — so it is ignored when collecting the page list.

Two ways to enumerate the pages were probed against this host; both work and return an identical, sort-index-ordered page list, so this module uses whichever the caller does not override:

/search/api/client/v7.0/items/{pid}/info/structure
    -> {"children": {"own": [{"pid", "relation": "hasPage"|"hasIntCompPart"}, ...]}}
    Filter to `relation == "hasPage"`; the array order already matches
    document order (verified against `page.index` below).

/search/api/client/v7.0/search
    ?q=own_parent.pid:"{pid}" AND model:page
    &rows=2000&sort=rels_ext_index.sort asc
    &fl=pid,model,title.search,page.index,page.number
    -> {"response": {"docs": [{"pid", "page.index", "page.number", ...}, ...]}}
    Explicitly sorted by the Fedora RELS-EXT ordering predicate; carries
    the printed page number/label for free. This is what the module uses
    by default (`iter_pages`), falling back to `info/structure` if the
    Solr query ever comes back empty.

/search/api/client/v7.0/items/{pid}/children (the v5-shaped guess) is a straight 404 on this host — do not use it.

Per-document metadata / access info:

/search/api/client/v7.0/items/{pid}/info
    -> {"providedByLicenses": [...], "data": {"image": {...}, "ocr": {...}}, ...}
    Access-policy summary (e.g. "public"), not a display title.

/search/api/client/v7.0/search?q=pid:"{pid}"&fl=pid,model,title.search,
    title.sort,date.str,root.pid,root.title
    -> the actual bibliographic title, root title, model and date. Used
    for the identity check and the output filename.

/search/api/client/v7.0/items/{pid}/info/data
    -> {"image": {"preview","thumb","full"}, "ocr": {"text","alto"}, ...}
    Per-item boolean availability flags — checked once per page so a
    genuinely-absent stream is skipped without wasting a 404 round-trip
    (Kramerius 7 answers a missing datastream with 404, not an empty body).

Per-page datastreams (confirmed present on kramerius.msvk.cz, 2026-08):

/items/{pid}/image        image/jpeg   full-resolution page scan  -> PDF
/items/{pid}/ocr/text     text/plain   OCR of that page           -> TXT
/items/{pid}/ocr/alto     text/xml     ALTO word coordinates      -> per-page XML (if present)

Progress

A tqdm bar is drawn over the page loop (--no-progress, or progress=False, falls back to a log line every 25 pages). Several documents can share one screen by giving each a progress_position — see run_lexicon_downloads.py.

TLS note

requests fails certificate verification against this host even though the Windows trust store (and curl) accept it — the local certifi bundle is stale for this host's chain. Default here is therefore verify_tls=False (the opposite default from the v5 module, which talks to a host that verifies fine); pass --verify-tls to force verification back on.

CLI usage

python utils/scraping/scraper_kramerius7.py \
    --url "https://kramerius.msvk.cz/view/uuid:522ce040-5386-11df-a073-0013d398622b" \
    --out library/lexicons --name MSVK_Spezialortsrepertorium-Schlesien-1910_de --alto

class Kramerius7Client:
    """Thin, polite wrapper over the Kramerius 7 "client v7.0" read API."""

    def __init__(
        self,
        host: str = DEFAULT_HOST,
        *,
        delay: float = 0.5,
        timeout: float = 60.0,
        retries: int = 4,
        verify_tls: bool = False,
    ) -> None:
        self.base = host.rstrip("/") + API_PATH
        self.delay = delay
        self.timeout = timeout
        self.retries = retries
        self.session = requests.Session()
        self.session.headers.update({"User-Agent": USER_AGENT})
        self.session.verify = verify_tls
        if not verify_tls:
            import urllib3
            urllib3.disable_warnings(urllib3.exceptions.InsecureRequestWarning)

    # -- low level ------------------------------------------------------
    def _get(self, url: str, **kwargs) -> requests.Response:
        """GET with linear backoff on 429/5xx; raise on other 4xx (incl. 404)."""
        last_exc: Exception | None = None
        for attempt in range(1, self.retries + 1):
            try:
                r = self.session.get(url, timeout=self.timeout, **kwargs)
                if r.status_code in (429, 500, 502, 503, 504):
                    wait = self.delay * attempt * 3
                    log.warning("  %s on %s — retry %d/%d in %.1fs",
                                r.status_code, url, attempt, self.retries, wait)
                    time.sleep(wait)
                    continue
                r.raise_for_status()
                if self.delay:
                    time.sleep(self.delay)
                return r
            except requests.RequestException as exc:
                # 4xx (incl. 404 "no such datastream") should not be retried —
                # raise_for_status already raised for those; this branch is
                # network hiccups (timeout, connection reset, etc.)
                if isinstance(exc, requests.HTTPError) and exc.response is not None \
                        and exc.response.status_code not in (429, 500, 502, 503, 504):
                    raise
                last_exc = exc
                wait = self.delay * attempt * 3
                log.warning("  %s on %s — retry %d/%d in %.1fs",
                            exc.__class__.__name__, url, attempt, self.retries, wait)
                time.sleep(wait)
        raise RuntimeError(f"GET failed after {self.retries} tries: {url}") from last_exc

    # -- metadata ---------------------------------------------------------
    def solr_doc(self, pid: str, fl: str = "pid,model,title.search,title.sort,date.str,root.pid,root.title") -> dict:
        """Look up one item's Solr document (title, model, date, root title)."""
        url = f"{self.base}/search?q=pid:%22{pid}%22&fl={fl}"
        docs = self._get(url).json().get("response", {}).get("docs", [])
        return docs[0] if docs else {}

    def info(self, pid: str) -> dict:
        """Access-policy / license summary for an item."""
        return self._get(f"{self.base}/items/{pid}/info").json()

    def info_data(self, pid: str) -> dict:
        """Per-item datastream availability flags (image/ocr/audio/metadata booleans)."""
        return self._get(f"{self.base}/items/{pid}/info/data").json()

    def structure(self, pid: str) -> dict:
        return self._get(f"{self.base}/items/{pid}/info/structure").json()

    # -- streams ------------------------------------------------------------
    def try_bytes(self, url: str) -> bytes | None:
        try:
            return self._get(url).content
        except Exception as exc:
            log.debug("    no data at %s (%s)", url, exc)
            return None

    def try_text(self, url: str) -> str | None:
        try:
            r = self._get(url)
            # force UTF-8; Kramerius OCR is UTF-8 but requests may guess wrong
            # if the response omits/mis-states charset.
            return r.content.decode("utf-8", errors="replace")
        except Exception as exc:
            log.debug("    no data at %s (%s)", url, exc)
            return None

    def image(self, pid: str) -> bytes | None:
        return self.try_bytes(f"{self.base}/items/{pid}/image")

    def ocr_text(self, pid: str) -> str | None:
        return self.try_text(f"{self.base}/items/{pid}/ocr/text")

    def ocr_alto(self, pid: str) -> str | None:
        return self.try_text(f"{self.base}/items/{pid}/ocr/alto")

    # -- page listing ---------------------------------------------------
    def iter_pages(self, pid: str) -> Iterator[dict]:
        """Yield page dicts (pid, label, index) in document order.

        Tries the Solr ``own_parent.pid`` query first (explicitly sorted by
        the Fedora RELS-EXT ordering predicate, and carries the printed page
        number as ``page.number``); falls back to ``info/structure`` — whose
        ``children.own`` array order also matches document order — if the
        Solr query comes back empty (e.g. a host that has not indexed
        ``own_parent.pid``).
        """
        url = (f"{self.base}/search?q=own_parent.pid:%22{pid}%22+AND+model:page"
               f"&rows=5000&sort=rels_ext_index.sort%20asc"
               f"&fl=pid,model,title.search,page.index,page.number")
        docs = self._get(url).json().get("response", {}).get("docs", [])
        if docs:
            for d in docs:
                yield {"pid": d["pid"], "label": d.get("page.number") or d.get("title.search") or "",
                       "index": d.get("page.index")}
            return

        log.info("  Solr own_parent query empty — falling back to info/structure")
        struct = self.structure(pid)
        own = struct.get("children", {}).get("own", [])
        for i, child in enumerate(own):
            if child.get("relation") == "hasPage":
                yield {"pid": child["pid"], "label": str(i), "index": i}

def parse_pid(url_or_pid: str) -> str:
    """Extract the document ``uuid:…`` from a viewer URL or accept a bare pid."""
    s = url_or_pid.strip()
    m = re.search(r"/(?:view|uuid|periodical|monograph)/(uuid:[0-9a-fA-F-]+)", s)
    if m:
        return m.group(1)
    m = re.search(r"(uuid:[0-9a-fA-F-]+)", s.split("?page=")[0])
    if m:
        return m.group(1)
    if re.fullmatch(r"[0-9a-fA-F-]{36}", s):
        return "uuid:" + s
    raise ValueError(f"could not find a uuid in: {url_or_pid!r}")

def parse_host(url: str) -> str | None:
    """Return scheme+host from a viewer URL (Kramerius 7 API lives on the same host)."""
    m = re.match(r"https?://([^/]+)", url)
    return f"https://{m.group(1)}" if m else None

def safe_filename(text: str, *, max_len: int = 120) -> str:
    text = _ILLEGAL.sub("", text)
    text = re.sub(r"\s+", " ", text).strip().rstrip(". ")
    if len(text) > max_len:
        text = text[:max_len].rstrip(". ")
    return text or "kramerius_document"

def download_document(
    url_or_pid: str,
    out_dir: str | Path,
    *,
    host: str | None = None,
    make_pdf: bool = True,
    make_txt: bool = True,
    per_page_txt: bool = False,
    save_alto: bool = True,
    delay: float = 0.5,
    verify_tls: bool = False,
    keep_pages: bool = True,
    name: str | None = None,
    page_from: int = 1,
    page_to: int | None = None,
    batch_size: int = 20,
    batch_pause: float = 10.0,
    progress: bool = True,
    progress_position: int | None = None,
    progress_desc: str | None = None,
) -> dict:
    """Download pages of a Kramerius 7 document to ``out_dir``.

    Returns a small summary dict. Page images/OCR/ALTO are cached under
    ``out_dir/<slug>_pages/`` so a re-run resumes instead of re-fetching
    (each page artefact is skipped if already present with nonzero size).

    Downloading is **batched by default**: every ``batch_size`` pages the run
    pauses for ``batch_pause`` seconds, so a long volume is pulled in polite
    bursts rather than one sustained stream.  A batch served entirely from cache
    does not pause, so resuming stays fast.  ``batch_size=0`` disables batching.

    ``page_from``/``page_to`` (1-based, inclusive) restrict the fetch to a slice
    of the document — use these to stop after a fixed slice, not for pacing
    (batching already handles that).  Page numbering stays global, so ranges
    share one cache directory.  A partial range fills the cache only — re-run
    with no range once complete to assemble the PDF/TXT (that pass fetches
    nothing).

    A ``tqdm`` progress bar over the page loop is on by default; pass
    ``progress=False`` for the older every-25-pages log line instead.
    ``progress_position`` stacks the bar when several documents run at once
    (see ``run_lexicon_downloads.py``), ``progress_desc`` labels it.
    """
    pid = parse_pid(url_or_pid)
    if host is None and url_or_pid.lower().startswith("http"):
        host = parse_host(url_or_pid)
    client = Kramerius7Client(host or DEFAULT_HOST, delay=delay, verify_tls=verify_tls)

    doc = client.solr_doc(pid)
    # `name` overrides the output *filename stem* only — the title stays whatever
    # the library calls the volume, so it is what the TXT header reports.
    title = doc.get("title.search") or doc.get("root.title") or pid
    model = doc.get("model", "?")
    date = doc.get("date.str", "?")
    root_title = doc.get("root.title", "")

    slug = safe_filename(name or title)
    out_dir = Path(out_dir)
    out_dir.mkdir(parents=True, exist_ok=True)
    pages_dir = out_dir / f"{slug}_pages"
    pages_dir.mkdir(exist_ok=True)

    log.info("Title    : %s", title)
    log.info("Root     : %s", root_title)
    log.info("PID      : %s  (model=%s, date=%s, host=%s)", pid, model, date, client.base)

    log.info("Collecting page list …")
    pages = list(client.iter_pages(pid))
    n = len(pages)
    log.info("  %d pages", n)
    if n == 0:
        raise RuntimeError("no pages found under this pid")

    lo = max(1, page_from)
    hi = min(n, page_to if page_to is not None else n)
    partial = (lo > 1) or (hi < n)
    if partial:
        log.info("Range    : pages %d–%d of %d (partial — PDF/TXT not assembled)", lo, hi, n)
    if batch_size > 0:
        log.info("Batching : %d pages per batch, %.0fs pause between batches",
                 batch_size, batch_pause)

    image_paths: list[Path] = []
    ocr_parts: list[str] = []
    n_img = n_ocr = n_alto = n_missing_img = n_fetched = 0
    batch_pos = batch_mark = 0

    bar = page_bar(n, progress_desc or slug, enabled=progress, position=progress_position)
    bar_live = getattr(bar, "live", False)

    # With a bar drawn, every log line goes through tqdm.write so it does not
    # shred it; without one, the every-25-pages line below is the only progress.
    with bar, redirect_logging():
        for i, pg in enumerate(pages, 1):
            ppid = pg["pid"]
            label = str(pg.get("label") or i)
            img_path = pages_dir / f"{i:04d}.jpg"
            txt_path = pages_dir / f"{i:04d}.txt"
            alto_path = pages_dir / f"{i:04d}.alto.xml"
            in_range = lo <= i <= hi

            # -- image (cached / resumable) --------------------------------
            if make_pdf:
                if img_path.exists() and img_path.stat().st_size > 0:
                    image_paths.append(img_path)
                    n_img += 1
                elif in_range:
                    data = client.image(ppid)
                    if data is None:
                        n_missing_img += 1
                        log.warning("  p%d/%d %-8s no image (skipped in PDF)", i, n, label)
                    else:
                        img_path.write_bytes(data)
                        image_paths.append(img_path)
                        n_img += 1
                        n_fetched += 1

            # -- OCR text (always cached to disk -> resumable regardless of
            #    per_page_txt, which only controls whether it's kept vs. tidied) -
            txt = None
            if make_txt or per_page_txt:
                if txt_path.exists() and txt_path.stat().st_size > 0:
                    txt = txt_path.read_text(encoding="utf-8")
                elif in_range:
                    txt = client.ocr_text(ppid)
                    if txt is not None:
                        txt_path.write_text(txt, encoding="utf-8")
                        n_fetched += 1
                if txt is not None:
                    n_ocr += 1
                    header = f"\n\n===== p. {i}  ({label})  [{ppid}] =====\n"
                    ocr_parts.append(header + txt.strip())

            # -- ALTO (word coordinates) --------------------------------------
            if save_alto:
                if alto_path.exists() and alto_path.stat().st_size > 0:
                    n_alto += 1
                elif in_range:
                    alto = client.ocr_alto(ppid)
                    if alto is not None:
                        alto_path.write_text(alto, encoding="utf-8")
                        n_alto += 1
                        n_fetched += 1
                    else:
                        log.debug("  p%d/%d %-8s no ALTO", i, n, label)

            bar.update(1)
            bar.set_postfix(fetched=n_fetched, refresh=False)
            if not bar_live and (i % 25 == 0 or i == n):
                log.info("  … %d/%d pages (img=%d ocr=%d alto=%d)", i, n, n_img, n_ocr, n_alto)

            # -- polite batching: rest after every `batch_size` in-range pages -----
            # A batch served entirely from cache made no requests, so it does not
            # pause — resuming a part-downloaded volume stays fast.
            if in_range and batch_size > 0:
                batch_pos += 1
                if batch_pos >= batch_size:
                    did = n_fetched - batch_mark
                    if did and i < hi:
                        if bar_live:
                            bar.set_postfix(fetched=n_fetched,
                                            resting=f"{batch_pause:.0f}s")
                        else:
                            log.info("  batch: %d pages, %d requests — pausing %.0fs",
                                     batch_pos, did, batch_pause)
                        time.sleep(batch_pause)
                        bar.set_postfix(fetched=n_fetched)
                    batch_pos = 0
                    batch_mark = n_fetched

    # -- assemble outputs -----------------------------------------------
    result: dict = {"pid": pid, "title": title, "model": model, "date": date,
                     "pages": n, "images": n_img, "ocr_pages": n_ocr, "alto_pages": n_alto,
                     "range": (lo, hi), "complete": n_img >= n}

    if partial:
        log.info("Cache: %d/%d scans, %d/%d OCR, %d/%d ALTO.", n_img, n, n_ocr, n, n_alto, n)
        log.info("Re-run with no --page-from/--page-to once complete to assemble "
                 "the PDF/TXT (that pass fetches nothing).")
        return result

    if make_pdf and image_paths:
        out_pdf = out_dir / f"{slug}.pdf"
        backend = _build_pdf(image_paths, out_pdf)
        size_mb = out_pdf.stat().st_size / 1e6
        log.info("PDF   -> %s  (%d pp, %.1f MB, via %s)", out_pdf.name, n_img, size_mb, backend)
        result["pdf"] = str(out_pdf)
        result["pdf_backend"] = backend
    elif make_pdf:
        log.warning("No page images fetched — PDF not written.")

    if make_txt and ocr_parts:
        out_txt = out_dir / f"{slug}.txt"
        head = (f"OCR text — {title}\nKramerius PID: {pid}\n"
                f"Source host: {client.base}\nPages with OCR: {n_ocr}/{n}\n"
                + "=" * 70)
        out_txt.write_text(head + "".join(ocr_parts) + "\n", encoding="utf-8")
        log.info("TXT   -> %s  (%d/%d pages had OCR)", out_txt.name, n_ocr, n)
        result["txt"] = str(out_txt)

    log.info("Page cache kept at %s (img=%d ocr=%d alto=%d of %d pages).",
              pages_dir, n_img, n_ocr, n_alto, n)
    if not keep_pages:
        log.info("(--keep-pages not set, but v7 module always keeps the cache; "
                 "delete %s manually if you don't need it.)", pages_dir)

    if n_missing_img:
        log.warning("%d/%d pages had no downloadable image.", n_missing_img, n)
    if save_alto and n_alto == 0:
        log.warning("No ALTO XML available for any page of this document/host.")
    return result

#!/usr/bin/env python3
"""
Kramerius v7 downloader — importable module + CLI.

Downloads a whole digital-library document (all its pages) from a Kramerius 7
instance as a single **PDF** (the page scans), a concatenated **TXT** (the
per-page OCR) and, where present, per-page **ALTO** XML (word coordinates).
Written for the *Moravskoslezská vědecká knihovna* (MSVK, `kramerius.msvk.cz`)
but should work against any Kramerius 7.x "client v7.0" REST API; just pass
``--host``.

Why this is a separate module from ``scraper_kramerius.py``
-------------------------------------------------------------
That module targets Kramerius **v5** (``/search/api/v5.0/item/{pid}/...``,
``streams/IMG_FULL`` datastream names). Kramerius **v7** renamed almost
everything: a different base path, JSON-only responses shaped differently, no
``children`` endpoint (404), and per-page datastreams that hang off
``/items/{pid}/image`` and ``/items/{pid}/ocr/...`` instead of a generic
``streams/{NAME}``. The two APIs are incompatible enough that patching one
module to handle both would obscure more than it saved, so this is a fresh,
parallel implementation that mirrors the v5 module's *conventions*
(docstring shape, ``__version__``, client class, ``download_document()``
entry point, argparse CLI, resumable page cache, PDF assembly) so the two
scrapers stay interchangeable from the caller's point of view.

What a Kramerius 7 document looks like
---------------------------------------
Every object has a ``pid`` (``uuid:XX…``) and a ``model``. A ``monograph``
(or ``periodical`` / ``periodicalvolume`` / ``periodicalitem`` / ``monographunit``)
holds page children directly; leaf pages have ``model == "page"``. Kramerius 7
also has an ``internalpart`` model (chapter/section headings such as
"Vorwort") that hangs off the same parent via ``hasIntCompPart`` but does
**not** introduce further pages of its own — it just labels a range of the
same pages via a foster ``isOnPage`` relation — so it is ignored when
collecting the page list.

Two ways to enumerate the pages were probed against this host; both work and
return an identical, sort-index-ordered page list, so this module uses
whichever the caller does not override:

    /search/api/client/v7.0/items/{pid}/info/structure
        -> {"children": {"own": [{"pid", "relation": "hasPage"|"hasIntCompPart"}, ...]}}
        Filter to ``relation == "hasPage"``; the array order already matches
        document order (verified against ``page.index`` below).

    /search/api/client/v7.0/search
        ?q=own_parent.pid:"{pid}" AND model:page
        &rows=2000&sort=rels_ext_index.sort asc
        &fl=pid,model,title.search,page.index,page.number
        -> {"response": {"docs": [{"pid", "page.index", "page.number", ...}, ...]}}
        Explicitly sorted by the Fedora RELS-EXT ordering predicate; carries
        the printed page number/label for free. This is what the module uses
        by default (``iter_pages``), falling back to ``info/structure`` if the
        Solr query ever comes back empty.

``/search/api/client/v7.0/items/{pid}/children`` (the v5-shaped guess) is a
straight 404 on this host — do not use it.

Per-document metadata / access info:

    /search/api/client/v7.0/items/{pid}/info
        -> {"providedByLicenses": [...], "data": {"image": {...}, "ocr": {...}}, ...}
        Access-policy summary (e.g. "public"), not a display title.

    /search/api/client/v7.0/search?q=pid:"{pid}"&fl=pid,model,title.search,
        title.sort,date.str,root.pid,root.title
        -> the actual bibliographic title, root title, model and date. Used
        for the identity check and the output filename.

    /search/api/client/v7.0/items/{pid}/info/data
        -> {"image": {"preview","thumb","full"}, "ocr": {"text","alto"}, ...}
        Per-item boolean availability flags — checked once per page so a
        genuinely-absent stream is skipped without wasting a 404 round-trip
        (Kramerius 7 answers a missing datastream with 404, not an empty body).

Per-page datastreams (confirmed present on kramerius.msvk.cz, 2026-08):

    /items/{pid}/image        image/jpeg   full-resolution page scan  -> PDF
    /items/{pid}/ocr/text     text/plain   OCR of that page           -> TXT
    /items/{pid}/ocr/alto     text/xml     ALTO word coordinates      -> per-page XML (if present)

Progress
--------
A ``tqdm`` bar is drawn over the page loop (``--no-progress``, or
``progress=False``, falls back to a log line every 25 pages).  Several documents
can share one screen by giving each a ``progress_position`` — see
``run_lexicon_downloads.py``.

TLS note
--------
``requests`` fails certificate verification against this host even though the
Windows trust store (and curl) accept it — the local certifi bundle is stale
for this host's chain. Default here is therefore ``verify_tls=False`` (the
opposite default from the v5 module, which talks to a host that verifies
fine); pass ``--verify-tls`` to force verification back on.

CLI usage
---------
    python utils/scraping/scraper_kramerius7.py \\
        --url "https://kramerius.msvk.cz/view/uuid:522ce040-5386-11df-a073-0013d398622b" \\
        --out library/lexicons --name MSVK_Spezialortsrepertorium-Schlesien-1910_de --alto
"""

# Version

__version__ = "1.2.0"

log = logging.getLogger("scraper_kramerius7")

# ---------------------------------------------------------------------------
# Defaults
# ---------------------------------------------------------------------------
DEFAULT_HOST = "https://kramerius.msvk.cz"   # MSVK (Moravskoslezská vědecká knihovna)
API_PATH = "/search/api/client/v7.0"
USER_AGENT = "scraper_kramerius7/%s" % __version__
PAGE_MODEL = "page"


# ---------------------------------------------------------------------------
# Client
# ---------------------------------------------------------------------------
class Kramerius7Client:
    """Thin, polite wrapper over the Kramerius 7 "client v7.0" read API."""

    def __init__(
        self,
        host: str = DEFAULT_HOST,
        *,
        delay: float = 0.5,
        timeout: float = 60.0,
        retries: int = 4,
        verify_tls: bool = False,
    ) -> None:
        self.base = host.rstrip("/") + API_PATH
        self.delay = delay
        self.timeout = timeout
        self.retries = retries
        self.session = requests.Session()
        self.session.headers.update({"User-Agent": USER_AGENT})
        self.session.verify = verify_tls
        if not verify_tls:
            import urllib3
            urllib3.disable_warnings(urllib3.exceptions.InsecureRequestWarning)

    # -- low level ------------------------------------------------------
    def _get(self, url: str, **kwargs) -> requests.Response:
        """GET with linear backoff on 429/5xx; raise on other 4xx (incl. 404)."""
        last_exc: Exception | None = None
        for attempt in range(1, self.retries + 1):
            try:
                r = self.session.get(url, timeout=self.timeout, **kwargs)
                if r.status_code in (429, 500, 502, 503, 504):
                    wait = self.delay * attempt * 3
                    log.warning("  %s on %s — retry %d/%d in %.1fs",
                                r.status_code, url, attempt, self.retries, wait)
                    time.sleep(wait)
                    continue
                r.raise_for_status()
                if self.delay:
                    time.sleep(self.delay)
                return r
            except requests.RequestException as exc:
                # 4xx (incl. 404 "no such datastream") should not be retried —
                # raise_for_status already raised for those; this branch is
                # network hiccups (timeout, connection reset, etc.)
                if isinstance(exc, requests.HTTPError) and exc.response is not None \
                        and exc.response.status_code not in (429, 500, 502, 503, 504):
                    raise
                last_exc = exc
                wait = self.delay * attempt * 3
                log.warning("  %s on %s — retry %d/%d in %.1fs",
                            exc.__class__.__name__, url, attempt, self.retries, wait)
                time.sleep(wait)
        raise RuntimeError(f"GET failed after {self.retries} tries: {url}") from last_exc

    # -- metadata ---------------------------------------------------------
    def solr_doc(self, pid: str, fl: str = "pid,model,title.search,title.sort,date.str,root.pid,root.title") -> dict:
        """Look up one item's Solr document (title, model, date, root title)."""
        url = f"{self.base}/search?q=pid:%22{pid}%22&fl={fl}"
        docs = self._get(url).json().get("response", {}).get("docs", [])
        return docs[0] if docs else {}

    def info(self, pid: str) -> dict:
        """Access-policy / license summary for an item."""
        return self._get(f"{self.base}/items/{pid}/info").json()

    def info_data(self, pid: str) -> dict:
        """Per-item datastream availability flags (image/ocr/audio/metadata booleans)."""
        return self._get(f"{self.base}/items/{pid}/info/data").json()

    def structure(self, pid: str) -> dict:
        return self._get(f"{self.base}/items/{pid}/info/structure").json()

    # -- streams ------------------------------------------------------------
    def try_bytes(self, url: str) -> bytes | None:
        try:
            return self._get(url).content
        except Exception as exc:
            log.debug("    no data at %s (%s)", url, exc)
            return None

    def try_text(self, url: str) -> str | None:
        try:
            r = self._get(url)
            # force UTF-8; Kramerius OCR is UTF-8 but requests may guess wrong
            # if the response omits/mis-states charset.
            return r.content.decode("utf-8", errors="replace")
        except Exception as exc:
            log.debug("    no data at %s (%s)", url, exc)
            return None

    def image(self, pid: str) -> bytes | None:
        return self.try_bytes(f"{self.base}/items/{pid}/image")

    def ocr_text(self, pid: str) -> str | None:
        return self.try_text(f"{self.base}/items/{pid}/ocr/text")

    def ocr_alto(self, pid: str) -> str | None:
        return self.try_text(f"{self.base}/items/{pid}/ocr/alto")

    # -- page listing ---------------------------------------------------
    def iter_pages(self, pid: str) -> Iterator[dict]:
        """Yield page dicts (pid, label, index) in document order.

        Tries the Solr ``own_parent.pid`` query first (explicitly sorted by
        the Fedora RELS-EXT ordering predicate, and carries the printed page
        number as ``page.number``); falls back to ``info/structure`` — whose
        ``children.own`` array order also matches document order — if the
        Solr query comes back empty (e.g. a host that has not indexed
        ``own_parent.pid``).
        """
        url = (f"{self.base}/search?q=own_parent.pid:%22{pid}%22+AND+model:page"
               f"&rows=5000&sort=rels_ext_index.sort%20asc"
               f"&fl=pid,model,title.search,page.index,page.number")
        docs = self._get(url).json().get("response", {}).get("docs", [])
        if docs:
            for d in docs:
                yield {"pid": d["pid"], "label": d.get("page.number") or d.get("title.search") or "",
                       "index": d.get("page.index")}
            return

        log.info("  Solr own_parent query empty — falling back to info/structure")
        struct = self.structure(pid)
        own = struct.get("children", {}).get("own", [])
        for i, child in enumerate(own):
            if child.get("relation") == "hasPage":
                yield {"pid": child["pid"], "label": str(i), "index": i}

def parse_pid(url_or_pid: str) -> str:
    """Extract the document ``uuid:…`` from a viewer URL or accept a bare pid."""
    s = url_or_pid.strip()
    m = re.search(r"/(?:view|uuid|periodical|monograph)/(uuid:[0-9a-fA-F-]+)", s)
    if m:
        return m.group(1)
    m = re.search(r"(uuid:[0-9a-fA-F-]+)", s.split("?page=")[0])
    if m:
        return m.group(1)
    if re.fullmatch(r"[0-9a-fA-F-]{36}", s):
        return "uuid:" + s
    raise ValueError(f"could not find a uuid in: {url_or_pid!r}")


def parse_host(url: str) -> str | None:
    """Return scheme+host from a viewer URL (Kramerius 7 API lives on the same host)."""
    m = re.match(r"https?://([^/]+)", url)
    return f"https://{m.group(1)}" if m else None


_ILLEGAL = re.compile(r'[<>:"/\\|?*\x00-\x1f]')


def safe_filename(text: str, *, max_len: int = 120) -> str:
    text = _ILLEGAL.sub("", text)
    text = re.sub(r"\s+", " ", text).strip().rstrip(". ")
    if len(text) > max_len:
        text = text[:max_len].rstrip(". ")
    return text or "kramerius_document"


def _build_pdf(image_paths: list[Path], out_pdf: Path) -> str:
    """Assemble a PDF from JPEG page files. Returns the backend used."""
    try:
        import img2pdf  # lossless: embeds the JPEGs unchanged
        with open(out_pdf, "wb") as fh:
            fh.write(img2pdf.convert([str(p) for p in image_paths]))
        return "img2pdf"
    except ImportError:
        from PIL import Image  # fallback: re-encodes
        imgs = [Image.open(p).convert("RGB") for p in image_paths]
        imgs[0].save(out_pdf, "PDF", save_all=True, append_images=imgs[1:])
        for im in imgs:
            im.close()
        return "Pillow"


# ---------------------------------------------------------------------------
# Main entry point
# ---------------------------------------------------------------------------
def download_document(
    url_or_pid: str,
    out_dir: str | Path,
    *,
    host: str | None = None,
    make_pdf: bool = True,
    make_txt: bool = True,
    per_page_txt: bool = False,
    save_alto: bool = True,
    delay: float = 0.5,
    verify_tls: bool = False,
    keep_pages: bool = True,
    name: str | None = None,
    page_from: int = 1,
    page_to: int | None = None,
    batch_size: int = 20,
    batch_pause: float = 10.0,
    progress: bool = True,
    progress_position: int | None = None,
    progress_desc: str | None = None,
) -> dict:
    """Download pages of a Kramerius 7 document to ``out_dir``.

    Returns a small summary dict. Page images/OCR/ALTO are cached under
    ``out_dir/<slug>_pages/`` so a re-run resumes instead of re-fetching
    (each page artefact is skipped if already present with nonzero size).

    Downloading is **batched by default**: every ``batch_size`` pages the run
    pauses for ``batch_pause`` seconds, so a long volume is pulled in polite
    bursts rather than one sustained stream.  A batch served entirely from cache
    does not pause, so resuming stays fast.  ``batch_size=0`` disables batching.

    ``page_from``/``page_to`` (1-based, inclusive) restrict the fetch to a slice
    of the document — use these to stop after a fixed slice, not for pacing
    (batching already handles that).  Page numbering stays global, so ranges
    share one cache directory.  A partial range fills the cache only — re-run
    with no range once complete to assemble the PDF/TXT (that pass fetches
    nothing).

    A ``tqdm`` progress bar over the page loop is on by default; pass
    ``progress=False`` for the older every-25-pages log line instead.
    ``progress_position`` stacks the bar when several documents run at once
    (see ``run_lexicon_downloads.py``), ``progress_desc`` labels it.
    """
    pid = parse_pid(url_or_pid)
    if host is None and url_or_pid.lower().startswith("http"):
        host = parse_host(url_or_pid)
    client = Kramerius7Client(host or DEFAULT_HOST, delay=delay, verify_tls=verify_tls)

    doc = client.solr_doc(pid)
    # `name` overrides the output *filename stem* only — the title stays whatever
    # the library calls the volume, so it is what the TXT header reports.
    title = doc.get("title.search") or doc.get("root.title") or pid
    model = doc.get("model", "?")
    date = doc.get("date.str", "?")
    root_title = doc.get("root.title", "")

    slug = safe_filename(name or title)
    out_dir = Path(out_dir)
    out_dir.mkdir(parents=True, exist_ok=True)
    pages_dir = out_dir / f"{slug}_pages"
    pages_dir.mkdir(exist_ok=True)

    log.info("Title    : %s", title)
    log.info("Root     : %s", root_title)
    log.info("PID      : %s  (model=%s, date=%s, host=%s)", pid, model, date, client.base)

    log.info("Collecting page list …")
    pages = list(client.iter_pages(pid))
    n = len(pages)
    log.info("  %d pages", n)
    if n == 0:
        raise RuntimeError("no pages found under this pid")

    lo = max(1, page_from)
    hi = min(n, page_to if page_to is not None else n)
    partial = (lo > 1) or (hi < n)
    if partial:
        log.info("Range    : pages %d–%d of %d (partial — PDF/TXT not assembled)", lo, hi, n)
    if batch_size > 0:
        log.info("Batching : %d pages per batch, %.0fs pause between batches",
                 batch_size, batch_pause)

    image_paths: list[Path] = []
    ocr_parts: list[str] = []
    n_img = n_ocr = n_alto = n_missing_img = n_fetched = 0
    batch_pos = batch_mark = 0

    bar = page_bar(n, progress_desc or slug, enabled=progress, position=progress_position)
    bar_live = getattr(bar, "live", False)

    # With a bar drawn, every log line goes through tqdm.write so it does not
    # shred it; without one, the every-25-pages line below is the only progress.
    with bar, redirect_logging():
        for i, pg in enumerate(pages, 1):
            ppid = pg["pid"]
            label = str(pg.get("label") or i)
            img_path = pages_dir / f"{i:04d}.jpg"
            txt_path = pages_dir / f"{i:04d}.txt"
            alto_path = pages_dir / f"{i:04d}.alto.xml"
            in_range = lo <= i <= hi

            # -- image (cached / resumable) --------------------------------
            if make_pdf:
                if img_path.exists() and img_path.stat().st_size > 0:
                    image_paths.append(img_path)
                    n_img += 1
                elif in_range:
                    data = client.image(ppid)
                    if data is None:
                        n_missing_img += 1
                        log.warning("  p%d/%d %-8s no image (skipped in PDF)", i, n, label)
                    else:
                        img_path.write_bytes(data)
                        image_paths.append(img_path)
                        n_img += 1
                        n_fetched += 1

            # -- OCR text (always cached to disk -> resumable regardless of
            #    per_page_txt, which only controls whether it's kept vs. tidied) -
            txt = None
            if make_txt or per_page_txt:
                if txt_path.exists() and txt_path.stat().st_size > 0:
                    txt = txt_path.read_text(encoding="utf-8")
                elif in_range:
                    txt = client.ocr_text(ppid)
                    if txt is not None:
                        txt_path.write_text(txt, encoding="utf-8")
                        n_fetched += 1
                if txt is not None:
                    n_ocr += 1
                    header = f"\n\n===== p. {i}  ({label})  [{ppid}] =====\n"
                    ocr_parts.append(header + txt.strip())

            # -- ALTO (word coordinates) --------------------------------------
            if save_alto:
                if alto_path.exists() and alto_path.stat().st_size > 0:
                    n_alto += 1
                elif in_range:
                    alto = client.ocr_alto(ppid)
                    if alto is not None:
                        alto_path.write_text(alto, encoding="utf-8")
                        n_alto += 1
                        n_fetched += 1
                    else:
                        log.debug("  p%d/%d %-8s no ALTO", i, n, label)

            bar.update(1)
            bar.set_postfix(fetched=n_fetched, refresh=False)
            if not bar_live and (i % 25 == 0 or i == n):
                log.info("  … %d/%d pages (img=%d ocr=%d alto=%d)", i, n, n_img, n_ocr, n_alto)

            # -- polite batching: rest after every `batch_size` in-range pages -----
            # A batch served entirely from cache made no requests, so it does not
            # pause — resuming a part-downloaded volume stays fast.
            if in_range and batch_size > 0:
                batch_pos += 1
                if batch_pos >= batch_size:
                    did = n_fetched - batch_mark
                    if did and i < hi:
                        if bar_live:
                            bar.set_postfix(fetched=n_fetched,
                                            resting=f"{batch_pause:.0f}s")
                        else:
                            log.info("  batch: %d pages, %d requests — pausing %.0fs",
                                     batch_pos, did, batch_pause)
                        time.sleep(batch_pause)
                        bar.set_postfix(fetched=n_fetched)
                    batch_pos = 0
                    batch_mark = n_fetched

    # -- assemble outputs -----------------------------------------------
    result: dict = {"pid": pid, "title": title, "model": model, "date": date,
                     "pages": n, "images": n_img, "ocr_pages": n_ocr, "alto_pages": n_alto,
                     "range": (lo, hi), "complete": n_img >= n}

    if partial:
        log.info("Cache: %d/%d scans, %d/%d OCR, %d/%d ALTO.", n_img, n, n_ocr, n, n_alto, n)
        log.info("Re-run with no --page-from/--page-to once complete to assemble "
                 "the PDF/TXT (that pass fetches nothing).")
        return result

    if make_pdf and image_paths:
        out_pdf = out_dir / f"{slug}.pdf"
        backend = _build_pdf(image_paths, out_pdf)
        size_mb = out_pdf.stat().st_size / 1e6
        log.info("PDF   -> %s  (%d pp, %.1f MB, via %s)", out_pdf.name, n_img, size_mb, backend)
        result["pdf"] = str(out_pdf)
        result["pdf_backend"] = backend
    elif make_pdf:
        log.warning("No page images fetched — PDF not written.")

    if make_txt and ocr_parts:
        out_txt = out_dir / f"{slug}.txt"
        head = (f"OCR text — {title}\nKramerius PID: {pid}\n"
                f"Source host: {client.base}\nPages with OCR: {n_ocr}/{n}\n"
                + "=" * 70)
        out_txt.write_text(head + "".join(ocr_parts) + "\n", encoding="utf-8")
        log.info("TXT   -> %s  (%d/%d pages had OCR)", out_txt.name, n_ocr, n)
        result["txt"] = str(out_txt)

    log.info("Page cache kept at %s (img=%d ocr=%d alto=%d of %d pages).",
              pages_dir, n_img, n_ocr, n_alto, n)
    if not keep_pages:
        log.info("(--keep-pages not set, but v7 module always keeps the cache; "
                 "delete %s manually if you don't need it.)", pages_dir)

    if n_missing_img:
        log.warning("%d/%d pages had no downloadable image.", n_missing_img, n)
    if save_alto and n_alto == 0:
        log.warning("No ALTO XML available for any page of this document/host.")
    return result


# ---------------------------------------------------------------------------
# CLI
# ---------------------------------------------------------------------------
def _build_argparser() -> argparse.ArgumentParser:
    p = argparse.ArgumentParser(
        description="Download a Kramerius 7 document (all pages) as PDF + OCR TXT + ALTO XML.",
        formatter_class=argparse.ArgumentDefaultsHelpFormatter,
    )
    src = p.add_mutually_exclusive_group(required=True)
    src.add_argument("--url", help="viewer URL, e.g. https://kramerius.msvk.cz/view/uuid:…")
    src.add_argument("--uuid", help="bare document pid, e.g. uuid:522ce040-… (or the 36-char id)")
    p.add_argument("--out", default="library/downloads", help="output directory")
    p.add_argument("--host", default=None, help="Kramerius 7 backend host (default: kramerius.msvk.cz)")
    p.add_argument("--name", default=None, help="override the output filename stem")
    p.add_argument("--no-pdf", action="store_true", help="skip the PDF (OCR only)")
    p.add_argument("--no-txt", action="store_true", help="skip the OCR TXT (PDF only)")
    p.add_argument("--per-page-txt", action="store_true", help="also write one .txt per page (default: on)")
    p.add_argument("--no-alto", action="store_true", help="skip per-page ALTO xml (default: fetched)")
    p.add_argument("--page-from", type=int, default=1,
                   help="first page to fetch (1-based, inclusive)")
    p.add_argument("--page-to", type=int, default=None,
                   help="last page to fetch (1-based, inclusive). A partial range "
                        "fills the cache only; re-run with no range to assemble.")
    p.add_argument("--batch-size", type=int, default=20,
                   help="pages per batch before pausing (0 = no batching)")
    p.add_argument("--batch-pause", type=float, default=10.0,
                   help="seconds to rest between batches")
    p.add_argument("--delay", type=float, default=0.5, help="seconds between requests")
    p.add_argument("--verify-tls", action="store_true", help="enable TLS verification (default: disabled)")
    p.add_argument("--no-progress", action="store_true",
                   help="no progress bar; log every 25 pages instead")
    p.add_argument("-v", "--verbose", action="store_true", help="debug logging")
    return p


def main(argv: list[str] | None = None) -> int:
    args = _build_argparser().parse_args(argv)
    logging.basicConfig(
        level=logging.DEBUG if args.verbose else logging.INFO,
        format="%(message)s",
    )
    try:
        download_document(
            args.url or args.uuid,
            out_dir=args.out,
            host=args.host,
            make_pdf=not args.no_pdf,
            make_txt=not args.no_txt,
            per_page_txt=True,  # v7 module always writes per-page txt (needed for resumability)
            save_alto=not args.no_alto,
            delay=args.delay,
            verify_tls=args.verify_tls,
            name=args.name,
            page_from=args.page_from,
            page_to=args.page_to,
            batch_size=args.batch_size,
            batch_pause=args.batch_pause,
            progress=not args.no_progress,
        )
    except Exception as exc:
        log.error("FAILED: %s", exc)
        return 1
    return 0


if __name__ == "__main__":
    sys.exit(main())
