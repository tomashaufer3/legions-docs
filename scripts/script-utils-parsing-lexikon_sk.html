TL;DR

Transleithanian analogue of utils.parsing.lexikon (the Czech ČSÚ register). Parses the 1910 period-administrative section of Juraj Majo's Historicko-demografický lexikón obcí Slovenska 1880–1910 (Štatistický úrad SR, 2012; library/lexicons/Majo-2012_Historicko-demograficky-lexikon-obci-Slovenska_1880-1910.pdf) into an obec → 1910 okres/župa crosswalk carrying the mother-tongue breakdown.

How it works

Why this fills a gap

The GISta backbone (utils.parsing.districts_hu) + census (utils.parsing.census_hu) are district-level only, and utils.parsing.records_geo_hu can therefore resolve a Slovak birthplace only when the string is a district/county seat (or a curated alias). This lexicon supplies the missing settlement layer — every obec on today's Slovak territory with its 1910 okres — so an ordinary village birth resolves to its járás, joining the census. It is the exact counterpart of how lexikon feeds records_geo on the Czech side.

Section & layout

Part I (mother tongue), sub-part 1910.1 (structure as at the 1910 census) spans printed pages 758–875, ordered ŽUPA (county) → okres (district) → obec, with časti obce (settlement parts) as un-numbered sub-rows. Names are the standardised Slovak forms (the okres name is the Slovak district seat — the join key to the GISta name_sk). Nine right-aligned numeric columns follow each name:

1 total · 2 slovak · 3 magyar · 4 german · 5 romanian · 6 rusyn · 7 croat · 8 serb · 9 other

Because zero columns are simply not printed, a trailing value cannot be assigned to its category by text order (Myjava's 114 is other, not romanian). We therefore read word x-coordinates with pdfplumber and assign each number to the column whose header anchor (a b 1 2 … 9 row) it sits under — by its right edge, because the columns are right-aligned (see _bounds). Row totals are sum-checked against the categories.

Section headers

Two dividers structure the section, and each is printed in more than one wording. Both defects found on 2026-08-01 were the same mistake — a regex narrower than the source — so the full inventory is recorded here and in the regexes below:

  • an okres divider, printed either okres X or, three times, adjectivally as X okres (Hradný okres, Pohronský okres, Medzibodrocký okres) — DECISIONS D-21;
  • a chartered-town divider closing each county, in four wordings, singular and plural (mesto so župnou právomocou / mesto so župnými právomocami / mesto so zriadeným magistrátom / mestá so zriadeným magistrátom) — DECISIONS D-20.

Usage

from utils.parsing import lexikon_sk as lxs

cross = lxs.build_crosswalk_sk(SK_LEXIKON_PDF, backbone_hu) # + GISta unit_id + language shares

def parse_lexikon_sk(pdf_path, page_first: int = _PAGE_FIRST, page_last: int = _PAGE_LAST
                     ) -> pd.DataFrame:
    """Parse the 1910.1 section → one row per obec / *časť obce* with mother-tongue counts.

    Columns: ``obec_sk`` · ``unit_type`` (``obec`` / ``part`` / ``town``) · ``parent`` (parent obec
    for a part) · ``okres_sk`` · ``zupa_sk`` · ``pop_total`` · ``n_{slovak,magyar,german,romanian,
    rusyn,croat,serb,other}`` · ``sum_ok`` (categories reconcile to the total).
    """
    recs: list[dict] = []
    zupa = okres = None
    kind = "jaras"                      # 'jaras' (obce sit in an okres) | 'town' (standalone unit)
    parent: str | None = None

    with pdfplumber.open(str(pdf_path)) as pdf:
        for i, page in enumerate(pdf.pages):
            if i < _IDX_LO:                       # scan-speed prefilter (see module header)
                continue
            if i > _IDX_HI:
                break
            words = page.extract_words()
            if not words:
                continue
            pno = _printed_page_no(words)
            if pno is None or not (page_first <= pno <= page_last):
                continue
            rows = _rows(words)
            anchors = _anchors(rows)
            if anchors is None:
                continue
            for r in rows:
                toks = [w["text"] for w in r]
                text = " ".join(toks)
                low = text.lower()
                # ── structural lines ────────────────────────────────────────
                if "p.č" in low or low.startswith(("a b", "obyvateľov", "počet")):
                    continue                                   # repeating column header
                mz = _ZUPA.match(text)
                if mz and not any(w["x0"] >= _NUM_X0 for w in r):
                    new_zupa = _clean_zupa(mz.group("n"))
                    if new_zupa != zupa:               # real county change (not the repeating header)
                        zupa, okres, kind, parent = new_zupa, None, "jaras", None
                    continue
                mo = _OKRES.match(text)
                if mo and not any(w["x0"] >= _NUM_X0 for w in r):
                    name_ = (mo.group("full") or mo.group("adj")).strip()
                    okres, kind, parent = name_, "jaras", None
                    continue
                if _TOWN.match(text):
                    okres, kind, parent = None, "town", None
                    continue
                if low.startswith("spolu"):
                    continue                                   # okres / župa subtotal

                # ── data rows (obec / part) ─────────────────────────────────
                nums = [w for w in r if w["x0"] >= _NUM_X0 and re.fullmatch(r"\d+", w["text"])]
                name_ws = [w for w in r if w["x0"] < _NUM_X0]
                has_pc = bool(name_ws) and name_ws[0]["x1"] <= _PC_X1 and name_ws[0]["text"].isdigit()
                name_ws = name_ws[1:] if has_pc else name_ws
                name = " ".join(w["text"] for w in name_ws).strip()
                is_x = "x" in [w["text"] for w in r] and not nums          # obec with no counts
                if not name or (not nums and not is_x):
                    continue

                unit_type = "town" if kind == "town" else ("obec" if has_pc else "part")
                vals = _read_numbers(nums, anchors) if nums else [None] * 9
                rec = {"obec_sk": name, "unit_type": unit_type,
                       "parent": parent if unit_type == "part" else None,
                       "okres_sk": okres, "zupa_sk": zupa,
                       "pop_total": vals[0]}
                for c, v in zip(_CATS, vals[1:]):
                    rec[f"n_{c}"] = v
                cats = [v for v in vals[1:] if v is not None]
                rec["sum_ok"] = (vals[0] is not None and sum(cats) == vals[0])
                recs.append(rec)
                if unit_type == "obec":
                    parent = name                              # parts below inherit this obec

    return pd.DataFrame.from_records(recs)

Parse + attach the GISta unit_id (járás/town) and mother-tongue shares.

unit_id is resolved from the lexicon okres (a district, Slovak-named). The backbone stores that district as jaras_hu (Magyar adjectival) with name_sk = the seat town — a different place — so the matcher keys each járás by: its Slovak seat name(s), its Magyar seat, and the district name recovered from jaras_hu via the backbone's own Magyar→Slovak map (chartered-town exonym pairs); then exact, then subset-guarded rapidfuzz ≥ fuzzy_threshold. def build_crosswalk_sk(pdf_path, backbone_hu: pd.DataFrame, fuzzy_threshold: int = 90
                       ) -> pd.DataFrame:
    """Parse + attach the GISta ``unit_id`` (járás/town) and mother-tongue shares.

    ``unit_id`` is resolved from the lexicon ``okres`` (a *district*, Slovak-named). The backbone
    stores that district as ``jaras_hu`` (Magyar adjectival) with ``name_sk`` = the *seat* town —
    a different place — so the matcher keys each járás by: its Slovak seat name(s), its Magyar seat,
    and the **district** name recovered from ``jaras_hu`` via the backbone's own Magyar→Slovak map
    (chartered-town exonym pairs); then exact, then subset-guarded rapidfuzz ≥ *fuzzy_threshold*.
    The handful of district exonyms whose base town is absent from the backbone (Fülek→Fiľakovo,
    Párkány→Štúrovo, Rimaszécs→Rimavská Seč, Udvard→Dvory nad Žitavou) are curated as ``name_sk`` /
    ``name_sk_alt`` in ``district_sk_curation.csv`` (Wikidata-validated). A ``town`` row maps to the
    backbone town unit of the same name. Rows whose district is a Hungarian-seated okres outside the
    Felvidék backbone (e.g. Cserhát, Rajka) or a region label (Žitný ostrov) keep ``unit_id`` =
    ``<NA>`` and are reported.
    """
    df = parse_lexikon_sk(pdf_path)

    # The backbone's own Magyar→Slovak dictionary: name_hu → name_sk over EVERY unit that carries
    # both. Chartered towns supply the exonym pairs the district names need (Érsekújvár↔Nové Zámky,
    # Nagyrőce↔Revúca, …), so the crosswalk needs no external source for most of them.
    hu2sk = {_norm(r["name_hu"]): r["name_sk"]
             for _, r in backbone_hu.iterrows() if r.get("name_hu") and r.get("name_sk")}

    # járás lookup: norm(name) -> unit_id. Keys per járás: Slovak seat name(s) + Magyar seat + the
    # DISTRICT name. The lexicon's "okres X" is the district (jaras_hu adjectival, e.g. Érsekújvári),
    # NOT the seat settlement (name_sk = Šurany); derive the district's Slovak name from the jaras_hu
    # base town via hu2sk so "okres Nové Zámky" reaches the Érsekújvári járás. (name_sk_alt also
    # carries curated district exonyms whose base town is absent from the backbone — Fülek→Fiľakovo.)
    jar = backbone_hu[backbone_hu["unit_type"] == "járás"].copy()
    seat_lut = {}
    for _, r in jar.iterrows():
        keys = [r.get("name_sk"), r.get("name_sk_alt"), r.get("name_sk_modern"), r.get("name_hu")]
        base = _hu_adj_base(r.get("jaras_hu"))
        if base:
            keys += [base, hu2sk.get(_norm(base))]        # Magyar district base + its Slovak form
        for nm in keys:
            k = _norm(nm)
            if k:
                seat_lut.setdefault(k, r["unit_id"])
    town_lut = {}
    for _, r in backbone_hu[backbone_hu["unit_type"] != "járás"].iterrows():
        for nm in (r.get("name_sk"), r.get("name_sk_alt"), r.get("name_sk_modern")):
            k = _norm(nm)
            if k:
                town_lut.setdefault(k, r["unit_id"])

    from rapidfuzz import process, fuzz
    seat_keys, town_keys = list(seat_lut), list(town_lut)

    def _lut_unit(name, lut: dict, keys: list):
        """Slovak name → GISta unit_id: exact, else token-subset fuzzy.

        The lexicon uses the *1910* short name (``Brezno``, ``Bytča``) while the backbone often
        carries the modern full form (``Brezno nad Hronom``, ``Veľká Bytča``); a subset-guarded
        ``token_set_ratio`` bridges these without accepting mere letter overlap (``Fiľakovo`` vs
        ``Ilava`` scored 62, safely below threshold). Used for both lookups — the chartered towns
        need it for exactly the same reason the districts do: the lexicon prints ``Brezno``, the
        backbone ``Brezno nad Hronom``, and without the fallback that town resolves to nothing.
        """
        k = _norm(name)
        if not k:
            return pd.NA
        if k in lut:
            return lut[k]
        m = process.extractOne(k, keys, scorer=fuzz.token_set_ratio)
        if m and m[1] >= fuzzy_threshold:
            a, b = set(k.split()), set(m[0].split())
            if a <= b or b <= a:                      # one name's tokens contained in the other's
                return lut[m[0]]
        return pd.NA

    def _okres_unit(okres):
        return _lut_unit(okres, seat_lut, seat_keys)

    unit_ids = []
    for _, r in df.iterrows():
        if r["unit_type"] == "town":
            # a town row carries no okres of its own (the block replaces it), so the town lookup
            # is the whole answer; the okres fallback only covers a row mis-typed as a town
            uid = _lut_unit(r["obec_sk"], town_lut, town_keys)
            unit_ids.append(uid if pd.notna(uid) else _okres_unit(r["okres_sk"]))
        else:
            unit_ids.append(_okres_unit(r["okres_sk"]))
    df["unit_id"] = pd.array(unit_ids, dtype="object")

    # mother-tongue shares (fraction of the obec's present population)
    pop = pd.to_numeric(df["pop_total"], errors="coerce")
    for share, col in [("slovak_share", "n_slovak"), ("magyar_share", "n_magyar"),
                       ("german_share", "n_german"), ("rusyn_share", "n_rusyn")]:
        df[share] = pd.to_numeric(df[col], errors="coerce").fillna(0) / pop.replace(0, pd.NA)

    df["name_norm"] = df["obec_sk"].map(_norm)
    return df.reset_index(drop=True)

def lexikon_sk_report(cross: pd.DataFrame) -> None:
    """Print coverage: obce/parts/towns, okres→unit mapping, sum-check, ethnicity summary."""
    n = len(cross)
    vc = cross["unit_type"].value_counts().to_dict()
    mapped = cross["unit_id"].notna().sum()
    with_pop = cross["pop_total"].notna().sum()
    sum_ok = cross["sum_ok"].sum()
    print(f"Slovak lexikón crosswalk (Majo 2012, 1910.1)  rows = {n}  {vc}")
    print(f"  okres/town -> GISta unit_id: {mapped}/{n} ({mapped/n*100:.1f}%)")
    print(f"  with population:             {with_pop}/{n} ({with_pop/n*100:.1f}%)")
    print(f"  category sum == total:       {sum_ok}/{with_pop} "
          f"({sum_ok/max(with_pop,1)*100:.1f}% of populated rows)")
    unmatched = sorted(set(cross.loc[cross["unit_id"].isna() & cross["okres_sk"].notna(), "okres_sk"]))
    if unmatched:
        print(f"  okres without a backbone unit ({len(unmatched)}): {', '.join(unmatched[:12])}"
              + (" …" if len(unmatched) > 12 else ""))
    if "slovak_share" in cross:
        s = cross.loc[cross["unit_type"] != "part", "slovak_share"].dropna()
        print(f"  Slovak-speaker share (obce/towns): mean {s.mean():.1%}, median {s.median():.1%} "
              f"(≥50% Slovak: {(s >= 0.5).sum()}/{len(s)})")

"""
lexikon_sk.py — Slovak settlement crosswalk + 1910 ethnicity from the Majo (2012) lexikón
=========================================================================================
Transleithanian analogue of :mod:`utils.parsing.lexikon` (the Czech ČSÚ register). Parses the
**1910 period-administrative section** of Juraj Majo's *Historicko-demografický lexikón obcí
Slovenska 1880–1910* (Štatistický úrad SR, 2012;
``library/lexicons/Majo-2012_Historicko-demograficky-lexikon-obci-Slovenska_1880-1910.pdf``) into an
**obec → 1910 okres/župa** crosswalk carrying the **mother-tongue** breakdown.

Why this fills a gap
--------------------
The GISta backbone (:mod:`utils.parsing.districts_hu`) + census (:mod:`utils.parsing.census_hu`)
are **district-level** only, and :mod:`utils.parsing.records_geo_hu` can therefore resolve a Slovak
birthplace **only** when the string is a district/county seat (or a curated alias). This lexicon
supplies the missing **settlement** layer — every obec on today's Slovak territory with its 1910
okres — so an ordinary village birth resolves to its járás, joining the census. It is the exact
counterpart of how :mod:`lexikon` feeds :mod:`records_geo` on the Czech side.

Section & layout
----------------
Part I (mother tongue), sub-part ``1910.1`` (structure *as at the 1910 census*) spans **printed
pages 758–875**, ordered ŽUPA (county) → okres (district) → obec, with *časti obce* (settlement
parts) as un-numbered sub-rows. Names are the standardised **Slovak** forms (the okres name is the
Slovak district seat — the join key to the GISta ``name_sk``). Nine right-aligned numeric columns
follow each name:

    1 total · 2 slovak · 3 magyar · 4 german · 5 romanian · 6 rusyn · 7 croat · 8 serb · 9 other

Because zero columns are simply **not printed**, a trailing value cannot be assigned to its category
by text order (Myjava's ``114`` is *other*, not *romanian*). We therefore read **word x-coordinates**
with :mod:`pdfplumber` and assign each number to the column whose header anchor (``a b 1 2 … 9`` row)
it sits under — by its **right** edge, because the columns are right-aligned (see :func:`_bounds`).
Row totals are sum-checked against the categories.

Section headers
---------------
Two dividers structure the section, and each is printed in more than one wording. Both defects
found on 2026-08-01 were the same mistake — a regex narrower than the source — so the full
inventory is recorded here and in the regexes below:

* an **okres** divider, printed either ``okres X`` or, three times, adjectivally as ``X okres``
  (``Hradný okres``, ``Pohronský okres``, ``Medzibodrocký okres``) — DECISIONS D-21;
* a **chartered-town** divider closing each county, in four wordings, singular *and* plural
  (``mesto so župnou právomocou`` / ``mesto so župnými právomocami`` /
  ``mesto so zriadeným magistrátom`` / ``mestá so zriadeným magistrátom``) — DECISIONS D-20.

Usage
-----
    from utils.parsing import lexikon_sk as lxs
    obce = lxs.parse_lexikon_sk(SK_LEXIKON_PDF)                 # raw obec/part rows + counts
    cross = lxs.build_crosswalk_sk(SK_LEXIKON_PDF, backbone_hu) # + GISta unit_id + language shares
    lxs.lexikon_sk_report(cross)
"""

from __future__ import annotations

import re
import statistics
from pathlib import Path

import pandas as pd

try:
    import pdfplumber
except ImportError as exc:  # pragma: no cover

# Printed-page span of the 1910.1 mother-tongue section (period administrative structure). The
# printed number is the precise selector (it also excludes the 1880/1890/1900 blocks, all ≤ 756,
# and 1910.2 / Part II, all ≥ 876); the PDF-index window is only a scan-speed prefilter for this
# fixed 2009-page artifact (printed 758–875 ≈ PDF pages 766–883).
_PAGE_FIRST, _PAGE_LAST = 758, 875
_IDX_LO, _IDX_HI = 700, 905
# Census category columns, in printed order after the total (col 1).
_CATS = ["slovak", "magyar", "german", "romanian", "rusyn", "croat", "serb", "other"]
_NUM_X0 = 300          # a token whose left edge is ≥ this is a numeric-column value, not the name
_PC_X1 = 70            # a p.č. integer sits left of this; a name/part starts to its right


# ═══════════════════════════════════════════════════════════════════════════
# Low-level page geometry
# ═══════════════════════════════════════════════════════════════════════════
def _printed_page_no(words) -> int | None:
    """The printed page number = the bottom-most standalone integer on the page."""
    ints = [(w["top"], w["text"]) for w in words if re.fullmatch(r"\d{1,4}", w["text"])]
    if not ints:
        return None
    return int(max(ints, key=lambda t: t[0])[1])          # largest `top` = lowest on the page


def _rows(words, tol: float = 3.0) -> list[list[dict]]:
    """Cluster words into visual rows by their ``top`` coordinate (tolerance in px)."""
    out: list[list[dict]] = []
    for w in sorted(words, key=lambda w: (w["top"], w["x0"])):
        if out and abs(w["top"] - out[-1][0]) <= tol:
            out[-1][1].append(w)                          # type: ignore[index]
        else:
            out.append((w["top"], [w]))                   # type: ignore[list-item]
    return [sorted(r, key=lambda w: w["x0"]) for _, r in out]


def _anchors(rows) -> list[float] | None:
    """Column anchors [total, cat1..cat8] from the ``a b 1 2 3 4 5 6 7 8 9`` header row."""
    for r in rows:
        toks = [w["text"] for w in r]
        if toks[:2] == ["a", "b"] and [t for t in toks if t.isdigit()][:9] == list("123456789"):
            xs = [w["x0"] for w in r if w["text"].isdigit()][:9]
            if len(xs) == 9:
                return xs
    return None


def _bounds(anchors: list[float]) -> list[float]:
    """Boundaries between the 9 columns, expressed on the tokens' **right** edge (len 8).

    The anchors are the header digits' *left* edges, but the values beneath them are
    **right-aligned**: on printed p. 803 the ``4`` header sits at x0 471.1 while every value in
    that column ends at x1 496.8 — about half a column further right. So the boundary between
    two columns is the anchors' midpoint shifted right by that much, and half the *median*
    anchor gap is used rather than a constant so the rule survives the small per-page drift
    between recto and verso.

    Comparing a token's **centre** against the unshifted midpoints (what this did before) drifts
    narrow values one column to the left, and can drop two of them into the same bucket, where
    they silently concatenate: Nitra's ``9`` Croats and ``13`` Serbs became *913 Serbs*. That cost
    27 broken row sums and — worse, because the sum check cannot see it — 135 further rows whose
    counts reconciled while sitting under the wrong heading. DECISIONS D-20.
    """
    half = statistics.median([anchors[i + 1] - anchors[i]
                              for i in range(len(anchors) - 1)]) / 2
    return [(anchors[i] + anchors[i + 1]) / 2 + half for i in range(len(anchors) - 1)]


def _read_numbers(nums, anchors: list[float]) -> list[int | None]:
    """Assign numeric tokens to the 9 columns by right edge; concatenate within a column.

    Zero columns are unprinted, so a column with no token stays ``None`` (kept distinct from a
    printed 0). Thousands are split tokens (``10`` + ``063``) that share a column and re-join.
    """
    bnds = _bounds(anchors)
    buckets: list[list[str]] = [[] for _ in range(9)]
    for w in nums:
        x1 = w["x1"]                        # right-aligned columns -> the right edge is the key
        col = 0
        while col < 8 and x1 >= bnds[col]:
            col += 1
        buckets[col].append(w["text"])
    return [int("".join(b)) if b else None for b in buckets]

# Parser
# ═══════════════════════════════════════════════════════════════════════════
_ZUPA = re.compile(r"^(?!.*p\.\s*č)(?P<n>[A-Za-zÁ-ž][A-Za-zÁ-ž .\-]*?)\s*župa$", re.IGNORECASE)

# The okres divider is printed in TWO forms. The usual one names the district outright
# ("okres Revúca"); three blocks instead use the **adjectival** form ("Hradný okres" = Vári
# járás/Tvrdošín, "Pohronský okres" = Garamvölgyi, "Medzibodrocký okres" = Bodrogközi).
# Matching only the first form left those 55 obce with no okres of their own — and the 19 Orava
# obce of the Hradný block did not even fail loudly: they inherited the *previous* okres and were
# filed under Trstená, ~98 person records on the wrong járás. The three adjectives resolve to a
# unit through curated `sk_alt` entries (utils/reference_tools/places/build_sk_curation.py), because the
# Magyar->Slovak bridge cannot reach them (_hu_adj_base("Vári") -> "Vár", not a chartered town).
# Case is spelled out rather than using re.IGNORECASE, so the adjectival branch still requires a
# capitalised head word. DECISIONS D-21.
_OKRES = re.compile(r"^(?:[Oo]kres\s+(?P<full>.+)"
                    r"|(?P<adj>[A-ZÁ-Ž][A-Za-zÁ-ž\-]*)\s+[Oo]kres)$")

# Each county closes with its chartered towns, under one of FOUR printed headers — singular
# "mesto so župnou právomocou" / "mesto so župnými právomocami" / "mesto so zriadeným
# magistrátom", and plural "mestá so zriadeným magistrátom". The old `^mesto so ` matched the
# three singular forms only, and the plural is the ONLY header seven counties use (Gemer, Nitra,
# Spiš, Šariš, Tekov, Trenčín, Zvolen): their 27 town rows therefore kept the last-seen okres —
# the county's final járás — so obec Nitra was filed under okres Nové Mesto nad Váhom. The four
# Bratislava towns escaped only by accident, a singular block sitting above them on the same page
# leaving `kind` set. Anchored on the two attested stems so it cannot swallow an obec headword.
# DECISIONS D-20.
_TOWN = re.compile(r"^(mest[oá]\s+so\s+(župn|zriaden)|slobodné\s+kráľ)", re.IGNORECASE)


def _clean_zupa(name: str) -> str:
    """Canonical župa name: normalise hyphen/space and case so the running page header and the
    ALL-CAPS section-divider render identically (else a župa 'change' spuriously resets the okres)."""
    return re.sub(r"\s*-\s*", "-", " ".join(name.split())).title()


def _hu_adj_base(jaras_hu) -> str | None:
    """Base town of a Hungarian adjectival district name (``Érsekújvári`` → ``Érsekújvár``).

    The lexicon's ``okres`` is the *district* (named after a town, in Slovak); the GISta backbone
    stores that district's Magyar adjectival form in ``jaras_hu``. Stripping the ``-i`` adjectival
    suffix recovers the base town, which the backbone's own Magyar→Slovak map then translates.
    """
    if not isinstance(jaras_hu, str) or not jaras_hu.strip():
        return None
    return re.sub(r"i$", "", jaras_hu.strip())


def parse_lexikon_sk(pdf_path, page_first: int = _PAGE_FIRST, page_last: int = _PAGE_LAST
                     ) -> pd.DataFrame:
    """Parse the 1910.1 section → one row per obec / *časť obce* with mother-tongue counts.

    Columns: ``obec_sk`` · ``unit_type`` (``obec`` / ``part`` / ``town``) · ``parent`` (parent obec
    for a part) · ``okres_sk`` · ``zupa_sk`` · ``pop_total`` · ``n_{slovak,magyar,german,romanian,
    rusyn,croat,serb,other}`` · ``sum_ok`` (categories reconcile to the total).
    """
    recs: list[dict] = []
    zupa = okres = None
    kind = "jaras"                      # 'jaras' (obce sit in an okres) | 'town' (standalone unit)
    parent: str | None = None

    with pdfplumber.open(str(pdf_path)) as pdf:
        for i, page in enumerate(pdf.pages):
            if i < _IDX_LO:                       # scan-speed prefilter (see module header)
                continue
            if i > _IDX_HI:
                break
            words = page.extract_words()
            if not words:
                continue
            pno = _printed_page_no(words)
            if pno is None or not (page_first <= pno <= page_last):
                continue
            rows = _rows(words)
            anchors = _anchors(rows)
            if anchors is None:
                continue
            for r in rows:
                toks = [w["text"] for w in r]
                text = " ".join(toks)
                low = text.lower()
                # ── structural lines ────────────────────────────────────────
                if "p.č" in low or low.startswith(("a b", "obyvateľov", "počet")):
                    continue                                   # repeating column header
                mz = _ZUPA.match(text)
                if mz and not any(w["x0"] >= _NUM_X0 for w in r):
                    new_zupa = _clean_zupa(mz.group("n"))
                    if new_zupa != zupa:               # real county change (not the repeating header)
                        zupa, okres, kind, parent = new_zupa, None, "jaras", None
                    continue
                mo = _OKRES.match(text)
                if mo and not any(w["x0"] >= _NUM_X0 for w in r):
                    name_ = (mo.group("full") or mo.group("adj")).strip()
                    okres, kind, parent = name_, "jaras", None
                    continue
                if _TOWN.match(text):
                    okres, kind, parent = None, "town", None
                    continue
                if low.startswith("spolu"):
                    continue                                   # okres / župa subtotal

                # ── data rows (obec / part) ─────────────────────────────────
                nums = [w for w in r if w["x0"] >= _NUM_X0 and re.fullmatch(r"\d+", w["text"])]
                name_ws = [w for w in r if w["x0"] < _NUM_X0]
                has_pc = bool(name_ws) and name_ws[0]["x1"] <= _PC_X1 and name_ws[0]["text"].isdigit()
                name_ws = name_ws[1:] if has_pc else name_ws
                name = " ".join(w["text"] for w in name_ws).strip()
                is_x = "x" in [w["text"] for w in r] and not nums          # obec with no counts
                if not name or (not nums and not is_x):
                    continue

                unit_type = "town" if kind == "town" else ("obec" if has_pc else "part")
                vals = _read_numbers(nums, anchors) if nums else [None] * 9
                rec = {"obec_sk": name, "unit_type": unit_type,
                       "parent": parent if unit_type == "part" else None,
                       "okres_sk": okres, "zupa_sk": zupa,
                       "pop_total": vals[0]}
                for c, v in zip(_CATS, vals[1:]):
                    rec[f"n_{c}"] = v
                cats = [v for v in vals[1:] if v is not None]
                rec["sum_ok"] = (vals[0] is not None and sum(cats) == vals[0])
                recs.append(rec)
                if unit_type == "obec":
                    parent = name                              # parts below inherit this obec

    return pd.DataFrame.from_records(recs)


# ═══════════════════════════════════════════════════════════════════════════
# Crosswalk to the GISta backbone
# ═══════════════════════════════════════════════════════════════════════════
def build_crosswalk_sk(pdf_path, backbone_hu: pd.DataFrame, fuzzy_threshold: int = 90
                       ) -> pd.DataFrame:
    """Parse + attach the GISta ``unit_id`` (járás/town) and mother-tongue shares.

    ``unit_id`` is resolved from the lexicon ``okres`` (a *district*, Slovak-named). The backbone
    stores that district as ``jaras_hu`` (Magyar adjectival) with ``name_sk`` = the *seat* town —
    a different place — so the matcher keys each járás by: its Slovak seat name(s), its Magyar seat,
    and the **district** name recovered from ``jaras_hu`` via the backbone's own Magyar→Slovak map
    (chartered-town exonym pairs); then exact, then subset-guarded rapidfuzz ≥ *fuzzy_threshold*.
    The handful of district exonyms whose base town is absent from the backbone (Fülek→Fiľakovo,
    Párkány→Štúrovo, Rimaszécs→Rimavská Seč, Udvard→Dvory nad Žitavou) are curated as ``name_sk`` /
    ``name_sk_alt`` in ``district_sk_curation.csv`` (Wikidata-validated). A ``town`` row maps to the
    backbone town unit of the same name. Rows whose district is a Hungarian-seated okres outside the
    Felvidék backbone (e.g. Cserhát, Rajka) or a region label (Žitný ostrov) keep ``unit_id`` =
    ``<NA>`` and are reported.
    """
    df = parse_lexikon_sk(pdf_path)

    # The backbone's own Magyar→Slovak dictionary: name_hu → name_sk over EVERY unit that carries
    # both. Chartered towns supply the exonym pairs the district names need (Érsekújvár↔Nové Zámky,
    # Nagyrőce↔Revúca, …), so the crosswalk needs no external source for most of them.
    hu2sk = {_norm(r["name_hu"]): r["name_sk"]
             for _, r in backbone_hu.iterrows() if r.get("name_hu") and r.get("name_sk")}

    # járás lookup: norm(name) -> unit_id. Keys per járás: Slovak seat name(s) + Magyar seat + the
    # DISTRICT name. The lexicon's "okres X" is the district (jaras_hu adjectival, e.g. Érsekújvári),
    # NOT the seat settlement (name_sk = Šurany); derive the district's Slovak name from the jaras_hu
    # base town via hu2sk so "okres Nové Zámky" reaches the Érsekújvári járás. (name_sk_alt also
    # carries curated district exonyms whose base town is absent from the backbone — Fülek→Fiľakovo.)
    jar = backbone_hu[backbone_hu["unit_type"] == "járás"].copy()
    seat_lut = {}
    for _, r in jar.iterrows():
        keys = [r.get("name_sk"), r.get("name_sk_alt"), r.get("name_sk_modern"), r.get("name_hu")]
        base = _hu_adj_base(r.get("jaras_hu"))
        if base:
            keys += [base, hu2sk.get(_norm(base))]        # Magyar district base + its Slovak form
        for nm in keys:
            k = _norm(nm)
            if k:
                seat_lut.setdefault(k, r["unit_id"])
    town_lut = {}
    for _, r in backbone_hu[backbone_hu["unit_type"] != "járás"].iterrows():
        for nm in (r.get("name_sk"), r.get("name_sk_alt"), r.get("name_sk_modern")):
            k = _norm(nm)
            if k:
                town_lut.setdefault(k, r["unit_id"])

    from rapidfuzz import process, fuzz
    seat_keys, town_keys = list(seat_lut), list(town_lut)

    def _lut_unit(name, lut: dict, keys: list):
        """Slovak name → GISta unit_id: exact, else token-subset fuzzy.

        The lexicon uses the *1910* short name (``Brezno``, ``Bytča``) while the backbone often
        carries the modern full form (``Brezno nad Hronom``, ``Veľká Bytča``); a subset-guarded
        ``token_set_ratio`` bridges these without accepting mere letter overlap (``Fiľakovo`` vs
        ``Ilava`` scored 62, safely below threshold). Used for both lookups — the chartered towns
        need it for exactly the same reason the districts do: the lexicon prints ``Brezno``, the
        backbone ``Brezno nad Hronom``, and without the fallback that town resolves to nothing.
        """
        k = _norm(name)
        if not k:
            return pd.NA
        if k in lut:
            return lut[k]
        m = process.extractOne(k, keys, scorer=fuzz.token_set_ratio)
        if m and m[1] >= fuzzy_threshold:
            a, b = set(k.split()), set(m[0].split())
            if a <= b or b <= a:                      # one name's tokens contained in the other's
                return lut[m[0]]
        return pd.NA

    def _okres_unit(okres):
        return _lut_unit(okres, seat_lut, seat_keys)

    unit_ids = []
    for _, r in df.iterrows():
        if r["unit_type"] == "town":
            # a town row carries no okres of its own (the block replaces it), so the town lookup
            # is the whole answer; the okres fallback only covers a row mis-typed as a town
            uid = _lut_unit(r["obec_sk"], town_lut, town_keys)
            unit_ids.append(uid if pd.notna(uid) else _okres_unit(r["okres_sk"]))
        else:
            unit_ids.append(_okres_unit(r["okres_sk"]))
    df["unit_id"] = pd.array(unit_ids, dtype="object")

    # mother-tongue shares (fraction of the obec's present population)
    pop = pd.to_numeric(df["pop_total"], errors="coerce")
    for share, col in [("slovak_share", "n_slovak"), ("magyar_share", "n_magyar"),
                       ("german_share", "n_german"), ("rusyn_share", "n_rusyn")]:
        df[share] = pd.to_numeric(df[col], errors="coerce").fillna(0) / pop.replace(0, pd.NA)

    df["name_norm"] = df["obec_sk"].map(_norm)
    return df.reset_index(drop=True)


def lexikon_sk_report(cross: pd.DataFrame) -> None:
    """Print coverage: obce/parts/towns, okres→unit mapping, sum-check, ethnicity summary."""
    n = len(cross)
    vc = cross["unit_type"].value_counts().to_dict()
    mapped = cross["unit_id"].notna().sum()
    with_pop = cross["pop_total"].notna().sum()
    sum_ok = cross["sum_ok"].sum()
    print(f"Slovak lexikón crosswalk (Majo 2012, 1910.1)  rows = {n}  {vc}")
    print(f"  okres/town -> GISta unit_id: {mapped}/{n} ({mapped/n*100:.1f}%)")
    print(f"  with population:             {with_pop}/{n} ({with_pop/n*100:.1f}%)")
    print(f"  category sum == total:       {sum_ok}/{with_pop} "
          f"({sum_ok/max(with_pop,1)*100:.1f}% of populated rows)")
    unmatched = sorted(set(cross.loc[cross["unit_id"].isna() & cross["okres_sk"].notna(), "okres_sk"]))
    if unmatched:
        print(f"  okres without a backbone unit ({len(unmatched)}): {', '.join(unmatched[:12])}"
              + (" …" if len(unmatched) > 12 else ""))
    if "slovak_share" in cross:
        s = cross.loc[cross["unit_type"] != "part", "slovak_share"].dropna()
        print(f"  Slovak-speaker share (obce/towns): mean {s.mean():.1%}, median {s.median():.1%} "
              f"(≥50% Slovak: {(s >= 0.5).sum()}/{len(s)})")
