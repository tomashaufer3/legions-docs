How it works

The route learns that a call failed by recognising the error: a 429 or a word like quota stops a pass and marks it incomplete. Any other wording — an exhausted credit balance, an outage, a refusal — is an ordinary failure: the crop is retried, dropped, and the pass is still marked finished. Its marks are then missing from the inventory, which reads as not printed: zero where the truth is unknown, the error shape that fabricated exit_N.

So completeness is checked on the outcome, whatever the cause: every request a pass queued (&lt;label&gt;.queue.jsonl, one line per crop or table block, with its key and cache_dir) must have its reply in the cache (&lt;cache_dir&gt;/&lt;key&gt;.json) — a reply that failed is never cached. Every Opus call the run built must have its answer. A gap the author accepts is listed by key in notebook 15's ACCEPT_FAILED, so letting one through is a recorded decision, never a silence; the record is written beside the run's reads.

Notebook 15 calls this after 7d (an incomplete pass loses its .done, so 7d reads the gap again), before the ledger (section 12) and before the anchor's ledger (14b). It lives outside utils/lexikon_1910 on purpose: every module there is digested into the freeze, and a guard must not make the full run a different route from the gold it is held to.

def write_record(path: Path, gaps: dict[str, list[str]], accept, stage: str) -> dict:
    """Keep what was found at ``stage`` and what was accepted, the earlier stages' entries
    kept beside it; returns the record."""
    path = Path(path)
    record = json.loads(path.read_text(encoding="utf-8")) if path.exists() else {}
    record[stage] = {"checked": time.strftime("%Y-%m-%d %H:%M:%S"), "runner": __version__,
                     "gaps": gaps, "accepted": sorted({str(k) for k in (accept or ())}),
                     "unaccepted": unaccepted(gaps, accept)}
    path.parent.mkdir(parents=True, exist_ok=True)
    path.write_text(json.dumps(record, indent=1, ensure_ascii=False), encoding="utf-8")
    return record

def report(edition: str, gaps: dict[str, list[str]], open_gaps: dict[str, list[str]]) -> str:
    """One line per pass with a gap: how many replies are missing and how many are accepted."""
    if not gaps:
        return f"{edition}: complete — every queued request has its reply"
    lines = [f"{edition}: {sum(map(len, open_gaps.values()))} replies missing"
             + (f" ({sum(map(len, gaps.values())) - sum(map(len, open_gaps.values()))} accepted)"
                if gaps != open_gaps else "")]
    for label, keys in gaps.items():
        still = len(open_gaps.get(label, []))
        lines.append(f"  {label}: {len(keys)} without a reply, {still} not accepted"
                     + (f" — e.g. {open_gaps[label][0]}" if still else ""))
    return "\n".join(lines)

from __future__ import annotations

__version__ = "0.1.0"

import json
import time
from pathlib import Path

#: A queue's file name is its pass's label and this suffix (``run_frozen._queue``).
QUEUE_SUFFIX = ".queue.jsonl"
#: Written beside the run's reads: every gap found and every gap the author accepted.
RECORD_NAME = "completeness.json"


def queue_label(queue: Path) -> str:
