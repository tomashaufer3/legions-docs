How it works

Nothing in the pipeline says where a mark is: the readers return tokens, and test A (D-91) showed that on a clean box even 32 x 32 pixels tell the fill pairs apart — so the box is the hard part. This module finds the boxes on the gold section images (transcription_gold/cz/{calibration,purposive}) in three steps:

  1. Candidates. The ink is split into connected components, each component is put on its printed line, small marks at the foot of the line (full stops, commas) are set aside, and the rest are joined left to right into clusters wherever the gap is narrower than a word space. A cluster is a word, a number, a key — or a glyph. Every cluster gets shape features in line heights: width, height, ink density, holes, stroke width, where it sits against the baseline.

  2. Glyphness. A logistic model on those features says how much a cluster looks like a pictogram rather than type. It is trained without a single hand label: the gold says how many marks each entry prints and in what order, the alignment below picks that many clusters, and the clusters it picks are the positives of the next round (train_glyphness). Only calibration pages train it (D-69), and a calibration page is scored by a model that never saw it.

  3. Alignment. The clusters of a section, in reading order, are matched to the claims, in printed order (D-73: the order of the marks is a fact of the print, and the order check in the scorer already relies on it). A monotone dynamic programme picks one cluster per claim, maximising the summed score, may leave a claim unplaced at a cost, and keeps every claim inside its own entry's lines where the entries can be located. The score of cluster i for claim j is a matrix, so the encoder's similarity to the claimed token's exemplars (run_glyph_e3.py) is added on Heavyhorse6 without touching this code.

  4. Modifiers (1.1.0). The plate builds a fifth of its tokens from another: (school) is [school-exp], ♁ A is [ev-parish-ab], (block of four) is [colony] (glyph_composites.csv). A claim is therefore placed on its base glyph — templates and sizes are kept per base — and brackets are never part of a cluster nor the base of a claim. Beside each placed base the brackets (round or square) and a letter are then looked for without the claim (modifiers), so the check of a claim cannot be steered by it.

The claims can be the gold's (to measure the locator, and to cut the bank) or a reader's (to check that reader): the boxes then show the encoder what the reader says is there. A glyph no claim mentions is not placed — which is why the glyphness score is also written for every cluster, for a later pass that looks for marks nobody read.

measure scores the locator against the 141 glyphs the author clicked for test A (output/glyph_bank/glyph_bank.csv): the share of clicked glyphs inside some candidate, inside the box aligned to their claim, the centre distance, and the clusters per entry that look like glyphs but carry no claim.

def read_sections(path: Path) -> list[Section]:
    """Every 2a/2b section of one gold sheet, with its claims in printed order."""
    from build_token_review import _sheet_sections
    from read_transcription_md import _key

    role = path.parent.name
    if role not in ROLES:
        raise ValueError(f"refused: {path} is not a {'/'.join(ROLES)} sheet")
    text = path.read_text(encoding="utf-8")
    out = []
    # one `## 2a — …` / `## 2b — …` heading opens each block, in the same order
    districts = [section_district(line) for line in text.splitlines()
                 if re.match(r"^##\s*2[ab]\s*—", line)]
    for index, block in enumerate(_sheet_sections(text)):
        section = Section(scan=path.stem, role=role,
                          kind="parts" if block["section"] == "2a" else "offices",
                          images=[n for n in block["images"] if (path.parent / n).exists()],
                          sheet_dir=path.parent,
                          district=districts[index] if index < len(districts) else "")
        for _lineno, line in block["lines"]:
            parsed = _key(line)
            if not parsed or parsed[0] == "__" or not parsed[-1]:
                continue
            muni, seq, *_rest, answer = parsed
            if int(muni) not in section.printed:
                section.printed.append(int(muni))
            section.keys.append((int(muni), str(seq)))
            for token in claims_in_answer(answer):
                section.claims.append(Claim(token, int(muni), seq, len(section.claims)))
        if section.images:
            out.append(section)
    return out

def bitmap(patch):
    """A cluster's ink, padded to a square and reduced to BITMAP x BITMAP: the
    shape without its size, zero mean and unit norm, so a dot product is a
    correlation."""
    import numpy as np
    from PIL import Image

    h, w = patch.shape
    side = max(h, w, 1)
    square = np.zeros((side, side), dtype=np.uint8)
    square[(side - h) // 2:(side - h) // 2 + h, (side - w) // 2:(side - w) // 2 + w] = patch * 255
    small = np.asarray(Image.fromarray(square).resize((BITMAP, BITMAP), Image.BOX),
                       dtype=np.float32).ravel()
    small -= small.mean()
    norm = float(np.linalg.norm(small))
    return small / norm if norm else small

def shape_features(patch, lh: float, top_rel: float, bottom_rel: float, x_rel: float,
                   n_comp: int) -> dict:
    """Features of one cluster, all scale-free (in line heights or shares)."""
    import numpy as np
    from scipy import ndimage

    h, w = patch.shape
    area = float(patch.sum())
    edge = area - float(ndimage.binary_erosion(patch).sum())
    rows = patch.mean(axis=1)
    cols = patch.mean(axis=0)
    return {
        "log_w": math.log(max(w, 1) / lh), "log_h": math.log(max(h, 1) / lh),
        "aspect": math.log(max(w, 1) / max(h, 1)), "density": area / max(1, w * h),
        "n_comp": min(n_comp, 8), "holes": min(_holes(patch), 6),

        "fill_rows": float((rows > 0.6).mean()), "fill_cols": float((cols > 0.6).mean()),
        "letters_left": 0.0, "letters_right": 0.0,
    }

def baselines(boxes: list[tuple[int, int, int, int]], lh: float) -> list[float]:
    """The baselines of a section image, from the feet of the marks on them.

    The bands of :func:`build_token_review.text_lines` split on blank rows, and on
    a dense page an accent or a descender bridges two lines, so a band can hold two
    or three of them (scan 0136: a 139-px band at a line height of 66). The feet of
    the letters do not move: they pile up on each baseline, and a peak in their
    histogram is a line. A small letter counts in full; any other mark of about
    letter size counts half, so that a line of glyphs and numerals alone
    (``2, —) [school] II, [fire-brigade].``, scan 0019) is still a line; and a
    mark of glyph size counts half at its foot raised by :data:`GLYPH_DROP`, so
    that ``6, —) [castle].`` (scan 0136) is one too.
    """
    import numpy as np

    marks = []
    for x0, y0, x1, y1 in boxes:
        h, w = y1 - y0, x1 - x0
        if X_HEIGHT[0] * lh <= h <= X_HEIGHT[1] * lh and w <= 0.8 * lh:
            marks.append((y1, 1.0))
        elif MARK_HEIGHT[0] * lh <= h <= MARK_HEIGHT[1] * lh and w <= 1.3 * lh:
            marks.append((y1, 0.5))
        elif MARK_HEIGHT[1] * lh < h <= GLYPH_HEIGHT * lh and w <= 1.6 * lh:
            marks.append((int(round(y1 - GLYPH_DROP * lh)), 0.5))
    if not marks:
        return []
    feet = np.array([y for y, _w in marks])
    top, bottom = int(feet.min()) - 3, int(feet.max()) + 4
    hist = np.bincount(feet - top, weights=[w for _y, w in marks],
                       minlength=bottom - top)
    smooth = np.convolve(hist, np.ones(5), mode="same")
    order = np.argsort(-smooth)
    found: list[int] = []
    gap = 0.6 * lh
    for y in order:
        if smooth[y] < MIN_LINE_VOTES:
            break
        if all(abs(y - f) >= gap for f in found):
            found.append(int(y))
    out = []
    for y in sorted(found):
        near = feet[np.abs(feet - (y + top)) <= 3]
        out.append(float(np.median(near)) if len(near) else float(y + top))
    return out

def bracket_kind(patch, box, baseline: float, lh: float) -> tuple[str, str]:
    """``(kind, side)`` when one ink component is a bracket — ``("round", "open")``
    for ``(``, ``("square", "close")`` for ``]`` — else ``("", "")``.

    Read off the shape and position alone, never off a claim: a bracket is a
    thin stroke taller than a capital that reaches below the baseline; its
    middle has no crossbar; a round one curves and a square one is straight.
    Which way it faces is where the ink of its middle sits: left of centre opens.
    ``patch`` may be several stacked pieces: a faint bracket prints broken.
    """
    import numpy as np

    x0, y0, x1, y1 = box
    h, w = y1 - y0, x1 - x0
    if not (h >= BRACKET_SIZE[0] * lh and w <= BRACKET_SIZE[1] * lh and h >= 2.5 * w):
        return "", ""
    drop = BRACKET_DROP if h < TALL_BRACKET * lh else SHALLOW_DROP
    if y1 < baseline + drop * lh or y0 > baseline - BRACKET_RISE * lh:
        return "", ""
    rows = patch.any(axis=1)
    if not rows.any():
        return "", ""

    def span(row):
        cols = np.flatnonzero(row)
        return (cols[-1] - cols[0] + 1) / max(w, 1) if len(cols) else 0.0

    middle = patch[int(0.25 * h):max(int(0.75 * h), int(0.25 * h) + 1)]
    if max((span(r) for r in middle), default=1.0) > BRACKET_MIDDLE:
        return "", ""
    def stroke_x(lo, hi):
        part = patch[int(lo * h):max(int(hi * h), int(lo * h) + 1)]
        xs = np.nonzero(part)[1]
        return xs.mean() if len(xs) else None

    centre = stroke_x(0.45, 0.55)
    if centre is None:
        return "", ""
    ends = [x for x in (stroke_x(0.15, 0.30), stroke_x(0.70, 0.85)) if x is not None]
    round_ = bool(ends) and max(abs(x - centre) for x in ends) / max(w, 1) >= ROUND_SHIFT
    side = "open" if centre < (w - 1) / 2 else "close"

def stacked_pieces(comps: list[int], boxes: dict, lh: float) -> list[list[int]]:
    """The thin components of a line, those stacked one above another joined —
    a faint bracket prints as two or three pieces. A component wider than a
    bracket stands alone; every other one is returned, joined or single."""
    thin = [k for k in comps if boxes[k][2] - boxes[k][0] <= BRACKET_SIZE[1] * lh]
    parent = {k: k for k in thin}

    def root(k):
        while parent[k] != k:
            parent[k] = parent[parent[k]]
            k = parent[k]
        return k

    for a in thin:
        for b in thin:
            if a >= b:
                continue
            (ax0, ay0, ax1, ay1), (bx0, by0, bx1, by1) = boxes[a], boxes[b]
            overlap = min(ax1, bx1) - max(ax0, bx0)
            gap = max(by0 - ay1, ay0 - by1)
            if overlap >= 0.3 * min(ax1 - ax0, bx1 - bx0) and gap <= 0.2 * lh:
                parent[root(a)] = root(b)
    groups: dict[int, list[int]] = defaultdict(list)
    for k in thin:
        groups[root(k)].append(k)
    return list(groups.values())

        baseline = lines[j]

        def punct(k):
            x0, y0, x1, y1 = boxes[k]
            w, h = x1 - x0, y1 - y0
            return (h <= PUNCT_SIZE[0] * lh and w <= PUNCT_SIZE[1] * lh
                    and w <= PUNCT_ASPECT * h and (y0 + y1) / 2 >= baseline - PUNCT_LIFT * lh

            y0 = min(boxes[k][1] for k in piece)
            x1 = max(boxes[k][2] for k in piece)
            y1 = max(boxes[k][3] for k in piece)

            kind, side = bracket_kind(patch, (x0, y0, x1, y1), baseline, lh)

def align(score, allowed=None, miss_cost: float = MISS_COST) -> list[int | None]:
    """Monotone assignment of claims to candidates.

    ``score[i, j]`` is how well candidate ``i`` fits claim ``j`` (log-odds); both
    are in reading / printed order. Returns, for each claim, the candidate it is
    placed on or ``None``. Candidates are used at most once and in order; leaving a
    claim unplaced costs ``miss_cost``; a candidate need not be used at all.
    ``allowed[i, j]`` False forbids a placement (another entry's lines).
    """
    import numpy as np

    score = np.asarray(score, dtype=float)
    m, n = score.shape
    if n == 0:
        return []
    if m == 0:
        return [None] * n
    s = score if allowed is None else np.where(allowed, score, -np.inf)
    neg = -1e18
    # best[j][i]: best total with the first j claims settled using candidates < i
    best = np.full((n + 1, m + 1), neg)
    best[0, :] = 0.0
    for j in range(1, n + 1):
        take = np.full(m + 1, neg)
        take[1:] = best[j - 1, :-1] + s[:, j - 1]
        skip = best[j - 1] - miss_cost
        best[j] = np.maximum.accumulate(np.maximum(take, skip))
    out: list[int | None] = [None] * n
    i = m
    for j in range(n, 0, -1):
        # walk left while the value came from an earlier candidate
        while i > 0 and best[j, i] == best[j, i - 1]:
            i -= 1
        if i > 0 and np.isclose(best[j, i], best[j - 1, i - 1] + s[i - 1, j - 1]):
            out[j - 1] = i - 1
            i -= 1
        # otherwise the claim was skipped at this i
    return out

class Locator:
    """What the self-training learns: glyphness, and per token a shape template
    (mean bitmap of its placed clusters) and a size (mean and spread of log
    width and height)."""
    glyph: GlyphModel = field(default_factory=GlyphModel)
    templates: dict = field(default_factory=dict)        # token -> unit vector
    sizes: dict = field(default_factory=dict)            # token -> (mu_w, mu_h, sd_w, sd_h)
    learned: set = field(default_factory=set)            # tokens whose template is entry-cut

    def token_scores(self, cands: list[Candidate], claims: list[Claim], blind: bool = False):
        """``[candidate, claim]``: how well each cluster fits each claimed token —
        shape correlation and size, zero for a token not yet learned.

        ``blind``: the same column for every claim — how well the cluster fits
        the template it fits *best*, whichever token that is. A claim under test
        is placed blind, so that its box is "the glyph at this point of the
        order", never "the glyph that looks most like what the reader says":
        otherwise the box is chosen to agree with the claim, and the encoder
        reading it is no longer an independent check."""
        import numpy as np

        out = np.zeros((len(cands), len(claims)))
        if not cands or not claims:
            return out
        maps = np.stack([c.bitmap for c in cands])
        if blind:
            if self.templates:
                stack = np.stack(list(self.templates.values()))
                best = (maps @ stack.T).max(axis=1)
                out += (TEMPLATE_WEIGHT * (best - TEMPLATE_CENTRE))[:, None]
            return out
        lw = np.array([c.features["log_w"] for c in cands])
        lh = np.array([c.features["log_h"] for c in cands])
        cache: dict[str, object] = {}
        for j, cl in enumerate(claims):
            # a claim looks for its BASE: [school-exp] for the book, [ev-parish-ab]
            # for the cross over a ring — the brackets and the letter stand beside it
            base = base_of(cl.token)
            if base not in cache:
                col = np.zeros(len(cands))
                if base in self.templates:
                    col += TEMPLATE_WEIGHT * (maps @ self.templates[base] - TEMPLATE_CENTRE)
                if base in self.sizes:
                    mw, mh, sw, sh = self.sizes[base]
                    z = ((lw - mw) / sw) ** 2 + ((lh - mh) / sh) ** 2
                    col -= SIZE_WEIGHT * np.minimum(z, SIZE_CAP)
                cache[base] = col
            out[:, j] = cache[base]
        return out

    def place(self, cands: list[Candidate], claims: list[Claim], extra=None,
              miss_cost: float = MISS_COST, blind: bool = False) -> list[int | None]:
        token = self.token_scores(cands, claims, blind)
        if extra is not None:
            token = token + extra
        return place(cands, claims, self.glyph.score(cands), token, miss_cost)

def best_threshold(scores, truth) -> float:
    """The score above which clusters are called marks, at the best F1."""
    import numpy as np

    order = np.argsort(-np.asarray(scores))
    s, t = np.asarray(scores)[order], np.asarray(truth)[order]
    tp = np.cumsum(t)
    fp = np.cumsum(1 - t)
    total = t.sum()
    f1 = 2 * tp / np.maximum(tp + fp + total, 1)
    return float(s[int(np.argmax(f1))])

"""E3, first half: a box for every printed glyph of the apparatus (D-69, D-72, D-93).

Nothing in the pipeline says *where* a mark is: the readers return tokens, and
test A (D-91) showed that on a clean box even 32 x 32 pixels tell the fill pairs
apart — so the box is the hard part. This module finds the boxes on the gold
section images (``transcription_gold/cz/{calibration,purposive}``) in three steps:

1. **Candidates.** The ink is split into connected components, each component is
   put on its printed line, small marks at the foot of the line (full stops,
   commas) are set aside, and the rest are joined left to right into clusters
   wherever the gap is narrower than a word space. A cluster is a word, a number,
   a key — or a glyph. Every cluster gets shape features in line heights: width,
   height, ink density, holes, stroke width, where it sits against the baseline.

2. **Glyphness.** A logistic model on those features says how much a cluster
   looks like a pictogram rather than type. It is trained without a single hand
   label: the gold says how many marks each entry prints and in what order, the
   alignment below picks that many clusters, and the clusters it picks are the
   positives of the next round (``train_glyphness``). Only calibration pages
   train it (D-69), and a calibration page is scored by a model that never saw it.

3. **Alignment.** The clusters of a section, in reading order, are matched to the
   claims, in printed order (D-73: the order of the marks is a fact of the print,
   and the order check in the scorer already relies on it). A monotone dynamic
   programme picks one cluster per claim, maximising the summed score, may leave a
   claim unplaced at a cost, and keeps every claim inside its own entry's lines
   where the entries can be located. The score of cluster *i* for claim *j* is a
   matrix, so the encoder's similarity to the claimed token's exemplars
   (``run_glyph_e3.py``) is added on Heavyhorse6 without touching this code.

4. **Modifiers** (1.1.0). The plate builds a fifth of its tokens from another:
   ``(school)`` is ``[school-exp]``, ``♁ A`` is ``[ev-parish-ab]``, ``(block of
   four)`` is ``[colony]`` (``glyph_composites.csv``). A claim is therefore placed on
   its **base** glyph — templates and sizes are kept per base — and brackets are
   never part of a cluster nor the base of a claim. Beside each placed base the
   brackets (round or square) and a letter are then looked for **without the
   claim** (:func:`modifiers`), so the check of a claim cannot be steered by it.

The claims can be the gold's (to measure the locator, and to cut the bank) or a
reader's (to check that reader): the boxes then show the encoder what the reader
says is there. A glyph no claim mentions is not placed — which is why the
glyphness score is also written for every cluster, for a later pass that looks for
marks nobody read.

``measure`` scores the locator against the 141 glyphs the author clicked for test A
(``output/glyph_bank/glyph_bank.csv``): the share of clicked glyphs inside some
candidate, inside the box aligned to their claim, the centre distance, and the
clusters per entry that look like glyphs but carry no claim.

    python utils/lexikon_1910/locate_glyphs.py              # train, align, measure
    python utils/lexikon_1910/locate_glyphs.py --draw 0136   # + overlays for a scan

"""

def composites(path: Path | None = None) -> dict[str, Parts]:
    """``token -> Parts`` for every composite of the plate (cached for the default file)."""
    global _TABLE

        return _TABLE
    out = {}

        for row in csv.DictReader(fh):
            out[row["token"]] = Parts(row["base"], row["brackets"].strip(), row["letter"].strip())

    return out

    table = composites() if table is None else table
    return table.get(token, Parts(token))

    return parts_of(token, table).base


def compose(base: str, brackets: str, letter: str, table: dict | None = None) -> str:
    """The token the plate prints as this base with these modifiers, or
    :data:`NOT_IN_LEGEND` — a combination the legend does not have is reported,
    never forced onto the nearest token. A base the plate prints only inside
    brackets (``[cottage-group-base]``) is not a token on its own."""
    table = composites() if table is None else table
    for token, parts in table.items():
        if parts == Parts(base, brackets, letter):
            return token
    if brackets or letter or base.endswith("-base]"):
        return NOT_IN_LEGEND
    return base

def ink_mask(image, threshold: int = INK):
    """Dark pixels of a section image at the bank's threshold, with the columns
    :func:`build_token_review._text_ink` blanks (frame, rules, gutter) blanked too."""

#: The side of the small bitmap a cluster is reduced to for the token templates.
BITMAP = 20


def bitmap(patch):
    """A cluster's ink, padded to a square and reduced to BITMAP x BITMAP: the
    shape without its size, zero mean and unit norm, so a dot product is a
    correlation."""
    import numpy as np
    from PIL import Image

    h, w = patch.shape
    side = max(h, w, 1)
    square = np.zeros((side, side), dtype=np.uint8)
    square[(side - h) // 2:(side - h) // 2 + h, (side - w) // 2:(side - w) // 2 + w] = patch * 255
    small = np.asarray(Image.fromarray(square).resize((BITMAP, BITMAP), Image.BOX),
                       dtype=np.float32).ravel()
    small -= small.mean()
    norm = float(np.linalg.norm(small))
    return small / norm if norm else small


def _holes(patch) -> int:
    """Enclosed background regions in a binary patch (a ring has one)."""
    import numpy as np
    from scipy import ndimage

    padded = np.pad(~patch, 1, constant_values=True)
    labels, n = ndimage.label(padded)
    if n <= 1:
        return 0
    sizes = np.bincount(labels.ravel())
    outer = labels[0, 0]
    return int(sum(1 for k in range(1, n + 1) if k != outer and sizes[k] >= 4))


def shape_features(patch, lh: float, top_rel: float, bottom_rel: float, x_rel: float,
                   n_comp: int) -> dict:
    """Features of one cluster, all scale-free (in line heights or shares)."""
    import numpy as np
    from scipy import ndimage

    h, w = patch.shape
    area = float(patch.sum())
    edge = area - float(ndimage.binary_erosion(patch).sum())
    rows = patch.mean(axis=1)
    cols = patch.mean(axis=0)
    return {
        "log_w": math.log(max(w, 1) / lh), "log_h": math.log(max(h, 1) / lh),
        "aspect": math.log(max(w, 1) / max(h, 1)), "density": area / max(1, w * h),
        "n_comp": min(n_comp, 8), "holes": min(_holes(patch), 6),
        # 2 * area / perimeter: the mean stroke width, in line heights
        "stroke": 2 * area / max(edge, 1) / lh,
        "top": top_rel, "bottom": bottom_rel, "x_rel": x_rel,
        # how much of the box is solid: rows / columns more than 60 % inked
        "fill_rows": float((rows > 0.6).mean()), "fill_cols": float((cols > 0.6).mean()),
        "letters_left": 0.0, "letters_right": 0.0,
    }


#: A lower-case letter without ascender or descender (a, e, m, n, o …) is this
#: tall, in line heights; its foot is the baseline.
X_HEIGHT = (0.22, 0.48)
#: Any mark of about letter size: capitals, numerals, most glyphs (line heights).
MARK_HEIGHT = (0.18, 0.85)
#: A glyph is up to this tall (line heights), and its foot sits about this far
#: below the baseline (the clicked fill-pair glyphs: median 0.25, D-93).
GLYPH_HEIGHT, GLYPH_DROP = 1.2, 0.22
#: A baseline needs this many votes (a small letter is 1, any other mark 0.5).
MIN_LINE_VOTES = 1.5
#: The middle of the x-height band sits this far above the baseline (line heights).
X_MIDDLE = 0.17


def baselines(boxes: list[tuple[int, int, int, int]], lh: float) -> list[float]:
    """The baselines of a section image, from the feet of the marks on them.

    The bands of :func:`build_token_review.text_lines` split on blank rows, and on
    a dense page an accent or a descender bridges two lines, so a band can hold two
    or three of them (scan 0136: a 139-px band at a line height of 66). The feet of
    the letters do not move: they pile up on each baseline, and a peak in their
    histogram is a line. A small letter counts in full; any other mark of about
    letter size counts half, so that a line of glyphs and numerals alone
    (``2, —) [school] II, [fire-brigade].``, scan 0019) is still a line; and a
    mark of glyph size counts half at its foot raised by :data:`GLYPH_DROP`, so
    that ``6, —) [castle].`` (scan 0136) is one too.
    """
    import numpy as np

    marks = []
    for x0, y0, x1, y1 in boxes:
        h, w = y1 - y0, x1 - x0
        if X_HEIGHT[0] * lh <= h <= X_HEIGHT[1] * lh and w <= 0.8 * lh:
            marks.append((y1, 1.0))
        elif MARK_HEIGHT[0] * lh <= h <= MARK_HEIGHT[1] * lh and w <= 1.3 * lh:
            marks.append((y1, 0.5))
        elif MARK_HEIGHT[1] * lh < h <= GLYPH_HEIGHT * lh and w <= 1.6 * lh:
            marks.append((int(round(y1 - GLYPH_DROP * lh)), 0.5))
    if not marks:
        return []
    feet = np.array([y for y, _w in marks])
    top, bottom = int(feet.min()) - 3, int(feet.max()) + 4
    hist = np.bincount(feet - top, weights=[w for _y, w in marks],
                       minlength=bottom - top)
    smooth = np.convolve(hist, np.ones(5), mode="same")
    order = np.argsort(-smooth)
    found: list[int] = []
    gap = 0.6 * lh
    for y in order:
        if smooth[y] < MIN_LINE_VOTES:
            break
        if all(abs(y - f) >= gap for f in found):
            found.append(int(y))
    out = []
    for y in sorted(found):
        near = feet[np.abs(feet - (y + top)) <= 3]
        out.append(float(np.median(near)) if len(near) else float(y + top))
    return out


#: A bracket is at least this tall and at most this wide (line heights), reaches
#: this far below the baseline and this high above it.
#: Measured on the brackets of the gold pages: 0.74-1.06 lh tall, 0.12-0.27 wide,
#: the top 0.52-0.75 above the baseline (scans 0076, 0118, 0136, 0270).
BRACKET_SIZE = (0.65, 0.32)
BRACKET_DROP, BRACKET_RISE = 0.08, 0.40
#: ... or, when at least TALL_BRACKET tall, only SHALLOW_DROP below the baseline
#: (a line of glyphs and figures alone puts its baseline estimate a little low).
TALL_BRACKET, SHALLOW_DROP = 0.85, 0.03
#: Its middle rows (25-75 % of its height) are one thin stroke: no row there inks
#: more than this share of its width (a curved paren reaches 0.73; a cross
#: ``[rc-filial]`` has a bar that inks it all). A round bracket curves: its stroke
#: at 15-30 % and 70-85 % of its height stands at least ROUND_SHIFT of its width
#: off where it is at mid-height; a square one is straight there, its serifs —
#: attached or broken off (scan 0118) — above and below the rows measured.
BRACKET_MIDDLE, ROUND_SHIFT = 0.80, 0.15
#: A frame or rule fragment: taller than 0.8 line heights and this many times
#: taller than wide. A bracket is 3-5 times.
RULE_ASPECT = 8.0


def bracket_kind(patch, box, baseline: float, lh: float) -> tuple[str, str]:
    """``(kind, side)`` when one ink component is a bracket — ``("round", "open")``
    for ``(``, ``("square", "close")`` for ``]`` — else ``("", "")``.

    Read off the shape and position alone, never off a claim: a bracket is a
    thin stroke taller than a capital that reaches below the baseline; its
    middle has no crossbar; a round one curves and a square one is straight.
    Which way it faces is where the ink of its middle sits: left of centre opens.
    ``patch`` may be several stacked pieces: a faint bracket prints broken.
    """
    import numpy as np

    x0, y0, x1, y1 = box
    h, w = y1 - y0, x1 - x0
    if not (h >= BRACKET_SIZE[0] * lh and w <= BRACKET_SIZE[1] * lh and h >= 2.5 * w):
        return "", ""
    drop = BRACKET_DROP if h < TALL_BRACKET * lh else SHALLOW_DROP
    if y1 < baseline + drop * lh or y0 > baseline - BRACKET_RISE * lh:
        return "", ""
    rows = patch.any(axis=1)
    if not rows.any():
        return "", ""

    def span(row):
        cols = np.flatnonzero(row)
        return (cols[-1] - cols[0] + 1) / max(w, 1) if len(cols) else 0.0

    middle = patch[int(0.25 * h):max(int(0.75 * h), int(0.25 * h) + 1)]
    if max((span(r) for r in middle), default=1.0) > BRACKET_MIDDLE:
        return "", ""
    def stroke_x(lo, hi):
        part = patch[int(lo * h):max(int(hi * h), int(lo * h) + 1)]
        xs = np.nonzero(part)[1]
        return xs.mean() if len(xs) else None

    centre = stroke_x(0.45, 0.55)
    if centre is None:
        return "", ""
    ends = [x for x in (stroke_x(0.15, 0.30), stroke_x(0.70, 0.85)) if x is not None]
    round_ = bool(ends) and max(abs(x - centre) for x in ends) / max(w, 1) >= ROUND_SHIFT
    side = "open" if centre < (w - 1) / 2 else "close"
    return ("round" if round_ else "square"), side


def stacked_pieces(comps: list[int], boxes: dict, lh: float) -> list[list[int]]:
    """The thin components of a line, those stacked one above another joined —
    a faint bracket prints as two or three pieces. A component wider than a
    bracket stands alone; every other one is returned, joined or single."""
    thin = [k for k in comps if boxes[k][2] - boxes[k][0] <= BRACKET_SIZE[1] * lh]
    parent = {k: k for k in thin}

    def root(k):
        while parent[k] != k:
            parent[k] = parent[parent[k]]
            k = parent[k]
        return k

    for a in thin:
        for b in thin:
            if a >= b:
                continue
            (ax0, ay0, ax1, ay1), (bx0, by0, bx1, by1) = boxes[a], boxes[b]
            overlap = min(ax1, bx1) - max(ax0, bx0)
            gap = max(by0 - ay1, ay0 - by1)
            if overlap >= 0.3 * min(ax1 - ax0, bx1 - bx0) and gap <= 0.2 * lh:
                parent[root(a)] = root(b)
    groups: dict[int, list[int]] = defaultdict(list)
    for k in thin:
        groups[root(k)].append(k)
    return list(groups.values())


@dataclass
class Lines:
    """The ink of one section image put on its printed lines: component labels,
    each component's area and box, each line's baseline and its components —
    lines numbered top to bottom. Shared by the glyph clusters and the keys."""
    labels: object
    areas: object
    boxes: dict
    baselines: dict
    components: dict
    width: int


def line_components(image, lh: float) -> Lines | None:
    """Label the ink and give every component its printed line (``None`` when
    the image holds no line)."""
    import numpy as np
    from scipy import ndimage

    ink = ink_mask(image)
    width = ink.shape[1]
    labels, n = ndimage.label(ink, structure=np.ones((3, 3)))
    if not n:
        return None
    slices = ndimage.find_objects(labels)
    areas = np.bincount(labels.ravel())
    all_boxes = {k: (sl[1].start, sl[0].start, sl[1].stop, sl[0].stop)
                 for k, sl in enumerate(slices, start=1)
                 if sl is not None and areas[k] >= MIN_AREA}
    lines = baselines(list(all_boxes.values()), lh)
    if not lines:
        return None
    middles = np.array(lines) - X_MIDDLE * lh
    per_line: dict[int, list[int]] = defaultdict(list)
    orphans = []
    for k, (x0, y0, x1, y1) in all_boxes.items():
        if y1 - y0 > 2.2 * lh:                      # a rule or the frame
            continue
        cy = (y0 + y1) / 2
        j = int(np.argmin(np.abs(middles - cy)))
        if abs(middles[j] - cy) <= (0.5 + LINE_SLACK) * lh:
            per_line[j].append(k)
        else:
            orphans.append(k)
    # A line too thin to vote for itself — a key and one glyph, ``2) [castle].``
    # (scan 0076) — is what is left over: marks of glyph size no baseline took,
    # grouped by height, each group a line whose baseline sits GLYPH_DROP above
    # its feet.
    orphans.sort(key=lambda k: (all_boxes[k][1] + all_boxes[k][3]) / 2)
    group: list[int] = []
    for k in orphans + [None]:
        cy = None if k is None else (all_boxes[k][1] + all_boxes[k][3]) / 2
        if group and (k is None or cy - (all_boxes[group[0]][1] + all_boxes[group[0]][3]) / 2 > 0.5 * lh):
            if max(all_boxes[g][3] - all_boxes[g][1] for g in group) >= 0.5 * lh:
                feet = float(np.median([all_boxes[g][3] for g in group]))
                lines.append(feet - GLYPH_DROP * lh)
                per_line[len(lines) - 1] = list(group)
            group = []
        if k is not None:
            group.append(k)
    # number the lines top to bottom, so that line order is reading order
    rank = {j: r for r, j in enumerate(sorted(per_line, key=lambda j: lines[j]))}
    per_line = {rank[j]: comps for j, comps in per_line.items()}
    lines = {rank[j]: y for j, y in enumerate(lines) if j in rank}
    return Lines(labels, areas, all_boxes, lines, per_line, width)


def candidates_on_image(image, name: str, lh: float) -> list[Candidate]:
    """Every cluster of ink on the printed lines of one section image."""
    import numpy as np

    found = line_components(image, lh)
    if found is None:
        return []
    labels, areas, all_boxes, lines, per_line, width = (
        found.labels, found.areas, found.boxes, found.baselines, found.components, found.width)
    out = []
    for j, comps in per_line.items():
        boxes = {k: all_boxes[k] for k in comps}
        baseline = lines[j]

        def punct(k):
            x0, y0, x1, y1 = boxes[k]
            w, h = x1 - x0, y1 - y0
            return (h <= PUNCT_SIZE[0] * lh and w <= PUNCT_SIZE[1] * lh
                    and w <= PUNCT_ASPECT * h and (y0 + y1) / 2 >= baseline - PUNCT_LIFT * lh
                    and (h <= PUNCT_STOP * lh or y1 >= baseline + PUNCT_DROP * lh))

        stops = sorted(boxes[k][0] for k in comps if punct(k))
        brackets: dict[int, object] = {}
        for k in comps:
            x0, y0, x1, y1 = boxes[k]
            if y1 - y0 > 0.8 * lh and (y1 - y0) > RULE_ASPECT * max(1, x1 - x0):
                brackets[k] = None                       # a rule: dropped
        def try_bracket(piece):
            x0 = min(boxes[k][0] for k in piece)
            y0 = min(boxes[k][1] for k in piece)
            x1 = max(boxes[k][2] for k in piece)
            y1 = max(boxes[k][3] for k in piece)
            patch = np.isin(labels[y0:y1, x0:x1], piece)
            kind, side = bracket_kind(patch, (x0, y0, x1, y1), baseline, lh)
            if not kind:
                return False
            for k in piece:
                brackets[k] = (kind, side)
            feats = shape_features(patch, lh, (baseline - y0) / lh, (baseline - y1) / lh,
                                   x0 / width, len(piece))
            out.append(Candidate(name, j, (x0, y0, x1, y1), lh, feats, bitmap=bitmap(patch),
                                 bracket=kind, side=side, stops=tuple(stops)))
            return True

        for piece in stacked_pieces([k for k in comps if k not in brackets], boxes, lh):
            # a bracket stacked against a column of blocks (``(■■)``) fails as a
            # group; each piece is then tried on its own
            if not try_bracket(piece) and len(piece) > 1:
                for k in piece:
                    try_bracket([k])
        # a bracket is a modifier of its neighbour, never part of its cluster
        keep = sorted((k for k in comps if not punct(k) and k not in brackets),
                      key=lambda k: boxes[k][0])
        def solid(k):
            x0, y0, x1, y1 = boxes[k]
            return (y1 - y0 <= BLOCK_HEIGHT * lh
                    and areas[k] >= BLOCK_FILL * (x1 - x0) * (y1 - y0))

        groups: list[list[int]] = []
        right = -10 ** 9
        for k in keep:
            x0 = boxes[k][0]
            gap = x0 - right
            # a full stop or comma between two marks always separates them
            stop_between = any(right <= s <= x0 for s in stops)
            # the solid blocks of [colony] / [house-group] stand a little further
            # apart than letters do (0.25 lh at scan 0019) and are joined across it
            blocks = bool(groups) and solid(k) and solid(groups[-1][-1])
            if groups and not stop_between and (
                    gap < JOIN_GAP * lh or (blocks and gap < BLOCK_GAP * lh)):
                groups[-1].append(k)
            else:
                groups.append([k])
            right = max(right, boxes[k][2]) if len(groups[-1]) > 1 else boxes[k][2]
        for g in groups:
            x0 = min(boxes[k][0] for k in g)
            y0 = min(boxes[k][1] for k in g)
            x1 = max(boxes[k][2] for k in g)
            y1 = max(boxes[k][3] for k in g)
            patch = np.isin(labels[y0:y1, x0:x1], g)
            feats = shape_features(patch, lh, (baseline - y0) / lh, (baseline - y1) / lh,
                                   x0 / width, len(g))
            out.append(Candidate(name, j, (x0, y0, x1, y1), lh, feats, bitmap=bitmap(patch),
                                 stops=tuple(stops)))
    # neighbours: a glyph is set between words, a letter inside one
    by_line: dict[int, list[Candidate]] = defaultdict(list)
    for c in out:
        by_line[c.line].append(c)
    for group in by_line.values():
        group.sort(key=lambda c: c.box[0])
        for a, c in enumerate(group):
            for side, b in (("letters_left", a - 1), ("letters_right", a + 1)):
                if 0 <= b < len(group):
                    gap = (c.box[0] - group[b].box[2]) if b < a else (group[b].box[0] - c.box[2])
                    c.features[side] = max(0.0, min(1.0, gap / lh))
                else:
                    c.features[side] = 1.0
    return out


def section_candidates(section: Section, cache: dict | None = None) -> list[Candidate]:
    """Every cluster of a section, in reading order, each tagged with its entry."""
    from PIL import Image
    from build_glyph_bank import line_height, scan_line_height
    from build_token_review import municipality_bands

    images = [Image.open(section.sheet_dir / n) for n in section.images]
    found: list[Candidate] = []
    for name, image in zip(section.images, images):
        lh = line_height(image.convert("L")) or scan_line_height(section.sheet_dir, section.scan)
        cands = candidates_on_image(image, name, lh)
        cands.sort(key=lambda c: (c.line, c.box[0]))
        found += cands
    if not tag_entries(found, section.printed, {n: im.width for n, im in zip(section.images, images)}):
        bands = municipality_bands(images, section.printed) if section.printed else {}
        for muni, pieces in bands.items():
            for index, top, bottom in pieces:
                name = section.images[index]
                for c in found:
                    if c.image == name and c.muni is None and top <= c.centre[1] < bottom:
                        c.muni = muni
    for k, c in enumerate(found):
        c.order = k
    return found


#: A line opens an entry when its first cluster starts within this share of the
#: image width of the leftmost line start and is at least this wide (share of the
#: width): a key's digits, not a sliver of the frame (the rule of
#: ``build_token_review.municipality_bands``, applied to these lines).
KEY_COLUMN_SHARE, KEY_MIN_SHARE = 0.02, 0.003


def tag_entries(found: list[Candidate], printed: list[int], widths: dict) -> bool:
    """Give each cluster the entry whose lines hold it, when the key lines found
    on the baselines number exactly the entries the sheet prints; else ``False``
    and nothing is tagged. A line before the first key (a heading, or an entry
    running on from the previous image) belongs to the entry open before it."""
    if not printed or not found:
        return False
    lines: dict = defaultdict(list)
    for c in found:
        lines[(c.image, c.line)].append(c)
    order = []                                  # ((image, line), opens) in reading order
    for name in dict.fromkeys(c.image for c in found):
        mine = sorted((k for k in lines if k[0] == name), key=lambda k: k[1])
        firsts = {k: min(lines[k], key=lambda c: c.box[0]) for k in mine}
        left = min(f.box[0] for f in firsts.values())
        width = widths[name]
        for k in mine:
            f = firsts[k]
            opens = (f.box[0] <= left + KEY_COLUMN_SHARE * width
                     and f.box[2] - f.box[0] >= KEY_MIN_SHARE * width)
            order.append((k, opens))
    if sum(opens for _k, opens in order) != len(printed):
        return False
    current = None
    n = -1
    for k, opens in order:
        if opens:
            n += 1
            current = printed[n]
        for c in lines[k]:
            c.muni = current
    return True

# Glyphness
# --------------------------------------------------------------------------- #

def heuristic_glyphness(f: dict) -> float:
    """A first guess, before any training. Log-odds, roughly.

    A pictogram is one piece of ink or two, about a line height tall, and it
    reaches below the baseline; its strokes are heavier than type and it often has
    a solid bar or a closed counter; it stands apart from its neighbours; and it
    is never in the key column. Set by hand after looking at the clicked fill-pair
    glyphs against every other cluster (D-93) — it only has to start the training
    off on the right side, since the alignment and the templates do the rest.
    """
    score = -1.5
    score += 1.0 if -0.55 < f["log_h"] < 0.25 else -1.5
    score += 0.0 if -1.2 < f["log_w"] < 0.75 else -2.0
    score += 0.8 if f["n_comp"] <= 2 else (-0.8 if f["n_comp"] >= 4 else 0.0)
    score += 0.6 * min(f["holes"], 2)
    score += 1.0 if f["stroke"] >= 0.095 else 0.0
    score += 0.8 if f["fill_rows"] > 0.05 else 0.0
    score += 0.8 if f["bottom"] < -0.12 else 0.0
    score += 0.5 * (f["letters_left"] > 0.35) + 0.5 * (f["letters_right"] > 0.35)
    score -= 3.0 if f["x_rel"] < 0.09 else 0.0
    return score


def feature_matrix(cands: list[Candidate]):
    import numpy as np

    return np.array([[c.features[k] for k in FEATURES] for c in cands], dtype=float)


@dataclass
class GlyphModel:
    """Logistic glyphness on :data:`FEATURES`; ``None`` coefficients = heuristic."""
    coef: list[float] | None = None
    intercept: float = 0.0
    mean: list[float] | None = None
    scale: list[float] | None = None
    trained_on: list[str] = field(default_factory=list)

    def score(self, cands: list[Candidate]):
        import numpy as np

        if self.coef is None:
            return np.array([heuristic_glyphness(c.features) for c in cands])
        x = (feature_matrix(cands) - np.array(self.mean)) / np.array(self.scale)
        return x @ np.array(self.coef) + self.intercept


def fit_glyph_model(x, y, trained_on: list[str]) -> GlyphModel:
    """Logistic regression with standardised features and a little shrinkage."""
    import numpy as np
    from sklearn.linear_model import LogisticRegression

    mean, scale = x.mean(axis=0), x.std(axis=0)
    scale[scale == 0] = 1.0
    model = LogisticRegression(C=0.5, max_iter=2000, class_weight="balanced")
    model.fit((x - mean) / scale, y)
    # class_weight="balanced" centres the intercept on equal priors; put the true
    # prior back, so a score reads as log-odds among this page's clusters
    prior = math.log(max(y.mean(), 1e-6) / max(1 - y.mean(), 1e-6))
    return GlyphModel(model.coef_[0].tolist(), float(model.intercept_[0]) + prior,
                      mean.tolist(), scale.tolist(), trained_on)

def align(score, allowed=None, miss_cost: float = MISS_COST) -> list[int | None]:
    """Monotone assignment of claims to candidates.

    ``score[i, j]`` is how well candidate ``i`` fits claim ``j`` (log-odds); both
    are in reading / printed order. Returns, for each claim, the candidate it is
    placed on or ``None``. Candidates are used at most once and in order; leaving a
    claim unplaced costs ``miss_cost``; a candidate need not be used at all.
    ``allowed[i, j]`` False forbids a placement (another entry's lines).
    """
    import numpy as np

    score = np.asarray(score, dtype=float)
    m, n = score.shape
    if n == 0:
        return []
    if m == 0:
        return [None] * n
    s = score if allowed is None else np.where(allowed, score, -np.inf)
    neg = -1e18
    # best[j][i]: best total with the first j claims settled using candidates < i
    best = np.full((n + 1, m + 1), neg)
    best[0, :] = 0.0
    for j in range(1, n + 1):
        take = np.full(m + 1, neg)
        take[1:] = best[j - 1, :-1] + s[:, j - 1]
        skip = best[j - 1] - miss_cost
        best[j] = np.maximum.accumulate(np.maximum(take, skip))
    out: list[int | None] = [None] * n
    i = m
    for j in range(n, 0, -1):
        # walk left while the value came from an earlier candidate
        while i > 0 and best[j, i] == best[j, i - 1]:
            i -= 1
        if i > 0 and np.isclose(best[j, i], best[j - 1, i - 1] + s[i - 1, j - 1]):
            out[j - 1] = i - 1
            i -= 1
        # otherwise the claim was skipped at this i
    return out


def entry_mask(cands: list[Candidate], claims: list[Claim]):
    """``allowed[i, j]``: candidate ``i`` lies in claim ``j``'s entry, or the
    entries could not be located (then nothing is forbidden)."""
    import numpy as np

    if not any(c.muni is not None for c in cands):
        return None
    munis = np.array([-1 if c.muni is None else c.muni for c in cands])
    return np.stack([munis == cl.muni for cl in claims], axis=1)


def place(cands: list[Candidate], claims: list[Claim], glyph_scores,
          token_scores=None, miss_cost: float = MISS_COST) -> list[int | None]:
    """Place every claim on a candidate: glyphness plus, if given, a
    ``[candidate, claim]`` matrix of token fit (the encoder's similarity).

    Glyphness is clipped to :data:`GLYPH_CLIP`: it is learned from what most
    glyphs look like, and a small one (``[ruin]``, ~0.4 line heights, scored
    about -7) must still be placeable when its shape fits the claim."""
    import numpy as np

    glyph = np.clip(np.asarray(glyph_scores, dtype=float), -GLYPH_CLIP, GLYPH_CLIP)
    score = np.repeat(glyph[:, None], len(claims), axis=1)
    if token_scores is not None:
        score = score + token_scores
    # too wide to be one glyph, or a bracket: never the base of a claim
    barred = np.array([c.features["log_w"] > math.log(MAX_GLYPH_WIDTH) or bool(c.bracket)
                       for c in cands])
    if len(cands):
        score[barred] = -np.inf
    return align(score, entry_mask(cands, claims), miss_cost)

#: Weight of the shape template's correlation, and the correlation that scores 0.
TEMPLATE_WEIGHT, TEMPLATE_CENTRE = 8.0, 0.45
#: Weight of the size term (squared standardised distance, capped), and the
#: floor on a token's size spread, in log line heights.
SIZE_WEIGHT, SIZE_FLOOR, SIZE_CAP = 0.5, 0.12, 9.0
#: A token gets a template once this many of its marks are placed in training.
MIN_TEMPLATE = 3


SYMBOLS = ROOT / "reference" / "places" / "symbols"


def plate_templates(symbols: Path = SYMBOLS) -> dict:
    """``token -> bitmap`` of each glyph as the legend plate prints it.

    Used only to start the locator's first round, so that a token the calibration
    pages print a few times is looked for by its shape and not by whatever the
    first, shape-blind alignment happened to put it on (``[cottage-group]``: 107
    marks, most on purposive scan 0449). Every later round replaces a seed by the
    mean of the entry clusters placed on it once there are :data:`MIN_TEMPLATE`.
    The plate never enters the classification bank (D-69): its glyphs are set
    larger, and the shape alone, reduced to 20 x 20, is all that is taken.
    """
    import numpy as np
    from PIL import Image
    from scipy import ndimage

    manifest = symbols / "manifest.csv"
    if not manifest.exists():
        return {}
    out = {}
    with manifest.open(encoding="utf-8", newline="") as fh:
        for row in csv.DictReader(fh):
            path = symbols / (row.get("file") or "")
            if not path.is_file():
                continue
            gray = np.asarray(Image.open(path).convert("L"), dtype=float)
            ink = gray < min(INK, 0.65 * float(np.median(gray)))
            labels, n = ndimage.label(ink, structure=np.ones((3, 3)))
            if not n:
                continue
            sizes = np.bincount(labels.ravel())[1:]
            boxes = ndimage.find_objects(labels)
            big = int(np.argmax(sizes))
            ys, xs = boxes[big]
            reach = 0.6 * max(ys.stop - ys.start, xs.stop - xs.start)
            keep = [k for k, (a, b) in enumerate(boxes) if sizes[k] >= 6
                    and a.start < ys.stop + reach and a.stop > ys.start - reach
                    and b.start < xs.stop + reach and b.stop > xs.start - reach]
            y0 = min(boxes[k][0].start for k in keep)
            y1 = max(boxes[k][0].stop for k in keep)
            x0 = min(boxes[k][1].start for k in keep)
            x1 = max(boxes[k][1].stop for k in keep)
            patch = np.isin(labels[y0:y1, x0:x1], [k + 1 for k in keep])
            parts = parts_of(row["token"])
            if parts == Parts(row["token"]):
                out[row["token"]] = bitmap(patch)
            elif parts.base.endswith("-base]"):
                # the plate prints this base only bracketed: a weak seed, brackets and all
                out.setdefault(parts.base, bitmap(patch))
    return out


@dataclass
class Locator:
    """What the self-training learns: glyphness, and per token a shape template
    (mean bitmap of its placed clusters) and a size (mean and spread of log
    width and height)."""
    glyph: GlyphModel = field(default_factory=GlyphModel)
    templates: dict = field(default_factory=dict)        # token -> unit vector
    sizes: dict = field(default_factory=dict)            # token -> (mu_w, mu_h, sd_w, sd_h)
    learned: set = field(default_factory=set)            # tokens whose template is entry-cut

    def token_scores(self, cands: list[Candidate], claims: list[Claim], blind: bool = False):
        """``[candidate, claim]``: how well each cluster fits each claimed token —
        shape correlation and size, zero for a token not yet learned.

        ``blind``: the same column for every claim — how well the cluster fits
        the template it fits *best*, whichever token that is. A claim under test
        is placed blind, so that its box is "the glyph at this point of the
        order", never "the glyph that looks most like what the reader says":
        otherwise the box is chosen to agree with the claim, and the encoder
        reading it is no longer an independent check."""
        import numpy as np

        out = np.zeros((len(cands), len(claims)))
        if not cands or not claims:
            return out
        maps = np.stack([c.bitmap for c in cands])
        if blind:
            if self.templates:
                stack = np.stack(list(self.templates.values()))
                best = (maps @ stack.T).max(axis=1)
                out += (TEMPLATE_WEIGHT * (best - TEMPLATE_CENTRE))[:, None]
            return out
        lw = np.array([c.features["log_w"] for c in cands])
        lh = np.array([c.features["log_h"] for c in cands])
        cache: dict[str, object] = {}
        for j, cl in enumerate(claims):
            # a claim looks for its BASE: [school-exp] for the book, [ev-parish-ab]
            # for the cross over a ring — the brackets and the letter stand beside it
            base = base_of(cl.token)
            if base not in cache:
                col = np.zeros(len(cands))
                if base in self.templates:
                    col += TEMPLATE_WEIGHT * (maps @ self.templates[base] - TEMPLATE_CENTRE)
                if base in self.sizes:
                    mw, mh, sw, sh = self.sizes[base]
                    z = ((lw - mw) / sw) ** 2 + ((lh - mh) / sh) ** 2
                    col -= SIZE_WEIGHT * np.minimum(z, SIZE_CAP)
                cache[base] = col
            out[:, j] = cache[base]
        return out

    def place(self, cands: list[Candidate], claims: list[Claim], extra=None,
              miss_cost: float = MISS_COST, blind: bool = False) -> list[int | None]:
        token = self.token_scores(cands, claims, blind)
        if extra is not None:
            token = token + extra
        return place(cands, claims, self.glyph.score(cands), token, miss_cost)


def learn_templates(placements: list[tuple[list[Candidate], list[Claim], list]]) -> tuple[dict, dict]:
    """Templates and sizes per BASE glyph from placed clusters:
    ``[(cands, claims, placed)]``. The bases of composite tokens pool with the
    plain glyph (``[colony]``'s block of four joins ``[house-group]``'s)."""
    import numpy as np

    maps: dict[str, list] = defaultdict(list)
    dims: dict[str, list] = defaultdict(list)
    for cands, claims, placed in placements:
        for cl in claims:
            i = placed[cl.order]
            if i is not None:
                base = base_of(cl.token)
                maps[base].append(cands[i].bitmap)
                dims[base].append((cands[i].features["log_w"], cands[i].features["log_h"]))
    templates, sizes = {}, {}
    for token, group in maps.items():
        if len(group) < MIN_TEMPLATE:
            continue
        mean = np.mean(group, axis=0)
        mean -= mean.mean()
        norm = float(np.linalg.norm(mean))
        if norm:
            templates[token] = mean / norm
        d = np.array(dims[token])
        sizes[token] = (float(d[:, 0].mean()), float(d[:, 1].mean()),
                        max(float(d[:, 0].std()), SIZE_FLOOR), max(float(d[:, 1].std()), SIZE_FLOOR))
    return templates, sizes


def train_locator(data, pages: set[str], rounds: int = 4, seeds: dict | None = None) -> Locator:
    """Self-training on the calibration pages in ``pages``, no hand label used:
    place the gold claims with what is known so far, then learn glyphness from
    placed-versus-not and a template and size per token from the placed clusters;
    repeat. The first round knows :func:`heuristic_glyphness` and the plate's
    shapes (:func:`plate_templates`); a token never placed often enough keeps
    its plate shape."""
    import numpy as np

    seeds = plate_templates() if seeds is None else seeds
    locator = Locator(templates=dict(seeds))
    use = [(s, c) for s, c in data if s.role == "calibration" and s.scan in pages and c]
    if not use:
        return locator
    for _ in range(rounds):
        xs, ys, placements = [], [], []
        for section, cands in use:
            placed = locator.place(cands, section.claims)
            label = np.zeros(len(cands))
            label[[i for i in placed if i is not None]] = 1
            xs.append(feature_matrix(cands))
            ys.append(label)
            placements.append((cands, section.claims, placed))
        glyph = fit_glyph_model(np.concatenate(xs), np.concatenate(ys), sorted(pages))
        templates, sizes = learn_templates(placements)
        locator = Locator(glyph, {**seeds, **templates}, sizes, set(templates))
    return locator


def locate_all(data, rounds: int = 4, blind: bool = False) -> tuple[dict, dict]:
    """Leave-page-out: each page is placed by a locator trained on the *other*
    calibration pages (a purposive page, by one trained on all of them); with
    ``blind``, placed without the claimed token's template (:meth:`Locator.token_scores`).
    Returns ``({section.key: (section, cands, placed)}, {page: locator})``."""
    calibration = sorted({s.scan for s, _ in data if s.role == "calibration"})
    seeds = plate_templates()
    trained: dict[tuple, Locator] = {}
    by_page: dict[str, Locator] = {}
    out = {}
    for section, cands in data:
        key = tuple(sorted(set(calibration) - {section.scan}))
        if key not in trained:
            trained[key] = train_locator(data, set(key), rounds, seeds)
        locator = by_page[section.scan] = trained[key]
        scores = locator.glyph.score(cands) if cands else []
        for c, s in zip(cands, scores):
            c.glyphness = float(s)
        out[section.key] = (section, cands, locator.place(cands, section.claims, blind=blind))
    return out, by_page


#: How far beside the base a bracket or a letter may stand, in line heights.
#: Measured on the composite marks of the gold pages: ``[ ♁ ]`` sets its square
#: brackets ~0.5 lh off, ``♁ A`` and ``staff V`` a word space (0.4-0.7 lh).
BRACKET_GAP, LETTER_GAP = 0.75, 0.9
#: A letter after a base: a capital's height (line heights), standing on the baseline.
#: Measured: ``A`` 0.73-0.79 lh tall and 0.58-0.73 wide, ``V`` 0.76 and 0.79 (scans 0019,
#: 0136); the old-style figures after a plain cross (``♁ 2…``) are 0.47 and are not letters.
LETTER_HEIGHT, LETTER_WIDTH, LETTER_FOOT = (0.60, 0.90), 0.85, 0.12


@dataclass
class Modifiers:
    """What stands beside a placed base, found without the claim: candidate
    indices of a left and a right bracket and of a letter, or ``None``."""
    left: int | None = None
    right: int | None = None
    letter: int | None = None

    def brackets(self, cands: list[Candidate]) -> str:
        """``round`` / ``square`` when both brackets are found (the left one's
        kind decides if they differ), else ``""``: one bracket alone brackets nothing."""
        if self.left is None or self.right is None:
            return ""
        return cands[self.left].bracket

    def box(self, cands: list[Candidate], base: int) -> tuple[int, int, int, int]:
        """The composite box: the base with whatever stands beside it."""
        parts = [cands[base].box] + [cands[i].box for i in (self.left, self.right, self.letter)
                                     if i is not None]
        return (min(b[0] for b in parts), min(b[1] for b in parts),
                max(b[2] for b in parts), max(b[3] for b in parts))


def letter_shaped(c: Candidate) -> bool:
    """A capital standing on the baseline: what A, H and V look like (and II, R, 2 too —
    which of them it is, the letter classifier says)."""
    f = c.features
    h = math.exp(f["log_h"])
    return (not c.bracket and LETTER_HEIGHT[0] <= h <= LETTER_HEIGHT[1]
            and math.exp(f["log_w"]) <= LETTER_WIDTH and abs(f["bottom"]) <= LETTER_FOOT)


#: A cluster smaller than this both ways (line heights) is a speck.
SPECK = 0.25


def is_speck(c: Candidate) -> bool:
    x0, y0, x1, y1 = c.box
    return not c.bracket and (y1 - y0) < SPECK * c.lh and (x1 - x0) < SPECK * c.lh


def line_neighbours(cands: list[Candidate]) -> dict[tuple, list[int]]:
    """``(image, line) -> candidate indices left to right``."""
    out: dict[tuple, list[int]] = defaultdict(list)
    for i, c in enumerate(cands):
        out[(c.image, c.line)].append(i)
    for key in out:
        out[key].sort(key=lambda i: cands[i].box[0])
    return out


def modifiers(cands: list[Candidate], base: int, lines: dict | None = None) -> Modifiers:
    """Brackets and a letter beside the cluster ``base``, by geometry alone.

    Token-blind on purpose: the claim says nothing about where to look, so the
    check of a claim cannot be steered by it. On the left, an opening bracket
    within BRACKET_GAP; on the right, either a closing bracket within
    BRACKET_GAP, or a letter-shaped cluster within LETTER_GAP and then perhaps
    a closing bracket after it (``(♁ A)``). Nothing is taken across a comma or
    a full stop.
    """
    lines = line_neighbours(cands) if lines is None else lines
    c = cands[base]
    lh = c.lh
    # a speck — paper noise, a serif broken off a bracket — is stepped over
    row = [i for i in lines[(c.image, c.line)]
           if i == base or not is_speck(cands[i])]
    at = row.index(base)

    def clear(a: Candidate, b: Candidate) -> bool:
        return not any(a.box[2] < s < b.box[0] for s in a.stops)

    out = Modifiers()
    if at > 0:
        left = cands[row[at - 1]]
        if (left.bracket and left.side == "open" and clear(left, c)
                and c.box[0] - left.box[2] <= BRACKET_GAP * lh):
            out.left = row[at - 1]
    if at + 1 < len(row):
        nxt = cands[row[at + 1]]
        gap = nxt.box[0] - c.box[2]
        if nxt.bracket:
            if nxt.side == "close" and clear(c, nxt) and gap <= BRACKET_GAP * lh:
                out.right = row[at + 1]
        elif letter_shaped(nxt) and clear(c, nxt) and gap <= LETTER_GAP * lh:
            out.letter = row[at + 1]
            if at + 2 < len(row):
                after = cands[row[at + 2]]
                if (after.bracket and after.side == "close" and clear(nxt, after)
                        and after.box[0] - nxt.box[2] <= BRACKET_GAP * lh):
                    out.right = row[at + 2]
    return out


def modifier_rows(located: dict) -> list[dict]:
    """One row per placed gold claim: what the plate says stands beside its base,
    and what the token-blind search found there."""
    rows = []
    for section, cands, placed in located.values():
        lines = line_neighbours(cands)
        for cl in section.claims:
            i = placed[cl.order]
            if i is None:
                continue
            m = modifiers(cands, i, lines)
            want = parts_of(cl.token)
            rows.append({"scan": section.scan, "role": section.role, "section": section.kind,
                         "muni": cl.muni, "order": cl.order, "token": cl.token,
                         "want_brackets": want.brackets, "want_letter": want.letter,
                         "found_left": cands[m.left].bracket if m.left is not None else "",
                         "found_right": cands[m.right].bracket if m.right is not None else "",
                         "found_brackets": m.brackets(cands),
                         "found_letter": m.letter is not None})
    return rows


def modifier_text(rows: list[dict]) -> str:
    def line(label, group, test):
        n = len(group)
        hit = sum(test(r) for r in group)
        return f"  {label:46s} {hit:4d} / {n:<4d} {hit / n if n else float('nan'):6.1%}"

    bracketed = [r for r in rows if r["want_brackets"]]
    plain = [r for r in rows if not r["want_brackets"]]
    lettered = [r for r in rows if r["want_letter"]]
    bare = [r for r in rows if not r["want_letter"]]
    out = ["== modifiers beside the placed base (token-blind) ==",
           line("bracketed marks: both brackets found", bracketed, lambda r: bool(r["found_brackets"])),
           line("   ... and of the right kind", bracketed,
                lambda r: r["found_brackets"] == r["want_brackets"]),
           line("plain marks: both brackets found (false)", plain, lambda r: bool(r["found_brackets"])),
           line("lettered marks: a letter-shaped cluster found", lettered, lambda r: r["found_letter"]),
           line("other marks: one found (II, R, 2 … the classifier's job)", bare,
                lambda r: r["found_letter"])]
    for token in sorted({r["token"] for r in bracketed + lettered}):
        g = [r for r in rows if r["token"] == token]
        out.append(f"    {token:22s} {len(g):3d}  brackets "
                   f"{sum(r['found_brackets'] == r['want_brackets'] for r in g):3d}  letter "
                   f"{sum(r['found_letter'] == bool(r['want_letter']) for r in g):3d}")
    return "\n".join(out)

    return {key: (section, cands, locators[section.scan].place(cands, section.claims, blind=True))

#: The text column starts at least this far right of the key column (line heights):
#: a part key (``2)``) starts ~2.3 lh in, the text ~3.8 lh (scans 0019, 0136).
TEXT_INDENT = 3.0
#: ... and when no line starts there, it is taken to start this far in.
TEXT_DEFAULT = 3.6


def line_starts(lines: Lines, lh: float) -> dict[int, int]:
    """``line -> x of its first real ink`` (specks and slivers of the frame left out)."""
    out = {}
    for j, comps in lines.components.items():
        xs = [lines.boxes[k][0] for k in comps
              if lines.boxes[k][3] - lines.boxes[k][1] >= 0.3 * lh
              and lines.boxes[k][2] - lines.boxes[k][0] >= 0.1 * lh]
        if xs:
            out[j] = min(xs)
    return out


def key_left(starts: dict[int, int], lh: float) -> float:
    """The key column's left edge: the leftmost start at least two lines share
    (within 0.6 line heights) — a sliver of the frame starts one line, a column
    starts several."""
    xs = sorted(starts.values())
    for x in xs:
        if sum(1 for y in xs if abs(y - x) <= 0.6 * lh) >= 2:
            return float(x)
    return float(xs[0]) if xs else 0.0


def text_column(starts: dict[int, int], lh: float) -> float:
    """Where the text of a section image starts: the leftmost line start at
    least TEXT_INDENT line heights right of the key column that two lines share
    (an indented paragraph or a centred heading starts further in, and only
    the text column is shared by many); TEXT_DEFAULT in when no line starts
    there (a parts section can be all key lines)."""
    if not starts:
        return 0.0
    left = key_left(starts, lh)
    far = sorted(x for x in starts.values() if x >= left + TEXT_INDENT * lh)
    for x in far:
        if sum(1 for y in far if abs(y - x) <= 0.5 * lh) >= 2:
            return float(x)
    return float(far[0]) if far else left + TEXT_DEFAULT * lh


def detector_features(cands: list[Candidate], locator: Locator):
    """Shape features, clipped glyphness and the best match to any template."""
    import numpy as np

    x = feature_matrix(cands)
    glyph = np.clip(locator.glyph.score(cands), -GLYPH_CLIP * 2, GLYPH_CLIP * 2)
    if locator.templates:
        maps = np.stack([c.bitmap for c in cands])
        best = (maps @ np.stack(list(locator.templates.values())).T).max(axis=1)
    else:
        best = np.zeros(len(cands))
    return np.column_stack([x, glyph, best])


def eligible(c: Candidate, text_x: float) -> bool:
    """A cluster that could be a mark: no bracket, no speck, not in the key column."""
    return not c.bracket and not is_speck(c) and c.box[0] >= text_x - 0.3 * c.lh


def fit_detector(x, y):
    import numpy as np
    from sklearn.linear_model import LogisticRegression

    mean, scale = x.mean(axis=0), x.std(axis=0)
    scale[scale == 0] = 1.0
    model = LogisticRegression(C=0.5, max_iter=3000, class_weight="balanced")
    model.fit((x - mean) / scale, y)
    return lambda z: model.decision_function((z - mean) / scale)


def best_threshold(scores, truth) -> float:
    """The score above which clusters are called marks, at the best F1."""
    import numpy as np

    order = np.argsort(-np.asarray(scores))
    s, t = np.asarray(scores)[order], np.asarray(truth)[order]
    tp = np.cumsum(t)
    fp = np.cumsum(1 - t)
    total = t.sum()
    f1 = 2 * tp / np.maximum(tp + fp + total, 1)
    return float(s[int(np.argmax(f1))])


def section_text_columns(section: Section) -> dict[str, float]:
    """``image -> x where its text starts``, from the line geometry alone."""
    from PIL import Image
    from build_glyph_bank import line_height, scan_line_height

    out = {}
    for name in section.images:
        image = Image.open(section.sheet_dir / name)
        lh = line_height(image.convert("L")) or scan_line_height(section.sheet_dir, section.scan)
        lines = line_components(image, lh)
        out[name] = text_column(line_starts(lines, lh), lh) if lines else 0.0
    return out


@dataclass
class Detection:
    """The token-blind detector's verdict on every cluster of every section."""
    scores: dict                 # section key -> score per candidate
    eligible: dict               # section key -> bool per candidate
    truth: dict                  # section key -> 1 where the gold placed a claim
    threshold: float
    columns: dict                # image -> text column x

    def marks(self, key: str) -> list[int]:
        """The candidates of a section called marks."""
        import numpy as np

        if key not in self.scores:
            return []
        hit = self.eligible[key] & (self.scores[key] >= self.threshold)
        return [int(i) for i in np.flatnonzero(hit)]


def detect_marks(located: dict, locators: dict) -> Detection:
    """Score every cluster with a detector trained on the calibration pages,
    where the gold says which clusters are marks — each page by a model that
    never saw it — and set one threshold on the calibration pages at the best
    F1. Uses no claim of the page it scores."""
    import numpy as np

    sections = list(located.values())
    columns: dict[str, float] = {}
    for section, _cands, _placed in sections:
        columns.update(section_text_columns(section))
    feats, truth, elig = {}, {}, {}
    for section, cands, placed in sections:
        if not cands:
            continue
        feats[section.key] = detector_features(cands, locators[section.scan])
        pos = {i for i in placed if i is not None}
        truth[section.key] = np.array([1 if i in pos else 0 for i in range(len(cands))])
        elig[section.key] = np.array([eligible(c, columns.get(c.image, 0.0)) for c in cands])
    scores: dict = {}
    for page in sorted({s.scan for s, _c, _p in sections}):
        train = [s.key for s, _c, _p in sections if s.role == "calibration" and s.scan != page
                 and s.key in feats]
        model = fit_detector(np.concatenate([feats[k][elig[k]] for k in train]),
                             np.concatenate([truth[k][elig[k]] for k in train]))
        for s, _c, _p in sections:
            if s.scan == page and s.key in feats:
                scores[s.key] = model(feats[s.key])
    cal = [s.key for s, _c, _p in sections if s.role == "calibration" and s.key in feats]
    tau = best_threshold(np.concatenate([scores[k][elig[k]] for k in cal]),
                         np.concatenate([truth[k][elig[k]] for k in cal]))
    return Detection(scores, elig, truth, tau, columns)

def inside(box, x: float, y: float, pad: float = 0.0) -> bool:
    x0, y0, x1, y1 = box
    return x0 - pad <= x <= x1 + pad and y0 - pad <= y <= y1 + pad


def match_clicks(clicks: list[dict], located: dict) -> list[dict]:
    """One row per clicked glyph: was it a candidate, was its claim placed on it.

    A click names a token and an entry, not which of the entry's marks it is, so
    the clicks of one (entry, token) are matched to the placements of that
    entry's claims of that token by nearest centre, one to one.
    """
    by_entry = defaultdict(list)
    for r in clicks:
        by_entry[(r["scan"], r["section"], int(r["muni"]), "[" + r["token"] + "]")].append(r)
    rows = []
    for (scan, kind, muni, token), group in by_entry.items():
        found = [(s, c, p) for s, c, p in located.values() if s.scan == scan and s.kind == kind
                 and group[0]["image"] in s.images]
        if not found:
            for r in group:
                rows.append({**_click_row(r), "section_found": False})
            continue
        section, cands, placed = found[0]
        boxes = [cands[placed[cl.order]] for cl in section.claims
                 if cl.muni == muni and cl.token == token and placed[cl.order] is not None]
        free = list(boxes)
        for r in group:
            x, y, lh = float(r["x"]), float(r["y"]), float(r["line_height"])
            on_image = [c for c in cands if c.image == r["image"]]
            hit = [c for c in on_image if inside(c.box, x, y, 0.1 * lh)]
            row = {**_click_row(r), "section_found": True,
                   "candidate_hit": bool(hit),
                   "candidate_glyphness": round(max((c.glyphness for c in hit), default=float("nan")), 2)}
            pool = [c for c in free if c.image == r["image"]]
            if pool:
                best = min(pool, key=lambda c: math.dist(c.centre, (x, y)))
                free.remove(best)
                row.update(placed_box=",".join(map(str, best.box)),
                           placed_hit=inside(best.box, x, y, 0.1 * lh),
                           centre_dist_lh=round(math.dist(best.centre, (x, y)) / lh, 3))
            else:
                row.update(placed_box="", placed_hit=False, centre_dist_lh=float("nan"))
            rows.append(row)
    return rows


def _click_row(r: dict) -> dict:
    return {k: r[k] for k in ("glyph_id", "token", "scan", "role", "section", "muni",
                              "image", "x", "y", "line_height")}


def false_boxes(located: dict, threshold: float = 0.0) -> list[dict]:
    """Per entry: claims, placed claims, and clusters scored as glyphs (above
    ``threshold``) that no claim was placed on — what a claim-free detector would
    have raised there."""
    rows = []
    for section, cands, placed in located.values():
        used = {i for i in placed if i is not None}
        by_muni = Counter(cl.muni for cl in section.claims)
        placed_by = Counter(cl.muni for cl in section.claims if placed[cl.order] is not None)
        extra = Counter(c.muni for i, c in enumerate(cands)
                        if i not in used and c.glyphness > threshold and c.muni is not None)
        for muni in section.printed:
            rows.append({"scan": section.scan, "role": section.role, "section": section.kind,
                         "muni": muni, "claims": by_muni[muni], "placed": placed_by[muni],
                         "unclaimed_glyphlike": extra[muni]})
    return rows


def summarise(click_rows: list[dict], entry_rows: list[dict]) -> str:
    import statistics as st

    lines = []
    n = len(click_rows)
    cand = sum(bool(r.get("candidate_hit")) for r in click_rows)
    hit = sum(bool(r.get("placed_hit")) for r in click_rows)
    dists = [r["centre_dist_lh"] for r in click_rows
             if isinstance(r.get("centre_dist_lh"), float) and not math.isnan(r["centre_dist_lh"])]
    lines.append(f"clicked glyphs: {n}")
    lines.append(f"  inside a candidate cluster        {cand:4d}  {cand / max(n, 1):6.1%}")
    lines.append(f"  inside the box placed for its claim {hit:4d}  {hit / max(n, 1):6.1%}")
    if dists:
        lines.append(f"  centre distance, placed box (lh): median {st.median(dists):.2f}, "
                     f"90th pct {sorted(dists)[int(0.9 * (len(dists) - 1))]:.2f}")
    for token in sorted({r["token"] for r in click_rows}):
        g = [r for r in click_rows if r["token"] == token]
        lines.append(f"    {token:14s} {len(g):3d}  candidate {sum(bool(r.get('candidate_hit')) for r in g) / len(g):6.1%}"
                     f"  placed {sum(bool(r.get('placed_hit')) for r in g) / len(g):6.1%}")
    for role in ROLES:
        g = [r for r in click_rows if r["role"] == role]
        if g:
            lines.append(f"    {role:14s} {len(g):3d}  placed {sum(bool(r.get('placed_hit')) for r in g) / len(g):6.1%}")
    claims = sum(r["claims"] for r in entry_rows)
    placed = sum(r["placed"] for r in entry_rows)
    with_claims = [r for r in entry_rows if r["claims"]]
    extra = [r["unclaimed_glyphlike"] for r in entry_rows]
    lines.append(f"entries: {len(entry_rows)} ({len(with_claims)} with a gold mark); "
                 f"claims {claims}, placed {placed} ({placed / max(claims, 1):.1%})")
    if extra:
        lines.append(f"  glyph-like clusters with no claim, per entry: mean "
                     f"{sum(extra) / len(extra):.2f}, median {st.median(extra):.0f}, "
                     f"entries with none {sum(e == 0 for e in extra) / len(extra):.1%}")
    return "\n".join(lines)

def box_stability(located: dict, locators: dict, sample: int = 400, seed: int = 0) -> list[dict]:
    """Does a wrong claim move its box? The bias of token-aware placement, measured.

    A reader's claim is placed with the template of the token the reader wrote,
    so where the reader is wrong the box might be pulled onto a cluster that looks
    like the wrong token — and the encoder would then agree with the error. For
    every fill-pair claim, and a random ``sample`` of the others, the claim alone is
    given a wrong token (its fill-pair partner; else a token drawn at random from
    the section's other claims) and the section placed again: is the claim's box
    the box it had with the true token?
    """
    import random

    rng = random.Random(seed)
    jobs = []
    for key, (section, cands, placed) in located.items():
        tokens = [cl.token for cl in section.claims]
        for cl in section.claims:
            if placed[cl.order] is None:
                continue
            if cl.token in PARTNER:
                jobs.append((key, cl.order, PARTNER[cl.token], "fill-pair partner"))
            else:
                others = [t for t in set(tokens) if t != cl.token]
                if others:
                    jobs.append((key, cl.order, rng.choice(sorted(others)), "random token"))
    fill = [j for j in jobs if j[3] == "fill-pair partner"]
    rest = [j for j in jobs if j[3] != "fill-pair partner"]
    jobs = fill + rng.sample(rest, min(sample, len(rest)))
    rows = []
    for key, order, wrong, kind in jobs:
        section, cands, placed = located[key]
        claims = [Claim(wrong if cl.order == order else cl.token, cl.muni, cl.seq, cl.order)
                  for cl in section.claims]
        again = locators[section.scan].place(cands, claims)
        others = [k for k, p in enumerate(placed) if p is not None and k != order]
        rows.append({"scan": section.scan, "section": section.kind, "order": order,
                     "true": section.claims[order].token, "claimed": wrong, "kind": kind,
                     "same_box": again[order] == placed[order],
                     "unplaced": again[order] is None,
                     "others_moved": sum(again[k] != placed[k] for k in others)})
    return rows


def stability_text(rows: list[dict]) -> str:
    lines = ["== a wrong claim, placed token-aware: does its box move? =="]
    for kind in ("fill-pair partner", "random token"):
        g = [r for r in rows if r["kind"] == kind]
        if g:
            same = sum(r["same_box"] for r in g)
            gone = sum(r["unplaced"] for r in g)
            lines.append(f"  {kind:18s} {len(g):4d}  same box {same / len(g):6.1%}  "
                         f"left unplaced {gone / len(g):6.1%}  moved elsewhere "
                         f"{(len(g) - same - gone) / len(g):6.1%}  (other claims moved: "
                         f"{sum(r['others_moved'] for r in g) / len(g):.2f} each)")
    return "\n".join(lines)


def draw(located: dict, scan: str, out_dir: Path) -> list[Path]:
    """Overlay each section image of ``scan``: grey = cluster, red = placed claim."""
    from PIL import Image, ImageDraw

    written = []
    for section, cands, placed in located.values():
        if section.scan != scan:
            continue
        labels = {placed[cl.order]: cl.token for cl in section.claims if placed[cl.order] is not None}
        for name in section.images:
            image = Image.open(section.sheet_dir / name).convert("RGB")
            pen = ImageDraw.Draw(image)
            for i, c in enumerate(cands):
                if c.image != name:
                    continue
                if i in labels:
                    pen.rectangle(c.box, outline=(210, 30, 40), width=3)
                    pen.text((c.box[0], c.box[3] + 2), labels[i].strip("[]"), fill=(210, 30, 40))
                elif c.glyphness > 0:
                    pen.rectangle(c.box, outline=(0, 90, 200), width=2)
                else:
                    pen.rectangle(c.box, outline=(170, 170, 170), width=1)
            out = out_dir / f"overlay_{Path(name).stem}.jpg"
            image.save(out, quality=85)
            written.append(out)
    return written


def write_boxes(located: dict, path: Path) -> None:
    """Every placed claim with its box — what the bank and the encoder read."""
    with path.open("w", encoding="utf-8", newline="") as fh:
        writer = csv.writer(fh)
        writer.writerow(["scan", "role", "section", "muni", "seq", "order", "token", "base",
                         "image", "x0", "y0", "x1", "y1", "line_height", "glyphness",
                         "bracket_left", "bracket_right", "letter_box", "composite_box"])
        for section, cands, placed in located.values():
            lines = line_neighbours(cands)
            for cl in section.claims:
                i = placed[cl.order]
                head = [section.scan, section.role, section.kind, cl.muni, cl.seq, cl.order,
                        cl.token, base_of(cl.token)]
                if i is None:
                    writer.writerow(head + [""] * 11)
                    continue
                c = cands[i]
                m = modifiers(cands, i, lines)
                writer.writerow(head + [c.image, *c.box, round(c.lh, 1), round(c.glyphness, 3),
                                        cands[m.left].bracket if m.left is not None else "",
                                        cands[m.right].bracket if m.right is not None else "",
                                        ",".join(map(str, cands[m.letter].box)) if m.letter is not None else "",
                                        ",".join(map(str, m.box(cands, i)))])


def write_candidates(located: dict, path: Path) -> None:
    """Every cluster of every section, with its features and glyphness."""
    with path.open("w", encoding="utf-8", newline="") as fh:
        writer = csv.writer(fh)
        writer.writerow(["scan", "role", "section", "image", "order", "line", "muni",
                         "x0", "y0", "x1", "y1", "line_height", "glyphness", "claim",
                         *FEATURES])
        for section, cands, placed in located.values():
            claim_of = {placed[cl.order]: cl.token for cl in section.claims
                        if placed[cl.order] is not None}
            for i, c in enumerate(cands):
                writer.writerow([section.scan, section.role, section.kind, c.image, c.order,
                                 c.line, "" if c.muni is None else c.muni, *c.box,
                                 round(c.lh, 1), round(c.glyphness, 3), claim_of.get(i, ""),
                                 *[round(c.features[k], 4) for k in FEATURES]])


def main(argv=None) -> int:
    for stream in (sys.stdout, sys.stderr):
        try:
            stream.reconfigure(encoding="utf-8", errors="replace")
        except (AttributeError, ValueError):
            pass
    ap = argparse.ArgumentParser(description=__doc__,
                                 formatter_class=argparse.RawDescriptionHelpFormatter)
    ap.add_argument("--rounds", type=int, default=4, help="self-training rounds")
    ap.add_argument("--draw", default="", help="comma-separated scans to overlay")
    ap.add_argument("--out", default=str(OUT))
    args = ap.parse_args(argv)
    out = Path(args.out)
    out.mkdir(parents=True, exist_ok=True)

    data = load_sections()
    print(f"locate: {len(data)} sections, {sum(len(c) for _s, c in data)} clusters, "
          f"{sum(len(s.claims) for s, _c in data)} gold marks on "
          f"{len({s.scan for s, _c in data})} pages")
    located, locators = locate_all(data, args.rounds)
    blind = place_blind(located, locators)
    write_boxes(located, out / "boxes_gold.csv")
    write_boxes(blind, out / "boxes_gold_blind.csv")
    write_candidates(located, out / "candidates.csv")
    with (BANK / "glyph_bank.csv").open(encoding="utf-8", newline="") as fh:
        clicks = list(csv.DictReader(fh))
    texts = []
    for mode, placed in (("token-aware", located), ("token-blind", blind)):
        click_rows = match_clicks(clicks, placed)
        entry_rows = false_boxes(placed)
        suffix = "" if mode == "token-aware" else "_blind"
        for name, rows in ((f"locator_clicks{suffix}.csv", click_rows),
                           (f"locator_entries{suffix}.csv", entry_rows)):
            with (out / name).open("w", encoding="utf-8", newline="") as fh:
                fields = list(dict.fromkeys(k for r in rows for k in r))
                writer = csv.DictWriter(fh, fieldnames=fields)
                writer.writeheader()
                writer.writerows(rows)
        texts.append(f"== placement {mode} ==\n" + summarise(click_rows, entry_rows))
    mods = modifier_rows(located)
    with (out / "locator_modifiers.csv").open("w", encoding="utf-8", newline="") as fh:
        writer = csv.DictWriter(fh, fieldnames=list(mods[0]))
        writer.writeheader()
        writer.writerows(mods)
    texts.append(modifier_text(mods))
    rows = box_stability(located, locators)
    with (out / "locator_stability.csv").open("w", encoding="utf-8", newline="") as fh:
        writer = csv.DictWriter(fh, fieldnames=list(rows[0]))
        writer.writeheader()
        writer.writerows(rows)
    texts.append(stability_text(rows))
    text = "\n\n".join(texts)
    print(text)
    (out / "locator.txt").write_text(text + "\n", encoding="utf-8")
    for scan in filter(None, args.draw.split(",")):
        for p in draw(located, scan, out):
            print(f"  overlay -> {p}")
    print(f"  -> {out}")
    return 0
