TL;DR

Harmonises the Rumpler-Seger / MPIDR census workbooks in data/raw/census/ and joins them to utils.parsing.districts (districts_1910) by exact unit code — the census IDCourtdistr equals our court_id (339/339) and IDPoldistrict equals our okres_id (region·1000 + district). No name matching.

How it works

Each workbook has a data sheet (ID columns + value columns) and a Variable Names sheet giving the multi-row, merged-cell German header for each value column. Value columns are named by topic + index (Religion1..18, Umgspr1..11, Gebor1.., Beruf1.. …) — the one exception is the district-court justice caseload file, whose columns are generic V1..V91.

Naming (_column_names)

The Variable Names sheet is read with openpyxl so merged cells are expanded exactly (a de-merged pandas read would let a deep label such as helvetischen Bekenntnisses bleed into the next column). Each value column becomes {prefix}_{leaf} where:

  • prefix comes from the value column's own stem via STEM_PREFIX (Religion→rel, Umgspr→umgspr, …), falling back to a filename topic (FILE_PREFIX) for the generic-V justice file — so a mixed workbook (Religion + Umgangssprache) keeps each family correctly labelled;
  • leaf is the merged header path with the redundant top category removed: within each prefix group the longest common leading label sequence (e.g. Anwesende Bevölkerung nach der Religion) is trimmed, leaving the discriminating tail (roemisch_katholisch, deutsch, bohmisch_mahrisch_slowakisch) while keeping a genuinely discriminating top label where it varies (lebendgeborene vs totgeborene).

load_census_file filters to the Czech crown lands and returns a tidy frame keyed by court_id (934-level files) or okres_id (406-level files). build_census_panel loads every Cisleithanian file, aggregates 934-level counts up to the okres, and returns one okres-level covariate table (158 Czech-lands okresy) — the join target for legionnaire/habsburg birth_okres. Hungarian and regional-court (72-level) files are skipped. As a final step the German covariate names are renamed to English by utils.parsing.census_labels (lang_czech, rel_jewish, literacy_rate …), with derived shares/rates added; the German→English crosswalk is reference/census_column_labels.csv.

Usage

panel = cz.build_census_panel(CENSUS_DIR, districts_1910)   # okres-level covariates
cz.census_report(panel)

def load_census_file(path) -> tuple[pd.DataFrame, str]:
    """Load one census workbook → (tidy Czech-lands frame, level).

    ``level`` is ``"court"`` (keyed ``court_id`` = ``IDCourtdistr``) or ``"okres"``
    (keyed ``okres_id`` = ``IDPoldistrict``). Value columns are renamed via
    :func:`_column_names`; ID/name columns are dropped except the key.
    """
    path = Path(path)
    xl = pd.ExcelFile(path)
    data = xl.parse(xl.sheet_names[0])

    if "IDCourtdistr" in data.columns:
        level, key_src = "court", "IDCourtdistr"
    elif "IDPoldistrict" in data.columns:
        level, key_src = "okres", "IDPoldistrict"
    else:
        raise ValueError(f"{path.name}: no IDCourtdistr/IDPoldistrict key column")

    id_cols = [c for c in data.columns
               if str(c).startswith("ID") or "Name" in str(c) or c in ("N", "Place")]
    # value columns: drop id columns and stray blank-header cells (pandas "Unnamed: N",
    # empty/NaN headers) that carry no variable-sheet entry
    val_cols = [c for c in data.columns
                if c not in id_cols
                and not str(c).startswith("Unnamed")
                and str(c).strip().lower() not in ("", "nan")]
    if not val_cols:
        raise ValueError(f"{path.name}: no value columns")

    # crown-land filter (Czech lands): use IDCrownland if present, else first 3 digits of the key
    if "IDCrownland" in data.columns:
        land = data["IDCrownland"].map(_land3)
    else:
        land = data[key_src].map(_land3)
    data = data[land.isin(CZECH_LAND_CODES)].copy()

    # build value-column names from the merged Variable-Names sheet
    var_sheet = next((s for s in xl.sheet_names if "variable" in s.lower()), None)
    prefixes = {str(c): _prefix_for(c, path.name) for c in val_cols}
    if var_sheet:
        varparts = _expand_varsheet(path, var_sheet, [str(c) for c in val_cols])
        varparts = {k: varparts.get(k, []) for k in map(str, val_cols)}
        rename = _column_names(varparts, prefixes)
    else:
        rename = {str(c): f"{prefixes[str(c)]}_{_clean_name(c)}" for c in val_cols}

    out = pd.DataFrame({"unit_id": data[key_src].astype("Int64")})
    for c in val_cols:
        out[rename[str(c)]] = pd.to_numeric(data[c], errors="coerce")
    # collapse duplicate unit rows (e.g. several Sparkassen per court) by sum
    out = out.groupby("unit_id", as_index=False).sum(min_count=1)
    return out, level

def build_census_panel(census_dir, districts: pd.DataFrame) -> pd.DataFrame

Load all Cisleithanian census files → one okres-level covariate panel.

Court-level (934) files are summed up to their okres (court_id // 1000 = IDPoldistrict). The result is joined to the okres identity from districts (one row per Czech-lands political okres) on okres_id.

City/rural twins are a structural gap in the court-level sources, and it is handled here rather than left for the reader. A statutory city had no Gerichtsbezirk of its own: the city and the rural seat court around it were one court, and the census keeps one row for it — Iglau/Jihlava Stadt, Olmuetz/Olomouc Stadt. The backbone splits that court in two so it can nest inside two okresy, so court_id // 1000 dumps the pair's total onto whichever member the id encodes and leaves the other empty. The result is not coarse, it is mislabelled: Opava (město) would read 0.463 Czech-speaking, which is Gerichtsbezirk Troppau — city plus ring — while Opava would read 0.069, which is only Odry and Vítkov.

Every twin okres missing its own seat court in a given file is recorded, with that file's columns, in panel.attrs["twin_suppressed"]. Nine of the ten pairs are flagged in the Religion/Umgangssprache source; Brno is not (it has genuine Brno Stadt and Brno Land court rows) and keeps its values throughout.

The panel this returns is unblanked — it still carries the merged value on whichever member absorbed it, because that value is the pair's total and pool_twin_okresy needs it. Use build_census_panels to get the pair of frames actually meant for use: the member-level panel with the twins blanked, and the pooled 148-row panel.

Used only inside this module.

def build_census_panel(census_dir, districts: pd.DataFrame) -> pd.DataFrame:
    """Load all Cisleithanian census files → one **okres-level** covariate panel.

    Court-level (934) files are summed up to their okres (``court_id // 1000`` =
    ``IDPoldistrict``). The result is joined to the okres identity from *districts*
    (one row per Czech-lands political okres) on ``okres_id``.

    City/rural twins are a **structural gap in the court-level sources**, and it is handled here
    rather than left for the reader. A statutory city had no Gerichtsbezirk of its own: the city
    and the rural seat court around it were one court, and the census keeps one row for it —
    ``Iglau/Jihlava Stadt``, ``Olmuetz/Olomouc Stadt``. The backbone splits that court in two so
    it can nest inside two okresy, so ``court_id // 1000`` dumps the **pair's** total onto
    whichever member the id encodes and leaves the other empty. The result is not coarse, it is
    *mislabelled*: ``Opava (město)`` would read 0.463 Czech-speaking, which is Gerichtsbezirk
    Troppau — city plus ring — while ``Opava`` would read 0.069, which is only Odry and Vítkov.

    Every twin okres missing its own **seat** court in a given file is recorded, with that file's
    columns, in ``panel.attrs["twin_suppressed"]``. Nine of the ten pairs are flagged in the
    Religion/Umgangssprache source; Brno is not (it has genuine ``Brno Stadt`` and ``Brno Land``
    court rows) and keeps its values throughout.

    The panel this returns is **unblanked** — it still carries the merged value on whichever
    member absorbed it, because that value is the pair's total and :func:`pool_twin_okresy` needs
    it. Use :func:`build_census_panels` to get the pair of frames actually meant for use: the
    member-level panel with the twins blanked, and the pooled 148-row panel.
    """
    census_dir = Path(census_dir)
    okres = (districts.drop_duplicates("okres_code")[["land", "okres_code", "okres_cs", "okres_de"]]
             .copy())
    okres["okres_id"] = okres["okres_code"].map(_okres_id)
    panel = okres.set_index("okres_id")

    twins = rg.build_twin_pairs(districts)
    seats = _seat_courts(districts)
    suppressed: dict[str, tuple[list[int], list[str]]] = {}

    loaded = []
    for f in sorted(census_dir.glob("*.xlsx")):
        if any(s in f.name for s in _SKIP_SUBSTR):
            continue
        try:
            tidy, level = load_census_file(f)
        except Exception as e:                       # noqa: BLE001 — report & continue
            print(f"  [skip] {f.name}: {e}")
            continue
        if level == "court":
            have = set(tidy["unit_id"].dropna().astype(int))
            tidy["okres_id"] = tidy["unit_id"] // 1000     # court_id → IDPoldistrict
            tidy = tidy.drop(columns="unit_id").groupby("okres_id").sum(min_count=1)
            # a twin okres missing its own SEAT court here → the pair was merged upstream, so
            # neither member's value is attributable. Recorded, not blanked: the value that
            # survived is the pair total, which pool_twin_okresy still needs.
            bad: set[int] = set()
            for oid, (rural, city, _keys) in twins.items():
                if seats.get(oid, set()) - have:
                    bad |= {rural, city}
            if bad:
                suppressed[f.name] = (sorted(bad), list(tidy.columns))
        else:
            tidy = tidy.rename(columns={"unit_id": "okres_id"}).set_index("okres_id")
        dup = [c for c in tidy.columns if c in panel.columns]
        if dup:
            # a later file re-producing an already-loaded column name would silently
            # shadow it — drop and SAY so, so a genuine cross-file collision is visible
            print(f"  [dup ] {f.name}: dropping {len(dup)} column(s) already loaded: "
                  f"{', '.join(map(str, dup[:6]))}{' …' if len(dup) > 6 else ''}")
            tidy = tidy.drop(columns=dup)
        panel = panel.join(tidy, how="left")
        loaded.append((f.name, level, tidy.shape[1]))

    panel = panel.reset_index()
    loaded_meta = loaded
    from utils.parsing import census_labels as _cl          # English labels + derived shares
    rename = _cl.english_rename_map(panel, "cis")           # carry the flags through the rename
    panel = _cl.to_english_census(panel, "cis")
    panel.attrs["loaded"] = loaded_meta
    panel.attrs["twin_suppressed"] = {
        name: (oids, [rename.get(c, c) for c in cols])
        for name, (oids, cols) in suppressed.items()
    }
    return panel

def okres_census_crosswalk(districts: pd.DataFrame) -> pd.DataFrame:
    """``okres_id → census_okres_id`` (+ ``twin_pooled``, ``twin_role``), one row per okres.

    The identity map everywhere except the twenty city/rural twin members, which both point at
    the **rural** member's id — the pooled unit. Written to ``data/final/geo/`` so an analysis
    can join on it without re-deriving the pairs.
    """
    twins = rg.build_twin_pairs(districts)
    rows = []
    for code in districts["okres_code"].drop_duplicates():
        oid = _okres_id(code)
        entry = twins.get(oid)
        if entry is None:
            rows.append({"okres_id": oid, "census_okres_id": oid,
                         "twin_pooled": False, "twin_role": pd.NA})
        else:
            rural, city, _ = entry
            rows.append({"okres_id": oid, "census_okres_id": rural, "twin_pooled": True,
                         "twin_role": "city" if oid == city else "ring"})
    return pd.DataFrame(rows).sort_values("okres_id").reset_index(drop=True)

def pool_twin_okresy(panel: pd.DataFrame, districts: pd.DataFrame) -> pd.DataFrame

Collapse each city/rural twin pair into one unit → the 148-row analytical panel.

This is the baseline unit for a district-level covariate merge, not a robustness variant: for nine of the ten pairs the court-level sources do not split city from ring at all (build_census_panel), so the pair is the finest unit on which language, religion and the justice caseload are defined. The okres-level (406) sources do split all ten, and those columns survive at member level in the un-pooled panel for anyone who wants them.

Counts are summed with min_count=1 — so a pair whose total sits on one row and &lt;NA&gt; on the other recovers the total, and a pair with no data at all stays &lt;NA&gt; — and every share is then re-derived from the pooled counts by census_labels.add_shares_cis. Identity (code, names, land) comes from the rural member, which is also the pooled id.

def pool_twin_okresy(panel: pd.DataFrame, districts: pd.DataFrame) -> pd.DataFrame:
    """Collapse each city/rural twin pair into one unit → the **148-row** analytical panel.

    This is the baseline unit for a district-level covariate merge, not a robustness variant:
    for nine of the ten pairs the court-level sources do not split city from ring at all
    (:func:`build_census_panel`), so the pair is the finest unit on which language, religion and
    the justice caseload are defined. The okres-level (406) sources *do* split all ten, and those
    columns survive at member level in the un-pooled panel for anyone who wants them.

    Counts are summed with ``min_count=1`` — so a pair whose total sits on one row and ``<NA>``
    on the other recovers the total, and a pair with no data at all stays ``<NA>`` — and every
    share is then **re-derived from the pooled counts** by ``census_labels.add_shares_cis``.
    Identity (code, names, land) comes from the rural member, which is also the pooled id.
    """
    from utils.parsing import census_labels as _cl

    xw = okres_census_crosswalk(districts).set_index("okres_id")["census_okres_id"]
    out = panel.copy()
    out["census_okres_id"] = out["okres_id"].map(xw).astype("Int64")

    ident = ["land", "okres_code", "okres_cs", "okres_de"]
    skip = set(ident) | {"okres_id", "census_okres_id"} | set(_derived_columns(out))
    counts = [c for c in out.columns if c not in skip]

    agg = out.groupby("census_okres_id")[counts].sum(min_count=1)
    idr = (out[out["okres_id"] == out["census_okres_id"]]
           .set_index("census_okres_id")[ident])
    pooled = idr.join(agg).reset_index()

    twins = rg.build_twin_pairs(districts)
    pooled["twin_pooled"] = pooled["census_okres_id"].isin({e[0] for e in twins.values()})
    return _cl.add_shares_cis(pooled)

def blank_twin_members(panel: pd.DataFrame) -> pd.DataFrame:
    """Blank the court-derived columns on the twin members the source could not separate.

    Reads ``panel.attrs["twin_suppressed"]`` (set by :func:`build_census_panel`) and sets those
    columns to ``<NA>`` on **both** members of every affected pair. The value being removed is
    not merely coarse — it is attached to the wrong unit — so leaving it in place would be worse
    than leaving a hole. Shares are re-derived afterwards so no stale ratio survives its counts.
    """
    from utils.parsing import census_labels as _cl

    out = panel.copy()
    for oids, cols in panel.attrs.get("twin_suppressed", {}).values():
        cols = [c for c in cols if c in out.columns]
        if cols:
            out.loc[out["okres_id"].isin(oids), cols] = float("nan")
    out = out.drop(columns=_derived_columns(out), errors="ignore")
    out = _cl.add_shares_cis(out)
    out.attrs["twin_suppressed"] = panel.attrs.get("twin_suppressed", {})
    out.attrs["loaded"] = panel.attrs.get("loaded", [])
    return out

def census_report(panel: pd.DataFrame) -> None:
    """Print coverage: okresy, covariate count, and which files loaded."""
    covs = [c for c in panel.columns
            if c not in ("okres_id", "land", "okres_code", "okres_cs", "okres_de")]
    print(f"Census okres panel  (okresy = {len(panel)}, covariates = {len(covs)})\n")
    for name, level, n in panel.attrs.get("loaded", []):
        print(f"  [{level:<5}] {n:>3} cols  {name}")
    miss = panel[covs].isna().all(axis=1).sum()
    print(f"\n  okresy with no census match: {miss}")
    sup = panel.attrs.get("twin_suppressed", {})
    if sup:
        print("\n  city/rural twins the source cannot separate (one court row per pair; the")
        print("  member values are blanked, the pair total survives in the pooled panel):")
        for name, (oids, cols) in sorted(sup.items()):
            print(f"    [{len(oids):>2} okresy · {len(cols):>2} cols] {name}")

"""
census.py — 1910/1911 Cisleithanian census loader, joined to the district backbone
==================================================================================
Harmonises the Rumpler-Seger / MPIDR census workbooks in ``data/raw/census/`` and joins
them to :mod:`utils.parsing.districts` (``districts_1910``) by **exact unit code** — the
census ``IDCourtdistr`` equals our ``court_id`` (339/339) and ``IDPoldistrict`` equals our
``okres_id`` (``region·1000 + district``). No name matching.

Each workbook has a data sheet (ID columns + value columns) and a *Variable Names* sheet
giving the **multi-row, merged-cell German header** for each value column. Value columns are
named by topic + index (``Religion1..18``, ``Umgspr1..11``, ``Gebor1..``, ``Beruf1..`` …) —
the one exception is the district-court justice caseload file, whose columns are generic
``V1..V91``.

Naming (:func:`_column_names`)
------------------------------
The *Variable Names* sheet is read with :mod:`openpyxl` so merged cells are expanded
**exactly** (a de-merged pandas read would let a deep label such as
``helvetischen Bekenntnisses`` bleed into the next column). Each value column becomes
``{prefix}_{leaf}`` where:

* ``prefix`` comes from the value column's own stem via :data:`STEM_PREFIX`
  (``Religion→rel``, ``Umgspr→umgspr``, …), falling back to a filename topic
  (:data:`FILE_PREFIX`) for the generic-``V`` justice file — so a mixed workbook
  (Religion + Umgangssprache) keeps each family correctly labelled;
* ``leaf`` is the merged header path with the redundant top **category** removed: within
  each prefix group the longest common leading label sequence (e.g.
  ``Anwesende Bevölkerung nach der Religion``) is trimmed, leaving the discriminating tail
  (``roemisch_katholisch``, ``deutsch``, ``bohmisch_mahrisch_slowakisch``) while keeping a
  genuinely discriminating top label where it varies (``lebendgeborene`` vs ``totgeborene``).

:func:`load_census_file` filters to the Czech crown lands and returns a tidy frame keyed by
``court_id`` (934-level files) or ``okres_id`` (406-level files). :func:`build_census_panel`
loads every Cisleithanian file, aggregates 934-level counts up to the okres, and returns one
**okres-level** covariate table (158 Czech-lands okresy) — the join target for
legionnaire/habsburg ``birth_okres``. Hungarian and regional-court (72-level) files are skipped.
As a final step the German covariate names are **renamed to English** by
:mod:`utils.parsing.census_labels` (``lang_czech``, ``rel_jewish``, ``literacy_rate`` …), with
derived shares/rates added; the German→English crosswalk is `reference/census_column_labels.csv`.

Usage
-----
    from utils.parsing import census as cz
    panel = cz.build_census_panel(CENSUS_DIR, districts_1910)   # okres-level covariates
    cz.census_report(panel)
"""

from __future__ import annotations

import re
import unicodedata
from pathlib import Path

import openpyxl
import pandas as pd

from utils.parsing import records_geo as rg

__version__ = "1.3.0"

# Czech crown-land census codes (first three digits): Böhmen 301 / Mähren 302 / Schlesien 303.
CZECH_LAND_CODES = {301, 302, 303}

# Files to skip: Hungarian (Transleithania), regional-court (72-level, coarser than backbone),
# and the code-book itself.
_SKIP_SUBSTR = ("Justizstatistik HUN", "Regional courts 72", "Gerichtshofe", "Gerichtshoefen",
                "CODE file")

# Value-column stem (digits stripped, cleaned) → short covariate prefix.
STEM_PREFIX = {
    "gebor": "geb",            # Bewegung der Bevölkerung — Geborene
    "gestorbkind": "gest_kind",  # Gestorbene Kinder bis 5
    "gestorb": "gest",         # Gestorbene
    "todesur": "todes",        # Todesursachen
    "beruf": "beruf",          # Volkszählung — Beruf
    "lit": "bild",             # Bildungsgrad (Literaten)
    "einwohn": "pop",          # Einwohner nach Größenkategorien
    "religion": "rel",         # Religion
    "umgspr": "umgspr",        # Umgangssprache
    "grossvieh": "vieh_gross",
    "kleinvieh": "vieh_klein",
    "viehgesamt": "vieh_ges",
    "sparbil": "spar_bil",     # Sparkassen Bilanzen
    "sparbucher": "spar_buch",  # Sparkassebücher
    "pbg": "just_pers",        # Personal bei Bezirksgerichte
}

# Fallback prefix by filename substring, used when the stem is generic (e.g. ``V``).
FILE_PREFIX = (
    ("Justizstatistik Bezirksgericht", "just_bg"),
)


# ═══════════════════════════════════════════════════════════════════════════
# Header naming (openpyxl merge-expanded)
# ═══════════════════════════════════════════════════════════════════════════
def _clean_name(s) -> str:
    """snake_case ASCII from a German header fragment (ä→a, ß→ss, spaces→_)."""
    s = str(s).strip().lower()
    s = s.replace("ä", "a").replace("ö", "o").replace("ü", "u").replace("ß", "ss")
    s = "".join(c for c in unicodedata.normalize("NFKD", s) if not unicodedata.combining(c))
    s = re.sub(r"[^a-z0-9]+", "_", s)
    return s.strip("_")


def _stem(col) -> str:
    """Value-column stem: strip a trailing index (``Religion1`` → ``religion``)."""
    return _clean_name(re.sub(r"\d+$", "", str(col)))


def _prefix_for(col, filename: str) -> str:
    """Covariate prefix for one value column: stem map → filename fallback → cleaned stem."""
    st = _stem(col)
    if st in STEM_PREFIX:
        return STEM_PREFIX[st]
    for sub, pfx in FILE_PREFIX:
        if sub in filename:
            return pfx
    return st or "v"


def _expand_varsheet(path: Path, sheet: str, val_ids: list) -> dict:
    """Return {value-column id → ordered list of merged-header label strings}.

    Reads with :mod:`openpyxl` and fills every merged range with its top-left value so the
    header hierarchy is reconstructed exactly. The header id row (holding ``Religion1`` …) is
    located by matching *val_ids*; labels are the rows below it.
    """
    wb = openpyxl.load_workbook(path, data_only=True, read_only=False)
    ws = wb[sheet]
    grid = [[c.value for c in row] for row in ws.iter_rows()]
    for mr in ws.merged_cells.ranges:                       # expand merges exactly
        tl = ws.cell(mr.min_row, mr.min_col).value
        for r in range(mr.min_row, mr.max_row + 1):
            for c in range(mr.min_col, mr.max_col + 1):
                grid[r - 1][c - 1] = tl
    if not grid:
        return {}
    idset = {str(v) for v in val_ids}
    id_row = max(range(len(grid)),
                 key=lambda r: sum(1 for x in grid[r] if str(x) in idset))
    colpos: dict[str, int] = {}
    for c, x in enumerate(grid[id_row]):
        if str(x) in idset and str(x) not in colpos:
            colpos[str(x)] = c
    out: dict[str, list] = {}
    for vid, c in colpos.items():
        parts = [grid[r][c] for r in range(id_row + 1, len(grid))
                 if grid[r][c] is not None and str(grid[r][c]).strip()]
        out[vid] = parts
    return out


def _lcp(seqs: list[list[str]]) -> int:
    """Length of the longest common leading subsequence across *seqs* (empty → 0)."""
    if not seqs:
        return 0
    n = min(len(s) for s in seqs)
    i = 0
    while i < n and len({s[i] for s in seqs}) == 1:
        i += 1
    return i


def _column_names(varparts: dict, prefixes: dict) -> dict:
    """Map each value-column id → ``{prefix}_{trimmed leaf}``, unique within the file.

    Within each prefix group the shared leading labels (the topic category) are trimmed so
    only the discriminating tail survives; a category that genuinely varies across the group
    (``lebendgeborene`` vs ``totgeborene``) is kept because it is not part of the common prefix.
    """
    # clean + dedupe the label path per column
    cleaned = {vid: [p for p in dict.fromkeys(_clean_name(x) for x in parts) if p]
               for vid, parts in varparts.items()}

    names: dict[str, str] = {}
    groups: dict[str, list[str]] = {}
    for vid, pfx in prefixes.items():
        groups.setdefault(pfx, []).append(vid)

    for pfx, vids in groups.items():
        multi = [cleaned.get(v, []) for v in vids if len(cleaned.get(v, [])) >= 2]
        drop = _lcp(multi) if len(multi) >= 2 else 0
        for v in vids:
            parts = cleaned.get(v, [])
            if len(parts) > drop:                            # keep at least the leaf
                parts = parts[drop:]
            body = "_".join(parts) if parts else ""
            body = re.sub(r"_?spalte_\d+(?:_\d+)*", "", body)  # drop "(Spalte 2-18)" noise
            body = body.strip("_")
            names[v] = f"{pfx}_{body}" if body else pfx

    # guarantee uniqueness (defensive: collisions get a numeric suffix)
    seen: dict[str, int] = {}
    for v in list(names):
        base = names[v]
        if base in seen.values() or list(names.values()).count(base) > 1:
            seen[base] = seen.get(base, 0) + 1
            if seen[base] > 1:
                names[v] = f"{base}_{seen[base]}"
    return names


# ═══════════════════════════════════════════════════════════════════════════
# Per-file loader
# ═══════════════════════════════════════════════════════════════════════════
def _land3(code) -> int:
    """First three digits of a unit code (crown land), robust to 6- or 9-digit ids."""
    try:
        return int(str(int(code))[:3])
    except (ValueError, TypeError):
        return -1


def load_census_file(path) -> tuple[pd.DataFrame, str]:
    """Load one census workbook → (tidy Czech-lands frame, level).

    ``level`` is ``"court"`` (keyed ``court_id`` = ``IDCourtdistr``) or ``"okres"``
    (keyed ``okres_id`` = ``IDPoldistrict``). Value columns are renamed via
    :func:`_column_names`; ID/name columns are dropped except the key.
    """
    path = Path(path)
    xl = pd.ExcelFile(path)
    data = xl.parse(xl.sheet_names[0])

    if "IDCourtdistr" in data.columns:
        level, key_src = "court", "IDCourtdistr"
    elif "IDPoldistrict" in data.columns:
        level, key_src = "okres", "IDPoldistrict"
    else:
        raise ValueError(f"{path.name}: no IDCourtdistr/IDPoldistrict key column")

    id_cols = [c for c in data.columns
               if str(c).startswith("ID") or "Name" in str(c) or c in ("N", "Place")]
    # value columns: drop id columns and stray blank-header cells (pandas "Unnamed: N",
    # empty/NaN headers) that carry no variable-sheet entry
    val_cols = [c for c in data.columns
                if c not in id_cols
                and not str(c).startswith("Unnamed")
                and str(c).strip().lower() not in ("", "nan")]
    if not val_cols:
        raise ValueError(f"{path.name}: no value columns")

    # crown-land filter (Czech lands): use IDCrownland if present, else first 3 digits of the key
    if "IDCrownland" in data.columns:
        land = data["IDCrownland"].map(_land3)
    else:
        land = data[key_src].map(_land3)
    data = data[land.isin(CZECH_LAND_CODES)].copy()

    # build value-column names from the merged Variable-Names sheet
    var_sheet = next((s for s in xl.sheet_names if "variable" in s.lower()), None)
    prefixes = {str(c): _prefix_for(c, path.name) for c in val_cols}
    if var_sheet:
        varparts = _expand_varsheet(path, var_sheet, [str(c) for c in val_cols])
        varparts = {k: varparts.get(k, []) for k in map(str, val_cols)}
        rename = _column_names(varparts, prefixes)
    else:
        rename = {str(c): f"{prefixes[str(c)]}_{_clean_name(c)}" for c in val_cols}

    out = pd.DataFrame({"unit_id": data[key_src].astype("Int64")})
    for c in val_cols:
        out[rename[str(c)]] = pd.to_numeric(data[c], errors="coerce")
    # collapse duplicate unit rows (e.g. several Sparkassen per court) by sum
    out = out.groupby("unit_id", as_index=False).sum(min_count=1)
    return out, level


# ═══════════════════════════════════════════════════════════════════════════
# Panel builder
# ═══════════════════════════════════════════════════════════════════════════
def _okres_id(okres_code: str) -> int:
    r, d = str(okres_code).split("-")
    return int(r) * 1000 + int(d)


def _seat_courts(districts: pd.DataFrame) -> dict[int, set[int]]:
    """``{okres_id → {seat court_id}}`` — the court that shares the okres's own name.

    The **seat** court is the discriminating one. When the census merges a statutory city into
    its rural neighbour it is always the shared *seat* court that loses its row, because that is
    the one physically covering both units. A missing non-seat court means something else
    entirely — the Sparkassen files omit ~50 courts simply because no savings bank existed there,
    which is a real zero and must not be mistaken for a merge.
    """
    out: dict[int, set[int]] = {}
    for code, cid, seat in zip(districts["okres_code"], districts["court_id"],
                               districts["is_okres_seat"]):
        if pd.notna(cid) and bool(seat):
            out.setdefault(_okres_id(code), set()).add(int(cid))
    return out


def build_census_panel(census_dir, districts: pd.DataFrame) -> pd.DataFrame:
    """Load all Cisleithanian census files → one **okres-level** covariate panel.

    Court-level (934) files are summed up to their okres (``court_id // 1000`` =
    ``IDPoldistrict``). The result is joined to the okres identity from *districts*
    (one row per Czech-lands political okres) on ``okres_id``.

    City/rural twins are a **structural gap in the court-level sources**, and it is handled here
    rather than left for the reader. A statutory city had no Gerichtsbezirk of its own: the city
    and the rural seat court around it were one court, and the census keeps one row for it —
    ``Iglau/Jihlava Stadt``, ``Olmuetz/Olomouc Stadt``. The backbone splits that court in two so
    it can nest inside two okresy, so ``court_id // 1000`` dumps the **pair's** total onto
    whichever member the id encodes and leaves the other empty. The result is not coarse, it is
    *mislabelled*: ``Opava (město)`` would read 0.463 Czech-speaking, which is Gerichtsbezirk
    Troppau — city plus ring — while ``Opava`` would read 0.069, which is only Odry and Vítkov.

    Every twin okres missing its own **seat** court in a given file is recorded, with that file's
    columns, in ``panel.attrs["twin_suppressed"]``. Nine of the ten pairs are flagged in the
    Religion/Umgangssprache source; Brno is not (it has genuine ``Brno Stadt`` and ``Brno Land``
    court rows) and keeps its values throughout.

    The panel this returns is **unblanked** — it still carries the merged value on whichever
    member absorbed it, because that value is the pair's total and :func:`pool_twin_okresy` needs
    it. Use :func:`build_census_panels` to get the pair of frames actually meant for use: the
    member-level panel with the twins blanked, and the pooled 148-row panel.
    """
    census_dir = Path(census_dir)
    okres = (districts.drop_duplicates("okres_code")[["land", "okres_code", "okres_cs", "okres_de"]]
             .copy())
    okres["okres_id"] = okres["okres_code"].map(_okres_id)
    panel = okres.set_index("okres_id")

    twins = rg.build_twin_pairs(districts)
    seats = _seat_courts(districts)
    suppressed: dict[str, tuple[list[int], list[str]]] = {}

    loaded = []
    for f in sorted(census_dir.glob("*.xlsx")):
        if any(s in f.name for s in _SKIP_SUBSTR):
            continue
        try:
            tidy, level = load_census_file(f)
        except Exception as e:                       # noqa: BLE001 — report & continue
            print(f"  [skip] {f.name}: {e}")
            continue
        if level == "court":
            have = set(tidy["unit_id"].dropna().astype(int))
            tidy["okres_id"] = tidy["unit_id"] // 1000     # court_id → IDPoldistrict
            tidy = tidy.drop(columns="unit_id").groupby("okres_id").sum(min_count=1)
            # a twin okres missing its own SEAT court here → the pair was merged upstream, so
            # neither member's value is attributable. Recorded, not blanked: the value that
            # survived is the pair total, which pool_twin_okresy still needs.
            bad: set[int] = set()
            for oid, (rural, city, _keys) in twins.items():
                if seats.get(oid, set()) - have:
                    bad |= {rural, city}
            if bad:
                suppressed[f.name] = (sorted(bad), list(tidy.columns))
        else:
            tidy = tidy.rename(columns={"unit_id": "okres_id"}).set_index("okres_id")
        dup = [c for c in tidy.columns if c in panel.columns]
        if dup:
            # a later file re-producing an already-loaded column name would silently
            # shadow it — drop and SAY so, so a genuine cross-file collision is visible
            print(f"  [dup ] {f.name}: dropping {len(dup)} column(s) already loaded: "
                  f"{', '.join(map(str, dup[:6]))}{' …' if len(dup) > 6 else ''}")
            tidy = tidy.drop(columns=dup)
        panel = panel.join(tidy, how="left")
        loaded.append((f.name, level, tidy.shape[1]))

    panel = panel.reset_index()
    loaded_meta = loaded
    from utils.parsing import census_labels as _cl          # English labels + derived shares
    rename = _cl.english_rename_map(panel, "cis")           # carry the flags through the rename
    panel = _cl.to_english_census(panel, "cis")
    panel.attrs["loaded"] = loaded_meta
    panel.attrs["twin_suppressed"] = {
        name: (oids, [rename.get(c, c) for c in cols])
        for name, (oids, cols) in suppressed.items()
    }
    return panel


# ── City/rural twins: the pooled analytical unit ──────────────────────────────
# Recomputed, never averaged. Every share in the panel is a ratio of two counts, so pooling has
# to happen on the **counts** and the shares be derived again afterwards — averaging a pair's two
# shares would weight a 5,174-person city equally with a 107,015-person ring.
_DERIVED_RATES = ("literacy_rate", "pop_total", "illegitimacy_rate")


def _derived_columns(panel: pd.DataFrame) -> list[str]:
    return ([c for c in panel.columns if c.endswith("_share")]
            + [c for c in _DERIVED_RATES if c in panel.columns])


def okres_census_crosswalk(districts: pd.DataFrame) -> pd.DataFrame:
    """``okres_id → census_okres_id`` (+ ``twin_pooled``, ``twin_role``), one row per okres.

    The identity map everywhere except the twenty city/rural twin members, which both point at
    the **rural** member's id — the pooled unit. Written to ``data/final/geo/`` so an analysis
    can join on it without re-deriving the pairs.
    """
    twins = rg.build_twin_pairs(districts)
    rows = []
    for code in districts["okres_code"].drop_duplicates():
        oid = _okres_id(code)
        entry = twins.get(oid)
        if entry is None:
            rows.append({"okres_id": oid, "census_okres_id": oid,
                         "twin_pooled": False, "twin_role": pd.NA})
        else:
            rural, city, _ = entry
            rows.append({"okres_id": oid, "census_okres_id": rural, "twin_pooled": True,
                         "twin_role": "city" if oid == city else "ring"})
    return pd.DataFrame(rows).sort_values("okres_id").reset_index(drop=True)


def pool_twin_okresy(panel: pd.DataFrame, districts: pd.DataFrame) -> pd.DataFrame:
    """Collapse each city/rural twin pair into one unit → the **148-row** analytical panel.

    This is the baseline unit for a district-level covariate merge, not a robustness variant:
    for nine of the ten pairs the court-level sources do not split city from ring at all
    (:func:`build_census_panel`), so the pair is the finest unit on which language, religion and
    the justice caseload are defined. The okres-level (406) sources *do* split all ten, and those
    columns survive at member level in the un-pooled panel for anyone who wants them.

    Counts are summed with ``min_count=1`` — so a pair whose total sits on one row and ``<NA>``
    on the other recovers the total, and a pair with no data at all stays ``<NA>`` — and every
    share is then **re-derived from the pooled counts** by ``census_labels.add_shares_cis``.
    Identity (code, names, land) comes from the rural member, which is also the pooled id.
    """
    from utils.parsing import census_labels as _cl

    xw = okres_census_crosswalk(districts).set_index("okres_id")["census_okres_id"]
    out = panel.copy()
    out["census_okres_id"] = out["okres_id"].map(xw).astype("Int64")

    ident = ["land", "okres_code", "okres_cs", "okres_de"]
    skip = set(ident) | {"okres_id", "census_okres_id"} | set(_derived_columns(out))
    counts = [c for c in out.columns if c not in skip]

    agg = out.groupby("census_okres_id")[counts].sum(min_count=1)
    idr = (out[out["okres_id"] == out["census_okres_id"]]
           .set_index("census_okres_id")[ident])
    pooled = idr.join(agg).reset_index()

    twins = rg.build_twin_pairs(districts)
    pooled["twin_pooled"] = pooled["census_okres_id"].isin({e[0] for e in twins.values()})
    return _cl.add_shares_cis(pooled)


def blank_twin_members(panel: pd.DataFrame) -> pd.DataFrame:
    """Blank the court-derived columns on the twin members the source could not separate.

    Reads ``panel.attrs["twin_suppressed"]`` (set by :func:`build_census_panel`) and sets those
    columns to ``<NA>`` on **both** members of every affected pair. The value being removed is
    not merely coarse — it is attached to the wrong unit — so leaving it in place would be worse
    than leaving a hole. Shares are re-derived afterwards so no stale ratio survives its counts.
    """
    from utils.parsing import census_labels as _cl

    out = panel.copy()
    for oids, cols in panel.attrs.get("twin_suppressed", {}).values():
        cols = [c for c in cols if c in out.columns]
        if cols:
            out.loc[out["okres_id"].isin(oids), cols] = float("nan")
    out = out.drop(columns=_derived_columns(out), errors="ignore")
    out = _cl.add_shares_cis(out)
    out.attrs["twin_suppressed"] = panel.attrs.get("twin_suppressed", {})
    out.attrs["loaded"] = panel.attrs.get("loaded", [])
    return out


def build_census_panels(census_dir, districts: pd.DataFrame
                        ) -> tuple[pd.DataFrame, pd.DataFrame]:
    """The two okres-level census frames the pipeline actually uses.

    Returns ``(member, pooled)``:

    * **member** — 158 rows, one per political okres, with the court-derived columns blanked on
      the eighteen twin members the source merges. Okres-level (406) covariates — literacy,
      illegitimacy, occupation, livestock, population — remain valid for all twenty.
    * **pooled** — 148 rows, each city/rural pair collapsed onto the rural member's id, counts
      summed and shares re-derived. **This is the baseline unit** for a covariate merge; join it
      on ``{prefix}_census_okres_id`` (:func:`add_census_okres_id`).
    """
    raw = build_census_panel(census_dir, districts)
    return blank_twin_members(raw), pool_twin_okresy(raw, districts)


def add_census_okres_id(df: pd.DataFrame, districts: pd.DataFrame,
                        prefix: str = "birth") -> pd.DataFrame:
    """Add ``{prefix}_census_okres_id`` — the unit to merge the pooled census panel on."""
    xw = okres_census_crosswalk(districts).set_index("okres_id")["census_okres_id"]
    out = df.copy()
    out[f"{prefix}_census_okres_id"] = out[f"{prefix}_okres_id"].map(xw).astype("Int64")
    return out


def census_report(panel: pd.DataFrame) -> None:
    """Print coverage: okresy, covariate count, and which files loaded."""
    covs = [c for c in panel.columns
            if c not in ("okres_id", "land", "okres_code", "okres_cs", "okres_de")]
    print(f"Census okres panel  (okresy = {len(panel)}, covariates = {len(covs)})\n")
    for name, level, n in panel.attrs.get("loaded", []):
        print(f"  [{level:<5}] {n:>3} cols  {name}")
    miss = panel[covs].isna().all(axis=1).sum()
    print(f"\n  okresy with no census match: {miss}")
    sup = panel.attrs.get("twin_suppressed", {})
    if sup:
        print("\n  city/rural twins the source cannot separate (one court row per pair; the")
        print("  member values are blanked, the pair total survives in the pooled panel):")
        for name, (oids, cols) in sorted(sup.items()):
            print(f"    [{len(oids):>2} okresy · {len(cols):>2} cols] {name}")
