How it works

The pilot reads crop by crop, live. Batched, each reader costs half, and the route does not care how a reply arrived — only that the crop cache holds it. So:

  1. prepare — the pilot runs with --batch-prepare QUEUE: every crop not in its cache becomes one line of QUEUE (the cache key, the cache folder and the request the reader would have sent), and nothing is sent;
  2. submit (submit) — Claude lines go to the Message Batches API; Gemini lines, once GEMINI_BATCH is on, to Gemini's native Batch API (1.4.0): each request translated by to_native, written into JSONL input files under the File API's limit, uploaded, one job a file;
  3. collect (collect) — each reply is parsed as the reader parses a live one and written into the crop cache under its key, in the pilot's own format;
  4. the pilot runs again without the flag and finds every crop in its cache.

A reply that fails — an error, a truncation, a setting the batch endpoint refuses — is not cached: the second run reads that crop live, as before. So the worst a batch can do is cost a little and save nothing; it cannot lose a crop.

State lives beside the queue (&lt;queue&gt;.batches.json).

A queue line may carry payload_key — "rows" for a table block (1.1.0) — which names the reply's list as the reader names it; the cache record keeps it under lines either way, as both the notes' and the table's caches read it.

Gemini, natively (1.4.0, D-117). The OpenAI-compatible batch endpoint refused the structured output the live reader sends, so Gemini's lines now go to the native Batch API in Gemini's own dialect. That is the measured reader only if the translation is exact: to_native maps every field it knows and refuses every other, and each line is checked against its live request before it is written (_same_request; check_translation runs that over a whole queue, offline). Whether the replies are the measured reader's is then measured, not assumed: gemini_equivalence_submit and gemini_equivalence_collect send gold requests that already have live readings through the native path into a scratch folder, and hold the replies to a bar written before anything is sent (EQUIVALENCE_BAR). GEMINI_BATCH stays off until that check passes on the machine of record.

A line at a time (1.4.0). A volume's queue runs to ~12 GB for Gemini and ~17 GB for each Haiku pass. index_queue keeps each line's envelope and where it starts; a request is loaded only while its batch is written, and collect reads the queue only once a batch has ended — a poll while every batch is processing reads nothing.

def read_queue(path: Path) -> list[dict]:
    """The queued lines, one per cache key (a re-run may queue a crop twice)."""
    out: dict = {}
    if not Path(path).exists():
        return []
    with Path(path).open(encoding="utf-8") as fh:
        for line in fh:
            if line.strip():
                rec = json.loads(line)
                out[rec["key"]] = rec
    return list(out.values())

def index_queue(path: Path) -> dict[str, dict]:
    """``key -> line`` without its request, read a line at a time: the envelope, plus the
    queue (``_queue``), where the line starts (``_offset``), its length (``_bytes``) and
    whether it still holds its request (``_sendable``: the frozen run drops the request of
    every line a batch has held, D-123). One line a key — the last, as :func:`read_queue`
    keeps it."""
    out: dict = {}
    if not Path(path).exists():
        return out
    with Path(path).open("rb") as fh:
        offset = 0
        for raw in fh:
            if raw.strip():
                rec = json.loads(raw)
                sendable = rec.pop("request", None) is not None
                rec.update(_queue=str(path), _offset=offset, _bytes=len(raw), _sendable=sendable)
                out[rec["key"]] = rec
            offset += len(raw)
    return out

def submit(queue: Path) -> list[str]:
    """One or more batches for the queued lines not yet cached nor in flight."""
    state = _state(queue)
    in_flight = {k for b in state if not b.get("collected") for k in b["keys"]}
    todo = [r for r in index_queue(queue).values() if not _cached(r) and r["key"] not in in_flight]
    dropped = [r for r in todo if not r["_sendable"]]
    todo = [r for r in todo if r["_sendable"]]
    if dropped:
        print(f"  {Path(queue).name}: {len(dropped)} crops a batch held and did not answer — their "
              f"request is no longer queued (D-123); they are read live when the pass is finished")
    sent = []
    claude = [r for r in todo if r["reader"] == "claude"]
    gemini = [r for r in todo if r["reader"] == "openai-compatible"]
    # The state is saved after every batch sent (1.2.0): a failure on a later one must not
    # forget a batch already paid for, or the next run would send it again.
    for chunk in _chunks(claude):
        sent.append(_submit_claude(queue, chunk, state))
        _save_state(queue, state)
    if gemini and not GEMINI_BATCH:
        print(f"  {Path(queue).name}: {len(gemini)} Gemini crops not batched — the native batch "
              f"waits for its equivalence check (D-117); they are read live when the pass is finished")
    elif gemini:
        sent += _submit_gemini(queue, gemini, state)            # saves the state after every job
    if not todo and not dropped:
        print("  nothing to submit: every queued crop is cached or in flight")
    return sent

def to_native(request: dict) -> dict:
    """The live chat-completions body as the native ``GenerateContentRequest`` it amounts to.

    Pure, and exact or nothing: every field is translated or refused with a ``ValueError``
    naming it, never dropped. The model is checked but not carried: a native batch names
    it once, for the whole job (:func:`_submit_gemini`).

    * ``messages`` — the system string becomes ``systemInstruction``; the user parts become
      ``contents``, in the same order: a PNG data URI an ``inlineData`` (``mimeType`` and
      the same base64 ``data``), a text part a ``text``;
    * ``max_tokens`` -> ``maxOutputTokens``; ``temperature`` as it is — "silently ignored on
      Gemini 3.6 Flash and newer models" (the REST reference, ``GenerationConfig``), live
      and batched alike, which is why the live reads are not deterministic;
    * ``response_format`` (strict ``json_schema``) -> ``responseMimeType``
      ``application/json`` and ``responseJsonSchema``, the schema as sent,
      ``additionalProperties`` and all: the field that "accepts JSON Schema" where
      ``responseSchema`` takes an OpenAPI subset (REST reference), and the one google-genai
      puts ``response_json_schema`` on the wire as, unchanged (``_transformers.t_json_schema``).
      The schema's ``name`` is a label with no native counterpart; the native schema is
      always enforced, so a schema not marked ``strict`` is refused;
    * ``reasoning_effort`` -> ``thinkingConfig`` (:data:`NATIVE_THINKING`).
    """
    unknown = set(request) - _LIVE_FIELDS
    if unknown:
        raise ValueError(f"to_native: no translation for {sorted(unknown)}")
    if not isinstance(request.get("model"), str) or not request["model"]:
        raise ValueError("to_native: the request names no model")
    messages = list(request.get("messages") or [])
    native: dict = {}
    if messages and messages[0].get("role") == "system":
        native["systemInstruction"] = {"parts": _native_parts(messages.pop(0), system=True)}
    if len(messages) != 1 or messages[0].get("role") != "user":
        raise ValueError("to_native: expected one user message after the system one, not "
                         f"{[m.get('role') for m in messages]}")
    native["contents"] = [{"role": "user", "parts": _native_parts(messages[0])}]
    config: dict = {}
    if "temperature" in request:
        config["temperature"] = request["temperature"]
    if "max_tokens" in request:
        config["maxOutputTokens"] = request["max_tokens"]
    if "response_format" in request:
        config.update(_native_format(request["response_format"]))
    if "reasoning_effort" in request:
        effort = request["reasoning_effort"]
        if effort not in NATIVE_THINKING:
            raise ValueError(f"to_native: no native setting for reasoning_effort={effort!r}")
        config["thinkingConfig"] = dict(NATIVE_THINKING[effort])
    if config:
        native["generationConfig"] = config
    return native

def check_translation(queue: Path) -> dict:
    """Every Gemini line of ``queue`` that still holds its request translated as :func:`submit`
    would send it, offline and free: raises on the first that cannot be translated exactly.
    Returns how many lines, the input files they make, their bytes, the largest line, and the
    lines whose request was dropped (D-123)."""
    lines = total = largest = files = size = 0
    gemini = [r for r in index_queue(queue).values() if r["reader"] == "openai-compatible"]
    for rec, request in _requests([r for r in gemini if r["_sendable"]]):
        n = len(_native_line(rec, request)) + 1
        if size and size + n > GEMINI_FILE_BYTES:
            files, size = files + 1, 0
        lines, total, largest, size = lines + 1, total + n, max(largest, n), size + n
    return {"lines": lines, "files": files + (1 if size else 0), "bytes": total, "largest": largest,
            "dropped": sum(not r["_sendable"] for r in gemini)}

def collect(queue: Path) -> bool:
    """Write every ended batch's replies into the cache. ``True`` when none is pending.

    The queue is indexed only once a batch has ended (1.4.0), so a poll while everything
    is processing costs one status call a batch."""
    state = _state(queue)
    index: list = []

    def records() -> dict:
        if not index:
            index.append(index_queue(queue))
        return index[0]

    pending = False
    for b in state:
        if b.get("collected"):
            continue
        collector = {"anthropic": _collect_claude, GEMINI: _collect_gemini}.get(b["provider"])
        done = collector(b, records) if collector else _collect_unknown(b)
        if done is None:
            pending = True
            continue
        b["collected"] = True
        b["cached"], b["failed"] = done
        _save_state(queue, state)
        print(f"  {b['provider']} batch {b['id']}: {done[0]} cached, {done[1]} left to read live")
    _save_state(queue, state)
    return not pending

def gemini_equivalence_submit(queues: list, scratch: Path, n=(98, 24), seed: int = EQUIVALENCE_SEED,
                              live_control: bool = True) -> dict:
    """Send the equivalence check: ``n`` requests of each queue that already have a live
    reading through the native batch into ``scratch/batch`` — and, with ``live_control``,
    once more through the live endpoint into ``scratch/live``, the reference made at the
    same time. Never into a reader's cache. Prints the cost before it sends; returns the
    manifest :func:`gemini_equivalence_collect` reads."""
    scratch = Path(scratch)
    if (scratch / "manifest.json").exists():
        raise ValueError(f"{scratch} already holds a check: collect it, or give a new folder")
    sizes = [n] * len(queues) if isinstance(n, int) else list(n)
    rng, picked = random.Random(seed), []
    for queue, k in zip(queues, sizes):
        live = [r for r in index_queue(queue).values()
                if r["reader"] == "openai-compatible" and r["_sendable"]
                and (_local(r["cache_dir"]) / f"{r['key']}.json").exists()]
        picked += sorted(rng.sample(live, min(k, len(live))), key=lambda r: r["_offset"])
    if not picked:
        raise ValueError("no queued Gemini request has a live reading to compare with")
    _refuse_real_cache(scratch, picked)
    plan = [_check_entry(rec, request, scratch) for rec, request in _requests(picked)]
    cost = _check_cost(plan, picked[0]["model"], live_control)
    kinds = Counter("table" if e["kind"] == "table" else "notes" for e in plan)
    print(f"  equivalence check: {', '.join(f'{v} {k}' for k, v in kinds.items())} requests; "
          f"≈ ${cost['batch']:.2f} batched + ${cost['control']:.2f} live control = ${cost['total']:.2f}")
    scratch.mkdir(parents=True, exist_ok=True)
    manifest = {"version": __version__, "created": time.time(), "seed": seed, "bar": EQUIVALENCE_BAR,
                "queues": [str(q) for q in queues], "n": sizes, "cost": cost, "requests": plan}
    _write_json(scratch / "manifest.json", manifest)        # first: whatever is sent next is on record
    manifest["jobs"] = _submit_gemini(scratch / "check", [dict(r, cache_dir=e["batch_dir"])
                                                         for r, e in zip(picked, plan)], [])
    if not manifest["jobs"]:
        (scratch / "manifest.json").unlink()
        raise RuntimeError("the check's batch was not sent (above); nothing was read live, "
                           "and the folder is free for another try")
    if live_control:
        manifest["control"] = _live_control([dict(r, cache_dir=e["control_dir"]) for r, e in zip(picked, plan)])
    _write_json(scratch / "manifest.json", manifest)
    return manifest

def line_agreement(a: list, b: list) -> float:
    """Two readings' shared lines, in order, as a share of both (Dice over difflib's
    matching blocks): 1 for the same lines, 0 for none in common; two empty readings agree."""
    if not a and not b:
        return 1.0
    a, b = ([x if isinstance(x, str) else json.dumps(x, sort_keys=True) for x in seq] for seq in (a, b))
    shared = sum(m.size for m in SequenceMatcher(None, a, b, autojunk=False).get_matching_blocks())
    return 2 * shared / (len(a) + len(b))

def cell_agreement(a: list, b: list) -> float:
    """The share of a table block's cells two readings agree on, rows paired in order; a row
    one reading has and the other lacks disagrees in every cell."""
    if not a and not b:
        return 1.0
    fields = sorted({k for row in a + b if isinstance(row, dict) for k in row})
    if not fields:
        return float(a == b)
    same = sum(1 for x, y in zip(a, b) if isinstance(x, dict) and isinstance(y, dict)
               for f in fields if x.get(f) == y.get(f))
    return same / (max(len(a), len(b)) * len(fields))

"""The readers, batched: queued requests in, cached replies out (D-108's prices).

The pilot reads crop by crop, live. Batched, each reader costs half, and the route
does not care how a reply arrived — only that the crop cache holds it. So:

1. **prepare** — the pilot runs with ``--batch-prepare QUEUE``: every crop not in
   its cache becomes one line of ``QUEUE`` (the cache key, the cache folder and the
   request the reader would have sent), and nothing is sent;
2. **submit** (:func:`submit`) — Claude lines go to the Message Batches API; Gemini
   lines, once :data:`GEMINI_BATCH` is on, to Gemini's **native** Batch API (1.4.0):
   each request translated by :func:`to_native`, written into JSONL input files under
   the File API's limit, uploaded, one job a file;
3. **collect** (:func:`collect`) — each reply is parsed as the reader parses a live
   one and written into the crop cache under its key, in the pilot's own format;
4. the pilot runs again without the flag and finds every crop in its cache.

A reply that fails — an error, a truncation, a setting the batch endpoint refuses
— is **not** cached: the second run reads that crop live, as before. So the worst
a batch can do is cost a little and save nothing; it cannot lose a crop.

State lives beside the queue (``<queue>.batches.json``).

A queue line may carry ``payload_key`` — ``"rows"`` for a table block (1.1.0) —
which names the reply's list as the reader names it; the cache record keeps it
under ``lines`` either way, as both the notes' and the table's caches read it.

**Gemini, natively (1.4.0, D-117).** The OpenAI-compatible batch endpoint refused the
structured output the live reader sends, so Gemini's lines now go to the native Batch
API in Gemini's own dialect. That is the measured reader only if the translation is
exact: :func:`to_native` maps every field it knows and refuses every other, and each
line is checked against its live request before it is written (:func:`_same_request`;
:func:`check_translation` runs that over a whole queue, offline). Whether the replies
are the measured reader's is then measured, not assumed: :func:`gemini_equivalence_submit`
and :func:`gemini_equivalence_collect` send gold requests that already have live readings
through the native path into a scratch folder, and hold the replies to a bar written
before anything is sent (:data:`EQUIVALENCE_BAR`). :data:`GEMINI_BATCH` stays off until
that check passes on the machine of record.

**A line at a time (1.4.0).** A volume's queue runs to ~12 GB for Gemini and ~17 GB for
each Haiku pass. :func:`index_queue` keeps each line's envelope and where it starts; a
request is loaded only while its batch is written, and :func:`collect` reads the queue
only once a batch has ended — a poll while every batch is processing reads nothing.
"""

def read_queue(path: Path) -> list[dict]:
    """The queued lines, one per cache key (a re-run may queue a crop twice)."""
    out: dict = {}
    if not Path(path).exists():
        return []
    with Path(path).open(encoding="utf-8") as fh:
        for line in fh:
            if line.strip():
                rec = json.loads(line)
                out[rec["key"]] = rec
    return list(out.values())


def index_queue(path: Path) -> dict[str, dict]:
    """``key -> line`` without its request, read a line at a time: the envelope, plus the
    queue (``_queue``), where the line starts (``_offset``), its length (``_bytes``) and
    whether it still holds its request (``_sendable``: the frozen run drops the request of
    every line a batch has held, D-123). One line a key — the last, as :func:`read_queue`
    keeps it."""
    out: dict = {}
    if not Path(path).exists():
        return out
    with Path(path).open("rb") as fh:
        offset = 0
        for raw in fh:
            if raw.strip():
                rec = json.loads(raw)
                sendable = rec.pop("request", None) is not None
                rec.update(_queue=str(path), _offset=offset, _bytes=len(raw), _sendable=sendable)
                out[rec["key"]] = rec
            offset += len(raw)
    return out


def _requests(records: list[dict]):
    """``(record, request)`` in order: the request a record carries, or the one its
    queue holds at its offset (:func:`index_queue`)."""
    handles: dict = {}
    try:
        for rec in records:
            if "request" in rec:
                yield rec, rec["request"]
                continue
            fh = handles.get(rec["_queue"])
            if fh is None:
                fh = handles[rec["_queue"]] = Path(rec["_queue"]).open("rb")
            fh.seek(rec["_offset"])
            line = json.loads(fh.readline())
            if line.get("request") is None:
                raise ValueError(f"{rec['key']}: its request is no longer in {rec['_queue']} (D-123)")
            yield rec, line["request"]
    finally:
        for fh in handles.values():
            fh.close()


def _state_path(queue: Path) -> Path:
    return Path(str(queue) + ".batches.json")


def _state(queue: Path) -> list[dict]:
    p = _state_path(queue)
    return json.loads(p.read_text(encoding="utf-8")) if p.exists() else []


def _save_state(queue: Path, state: list[dict]) -> None:
    # Written whole and then renamed (1.4.0): a state cut off mid-write would forget
    # batches already paid for.
    tmp = Path(str(_state_path(queue)) + ".part")
    tmp.write_text(json.dumps(state, indent=1), encoding="utf-8")
    tmp.replace(_state_path(queue))


def _cached(rec: dict) -> bool:
    return (Path(rec["cache_dir"]) / f"{rec['key']}.json").exists()


def _write_cache(rec: dict, lines: list, usage: dict) -> None:
    """The pilot's own cache record (``run_lexikon_1910_pilot.read_crop``)."""
    folder = Path(rec["cache_dir"])
    folder.mkdir(parents=True, exist_ok=True)
    tmp = folder / f"{rec['key']}.json.part"
    tmp.write_text(json.dumps({"lines": lines, "usage": usage, "slot": rec["slot"],
                               "kind": rec["kind"], "model": rec["model"],
                               "at": time.time(), "batched": True}), encoding="utf-8")
    tmp.replace(folder / f"{rec['key']}.json")

def submit(queue: Path) -> list[str]:
    """One or more batches for the queued lines not yet cached nor in flight."""
    state = _state(queue)
    in_flight = {k for b in state if not b.get("collected") for k in b["keys"]}
    todo = [r for r in index_queue(queue).values() if not _cached(r) and r["key"] not in in_flight]
    dropped = [r for r in todo if not r["_sendable"]]
    todo = [r for r in todo if r["_sendable"]]
    if dropped:
        print(f"  {Path(queue).name}: {len(dropped)} crops a batch held and did not answer — their "
              f"request is no longer queued (D-123); they are read live when the pass is finished")
    sent = []
    claude = [r for r in todo if r["reader"] == "claude"]
    gemini = [r for r in todo if r["reader"] == "openai-compatible"]
    # The state is saved after every batch sent (1.2.0): a failure on a later one must not
    # forget a batch already paid for, or the next run would send it again.
    for chunk in _chunks(claude):
        sent.append(_submit_claude(queue, chunk, state))
        _save_state(queue, state)
    if gemini and not GEMINI_BATCH:
        print(f"  {Path(queue).name}: {len(gemini)} Gemini crops not batched — the native batch "
              f"waits for its equivalence check (D-117); they are read live when the pass is finished")
    elif gemini:
        sent += _submit_gemini(queue, gemini, state)            # saves the state after every job
    if not todo and not dropped:
        print("  nothing to submit: every queued crop is cached or in flight")
    return sent


def _chunks(records: list[dict]) -> list[list[dict]]:
    out, size, cur = [], 0, []
    for r in records:
        n = r["_bytes"] if "_bytes" in r else len(json.dumps(r["request"]))
        if cur and size + n > MAX_BATCH_BYTES:
            out.append(cur)
            cur, size = [], 0
        cur.append(r)
        size += n
    if cur:
        out.append(cur)
    return out


def _submit_claude(queue: Path, records: list[dict], state: list[dict]) -> str:
    client = _claude_client()
    batch = client.messages.batches.create(
        requests=[{"custom_id": r["key"], "params": request} for r, request in _requests(records)])
    state.append({"provider": "anthropic", "id": batch.id, "keys": [r["key"] for r in records],
                  "submitted": time.time(), "collected": False})
    print(f"  Claude batch {batch.id}: {len(records)} crops")
    return batch.id

#: The live body's fields. Each is translated by :func:`to_native`; any other is refused.
_LIVE_FIELDS = {"model", "messages", "max_tokens", "temperature", "response_format",
                "reasoning_effort"}
#: ``reasoning_effort`` -> the native ``thinkingConfig``. Only ``none`` is sent: the reader
#: of record reads with thinking off (D-108), and its 297 live gold records booked 0
#: thinking tokens. No ``thinkingLevel`` says "off" on Gemini 3.8 Flash — its levels are
#: low, medium and high, and ``minimal`` "will return an error" (What's new in Gemini 3.8
#: Flash, https://ai.google.dev/gemini-api/docs/generate-content/whats-new-gemini-3.8) —
#: so the budget is the one native setting that can: "0 is DISABLED"
#: (``google.genai.types.ThinkingConfig.thinking_budget``). It is what the OpenAI layer
#: documents ``none`` as, on the models it maps by budget
#: (https://ai.google.dev/gemini-api/docs/openai), and what this project measured on 3.8
#: through that layer's ``extra_body`` on 2026-09-22: no thinking tokens, as with
#: ``reasoning_effort="none"`` (``SYMBOL_ACCURACY_PLAN.md``). That the native endpoint
#: takes it on 3.8 — the 3.8 guide says to "replace" the budget — is not assumed: the
#: equivalence check fails on a refused line or a thinking reply.
NATIVE_THINKING = {"none": {"thinkingBudget": 0}}


def to_native(request: dict) -> dict:
    """The live chat-completions body as the native ``GenerateContentRequest`` it amounts to.

    Pure, and exact or nothing: every field is translated or refused with a ``ValueError``
    naming it, never dropped. The model is checked but not carried: a native batch names
    it once, for the whole job (:func:`_submit_gemini`).

    * ``messages`` — the system string becomes ``systemInstruction``; the user parts become
      ``contents``, in the same order: a PNG data URI an ``inlineData`` (``mimeType`` and
      the same base64 ``data``), a text part a ``text``;
    * ``max_tokens`` -> ``maxOutputTokens``; ``temperature`` as it is — "silently ignored on
      Gemini 3.6 Flash and newer models" (the REST reference, ``GenerationConfig``), live
      and batched alike, which is why the live reads are not deterministic;
    * ``response_format`` (strict ``json_schema``) -> ``responseMimeType``
      ``application/json`` and ``responseJsonSchema``, the schema as sent,
      ``additionalProperties`` and all: the field that "accepts JSON Schema" where
      ``responseSchema`` takes an OpenAPI subset (REST reference), and the one google-genai
      puts ``response_json_schema`` on the wire as, unchanged (``_transformers.t_json_schema``).
      The schema's ``name`` is a label with no native counterpart; the native schema is
      always enforced, so a schema not marked ``strict`` is refused;
    * ``reasoning_effort`` -> ``thinkingConfig`` (:data:`NATIVE_THINKING`).
    """
    unknown = set(request) - _LIVE_FIELDS
    if unknown:
        raise ValueError(f"to_native: no translation for {sorted(unknown)}")
    if not isinstance(request.get("model"), str) or not request["model"]:
        raise ValueError("to_native: the request names no model")
    messages = list(request.get("messages") or [])
    native: dict = {}
    if messages and messages[0].get("role") == "system":
        native["systemInstruction"] = {"parts": _native_parts(messages.pop(0), system=True)}
    if len(messages) != 1 or messages[0].get("role") != "user":
        raise ValueError("to_native: expected one user message after the system one, not "
                         f"{[m.get('role') for m in messages]}")
    native["contents"] = [{"role": "user", "parts": _native_parts(messages[0])}]
    config: dict = {}
    if "temperature" in request:
        config["temperature"] = request["temperature"]
    if "max_tokens" in request:
        config["maxOutputTokens"] = request["max_tokens"]
    if "response_format" in request:
        config.update(_native_format(request["response_format"]))
    if "reasoning_effort" in request:
        effort = request["reasoning_effort"]
        if effort not in NATIVE_THINKING:
            raise ValueError(f"to_native: no native setting for reasoning_effort={effort!r}")
        config["thinkingConfig"] = dict(NATIVE_THINKING[effort])
    if config:
        native["generationConfig"] = config
    return native


def _native_parts(message: dict, system: bool = False) -> list[dict]:
    extra = set(message) - {"role", "content"}
    if extra:
        raise ValueError(f"to_native: no translation for message fields {sorted(extra)}")
    content = message.get("content")
    if isinstance(content, str):
        return [{"text": content}]
    if not isinstance(content, list):
        raise ValueError(f"to_native: message content of type {type(content).__name__}")
    parts = []
    for part in content:
        if part.get("type") == "text" and set(part) == {"type", "text"}:
            parts.append({"text": part["text"]})
        elif part.get("type") == "image_url" and set(part) == {"type", "image_url"} and not system:
            parts.append({"inlineData": _inline_data(part["image_url"])})
        else:
            raise ValueError(f"to_native: no translation for a {'system' if system else 'user'} "
                             f"part of type {part.get('type')!r} with fields {sorted(part)}")
    return parts


def _inline_data(image_url: dict) -> dict:
    if set(image_url) != {"url"}:
        raise ValueError(f"to_native: no translation for image_url fields "
                         f"{sorted(set(image_url) - {'url'})}")
    head, sep, data = str(image_url["url"]).partition(",")
    mime = head.removeprefix("data:").removesuffix(";base64")
    if not (sep and head.startswith("data:") and head.endswith(";base64") and mime and data):
        raise ValueError("to_native: an image must be a base64 data URI, not a link")
    return {"mimeType": mime, "data": data}


def _native_format(fmt: dict) -> dict:
    if not isinstance(fmt, dict) or fmt.get("type") != "json_schema" or set(fmt) != {"type", "json_schema"}:
        raise ValueError(f"to_native: only a json_schema response_format is translated, not "
                         f"{str(fmt)[:120]}")
    spec = fmt["json_schema"]
    unknown = set(spec) - {"name", "schema", "strict"}
    if unknown:
        raise ValueError(f"to_native: no translation for json_schema fields {sorted(unknown)}")
    if spec.get("strict") is not True:
        raise ValueError("to_native: a schema not marked strict has no native counterpart "
                         "(the native schema is always enforced)")
    if not isinstance(spec.get("schema"), dict):
        raise ValueError("to_native: the json_schema carries no schema")
    return {"responseMimeType": "application/json", "responseJsonSchema": spec["schema"]}


def _same_request(request: dict, native: dict) -> None:
    """Raise unless ``native`` asks what ``request`` asks — each read off independently of
    :func:`to_native`: every system and user text and every image (mime type and base64,
    byte for byte) in the same order, the schema, the token cap, the temperature and the
    thinking setting."""
    def live_items():
        for m in request["messages"]:
            content = m["content"] if isinstance(m["content"], list) else [{"type": "text", "text": m["content"]}]
            for p in content:
                if p["type"] == "image_url":
                    mime, _, data = p["image_url"]["url"].removeprefix("data:").partition(";base64,")
                    yield m["role"], "image", mime, data
                else:
                    yield m["role"], "text", p["text"]

    def native_items():
        turns = [("system", native["systemInstruction"])] if "systemInstruction" in native else []
        for role, content in turns + [(c["role"], c) for c in native["contents"]]:
            for p in content["parts"]:
                if "inlineData" in p:
                    yield role, "image", p["inlineData"]["mimeType"], p["inlineData"]["data"]
                else:
                    yield role, "text", p["text"]

    if list(live_items()) != list(native_items()):
        raise ValueError("translation check: the native request's texts or images differ")
    config, fmt = native.get("generationConfig", {}), request.get("response_format")
    wanted = {"maxOutputTokens": request.get("max_tokens"), "temperature": request.get("temperature"),
              "responseJsonSchema": fmt["json_schema"]["schema"] if fmt else None,
              "responseMimeType": "application/json" if fmt else None,
              "thinkingConfig": NATIVE_THINKING.get(request.get("reasoning_effort"))}
    differ = [k for k, v in wanted.items() if config.get(k) != v]
    if differ or set(config) - set(wanted):
        raise ValueError(f"translation check: generationConfig differs in "
                         f"{sorted(differ) or sorted(set(config) - set(wanted))}")


def _native_line(rec: dict, request: dict) -> str:
    """One line of a native batch's input file — ``{"key", "request"}``, the request a
    ``GenerateContentRequest`` (https://ai.google.dev/gemini-api/docs/batch-mode) —
    checked against its live request before it is written."""
    native = to_native(request)
    _same_request(request, native)
    return json.dumps({"key": rec["key"], "request": native})


def check_translation(queue: Path) -> dict:
    """Every Gemini line of ``queue`` that still holds its request translated as :func:`submit`
    would send it, offline and free: raises on the first that cannot be translated exactly.
    Returns how many lines, the input files they make, their bytes, the largest line, and the
    lines whose request was dropped (D-123)."""
    lines = total = largest = files = size = 0
    gemini = [r for r in index_queue(queue).values() if r["reader"] == "openai-compatible"]
    for rec, request in _requests([r for r in gemini if r["_sendable"]]):
        n = len(_native_line(rec, request)) + 1
        if size and size + n > GEMINI_FILE_BYTES:
            files, size = files + 1, 0
        lines, total, largest, size = lines + 1, total + n, max(largest, n), size + n
    return {"lines": lines, "files": files + (1 if size else 0), "bytes": total, "largest": largest,
            "dropped": sum(not r["_sendable"] for r in gemini)}

def _native_files(records: list[dict]):
    """``(path, records, bytes)`` for each input file of a native batch, at most
    :data:`GEMINI_FILE_BYTES` (a longer line goes alone), written a line at a time into the
    temp folder — never beside the queue, which Dropbox would sync. The caller deletes it."""
    chunk, size, fh, path = [], 0, None, None
    try:
        for rec, request in _requests(records):
            line = (_native_line(rec, request) + "\n").encode("ascii")    # json.dumps escapes to ASCII
            if chunk and size + len(line) > GEMINI_FILE_BYTES:
                fh.close()
                fh = None
                yield path, chunk, size
                chunk, size, path = [], 0, None
            if fh is None:
                fd, name = tempfile.mkstemp(prefix="gemini-batch-", suffix=".jsonl")
                fh, path = os.fdopen(fd, "wb"), Path(name)
            fh.write(line)
            chunk.append(rec)
            size += len(line)
        if fh is not None:
            fh.close()
            fh = None
            yield path, chunk, size
    finally:
        if fh is not None:                          # a translation refused mid-file
            fh.close()
            path.unlink(missing_ok=True)


def _submit_gemini(queue: Path, records: list[dict], state: list[dict]) -> list[str]:
    """One native batch job an input file: uploaded with ``client.files.upload``, sent with
    ``client.batches.create``, deleted locally. The state is saved after every job (1.2.0).

    The API refusing a file — the batch enqueued-token limit is 3M tokens on Tier 1 for 3.8
    Flash (rate-limits page), a volume's notes ~16M — stops this queue, not the run: the
    jobs before it are on record, the rest wait for the next submit (or are read live), and
    the queues after it are still sent. Uploads not yet collected are held under
    :data:`GEMINI_HELD_BYTES` the same way. A request that cannot be translated raises."""
    models = sorted({r["model"] for r in records})
    stray = [m for m in models if not str(m).startswith("gemini")]
    if stray:
        raise ValueError(f"{Path(queue).name}: OpenAI-compatible lines for {stray} — "
                         f"the native batch is Gemini's only")
    client = _gemini_client()                       # held for the whole call (1.2.0)
    held = sum(b.get("input_bytes", 0) for b in state if b["provider"] == GEMINI and not b.get("collected"))
    label = Path(queue).name.removesuffix(".queue.jsonl")
    sent, waiting = [], len(records)
    for model in models:
        # Closed however the loop is left, so no handle on the queue outlives the call (on
        # Windows one would stop the frozen run replacing the queue, D-123).
        with contextlib.closing(_native_files([r for r in records if r["model"] == model])) as files:
            for path, chunk, size in files:
                try:
                    if held + size > GEMINI_HELD_BYTES:
                        print(f"  {label}: {waiting} Gemini crops wait — {held / 1e9:.1f} GB is "
                              f"uploaded and not yet collected; collect, then submit again")
                        return sent
                    name = f"lexikon1910-{label}-{len(state) + 1}"
                    try:
                        uploaded = client.files.upload(file=str(path), config={"display_name": name,
                                                                               "mime_type": "jsonl"})
                        try:
                            job = client.batches.create(model=model, src=uploaded.name,
                                                        config={"display_name": name})
                        except Exception:
                            _delete_file(client, uploaded.name)     # nothing was sent: no upload left
                            raise
                    except Exception as exc:            # noqa: BLE001 — stops this queue, not the run
                        print(f"  {label}: {waiting} Gemini crops not sent — {type(exc).__name__}: "
                              f"{str(exc)[:300]}. Jobs sent before it, on record: {len(sent)}; "
                              f"submit again once they are collected, or the rest are read live")
                        return sent
                finally:
                    path.unlink(missing_ok=True)
                state.append({"provider": GEMINI, "id": job.name, "model": model,
                              "keys": [r["key"] for r in chunk], "input_file": uploaded.name,
                              "input_bytes": size,
                              "results": f"{queue}.{job.name.rsplit('/', 1)[-1]}.results.jsonl",
                              "submitted": time.time(), "collected": False})
                _save_state(queue, state)
                held, waiting = held + size, waiting - len(chunk)
                sent.append(job.name)
                print(f"  Gemini batch {job.name}: {len(chunk)} crops, {size / 1e6:,.0f} MB")
    return sent


def _delete_file(client, name: str) -> bool:
    try:
        client.files.delete(name=name)
        return True
    except Exception as exc:                        # noqa: BLE001 — the File API drops it in 48 h
        print(f"  could not delete {name} ({type(exc).__name__}); the File API drops it after 48 hours")
        return False

def collect(queue: Path) -> bool:
    """Write every ended batch's replies into the cache. ``True`` when none is pending.

    The queue is indexed only once a batch has ended (1.4.0), so a poll while everything
    is processing costs one status call a batch."""
    state = _state(queue)
    index: list = []

    def records() -> dict:
        if not index:
            index.append(index_queue(queue))
        return index[0]

    pending = False
    for b in state:
        if b.get("collected"):
            continue
        collector = {"anthropic": _collect_claude, GEMINI: _collect_gemini}.get(b["provider"])
        done = collector(b, records) if collector else _collect_unknown(b)
        if done is None:
            pending = True
            continue
        b["collected"] = True
        b["cached"], b["failed"] = done
        _save_state(queue, state)
        print(f"  {b['provider']} batch {b['id']}: {done[0]} cached, {done[1]} left to read live")
    _save_state(queue, state)
    return not pending


def _collect_unknown(b: dict) -> tuple[int, int]:
    print(f"  {b['provider']} batch {b['id']}: not a provider this version collects; its crops are read live")
    return 0, len(b["keys"])


def _parse_claude(message, payload_key: str = "lines") -> tuple[list, dict] | None:
    """As ``ClaudeReader.__call__`` reads a live reply; ``None`` for one not worth caching."""
    if message.stop_reason in ("refusal", "max_tokens"):
        return None
    text = next((b.text for b in message.content if b.type == "text"), "")
    if not text:
        return None
    u = message.usage
    usage = {"input": u.input_tokens, "output": u.output_tokens,
             "cache_write": getattr(u, "cache_creation_input_tokens", 0) or 0,
             "cache_read": getattr(u, "cache_read_input_tokens", 0) or 0}
    try:
        return json.loads(text)[payload_key], usage
    except (ValueError, KeyError):
        return None


def _collect_claude(b: dict, records) -> tuple[int, int] | None:
    client = _claude_client()
    batch = client.messages.batches.retrieve(b["id"])
    if batch.processing_status != "ended":
        print(f"  Claude batch {b['id']}: {batch.processing_status}, "
              f"{batch.request_counts.processing} processing")
        return None
    records = records()
    cached = failed = 0
    for result in client.messages.batches.results(b["id"]):
        rec = records.get(result.custom_id)
        parsed = (_parse_claude(result.result.message, rec.get("payload_key", "lines"))
                  if rec and result.result.type == "succeeded" else None)
        if parsed:
            _write_cache(rec, *parsed)
            cached += 1
        else:
            failed += 1
    return cached, failed


def _parse_openai(body: dict, payload_key: str = "lines") -> tuple[list, dict] | None:
    """As ``OpenAICompatibleReader.__call__`` reads a live reply."""
    import run_lexikon_1910_pilot as pilot

    choice = (body.get("choices") or [{}])[0]
    if choice.get("finish_reason") == "length":
        return None
    text = (choice.get("message") or {}).get("content") or ""
    if not text:
        return None
    u = body.get("usage") or {}
    prompt, completion, total = (u.get("prompt_tokens", 0) or 0, u.get("completion_tokens", 0) or 0,
                                 u.get("total_tokens", 0) or 0)
    hidden = max(total - prompt - completion, 0)
    usage = {"input": prompt, "output": completion + hidden, "thinking": hidden,
             "cache_write": 0, "cache_read": 0}
    try:
        return pilot._salvage_json(text).get(payload_key, []), usage
    except Exception:                                           # noqa: BLE001
        return None


def _parse_native(response: dict, payload_key: str = "lines",
                  why: Counter | None = None) -> tuple[list, dict] | None:
    """As ``OpenAICompatibleReader.__call__`` reads a live reply, from a native
    ``GenerateContentResponse``; ``None`` for one not worth caching (``why`` counts why).

    Only a reply that stopped by itself (``finishReason`` STOP) is cached: MAX_TOKENS is the
    live ``length`` the reader refuses, and anything rarer is left to the finishing pass to
    read live, as the live reader would. The text is the candidate's parts that are not
    thought; the usage is the live record's — ``thoughtsTokenCount`` the thinking, booked
    with the answer at the output rate, as the live reader books ``total - prompt - completion``.
    """
    import run_lexikon_1910_pilot as pilot

    def refuse(reason: str) -> None:
        if why is not None:
            why[reason] += 1

    candidates = response.get("candidates") or []
    if not candidates:
        block = (response.get("promptFeedback") or {}).get("blockReason")
        return refuse(f"blocked {block}" if block else "no candidate")
    finish = candidates[0].get("finishReason")
    if finish != "STOP":
        return refuse(f"finish {finish}")
    parts = (candidates[0].get("content") or {}).get("parts") or []
    text = "".join(p.get("text") or "" for p in parts if not p.get("thought"))
    if not text:
        return refuse("empty reply")
    u = response.get("usageMetadata") or {}
    thinking = u.get("thoughtsTokenCount", 0) or 0
    usage = {"input": u.get("promptTokenCount", 0) or 0,
             "output": (u.get("candidatesTokenCount", 0) or 0) + thinking,
             "thinking": thinking, "cache_write": 0, "cache_read": 0}
    try:
        return pilot._salvage_json(text).get(payload_key, []), usage
    except Exception:                                           # noqa: BLE001
        return refuse("unreadable JSON")


def _cache_native_results(text: str, keys: list[str], records: dict) -> tuple[int, Counter, str]:
    """Every result line of one job parsed as the live reader parses a reply, and cached
    under its ``key``. Matched by key only, never by position: a reading attached to the
    wrong crop would look entirely well-behaved. Returns how many were cached, why the
    rest were not, and the first error message the job returned."""
    wanted, seen, cached, why, first_error = set(keys), set(), set(), Counter(), ""
    for line in text.splitlines():
        if not line.strip():
            continue
        row = json.loads(line)
        key = row.get("key")
        if key not in wanted:
            why["a line with no key of this job"] += 1
            continue
        seen.add(key)
        rec, error = records.get(key), row.get("error")
        if rec is None:
            why["no longer in the queue"] += 1
        elif error or not row.get("response"):
            error = error if isinstance(error, dict) else {"message": str(error or "no response")}
            why[f"error {error.get('code', '')} {error.get('status', '')}".strip()] += 1
            first_error = first_error or str(error.get("message", ""))[:300]
        elif (parsed := _parse_native(row["response"], rec.get("payload_key", "lines"), why)) is not None:
            _write_cache(rec, *parsed)
            cached.add(key)
    if wanted - seen:
        why["no result line"] += len(wanted - seen)
    return len(cached), why, first_error


def _gemini_results(client, b: dict, file_name: str) -> str:
    """The job's results file — downloaded once and kept beside the queue, so a collect run
    again reads the copy: the replies are what was paid for."""
    local = Path(b["results"]) if b.get("results") else None
    if local is not None and local.exists():
        return local.read_text(encoding="utf-8")
    text = client.files.download(file=file_name).decode("utf-8")
    if local is not None:
        tmp = Path(str(local) + ".part")
        tmp.write_text(text, encoding="utf-8")
        tmp.replace(local)
    return text


def _collect_gemini(b: dict, records) -> tuple[int, int] | None:
    client = _gemini_client()                       # held, as in _submit_gemini
    job = client.batches.get(name=b["id"])
    state = str(getattr(getattr(job, "state", None), "name", getattr(job, "state", None)))
    if state not in GEMINI_ENDED:
        print(f"  Gemini batch {b['id']}: {state}")
        return None
    b["state"], b["ended"] = state, str(getattr(job, "update_time", None) or "")
    file_name = getattr(getattr(job, "dest", None), "file_name", None)
    if file_name:
        cached, why, first_error = _cache_native_results(_gemini_results(client, b, file_name),
                                                         b["keys"], records())
    else:
        error = getattr(job, "error", None)
        cached, why, first_error = 0, Counter({"no results file": len(b["keys"])}), str(error or "")
        print(f"  Gemini batch {b['id']} ended {state} with no results: its crops are read live")
    if why:
        b["refused"] = dict(why)
        print(f"  Gemini batch {b['id']} ({state}), not cached: "
              + ", ".join(f"{n} {reason}" for reason, n in why.most_common()))
    if first_error:
        b["first_error"] = first_error
        print(f"    first error: {first_error}")
    if b.get("input_file") and not b.get("input_deleted"):
        b["input_deleted"] = _delete_file(client, b["input_file"])
    return cached, len(b["keys"]) - cached

# The equivalence check: is the batched Gemini the measured one?
# --------------------------------------------------------------------------- #

#: The check's sample is drawn with this seed, so a check run again draws the same crops.
EQUIVALENCE_SEED = 20261024
#: The bar, written before any native batch was sent (1.4.0). "Returned identically" cannot
#: be it: Gemini 3.8 Flash samples whatever the temperature — "silently ignored on Gemini 3.6
#: Flash and newer models" (REST reference) — and the four live reads of the 98 gold notes
#: requests (r5atlasntg1-3 on 2026-10-21, the frozen pass on 10-23; one cache key, so
#: byte-identical requests) give the same crop in 48.6 % of pairs and the same line in 78 %:
#: 57 % the same day, 40 % two days apart. So what is deterministic is held exactly, and the
#: answers are held to a live read of the same requests made alongside the batch (the
#: check's live control), which drifts with it. All five must hold:
EQUIVALENCE_BAR = {
    # 1. every sampled request answered, parsed and cached, and the job SUCCEEDED
    "failures": 0,
    # 2. promptTokenCount equal to the live prompt tokens (the control's, else the record's)
    #    on every request: the four live reads of each gold request never differed (0 of 98),
    #    so a difference means the model was shown something else
    "prompt_mismatches": 0,
    # 3. thinking off: no reply over this many thought tokens (live: 0 on 390 of 392 gold
    #    reads, at most 91; thinking on: ~2,000-5,700 a crop on 3.8, SYMBOL_ACCURACY_PLAN.md)
    "thinking_max": 200,
    # 4. every reply holds the schema its request sent (the 591 live gold records all do)
    "schema_violations": 0,
    # 5. the batch agrees with the live reads made before the check no worse than the
    #    control does: lines for notes, cells for a table block, per request; fails when the
    #    mean paired difference is below -z standard errors. z = 1.96: one-sided 2.5 % for
    #    each of the two kinds, so a batch that is the live reader fails by chance about one
    #    time in twenty; on at least min_pairs requests a kind, or the check is inconclusive
    "z": 1.96,
    "min_pairs": 20,
}


def gemini_equivalence_submit(queues: list, scratch: Path, n=(98, 24), seed: int = EQUIVALENCE_SEED,
                              live_control: bool = True) -> dict:
    """Send the equivalence check: ``n`` requests of each queue that already have a live
    reading through the native batch into ``scratch/batch`` — and, with ``live_control``,
    once more through the live endpoint into ``scratch/live``, the reference made at the
    same time. Never into a reader's cache. Prints the cost before it sends; returns the
    manifest :func:`gemini_equivalence_collect` reads."""
    scratch = Path(scratch)
    if (scratch / "manifest.json").exists():
        raise ValueError(f"{scratch} already holds a check: collect it, or give a new folder")
    sizes = [n] * len(queues) if isinstance(n, int) else list(n)
    rng, picked = random.Random(seed), []
    for queue, k in zip(queues, sizes):
        live = [r for r in index_queue(queue).values()
                if r["reader"] == "openai-compatible" and r["_sendable"]
                and (_local(r["cache_dir"]) / f"{r['key']}.json").exists()]
        picked += sorted(rng.sample(live, min(k, len(live))), key=lambda r: r["_offset"])
    if not picked:
        raise ValueError("no queued Gemini request has a live reading to compare with")
    _refuse_real_cache(scratch, picked)
    plan = [_check_entry(rec, request, scratch) for rec, request in _requests(picked)]
    cost = _check_cost(plan, picked[0]["model"], live_control)
    kinds = Counter("table" if e["kind"] == "table" else "notes" for e in plan)
    print(f"  equivalence check: {', '.join(f'{v} {k}' for k, v in kinds.items())} requests; "
          f"≈ ${cost['batch']:.2f} batched + ${cost['control']:.2f} live control = ${cost['total']:.2f}")
    scratch.mkdir(parents=True, exist_ok=True)
    manifest = {"version": __version__, "created": time.time(), "seed": seed, "bar": EQUIVALENCE_BAR,
                "queues": [str(q) for q in queues], "n": sizes, "cost": cost, "requests": plan}
    _write_json(scratch / "manifest.json", manifest)        # first: whatever is sent next is on record
    manifest["jobs"] = _submit_gemini(scratch / "check", [dict(r, cache_dir=e["batch_dir"])
                                                         for r, e in zip(picked, plan)], [])
    if not manifest["jobs"]:
        (scratch / "manifest.json").unlink()
        raise RuntimeError("the check's batch was not sent (above); nothing was read live, "
                           "and the folder is free for another try")
    if live_control:
        manifest["control"] = _live_control([dict(r, cache_dir=e["control_dir"]) for r, e in zip(picked, plan)])
    _write_json(scratch / "manifest.json", manifest)
    return manifest


def gemini_equivalence_collect(scratch: Path) -> dict | None:
    """Collect the check's batch into its scratch folder and print the verdict against the bar
    it was sent with. ``None`` while the job is still processing; run again."""
    scratch = Path(scratch)
    manifest = _read_json(scratch / "manifest.json")
    anchor, state = scratch / "check", _state(scratch / "check")
    if not state:
        raise ValueError(f"{scratch}: no batch was sent from this check")
    records = {e["key"]: {"key": e["key"], "cache_dir": e["batch_dir"], "slot": e["slot"],
                          "kind": e["kind"], "model": e["model"], "payload_key": e["payload_key"]}
               for e in manifest["requests"]}
    pending = False
    for b in state:
        if b.get("collected"):
            continue
        done = _collect_gemini(b, lambda: records)
        if done is None:
            pending = True
            continue
        b["collected"] = True
        b["cached"], b["failed"] = done
    _save_state(anchor, state)
    if pending:
        print("  the check's batch is still processing: run this again")
        return None
    verdict = _equivalence_verdict(manifest, state)
    _write_json(scratch / "verdict.json", verdict)
    print(_verdict_text(verdict))
    return verdict


def _local(cache_dir: str) -> Path:
    """A queue line's cache folder on this machine: as written, or — for a line queued on
    another machine — the same path from ``output`` down, in this checkout."""
    path = Path(cache_dir)
    parts = PureWindowsPath(cache_dir).parts
    if path.exists() or "output" not in parts:
        return path
    return ROOT.joinpath(*parts[parts.index("output"):])


def _read_json(path: Path) -> dict:
    return json.loads(Path(path).read_text(encoding="utf-8"))


def _write_json(path: Path, obj) -> None:
    tmp = Path(str(path) + ".part")
    tmp.write_text(json.dumps(obj, indent=1, ensure_ascii=False), encoding="utf-8")
    tmp.replace(path)


def _refuse_real_cache(scratch: Path, records: list[dict]) -> None:
    here = scratch.resolve()
    for root in {_local(r["cache_dir"]).resolve().parent for r in records}:
        if here == root or root in here.parents:
            raise ValueError(f"the check's scratch folder {scratch} is inside a reader's cache ({root})")


def _check_entry(rec: dict, request: dict, scratch: Path) -> dict:
    """What the check keeps of one sampled request: where its live readings are — the
    record of the pass that queued it first, then any other live reading of the same key —
    and where the batch and the control write theirs."""
    folder = _local(rec["cache_dir"])
    record = folder / f"{rec['key']}.json"
    others = sorted(p for p in folder.parent.glob(f"*/{rec['key']}.json")
                    if p != record and not _read_json(p).get("batched"))
    return {"key": rec["key"], "kind": rec["kind"], "slot": rec["slot"], "model": rec["model"],
            "payload_key": rec.get("payload_key", "lines"), "label": folder.name,
            "refs": [str(p) for p in [record, *others]],
            "schema": ((request.get("response_format") or {}).get("json_schema") or {}).get("schema"),
            "batch_dir": str(scratch / "batch" / folder.name),
            "control_dir": str(scratch / "live" / folder.name)}


def _check_cost(plan: list[dict], model: str, live_control: bool) -> dict:
    """Dollars, from the live records' own tokens, at the price list's rates
    (``lexikon_1910_pages.MODELS``): the batch at its discount, the control in full."""
    from utils.lexikon_1910 import lexikon_1910_pages as lxp

    spec = lxp.MODELS[model]
    used = [_read_json(Path(e["refs"][0]))["usage"] for e in plan]
    tokens_in, tokens_out = sum(u.get("input", 0) for u in used), sum(u.get("output", 0) for u in used)
    full = (tokens_in * spec.price_in + tokens_out * spec.price_out) / 1e6
    batch, control = full * spec.batch_discount, (full if live_control else 0.0)
    return {"input_tokens": tokens_in, "output_tokens": tokens_out, "price_in": spec.price_in,
            "price_out": spec.price_out, "batch": batch, "control": control, "total": batch + control}


def _live_control(records: list[dict], workers: int = 4) -> dict:
    """Each sampled request sent once more exactly as the live reader sends it, into the
    check's ``live`` folder: the reference the batch is held to, made at the same time,
    since the live reader drifts from day to day."""
    from openai import OpenAI

    import run_lexikon_1910_pilot                   # noqa: F401 — imported once, before the threads

    client = OpenAI(api_key=os.environ.get("GEMINI_API_KEY", ""), base_url=GEMINI_URL)
    why: Counter = Counter()

    def read(pair) -> str | None:
        rec, request = pair
        for attempt in range(3):
            try:
                body = client.chat.completions.create(**request).model_dump()
                break
            except Exception as exc:                            # noqa: BLE001
                if attempt == 2:
                    return f"error {type(exc).__name__}"
                time.sleep(2 * (attempt + 1))
        parsed = _parse_openai(body, rec.get("payload_key", "lines"))
        if parsed is None:
            return "refused (truncated, empty or unreadable)"
        folder = Path(rec["cache_dir"])
        folder.mkdir(parents=True, exist_ok=True)
        (folder / f"{rec['key']}.json").write_text(json.dumps(
            {"lines": parsed[0], "usage": parsed[1], "slot": rec["slot"], "kind": rec["kind"],
             "model": rec["model"], "at": time.time(), "control": True}), encoding="utf-8")
        return None

    started, pairs = time.time(), _requests(records)
    with ThreadPoolExecutor(max_workers=workers) as pool:
        while batch := list(islice(pairs, workers)):
            why.update(reason for reason in pool.map(read, batch) if reason)
    failed = sum(why.values())
    print(f"  live control: {len(records) - failed} of {len(records)} read"
          + (f"; not: {dict(why)}" if why else ""))
    return {"read": len(records) - failed, "failed": failed, "why": dict(why),
            "started": started, "ended": time.time()}


def line_agreement(a: list, b: list) -> float:
    """Two readings' shared lines, in order, as a share of both (Dice over difflib's
    matching blocks): 1 for the same lines, 0 for none in common; two empty readings agree."""
    if not a and not b:
        return 1.0
    a, b = ([x if isinstance(x, str) else json.dumps(x, sort_keys=True) for x in seq] for seq in (a, b))
    shared = sum(m.size for m in SequenceMatcher(None, a, b, autojunk=False).get_matching_blocks())
    return 2 * shared / (len(a) + len(b))


def cell_agreement(a: list, b: list) -> float:
    """The share of a table block's cells two readings agree on, rows paired in order; a row
    one reading has and the other lacks disagrees in every cell."""
    if not a and not b:
        return 1.0
    fields = sorted({k for row in a + b if isinstance(row, dict) for k in row})
    if not fields:
        return float(a == b)
    same = sum(1 for x, y in zip(a, b) if isinstance(x, dict) and isinstance(y, dict)
               for f in fields if x.get(f) == y.get(f))
    return same / (max(len(a), len(b)) * len(fields))


def _schema_errors(value, schema: dict, where: str = "$") -> list[str]:
    """Where ``value`` breaks ``schema``, for the keywords the readers' schemas use: ``type``
    (object, array, string), ``properties``, ``required``, ``additionalProperties: false``
    and ``items``."""
    kind = schema.get("type")
    if kind == "object":
        if not isinstance(value, dict):
            return [f"{where}: not an object"]
        props = schema.get("properties", {})
        errors = [f"{where}: no {k}" for k in schema.get("required", []) if k not in value]
        if schema.get("additionalProperties") is False:
            errors += [f"{where}: extra {k}" for k in value if k not in props]
        return errors + [e for k, sub in props.items() if k in value
                         for e in _schema_errors(value[k], sub, f"{where}.{k}")]
    if kind == "array":
        if not isinstance(value, list):
            return [f"{where}: not an array"]
        return [e for i, item in enumerate(value)
                for e in _schema_errors(item, schema.get("items", {}), f"{where}[{i}]")]
    if kind == "string" and not isinstance(value, str):
        return [f"{where}: not a string"]
    return []


def _compare(entry: dict) -> dict:
    """One sampled request: the batch's reading against the live ones, and the control's."""
    def load(folder: str):
        path = Path(folder) / f"{entry['key']}.json"
        return _read_json(path) if path.exists() else None

    batch, control = load(entry["batch_dir"]), load(entry["control_dir"])
    refs = [_read_json(Path(p)) for p in entry["refs"]]
    table = entry["kind"] == "table"
    agree = cell_agreement if table else line_agreement
    out = {"key": entry["key"], "kind": "table" if table else "notes", "failed": batch is None,
           "refs_identical": [x["lines"] == y["lines"] for x, y in combinations(refs, 2)]}
    if batch is None:
        return out
    lines, prompt = batch["lines"], (control or refs[0])["usage"].get("input", 0)
    out.update(prompt_diff=batch["usage"].get("input", 0) - prompt,
               thinking=batch["usage"].get("thinking", 0) or 0,
               schema_errors=(len(_schema_errors({entry["payload_key"]: lines}, entry["schema"]))
                              if entry["schema"] else 0),
               identical=lines == refs[0]["lines"],
               agree_batch=statistics.mean(agree(lines, r["lines"]) for r in refs))
    if control is not None:
        out.update(control_identical=control["lines"] == refs[0]["lines"],
                   batch_is_control=lines == control["lines"],
                   agree_control=statistics.mean(agree(control["lines"], r["lines"]) for r in refs),
                   control_prompt_drift=control["usage"].get("input", 0) - refs[0]["usage"].get("input", 0))
    return out


def _summary(rows: list[dict], bar: dict) -> dict:
    """One kind's numbers, and whether its batch agreed with the live reads as the control did."""
    done = [r for r in rows if not r["failed"]]
    paired = [r for r in done if "agree_control" in r]
    diffs = [r["agree_batch"] - r["agree_control"] for r in paired]
    share = lambda xs: statistics.mean(map(float, xs)) if xs else None      # noqa: E731
    refs = [x for r in rows for x in r["refs_identical"]]
    floor = (-bar["z"] * statistics.stdev(diffs) / math.sqrt(len(diffs))) if len(diffs) > 1 else None
    return {"requests": len(rows), "failed": len(rows) - len(done),
            "prompt_mismatches": sum(r["prompt_diff"] != 0 for r in done),
            "prompt_diffs": dict(Counter(str(r["prompt_diff"]) for r in done if r["prompt_diff"])),
            "thinking_max": max((r["thinking"] for r in done), default=0),
            "schema_violations": sum(r["schema_errors"] > 0 for r in done),
            "identical": share([r["identical"] for r in done]),
            "control_identical": share([r["control_identical"] for r in paired]),
            "batch_is_control": share([r["batch_is_control"] for r in paired]),
            "live_identical": share(refs), "live_pairs": len(refs),
            "control_prompt_drift": sum(r["control_prompt_drift"] != 0 for r in paired),
            "agree_batch": share([r["agree_batch"] for r in done]),
            "agree_control": share([r["agree_control"] for r in paired]),
            "pairs": len(diffs), "difference": share(diffs), "floor": floor}


def _equivalence_verdict(manifest: dict, state: list[dict]) -> dict:
    bar = manifest["bar"]                           # the bar the check was sent with
    rows = [_compare(e) for e in manifest["requests"]]
    kinds = {k: _summary([r for r in rows if r["kind"] == k], bar)
             for k in ("notes", "table") if any(r["kind"] == k for r in rows)}
    reasons = [f"job {b['id']} ended {b.get('state')}" for b in state if b.get("state") != "JOB_STATE_SUCCEEDED"]
    for kind, s in kinds.items():
        if s["failed"] > bar["failures"]:
            reasons.append(f"{kind}: {s['failed']} of {s['requests']} requests not answered "
                           f"({'; '.join(f'{k}: {v}' for b in state for k, v in b.get('refused', {}).items())})")
        if s["prompt_mismatches"] > bar["prompt_mismatches"]:
            reasons.append(f"{kind}: prompt tokens differ on {s['prompt_mismatches']} (by {s['prompt_diffs']})")
        if s["thinking_max"] > bar["thinking_max"]:
            reasons.append(f"{kind}: a reply thought {s['thinking_max']} tokens (bar {bar['thinking_max']})")
        if s["schema_violations"] > bar["schema_violations"]:
            reasons.append(f"{kind}: {s['schema_violations']} replies break their schema")
        if s["pairs"] >= bar["min_pairs"] and s["difference"] < s["floor"]:
            reasons.append(f"{kind}: agrees with the live reads less than the control does "
                           f"({s['difference']:+.3f}, floor {s['floor']:+.3f})")
    untested = [k for k, s in kinds.items() if s["pairs"] < bar["min_pairs"]]
    verdict = "FAIL" if reasons else ("INCONCLUSIVE" if untested else "PASS")
    if verdict == "INCONCLUSIVE":
        reasons = [f"{k}: {kinds[k]['pairs']} batch-and-control pairs, fewer than {bar['min_pairs']}" for k in untested]
    return {"verdict": verdict, "reasons": reasons, "kinds": kinds, "bar": bar,
            "jobs": [{k: b.get(k) for k in ("id", "state", "submitted", "ended", "cached", "failed",
                                            "refused", "first_error")} for b in state],
            "control": manifest.get("control"), "collected": time.time(), "version": __version__}


def _verdict_text(verdict: dict) -> str:
    """The verdict as a table: B is the batch, C the live control, "live" the record of the
    pass that queued the request; agreement is with every live reading made before."""
    def pct(x):
        return "—" if x is None else f"{100 * x:.1f}%"

    def num(x, sign: bool = False):
        return "—" if x is None else (f"{x:+.3f}" if sign else f"{x:.3f}")

    head = ("", "asked", "failed", "prompt≠", "think", "schema✗", "B=live", "C=live", "B=C",
            "live=live", "agree B", "agree C", "B−C", "floor")
    rows = [head] + [(kind, s["requests"], s["failed"], s["prompt_mismatches"], s["thinking_max"],
                      s["schema_violations"], pct(s["identical"]), pct(s["control_identical"]),
                      pct(s["batch_is_control"]), pct(s["live_identical"]), num(s["agree_batch"]),
                      num(s["agree_control"]), num(s["difference"], True), num(s["floor"], True))
                     for kind, s in verdict["kinds"].items()]
    widths = [max(len(str(row[i])) for row in rows) for i in range(len(head))]
    clock = lambda t: time.strftime("%Y-%m-%d %H:%M", time.localtime(t)) if t else "—"   # noqa: E731
    control = verdict.get("control") or {}
    out = ["Gemini native batch vs live: " + ", ".join(
        f"{j['id']} {j['state']} (sent {clock(j.get('submitted'))}, ended {j.get('ended') or '—'})"
        for j in verdict["jobs"])
        + f"; control read {clock(control.get('started'))}–{clock(control.get('ended'))}"]
    out += ["  " + "  ".join(str(v).rjust(w) for v, w in zip(row, widths)) for row in rows]
    out.append(f"VERDICT: {verdict['verdict']}"
               + {"PASS": " — reader_batches.GEMINI_BATCH may go True for the full run",
                  "FAIL": " — GEMINI_BATCH stays False (D-117 stands)",
                  "INCONCLUSIVE": " — GEMINI_BATCH stays False until a check is conclusive"}[verdict["verdict"]])
    return "\n".join(out + [f"  - {r}" for r in verdict["reasons"]])
