How it works

After D-207 the rechecked register still held 83 municipalities with institutions and no table row (Czech 27, German Böhmen 49, Mähren 7). The rows are mostly in the table: the reader read the number, the name and the figures and got the row's structure wrong, so the register — which files a row only by the number on its row 0 — passed them by. Three shapes, mended here on the run handed to register_rechecked and never in the frozen route:

  • A. A numbered row tagged as a total (numbered_totals; German volumes). The German reader tags each block (D-160): a district total (summary) names no place and is skipped. On German Böhmen 0273 and 0332 it tagged every block of the page summary — Bechyně 3–23 and Vodňany 1–15, numbers, names and figures all read right. A total line never carries a running number, so a summary block whose row 0 has one, and whose name is not a total line's, is a municipality.
  • B. A row opened on the seat town's darunter Militär line (military_openings; German volumes). The town's military sub-line, printed below its last part, was read as row 0 of a new block, with no number, and the next municipality as that block's row 1 (Dobern, Dobranov 2 under Böhmisch Leipa on 0055; Vrchlabí 7, Karlovy Vary 21, Karlín 17, Lanškroun 10, Stříbro 23 …). The line is dropped and the row below opens the block — only where its number is the one the court's numbering expects there (the numbered row before it, of the same label, is n − 1, or the one after it n + 1).
  • C. Rows read without their number (number_gaps; every volume). A name printed on two lines, read from its second line (Volyně 18 Kraselow, 19 Lhota ob Rohanow), or a row at a page break. D-207 numbered one row between n − 1 and n + 1 of one label on one page; this numbers k unnumbered rows between two numbered rows of one court whose numbers leave exactly k free — across a page break too — and a single unnumbered row where a court ends or begins, at the number next to its neighbour. Each row is numbered only where the court's list of parts names it, or, where that list says nothing, the apparatus holds that number of the court on its page (table_courts.evidence), and never where the court already has a table row with that number.
  • D. A part read as a row of its own, E. one number read twice, and F. one row read twice (mend_duplicates; every volume), both seen as two table rows filed under one court and number. A part printed under its municipality was read with its part number as a new municipality's row (Zákupy 40, then "1 Nové Zákupy", Mimoň on Czech 0059): where the municipality above's list of parts names it, and the list of the number it carries does not, it joins the municipality's block as a part. A number read twice in a row (Broumov 14, 14, 16 on Czech 0039) takes the number its neighbours leave free, where that number's list of parts names the row. A row read twice — the same name and figures under one number (Rvenice 1 on Böhmen 0390) — loses its copy, and what the reader put under the copy opens its own block. Another court's rows filed under this court's numbers — a label no fix has resolved — are left, and the check lists them.

Three more, from what the run read besides the reader of record's blocks (D-215, mend_numbers): G0 a row under a neighbour's label, between two rows of one court that read n − 1 and n + 1, takes their label where that court's parts list names it (mend_labels); G where the reader of record's block has no number or reads a total line, the second table reader's block is added if the parts list names its row (second_reader); R the rows table_reread read from the page bands enter where one court of the page lacks the number and its parts list names the row (reread_rows).

check then reads every volume's table for what is left: a numbered total, a military opening, an unnumbered row that is not a total line, two rows filed under one number, and every municipality with no table row. What is left after the mends is what only a new read of the table can give.

def blocks(table: pd.DataFrame) -> pd.DataFrame:
    """One row per channel-A block in printed order: page, block, kind, label, row-0 number and name,
    and every row index of the block (row 0 first)."""
    out = []
    a = table[table["channel"] == "A"] if "channel" in table else table.iloc[0:0]
    for block_id, g in a.groupby("block_id", sort=False):
        first = g[g["row"].astype(str) == "0"]
        head = first.iloc[0] if len(first) else g.iloc[0]
        value = g["block_kind"].iloc[0] if "block_kind" in g else None
        kind = str(value) if value is not None and not pd.isna(value) and str(value) else "municipality"
        out.append({"page": str(head["page"]).zfill(4), "block_id": block_id, "kind": kind,
                    "label": str(head.get("court_label", "") or ""), "n": _seq(head["seq"]) if len(first) else None,
                    "name": reg.clean_display(head["name"]), "rows": list(g.index),
                    "row1_seq": _seq(g[g["row"].astype(str) == "1"]["seq"].iloc[0])
                    if (g["row"].astype(str) == "1").any() else None})
    frame = pd.DataFrame(out, columns=["page", "block_id", "kind", "label", "n", "name", "rows", "row1_seq"])
    for col in ("n", "row1_seq"):                # ints or None, never a float NaN (``is None`` tests below)
        frame[col] = pd.Series([r[col] for r in out], index=frame.index, dtype=object)
    return frame

def numbered_totals(table: pd.DataFrame) -> tuple[pd.DataFrame, list[dict]]:

    court expects there — the line dropped, its rows moved up one."""

def court_lookup(units):
    """``lexikon_1910_register._table_court`` indexed once per volume: the register's own rule (the row's
    label where ``courts.csv`` knows it, else the page's only court, else the one court holding that
    number on the page), without a scan of every place for every row."""
    holding, on_page = defaultdict(set), defaultdict(set)
    for (ck, muni, _seq), place in units.places.items():
        for page in place["pages"]:
            holding[(muni, page)].add(ck)
    for (page, _district), court in units.court_of.items():
        on_page[page].add(court)

    def court(page: str, muni: int, label: str) -> str | None:
        if label and (page, reg._label(label)) in units.court_of:
            return units.key(page, label)
        if len(on_page[page]) == 1:
            return reg.court_key(next(iter(on_page[page])), "")
        found = holding[(muni, page)]
        return next(iter(found)) if len(found) == 1 else None
    return court

            table = table.copy() if table is run.table else table
            for i, (_j, s) in enumerate(stretch.iterrows()):

def mend_duplicates(run: reg.RunInput) -> tuple[reg.RunInput, list[dict], list[dict]]:
    """Shapes D and E: of two table rows filed under one court and number, the one the parts list
    shows to be (D) a part of the municipality above it, read as a row of its own (Zákupy 40 then
    "1 Nové Zákupy", Mimoň on Czech 0059), joins that municipality's block as its part; or (E) one
    number read twice in a row (Broumov 14, 14, 16 on Czech 0039) takes the number its neighbours
    leave free where that number's parts name it. Only blocks in a duplicate filing are touched.
    Returns the run, what moved, and the duplicates left as they were."""
    frame = blocks(run.table)
    units, names = tc.apparatus(run)
    units.lookup = court_lookup(units)
    filed = _filed(units, frame)
    dup = {b for ids in filed.values() if len(ids) > 1 for b in ids}
    court = {b.block_id: units.lookup(b.page, int(b.n), b.label)
             for b in frame.itertuples() if b.n is not None}
    table, done, owner, drop = run.table.copy(), [], None, []
    for k, b in enumerate(frame.itertuples()):
        if b.n is None:
            continue
        ck = court.get(b.block_id)
        o = owner
        if b.block_id in dup and o is not None and o["n"] == b.n and _same_row(table, o["rows"][0], b.rows[0]):
            # F: the row read twice (Rvenice 1 on Böhmen 0390, its copy carrying Vrbka 2): the copy goes,
            # and what the reader put under it opens its own block
            drop.append(b.rows[0])
            rest = list(b.rows[1:])
            table.loc[rest, "row"] = [str(int(str(r)) - 1) for r in table.loc[rest, "row"]]
            done.append({"shape": "a row read twice", "page": b.page, "label": b.label, "court": ck,
                         "seq": b.n, "name": b.name})
            if rest:
                n2 = _seq(table.loc[rest[0], "seq"])
                owner = {"block_id": b.block_id, "label": b.label, "n": n2, "rows": rest} if n2 else owner
            continue
        if b.block_id in dup and ck and o is not None and o["label"] == b.label and court.get(o["block_id"]) == ck                 and o["n"] >= b.n and _names_it(names, ck, o["n"], b.name)                 and not _names_it(names, ck, b.n if o["n"] != b.n else b.n + 1, b.name):
            # the row's own number (or, read twice, the next) names it: a municipality, not a part
            last = max(int(str(r)) for r in table.loc[o["rows"], "row"])
            table.loc[b.rows, "block_id"] = o["block_id"]
            table.loc[b.rows, "row"] = [str(last + 1 + i) for i in range(len(b.rows))]
            if "block_kind" in table:
                table.loc[b.rows, "block_kind"] = table.loc[o["rows"][0], "block_kind"]
            o["rows"] = o["rows"] + list(b.rows)
            done.append({"shape": "part read as a row", "page": b.page, "label": b.label, "court": ck,
                         "seq": b.n, "joins": o["n"], "name": b.name})
            continue
        if b.block_id in dup and ck and o is not None and o["n"] == b.n and court.get(o["block_id"]) == ck:
            nxt = next((frame.iloc[j] for j in range(k + 1, len(frame)) if frame.iloc[j]["n"] is not None), None)
            free = b.n + 1
            if (nxt is not None and nxt["n"] == b.n + 2 and (ck, free) not in filed
                    and _names_it(names, ck, free, b.name)):   # the numbering leaves n + 1 free, and its list names it
                row0 = [r for r in b.rows if str(table.loc[r, "row"]) == "0"]
                table.loc[row0, "seq"] = str(free)
                filed[(ck, free)] = [b.block_id]
                done.append({"shape": "one number read twice", "page": b.page, "label": b.label, "court": ck,
                             "seq": b.n, "becomes": free, "name": b.name})
                owner = {"block_id": b.block_id, "label": b.label, "n": free, "rows": list(b.rows)}
                continue
        owner = {"block_id": b.block_id, "label": b.label, "n": b.n, "rows": list(b.rows)}
    run = replace(run, table=table.drop(index=drop))
    left_frame = blocks(run.table)
    left = [{"court": ck, "seq": n, "blocks": len(ids)} for (ck, n), ids in _filed(units, left_frame).items()
            if len(ids) > 1]
    return run, done, left

def reread_rows(run: reg.RunInput, replies: dict) -> tuple[reg.RunInput, list[dict]]:
    """R. The rows ``table_reread`` read from the page bands (D-215). A municipality line (a number
    and its area) enters where exactly one court of the page holds no row with that number and
    that court's parts list names it — or, where no list names it (a municipality without parts:
    Tribischl 14 and Weigensdorf 16 on Czech 0360, Kleinkarlowitz 11 on Mähren 0151), where the
    apparatus holds that number of the court on the page **and** the municipality line next to it
    in the band is the very row that court has filed at *n − 1* or *n + 1*, by name. The number alone
    is not enough: on Mähren 0050 Břeclav and Strážnice both hold a 3 and a 5, and a first version
    filed Břeclav's Kostel 4 and Lundenburg 8 as Strážnice 4 and 8 — with the part lines printed under it (numbered
    1, 2 …, no area). The reader of record's reply is taken; the second reader's agreement (the
    same number, a name in common and the same population) is reported."""
    primary, second = replies.get("gemini38") or [], replies.get("haiku55") or []
    if not primary:
        return run, []
    frame = blocks(run.table)
    units, names = tc.apparatus(run)
    units.lookup = court_lookup(units)
    filed = _filed(units, frame)
    filed_names: dict = {}                       # (court, n) -> the names its table rows print
    for b in frame[frame["n"].notna()].itertuples():
        ck = units.lookup(b.page, int(b.n), b.label)
        if ck:
            filed_names.setdefault((ck, int(b.n)), []).append(b.name)
    theirs: dict = {}
    for band in second:
        for r in band["rows"]:
            if _seq(r.get("seq")) is not None:
                theirs.setdefault((band["page"], _seq(r.get("seq"))), []).append(r)
    position = {i: k for k, i in enumerate(run.table.index)}
    last_on_page: dict = {}
    for b in frame.itertuples():
        last_on_page[b.page] = max(last_on_page.get(b.page, -1), max(position[i] for i in b.rows))
    pieces, done = [], []
    for band in primary:
        page, rows = band["page"], band["rows"]
        courts = sorted({reg.court_key(c, d) for (p, d), c in units.court_of.items() if p == page})
        for k, r in enumerate(rows):
            n, name = _seq(r.get("seq")), str(r.get("name") or "")
            if n is None or not str(r.get("area_ha") or "").strip():
                continue

            if not fits:

                fits, how = [c for c in courts if (c, n) not in filed and _on_page(units, c, n, page)
                             and any(abs(m - n) == 1 and _same_place(nm, filed_names.get((c, m), []))
                                     for m, nm in beside)], "position"

                    block.append(r2)
                elif MILITARY.search(str(r2.get("name") or "")):
                    continue
                else:
                    break
            agree = any(tc._named(tc._pieces(name), tc._pieces(s.get("name") or ""))
                        and str(s.get("pop_total")) == str(r.get("pop_total")) for s in theirs.get((page, n), []))
            out = pd.DataFrame([{"channel": "A", "page": page, "block_id": f"{page}#R{n:03d}",

def check(run: reg.RunInput, places: pd.DataFrame | None = None) -> pd.DataFrame:
    """Everything in one volume's table that still breaks the register's reading of it: one row per
    fault, with its kind (:data:`ISSUES`). ``places``: the built register's places, for the
    municipalities with no table row."""
    frame = blocks(run.table)
    units, _names = tc.apparatus(run)
    units.lookup = court_lookup(units)
    out = []
    for k, b in enumerate(frame.itertuples()):
        if b.kind == "summary" and b.n is not None and not TOTAL.search(b.name):
            out.append({"issue": "numbered_total", "page": b.page, "label": b.label, "muni_seq": b.n, "name": b.name})
        elif b.n is None and MILITARY.search(b.name) and b.row1_seq is not None:
            out.append({"issue": "military_opening", "page": b.page, "label": b.label, "muni_seq": b.row1_seq,
                        "name": b.name})
        elif b.n is None and not TOTAL.search(b.name) and (b.kind == "municipality" or _inside(frame, k)):
            out.append({"issue": "unnumbered_row", "page": b.page, "label": b.label, "muni_seq": None, "name": b.name})
    for (ck, n), ids in _filed(units, frame).items():
        if len(ids) > 1:
            pages = frame.set_index("block_id").loc[ids, "page"]
            out.append({"issue": "duplicate_row", "page": ";".join(pages), "label": units.court_cs.get(ck, ""),
                        "court_key": ck, "muni_seq": n, "name": f"{len(ids)} rows"})
    if places is not None and len(places):
        mun = places[(places["edition"] == run.edition) & (places["place_level"] == "municipality")
                     & (places["name_source"] != "table")]
        for p in mun.itertuples():
            out.append({"issue": "missing_row", "page": p.pages, "label": p.court_cs, "court_key": str(p.court_key),
                        "muni_seq": p.muni_seq, "name": p.printed_name})
    frame_out = pd.DataFrame(out, columns=["issue", "page", "label", "court_key", "muni_seq", "name"])
    frame_out["muni_seq"] = pd.array([_seq(m) if m is not None and not pd.isna(m) else None
                                      for m in frame_out["muni_seq"]], dtype="Int64")
    frame_out.insert(0, "edition", run.edition)
    return frame_out

def check_report(faults: pd.DataFrame, claims: pd.DataFrame | None = None) -> dict:
    """Counts by volume and kind, and how many of the missing rows carry institutions."""
    out = {ed: {i: int((g["issue"] == i).sum()) for i in ISSUES} for ed, g in faults.groupby("edition")}
    if claims is not None and len(claims):
        def key(ed, ck, m):
            return ed, str(ck), _seq(str(m).split(".")[0]) if pd.notna(m) else None
        held = {key(e, k, m) for e, k, m in zip(claims["edition"], claims["court_key"], claims["muni_seq"])}
        miss = faults[faults["issue"] == "missing_row"]
        for ed, g in miss.groupby("edition"):
            out[ed]["missing_row_with_institutions"] = int(sum(
                key(ed, ck, m) in held for ck, m in zip(g["court_key"], g["muni_seq"])))
    return out

handed to ``register_rechecked`` and never in the frozen route:

MILITARY = re.compile(r"^\s*(darunter Milit|mezi tím vojsko)", re.IGNORECASE)
GERMAN = ("de-bohemia", "de-moravia", "de-silesia")
ISSUES = ("numbered_total", "military_opening", "unnumbered_row", "duplicate_row", "missing_row")


def _seq(value) -> int | None:
    if isinstance(value, float) and value.is_integer():
        return int(value)
    text = str(value).strip()
    return int(text) if text.isdigit() else None


def blocks(table: pd.DataFrame) -> pd.DataFrame:
    """One row per channel-A block in printed order: page, block, kind, label, row-0 number and name,
    and every row index of the block (row 0 first)."""
    out = []
    a = table[table["channel"] == "A"] if "channel" in table else table.iloc[0:0]
    for block_id, g in a.groupby("block_id", sort=False):
        first = g[g["row"].astype(str) == "0"]
        head = first.iloc[0] if len(first) else g.iloc[0]
        value = g["block_kind"].iloc[0] if "block_kind" in g else None
        kind = str(value) if value is not None and not pd.isna(value) and str(value) else "municipality"
        out.append({"page": str(head["page"]).zfill(4), "block_id": block_id, "kind": kind,
                    "label": str(head.get("court_label", "") or ""), "n": _seq(head["seq"]) if len(first) else None,
                    "name": reg.clean_display(head["name"]), "rows": list(g.index),
                    "row1_seq": _seq(g[g["row"].astype(str) == "1"]["seq"].iloc[0])
                    if (g["row"].astype(str) == "1").any() else None})
    frame = pd.DataFrame(out, columns=["page", "block_id", "kind", "label", "n", "name", "rows", "row1_seq"])
    for col in ("n", "row1_seq"):                # ints or None, never a float NaN (``is None`` tests below)
        frame[col] = pd.Series([r[col] for r in out], index=frame.index, dtype=object)
    return frame


def numbered_totals(table: pd.DataFrame) -> tuple[pd.DataFrame, list[dict]]:
    """Shape A: every ``summary`` block whose row 0 carries a number and names no total, retagged
    ``municipality``."""
    if "block_kind" not in table:
        return table, []
    table, done = table.copy(), []
    for b in blocks(table).itertuples():
        if b.kind == "summary" and b.n is not None and not TOTAL.search(b.name):
            table.loc[b.rows, "block_kind"] = "municipality"
            done.append({"page": b.page, "label": b.label, "seq": b.n, "name": b.name})
    return table, done


def _numbered_neighbours(frame: pd.DataFrame, k: int) -> tuple:
    """The nearest numbered block before and after position ``k`` (``None`` where there is none)."""
    before = next((frame.iloc[j] for j in range(k - 1, -1, -1) if frame.iloc[j]["n"] is not None), None)
    after = next((frame.iloc[j] for j in range(k + 1, len(frame)) if frame.iloc[j]["n"] is not None), None)
    return before, after


def military_openings(table: pd.DataFrame) -> tuple[pd.DataFrame, list[dict]]:
    """Shape B: a block opened on an unnumbered military line whose row 1 carries the number the
    court expects there — the line dropped, its rows moved up one."""
    frame = blocks(table)
    drop, shift, done = [], [], []
    for k, b in enumerate(frame.itertuples()):
        if b.n is not None or b.row1_seq is None or not MILITARY.search(b.name):
            continue
        before, after = _numbered_neighbours(frame, k)
        n = b.row1_seq
        fits = ((before is not None and before["label"] == b.label and before["n"] + 1 == n)
                or (after is not None and after["label"] == b.label and after["n"] - 1 == n))
        if not fits:
            continue
        drop.append(b.rows[0])
        shift += b.rows[1:]
        done.append({"page": b.page, "label": b.label, "seq": n,
                     "name": reg.clean_display(table.loc[b.rows[1], "name"])})
    if not done:
        return table, done
    table = table.copy()
    table.loc[shift, "row"] = [str(int(str(r)) - 1) for r in table.loc[shift, "row"]]
    return table.drop(index=drop), done


def court_lookup(units):
    """``lexikon_1910_register._table_court`` indexed once per volume: the register's own rule (the row's
    label where ``courts.csv`` knows it, else the page's only court, else the one court holding that
    number on the page), without a scan of every place for every row."""
    holding, on_page = defaultdict(set), defaultdict(set)
    for (ck, muni, _seq), place in units.places.items():
        for page in place["pages"]:
            holding[(muni, page)].add(ck)
    for (page, _district), court in units.court_of.items():
        on_page[page].add(court)

    def court(page: str, muni: int, label: str) -> str | None:
        if label and (page, reg._label(label)) in units.court_of:
            return units.key(page, label)
        if len(on_page[page]) == 1:
            return reg.court_key(next(iter(on_page[page])), "")
        found = holding[(muni, page)]
        return next(iter(found)) if len(found) == 1 else None
    return court


def _filed(units, frame: pd.DataFrame) -> dict:
    """``{(court_key, n): [block_id, …]}`` for every numbered block, by the register's own rule."""
    out: dict = {}
    for b in frame[frame["n"].notna()].itertuples():
        ck = units.lookup(b.page, int(b.n), b.label)
        if ck:
            out.setdefault((ck, int(b.n)), []).append(b.block_id)
    return out


def _supports(units, names, page: str, n: int, name: str, court: str) -> bool:
    """The court's list of parts names the row, or (that list silent) the apparatus holds ``n`` there."""
    return tc.evidence(units, names, page, n, name, court, None) in ("heading", "both")


def _candidate(b) -> bool:
    return b["n"] is None and not TOTAL.search(b["name"]) and b["kind"] in ("municipality", "summary")


def _inside(frame: pd.DataFrame, k: int) -> bool:
    """The block sits inside one label's numbering (a ``summary`` block there is a row read as a total;
    elsewhere it is a heading's second line)."""
    before, after = _numbered_neighbours(frame, k)
    return before is not None and after is not None and before["label"] == after["label"]


def _gap_readings(units, before, after, k: int) -> list[tuple[str, int]]:
    """Where ``k`` unnumbered rows between ``before`` and ``after`` may sit: ``[(court, first n)]``."""
    def court(b):
        return units.lookup(b["page"], int(b["n"]), b["label"]) if b is not None else None

    cb, ca = court(before), court(after)
    if cb and cb == ca and after["n"] - before["n"] - 1 == k:
        return [(cb, before["n"] + 1)]                   # inside one court's numbering, exactly k free
    if k != 1:
        return []
    readings = []
    if cb and (ca != cb or after is None or after["n"] <= before["n"]):
        readings.append((cb, before["n"] + 1))           # the last row of a court
    if ca and after["n"] > 1 and (cb != ca or before is None):
        readings.append((ca, after["n"] - 1))            # the first row of a court
    return readings


def number_gaps(run: reg.RunInput) -> tuple[reg.RunInput, list[dict], list[dict]]:
    """Shape C: unnumbered rows given the number their neighbours leave free, on the evidence.
    Returns the run, what was numbered, and the unnumbered stretches left as they were."""
    frame = blocks(run.table)
    units, names = tc.apparatus(run)
    units.lookup = court_lookup(units)
    filed = _filed(units, frame)
    table, done, left = run.table, [], []
    k = 0
    while k < len(frame):
        if not _candidate(frame.iloc[k]):
            k += 1
            continue
        end = k
        while end + 1 < len(frame) and _candidate(frame.iloc[end + 1]):
            end += 1
        stretch = frame.iloc[k:end + 1]
        before, after = _numbered_neighbours(frame, k)
        after = next((frame.iloc[j] for j in range(end + 1, len(frame)) if frame.iloc[j]["n"] is not None), None)
        pages = {int(p) for p in stretch["page"]} | {int(b["page"]) for b in (before, after) if b is not None}
        readings = _gap_readings(units, before, after, len(stretch)) if max(pages) - min(pages) <= 1 else []
        if (stretch["kind"] == "summary").any():         # a heading's second line sits between courts
            readings = readings[:1] if readings and after is not None and before is not None                 and readings[0] == (units.lookup(before["page"], int(before["n"]), before["label"]),
                                    before["n"] + 1) and after["n"] - before["n"] - 1 == len(stretch) else []
        fits = [(c, first) for c, first in readings
                if all((c, first + i) not in filed
                       and _supports(units, names, s["page"], first + i, s["name"], c)
                       for i, (_j, s) in enumerate(stretch.iterrows()))]
        if len(fits) == 1:
            court, first = fits[0]
            table = table.copy() if table is run.table else table
            for i, (_j, s) in enumerate(stretch.iterrows()):
                row0 = [r for r in s["rows"] if str(table.loc[r, "row"]) == "0"] or s["rows"][:1]
                table.loc[row0, "seq"] = str(first + i)
                if "block_kind" in table:
                    table.loc[s["rows"], "block_kind"] = "municipality"
                filed[(court, first + i)] = [s["block_id"]]
                done.append({"page": s["page"], "label": s["label"], "court": court, "seq": first + i,
                             "name": s["name"]})
        elif (stretch["kind"] == "municipality").any() or readings:
            left += [{"page": s["page"], "label": s["label"], "name": s["name"],
                      "readings": "; ".join(f"{c} {f}" for c, f in readings)} for _j, s in stretch.iterrows()]
        k = end + 1
    return replace(run, table=table), done, left


def _names_it(names, ck: str, muni: int, name: str) -> bool:
    """The list of parts (and claims) of ``(ck, muni)`` names the printed name."""
    return tc._named(tc._pieces(name), names[(ck, muni)])


FIGURES = ("pop_total", "pop_male", "pop_female")   # the copy can misread a cell (area 297 for 417 at Rvenice)


def _same_row(table: pd.DataFrame, a, b) -> bool:
    """Two table rows with the same name and the same population, total, men and women: one printed
    row read twice."""
    cols = [c for c in FIGURES if c in table]
    same = reg.clean_display(table.loc[a, "name"]) == reg.clean_display(table.loc[b, "name"])
    return same and bool(cols) and all(str(table.loc[a, c]) == str(table.loc[b, c]) for c in cols)


def mend_duplicates(run: reg.RunInput) -> tuple[reg.RunInput, list[dict], list[dict]]:
    """Shapes D and E: of two table rows filed under one court and number, the one the parts list
    shows to be (D) a part of the municipality above it, read as a row of its own (Zákupy 40 then
    "1 Nové Zákupy", Mimoň on Czech 0059), joins that municipality's block as its part; or (E) one
    number read twice in a row (Broumov 14, 14, 16 on Czech 0039) takes the number its neighbours
    leave free where that number's parts name it. Only blocks in a duplicate filing are touched.
    Returns the run, what moved, and the duplicates left as they were."""
    frame = blocks(run.table)
    units, names = tc.apparatus(run)
    units.lookup = court_lookup(units)
    filed = _filed(units, frame)
    dup = {b for ids in filed.values() if len(ids) > 1 for b in ids}
    court = {b.block_id: units.lookup(b.page, int(b.n), b.label)
             for b in frame.itertuples() if b.n is not None}
    table, done, owner, drop = run.table.copy(), [], None, []
    for k, b in enumerate(frame.itertuples()):
        if b.n is None:
            continue
        ck = court.get(b.block_id)
        o = owner
        if b.block_id in dup and o is not None and o["n"] == b.n and _same_row(table, o["rows"][0], b.rows[0]):
            # F: the row read twice (Rvenice 1 on Böhmen 0390, its copy carrying Vrbka 2): the copy goes,
            # and what the reader put under it opens its own block
            drop.append(b.rows[0])
            rest = list(b.rows[1:])
            table.loc[rest, "row"] = [str(int(str(r)) - 1) for r in table.loc[rest, "row"]]
            done.append({"shape": "a row read twice", "page": b.page, "label": b.label, "court": ck,
                         "seq": b.n, "name": b.name})
            if rest:
                n2 = _seq(table.loc[rest[0], "seq"])
                owner = {"block_id": b.block_id, "label": b.label, "n": n2, "rows": rest} if n2 else owner
            continue
        if b.block_id in dup and ck and o is not None and o["label"] == b.label and court.get(o["block_id"]) == ck                 and o["n"] >= b.n and _names_it(names, ck, o["n"], b.name)                 and not _names_it(names, ck, b.n if o["n"] != b.n else b.n + 1, b.name):
            # the row's own number (or, read twice, the next) names it: a municipality, not a part
            last = max(int(str(r)) for r in table.loc[o["rows"], "row"])
            table.loc[b.rows, "block_id"] = o["block_id"]
            table.loc[b.rows, "row"] = [str(last + 1 + i) for i in range(len(b.rows))]
            if "block_kind" in table:
                table.loc[b.rows, "block_kind"] = table.loc[o["rows"][0], "block_kind"]
            o["rows"] = o["rows"] + list(b.rows)
            done.append({"shape": "part read as a row", "page": b.page, "label": b.label, "court": ck,
                         "seq": b.n, "joins": o["n"], "name": b.name})
            continue
        if b.block_id in dup and ck and o is not None and o["n"] == b.n and court.get(o["block_id"]) == ck:
            nxt = next((frame.iloc[j] for j in range(k + 1, len(frame)) if frame.iloc[j]["n"] is not None), None)
            free = b.n + 1
            if (nxt is not None and nxt["n"] == b.n + 2 and (ck, free) not in filed
                    and _names_it(names, ck, free, b.name)):   # the numbering leaves n + 1 free, and its list names it
                row0 = [r for r in b.rows if str(table.loc[r, "row"]) == "0"]
                table.loc[row0, "seq"] = str(free)
                filed[(ck, free)] = [b.block_id]
                done.append({"shape": "one number read twice", "page": b.page, "label": b.label, "court": ck,
                             "seq": b.n, "becomes": free, "name": b.name})
                owner = {"block_id": b.block_id, "label": b.label, "n": free, "rows": list(b.rows)}
                continue
        owner = {"block_id": b.block_id, "label": b.label, "n": b.n, "rows": list(b.rows)}
    run = replace(run, table=table.drop(index=drop))
    left_frame = blocks(run.table)
    left = [{"court": ck, "seq": n, "blocks": len(ids)} for (ck, n), ids in _filed(units, left_frame).items()
            if len(ids) > 1]
    return run, done, left

def _insert(table: pd.DataFrame, pieces: list[tuple[float, pd.DataFrame]]) -> pd.DataFrame:
    """The table with each ``(position, rows)`` placed just after that position of its printed order
    (position *k* − 1 puts the rows before the table's *k*-th row)."""
    if not pieces:
        return table
    parts = [table.assign(_pos=[float(i) for i in range(len(table))])]
    for k, (pos, rows) in enumerate(pieces):
        parts.append(rows.assign(_pos=[pos + 0.5 + (k + 1) * 1e-6 + i * 1e-9 for i in range(len(rows))]))
    out = pd.concat(parts, ignore_index=True).sort_values("_pos", kind="stable")
    return out.drop(columns="_pos").reset_index(drop=True)


def mend_labels(run: reg.RunInput) -> tuple[reg.RunInput, list[dict]]:
    """G0. A numbered row labelled with another court than the two numbered rows around it, which
    share one court and read *n − 1* and *n + 1* (Strážnice 4 under Břeclav's label on Mähren 0050):
    it takes their label, where their court holds no row with that number and its **list of parts**
    names the row. Not the apparatus: on 0050 the labels alternate, so every Strážnice row there also
    sits between two Břeclav rows, and Břeclav's apparatus holds those numbers too."""
    frame = blocks(run.table)
    units, names = tc.apparatus(run)
    units.lookup = court_lookup(units)
    numbered = [k for k in range(len(frame)) if frame.iloc[k]["n"] is not None]
    filed = _filed(units, frame)
    table, done = run.table.copy(), []
    for i in range(1, len(numbered) - 1):
        p, b, q = (frame.iloc[numbered[j]] for j in (i - 1, i, i + 1))
        if not (p["label"] == q["label"] != b["label"] and p["n"] + 1 == b["n"] == q["n"] - 1
                and int(q["page"]) - int(p["page"]) <= 1):
            continue
        court = units.lookup(p["page"], int(p["n"]), p["label"])
        if court and court == units.lookup(q["page"], int(q["n"]), q["label"]) \
                and (court, int(b["n"])) not in filed and _names_it(names, court, int(b["n"]), b["name"]):
            table.loc[b["rows"], "court_label"] = p["label"]
            done.append({"page": b["page"], "label": b["label"], "becomes": p["label"], "seq": b["n"],
                         "name": b["name"]})
    return replace(run, table=table), done


def second_reader(run: reg.RunInput, second: pd.DataFrame | None) -> tuple[reg.RunInput, list[dict]]:
    """G. The run's second table reader (Haiku) read every block the reader of record did. Where the
    reader of record's row 0 has no number or is a total line, and Haiku read a numbered row there
    (Kadaň 44 *Wernsdorf* on Czech 0154 and Sušice 40 *Žichovice* on 0424, where Gemini read the
    district total below it), the court holds no row with that number and its list of parts names
    the row, Haiku's block is added before Gemini's, under Gemini's label. Where both read a number
    and the numbers differ (Dessendorf 2 or 3 on Czech 0134), one of them is wrong and nothing here
    says which: the page re-read settles those (D-215)."""
    if second is None or second.empty:
        return run, []
    frame, other = blocks(run.table), blocks(second)
    units, names = tc.apparatus(run)
    units.lookup = court_lookup(units)
    filed = _filed(units, frame)
    theirs = {b.block_id: b for b in other.itertuples()}
    position = {i: k for k, i in enumerate(run.table.index)}
    pieces, done = [], []
    for b in frame.itertuples():
        s = theirs.get(b.block_id)
        if s is None or s.n is None or (b.n is not None and not TOTAL.search(b.name)):
            continue
        court = units.lookup(b.page, int(s.n), b.label)
        if not court or (court, s.n) in filed or not _names_it(names, court, int(s.n), s.name):
            continue
        rows = second.loc[s.rows].copy()
        rows["block_id"], rows["court_label"] = f"{b.block_id}h", b.label
        if "block_kind" in rows:
            rows["block_kind"] = "municipality"
        pieces.append((position[b.rows[0]] - 1, rows))
        filed[(court, s.n)] = [f"{b.block_id}h"]
        done.append({"page": b.page, "court": court, "seq": s.n, "name": s.name, "theirs_instead_of": b.n})
    return replace(run, table=_insert(run.table, pieces)), done


def _beside(rows: list[dict], k: int) -> list[tuple[int, str]]:
    """``(number, name)`` of the municipality lines (a number and an area) nearest above and below line ``k``."""
    def municipality(r):
        return _seq(r.get("seq")) is not None and str(r.get("area_ha") or "").strip()
    above = next((rows[j] for j in range(k - 1, -1, -1) if municipality(rows[j])), None)
    below = next((rows[j] for j in range(k + 1, len(rows)) if municipality(rows[j])), None)
    return [(_seq(r.get("seq")), str(r.get("name") or "")) for r in (above, below) if r is not None]


def _same_place(name: str, filed: list[str]) -> bool:
    return any(tc._named(tc._pieces(name), tc._pieces(other)) for other in filed)


def _on_page(units, court: str, n: int, page: str) -> bool:
    """The apparatus (a claim or the parts list) holds municipality ``n`` of ``court`` on ``page``."""
    return any(page in place["pages"] for (ck, m, _s), place in units.places.items() if ck == court and m == n)


def reread_rows(run: reg.RunInput, replies: dict) -> tuple[reg.RunInput, list[dict]]:
    """R. The rows ``table_reread`` read from the page bands (D-215). A municipality line (a number
    and its area) enters where exactly one court of the page holds no row with that number and
    that court's parts list names it — or, where no list names it (a municipality without parts:
    Tribischl 14 and Weigensdorf 16 on Czech 0360, Kleinkarlowitz 11 on Mähren 0151), where the
    apparatus holds that number of the court on the page **and** the municipality line next to it
    in the band is the very row that court has filed at *n − 1* or *n + 1*, by name. The number alone
    is not enough: on Mähren 0050 Břeclav and Strážnice both hold a 3 and a 5, and a first version
    filed Břeclav's Kostel 4 and Lundenburg 8 as Strážnice 4 and 8 — with the part lines printed under it (numbered
    1, 2 …, no area). The reader of record's reply is taken; the second reader's agreement (the
    same number, a name in common and the same population) is reported."""
    primary, second = replies.get("gemini38") or [], replies.get("haiku55") or []
    if not primary:
        return run, []
    frame = blocks(run.table)
    units, names = tc.apparatus(run)
    units.lookup = court_lookup(units)
    filed = _filed(units, frame)
    filed_names: dict = {}                       # (court, n) -> the names its table rows print
    for b in frame[frame["n"].notna()].itertuples():
        ck = units.lookup(b.page, int(b.n), b.label)
        if ck:
            filed_names.setdefault((ck, int(b.n)), []).append(b.name)
    theirs: dict = {}
    for band in second:
        for r in band["rows"]:
            if _seq(r.get("seq")) is not None:
                theirs.setdefault((band["page"], _seq(r.get("seq"))), []).append(r)
    position = {i: k for k, i in enumerate(run.table.index)}
    last_on_page: dict = {}
    for b in frame.itertuples():
        last_on_page[b.page] = max(last_on_page.get(b.page, -1), max(position[i] for i in b.rows))
    pieces, done = [], []
    for band in primary:
        page, rows = band["page"], band["rows"]
        courts = sorted({reg.court_key(c, d) for (p, d), c in units.court_of.items() if p == page})
        for k, r in enumerate(rows):
            n, name = _seq(r.get("seq")), str(r.get("name") or "")
            if n is None or not str(r.get("area_ha") or "").strip():
                continue
            fits, how = [c for c in courts if (c, n) not in filed and _names_it(names, c, n, name)], "parts list"
            if not fits:
                beside = _beside(rows, k)
                fits, how = [c for c in courts if (c, n) not in filed and _on_page(units, c, n, page)
                             and any(abs(m - n) == 1 and _same_place(nm, filed_names.get((c, m), []))
                                     for m, nm in beside)], "position"
            if len(fits) != 1:
                continue
            court, block = fits[0], [r]
            for r2 in rows[k + 1:]:
                if _seq(r2.get("seq")) == len(block) and not str(r2.get("area_ha") or "").strip():
                    block.append(r2)
                elif MILITARY.search(str(r2.get("name") or "")):
                    continue
                else:
                    break
            agree = any(tc._named(tc._pieces(name), tc._pieces(s.get("name") or ""))
                        and str(s.get("pop_total")) == str(r.get("pop_total")) for s in theirs.get((page, n), []))
            out = pd.DataFrame([{"channel": "A", "page": page, "block_id": f"{page}#R{n:03d}",
                                 "block_kind": "municipality", "court_label": units.court_cs.get(court, ""),
                                 "row": str(i), **{c: str(x.get(c) or "").strip() for c in COLUMNS}}
                                for i, x in enumerate(block)])
            if "block_kind" not in run.table:        # the Czech table has none: adding it blanked every other row's
                out = out.drop(columns="block_kind")
            pieces.append((last_on_page.get(page, len(run.table) - 1), out))
            filed[(court, n)] = [f"{page}#R{n:03d}"]
            filed_names[(court, n)] = [name]
            done.append({"page": page, "court": court, "seq": n, "name": name, "parts": len(block) - 1,
                         "pop_total": str(r.get("pop_total") or ""), "evidence": how,
                         "second_reader_agrees": agree})
    return replace(run, table=_insert(run.table, pieces)), done


def mend_structure(run: reg.RunInput) -> tuple[reg.RunInput, dict]:
    """Shapes A and B, before the table's courts are read (D-202 needs the totals as totals)."""
    table, totals = numbered_totals(run.table) if run.edition in GERMAN else (run.table, [])
    table, military = military_openings(table) if run.edition in GERMAN else (table, [])
    return replace(run, table=table), {"edition": run.edition, "numbered_totals": totals, "military_openings": military}


def mend_numbers(run: reg.RunInput, report: dict, second: pd.DataFrame | None = None,
                 replies: dict | None = None) -> tuple[reg.RunInput, dict]:
    """After the courts and runs are filed (D-202, D-207), so a row's neighbours carry their court:
    a row under a neighbour's label (G0), the second reader's rows (G) and the page re-read's (R,
    D-215), then the unnumbered rows (C) and the duplicate filings (D–F)."""
    run, labelled = mend_labels(run)
    run, theirs = second_reader(run, second)
    run, reread = reread_rows(run, replies or {})
    run, numbered, left = number_gaps(run)
    run, joined, duplicates = mend_duplicates(run)
    return run, {**report, "labels_mended": labelled, "second_reader": theirs, "reread": reread,
                 "numbered": numbered, "unnumbered_left": left, "duplicates_mended": joined,
                 "duplicates_left": duplicates}


def check(run: reg.RunInput, places: pd.DataFrame | None = None) -> pd.DataFrame:
    """Everything in one volume's table that still breaks the register's reading of it: one row per
    fault, with its kind (:data:`ISSUES`). ``places``: the built register's places, for the
    municipalities with no table row."""
    frame = blocks(run.table)
    units, _names = tc.apparatus(run)
    units.lookup = court_lookup(units)
    out = []
    for k, b in enumerate(frame.itertuples()):
        if b.kind == "summary" and b.n is not None and not TOTAL.search(b.name):
            out.append({"issue": "numbered_total", "page": b.page, "label": b.label, "muni_seq": b.n, "name": b.name})
        elif b.n is None and MILITARY.search(b.name) and b.row1_seq is not None:
            out.append({"issue": "military_opening", "page": b.page, "label": b.label, "muni_seq": b.row1_seq,
                        "name": b.name})
        elif b.n is None and not TOTAL.search(b.name) and (b.kind == "municipality" or _inside(frame, k)):
            out.append({"issue": "unnumbered_row", "page": b.page, "label": b.label, "muni_seq": None, "name": b.name})
    for (ck, n), ids in _filed(units, frame).items():
        if len(ids) > 1:
            pages = frame.set_index("block_id").loc[ids, "page"]
            out.append({"issue": "duplicate_row", "page": ";".join(pages), "label": units.court_cs.get(ck, ""),
                        "court_key": ck, "muni_seq": n, "name": f"{len(ids)} rows"})
    if places is not None and len(places):
        mun = places[(places["edition"] == run.edition) & (places["place_level"] == "municipality")
                     & (places["name_source"] != "table")]
        for p in mun.itertuples():
            out.append({"issue": "missing_row", "page": p.pages, "label": p.court_cs, "court_key": str(p.court_key),
                        "muni_seq": p.muni_seq, "name": p.printed_name})
    frame_out = pd.DataFrame(out, columns=["issue", "page", "label", "court_key", "muni_seq", "name"])
    frame_out["muni_seq"] = pd.array([_seq(m) if m is not None and not pd.isna(m) else None
                                      for m in frame_out["muni_seq"]], dtype="Int64")
    frame_out.insert(0, "edition", run.edition)
    return frame_out


def check_report(faults: pd.DataFrame, claims: pd.DataFrame | None = None) -> dict:
    """Counts by volume and kind, and how many of the missing rows carry institutions."""
    out = {ed: {i: int((g["issue"] == i).sum()) for i in ISSUES} for ed, g in faults.groupby("edition")}
    if claims is not None and len(claims):
        def key(ed, ck, m):
            return ed, str(ck), _seq(str(m).split(".")[0]) if pd.notna(m) else None
        held = {key(e, k, m) for e, k, m in zip(claims["edition"], claims["court_key"], claims["muni_seq"])}
        miss = faults[faults["issue"] == "missing_row"]
        for ed, g in miss.groupby("edition"):
            out[ed]["missing_row_with_institutions"] = int(sum(
                key(ed, ck, m) in held for ck, m in zip(g["court_key"], g["muni_seq"])))
    return out
