How it works

dg_praha Divizní soud Praha NAD 229, pomůcka č. 699 (2024) ldg_praha Zeměbranecký divizní soud Praha NAD 360, pomůcka č. 729 (2025) ldg_brno Zeměbranecký divizní soud – expozitura Brno NAD 356, pomůcka č. 704 (2024)

Each case file is one entry::

2 2//7 14 1/11                                   level, reference, running no., carton
původní signatura: Dst 99/15
RŮŽIČKA Čabo (pěšák, c. a k. pěší pluk č. 35, nar. 1886). 1915
Stručný popis trestného činu: odešel 11. 1. 1915 z posádky bez ohlášení. Po dezerci
následovaly krádeže.
Obžalovací spis i rozsudek.
obecný pojem: dezerce (delikt); krádeže
odkazy na příbuzné dokumenty, archiválie a pomůcky (text): § 183 Militär-Strafgesetzbuch

This module turns that into two tables: one row per entry (case file) and one row per accused — an entry can name a dozen people.

What the text layer does, and how it is handled

  • The Datace column is a separate table cell; pdfplumber appends it to the first line of the accused block (… pěší pluk č. 88, nar. 1914 / 1891). — the 1914 is the date of the file, not a birth year). It is cut off that line by _DATACE, which only matches 1910–1929, so a birth year can never be taken for it.
  • Every page repeats two header lines and ends in its page number. A numeric line is dropped only when a page header follows it, so a wrapped line that happens to be a bare number survives.
  • A file kept in several cartons has no carton of its own; its parts follow as level-3 rows (3 4//86/1 1128 104 / 1. část spisu 1918) and their cartons are collected.
  • The description and the note on what the file holds share one cell. The note opens with one of a handful of formulas (Obžalovací spis…, Šetření ukončeno…, Spisy bez rozsudku…, Řízení…, Rozsudek…); outcome_text starts at the first such line.

What the source does not say

  • Brno lists places without labelling them (civilní osoba, Vlkoš, Kyjov, nar. 1893). The first is read as the birthplace and the rest as the domicile; where the inventory is explicit (Bialystok (Polsko), přísl. Brno) that reading holds, but it is inferred. birthplace_how records which side of nar. the place stood on.
  • Unauthorised absence has no subject term. absence is § 212 of the Militär-Strafgesetzbuch or the wording of the description (_ABSENCE_TEXT: svévolně se vzdálit od svého útvaru, překročit povolenou dovolenku …). That § 212 is eigenmächtige Entfernung is read off the inventories themselves — it is the paragraph cited where a description says "bez úmyslu dezerce" — and has not been checked against the text of the 1855 code; check it before the flag carries a result. The two components are kept apart in absence_par212 / absence_text. work_absence is a different thing: the subject term for militarised labourers who left a mine or a works.
  • Desertion is the subject term dezerce (delikt) or § 183 of the military code, again with both components kept (desertion_term / desertion_par183).
  • Survival is partial: the 1917–18 files were heavily weeded (DG Praha lost roughly two thirds), and these are hinterland courts — men caught at home, not men who crossed the lines.

    with pdfplumber.open(pdf_path) as pdf:

def split_entries(lines: list[str]) -> list[dict]:
    """Cut an inventory into case files.

    Returns one dict per level-2 row: ``year`` (the *Ročník* it stands under), ``ref``,
    ``seq_no``, ``cartons`` (its own and those of its level-3 parts), ``n_parts`` and
    ``body`` — the lines from ``původní signatura`` to the next row, furniture removed.
    """
    lines = _strip_furniture(lines)
    entries: list[dict] = []
    year, cur, started = pd.NA, None, False
    i = 0
    while i < len(lines):
        line = lines[i]
        nxt = lines[i + 1] if i + 1 < len(lines) else ""
        row = _ROW.match(line)
        if started and _REGISTER.match(line):
            break                                        # the indexes follow the last entry
        if row and row["level"] == "1" and "//" not in row["ref"] and _SERIES_TITLE.match(nxt):
            year, cur, started = int(_SERIES_TITLE.match(nxt)[1]), None, True
            i += 2
            continue
        if row and row["level"] == "2" and "//" in row["ref"]:
            cur = {"year": year, "ref": row["ref"], "seq_no": int(row["seq"]),
                   "cartons": [row["store"]] if row["store"] else [], "n_parts": 0,
                   "part_dates": [], "body": []}
            entries.append(cur)
            started = True
        elif row and row["level"] == "3" and cur is not None:
            cur["n_parts"] += 1
            if row["store"]:
                cur["cartons"].append(row["store"])
            m = _DATACE.search(" " + nxt)                # "1. část spisu 1918"
            if m:
                cur["part_dates"].append(m[1])
            i += 1                                       # the part's title line
        elif cur is not None:
            cur["body"].append(line)
        i += 1
    return entries

def parse_paragraphs(text) -> list[tuple[str, str]]:
    """``"§§ 183, 198 Militär-Strafgesetzbuch, § 65 Strafgesetzbuch"`` →
    ``[("183", "MStG"), ("198", "MStG"), ("65", "StG")]``. An unrecognised code is ``"?"``."""
    if not isinstance(text, str) or not text.strip():
        return []
    groups = list(_PARAGRAPH_GROUP.finditer(text))
    out: list[tuple[str, str]] = []
    for k, g in enumerate(groups):
        tail = text[g.end(): groups[k + 1].start() if k + 1 < len(groups) else len(text)]
        code = next((label for pat, label in _CODES if re.search(pat, tail)), None)
        if code is None:                                 # "§ 64, § 65 Strafgesetzbuch"
            rest = text[g.end():]
            code = next((label for pat, label in _CODES if re.search(pat, rest)), "?")
        out += [(n, code) for n in re.findall(r"\d+[a-z]?\b", g[1])]
    return out

    fields: dict[str, list[str]] = {}
    free: list[str] = []

        sig = _SIGNATURE.match(line)
        hit = next((lab for lab in _INDEX_LABELS if line.startswith(lab + ":")), None)
        if sig and signature is pd.NA and not free:
            signature = sig[1].strip() or pd.NA
        elif hit:
            label = hit

            fields[label][-1] = _join([fields[label][-1], line])
        else:
            free.append(line)

def parse_attributes(content) -> dict:
    """The bracket after a name → rank, unit, birth year, places, occupation, status.

    Items are classified by what they say, then by where they stand: a capitalised item is
    a place (birthplace first; in Brno the places come *before* ``nar.``), a lower-case one
    after the places is the occupation, one before them a rank or status.
    """
    a = {"status": None, "rank": [], "unit": [], "birth_year": pd.NA, "birth_raw": pd.NA,
         "pre": [], "post": [], "birth_okres": pd.NA, "domicile": pd.NA,
         "domicile_okres": pd.NA, "occupation": []}
    seen_birth = seen_domicile = False
    for item in _split_items(content if isinstance(content, str) else ""):
        dom, okr = _DOMICILE.match(item), _OKRES.match(item)
        rank_first = bool(_RANK.search(" ".join(item.split()[:2])))
        if _CIVILIAN.match(item) or _POW.search(item):
            a["status"] = "civilian" if _CIVILIAN.match(item) else "pow"
            extra = re.split(r"\s+-\s+", item, maxsplit=1)[1:]         # "civilní osoba - služebná"
            if extra and not _TITLE.match(extra[0]):
                a["rank" if _RANK.search(extra[0]) else "occupation"].append(extra[0])
        elif _BIRTH.match(item) or re.fullmatch(r"1[89]\d\d", item):
            years = _YEAR.findall(item)
            a["birth_raw"], seen_birth = item, True
            a["birth_year"] = int(years[0]) if len(years) == 1 else pd.NA
            place = re.sub(r"^nar\.\s*(?:a přísl\.\s*)?", "", item)
            if not years and place[:1].isupper():                      # "nar. Lány"
                a["post"].append(place)
        elif _SAME_OKRES.match(item):
            a["domicile_okres"] = a["birth_okres"]
        elif okr:
            a["domicile_okres" if seen_domicile else "birth_okres"] = okr[1].strip()
        elif dom:
            seen_domicile = True
            a["domicile"] = "tamtéž" if item.startswith("tamtéž") else dom[1].strip() or pd.NA
        elif item == "tamtéž" or _TITLE.match(item):
            continue                                                   # "same as the last one"
        elif _UNIT.search(item) and (not rank_first or _UNIT_NOUN.search(item)):
            a["unit"].append(item)
        elif item[0].isupper():
            a["post" if seen_birth else "pre"].append(item)
        elif _RANK.search(item) and not (a["post"] or seen_domicile):
            a["rank"].append(item)
        elif seen_birth or a["pre"] or a["status"] == "civilian":
            a["occupation"].append(item)
        else:
            a["rank"].append(item)                                     # status as written
    return _place_attributes(a)

def parse_name(head: str) -> tuple[object, object]:
    """``"ROTENSTERN (pseudonym TESI) Anna"`` → ``("ROTENSTERN/TESI", "Anna")``.

    The surname is the run of capitalised tokens; spelling variants and aliases the
    inventory gives (in brackets, after a slash, after *recte*) are kept in the surname,
    slash-separated, so a name comparison can meet either.
    """
    head = re.sub(r"\s*-\s*recte\s+|\s+alias\s+|,?\s+respektive?\s+", " / ", head)
    head = re.sub(r"\(([^()]*)\)", lambda m: " / " + m[1] + " ", head)
    surnames: list[str] = []
    givens: list[str] = []
    for variant in head.split("/"):
        surname: list[str] = []
        given: list[str] = []
        for tok in re.split(r"[\s,]+", variant):
            word = tok.strip(".;:")
            if not word or _TITLE.match(tok) or word in {"Ritter", "von", "hrabě"}:
                continue
            if _is_caps(word) and "." not in word and not given:
                surname.append(word)
            elif word[:1].isupper():
                given.append(word)                       # given names, initials
        surnames.append(" ".join(surname))
        givens.append(" ".join(given))

    def tidy(parts: list[str]) -> object:
        return "/".join(dict.fromkeys(p for p in parts if p)) or pd.NA
    if not any(surnames) and len(givens) == 1 and len(givens[0].split()) >= 2:
        first, _, rest = givens[0].partition(" ")        # "Dostál Josef": not in capitals
        return first, rest
    return tidy(surnames), tidy(givens)

def split_accused(block) -> tuple[list[dict], object]:
    """An accused block → one dict per named person, plus the note that trails the list
    (``et alii``, ``a spol. - tj. 33 dalších pachatelů``, ``- civilní osoby``)."""
    if not isinstance(block, str) or not block.strip():
        return [], pd.NA
    text = re.sub(r"\s+", " ", block).strip()
    pairs, tail = _scan_groups(text)
    tail = tail.strip(" .,")
    if not pairs and re.search(r",\s*nar\.", tail):                     # opening bracket lost
        name, _, attrs = tail.partition(",")
        pairs, tail = [(name, attrs.rstrip(") "))], ""
    people: list[dict] = []
    group_status = None
    for head, content in pairs:
        lead, colon, rest = head.rpartition(":")         # "a další civilní osoby: VODOVÁ …"
        if colon and _is_caps((rest.split() or [""])[0]):
            head = rest
            group_status = ("civilian" if "civiln" in lead else
                            "pow" if _POW.search(lead) else group_status)
        note = _ET_ALII.search(head)
        if note:
            tail = f"{head[note.start():].strip()} {tail}".strip()
            head = head[:note.start()]
        if not re.search(rf"[{_U}{_L}]{{2}}", re.sub(r"\bresp\.", "", head)):
            nested = split_accused(content)[0] if "(" in content else []
            people += nested                             # "resp. (SCHMIED Josef (…))"
            if not nested:
                tail = f"{tail} ({content})".strip()     # "et alii (mj. Anna Zelenková …)"
            continue
        names = _heads(head)
        attrs = parse_attributes(content)
        attrs["status"] = attrs["status"] or group_status
        for name in names:
            firm = bool(_FIRM.match(name.strip()))
            surname, given = (pd.NA, pd.NA) if firm else parse_name(name)
            people.append({"name_raw": name.strip(), "surname": surname, "given_name": given,
                           **attrs, "attrs_raw": content.strip(),
                           "attrs_shared": len(names) > 1, "is_firm": firm})
    if not people and tail:                              # a list with no bracket at all
        first = tail.split(",")[0]
        named = _is_caps((first.split() or [""])[0])     # not "Vězni na Špilberku - 112 …"

                       **parse_attributes(""), "attrs_raw": "", "attrs_shared": False,
                       "is_firm": bool(_FIRM.match(tail)), "unstructured": True})
        tail = ""
    return people, (tail or pd.NA)

def parse_lines(lines: list[str], court: str) -> tuple[pd.DataFrame, pd.DataFrame]:
    """Parse the printed lines of one inventory.

    Returns ``(entries, persons)``: one row per case file keyed ``entry_id``, one row per
    accused keyed ``person_id``. The offence fields live on the entry — a case file has one
    description and one set of paragraphs however many people it names — and reach a
    person through ``entry_id``.
    """
    if court not in COURTS:
        raise ValueError(f"unknown court {court!r}; expected one of {list(COURTS)}")
    entries, persons = [], []
    for raw in split_entries(lines):
        entry = parse_entry(raw, court)
        rows, note = _person_rows(entry)
        entry["n_accused"] = len(rows)
        entry["accused_note"] = note
        entry["et_alii"] = bool(_ET_ALII.search(entry["accused_block"] or ""))
        entries.append(entry)
        persons.extend(rows)
    E = pd.DataFrame(entries)
    P = pd.DataFrame(persons, columns=_PERSON_COLS)
    for frame, cols in ((E, ["year", "sig_no", "sig_year"]), (P, ["year", "birth_year"])):
        for c in cols:
            if c in frame:
                frame[c] = pd.array(frame[c], dtype="Int64")
    if len(E) and (E["entry_id"].duplicated().any() or P["person_id"].duplicated().any()):
        raise ValueError(f"{court}: entry_id / person_id is not unique")
    return E, P

def habsburg_unit_key(unit) -> object:
    """A Habsburg unit as ``"<arm> <number>"`` (``"IR 28"``, ``"LIR 8"``), or ``<NA>``.

    Reads both the inventories' full Czech (``c. a k. pěší pluk č. 28``) and the csol.cz
    abbreviations (``28.p.pl.``, ``8.zem.p.pl.``), so the two can be compared. Landwehr
    infantry and its 1917 name *Schützenregiment* (``stř.pl.``) share ``LIR``. Only the
    first unit of a list is keyed; a unit with no number has no key.
    """
    if not isinstance(unit, str):
        return pd.NA
    first = re.split(r";|,(?=\s*\d+\s*\.)", unit)[0].lower()
    if "rusk" in first:                                  # a prisoner of war's own regiment
        return pd.NA
    number = re.search(r"\d+", first)
    arm = next((a for a, pat in _UNIT_ARMS if re.search(pat, first)), None)
    return f"{arm} {int(number[0])}" if arm and number else pd.NA

def pilot_link(persons: pd.DataFrame, legion: pd.DataFrame, *, year_shift: int = 0
               ) -> tuple[pd.DataFrame, pd.DataFrame]:
    """Candidate links from the **military** accused to the legionnaire file.

    A candidate is a legionnaire with the **same birth year** whose surname and given name
    both pass :func:`utils.linkage.names_compatible` (the phonetic part-by-part test of the
    cross-dataset linkage, at its uncorroborated surname bar). The Habsburg unit only
    breaks ties: among several candidates, the single one whose capture or peacetime unit
    has the accused's :func:`habsburg_unit_key` is picked.

    ``year_shift`` moves every court birth year by that many years — a placebo that counts
    how many links name and year produce by coincidence alone.

    Returns ``(candidates, picks)``: every candidate pair, and one row per eligible accused
    with ``n_candidates``, ``status`` (``unmatched`` / ``unique`` / ``unit_resolved`` /
    ``ambiguous``) and the picked ``legion_id``. Writes nothing.
    """
    from utils.linkage import names_compatible, phonetic_key

    acc = persons[persons["is_military"] & persons["surname"].notna()
                  & persons["given_name"].notna() & persons["birth_year"].notna()].copy()
    L = legion[legion["surname"].notna() & legion["given_name"].notna()
               & legion["birth_year"].notna()]
    block = (L["birth_year"].astype(int).astype(str) + "|"
             + L["surname"].map(phonetic_key).str[:1])
    blocks = {k: idx for k, idx in L.groupby(block).groups.items()}
    L_keys = pd.DataFrame({c: L[c].map(habsburg_unit_key) for c in
                           ("habsburg_unit_capture", "habsburg_unit_peacetime") if c in L})

    cands = []
    for p in acc.itertuples():
        year = int(p.birth_year) + year_shift
        initials = {phonetic_key(s)[:1] for s in str(p.surname).split("/")} - {""}
        for ini in initials:
            for ix in blocks.get(f"{year}|{ini}", []):
                r = L.loc[ix]
                ok, s, g = names_compatible(p.surname, p.given_name, r["surname"],
                                            r["given_name"])
                if not ok:
                    continue
                keys = set(L_keys.loc[ix].dropna())
                place = {_norm_place(r.get("birth_municipality")),
                         _norm_place(r.get("birth_okres"))} - {""}
                cands.append({
                    "person_id": p.person_id, "legion_id": r["legion_id"],
                    "surname_court": p.surname, "given_court": p.given_name,
                    "surname_legion": r["surname"], "given_legion": r["given_name"],
                    "birth_year": year, "surname_score": round(s, 1),
                    "given_score": round(g, 1), "unit_court": p.unit,
                    "unit_legion": r.get("habsburg_unit_capture"),
                    "unit_agree": (pd.NA if pd.isna(p.unit_key) or not keys
                                   else p.unit_key in keys),
                    "place_agree": (pd.NA if pd.isna(p.birthplace) or not place
                                    else _norm_place(p.birthplace) in place),
                })
    C = pd.DataFrame(cands, columns=[
        "person_id", "legion_id", "surname_court", "given_court", "surname_legion",
        "given_legion", "birth_year", "surname_score", "given_score", "unit_court",
        "unit_legion", "unit_agree", "place_agree"]).drop_duplicates(["person_id", "legion_id"])
    C["legion_id"] = pd.array(C["legion_id"], dtype="Int64")
    for col in ("unit_agree", "place_agree"):
        C[col] = C[col].astype("boolean")
    return C, _resolve_picks(acc, C)

"""
vua_courts.py — the VÚA inventories of three Habsburg military courts, as tables
===============================================================================
The Vojenský historický archiv publishes name-level inventories of three wartime
military courts in the Czech lands as born-digital PDFs (fetched by
``utils/scraping/fetch_vua_courts.py`` into ``data/raw/vua_courts/``):

    dg_praha    Divizní soud Praha                           NAD 229, pomůcka č. 699 (2024)
    ldg_praha   Zeměbranecký divizní soud Praha              NAD 360, pomůcka č. 729 (2025)
    ldg_brno    Zeměbranecký divizní soud – expozitura Brno  NAD 356, pomůcka č. 704 (2024)

Each case file is one entry::

    2 2//7 14 1/11                                   level, reference, running no., carton
    původní signatura: Dst 99/15
    RŮŽIČKA Čabo (pěšák, c. a k. pěší pluk č. 35, nar. 1886). 1915
    Stručný popis trestného činu: odešel 11. 1. 1915 z posádky bez ohlášení. Po dezerci
    následovaly krádeže.
    Obžalovací spis i rozsudek.
    obecný pojem: dezerce (delikt); krádeže
    odkazy na příbuzné dokumenty, archiválie a pomůcky (text): § 183 Militär-Strafgesetzbuch

This module turns that into two tables: one row per **entry** (case file) and one row
per **accused** — an entry can name a dozen people.

What the text layer does, and how it is handled
-----------------------------------------------
* The *Datace* column is a separate table cell; pdfplumber appends it to the **first line
  of the accused block** (``… pěší pluk č. 88, nar. 1914`` / ``1891).`` — the 1914 is the
  date of the file, not a birth year). It is cut off that line by :data:`_DATACE`, which
  only matches 1910–1929, so a birth year can never be taken for it.
* Every page repeats two header lines and ends in its page number. A numeric line is
  dropped only when a page header follows it, so a wrapped line that happens to be a bare
  number survives.
* A file kept in several cartons has no carton of its own; its parts follow as level-3
  rows (``3 4//86/1 1128 104`` / ``1. část spisu 1918``) and their cartons are collected.
* The description and the note on what the file holds share one cell. The note opens with
  one of a handful of formulas (*Obžalovací spis…*, *Šetření ukončeno…*, *Spisy bez
  rozsudku…*, *Řízení…*, *Rozsudek…*); ``outcome_text`` starts at the first such line.

What the source does not say
----------------------------
* **Brno lists places without labelling them** (``civilní osoba, Vlkoš, Kyjov, nar. 1893``).
  The first is read as the birthplace and the rest as the domicile; where the inventory is
  explicit (``Bialystok (Polsko), přísl. Brno``) that reading holds, but it is inferred.
  ``birthplace_how`` records which side of ``nar.`` the place stood on.
* **Unauthorised absence has no subject term.** ``absence`` is § 212 of the
  *Militär-Strafgesetzbuch* **or** the wording of the description (:data:`_ABSENCE_TEXT`:
  *svévolně se vzdálit od svého útvaru*, *překročit povolenou dovolenku* …). That § 212 is
  *eigenmächtige Entfernung* is read off the inventories themselves — it is the paragraph
  cited where a description says "bez úmyslu dezerce" — and has **not** been checked against
  the text of the 1855 code; check it before the flag carries a result. The two components
  are kept apart in ``absence_par212`` / ``absence_text``. ``work_absence`` is a different
  thing: the subject term for militarised labourers who left a mine or a works.
* **Desertion** is the subject term ``dezerce (delikt)`` **or** § 183 of the military code,
  again with both components kept (``desertion_term`` / ``desertion_par183``).
* Survival is partial: the 1917–18 files were heavily weeded (DG Praha lost roughly two
  thirds), and these are hinterland courts — men caught at home, not men who crossed the
  lines.

Usage
-----
    from utils.parsing import vua_courts as vc
    entries, persons = vc.parse_all()            # reads data/raw/vua_courts/*.pdf
    vc.courts_report(entries, persons)
    cands, picks = vc.pilot_link(persons, legion_df)
    vc.pilot_link_report(cands, picks, persons)
"""

def _is_caps(token: str) -> bool:
    """True for a token written in capitals (a surname): at least two letters, all upper."""
    letters = [c for c in token if c.isalpha()]
    return len(letters) >= 2 and all(c.isupper() for c in letters)


def _join(lines: list[str]) -> str:
    """Join wrapped lines; a word hyphenated at the line end is closed up again."""
    out = ""
    for line in (ln.strip() for ln in lines):
        if not line:
            continue
        if out and re.search(r"\w-$", out) and line[0].isalpha():
            out += line
        else:
            out += (" " if out else "") + line
    return re.sub(r"\s+", " ", out).strip()


# ── Reading the PDF ───────────────────────────────────────────────────────────

def read_inventory_lines(pdf_path: Path) -> list[str]:
    """The text layer of one inventory, one string per printed line, pages in order."""
    import pdfplumber
    lines: list[str] = []
    with pdfplumber.open(pdf_path) as pdf:
        for page in pdf.pages:
            lines.extend((page.extract_text() or "").split("\n"))
    return lines


def _strip_furniture(lines: list[str]) -> list[str]:
    """Drop the page headers and the page number that precedes each of them."""
    keep: list[str] = []
    for i, raw in enumerate(lines):
        line = raw.strip()
        if not line or _PAGE_HEADER.match(line):
            continue
        nxt = lines[i + 1].strip() if i + 1 < len(lines) else ""
        if line.isdigit() and (_PAGE_HEADER.match(nxt) or _REGISTER.match(nxt) or not nxt):
            continue
        keep.append(line)
    return keep


# ── Entries ───────────────────────────────────────────────────────────────────

def split_entries(lines: list[str]) -> list[dict]:
    """Cut an inventory into case files.

    Returns one dict per level-2 row: ``year`` (the *Ročník* it stands under), ``ref``,
    ``seq_no``, ``cartons`` (its own and those of its level-3 parts), ``n_parts`` and
    ``body`` — the lines from ``původní signatura`` to the next row, furniture removed.
    """
    lines = _strip_furniture(lines)
    entries: list[dict] = []
    year, cur, started = pd.NA, None, False
    i = 0
    while i < len(lines):
        line = lines[i]
        nxt = lines[i + 1] if i + 1 < len(lines) else ""
        row = _ROW.match(line)
        if started and _REGISTER.match(line):
            break                                        # the indexes follow the last entry
        if row and row["level"] == "1" and "//" not in row["ref"] and _SERIES_TITLE.match(nxt):
            year, cur, started = int(_SERIES_TITLE.match(nxt)[1]), None, True
            i += 2
            continue
        if row and row["level"] == "2" and "//" in row["ref"]:
            cur = {"year": year, "ref": row["ref"], "seq_no": int(row["seq"]),
                   "cartons": [row["store"]] if row["store"] else [], "n_parts": 0,
                   "part_dates": [], "body": []}
            entries.append(cur)
            started = True
        elif row and row["level"] == "3" and cur is not None:
            cur["n_parts"] += 1
            if row["store"]:
                cur["cartons"].append(row["store"])
            m = _DATACE.search(" " + nxt)                # "1. část spisu 1918"
            if m:
                cur["part_dates"].append(m[1])
            i += 1                                       # the part's title line
        elif cur is not None:
            cur["body"].append(line)
        i += 1
    return entries


def parse_paragraphs(text) -> list[tuple[str, str]]:
    """``"§§ 183, 198 Militär-Strafgesetzbuch, § 65 Strafgesetzbuch"`` →
    ``[("183", "MStG"), ("198", "MStG"), ("65", "StG")]``. An unrecognised code is ``"?"``."""
    if not isinstance(text, str) or not text.strip():
        return []
    groups = list(_PARAGRAPH_GROUP.finditer(text))
    out: list[tuple[str, str]] = []
    for k, g in enumerate(groups):
        tail = text[g.end(): groups[k + 1].start() if k + 1 < len(groups) else len(text)]
        code = next((label for pat, label in _CODES if re.search(pat, tail)), None)
        if code is None:                                 # "§ 64, § 65 Strafgesetzbuch"
            rest = text[g.end():]
            code = next((label for pat, label in _CODES if re.search(pat, rest)), "?")
        out += [(n, code) for n in re.findall(r"\d+[a-z]?\b", g[1])]
    return out


def _split_description(lines: list[str]) -> tuple[str, object, object]:
    """``(offence_text, outcome_text, languages)`` from the lines of the description cell."""
    lines = list(lines)
    languages = pd.NA
    while len(lines) > 1 and _LANGUAGES.match(lines[-1]):
        languages = lines.pop() if languages is pd.NA else f"{lines.pop()}, {languages}"
    for k in range(1, len(lines)):
        if _OUTCOME_STRONG.match(lines[k]) or (_TERMINAL.search(lines[k - 1])
                                               and _OUTCOME_OPENER.match(lines[k])):
            return _join(lines[:k]), _join(lines[k:]), languages
    text = _join(lines)
    m = _OUTCOME_INLINE.search(text)
    if m:
        return text[:m.start()].strip(), text[m.start():].strip(), languages
    return text, pd.NA, languages


def parse_entry(raw: dict, court: str) -> dict:
    """One case file → its entry-level fields (the accused are in ``accused_block``)."""
    body = raw["body"]
    signature, datace = pd.NA, pd.NA
    fields: dict[str, list[str]] = {}
    free: list[str] = []
    label = None
    for line in body:
        sig = _SIGNATURE.match(line)
        hit = next((lab for lab in _INDEX_LABELS if line.startswith(lab + ":")), None)
        if sig and signature is pd.NA and not free:
            signature = sig[1].strip() or pd.NA
        elif hit:
            label = hit
            fields.setdefault(hit, []).append(line[len(hit) + 1:].strip())
        elif label:
            fields[label][-1] = _join([fields[label][-1], line])
        else:
            free.append(line)
    if free:
        m = _DATACE.search(free[0])
        if m:
            datace, free[0] = m[1], free[0][:m.start()]
    if datace is pd.NA and raw["part_dates"]:
        datace = "; ".join(dict.fromkeys(raw["part_dates"]))

    at = next((k for k, ln in enumerate(free) if _DESCRIPTION.search(ln)), None)
    if at is None:
        accused, offence, outcome, languages = _join(free), pd.NA, pd.NA, pd.NA
    else:
        m = _DESCRIPTION.search(free[at])
        accused = _join(free[:at] + [free[at][:m.start()]])
        offence, outcome, languages = _split_description([free[at][m.end():]] + free[at + 1:])

    terms = [t.strip() for t in "; ".join(fields.get("obecný pojem", [])).split(";") if t.strip()]
    par_raw = "; ".join(fields.get(_PARAGRAPH_LABEL, []))
    pars = parse_paragraphs(par_raw)
    sig_m = _SIG_PARTS.search(signature) if isinstance(signature, str) else None
    offence_s = offence if isinstance(offence, str) else ""
    desertion_term = DESERTION_TERM in terms
    desertion_par = DESERTION_PARAGRAPH in pars
    absence_par = ABSENCE_PARAGRAPH in pars
    absence_text = bool(_ABSENCE_TEXT.search(offence_s))
    return {
        "entry_id": f"{court}:{raw['seq_no']}", "court": court, "court_name": COURTS[court][1],
        "year": raw["year"], "seq_no": raw["seq_no"], "ref": raw["ref"],
        "signature": signature,
        "sig_no": int(sig_m[1]) if sig_m else pd.NA,
        "sig_year": 1900 + int(sig_m[2]) if sig_m else pd.NA,
        "carton": "; ".join(dict.fromkeys(raw["cartons"])) or pd.NA,
        "n_parts": raw["n_parts"], "datace": datace,
        "accused_block": accused, "offence_text": offence, "outcome_text": outcome,
        "languages": languages,
        "subject_terms": "; ".join(terms) or pd.NA,
        "persons_indexed": "; ".join(fields.get("osoba/bytost", []) + fields.get("osoby", []))
                           or pd.NA,
        "geo_terms": "; ".join(fields.get("geografický objekt", [])) or pd.NA,
        "paragraphs_raw": par_raw or pd.NA,
        "paragraphs": "; ".join(dict.fromkeys(f"{n} {c}" for n, c in pars)) or pd.NA,
        "desertion": desertion_term or desertion_par,
        "desertion_term": desertion_term, "desertion_par183": desertion_par,
        "absence": absence_par or absence_text,
        "absence_par212": absence_par, "absence_text": absence_text,
        "work_absence": any(t in terms for t in WORK_ABSENCE_TERMS),
    }


# ── The accused ───────────────────────────────────────────────────────────────

def _scan_groups(text: str) -> tuple[list[tuple[str, str]], str]:
    """Cut an accused block into ``(head, bracket content)`` pairs and the trailing text.

    Brackets nest (``polní dělostřelecký (kanónový) pluk``). A bracket set between a bare
    surname and the given name is an alias and stays in the head
    (``ROTENSTERN (pseudonym TESI) Anna (…)``); a bracket never closed ends where the next
    accused begins.
    """
    pairs: list[tuple[str, str]] = []
    pos, head_from = 0, 0
    while True:
        op = text.find("(", pos)
        if op == -1:
            return pairs, text[head_from:]
        depth, close = 0, len(text)
        for j in range(op, len(text)):
            depth += (text[j] == "(") - (text[j] == ")")
            if depth == 0:
                close = j
                break
        content, after = text[op + 1:close], close + 1
        cut = _NEW_PERSON.search(content)
        if cut:
            content, after = content[:cut.start()], op + 1 + cut.start()
        head = text[head_from:op]
        rest = text[after:]
        glued = bool(rest) and rest[0].isalpha()                       # RAKOV(W)ITZ
        words = [w for w in re.split(r"[\s,;]+", head) if any(c.isalpha() for c in w)]
        bare_surname = bool(words) and _is_caps(words[-1]) and not cut
        if glued or (bare_surname and re.match(rf"\s*[{_U}][{_L}]+\b", rest)
                     and "nar." not in content):
            pos = after                                                # alias: keep scanning
            continue
        pairs.append((head, content))
        pos = head_from = after


def _split_items(content: str) -> list[str]:
    """Split a bracket's content on its top-level commas and semicolons."""
    items, depth, cur = [], 0, ""
    for ch in content:
        depth += (ch in "([") - (ch in ")]")
        if ch in ",;" and depth <= 0:
            items.append(cur)
            cur = ""
        else:
            cur += ch
    items.append(cur)
    return [it.strip(" .") for it in items if it.strip(" .")]


def parse_attributes(content) -> dict:
    """The bracket after a name → rank, unit, birth year, places, occupation, status.

    Items are classified by what they say, then by where they stand: a capitalised item is
    a place (birthplace first; in Brno the places come *before* ``nar.``), a lower-case one
    after the places is the occupation, one before them a rank or status.
    """
    a = {"status": None, "rank": [], "unit": [], "birth_year": pd.NA, "birth_raw": pd.NA,
         "pre": [], "post": [], "birth_okres": pd.NA, "domicile": pd.NA,
         "domicile_okres": pd.NA, "occupation": []}
    seen_birth = seen_domicile = False
    for item in _split_items(content if isinstance(content, str) else ""):
        dom, okr = _DOMICILE.match(item), _OKRES.match(item)
        rank_first = bool(_RANK.search(" ".join(item.split()[:2])))
        if _CIVILIAN.match(item) or _POW.search(item):
            a["status"] = "civilian" if _CIVILIAN.match(item) else "pow"
            extra = re.split(r"\s+-\s+", item, maxsplit=1)[1:]         # "civilní osoba - služebná"
            if extra and not _TITLE.match(extra[0]):
                a["rank" if _RANK.search(extra[0]) else "occupation"].append(extra[0])
        elif _BIRTH.match(item) or re.fullmatch(r"1[89]\d\d", item):
            years = _YEAR.findall(item)
            a["birth_raw"], seen_birth = item, True
            a["birth_year"] = int(years[0]) if len(years) == 1 else pd.NA
            place = re.sub(r"^nar\.\s*(?:a přísl\.\s*)?", "", item)
            if not years and place[:1].isupper():                      # "nar. Lány"
                a["post"].append(place)
        elif _SAME_OKRES.match(item):
            a["domicile_okres"] = a["birth_okres"]
        elif okr:
            a["domicile_okres" if seen_domicile else "birth_okres"] = okr[1].strip()
        elif dom:
            seen_domicile = True
            a["domicile"] = "tamtéž" if item.startswith("tamtéž") else dom[1].strip() or pd.NA
        elif item == "tamtéž" or _TITLE.match(item):
            continue                                                   # "same as the last one"
        elif _UNIT.search(item) and (not rank_first or _UNIT_NOUN.search(item)):
            a["unit"].append(item)
        elif item[0].isupper():
            a["post" if seen_birth else "pre"].append(item)
        elif _RANK.search(item) and not (a["post"] or seen_domicile):
            a["rank"].append(item)
        elif seen_birth or a["pre"] or a["status"] == "civilian":
            a["occupation"].append(item)
        else:
            a["rank"].append(item)                                     # status as written
    return _place_attributes(a)


def _place_attributes(a: dict) -> dict:
    """Decide which of the place items is the birthplace (see :func:`parse_attributes`)."""
    if a["post"]:
        places, how, rest = a["post"], "after_nar", a["pre"]
    else:
        places, how, rest = a["pre"][:1], "before_nar" if a["pre"] else pd.NA, a["pre"][1:]
    birthplace = places[0] if places else pd.NA
    extra = ", ".join(places[1:]) or pd.NA
    domicile = a["domicile"]
    if isinstance(domicile, str) and domicile.startswith("tamtéž"):
        domicile = birthplace
        if pd.isna(a["domicile_okres"]):
            a["domicile_okres"] = a["birth_okres"]
    elif pd.isna(domicile) and rest and how == "before_nar":
        domicile = ", ".join(rest)
    return {
        "status": a["status"], "rank": ", ".join(a["rank"]) or pd.NA,
        "unit": "; ".join(a["unit"]) or pd.NA,
        "birth_year": a["birth_year"], "birth_raw": a["birth_raw"],
        "birthplace": birthplace, "birthplace_extra": extra, "birthplace_how": how,
        "birth_okres": a["birth_okres"], "domicile": domicile,
        "domicile_okres": a["domicile_okres"],
        "occupation": ", ".join(a["occupation"]) or pd.NA,
    }


def parse_name(head: str) -> tuple[object, object]:
    """``"ROTENSTERN (pseudonym TESI) Anna"`` → ``("ROTENSTERN/TESI", "Anna")``.

    The surname is the run of capitalised tokens; spelling variants and aliases the
    inventory gives (in brackets, after a slash, after *recte*) are kept in the surname,
    slash-separated, so a name comparison can meet either.
    """
    head = re.sub(r"\s*-\s*recte\s+|\s+alias\s+|,?\s+respektive?\s+", " / ", head)
    head = re.sub(r"\(([^()]*)\)", lambda m: " / " + m[1] + " ", head)
    surnames: list[str] = []
    givens: list[str] = []
    for variant in head.split("/"):
        surname: list[str] = []
        given: list[str] = []
        for tok in re.split(r"[\s,]+", variant):
            word = tok.strip(".;:")
            if not word or _TITLE.match(tok) or word in {"Ritter", "von", "hrabě"}:
                continue
            if _is_caps(word) and "." not in word and not given:
                surname.append(word)
            elif word[:1].isupper():
                given.append(word)                       # given names, initials
        surnames.append(" ".join(surname))
        givens.append(" ".join(given))

    def tidy(parts: list[str]) -> object:
        return "/".join(dict.fromkeys(p for p in parts if p)) or pd.NA
    if not any(surnames) and len(givens) == 1 and len(givens[0].split()) >= 2:
        first, _, rest = givens[0].partition(" ")        # "Dostál Josef": not in capitals
        return first, rest
    return tidy(surnames), tidy(givens)


def _heads(head: str) -> list[str]:
    """Split a head naming several people who share one bracket (``A Jan, B Karel (…)``)."""
    head = re.sub(r"^[\s,;.]+|\s+$", "", head)
    head = re.sub(r"^(?:a|et|resp\.|podezřív\w+)\s+", "", head)
    pieces = [p.strip() for p in re.split(r",\s+|;\s+|\s+a\s+", head) if p.strip()]
    if len(pieces) > 1 and all(_is_caps(p.split()[0].strip(".")) and len(p.split()) > 1
                               for p in pieces):
        return pieces
    return [head]


def split_accused(block) -> tuple[list[dict], object]:
    """An accused block → one dict per named person, plus the note that trails the list
    (``et alii``, ``a spol. - tj. 33 dalších pachatelů``, ``- civilní osoby``)."""
    if not isinstance(block, str) or not block.strip():
        return [], pd.NA
    text = re.sub(r"\s+", " ", block).strip()
    pairs, tail = _scan_groups(text)
    tail = tail.strip(" .,")
    if not pairs and re.search(r",\s*nar\.", tail):                     # opening bracket lost
        name, _, attrs = tail.partition(",")
        pairs, tail = [(name, attrs.rstrip(") "))], ""
    people: list[dict] = []
    group_status = None
    for head, content in pairs:
        lead, colon, rest = head.rpartition(":")         # "a další civilní osoby: VODOVÁ …"
        if colon and _is_caps((rest.split() or [""])[0]):
            head = rest
            group_status = ("civilian" if "civiln" in lead else
                            "pow" if _POW.search(lead) else group_status)
        note = _ET_ALII.search(head)
        if note:
            tail = f"{head[note.start():].strip()} {tail}".strip()
            head = head[:note.start()]
        if not re.search(rf"[{_U}{_L}]{{2}}", re.sub(r"\bresp\.", "", head)):
            nested = split_accused(content)[0] if "(" in content else []
            people += nested                             # "resp. (SCHMIED Josef (…))"
            if not nested:
                tail = f"{tail} ({content})".strip()     # "et alii (mj. Anna Zelenková …)"
            continue
        names = _heads(head)
        attrs = parse_attributes(content)
        attrs["status"] = attrs["status"] or group_status
        for name in names:
            firm = bool(_FIRM.match(name.strip()))
            surname, given = (pd.NA, pd.NA) if firm else parse_name(name)
            people.append({"name_raw": name.strip(), "surname": surname, "given_name": given,
                           **attrs, "attrs_raw": content.strip(),
                           "attrs_shared": len(names) > 1, "is_firm": firm})
    if not people and tail:                              # a list with no bracket at all
        first = tail.split(",")[0]
        named = _is_caps((first.split() or [""])[0])     # not "Vězni na Špilberku - 112 …"
        surname, given = parse_name(first) if named else (pd.NA, pd.NA)
        people.append({"name_raw": tail, "surname": surname, "given_name": given,
                       **parse_attributes(""), "attrs_raw": "", "attrs_shared": False,
                       "is_firm": bool(_FIRM.match(tail)), "unstructured": True})
        tail = ""
    return people, (tail or pd.NA)


def _accused_type(p: dict, note) -> str:
    """``military`` / ``civilian`` / ``pow`` / ``firm`` / ``unknown`` for one accused."""
    note = note if isinstance(note, str) else ""
    if p.get("is_firm"):
        return "firm"
    if p["status"]:
        return p["status"]
    if _POW.search(note):
        return "pow"
    if isinstance(p["rank"], str) or isinstance(p["unit"], str):
        return "military"
    if re.search(r"civiln\w+ osob", note):
        return "civilian"
    if _ALL_OF_THEM.search(note) and (_RANK.search(note) or _UNIT.search(note)):
        return "military"
    return "unknown"


def _person_rows(entry: dict) -> tuple[list[dict], object]:
    """The accused of one entry as rows keyed ``person_id`` = ``entry_id:person_no``."""
    people, note = split_accused(entry["accused_block"])
    rows = []
    for k, p in enumerate(people, 1):
        if entry["court"] in _PLACE_IS_POSTING and str(p["birthplace_how"]) == "before_nar":
            p["unit"] = "; ".join(x for x in (p["unit"], p["birthplace"]) if isinstance(x, str))
            p["birthplace"] = p["birthplace_how"] = pd.NA
        kind = _accused_type(p, note)
        named = kind != "firm"                           # a firm has no surname to miss
        flags = [f for f, on in (("unstructured", p.get("unstructured")),
                                 ("no_surname", named and pd.isna(p["surname"])),
                                 ("no_given_name", named and pd.isna(p["given_name"]))) if on]
        rows.append({
            "person_id": f"{entry['entry_id']}:{k}", "entry_id": entry["entry_id"],
            "court": entry["court"], "year": entry["year"], "person_no": k,
            "n_accused": len(people), **{c: p.get(c, pd.NA) for c in _PERSON_COLS[6:9]},
            "accused_type": kind, "is_military": kind == "military",
            "is_civilian": kind == "civilian", "rank": p["rank"], "unit": p["unit"],
            "unit_key": habsburg_unit_key(p["unit"]),
            **{c: p[c] for c in _PERSON_COLS[15:24]},
            "attrs_raw": p["attrs_raw"], "attrs_shared": p["attrs_shared"],
            "parse_flag": "; ".join(flags) or pd.NA,
        })
    return rows, note

def parse_lines(lines: list[str], court: str) -> tuple[pd.DataFrame, pd.DataFrame]:
    """Parse the printed lines of one inventory.

    Returns ``(entries, persons)``: one row per case file keyed ``entry_id``, one row per
    accused keyed ``person_id``. The offence fields live on the entry — a case file has one
    description and one set of paragraphs however many people it names — and reach a
    person through ``entry_id``.
    """
    if court not in COURTS:
        raise ValueError(f"unknown court {court!r}; expected one of {list(COURTS)}")
    entries, persons = [], []
    for raw in split_entries(lines):
        entry = parse_entry(raw, court)
        rows, note = _person_rows(entry)
        entry["n_accused"] = len(rows)
        entry["accused_note"] = note
        entry["et_alii"] = bool(_ET_ALII.search(entry["accused_block"] or ""))
        entries.append(entry)
        persons.extend(rows)
    E = pd.DataFrame(entries)
    P = pd.DataFrame(persons, columns=_PERSON_COLS)
    for frame, cols in ((E, ["year", "sig_no", "sig_year"]), (P, ["year", "birth_year"])):
        for c in cols:
            if c in frame:
                frame[c] = pd.array(frame[c], dtype="Int64")
    if len(E) and (E["entry_id"].duplicated().any() or P["person_id"].duplicated().any()):
        raise ValueError(f"{court}: entry_id / person_id is not unique")
    return E, P


def parse_inventory(pdf_path: Path, court: str) -> tuple[pd.DataFrame, pd.DataFrame]:
    """Parse one inventory PDF (see :func:`parse_lines`)."""
    return parse_lines(read_inventory_lines(pdf_path), court)


def parse_all(raw_dir: Path = RAW_DIR) -> tuple[pd.DataFrame, pd.DataFrame]:
    """Parse the three inventories in *raw_dir* and stack them."""
    parts = []
    for court, (name, _) in COURTS.items():
        path = Path(raw_dir) / name
        if not path.exists():
            raise FileNotFoundError(f"{path} — run utils/scraping/fetch_vua_courts.py first")
        parts.append(parse_inventory(path, court))
    entries = pd.concat([e for e, _ in parts], ignore_index=True)
    persons = pd.concat([p for _, p in parts], ignore_index=True)
    return entries, persons

# arm of service → the stems that name it, court spelling and csol abbreviation alike;
# the first arm whose pattern matches wins, so the specific arms stand before "pěší".
_UNIT_ARMS: tuple[tuple[str, str], ...] = (
    ("HIR", r"honv"),
    ("LST", r"domobran|\bdom\."),
    ("LIR", r"zeměbran|\bzem\.|\bstř\.|střeleck|\bzp\b|\bz\.pl"),
    ("FJB", r"mysliv|\bmys"),
    ("CAV", r"jezdeck|dragoun|\bdrag|hulán|\bhul\.|husar|\bhus\.|\bjízd"),
    ("ART", r"dělostřel|\bděl\.|houfnic"),
    ("SAP", r"zákop"),
    ("IR", r"pěší pluk|\bp\.\s?pl|\bpp\b|\bIR\b"),
)


def habsburg_unit_key(unit) -> object:
    """A Habsburg unit as ``"<arm> <number>"`` (``"IR 28"``, ``"LIR 8"``), or ``<NA>``.

    Reads both the inventories' full Czech (``c. a k. pěší pluk č. 28``) and the csol.cz
    abbreviations (``28.p.pl.``, ``8.zem.p.pl.``), so the two can be compared. Landwehr
    infantry and its 1917 name *Schützenregiment* (``stř.pl.``) share ``LIR``. Only the
    first unit of a list is keyed; a unit with no number has no key.
    """
    if not isinstance(unit, str):
        return pd.NA
    first = re.split(r";|,(?=\s*\d+\s*\.)", unit)[0].lower()
    if "rusk" in first:                                  # a prisoner of war's own regiment
        return pd.NA
    number = re.search(r"\d+", first)
    arm = next((a for a, pat in _UNIT_ARMS if re.search(pat, first)), None)
    return f"{arm} {int(number[0])}" if arm and number else pd.NA


def _norm_place(v) -> str:
    from utils.linkage import _norm_okres
    return re.sub(r"\s*\(.*?\)|\s+-\s+.*$", "", _norm_okres(v)).strip()


def pilot_link(persons: pd.DataFrame, legion: pd.DataFrame, *, year_shift: int = 0
               ) -> tuple[pd.DataFrame, pd.DataFrame]:
    """Candidate links from the **military** accused to the legionnaire file.

    A candidate is a legionnaire with the **same birth year** whose surname and given name
    both pass :func:`utils.linkage.names_compatible` (the phonetic part-by-part test of the
    cross-dataset linkage, at its uncorroborated surname bar). The Habsburg unit only
    breaks ties: among several candidates, the single one whose capture or peacetime unit
    has the accused's :func:`habsburg_unit_key` is picked.

    ``year_shift`` moves every court birth year by that many years — a placebo that counts
    how many links name and year produce by coincidence alone.

    Returns ``(candidates, picks)``: every candidate pair, and one row per eligible accused
    with ``n_candidates``, ``status`` (``unmatched`` / ``unique`` / ``unit_resolved`` /
    ``ambiguous``) and the picked ``legion_id``. Writes nothing.
    """
    from utils.linkage import names_compatible, phonetic_key

    acc = persons[persons["is_military"] & persons["surname"].notna()
                  & persons["given_name"].notna() & persons["birth_year"].notna()].copy()
    L = legion[legion["surname"].notna() & legion["given_name"].notna()
               & legion["birth_year"].notna()]
    block = (L["birth_year"].astype(int).astype(str) + "|"
             + L["surname"].map(phonetic_key).str[:1])
    blocks = {k: idx for k, idx in L.groupby(block).groups.items()}
    L_keys = pd.DataFrame({c: L[c].map(habsburg_unit_key) for c in
                           ("habsburg_unit_capture", "habsburg_unit_peacetime") if c in L})

    cands = []
    for p in acc.itertuples():
        year = int(p.birth_year) + year_shift
        initials = {phonetic_key(s)[:1] for s in str(p.surname).split("/")} - {""}
        for ini in initials:
            for ix in blocks.get(f"{year}|{ini}", []):
                r = L.loc[ix]
                ok, s, g = names_compatible(p.surname, p.given_name, r["surname"],
                                            r["given_name"])
                if not ok:
                    continue
                keys = set(L_keys.loc[ix].dropna())
                place = {_norm_place(r.get("birth_municipality")),
                         _norm_place(r.get("birth_okres"))} - {""}
                cands.append({
                    "person_id": p.person_id, "legion_id": r["legion_id"],
                    "surname_court": p.surname, "given_court": p.given_name,
                    "surname_legion": r["surname"], "given_legion": r["given_name"],
                    "birth_year": year, "surname_score": round(s, 1),
                    "given_score": round(g, 1), "unit_court": p.unit,
                    "unit_legion": r.get("habsburg_unit_capture"),
                    "unit_agree": (pd.NA if pd.isna(p.unit_key) or not keys
                                   else p.unit_key in keys),
                    "place_agree": (pd.NA if pd.isna(p.birthplace) or not place
                                    else _norm_place(p.birthplace) in place),
                })
    C = pd.DataFrame(cands, columns=[
        "person_id", "legion_id", "surname_court", "given_court", "surname_legion",
        "given_legion", "birth_year", "surname_score", "given_score", "unit_court",
        "unit_legion", "unit_agree", "place_agree"]).drop_duplicates(["person_id", "legion_id"])
    C["legion_id"] = pd.array(C["legion_id"], dtype="Int64")
    for col in ("unit_agree", "place_agree"):
        C[col] = C[col].astype("boolean")
    return C, _resolve_picks(acc, C)


def _resolve_picks(acc: pd.DataFrame, C: pd.DataFrame) -> pd.DataFrame:
    """One row per eligible accused: how many candidates, and which one (if any) is picked."""
    rows = []
    by_person = dict(tuple(C.groupby("person_id")))
    for pid in acc["person_id"]:
        g = by_person.get(pid)
        n = 0 if g is None else len(g)
        pick, status = pd.NA, "unmatched"
        if n == 1:
            pick, status = g["legion_id"].iloc[0], "unique"
        elif n > 1:
            agree = g[g["unit_agree"].fillna(False).astype(bool)]
            status = "unit_resolved" if len(agree) == 1 else "ambiguous"
            pick = agree["legion_id"].iloc[0] if len(agree) == 1 else pd.NA
        rows.append({"person_id": pid, "n_candidates": n, "status": status,
                     "legion_id": pick})
    picks = pd.DataFrame(rows, columns=["person_id", "n_candidates", "status", "legion_id"])
    picks["legion_id"] = pd.array(picks["legion_id"], dtype="Int64")
    n_before = len(picks)
    picks = picks.merge(C[["person_id", "legion_id", "unit_agree", "place_agree"]],
                        on=["person_id", "legion_id"], how="left", validate="1:1")
    assert len(picks) == n_before, "evidence merge changed the row count"
    claims = picks["legion_id"].map(picks["legion_id"].value_counts())
    picks["one_to_one"] = picks["legion_id"].notna() & (claims == 1)
    return picks


def pilot_link_report(cands: pd.DataFrame, picks: pd.DataFrame, persons: pd.DataFrame,
                      entries: pd.DataFrame | None = None, label: str = "") -> None:
    """Print the pilot-link counts: eligible, candidates, one-to-one, ambiguous."""
    n_mil = int(persons["is_military"].sum())
    status = picks["status"].value_counts()
    picked = picks[picks["legion_id"].notna()]
    print(f"Pilot link — military accused → legionnaires{label}")
    print(f"  military accused                     : {n_mil:>6,}")
    print(f"  eligible (name + birth year)         : {len(picks):>6,}")
    print(f"  candidate pairs (name + birth year)  : {len(cands):>6,}")
    print(f"  accused with at least one candidate  : {int((picks['n_candidates'] > 0).sum()):>6,}")
    for s, text in (("unique", "exactly one candidate"),
                    ("unit_resolved", "several, one picked by the unit"),
                    ("ambiguous", "several, unit does not decide"),
                    ("unmatched", "no candidate")):
        print(f"    {text:<35}: {int(status.get(s, 0)):>6,}")
    print(f"  picked (unique + unit_resolved)      : {len(picked):>6,}")
    print(f"    one-to-one (legionnaire picked once): {int(picked['one_to_one'].sum()):>6,}")
    print(f"    legionnaire picked by >1 accused    : {int((~picked['one_to_one']).sum()):>6,}"
          "   (one man in two files, or a coincidence)")
    for col, text in (("unit_agree", "Habsburg unit"), ("place_agree", "birthplace")):
        v = picked[col].astype("boolean")
        print(f"    {text:<13} agrees / differs / not comparable: "
              f"{int(v.fillna(False).sum())} / {int((~v).fillna(False).sum())} / "
              f"{int(v.isna().sum())}")
    if entries is not None and len(picked):
        flags = persons[["person_id", "entry_id", "court"]].merge(
            entries[["entry_id", "desertion", "absence"]], on="entry_id", how="left",
            validate="m:1")
        got = picked.merge(flags, on="person_id", how="left", validate="1:1")
        assert len(got) == len(picked), "pick merge changed the row count"
        print("  picked, by court                     : "
              + ", ".join(f"{k} {v}" for k, v in got["court"].value_counts().items()))
        print(f"  picked, in a desertion / absence file: {int(got['desertion'].sum())} / "
              f"{int(got['absence'].sum())}")
