How it works

The eleven statutory cities print their institutions as prose, not pictograms, so the register has no row for them in register_municipalities and an okres aggregate built from it is missing for their okresy (D-178). Their prose is read into register_statutory (one row per printed mention, stage 2 of statutory_institutions.py). This carries it into the same columns the plates fill, for the kinds of institution the two sources share, and writes two tables beside the register:

  • register_statutory_counts — one row per statutory city, key okres_id (each city was an okres of its own; Prague has no single settlement). The municipal table's shared count columns under their own names, count_source = "prose", and n_prose_*: what the prose names, by its own categories.
  • register_okres — one row per 1910 political okres, key okres_id: the municipalities' counts summed (count_source = "plates") and the statutory cities stacked under them ("prose").

How a mention becomes a count. Each row is routed by its code exactly as the register routes a claim off the plates: a pictogram to n_cat_&lt;category&gt; / n_mark_&lt;code&gt;, a text abbreviation to n_cat_txt_&lt;english&gt; / n_mark_txt_&lt;code&gt;, a cooperative letter to n_coop, its kind and its language. The register's own functions name and spread the columns (spread_columns, _wide, school_columns), so a name never differs between the two tables. Four rules on top:

  1. Totals or members, never both. A row printed as a total before its own members (is_total) is left out and its members counted. A generic cooperative total ([cooperative], count > 1) that the city's lettered cooperatives reach is a total even if stage 2 did not flag it — the guard for 0.5.0's missed , und zwar: (eight cities), reported as totals_unflagged. A total stage 2 coded "" (Olmütz's 10 Vorschußvereine before its 9 + 1) reaches no shared column, but is counted in n_prose_cooperative beside its members.
  2. The pictogram's column where the prose spelled a pictogram out. The prose writes every institution in words, so whether a reader coded Sparkasse as the text abbreviation or as the plate's pictogram is the reader's choice. A text code whose language's pictogram has the identical English meaning (savings bank, hospital, pharmacy, customs office, railway station, sanatorium, factory) is counted under the pictogram, where the plates count it.
  3. A joint post and telegraph office is both. Stage 2 gives one code per mention, so 2 ärarische Post- und Telegraphenämter is [post] only; the plates print the two pictograms apart. A [post] row whose words name the telegraph also counts as [telegraph].
  4. Only what both sources print. A column is shared when the municipal table holds it and the vocabulary files its code under an institution's category — not a settlement type, an industry pictogram (the mill, the brickworks), the connector [besides] or a unit, which the prose leaves out by design, so a 0 there would be invented. Shared columns are 0 where the prose names nothing; the rest are not in register_statutory_counts and are &lt;NA&gt; for a prose row of register_okres. What the prose names beyond them is in n_prose_*.

What it is blind to. Stage 2's coding: a mention coded "" reaches no shared column (two universities, the commercial academies) and a mention coded wrongly reaches the wrong one; only reader agreement stands behind it; statutory_coding_check.py measures it, blind, on a stratified sample (D-232). The two Bohemian volumes code Prague very differently (music schools 53 against 0, unspecified schools 35 against 166: the report's cross_edition), so the coding, not the routing, is what limits these columns. school_top_rung is on the plates' definition (SCHOOL_TYPES), which has no university type. Prague and Liberec are printed in both Bohemian volumes; the Czech one is used (EDITION_PRIORITY) and the German one compared, column by column, in the report.

def pictogram_twins(vocab: pd.DataFrame) -> dict[tuple[str, str], str]:
    """``{(lang, text code): pictogram}`` where exactly one pictogram of that language means the same in
    English (rule 2): ``("de", "Sparkasse") → "[savings-bank]"``."""
    pic = vocab[vocab["code"].str.startswith("[") & vocab["english"].ne("")]
    one = {(lang, eng): codes.iloc[0] for (lang, eng), codes in pic.groupby(["lang", "english"])["code"]
           if codes.nunique() == 1}
    text = vocab[~vocab["code"].str.startswith("[") & vocab["kind"].ne("cooperative")]
    return {(r.lang, r.code): one[(r.lang, r.english)] for r in text.itertuples() if (r.lang, r.english) in one}

def totals(stat: pd.DataFrame, vocab: pd.DataFrame) -> tuple[pd.Series, pd.Series]:
    """``(left out, caught by the guard)``: ``is_total``, or a generic cooperative total (``[cooperative]``,
    count > 1) that the city's lettered cooperatives reach (rule 1): they are counted, so counting it too
    would count them twice. *Reach*, not *equal*: Iglau names one of its cooperatives again further on
    (16 letters against a printed 15). Order-free on purpose:
    ``row`` numbers a city's mentions in stage 2's order (agreed, then adjudicated, then ruled), not
    the printed one, so a total and its members need not sit together (Olmütz's 10 Vorschußvereine)."""
    coop = vocab[vocab["kind"].eq("cooperative")]
    letter = pd.Series([(c, LANGUAGE[e]) in set(zip(coop["code"], coop["lang"]))
                        for c, e in zip(stat["code"], stat["edition"])], index=stat.index)
    members = stat["count"].where(letter, 0).groupby([stat["edition"], stat["city"]]).transform("sum")
    flagged = stat["is_total"].astype(bool)
    guard = stat["code"].eq("[cooperative]") & stat["count"].gt(1) & ~flagged & members.ge(stat["count"])
    return flagged | guard, guard

def route(stat: pd.DataFrame, vocab: pd.DataFrame, religion: pd.DataFrame,
          skip: pd.Series | None = None) -> tuple[pd.DataFrame, pd.DataFrame, dict]:
    """``(institution claims, cooperative claims, report)``: every counted row routed by its code as the
    register routes a plate claim, with ``owner`` = ``edition|city``. Totals are left out (rule 1), and so is what
    ``skip`` marks (:func:`lookup_not_counted`)."""
    out_total, guard = totals(stat, vocab)
    n_totals = int(out_total.sum())
    if skip is not None:
        out_total = out_total | skip
    twins, lookup = pictogram_twins(vocab), vocab.drop_duplicates(["code", "lang"]).set_index(["code", "lang"])
    inst, coop = [], []
    report = {"rows": len(stat), "totals_left_out": n_totals, "totals_unflagged": int(guard.sum()),
              "twins": {}, "joint": 0, "uncoded": 0}
    for i, r in stat[~out_total].iterrows():
        owner, lang, code, n = f"{r['edition']}|{r['city']}", LANGUAGE[r["edition"]], r["code"], int(r["count"])
        if not code or (code, lang) not in lookup.index:
            report["uncoded"] += 1
            continue
        if lookup.at[(code, lang), "kind"] == "cooperative":
            coop += [{"owner": owner, "coop_kind": lookup.at[(code, lang), "english"], "language": language,
                      "count": k} for language, k in _split(r["languages"], n)]
            continue
        if (lang, code) in twins:
            report["twins"][f"{code} → {twins[(lang, code)]}"] = report["twins"].get(f"{code} → {twins[(lang, code)]}", 0) + 1
            code = twins[(lang, code)]
        codes = [code] + [other for first, other, words in JOINT if code == first and words.search(r["quote"])]
        report["joint"] += len(codes) - 1
        for c in codes:
            inst.append(_claim(owner, c, lang, n, r["quote"], lookup, religion))
    return pd.DataFrame(inst), pd.DataFrame(coop), report

def city_counts(inst: pd.DataFrame, coop: pd.DataFrame, owners, universe: dict | None = None) -> pd.DataFrame:
    """The municipal table's count columns for each owner (``edition|city``), spread by the register's own
    functions, so every name is the one ``build_municipalities`` gives the same value."""
    universe = reg._spread_universe() if universe is None else universe
    inst = inst if not inst.empty else pd.DataFrame(columns=["owner", "mark", "english", "common_category", "count",
                                                             "rc_cure_seat", "rc_parish_strict", "class_column", "classes"])
    coop = coop if not coop.empty else pd.DataFrame(columns=["owner", "coop_kind", "language", "count"])
    names: dict[str, dict[str, str]] = {}
    for r in reg.spread_columns(inst, coop, universe).itertuples():
        names.setdefault(r.source_column, {})[r.value] = r.column
    out = pd.DataFrame(index=pd.Index(list(owners), name="owner"))
    owner_i, owner_c = inst["owner"], coop["owner"]
    out["rc_cure_seat"] = out.index.isin(inst.loc[inst["rc_cure_seat"].astype(bool), "owner"])
    out["rc_parish_strict"] = out.index.isin(inst.loc[inst["rc_parish_strict"].astype(bool), "owner"])
    out["n_rc_cure_seat"] = (inst[inst["rc_cure_seat"].astype(bool)].groupby("owner")["count"].sum()
                             .reindex(out.index).fillna(0).astype("Int64"))
    out["n_coop"] = coop.groupby("owner")["count"].sum().reindex(out.index).fillna(0).astype("Int64")
    for frame, col, owner in ((inst, "common_category", owner_i), (inst, "mark", owner_i),
                              (coop, "coop_kind", owner_c), (coop, "language", owner_c)):
        block = reg._wide(frame, col, owner, names.get(col, {})) if not frame.empty else pd.DataFrame()
        if not block.empty:
            out = out.join(block, how="left")
            out[block.columns] = out[block.columns].fillna(0).astype("Int64")
    read = pd.Series(True, index=out.index)
    out = out.join(reg.school_columns(inst, owner_i, out.index, read)).join(_classes(inst, out.index))
    return out

def prose_columns(stat: pd.DataFrame, left_out: pd.Series, unshared: pd.Series,
                  not_counted: pd.Series | None = None) -> pd.DataFrame:
    """``n_prose_<category>`` per owner (every counted mention, coded or not), ``n_prose_uncoded``,
    ``n_prose_unshared`` (coded, but in no shared column), ``n_prose_totals_left_out``, ``n_prose_rows``, and
    ``n_prose_lookup_left_out``: the mentions the type lookup rules not counted (0.4.0)."""
    s = stat.assign(owner=stat["edition"] + "|" + stat["city"])
    not_counted = pd.Series(False, index=stat.index) if not_counted is None else not_counted
    kept = s[~left_out & ~not_counted]
    out = (kept.pivot_table(index="owner", columns="category", values="count", aggfunc="sum", fill_value=0)
           .reindex(columns=list(PROSE_CATEGORIES), fill_value=0).add_prefix("n_prose_"))
    out = out.reindex(s["owner"].unique(), fill_value=0)
    out["n_prose_uncoded"] = kept[kept["code"].eq("")].groupby("owner")["count"].sum()
    out["n_prose_unshared"] = unshared
    out["n_prose_totals_left_out"] = s[left_out].groupby("owner").size()
    out["n_prose_lookup_left_out"] = s[not_counted & ~left_out].groupby("owner").size()
    out["n_prose_rows"] = kept.groupby("owner").size()
    return out.fillna(0).astype("Int64")

def okres_table(muni: pd.DataFrame, counts: pd.DataFrame) -> pd.DataFrame:
    """``register_okres``: the municipalities summed per okres (``plates``; a column any of whose
    municipalities is ``<NA>`` is ``<NA>`` for the okres: not read is not zero), ``school_top_rung`` their
    highest, ``n_munis_rc_*`` how many carry the flag; and the statutory cities beneath them (``prose``;
    a column the prose does not share is ``<NA>``, an ``n_prose_*`` column is ``<NA>`` for the plates)."""
    if muni["okres_id"].isna().any():
        raise ValueError("register_municipalities: a municipality with no okres_id")
    cols, okres = _count_columns(muni), muni["okres_id"]
    g = muni.groupby(okres)
    plates = g[cols].sum(min_count=1).mask(muni[cols].isna().groupby(okres).any())
    plates["school_top_rung"] = g["school_top_rung"].max().mask(muni["school_top_rung"].isna().groupby(okres).any())
    for flag in ("rc_cure_seat", "rc_parish_strict"):
        plates[f"n_munis_{flag}"] = g[flag].sum()
    plates.insert(0, "n_municipalities", g.size())
    plates.insert(0, "count_source", "plates")
    prose = counts.set_index("okres_id")
    overlap = sorted(set(prose.index) & set(plates.index))
    if overlap:
        raise ValueError(f"register_okres: statutory okres(y) {overlap} also hold plate municipalities")
    prose = prose.assign(n_municipalities=1, **{f"n_munis_{f}": prose[f].astype(int)
                                               for f in ("rc_cure_seat", "rc_parish_strict")})
    prose_only = [c for c in prose.columns if c.startswith("n_prose_")]
    keep = [c for c in plates.columns if c in prose.columns] + prose_only
    out = pd.concat([plates, prose[keep]]).rename_axis("okres_id").reset_index()
    out = out.reindex(columns=["okres_id", *plates.columns, *prose_only])
    out = out.astype({"okres_id": "Int64", **{c: "Int64" for c in out.columns if c not in ("okres_id", "count_source")}})
    _assert_key("register_okres", out)
    return out

CLASSES = re.compile(r"\b(?:o|mit)\s+(\d+)\s+(?:třídách|Klassen)\b")
#: The school types whose classes the plates sum (``school_classes``, ``burgher_school_classes``).
CLASS_COLUMNS = {"elementary": "school_classes", "burgher": "burgher_school_classes"}
#: Columns of the municipal table outside the spread map that the prose fills.
FIXED = ("n_coop", "n_rc_cure_seat", "rc_cure_seat", "rc_parish_strict", "school_top_rung",
         "school_classes", "burgher_school_classes")


# ── the vocabulary ──────────────────────────────────────────────────────────────
def vocabulary(path: Path = ABBREVIATIONS, additions: Path = ADDITIONS) -> pd.DataFrame:
    """``code``, ``lang``, ``english``, ``category``, ``kind`` of every code of the abbreviation table and the
    census additions (D-233), each ``english`` its standard name (``standard_codes``), as the rechecked register
    names its columns (0.2.0)."""
    from utils.recheck import standard_codes as std

    frames = [pd.read_csv(p, dtype=str, keep_default_na=False) for p in (path, additions) if Path(p).exists()]
    table = pd.concat(frames, ignore_index=True)[["code", "lang", "english", "category", "kind"]]
    return std.standardise(table)


def pictogram_twins(vocab: pd.DataFrame) -> dict[tuple[str, str], str]:
    """``{(lang, text code): pictogram}`` where exactly one pictogram of that language means the same in
    English (rule 2): ``("de", "Sparkasse") → "[savings-bank]"``."""
    pic = vocab[vocab["code"].str.startswith("[") & vocab["english"].ne("")]
    one = {(lang, eng): codes.iloc[0] for (lang, eng), codes in pic.groupby(["lang", "english"])["code"]
           if codes.nunique() == 1}
    text = vocab[~vocab["code"].str.startswith("[") & vocab["kind"].ne("cooperative")]
    return {(r.lang, r.code): one[(r.lang, r.english)] for r in text.itertuples() if (r.lang, r.english) in one}


def value_category(source_column: str, value: str, vocab: pd.DataFrame, religion: pd.DataFrame) -> str:
    """The vocabulary category behind one spread column's value (``register_columns.csv``), ``""`` if none."""
    if source_column in ("coop_kind", "language"):
        return "cooperative"
    if value in set(religion["category"]) - {""}:
        return "religion"
    if value.startswith("txt:"):
        field = "code" if source_column == "mark" else "english"
        hit = vocab.loc[~vocab["code"].str.startswith("[") & vocab[field].eq(value[4:]), "category"]
    else:
        hit = vocab.loc[vocab["code"].eq(value), "category"]
    return hit.iloc[0] if len(hit) else ""


def shared_columns(muni: pd.DataFrame, columns_map: pd.DataFrame, vocab: pd.DataFrame,
                   religion: pd.DataFrame) -> list[str]:
    """The municipal columns the prose can fill (rule 4), in the municipal table's order."""
    ok = {r.column for r in columns_map.itertuples()
          if value_category(r.source_column, str(r.value), vocab, religion) not in ("", *NOT_SHARED)}
    ok |= set(FIXED) | {c for c in muni.columns if c.startswith(("n_school_", "n_coop_lang_imputed_"))}
    return [c for c in muni.columns if c in ok]


# ── the rows ──────────────────────────────────────────────────────────────────
def totals(stat: pd.DataFrame, vocab: pd.DataFrame) -> tuple[pd.Series, pd.Series]:
    """``(left out, caught by the guard)``: ``is_total``, or a generic cooperative total (``[cooperative]``,
    count > 1) that the city's lettered cooperatives reach (rule 1): they are counted, so counting it too
    would count them twice. *Reach*, not *equal*: Iglau names one of its cooperatives again further on
    (16 letters against a printed 15). Order-free on purpose:
    ``row`` numbers a city's mentions in stage 2's order (agreed, then adjudicated, then ruled), not
    the printed one, so a total and its members need not sit together (Olmütz's 10 Vorschußvereine)."""
    coop = vocab[vocab["kind"].eq("cooperative")]
    letter = pd.Series([(c, LANGUAGE[e]) in set(zip(coop["code"], coop["lang"]))
                        for c, e in zip(stat["code"], stat["edition"])], index=stat.index)
    members = stat["count"].where(letter, 0).groupby([stat["edition"], stat["city"]]).transform("sum")
    flagged = stat["is_total"].astype(bool)
    guard = stat["code"].eq("[cooperative]") & stat["count"].gt(1) & ~flagged & members.ge(stat["count"])
    return flagged | guard, guard


def lookup_not_counted(stat: pd.DataFrame) -> tuple[pd.Series, str | None]:
    """``(left out, why not read)``: the mentions the frozen type lookup rules not counted for the city — a Land body's
    members printed under its seat (*107 landwirtschaftliche Bezirksvereine*), a seat held elsewhere for now, a
    language section — so the plate-code columns leave them out as the type columns do (0.4.0, D-252). Totals are
    rule 1's. Where the lookup does not hold a string (a test, or a reading newer than the freeze) nothing is left
    out and the reason is returned; ``statutory_types.add`` refuses such a build anyway."""
    from utils.recheck import statutory_types as stt

    none = pd.Series(False, index=stat.index)
    try:
        lab = stt.mentions(stat)
    except ValueError as err:
        return none, str(err)
    out = lab.groupby(["edition", "city", "row"]).apply(lambda g: not g["counted"].any() and not g["is_total"].any())
    rows = pd.MultiIndex.from_arrays([stat["edition"], stat["city"], stat["row"].astype(int)])
    return pd.Series(out.reindex(rows).fillna(False).to_numpy(dtype=bool), index=stat.index), None


def _split(languages: str, count: int) -> list[tuple[str, int]]:
    """``"czech 62, german 12"`` → ``[("czech", 62), ("german", 12)]``; what no language covers is not stated."""
    out = [(lang, int(n)) for lang, n in (p.strip().rsplit(" ", 1) for p in str(languages).split(",") if p.strip())]
    rest = int(count) - sum(n for _, n in out)
    return out + ([("not_stated", rest)] if rest > 0 else [])


def route(stat: pd.DataFrame, vocab: pd.DataFrame, religion: pd.DataFrame,
          skip: pd.Series | None = None) -> tuple[pd.DataFrame, pd.DataFrame, dict]:
    """``(institution claims, cooperative claims, report)``: every counted row routed by its code as the
    register routes a plate claim, with ``owner`` = ``edition|city``. Totals are left out (rule 1), and so is what
    ``skip`` marks (:func:`lookup_not_counted`)."""
    out_total, guard = totals(stat, vocab)
    n_totals = int(out_total.sum())
    if skip is not None:
        out_total = out_total | skip
    twins, lookup = pictogram_twins(vocab), vocab.drop_duplicates(["code", "lang"]).set_index(["code", "lang"])
    inst, coop = [], []
    report = {"rows": len(stat), "totals_left_out": n_totals, "totals_unflagged": int(guard.sum()),
              "twins": {}, "joint": 0, "uncoded": 0}
    for i, r in stat[~out_total].iterrows():
        owner, lang, code, n = f"{r['edition']}|{r['city']}", LANGUAGE[r["edition"]], r["code"], int(r["count"])
        if not code or (code, lang) not in lookup.index:
            report["uncoded"] += 1
            continue
        if lookup.at[(code, lang), "kind"] == "cooperative":
            coop += [{"owner": owner, "coop_kind": lookup.at[(code, lang), "english"], "language": language,
                      "count": k} for language, k in _split(r["languages"], n)]
            continue
        if (lang, code) in twins:
            report["twins"][f"{code} → {twins[(lang, code)]}"] = report["twins"].get(f"{code} → {twins[(lang, code)]}", 0) + 1
            code = twins[(lang, code)]
        codes = [code] + [other for first, other, words in JOINT if code == first and words.search(r["quote"])]
        report["joint"] += len(codes) - 1
        for c in codes:
            inst.append(_claim(owner, c, lang, n, r["quote"], lookup, religion))
    return pd.DataFrame(inst), pd.DataFrame(coop), report


def _claim(owner: str, code: str, lang: str, count: int, quote: str, lookup: pd.DataFrame,
           religion: pd.DataFrame) -> dict:
    """One institution claim, as ``build_institutions`` writes a plate claim (mark, category, flags)."""
    english = lookup.at[(code, lang), "english"] if (code, lang) in lookup.index else ""
    if code.startswith("["):
        mark, cat = code, religion["category"].get(code, code)
        category = cat if cat != "" else None                      # Kaplanei, Primissariat: no category
    else:
        mark, category = "txt:" + code, "txt:" + english
    kind = reg.school_type(mark, english)
    classes = CLASSES.search(quote) if kind in CLASS_COLUMNS else None
    return {"owner": owner, "mark": mark, "english": english, "common_category": category, "count": count,
            "rc_cure_seat": bool(religion["rc_cure_seat"].get(code, False)),
            "rc_parish_strict": bool(religion["rc_parish_strict"].get(code, False)),
            "class_column": CLASS_COLUMNS.get(kind, ""), "classes": int(classes.group(1)) if classes else pd.NA}


# ── the counts ────────────────────────────────────────────────────────────────
def _classes(inst: pd.DataFrame, owners) -> pd.DataFrame:
    """Classes per owner and school type: summed, ``<NA>`` where one of the type's rows prints none."""
    out = pd.DataFrame(index=owners)
    for col in CLASS_COLUMNS.values():
        rows = inst[inst["class_column"].eq(col)] if not inst.empty else inst
        total = rows.groupby("owner")["classes"].agg(lambda s: pd.NA if s.isna().any() else int(s.sum()))
        out[col] = total.reindex(out.index).astype("Int64").where(out.index.isin(total.index), 0)
    return out


def city_counts(inst: pd.DataFrame, coop: pd.DataFrame, owners, universe: dict | None = None) -> pd.DataFrame:
    """The municipal table's count columns for each owner (``edition|city``), spread by the register's own
    functions, so every name is the one ``build_municipalities`` gives the same value."""
    universe = reg._spread_universe() if universe is None else universe
    inst = inst if not inst.empty else pd.DataFrame(columns=["owner", "mark", "english", "common_category", "count",
                                                             "rc_cure_seat", "rc_parish_strict", "class_column", "classes"])
    coop = coop if not coop.empty else pd.DataFrame(columns=["owner", "coop_kind", "language", "count"])
    names: dict[str, dict[str, str]] = {}
    for r in reg.spread_columns(inst, coop, universe).itertuples():
        names.setdefault(r.source_column, {})[r.value] = r.column
    out = pd.DataFrame(index=pd.Index(list(owners), name="owner"))
    owner_i, owner_c = inst["owner"], coop["owner"]
    out["rc_cure_seat"] = out.index.isin(inst.loc[inst["rc_cure_seat"].astype(bool), "owner"])
    out["rc_parish_strict"] = out.index.isin(inst.loc[inst["rc_parish_strict"].astype(bool), "owner"])
    out["n_rc_cure_seat"] = (inst[inst["rc_cure_seat"].astype(bool)].groupby("owner")["count"].sum()
                             .reindex(out.index).fillna(0).astype("Int64"))
    out["n_coop"] = coop.groupby("owner")["count"].sum().reindex(out.index).fillna(0).astype("Int64")
    for frame, col, owner in ((inst, "common_category", owner_i), (inst, "mark", owner_i),
                              (coop, "coop_kind", owner_c), (coop, "language", owner_c)):
        block = reg._wide(frame, col, owner, names.get(col, {})) if not frame.empty else pd.DataFrame()
        if not block.empty:
            out = out.join(block, how="left")
            out[block.columns] = out[block.columns].fillna(0).astype("Int64")
    read = pd.Series(True, index=out.index)
    out = out.join(reg.school_columns(inst, owner_i, out.index, read)).join(_classes(inst, out.index))
    return out


def prose_columns(stat: pd.DataFrame, left_out: pd.Series, unshared: pd.Series,
                  not_counted: pd.Series | None = None) -> pd.DataFrame:
    """``n_prose_<category>`` per owner (every counted mention, coded or not), ``n_prose_uncoded``,
    ``n_prose_unshared`` (coded, but in no shared column), ``n_prose_totals_left_out``, ``n_prose_rows``, and
    ``n_prose_lookup_left_out``: the mentions the type lookup rules not counted (0.4.0)."""
    s = stat.assign(owner=stat["edition"] + "|" + stat["city"])
    not_counted = pd.Series(False, index=stat.index) if not_counted is None else not_counted
    kept = s[~left_out & ~not_counted]
    out = (kept.pivot_table(index="owner", columns="category", values="count", aggfunc="sum", fill_value=0)
           .reindex(columns=list(PROSE_CATEGORIES), fill_value=0).add_prefix("n_prose_"))
    out = out.reindex(s["owner"].unique(), fill_value=0)
    out["n_prose_uncoded"] = kept[kept["code"].eq("")].groupby("owner")["count"].sum()
    out["n_prose_unshared"] = unshared
    out["n_prose_totals_left_out"] = s[left_out].groupby("owner").size()
    out["n_prose_lookup_left_out"] = s[not_counted & ~left_out].groupby("owner").size()
    out["n_prose_rows"] = kept.groupby("owner").size()
    return out.fillna(0).astype("Int64")


# ── the tables ────────────────────────────────────────────────────────────────
def statutory_counts(stat: pd.DataFrame, muni: pd.DataFrame, columns_map: pd.DataFrame,
                     vocab: pd.DataFrame | None = None, religion: pd.DataFrame | None = None,
                     universe: dict | None = None) -> tuple[pd.DataFrame, dict]:
    """``register_statutory_counts`` (one row per city, key ``okres_id``, the edition first in
    ``EDITION_PRIORITY``) and the report: what was routed how, and the cities read in two editions
    compared column by column."""
    vocab = vocabulary() if vocab is None else vocab
    religion = reg._religion_table() if religion is None else religion
    stat = stat.assign(is_total=stat["is_total"].astype(bool), count=stat["count"].astype(int))
    left_out, _ = totals(stat, vocab)
    skip, missing = lookup_not_counted(stat)
    skip = skip & ~left_out
    inst, coop, report = route(stat, vocab, religion, skip)
    report["lookup_left_out"] = int(skip.sum())
    if missing:
        report["lookup_not_read"] = missing
    owners = list(dict.fromkeys(stat["edition"] + "|" + stat["city"]))
    wide = city_counts(inst, coop, owners, universe)
    shared = shared_columns(muni, columns_map, vocab, religion)
    off = [c for c in wide.columns if c.startswith("n_cat_") and c not in shared]
    no_cat = (inst[inst["common_category"].isna()].groupby("owner")["count"].sum()
              if not inst.empty else pd.Series(dtype="Int64"))
    unshared = wide[off].sum(axis=1).add(no_cat.reindex(wide.index).fillna(0), fill_value=0)
    report["unshared_columns"] = {c: int(wide[c].sum()) for c in off if wide[c].sum()}
    out = wide.reindex(columns=shared)
    for c in shared:
        if c not in wide.columns:
            out[c] = 0
    for c in shared:                                  # D-238: the prose prints its own split; it imputes nothing
        if c.startswith("n_coop_lang_imputed_"):
            printed = c.replace("n_coop_lang_imputed_", "n_coop_lang_")
            out[c] = wide[printed].reindex(out.index).fillna(0) if printed in wide.columns else 0
    out = out.astype({c: "Int64" for c in shared if c not in ("rc_cure_seat", "rc_parish_strict")})
    out = out.join(prose_columns(stat, left_out, unshared, skip))
    meta = stat.drop_duplicates(["edition", "city"]).assign(owner=lambda d: d["edition"] + "|" + d["city"])
    out = meta.set_index("owner")[["edition", "city", "okres_id"]].join(out)
    rank = {e: k for k, e in enumerate(reg.EDITION_PRIORITY)}
    out = out.assign(_rank=out["edition"].map(rank)).sort_values(["okres_id", "_rank"])
    seen = out.groupby("okres_id")["edition"].agg(";".join)
    report["cross_edition"] = _cross_edition(out, shared)
    out = out.drop_duplicates("okres_id", keep="first").drop(columns="_rank")
    out.insert(3, "editions_seen", out["okres_id"].map(seen))
    out.insert(4, "count_source", "prose")
    out = out.reset_index(drop=True).astype({"okres_id": "Int64"})
    _assert_key("register_statutory_counts", out)
    return out, report


def _cross_edition(frame: pd.DataFrame, shared: list[str]) -> dict:
    """``{city: {column: [first edition, second]}}`` for every shared column two editions disagree on."""
    out = {}
    common = [c for c in shared if not c.startswith("n_mark_")]       # a mark is the volume's own code
    for _, g in frame.groupby("okres_id"):
        if len(g) < 2:
            continue
        a, b = g.iloc[0], g.iloc[1]
        out[f"{a['city']}/{b['city']}"] = {c: [_plain(a[c]), _plain(b[c])] for c in common
                                           if _plain(a[c]) != _plain(b[c])}
    return out


def _plain(value):
    return None if pd.isna(value) else int(value)


def _count_columns(muni: pd.DataFrame) -> list[str]:
    """The okres table's summed columns (the top rung is a maximum, the two flags are counted apart)."""
    return [c for c in muni.columns if c.startswith(("n_cat_", "n_mark_", "n_coop", "n_school_"))
            or c in ("n_rc_cure_seat", "school_classes", "burgher_school_classes")]


def okres_table(muni: pd.DataFrame, counts: pd.DataFrame) -> pd.DataFrame:
    """``register_okres``: the municipalities summed per okres (``plates``; a column any of whose
    municipalities is ``<NA>`` is ``<NA>`` for the okres: not read is not zero), ``school_top_rung`` their
    highest, ``n_munis_rc_*`` how many carry the flag; and the statutory cities beneath them (``prose``;
    a column the prose does not share is ``<NA>``, an ``n_prose_*`` column is ``<NA>`` for the plates)."""
    if muni["okres_id"].isna().any():
        raise ValueError("register_municipalities: a municipality with no okres_id")
    cols, okres = _count_columns(muni), muni["okres_id"]
    g = muni.groupby(okres)
    plates = g[cols].sum(min_count=1).mask(muni[cols].isna().groupby(okres).any())
    plates["school_top_rung"] = g["school_top_rung"].max().mask(muni["school_top_rung"].isna().groupby(okres).any())
    for flag in ("rc_cure_seat", "rc_parish_strict"):
        plates[f"n_munis_{flag}"] = g[flag].sum()
    plates.insert(0, "n_municipalities", g.size())
    plates.insert(0, "count_source", "plates")
    prose = counts.set_index("okres_id")
    overlap = sorted(set(prose.index) & set(plates.index))
    if overlap:
        raise ValueError(f"register_okres: statutory okres(y) {overlap} also hold plate municipalities")
    prose = prose.assign(n_municipalities=1, **{f"n_munis_{f}": prose[f].astype(int)
                                               for f in ("rc_cure_seat", "rc_parish_strict")})
    prose_only = [c for c in prose.columns if c.startswith("n_prose_")]
    keep = [c for c in plates.columns if c in prose.columns] + prose_only
    out = pd.concat([plates, prose[keep]]).rename_axis("okres_id").reset_index()
    out = out.reindex(columns=["okres_id", *plates.columns, *prose_only])
    out = out.astype({"okres_id": "Int64", **{c: "Int64" for c in out.columns if c not in ("okres_id", "count_source")}})
    _assert_key("register_okres", out)
    return out


def _assert_key(name: str, frame: pd.DataFrame) -> None:
    key = TABLE_KEYS[name]
    if frame[key].isna().any().any() or frame.duplicated(key).any():
        raise AssertionError(f"{name}: key {key} missing or duplicated")


def add(tables: dict) -> dict:
    """``tables`` with ``register_statutory_counts`` and ``register_okres``; the report under ``_meta``."""
    counts, report = statutory_counts(tables["register_statutory"], tables["register_municipalities"],
                                      tables["register_columns"])
    report["cities"] = len(counts)
    out = {**tables, "register_statutory_counts": counts,
           "register_okres": okres_table(tables["register_municipalities"], counts)}
    out["_meta"] = {**tables.get("_meta", {}), "statutory_counts": report}
    return out


def write(tables: dict, out_dir: Path) -> None:
    """The two tables, as the register writes its own (parquet and csv)."""
    for name in TABLE_KEYS:
        tables[name].to_parquet(Path(out_dir) / f"{name}.parquet", index=False)
        tables[name].to_csv(Path(out_dir) / f"{name}.csv", index=False, encoding="utf-8")

#: The sentence ``lexikon_1910_register.build_block`` (frozen; written at 1.4.0, before stage 2) puts in
#: the README's generated block. "Not read" contradicts the ``register_statutory`` row of the table above it.
STALE = re.compile(r"\*\*Not read: the statutory cities\*\* (?P<cities>[^\n]*?)\. Each prints its institutions as "
                   r"prose with no pictogram \(D-40, D-82\) and the full run skips its pages, so it has no row here: "
                   r"aggregated to its okres, its counts are missing, never zero\.")
CURRENT = ("**No row in `register_municipalities`: the statutory cities** {cities}. Each prints its institutions as "
           "prose with no pictogram (D-40, D-82), the full run skips its pages, and Prague has no single settlement "
           "to key a row on. Their prose is read into `register_statutory` (D-178), and notebook 17 §9 carries it "
           "into `register_statutory_counts` and the okres table `register_okres` of `data/final/register_rechecked/` "
           "(D-232). Aggregated from `register_municipalities` alone, their okresy are missing, never zero.")


def patch_readme(path: Path = reg.README) -> bool:
    """Replace the frozen generator's stale sentence (:data:`STALE`) with :data:`CURRENT`; ``True`` if the
    file changed. Notebook 15 §18 writes the old sentence back on every build, and §9 runs after §18 (the
    QA gate's build-order check), so §9 corrects it each time. The fix that ends this is in the generator,
    once the freeze is lifted."""
    text = Path(path).read_text(encoding="utf-8")
    new = STALE.sub(lambda m: CURRENT.format(cities=m.group("cities")), text)
    if new == text:
        return False
    Path(path).write_text(new, encoding="utf-8", newline="\n")
    return True
