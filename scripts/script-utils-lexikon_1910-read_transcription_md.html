How it works

Companion to check_transcription, which reads the old free-form format of the four development pages and is left alone. That sheet asked for one of the three documents the register prints; this one asks for all of them, so it needs its own reader — and the two must both keep working, because the four purposive pages are transcribed under both protocols and the disagreement between them is a measurement of the transcriber that nothing else in this project can make.

What it emits

Four frames, from the four sections of a &lt;scan&gt;.md sheet:

inventory_human.csv section 2b, in exactly the columns the model passes produce, so score_against_reference and the bake-off's comparisons consume it unchanged parts_human.csv section 2a — the named parts, their topographic mark and their house–population pair table_human.csv section 1 — the seventeen columns, one row per printed line legend_human.csv section 3 — the postal and station keys

Why it grades as it reads

The register's own arithmetic is a check on the person, not only on the OCR. The table has to add up four ways and the Části osad pairs have to sum to the settlement's row above them, and none of that was available while the sheet asked only for symbols: the apparatus has no arithmetic, so a symbols-only gold could be graded by nothing but a second reading of the same pages. Reading the whole page puts I1–I4 and I8 back within reach of the transcription, per page, while the page is still open and the image still in front of the reader.

That is why the sheet says "do not make them add up, just read them". A reader who balances the figures produces a transcription that passes every check and measures nothing — the same reason the models are never shown the invariants.

def front_matter(text: str) -> dict:
    """The `---` block at the top, flat, without a YAML dependency.

    Only the handful of scalars this reader needs are taken. `minutes:` is kept
    as its raw inline mapping because it is the budget evidence and is meant to
    be read by a person, not joined on.
    """
    if not text.startswith("---"):
        return {}
    end = text.find("\n---", 3)
    out: dict = {}
    for line in text[3:end if end > 0 else len(text)].splitlines():
        if line.startswith((" ", "\t")) or ":" not in line:
            continue
        key, _, value = line.partition(":")
        out[key.strip()] = value.split("#")[0].strip().strip('"')
    return out

def read_parts(scan: str, blocks: list, problems: list) -> tuple[list, int]:
    rows: list[dict] = []
    blank = 0
    for section, district, kind, lines in blocks:
        if kind != "ledger" or section != "2a":
            continue
        for line in lines:
            if line.lstrip().startswith("=="):
                continue
            parsed = _key(line)
            if not parsed:
                _bad_key(scan, district, line, problems)
                continue
            muni, seq, _short, settlement, _flag, answer = parsed
            if muni == "__" or not answer:
                blank += 1
                continue
            # ONE SPLITTER, IN `lexikon_1910_notes`, USED BY BOTH SIDES. The
            # commas that separate the parts also sit inside a name's German twin
            # (`Hazlov, Haslau 217—2266`), the `&` residual is an entry with no
            # name, and a cross-reference in parentheses must survive intact —
            # three rules that a second copy here would drift on, and drift on
            # exactly the entries where the two readings are compared.
            for part in lxnt.split_parts(answer):
                if part["unparsed"]:
                    problems.append(
                        f"  {scan} {district} {muni},{seq}: cannot read "
                        f"{part['unparsed'][:50]!r} as `name <mark> "
                        f"houses—population`")
                    continue
                # THE ANSWER HAS TO STAND ALONE. The ledger prints the settlement
                # to the LEFT of the `›` so a transcriber twenty rows into a
                # block knows where they are; that column is a locator, not a
                # value, and an answer that leans on it (`> [ves] 162-676`)
                # parses to figures with no name and passes every other test on
                # this page. The register never prints a pair without a name, so
                # this is always a slip. Flagged, and RECORDED anyway — the loop
                # below already records and flags rather than dropping, and a
                # silently short parts list is what `grade_parts` then blames on
                # the print.
                if not part["name"]:
                    problems.append(
                        f"  {scan} {district} {muni},{seq}: part "
                        f"{part['position'] + 1} has figures but no name — "
                        f"write the name out even where it repeats the "
                        f"settlement's own")
                # TWO BRACKET TOKENS IN A ROW, and only the last is the mark:
                # `_BRACKET_RE` anchors at the END of the body, so
                # `[besides] [scattered] 2-9` files a part literally NAMED
                # `[besides]`. `[besides]` is on the atlas (`mimo to`) but it is a
                # connector, and this document's residual entry is written `&` —
                # the convention the sheet asks for and the one `parts_report`
                # counts on.
                elif part["name"].startswith("[") and part["name"].endswith("]"):
                    problems.append(
                        f"  {scan} {district} {muni},{seq}: {part['name']} is a "
                        f"symbol standing in the NAME slot — a part carries one "
                        f"mark; write the register's residual entry as `&`")
                mark = part["topographic"] or part["topographic_raw"]
                # IN SECTION 2a THE MARK'S POSITION SETTLES ITS ROLE, so a token
                # outside `TOPOGRAPHIC` is recorded and flagged, never dropped.
                # That list was derived from the offices context, where a mark in
                # the symbol list has to be told apart from an institution; here
                # it stands beside a name and can only be saying what the place
                # is. The register prints mill glyphs exactly this way —
                # `Prechtelmühle ф 1—3`, `Obermühle ф 1—25` — and `[mill]` is in
                # the institution vocabulary and NOT in `TOPOGRAPHIC`, so the
                # strict test rejected a correct reading. Whether that list
                # should grow is a question for the recon page to answer, not
                # for this parser to decide by refusing the data.
                review = bool(mark) and lxv.canonical(mark) not in TOPOGRAPHIC
                rows.append({
                    "check": "I8_parts", "page": scan, "district": district,
                    "muni_seq": int(muni), "settlement_seq": seq,
                    "part_name": part["name"],
                    "settlement": settlement, "topographic": mark,
                    "topographic_review": "yes" if review else "",
                    "houses": part["houses"],
                    "population": part["population"],
                    "position": part["position"], "source": "human",
                })
    return rows, blank

def read_table(scan: str, blocks: list, problems: list,
               names: list[str] | None = None) -> list[dict]:
    """Section 1's rows, each against ``names`` — the sheet's own header
    (:func:`_header_columns`, which :func:`read_sheet` passes), else ``lx.COLUMNS``."""
    names = names or [name for name, _kind in lx.COLUMNS]
    rows: list[dict] = []
    for section, district, kind, lines in blocks:
        if kind != "table" or section != "1":
            continue
        for line in lines:
            match = _TABLE_ROW_RE.match(line.strip())
            if not match:
                continue
            position, rest = match.groups()
            cells = [c.strip() for c in rest.split("|")]
            if len(cells) and not cells[-1]:
                cells = cells[:-1]
            if len(cells) != len(names):
                problems.append(
                    f"  {scan} {district} r{position}: {len(cells)} cells for "
                    f"{len(names)} columns — a pipe was added or lost")
                continue
            row = {"page": scan, "district": district, "position": int(position),
                   "source": "human"}
            row.update({name: "" for name, _kind in lx.COLUMNS})
            row.update(dict(zip(names, cells)))
            if any(row[name] for name in names):
                rows.append(row)
    return rows

def grade_table(records: list[dict]) -> list[dict]:
    """I1–I4 on the transcription itself.

    A failure here is either an OCR error in the printed table — which is a
    finding, since it is what the gold exists to measure — or a slip of the
    transcriber's, which is the other thing this was never able to see. Which of
    the two it is has to be settled by eye, against the image, and the point of
    running it per page is that the image is still open.

    A BLOCK IS CARRIED ACROSS SCANS. Graded one scan at a time, a municipality
    split by a page break was summed without the settlements printed overleaf:
    Trutnov's row closes scan 0450 with two of its three settlements, the town
    itself opens scan 0451, and I4 failed in ten columns on a block that adds
    up exactly. Pass the records of every sheet in the set, in the sheets' own
    order. Where the next scan is not in the set the block cannot be completed,
    and a sum that falls short there is `na`, not `fail`.
    """
    out: list[dict] = []
    blocks: list[lx.Block] = []
    open_at_foot: set[int] = set()
    # Only the court printed LAST on a scan can run on over the page, and the
    # records arrive in the sheet's own order, so the last one names it.
    last_court = {record["page"]: record["district"] for record in records}
    current: lx.Block | None = None
    previous: dict | None = None

    def close_run() -> None:
        if (current is not None and previous is not None
                and last_court[previous["page"]] == previous["district"]):
            open_at_foot.add(current.index)

    for record in sorted(records, key=_reading_order):
        row = _as_row(record)
        for invariant in _invariants(record):
            verdict, detail = lx.grade_row(row, invariant)
            out.append({"check": invariant.key, "page": record["page"],
                        "district": record["district"],
                        "row": record["position"], "verdict": verdict,
                        "detail": detail})
        if not _same_run(previous, record):
            close_run()
            current = None
        previous = record
        if row.is_municipality:
            current = lx.Block(page=record["page"], index=len(blocks),
                               municipality=row,
                               court_label=record["district"])
            blocks.append(current)
        elif current is not None and not row.is_of_which:
            current.settlements.append(row)
    close_run()
    for block in blocks:
        for column, (verdict, detail) in lx.grade_block_sum(block).items():
            if verdict == "fail" and block.index in open_at_foot:
                verdict = "na"
                detail += (" — the block is open at the foot of its scan and "
                           "the next scan is not in this set")
            out.append({"check": "I4_block", "page": block.page,
                        "district": block.court_label,
                        "row": f"muni@{block.municipality.top}",
                        "verdict": verdict, "detail": f"{column}: {detail}"})
    return out

def grade_parts(parts: list[dict], table: list[dict]) -> list[dict]:
    """I8 on the transcription: the parts pairs sum to their settlement's row.

    This is the check that grades the *person*. The `Části osad` figures are the
    same quantities the table prints, set in different type in a different part of
    the page, so a reading of one that disagrees with a reading of the other is an
    error somewhere the transcriber can still go and look at.
    """
    index = _table_index(table)
    grouped: dict[tuple, list] = {}
    for part in parts:
        grouped.setdefault((part["page"], part["district"], part["muni_seq"],
                            part["settlement_seq"]), []).append(part)

    out: list[dict] = []
    for key, members in sorted(grouped.items()):
        page, district, muni, seq = key
        where = f"{muni},{seq} {members[0]['settlement'][:24]}"
        if seq in ("?", "+"):
            out.append({"check": "I8_parts", "page": page, "district": district,
                        "row": where, "verdict": "na",
                        "detail": "key carries no part figure to join on"})
            continue
        row = index.get(key)
        if row is None:
            out.append({"check": "I8_parts", "page": page, "district": district,
                        "row": where, "verdict": "na",
                        "detail": "no table row for this key on this scan — the "
                                  "apparatus runs on from an earlier page"})
            continue
        for column, field in (("houses", "houses"), ("population", "pop_total")):
            values = [lx.parse_int_cell(m[column]) for m in members]
            whole, whole_status = lx.parse_int_cell(row.get(field))
            if whole_status != "ok" or any(st != "ok" for _v, st in values):
                out.append({"check": "I8_parts", "page": page,
                            "district": district, "row": where,
                            "verdict": "unparseable" if whole_status == "bad"
                            else "na", "detail": f"{column} not readable on both "
                                                 f"sides"})
                continue
            total = sum(v for v, _st in values)
            out.append({"check": "I8_parts", "page": page, "district": district,
                        "row": where,
                        "verdict": "pass" if total == whole else "fail",
                        "detail": "" if total == whole
                        else f"{column}: parts={total} row={whole}"})
    return out

def read_order_reference(roles=ORDER_ROLES, abbreviations=None) -> list[dict]:
    """The runs of marks the gold sheets print, for `lexikon_1910_institutions` I22.

    One row per run — a filled section-2b line, cut again at each named part
    (``Valdice:``) and with parenthesised text left out — as
    ``{"page", "district", "muni_seq", "settlement_seq", "named_part", "codes"}``,
    in the order the sheets print them. ``codes`` are the bracketed symbols
    only, found by the decoder the readers' lines go through, so the reference
    and a reading are cut by one rule.

    **Every filled line counts, whatever the sheet's ``status:``** — a draft
    sheet's lines are in, a blank key is not — and so does the few-shot page:
    it is held out of the *scored* gold because the reader is shown it, and
    the order is not a reader. A token the atlas does not have (a typo such as
    ``[coopearative]``) is not decoded and is simply absent from its run; the
    reader's own report (`read_sheet`) is what names it.

    Reads the sheets, writes nothing, and refuses a sealed role.
    """
    sealed = set(roles) - set(ORDER_ROLES)
    if sealed:
        raise ValueError(f"the printed order is learned from {ORDER_ROLES} only, "
                         f"not {sorted(sealed)}")
    if abbreviations is None:
        abbreviations = lxin.load_abbreviations(ABBREVIATIONS, lang="cs")
    rows: list[dict] = []
    for role in roles:
        for path in sorted((GOLD_ROOT / role).glob("[0-9][0-9][0-9][0-9].md")):
            text = path.read_text(encoding="utf-8")
            scan = front_matter(text).get("scan") or path.stem
            for section, district, kind, lines in _blocks(text):
                if kind != "ledger" or section != "2b":
                    continue
                for line in lines:
                    parsed = _key(line)
                    if not parsed:
                        continue
                    muni, seq, _short, _part, _flag, answer = parsed
                    if muni == "__" or not answer:
                        continue
                    entry = lxin.Entry(district=district, page=scan,
                                       muni_seq=int(muni), settlement_seq=seq,
                                       text=answer, index=0)
                    records = lxin.decode_entry(entry, abbreviations)
                    for named_part, run in enumerate(
                            lxin.order_runs(records, text=answer)):
                        rows.append({"page": scan, "district": district,
                                     "muni_seq": int(muni), "settlement_seq": seq,
                                     "named_part": named_part,
                                     "codes": [r["code"] for r in run]})
    return rows

    print(f"\n{'scan':>6}  {'status':<12} {'table':>6} {'parts':>6} "
          f"{'offices':>8} {'legend':>7} {'notes':>6}  minutes")

              f"{len(sheet['table']):6d} {len(sheet['parts']):6d} "
              f"{len(sheet['offices']):8d} {len(sheet['legend']):7d} "
              f"{len(sheet['notes']):6d}  {meta.get('minutes', '')}")

    if verdicts:
        print("\n  the register's own arithmetic, applied to the TRANSCRIPTION:")
        by_check: dict[str, Counter] = {}
        for verdict in verdicts:
            by_check.setdefault(verdict["check"], Counter())[verdict["verdict"]] += 1
        for check, counts in sorted(by_check.items()):
            scored = counts["pass"] + counts["fail"]
            rate = f"{counts['pass'] / scored:6.1%}" if scored else "     —"
            print(f"    {check:<16} {rate}  "
                  + "  ".join(f"{k} {counts[k]}" for k in lx.VERDICTS if counts[k]))
        print("\n    A failure is an OCR error in the printed table or a slip of "
              "the transcriber's.\n    Which one has to be settled by eye, "
              "against the image, before the page is closed.")
        for verdict in verdicts:
            if verdict["verdict"] == "fail":
                print(f"      {verdict['check']:<14} {verdict['page']} "
                      f"{verdict['district'][:16]:16s} {verdict['row']}  "
                      f"{verdict['detail']}")

    problems = [p for s in sheets for p in s["problems"]]
    if problems:
        print(f"\n  {len(problems)} problem(s):")
        for problem in problems[:40]:
            print(problem)
    blank = sum(s["blank"] for s in sheets)

          "  (a blank key is DATA where the register prints nothing there)")

def write(sheets: list[dict], out_dir: Path) -> None:
    from utils.lexikon_1910.lexikon_1910_pages import FEWSHOT_PAGE

    out_dir.mkdir(parents=True, exist_ok=True)
    for name, key in (("inventory_human.csv", "offices"),
                      ("attributes_human.csv", "attributes"),
                      ("parts_human.csv", "parts"),
                      ("table_human.csv", "table"),
                      ("legend_human.csv", "legend")):
        rows = [r for sheet in sheets for r in sheet[key]]
        if name == "inventory_human.csv":
            # THE SCORED GOLD LEAVES OUT THE FEW-SHOT PAGE. That scan is shown to
            # the whole-page reader as its worked example, so a claim on it would
            # grade a model against its own prompt (`lexikon_1910_pages`,
            # `FEWSHOT_PAGE` / `GOLD_SCORED_PAGES`). Its other frames are written:
            # nothing scores a symbol against them.
            held = [r for r in rows if int(r["page"]) == FEWSHOT_PAGE]
            rows = [r for r in rows if int(r["page"]) != FEWSHOT_PAGE]
            if held:
                print(f"  held out of {name}: {len(held)} rows on scan "
                      f"{FEWSHOT_PAGE:04d}, the few-shot page")
        if not rows:
            continue
        path = out_dir / name
        with path.open("w", encoding="utf-8", newline="") as fh:
            writer = csv.DictWriter(fh, fieldnames=list(rows[0]))
            writer.writeheader()
            writer.writerows(rows)
        print(f"  wrote {len(rows):5d} rows  {path}")

def main() -> int:
    # The report names Czech districts and prints the atlas tokens back. A
    # Windows console defaults to cp1250 here, which turned `Aš` into `A?` in
    # the very line a transcriber uses to find the row they mis-read.
    for stream in (sys.stdout, sys.stderr):
        try:
            stream.reconfigure(encoding="utf-8", errors="replace")
        except (AttributeError, ValueError):
            pass
    ap = argparse.ArgumentParser(
        description=__doc__,
        formatter_class=argparse.RawDescriptionHelpFormatter)
    ap.add_argument("--role", default="calibration",
                    choices=("calibration", "certification", "purposive", "gold"),
                    help="gold = calibration and purposive together, the set the "
                         "r5 bake-off is scored on (D-81); certification stays sealed")
    ap.add_argument("--sheet", default="", help="one sheet, instead of a role")
    ap.add_argument("--out", default=str(OUT_DIR))
    ap.add_argument("--write", action="store_true",
                    help="write the four frames for the comparison tools")
    args = ap.parse_args()

    if args.sheet:
        paths = [Path(args.sheet)]
    else:
        roles = ("calibration", "purposive") if args.role == "gold" else (args.role,)
        paths = [p for role in roles
                 for p in sorted((GOLD_ROOT / role).glob("[0-9][0-9][0-9][0-9].md"))]
    paths = [p for p in paths if p.exists()]
    if not paths:
        print("no sheets found — run make_gold_worksheet.py first")
        return 1

    abbreviations = lxin.load_abbreviations(ABBREVIATIONS, lang="cs")
    allowed = lxv.vocabulary(abbreviations) | {OFF_ATLAS} | TOPOGRAPHIC
    sheets = [read_sheet(path, allowed) for path in paths]
    report(sheets)
    if args.write:
        write(sheets, Path(args.out))
    return 1 if any(s["problems"] for s in sheets) else 0

"""Read the whole-page gold sheets, and grade the transcriber while doing it.

Companion to :mod:`check_transcription`, which reads the **old** free-form format
of the four development pages and is left alone. That sheet asked for one of the
three documents the register prints; this one asks for all of them, so it needs
its own reader — and the two must both keep working, because the four purposive
pages are transcribed under both protocols and the disagreement between them is a
measurement of the transcriber that nothing else in this project can make.

What it emits
-------------
Four frames, from the four sections of a ``<scan>.md`` sheet:

``inventory_human.csv``   section 2b, in **exactly** the columns the model passes
                          produce, so ``score_against_reference`` and the
                          bake-off's comparisons consume it unchanged
``parts_human.csv``       section 2a — the named parts, their topographic mark
                          and their house–population pair
``table_human.csv``       section 1 — the seventeen columns, one row per printed
                          line
``legend_human.csv``      section 3 — the postal and station keys

Why it grades as it reads
-------------------------
**The register's own arithmetic is a check on the person, not only on the OCR.**
The table has to add up four ways and the ``Části osad`` pairs have to sum to the
settlement's row above them, and none of that was available while the sheet asked
only for symbols: the apparatus has no arithmetic, so a symbols-only gold could
be graded by nothing but a second reading of the same pages. Reading the whole
page puts I1–I4 and I8 back within reach *of the transcription*, per page, while
the page is still open and the image still in front of the reader.

That is why the sheet says "do not make them add up, just read them". A reader
who balances the figures produces a transcription that passes every check and
measures nothing — the same reason the models are never shown the invariants.

    python utils/lexikon_1910/read_transcription_md.py --role calibration
    python utils/lexikon_1910/read_transcription_md.py --sheet .../0019.md --write
"""

#: One ledger answer: ``   8,1   Hirschfeld › Halbgebäu О   !roster   > [post]``.
#:
#: Split on the **last** `>` rather than the first, because the left side carries
#: printed names and this project has already been bitten once by a name that
#: contained the answer marker (``Pekelec, Pekeletz >-``). The key allows `+` and
#: `?` beside the digits: `m,+` is a part the print names and the table has no
#: number for, `m,?` a part whose figure could not be read, and both are readings
#: rather than defects.
_LEDGER_RE = re.compile(r"^\s*(\d{1,3}|__)\s*,\s*([0-9]{1,3}|\+|\?)\s+(.*)$")

#: A filled-in table row. The header also opens ``| r |``; only a data row
#: carries a number, and confusing the two once made the generator's own
#: overwrite guard refuse every sheet it had just written.
_TABLE_ROW_RE = re.compile(r"^\|\s*r(\d+)\s*\|(.*)$")

#: ``## 2a — Části osad v soudním okresu Aš`` → section label and district.
_SUB_RE = re.compile(r"^##\s*(\d[ab]?)\s*—\s*(.*?)\s*$")
_DISTRICT_RE = re.compile(r"(?:soudním okresu|soudní okres|s\.\s*o\.)\s*(.+)$",
                          re.IGNORECASE)

def front_matter(text: str) -> dict:
    """The `---` block at the top, flat, without a YAML dependency.

    Only the handful of scalars this reader needs are taken. `minutes:` is kept
    as its raw inline mapping because it is the budget evidence and is meant to
    be read by a person, not joined on.
    """
    if not text.startswith("---"):
        return {}
    end = text.find("\n---", 3)
    out: dict = {}
    for line in text[3:end if end > 0 else len(text)].splitlines():
        if line.startswith((" ", "\t")) or ":" not in line:
            continue
        key, _, value = line.partition(":")
        out[key.strip()] = value.split("#")[0].strip().strip('"')
    return out


def _blocks(text: str) -> list[tuple]:
    """``[(section, district, kind, lines)]`` — the fenced blocks and table runs.

    ``kind`` is the fence's info string (``ledger``, ``legend``, ``notes``) or
    ``table`` for a run of pipe rows, which markdown does not fence.
    """
    out: list[tuple] = []
    section = district = ""
    fence = None
    comment = False
    buffer: list[str] = []
    table: list[str] = []

    def flush_table():
        if table:
            out.append((section, district, "table", list(table)))
            table.clear()

    for line in text.splitlines():
        if fence is not None:
            if line.strip().startswith("```"):
                out.append((section, district, fence, buffer))
                fence, buffer = None, []
            else:
                buffer.append(line)
            continue
        if line.strip().startswith("```"):
            flush_table()
            info = line.strip().lstrip("`").strip()
            fence, buffer = (info or "text"), []
            continue
        # AN HTML COMMENT IS NOT A HEADING, AND ITS LINES START WITH `#`. The
        # offices hint — the text layer's own read of the section — is carried in
        # a comment so it renders as guidance rather than as content, and it
        # quotes apparatus lines verbatim. One of them opens `#   rest; the image
        # decides…`, which the splitter took for a section heading and used to
        # file every offices ledger under a section called `rest;`. Nothing
        # downstream matched that, and the whole 2b block silently vanished.
        if comment:
            if "-->" in line:
                comment = False
            continue
        if line.lstrip().startswith("<!--"):
            comment = "-->" not in line
            continue
        if line.startswith("#"):
            flush_table()
            match = _SUB_RE.match(line)
            if match:
                section, rest = match.groups()
                found = _DISTRICT_RE.search(rest)
                # SLUGGED, because `district` is half the join key. `_entry_of`
                # keys a claim on `(page, district, muni_seq)` verbatim, and every
                # other producer in this pipeline — the pilot's summaries, the
                # crop filenames, the live `inventory_human.csv` — already stores
                # `ceskaskalice`. Passing the printed heading `Česká Skalice`
                # through would have made every entry unshared and scored a
                # perfect pass at zero recall, silently.
                district = lxnt.normalise(found.group(1) if found else "")
            elif line.startswith("# "):
                section = line[2:].strip().split(" ")[0]
                district = ""
            continue
        if _TABLE_ROW_RE.match(line.strip()):
            table.append(line)
        else:
            flush_table()
    flush_table()
    return out


def _key(line: str):
    """``(muni, seq, names, flag, answer)`` for one ledger line, else ``None``."""
    if "›" not in line or ">" not in line:
        return None
    match = _LEDGER_RE.match(line)
    if not match:
        return None
    muni, seq, rest = match.groups()
    left, _, answer = rest.rpartition(">")
    _muni_name, _, part = left.partition("›")
    flag = ""
    for mark in ("!roster",):
        if mark in part:
            part, flag = part.replace(mark, ""), mark
    return (muni, seq, _muni_name.strip(), part.strip(), flag, answer.strip())


def _bad_key(scan: str, district: str, line: str, problems: list) -> bool:
    """A ledger-shaped line whose KEY does not parse. Records it; returns True.

    A line carrying both `›` and `>` is a ledger row by construction — the
    generator wrote it — so a `_LEDGER_RE` miss means the KEY is malformed, not
    that the line is prose. Both readers used to `continue` on the two cases
    alike, which made a filled answer behind a mistyped key **disappear**: the
    row never reached the frame, never reached `problems`, and was not even
    counted among the blanks, so the sheet reported a clean pass at one row less.
    Scan 0118 lost its `1,1` parts entry that way, to a `)` copied off the print.

    The key is NOT widened to admit what fails here. Two shapes reach this
    branch and only one of them is a typo. The other is the generator's own
    `!roster` rows — `13,i`, `2,-?`, `4,г-`, `17,(g` — where the text layer's
    read of the number column is the damaged thing and repairing it against the
    image is the whole point of the flag. Letting the grammar swallow those
    would file a part under a key no table row has.
    """
    if "›" not in line or ">" not in line or line.lstrip().startswith("#"):
        return False
    stripped = line.strip()
    key = stripped.split(None, 1)[0]
    answer = line.rpartition(">")[2].strip()
    problems.append(
        f"  {scan} {district} {key!r}: not a ledger key — expected "
        f"`municipality,part` with the print's brackets stripped and its dash "
        f"written `0` (`1, 1)` → `1,1`, `3, —)` → `3,0`)"
        + (f"; THE ANSWER {answer[:40]!r} IS BEING DROPPED" if answer else ""))
    return True

def _symbols(answer: str, allowed: set, where: str, problems: list) -> list[tuple]:
    """``[(code, count, unsure_kind)]`` from one answer, in printed order."""
    out: list[tuple] = []
    for count, token, unsure in _TOKEN_RE.findall(answer):
        canonical = lxv.canonical(token) if len(token) > 3 else token
        if canonical not in allowed and token not in (UNREADABLE, OFF_ATLAS):
            problems.append(
                f"  {where}: {token!r} is not on the atlas — check the spelling "
                f"against symbols/manifest.csv, or write {OFF_ATLAS} if the "
                f"symbol is genuinely not there")
            continue
        if canonical in TOPOGRAPHIC:
            # It says what the place *is*, not what it has. In the institution
            # list it would read as a village having been built in the village.
            problems.append(
                f"  {where}: {canonical} is a topographic symbol in an "
                f"institution list — should it be against the name?")
            continue
        out.append((canonical, int(count) if count else 1,
                    "unsure" if unsure else
                    "unreadable" if token == UNREADABLE else
                    "off-atlas" if token == OFF_ATLAS else "certain"))
    return out


def read_offices(scan: str, blocks: list, allowed: set,
                 problems: list) -> tuple[list, int]:
    rows: list[dict] = []
    blank = 0
    for section, district, kind, lines in blocks:
        if kind != "ledger" or section != "2b":
            continue
        muni_name = ""
        for line in lines:
            if line.lstrip().startswith("=="):
                muni_name = line.split(None, 2)[-1].split("[")[0].strip()
                continue
            parsed = _key(line)
            if not parsed:
                _bad_key(scan, district, line, problems)
                continue
            muni, seq, short, part, _flag, answer = parsed
            if muni == "__" or not answer:
                blank += 1
                continue
            where = f"{scan} {district} {muni},{seq}"
            for position, (code, count, confidence) in enumerate(
                    _symbols(answer, allowed, where, problems)):
                rows.append({
                    "check": "I13_inventory", "page": scan,
                    "district": district, "muni_seq": int(muni),
                    "settlement_seq": seq, "entry_index": "",
                    "municipality": muni_name or short,
                    "settlement": part, "topographic": "",
                    "code": code, "count": count, "position": position,
                    "source": "human", "confidence": confidence,
                    "english": "", "category": "", "corroborated": "",
                    "count_text": "", "glyph": "",
                    "context": answer[:80],
                })
    return rows, blank

def read_parts(scan: str, blocks: list, problems: list) -> tuple[list, int]:
    rows: list[dict] = []
    blank = 0
    for section, district, kind, lines in blocks:
        if kind != "ledger" or section != "2a":
            continue
        for line in lines:
            if line.lstrip().startswith("=="):
                continue
            parsed = _key(line)
            if not parsed:
                _bad_key(scan, district, line, problems)
                continue
            muni, seq, _short, settlement, _flag, answer = parsed
            if muni == "__" or not answer:
                blank += 1
                continue
            # ONE SPLITTER, IN `lexikon_1910_notes`, USED BY BOTH SIDES. The
            # commas that separate the parts also sit inside a name's German twin
            # (`Hazlov, Haslau 217—2266`), the `&` residual is an entry with no
            # name, and a cross-reference in parentheses must survive intact —
            # three rules that a second copy here would drift on, and drift on
            # exactly the entries where the two readings are compared.
            for part in lxnt.split_parts(answer):
                if part["unparsed"]:
                    problems.append(
                        f"  {scan} {district} {muni},{seq}: cannot read "
                        f"{part['unparsed'][:50]!r} as `name <mark> "
                        f"houses—population`")
                    continue
                # THE ANSWER HAS TO STAND ALONE. The ledger prints the settlement
                # to the LEFT of the `›` so a transcriber twenty rows into a
                # block knows where they are; that column is a locator, not a
                # value, and an answer that leans on it (`> [ves] 162-676`)
                # parses to figures with no name and passes every other test on
                # this page. The register never prints a pair without a name, so
                # this is always a slip. Flagged, and RECORDED anyway — the loop
                # below already records and flags rather than dropping, and a
                # silently short parts list is what `grade_parts` then blames on
                # the print.
                if not part["name"]:
                    problems.append(
                        f"  {scan} {district} {muni},{seq}: part "
                        f"{part['position'] + 1} has figures but no name — "
                        f"write the name out even where it repeats the "
                        f"settlement's own")
                # TWO BRACKET TOKENS IN A ROW, and only the last is the mark:
                # `_BRACKET_RE` anchors at the END of the body, so
                # `[besides] [scattered] 2-9` files a part literally NAMED
                # `[besides]`. `[besides]` is on the atlas (`mimo to`) but it is a
                # connector, and this document's residual entry is written `&` —
                # the convention the sheet asks for and the one `parts_report`
                # counts on.
                elif part["name"].startswith("[") and part["name"].endswith("]"):
                    problems.append(
                        f"  {scan} {district} {muni},{seq}: {part['name']} is a "
                        f"symbol standing in the NAME slot — a part carries one "
                        f"mark; write the register's residual entry as `&`")
                mark = part["topographic"] or part["topographic_raw"]
                # IN SECTION 2a THE MARK'S POSITION SETTLES ITS ROLE, so a token
                # outside `TOPOGRAPHIC` is recorded and flagged, never dropped.
                # That list was derived from the offices context, where a mark in
                # the symbol list has to be told apart from an institution; here
                # it stands beside a name and can only be saying what the place
                # is. The register prints mill glyphs exactly this way —
                # `Prechtelmühle ф 1—3`, `Obermühle ф 1—25` — and `[mill]` is in
                # the institution vocabulary and NOT in `TOPOGRAPHIC`, so the
                # strict test rejected a correct reading. Whether that list
                # should grow is a question for the recon page to answer, not
                # for this parser to decide by refusing the data.
                review = bool(mark) and lxv.canonical(mark) not in TOPOGRAPHIC
                rows.append({
                    "check": "I8_parts", "page": scan, "district": district,
                    "muni_seq": int(muni), "settlement_seq": seq,
                    "part_name": part["name"],
                    "settlement": settlement, "topographic": mark,
                    "topographic_review": "yes" if review else "",
                    "houses": part["houses"],
                    "population": part["population"],
                    "position": part["position"], "source": "human",
                })
    return rows, blank

def _header_columns(lines: list[str]) -> list[str]:
    """The column names a sheet's own table header prints (``| r | seq | name | …``).

    A volume can print other columns than Bohemia's — Silesia has a fourth language
    column, ``lang_polish`` (D-133) — so a row is read against its sheet's header, and
    against ``lx.COLUMNS`` only where a sheet has none (``None``)."""
    for line in lines:
        cells = [c.strip() for c in line.strip().strip("|").split("|")]
        if cells and cells[0] == "r" and len(cells) > 1:
            return cells[1:]
    return None


def read_table(scan: str, blocks: list, problems: list,
               names: list[str] | None = None) -> list[dict]:
    """Section 1's rows, each against ``names`` — the sheet's own header
    (:func:`_header_columns`, which :func:`read_sheet` passes), else ``lx.COLUMNS``."""
    names = names or [name for name, _kind in lx.COLUMNS]
    rows: list[dict] = []
    for section, district, kind, lines in blocks:
        if kind != "table" or section != "1":
            continue
        for line in lines:
            match = _TABLE_ROW_RE.match(line.strip())
            if not match:
                continue
            position, rest = match.groups()
            cells = [c.strip() for c in rest.split("|")]
            if len(cells) and not cells[-1]:
                cells = cells[:-1]
            if len(cells) != len(names):
                problems.append(
                    f"  {scan} {district} r{position}: {len(cells)} cells for "
                    f"{len(names)} columns — a pipe was added or lost")
                continue
            row = {"page": scan, "district": district, "position": int(position),
                   "source": "human"}
            row.update({name: "" for name, _kind in lx.COLUMNS})
            row.update(dict(zip(names, cells)))
            if any(row[name] for name in names):
                rows.append(row)
    return rows


def _as_row(record: dict) -> lx.Row:
    """A gold record as the :class:`lexikon_1910.Row` the graders expect.

    Schlesien's ``lang_polish`` (D-133) is kept beside :data:`lexikon_1910.COLUMNS`:
    dropped, every Polish-speaking row failed I3 on a table that adds up."""
    cells = {name: record.get(name, "") for name, _kind in lx.COLUMNS}
    if "lang_polish" in record:
        cells["lang_polish"] = record["lang_polish"]
    return lx.Row(page=record["page"], top=record["position"],
                  bottom=record["position"], cells=cells)


def _invariants(record: dict) -> tuple:
    """:data:`lexikon_1910.INVARIANTS`, with Schlesien's Polish column counted in I3 where the
    sheet prints one (D-133). The Czech constants stay as the Czech profile states them."""
    if "lang_polish" not in record:
        return lx.INVARIANTS
    return tuple(lx.Invariant(i.key, i.label, i.parts + ("lang_polish",), i.whole, i.scope)
                 if i.key == "I3_language" else i for i in lx.INVARIANTS)


def _reading_order(record: dict) -> tuple:
    """Sort key that keeps one court's table together across its scans."""
    return (record["district"], int(record["page"]), record["position"])


def _same_run(previous: dict | None, record: dict) -> bool:
    """Whether ``record`` continues the table ``previous`` belongs to.

    A court's table runs down one scan and on at the head of the next, so a
    municipality printed at the foot of a page has its remaining settlements
    over the page. Rows on the same scan or the scan directly after it, under
    the same court, are one run; another court, or a gap in the scans, is not.
    """
    if previous is None or previous["district"] != record["district"]:
        return False
    return 0 <= int(record["page"]) - int(previous["page"]) <= 1


def grade_table(records: list[dict]) -> list[dict]:
    """I1–I4 on the transcription itself.

    A failure here is either an OCR error in the printed table — which is a
    finding, since it is what the gold exists to measure — or a slip of the
    transcriber's, which is the other thing this was never able to see. Which of
    the two it is has to be settled by eye, against the image, and the point of
    running it per page is that the image is still open.

    A BLOCK IS CARRIED ACROSS SCANS. Graded one scan at a time, a municipality
    split by a page break was summed without the settlements printed overleaf:
    Trutnov's row closes scan 0450 with two of its three settlements, the town
    itself opens scan 0451, and I4 failed in ten columns on a block that adds
    up exactly. Pass the records of every sheet in the set, in the sheets' own
    order. Where the next scan is not in the set the block cannot be completed,
    and a sum that falls short there is `na`, not `fail`.
    """
    out: list[dict] = []
    blocks: list[lx.Block] = []
    open_at_foot: set[int] = set()
    # Only the court printed LAST on a scan can run on over the page, and the
    # records arrive in the sheet's own order, so the last one names it.
    last_court = {record["page"]: record["district"] for record in records}
    current: lx.Block | None = None
    previous: dict | None = None

    def close_run() -> None:
        if (current is not None and previous is not None
                and last_court[previous["page"]] == previous["district"]):
            open_at_foot.add(current.index)

    for record in sorted(records, key=_reading_order):
        row = _as_row(record)
        for invariant in _invariants(record):
            verdict, detail = lx.grade_row(row, invariant)
            out.append({"check": invariant.key, "page": record["page"],
                        "district": record["district"],
                        "row": record["position"], "verdict": verdict,
                        "detail": detail})
        if not _same_run(previous, record):
            close_run()
            current = None
        previous = record
        if row.is_municipality:
            current = lx.Block(page=record["page"], index=len(blocks),
                               municipality=row,
                               court_label=record["district"])
            blocks.append(current)
        elif current is not None and not row.is_of_which:
            current.settlements.append(row)
    close_run()
    for block in blocks:
        for column, (verdict, detail) in lx.grade_block_sum(block).items():
            if verdict == "fail" and block.index in open_at_foot:
                verdict = "na"
                detail += (" — the block is open at the foot of its scan and "
                           "the next scan is not in this set")
            out.append({"check": "I4_block", "page": block.page,
                        "district": block.court_label,
                        "row": f"muni@{block.municipality.top}",
                        "verdict": verdict, "detail": f"{column}: {detail}"})
    return out


def _table_index(table: list[dict]) -> dict:
    """``(page, district, muni_seq, settlement_seq) -> row`` from the gold table.

    **Joined on the transcriber's own reading of column 1, not on a name.**
    ``lexikon_1910_notes.parts_check`` matches by name for a good reason — against
    the machine reading, column 1 is the most heavily damaged text on the page and
    joining on it would lose entries to the OCR rather than to disagreement. That
    reason does not apply here: the number in this table was read by the person
    who also read the parts, off the same image, and it is one of the things the
    gold set exists to grade. If it is wrong, I8 is supposed to say so.

    Settlements are numbered by printed order within their block, which is the
    numbering — they run 1..n densely inside a municipality, the same fact
    ``_roster`` relies on one document up.

    The count carries over a page break with its block (:func:`_same_run`), so
    a settlement printed at the head of the next scan keeps its municipality's
    number and its own place in the run. Each row is keyed by the scan it is
    printed on, which is where its parts entry is printed too.
    """
    index: dict = {}
    muni_seq = None
    settlement = 0
    previous: dict | None = None
    for row in sorted(table, key=_reading_order):
        if not _same_run(previous, row):
            muni_seq, settlement = None, 0
        previous = row
        key_prefix = (row["page"], row["district"])
        if _as_row(row).is_municipality:
            value, status = lx.parse_int_cell(row.get("seq"))
            muni_seq, settlement = (value if status == "ok" else None), 0
            if muni_seq is not None:
                index[(*key_prefix, muni_seq, "0")] = row
        elif muni_seq is not None and not _as_row(row).is_of_which:
            settlement += 1
            index[(*key_prefix, muni_seq, str(settlement))] = row
    return index


def grade_parts(parts: list[dict], table: list[dict]) -> list[dict]:
    """I8 on the transcription: the parts pairs sum to their settlement's row.

    This is the check that grades the *person*. The `Části osad` figures are the
    same quantities the table prints, set in different type in a different part of
    the page, so a reading of one that disagrees with a reading of the other is an
    error somewhere the transcriber can still go and look at.
    """
    index = _table_index(table)
    grouped: dict[tuple, list] = {}
    for part in parts:
        grouped.setdefault((part["page"], part["district"], part["muni_seq"],
                            part["settlement_seq"]), []).append(part)

    out: list[dict] = []
    for key, members in sorted(grouped.items()):
        page, district, muni, seq = key
        where = f"{muni},{seq} {members[0]['settlement'][:24]}"
        if seq in ("?", "+"):
            out.append({"check": "I8_parts", "page": page, "district": district,
                        "row": where, "verdict": "na",
                        "detail": "key carries no part figure to join on"})
            continue
        row = index.get(key)
        if row is None:
            out.append({"check": "I8_parts", "page": page, "district": district,
                        "row": where, "verdict": "na",
                        "detail": "no table row for this key on this scan — the "
                                  "apparatus runs on from an earlier page"})
            continue
        for column, field in (("houses", "houses"), ("population", "pop_total")):
            values = [lx.parse_int_cell(m[column]) for m in members]
            whole, whole_status = lx.parse_int_cell(row.get(field))
            if whole_status != "ok" or any(st != "ok" for _v, st in values):
                out.append({"check": "I8_parts", "page": page,
                            "district": district, "row": where,
                            "verdict": "unparseable" if whole_status == "bad"
                            else "na", "detail": f"{column} not readable on both "
                                                 f"sides"})
                continue
            total = sum(v for v, _st in values)
            out.append({"check": "I8_parts", "page": page, "district": district,
                        "row": where,
                        "verdict": "pass" if total == whole else "fail",
                        "detail": "" if total == whole
                        else f"{column}: parts={total} row={whole}"})
    return out

# Section 3 — the legend

def read_legend(scan: str, blocks: list) -> list[dict]:
    rows: list[dict] = []
    for section, district, kind, lines in blocks:
        if kind != "legend" or section != "3":
            continue
        for line in lines:
            if not line.strip():
                continue
            # ONE DEFINITION OF A LEGEND KEY, in `lexikon_1910_notes`. The old
            # copy here carried its own regex and took the place name as
            # `[^)]*?` — everything up to the next `)` — which cut
            # `Kupferhammer-Grünthal (Sasko)` at the bracket AND read the `sko)`
            # as the next key, losing two entries on scan 0118 alone. The
            # machine side had the same hole; fixing it in one place is the only
            # way the two readings stay comparable entry by entry.
            marks = lxnt.legend_key_marks(line)
            for position, mark in enumerate(marks):
                end = (marks[position + 1].start()
                       if position + 1 < len(marks) else len(line))
                rows.append({"check": "I9_legend", "page": scan,
                             "district": district, "key": mark.group(1).strip(),
                             # Trimmed the way `_legend_entries` trims, so the
                             # two sides are compared on the name and not on the
                             # register's sentence punctuation.
                             "place": line[mark.end():end].strip(" .,;"),
                             "source": "human"})
    return rows


def read_notes(blocks: list) -> list[str]:
    return [line.strip() for _s, _d, kind, lines in blocks if kind == "notes"
            for line in lines if line.strip()]

def read_attributes(scan: str, blocks: list) -> list[dict]:
    """What the sheet writes beside the school and cooperative glyphs (section 2b).

    Read from the WHOLE answer, by the parser the reader's lines go through
    (:mod:`lexikon_1910_attributes`). `read_offices` keeps only the first 80
    characters of an answer as context, which is enough to find a symbol again
    and not enough to hold a town's cooperative list.
    """
    parts: list[tuple] = []
    for section, district, kind, lines in blocks:
        if kind != "ledger" or section != "2b":
            continue
        for line in lines:
            parsed = _key(line)
            if not parsed:
                continue
            muni, seq, _short, _part, _flag, answer = parsed
            if muni == "__" or not answer:
                continue
            parts.append((scan, district, int(muni), seq, answer))
    return lxat.attribute_records(parts, source="human")


#: The roles the printed order is learned from. Never ``certification``: those
#: sheets are sealed until the reader is certified against them, and an order
#: learned from them would have read them.
ORDER_ROLES = ("purposive", "calibration")

#: The three introductions' worked examples (D-149): each volume's *Anleitung* / *Návod*
#: reads one entry out in full — Sternberg (Mähren, p. IX), Odrau (Schlesien, p. VIII),
#: Bílina (Čechy, p. VIII) — in the order the print sets the marks. Their marks, as the
#: volume decodes them, with the volume's own words beside each.
WORKED_EXAMPLES = ROOT / "reference" / "places" / "order_worked_examples.csv"


def read_worked_examples(path: Path = WORKED_EXAMPLES) -> list[dict]:
    """The worked examples as :func:`read_order_reference` rows, one run per example.

    Their ``page`` is ``intro:<volume>``, which no reading's page is, so a leave-page-out
    never drops them: they are the volume's statement of its order, not a reading of a
    gold page. They add what ten pages never printed together — the kindergarten before
    the day nursery (Sternberg) — and nothing they print runs against the sheets.
    """
    import csv
    runs: dict[tuple, list[tuple[int, str]]] = {}
    with Path(path).open(encoding="utf-8", newline="") as fh:
        for row in csv.DictReader(fh):
            runs.setdefault((row["volume"], row["place"]), []).append((int(row["position"]), row["token"]))
    return [{"page": f"intro:{volume}", "district": place, "muni_seq": 0, "settlement_seq": "0",
             "named_part": 0, "codes": [token for _n, token in sorted(marks)]}
            for (volume, place), marks in sorted(runs.items())]


def read_order_reference(roles=ORDER_ROLES, abbreviations=None) -> list[dict]:
    """The runs of marks the gold sheets print, for `lexikon_1910_institutions` I22.

    One row per run — a filled section-2b line, cut again at each named part
    (``Valdice:``) and with parenthesised text left out — as
    ``{"page", "district", "muni_seq", "settlement_seq", "named_part", "codes"}``,
    in the order the sheets print them. ``codes`` are the bracketed symbols
    only, found by the decoder the readers' lines go through, so the reference
    and a reading are cut by one rule.

    **Every filled line counts, whatever the sheet's ``status:``** — a draft
    sheet's lines are in, a blank key is not — and so does the few-shot page:
    it is held out of the *scored* gold because the reader is shown it, and
    the order is not a reader. A token the atlas does not have (a typo such as
    ``[coopearative]``) is not decoded and is simply absent from its run; the
    reader's own report (`read_sheet`) is what names it.

    Reads the sheets, writes nothing, and refuses a sealed role.
    """
    sealed = set(roles) - set(ORDER_ROLES)
    if sealed:
        raise ValueError(f"the printed order is learned from {ORDER_ROLES} only, "
                         f"not {sorted(sealed)}")
    if abbreviations is None:
        abbreviations = lxin.load_abbreviations(ABBREVIATIONS, lang="cs")
    rows: list[dict] = []
    for role in roles:
        for path in sorted((GOLD_ROOT / role).glob("[0-9][0-9][0-9][0-9].md")):
            text = path.read_text(encoding="utf-8")
            scan = front_matter(text).get("scan") or path.stem
            for section, district, kind, lines in _blocks(text):
                if kind != "ledger" or section != "2b":
                    continue
                for line in lines:
                    parsed = _key(line)
                    if not parsed:
                        continue
                    muni, seq, _short, _part, _flag, answer = parsed
                    if muni == "__" or not answer:
                        continue
                    entry = lxin.Entry(district=district, page=scan,
                                       muni_seq=int(muni), settlement_seq=seq,
                                       text=answer, index=0)
                    records = lxin.decode_entry(entry, abbreviations)
                    for named_part, run in enumerate(
                            lxin.order_runs(records, text=answer)):
                        rows.append({"page": scan, "district": district,
                                     "muni_seq": int(muni), "settlement_seq": seq,
                                     "named_part": named_part,
                                     "codes": [r["code"] for r in run]})
    return rows


def read_sheet(path: Path, allowed: set) -> dict:
    text = path.read_text(encoding="utf-8")
    meta = front_matter(text)
    scan = meta.get("scan") or path.stem
    blocks = _blocks(text)
    problems: list[str] = []
    offices, blank_offices = read_offices(scan, blocks, allowed, problems)
    parts, blank_parts = read_parts(scan, blocks, problems)
    table = read_table(scan, blocks, problems, _header_columns(text.splitlines()))
    return {
        "scan": scan, "meta": meta, "problems": problems,
        "offices": offices, "parts": parts, "table": table,
        "attributes": read_attributes(scan, blocks),
        "legend": read_legend(scan, blocks), "notes": read_notes(blocks),
        "blank": blank_offices + blank_parts,
        "verdicts": grade_table(table) + grade_parts(parts, table),
    }


def grade_sheets(sheets: list[dict]) -> list[dict]:
    """I1–I4 and I8 over the whole set of sheets at once.

    One pass rather than one per sheet, because a block and its parts are only
    complete with the rows the next scan prints (:func:`grade_table`).
    """
    table = [row for sheet in sheets for row in sheet["table"]]
    parts = [part for sheet in sheets for part in sheet["parts"]]
    return grade_table(table) + grade_parts(parts, table)


def report(sheets: list[dict]) -> None:
    print(f"\n{'scan':>6}  {'status':<12} {'table':>6} {'parts':>6} "
          f"{'offices':>8} {'legend':>7} {'notes':>6}  minutes")
    for sheet in sheets:
        meta = sheet["meta"]
        print(f"{sheet['scan']:>6}  {meta.get('status', '?'):<12} "
              f"{len(sheet['table']):6d} {len(sheet['parts']):6d} "
              f"{len(sheet['offices']):8d} {len(sheet['legend']):7d} "
              f"{len(sheet['notes']):6d}  {meta.get('minutes', '')}")

    verdicts = grade_sheets(sheets)
    if verdicts:
        print("\n  the register's own arithmetic, applied to the TRANSCRIPTION:")
        by_check: dict[str, Counter] = {}
        for verdict in verdicts:
            by_check.setdefault(verdict["check"], Counter())[verdict["verdict"]] += 1
        for check, counts in sorted(by_check.items()):
            scored = counts["pass"] + counts["fail"]
            rate = f"{counts['pass'] / scored:6.1%}" if scored else "     —"
            print(f"    {check:<16} {rate}  "
                  + "  ".join(f"{k} {counts[k]}" for k in lx.VERDICTS if counts[k]))
        print("\n    A failure is an OCR error in the printed table or a slip of "
              "the transcriber's.\n    Which one has to be settled by eye, "
              "against the image, before the page is closed.")
        for verdict in verdicts:
            if verdict["verdict"] == "fail":
                print(f"      {verdict['check']:<14} {verdict['page']} "
                      f"{verdict['district'][:16]:16s} {verdict['row']}  "
                      f"{verdict['detail']}")

    problems = [p for s in sheets for p in s["problems"]]
    if problems:
        print(f"\n  {len(problems)} problem(s):")
        for problem in problems[:40]:
            print(problem)
    blank = sum(s["blank"] for s in sheets)
    print(f"\n  {blank} keys still blank"
          "  (a blank key is DATA where the register prints nothing there)")


def write(sheets: list[dict], out_dir: Path) -> None:
    from utils.lexikon_1910.lexikon_1910_pages import FEWSHOT_PAGE

    out_dir.mkdir(parents=True, exist_ok=True)
    for name, key in (("inventory_human.csv", "offices"),
                      ("attributes_human.csv", "attributes"),
                      ("parts_human.csv", "parts"),
                      ("table_human.csv", "table"),
                      ("legend_human.csv", "legend")):
        rows = [r for sheet in sheets for r in sheet[key]]
        if name == "inventory_human.csv":
            # THE SCORED GOLD LEAVES OUT THE FEW-SHOT PAGE. That scan is shown to
            # the whole-page reader as its worked example, so a claim on it would
            # grade a model against its own prompt (`lexikon_1910_pages`,
            # `FEWSHOT_PAGE` / `GOLD_SCORED_PAGES`). Its other frames are written:
            # nothing scores a symbol against them.
            held = [r for r in rows if int(r["page"]) == FEWSHOT_PAGE]
            rows = [r for r in rows if int(r["page"]) != FEWSHOT_PAGE]
            if held:
                print(f"  held out of {name}: {len(held)} rows on scan "
                      f"{FEWSHOT_PAGE:04d}, the few-shot page")
        if not rows:
            continue
        path = out_dir / name
        with path.open("w", encoding="utf-8", newline="") as fh:
            writer = csv.DictWriter(fh, fieldnames=list(rows[0]))
            writer.writeheader()
            writer.writerows(rows)
        print(f"  wrote {len(rows):5d} rows  {path}")


def main() -> int:
    # The report names Czech districts and prints the atlas tokens back. A
    # Windows console defaults to cp1250 here, which turned `Aš` into `A?` in
    # the very line a transcriber uses to find the row they mis-read.
    for stream in (sys.stdout, sys.stderr):
        try:
            stream.reconfigure(encoding="utf-8", errors="replace")
        except (AttributeError, ValueError):
            pass
    ap = argparse.ArgumentParser(
        description=__doc__,
        formatter_class=argparse.RawDescriptionHelpFormatter)
    ap.add_argument("--role", default="calibration",
                    choices=("calibration", "certification", "purposive", "gold"),
                    help="gold = calibration and purposive together, the set the "
                         "r5 bake-off is scored on (D-81); certification stays sealed")
    ap.add_argument("--sheet", default="", help="one sheet, instead of a role")
    ap.add_argument("--out", default=str(OUT_DIR))
    ap.add_argument("--write", action="store_true",
                    help="write the four frames for the comparison tools")
    args = ap.parse_args()

    if args.sheet:
        paths = [Path(args.sheet)]
    else:
        roles = ("calibration", "purposive") if args.role == "gold" else (args.role,)
        paths = [p for role in roles
                 for p in sorted((GOLD_ROOT / role).glob("[0-9][0-9][0-9][0-9].md"))]
    paths = [p for p in paths if p.exists()]
    if not paths:
        print("no sheets found — run make_gold_worksheet.py first")
        return 1

    abbreviations = lxin.load_abbreviations(ABBREVIATIONS, lang="cs")
    allowed = lxv.vocabulary(abbreviations) | {OFF_ATLAS} | TOPOGRAPHIC
    sheets = [read_sheet(path, allowed) for path in paths]
    report(sheets)
    if args.write:
        write(sheets, Path(args.out))
    return 1 if any(s["problems"] for s in sheets) else 0
