The settlement tables join on the canonical birthplace (birthplace_canonical, notebook 02 §4d, D-261): birth_place_settlement_id / birth_place_settlement_sk_id, set exactly where the canonical place is a settlement and then equal to birth_settlement_id / birth_settlement_sk_id. On a data/final built before §4d the person-side readers fall back to those two (0.3.0, person_link); the municipality join keeps birth_municipality_settlement_id, which the canonical block does not restate.

The census covariates are not copied here. Each settlement table carries the census foreign key of its settlement — census_okres_id (Czech, the pooled unit of its okres, D-18) and unit_id (Slovak, its járás or chartered town, D-19) — and the census tables stay in data/final/census. A person joins the census on their own key, as notebook 02 §4b does: birth_census_okres_id (D-247) and birth_census_jaras_id (D-262), both of which follow the settlement link. census_key_agreement checks that the two routes give the same census unit for every linked birth (0.4.0): before D-262 the Slovak person key was the written járás and disagreed with the settlement's unit wherever the link had moved it.

Why two Czech tables. The 1910 register (register_rechecked, D-200) prints its institutions and cooperatives per municipality: a part's claims are summed into its municipality's row (REGISTER_VARIABLES.md, step 6). Copying them to every hamlet would state that the hamlet had them. So they live in birthplace_municipality_cz, keyed by the municipality's settlement_id (the key of register_municipalities), and the settlement table holds only what is the settlement's own: its 1910 status, its point, the register's own figures row where the register prints one for it, and the amateur-theatre stocks of the settlement panel (D-254/D-255).

The municipality join is gated. birth_in_register_municipalities is a key comparison (birth_settlement 0.16.x): where it is False the register holds the municipality on a row the gazetteer does not, and joining on the settlement id alone would attach that row (39 legion records in the build of 2026-11-18). The gate is a column the person table already carries, so the merge itself stays plain.

The statutory cities (Prague, Liberec and the nine Moravian and Silesian cities) have no row in register_municipalities; register_statutory_counts carries their prose into the shared municipal columns (D-232). They enter the municipality table as rows of their own, flagged muni_count_source = "prose" (include_statutory_cities). Each city is its own okres, so its theatre stocks come from theatre_okres_year (theatre_unit = "statutory_okres"): the settlement panel files Prague's companies under quarters that have no 1910 okres, and holds praha:1 at zero.

Which settlements a municipality's theatre sums (0.2.0). The members of a municipality are the settlements the birth link itself rolls up to it — birth_settlement P5 applied to every settlement of settlements_1910 (load_rollup): the register part's municipality row, else the lexikon parent_1910 resolved in the okres. So a birth's settlement is always inside the aggregate of the municipality it is linked to (membership_consistency, 0 by construction). 0.1.0 took only the parts anchored under the municipality's own row in register_places (an inner merge on that row's edition, unlogged): 480 legion and 646 VÚA gated births had a settlement outside their municipality's aggregate, and on 287 legion / 447 VÚA births muni_theatre_* read False where a member was active (Teplice-Šanov without Teplice). Where the register still anchors a part (any edition) or the municipality itself to a settlement the roll-up refuses, or a member is outside the theatre panel, muni_theatre_members_incomplete is True and, under the default incomplete_policy="na", a side with no activity among the members reached is &lt;NA&gt;, not False (mask_incomplete); a side with activity is a lower bound.

Missing stays missing: a settlement outside the theatre panel (no 1910 okres), a municipality the register did not anchor, a figure the register did not print — all &lt;NA&gt;, never 0 or False. A 0 is a 0 only where the source read the unit (a register municipality read, a settlement in the theatre panel, a municipality whose members are complete: the NIK database records every Czech company, so a place without one is a true zero of the treatment, THEATRE_MEASURE.md).

The register is a model-read source with a measured error (D-55 correction still to come): every register column is an error-prone proxy whose certification figures go beside any result (CAVEATS).

def language_shares(df: pd.DataFrame, prefix: str = "") -> pd.DataFrame:
    """``<prefix>lang_<l>_share`` = lang_<l> / (pop_total − foreigners), the register's I3 base.

    ``<NA>`` where a count or the base is missing, or the base is not positive; a share above 1
    (a misread row) is kept, and the QA check reports it rather than clipping it."""
    out = df.copy()
    base = (out[f"{prefix}pop_total"].astype("Float64") - out[f"{prefix}foreigners"].astype("Float64"))
    base = base.where(base > 0)
    for lang in LANGS:
        out[f"{prefix}lang_{lang}_share"] = (out[f"{prefix}lang_{lang}"].astype("Float64") / base)
    return out

def settlement_register_figures(places: pd.DataFrame, edition_priority=EDITION_PRIORITY,
                                log: list | None = None) -> pd.DataFrame:
    """One row per settlement: the register row that is the settlement's *own*.

    A part row anchored to it (``place_figures_level = "part"``), else a municipality row anchored to
    it when that municipality prints no parts (``"municipality_no_parts"``: then the municipality is
    the settlement). A municipality with parts prints its *total* on row 0, which is not the
    settlement's own figure, so it gives none here (it is in the municipality table). Two own rows in
    one edition are refused (``<NA>``); across editions :data:`EDITION_PRIORITY` decides."""
    log = [] if log is None else log
    p = places.copy()
    p["court_key"] = p["court_key"].astype(str)
    mkey = ["edition", "court_key", "muni_seq"]
    n_parts = p[p["settlement_seq"] > 0].groupby(mkey).size().rename("_n_part_rows").reset_index()
    p = _merge(p, n_parts, mkey, "m:1", "register_places x part counts", log)
    p["_n_part_rows"] = p["_n_part_rows"].fillna(0).astype(int)
    anchored = p[p["settlement_id"].notna()]
    part = anchored[anchored["settlement_seq"] > 0].assign(place_figures_level="part")
    solo = anchored[(anchored["settlement_seq"] == 0) & (anchored["_n_part_rows"] == 0)]
    own = pd.concat([part, solo.assign(place_figures_level="municipality_no_parts")])
    dup = own.duplicated(["edition", "settlement_id"], keep=False)
    log.append({"merge": "own register row: refused (two in one edition)", "rows_before": int(dup.sum())})
    own = own[~dup]
    rank = {e: i for i, e in enumerate(edition_priority)}
    own = own.assign(_rank=own["edition"].map(rank).fillna(len(rank))).sort_values(["settlement_id", "_rank"])
    own = own.drop_duplicates("settlement_id")
    own["place_register_key"] = (own["edition"] + "|" + own["court_key"] + "|" + own["muni_seq"].astype(str)
                                 + "|" + own["settlement_seq"].astype(str))
    own["place_status"] = own["place_status"].replace("", pd.NA).astype("string")
    own["place_figures_check"] = own["figures_check"].replace("", "all_hold").astype("string")
    out = own[["settlement_id", "place_register_key", "place_figures_level", "place_status",
               "place_figures_check", *PLACE_FIGURES]]
    out = out.rename(columns={c: f"place_{c}" for c in PLACE_FIGURES})
    return language_shares(out, prefix="place_").reset_index(drop=True)

def theatre_stocks(panel: pd.DataFrame, key: str, stock_year: int = STOCK_YEAR,
                   prefix: str = "theatre_") -> pd.DataFrame:
    """Collapse a unit × year theatre panel to pre-war stocks, one row per unit, both sides.

    ``ever`` (any activity by *stock_year*), ``first_year`` (first year with activity),
    ``years_active``, ``first_founded`` (first founding recorded), ``active_<Y>`` /
    ``ensembles_<Y>`` (in the stock year), ``performances`` (minimum performances summed) and
    ``national_fund`` (National Theatre fund records). Years after *stock_year* are dropped; a
    first year with no event is ``<NA>``."""
    p = panel[panel["year"] <= stock_year]
    units = pd.Index(p[key].drop_duplicates(), name=key)
    out = pd.DataFrame(index=units)
    for s in SIDES:
        act = p[f"any_activity_{s}"].astype(bool)
        g = act.groupby(p[key])
        out[f"{prefix}ever_{s}"] = g.any().reindex(units).astype("boolean")
        out[f"{prefix}years_active_{s}"] = g.sum().reindex(units).astype("Int64")
        out[f"{prefix}first_year_{s}"] = p.loc[act].groupby(key)["year"].min().reindex(units).astype("Int64")
        fnd = p[f"founded_{s}"] > 0
        out[f"{prefix}first_founded_{s}"] = p.loc[fnd].groupby(key)["year"].min().reindex(units).astype("Int64")
        last = p[p["year"] == stock_year].set_index(key)
        out[f"{prefix}active_{stock_year}_{s}"] = last[f"any_activity_{s}"].reindex(units).astype("boolean")
        out[f"{prefix}ensembles_{stock_year}_{s}"] = last[f"ensembles_active_{s}"].reindex(units).astype("Int64")
        out[f"{prefix}performances_{s}"] = p.groupby(key)[f"performances_min_{s}"].sum().reindex(units).astype("Int64")
        out[f"{prefix}national_fund_{s}"] = p.groupby(key)[f"national_theatre_{s}"].sum().reindex(units).astype("Int64")
    return out.reset_index()

def aggregate_panel(panel: pd.DataFrame, members: pd.DataFrame, unit: str, log: list) -> pd.DataFrame:
    """Sum a settlement × year panel to *unit* × year through a settlement → unit membership
    (one unit per settlement): counts summed, ``any_activity`` OR-ed. Settlements of no unit drop."""
    cols = _panel_columns()

def members_completeness(munis: pd.DataFrame, members: pd.DataFrame, children: pd.DataFrame,
                         rollup: pd.DataFrame, panel_ids, log: list) -> pd.DataFrame:
    """One row per register municipality: ``n_members``, ``n_members_in_panel``, ``n_unreached``,
    ``members_incomplete``. *Unreached*: the municipality's own settlement, or a part the register
    anchors under it (:func:`register_children`), to which the roll-up gives **no** municipality
    (refused: two owners, a name conflict), so its activity is in no aggregate; and the
    municipality's own settlement when the roll-up files it under another municipality (the row's
    own place is then not in its aggregate: *Šárovcova Lhota*). A *part* the roll-up puts in
    another municipality is that one's (the link's verdict) and is only counted in the log.
    Incomplete = an unreached child, or a member outside the theatre panel."""
    key = "municipality_settlement_id"
    out = munis[["settlement_id"]].astype("string").rename(columns={"settlement_id": key})
    kids = pd.concat([out.assign(settlement_id=out[key]), children], ignore_index=True).drop_duplicates()
    rolled = rollup[["settlement_id", "municipality_settlement_id"]].rename(columns={key: "_rolled"})
    kids = _merge(kids, rolled, "settlement_id", "m:1", "register children x settlement roll-up", log)
    elsewhere = kids["_rolled"].notna() & (kids["_rolled"] != kids[key])
    log.append({"merge": "register children the roll-up puts in another municipality (counted there)",
                "rows_before": int(elsewhere.sum())})
    own_away = elsewhere & (kids["settlement_id"] == kids[key])
    unreached = kids[kids["_rolled"].isna() | own_away].groupby(key).size().rename("n_unreached").reset_index()
    m = members.assign(_in_panel=members["settlement_id"].isin(pd.Index(panel_ids)))
    counts = m.groupby(key).agg(n_members=("settlement_id", "size"), n_members_in_panel=("_in_panel", "sum"))
    out = _merge(out, counts.reset_index(), key, "1:1", "register municipalities x member counts", log)
    out = _merge(out, unreached, key, "1:1", "register municipalities x unreached children", log)
    ints = ["n_members", "n_members_in_panel", "n_unreached"]

birthplace_covariates.py — the pre-war characteristics of the place each birth links to
=====================================================================================

Three tables, one per frame and level, each on its own declared key, built from ``data/final``
only and kept normalised: the estimation frame joins them to persons by foreign key at the last
step, with no manipulation in the merge.

===============================  ===============================  ======================================
table                            key                              a person joins on
===============================  ===============================  ======================================
``birthplace_settlement_cz``     ``settlement_id``                ``birth_place_settlement_id``
``birthplace_municipality_cz``   ``municipality_settlement_id``   ``birth_municipality_settlement_id``,
                                                                  only where
                                                                  ``birth_in_register_municipalities``
                                                                  or ``birth_link_unit ==
                                                                  "statutory_okres"`` (see below)
``birthplace_settlement_sk``     ``idtel``                        ``birth_place_settlement_sk_id``
===============================  ===============================  ======================================

The settlement tables join on the **canonical birthplace** (``birthplace_canonical``, notebook 02 §4d,
D-261): ``birth_place_settlement_id`` / ``birth_place_settlement_sk_id``, set exactly where the
canonical place is a settlement and then equal to ``birth_settlement_id`` / ``birth_settlement_sk_id``.
On a ``data/final`` built before §4d the person-side readers fall back to those two (0.3.0,
:func:`person_link`); the municipality join keeps ``birth_municipality_settlement_id``, which the
canonical block does not restate.

**The census covariates are not copied here.** Each settlement table carries the census foreign key of its
settlement — ``census_okres_id`` (Czech, the pooled unit of its okres, D-18) and ``unit_id`` (Slovak, its járás or
chartered town, D-19) — and the census tables stay in ``data/final/census``. A *person* joins the census on their own
key, as notebook 02 §4b does: ``birth_census_okres_id`` (D-247) and ``birth_census_jaras_id`` (D-262), both of which
follow the settlement link. :func:`census_key_agreement` checks that the two routes give the same census unit for
every linked birth (0.4.0): before D-262 the Slovak person key was the written járás and disagreed with the
settlement's unit wherever the link had moved it.

**Why two Czech tables.** The 1910 register (``register_rechecked``, D-200) prints its institutions
and cooperatives per *municipality*: a part's claims are summed into its municipality's row
(REGISTER_VARIABLES.md, step 6). Copying them to every hamlet would state that the hamlet had
them. So they live in ``birthplace_municipality_cz``, keyed by the municipality's
``settlement_id`` (the key of ``register_municipalities``), and the settlement table holds only what
is the settlement's own: its 1910 status, its point, the register's own figures row where the
register prints one for it, and the amateur-theatre stocks of the settlement panel (D-254/D-255).

**The municipality join is gated.** ``birth_in_register_municipalities`` is a *key* comparison
(birth_settlement 0.16.x): where it is False the register holds the municipality on a row the
gazetteer does not, and joining on the settlement id alone would attach that row (39 legion
records in the build of 2026-11-18). The gate is a column the person table already carries, so the
merge itself stays plain.

**The statutory cities** (Prague, Liberec and the nine Moravian and Silesian cities) have no row in
``register_municipalities``; ``register_statutory_counts`` carries their prose into the shared
municipal columns (D-232). They enter the municipality table as rows of their own, flagged
``muni_count_source = "prose"`` (``include_statutory_cities``). Each city is its own okres, so its
theatre stocks come from ``theatre_okres_year`` (``theatre_unit = "statutory_okres"``): the
settlement panel files Prague's companies under quarters that have no 1910 okres, and holds
``praha:1`` at zero.

settlements the *birth link itself* rolls up to it — ``birth_settlement`` P5 applied to every
settlement of ``settlements_1910`` (:func:`load_rollup`): the register part's municipality row, else
the lexikon ``parent_1910`` resolved in the okres. So a birth's settlement is always inside the
aggregate of the municipality it is linked to (:func:`membership_consistency`, 0 by construction).

# --------------------------------------------------------------------------- merge discipline

def _merge(left: pd.DataFrame, right: pd.DataFrame, on, validate: str, label: str,
           log: list) -> pd.DataFrame:
    """Left merge on *on* with ``validate``; asserts the row count is unchanged and logs the rows
    before and after, the left rows with no match and the right keys no left row used."""
    out = left.merge(right, how="left", on=on, validate=validate, indicator="_m")
    if len(out) != len(left):
        raise AssertionError(f"{label}: merge changed rows {len(left)} -> {len(out)}")
    keys = [on] if isinstance(on, str) else list(on)
    used = right[keys].drop_duplicates().merge(left[keys].drop_duplicates(), how="left", indicator="_u")
    log.append({"merge": label, "validate": validate, "rows_before": len(left), "rows_after": len(out),
                "left_unmatched": int((out["_m"] == "left_only").sum()), "right_rows": len(right),
                "right_keys_unused": int((used["_u"] == "left_only").sum())})
    return out.drop(columns="_m")


# --------------------------------------------------------------------------- shares

def language_shares(df: pd.DataFrame, prefix: str = "") -> pd.DataFrame:
    """``<prefix>lang_<l>_share`` = lang_<l> / (pop_total − foreigners), the register's I3 base.

    ``<NA>`` where a count or the base is missing, or the base is not positive; a share above 1
    (a misread row) is kept, and the QA check reports it rather than clipping it."""
    out = df.copy()
    base = (out[f"{prefix}pop_total"].astype("Float64") - out[f"{prefix}foreigners"].astype("Float64"))
    base = base.where(base > 0)
    for lang in LANGS:
        out[f"{prefix}lang_{lang}_share"] = (out[f"{prefix}lang_{lang}"].astype("Float64") / base)
    return out

def settlement_register_figures(places: pd.DataFrame, edition_priority=EDITION_PRIORITY,
                                log: list | None = None) -> pd.DataFrame:
    """One row per settlement: the register row that is the settlement's *own*.

    A part row anchored to it (``place_figures_level = "part"``), else a municipality row anchored to
    it when that municipality prints no parts (``"municipality_no_parts"``: then the municipality is
    the settlement). A municipality with parts prints its *total* on row 0, which is not the
    settlement's own figure, so it gives none here (it is in the municipality table). Two own rows in
    one edition are refused (``<NA>``); across editions :data:`EDITION_PRIORITY` decides."""
    log = [] if log is None else log
    p = places.copy()
    p["court_key"] = p["court_key"].astype(str)
    mkey = ["edition", "court_key", "muni_seq"]
    n_parts = p[p["settlement_seq"] > 0].groupby(mkey).size().rename("_n_part_rows").reset_index()
    p = _merge(p, n_parts, mkey, "m:1", "register_places x part counts", log)
    p["_n_part_rows"] = p["_n_part_rows"].fillna(0).astype(int)
    anchored = p[p["settlement_id"].notna()]
    part = anchored[anchored["settlement_seq"] > 0].assign(place_figures_level="part")
    solo = anchored[(anchored["settlement_seq"] == 0) & (anchored["_n_part_rows"] == 0)]
    own = pd.concat([part, solo.assign(place_figures_level="municipality_no_parts")])
    dup = own.duplicated(["edition", "settlement_id"], keep=False)
    log.append({"merge": "own register row: refused (two in one edition)", "rows_before": int(dup.sum())})
    own = own[~dup]
    rank = {e: i for i, e in enumerate(edition_priority)}
    own = own.assign(_rank=own["edition"].map(rank).fillna(len(rank))).sort_values(["settlement_id", "_rank"])
    own = own.drop_duplicates("settlement_id")
    own["place_register_key"] = (own["edition"] + "|" + own["court_key"] + "|" + own["muni_seq"].astype(str)
                                 + "|" + own["settlement_seq"].astype(str))
    own["place_status"] = own["place_status"].replace("", pd.NA).astype("string")
    own["place_figures_check"] = own["figures_check"].replace("", "all_hold").astype("string")
    out = own[["settlement_id", "place_register_key", "place_figures_level", "place_status",
               "place_figures_check", *PLACE_FIGURES]]
    out = out.rename(columns={c: f"place_{c}" for c in PLACE_FIGURES})
    return language_shares(out, prefix="place_").reset_index(drop=True)


# --------------------------------------------------------------------------- theatre stocks

def theatre_stocks(panel: pd.DataFrame, key: str, stock_year: int = STOCK_YEAR,
                   prefix: str = "theatre_") -> pd.DataFrame:
    """Collapse a unit × year theatre panel to pre-war stocks, one row per unit, both sides.

    ``ever`` (any activity by *stock_year*), ``first_year`` (first year with activity),
    ``years_active``, ``first_founded`` (first founding recorded), ``active_<Y>`` /
    ``ensembles_<Y>`` (in the stock year), ``performances`` (minimum performances summed) and
    ``national_fund`` (National Theatre fund records). Years after *stock_year* are dropped; a
    first year with no event is ``<NA>``."""
    p = panel[panel["year"] <= stock_year]
    units = pd.Index(p[key].drop_duplicates(), name=key)
    out = pd.DataFrame(index=units)
    for s in SIDES:
        act = p[f"any_activity_{s}"].astype(bool)
        g = act.groupby(p[key])
        out[f"{prefix}ever_{s}"] = g.any().reindex(units).astype("boolean")
        out[f"{prefix}years_active_{s}"] = g.sum().reindex(units).astype("Int64")
        out[f"{prefix}first_year_{s}"] = p.loc[act].groupby(key)["year"].min().reindex(units).astype("Int64")
        fnd = p[f"founded_{s}"] > 0
        out[f"{prefix}first_founded_{s}"] = p.loc[fnd].groupby(key)["year"].min().reindex(units).astype("Int64")
        last = p[p["year"] == stock_year].set_index(key)
        out[f"{prefix}active_{stock_year}_{s}"] = last[f"any_activity_{s}"].reindex(units).astype("boolean")
        out[f"{prefix}ensembles_{stock_year}_{s}"] = last[f"ensembles_active_{s}"].reindex(units).astype("Int64")
        out[f"{prefix}performances_{s}"] = p.groupby(key)[f"performances_min_{s}"].sum().reindex(units).astype("Int64")
        out[f"{prefix}national_fund_{s}"] = p.groupby(key)[f"national_theatre_{s}"].sum().reindex(units).astype("Int64")
    return out.reset_index()


def _panel_columns() -> list[str]:
    return [f"{b}_{s}" for b in THEATRE_BASES for s in SIDES]


def aggregate_panel(panel: pd.DataFrame, members: pd.DataFrame, unit: str, log: list) -> pd.DataFrame:
    """Sum a settlement × year panel to *unit* × year through a settlement → unit membership
    (one unit per settlement): counts summed, ``any_activity`` OR-ed. Settlements of no unit drop."""
    cols = _panel_columns()
    p = panel[["settlement_id", "year", *cols]]
    p = _merge(p, members[["settlement_id", unit]], "settlement_id", "m:1", f"theatre panel x {unit}", log)
    p = p[p[unit].notna()]
    agg = {c: ("max" if c.startswith("any_activity") else "sum") for c in cols}
    return p.groupby([unit, "year"], as_index=False).agg(agg)

def statutory_city_settlements(settlements: pd.DataFrame, okres_ids) -> pd.DataFrame:
    """Each statutory city's settlement: the one settlement of its okres (each city was an okres
    of its own, D-232). An okres with none or several gives no row (reported by the caller)."""
    s = settlements[settlements["okres_id"].isin(list(okres_ids))]
    one = s.groupby("okres_id")["settlement_id"].agg(["count", "first"])
    one = one[one["count"] == 1]["first"].rename("municipality_settlement_id")
    return one.reset_index()


def settlement_rollup(settlements: pd.DataFrame, roll) -> pd.DataFrame:
    """The person link's own roll-up (``birth_settlement`` P5) applied to **every** settlement:
    ``roll(settlement_id, okres_id) -> dict`` with ``municipality_settlement_id``,
    ``municipality_source`` and ``rollup_refusal`` (:func:`load_rollup` passes
    ``birth_settlement.roll_up`` on the gazetteer). One row per settlement."""
    rows = []
    for sid, oid in zip(settlements["settlement_id"], settlements["okres_id"]):
        r = roll(sid, None if pd.isna(oid) else int(oid))
        rows.append({"settlement_id": sid, **{c: r.get(c) for c in ROLLUP_COLUMNS[1:]}})
    out = pd.DataFrame(rows, columns=list(ROLLUP_COLUMNS)).astype("string")
    assert out["settlement_id"].is_unique
    return out


def load_rollup(final: Path = FINAL) -> pd.DataFrame:
    """:func:`settlement_rollup` on the gazetteer the birth link is built on
    (``birth_settlement.load_gazetteer``: data/final read only, plus the anchor overrides and the
    author's rulings in ``reference/places/``). About a minute."""
    from utils.parsing import birth_settlement as bs
    g = bs.load_gazetteer(Path(final))
    settlements = pd.read_parquet(Path(final) / SOURCES["settlements"], columns=["settlement_id", "okres_id"])
    return settlement_rollup(settlements, lambda sid, oid: bs.roll_up(sid, oid, g))


def municipality_members(munis: pd.DataFrame, rollup: pd.DataFrame, log: list) -> pd.DataFrame:
    """settlement_id → the register municipality whose theatre aggregate it enters: the roll-up the
    birth link uses (:func:`settlement_rollup`; sources :data:`MEMBER_SOURCES` — the register part,
    else the lexikon ``parent_1910``), kept where its municipality is a ``register_municipalities``
    row. A birth's settlement is therefore always a member of the municipality it is linked to."""
    keys = munis[["settlement_id"]].astype("string").rename(columns={"settlement_id": "municipality_settlement_id"})
    keys = keys.assign(_in_rm=True)
    r = rollup[rollup["municipality_source"].isin(MEMBER_SOURCES) & rollup["municipality_settlement_id"].notna()]
    r = _merge(r, keys, "municipality_settlement_id", "m:1", "settlement roll-up x register_municipalities", log)
    log.append({"merge": "roll-up members of a municipality register_municipalities lacks (in no aggregate)",
                "rows_before": int(r["_in_rm"].isna().sum())})
    out = r[r["_in_rm"].notna()][["settlement_id", "municipality_settlement_id", "municipality_source"]]
    return out.rename(columns={"municipality_source": "member_source"}).reset_index(drop=True)


def register_children(places: pd.DataFrame, log: list) -> pd.DataFrame:
    """``(settlement_id, municipality_settlement_id)`` of every part ``register_places`` anchors under
    an anchored municipality row, in **any** edition (a part only the German volume prints counts):
    the register's own claim of who belongs where, against which :func:`members_completeness` checks
    the roll-up. Parts under an unanchored municipality row are logged."""
    mkey = ["edition", "court_key", "muni_seq"]
    p = places.assign(court_key=places["court_key"].astype(str))
    rows = p[p["settlement_seq"] == 0][mkey + ["settlement_id"]].drop_duplicates(mkey)
    rows = rows.rename(columns={"settlement_id": "municipality_settlement_id"})
    parts = p[(p["settlement_seq"] > 0) & p["settlement_id"].notna()][mkey + ["settlement_id"]]
    parts = _merge(parts, rows, mkey, "m:1", "anchored register parts x their municipality row", log)
    lost = parts["municipality_settlement_id"].isna()
    log.append({"merge": "anchored register parts under an unanchored municipality row", "rows_before": int(lost.sum())})
    out = parts[~lost][["settlement_id", "municipality_settlement_id"]].astype("string")
    return out.drop_duplicates().reset_index(drop=True)


def members_completeness(munis: pd.DataFrame, members: pd.DataFrame, children: pd.DataFrame,
                         rollup: pd.DataFrame, panel_ids, log: list) -> pd.DataFrame:
    """One row per register municipality: ``n_members``, ``n_members_in_panel``, ``n_unreached``,
    ``members_incomplete``. *Unreached*: the municipality's own settlement, or a part the register
    anchors under it (:func:`register_children`), to which the roll-up gives **no** municipality
    (refused: two owners, a name conflict), so its activity is in no aggregate; and the
    municipality's own settlement when the roll-up files it under another municipality (the row's
    own place is then not in its aggregate: *Šárovcova Lhota*). A *part* the roll-up puts in
    another municipality is that one's (the link's verdict) and is only counted in the log.
    Incomplete = an unreached child, or a member outside the theatre panel."""
    key = "municipality_settlement_id"
    out = munis[["settlement_id"]].astype("string").rename(columns={"settlement_id": key})
    kids = pd.concat([out.assign(settlement_id=out[key]), children], ignore_index=True).drop_duplicates()
    rolled = rollup[["settlement_id", "municipality_settlement_id"]].rename(columns={key: "_rolled"})
    kids = _merge(kids, rolled, "settlement_id", "m:1", "register children x settlement roll-up", log)
    elsewhere = kids["_rolled"].notna() & (kids["_rolled"] != kids[key])
    log.append({"merge": "register children the roll-up puts in another municipality (counted there)",
                "rows_before": int(elsewhere.sum())})
    own_away = elsewhere & (kids["settlement_id"] == kids[key])
    unreached = kids[kids["_rolled"].isna() | own_away].groupby(key).size().rename("n_unreached").reset_index()
    m = members.assign(_in_panel=members["settlement_id"].isin(pd.Index(panel_ids)))
    counts = m.groupby(key).agg(n_members=("settlement_id", "size"), n_members_in_panel=("_in_panel", "sum"))
    out = _merge(out, counts.reset_index(), key, "1:1", "register municipalities x member counts", log)
    out = _merge(out, unreached, key, "1:1", "register municipalities x unreached children", log)
    ints = ["n_members", "n_members_in_panel", "n_unreached"]
    out[ints] = out[ints].fillna(0).astype("Int64")
    out["members_incomplete"] = ((out["n_unreached"] > 0)
                                 | (out["n_members_in_panel"] < out["n_members"])).astype("boolean")
    return out


def mask_incomplete(stocks: pd.DataFrame, prefix: str, policy: str = "na") -> pd.DataFrame:
    """On a municipality whose members are incomplete, a side with **no** activity among the members
    reached is not a zero: ``policy="na"`` (the default, :data:`INCOMPLETE_POLICY`) sets every stock
    of that side to ``<NA>``. A side with activity keeps its values, which are then lower bounds
    (the flag says so). ``"keep"`` leaves everything as summed."""
    if policy not in ("na", "keep"):
        raise ValueError(f"policy must be 'na' or 'keep', not {policy!r}")
    out = stocks.copy()
    if policy == "keep":
        return out
    flag = out[f"{prefix}members_incomplete"].fillna(False).astype(bool)
    for s in SIDES:
        blank = flag & ~out[f"{prefix}ever_{s}"].fillna(False).astype(bool)
        for c in [c for c in out.columns if c.startswith(prefix) and c.endswith(f"_{s}")]:
            out[c] = out[c].mask(blank)
    return out


def membership_consistency(members: pd.DataFrame, persons: dict) -> pd.DataFrame:
    """Per person file: births through the municipality gate (not statutory) whose birth settlement
    is **not** a member of the municipality it is linked to. 0 by construction when the roll-up is
    the link's; the dry run and the notebook assert it."""
    pairs = set(zip(members["settlement_id"], members["municipality_settlement_id"]))
    rows = []
    for ds, p in persons.items():
        sid = person_link(p, "birth_settlement_id")
        gate = p["birth_in_register_municipalities"].fillna(False).astype(bool) & p[sid].notna()
        gate &= p["birth_link_unit"] != "statutory_okres"
        g = p[gate]
        bad = [(s, m) not in pairs for s, m in zip(g[sid], g["birth_municipality_settlement_id"])]
        rows.append({"dataset": ds, "gated_births": int(len(g)), "settlement_not_member": int(sum(bad))})
    return pd.DataFrame(rows)

def _statutory_theatre(stocks: pd.DataFrame, src: dict, stock_year: int, key: str, prefix: str,
                       log: list) -> pd.DataFrame:
    """Replace the statutory cities' theatre rows by their okres panel's stocks (the city is its
    okres, D-232); ``<prefix>unit = "statutory_okres"`` marks them."""
    okres_ids = src["register_statutory_counts"]["okres_id"].astype("Int64")
    city = statutory_city_settlements(src["settlements"], okres_ids)
    city = city.rename(columns={"municipality_settlement_id": key})
    panel = src["theatre_okres_year"].astype({"okres_id": "Int64"})
    panel = panel[panel["okres_id"].isin(city["okres_id"].tolist())]
    okres = theatre_stocks(panel, "okres_id", stock_year, prefix)
    okres = _merge(city, okres, "okres_id", "1:1", f"statutory cities x theatre_okres_year ({key})", log)
    okres = okres.drop(columns="okres_id").assign(**{f"{prefix}unit": "statutory_okres"})
    kept = stocks[~stocks[key].isin(okres[key])]
    nullable = {c: kept[c].dtype for c in kept.columns if str(kept[c].dtype) in ("Int64", "boolean", "Float64", "string")}
    return pd.concat([kept, okres.reindex(columns=kept.columns).astype(nullable)], ignore_index=True).astype(nullable)


def _statutory_rows(src: dict, columns: list, log: list) -> pd.DataFrame:
    """``register_statutory_counts`` as municipality rows: the shared columns as printed (0 where
    the prose names none), every other column ``<NA>``; ``count_source = "prose"``."""
    sc = src["register_statutory_counts"].astype({"okres_id": "Int64"})
    city = statutory_city_settlements(src["settlements"], sc["okres_id"])
    rows = _merge(sc, city, "okres_id", "1:1", "register_statutory_counts x city settlement", log)
    missing = rows["municipality_settlement_id"].isna()
    log.append({"merge": "statutory cities with no single settlement (dropped)", "rows_before": int(missing.sum())})
    rows = rows[~missing].rename(columns={"municipality_settlement_id": "settlement_id"})
    court = src["settlements"][["settlement_id", "court_id"]]
    rows = _merge(rows.drop(columns=["court_id"], errors="ignore"), court, "settlement_id", "1:1",
                  "statutory cities x settlement court", log)
    rows = rows.assign(count_source="prose", is_statutory_city=True, register_key=pd.NA)
    return rows.reindex(columns=columns)

def build_birthplace_settlement_cz(src: dict, stock_year: int = STOCK_YEAR,
                                   statutory_theatre_from_okres: bool = True,
                                   log: list | None = None) -> pd.DataFrame:
    """Key ``settlement_id``: every 1910 settlement of ``settlements_1910``, with what is its own."""
    log = [] if log is None else log
    st = src["settlements"][["settlement_id", "status_1910", "land", "okres_id", "court_id"]].copy()
    geo = src["settlements_geo"][["settlement_id", "lat", "lon", "coord_source"]]

    out = _merge(out, src["okres_census"][["okres_id", "census_okres_id"]], "okres_id", "m:1",
                 "settlements x okres_census_crosswalk", log)

    stocks["theatre_unit"] = "settlement"
    if statutory_theatre_from_okres:
        stocks = _statutory_theatre(stocks, src, stock_year, "settlement_id", "theatre_", log)
    out = _merge(out, stocks, "settlement_id", "1:1", "settlements x theatre stocks", log)
    return out.astype({"settlement_id": "string", "theatre_unit": "string"})


def _municipality_base(src: dict, include_statutory_cities: bool, keep_mark_columns: bool,
                       log: list) -> pd.DataFrame:
    """register_municipalities' columns this table carries, plus the statutory cities' rows."""
    rm = src["register_municipalities"]
    fams = MUNI_FAMILIES + (("n_mark_",) if keep_mark_columns else ())
    spread = [c for c in rm.columns if c.startswith(fams)]
    cols = ["settlement_id", "court_id", "okres_id", "muni_seq", *MUNI_QUALITY, *MUNI_FIGURES,
            *MUNI_INSTITUTIONS, *spread]
    base = rm[cols].copy()
    base["register_key"] = (base["edition"] + "|" + base["court_id"].astype("string") + "|"
                            + base["muni_seq"].astype(str))
    base = base.assign(count_source="plates", is_statutory_city=False)
    for c in base.columns:
        if base[c].dtype == bool:
            base[c] = base[c].astype("boolean")
    if include_statutory_cities:
        stat = _statutory_rows(src, list(base.columns), log)
        nullable = {c: base[c].dtype for c in base.columns
                    if str(base[c].dtype) in ("Int64", "boolean", "Float64")}
        base = pd.concat([base, stat.astype(nullable)], ignore_index=True)
    base["place_status"] = base["place_status"].replace("", pd.NA).astype("string")
    base["figures_check"] = base["figures_check"].replace("", "all_hold").astype("string")
    return base.drop(columns="muni_seq")


def municipality_theatre(src: dict, stock_year: int = STOCK_YEAR, include_statutory_cities: bool = True,
                         incomplete_policy: str = INCOMPLETE_POLICY, log: list | None = None) -> pd.DataFrame:
    """``muni_theatre_*`` per register municipality: the settlement panel summed over the roll-up
    members (:func:`municipality_members`), the completeness counts and flag
    (:func:`members_completeness`) and :func:`mask_incomplete`; the statutory cities from their okres."""
    log = [] if log is None else log
    if "rollup" not in src:
        raise KeyError("src['rollup'] missing: load_sources(final, rollup=True) or pass theatre_at_municipality=False")
    key, pre = "municipality_settlement_id", "muni_theatre_"
    rm, panel = src["register_municipalities"], src["theatre_settlement_year"]
    members = municipality_members(rm, src["rollup"], log)
    children = register_children(src["register_places"], log)
    info = members_completeness(rm, members, children, src["rollup"], panel["settlement_id"].unique(), log)
    agg = aggregate_panel(panel, members, key, log)
    stocks = theatre_stocks(agg, key, stock_year, prefix=pre)
    info = info.rename(columns={c: f"{pre}{c}" for c in info.columns if c != key})
    stocks = _merge(info, stocks, key, "1:1", "register municipalities x member theatre stocks", log)
    stocks = mask_incomplete(stocks, pre, incomplete_policy)
    stocks[f"{pre}unit"] = "municipality_members"
    if include_statutory_cities:
        stocks = _statutory_theatre(stocks, src, stock_year, key, pre, log)
    return stocks


def build_birthplace_municipality_cz(src: dict, stock_year: int = STOCK_YEAR,
                                     include_statutory_cities: bool = True,
                                     theatre_at_municipality: bool = True,
                                     keep_mark_columns: bool = False,
                                     incomplete_policy: str = INCOMPLETE_POLICY,
                                     log: list | None = None) -> pd.DataFrame:
    """Key ``municipality_settlement_id``: every municipality of ``register_municipalities`` (and,
    by default, the statutory cities), its register totals and institutions prefixed ``muni_``."""
    log = [] if log is None else log
    base = _municipality_base(src, include_statutory_cities, keep_mark_columns, log)
    fk = ("settlement_id", "court_id", "okres_id")
    base = base.rename(columns={c: f"muni_{c}" for c in base.columns if c not in fk})
    base = base.rename(columns={"settlement_id": "municipality_settlement_id"})
    base["municipality_settlement_id"] = base["municipality_settlement_id"].astype("string")
    out = _merge(base, src["okres_census"][["okres_id", "census_okres_id"]], "okres_id", "m:1",
                 "municipalities x okres_census_crosswalk", log)
    out = language_shares(out, prefix="muni_")
    if theatre_at_municipality:
        stocks = municipality_theatre(src, stock_year, include_statutory_cities, incomplete_policy, log)
        out = _merge(out, stocks, "municipality_settlement_id", "1:1", "municipalities x theatre stocks", log)
        out["muni_theatre_unit"] = out["muni_theatre_unit"].astype("string")
    lead = ["municipality_settlement_id", "muni_register_key", "muni_count_source",
            "muni_is_statutory_city", "okres_id", "census_okres_id", "court_id"]
    text = {c: "string" for c in out.columns if out[c].dtype == object}
    out = out.astype({**text, "municipality_settlement_id": "string", "muni_register_key": "string"})
    return out[lead + [c for c in out.columns if c not in lead]]


def build_birthplace_settlement_sk(src: dict, log: list | None = None) -> pd.DataFrame:
    """Key ``idtel``: every GISta 1910 settlement, with its census figures and point. ``unit_id``
    is the foreign key to ``census_hu_jaras_1910`` (its covariates stay there)."""
    log = [] if log is None else log
    counts = [f"n_{t}" for t in MOTHER_TONGUES]
    cols = ["idtel", "name_1912", "unit_id", "unit_type", "megye_id", "megye_seat", "jaras_seat",
            "in_backbone", "subcarpathian", "mai_orszag", "pop_1910", *counts, "lat", "lon",
            "majo_join", "majo_pop"]
    out = src["gista"][cols].copy().astype({"idtel": "string"})
    ints = counts + ["pop_1910", "majo_pop"]
    out[ints] = out[ints].astype("Int64")
    base = out["pop_1910"].astype("Float64").where(out["pop_1910"] > 0)
    for t in MOTHER_TONGUES:

    return out

# --------------------------------------------------------------------------- checks, coverage, report

def _theatre_checks(t: pd.DataFrame, p: str) -> list[tuple[str, bool, str]]:
    if f"{p}ever_certain" not in t:
        return []
    bad = int((t[f"{p}ever_certain"].fillna(False) & ~t[f"{p}ever_possible"].fillna(False)).sum())
    bad += int((t[f"{p}years_active_certain"] > t[f"{p}years_active_possible"]).fillna(False).sum())
    early = int((t[f"{p}first_year_certain"] < t[f"{p}first_year_possible"]).fillna(False).sum())
    return [(f"{p}: certain within possible", bad == 0, f"{bad} violations"),
            (f"{p}: first certain year not before first possible", early == 0, f"{early} violations")]


def check_tables(tables: dict, src: dict) -> list[tuple[str, bool, str]]:
    """``(label, ok, detail)`` for every invariant the tables must satisfy."""
    out = []
    for name, key in TABLES.items():
        t = tables[name]
        out.append((f"{name}: key {key} never missing", bool(t[key].notna().all()), f"{int(t[key].isna().sum())} missing"))
        out.append((f"{name}: key {key} unique", bool(t[key].is_unique), f"{int(t[key].duplicated().sum())} duplicated"))
    s, m, k = (tables[n] for n in TABLES)
    sett = src["settlements"]["settlement_id"]
    out.append(("settlement_cz rows = settlements_1910", len(s) == len(sett), f"{len(s)} vs {len(sett)}"))
    out.append(("municipality_cz keys are settlements_1910 ids", bool(m["municipality_settlement_id"].isin(sett).all()), ""))
    n_plates = int((m["muni_count_source"] == "plates").sum())
    out.append(("municipality_cz plate rows = register_municipalities rows",
                n_plates == len(src["register_municipalities"]), f"{n_plates}"))
    out.append(("settlement_sk rows = settlements_gista_1910", len(k) == len(src["gista"]), f"{len(k)}"))
    out += _theatre_checks(s, "theatre_") + _theatre_checks(m, "muni_theatre_")
    if "muni_theatre_n_members" in m:
        over = int((m["muni_theatre_n_members_in_panel"] > m["muni_theatre_n_members"]).fillna(False).sum())
        out.append(("municipality_cz: members in the panel within members", over == 0, f"{over} violations"))
    for name, t in tables.items():
        shares = [c for c in t.columns if c.endswith("_share")]
        neg = int((t[shares] < 0).fillna(False).to_numpy().sum())
        over = int((t[shares] > 1).fillna(False).to_numpy().sum())
        out.append((f"{name}: shares non-negative", neg == 0, f"{neg} negative"))
        out.append((f"{name}: shares above 1 (soft: a misread row, kept)", True, f"{over} cells"))
    return out


def _linked(p: pd.DataFrame, link: str, gated: bool) -> tuple[int, pd.DataFrame]:
    """Births linked on *link* (its canonical column where present, :func:`person_link`); for the municipality
    table only those through the gate. The returned frame's column is named *link*."""
    col = person_link(p, link)
    linked = p[p[col].notna()]
    if col != link:
        linked = linked.drop(columns=[link], errors="ignore").rename(columns={col: link})
    if not gated:
        return len(linked), linked[[link]]
    through = linked["birth_in_register_municipalities"].fillna(False).astype(bool) \
        | (linked["birth_link_unit"] == "statutory_okres")
    return len(linked), linked.loc[through, [link]]


def coverage(tables: dict, persons: dict) -> pd.DataFrame:
    """Share of linked births whose place has each covariate, per person file and table."""
    rows = []
    specs = (("birthplace_settlement_cz", "birth_settlement_id", False),
             ("birthplace_municipality_cz", "birth_municipality_settlement_id", True),
             ("birthplace_settlement_sk", "birth_settlement_sk_id", False))
    for ds, p in persons.items():
        for name, link, gated in specs:
            t, key = tables[name], TABLES[name]
            n_linked, j = _linked(p, link, gated)
            j = j.merge(t, left_on=link, right_on=key, how="left", validate="m:1")
            n_joined = int(j[key].notna().sum())
            nn = j[t.columns].notna().sum()
            for c in t.columns:
                rows.append({"dataset": ds, "table": name, "column": c, "n_linked": n_linked,
                             "n_through_gate": len(j), "n_joined": n_joined, "n_with_value": int(nn[c]),
                             "share_of_linked": round(nn[c] / max(n_linked, 1), 4)})
    return pd.DataFrame(rows)


def census_key_agreement(tables: dict, persons: dict) -> pd.DataFrame:
    """0.4.0 (D-262): per person file and settlement table, the births linked to a settlement (:func:`person_link`)
    and whether the table's census foreign key (``census_okres_id`` / ``unit_id``) names the same census unit as the
    person's own key (``birth_census_okres_id`` / ``birth_census_jaras_id``): ``agree``, ``differ``, or set on one
    side only (``table_only``, ``person_only``). ``differ`` is 0 on both frames by construction; the counts are
    ``<NA>`` where a person file lacks its key (a ``data/final`` from before D-262)."""
    rows = []
    for ds, p in persons.items():
        for name, (link, fk, key) in CENSUS_KEYS.items():
            row = {"dataset": ds, "table": name, "table_key": fk, "person_key": key}
            col = person_link(p, link)
            if key not in p.columns:
                rows.append(row | {c: pd.NA for c in ("n_linked", "agree", "differ", "table_only", "person_only")})
                continue
            t = tables[name][[TABLES[name], fk]]
            j = _merge(p.loc[p[col].notna(), [col, key]], t.rename(columns={TABLES[name]: col, fk: "_fk"}),
                       col, "m:1", f"{ds} persons x {name} (census-key agreement)", [])
            a, b = j["_fk"].astype("string"), j[key].astype("string")
            both = a.notna() & b.notna()
            rows.append(row | {"n_linked": len(j), "agree": int((both & (a == b)).sum()),
                               "differ": int((both & (a != b)).sum()), "table_only": int((a.notna() & b.isna()).sum()),
                               "person_only": int((a.isna() & b.notna()).sum())})
    return pd.DataFrame(rows)


def write_tables(tables: dict, out_dir: Path) -> None:
    """Each table as parquet and as UTF-8 CSV with LF line ends."""
    out_dir = Path(out_dir)
    out_dir.mkdir(parents=True, exist_ok=True)
    for name, t in tables.items():
        t.to_parquet(out_dir / f"{name}.parquet", index=False)
        t.to_csv(out_dir / f"{name}.csv", index=False, encoding="utf-8", lineterminator="\n")

def birthplace_covariates_report(tables: dict, log: list, checks: list, cov: pd.DataFrame | None = None) -> str:
    """Rows and keys, every merge, every check, and the headline coverage."""
    lines = [f"birthplace_covariates {__version__}"]
    for name, key in TABLES.items():
        lines.append(f"  {name}: {len(tables[name]):,} rows x {tables[name].shape[1]} columns, key {key}")
    lines.append("merges:")
    lines += ["  " + "; ".join(f"{k}={v}" for k, v in r.items()) for r in log]
    lines.append("checks:")
    lines += [f"  [{'ok' if ok else 'FAIL'}] {label} {detail}" for label, ok, detail in checks]
    if cov is not None:
        lines.append("coverage (share of linked births with a value):")
        for name, cols in REPORT_COLUMNS.items():
            c = cov[(cov["table"] == name) & cov["column"].isin(cols)]
            for ds, d in c.groupby("dataset"):
                vals = ", ".join(f"{r.column} {r.share_of_linked:.3f}" for r in d.itertuples())
                lines.append(f"  {ds} {name} (linked {int(d['n_linked'].iloc[0]):,}, through gate "
                             f"{int(d['n_through_gate'].iloc[0]):,}): {vals}")
    return "\n".join(lines)
