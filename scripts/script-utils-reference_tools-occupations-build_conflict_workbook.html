TL;DR

The Czech→HISCO dictionary flags keys review where the coding is not settled, and the rival codes behind those flags are scattered across four places: a semicolon list in link_hisco (the German bridge, where one German gloss reaches several HISCO codes), a single column for OccCANINE, a single column for CZ-ISCO, and free prose in note. No file anywhere holds the one shape in which "code A or code B?" can actually be answered — (key, candidate code, that code's English job title, that code's HISCLASS).

How it works

This builds it. One row per (key × candidate HISCO code), every candidate carrying its own label and class, plus a moves column saying whether choosing it would change the social class at all — because most of these disputes do not. zámečník is HISCLASS 7 under all four of its candidates; the argument is real but it moves nothing downstream.

CZ-ISCO is never a candidate. It is ISCO-08, ILO's crosswalks reach only ISCO-88, and HISCO is ISCO-68 — there is no path from a CZ-ISCO code to a HISCO code, which is why run_czisco_check.py asserts it never touches hisco. It travels here as evidence about the Czech reading, in its own columns and its own sheet, never as an option to pick.

The workbook asks one question per word, not one per candidate. The long table above is the evidence; it is not the shape a decision is made in. A human answering "which code for kovář" needs one row, and only where the answer moves something. On the first build — 172 flagged keys, ~25.3k records — 76 had a rival that changed the HISCLASS and those were the sheet that opened; the 44 arguments that left the class where it was sat on a second sheet and the 52 keys with no rival at all on a third. Nine columns instead of twenty-five — the four candidate columns collapse into one wrapped cell (59 of the 76 were a plain A-or-B), the German gloss, the note and CZ-ISCO's verdict merge into one, and hisclass_basis, whose four values needed a paragraph of instructions to serve eleven rows, becomes a parenthesis in the cell it qualifies. The CSV twin keeps the full per-candidate shape.

It builds from the live flag, so it shrinks as questions get answered. The 2026-08-26 pass settled 171 of 181 (czech_glosses.ADJUDICATED); the ten that survived are what the next build holds. A key already carrying a verdict is not asked about again — including on the CZ-ISCO sheet, which is not driven by review and would otherwise repeat itself every run.

Nothing is written back. An accepted decision is applied by hand to czech_glosses.HISCO_OVERRIDE and the curation is rebuilt — same protocol as czisco_tail_candidates.csv.

Outputs: output/occupation_conflicts.xlsx — the fill-in workbook (gitignored) reference/occupations/occupation_conflicts.csv — every candidate, tracked and diffable

Run: python utils/reference_tools/occupations/build_conflict_workbook.py

def candidates(row: pd.Series, known: set[str]) -> list[tuple[str, str]]:
    """``[(code, proposed_by)]`` for one curation row — the current code first.

    Four sources, three of them structured and one prose:

    * ``current`` — what the pipeline codes today. **Always emitted**, even as a sentinel
      (``-1`` no occupation, ``-2`` an employer rather than a job) and even as an empty
      string: six flagged keys carry no code at all, and "today this record has no
      occupation" is the baseline the alternatives have to beat, not a row to omit.
    * ``german-bridge`` — ``link_hisco``, semicolon-separated where one German gloss reached
      several HISCO codes. This is the only genuinely *enumerated* alternatives list in the
      project.
    * ``occcanine`` — the transformer's single dissenting code.
    * ``note`` — five-digit codes named in the hand-written note, kept only if the authority
      recognises them. This is what recovers ``rytec``'s "could equally be 92420 or 89420":
      an argument that until now existed only as a sentence.
    """
    cur = row["hisco"].strip()
    seen: dict[str, list[str]] = {cur: ["current"]}

    def _add(code: str, src: str) -> None:
        code = code.strip()
        if not code or code == cur:
            return
        # two coders landing on the same code is the strongest signal in the sheet — record
        # both, rather than letting whichever ran first take the credit
        seen.setdefault(code, []).append(src)

    for c in row["link_hisco"].split(";"):
        _add(c, "german-bridge")
    _add(row["occcanine_hisco"], "occcanine")
    for c in _CODE_RE.findall(row["note"]):
        if c in known:                                   # a bare number in prose is not a code
            _add(c, "note")
    return [(code, "+".join(dict.fromkeys(srcs))) for code, srcs in seen.items()]

def build_conflicts(cur_df: pd.DataFrame) -> pd.DataFrame:
    """The adjudication table: one row per (review-flagged key × candidate code)."""
    known = _known_codes()
    coded_n = cur_df.loc[cur_df["hisco"].str.strip() != "", "_n"].sum()
    rows: list[dict] = []

    flagged = cur_df[cur_df["review"].str.strip() == "1"].sort_values(
        "_n", ascending=False, kind="stable")

    for _, r in flagged.iterrows():
        status = r["status"] or "-9"
        relation = r["relation"] or "-9"
        product = r["product"] or "-9"
        cands = candidates(r, known)
        block: list[dict] = []
        for letter, (code, src) in zip("ABCDEFGH", cands):
            look = _lookup(code, status, relation, product)
            block.append({
                "key": r["key"],
                "n": int(r["_n"]),
                "pct_of_coded": round(r["_n"] / coded_n * 100, 3) if coded_n else 0.0,
                "de_gloss": r["de_gloss"],
                "en_gloss": r["en_gloss"],
                "cand": letter,
                "is_current": "current" if src == "current" else "",
                "hisco": code,
                "hisco_label_en": _title(look, code),
                "major_label": look["major_label"],
                "hisclass": look["hisclass"],
                "hisclass_label": look["hisclass_label"],
                "hisclass_5": look["hisclass_5"],
                "hisclass_basis": look["basis"],
                "proposed_by": src,
                "occcanine_p": r["occcanine_p"] if "occcanine" in src else "",
                "_is_current": src == "current",
            })
        cur_row = next((b for b in block if b["_is_current"]), block[0])
        for b in block:
            b["moves"] = _moves(b, cur_row)

        # CZ-ISCO, the curation note and the human columns belong to the KEY, not to any one
        # candidate — they go on the first row of the block so the group reads as a group.
        for i, b in enumerate(block):
            first = i == 0
            b |= {
                "czisco_cs": r["czisco_cs"] if first else "",
                "czisco_en": r["czisco_en"] if first else "",
                "czisco_agree": r["czisco_agree"] if first else "",
                "note": r["note"] if first else "",
                "DECISION": "", "final_hisco": "", "reason": "",
            }
            b.pop("_is_current")
        rows.extend(block)

    out = pd.DataFrame(rows)
    out.insert(0, "row", range(1, len(out) + 1))
    return out

def build_czisco_only(cur_df: pd.DataFrame) -> pd.DataFrame:
    """CZ-ISCO contradicts us and nothing flagged it — a gap in the flagging, not the coding.

    ``run_czisco_check.py`` writes the ``czisco_*`` columns but never the ``review`` column,
    so a disagreement it found only reaches a human if some *other* check flagged the same
    key. These are the ones no other check reached — minus any already carrying a
    ``verdict``, since nothing here would ever clear them and the sheet would repeat itself
    on every build. They are kept on their own sheet because
    the question is different in kind: not "which of these HISCO codes", but "is the Czech
    reading itself wrong" — CZ-ISCO offers no HISCO code to switch to.
    """
    answered = (cur_df["verdict"].str.strip() != "" if "verdict" in cur_df.columns
                else pd.Series(False, index=cur_df.index))
    d = cur_df[(cur_df["czisco_agree"].str.strip() == "0")
               & (cur_df["hisco"].str.strip() != "")
               & (cur_df["review"].str.strip() != "1")
               & ~answered].sort_values("_n", ascending=False, kind="stable")
    rows = []
    for _, r in d.iterrows():
        look = _lookup(r["hisco"].strip(), r["status"] or "-9",
                       r["relation"] or "-9", r["product"] or "-9")
        rows.append({
            "key": r["key"], "n": int(r["_n"]),
            "de_gloss": r["de_gloss"], "en_gloss": r["en_gloss"],
            "our_hisco": r["hisco"], "our_label_en": _title(look, r["hisco"].strip()),
            "our_hisclass": look["hisclass"], "our_hisclass_label": look["hisclass_label"],
            "czisco_code": r["czisco_code"], "czisco_cs": r["czisco_cs"],
            "czisco_en": r["czisco_en"], "czisco_n_hits": r["czisco_n_hits"],
            "note": r["note"],
            "VERDICT": "", "final_hisco": "", "reason": "",
        })
    out = pd.DataFrame(rows)
    if len(out):
        out.insert(0, "row", range(1, len(out) + 1))
    return out

def build_decisions(conf: pd.DataFrame) -> dict[str, pd.DataFrame]:
    """Collapse the candidate rows into one row per key, split by whether it is worth time.

    The long table answers "what are the candidates". Nobody has to answer that question.
    The question in front of a human is "which code, for this word" — one per key, 172 of
    them, and only 76 where the answer moves records between social classes. So the sheet
    that gets opened holds those 76, the 44 code-only arguments sit behind it, and the 52
    keys with no rival at all are a list rather than a decision.
    """
    frames: dict[str, list[dict]] = {"live": [], "same": [], "none": []}

    for key, g in conf.groupby("key", sort=False):
        cur = g[g["is_current"] == "current"].iloc[0]
        rivals = g[g["is_current"] != "current"]
        moves = g["moves"].isin(("class", "no code today")).any()
        bucket = "none" if rivals.empty else ("live" if moves else "same")

        row = {
            "occupation": key,
            "records": int(cur["n"]),
            "% of coded": cur["pct_of_coded"],
            "now": _now_cell(cur),
            "alternatives": _alt_cell(rivals) if len(rivals) else "none proposed by any coder",
            "evidence": _evidence_cell(cur),
        }
        if bucket == "none":
            row |= {"VERDICT": "", "why / what it should be": ""}
        else:
            row |= {"DECISION": "", "why / what it should be": "",
                    "_options": ",".join(["A (keep)"] + list(rivals["cand"])
                                         + ["other", "unsure"])}
        frames[bucket].append(row)

    out = {}
    for name, rows in frames.items():
        # An empty bucket must still carry its columns. ``pd.DataFrame([])`` has none, so
        # the sheet went out with no header row at all and `verify_xlsx` could not find one
        # — which is exactly what happened the first time the adjudication emptied `live`
        # and `same` (2026-08-26): the ten surviving keys are all sentinels and bare words
        # no coder proposed a rival for, so both decision sheets were empty for the first
        # time. A sheet with a header and no rows is the honest rendering of "nothing left
        # to decide here"; a sheet with neither is a bug that reads like one.
        cols = _NONE_COLS if name == "none" else _DECIDE_COLS
        df = pd.DataFrame(rows, columns=cols)
        if len(df):
            df = df.sort_values("records", ascending=False, kind="stable")
            df = df.reset_index(drop=True)
        df.insert(0, "#", range(1, len(df) + 1))
        out[name] = df
    return out

def verify_xlsx(path: Path) -> int:
    """Read the saved workbook back and check every dropdown against its own row.

    A dropdown is placed by row index, and a row index computed from ``max_row`` was
    silently one short — the offence the repo has met four times before (an unguarded
    index, wrong in a way that still produces a plausible-looking sheet). The only proof
    is the file itself: the letters offered in a cell must be the letters printed in the
    ``alternatives`` cell beside it. Returns the number of rows checked.
    """
    from openpyxl import load_workbook
    from openpyxl.utils import get_column_letter

    wb = load_workbook(path)
    checked = 0
    for ws in wb:
        head = next((r for r in range(1, 12)
                     if ws.cell(row=r, column=1).value in ("#", "occupation")), None)
        assert head, f"{ws.title}: no header row found"
        cols = {ws.cell(row=head, column=j).value: j
                for j in range(1, ws.max_column + 1)}
        if "DECISION" not in cols or "alternatives" not in cols:
            continue
        letter = get_column_letter(cols["DECISION"])
        at = {str(rng): dv.formula1
              for dv in ws.data_validations.dataValidation for rng in dv.sqref.ranges}
        for r in range(head + 1, ws.max_row + 1):
            alts = str(ws.cell(row=r, column=cols["alternatives"]).value or "")
            want = [ln.split(" ·")[0].strip() for ln in alts.splitlines()
                    if ln[:1].isalpha() and ln[1:2] == " "]
            got = at.get(f"{letter}{r}", "").strip('"').split(",")
            assert got[:1] == ["A (keep)"] and got[1:1 + len(want)] == want, (
                f"{ws.title} row {r} ({ws.cell(row=r, column=2).value!r}): "
                f"dropdown {got} does not match the candidates {want}")
            checked += 1
    return checked

def main() -> None:
    """Build the sheets, check the invariants, write the workbook and its CSV twin."""
    try:
        sys.stdout.reconfigure(encoding="utf-8", errors="replace")
    except (AttributeError, OSError):                    # pragma: no cover
        pass

    cur_df = load_curation()
    conf = build_conflicts(cur_df)
    czo = build_czisco_only(cur_df)
    dec = build_decisions(conf)

    # ── invariants: a silent failure here would look exactly like a finding ─────────
    n_keys = conf["key"].nunique()
    assert n_keys == int((cur_df["review"].str.strip() == "1").sum()), \
        f"{n_keys} keys in the sheet, {(cur_df['review'] == '1').sum()} flagged in the curation"
    per_key_current = conf.groupby("key")["is_current"].apply(lambda s: (s == "current").sum())
    assert (per_key_current == 1).all(), \
        f"keys without exactly one current row: {list(per_key_current[per_key_current != 1].index)}"
    # collapsing to one row per key must lose no key and duplicate none
    assert sum(len(d) for d in dec.values()) == n_keys, \
        f"{sum(len(d) for d in dec.values())} rows across the sheets, {n_keys} flagged keys"
    unknown = conf[(conf["hisco"].str.strip() != "")
                   & (conf["hisclass_basis"] == "not-in-authority")]
    if len(unknown):
        print(f"!! {len(unknown)} candidate codes are not in hisco_authority.csv "
              f"(a bug, not a finding): {sorted(set(unknown['hisco']))}")
    czisco_codes = set(cur_df["czisco_code"]) - {""}
    assert not (set(conf["hisco"]) & czisco_codes - _known_codes()), \
        "a CZ-ISCO code leaked into the HISCO candidate column"

    OUT_CSV.parent.mkdir(parents=True, exist_ok=True)
    conf.to_csv(OUT_CSV, index=False, encoding="utf-8")
    path = _write_xlsx(dec, czo)

    n_checked = verify_xlsx(path)

    print(f"wrote {path.relative_to(ROOT)}  ({n_checked} dropdowns verified against their row)")
    print(f"wrote {OUT_CSV.relative_to(ROOT)}  ({len(conf)} candidate rows, unchanged shape)")
    print(f"  {n_keys} flagged keys, {int(conf.groupby('key')['n'].first().sum()):,} records")
    for sheet, name in (("live", "Decide (a rival moves HISCLASS)"),
                        ("same", "Same class either way"),
                        ("none", "Nothing to choose from")):
        d = dec[sheet]
        print(f"    {name:<34} {len(d):>4} keys  {int(d['records'].sum()):>7,} records"
              if len(d) else f"    {name:<34}    0 keys")
    print(f"    CZ-ISCO says otherwise             {len(czo):>4} keys  "
          f"{int(czo['n'].sum()) if len(czo) else 0:>7,} records")

"""
build_conflict_workbook.py — every unresolved occupation coding, as one adjudicable table
=========================================================================================
The Czech→HISCO dictionary flags keys ``review`` where the coding is not settled, and the
rival codes behind those flags are scattered across four places: a semicolon list in
``link_hisco`` (the German bridge, where one German gloss reaches several HISCO codes), a
single column for OccCANINE, a single column for CZ-ISCO, and free prose in ``note``. No
file anywhere holds the one shape in which "code A or code B?" can actually be answered —
``(key, candidate code, that code's English job title, that code's HISCLASS)``.

This builds it. One row per **(key × candidate HISCO code)**, every candidate carrying its
own label and class, plus a ``moves`` column saying whether choosing it would change the
social class at all — because most of these disputes do not. ``zámečník`` is HISCLASS 7
under all four of its candidates; the argument is real but it moves nothing downstream.

**CZ-ISCO is never a candidate.** It is ISCO-08, ILO's crosswalks reach only ISCO-88, and
HISCO is ISCO-68 — there is no path from a CZ-ISCO code to a HISCO code, which is why
``run_czisco_check.py`` asserts it never touches ``hisco``. It travels here as *evidence*
about the Czech reading, in its own columns and its own sheet, never as an option to pick.

**The workbook asks one question per word, not one per candidate.** The long table above
is the evidence; it is not the shape a decision is made in. A human answering "which code
for ``kovář``" needs one row, and only where the answer moves something. On the first
build — 172 flagged keys, ~25.3k records — 76 had a rival that changed the HISCLASS and
those were the sheet that opened; the 44 arguments that left the class where it was sat on
a second sheet and the 52 keys with no rival at all on a third. Nine columns instead of
twenty-five — the four candidate columns collapse into one wrapped cell (59 of the 76 were
a plain A-or-B), the German gloss, the note and CZ-ISCO's verdict merge into one, and
``hisclass_basis``, whose four values needed a paragraph of instructions to serve eleven
rows, becomes a parenthesis in the cell it qualifies. The CSV twin keeps the full
per-candidate shape.

**It builds from the live flag, so it shrinks as questions get answered.** The 2026-08-26
pass settled 171 of 181 (`czech_glosses.ADJUDICATED`); the ten that survived are what the
next build holds. A key already carrying a ``verdict`` is not asked about again — including
on the CZ-ISCO sheet, which is not driven by ``review`` and would otherwise repeat itself
every run.

Nothing is written back. An accepted decision is applied by hand to
``czech_glosses.HISCO_OVERRIDE`` and the curation is rebuilt — same protocol as
``czisco_tail_candidates.csv``.

Outputs:
    output/occupation_conflicts.xlsx          — the fill-in workbook (gitignored)
    reference/occupations/occupation_conflicts.csv — every candidate, tracked and diffable

Run:
    python utils/reference_tools/occupations/build_conflict_workbook.py
"""

import datetime as _dt
import re
import sys
from pathlib import Path

import pandas as pd

ROOT = Path(__file__).resolve().parents[3]
sys.path.insert(0, str(ROOT))

HERE = ROOT / "reference" / "occupations"
CURATION = HERE / "occupation_hisco_curation.csv"

_CODE_RE = re.compile(r"\b\d{5}\b")          # a HISCO code as it appears in a prose note


# ═══════════════════════════════════════════════════════════════════════════
# The authority lookup — one code, its job title and its class
# ═══════════════════════════════════════════════════════════════════════════
_LOOKUP_COLS = ["label_en", "unit_label", "minor_label", "major", "major_label",
                "hisclass", "hisclass_label", "hisclass_5", "hisclass_5_label"]

# The sentinels are not HISCO codes and carry no label in the authority, but they *are*
# legitimate answers here — several keys are flagged precisely because the honest coding is
# "this is not an occupation". Spelling them out stops a blank cell reading as a bug.
_SENTINEL_LABEL = {
    "-1": "(no occupation / not classifiable)",
    "-2": "(an employer or institution, not an occupation)",
    "-3": "(no occupation recorded in the source)",
}


def _title(look: dict, code: str) -> str:
    """The most specific job title available for a code.

    A handful of authority rows carry no ``label_en`` — 92000 is one — but always sit inside
    a named unit or minor group. A group name is a worse answer than a job title and a far
    better one than an empty cell, which a reader can only read as a failure.
    """
    if code in _SENTINEL_LABEL:
        return _SENTINEL_LABEL[code]
    for c in ("label_en", "unit_label", "minor_label"):
        v = look.get(c)
        if pd.notna(v) and str(v).strip():
            return str(v)
    return ""


def _lookup(code: str, status: str, relation: str, product: str) -> dict:
    """Job title + HISCLASS for one candidate code, under the key's own modifiers.

    The first two steps mirror ``occupations._scales`` deliberately rather than simplifying
    it. The authority is keyed on ``(hisco, status, relation, product)`` and holds only
    combinations HSN actually observed, so a curated modifier may have no row; those fall
    back to the **base code**. The one case where the fallback must not fire is a non-empty
    ``relation`` — HISCO withholds HISCLASS from relation-bearing entries entirely, and
    reaching past the missing key would manufacture a class the scheme refuses to give.

    The key's modifiers are applied to *every* candidate, not just the current one: a rival
    code is a rival for the same person, so the same status applies to it.

    There is a third step here that the pipeline does not need. Some codes exist in the
    authority *only* with a modifier — 88060 *Precious Metal Roller* appears solely as
    status 21 (Master), 95240 *Cement Finisher* solely as 32/33 — so both lookups above
    miss and the pipeline would honestly return no scales. A workbook whose job is to let a
    human read what a code means must still show the job title, which does not vary by
    modifier. So the title is taken from any row, and the class only when every row for
    that code agrees on it; ``basis`` names which of the three routes was used, and the two
    unhappy ones say so out loud.
    """
    out = {c: pd.NA for c in _LOOKUP_COLS} | {"basis": "not-in-authority"}
    if not code:
        return out
    auth = occ.load_hisco_authority()
    idx = (code, status, relation, product)
    basis = "exact-4tuple"
    if idx not in auth.index and relation == "-9":
        idx, basis = (code, "-9", "-9", "-9"), "base-fallback"
    if idx in auth.index:
        a = auth.loc[idx]
        if isinstance(a, pd.DataFrame):                  # defensive: key must be unique
            a = a.iloc[0]
        return {c: a.get(c) for c in _LOOKUP_COLS} | {"basis": basis}

    rows = _by_code().get(code)
    if rows is None:
        return out
    got = {c: next((v for v in rows[c] if pd.notna(v)), pd.NA) for c in _LOOKUP_COLS}
    classes = {int(v) for v in rows["hisclass"] if pd.notna(v)}
    if len(classes) == 1:
        mods = ",".join(sorted(set(rows["status"].astype(str))))
        return got | {"basis": f"only-with-status-{mods}"}
    got |= {c: pd.NA for c in ("hisclass", "hisclass_label", "hisclass_5", "hisclass_5_label")}
    return got | {"basis": "class-varies-by-modifier"}


def _by_code() -> dict[str, pd.DataFrame]:
    """``{hisco -> its authority rows}`` — the last-resort lookup, built once."""
    global _BY_CODE
    if _BY_CODE is None:
        a = occ.load_hisco_authority().reset_index()
        _BY_CODE = {c: g for c, g in a.groupby("hisco", sort=False)}
    return _BY_CODE


_BY_CODE: dict[str, pd.DataFrame] | None = None


def _known_codes() -> set[str]:
    """Every HISCO code the authority recognises — the gate on note-derived candidates."""
    return set(occ.load_hisco_authority().index.get_level_values("hisco"))


# ═══════════════════════════════════════════════════════════════════════════
# The candidate universe
# ═══════════════════════════════════════════════════════════════════════════
def candidates(row: pd.Series, known: set[str]) -> list[tuple[str, str]]:
    """``[(code, proposed_by)]`` for one curation row — the current code first.

    Four sources, three of them structured and one prose:

    * ``current`` — what the pipeline codes today. **Always emitted**, even as a sentinel
      (``-1`` no occupation, ``-2`` an employer rather than a job) and even as an empty
      string: six flagged keys carry no code at all, and "today this record has no
      occupation" is the baseline the alternatives have to beat, not a row to omit.
    * ``german-bridge`` — ``link_hisco``, semicolon-separated where one German gloss reached
      several HISCO codes. This is the only genuinely *enumerated* alternatives list in the
      project.
    * ``occcanine`` — the transformer's single dissenting code.
    * ``note`` — five-digit codes named in the hand-written note, kept only if the authority
      recognises them. This is what recovers ``rytec``'s "could equally be 92420 or 89420":
      an argument that until now existed only as a sentence.
    """
    cur = row["hisco"].strip()
    seen: dict[str, list[str]] = {cur: ["current"]}

    def _add(code: str, src: str) -> None:
        code = code.strip()
        if not code or code == cur:
            return
        # two coders landing on the same code is the strongest signal in the sheet — record
        # both, rather than letting whichever ran first take the credit
        seen.setdefault(code, []).append(src)

    for c in row["link_hisco"].split(";"):
        _add(c, "german-bridge")
    _add(row["occcanine_hisco"], "occcanine")
    for c in _CODE_RE.findall(row["note"]):
        if c in known:                                   # a bare number in prose is not a code
            _add(c, "note")
    return [(code, "+".join(dict.fromkeys(srcs))) for code, srcs in seen.items()]


def _moves(cand: dict, cur: dict) -> str:
    """Does taking this candidate change the social class, or only the five-digit code?

    The column the whole sheet exists for. A code-only difference is a scholarly nicety;
    a class difference moves records between rungs of the outcome variable.
    """
    if cand["_is_current"]:
        return "—"
    if not str(cur["hisco"]).strip():
        return "no code today"            # nothing to move from; any candidate is a gain
    a, b = cand["hisclass"], cur["hisclass"]
    if pd.isna(a) and pd.isna(b):
        return "code only"
    if pd.isna(a) or pd.isna(b) or int(a) != int(b):
        return "class"
    return "code only"


def build_conflicts(cur_df: pd.DataFrame) -> pd.DataFrame:
    """The adjudication table: one row per (review-flagged key × candidate code)."""
    known = _known_codes()
    coded_n = cur_df.loc[cur_df["hisco"].str.strip() != "", "_n"].sum()
    rows: list[dict] = []

    flagged = cur_df[cur_df["review"].str.strip() == "1"].sort_values(
        "_n", ascending=False, kind="stable")

    for _, r in flagged.iterrows():
        status = r["status"] or "-9"
        relation = r["relation"] or "-9"
        product = r["product"] or "-9"
        cands = candidates(r, known)
        block: list[dict] = []
        for letter, (code, src) in zip("ABCDEFGH", cands):
            look = _lookup(code, status, relation, product)
            block.append({
                "key": r["key"],
                "n": int(r["_n"]),
                "pct_of_coded": round(r["_n"] / coded_n * 100, 3) if coded_n else 0.0,
                "de_gloss": r["de_gloss"],
                "en_gloss": r["en_gloss"],
                "cand": letter,
                "is_current": "current" if src == "current" else "",
                "hisco": code,
                "hisco_label_en": _title(look, code),
                "major_label": look["major_label"],
                "hisclass": look["hisclass"],
                "hisclass_label": look["hisclass_label"],
                "hisclass_5": look["hisclass_5"],
                "hisclass_basis": look["basis"],
                "proposed_by": src,
                "occcanine_p": r["occcanine_p"] if "occcanine" in src else "",
                "_is_current": src == "current",
            })
        cur_row = next((b for b in block if b["_is_current"]), block[0])
        for b in block:
            b["moves"] = _moves(b, cur_row)

        # CZ-ISCO, the curation note and the human columns belong to the KEY, not to any one
        # candidate — they go on the first row of the block so the group reads as a group.
        for i, b in enumerate(block):
            first = i == 0
            b |= {
                "czisco_cs": r["czisco_cs"] if first else "",
                "czisco_en": r["czisco_en"] if first else "",
                "czisco_agree": r["czisco_agree"] if first else "",
                "note": r["note"] if first else "",
                "DECISION": "", "final_hisco": "", "reason": "",
            }
            b.pop("_is_current")
        rows.extend(block)

    out = pd.DataFrame(rows)
    out.insert(0, "row", range(1, len(out) + 1))
    return out


def build_czisco_only(cur_df: pd.DataFrame) -> pd.DataFrame:
    """CZ-ISCO contradicts us and nothing flagged it — a gap in the flagging, not the coding.

    ``run_czisco_check.py`` writes the ``czisco_*`` columns but never the ``review`` column,
    so a disagreement it found only reaches a human if some *other* check flagged the same
    key. These are the ones no other check reached — minus any already carrying a
    ``verdict``, since nothing here would ever clear them and the sheet would repeat itself
    on every build. They are kept on their own sheet because
    the question is different in kind: not "which of these HISCO codes", but "is the Czech
    reading itself wrong" — CZ-ISCO offers no HISCO code to switch to.
    """
    answered = (cur_df["verdict"].str.strip() != "" if "verdict" in cur_df.columns
                else pd.Series(False, index=cur_df.index))
    d = cur_df[(cur_df["czisco_agree"].str.strip() == "0")
               & (cur_df["hisco"].str.strip() != "")
               & (cur_df["review"].str.strip() != "1")
               & ~answered].sort_values("_n", ascending=False, kind="stable")
    rows = []
    for _, r in d.iterrows():
        look = _lookup(r["hisco"].strip(), r["status"] or "-9",
                       r["relation"] or "-9", r["product"] or "-9")
        rows.append({
            "key": r["key"], "n": int(r["_n"]),
            "de_gloss": r["de_gloss"], "en_gloss": r["en_gloss"],
            "our_hisco": r["hisco"], "our_label_en": _title(look, r["hisco"].strip()),
            "our_hisclass": look["hisclass"], "our_hisclass_label": look["hisclass_label"],
            "czisco_code": r["czisco_code"], "czisco_cs": r["czisco_cs"],
            "czisco_en": r["czisco_en"], "czisco_n_hits": r["czisco_n_hits"],
            "note": r["note"],
            "VERDICT": "", "final_hisco": "", "reason": "",
        })
    out = pd.DataFrame(rows)
    if len(out):
        out.insert(0, "row", range(1, len(out) + 1))
    return out


# ═══════════════════════════════════════════════════════════════════════════
# One row per key — the shape a decision is actually made in
# ═══════════════════════════════════════════════════════════════════════════
_SOURCE_NAME = {"current": "current", "german-bridge": "German gloss",
                "occcanine": "OccCANINE", "note": "the note"}

_BASIS_CAVEAT = {
    "base-fallback": "class shown is the unmodified code's",
    "only-with-status-21": "class holds only for a master of the trade",
    "class-varies-by-modifier": "class depends on a modifier we do not have",
    "not-in-authority": "code is not in the HISCO hierarchy — treat with suspicion",
}


def _class_phrase(row: pd.Series) -> str:
    """``class 7 — Medium skilled workers``, with the caveat inline where there is one.

    ``hisclass_basis`` used to be a column of its own with four values and a paragraph of
    instructions explaining them. Eleven rows in the whole sheet are not ``exact-4tuple``,
    so the column cost 327 readings to serve 11: the caveat belongs in the cell it qualifies.
    """
    cls = row["hisclass"]
    txt = "no HISCLASS" if pd.isna(cls) else f"class {int(cls)} — {row['hisclass_label']}"
    caveat = _BASIS_CAVEAT.get(row["hisclass_basis"])
    return f"{txt}  ({caveat})" if caveat else txt


def _sources(proposed_by: str) -> str:
    return " + ".join(_SOURCE_NAME.get(s, s) for s in proposed_by.split("+"))


def _now_cell(cur: pd.Series) -> str:
    """What the pipeline codes today — the baseline every alternative has to beat."""
    if not str(cur["hisco"]).strip():
        return "no code at all\n(any candidate is a gain)"
    return f"A · {cur['hisco']}  {cur['hisco_label_en']}\n{_class_phrase(cur)}"


def _alt_cell(rivals: pd.DataFrame) -> str:
    """Every rival on its own line, the class-movers marked.

    One cell rather than one column per candidate: 59 of the 76 live conflicts are a plain
    A-or-B, so a C/D/E column would sit empty on all of them to serve the single key
    (``železniční zřízenec``) that reaches G.
    """
    lines = []
    for _, r in rivals.iterrows():
        mark = "   <-- MOVES" if r["moves"] == "class" else ""
        src = _sources(r["proposed_by"])
        if "occcanine" in r["proposed_by"] and str(r["occcanine_p"]).strip():
            src += f" p={float(r['occcanine_p']):.2f}"
        lines.append(f"{r['cand']} · {r['hisco']}  {r['hisco_label_en']}{mark}\n"
                     f"      {_class_phrase(r)}   [{src}]")
    return "\n".join(lines)


def _evidence_cell(cur: pd.Series) -> str:
    """The German gloss, the curation note and CZ-ISCO's one line — merged into a paragraph.

    Four columns became one. CZ-ISCO stays exactly what it was: evidence about the Czech
    reading, never a code to pick, so it says what it thinks and offers nothing to choose.
    """
    gloss = f"{cur['de_gloss']} · {cur['en_gloss']}".strip(" ·")
    parts = [gloss] if gloss else []
    # 86 of the 167 notes are the current code's English title typed out again; the title is
    # already in the `now` cell one column left, so repeating it here is pure column noise
    said = f"{gloss} | {cur['hisco_label_en']}".lower()
    note = str(cur["note"]).strip()
    if note and note.lower() not in said:
        parts.append(note)
    agree = str(cur["czisco_agree"]).strip()
    if agree == "0":
        parts.append(f"CZ-ISCO reads it differently: {cur['czisco_cs']} ({cur['czisco_en']})")
    elif agree == "1":
        parts.append("CZ-ISCO agrees with the current code.")
    elif agree == "band":
        parts.append("CZ-ISCO agrees to within a class band.")
    return "\n".join(p for p in parts if p)


# The column order of each bucket, so an emptied sheet still knows what it is (v2.1.1).
_DECIDE_COLS = ["occupation", "records", "% of coded", "now", "alternatives", "evidence",
                "DECISION", "why / what it should be", "_options"]
_NONE_COLS = ["occupation", "records", "% of coded", "now", "alternatives", "evidence",
              "VERDICT", "why / what it should be"]


def build_decisions(conf: pd.DataFrame) -> dict[str, pd.DataFrame]:
    """Collapse the candidate rows into one row per key, split by whether it is worth time.

    The long table answers "what are the candidates". Nobody has to answer that question.
    The question in front of a human is "which code, for this word" — one per key, 172 of
    them, and only 76 where the answer moves records between social classes. So the sheet
    that gets opened holds those 76, the 44 code-only arguments sit behind it, and the 52
    keys with no rival at all are a list rather than a decision.
    """
    frames: dict[str, list[dict]] = {"live": [], "same": [], "none": []}

    for key, g in conf.groupby("key", sort=False):
        cur = g[g["is_current"] == "current"].iloc[0]
        rivals = g[g["is_current"] != "current"]
        moves = g["moves"].isin(("class", "no code today")).any()
        bucket = "none" if rivals.empty else ("live" if moves else "same")

        row = {
            "occupation": key,
            "records": int(cur["n"]),
            "% of coded": cur["pct_of_coded"],
            "now": _now_cell(cur),
            "alternatives": _alt_cell(rivals) if len(rivals) else "none proposed by any coder",
            "evidence": _evidence_cell(cur),
        }
        if bucket == "none":
            row |= {"VERDICT": "", "why / what it should be": ""}
        else:
            row |= {"DECISION": "", "why / what it should be": "",
                    "_options": ",".join(["A (keep)"] + list(rivals["cand"])
                                         + ["other", "unsure"])}
        frames[bucket].append(row)

    out = {}
    for name, rows in frames.items():
        # An empty bucket must still carry its columns. ``pd.DataFrame([])`` has none, so
        # the sheet went out with no header row at all and `verify_xlsx` could not find one
        # — which is exactly what happened the first time the adjudication emptied `live`
        # and `same` (2026-08-26): the ten surviving keys are all sentinels and bare words
        # no coder proposed a rival for, so both decision sheets were empty for the first
        # time. A sheet with a header and no rows is the honest rendering of "nothing left
        # to decide here"; a sheet with neither is a bug that reads like one.
        cols = _NONE_COLS if name == "none" else _DECIDE_COLS
        df = pd.DataFrame(rows, columns=cols)
        if len(df):
            df = df.sort_values("records", ascending=False, kind="stable")
            df = df.reset_index(drop=True)
        df.insert(0, "#", range(1, len(df) + 1))
        out[name] = df
    return out

_HUMAN_COLS = {"DECISION", "VERDICT", "why / what it should be"}

_HOW = ("Pick A to keep the current code, or the letter of the rival you want. "
        "'other' = a code nobody proposed — name it in the last column. "
        "Leave a row blank rather than guess: an open flag is honest, a wrong code is not. "
        "Nothing is applied automatically — a filled row goes by hand into HISCO_OVERRIDE "
        "in utils/reference_tools/occupations/czech_glosses.py, then the curation is rebuilt.")

_WIDTH = {"#": 5, "occupation": 22, "records": 9, "% of coded": 10,
          "now": 40, "alternatives": 56, "evidence": 46,
          "DECISION": 13, "VERDICT": 13, "why / what it should be": 34,
          "our_hisco": 11, "our_label_en": 30, "our_hisclass": 11,
          "czisco_cs": 26, "czisco_en": 26, "note": 34}


def _write_xlsx(dec: dict[str, pd.DataFrame], czo: pd.DataFrame) -> Path:
    """Write the workbook — same visual language as ``build_validation_workbook.py``."""
    from openpyxl import Workbook
    from openpyxl.styles import Alignment, Font, PatternFill
    from openpyxl.utils import get_column_letter
    from openpyxl.worksheet.datavalidation import DataValidation

    wb = Workbook()
    hdr_fill = PatternFill("solid", fgColor="003657")        # CU navy
    hdr_font = Font(bold=True, color="FFFFFF")
    ask_fill = PatternFill("solid", fgColor="FDE9EC")        # light red — the human columns
    band_fill = PatternFill("solid", fgColor="F2F5F8")
    banner_font = Font(italic=True, color="6E6E6E", size=10)

    def _dump(df: pd.DataFrame, title: str, banner: list[str],
              *, fixed_list: tuple[str, str] | None = None) -> None:
        df = df.copy()
        opts = df.pop("_options") if "_options" in df.columns else None
        ws = wb.create_sheet(title)

        # Written by explicit coordinate, never by ``append``: an ``append([])`` spacer row
        # creates no cell, so ``max_row`` does not advance past it and every subsequent row
        # index is one short — which put the header styling on the blank row and every
        # per-key dropdown one row above the key it belongs to.
        head = len(banner) + 2                       # banner lines, one blank row, the header
        for i, line in enumerate(banner, start=1):
            ws.cell(row=i, column=1, value=line).font = banner_font
        for j, col in enumerate(df.columns, start=1):
            ws.cell(row=head, column=j, value=col)
        for i, (_, r) in enumerate(df.iterrows()):
            for j, v in enumerate(r, start=1):
                ws.cell(row=head + 1 + i, column=j, value=("" if pd.isna(v) else v))

        for j, col in enumerate(df.columns, start=1):
            c = ws.cell(row=head, column=j)
            c.fill, c.font = hdr_fill, hdr_font
            c.alignment = Alignment(vertical="center", wrap_text=True)
            ws.column_dimensions[get_column_letter(j)].width = _WIDTH.get(col, 18)
            for i in range(len(df)):
                cell = ws.cell(row=head + 1 + i, column=j)
                cell.alignment = Alignment(vertical="top", wrap_text=True)
                if col in _HUMAN_COLS:
                    cell.fill = ask_fill
                elif i % 2:
                    cell.fill = band_fill

        # the dropdown lists THIS key's own letters — a generic correct/wrong list would
        # not tell the reader what they are choosing between
        if opts is not None:
            col = get_column_letter(list(df.columns).index("DECISION") + 1)
            for i, formula in enumerate(opts):
                dv = DataValidation(type="list", formula1=f'"{formula}"', allow_blank=True)
                ws.add_data_validation(dv)
                dv.add(f"{col}{head + 1 + i}")
        if fixed_list and len(df):
            name, options = fixed_list
            col = get_column_letter(list(df.columns).index(name) + 1)
            dv = DataValidation(type="list", formula1=f'"{options}"', allow_blank=True)
            ws.add_data_validation(dv)
            dv.add(f"{col}{head + 1}:{col}{head + len(df)}")
        ws.freeze_panes = f"C{head + 1}"

    def _size(df: pd.DataFrame) -> str:
        return f"{len(df)} words, {int(df['records'].sum()):,} records" if len(df) else "empty"

    stamp = (f"Built {_dt.date.today().isoformat()} · build_conflict_workbook {__version__} "
             f"· occupations {occ.__version__} · every candidate, with its provenance, in "
             f"reference/occupations/occupation_conflicts.csv")

    wb.remove(wb.active)                                     # no Instructions sheet
    _dump(dec["live"], "Decide",
          ["The occupation codings still open where the answer moves records between social "
           f"classes — {_size(dec['live'])}, biggest first.", _HOW, stamp])
    _dump(dec["same"], "Same class either way",
          [f"A rival code exists but carries the same HISCLASS — {_size(dec['same'])}. "
           "Nothing downstream moves whichever way these go. Answer them if you want the "
           "five-digit codes right; skip them if you want the class variable right.", _HOW])
    _dump(dec["none"], "Nothing to choose from",
          [f"Flagged for review, but no coder proposed an alternative — {_size(dec['none'])}. "
           "There is no A-or-B here: either the current code stands or the right one has to "
           "be found outside this project. VERDICT: keep / wrong / unsure.", _HOW],
          fixed_list=("VERDICT", "keep,wrong,unsure"))
    if len(czo):
        czo = czo.rename(columns={"key": "occupation", "n": "records",
                                  "reason": "why / what it should be"})
        _dump(czo[["occupation", "records", "our_hisco", "our_label_en", "our_hisclass",
                   "czisco_cs", "czisco_en", "note", "VERDICT", "why / what it should be"]],
              "CZ-ISCO says otherwise",
              ["CZ-ISCO contradicts our Czech reading and no other check flagged the word — "
               f"{len(czo)} words. CZ-ISCO is ISCO-08 and HISCO is ISCO-68, so there is no "
               "code here to switch to: the question is only whether the reading is wrong.",
               _HOW],
              fixed_list=("VERDICT", "keep,wrong,unsure"))

    OUT_XLSX.parent.mkdir(parents=True, exist_ok=True)
    wb.save(OUT_XLSX)
    return OUT_XLSX


def verify_xlsx(path: Path) -> int:
    """Read the saved workbook back and check every dropdown against its own row.

    A dropdown is placed by row index, and a row index computed from ``max_row`` was
    silently one short — the offence the repo has met four times before (an unguarded
    index, wrong in a way that still produces a plausible-looking sheet). The only proof
    is the file itself: the letters offered in a cell must be the letters printed in the
    ``alternatives`` cell beside it. Returns the number of rows checked.
    """
    from openpyxl import load_workbook
    from openpyxl.utils import get_column_letter

    wb = load_workbook(path)
    checked = 0
    for ws in wb:
        head = next((r for r in range(1, 12)
                     if ws.cell(row=r, column=1).value in ("#", "occupation")), None)
        assert head, f"{ws.title}: no header row found"
        cols = {ws.cell(row=head, column=j).value: j
                for j in range(1, ws.max_column + 1)}
        if "DECISION" not in cols or "alternatives" not in cols:
            continue
        letter = get_column_letter(cols["DECISION"])
        at = {str(rng): dv.formula1
              for dv in ws.data_validations.dataValidation for rng in dv.sqref.ranges}
        for r in range(head + 1, ws.max_row + 1):
            alts = str(ws.cell(row=r, column=cols["alternatives"]).value or "")
            want = [ln.split(" ·")[0].strip() for ln in alts.splitlines()
                    if ln[:1].isalpha() and ln[1:2] == " "]
            got = at.get(f"{letter}{r}", "").strip('"').split(",")
            assert got[:1] == ["A (keep)"] and got[1:1 + len(want)] == want, (
                f"{ws.title} row {r} ({ws.cell(row=r, column=2).value!r}): "
                f"dropdown {got} does not match the candidates {want}")
            checked += 1
    return checked

def load_curation() -> pd.DataFrame:
    """The raw curation CSV — *all* rows, including the uncoded ones.

    Deliberately not ``occupations.load_occupation_curation``, which drops rows without a
    HISCO code so that an uncoded skeleton row behaves like an absent one. Six flagged keys
    have no code at all (``lihovarník``, ``dřevorubec``, ``kněz``…) and they are exactly the
    ones a human most needs to see.
    """
    df = pd.read_csv(CURATION, dtype=str).fillna("")
    df["_n"] = pd.to_numeric(df["n"], errors="coerce").fillna(0)
    return df


def main() -> None:
    """Build the sheets, check the invariants, write the workbook and its CSV twin."""
    try:
        sys.stdout.reconfigure(encoding="utf-8", errors="replace")
    except (AttributeError, OSError):                    # pragma: no cover
        pass

    cur_df = load_curation()
    conf = build_conflicts(cur_df)
    czo = build_czisco_only(cur_df)
    dec = build_decisions(conf)

    # ── invariants: a silent failure here would look exactly like a finding ─────────
    n_keys = conf["key"].nunique()
    assert n_keys == int((cur_df["review"].str.strip() == "1").sum()), \
        f"{n_keys} keys in the sheet, {(cur_df['review'] == '1').sum()} flagged in the curation"
    per_key_current = conf.groupby("key")["is_current"].apply(lambda s: (s == "current").sum())
    assert (per_key_current == 1).all(), \
        f"keys without exactly one current row: {list(per_key_current[per_key_current != 1].index)}"
    # collapsing to one row per key must lose no key and duplicate none
    assert sum(len(d) for d in dec.values()) == n_keys, \
        f"{sum(len(d) for d in dec.values())} rows across the sheets, {n_keys} flagged keys"
    unknown = conf[(conf["hisco"].str.strip() != "")
                   & (conf["hisclass_basis"] == "not-in-authority")]
    if len(unknown):
        print(f"!! {len(unknown)} candidate codes are not in hisco_authority.csv "
              f"(a bug, not a finding): {sorted(set(unknown['hisco']))}")
    czisco_codes = set(cur_df["czisco_code"]) - {""}
    assert not (set(conf["hisco"]) & czisco_codes - _known_codes()), \
        "a CZ-ISCO code leaked into the HISCO candidate column"

    OUT_CSV.parent.mkdir(parents=True, exist_ok=True)
    conf.to_csv(OUT_CSV, index=False, encoding="utf-8")
    path = _write_xlsx(dec, czo)

    n_checked = verify_xlsx(path)

    print(f"wrote {path.relative_to(ROOT)}  ({n_checked} dropdowns verified against their row)")
    print(f"wrote {OUT_CSV.relative_to(ROOT)}  ({len(conf)} candidate rows, unchanged shape)")
    print(f"  {n_keys} flagged keys, {int(conf.groupby('key')['n'].first().sum()):,} records")
    for sheet, name in (("live", "Decide (a rival moves HISCLASS)"),
                        ("same", "Same class either way"),
                        ("none", "Nothing to choose from")):
        d = dec[sheet]
        print(f"    {name:<34} {len(d):>4} keys  {int(d['records'].sum()):>7,} records"
              if len(d) else f"    {name:<34}    0 keys")
    print(f"    CZ-ISCO says otherwise             {len(czo):>4} keys  "
          f"{int(czo['n'].sum()) if len(czo) else 0:>7,} records")


if __name__ == "__main__":
    main()
