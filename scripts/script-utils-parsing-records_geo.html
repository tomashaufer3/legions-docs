How it works

Why this is not a plain equality join

The csol.cz / VÚA birth_okres field mixes two administrative levels:

  • the political okres (politický okres) — e.g. Most, Trutnov — which is the census unit, and
  • the court district (soudní okres / Gerichtsbezirk) — e.g. Hořovice (which sat in political okres Beroun), Falknov nad Ohří (in Loket), Nymburk (in Poděbrady).

So the lookup is built from both the political-okres names (okres_cs / okres_cs_modern / okres_de) and the court names (gerichtsbezirk_cs / …_modern / …_de), every one resolving to its parent okres_id. Political-okres names take priority where a name is shared with a court in a different okres (the city/rural pairs, e.g. Olomouc vs Olomouc (město), whose seat court carries the same name in both units).

City/rural twins

Ten seats name two units, a statutory city and the rural district around it. A district string alone cannot tell them apart, so add_birth_okres_id resolves the bare name to the rural unit throughout, a trailing rural qualifier (Olomouc venkov) is stripped by rule rather than by fuzzy accident, and resolve_twin_pairs then promotes to the city unit exactly those records whose municipality is the city itself. See DECISIONS D-17.

Greater Prague — a 1922 boundary written onto 1910 records

Prague absorbed 37 municipalities on 1 January 1922, and both person databases were compiled afterwards. A clerk copying the card of a man born in Žižkov in 1890 wrote the okres he knew — Praha — for a town that in 1910 was the seat of its own political okres. The okres tier matches that outright and never consults the municipality, so those records carried inner-Prague census covariates. resolve_prague_suburbs sends them to the 1910 okres their municipality actually had, from the curated reference/places/prague_suburb_curation.csv. Same shape as the twin rule — the municipality decides — but not the same thing: a twin pair coexisted in 1910, whereas here one unit swallowed the others twelve years later. Carried in {prefix}_okres_prague (city / suburb). See DECISIONS D-36.

Match tiers (birth_okres_match)

okres matched a political-okres name (strongest) court matched a court-district name → its parent okres fuzzy token-set ratio ≥ threshold to a lookup key (near-exact variants such as Teplice-Šanov → Teplice). A tie at the top score means the cell names more than one district; it is broken by the record's own municipality, else by the Prague-suburb rule, else refused (DECISIONS D-23) alias resolved via a curated ALIAS_OVERRIDE entry &lt;NA&gt; no confident match — overwhelmingly a birthplace outside the Czech-lands 1910 census frame (Slovakia, Hungary, Vienna, Galicia, Russia) or an okres created after 1910; these individuals legitimately have no Cisleithanian census covariate.

def settlement_name_set(settlements: pd.DataFrame,
                        cols: tuple[str, ...] = ("cs_name", "name_1910", "de_name")) -> set[str]:
    """All normalised settlement names of a crosswalk (for cross-frame ambiguity guards).

    Used to refuse bare-municipality matches whose name exists in the *other*
    country's settlement frame too (a Czech record "Petrovice" must not be claimed
    by the single Slovak Petrovice, and vice versa): with no district to
    corroborate, a name present in both frames is genuinely ambiguous. Pass the
    Czech set to :func:`records_geo_hu.add_settlement_jaras` and the Slovak set

    out: set[str] = set()
    for c in cols:
        if c in settlements.columns:
            out |= {_norm(v) for v in settlements[c].dropna()}
    out.discard("")
    return out

def build_okres_lookup(districts: pd.DataFrame,
                       report_collisions: bool = False) -> dict[str, tuple[int, str]]:
    """``{normalised name → (okres_id, level)}`` from political-okres and court names.

    ``level`` is ``"okres"`` for a political-okres name and ``"court"`` for a court name.
    On a name shared across okresy, a political-okres name wins over a court name; ties
    between two court names in different okresy keep the first seen (rare; city/rural pairs).
    Pass ``report_collisions=True`` to print every silently-resolved name collision once
    (audit aid — a colliding court name can mis-assign records that carry only that name).
    """
    def okres_id(code: str) -> int:
        r, d = str(code).split("-")
        return int(r) * 1000 + int(d)

    lut: dict[str, tuple[int, str]] = {}
    collisions: list[tuple[str, str, int, str, int]] = []   # (name, kept lvl, kept oid, new lvl, new oid)

    def add(value, oid: int, level: str) -> None:
        k = _norm(value)
        if not k:
            return
        cur = lut.get(k)
        if cur is None or (level == "okres" and cur[1] == "court"):
            lut[k] = (oid, level)
        elif cur[0] != oid:                                  # same name, different okres — kept first
            collisions.append((k, cur[1], cur[0], level, oid))

    okres_rows = districts.drop_duplicates("okres_code")
    for _, r in okres_rows.iterrows():
        oid = okres_id(r["okres_code"])
        for col in ("okres_cs", "okres_cs_modern", "okres_de"):
            add(r.get(col), oid, "okres")
    for _, r in districts.iterrows():
        oid = okres_id(r["okres_code"])
        for col in ("gerichtsbezirk_cs", "gerichtsbezirk_cs_modern", "gerichtsbezirk_de"):
            add(r.get(col), oid, "court")
    if report_collisions and collisions:
        print(f"okres lookup: {len(collisions)} cross-okres name collisions (first seen wins):")
        for k, l0, o0, l1, o1 in sorted(set(collisions)):
            print(f"    {k!r}: kept {l0} → {o0}, ignored {l1} → {o1}")
    return lut

def add_birth_okres_id(
    df: pd.DataFrame,
    districts: pd.DataFrame,
    okres_col: str | None = None,
    fuzzy: bool = True,
    threshold: int = 90,
    aliases: dict[str, int | None] | None = None,
    prefix: str = "birth",
    settlements: pd.DataFrame | None = None,
    muni_col: str | None = None,
) -> pd.DataFrame:
    """Add ``{prefix}_okres_id`` (Int64) and ``{prefix}_okres_match`` (category) to *df*.

    Resolution order per distinct value: alias override → exact (okres, then court) →
    rural-suffix strip and retry → optional token-set fuzzy (≥ *threshold*). Unresolved values
    get ``<NA>`` / ``<NA>``. Matching is done on the ~few-thousand **distinct** district strings,
    then broadcast. *okres_col* defaults to ``{prefix}_okres``; pass it explicitly to read another
    column (e.g. the lexikon's ``okres_1910``).

    Fuzzy ties
    ----------
    A token-set ratio scores 100 against **every** district a cell names, so ``Tábor Praha``,
    ``Ostrava`` and ``Nové Město`` all tie at the top — and the winner was whichever key the
    lookup happened to hold first, which is dict insertion order wearing a match's clothes.
    Pass *settlements* (the ``settlements_1910`` crosswalk) and a tie is instead resolved
    per **record**, by evidence (:func:`_resolve_fuzzy_ties`, DECISIONS D-23):

    1. the record's own ``{muni_col}`` sits in exactly one of the tied okresy → that one;
    2. else, the tie is Praha plus exactly one Prague-suburb okres → the **suburb**;
    3. else refuse — ``<NA>``, not a coin flip.

    Without *settlements* there is nothing to corroborate with, and the behaviour is unchanged
    (first match wins). That is deliberate, and it is what the :mod:`utils.parsing.lexikon` call
    wants: the ČSÚ register writes the **1910 period name** for the Bohemian member of a
    Bohemia/Moravia twin — bare ``Krumlov`` and ``Budějovice``, whose own ``okres_all`` timelines
    read ``Krumlov|Český Krumlov`` — and always qualifies the Moravian one (``Moravský Krumlov``,
    ``Moravské Budějovice``). For those 481 settlement rows the first match is the *right* answer,
    and refusing them would cost the settlement layer its okresy.
    """
    if okres_col is None:
        okres_col = f"{prefix}_okres"
    if muni_col is None:
        muni_col = f"{prefix}_municipality"
    aliases = {**ALIAS_OVERRIDE, **(aliases or {})}
    lut = build_okres_lookup(districts)
    keys = list(lut.keys())
    lut_nospace = _nospace_index(lut)
    break_ties = settlements is not None and muni_col in df.columns

    distinct = pd.Index(df[okres_col].dropna().unique())
    id_map: dict[str, "int | None"] = {}
    tier_map: dict[str, "str | None"] = {}
    tied: dict[str, set[int]] = {}
    for raw in distinct:
        k = _norm(raw)
        if not k:
            id_map[raw], tier_map[raw] = None, None
            continue
        if k in aliases:                                   # curated override (may be None)
            oid = aliases[k]
            id_map[raw], tier_map[raw] = oid, ("alias" if oid is not None else None)
            continue
        hit = lut.get(k)
        if hit is not None:
            id_map[raw], tier_map[raw] = hit[0], hit[1]    # "okres" or "court"
            continue
        bare = _RURAL_SUFFIX.sub("", k).strip()            # "olomouc venkov" -> "olomouc"
        if bare and bare != k:
            hit = lut.get(bare)
            if hit is not None:
                id_map[raw], tier_map[raw] = hit[0], hit[1]
                continue
        hit = lut_nospace.get(k.replace(" ", ""))          # "prachat ice" -> "prachatice"
        if hit is not None:
            id_map[raw], tier_map[raw] = hit[0], hit[1]
            continue
        if fuzzy:
            m = process.extractOne(k, keys, scorer=fuzz.token_set_ratio)
            if m is not None and m[1] >= threshold:
                id_map[raw], tier_map[raw] = lut[m[0]][0], "fuzzy"
                if break_ties:
                    best = {lut[x][0] for x in keys
                            if fuzz.token_set_ratio(k, x) == m[1]}
                    if len(best) > 1:                      # decided per record, below
                        id_map[raw], tier_map[raw] = None, None
                        tied[raw] = best
                continue
        id_map[raw], tier_map[raw] = None, None

    out = df.copy()
    out[f"{prefix}_okres_id"] = out[okres_col].map(id_map).astype("Int64")
    out[f"{prefix}_okres_match"] = pd.Categorical(
        out[okres_col].map(tier_map),
        categories=["okres", "court", "fuzzy", "alias", "settlement", "muni"],
    )
    if tied:
        out = _resolve_fuzzy_ties(out, tied, districts, settlements,
                                  okres_col, muni_col, prefix)
    return out

def add_birth_settlement_okres(
    df: pd.DataFrame,
    settlements: pd.DataFrame,
    okres_col: str | None = None,
    muni_col: str | None = None,
    land_col: str | None = None,
    prefix: str = "birth",
    exclude_names: set[str] | None = None,
) -> pd.DataFrame:
    """Second pass: recover ``birth_okres_id`` for still-unmatched rows via the settlement.

    Uses the Historický-lexikon crosswalk (:mod:`utils.parsing.lexikon`), matching on
    ``birth_municipality``. Two cases, both requiring a settlement named like the municipality:

    * **okres present but unmatched** → recover only when the record's raw ``birth_okres`` lies
      **somewhere in the settlement's okres timeline** (``okres_all``). This temporal gate resolves
      post-1910 okres labels (``Praha-venkov``, ``Kralupy`` → the 1910 okres) while rejecting
      foreign homonyms (a Czech village *Vídeň* never sat in okres *Vídeň*). Tier ``settlement``.
    * **okres missing entirely** → assign when the municipality maps to a settlement with an
      **unambiguous** 1910 okres (a single okres_id across all like-named settlements). There is no
      okres to corroborate, so this is the weaker tier ``muni`` — kept distinct so it can be
      filtered out for strict analyses, and **vetoed** when (a) ``land_col`` marks the birth as
      positively non-Czech (anything but "Czech lands"/NA — otherwise Austrian births whose village
      name coincides with a unique Czech settlement get mis-assigned), or (b) the name appears in
      *exclude_names* — the **cross-frame homonym guard**: pass the Slovak obec name set
      (:func:`settlement_name_set` on ``settlements_hu_1910`` with ``cols=("obec_sk",)``) so a bare
      name that exists in both countries' frames is refused rather than guessed, or (c) the only
      candidate is not an independent municipality (:data:`_NOT_A_PLACE` — an *osada* or a
      *část* of another village), which is the shape every big-city miss took.

    Requires :func:`add_birth_okres_id` to have run first (fills only the remaining ``<NA>``).
    Note: the returned frame has a **reset RangeIndex** (positional buffers are used
    internally) — callers relying on a meaningful index must re-attach it.
    """
    if okres_col is None:
        okres_col = f"{prefix}_okres"
    if muni_col is None:
        muni_col = f"{prefix}_municipality"
    if land_col is None:
        land_col = f"{prefix}_land"
    id_col, match_col = f"{prefix}_okres_id", f"{prefix}_okres_match"
    if id_col not in df.columns:
        raise ValueError(f"run add_birth_okres_id(..., prefix='{prefix}') first")

    # settlement name (modern + 1910 + German) → list of (okres timeline set, okres_id, status)
    sett = settlements[settlements["okres_id"].notna()]
    name_index: dict[str, list[tuple[set[str], int, str]]] = {}
    for _, r in sett.iterrows():
        timeline = {_norm(o) for o in str(r.get("okres_all") or "").split("|") if o.strip()}
        timeline.add(_norm(r["okres_1910"]))
        entry = (timeline, int(r["okres_id"]), str(r.get("status_1910") or ""))
        for nm in (r["cs_name"], r.get("name_1910"), r.get("de_name")):
            k = _norm(nm)
            if k:
                name_index.setdefault(k, []).append(entry)

    out = df.copy().reset_index(drop=True)
    ids = out[id_col].to_numpy(dtype="object")
    tiers = out[match_col].astype("object").to_numpy()
    has_muni = out[muni_col].notna()
    unmatched = out[id_col].isna()
    okres_present = out[okres_col].notna()
    land = out[land_col] if land_col in out.columns else None

    for pos in out.index[unmatched & has_muni]:
        cands = name_index.get(_norm(out.at[pos, muni_col]))
        if not cands:
            continue
        if okres_present.iat[pos]:
            ok = _norm(out.at[pos, okres_col])
            hit_ids = {oid for tl, oid, _st in cands if ok in tl}    # timeline gate
            if len(hit_ids) == 1:
                ids[pos], tiers[pos] = next(iter(hit_ids)), "settlement"
        else:
            if land is not None and pd.notna(land.iat[pos]) and land.iat[pos] != "Czech lands":
                continue                                         # veto foreign births (no okres)
            k = _norm(out.at[pos, muni_col])
            if k in CROSS_FRAME_WHITELIST:        # curated base-rate exception (e.g. Praha)
                ids[pos], tiers[pos] = CROSS_FRAME_WHITELIST[k], "muni"
                continue
            if exclude_names and k in exclude_names:
                continue                          # name exists in the SK frame too → ambiguous
            all_ids = {oid for _, oid, st in cands if st not in _NOT_A_PLACE}
            if len(all_ids) == 1:                 # unambiguous *municipality* only
                ids[pos], tiers[pos] = next(iter(all_ids)), "muni"
    out[id_col] = pd.array(ids, dtype="Int64")
    out[match_col] = pd.Categorical(tiers, categories=_TIERS)
    return out

def build_twin_pairs(districts: pd.DataFrame, settlements: pd.DataFrame | None=None) -> dict[int, tuple[int, int, frozenset[str]]]

{okres_id → (rural_id, city_id, city name keys)} for both members of every twin pair.

A 1910 Statutarstadt was its own political district, separate from the rural district around it, so ten seats name two units. The backbone spells them X (město) (city) and bare X (rural) — the pairs are derived from that convention rather than listed here, and the caller is expected to assert the count.

The city name keys are what a record's municipality is tested against. They come from the pair's own names: the bare Czech seat name, the German okres name (and its de-umlauted form, since the backbone writes Olmuetz where a record writes Olmütz), and — when settlements is passed — every name of the settlements the crosswalk places inside the city unit. That last source is exact rather than clever: a statutory city was a single municipality, so the crosswalk holds exactly one settlement per city unit, and it is the city.

def build_twin_pairs(districts: pd.DataFrame,
                     settlements: pd.DataFrame | None = None,
                     ) -> dict[int, tuple[int, int, frozenset[str]]]:
    """``{okres_id → (rural_id, city_id, city name keys)}`` for both members of every twin pair.

    A 1910 *Statutarstadt* was its own political district, separate from the rural district
    around it, so ten seats name two units. The backbone spells them ``X (město)`` (city) and
    bare ``X`` (rural) — the pairs are **derived** from that convention rather than listed here,
    and the caller is expected to assert the count.

    The *city name keys* are what a record's municipality is tested against. They come from the
    pair's own names: the bare Czech seat name, the German okres name (and its de-umlauted form,
    since the backbone writes ``Olmuetz`` where a record writes ``Olmütz``), and — when
    *settlements* is passed — every name of the settlements the crosswalk places **inside** the
    city unit. That last source is exact rather than clever: a statutory city was a *single*
    municipality, so the crosswalk holds exactly one settlement per city unit, and it is the city.
    """
    okres = districts.drop_duplicates("okres_code").copy()
    okres["oid"] = [int(c.split("-")[0]) * 1000 + int(c.split("-")[1])
                    for c in okres["okres_code"]]
    by_name = {str(cs): (int(oid), de) for cs, oid, de
               in zip(okres["okres_cs"], okres["oid"], okres["okres_de"])}

    pairs: dict[int, tuple[int, int, frozenset[str]]] = {}
    for cs, (city_id, city_de) in by_name.items():
        if not _MESTO.search(cs):
            continue
        base = _MESTO.sub("", cs)
        if base not in by_name:                       # a (město) unit with no bare twin
            continue
        rural_id = by_name[base][0]
        keys = {_norm(base)}
        if isinstance(city_de, str) and city_de.strip():
            keys.add(_norm(city_de))
            keys.add(_norm(city_de).replace("ue", "u"))   # Olmuetz -> olmutz, Bruenn -> brunn
        if settlements is not None and "okres_id" in settlements.columns:
            inside = settlements[settlements["okres_id"] == city_id]
            for col in ("cs_name", "name_1910", "de_name"):
                if col in inside.columns:
                    keys |= {_norm(v) for v in inside[col].dropna()}
        keys.discard("")
        entry = (rural_id, city_id, frozenset(keys))
        pairs[rural_id] = entry
        pairs[city_id] = entry
    return pairs

    # be excluded, and a flag that stops at the settlement frame cannot be excluded per record.
    fields = ("cs_name", "de_name", "court_id", "court_cs", "court_de", "court_snapped",

        # toward name ambiguity, but can never be resolved via the unique-name path
        key = qid if qid is not None and pd.notna(qid) else f"_row{rowno}"
        for nm in (rd.get("cs_name"), rd.get("name_1910"), rd.get("de_name")):

        if qid is not None and pd.notna(qid):
            row_by_qid[qid] = rec

    for k, s in name_ids.items():
        if len(s) == 1:
            v = next(iter(s))
            if v in row_by_qid:

    # place is not Czech — such a record must not pick up attrs by bare-name uniqueness

    # capture a Vienna-born record); an unresolved (<NA>) land is treated as possibly-Czech.
    land_col = f"{prefix}_land"
    lands = df[land_col].to_numpy() if land_col in df.columns else [pd.NA] * len(df)

    for i, (mu, oid, land, has_okres) in enumerate(zip(munis, oids, lands, okres_raw)):
        if pd.isna(mu):
            continue
        k = _norm(mu)
        rec = None
        if pd.notna(oid) and (k, int(oid)) in keyed:
            rec = keyed[(k, int(oid))]                       # okres-corroborated: always safe
        elif (k in uniq_name
              and not has_okres                              # an unresolved okres => not Czech
              and (pd.isna(land) or land == "Czech lands")   # bare-name: skip if foreign
              and not (exclude_names and k in exclude_names)):  # ... or a cross-frame homonym
            rec = uniq_name[k]
        if rec is not None:
            for c in have:
                cols[c][i] = rec[c]

    out = df.copy()
    rename = {"cs_name": f"{prefix}_municipality_cs", "de_name": f"{prefix}_municipality_de",
              "court_id": f"{prefix}_court_id", "court_cs": f"{prefix}_court_cs",
              "court_de": f"{prefix}_court_de", "court_snapped": f"{prefix}_court_snapped",
              "lat": f"{prefix}_lat", "lon": f"{prefix}_lon", "wd_qid": f"{prefix}_qid"}
    for c in have:
        s = pd.Series(cols[c], index=out.index)
        if c == "court_id":
            s = s.astype("Int64")
        elif c == "court_snapped":
            # boolean where a settlement matched, <NA> where none did — a record with no
            # court was not "not snapped", it has no court at all
            s = s.astype("boolean")
        elif c == "cs_name":
            s = s.map(_titlecase_cs)              # lexikon headwords are ALL-CAPS
        out[rename[c]] = s
    return out

"""
records_geo.py — attach the 1910 political-okres id to person records
=====================================================================
Maps a soldier's birth district string (``birth_okres``) to the 1910 political-okres
identifier (``okres_id`` = ``region·1000 + district``) of :mod:`utils.parsing.districts`
(``districts_1910``), so the okres-level census panel (:mod:`utils.parsing.census`) can be
joined on.

Why this is not a plain equality join
-------------------------------------
The csol.cz / VÚA ``birth_okres`` field mixes **two** administrative levels:

* the **political okres** (politický okres) — e.g. ``Most``, ``Trutnov`` — which is the
  census unit, *and*
* the **court district** (soudní okres / Gerichtsbezirk) — e.g. ``Hořovice`` (which sat in
  political okres *Beroun*), ``Falknov nad Ohří`` (in *Loket*), ``Nymburk`` (in *Poděbrady*).

So the lookup is built from **both** the political-okres names (``okres_cs`` / ``okres_cs_modern``
/ ``okres_de``) and the court names (``gerichtsbezirk_cs`` / ``…_modern`` / ``…_de``), every one
resolving to its **parent** ``okres_id``. Political-okres names take priority where a name is
shared with a court in a different okres (the city/rural pairs, e.g. *Olomouc* vs
*Olomouc (město)*, whose seat court carries the same name in both units).

City/rural twins
----------------
Ten seats name **two** units, a statutory city and the rural district around it. A district
string alone cannot tell them apart, so :func:`add_birth_okres_id` resolves the bare name to the
**rural** unit throughout, a trailing rural qualifier (``Olomouc venkov``) is stripped by rule
rather than by fuzzy accident, and :func:`resolve_twin_pairs` then promotes to the city unit
exactly those records whose *municipality* is the city itself. See DECISIONS D-17.

Greater Prague — a 1922 boundary written onto 1910 records
----------------------------------------------------------
Prague absorbed 37 municipalities on 1 January 1922, and **both** person databases were
compiled afterwards. A clerk copying the card of a man born in Žižkov in 1890 wrote the okres
he knew — *Praha* — for a town that in 1910 was the seat of its own political okres. The
``okres`` tier matches that outright and never consults the municipality, so those records
carried inner-Prague census covariates. :func:`resolve_prague_suburbs` sends them to the 1910
okres their municipality actually had, from the curated
``reference/places/prague_suburb_curation.csv``. Same shape as the twin rule — the
municipality decides — but not the same thing: a twin pair coexisted in 1910, whereas here one
unit swallowed the others twelve years later. Carried in ``{prefix}_okres_prague``
(``city`` / ``suburb``). See DECISIONS D-36.

Match tiers (``birth_okres_match``)
-----------------------------------
``okres``  matched a political-okres name (strongest)
``court``  matched a court-district name → its parent okres
``fuzzy``  token-set ratio ≥ *threshold* to a lookup key (near-exact variants such as
           ``Teplice-Šanov`` → *Teplice*). A tie at the top score means the cell names more
           than one district; it is broken by the record's own **municipality**, else by the
           Prague-suburb rule, else refused (DECISIONS D-23)
``alias``  resolved via a curated :data:`ALIAS_OVERRIDE` entry
``<NA>``   no confident match — overwhelmingly a birthplace **outside** the Czech-lands 1910
           census frame (Slovakia, Hungary, Vienna, Galicia, Russia) or an okres created
           after 1910; these individuals legitimately have no Cisleithanian census covariate.

Usage
-----
    from utils.parsing import records_geo as rg
    legion = rg.add_birth_okres_id(legion, districts_1910)
    rg.birth_okres_report(legion)
"""

    "ceska trebova": 301045,
    # 1910 spellings of an okres seat the backbone carries under its modern name. The ČSÚ
    # register writes "Horšův Týn", which is what the town was called until 1926.
    "horsuv tyn": 301004,              # okres Horšovský Týn
    # Foreign places that phonetically fuzzy-match a Czech okres — vetoed to <NA>

    "schweidnitz": None,               # Świdnica, Prussian Silesia (≈ Schweinitz/Trhové Sviny)

# A trailing "rural" qualifier on a district string: the record means the *ring* district of a
# city/rural twin pair — "Olomouc venkov", "Brno (venkov)", "Brünn Umgebung", "Košice vonkov".
# The backbone names the rural unit with the **bare** name (see DECISIONS D-17, and D-19 for the
# járás/town twins that work the same way), so stripping the qualifier and retrying the exact
# lookup is the whole rule. It replaces an accident: token-set fuzzy scored these ≥ 90 against the
# bare name and reached the same answer, which meant ~1,400 Czech and ~589 Slovak records were
# resolved at the `fuzzy` tier and were afterwards indistinguishable from a bare "Olomouc".
# Applied only after an exact lookup has already failed, and after ALIAS_OVERRIDE has had its
# say — so the curated veto on "praha venkov" (a 1927 creation, no 1910 equivalent) still wins.
# Shared with :mod:`utils.parsing.records_geo_hu`: `vonkov` / `vidiek` are the Slovak forms, and
# one regex for both lanes is how the two stay in step. No Czech okres or court name ends in any
# of these words, so widening it costs the Cisleithanian side nothing.
_RURAL_SUFFIX = re.compile(
    r"[\s(]*\b(venkov|vonkov|vidiek|okoli|okolí|land|umgebung)\b[\s)]*$")


# ── Normalisation ─────────────────────────────────────────────────────────────
def _norm(v) -> str:
    """De-accent, lowercase, treat ``-`` as a space, collapse whitespace.

    An **interior** ``n.``/``n`` token expands to ``nad`` — the near-universal
    Czech/Slovak place-name abbreviation ("Ústí n. Labem" → "usti nad labem",
    "Nové Mesto n. Váhom" → "nove mesto nad vahom"). Leading/trailing ``n.`` is
    left alone (a leading ``N.`` usually abbreviates *Nová/Nové*, and a trailing
    ``n.`` leaves the river ambiguous — expanding would let token-set fuzzy claim
    the wrong okres at 100).
    """
    if pd.isna(v):
        return ""
    s = "".join(c for c in unicodedata.normalize("NFKD", str(v)) if not unicodedata.combining(c))
    s = s.lower().replace("-", " ")
    toks = s.split()
    toks = ["nad" if t in ("n.", "n") and 0 < i < len(toks) - 1 else t
            for i, t in enumerate(toks)]
    return " ".join(toks)


def settlement_name_set(settlements: pd.DataFrame,
                        cols: tuple[str, ...] = ("cs_name", "name_1910", "de_name")) -> set[str]:
    """All normalised settlement names of a crosswalk (for cross-frame ambiguity guards).

    Used to refuse bare-municipality matches whose name exists in the *other*
    country's settlement frame too (a Czech record "Petrovice" must not be claimed
    by the single Slovak Petrovice, and vice versa): with no district to
    corroborate, a name present in both frames is genuinely ambiguous. Pass the
    Czech set to :func:`records_geo_hu.add_settlement_jaras` and the Slovak set
    (``cols=("obec_sk",)``) to :func:`add_birth_settlement_okres`.
    """
    out: set[str] = set()
    for c in cols:
        if c in settlements.columns:
            out |= {_norm(v) for v in settlements[c].dropna()}
    out.discard("")
    return out


# ── Lookup ────────────────────────────────────────────────────────────────────
def build_okres_lookup(districts: pd.DataFrame,
                       report_collisions: bool = False) -> dict[str, tuple[int, str]]:
    """``{normalised name → (okres_id, level)}`` from political-okres and court names.

    ``level`` is ``"okres"`` for a political-okres name and ``"court"`` for a court name.
    On a name shared across okresy, a political-okres name wins over a court name; ties
    between two court names in different okresy keep the first seen (rare; city/rural pairs).
    Pass ``report_collisions=True`` to print every silently-resolved name collision once
    (audit aid — a colliding court name can mis-assign records that carry only that name).
    """
    def okres_id(code: str) -> int:
        r, d = str(code).split("-")
        return int(r) * 1000 + int(d)

    lut: dict[str, tuple[int, str]] = {}
    collisions: list[tuple[str, str, int, str, int]] = []   # (name, kept lvl, kept oid, new lvl, new oid)

    def add(value, oid: int, level: str) -> None:
        k = _norm(value)
        if not k:
            return
        cur = lut.get(k)
        if cur is None or (level == "okres" and cur[1] == "court"):
            lut[k] = (oid, level)
        elif cur[0] != oid:                                  # same name, different okres — kept first
            collisions.append((k, cur[1], cur[0], level, oid))

    okres_rows = districts.drop_duplicates("okres_code")
    for _, r in okres_rows.iterrows():
        oid = okres_id(r["okres_code"])
        for col in ("okres_cs", "okres_cs_modern", "okres_de"):
            add(r.get(col), oid, "okres")
    for _, r in districts.iterrows():
        oid = okres_id(r["okres_code"])
        for col in ("gerichtsbezirk_cs", "gerichtsbezirk_cs_modern", "gerichtsbezirk_de"):
            add(r.get(col), oid, "court")
    if report_collisions and collisions:
        print(f"okres lookup: {len(collisions)} cross-okres name collisions (first seen wins):")
        for k, l0, o0, l1, o1 in sorted(set(collisions)):
            print(f"    {k!r}: kept {l0} → {o0}, ignored {l1} → {o1}")
    return lut


def _nospace_index(lut: dict[str, tuple[int, str]]) -> dict[str, tuple[int, str]]:
    """The okres lookup keyed with every space removed; keys that collide are dropped.

    The ČSÚ register's PDF text layer breaks words at random (``Prachat ice``, ``Budě jovice``,
    ``Ž ižkov``), so 81 settlements matched no okres and 169 more reached one only through the
    fuzzy tier. Removing the spaces restores the name exactly — on every one of those 169 the
    answer is the same as fuzzy's — and a key two okresy would share is refused rather than
    picked (audit 2026-09-22 §B24).
    """
    out: dict[str, tuple[int, str]] = {}
    clash: set[str] = set()
    for k, v in lut.items():
        ns = k.replace(" ", "")
        if ns in out and out[ns][0] != v[0]:
            clash.add(ns)
        out.setdefault(ns, v)
    for ns in clash:
        del out[ns]
    return out


# The 1910 Prague agglomeration. The capital's suburbs were political okresy **in their own
# right**, so a district string naming both Praha and one of them names the *suburb* — the more
# specific unit — and is not a choice between two places. Held by name and resolved against the
# backbone at call time, so a renamed row drops out loudly rather than silently.
_PRAGUE_RING_CS = ("Praha", "Karlín", "Královské Vinohrady", "Smíchov", "Žižkov")


def _prague_agglomeration(districts: pd.DataFrame) -> tuple[set[int], int | None]:
    """``({okres_id of every Prague-agglomeration okres}, okres_id of Praha)``."""
    okres = districts.drop_duplicates("okres_code")
    ids = {str(cs): int(c.split("-")[0]) * 1000 + int(c.split("-")[1])
           for cs, c in zip(okres["okres_cs"], okres["okres_code"])}
    return {ids[n] for n in _PRAGUE_RING_CS if n in ids}, ids.get("Praha")


# ── Attach ────────────────────────────────────────────────────────────────────
def add_birth_okres_id(
    df: pd.DataFrame,
    districts: pd.DataFrame,
    okres_col: str | None = None,
    fuzzy: bool = True,
    threshold: int = 90,
    aliases: dict[str, int | None] | None = None,
    prefix: str = "birth",
    settlements: pd.DataFrame | None = None,
    muni_col: str | None = None,
) -> pd.DataFrame:
    """Add ``{prefix}_okres_id`` (Int64) and ``{prefix}_okres_match`` (category) to *df*.

    Resolution order per distinct value: alias override → exact (okres, then court) →
    rural-suffix strip and retry → optional token-set fuzzy (≥ *threshold*). Unresolved values
    get ``<NA>`` / ``<NA>``. Matching is done on the ~few-thousand **distinct** district strings,
    then broadcast. *okres_col* defaults to ``{prefix}_okres``; pass it explicitly to read another
    column (e.g. the lexikon's ``okres_1910``).

    Fuzzy ties
    ----------
    A token-set ratio scores 100 against **every** district a cell names, so ``Tábor Praha``,
    ``Ostrava`` and ``Nové Město`` all tie at the top — and the winner was whichever key the
    lookup happened to hold first, which is dict insertion order wearing a match's clothes.
    Pass *settlements* (the ``settlements_1910`` crosswalk) and a tie is instead resolved
    per **record**, by evidence (:func:`_resolve_fuzzy_ties`, DECISIONS D-23):

    1. the record's own ``{muni_col}`` sits in exactly one of the tied okresy → that one;
    2. else, the tie is Praha plus exactly one Prague-suburb okres → the **suburb**;
    3. else refuse — ``<NA>``, not a coin flip.

    Without *settlements* there is nothing to corroborate with, and the behaviour is unchanged
    (first match wins). That is deliberate, and it is what the :mod:`utils.parsing.lexikon` call
    wants: the ČSÚ register writes the **1910 period name** for the Bohemian member of a
    Bohemia/Moravia twin — bare ``Krumlov`` and ``Budějovice``, whose own ``okres_all`` timelines
    read ``Krumlov|Český Krumlov`` — and always qualifies the Moravian one (``Moravský Krumlov``,
    ``Moravské Budějovice``). For those 481 settlement rows the first match is the *right* answer,
    and refusing them would cost the settlement layer its okresy.
    """
    if okres_col is None:
        okres_col = f"{prefix}_okres"
    if muni_col is None:
        muni_col = f"{prefix}_municipality"
    aliases = {**ALIAS_OVERRIDE, **(aliases or {})}
    lut = build_okres_lookup(districts)
    keys = list(lut.keys())
    lut_nospace = _nospace_index(lut)
    break_ties = settlements is not None and muni_col in df.columns

    distinct = pd.Index(df[okres_col].dropna().unique())
    id_map: dict[str, "int | None"] = {}
    tier_map: dict[str, "str | None"] = {}
    tied: dict[str, set[int]] = {}
    for raw in distinct:
        k = _norm(raw)
        if not k:
            id_map[raw], tier_map[raw] = None, None
            continue
        if k in aliases:                                   # curated override (may be None)
            oid = aliases[k]
            id_map[raw], tier_map[raw] = oid, ("alias" if oid is not None else None)
            continue
        hit = lut.get(k)
        if hit is not None:
            id_map[raw], tier_map[raw] = hit[0], hit[1]    # "okres" or "court"
            continue
        bare = _RURAL_SUFFIX.sub("", k).strip()            # "olomouc venkov" -> "olomouc"
        if bare and bare != k:
            hit = lut.get(bare)
            if hit is not None:
                id_map[raw], tier_map[raw] = hit[0], hit[1]
                continue
        hit = lut_nospace.get(k.replace(" ", ""))          # "prachat ice" -> "prachatice"
        if hit is not None:
            id_map[raw], tier_map[raw] = hit[0], hit[1]
            continue
        if fuzzy:
            m = process.extractOne(k, keys, scorer=fuzz.token_set_ratio)
            if m is not None and m[1] >= threshold:
                id_map[raw], tier_map[raw] = lut[m[0]][0], "fuzzy"
                if break_ties:
                    best = {lut[x][0] for x in keys
                            if fuzz.token_set_ratio(k, x) == m[1]}
                    if len(best) > 1:                      # decided per record, below
                        id_map[raw], tier_map[raw] = None, None
                        tied[raw] = best
                continue
        id_map[raw], tier_map[raw] = None, None

    out = df.copy()
    out[f"{prefix}_okres_id"] = out[okres_col].map(id_map).astype("Int64")
    out[f"{prefix}_okres_match"] = pd.Categorical(
        out[okres_col].map(tier_map),
        categories=["okres", "court", "fuzzy", "alias", "settlement", "muni"],
    )
    if tied:
        out = _resolve_fuzzy_ties(out, tied, districts, settlements,
                                  okres_col, muni_col, prefix)
    return out


def _resolve_fuzzy_ties(df: pd.DataFrame, tied: dict[str, set[int]],
                        districts: pd.DataFrame, settlements: pd.DataFrame,
                        okres_col: str, muni_col: str, prefix: str) -> pd.DataFrame:
    """Decide a tied fuzzy district match per record; leave ``<NA>`` where nothing decides it.

    The tie is a real ambiguity in the *district* field, and the record's own **municipality**
    is the evidence that settles it — the same move that picks the member of a city/rural twin
    (D-17), and the same standard the settlement pass already holds itself to. A municipality
    that sits in exactly one of the tied okresy names that okres; one that sits in several, or
    in none of them, decides nothing.

    This is not merely tidier than the arbitrary winner, it **disagrees** with it: of 224 birth
    records the municipality can decide, 59 land in a different okres. 22 births recorded as
    ``Ostrava`` are in okres *Frýdek* (the Silesian side), not Moravská Ostrava; 14 ``Nové Město``
    are *na Moravě*, not *nad Metují*. A base-rate rule would have got every one of those wrong.

    The Prague fallback catches what the municipality cannot (79 records with no usable
    municipality): the capital's suburbs were separate okresy in 1910, so ``Praha - Smíchov``
    names *Smíchov*. Note it never contradicts the municipality — on all 217 rows where both
    have a say they agree — so it is a fallback, not a competing rule.
    """
    ring, praha = _prague_agglomeration(districts)

    # municipality name (Czech / 1910 / German) -> every okres a settlement of that name sits in
    sett = settlements[settlements["okres_id"].notna()]
    muni_ids: dict[str, set[int]] = {}
    for r in sett.itertuples(index=False):
        rd = r._asdict()
        for nm in (rd.get("cs_name"), rd.get("name_1910"), rd.get("de_name")):
            k = _norm(nm)
            if k:
                muni_ids.setdefault(k, set()).add(int(rd["okres_id"]))

    out = df.copy()
    ids = out[f"{prefix}_okres_id"].to_numpy(dtype="object")
    tiers = out[f"{prefix}_okres_match"].astype("object").to_numpy()
    raws = out[okres_col].to_numpy()
    munis = out[muni_col].to_numpy() if muni_col in out.columns else [pd.NA] * len(out)

    for i, (raw, mu) in enumerate(zip(raws, munis)):
        cands = tied.get(raw) if isinstance(raw, str) else None
        if not cands:
            continue
        hit = muni_ids.get(_norm(mu)) if pd.notna(mu) else None
        inter = (cands & hit) if hit else set()
        if len(inter) == 1:                                  # the municipality decides
            ids[i], tiers[i] = next(iter(inter)), "fuzzy"
        elif praha in cands and len(cands) == 2 and cands <= ring:
            ids[i], tiers[i] = next(iter(cands - {praha})), "fuzzy"   # the suburb, not the city
        # else: nothing decides it -> stays <NA>, on purpose
    out[f"{prefix}_okres_id"] = pd.array(ids, dtype="Int64")
    out[f"{prefix}_okres_match"] = pd.Categorical(tiers, categories=_TIERS)
    return out


_TIERS = ["okres", "court", "fuzzy", "alias", "settlement", "muni"]

# Curated exceptions to the cross-frame homonym guard: a bare municipality (no okres text)
# whose name exists in BOTH countries' settlement frames is normally refused as unknowable.
# These are the names where the base rate is so lopsided, and measured, that refusing costs
# far more than assigning. Keyed norm(municipality) -> okres_id; assigned at the weakest
# ``muni`` tier, so a strict analysis can still drop them.
CROSS_FRAME_WHITELIST: dict[str, int] = {
    # "Praha" with no district: the capital (1910 pop. ~677,000) vs the ~300-soul hamlet in
    # okres Lučenec / járás Halič — prior odds ~1 : 2,250. Every genuinely hamlet-born record
    # in the data writes its okres (it must, to be understood at all): all 6 found carry okres
    # "Lučenec", and the whole VÚA scrape should contain only ~2 hamlet-born (0.65 % sampling
    # rate x 300 pop), so they are already accounted for. A char-n-gram name classifier
    # (AUC 0.955 capital-vs-Lučenec) cannot overturn the prior for ANY bare record (max
    # posterior 0.22) and would systematically expel the capital's Slovak/Magyar-named
    # migrants — 4.9 % of confirmed Prague-born score LR>10 — i.e. a bias correlated with
    # ethnicity rather than random noise. Expected cost of assigning: ~3 of ~1,780 (0.2 %).
    # Decision + evidence: AUDIT_2026-07-16.md §E.
    "praha": 301072,
}

# Register statuses that are NOT an independent municipality: an ``osada`` is a named part of
# another village, a ``cast`` a quarter of one. They are legitimate targets when the record's
# own okres corroborates them (the ``settlement`` tier), but they must not win the bare-name
# ``muni`` tier: a record that says only "born in X", matched to something that is not even a
# municipality, is the weakest inference the pipeline can draw — and it is where every instance
# of one bug family lived. `Brno` reached okres Jilemnice through an osada of Bratrouchov (456
# records), `Těšín` reached okres Jičín through an osada of Železnice, `Lvov` reached Falknov
# through an osada of Lomnice. Refusing them costs ~19 legion / ~160 VÚA genuine hamlet matches
# and removes the whole class. See DECISIONS D-16.
_NOT_A_PLACE = {"osada", "cast"}


def add_birth_settlement_okres(
    df: pd.DataFrame,
    settlements: pd.DataFrame,
    okres_col: str | None = None,
    muni_col: str | None = None,
    land_col: str | None = None,
    prefix: str = "birth",
    exclude_names: set[str] | None = None,
) -> pd.DataFrame:
    """Second pass: recover ``birth_okres_id`` for still-unmatched rows via the settlement.

    Uses the Historický-lexikon crosswalk (:mod:`utils.parsing.lexikon`), matching on
    ``birth_municipality``. Two cases, both requiring a settlement named like the municipality:

    * **okres present but unmatched** → recover only when the record's raw ``birth_okres`` lies
      **somewhere in the settlement's okres timeline** (``okres_all``). This temporal gate resolves
      post-1910 okres labels (``Praha-venkov``, ``Kralupy`` → the 1910 okres) while rejecting
      foreign homonyms (a Czech village *Vídeň* never sat in okres *Vídeň*). Tier ``settlement``.
    * **okres missing entirely** → assign when the municipality maps to a settlement with an
      **unambiguous** 1910 okres (a single okres_id across all like-named settlements). There is no
      okres to corroborate, so this is the weaker tier ``muni`` — kept distinct so it can be
      filtered out for strict analyses, and **vetoed** when (a) ``land_col`` marks the birth as
      positively non-Czech (anything but "Czech lands"/NA — otherwise Austrian births whose village
      name coincides with a unique Czech settlement get mis-assigned), or (b) the name appears in
      *exclude_names* — the **cross-frame homonym guard**: pass the Slovak obec name set
      (:func:`settlement_name_set` on ``settlements_hu_1910`` with ``cols=("obec_sk",)``) so a bare
      name that exists in both countries' frames is refused rather than guessed, or (c) the only
      candidate is not an independent municipality (:data:`_NOT_A_PLACE` — an *osada* or a
      *část* of another village), which is the shape every big-city miss took.

    Requires :func:`add_birth_okres_id` to have run first (fills only the remaining ``<NA>``).
    Note: the returned frame has a **reset RangeIndex** (positional buffers are used
    internally) — callers relying on a meaningful index must re-attach it.
    """
    if okres_col is None:
        okres_col = f"{prefix}_okres"
    if muni_col is None:
        muni_col = f"{prefix}_municipality"
    if land_col is None:
        land_col = f"{prefix}_land"
    id_col, match_col = f"{prefix}_okres_id", f"{prefix}_okres_match"
    if id_col not in df.columns:
        raise ValueError(f"run add_birth_okres_id(..., prefix='{prefix}') first")

    # settlement name (modern + 1910 + German) → list of (okres timeline set, okres_id, status)
    sett = settlements[settlements["okres_id"].notna()]
    name_index: dict[str, list[tuple[set[str], int, str]]] = {}
    for _, r in sett.iterrows():
        timeline = {_norm(o) for o in str(r.get("okres_all") or "").split("|") if o.strip()}
        timeline.add(_norm(r["okres_1910"]))
        entry = (timeline, int(r["okres_id"]), str(r.get("status_1910") or ""))
        for nm in (r["cs_name"], r.get("name_1910"), r.get("de_name")):
            k = _norm(nm)
            if k:
                name_index.setdefault(k, []).append(entry)

    out = df.copy().reset_index(drop=True)
    ids = out[id_col].to_numpy(dtype="object")
    tiers = out[match_col].astype("object").to_numpy()
    has_muni = out[muni_col].notna()
    unmatched = out[id_col].isna()
    okres_present = out[okres_col].notna()
    land = out[land_col] if land_col in out.columns else None

    for pos in out.index[unmatched & has_muni]:
        cands = name_index.get(_norm(out.at[pos, muni_col]))
        if not cands:
            continue
        if okres_present.iat[pos]:
            ok = _norm(out.at[pos, okres_col])
            hit_ids = {oid for tl, oid, _st in cands if ok in tl}    # timeline gate
            if len(hit_ids) == 1:
                ids[pos], tiers[pos] = next(iter(hit_ids)), "settlement"
        else:
            if land is not None and pd.notna(land.iat[pos]) and land.iat[pos] != "Czech lands":
                continue                                         # veto foreign births (no okres)
            k = _norm(out.at[pos, muni_col])
            if k in CROSS_FRAME_WHITELIST:        # curated base-rate exception (e.g. Praha)
                ids[pos], tiers[pos] = CROSS_FRAME_WHITELIST[k], "muni"
                continue
            if exclude_names and k in exclude_names:
                continue                          # name exists in the SK frame too → ambiguous
            all_ids = {oid for _, oid, st in cands if st not in _NOT_A_PLACE}
            if len(all_ids) == 1:                 # unambiguous *municipality* only
                ids[pos], tiers[pos] = next(iter(all_ids)), "muni"
    out[id_col] = pd.array(ids, dtype="Int64")
    out[match_col] = pd.Categorical(tiers, categories=_TIERS)
    return out


# ── City / rural twins ────────────────────────────────────────────────────────
_MESTO = re.compile(r"\s*\(město\)\s*$")


def build_twin_pairs(districts: pd.DataFrame,
                     settlements: pd.DataFrame | None = None,
                     ) -> dict[int, tuple[int, int, frozenset[str]]]:
    """``{okres_id → (rural_id, city_id, city name keys)}`` for both members of every twin pair.

    A 1910 *Statutarstadt* was its own political district, separate from the rural district
    around it, so ten seats name two units. The backbone spells them ``X (město)`` (city) and
    bare ``X`` (rural) — the pairs are **derived** from that convention rather than listed here,
    and the caller is expected to assert the count.

    The *city name keys* are what a record's municipality is tested against. They come from the
    pair's own names: the bare Czech seat name, the German okres name (and its de-umlauted form,
    since the backbone writes ``Olmuetz`` where a record writes ``Olmütz``), and — when
    *settlements* is passed — every name of the settlements the crosswalk places **inside** the
    city unit. That last source is exact rather than clever: a statutory city was a *single*
    municipality, so the crosswalk holds exactly one settlement per city unit, and it is the city.
    """
    okres = districts.drop_duplicates("okres_code").copy()
    okres["oid"] = [int(c.split("-")[0]) * 1000 + int(c.split("-")[1])
                    for c in okres["okres_code"]]
    by_name = {str(cs): (int(oid), de) for cs, oid, de
               in zip(okres["okres_cs"], okres["oid"], okres["okres_de"])}

    pairs: dict[int, tuple[int, int, frozenset[str]]] = {}
    for cs, (city_id, city_de) in by_name.items():
        if not _MESTO.search(cs):
            continue
        base = _MESTO.sub("", cs)
        if base not in by_name:                       # a (město) unit with no bare twin
            continue
        rural_id = by_name[base][0]
        keys = {_norm(base)}
        if isinstance(city_de, str) and city_de.strip():
            keys.add(_norm(city_de))
            keys.add(_norm(city_de).replace("ue", "u"))   # Olmuetz -> olmutz, Bruenn -> brunn
        if settlements is not None and "okres_id" in settlements.columns:
            inside = settlements[settlements["okres_id"] == city_id]
            for col in ("cs_name", "name_1910", "de_name"):
                if col in inside.columns:
                    keys |= {_norm(v) for v in inside[col].dropna()}
        keys.discard("")
        entry = (rural_id, city_id, frozenset(keys))
        pairs[rural_id] = entry
        pairs[city_id] = entry
    return pairs


def resolve_twin_pairs(df: pd.DataFrame, districts: pd.DataFrame,
                       settlements: pd.DataFrame | None = None,
                       prefix: str = "birth") -> pd.DataFrame:
    """Split a twin pair's records between the city and the rural unit by their municipality.

    A district string alone cannot decide a twin: the name belongs to both units. The
    municipality can, and it decides *by definition* rather than by inference — the statutory
    city was one municipality, so a record naming the city belongs to the city unit and a record
    naming anything else belongs to the ring. Adds ``{prefix}_okres_twin``:

    ``city``       the municipality is the city itself
    ``ring``       the municipality is some other place → the rural unit
    ``undecided``  no municipality at all; assigned to the rural unit, flagged so it can be
                   dropped (66 records across both datasets, 0.36 % of the twin population)
    ``<NA>``       the record is not in a twin pair

    Run **after** both okres passes: it only re-reads records already placed in one of the twenty
    twin units. Note this does not touch ``{prefix}_okres_match`` — the tier records how the
    *district* was found, which is unchanged; the twin column records how the *member* was chosen.
    """
    id_col, muni_col = f"{prefix}_okres_id", f"{prefix}_municipality"
    if id_col not in df.columns:
        raise ValueError(f"run add_birth_okres_id(..., prefix='{prefix}') first")
    pairs = build_twin_pairs(districts, settlements)

    out = df.copy()
    ids = out[id_col].to_numpy(dtype="object")
    munis = out[muni_col].to_numpy() if muni_col in out.columns else [pd.NA] * len(out)
    twin: list[object] = [pd.NA] * len(out)
    for i, (oid, mu) in enumerate(zip(ids, munis)):
        if pd.isna(oid):
            continue
        entry = pairs.get(int(oid))
        if entry is None:
            continue
        rural_id, city_id, city_keys = entry
        k = _norm(mu)
        if not k:
            ids[i], twin[i] = rural_id, "undecided"
        elif k in city_keys:
            ids[i], twin[i] = city_id, "city"
        else:
            ids[i], twin[i] = rural_id, "ring"
    out[id_col] = pd.array(ids, dtype="Int64")
    out[f"{prefix}_okres_twin"] = pd.Categorical(twin, categories=["city", "ring", "undecided"])
    return out


# ── Greater Prague: a 1922 boundary written onto 1910 records ─────────────────
#
# Prague absorbed 37 surrounding municipalities on 1 January 1922. csol.cz and the VÚA
# database were both compiled *after* that, so a clerk copying a card for a man born in
# Žižkov in 1890 wrote the okres he knew — Praha — for a town that in 1910 was the seat of
# its own political okres. The okres tier matches "Praha" outright and never consults the
# municipality, so 1,658 records carry inner-Prague census covariates for men born in
# working-class suburbs whose 1910 districts look nothing like it.
#
# This is the twin rule's shape — the municipality decides the member — but it is *not* the
# twin rule: a twin pair is two units that coexisted in 1910, whereas here one unit swallowed
# the others twelve years later. So it gets its own resolver and its own column.
PRAHA_OKRES_ID = 301072
PRAGUE_SUBURB_CSV = Path(__file__).resolve().parents[2] / "reference" / "places" / \
    "prague_suburb_curation.csv"

_PRAHA_PREFIX = re.compile(r"^\s*prah[ay]\s*[-–—,/]?\s*", re.I)
_PRAHA_SUFFIX = re.compile(r"\s*[-–—,/]?\s*prah[ay]\s*$", re.I)


def strip_praha(value) -> str:
    """``"Praha-Žižkov"`` / ``"Žižkov, Praha"`` → ``"žižkov"``; normalised for lookup.

    A cadastral number keeps its digits (``"Praha 2"`` → ``"2"``) and so matches nothing,
    which is correct: *Praha II* was Nové Město, inside the 1910 city, and must not move.
    """
    if value is None or (isinstance(value, float) and pd.isna(value)):
        return ""
    return _norm(_PRAHA_SUFFIX.sub("", _PRAHA_PREFIX.sub("", str(value))))


def load_prague_suburbs(path=None) -> dict[str, int]:
    """``{normalised suburb name → its 1910 okres_id}`` from the curation — settled rows only.

    A row without an ``okres_id_1910`` is a *candidate*: a municipality observed under okres
    Praha whose 1910 district has not been established from the Spezialortsrepertorium yet.
    Candidates are deliberately inert — an unverified reassignment would be worse than the
    anachronism it replaces, because it would look settled.
    """
    p = Path(path) if path else PRAGUE_SUBURB_CSV
    if not p.exists():
        return {}
    cur = pd.read_csv(p, dtype=str).fillna("")
    out: dict[str, int] = {}
    for _, r in cur.iterrows():
        oid = r["okres_id_1910"].strip()
        if oid:
            out[_norm(r["municipality"])] = int(oid)
    return out


def resolve_prague_suburbs(df: pd.DataFrame, prefix: str = "birth",
                           curation=None, districts: pd.DataFrame | None = None,
                           settlements: pd.DataFrame | None = None) -> pd.DataFrame:
    """Send a record filed under okres Praha to the 1910 okres its municipality really had.

    Fires only where the resolved okres is Praha itself *and* the municipality is a curated
    suburb with an established 1910 district. Adds ``{prefix}_okres_prague``:

    ``city``     the municipality was inside the 1910 city (or is unrecognised) — unchanged
    ``suburb``   moved to its own 1910 okres
    ``<NA>``     the record is not in okres Praha at all

    **Run this before anything that derives from the okres id** — the census merge key, the
    twin resolution, the court cross-check — or those will carry the pre-move district.

    Pass *districts* to re-derive ``{prefix}_okres_cs`` / ``_okres_de`` in the same call, and
    *settlements* to re-key the settlement attributes (standardised municipality names, court,
    coordinates) of the moved rows: they were looked up under ``(municipality, Praha)``, which
    the suburb's own settlement row never matches, so all 1,537 moved records came out without
    them (audit 2026-09-22 §B7).
    Changing an id silently invalidates every label already read off it, and the first run of
    this rule did exactly that: 1,468 records carried okres id *Žižkov* under the name
    *Praha*. The repair belongs here rather than in the caller, because a fix that depends on
    remembering to call something afterwards is the bug waiting to happen again.
    """
    out = df.copy()
    id_col, muni_col = f"{prefix}_okres_id", f"{prefix}_municipality"
    col = f"{prefix}_okres_prague"
    if id_col not in out.columns or muni_col not in out.columns:
        out[col] = pd.Categorical([pd.NA] * len(out), categories=["city", "suburb"])
        return out

    table = load_prague_suburbs() if curation is None else curation
    in_praha = out[id_col].eq(PRAHA_OKRES_ID).fillna(False).to_numpy()
    ids = out[id_col].to_numpy(copy=True)
    tag: list[object] = [pd.NA] * len(out)
    munis = out[muni_col].to_numpy()
    for i in np.flatnonzero(in_praha):
        hit = table.get(strip_praha(munis[i]))
        if hit is None:
            tag[i] = "city"
            continue
        ids[i], tag[i] = hit, "suburb"
    out[id_col] = pd.array(ids, dtype="Int64")
    out[col] = pd.Categorical(tag, categories=["city", "suburb"])
    moved = (out[col] == "suburb").fillna(False).to_numpy()
    if settlements is not None and moved.any():
        sub = add_settlement_attrs(out.loc[moved].copy(), settlements, prefix=prefix)
        for c in (f"{prefix}_municipality_cs", f"{prefix}_municipality_de", f"{prefix}_court_id",
                  f"{prefix}_court_cs", f"{prefix}_court_de", f"{prefix}_court_snapped",
                  f"{prefix}_lat", f"{prefix}_lon", f"{prefix}_qid"):
            if c in sub.columns and c in out.columns:
                out.loc[moved, c] = sub[c].to_numpy()
    if districts is not None and f"{prefix}_okres_cs" in out.columns:
        out = add_okres_names(out, districts, prefix=prefix)
    return out

def sync_cisleithanian(df: pd.DataFrame, prefix: str = "birth") -> pd.DataFrame:
    """Recompute ``{prefix}_cisleithanian`` from the corrected ``{prefix}_land`` (if both exist).

    The flag came from :mod:`locations`' text-only land, and kept that answer after the land
    itself was corrected — 2,270 Czech-lands VÚA births said *not* Cisleithanian (1,747 of them
    Uherské Hradiště and Uherský Brod, read as Hungary) and 8,997 Slovak births said they were.
    A derived flag must be derived from the value it describes (audit 2026-09-22 §A7).
    """
    flag, land = f"{prefix}_cisleithanian", f"{prefix}_land"
    if flag not in df.columns or land not in df.columns:
        return df
    out = df.copy()
    out[flag] = pd.array([_CISLEITHANIAN.get(v, pd.NA) if pd.notna(v) else pd.NA
                          for v in out[land]], dtype="boolean")
    return out


def _classify_land_positive(okres_raw, muni_raw, okres_id_resolved: bool) -> object:
    """Positive land classification for one record.

    Czech-lands is asserted by a **resolved** ``okres_id`` (the record's district sits in the
    MPIDR Czech-lands backbone) — robust even for bare district names. Otherwise Slovak is caught
    by the curated district list, and the remaining foreign lands by text markers on the raw
    okres/municipality. Unresolvable → ``<NA>``.
    """
    if okres_id_resolved:
        return "Czech lands"
    ok = _norm(okres_raw)
    if ok in _SLOVAK_DISTRICTS or _norm(muni_raw) in _SLOVAK_DISTRICTS:
        return "Slovakia"
    blob = f"{ok} {_norm(muni_raw)}"
    for rx, land in _LAND_MARKER_RES:
        if rx.search(blob):
            return land
    return pd.NA


# Czech place-name connectives kept lowercase when title-casing an ALL-CAPS lexikon headword.
_CS_LOWER = {"nad", "pod", "u", "na", "v", "ve", "se", "a", "při", "za", "nad."}


def _titlecase_cs(name) -> object:
    """Title-case an ALL-CAPS lexikon headword (``KOSTELEC NAD ČERNÝMI LESY`` → proper case).

    Diacritics are handled by ``str`` casing; Czech connectives (``nad``/``pod``/``u``/…) are
    lowered. Left unchanged if the name already has lower-case letters (not an all-caps headword).
    """
    if not isinstance(name, str) or not name.strip():
        return pd.NA
    if name != name.upper():                      # already mixed-case → leave as-is
        return name
    parts = name.split()
    out = [w.capitalize() if i == 0 or w.lower() not in _CS_LOWER else w.lower()
           for i, w in enumerate(parts)]
    return " ".join(out)


def add_settlement_attrs(df: pd.DataFrame, settlements: pd.DataFrame,
                         prefix: str = "birth",
                         exclude_names: set[str] | None = None) -> pd.DataFrame:
    """Attach the resolved-settlement attributes for *prefix* from the enriched master.

    Keys a record's ``{prefix}_municipality`` to a settlement by ``({muni}, {prefix}_okres_id)``
    (the resolved okres_id disambiguates homonyms exactly), with a unique-name fallback where the
    settlement name is unambiguous. The municipality is matched against the settlement's Czech,
    1910-era, and German names — so a German-named record (``Wiesenberg``) resolves to its Czech
    settlement where the master carries that exonym. Adds, from the matched settlement:
    ``{prefix}_municipality_cs`` (cs_name), ``{prefix}_municipality_de`` (de_name),
    ``{prefix}_court_id`` / ``{prefix}_court_cs`` / ``{prefix}_court_de``,
    ``{prefix}_lat`` / ``{prefix}_lon`` / ``{prefix}_qid``.

    The unique-name fallback carries the same two guards as the ``muni`` okres tier: a
    positively-foreign ``{prefix}_land`` vetoes it, and *exclude_names* (the Slovak obec
    name set) refuses **cross-frame homonyms** — otherwise a Slovak-born record whose land
    has not yet resolved, and whose village name happens to be unique in the Czech lexikon,
    silently acquires Czech coordinates/court/names and then gets a Slovak járás from the
    later Transleithanian pass (124 such records before this guard; audit 2026-07-16). Records
    already corroborated by ``(municipality, okres_id)`` are unaffected — including the
    curated :data:`CROSS_FRAME_WHITELIST` ones, which by then carry a real okres_id.
    """
    muni_col, id_col = f"{prefix}_municipality", f"{prefix}_okres_id"
    # `court_snapped` travels with the court: the flag exists so a near-miss repair (D-35) can
    # be excluded, and a flag that stops at the settlement frame cannot be excluded per record.
    fields = ("cs_name", "de_name", "court_id", "court_cs", "court_de", "court_snapped",
              "lat", "lon", "wd_qid")
    have = [c for c in fields if c in settlements.columns]

    keyed: dict[tuple[str, int], dict] = {}
    name_ids: dict[str, set] = {}
    row_by_qid: dict = {}
    for rowno, r in enumerate(settlements.itertuples(index=False)):
        rd = r._asdict()
        rec = {c: rd.get(c) for c in have}
        qid = rd.get("wd_qid")
        # settlements without a QID get an explicit per-row sentinel: they still count
        # toward name ambiguity, but can never be resolved via the unique-name path
        key = qid if qid is not None and pd.notna(qid) else f"_row{rowno}"
        for nm in (rd.get("cs_name"), rd.get("name_1910"), rd.get("de_name")):
            k = _norm(nm)
            if not k:
                continue
            name_ids.setdefault(k, set()).add(key)
            if pd.notna(rd.get("okres_id")):
                keyed[(k, int(rd["okres_id"]))] = rec
        if qid is not None and pd.notna(qid):
            row_by_qid[qid] = rec
    uniq_name: dict[str, dict] = {}
    for k, s in name_ids.items():
        if len(s) == 1:
            v = next(iter(s))
            if v in row_by_qid:
                uniq_name[k] = row_by_qid[v]

    munis = df[muni_col].to_numpy()
    oids = df[id_col].to_numpy() if id_col in df.columns else [pd.NA] * len(df)
    # a raw okres string that did NOT resolve to a Czech okres_id is positive evidence the
    # place is not Czech — such a record must not pick up attrs by bare-name uniqueness
    okres_col = f"{prefix}_okres"
    okres_raw = (df[okres_col].notna().to_numpy() if okres_col in df.columns
                 else [False] * len(df))
    # a positively-foreign land vetoes the bare-name fallback (a Czech village *Vídeň* must not
    # capture a Vienna-born record); an unresolved (<NA>) land is treated as possibly-Czech.
    land_col = f"{prefix}_land"
    lands = df[land_col].to_numpy() if land_col in df.columns else [pd.NA] * len(df)
    cols: dict[str, list] = {c: [pd.NA] * len(df) for c in have}
    for i, (mu, oid, land, has_okres) in enumerate(zip(munis, oids, lands, okres_raw)):
        if pd.isna(mu):
            continue
        k = _norm(mu)
        rec = None
        if pd.notna(oid) and (k, int(oid)) in keyed:
            rec = keyed[(k, int(oid))]                       # okres-corroborated: always safe
        elif (k in uniq_name
              and not has_okres                              # an unresolved okres => not Czech
              and (pd.isna(land) or land == "Czech lands")   # bare-name: skip if foreign
              and not (exclude_names and k in exclude_names)):  # ... or a cross-frame homonym
            rec = uniq_name[k]
        if rec is not None:
            for c in have:
                cols[c][i] = rec[c]

    out = df.copy()
    rename = {"cs_name": f"{prefix}_municipality_cs", "de_name": f"{prefix}_municipality_de",
              "court_id": f"{prefix}_court_id", "court_cs": f"{prefix}_court_cs",
              "court_de": f"{prefix}_court_de", "court_snapped": f"{prefix}_court_snapped",
              "lat": f"{prefix}_lat", "lon": f"{prefix}_lon", "wd_qid": f"{prefix}_qid"}
    for c in have:
        s = pd.Series(cols[c], index=out.index)
        if c == "court_id":
            s = s.astype("Int64")
        elif c == "court_snapped":
            # boolean where a settlement matched, <NA> where none did — a record with no
            # court was not "not snapped", it has no court at all
            s = s.astype("boolean")
        elif c == "cs_name":
            s = s.map(_titlecase_cs)              # lexikon headwords are ALL-CAPS
        out[rename[c]] = s
    return out


def add_okres_names(df: pd.DataFrame, districts: pd.DataFrame,
                    prefix: str = "birth") -> pd.DataFrame:
    """Add ``{prefix}_okres_cs`` / ``{prefix}_okres_de`` from ``{prefix}_okres_id`` via backbone."""
    id_col = f"{prefix}_okres_id"
    okres = districts.drop_duplicates("okres_code").copy()
    okres["oid"] = okres["okres_code"].map(
        lambda c: int(c.split("-")[0]) * 1000 + int(c.split("-")[1]))
    cs = dict(zip(okres["oid"], okres["okres_cs"]))
    de = dict(zip(okres["oid"], okres["okres_de"]))
    out = df.copy()
    key = out[id_col]
    out[f"{prefix}_okres_cs"] = key.map(cs)
    out[f"{prefix}_okres_de"] = key.map(de)
    return out


def add_land(df: pd.DataFrame, prefix: str = "birth") -> pd.DataFrame:
    """Add a corrected ``{prefix}_land`` via positive district identification.

    Supersedes the text-marker-only ``locations.py`` land (which mislabels bare Slovak district
    names as "Czech lands"). Czech lands = a resolved ``{prefix}_okres_id``; Slovakia = the curated
    Upper-Hungary district list; remaining foreign lands via markers on the raw okres/municipality.
    """
    id_col = f"{prefix}_okres_id"
    okres_raw, muni_raw = f"{prefix}_okres", f"{prefix}_municipality"
    resolved = df[id_col].notna() if id_col in df.columns else pd.Series(False, index=df.index)
    okr = df[okres_raw] if okres_raw in df.columns else pd.Series(pd.NA, index=df.index)
    mun = df[muni_raw] if muni_raw in df.columns else pd.Series(pd.NA, index=df.index)
    out = df.copy()
    out[f"{prefix}_land"] = [
        _classify_land_positive(o, m, bool(r))
        for o, m, r in zip(okr, mun, resolved)
    ]
    return sync_cisleithanian(out, prefix)


def add_place_standardization(df: pd.DataFrame, districts: pd.DataFrame,
                              settlements: pd.DataFrame, prefix: str = "birth",
                              aliases: dict[str, int | None] | None = None,
                              exclude_names: set[str] | None = None) -> pd.DataFrame:
    """One-call place standardisation for *prefix* (``birth`` / ``home``).

    From the raw ``{prefix}_municipality`` + ``{prefix}_okres`` it produces the full set:
    okres id/match (name→okres, two passes), Czech + German municipality names, okres Czech +
    German names, court district (id + Czech + German, from the resolved settlement's spatial
    ``court_id``), birth/home coordinates, and a corrected ``{prefix}_land``. The raw columns are
    kept unchanged as the authoritative source text. *settlements* is handed to pass 1 as well as
    pass 2, so an ambiguous district string is settled by the record's own municipality rather
    than by lookup order (:func:`_resolve_fuzzy_ties`, D-23). Pass *exclude_names* = the **Slovak** obec
    name set (:func:`settlement_name_set` on ``settlements_hu_1910``, ``cols=("obec_sk",)``) so
    the bare-name ``muni`` tier refuses cross-frame homonyms (names present in both countries).
    """
    df = add_birth_okres_id(df, districts, prefix=prefix, aliases=aliases,
                            settlements=settlements)
    df = add_land(df, prefix=prefix)                  # preliminary land → pass-2 muni-tier veto
    df = add_birth_settlement_okres(df, settlements, prefix=prefix, exclude_names=exclude_names)
    df = add_land(df, prefix=prefix)                  # refine land now pass-2 resolved more okresy
    # split the city/rural twins BEFORE attributes: the settlement crosswalk keys on
    # (municipality, okres_id), so a record still sitting on the wrong member of a pair
    # cannot pick up its coordinates, court or standardised names
    df = resolve_twin_pairs(df, districts, settlements, prefix=prefix)
    df = add_settlement_attrs(df, settlements, prefix=prefix, exclude_names=exclude_names)
    df = add_okres_names(df, districts, prefix=prefix)
    return df
