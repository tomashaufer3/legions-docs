How it works

This module tabulates that from data/final only, and writes the evidence block of the design note between its markers, so the numbers there are rebuilt by code, not typed:

python -m utils.panels.vua_overlap            # from the repo root: rewrites the block

Categories, first that applies (CATEGORIES):

vua_dead_before_entry VÚA's death date (its last possible day for a year-only date) is before the Legion entry date: the man joined the Legion after the Habsburg army recorded him dead or missing; legion_survived the Legion record ends in demobilisation, return home or transfer to the Czechoslovak army (a death beside DM/V counts as demobilised, the D-260 rule), yet VÚA lists him among the fallen; consistent_death the Legion records a death too; legion_missing the Legion records him missing (N); legion_no_exit the Legion record has no exit code; other desertion, see note, discharge unfit, or an exit date with no code.

The gap is in days: Legion entry − VÚA death (vua_dead_before_entry), Legion exit − VÚA death (every other category; positive = the Legion has him alive after VÚA's date).

A confirmed link can still be two men. The overlap is confirmed on name + full date of birth (high) or on VÚA's own Legion note + birth okres + birth year (medium); a name + DOB coincidence on a common name lands exactly in the "inconsistent" categories. So each category also carries the link's own evidence from overlap_matches.csv: the birth okres agrees (okres_match), VÚA's note names the Legion (note_legion), the pair is note-confirmed (confidence == "medium"), whether both sides name the same Habsburg regiment (regiment_agrees: the branch and number of csol.cz habsburg_unit_capture against VÚA's ah_unit_primary, csol_branch / vua_branch; IR 28 is not Landwehr 28, and a VÚA unit that names the Legion carries no Habsburg regiment), and, for a man VÚA wrote off before his Legion entry, whether VÚA's date lies within CAPTURE_WINDOW_DAYS of the Legion's capture date. The pairs whose okres agrees or whose VÚA note names the Legion (corroborated) are the corroborated subset, not a bound: an okres agreement alone still admits two men of one name and birth date from one district, which a regiment conflict then shows. Examples are chosen only among pairs whose regiment agrees, or that are corroborated with no regiment conflict (example_eligible); a legion_survived example must also have VÚA name the Legion (vua_names_legion) and no VÚA place in a theatre the csol.cz record rules out (theatre_ruled_out).

Only the vua_dead_before_entry row can show a Habsburg write-off of a man who then served. Where VÚA dates the death inside the Legion service (most of legion_survived) its unit can be a Legion one (pluk 1, rota 7), so a regiment disagreement there is no evidence against the link, and the row is a csol.cz-vs-VÚA conflict over a Legion-period death, or two men.

Switches (1.3.0, module constants, each also a keyword of the function it governs): with all four off the categorised frame, the table and the examples are those of 1.2.0.

def load(final: Path) -> pd.DataFrame:
    """Overlap crosswalk + both person files (m:1 merges, row counts asserted)."""
    ov = pd.read_csv(final / "persons" / "overlap_matches.csv", usecols=OVERLAP_COLS)
    for flag in ("okres_match", "note_legion"):
        ov[flag] = ov[flag].astype("boolean")
    L = pd.read_parquet(final / "persons" / "legionnaires_clean.parquet", columns=LEGION_COLS)
    V = pd.read_parquet(final / "persons" / "habsburg_clean.parquet", columns=VUA_COLS)
    L, V = L.rename(columns={"theater": "legion_theater"}), V.rename(columns={"theater": "vua_theater"})
    n = len(ov)
    df = ov.merge(L, on="legion_id", how="left", validate="1:1", indicator="_l")
    df = df.merge(V, on="vua_id", how="left", validate="1:1", indicator="_v")
    assert len(df) == n, "an overlap merge changed the row count"
    missing = int((df["_l"] != "both").sum() + (df["_v"] != "both").sum())
    assert missing == 0, f"{missing} overlap id(s) not in the person files"
    return df.drop(columns=["_l", "_v"])

def regiment_agrees(df: pd.DataFrame, by_branch: bool | None = None,
                    legion_not_comparable: bool | None = None) -> pd.Series:
    """True where the csol.cz capture unit (``habsburg_unit_capture``) and VÚA's unit
    (``ah_unit_primary``) name the same regiment, False where both name one and they differ, <NA>
    where either names none (or either unit is written with a ``?``).

    ``by_branch`` (default :data:`REGIMENT_BY_BRANCH`): the regiment is branch + number
    (:func:`csol_branch`, :func:`vua_branch`; the first number of each side's first unit). A
    different number is a conflict; the same number in another branch (IR 28 against Landwehr 28)
    is a near match, neither agreement nor conflict (<NA>, counted by
    :func:`regiment_branch_differs`), since the two sources use the branch words loosely (csol.cz
    *dom.* against VÚA *zeměbranecký* on one number, VÚA *pěší pluk* for a Landwehr one); a unit
    with no branch is not comparable. Off: the first number of the csol.cz string against VÚA's
    ``ah_regiment_no`` (1.2.0).
    ``legion_not_comparable`` (default :data:`LEGION_UNIT_NOT_COMPARABLE`): a VÚA unit that names
    the Legion (:data:`LEGION_UNIT_RE`) carries no Habsburg regiment."""
    by_branch = REGIMENT_BY_BRANCH if by_branch is None else by_branch
    legion_na = LEGION_UNIT_NOT_COMPARABLE if legion_not_comparable is None else legion_not_comparable
    leg, vua, same_branch = _regiment_sides(df, by_branch, legion_na)
    both = leg.notna() & vua.notna()
    same = leg == vua
    out = same.astype("boolean").where(both)
    if same_branch is not None:
        out = out.mask(both & same.fillna(False).astype(bool) & ~same_branch)
    return out

def categorise(df: pd.DataFrame) -> pd.DataFrame:
    """Adds ``vua_death_lo``, ``legion_outcome``, ``category``, ``gap_days``,
    ``vua_near_capture`` (<NA> without both dates), ``vua_in_service`` (VÚA's first possible day
    between Legion entry and exit; <NA> without the three dates), ``corroborated``,
    ``regiment_agrees``, ``regiment_branch_differs``, ``vua_names_legion`` and
    ``vua_theatre_ruled_out``."""
    out = df.copy()
    lo, hi = _vua_death_bounds(out)
    out["vua_death_lo"] = lo
    codes = out["exit_codes"].astype("string")
    rec = codes.map(lambda c: sp.resolve_outcome(c)).astype("string")
    rec[rec.eq("death").fillna(False) & sp.death_demob_pair(codes)] = "demob_return"   # D-260
    out["legion_outcome"] = rec
    entry = pd.to_datetime(out["enroll_date"])
    cat = pd.Series("other", index=out.index, dtype="string")
    cat[rec.isna()] = "legion_no_exit"
    cat[rec.eq("missing").fillna(False)] = "legion_missing"
    cat[rec.eq("death").fillna(False)] = "consistent_death"
    cat[rec.isin(["demob_return", "transfer_csa"]).fillna(False)] = "legion_survived"
    cat[(hi < entry).fillna(False)] = "vua_dead_before_entry"
    out["category"] = cat
    exit_ = pd.to_datetime(out["exit_date"])
    out["gap_days"] = ((entry - lo).dt.days.where(cat.eq("vua_dead_before_entry"),
                                                   (exit_ - lo).dt.days)).astype("Int64")
    near = (lo - pd.to_datetime(out["capture_date"])).abs().dt.days
    out["vua_near_capture"] = (near <= CAPTURE_WINDOW_DAYS).astype("boolean").where(near.notna())
    known = lo.notna() & entry.notna() & exit_.notna()
    out["vua_in_service"] = ((lo >= entry) & (lo <= exit_)).astype("boolean").where(known)
    out["corroborated"] = corroborated(out)
    out["regiment_agrees"] = regiment_agrees(out)
    out["regiment_branch_differs"] = regiment_branch_differs(out)
    out["vua_names_legion"] = vua_names_legion(out)
    out["vua_theatre_ruled_out"] = theatre_ruled_out(out)
    return out

#: both sides (a man reported missing when he was taken prisoner): two months of 30 days.
CAPTURE_WINDOW_DAYS = 2 * 30

#: The four switches of 1.3.0 (all on). Off, each restores the 1.2.0 behaviour of its rule.
#: Compare the Habsburg regiment's branch and number, not the first number alone.
REGIMENT_BY_BRANCH = True
#: A VÚA unit that names the Legion (:data:`LEGION_UNIT_RE`) is not comparable (<NA>).
LEGION_UNIT_NOT_COMPARABLE = True
#: A ``legion_survived`` example needs VÚA to name the Legion (:func:`vua_names_legion`).
SURVIVED_EXAMPLES_NEED_LEGION = True
#: A ``legion_survived`` example may not have its VÚA place in a theatre csol.cz rules out.
SURVIVED_EXAMPLES_THEATRE = True

#: Legion vocabulary in a VÚA unit: *čs.*, *čsl*, *česk-*/*čes.* (*česká družina*, *čes. legií*),
#: *legie / legií / legionář / legion*, the *leg.* abbreviation, rota *Nazdar*, *družina*, the French
#: *cizinecká* legion, a *dobrovolník* (the Serbian and French volunteer corps), *italská* (the
#: Italian Legion and its *domobrana*). A Habsburg unit name carries none of these.
LEGION_UNIT_RE = re.compile(r"čs\.|čsl|čes\.|česk|legi|legion|\bleg\.|nazdar|družin|cizineck|"
                            r"dobrovol|italsk", re.IGNORECASE)
#: The Legion's own way of writing a unit in VÚA: *pluk N, rota M* with no arm or organisation
#: word. VÚA-wide (2026-11-18) the 105 such records all die 1917–1920, 69 in Russia, and 38 % are
#: in the overlap (0.7 % of VÚA overall); a Habsburg record names its arm (*pěší pluk N, rota M*
#: runs from 1914).
LEGION_FORM_RE = re.compile(r"(?:\d+\s*\.\s*)?pluk(?:\s*\d+)?\s*,?\s*(?:\d+\s*\.\s*)?rota(?:\s*\d+)?",
                            re.IGNORECASE)
#: Legion vocabulary in a VÚA death place (*ruské legie Vladivostok*); stricter than the unit's,
#: since a place name can begin *Česk-* (České Budějovice).
LEGION_PLACE_RE = re.compile(r"legi|legion|\bleg\.|nazdar|družin", re.IGNORECASE)

#: csol.cz capture unit → Habsburg branch, read on the first unit (before ``,`` ``;`` ``/``) with
#: digits, spaces and dots removed, matched whole. IR k.u.k. infantry; LIR k.k. Landwehr infantry
#: (*zem.*, and *stř.*, the Schützen the Landwehr regiments became in 1917); LstIR / LstBn Landsturm
#: regiment / battalion; HIR Honvéd; BHIR Bosnian-Herzegovinian; FJB field Jäger battalion; TKJ
#: Tyrolean Kaiserjäger; DR / UR / HR / LUR / HHR cavalry; FAR / FsAR / HAR field / fortress /
#: heavy artillery. A generic *děl.pl.*, a battalion of an arm numbered by regiment, a sapper, a
#: train unit: no branch (<NA>), so not comparable.
CSOL_BRANCH = (
    ("IR", r"ppl?"),
    ("LIR", r"(?:zeměbr|zembr|zemb|zbr|zem|z)(?:ppl|pl|pp|p)|stř(?:p)?pl"),
    ("LstIR", r"(?:domobr|dom)(?:ppl|pl|pp|p)"),
    ("LstBn", r"dom(?:p)?pr"),
    ("HIR", r"honv(?:ppl|pl|pp|p)"),
    ("BHIR", r"(?:bosherceg|bosherc|bosen|bos|bh)(?:ppl|pl|pp|p)"),
    ("FJB", r"(?:pr)?polmysl?(?:pr)?|myslpr|myspr"),
    ("TKJ", r"(?:tyrol)?císmyspl|plcísmys|myslpl"),
    ("HHR", r"honvhuspl"),
    ("LUR", r"zemhulpl"),
    ("DR", r"drag(?:pl|p)?"),
    ("UR", r"hul(?:pl)?"),
    ("HR", r"huspl"),
    ("FAR", r"(?:pl)?polděl(?:pl)?"),
    ("FsAR", r"(?:pl)?pevděl(?:pl)?"),
    ("HAR", r"těžděl(?:pl)?"),
)
#: VÚA unit → the same branches, searched in order on the first unit (before ``,`` ``;`` ``/``
#: `` (``), the specific organisation before the generic *pěší pluk*. A bare *pluk N* names no
#: branch (<NA>); *střelecký pluk* is the k.k. Schützen (VÚA-wide 3,967 records, 0.2 % with a Legion
#: note); a generic *dělostřelecký pluk* or a *houfnicový* one has no branch.
VUA_BRANCH = (
    ("TKJ", r"tyrolsk\w*\s+myslivec\w*\s+pluk|^\W*(?:\d+\W*)?myslivecký\s+pluk"),
    ("BHIR", r"bos[eň]\w*.*pluk|bosensk"),
    ("FJB", r"^(?!.*tyrol).*(?:myslivc|myslivec).*prapor|^(?!.*tyrol).*prapor.*(?:myslivc|myslivec)"),
    ("HHR", r"honvéd\w*\s+husar"),
    ("HIR", r"\bhonvéd\w*.*pluk"),
    ("LUR", r"\bzeměbran\w*\s+hulán"),
    ("DR", r"\bdragoun\w*\s+pluk"),
    ("UR", r"\b(?:hulán|ulán)\w*\s+pluk"),
    ("HR", r"\bhusar\w*\s+pluk"),
    ("FAR", r"\bpolní\s+dělostřel\w*\s+pluk"),
    ("FsAR", r"\bpevnostní\s+dělostřel\w*\s+pluk"),
    ("HAR", r"\btěžk\w*\s+dělostřel\w*\s+pluk"),
    ("LstIR", r"\bdomob?r\w*\s+(?:pěší\s+)?pluk"),
    ("LstBn", r"\bdomob?r\w*\s+prapor"),
    ("LIR", r"\b(?:zeměbran|zemsk|střeleck)\w*\s+(?:pěší\s+)?pluk"),
    ("IR", r"\bpěší\)?\s+pluk"),
)
#: VÚA's theatre on csol.cz's names; the rest (Rear, Romania, Unknown) carries none.
VUA_THEATRE = {"France": "France", "Italy": "Italy", "Russia": "Russia",
               "Serbia": "Serbia/Balkans", "Macedonia": "Serbia/Balkans"}
#: (csol.cz theatre, VÚA theatre) pairs that differ but a man could cover: the 1918 transports from
#: Russia to France (a man csol.cz files under either), and the Serbian volunteer division formed
#: in Russia.
THEATRE_COMPATIBLE = {("Russia", "France"), ("France", "Russia"), ("Serbia/Balkans", "Russia")}

def load(final: Path) -> pd.DataFrame:
    """Overlap crosswalk + both person files (m:1 merges, row counts asserted)."""
    ov = pd.read_csv(final / "persons" / "overlap_matches.csv", usecols=OVERLAP_COLS)
    for flag in ("okres_match", "note_legion"):
        ov[flag] = ov[flag].astype("boolean")
    L = pd.read_parquet(final / "persons" / "legionnaires_clean.parquet", columns=LEGION_COLS)
    V = pd.read_parquet(final / "persons" / "habsburg_clean.parquet", columns=VUA_COLS)
    L, V = L.rename(columns={"theater": "legion_theater"}), V.rename(columns={"theater": "vua_theater"})
    n = len(ov)
    df = ov.merge(L, on="legion_id", how="left", validate="1:1", indicator="_l")
    df = df.merge(V, on="vua_id", how="left", validate="1:1", indicator="_v")
    assert len(df) == n, "an overlap merge changed the row count"
    missing = int((df["_l"] != "both").sum() + (df["_v"] != "both").sum())
    assert missing == 0, f"{missing} overlap id(s) not in the person files"
    return df.drop(columns=["_l", "_v"])


def _vua_death_bounds(df: pd.DataFrame) -> tuple[pd.Series, pd.Series]:
    """First and last possible day of VÚA's death date (a year-only date spans its year)."""
    year = pd.to_datetime(df["death_year"].astype("Int64").astype("string") + "-01-01", errors="coerce")
    yo = df["death_year_only"].fillna(False).astype(bool)
    lo = pd.to_datetime(df["death_date"]).where(~yo & df["death_date"].notna(), year)
    hi = lo.where(~yo, year + pd.offsets.YearEnd(0))
    return lo, hi


def corroborated(df: pd.DataFrame) -> pd.Series:
    """True where the link has evidence beyond name + date of birth: the birth okres agrees or
    VÚA's own note names the Legion."""
    return (df["okres_match"].fillna(False) | df["note_legion"].fillna(False)).astype(bool)


def regiment_number(unit) -> object:
    """The first integer in a unit string (``28.p.pl.``, ``p.pl.28``, ``3 p.p.`` → 28, 28, 3); <NA>
    without a digit or for a unit written with a ``?`` (no evidence)."""
    if not isinstance(unit, str) or "?" in unit:
        return pd.NA
    m = re.search(r"\d+", unit)
    return int(m.group()) if m else pd.NA


def _first_unit(unit, cut: str) -> str | None:
    """The first unit of a unit string, cut at the first of ``cut``; None for a non-string or a
    unit written with a ``?`` (no evidence)."""
    if not isinstance(unit, str) or "?" in unit:
        return None
    return re.split(cut, unit, maxsplit=1)[0].strip().lower()


def csol_branch(unit) -> object:
    """The Habsburg branch of a csol.cz capture unit (:data:`CSOL_BRANCH`: ``28.p.pl.`` → IR,
    ``7.zem.p.pl.`` → LIR, ``2.dom.p.pl.`` → LstIR); <NA> where the first unit names none."""
    first = _first_unit(unit, r"[,;/]")
    if first is None:
        return pd.NA
    token = re.sub(r"[\d\s.]", "", first)
    for branch, pattern in CSOL_BRANCH:
        if re.fullmatch(pattern, token):
            return branch
    return pd.NA


def vua_unit_names_legion(unit) -> bool:
    """True where VÚA's unit names the Legion (:data:`LEGION_UNIT_RE`) or is written in the
    Legion's form (:data:`LEGION_FORM_RE`, *pluk 1, rota 7*)."""
    if not isinstance(unit, str):
        return False
    return bool(LEGION_UNIT_RE.search(unit) or LEGION_FORM_RE.fullmatch(unit.strip()))


def vua_branch(unit) -> object:
    """The Habsburg branch of a VÚA unit (:data:`VUA_BRANCH`: *pěší pluk 28* → IR,
    *zeměbranecký pěší pluk 7* → LIR); <NA> for a bare *pluk N*, a generic artillery unit, a ``?``."""
    first = _first_unit(unit, r"[,;/]| \(")
    if first is None:
        return pd.NA
    for branch, pattern in VUA_BRANCH:
        if re.search(pattern, first):
            return branch
    return pd.NA


def _regiment_sides(df: pd.DataFrame, by_branch: bool, legion_na: bool):
    """Each side's regiment number (<NA> where it names none) and, with ``by_branch``, whether the
    two branches are the same (None without it)."""
    vua_unit = df["ah_unit_primary"]
    same_branch = None
    if by_branch:
        leg = df["habsburg_unit_capture"].map(lambda u: regiment_number(_first_unit(u, r"[,;/]")))
        vua = vua_unit.map(lambda u: regiment_number(_first_unit(u, r"[,;/]| \(")))
        leg_b, vua_b = df["habsburg_unit_capture"].map(csol_branch), vua_unit.map(vua_branch)
        leg = leg.astype("Int64").where(leg_b.notna().to_numpy())
        vua = vua.astype("Int64").where(vua_b.notna().to_numpy())
        same_branch = (leg_b.astype("string") == vua_b.astype("string")).fillna(False).astype(bool)
    else:
        leg = df["habsburg_unit_capture"].map(regiment_number).astype("Int64")
        doubt = vua_unit.astype("string").str.contains("?", regex=False).fillna(False)
        vua = pd.to_numeric(df["ah_regiment_no"], errors="coerce").round().astype("Int64")
        vua = vua.mask(doubt.astype(bool))
    if legion_na:
        named = vua_unit.map(lambda u: isinstance(u, str) and bool(LEGION_UNIT_RE.search(u)))
        vua = vua.mask(named.astype(bool))
    return leg, vua, same_branch


def regiment_agrees(df: pd.DataFrame, by_branch: bool | None = None,
                    legion_not_comparable: bool | None = None) -> pd.Series:
    """True where the csol.cz capture unit (``habsburg_unit_capture``) and VÚA's unit
    (``ah_unit_primary``) name the same regiment, False where both name one and they differ, <NA>
    where either names none (or either unit is written with a ``?``).

    ``by_branch`` (default :data:`REGIMENT_BY_BRANCH`): the regiment is branch + number
    (:func:`csol_branch`, :func:`vua_branch`; the first number of each side's first unit). A
    different number is a conflict; the same number in another branch (IR 28 against Landwehr 28)
    is a near match, neither agreement nor conflict (<NA>, counted by
    :func:`regiment_branch_differs`), since the two sources use the branch words loosely (csol.cz
    *dom.* against VÚA *zeměbranecký* on one number, VÚA *pěší pluk* for a Landwehr one); a unit
    with no branch is not comparable. Off: the first number of the csol.cz string against VÚA's
    ``ah_regiment_no`` (1.2.0).
    ``legion_not_comparable`` (default :data:`LEGION_UNIT_NOT_COMPARABLE`): a VÚA unit that names
    the Legion (:data:`LEGION_UNIT_RE`) carries no Habsburg regiment."""
    by_branch = REGIMENT_BY_BRANCH if by_branch is None else by_branch
    legion_na = LEGION_UNIT_NOT_COMPARABLE if legion_not_comparable is None else legion_not_comparable
    leg, vua, same_branch = _regiment_sides(df, by_branch, legion_na)
    both = leg.notna() & vua.notna()
    same = leg == vua
    out = same.astype("boolean").where(both)
    if same_branch is not None:
        out = out.mask(both & same.fillna(False).astype(bool) & ~same_branch)
    return out


def regiment_branch_differs(df: pd.DataFrame, by_branch: bool | None = None,
                            legion_not_comparable: bool | None = None) -> pd.Series:
    """True where both sides name a regiment with the same number in different branches (the near
    match :func:`regiment_agrees` leaves <NA>); False otherwise, and everywhere with ``by_branch``
    (default :data:`REGIMENT_BY_BRANCH`) off."""
    by_branch = REGIMENT_BY_BRANCH if by_branch is None else by_branch
    legion_na = LEGION_UNIT_NOT_COMPARABLE if legion_not_comparable is None else legion_not_comparable
    if not by_branch:
        return pd.Series(False, index=df.index)
    leg, vua, same_branch = _regiment_sides(df, True, legion_na)
    near = (leg.notna() & vua.notna() & (leg == vua).fillna(False).astype(bool) & ~same_branch)
    return near.astype(bool)


def vua_names_legion(df: pd.DataFrame) -> pd.Series:
    """True where VÚA's own record points at the Legion: its note names it (``note_legion``, the
    KLEG notes among them), its unit names it or is in the Legion's form
    (:func:`vua_unit_names_legion`), or its death place names it (:data:`LEGION_PLACE_RE`)."""
    unit = df["ah_unit_primary"].map(vua_unit_names_legion).astype(bool)
    place = df["death_place"].map(lambda p: isinstance(p, str) and bool(LEGION_PLACE_RE.search(p)))
    return (df["note_legion"].fillna(False).astype(bool) | unit | place.astype(bool))


def theatre_ruled_out(df: pd.DataFrame) -> pd.Series:
    """True where VÚA's place lies in a theatre the csol.cz record rules out: both theatres known
    (:data:`VUA_THEATRE`; csol.cz France, Italy, Russia or Serbia/Balkans), different, and not a
    pair a man could cover (:data:`THEATRE_COMPATIBLE`); <NA> where either is unknown. Meant for a
    VÚA date inside the Legion service: before it, a man could have fallen on another front."""
    vua = df["vua_theater"].map(VUA_THEATRE)
    leg = df["legion_theater"].where(df["legion_theater"].isin(set(VUA_THEATRE.values())))
    known = vua.notna() & leg.notna()
    compatible = pd.Series([p in THEATRE_COMPATIBLE for p in zip(leg, vua)], index=df.index)
    out = (leg != vua) & ~compatible
    return out.astype("boolean").where(known)


def example_eligible(df: pd.DataFrame, need_legion: bool | None = None,
                     theatre: bool | None = None) -> pd.Series:
    """A pair fit to show: the Habsburg regiment agrees, or the link is corroborated (okres or VÚA
    note) and no regiment number conflicts. A ``legion_survived`` pair (VÚA-fallen, the Legion
    demobilised him) must also, with ``need_legion`` (default :data:`SURVIVED_EXAMPLES_NEED_LEGION`),
    have VÚA name the Legion (``vua_names_legion``), and, with ``theatre`` (default
    :data:`SURVIVED_EXAMPLES_THEATRE`), no VÚA place in a theatre csol.cz rules out
    (``vua_theatre_ruled_out``)."""
    need_legion = SURVIVED_EXAMPLES_NEED_LEGION if need_legion is None else need_legion
    theatre = SURVIVED_EXAMPLES_THEATRE if theatre is None else theatre
    reg = df["regiment_agrees"]
    agrees = reg.fillna(False).astype(bool)
    no_conflict = reg.ne(False).fillna(True).astype(bool)
    ok = agrees | (df["corroborated"].astype(bool) & no_conflict)
    survived = df["category"].eq("legion_survived").fillna(False).astype(bool)
    if need_legion:
        ok &= ~survived | df["vua_names_legion"].astype(bool)
    if theatre:
        ok &= ~survived | ~df["vua_theatre_ruled_out"].fillna(False).astype(bool)
    return ok


def categorise(df: pd.DataFrame) -> pd.DataFrame:
    """Adds ``vua_death_lo``, ``legion_outcome``, ``category``, ``gap_days``,
    ``vua_near_capture`` (<NA> without both dates), ``vua_in_service`` (VÚA's first possible day
    between Legion entry and exit; <NA> without the three dates), ``corroborated``,
    ``regiment_agrees``, ``regiment_branch_differs``, ``vua_names_legion`` and
    ``vua_theatre_ruled_out``."""
    out = df.copy()
    lo, hi = _vua_death_bounds(out)
    out["vua_death_lo"] = lo
    codes = out["exit_codes"].astype("string")
    rec = codes.map(lambda c: sp.resolve_outcome(c)).astype("string")
    rec[rec.eq("death").fillna(False) & sp.death_demob_pair(codes)] = "demob_return"   # D-260
    out["legion_outcome"] = rec
    entry = pd.to_datetime(out["enroll_date"])
    cat = pd.Series("other", index=out.index, dtype="string")
    cat[rec.isna()] = "legion_no_exit"
    cat[rec.eq("missing").fillna(False)] = "legion_missing"
    cat[rec.eq("death").fillna(False)] = "consistent_death"
    cat[rec.isin(["demob_return", "transfer_csa"]).fillna(False)] = "legion_survived"
    cat[(hi < entry).fillna(False)] = "vua_dead_before_entry"
    out["category"] = cat
    exit_ = pd.to_datetime(out["exit_date"])
    out["gap_days"] = ((entry - lo).dt.days.where(cat.eq("vua_dead_before_entry"),
                                                   (exit_ - lo).dt.days)).astype("Int64")
    near = (lo - pd.to_datetime(out["capture_date"])).abs().dt.days
    out["vua_near_capture"] = (near <= CAPTURE_WINDOW_DAYS).astype("boolean").where(near.notna())
    known = lo.notna() & entry.notna() & exit_.notna()
    out["vua_in_service"] = ((lo >= entry) & (lo <= exit_)).astype("boolean").where(known)
    out["corroborated"] = corroborated(out)
    out["regiment_agrees"] = regiment_agrees(out)
    out["regiment_branch_differs"] = regiment_branch_differs(out)
    out["vua_names_legion"] = vua_names_legion(out)
    out["vua_theatre_ruled_out"] = theatre_ruled_out(out)
    return out


def category_table(c: pd.DataFrame) -> pd.DataFrame:
    """Men per category; the link's evidence (okres agrees, VÚA Legion note, note-confirmed,
    either of the first two; Habsburg regiment agrees, of the pairs where both sides name one,
    overall and among the corroborated; the same number in another branch); how many VÚA codes
    missing (vs declared dead); the gap in days."""
    c = c.assign(_corr_reg=c["corroborated"].astype(bool) & c["regiment_agrees"].notna(),
                 _corr_conflict=c["corroborated"].astype(bool) & c["regiment_agrees"].eq(False).fillna(False))
    g = c.groupby("category")
    t = pd.DataFrame({
        "men": g.size(),
        "okres_agrees": g["okres_match"].apply(lambda s: int(s.fillna(False).sum())),
        "vua_legion_note": g["note_legion"].apply(lambda s: int(s.fillna(False).sum())),
        "note_confirmed": g["confidence"].apply(lambda s: int(s.eq("medium").sum())),
        "corroborated": g["corroborated"].sum(),
        "regiment_both": g["regiment_agrees"].apply(lambda s: int(s.notna().sum())),
        "regiment_agrees": g["regiment_agrees"].apply(lambda s: int(s.fillna(False).sum())),
        "regiment_branch_differs": g["regiment_branch_differs"].sum(),
        "corroborated_regiment_both": g["_corr_reg"].sum(),
        "corroborated_regiment_conflict": g["_corr_conflict"].sum(),
        "vua_missing": g["cause_label"].apply(lambda s: int(s.astype("string").eq("Missing").sum())),
        "vua_declared_dead": g["note_declared_dead"].apply(lambda s: int(s.fillna(False).sum())),
        "gap_median_days": g["gap_days"].median(),
        "gap_q1": g["gap_days"].quantile(0.25),
        "gap_q3": g["gap_days"].quantile(0.75),
    }).reindex(list(CATEGORIES))
    counts = ["men", "okres_agrees", "vua_legion_note", "note_confirmed", "corroborated", "regiment_both",
              "regiment_agrees", "regiment_branch_differs", "corroborated_regiment_both",
              "corroborated_regiment_conflict"]
    t[counts] = t[counts].fillna(0).astype(int)
    return t


def examples(c: pd.DataFrame, n_by_rule: int = 3) -> pd.DataFrame:
    """The pinned pairs, then per category ``vua_dead_before_entry`` and ``legion_survived``
    the ``n_by_rule`` largest gaps among eligible pairs (:func:`example_eligible`) with a
    day-precise VÚA date that is not 1 January (a likely placeholder); ties by legion_id."""
    ok = example_eligible(c)
    pinned = c[c["legion_id"].isin(PINNED_EXAMPLES) & ok]
    vua_date = pd.to_datetime(c["vua_death_lo"])
    jan1 = (vua_date.dt.month.eq(1) & vua_date.dt.day.eq(1)).fillna(False).astype(bool)
    rest = c[~c["legion_id"].isin(PINNED_EXAMPLES) & ok & ~jan1
             & ~c["death_year_only"].fillna(False).astype(bool)]
    picks = [pinned]
    for cat in ("vua_dead_before_entry", "legion_survived"):
        r = rest[rest["category"].eq(cat) & rest["gap_days"].notna()]
        picks.append(r.sort_values(["gap_days", "legion_id"], ascending=[False, True]).head(n_by_rule))
    return pd.concat(picks).drop_duplicates("legion_id")


def _date(v, year_only=False) -> str:
    if pd.isna(v):
        return "—"
    return str(pd.Timestamp(v).year) if year_only else pd.Timestamp(v).strftime("%Y-%m-%d")


def _pct(n, d) -> str:
    return f"{int(n):,} ({100 * n / d:.0f}%)" if d else "—"


def _link(r) -> str:
    """The link's evidence beyond name + DOB, in words."""
    parts = [w for ok, w in ((r.okres_match, "same birth okres"), (r.note_legion, "VÚA note: Legion"))
             if not pd.isna(ok) and bool(ok)]
    if getattr(r, "vua_names_legion", False) and "VÚA note: Legion" not in parts:
        parts.append("VÚA unit or place: Legion")
    if not pd.isna(r.regiment_agrees):
        parts.append(f"regiment {'agrees' if r.regiment_agrees else 'differs'} "
                     f"({r.habsburg_unit_capture} / {r.ah_unit_primary})")
    return ", ".join(parts) or "name + DOB only"


def _in_service_reading(s: pd.DataFrame) -> str:
    """What VÚA says of the demobilised-alive men whose VÚA date lies inside their Legion service:
    how many it ties to the Legion, how many it places where csol.cz rules out, and the rest."""
    svc = s[s["vua_in_service"].fillna(False).astype(bool)]
    legion = svc["vua_names_legion"].astype(bool)
    ruled = svc["vua_theatre_ruled_out"].fillna(False).astype(bool) & ~legion
    rest = int((~legion & ~ruled).sum())
    return (f"Of those {len(svc):,}, {int(legion.sum()):,} have VÚA name the Legion (a Legion unit, "
            f"or the Legion's own *pluk N, rota M*; a Legion place; or VÚA's Legion note, the KLEG "
            f"notes among them), {int(ruled.sum()):,} more have VÚA's place in a theatre the csol.cz "
            f"record rules out (Italy for a man who served in Russia), and the other {rest:,} carry a "
            f"Habsburg unit, an Italian place or nothing. The row is a disagreement between csol.cz "
            f"and VÚA over **Legion-period deaths**, read three ways: VÚA lists as Legion dead men "
            f"whom csol.cz records as demobilised; csol.cz is wrong; or the pair is two men, or a "
            f"mislinked record, the likeliest reading where VÚA names a Habsburg unit or a theatre "
            f"the Legion record rules out. It is not evidence that a Habsburg code wrote off a "
            f"captured man; only the first row is.")


def _reading(c: pd.DataFrame, t: pd.DataFrame) -> str:
    """How sure the links are (okres, note, regiment), and what each of the first two rows can
    show, with its counts."""
    pre, srv, con = (t.loc[k] for k in ("vua_dead_before_entry", "legion_survived", "consistent_death"))
    b = c[c["category"].eq("vua_dead_before_entry")]
    s = c[c["category"].eq("legion_survived")]
    near, known = int(b["vua_near_capture"].fillna(False).sum()), int(b["vua_near_capture"].notna().sum())
    in_svc, svc_known = int(s["vua_in_service"].fillna(False).sum()), int(s["vua_in_service"].notna().sum())
    fit = int(example_eligible(b).sum())
    other_branch = (f" ({int(pre['regiment_branch_differs']):,} more give the same number in another "
                    f"branch, read as neither)" if pre["regiment_branch_differs"] else "")
    return (f"**How sure each link is.** The birth okres agrees for {_pct(pre['okres_agrees'], pre['men'])} "
            f"of the men written off before entry and {_pct(srv['okres_agrees'], srv['men'])} of those "
            f"demobilised alive, against {_pct(con['okres_agrees'], con['men'])} of the consistent deaths; "
            f"VÚA's note names the Legion for {_pct(pre['vua_legion_note'], pre['men'])} and "
            f"{_pct(srv['vua_legion_note'], srv['men'])}, against {_pct(con['vua_legion_note'], con['men'])}. "
            f"A name + date-of-birth coincidence on a common name lands exactly in these two categories, "
            f"so part of them may be two different men. The pairs whose birth okres agrees or whose VÚA "
            f"note names the Legion are the **corroborated subset** ({int(pre['corroborated']):,} of the "
            f"{int(pre['men']):,} written off before entry, {int(srv['corroborated']):,} of the "
            f"{int(srv['men']):,} demobilised alive), not a bound: an okres agreement alone still admits "
            f"two men, and {int(pre['corroborated_regiment_conflict']):,} of the "
            f"{int(pre['corroborated_regiment_both']):,} corroborated before-entry pairs that name a "
            f"regiment on both sides disagree on it. The stronger check is the **Habsburg "
            f"regiment**: csol.cz's capture unit and VÚA's unit name the same one for "
            f"{int(pre['regiment_agrees']):,} of the {int(pre['regiment_both']):,} before-entry pairs "
            f"where both name one{other_branch}. {fit:,} of the {int(pre['men']):,} before-entry pairs have "
            f"the regiment agreeing, or are corroborated with no regiment conflict. Of the {known:,} with "
            f"both a VÚA date and a Legion capture date, {near:,} have the VÚA date within "
            f"{CAPTURE_WINDOW_DAYS} days of capture.\n\n"
            f"**The demobilised-alive row is another conflict.** {in_svc:,} of the {svc_known:,} men in "
            f"it with a VÚA date and both Legion dates have VÚA's date *inside* their Legion service, and "
            f"the Habsburg regiment agrees on only {int(srv['regiment_agrees']):,} of the "
            f"{int(srv['regiment_both']):,} pairs where both name one. " + _in_service_reading(s))


def _regiment_note() -> str:
    """How the regiment column is read, for the switch in force."""
    if not REGIMENT_BY_BRANCH:
        return ("*Habsburg regiment agrees* compares the first number of csol.cz's "
                "`habsburg_unit_capture` with VÚA's `ah_regiment_no`, counted only where both carry "
                "one (a unit written with a `?` carries none). ")
    legion = ("; a VÚA unit that names the Legion names no Habsburg regiment" if LEGION_UNIT_NOT_COMPARABLE
              else "")
    return ("*Habsburg regiment agrees* compares the branch and number of csol.cz's "
            "`habsburg_unit_capture` with those of VÚA's `ah_unit_primary`, each side's first unit "
            "(infantry, Landwehr, Landsturm, Honvéd, Bosnian, Jäger, Kaiserjäger, dragoons, uhlans, "
            "hussars, field, fortress and heavy artillery), counted only where both name one: a unit "
            "written with a `?`, a bare *pluk N*, a generic artillery unit names none" + legion + ". "
            "The same number in another branch is counted apart (*+n other branch*), neither "
            "agreement nor conflict, since the two sources use the branch words loosely. ")


def _examples_note() -> str:
    """How the examples are chosen, for the switches in force."""
    extra = [w for on, w in ((SURVIVED_EXAMPLES_NEED_LEGION, "VÚA name the Legion (unit, place or note)"),
                             (SURVIVED_EXAMPLES_THEATRE, "no VÚA place in a theatre the csol.cz record "
                                                         "rules out")) if on]
    survived = (f"; a demobilised-alive example must also have {' and '.join(extra)}" if extra else "")
    return ("Examples: the largest gaps among pairs whose Habsburg regiment agrees, or whose birth "
            "okres agrees or VÚA note names the Legion with no regiment conflict, never on a "
            f"1 January VÚA date (a likely placeholder){survived}.")


def render(c: pd.DataFrame) -> str:
    """The Markdown block for the design note (tables + reading), from the categorised frame."""
    t, ex = category_table(c), examples(c)
    lines = [BEGIN, "",
             f"*Built by `utils/panels/vua_overlap.py` {__version__} from `data/final/persons/"
             f"overlap_matches.csv` and both person files ({len(c):,} confirmed men).*", "",
             "| category | men | birth okres agrees | VÚA note names the Legion | note-confirmed | "
             "okres or note | Habsburg regiment agrees (of both named) | VÚA: missing | "
             "VÚA: declared dead | gap, median days (IQR) |",
             "|---|--:|--:|--:|--:|--:|--:|--:|--:|---|"]
    for cat, r in t.iterrows():
        gap = ("—" if pd.isna(r["gap_median_days"]) else
               f"{r['gap_median_days']:,.0f} ({r['gap_q1']:,.0f} to {r['gap_q3']:,.0f})")
        reg = (f"{int(r['regiment_agrees']):,} of {int(r['regiment_both']):,}" if r["regiment_both"]
               else "—")
        if r["regiment_branch_differs"]:
            reg += f" (+{int(r['regiment_branch_differs']):,} other branch)"
        lines.append(f"| {LABELS[cat]} | {int(r['men']):,} | {_pct(r['okres_agrees'], r['men'])} | "
                     f"{_pct(r['vua_legion_note'], r['men'])} | {_pct(r['note_confirmed'], r['men'])} | "
                     f"{_pct(r['corroborated'], r['men'])} | {reg} | {int(r['vua_missing'] or 0):,} | "
                     f"{int(r['vua_declared_dead'] or 0):,} | {gap} |")
    possibly = int(((c["vua_death_lo"] < pd.to_datetime(c["enroll_date"])).fillna(False)
                    & c["category"].ne("vua_dead_before_entry")).sum())
    lines += ["", "Gap: Legion entry − VÚA date for the first row, Legion exit − VÚA date for the "
              "others (positive = the Legion has him alive after VÚA's date). The first row counts "
              f"a year-only VÚA date at its last day (certainly before entry); {possibly:,} more "
              "men have a VÚA date that may fall before entry (a year-only date in the entry "
              "year, read at its first day). *Birth okres agrees* is the linkage's own `okres_match` "
              "(False where either side has no okres); *note-confirmed* is `confidence = medium`; "
              + _regiment_note() + "Where VÚA dates the death inside the "
              "Legion service its unit can be a Legion one (*pluk 1, rota 7*), so the column tests a "
              "link only where VÚA's unit is a Habsburg one; its low agreement among the consistent "
              "deaths is no evidence against those links.", "",
              _reading(c, t), "",
              _examples_note(), "",
              "| legion_id / vua_id | VÚA: date · cause · place | Legion: entry → exit (codes) | link | category |",
              "|---|---|---|---|---|"]
    for r in ex.itertuples(index=False):
        place = re.sub(r"\s+", " ", str(r.death_place)) if pd.notna(r.death_place) else "—"
        codes = r.exit_codes if pd.notna(r.exit_codes) else "no code"
        lines.append(f"| {r.legion_id} / {r.vua_id} | {_date(r.vua_death_lo, bool(r.death_year_only))} · "
                     f"{r.cause_label if pd.notna(r.cause_label) else '—'} · {place} | "
                     f"{_date(r.enroll_date)} → {_date(r.exit_date)} ({codes}) | "
                     f"{_link(r)} | {LABELS[r.category]} |")
    lines += ["", END]
    return "\n".join(lines)


def write_block(block: str, note: Path = DESIGN_NOTE) -> None:
    """Replace the text between the markers in the design note (UTF-8, LF)."""
    text = note.read_text(encoding="utf-8")
    a, b = text.find(BEGIN), text.find(END)
    if a < 0 or b < a:
        raise ValueError(f"markers not found in {note}")
    note.write_text(text[:a] + block + text[b + len(END):], encoding="utf-8", newline="\n")
