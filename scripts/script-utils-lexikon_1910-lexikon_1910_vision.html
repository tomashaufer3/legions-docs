How it works

The footnote apparatus is where the text layer stops paying. The table above it is digits between printed rules and the ALTO reads it at ~88 %; the apparatus is small type, superscript keys, and — for most of what it records — pictograms, which the OCR renders as Щ1, gg§!, ф, ľ. Those are not damaged characters that better parsing recovers. The engine never identified a symbol, so there is nothing in the text layer to parse, and utils.lexikon_1910.lexikon_1910_institutions correctly emits them as unresolved slots rather than guessing.

This module fills those slots by looking at the paper. It is deliberately the narrowest possible vision channel:

  • One call per region, not per municipality. The apparatus is three crops on a page (left column, right column, the full-width postal footer). The table above it is ~15 blocks. Reading the apparatus for the whole Čechy volume is therefore on the order of 2,300 calls against ~11,775 for the table — which is what makes a cheap reader on the apparatus and no reader on the table an affordable combination.
  • It returns printed lines, not structure. The reply is a list of strings in printed order, which is exactly what utils.lexikon_1910.lexikon_1910_notes.extract_notes produces from the ALTO. So a vision read is assembled straight into a utils.lexikon_1910.lexikon_1910_notes.Notes and every downstream consumer — section cutting, parts_check, the postal legend, the institution decoder — runs on it without a line of new code, and the two channels are gradeable against each other because they produce the same object.
  • Symbols come back as tokens from a closed list. The model may emit [post], [school], [doctor] … and nothing else; anything it cannot place is [?]. The vocabulary is not invented here — it is the pictogram rows of reference/places/institution_abbreviations.csv, so the decoder resolves a token by the same table lookup it uses for o. hjtm. or gymn., and a token outside the table is rejected on arrival rather than becoming an institution nobody curated.

The closed set is doing the same job the invariants do for the table. There is no arithmetic identity down here to catch a confabulated symbol, so the only defence is that the model cannot name anything that is not on the list, and that an unknown symbol has a place to go — [?] — that is not a wrong answer. A vocabulary the model can extend at will would produce a clean-looking inventory with no way to tell which parts of it were read and which were composed.

The symbol legend itself is provisional until the preface plates (pp. VIII–XIV) are transcribed; the tokens carry that in their note column. Getting the vocabulary wrong misnames an institution — it does not silently invent one — and the fix is a CSV edit plus a re-run of these crops, not a re-extraction.

def canonical(token: str) -> str:
    """``[Post Office]`` -> ``[post-office]``. Case and spacing are not meaning."""
    inner = token[1:-1].strip().lower()
    return "[" + re.sub(r"[\s_]+", "-", inner) + "]"

def build_system(abbreviations, style: str = "annotate",
                 section: str = "", atlas: bool = False,
                 think: bool = False, contrast: bool = False) -> str:
    """The transcription prompt, with the token list read off the curated table.

    Built rather than written out so the vocabulary has exactly one definition. A
    token list typed into a prompt and a token table read by the decoder drift
    apart on the first edit, and the failure is silent in the worst direction: the
    model emits a token nobody can resolve, and the symbol is lost exactly as if it
    had never been read.

    ``style`` selects between the two jobs described at :data:`PROMPT_STYLES`. The
    ``transcribe`` style still marks every symbol's *position and count* with
    ``[?]``, which is most of the value: a slot with a page reference is a join for
    a later pass, where a missing symbol is a hole nobody knows about.

    ``section`` says the crop is one section rather than a whole column, and
    changes two things together: the head describes that one kind of entry (see
    :data:`SECTION_HEADS`), and the token list is narrowed to the symbols that
    section prints (see :data:`SECTION_CATEGORIES`). Both are only worth doing
    when the crop really was cut on a heading — which is why it is one argument
    and not two.

    ``contrast`` says a sheet of look-alike symbols (``build_contrast_sheet.py``,
    D-99) is sent between the key and the page, which makes the page the third
    image; it needs ``atlas``.
    """
    if style not in PROMPT_STYLES:
        raise ValueError(f"style must be one of {PROMPT_STYLES}, got {style!r}")
    head = SECTION_HEADS.get(section, _SHARED_HEAD)
    if contrast and not atlas:
        raise ValueError("a contrast sheet is read against the key: it needs atlas=True")
    if atlas:
        head += (_CONTRAST_NOTE if contrast else _ATLAS_NOTE).format(unknown=UNKNOWN_TOKEN)
    # Only when the model is actually going to think. Told to a reader that
    # answers in one shot, "work through it before you answer" is a description
    # of a process that will not happen, and it costs prompt tokens on every
    # crop to say so. The guidance leans on restraint because that is what the
    # bake-off measured: the union of 23 passes asserted 1,280 claims for 280
    # true ones, so these readers fail by over-asserting, not by under-seeing.
    if think:
        head += _THINK_NOTE.format(unknown=UNKNOWN_TOKEN)
    if style == "transcribe":
        return head + _TRANSCRIBE_TAIL.format(unknown=UNKNOWN_TOKEN)

    rows = pictograms(abbreviations, section=section)
    if not rows:
        raise ValueError(
            "no pictogram rows in the abbreviation table — channel G would run "
            "with an empty token list and every symbol would come back as "
            f"{UNKNOWN_TOKEN}")
    listing = "\n".join(f"    {a.code:<16} {a.english}"
                        + (f" ({a.note})" if a.note else "")
                        for a in rows)
    return head + _ANNOTATE_TAIL.format(
        vocabulary=listing, unknown=UNKNOWN_TOKEN, example=rows[0].code)

    """Split a plain-text reply into printed lines.

    A dedicated OCR model returns the page, not an object: markdown, sometimes in a
    fenced block, sometimes with a stray "Here is the transcription:" ahead of it.

    about the reading; erasing it here would hide it from the comparison.

    lines = [line.strip() for line in body.splitlines()]
    return [line for line in lines if line]

def guard_tokens(lines: list[str], allowed: set[str]) -> tuple[list[str], Counter]:
    """Hold the reply to the closed list, and report what it tried to say.

    A token that is on the list is normalised to its canonical spelling, so
    ``[Post]`` and ``[post]`` reach the decoder as the same code. A token that is
    not is replaced with :data:`UNKNOWN_TOKEN` and **counted**: a reader that
    invents symbols is a reader whose other output is worth less, and that belongs
    in the run's ledger rather than being quietly normalised away.

    Returns the cleaned lines and the rejects.
    """
    rejected: Counter = Counter()

    def replace(match: re.Match) -> str:
        token = canonical(match.group(0))
        if token in allowed:
            return token
        rejected[match.group(0)] += 1
        return UNKNOWN_TOKEN

    return [_TOKEN_RE.sub(replace, line) for line in lines], rejected

def drop_repeats(lines: list[str]) -> tuple[list[str], int]:
    """Remove a line that exactly repeats an earlier one in the same crop.

    Small models loop. Asked for one region, ``glm-ocr`` returned three lines and
    then returned the same three again — and a repeated line is not harmless here:
    every consumer downstream *sums*. A duplicated ``Části osad`` entry double-counts
    a settlement's houses and population into the parts check, and a duplicated
    legend entry silently overwrites a key.

    Exact repetition of a long line is the signature of the loop rather than of the
    print: the apparatus does not set the same forty characters twice within one
    column. Short lines are left alone (see :data:`_REPEAT_MIN_CHARS`), and the
    count is returned so the run can report how much of the reply was loop.
    """
    seen: set[str] = set()
    kept: list[str] = []
    dropped = 0
    for line in lines:
        key = " ".join(line.split())
        if len(key) >= _REPEAT_MIN_CHARS and key in seen:
            dropped += 1
            continue
        seen.add(key)
        kept.append(line)
    return kept, dropped

The ALTO at least emits something where a pictogram was printed — Щ1, ф, gg§! — which the institution decoder turns into an unresolved slot with a page and a position, and a slot is a join for a later pass. A model that reads the words and silently omits the pictures produces cleaner text and less information: the reader cannot tell a place that had no post office from a place whose post office was never transcribed.

This is the destructive case: a place with no post office becomes indistinguishable from a place whose post office was never transcribed.

                          f"of the section and not its content, which is what a "
                          f"reader that never saw the image produces"})

    ``find`` is the heading matcher used to strip a transcribed heading off the
    first line — :func:`find_heading` by default, a volume profile's
    ``find_heading`` for a volume in another language (0.4.0, D-92).

    ``read`` is ``[(segment, lines), …]`` in reading order. Segments of the same
    section — the two halves either side of the divider, or the continuation on
    the next page — are merged back into one section, because that is the unit
    ``parts_check`` and the institution decoder consume and the unit the source
    is numbered in.

    **The identity comes from the text layer, the content from the model**, and
    the split is deliberate. Which district a crop belongs to is a fact about
    where it was cut, not about what the reader made of the ink: a carried
    segment has no heading in it at all, and a segment that does may have the
    heading damaged in the image exactly as it is damaged in the ALTO. Taking the
    district from the crop's own provenance is therefore the honest answer, and
    it is what makes a section-targeted pass joinable to the text layer at all.

    The consequence has to be stated where the results are read: in this mode the
    ``G_section`` verdict is true by construction and grades nothing. What still
    grades is everything inside the section — the keys, the altitudes, the
    house-population pairs, and the symbols.
    """
    merged: dict[tuple[str, str, str], Section] = {}
    order: list[tuple[str, str, str]] = []
    for segment, lines in read:
        key = (segment.page, segment.kind, segment.key)
        section = merged.get(key)
        if section is None:
            section = Section(kind=segment.kind, district=segment.district,
                              page=segment.page, lines=[])
            merged[key] = section
            order.append(key)
        for line in lines:
            heading = (find or find_heading)(line)
            # The crop opens on the heading, so the model transcribes it. Strip it
            # the way Notes.sections does — keeping whatever the same printed line
            # carries after it, because an entry often starts there.
            tail = line[heading[2]:] if heading else line
            if tail.strip():
                section.lines.append(tail)
    return [merged[key] for key in order]

def compare_sections(alto_sections, vision_sections) -> list[dict]:
    """Grade channel G against channel B on what both of them produce.

    Only quantities are compared, never prose. The two channels read the same ink
    with different machinery, so a difference in wording is expected and says
    nothing; a difference in a **number** is one of them being wrong, and the
    numbers here are the ones the rest of the pipeline consumes — the key sets that
    resolve columns 16 and 17, the house-population pairs that re-check the table,
    and the altitudes.

    Agreement is evidence, not proof: both readings descend from the same printed
    page, so a figure the press set badly is misread identically by both. What this
    catches is one channel dropping, merging or fabricating an entry, which is the
    failure mode that actually happens here.

    Sections are matched on ``(page, kind, district)``. A section only one channel
    found is reported as ``only_B`` / ``only_G`` rather than being dropped — a
    heading the vision read lost takes a whole district's entries with it, and that
    must not disappear into a denominator.
    """
    left = _sections_by_key(alto_sections)
    right = _sections_by_key(vision_sections)
    findings: list[dict] = []

    for key in sorted(set(left) | set(right)):
        page, kind, district = key
        base = {"check": "G_section", "page": page, "district": district,
                "row_kind": kind}
        if key not in right:
            findings.append({**base, "verdict": "only_B",
                             "detail": "section found in the text layer only"})
            continue
        if key not in left:
            findings.append({**base, "verdict": "only_G",
                             "detail": "section found in the image read only"})
            continue
        findings.append({**base, "verdict": "pass", "detail": ""})

        b_text, g_text = left[key].text, right[key].text
        for check, pattern, label in (
                ("G_keys", KEY_RE, "footnote keys"),
                ("G_altitudes", ALTITUDE_RE, "altitudes"),
        ):
            b_set = Counter(pattern.findall(b_text))
            g_set = Counter(pattern.findall(g_text))
            findings.append(_agreement(base, check, label, b_set, g_set))

        b_parts = Counter(PART_RE.findall(b_text))
        g_parts = Counter(PART_RE.findall(g_text))
        findings.append(_agreement(base, "G_parts", "house-population pairs",
                                   b_parts, g_parts))
    return findings

def lexikon_1910_vision_report(pages_read: int, regions: Counter,
                               rejected: Counter, findings: list[dict],
                               resolved: list[dict] | None = None,
                               repeats: int = 0, targeted: bool = False) -> str:
    """Ledger for the image read of the apparatus."""
    lines = [f"lexikon_1910_vision v{__version__} — "
             f"below-table apparatus, read from the image", ""]
    if not pages_read:
        return "\n".join(lines + ["  no page was read"])

    labels = sorted(regions) if targeted else NOTES_REGIONS
    lines.append(f"  {pages_read} pages, "
                 + ", ".join(f"{regions[r]} {r}" for r in labels
                             if regions.get(r))
                 + (" section crops" if targeted else " crops"))
    if rejected:
        total = sum(rejected.values())
        sample = ", ".join(f"{t}×{n}" for t, n in rejected.most_common(5))
        lines.append(f"  ! {total} tokens outside the closed list, replaced with "
                     f"{UNKNOWN_TOKEN}: {sample}")
    else:
        lines.append("  every symbol token was on the closed list")
    if repeats:
        lines.append(f"  ! {repeats} repeated lines dropped — the reader looped. "
                     f"Every consumer here sums, so a repeat double-counts")

    if resolved is not None:
        symbols = [r for r in resolved if r.get("source") == "abbrev"
                   and str(r.get("code", "")).startswith("[")]
        unknown = [r for r in symbols if r.get("code") == UNKNOWN_TOKEN]
        lines.append(f"  symbols resolved to an institution: "
                     f"{len(symbols) - len(unknown)}  "
                     f"(unplaced {UNKNOWN_TOKEN}: {len(unknown)})")

    dropped = [f for f in findings
               if f["check"] == "G_symbols" and f["verdict"] == "dropped"]
    unnamed = [f for f in findings
               if f["check"] == "G_symbols" and f["verdict"] == "unnamed"]
    if unnamed:
        lines.append("")
        lines.append(f"  {len(unnamed)} regions where the symbols came back as "
                     f"unnamed placeholders. Positions and")
        lines.append("     counts survive, so the entry structure and the letter "
                     "codes (R, Sch, K, H) are")
        lines.append("     usable — but the identities are not. Name them with a "
                     "second pass")
        lines.append("     (--notes-style annotate) before using the inventory.")
    if dropped:
        lines.append("")
        lines.append(f"  !! {len(dropped)} regions where this reader transcribed "
                     f"the words and omitted the printed symbols entirely.")
        lines.append("     Do NOT build the institution inventory from those: a "
                     "place with no post office")
        lines.append("     cannot be told from a place whose post office was "
                     "never read.")

    if targeted:
        lines.append("")
        lines.append("  Section-targeted pass: each crop was cut on its printed "
                     "heading, so the")
        lines.append("     district is a property of the crop and G_section is "
                     "true by construction —")
        lines.append("     it grades nothing here. The keys, altitudes, pairs and "
                     "symbols still do.")

    lines.append("")
    by_check: dict[str, Counter] = {}
    for finding in findings:
        by_check.setdefault(finding["check"], Counter())[finding["verdict"]] += 1
    for check in sorted(by_check):
        counts = by_check[check]
        graded = counts["pass"] + counts["fail"]
        rate = f"{counts['pass'] / graded:6.1%}" if graded else "     --"
        extra = "".join(f"  {k} {counts[k]}" for k in
                        ("only_B", "only_G", "na") if counts.get(k))
        lines.append(f"  {check:<14} {rate}  "
                     f"({counts['pass']} agree, {counts['fail']} differ){extra}")
    return "\n".join(lines)

"""Read the below-table apparatus from the *image*, and hand the result to the
existing parser unchanged.

The footnote apparatus is where the text layer stops paying. The table above it is
digits between printed rules and the ALTO reads it at ~88 %; the apparatus is
small type, superscript keys, and — for most of what it records — **pictograms**,
which the OCR renders as ``Щ1``, ``gg§!``, ``ф``, ``ľ``. Those are not damaged
characters that better parsing recovers. The engine never identified a symbol, so
there is nothing in the text layer to parse, and
:mod:`~utils.lexikon_1910.lexikon_1910_institutions` correctly emits them as unresolved
slots rather than guessing.

This module fills those slots by looking at the paper. It is deliberately the
*narrowest* possible vision channel:

* **One call per region, not per municipality.** The apparatus is three crops on a
  page (left column, right column, the full-width postal footer). The table above
  it is ~15 blocks. Reading the apparatus for the whole Čechy volume is therefore
  on the order of 2,300 calls against ~11,775 for the table — which is what makes
  a cheap reader on the apparatus and *no* reader on the table an affordable
  combination.
* **It returns printed lines, not structure.** The reply is a list of strings in
  printed order, which is exactly what :func:`~utils.lexikon_1910.lexikon_1910_notes.extract_notes`
  produces from the ALTO. So a vision read is assembled straight into a
  :class:`~utils.lexikon_1910.lexikon_1910_notes.Notes` and every downstream consumer —
  section cutting, ``parts_check``, the postal legend, the institution decoder —
  runs on it **without a line of new code**, and the two channels are gradeable
  against each other because they produce the same object.
* **Symbols come back as tokens from a closed list.** The model may emit
  ``[post]``, ``[school]``, ``[doctor]`` … and nothing else; anything it cannot
  place is ``[?]``. The vocabulary is not invented here — it is the ``pictogram``
  rows of ``reference/places/institution_abbreviations.csv``, so the decoder
  resolves a token by the same table lookup it uses for ``o. hjtm.`` or ``gymn.``,
  and a token outside the table is rejected on arrival rather than becoming an
  institution nobody curated.

**The closed set is doing the same job the invariants do for the table.** There is
no arithmetic identity down here to catch a confabulated symbol, so the only
defence is that the model cannot name anything that is not on the list, and that
an unknown symbol has a place to go — ``[?]`` — that is not a wrong answer. A
vocabulary the model can extend at will would produce a clean-looking inventory
with no way to tell which parts of it were read and which were composed.

The symbol legend itself is **provisional** until the preface plates (pp. VIII–XIV)
are transcribed; the tokens carry that in their ``note`` column. Getting the
vocabulary wrong misnames an institution — it does not silently invent one — and
the fix is a CSV edit plus a re-run of these crops, not a re-extraction.
"""

#: The ``kind`` that marks a row of the abbreviation table as a printed symbol
#: rather than an abbreviation.
PICTOGRAM_KIND = "pictogram"

#: Which of the volume's pictograms each kind of section actually prints, by the
#: ``category`` column of the abbreviation table.
#:
#: The *Výklad značek* is two lists in one plate. Twenty symbols name a **kind of
#: place** — obec, osada, město, ves, samota, hostinec, myslivna, zřícenina — and
#: those are printed in the table's name column and in the ``Části osad`` entries.
#: The remaining forty-five name an **institution** — school, doctor, post,
#: parish, gendarmerie, fire brigade — and those are what the ``Úřady, ústavy``
#: entries are made of. Handing a 4B model all 65 to hold while it transcribes
#: six-point type is most of an instruction-following budget spent on tokens that
#: cannot appear in the crop.
#:
#: ``industry`` is deliberately in **both**. ``[factory]`` and ``[brickworks]``
#: are printed between the settlement kinds and the institutions in the plate and
#: this project has not yet transcribed it (pp. VIII–XIV), so which group they
#: belong to is unsettled. Naming them to both readers costs two tokens; leaving
#: them out of the wrong one would silently cap what that pass can find.
#:
#: **This scopes the prompt, never the guard.** :func:`vocabulary` stays whole, so
#: a settlement symbol genuinely printed among the institutions still resolves
#: instead of being rejected as invention. A shorter list is an aid to the reader,
#: not a claim about what the press cannot have set.
SECTION_CATEGORIES = {
    "parts": ("settlement", "industry"),
    "offices": ("administration", "judiciary", "religion", "education",
                "transport", "health", "security", "economy", "finance",
                "cooperative", "industry", "professions"),
}

#: What the model returns for a symbol it cannot place on the list. It must have
#: somewhere to put these: without an "I don't know" token the closed list becomes
#: a forced choice, and a forced choice on an unfamiliar glyph is a guess wearing
#: the costume of a lookup.
UNKNOWN_TOKEN = "[?]"

#: What the guard treats as an attempt at a symbol token: brackets around an ASCII
#: word. Deliberately **not** "anything in brackets" — the OCR and the print both
#: put other things in brackets (``[ ý ]``, ``[2]``, ``[Š1``), and a guard that
#: rewrote those to :data:`UNKNOWN_TOKEN` would be destroying source text in the
#: name of protecting against invention. Only something shaped like a token from
#: the list is judged against the list.
_TOKEN_RE = re.compile(r"\[[A-Za-z][A-Za-z0-9 _-]{1,30}\]")


def canonical(token: str) -> str:
    """``[Post Office]`` -> ``[post-office]``. Case and spacing are not meaning."""
    inner = token[1:-1].strip().lower()
    return "[" + re.sub(r"[\s_]+", "-", inner) + "]"


def pictograms(abbreviations, section: str = "") -> list:
    """The pictogram rows of the abbreviation table, in table order.

    ``section`` narrows the list to the symbols that section prints — see
    :data:`SECTION_CATEGORIES`. An unknown section name returns the whole list
    rather than an empty one: a typo must not silently produce a prompt with no
    vocabulary in it, which would make every symbol on the page come back
    unnamed and look like a reader that cannot see.
    """
    rows = [a for a in abbreviations if a.kind == PICTOGRAM_KIND]
    allowed = SECTION_CATEGORIES.get(section)
    return [a for a in rows if a.category in allowed] if allowed else rows


def vocabulary(abbreviations) -> set[str]:
    """Every token the model is allowed to emit, including :data:`UNKNOWN_TOKEN`."""
    return {a.code for a in pictograms(abbreviations)} | {UNKNOWN_TOKEN}

def build_system(abbreviations, style: str = "annotate",
                 section: str = "", atlas: bool = False,
                 think: bool = False, contrast: bool = False) -> str:
    """The transcription prompt, with the token list read off the curated table.

    Built rather than written out so the vocabulary has exactly one definition. A
    token list typed into a prompt and a token table read by the decoder drift
    apart on the first edit, and the failure is silent in the worst direction: the
    model emits a token nobody can resolve, and the symbol is lost exactly as if it
    had never been read.

    ``style`` selects between the two jobs described at :data:`PROMPT_STYLES`. The
    ``transcribe`` style still marks every symbol's *position and count* with
    ``[?]``, which is most of the value: a slot with a page reference is a join for
    a later pass, where a missing symbol is a hole nobody knows about.

    ``section`` says the crop is one section rather than a whole column, and
    changes two things together: the head describes that one kind of entry (see
    :data:`SECTION_HEADS`), and the token list is narrowed to the symbols that
    section prints (see :data:`SECTION_CATEGORIES`). Both are only worth doing
    when the crop really was cut on a heading — which is why it is one argument
    and not two.

    ``contrast`` says a sheet of look-alike symbols (``build_contrast_sheet.py``,
    D-99) is sent between the key and the page, which makes the page the third
    image; it needs ``atlas``.
    """
    if style not in PROMPT_STYLES:
        raise ValueError(f"style must be one of {PROMPT_STYLES}, got {style!r}")
    head = SECTION_HEADS.get(section, _SHARED_HEAD)
    if contrast and not atlas:
        raise ValueError("a contrast sheet is read against the key: it needs atlas=True")
    if atlas:
        head += (_CONTRAST_NOTE if contrast else _ATLAS_NOTE).format(unknown=UNKNOWN_TOKEN)
    # Only when the model is actually going to think. Told to a reader that
    # answers in one shot, "work through it before you answer" is a description
    # of a process that will not happen, and it costs prompt tokens on every
    # crop to say so. The guidance leans on restraint because that is what the
    # bake-off measured: the union of 23 passes asserted 1,280 claims for 280
    # true ones, so these readers fail by over-asserting, not by under-seeing.
    if think:
        head += _THINK_NOTE.format(unknown=UNKNOWN_TOKEN)
    if style == "transcribe":
        return head + _TRANSCRIBE_TAIL.format(unknown=UNKNOWN_TOKEN)

    rows = pictograms(abbreviations, section=section)
    if not rows:
        raise ValueError(
            "no pictogram rows in the abbreviation table — channel G would run "
            "with an empty token list and every symbol would come back as "
            f"{UNKNOWN_TOKEN}")
    listing = "\n".join(f"    {a.code:<16} {a.english}"
                        + (f" ({a.note})" if a.note else "")
                        for a in rows)
    return head + _ANNOTATE_TAIL.format(
        vocabulary=listing, unknown=UNKNOWN_TOKEN, example=rows[0].code)


def lines_from_text(text: str) -> list[str]:
    """Split a plain-text reply into printed lines.

    A dedicated OCR model returns the page, not an object: markdown, sometimes in a
    fenced block, sometimes with a stray "Here is the transcription:" ahead of it.
    Asking a 0.5B decoder to hold a JSON schema on top of the OCR is asking for the
    schema to fail on the hard pages — exactly the pages worth reading — so the
    text path exists and the reply is split on its own line breaks.

    Markdown table pipes are kept. The apparatus is prose, not a table, so a model
    that emits pipes has decided the layout is tabular and that decision is data
    about the reading; erasing it here would hide it from the comparison.
    """
    body = str(text or "").strip()
    if body.startswith("```"):
        body = re.sub(r"^```[\w-]*\s*|\s*```$", "", body, flags=re.MULTILINE)
    lines = [line.strip() for line in body.splitlines()]
    return [line for line in lines if line]

def guard_tokens(lines: list[str], allowed: set[str]) -> tuple[list[str], Counter]:
    """Hold the reply to the closed list, and report what it tried to say.

    A token that is on the list is normalised to its canonical spelling, so
    ``[Post]`` and ``[post]`` reach the decoder as the same code. A token that is
    not is replaced with :data:`UNKNOWN_TOKEN` and **counted**: a reader that
    invents symbols is a reader whose other output is worth less, and that belongs
    in the run's ledger rather than being quietly normalised away.

    Returns the cleaned lines and the rejects.
    """
    rejected: Counter = Counter()

    def replace(match: re.Match) -> str:
        token = canonical(match.group(0))
        if token in allowed:
            return token
        rejected[match.group(0)] += 1
        return UNKNOWN_TOKEN

    return [_TOKEN_RE.sub(replace, line) for line in lines], rejected


#: A line shorter than this is not judged as a repetition. Short lines legitimately
#: repeat in this apparatus — a bare key, a lone ``*)`` — and dropping those would
#: be deleting print.
_REPEAT_MIN_CHARS = 24


def drop_repeats(lines: list[str]) -> tuple[list[str], int]:
    """Remove a line that exactly repeats an earlier one in the same crop.

    Small models loop. Asked for one region, ``glm-ocr`` returned three lines and
    then returned the same three again — and a repeated line is not harmless here:
    every consumer downstream *sums*. A duplicated ``Části osad`` entry double-counts
    a settlement's houses and population into the parts check, and a duplicated
    legend entry silently overwrites a key.

    Exact repetition of a long line is the signature of the loop rather than of the
    print: the apparatus does not set the same forty characters twice within one
    column. Short lines are left alone (see :data:`_REPEAT_MIN_CHARS`), and the
    count is returned so the run can report how much of the reply was loop.
    """
    seen: set[str] = set()
    kept: list[str] = []
    dropped = 0
    for line in lines:
        key = " ".join(line.split())
        if len(key) >= _REPEAT_MIN_CHARS and key in seen:
            dropped += 1
            continue
        seen.add(key)
        kept.append(line)
    return kept, dropped


#: Glyph noise in an ALTO line — the characters the engine emitted where a
#: pictogram was printed. Used only to ask whether the *other* channel saw
#: something there too; never to decode anything.
_NOISE_RE = re.compile(r"[^\w\s.,;:()\[\]/\-—–'\"§+&%]", re.UNICODE)


def symbols_check(alto_notes, vision_notes) -> list[dict]:
    """Did the image read keep the printed symbols, or quietly drop them?

    This is the one failure a transcription model has that no arithmetic notices.
    The ALTO at least emits *something* where a pictogram was printed — ``Щ1``,
    ``ф``, ``gg§!`` — which the institution decoder turns into an unresolved slot
    with a page and a position, and a slot is a join for a later pass. A model that
    reads the words and silently omits the pictures produces cleaner text and
    **less information**: the reader cannot tell a place that had no post office
    from a place whose post office was never transcribed.

    So the two channels are compared on symbol *presence*, not identity — and the
    verdict is three-way, because there are three outcomes and only two of them
    were visible at first:

    ``pass``      the reader named symbols from the closed list.
    ``unnamed``   it printed *something* at each symbol — ``glm-ocr`` renders them
                  all as one placeholder glyph — so the **position and the count
                  survive** even though the identity does not. ``2 ♡ V`` still says
                  two of something. That is a join for a later pass, not a loss,
                  and scoring it as a drop understates a usable reading.
    ``dropped``   the marks are simply gone. This is the destructive case: a place
                  with no post office becomes indistinguishable from a place whose
                  post office was never transcribed.
    """
    vision_by_page = {n.page: n for n in vision_notes}
    findings: list[dict] = []
    for alto in alto_notes:
        vision = vision_by_page.get(alto.page)
        if vision is None:
            continue
        for region in ("left", "right", "footer"):
            b_lines = getattr(alto, f"{region}_lines")
            g_lines = getattr(vision, f"{region}_lines")
            if not b_lines or not g_lines:
                continue
            findings.append(_symbol_verdict(
                b_lines, g_lines,
                {"check": "G_symbols", "page": alto.page, "row_kind": region,
                 "district": ""}))
    return findings


def symbols_check_sections(alto_sections, vision_sections) -> list[dict]:
    """The same three-way verdict, per section rather than per column.

    What a targeted pass needs, and it says more than the region version did. A
    column mixes a parts section with an offices section, so one verdict covered
    two different populations of symbol; a section is one district, one kind, and
    a ``dropped`` here names the district whose institutions cannot be built.
    """
    vision_by_key = {(s.page, s.kind, s.key): s for s in vision_sections}
    findings: list[dict] = []
    for alto in alto_sections:
        vision = vision_by_key.get((alto.page, alto.kind, alto.key))
        if vision is None or not alto.lines or not vision.lines:
            continue
        findings.append(_symbol_verdict(
            alto.lines, vision.lines,
            {"check": "G_symbols", "page": alto.page, "row_kind": alto.kind,
             "district": alto.district}))
    return findings


#: A word worth comparing between the channels: letters only, long enough not to
#: be a fragment. Short tokens are shared by any two pieces of Czech.
_WORD_RE = re.compile(r"[^\W\d_]{4,}", re.UNICODE)

#: Below this share of the text layer's own words reappearing in the image read,
#: the reply is treated as invented rather than merely bad. A genuine reader of
#: this print recovers most of the words — the two channels disagree on the
#: *symbols*, not on ``notář`` — while a reader working from the prompt alone
#: shares almost nothing but the format.
_CONTENT_MIN_SHARE = 0.25

#: Sections with fewer real words than this are not judged. Some offices sections
#: are almost pure pictogram (``24, -) f-``), and a denominator of two words
#: decides nothing either way.
_CONTENT_MIN_WORDS = 6


def content_check(alto_sections, vision_sections) -> list[dict]:
    """Did the reader see *this* section, or write a plausible one?

    The worst failure available here is not a bad transcription, it is a fluent
    invention. A text-only model at a vision endpoint does not error: it reads the
    prompt, writes something shaped like the thing described, and every downstream
    check then grades fiction. ``gemma4:latest`` did exactly this on page 270 —
    well-formed entries, on-list symbols, altitudes in metres, and entry keys
    lifted verbatim from the prompt's own worked examples.

    **The first version of this check compared entry keys, and it was wrong.** The
    reasoning was that the municipality numbers in a section are a fact about the
    district and cannot be guessed from a description of the format. Both halves
    of that are false. The numbering restarts at 1 in every soudní okres and runs
    consecutively, so ``1, 2, 3`` is not a guess, it is the answer; and
    :func:`~utils.lexikon_1910.lexikon_1910_institutions.parse_entries` *repairs* a key
    that falls outside the running sequence, which rewrote the invented keys into
    a plausible consecutive run before the check ever saw them. The blind reader
    scored 3/3. A check whose evidence is destroyed by a repair downstream of it
    is worse than no check, because it reports a pass.

    What cannot be guessed is the **words**. This district's entries print
    ``notář``, ``zastup``, ``poklad``, ``měšť``, ``pokr``, ``hosp``, ``spol`` in
    one particular arrangement, and the altitudes print ``290``, ``288``, ``443``.
    A reader working from the image recovers most of them — the two channels
    disagree about the pictograms, which is the whole reason for the second
    reading, but they agree about the type. A reader working from the prompt
    recovers the format and nothing else.

    This is the one check here that can detect a reader which is not reading. The
    symbol checks cannot: invented symbols are drawn from the same closed list as
    real ones and arrive in the same shape.
    """
    vision_by_key = {(s.page, s.kind, s.key): s for s in vision_sections}
    findings: list[dict] = []
    for alto in alto_sections:
        vision = vision_by_key.get((alto.page, alto.kind, alto.key))
        if vision is None:
            continue
        printed = {normalise(w) for w in _WORD_RE.findall(alto.text)}
        claimed = {normalise(w) for w in _WORD_RE.findall(vision.text)}
        printed.discard("")
        base = {"check": "G_content", "page": alto.page,
                "district": alto.district, "row_kind": alto.kind}
        if len(printed) < _CONTENT_MIN_WORDS:
            findings.append({
                **base, "verdict": "na",
                "detail": f"only {len(printed)} words in the text layer's "
                          f"reading — too few to decide"})
            continue
        hit = len(printed & claimed)
        share = hit / len(printed)
        if share >= _CONTENT_MIN_SHARE:
            findings.append({
                **base, "verdict": "pass",
                "detail": f"{hit}/{len(printed)} of the text layer's words "
                          f"reappear in the image read ({share:.0%})"})
        else:
            findings.append({
                **base, "verdict": "invented",
                "detail": f"only {hit}/{len(printed)} of the text layer's words "
                          f"reappear ({share:.0%}) — this reply shares the format "
                          f"of the section and not its content, which is what a "
                          f"reader that never saw the image produces"})
    return findings


def _symbol_verdict(b_lines: list[str], g_lines: list[str], base: dict) -> dict:
    """One symbol-presence verdict over two readings of the same print."""
    marks = sum(len(_NOISE_RE.findall(line)) for line in b_lines)
    # Count *symbol tokens*, not brackets. Counting "[" let a reader that emits
    # markdown or LaTeX pass this check while dropping every pictogram — the exact
    # failure the check exists to catch, scored as a pass by its own detector.
    tokens = sum(len(_TOKEN_RE.findall(line)) + line.count(UNKNOWN_TOKEN)
                 for line in g_lines)
    placeholders = sum(len(_NOISE_RE.findall(line)) for line in g_lines)
    if marks < 3:
        return {**base, "verdict": "na",
                "detail": "the text layer saw no marks here"}
    if tokens:
        return {**base, "verdict": "pass",
                "detail": f"{tokens} named symbols against {marks} glyph marks"}
    if placeholders >= 3:
        return {**base, "verdict": "unnamed",
                "detail": f"{placeholders} unnamed placeholder marks against "
                          f"{marks} in the text layer — positions and counts "
                          f"survive, identities do not"}
    return {**base, "verdict": "dropped",
            "detail": f"text layer has {marks} glyph marks, image read has "
                      f"neither a named symbol nor a placeholder — the "
                      f"pictograms were not transcribed at all"}


def notes_from_regions(page: str, lines_by_region: dict[str, list[str]],
                       template: Notes | None = None) -> Notes:
    """Assemble a :class:`Notes` from what the reader returned for each crop.

    The geometry is copied from the ALTO ``Notes`` the crops were cut from, because
    that is where it came from — the vision reader is given an image and never sees
    a coordinate. When there is no template (a page read by image alone) the
    geometry is zeroed, which is honest: nothing downstream uses it, and a
    plausible-looking invented ``split_x`` would be worse than an obvious 0.
    """
    return Notes(
        page=page,
        top=template.top if template else 0,
        bottom=template.bottom if template else 0,
        split_x=template.split_x if template else 0,
        band_top=template.band_top if template else 0,
        left_lines=list(lines_by_region.get("left", [])),
        right_lines=list(lines_by_region.get("right", [])),
        footer_lines=list(lines_by_region.get("footer", [])),
    )


def sections_from_segments(read: list[tuple], find=None) -> list[Section]:
    """Assemble the targeted read into :class:`Section` objects.

    ``find`` is the heading matcher used to strip a transcribed heading off the
    first line — :func:`find_heading` by default, a volume profile's
    ``find_heading`` for a volume in another language (0.4.0, D-92).

    ``read`` is ``[(segment, lines), …]`` in reading order. Segments of the same
    section — the two halves either side of the divider, or the continuation on
    the next page — are merged back into one section, because that is the unit
    ``parts_check`` and the institution decoder consume and the unit the source
    is numbered in.

    **The identity comes from the text layer, the content from the model**, and
    the split is deliberate. Which district a crop belongs to is a fact about
    where it was cut, not about what the reader made of the ink: a carried
    segment has no heading in it at all, and a segment that does may have the
    heading damaged in the image exactly as it is damaged in the ALTO. Taking the
    district from the crop's own provenance is therefore the honest answer, and
    it is what makes a section-targeted pass joinable to the text layer at all.

    The consequence has to be stated where the results are read: in this mode the
    ``G_section`` verdict is true by construction and grades nothing. What still
    grades is everything inside the section — the keys, the altitudes, the
    house-population pairs, and the symbols.
    """
    merged: dict[tuple[str, str, str], Section] = {}
    order: list[tuple[str, str, str]] = []
    for segment, lines in read:
        key = (segment.page, segment.kind, segment.key)
        section = merged.get(key)
        if section is None:
            section = Section(kind=segment.kind, district=segment.district,
                              page=segment.page, lines=[])
            merged[key] = section
            order.append(key)
        for line in lines:
            heading = (find or find_heading)(line)
            # The crop opens on the heading, so the model transcribes it. Strip it
            # the way Notes.sections does — keeping whatever the same printed line
            # carries after it, because an entry often starts there.
            tail = line[heading[2]:] if heading else line
            if tail.strip():
                section.lines.append(tail)
    return [merged[key] for key in order]

def _sections_by_key(sections) -> dict[tuple[str, str, str], object]:
    """``(page, kind, district)`` -> section, for the sections of one channel."""
    return {(s.page, s.kind, s.key): s for s in sections}


def compare_notes(alto_notes, vision_notes) -> list[dict]:
    """Grade two whole-apparatus readings against each other."""
    from .lexikon_1910_notes import collect_sections

    return compare_sections(collect_sections(alto_notes),
                            collect_sections(vision_notes))


def compare_sections(alto_sections, vision_sections) -> list[dict]:
    """Grade channel G against channel B on what both of them produce.

    Only quantities are compared, never prose. The two channels read the same ink
    with different machinery, so a difference in wording is expected and says
    nothing; a difference in a **number** is one of them being wrong, and the
    numbers here are the ones the rest of the pipeline consumes — the key sets that
    resolve columns 16 and 17, the house-population pairs that re-check the table,
    and the altitudes.

    Agreement is evidence, not proof: both readings descend from the same printed
    page, so a figure the press set badly is misread identically by both. What this
    catches is one channel dropping, merging or fabricating an entry, which is the
    failure mode that actually happens here.

    Sections are matched on ``(page, kind, district)``. A section only one channel
    found is reported as ``only_B`` / ``only_G`` rather than being dropped — a
    heading the vision read lost takes a whole district's entries with it, and that
    must not disappear into a denominator.
    """
    left = _sections_by_key(alto_sections)
    right = _sections_by_key(vision_sections)
    findings: list[dict] = []

    for key in sorted(set(left) | set(right)):
        page, kind, district = key
        base = {"check": "G_section", "page": page, "district": district,
                "row_kind": kind}
        if key not in right:
            findings.append({**base, "verdict": "only_B",
                             "detail": "section found in the text layer only"})
            continue
        if key not in left:
            findings.append({**base, "verdict": "only_G",
                             "detail": "section found in the image read only"})
            continue
        findings.append({**base, "verdict": "pass", "detail": ""})

        b_text, g_text = left[key].text, right[key].text
        for check, pattern, label in (
                ("G_keys", KEY_RE, "footnote keys"),
                ("G_altitudes", ALTITUDE_RE, "altitudes"),
        ):
            b_set = Counter(pattern.findall(b_text))
            g_set = Counter(pattern.findall(g_text))
            findings.append(_agreement(base, check, label, b_set, g_set))

        b_parts = Counter(PART_RE.findall(b_text))
        g_parts = Counter(PART_RE.findall(g_text))
        findings.append(_agreement(base, "G_parts", "house-population pairs",
                                   b_parts, g_parts))
    return findings


def _agreement(base: dict, check: str, label: str,
               b_counter: Counter, g_counter: Counter) -> dict:
    """One agreement verdict over two multisets of extracted values."""
    if not b_counter and not g_counter:
        return {**base, "check": check, "verdict": "na",
                "detail": f"no {label} in either channel"}
    shared = sum((b_counter & g_counter).values())
    total = max(sum(b_counter.values()), sum(g_counter.values()))
    if shared == total:
        return {**base, "check": check, "verdict": "pass",
                "detail": f"{total} {label} agree"}
    only_b = sorted((b_counter - g_counter).elements())[:4]
    only_g = sorted((g_counter - b_counter).elements())[:4]
    return {**base, "check": check, "verdict": "fail",
            "detail": f"{shared}/{total} {label} agree; "
                      f"text layer only {only_b}, image only {only_g}"}

def lexikon_1910_vision_report(pages_read: int, regions: Counter,
                               rejected: Counter, findings: list[dict],
                               resolved: list[dict] | None = None,
                               repeats: int = 0, targeted: bool = False) -> str:
    """Ledger for the image read of the apparatus."""
    lines = [f"lexikon_1910_vision v{__version__} — "
             f"below-table apparatus, read from the image", ""]
    if not pages_read:
        return "\n".join(lines + ["  no page was read"])

    labels = sorted(regions) if targeted else NOTES_REGIONS
    lines.append(f"  {pages_read} pages, "
                 + ", ".join(f"{regions[r]} {r}" for r in labels
                             if regions.get(r))
                 + (" section crops" if targeted else " crops"))
    if rejected:
        total = sum(rejected.values())
        sample = ", ".join(f"{t}×{n}" for t, n in rejected.most_common(5))
        lines.append(f"  ! {total} tokens outside the closed list, replaced with "
                     f"{UNKNOWN_TOKEN}: {sample}")
    else:
        lines.append("  every symbol token was on the closed list")
    if repeats:
        lines.append(f"  ! {repeats} repeated lines dropped — the reader looped. "
                     f"Every consumer here sums, so a repeat double-counts")

    if resolved is not None:
        symbols = [r for r in resolved if r.get("source") == "abbrev"
                   and str(r.get("code", "")).startswith("[")]
        unknown = [r for r in symbols if r.get("code") == UNKNOWN_TOKEN]
        lines.append(f"  symbols resolved to an institution: "
                     f"{len(symbols) - len(unknown)}  "
                     f"(unplaced {UNKNOWN_TOKEN}: {len(unknown)})")

    dropped = [f for f in findings
               if f["check"] == "G_symbols" and f["verdict"] == "dropped"]
    unnamed = [f for f in findings
               if f["check"] == "G_symbols" and f["verdict"] == "unnamed"]
    if unnamed:
        lines.append("")
        lines.append(f"  {len(unnamed)} regions where the symbols came back as "
                     f"unnamed placeholders. Positions and")
        lines.append("     counts survive, so the entry structure and the letter "
                     "codes (R, Sch, K, H) are")
        lines.append("     usable — but the identities are not. Name them with a "
                     "second pass")
        lines.append("     (--notes-style annotate) before using the inventory.")
    if dropped:
        lines.append("")
        lines.append(f"  !! {len(dropped)} regions where this reader transcribed "
                     f"the words and omitted the printed symbols entirely.")
        lines.append("     Do NOT build the institution inventory from those: a "
                     "place with no post office")
        lines.append("     cannot be told from a place whose post office was "
                     "never read.")

    if targeted:
        lines.append("")
        lines.append("  Section-targeted pass: each crop was cut on its printed "
                     "heading, so the")
        lines.append("     district is a property of the crop and G_section is "
                     "true by construction —")
        lines.append("     it grades nothing here. The keys, altitudes, pairs and "
                     "symbols still do.")

    lines.append("")
    by_check: dict[str, Counter] = {}
    for finding in findings:
        by_check.setdefault(finding["check"], Counter())[finding["verdict"]] += 1
    for check in sorted(by_check):
        counts = by_check[check]
        graded = counts["pass"] + counts["fail"]
        rate = f"{counts['pass'] / graded:6.1%}" if graded else "     --"
        extra = "".join(f"  {k} {counts[k]}" for k in
                        ("only_B", "only_G", "na") if counts.get(k))
        lines.append(f"  {check:<14} {rate}  "
                     f"({counts['pass']} agree, {counts['fail']} differ){extra}")
    return "\n".join(lines)
