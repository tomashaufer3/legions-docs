TL;DR

Collapses the free-text rank fields onto within-system ordinal scales — the k.u.k. Dienstgrade hierarchy (system="habsburg", 1–20) and the Czechoslovak Legion / early-ČSA ladder (system="legion", 1–14). The motivating use is the thesis's relative rank deprivation measure, so the ordinal is the headline output.

How it works

⚠️ The two ordinal (*_ord) scales are within-system and are not directly subtractable (rank_ladders.md intro, §F): a Habsburg poručík (ord 10) and a Legion poručík (ord 9) are the same OF‑1 grade. The cross-system reset instead bridges via the shared name-anchored common scale (ALT 1, §G): add_rank_columns also emits {prefix}_common (system-blind grade) and {prefix}_band (coarse NATO OF/OR band), and add_rank_reset differences the common columns to build rank_reset = legion_common − habsburg_common (never the within-system ordinals).

The Habsburg ladder is taken from reference/ranks/rank_ladders.md §A, validated against the bilingual Czech↔German table in Pod císařským praporem p.408:

Design notes

  • The j.d. token (jednoroční dobrovolník / Einjährig-Freiwilliger) is a status, not a rank (§E): it is stripped before matching and returned as a boolean flag.
  • Progression entries ("podporučík, poručík", "vojín, desátník") keep both ends: *_ord = highest reached, *_ord_low = lowest listed.
  • podporučík is not a k.u.k. rank (§A note); under system="habsburg" it is dropped to &lt;NA&gt; and surfaced in the residual report (do not score it as an officer). Under system="legion" it is a real rank (sub-Leutnant, ord 8).
  • rotmistr is likewise not a k.u.k. rank (the cavalry captain is rytmistr = Rittmeister): Habsburg rotmistr → &lt;NA&gt;; Legion rotmistr is a senior NCO / warrant grade (ord 6, §B).
  • Every lookup is keyed by system (rules, ordinals, drop-tokens, and tiers all differ): the §F harmonization trap (poručík = Leutnant here but a different OF slot in the Legion) is exactly why the two ladders never share a table.
  • Legion generals exist (ord 15–17, §B-gen) — unlike the Habsburg generals, which are in the ladder for completeness at n = 0. Both naming systems occur: Russian (generálmajor, generálporučík) and post-1918 ČSA French (brigádní/divizní/ armádní generál), paired by NATO grade. Bare "generál" is refused (tier, not grade).
  • Rule tokens must match at a word start (_at_word_start). Substring matching alone let a longer word silently resolve to a shorter rank it embedded — generálmajor → major, generálporučík → poručík, aspirant na podporučíka → poručík. Genuine compounds (nadstrážmistr, novobranec, nadělostřelec, …) are listed as their own tokens; anything else now surfaces as unresolved instead of being assigned a plausible wrong grade.

def add_rank_columns(df: pd.DataFrame,
                     source_col: str = "Hodnost v době zajetí",
                     system: str = "habsburg",
                     prefix: str = "habsburg_rank") -> pd.DataFrame:
    """Append standardised rank columns parsed from ``source_col``.

    Adds (with the given ``prefix``):
        ``{prefix}_clean``    canonical Czech label of the highest rank
        ``{prefix}_en``       English gloss of that label (German term in parens)
        ``{prefix}_ord``      Int64 ordinal of the highest rank (rank reached)
        ``{prefix}_ord_low``  Int64 ordinal of the lowest listed rank
        ``{prefix}_jd``       bool — one-year-volunteer (jednoroční dobrovolník)
        ``{prefix}_branch``   arm of service (sparse) or None
        ``{prefix}_tier``     coarse tier (system-specific labels: Czech / German)
        ``{prefix}_tier_en``  English gloss of the tier (Enlisted / NCO / Officer …)
        ``{prefix}_common``   Int64 system-blind ALT-1 common grade (subtractable
                              across systems; the reset input — §G)
        ``{prefix}_band``     coarse NATO/OF-OR band string (robustness axis)

    Args:
        df:         input DataFrame (not modified in place)
        source_col: raw rank column (Czech, pre-rename) to parse
        system:     rank ladder to use — ``"habsburg"`` (1–20) or ``"legion"`` (1–14)
        prefix:     output column-name prefix

    Returns:
        DataFrame with the ten rank columns appended.
    """
    _check_system(system)
    df = df.copy()

    parsed = df[source_col].apply(lambda s: _resolve(s, system))
    # A blank rank cell says nothing about a one-year volunteer, so the flag is <NA> there,
    # not False (v1.4.3, the D-52 rule); a recorded rank without the marker stays False.
    recorded = df[source_col].notna() & ~df[source_col].astype("string").str.strip().isin(
        ["", "?", "-"]).fillna(False)
    df[f"{prefix}_clean"]   = parsed.map(lambda p: p.clean)
    df[f"{prefix}_en"]      = parsed.map(lambda p: p.en)
    df[f"{prefix}_ord"]     = parsed.map(lambda p: p.ord_high).astype("Int64")
    df[f"{prefix}_ord_low"] = parsed.map(lambda p: p.ord_low).astype("Int64")
    df[f"{prefix}_jd"]      = parsed.map(lambda p: p.jd).where(recorded, pd.NA).astype("boolean")
    df[f"{prefix}_branch"]  = parsed.map(lambda p: p.branch)
    df[f"{prefix}_tier"]    = parsed.map(lambda p: p.tier)
    df[f"{prefix}_tier_en"] = df[f"{prefix}_tier"].map(RANK_TIER_EN)  # English gloss of the tier
    df[f"{prefix}_common"]  = parsed.map(lambda p: p.common).astype("Int64")
    df[f"{prefix}_band"]    = parsed.map(lambda p: p.band)
    return df

def add_rank_reset(df: pd.DataFrame,
                   habsburg_prefix: str = "habsburg_rank",
                   legion_prefix: str = "legion_rank",
                   out: str = "rank_reset") -> pd.DataFrame:
    """Append the cross-system rank-reset variables (the thesis's headline RHS).

    The *relative rank deprivation* upon Legion enrolment: the difference between a
    soldier's **Legion enrolment** rank and his **Habsburg** rank at capture, bridged
    onto the shared ALT-1 common scale (``rank_ladders.md`` §G) so the two
    within-system ordinals become subtractable.  Requires :func:`add_rank_columns`
    to have already produced the ``{prefix}_common`` / ``{prefix}_band`` columns for
    both sides.

    Adds:
        ``{out}``        Int64 — **fine ALT-1 sub-grade reset** (headline):
                         ``legion_common − habsburg_common``.  Negative = demotion.
                         Keeps the within-OF-1 resolution (podporučík −1 / poručík 0 /
                         nadporučík +1) that the raw NATO code collapses.
        ``{out}_band``   Int64 — **coarse NATO-band reset** (robustness): the same
                         difference on the monotone OF/OR band index; all three
                         subalterns share OF-1, so subaltern↔subaltern → 0.
        ``legion_noncombat`` boolean — the Legion enrolment rank is a non-combat
                         *status* (``pracovník``/``občan``, :data:`NONCOMBAT_STATUS`),
                         not a grade. The reset is still computed; restrict to
                         ``~legion_noncombat`` for the combat-rank specification.
    ``{out}`` / ``{out}_band`` are ``<NA>`` unless *both* sides resolved a rank.

    Args:
        df:              input DataFrame (not modified in place); must carry
                         ``{habsburg_prefix}_common``/``_band`` and
                         ``{legion_prefix}_common``/``_band``.
        habsburg_prefix: prefix of the Habsburg (at-capture) rank columns.
        legion_prefix:   prefix of the Legion (enrolment) rank columns — the
                         *enrolment* rank drives the reset, not the last rank held.
        out:             base name for the two output columns.

    Returns:
        DataFrame with ``{out}`` and ``{out}_band`` appended.
    """
    for pfx in (habsburg_prefix, legion_prefix):
        if missing := [c for c in (f"{pfx}_common", f"{pfx}_band") if c not in df.columns]:
            raise KeyError(
                f"add_rank_reset needs {missing}; run add_rank_columns(prefix={pfx!r}) first."
            )
    df = df.copy()

    hab_c = df[f"{habsburg_prefix}_common"].astype("Int64")
    leg_c = df[f"{legion_prefix}_common"].astype("Int64")
    df[out] = leg_c - hab_c  # <NA> propagates when either side is missing

    hab_b = df[f"{habsburg_prefix}_band"].map(_BAND_ORDER).astype("Int64")
    leg_b = df[f"{legion_prefix}_band"].map(_BAND_ORDER).astype("Int64")
    df[f"{out}_band"] = leg_b - hab_b

    # ``legion_noncombat`` marks records whose Legion *enrolment* rank is a non-combat
    # STATUS (pracovník = labour-service entry track; občan = civilian status), not a
    # combat grade. For these the reset is retained (it is still legion_common −
    # habsburg_common) but flagged: differencing a status against a real officer rank
    # manufactures the extreme "deprivation" (colonel → "labourer" = −16) that the
    # qualitative record does not support as a genuine demotion — the Italian labour
    # battalions were a transitional entry category, and systematic officer degradation
    # was an explicitly-rebutted rumour (reference/VALIDATION_FIDLER.md §3; rank_ladders
    # §H#1). Restrict to ``~legion_noncombat`` for the combat-rank spec; keep the full
    # column as the inclusive robustness variant.
    clean_c = f"{legion_prefix}_clean"
    if clean_c in df.columns:
        # <NA> where no Legion rank resolved: "not a non-combat status" is a claim about a
        # rank, and there is none (v1.4.3, the D-52 rule).
        df["legion_noncombat"] = (df[clean_c].isin(NONCOMBAT_STATUS)
                                  .where(df[clean_c].notna(), pd.NA).astype("boolean"))
    return df

def rank_report(df: pd.DataFrame,
                prefix: str = "habsburg_rank",
                source_col: str | None = None,
                top_n: int = 20,
                system: str = "habsburg") -> None:
    """Print the rank distribution, j.d. share, tier split, and coverage.

    Pass ``source_col`` (the raw column fed to :func:`add_rank_columns`) to get
    matched-record coverage and the top unmatched raw variants — the key QA signal.
    ``system`` selects which ladder labels/ordinals to reindex against.
    """
    _check_system(system)
    order = _ORDER_FOR[system]
    ordinal = _ORDINAL_FOR[system]
    clean_c, ord_c, jd_c, tier_c = (
        f"{prefix}_clean", f"{prefix}_ord", f"{prefix}_jd", f"{prefix}_tier")
    if ord_c not in df.columns:
        print(f"No {ord_c} column. Run add_rank_columns() first.")
        return

    total = len(df)
    matched = int(df[ord_c].notna().sum())
    counts = df[clean_c].value_counts()

    print(f"Rank report [{prefix}]  (N = {total:,})\n")
    print(f"  {'ord':>3}  {'rank':<22} {'n':>8}   share")
    for label in order:
        n = int(counts.get(label, 0))
        if n:
            o = ordinal[label]
            print(f"  {o:>3}  {label:<22} {n:>8,}  ({n/total:.1%})")

    print(f"\n  one-year volunteers (j.d.) : {int(df[jd_c].fillna(False).sum()):,}")
    print("  tier breakdown:")
    for tier, n in df[tier_c].value_counts().items():
        print(f"      {tier:<12} {int(n):>8,}")

    if source_col and source_col in df.columns:
        nn = int(df[source_col].notna().sum())
        cov = matched / nn if nn else 0.0
        print(f"\n  matched / non-null source : {matched:,} / {nn:,}  ({cov:.1%})")
        resid = (
            df.loc[df[clean_c].isna() & df[source_col].notna(), source_col]
            .value_counts().head(top_n)
        )
        if len(resid):
            print(f"\n  top {top_n} unmatched raw variants:")
            for val, n in resid.items():
                print(f"      {n:>6,}  {val}")
    else:
        print(f"\n  matched / total           : {matched:,} / {total:,}  "
              f"({matched/total:.1%})")

"""
ranks.py — Austro-Hungarian (Habsburg) **and** Czechoslovak Legion rank standardisation
=======================================================================================
Collapses the free-text rank fields onto **within-system ordinal** scales — the
k.u.k. *Dienstgrade* hierarchy (``system="habsburg"``, 1–20) and the Czechoslovak
Legion / early-ČSA ladder (``system="legion"``, 1–14). The motivating use is the
thesis's *relative rank deprivation* measure, so the ordinal is the headline output.

⚠️ The two ordinal (``*_ord``) scales are **within-system** and are *not* directly
subtractable (``rank_ladders.md`` intro, §F): a Habsburg *poručík* (ord 10) and a
Legion *poručík* (ord 9) are the **same** OF‑1 grade. The cross-system reset instead
bridges via the shared name-anchored **common** scale (ALT 1, §G): ``add_rank_columns``
also emits ``{prefix}_common`` (system-blind grade) and ``{prefix}_band`` (coarse
NATO OF/OR band), and :func:`add_rank_reset` differences the *common* columns to build
``rank_reset = legion_common − habsburg_common`` (never the within-system ordinals).

The Habsburg ladder is taken from ``reference/ranks/rank_ladders.md`` §A, validated
against the bilingual Czech↔German table in *Pod císařským praporem* p.408:

    1  vojín (+ branch privates)        Infanterist / Kanonier / …
    2  svobodník, nápředník, závodčí    Gefreiter / Oberkanonier / Patrouilleführer
    3  desátník                         Korporal
    4  četař                            Zugsführer
    5  šikovatel, strážmistr            Feldwebel / Wachtmeister
    6  kadet                            Kadett            ┐ officer-candidate band
    7  praporčík                        Fähnrich          │ (6–9 reconstructed —
    8  důstojnický zástupce             Offizierstellvertr│  p.408 treats it as a
    9  kadet-aspirant                   Kadettaspirant    ┘  band, hedge via tier)
    10 poručík                          Leutnant
    11 nadporučík                       Oberleutnant
    12 setník (hejtman/rytmistr/kapitán) Hauptmann
    13 major / 14 podplukovník / 15 plukovník
    16 generálmajor … 20 polní maršál

Design notes
------------
* The ``j.d.`` token (*jednoroční dobrovolník* / Einjährig-Freiwilliger) is a
  **status, not a rank** (§E): it is stripped before matching and returned as a
  boolean flag.
* Progression entries ("podporučík, poručík", "vojín, desátník") keep **both**
  ends: ``*_ord`` = highest reached, ``*_ord_low`` = lowest listed.
* ``podporučík`` is **not** a k.u.k. rank (§A note); under ``system="habsburg"`` it
  is dropped to ``<NA>`` and surfaced in the residual report (do not score it as an
  officer). Under ``system="legion"`` it **is** a real rank (sub-Leutnant, ord 8).
* ``rotmistr`` is likewise **not** a k.u.k. rank (the cavalry captain is *rytmistr*
  = Rittmeister): Habsburg ``rotmistr`` → ``<NA>``; Legion ``rotmistr`` is a senior
  NCO / warrant grade (ord 6, §B).
* Every lookup is keyed by ``system`` (rules, ordinals, drop-tokens, and tiers all
  differ): the §F harmonization trap (*poručík* = Leutnant here but a different OF
  slot in the Legion) is exactly why the two ladders never share a table.
* **Legion generals exist** (ord 15–17, §B-gen) — unlike the Habsburg generals, which
  are in the ladder for completeness at n = 0. Both naming systems occur: Russian
  (*generálmajor*, *generálporučík*) and post-1918 ČSA French (*brigádní/divizní/
  armádní generál*), paired by NATO grade. Bare "generál" is refused (tier, not grade).
* Rule tokens must match at a **word start** (:func:`_at_word_start`). Substring
  matching alone let a longer word silently resolve to a shorter rank it embedded —
  *generálmajor* → major, *generálporučík* → poručík, *aspirant na podporučíka* →
  poručík. Genuine compounds (*nadstrážmistr*, *novobranec*, *nadělostřelec*, …) are
  listed as their own tokens; anything else now surfaces as unresolved instead of
  being assigned a plausible wrong grade.

Usage
-----

def _tier_for(ordinal: int | None, system: str = "habsburg") -> str | None:
    """Coarse tier from a within-system ordinal.

    Habsburg hedges the reconstructed 6–9 candidate band; Legion follows the §B
    tier column (Mužstvo / Poddůstojník / Aspirant / Důstojník / Štábní důstojník).
    """
    if ordinal is None:
        return None
    if system == "legion":
        if ordinal <= 2:
            return "Mužstvo"
        if ordinal <= 6:
            return "Poddůstojník"
        if ordinal == 7:
            return "Aspirant"
        if ordinal <= 11:
            return "Důstojník"
        if ordinal <= 14:
            return "Štábní důstojník"
        return "Generál"
    # habsburg
    if ordinal <= 2:
        return "Mannschaft"
    if ordinal <= 5:
        return "NCO"
    if ordinal <= 9:
        return "Aspirant"
    return "Officer"

def _deaccent(s: str) -> str:
    """Fold Czech diacritics to ASCII and lowercase (šikovatel → sikovatel)."""
    nfkd = unicodedata.normalize("NFKD", str(s))
    return "".join(c for c in nfkd if not unicodedata.combining(c)).lower()


def _strip_jd(norm: str) -> tuple[str, bool]:
    """Remove j.d. tokens from a de-accented string; return (residual, flag)."""
    flag = bool(_JD_RE.search(norm))
    if flag:
        norm = _JD_RE.sub(" ", norm)
    return norm, flag


def _check_system(system: str) -> None:
    if system not in _RULES_FOR:
        raise ValueError(
            f"system must be one of {sorted(_RULES_FOR)}; got {system!r}."
        )

    a rank ("generalmajor" contains "major"; "nadstrazmistr" contains "strazmistr";
    "aspirant na podporucika" contains "porucik"). Unguarded, such a word silently
    resolves to whatever shorter rank it happens to embed — the failure that scored
    Legion generals as majors and lieutenants before v1.4.0.

    Requiring a word start keeps every intended match (a rank word, or one after a
    space/dot/hyphen) and refuses the accidental ones, which then surface as
    unresolved in ``rank_report`` instead of becoming a plausible wrong number.
    Genuine compounds are matched by listing them as their own token.
    """
    return re.search(rf"(?<![a-z0-9]){re.escape(token)}", s) is not None


def _match_token(norm_token: str, rules: list[tuple[str, list[str]]],
                 drops: list[str]) -> str | None:
    """Canonical label for one de-accented, j.d.-stripped token (else None)."""
    for drop in drops:
        if re.search(rf"\b{re.escape(drop)}\b", norm_token):
            return None
    for label, tokens in rules:
        if any(_at_word_start(t, norm_token) for t in tokens):
            return label
    return None


def _branch(norm_full: str) -> str | None:
    for token, branch in _BRANCH_RULES:
        if token.strip() in norm_full:
            return branch
    return None


class _RankParse(NamedTuple):
    clean: str | None
    en: str | None
    ord_high: int | None
    ord_low: int | None
    jd: bool
    branch: str | None
    tier: str | None
    common: int | None       # system-blind ALT-1 common grade (RANK_COMMON)
    band: str | None         # coarse NATO/OF-OR band string (_COMMON_TO_BAND)


def _resolve(s, system: str = "habsburg") -> _RankParse:
    """Parse one raw rank cell into its standardised components."""
    if pd.isna(s) or str(s).strip() in ("", "?", "-"):
        return _RankParse(None, None, None, None, False, None, None, None, None)

    rules = _RULES_FOR[system]
    ordinal = _ORDINAL_FOR[system]
    english = _EN_FOR[system]
    drops = _DROP_FOR[system]

    norm_full, jd = _strip_jd(_deaccent(s))

    labels: list[str] = []
    ords: list[int] = []
    for tok in _SPLIT_RE.split(norm_full):
        tok = tok.strip()
        if not tok:
            continue
        lab = _match_token(tok, rules, drops)
        if lab is not None:
            labels.append(lab)
            ords.append(ordinal[lab])

    branch = _branch(norm_full)

    if not ords:
        return _RankParse(None, None, None, None, jd, branch, None, None, None)

    hi = max(ords)
    lo = min(ords)
    # Several labels share a Legion ordinal but not a common grade (praporčík / kadet /
    # důstojnický zástupce all sit at 7 with common 9 / 7 / 8). Taking the first one listed
    # let word order decide the reset; the highest common grade decides it instead.
    tied = [lab for lab, o in zip(labels, ords) if o == hi]
    clean = max(tied, key=lambda lab: RANK_COMMON.get(lab, -1))
    # System-blind common grade (ALT 1, §G) is keyed on the canonical label, so it
    # is the same lookup for either system — that is the whole point of the bridge.
    common = RANK_COMMON.get(clean)
    return _RankParse(clean, english.get(clean), hi, lo, jd, branch,
                      _tier_for(hi, system), common, _band_for(common))

def add_rank_columns(df: pd.DataFrame,
                     source_col: str = "Hodnost v době zajetí",
                     system: str = "habsburg",
                     prefix: str = "habsburg_rank") -> pd.DataFrame:
    """Append standardised rank columns parsed from ``source_col``.

    Adds (with the given ``prefix``):
        ``{prefix}_clean``    canonical Czech label of the highest rank
        ``{prefix}_en``       English gloss of that label (German term in parens)
        ``{prefix}_ord``      Int64 ordinal of the highest rank (rank reached)
        ``{prefix}_ord_low``  Int64 ordinal of the lowest listed rank
        ``{prefix}_jd``       bool — one-year-volunteer (jednoroční dobrovolník)
        ``{prefix}_branch``   arm of service (sparse) or None
        ``{prefix}_tier``     coarse tier (system-specific labels: Czech / German)
        ``{prefix}_tier_en``  English gloss of the tier (Enlisted / NCO / Officer …)
        ``{prefix}_common``   Int64 system-blind ALT-1 common grade (subtractable
                              across systems; the reset input — §G)
        ``{prefix}_band``     coarse NATO/OF-OR band string (robustness axis)

    Args:
        df:         input DataFrame (not modified in place)
        source_col: raw rank column (Czech, pre-rename) to parse
        system:     rank ladder to use — ``"habsburg"`` (1–20) or ``"legion"`` (1–14)
        prefix:     output column-name prefix

    Returns:
        DataFrame with the ten rank columns appended.
    """
    _check_system(system)
    df = df.copy()

    parsed = df[source_col].apply(lambda s: _resolve(s, system))
    # A blank rank cell says nothing about a one-year volunteer, so the flag is <NA> there,
    # not False (v1.4.3, the D-52 rule); a recorded rank without the marker stays False.
    recorded = df[source_col].notna() & ~df[source_col].astype("string").str.strip().isin(
        ["", "?", "-"]).fillna(False)
    df[f"{prefix}_clean"]   = parsed.map(lambda p: p.clean)
    df[f"{prefix}_en"]      = parsed.map(lambda p: p.en)
    df[f"{prefix}_ord"]     = parsed.map(lambda p: p.ord_high).astype("Int64")
    df[f"{prefix}_ord_low"] = parsed.map(lambda p: p.ord_low).astype("Int64")
    df[f"{prefix}_jd"]      = parsed.map(lambda p: p.jd).where(recorded, pd.NA).astype("boolean")
    df[f"{prefix}_branch"]  = parsed.map(lambda p: p.branch)
    df[f"{prefix}_tier"]    = parsed.map(lambda p: p.tier)
    df[f"{prefix}_tier_en"] = df[f"{prefix}_tier"].map(RANK_TIER_EN)  # English gloss of the tier
    df[f"{prefix}_common"]  = parsed.map(lambda p: p.common).astype("Int64")
    df[f"{prefix}_band"]    = parsed.map(lambda p: p.band)
    return df


def add_rank_reset(df: pd.DataFrame,
                   habsburg_prefix: str = "habsburg_rank",
                   legion_prefix: str = "legion_rank",
                   out: str = "rank_reset") -> pd.DataFrame:
    """Append the cross-system rank-reset variables (the thesis's headline RHS).

    The *relative rank deprivation* upon Legion enrolment: the difference between a
    soldier's **Legion enrolment** rank and his **Habsburg** rank at capture, bridged
    onto the shared ALT-1 common scale (``rank_ladders.md`` §G) so the two
    within-system ordinals become subtractable.  Requires :func:`add_rank_columns`
    to have already produced the ``{prefix}_common`` / ``{prefix}_band`` columns for
    both sides.

    Adds:
        ``{out}``        Int64 — **fine ALT-1 sub-grade reset** (headline):
                         ``legion_common − habsburg_common``.  Negative = demotion.
                         Keeps the within-OF-1 resolution (podporučík −1 / poručík 0 /
                         nadporučík +1) that the raw NATO code collapses.
        ``{out}_band``   Int64 — **coarse NATO-band reset** (robustness): the same
                         difference on the monotone OF/OR band index; all three
                         subalterns share OF-1, so subaltern↔subaltern → 0.
        ``legion_noncombat`` boolean — the Legion enrolment rank is a non-combat
                         *status* (``pracovník``/``občan``, :data:`NONCOMBAT_STATUS`),
                         not a grade. The reset is still computed; restrict to
                         ``~legion_noncombat`` for the combat-rank specification.
    ``{out}`` / ``{out}_band`` are ``<NA>`` unless *both* sides resolved a rank.

    Args:
        df:              input DataFrame (not modified in place); must carry
                         ``{habsburg_prefix}_common``/``_band`` and
                         ``{legion_prefix}_common``/``_band``.
        habsburg_prefix: prefix of the Habsburg (at-capture) rank columns.
        legion_prefix:   prefix of the Legion (enrolment) rank columns — the
                         *enrolment* rank drives the reset, not the last rank held.
        out:             base name for the two output columns.

    Returns:
        DataFrame with ``{out}`` and ``{out}_band`` appended.
    """
    for pfx in (habsburg_prefix, legion_prefix):
        if missing := [c for c in (f"{pfx}_common", f"{pfx}_band") if c not in df.columns]:
            raise KeyError(
                f"add_rank_reset needs {missing}; run add_rank_columns(prefix={pfx!r}) first."
            )
    df = df.copy()

    hab_c = df[f"{habsburg_prefix}_common"].astype("Int64")
    leg_c = df[f"{legion_prefix}_common"].astype("Int64")
    df[out] = leg_c - hab_c  # <NA> propagates when either side is missing

    hab_b = df[f"{habsburg_prefix}_band"].map(_BAND_ORDER).astype("Int64")
    leg_b = df[f"{legion_prefix}_band"].map(_BAND_ORDER).astype("Int64")
    df[f"{out}_band"] = leg_b - hab_b

    # ``legion_noncombat`` marks records whose Legion *enrolment* rank is a non-combat
    # STATUS (pracovník = labour-service entry track; občan = civilian status), not a
    # combat grade. For these the reset is retained (it is still legion_common −
    # habsburg_common) but flagged: differencing a status against a real officer rank
    # manufactures the extreme "deprivation" (colonel → "labourer" = −16) that the
    # qualitative record does not support as a genuine demotion — the Italian labour
    # battalions were a transitional entry category, and systematic officer degradation
    # was an explicitly-rebutted rumour (reference/VALIDATION_FIDLER.md §3; rank_ladders
    # §H#1). Restrict to ``~legion_noncombat`` for the combat-rank spec; keep the full
    # column as the inclusive robustness variant.
    clean_c = f"{legion_prefix}_clean"
    if clean_c in df.columns:
        # <NA> where no Legion rank resolved: "not a non-combat status" is a claim about a
        # rank, and there is none (v1.4.3, the D-52 rule).
        df["legion_noncombat"] = (df[clean_c].isin(NONCOMBAT_STATUS)
                                  .where(df[clean_c].notna(), pd.NA).astype("boolean"))
    return df


def rank_report(df: pd.DataFrame,
                prefix: str = "habsburg_rank",
                source_col: str | None = None,
                top_n: int = 20,
                system: str = "habsburg") -> None:
    """Print the rank distribution, j.d. share, tier split, and coverage.

    Pass ``source_col`` (the raw column fed to :func:`add_rank_columns`) to get
    matched-record coverage and the top unmatched raw variants — the key QA signal.
    ``system`` selects which ladder labels/ordinals to reindex against.
    """
    _check_system(system)
    order = _ORDER_FOR[system]
    ordinal = _ORDINAL_FOR[system]
    clean_c, ord_c, jd_c, tier_c = (
        f"{prefix}_clean", f"{prefix}_ord", f"{prefix}_jd", f"{prefix}_tier")
    if ord_c not in df.columns:
        print(f"No {ord_c} column. Run add_rank_columns() first.")
        return

    total = len(df)
    matched = int(df[ord_c].notna().sum())
    counts = df[clean_c].value_counts()

    print(f"Rank report [{prefix}]  (N = {total:,})\n")
    print(f"  {'ord':>3}  {'rank':<22} {'n':>8}   share")
    for label in order:
        n = int(counts.get(label, 0))
        if n:
            o = ordinal[label]
            print(f"  {o:>3}  {label:<22} {n:>8,}  ({n/total:.1%})")

    print(f"\n  one-year volunteers (j.d.) : {int(df[jd_c].fillna(False).sum()):,}")
    print("  tier breakdown:")
    for tier, n in df[tier_c].value_counts().items():
        print(f"      {tier:<12} {int(n):>8,}")

    if source_col and source_col in df.columns:
        nn = int(df[source_col].notna().sum())
        cov = matched / nn if nn else 0.0
        print(f"\n  matched / non-null source : {matched:,} / {nn:,}  ({cov:.1%})")
        resid = (
            df.loc[df[clean_c].isna() & df[source_col].notna(), source_col]
            .value_counts().head(top_n)
        )
        if len(resid):
            print(f"\n  top {top_n} unmatched raw variants:")
            for val, n in resid.items():
                print(f"      {n:>6,}  {val}")
    else:
        print(f"\n  matched / total           : {matched:,} / {total:,}  "
              f"({matched/total:.1%})")
