Extraction strategy (v1.2.0)

VÚA writes an uncertain birthplace as the string it found on the card, a ?, then a parenthesised candidate list — its own readings, best first — and a second parenthesis of German names aligned with the candidates. The parser:

  1. finds the candidate list: the first top-level paren group holding an item with a place qualifier (okres/okr./o., a statutory-city form, or a land name — the last only when the group follows a ?);
  2. reads the written head (the text before that group) when it carries okres X — the v1.1 behaviour, unchanged — or a statutory-city form, and otherwise reads the first candidate as VÚA's primary reading (a head in the card's own shorthand, Vorlov, okr.Dedlčany ?, yields to VÚA's reading);
  3. with no candidate list at all, reads the string as v1.1 did, extended only by the qualifier forms v1.1 did not know (okr./o., statutory cities, chartered towns).

A reading NAME, QUALIFIER is decomposed by _parse_reading:

============================================= ======================================== qualifier result ============================================= ======================================== okres X / okr. X / o. X municipality NAME, okres X Hlavní město Praha / hl. měs. Praha statutory_city Praha, okres Praha; a Praha XI.-Žižkov NAME → quarter Žižkov, quarter_no XI Zemské hlavní město Brno statutory_city Brno, okres Brno (+ quarter) Město Olomouc (Město Kroměříž) statutory_city Olomouc, okres Olomouc — only for a 1910 Statutarstadt (_STATUTARSTADT); Město Touškov is a town name, not a city Mesto so zriadeným magistrátom X Slovak chartered town X, land Slovakia, no okres Město se zřízeným magistrátem X chartered town X (Mukačevo, Užhorod), land Transleithania, no okres a land (Čechy, Dolní Rakousy…) municipality NAME, land from the name a bare land (Čechy ?) land only, no municipality ============================================= ========================================

v1.1 anchored on the first okres anywhere in the string, so when the first candidate named no okres (Brno, Zemské hlavní město Brno ?; Bratrouchov-Brno, okres Jilemnice ?) it silently took a later candidate's hamlet and okres.

A statutory-city reading's municipality is the quarter when one is named, else the city; the city itself is in {prefix}_statutory_city. Greater Prague (1922), Greater Brno and Greater Olomouc (1919) are post-1910 boundaries, so Praha XI.-Žižkov was a separate 1910 town (okres Žižkov). Writing it as municipality Žižkov, okres Praha — the shape csol.cz uses — lets the existing linker settle it: records_geo's resolve_prague_suburbs moves a curated suburb to its 1910 okres and the twin rule sends Husovice/okres Brno to the rural okres, both keyed on the municipality. A municipality of Praha with the quarter aside would have filed every quarter in the 1910 city. The parser reports what the string says; the 1910 unit is the linker's call.

def german_forms(raw) -> tuple[str, ...]:
    """Every form of the VÚA German list (1.2.3): the first top-level parenthesis that is not the
    candidate list and names no okres, split on ``;`` and on the ``- ?, `` that closes an item
    (``Königreich I.- ?, Königreich II.- ?``); ``dříve:`` prefixes and ``- ?`` tails dropped.
    ``locations``' own ``german`` column keeps the first form only (unchanged)."""
    if raw is None or (not isinstance(raw, str) and pd.isna(raw)):
        return ()
    s = str(raw).strip()
    cand = _find_candidates(s)
    skip = cand[0] if cand else None
    for start, content in _paren_groups(s):
        c = content.strip()
        if start == skip or not c or c == "?" or "okres" in c.lower():
            continue
        out = []
        for item in _split_top(c):
            for part in re.split(r"(?<=\?)\s*,\s*", item):
                part = _DRIVE_RE.sub("", part.strip())
                part = re.sub(r"\s*[-–]\s*\??\s*$", "", part).strip(" ;,?")
                if part and part not in ("-", "?"):
                    out.append(part)
        return tuple(dict.fromkeys(out))
    return ()

"""
locations.py — Place-name decomposition (municipality / okres / land)
=====================================================================
Decomposes a free-text Czech place string into structured components.
Designed for the VÚA ``Místo narození`` / ``Domovem`` fields but kept
dataset-agnostic. (The legionnaire frame writes municipality and okres in two
separate fields and does **not** pass through this parser; ``records_geo`` reads
them directly.)

Runs **after** :func:`utils.parsing.clean.clean_places`, which strips the
trailing ``+`` verification marker but keeps the okres text and German exonym.

Field structure (most→least common)
------------------------------------
    Municipality, okres District (German exonym)
    Municipality, okres District, Slovensko          (Transleithanian)
    Municipality, Zemské hlavní město Brno (German)  (statutory city, no okres)
    Praha XI.-Žižkov, Hlavní město Praha             (a quarter of Prague)
    WRITTEN ? (CAND1 ?; CAND2, okres X ?; ...) (german1 - ?; german2 - ?)
                                                     (VÚA's candidate readings)
    Municipality, Čechy ?                            (land only)

Extraction strategy (v1.2.0)
----------------------------
VÚA writes an uncertain birthplace as the string it found on the card, a ``?``,
then a parenthesised **candidate list** — its own readings, best first — and a
second parenthesis of German names aligned with the candidates. The parser:

1. finds the candidate list: the first top-level paren group holding an item
   with a place qualifier (``okres``/``okr.``/``o.``, a statutory-city form, or a
   land name — the last only when the group follows a ``?``);
2. reads the **written head** (the text before that group) when it carries
   ``okres X`` — the v1.1 behaviour, unchanged — or a statutory-city form, and
   otherwise reads the **first candidate** as VÚA's primary reading (a head in
   the card's own shorthand, ``Vorlov, okr.Dedlčany ?``, yields to VÚA's reading);
3. with no candidate list at all, reads the string as v1.1 did, extended only
   by the qualifier forms v1.1 did not know (``okr.``/``o.``, statutory cities,
   chartered towns).

A reading ``NAME, QUALIFIER`` is decomposed by :func:`_parse_reading`:

=============================================  ========================================
qualifier                                      result
=============================================  ========================================
``okres X`` / ``okr. X`` / ``o. X``            municipality NAME, okres X
``Hlavní město Praha`` / ``hl. měs. Praha``    statutory_city Praha, okres Praha; a
                                               ``Praha XI.-Žižkov`` NAME → quarter
                                               ``Žižkov``, quarter_no ``XI``
``Zemské hlavní město Brno``                   statutory_city Brno, okres Brno (+ quarter)
``Město Olomouc`` (``Město Kroměříž``)         statutory_city Olomouc, okres Olomouc — only
                                               for a 1910 Statutarstadt (``_STATUTARSTADT``);
                                               ``Město Touškov`` is a town name, not a city
``Mesto so zriadeným magistrátom X``           Slovak chartered town X, land Slovakia,
                                               no okres
``Město se zřízeným magistrátem X``            chartered town X (Mukačevo, Užhorod),
                                               land Transleithania, no okres
a land (``Čechy``, ``Dolní Rakousy``…)         municipality NAME, land from the name
a bare land (``Čechy ?``)                      land only, no municipality
=============================================  ========================================

v1.1 anchored on the first ``okres`` *anywhere* in the string, so when the first
candidate named no okres (``Brno, Zemské hlavní město Brno ?; Bratrouchov-Brno,
okres Jilemnice ?``) it silently took a later candidate's hamlet and okres.

A statutory-city reading's **municipality is the quarter when one is named**, else the
city; the city itself is in ``{prefix}_statutory_city``. Greater Prague (1922), Greater
Brno and Greater Olomouc (1919) are post-1910 boundaries, so ``Praha XI.-Žižkov`` was a
separate 1910 town (okres Žižkov). Writing it as municipality *Žižkov*, okres *Praha* —
the shape csol.cz uses — lets the existing linker settle it: ``records_geo``'s
``resolve_prague_suburbs`` moves a curated suburb to its 1910 okres and the twin rule
sends ``Husovice``/okres *Brno* to the rural okres, both keyed on the municipality. A
municipality of *Praha* with the quarter aside would have filed every quarter in the
1910 city. The parser reports what the string says; the 1910 unit is the linker's call.

Columns added by :func:`add_location_columns` (per ``prefix``)
-------------------------------------------------------------
``{prefix}_municipality``     resolved Czech municipality (obec); the quarter of a city
``{prefix}_okres``            political district
``{prefix}_german``           German exonym, if present
``{prefix}_land``             Czech lands / Slovakia / Hungary / Galicia / Austria /
                              Transleithania (provisional; ``records_geo.add_land``
                              replaces it)
``{prefix}_cisleithanian``    bool — eligible for the 1910 Cisleithanian census
``{prefix}_loc_uncertain``    bool — raw contained ``?``
``{prefix}_n_candidates``     int  — VÚA candidate readings in the candidate list; with no
                              list, 1 + the top-level ``;`` count (v1.1 counted every ``;``,
                              the German list's included)
``{prefix}_quarter``          the quarter of a statutory city (``Žižkov``), else <NA>   [1.2]
``{prefix}_quarter_no``       its Roman district number (``XI``), else <NA>            [1.2]
``{prefix}_statutory_city``   the statutory city / chartered town the reading named
                              (``Praha``, ``Brno``, ``Bratislava``…), else <NA>         [1.2]
``{prefix}_loc_reading``      ``head`` / ``candidate`` / <NA> — which reading supplied the
                              municipality + okres (``candidate`` = VÚA's first candidate) [1.2]
``{prefix}_candidates_agree`` bool — every candidate names the same okres; <NA> with no
                              candidate list; False when any candidate names no okres   [1.2]
                              (okresy only: ``Velká Úpa I./II./III., okres Trutnov`` agree)
``{prefix}_candidates_agree_place`` bool — every reading names the same okres *and* the same
                              place (the whole reading — name, numeral, ``s.o.`` court,
                              parenthesised name — compared NFC + case-folded, punctuation
                              dropped, accents and numerals kept); <NA> with no candidate
                              list; False when any candidate names no municipality or okres
                              [1.2.2]. Since 1.2.3 the written head counts as a reading when
                              it is the primary one (``loc_reading = head``): ``Dražov, okres
                              Karlovy Vary ? (Dražov, okres Teplá ?)`` is False
``{prefix}_n_readings``       int  — readings of the place: ``n_candidates`` plus 1 when the
                              written head is the primary reading beside a candidate list [1.2.3],
                              or when an okres reading is followed by a parenthetical holding
                              only another okres and a ``?`` (``Bakov, okr. Náchod? (okr.
                              Slaný?)``: 2; ``candidates_agree_place`` then compares the two
                              okresy) [1.2.4] — as resolved okres ids, so a parenthetical naming
                              the head's own okres is no second reading (1, True) [1.2.5]; the ids
                              from the backbone's tracked inputs, never data/final [1.2.6]

Helpers for the settlement matcher (no column): :func:`german_forms` (every form of the German
list) and :func:`candidate_readings` (``(municipality, okres)`` per candidate) [1.2.3].

from __future__ import annotations

import re
import unicodedata

import pandas as pd

__version__ = "1.2.6"   # the okres lookup built from the backbone's tracked inputs, never data/final

# ── Regexes ───────────────────────────────────────────────────────────────────
# Municipality + okres anchored on "..., okres <name>" (the v1.1 regex, kept verbatim so a
# reading v1.1 parsed comes out identical). The municipality is the token directly before
# ", okres" (no comma/semicolon/paren inside it); the okres runs until a +, (, comma,
# semicolon, or ? terminator.
_OKRES_RE = re.compile(r"([^,;(]+),\s*okres\s+([^+(,;?]+)")

# The okres forms v1.1 did not read: "okr. X", "o. X", the typos "okre X" / "okresa X", and
# (inside one reading only) "X okres Y" with the comma missing.
_OKRES_ABBR_RE = re.compile(r"([^,;(]+),\s*(?:okr\.|o\.|okre\s|okresa\s)\s*([^+(,;?]+)")
_OKRES_NOCOMMA_RE = re.compile(r"^([^,;(]+?)\s+okres\s+([^+(,;?]+)")

# "Úvaly (Garschenthal), okr. Mikulov": a name, a parenthesised (German) name, then the okres
# (1.2.3). _OKRES_RE cannot see past the parenthesis: with "okr." the okres was dropped, with
# "okres" the municipality became "Garschenthal)". The whole string must have this shape.
_PAREN_OKRES_RE = re.compile(
    r"^\s*([^(),;?]+?)\s*\(([^()]*)\)\s*,\s*(?:okres\s+|okr\.\s*|o\.\s+)([^+(),;?]+?)[\s?\-–]*$")

# Parenthetical groups, e.g. "(Bleistadt)" or "(Česká Kamenice, okres Děčín ?)".
_PAREN_RE = re.compile(r"\(([^)]*)\)")

# A closed parenthesis nested inside one reading: "Dražíč-Karlov-Nepomuk (Neponek), okres X".
_NESTED_RE = re.compile(r"\([^()]*\)")

# "dříve: X" (formerly) prefix inside a German exonym parenthetical.
_DRIVE_RE = re.compile(r"^d[řr]íve:\s*", re.IGNORECASE)

# Trailing uncertainty / dash debris on one reading: "Brno ?", "Kozly - ?", "Polsko -".
_TRAIL_RE = re.compile(r"[\s?\-–]+$")

# ── Statutory cities and chartered towns ─────────────────────────────────────
# The 1910 Statutarstädte of the Czech lands besides Prague: exactly the ten "X (město)" units
# of the 1910 political-okres backbone (MPIDR/Rumpler-Seger shapefile, reference/places/mpidr/,
# built by utils.parsing.districts into data/final/geo/districts_1910: okres codes 301-80, 302-5,
# 302-13, 302-15, 302-28, 302-37, 302-42, 303-2, 303-7, 303-11), each its own political okres
# beside the rural one of the same name (records_geo.build_twin_pairs, DECISIONS D-17).
# Lower-cased, every spelling a record may use; tests/test_locations.py holds the list to the
# backbone. Brno is normally written "Zemské hlavní město Brno" (the pattern above it), and
# Liberec (Bohemia) has not been seen in the "Město X" form, but both were Statutarstädte, so a
# "Město Brno" / "Město Liberec" qualifier reads as one.
_STATUTARSTADT: tuple[str, ...] = (
    "brno", "jihlava", "kroměříž", "olomouc", "uherské hradiště", "znojmo",     # Moravia
    "opava", "frýdek", "bílsko", "bielsko", "bielitz",                         # Silesia
    "liberec",                                                                 # Bohemia
)
_STATUTARSTADT_RE = "|".join(re.escape(c) for c in _STATUTARSTADT)

# (pattern on the lower-cased qualifier, city or None = take the captured group, land,
#  okres_is_city). "Hlavní město Praha" is Prague; "Zemské hlavní město" Brno; "Město X" a
# Statutarstadt **only when X is one** (v1.2.1): "Město" is also the first word of ordinary town
# names — "Město Albrechtice", "Město Touškov", "Město Teplá", "Město Libavá" — and v1.2.0 read
# any "…, Město X" qualifier as a statutory city X with okres X, an okres that never existed.
# The two "magistrát" forms are the Hungarian chartered towns (törvényhatósági jogú város):
# Slovak spelling for Bratislava/Košice, Czech spelling for the Subcarpathian Mukačevo/Užhorod —
# those get no okres, since the Slovak side resolves the town by name (``records_geo_hu``).
_STATUTORY: list[tuple[re.Pattern, str | None, str | None, bool]] = [
    (re.compile(r"^(?:hlavní\s+město|hl\.\s*(?:měs|mšs|město)\.?)\s*praha\b"),
     "Praha", None, True),
    (re.compile(r"^zemské\s+hlavní\s+město\s+(\S.*)$"), None, None, True),
    (re.compile(r"^m[ěe]sto\s+so\s+zr[i]?adeným\s+magistrátom\s+(\S.*)$"),
     None, "Slovakia", False),
    (re.compile(r"^město\s+se\s+zřízeným\s+magistrátem\s+(\S.*)$"),
     None, "Transleithania", False),
    (re.compile(rf"^město\s+(?=(?:{_STATUTARSTADT_RE})(?![^\W\d_]))(\S.*)$"), None, None, True),
]

# "Praha XI.-Žižkov" → ("XI", "Žižkov"); "Praha I." → ("I", ""). The number needs its dot
# (or a following dash) so "Praha-Vinohrady" is not read as district V.
_ROMAN_RE = re.compile(r"^\s*([IVXL]+)(?:\.|(?=\s*[-–]))\s*[-–]?\s*(.*)$", re.IGNORECASE)

# ── Land names that may stand as a qualifier or alone ────────────────────────
# Exact (lower-cased) names. ``None`` = a foreign country the land scheme has no label for:
# the reading is still a land reading (no okres), and the land falls back to the v1.1
# whole-string keyword classification.
_LAND_NAMES: dict[str, str | None] = {
    "čechy": "Czech lands", "morava": "Czech lands", "slezsko": "Czech lands",
    "rakouské slezsko": None,    # Bielsko, Biała: v1.1 read "rakous" → Austria; kept
    "slovensko": "Slovakia", "podkarpatská rus": "Transleithania",
    "uhry": "Hungary", "uhersko": "Hungary", "maďarsko": "Hungary",
    "halič": "Galicia",
    "rakousko": "Austria", "rakousy": "Austria", "dolní rakousy": "Austria",
    "horní rakousy": "Austria", "štýrsko": "Austria", "korutany": "Austria",
    "tyrolsko": "Austria", "tyroly": "Austria",
    "německo": None, "sasko": None, "bavorsko": None, "prusko": None, "polsko": None,
    "rusko": None, "srbsko": None, "bosna": None,
}


# ── Land classification ───────────────────────────────────────────────────────
# Ordered (pattern, land); first hit wins.  Default → "Czech lands".
# Note: a "(dříve: <Magyar name>)" rename marker reliably flags a formerly-
# Hungarian (Slovak / Subcarpathian) place even when no explicit land is named
# — checked after the explicit Slovakia/Hungary tags so those stay precise.
#
# Every pattern must start a word (v1.1.0). The bare substring "uhersk" read the
# Moravian okres Uherské Hradiště and Uherský Brod as Hungary — 1,747 VÚA births
# flagged not-Cisleithanian (audit 2026-09-22 §A7). Hungary is now the noun
# (Uhry / Uhersko / Maďarsko), never the adjective a Moravian town name carries.
# (This land is provisional anyway: records_geo.add_land replaces it and
# re-derives the cisleithanian flag from the corrected value.)
_LAND_KEYWORDS: list[tuple[str, str]] = [
    (r"slovensk\w*", "Slovakia"),
    (r"uhry|uhrách|uhersko|uhersku", "Hungary"),
    (r"maďarsk\w*|maďar|maďaři", "Hungary"),
    (r"dříve", "Transleithania"),
    (r"halič\w*", "Galicia"),
    (r"rakous\w*", "Austria"),
    (r"štýrsk\w*", "Austria"),
    (r"korut\w*", "Austria"),
    (r"tyrol\w*", "Austria"),
]
_LAND_RES = [(re.compile(rf"(?<![^\W\d_])(?:{pat})(?![^\W\d_])"), land)
             for pat, land in _LAND_KEYWORDS]

# Lands outside Cisleithania (the Hungarian half) — excluded from the 1910
# Cisleithanian census.  "Transleithania" = Slovak / Subcarpathian places
# detected only via the rename marker or a Subcarpathian qualifier.
_TRANSLEITHANIAN = {"Slovakia", "Hungary", "Transleithania"}


def _classify_land(low: str) -> str:
    for rx, land in _LAND_RES:
        if rx.search(low):
            return land
    return "Czech lands"


# ── String structure ──────────────────────────────────────────────────────────

def _paren_groups(s: str) -> list[tuple[int, str]]:
    """Top-level paren groups as ``(start index, content)``; nesting kept inside the content.

    Tolerant of VÚA's malformed strings: a stray ``)`` is ignored, an unclosed group runs to
    the end of the string.
    """
    groups: list[tuple[int, str]] = []
    depth, start = 0, -1
    for i, ch in enumerate(s):
        if ch == "(":
            if depth == 0:
                start = i
            depth += 1
        elif ch == ")" and depth:
            depth -= 1
            if depth == 0:
                groups.append((start, s[start + 1:i]))
    if depth:
        groups.append((start, s[start + 1:]))
    return groups


def _split_top(text: str) -> list[str]:
    """Split *text* on ``;`` outside parentheses."""
    out, depth, cur = [], 0, []
    for ch in text:
        if ch == "(":
            depth += 1
        elif ch == ")" and depth:
            depth -= 1
        if ch == ";" and depth == 0:
            out.append("".join(cur))
            cur = []
        else:
            cur.append(ch)
    out.append("".join(cur))
    return out


def _empty_reading() -> dict:
    return {"kind": "empty", "municipality": pd.NA, "okres": pd.NA, "quarter": pd.NA,
            "quarter_no": pd.NA, "land": None, "statutory_city": pd.NA}


def _okres_reading(m: re.Match) -> dict:
    """An ``okres`` reading from an okres-regex match, with v1.1's cleanup."""
    out = _empty_reading()
    out.update(kind="okres", municipality=m.group(1).strip().strip("?").strip() or pd.NA,
               okres=m.group(2).strip().strip("?").strip() or pd.NA)
    return out


def _clean_okres(v) -> object:
    """Drop the debris v1.1 left on an okres: ``"Žamberk -"`` (from ``+- ?``), ``"Znojmo)"``."""
    if pd.isna(v):
        return pd.NA
    s = _TRAIL_RE.sub("", str(v).replace(")", " ")).strip()
    return s or pd.NA


def _split_quarter(name: str, city: str) -> tuple[object, object]:
    """``("Praha XI.-Žižkov", "Praha")`` → ``("Žižkov", "XI")``; the city itself → (NA, NA)."""
    name = name.strip()
    if name.casefold() == city.casefold():
        return pd.NA, pd.NA
    if name.casefold().startswith(city.casefold()):
        rest = name[len(city):]
        m = _ROMAN_RE.match(rest)
        if m:
            return (_TRAIL_RE.sub("", m.group(2)).strip() or pd.NA), m.group(1).upper()
        rest = _TRAIL_RE.sub("", rest).strip().lstrip("-–").strip()
        return (rest or pd.NA), pd.NA
    return (_TRAIL_RE.sub("", name).strip() or pd.NA), pd.NA


def _statutory_reading(name: str, qual: str):
    """A statutory-city / chartered-town reading, or ``None`` if *qual* is not one."""
    for rx, city, land, okres_is_city in _STATUTORY:
        m = rx.match(qual.casefold())          # casefold keeps these Czech letters' offsets
        if not m:
            continue
        if city is None:                       # take the city from the qualifier itself,
            city = qual[m.start(1):]           # in its original casing
            city = re.split(r"[/(]", _TRAIL_RE.sub("", city))[0].strip()
        quarter, number = _split_quarter(name, city)
        out = _empty_reading()
        # the municipality is the quarter when there is one: the city/okres pair is what the
        # twin rule and resolve_prague_suburbs key on (Žižkov, okres Praha → okres Žižkov)
        out.update(kind="statutory", municipality=city if pd.isna(quarter) else quarter,
                   quarter=quarter, quarter_no=number, statutory_city=city,
                   okres=city if okres_is_city else pd.NA, land=land)
        return out
    return None


def _parse_reading(text: str) -> dict:
    """Decompose one reading ``NAME, QUALIFIER ?`` (a written head or one candidate).

    ``kind`` is ``okres`` / ``statutory`` / ``land`` (a land qualifier or a bare land) /
    ``bare`` (a name with no recognised qualifier) / ``empty``.
    """
    t = _NESTED_RE.sub(" ", text)              # "Dražíč-Karlov-Nepomuk (Neponek), okres X"
    t = re.sub(r",\s*,", ",", t)               # "Martinovice, (Martinowitz), okres Jičín"
    t = _TRAIL_RE.sub("", t.split("(", 1)[0]).strip()
    if not t or t in ("-", "?"):
        return _empty_reading()
    out = _empty_reading()
    m = _OKRES_RE.search(t) or _OKRES_ABBR_RE.search(t) or _OKRES_NOCOMMA_RE.search(t)
    if m:
        return _okres_reading(m)
    if "," not in t:
        if t.casefold() in _LAND_NAMES:
            out.update(kind="land", land=_LAND_NAMES[t.casefold()])
            return out
        out.update(kind="bare", municipality=t.strip("?").strip() or pd.NA)
        return out
    name, qual = (p.strip() for p in t.split(",", 1))
    qual = _TRAIL_RE.sub("", qual).strip()
    stat = _statutory_reading(name, qual)
    if stat is not None:
        return stat
    if qual.casefold() in _LAND_NAMES:
        out.update(kind="land", municipality=name.strip("?").strip() or pd.NA,
                   land=_LAND_NAMES[qual.casefold()])
        return out
    out.update(kind="bare", municipality=name.strip("?").strip() or pd.NA)
    return out


# A German-list item: "Brünn - ?", "Pern-?", "dříve: Szalatna - ?", "nesprávně: X".
_GERMAN_ITEM_RE = re.compile(r"[-–]\s*\?\s*$|^\s*(?:d[řr]íve|nesprávně|správně)\s*:")

# VÚA closes its own readings with a spaced " ?"; the card's shorthand writes "Přimda?".
_VUA_Q_RE = re.compile(r"\s\?\s*$")


def _is_vua_form(item: str) -> bool:
    """A reading in VÚA's own standard form: ``X, okres Y`` or a statutory-city form."""
    return (bool(_OKRES_RE.search(_NESTED_RE.sub(" ", item)))
            or _parse_reading(item)["kind"] == "statutory")


def _is_candidate_list(s: str, start: int, items: list[str]) -> bool:
    """Is the group at *start* (non-empty *items*) VÚA's candidate list?

    Yes when any item is in VÚA's standard form (``okres Y`` / statutory city) — wherever
    the group stands, as v1.1's "first okres anywhere" assumed. A group right after the
    written head's spaced ``?`` is one too when an item carries ``o.``/``okr.`` or a land,
    or when every item is a bare name closed by its own spaced ``?`` and none looks like a
    German-list item (``(Železná Ruda Městys ?; Železná Ruda Ves ?)``). The transcriber's
    own alternatives, ``Neustadtl, okr. Přimda? (Česká Lípa?)``, are not candidates.
    """
    if any(_is_vua_form(it) for it in items):
        return True
    if not _VUA_Q_RE.search(s[:start]):
        return False
    kinds = [_parse_reading(it)["kind"] for it in items]
    if "okres" in kinds or "land" in kinds:
        return True
    return all(_VUA_Q_RE.search(it) and not _GERMAN_ITEM_RE.search(it) for it in items)


def _find_candidates(s: str) -> tuple[int, list[str]] | None:
    """The candidate list: ``(start index, items)`` of the first group that is one."""
    for start, content in _paren_groups(s):
        items = [it for it in _split_top(content) if _TRAIL_RE.sub("", it).strip()]
        if items and _is_candidate_list(s, start, items):
            return start, items
    return None


def _candidates_agree(items: list[str]) -> bool:
    """Every candidate names the same okres (and every one names an okres). Not the same
    *place*: ``Velká Úpa I.``/``II.``/``III.``, all okres Trutnov, agree here."""
    okresy = [_parse_reading(it)["okres"] for it in items]
    if any(pd.isna(o) for o in okresy):
        return False
    return len({str(o).casefold() for o in okresy}) == 1


def _place_key(text) -> str | None:
    """A candidate reading for comparison: NFC, case-folded, every run of non-word characters
    (``.``, ``-``, ``,``, ``?``, parens, spaces) one space. **Accents and numerals kept**:
    ``Velká Úpa I.`` → ``velká úpa i``, distinct from ``velká úpa ii``; a pure accent difference
    counts as a different place, so the flag errs towards *disagree*."""
    if pd.isna(text):
        return None
    key = re.sub(r"[\W_]+", " ", unicodedata.normalize("NFC", str(text)).casefold()).strip()
    return key or None


def _candidates_agree_place(items: list[str]) -> bool:
    """Every candidate names the same place: the same okres (:func:`_candidates_agree`), a
    municipality in every reading, and one :func:`_place_key` of the **whole** reading.

    The whole reading, not the parsed municipality: VÚA tells same-named places in one okres
    apart by what it writes beside the name — a numeral (``Velká Úpa I.``/``II.``), a court
    before or after the okres (``Nová Ves, s.o. Soběslav, okres Tábor``; ``Vlkonice, okres
    Strakonice, s.o. Volyně``), a German name in parens (``Skleněné Hutě, okres Kaplice
    (Glashütten)``/``(Bonaventura)``) — and the okres regex reads ``Nová Ves, s.o. Tábor`` as
    municipality ``s.o. Tábor``. Any written difference therefore counts as a different place;
    the flag errs towards *disagree*."""
    if not _candidates_agree(items):
        return False
    if any(pd.isna(_parse_reading(it)["municipality"]) for it in items):
        return False
    return len({_place_key(it) for it in items}) == 1


_OKR_WORD_RE = re.compile(r"\bokr\.\s*|\bo\.\s+(?=\w)", re.IGNORECASE)


def _reading_key(text) -> str | None:
    """:func:`_place_key` of a whole reading, ``okr.`` / ``o.`` written out as ``okres``."""
    return _place_key(_OKR_WORD_RE.sub("okres ", str(text))) if not pd.isna(text) else None


def _head_agrees(head: str, items: list[str]) -> bool:
    """The written head, when it is the primary reading, names the same place as every candidate:
    the whole reading compared (:func:`_reading_key`), so ``Dražov, okres Karlovy Vary`` and
    ``Dražov, okres Teplá`` differ, and ``Čivice`` / ``Staré Čivice`` differ (1.2.3)."""
    h = _reading_key(_TRAIL_RE.sub("", head).strip())
    return h is not None and all(_reading_key(_TRAIL_RE.sub("", it).strip()) == h for it in items)


def _n_readings(cand, source) -> int | None:
    """``n_candidates``, plus 1 when the written head is the primary reading beside a list."""
    if cand is None:
        return None
    return len(cand[1]) + (1 if source == "head" else 0)


# "(okr. Slaný?)", "(okres Hodonín - ?)": a parenthetical holding only an okres and a "?" (1.2.4)
_OKRES_ONLY_RE = re.compile(r"^\s*(?:okres\s+|okr\.\s*|o\.\s+)([^(),;?+]+?)[\s\-–+]*\?[\s?\-–]*$",
                            re.IGNORECASE)


def okres_only_alternative(s: str) -> str | None:
    """The okres of the first top-level parenthetical that holds only an okres and a ``?``
    (``Bakov, okr. Náchod? (okr. Slaný?)`` → ``Slaný``), else ``None`` (1.2.4). Without the ``?`` a
    parenthesised okres is VÚA's modern okres (``Drbalovice, okres Boskovice (okres Blansko)``), not
    an alternative."""
    for _start, content in _paren_groups(s):
        m = _OKRES_ONLY_RE.match(content)
        if m:
            return m.group(1).strip() or None
    return None


# 1.2.5: the okres-only alternative is compared with the head's okres as resolved 1910 okres ids.
_OKRES_LOOKUP: dict = {}

#: this (rapidfuzz ratio, 0-100) against one of that okres's own names: Frümvaldau / Freiwaldau 70

def set_okres_lookup(districts: pd.DataFrame | None) -> None:
    """Resolve okres names in :func:`same_okres` against *districts* (the ``districts_1910``
    backbone); ``None`` switches the comparison back to text (1.2.4). Without a call the backbone is
    built once from its tracked inputs (:func:`backbone_districts`, 1.2.6; 1.2.5 read
    ``data/final/geo/districts_1910.parquet``, which notebook 02 §3a writes only after §2 parses)."""
    _OKRES_LOOKUP.clear()
    _OKRES_LOOKUP["set"] = True
    if districts is None:
        _OKRES_LOOKUP["lut"] = None
        return
    from utils.parsing import records_geo as rg          # lazy: records_geo does not import this module
    lut = rg.build_okres_lookup(districts)
    names: dict[int, set[str]] = {}
    for k, (oid, _level) in lut.items():
        names.setdefault(oid, set()).add(k)
    _OKRES_LOOKUP.update(lut=lut, nospace=rg._nospace_index(lut), names=names)


def _okres_lookup() -> dict | None:
    if "set" not in _OKRES_LOOKUP:
        set_okres_lookup(backbone_districts())
    return _OKRES_LOOKUP if _OKRES_LOOKUP.get("lut") is not None else None


def okres_id_of(name) -> int | None:
    """The 1910 okres id an okres string names: an okres or court name of the backbone (Czech, German
    or modern), as written, without a ``venkov``/``okolí`` suffix, or space-free; else ``None``
    (1.2.5)."""
    lk = _okres_lookup()
    if lk is None or name is None or pd.isna(name):
        return None
    from utils.parsing import records_geo as rg
    k = rg._norm(_clean_okres(name))
    if not k:
        return None
    for kk in (k, rg._RURAL_SUFFIX.sub("", k).strip()):
        hit = lk["lut"].get(kk) or lk["nospace"].get(kk.replace(" ", ""))
        if hit is not None:
            return hit[0]
    return None


def same_okres(head_okres, alt_okres) -> bool:
    """Do the head's okres and an okres-only alternative name one okres (1.2.5)? Compared as resolved
    1910 okres ids, so *Göding* and *Hodonín* are one; a head that resolves to nothing is the
    alternative's okres when it scores >= :data:`SAME_OKRES_MIN_RATIO` against one of that okres's
    names (*Frümvaldau* / *Freiwaldau*). An alternative that resolves to nothing, or no backbone at
    all: the 1.2.4 text comparison."""
    lk = _okres_lookup()
    text_same = _place_key(alt_okres) == _place_key(_clean_okres(head_okres))
    if lk is None:
        return text_same
    a, h = okres_id_of(alt_okres), okres_id_of(head_okres)
    if a is not None and h is not None:
        return a == h
    if a is None:
        return text_same
    from rapidfuzz import fuzz
    from utils.parsing import records_geo as rg
    k = rg._norm(_clean_okres(head_okres))
    return bool(k) and max(fuzz.ratio(k, n) for n in lk["names"][a]) >= SAME_OKRES_MIN_RATIO


def german_forms(raw) -> tuple[str, ...]:
    """Every form of the VÚA German list (1.2.3): the first top-level parenthesis that is not the
    candidate list and names no okres, split on ``;`` and on the ``- ?, `` that closes an item
    (``Königreich I.- ?, Königreich II.- ?``); ``dříve:`` prefixes and ``- ?`` tails dropped.
    ``locations``' own ``german`` column keeps the first form only (unchanged)."""
    if raw is None or (not isinstance(raw, str) and pd.isna(raw)):
        return ()
    s = str(raw).strip()
    cand = _find_candidates(s)
    skip = cand[0] if cand else None
    for start, content in _paren_groups(s):
        c = content.strip()
        if start == skip or not c or c == "?" or "okres" in c.lower():
            continue
        out = []
        for item in _split_top(c):
            for part in re.split(r"(?<=\?)\s*,\s*", item):
                part = _DRIVE_RE.sub("", part.strip())
                part = re.sub(r"\s*[-–]\s*\??\s*$", "", part).strip(" ;,?")
                if part and part not in ("-", "?"):
                    out.append(part)
        return tuple(dict.fromkeys(out))
    return ()


# "s.o. Mohelnice": a court (soudní okres) the okres regex takes for the municipality (1.2.4)
_COURT_WORD_RE = re.compile(r"^s\.\s*o\.\s", re.IGNORECASE)


def candidate_readings(raw, with_text: bool = False) -> tuple[tuple, ...]:
    """``(municipality, okres)`` of every reading in VÚA's candidate list, in order (1.2.3); ``()``
    with no list. Missing pieces are ``None``. Since 1.2.4 a reading ``X, s.o. C, okres Y`` gives
    municipality X, not the court ``s.o. C`` the okres regex takes (``Vyšehoří, s.o. Mohelnice,
    okres Zábřeh``); this helper only — the ``municipality`` column keeps the v1.1 reading.
    With *with_text* (1.2.5) each is ``(municipality, okres, text)``, *text* the reading as written
    (``Rokytnice nad Jizerou-Horní Rokytnice, okrese Jilemnice ?``: an okres the regex misses)."""
    if raw is None or (not isinstance(raw, str) and pd.isna(raw)):
        return ()
    cand = _find_candidates(str(raw).strip())
    if cand is None:
        return ()
    out = []
    for it in cand[1]:
        r = _parse_reading(it)
        m, o = r["municipality"], _clean_okres(r["okres"])
        if not pd.isna(m) and _COURT_WORD_RE.match(str(m)):
            head = _TRAIL_RE.sub("", _NESTED_RE.sub(" ", it).split(",", 1)[0]).strip()
            m = pd.NA if not head or _COURT_WORD_RE.match(head) else head
        pair = (None if pd.isna(m) else str(m), None if pd.isna(o) else str(o))
        out.append((*pair, it.strip()) if with_text else pair)
    return tuple(out)


def _german(s: str, skip_start: int | None) -> object:
    """German exonym: first paren group with no "okres", not just "?", not the candidate list."""
    for m in _PAREN_RE.finditer(s):
        if skip_start is not None and m.start() == skip_start:
            continue
        c = m.group(1).strip()
        if not c or c == "?" or "okres" in c.lower():
            continue
        c = _DRIVE_RE.sub("", c)               # drop "dříve:" prefix
        c = re.split(r"\s*[-–]\s*\?", c)[0]    # drop trailing " - ?" uncertainty
        c = c.strip().strip(";").strip()
        if c and c != "?":
            return c
    return pd.NA


# ── Core parser ───────────────────────────────────────────────────────────────

def _primary_reading(s: str, cand: tuple[int, list[str]] | None) -> tuple[dict, object]:
    """VÚA's primary reading of *s* and where it came from (``head`` / ``candidate``)."""
    if cand is not None:
        head = s[:cand[0]]
        m = _OKRES_RE.search(head)
        if m:                                  # the written head carries "okres": v1.1
            return _okres_reading(m), "head"
        # a head in the card's own shorthand ("Vorlov, okr.Dedlčany ?") yields to a VÚA-form
        # reading of it, as under v1.1; a statutory-city head is taken as written
        h = _parse_reading(head)
        if h["kind"] == "statutory" or (
                h["kind"] == "okres" and not any(_is_vua_form(it) for it in cand[1])):
            return h, "head"
        return _parse_reading(cand[1][0]), "candidate"
    # no candidate list: "X (German), okr. Z" (1.2.3), else v1.1 (first "okres" anywhere), else
    # the head's own qualifier
    m = _PAREN_OKRES_RE.match(s)
    if m:
        r = _empty_reading()
        r.update(kind="okres", municipality=m.group(1).strip() or pd.NA,
                 okres=m.group(3).strip() or pd.NA)
        return r, "head"
    m = _OKRES_RE.search(s)
    if m:
        return _okres_reading(m), "head"
    head = s.split("(", 1)[0]
    h = _parse_reading(head)
    if h["kind"] in ("okres", "statutory", "land"):
        return h, "head"
    r = _empty_reading()
    r.update(kind="bare",
             municipality=head.split(",", 1)[0].strip().strip("?").strip() or pd.NA)
    return r, "head"


def parse_location(raw) -> dict:
    """Decompose a raw place string into structured components.

    Returns a dict with keys ``municipality``, ``okres``, ``german``, ``land``,
    ``cisleithanian``, ``uncertain``, ``n_candidates``, ``quarter``, ``quarter_no``,
    ``statutory_city``, ``reading``, ``candidates_agree``, ``candidates_agree_place``.  Missing
    pieces are ``pd.NA``.
    """
    blank = {
        "municipality": pd.NA, "okres": pd.NA, "german": pd.NA,
        "land": pd.NA, "cisleithanian": pd.NA,
        "uncertain": False, "n_candidates": 0,
        "quarter": pd.NA, "quarter_no": pd.NA, "statutory_city": pd.NA,
        "reading": pd.NA, "candidates_agree": pd.NA, "candidates_agree_place": pd.NA,
        "n_readings": 0,
    }
    if pd.isna(raw):
        return blank
    s = str(raw).strip()
    if not s:
        return blank

    cand = _find_candidates(s)
    reading, source = _primary_reading(s, cand)

    # land: the primary reading's own land qualifier, else v1.1's whole-string keywords
    land = reading["land"] or _classify_land(s.lower())

    def _norm(v):
        return pd.NA if (pd.isna(v) or str(v).strip() in ("", "?")) else v

    n_candidates = len(cand[1]) if cand else len(_split_top(s))
    agree_place = pd.NA
    n_readings = _n_readings(cand, source) if cand else n_candidates
    if cand:
        agree_place = _candidates_agree_place(cand[1])
        if source == "head":              # 1.2.3: the written head is a reading too
            agree_place = agree_place and _head_agrees(s[:cand[0]], cand[1])
    elif reading["kind"] == "okres" and not pd.isna(reading["okres"]):
        alt = okres_only_alternative(s)   # 1.2.4: "Bakov, okr. Náchod? (okr. Slaný?)"
        if alt is not None:
            # 1.2.5: a parenthetical naming the head's own okres (German or Czech) is no second reading
            agree_place = same_okres(reading["okres"], alt)
            n_readings = n_candidates + (0 if agree_place else 1)
    return {
        "municipality": _norm(reading["municipality"]),
        "okres": _clean_okres(_norm(reading["okres"])),
        "german": _german(s, cand[0] if cand else None),
        "land": land,
        "cisleithanian": land not in _TRANSLEITHANIAN,
        "uncertain": "?" in s,
        "n_candidates": n_candidates,
        "quarter": _norm(reading["quarter"]),
        "quarter_no": _norm(reading["quarter_no"]),
        "statutory_city": _norm(reading["statutory_city"]),
        "reading": source,
        "candidates_agree": _candidates_agree(cand[1]) if cand else pd.NA,
        "candidates_agree_place": agree_place,
        "n_readings": n_readings,
    }


# ── DataFrame helper ──────────────────────────────────────────────────────────

# parse_location key → column suffix, in output order (the v1.1 seven first, unchanged).
_COLUMNS: list[tuple[str, str]] = [
    ("municipality", "municipality"), ("okres", "okres"), ("german", "german"),
    ("land", "land"), ("cisleithanian", "cisleithanian"), ("uncertain", "loc_uncertain"),
    ("n_candidates", "n_candidates"),
    ("quarter", "quarter"), ("quarter_no", "quarter_no"), ("statutory_city", "statutory_city"),
    ("reading", "loc_reading"), ("candidates_agree", "candidates_agree"),
    ("candidates_agree_place", "candidates_agree_place"), ("n_readings", "n_readings"),
]


def add_location_columns(
    df: pd.DataFrame,
    source_col: str,
    prefix: str,
) -> pd.DataFrame:
    """Append decomposed location columns for *source_col* under *prefix*.

    Adds the v1.1 columns ``{prefix}_municipality``, ``_okres``, ``_german``, ``_land``,
    ``_cisleithanian``, ``_loc_uncertain``, ``_n_candidates`` and the v1.2 columns
    ``_quarter``, ``_quarter_no``, ``_statutory_city``, ``_loc_reading``, ``_candidates_agree``,
    the v1.2.2 ``_candidates_agree_place`` and the v1.2.3 ``_n_readings``.
    No-op if *source_col* is absent.
    """
    df = df.copy()
    if source_col not in df.columns:
        return df

    parsed = df[source_col].map(parse_location)
    for key, suffix in _COLUMNS:
        df[f"{prefix}_{suffix}"] = parsed.map(lambda d, k=key: d[k])
    for flag in ("candidates_agree", "candidates_agree_place"):
        df[f"{prefix}_{flag}"] = df[f"{prefix}_{flag}"].astype("boolean")
    return df


def location_report(df: pd.DataFrame, prefix: str) -> None:
    """Print coverage and land breakdown for a parsed location prefix."""
    muni = f"{prefix}_municipality"
    okr  = f"{prefix}_okres"
    if okr not in df.columns:
        raise ValueError(f"Run add_location_columns(df, ..., prefix='{prefix}') first.")

    n = len(df)
    n_muni = int(df[muni].notna().sum())
    n_okr  = int(df[okr].notna().sum())
    n_unc  = int(df[f"{prefix}_loc_uncertain"].sum())
    n_cis  = int((df[f"{prefix}_cisleithanian"] == True).sum())  # noqa: E712

    print(f"Location report [{prefix}]  (N = {n:,})\n")
    print(f"  municipality non-null : {n_muni:>9,}  ({n_muni/n:.1%})")
    print(f"  okres non-null        : {n_okr:>9,}  ({n_okr/n:.1%})")
    print(f"  marked uncertain (?)  : {n_unc:>9,}  ({n_unc/n:.1%})")
    print(f"  Cisleithanian (census): {n_cis:>9,}  ({n_cis/n:.1%})")

    if f"{prefix}_loc_reading" in df.columns:
        agree = df[f"{prefix}_candidates_agree"]
        n_list = int(agree.notna().sum())
        n_cand = int((df[f"{prefix}_loc_reading"] == "candidate").sum())
        n_dis = int((agree == False).sum())  # noqa: E712
        n_stat = int(df[f"{prefix}_statutory_city"].notna().sum())
        n_qtr = int(df[f"{prefix}_quarter"].notna().sum())
        print(f"  VÚA candidate list    : {n_list:>9,}  ({n_list/n:.1%})")
        print(f"    read off candidate 1: {n_cand:>9,}")
        print(f"    candidates disagree : {n_dis:>9,}  (okres differs or unnamed)")
        if f"{prefix}_candidates_agree_place" in df.columns:
            place = df[f"{prefix}_candidates_agree_place"]
            n_okres_only = int(((agree == True) & (place == False)).sum())  # noqa: E712
            print(f"    same okres, places differ: {n_okres_only:>4,}  (Velká Úpa I./II./III.)")
        print(f"  statutory-city form   : {n_stat:>9,}  (with a quarter: {n_qtr:,})")

    print("\n  Land breakdown:")
    print(df[f"{prefix}_land"].value_counts(dropna=False).to_string())

    print(f"\n  Top 15 {prefix} okres:")
    print(df[okr].value_counts().head(15).to_string())
