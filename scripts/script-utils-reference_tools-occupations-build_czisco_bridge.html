How it works

Why it matters: every HISCO code here is reached through a German gloss (obuvník → Schuhmacher) that this project wrote. Both existing external checks inherit that weakness — the History of Work link bridge starts from our gloss, and OccCANINE had to be fed our gloss because Czech is not among its 13 training languages. Neither validates the claim "this Czech word means that occupation". CZ-ISCO does, because the Czech statistical office publishes the Czech and the English label under the same code.

Two structural facts decide how it can be used, both asserted below:

  • KLAS80146_CS.csv and KLAS80146_EN.csv join 1:1 on chodnota — 1,991 codes over five levels.
  • English labels exist only at levels 1–4 (617 codes). All 1,374 five-digit national codes — the ones carrying actual trade names like Zámečníci strojů — have an empty text. They inherit English from their 4-digit ISCO-08 parent through nadvaz, which resolves for every one of them. So the bridge is Czech trade name → official English at ISCO-08 granularity, not at the Czech national level.

What this is not: a source of HISCO codes. CZ-ISCO is the 2025 classification and the historical core of this corpus is simply absent from it — rolník, hajný, příručí, tkadlec, mlynář, kolář, bednář, cihlář, havíř and soustružník have no label at any level. Nor is there a path to HISCO: ISCO.pdf is ILO's ISCO-08 Volume I, whose correspondence tables reach ISCO-88, while HISCO is built on ISCO-68. Chaining two lossy crosswalks across forty years of occupational change, into a scheme designed for 1690–1970 data, would manufacture precision the sources do not carry. CZ-ISCO corroborates a reading; it never assigns a code.

def head_nouns(label: str) -> list[tuple[str, bool]]:
    """(head noun, is phrase-initial) for every coordinate phrase in a CZ-ISCO label.

    ``Stavební zámečníci`` -> ``zámečníci``   (leading adjective stripped)
    ``Zámečníci strojů``   -> ``zámečníci``   (genitive complement follows the head)
    ``Obchodní náměstci``  -> ``náměstci``    (so ``obchodník`` does *not* match)
    ``Řídící pracovníci ve studentských ubytovnách`` -> ``pracovníci``
        (so ``student`` does *not* match — the failure this rule exists to prevent)
    ``Kováři, nástrojaři a příbuzní pracovníci`` -> three heads

    A phrase of adjectives only (``Kočí`` is indeclinable and looks like one) falls back to
    its first token, so a single-word label is always its own head.

    The second element records whether the head *opens* its phrase, i.e. carries no
    qualifying adjective. That flag is what separates ``Malíři interiérů`` from ``Umělečtí
    malíři`` — both have head ``malíři``, but only the second is qualified into a different
    trade, and preferring the bare head keeps a house painter out of the fine artists.
    """
    out: list[tuple[str, bool]] = []
    for phrase in _SPLIT.split(_PAREN.sub(" ", str(label))):
        toks = re.findall(r"[^\W\d_]+", phrase, re.UNICODE)
        if not toks:
            continue
        head = next((t for t in toks if not t.lower().endswith(_ADJ_END)), toks[0])
        out.append((head, head == toks[0]))
    return out

def matches_head(key: str, head: str) -> bool:
    """Is ``head`` an inflected form of ``key``? Inflection only — never derivation.

    The head may be at most two characters longer, and must be either the key itself plus
    an ending, or one of the two regular stem alternations above. That is deliberately
    tight, because near-miss Czech words are a trap this corpus is full of:

    ``zámečník`` -> ``zámečníci``   accepted (regular plural)
    ``sedlák``   -> ``sedláci``     accepted (palatalised plural)
    ``sedlák``   -> ``sedláři``     **rejected** — a saddler is not a farmer
    ``lesník``   -> ``lesnictví``   **rejected** — forestry is not a forester
    ``hospodář`` -> ``hospodyně``   **rejected** — a housekeeper is not a farm steward
    ``obchodník``-> ``obchodních``  **rejected** — an adjective, not the noun's plural
    ``student``  -> ``studentských``**rejected** — ``-sk-`` is derivational

    Used with the head-noun position from :func:`head_nouns`; both guards are needed.
    """
    k, h = _fold(key), _fold(head)
    if not k or not h or not 0 <= len(h) - len(k) <= 2:
        return False
    if h[:len(k)] == k:                       # plain suffixing: kovář -> kováři
        return True
    if len(k) < 4:
        return False
    if h[:len(k) - 1] != k[:len(k) - 1]:      # the stem must survive intact
        return False
    if k[-1] in "kh" and h[len(k) - 1:] in _PALATAL_END:
        return True
    return k[-1] == "e" and h[len(k) - 1:] == "i"

def build() -> pd.DataFrame:
    print("Reading CZ-ISCO …")
    cs, en = _read(CS), _read(EN)
    print(f"  CS {len(cs):,} rows   EN {len(en):,} rows")

    assert not cs["chodnota"].duplicated().any(), "duplicate code in KLAS80146_CS"
    assert set(cs["chodnota"]) == set(en["chodnota"]), \
        "the CS and EN files do not cover the same code set"

    df = cs.rename(columns={"text": "cs"})[["chodnota", "uroven", "cs", "nadvaz"]].merge(
        en.rename(columns={"text": "en_own"})[["chodnota", "en_own"]], on="chodnota")
    df = df.rename(columns={"chodnota": "code", "uroven": "level", "nadvaz": "parent"})

    # English is published down to the 4-digit ISCO-08 unit group only; the 1,374 national
    # 5-digit codes inherit it from their parent. Record which, so an analysis can restrict
    # to first-hand labels.
    own = dict(zip(df["code"], df["en_own"]))
    df["en"] = df["en_own"].fillna(df["parent"].map(own))
    df["en_source"] = df["en_own"].notna().map({True: "own", False: "parent"})

    # The 4-digit ancestor: the level at which CZ-ISCO *is* ISCO-08 and the code is
    # internationally comparable.
    df["isco08_4d"] = df["code"].str[:4].where(df["level"].astype(int) >= 4)

    heads = df["cs"].map(head_nouns)
    df["head_cs"] = heads.map(lambda hs: " | ".join(h for h, _ in hs))
    # Heads that open their phrase, i.e. carry no qualifying adjective. `run_czisco_check`
    # prefers a candidate matched on one of these.
    df["head_bare"] = heads.map(lambda hs: " | ".join(h for h, bare in hs if bare))

    lvl = df["level"].astype(int)
    assert df.loc[lvl > 1, "parent"].notna().all(), "a non-top-level code has no parent"
    assert df.loc[lvl == 5, "en"].notna().all(), \
        "a level-5 code did not inherit an English label"
    assert df["head_cs"].str.strip().ne("").all(), "a label yielded no head noun"

    print(f"  {len(df):,} codes; English own {int((df['en_source'] == 'own').sum()):,} / "
          f"inherited {int((df['en_source'] == 'parent').sum()):,}")
    print("  by level: " + "  ".join(
        f"L{k}={v}" for k, v in df["level"].value_counts().sort_index().items()))

    return df[["code", "level", "cs", "en", "en_source", "isco08_4d",
               "parent", "head_cs", "head_bare"]].sort_values("code", ignore_index=True)

def bridge_report(df: pd.DataFrame) -> None:
    print("\nHead-noun extraction — the cases this rule exists for:")
    for code in ("71266", "72222", "14113", "12211", "71195", "93320", "26512", "71311"):
        r = df[df["code"] == code]
        if len(r):
            r = r.iloc[0]
            print(f"  {code:<6} {r['cs'][:48]:<48} -> head {r['head_cs']}"
                  f"{'' if r['head_bare'] else '   (qualified)'}")

    # Every one of these was a live false positive before the rule was tightened.
    print("\nNear-miss Czech words that must NOT match:")
    for key, head in (("sedlák", "Sedláři"), ("lesník", "lesnictví"),
                      ("hospodář", "Hospodyně"), ("obchodník", "obchodních"),
                      ("student", "studentských"), ("myslivec", "myslivosti")):
        ok = matches_head(key, head)
        print(f"  {key:<10} vs {head:<14} {'** STILL MATCHES **' if ok else 'rejected'}")

    print("\nRegular inflections that must match:")
    for key, head in (("zámečník", "Zámečníci"), ("sedlák", "Sedláci"),
                      ("kovář", "Kováři"), ("řezník", "Řezníci"), ("kočí", "Kočí")):
        ok = matches_head(key, head)
        print(f"  {key:<10} vs {head:<14} {'accepted' if ok else '** REJECTED **'}")

build_czisco_bridge.py — generate reference/occupations/czisco_authority.csv
===========================================================================
CZ-ISCO (ČSÚ classification 80146, 2025) as a **Czech→English occupational bridge**, which
is the one thing this project's occupation coding has never had.

Why it matters: every HISCO code here is reached through a German gloss (``obuvník`` →
*Schuhmacher*) that this project wrote. Both existing external checks inherit that
weakness — the History of Work link bridge *starts* from our gloss, and OccCANINE had to be
*fed* our gloss because Czech is not among its 13 training languages. Neither validates the
claim "this Czech word means that occupation". CZ-ISCO does, because the Czech statistical
office publishes the Czech and the English label under the same code.

Two structural facts decide how it can be used, both asserted below:

  * ``KLAS80146_CS.csv`` and ``KLAS80146_EN.csv`` join 1:1 on ``chodnota`` — 1,991 codes
    over five levels.

    codes — the ones carrying actual trade names like ``Zámečníci strojů`` — have an empty
    ``text``. They inherit English from their 4-digit ISCO-08 parent through ``nadvaz``,
    which resolves for every one of them. So the bridge is *Czech trade name → official
    English at ISCO-08 granularity*, not at the Czech national level.

Consumed by utils/reference_tools/occupations/run_czisco_check.py (a validation script, not a pipeline

from __future__ import annotations

import re
import sys
import unicodedata
from pathlib import Path

ROOT = Path(__file__).resolve().parents[3]
sys.path.insert(0, str(ROOT))

import pandas as pd

__version__ = "1.0.0"

RAW = ROOT / "data" / "raw" / "czisco"
OUT = ROOT / "reference" / "occupations" / "czisco_authority.csv"
CS = RAW / "KLAS80146_CS.csv"
EN = RAW / "KLAS80146_EN.csv"

# Czech adjectives precede their noun, and in the nominative plural the ČSÚ labels use end
# in long -í (``Stavební``, ``Řídící``, ``Kvalifikovaní``, ``Obchodní``, ``příbuzní``)
# while the nouns end in short -i or in -é/-ové (``zámečníci``, ``Kováři``, ``Učitelé``,
# ``Meteorologové``). That long/short vowel contrast is the whole discriminator.
_ADJ_END = ("í", "ý", "á")

# Split a label into the coordinate phrases it actually contains: ``Kováři, nástrojaři a
# příbuzní pracovníci`` names three occupations, and a key may match any of them.
_SPLIT = re.compile(r",| a | i | nebo ")

# Parenthetical content is a qualifier or an *exclusion* (``Zedníci (kromě zedníků
# ohnivzdorného zdiva)``). Taking a head noun out of an exclusion would invert its meaning,
# so the parentheses are dropped before any head is looked for.
_PAREN = re.compile(r"\([^)]*\)")


def _fold(s: str) -> str:
    """Diacritic-folded lowercase — the comparison form, as everywhere else in this repo."""
    return "".join(c for c in unicodedata.normalize("NFD", str(s).lower())
                   if unicodedata.category(c) != "Mn")


def head_nouns(label: str) -> list[tuple[str, bool]]:
    """(head noun, is phrase-initial) for every coordinate phrase in a CZ-ISCO label.

    ``Stavební zámečníci`` -> ``zámečníci``   (leading adjective stripped)
    ``Zámečníci strojů``   -> ``zámečníci``   (genitive complement follows the head)
    ``Obchodní náměstci``  -> ``náměstci``    (so ``obchodník`` does *not* match)
    ``Řídící pracovníci ve studentských ubytovnách`` -> ``pracovníci``
        (so ``student`` does *not* match — the failure this rule exists to prevent)
    ``Kováři, nástrojaři a příbuzní pracovníci`` -> three heads

    A phrase of adjectives only (``Kočí`` is indeclinable and looks like one) falls back to
    its first token, so a single-word label is always its own head.

    The second element records whether the head *opens* its phrase, i.e. carries no
    qualifying adjective. That flag is what separates ``Malíři interiérů`` from ``Umělečtí
    malíři`` — both have head ``malíři``, but only the second is qualified into a different
    trade, and preferring the bare head keeps a house painter out of the fine artists.
    """
    out: list[tuple[str, bool]] = []
    for phrase in _SPLIT.split(_PAREN.sub(" ", str(label))):
        toks = re.findall(r"[^\W\d_]+", phrase, re.UNICODE)
        if not toks:
            continue
        head = next((t for t in toks if not t.lower().endswith(_ADJ_END)), toks[0])
        out.append((head, head == toks[0]))

# Czech masculine-animate plurals palatalise a final k/h/ch before the -i ending
# (sedlák -> sedláci, řezník -> řezníci, mnich -> mniši), and the soft declension swaps a
# final -e for -i (dozorce -> dozorci). Those are the only stem changes allowed; anything
# else is a different word.
_PALATAL_END = ("ci", "zi", "si")


def matches_head(key: str, head: str) -> bool:
    """Is ``head`` an inflected form of ``key``? Inflection only — never derivation.

    The head may be at most two characters longer, and must be either the key itself plus
    an ending, or one of the two regular stem alternations above. That is deliberately
    tight, because near-miss Czech words are a trap this corpus is full of:

    ``zámečník`` -> ``zámečníci``   accepted (regular plural)
    ``sedlák``   -> ``sedláci``     accepted (palatalised plural)
    ``sedlák``   -> ``sedláři``     **rejected** — a saddler is not a farmer
    ``lesník``   -> ``lesnictví``   **rejected** — forestry is not a forester
    ``hospodář`` -> ``hospodyně``   **rejected** — a housekeeper is not a farm steward
    ``obchodník``-> ``obchodních``  **rejected** — an adjective, not the noun's plural
    ``student``  -> ``studentských``**rejected** — ``-sk-`` is derivational

    Used with the head-noun position from :func:`head_nouns`; both guards are needed.
    """
    k, h = _fold(key), _fold(head)
    if not k or not h or not 0 <= len(h) - len(k) <= 2:
        return False
    if h[:len(k)] == k:                       # plain suffixing: kovář -> kováři
        return True
    if len(k) < 4:
        return False
    if h[:len(k) - 1] != k[:len(k) - 1]:      # the stem must survive intact
        return False
    if k[-1] in "kh" and h[len(k) - 1:] in _PALATAL_END:
        return True
    return k[-1] == "e" and h[len(k) - 1:] == "i"


def _read(path: Path) -> pd.DataFrame:
    if not path.exists():
        raise SystemExit(
            f"{path} not found.\n"
            "  CZ-ISCO (ČSÚ classification 80146) — see reference/DATA_SOURCES.md §3b")
    return pd.read_csv(path, dtype=str, encoding="utf-8-sig")


def build() -> pd.DataFrame:
    print("Reading CZ-ISCO …")
    cs, en = _read(CS), _read(EN)
    print(f"  CS {len(cs):,} rows   EN {len(en):,} rows")

    assert not cs["chodnota"].duplicated().any(), "duplicate code in KLAS80146_CS"
    assert set(cs["chodnota"]) == set(en["chodnota"]), \
        "the CS and EN files do not cover the same code set"

    df = cs.rename(columns={"text": "cs"})[["chodnota", "uroven", "cs", "nadvaz"]].merge(
        en.rename(columns={"text": "en_own"})[["chodnota", "en_own"]], on="chodnota")
    df = df.rename(columns={"chodnota": "code", "uroven": "level", "nadvaz": "parent"})

    # 5-digit codes inherit it from their parent. Record which, so an analysis can restrict
    # to first-hand labels.
    own = dict(zip(df["code"], df["en_own"]))
    df["en"] = df["en_own"].fillna(df["parent"].map(own))
    df["en_source"] = df["en_own"].notna().map({True: "own", False: "parent"})

    # The 4-digit ancestor: the level at which CZ-ISCO *is* ISCO-08 and the code is
    # internationally comparable.
    df["isco08_4d"] = df["code"].str[:4].where(df["level"].astype(int) >= 4)

    heads = df["cs"].map(head_nouns)
    df["head_cs"] = heads.map(lambda hs: " | ".join(h for h, _ in hs))
    # Heads that open their phrase, i.e. carry no qualifying adjective. `run_czisco_check`
    # prefers a candidate matched on one of these.
    df["head_bare"] = heads.map(lambda hs: " | ".join(h for h, bare in hs if bare))

    lvl = df["level"].astype(int)
    assert df.loc[lvl > 1, "parent"].notna().all(), "a non-top-level code has no parent"
    assert df.loc[lvl == 5, "en"].notna().all(), \
        "a level-5 code did not inherit an English label"
    assert df["head_cs"].str.strip().ne("").all(), "a label yielded no head noun"

    print(f"  {len(df):,} codes; English own {int((df['en_source'] == 'own').sum()):,} / "
          f"inherited {int((df['en_source'] == 'parent').sum()):,}")
    print("  by level: " + "  ".join(
        f"L{k}={v}" for k, v in df["level"].value_counts().sort_index().items()))

    return df[["code", "level", "cs", "en", "en_source", "isco08_4d",
               "parent", "head_cs", "head_bare"]].sort_values("code", ignore_index=True)


def bridge_report(df: pd.DataFrame) -> None:
    print("\nHead-noun extraction — the cases this rule exists for:")
    for code in ("71266", "72222", "14113", "12211", "71195", "93320", "26512", "71311"):
        r = df[df["code"] == code]
        if len(r):
            r = r.iloc[0]
            print(f"  {code:<6} {r['cs'][:48]:<48} -> head {r['head_cs']}"
                  f"{'' if r['head_bare'] else '   (qualified)'}")

    # Every one of these was a live false positive before the rule was tightened.
    print("\nNear-miss Czech words that must NOT match:")
    for key, head in (("sedlák", "Sedláři"), ("lesník", "lesnictví"),
                      ("hospodář", "Hospodyně"), ("obchodník", "obchodních"),
                      ("student", "studentských"), ("myslivec", "myslivosti")):
        ok = matches_head(key, head)
        print(f"  {key:<10} vs {head:<14} {'** STILL MATCHES **' if ok else 'rejected'}")

    print("\nRegular inflections that must match:")
    for key, head in (("zámečník", "Zámečníci"), ("sedlák", "Sedláci"),
                      ("kovář", "Kováři"), ("řezník", "Řezníci"), ("kočí", "Kočí")):
        ok = matches_head(key, head)
        print(f"  {key:<10} vs {head:<14} {'accepted' if ok else '** REJECTED **'}")
