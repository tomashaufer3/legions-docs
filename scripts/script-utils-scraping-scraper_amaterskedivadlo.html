How it works

Reads the Databáze českého amatérského divadla (DbČAD), the encyclopedic database of Czech amateur theatre kept by NIK – Národní institut pro kulturu (formerly NIPOS), for one question: is the date at which amateur theatre is first documented in a place usable as a settlement-level, dated measure of pre-1914 Czech associational life?

Two steps, deliberately separate because their cost differs by four orders of magnitude:

A  the map XML      one request     every place in the database, with coordinates
B  the place pages  1–2 per place   the ensembles of a place and their years

Step A — enumeration

ajax/map2.php?zoom=12&nex=…&ney=…&swx=…&swy=… returns one XML document of &lt;location&gt; elements (id, name, lat, lng, typ, typnazev, alive) whose CDATA body names the kraj and the okres with their own geo ids. Below zoom ~8 the endpoint returns kraj aggregates instead, so the zoom is fixed high. The XML carries no dates.

Step B — dates, and the view switch that decides what a page says

By default the site shows only ensembles active today and shortened records. The historical view is a PHP-session switch: the page's own buttons call ajax/prepinac.php?co=rozsah&val=1 (Historie) and …?co=delka&val=1 (Úplné záznamy) and reload. A scraper that forgets this gets a well-formed page listing one ensemble where there are thirteen — a silent error, not a loud one. So:

  • one session is kept for the whole run and both switches are set first;
  • a canary is then fetched live: geo id 936, Uhlířské Janovice, must list Beseda (od 1873 do 1908), or the run stops (HistoryViewError);
  • every page is checked before it is cached — each carries the switch buttons with the active one marked, so a session that expired mid-run is caught on the page where it happened (view_state), re-established once, and otherwise fatal.

Nothing is written to the cache unless it was served in the historical, full view.

Per place, two pages are available:

main.php?data=geo&id={geo_id}                        the place entry: type, okres,
    'První zpráva', a chronicle, bibliography, archive citations — and, under
    'Související Soubory', the ensembles with their years
index.php?data=soubor&list=soubor11&id={geo_id}      the ensemble list alone

The place page's block is a superset: it prints each ensemble as Place: Name (span) and also lists the ensembles filed under other places — a town's parts, a touring group's other homes. Only the rows filed under the page's own heading are this place's (parse_place_ensembles). Read that way the two pages agree — on all 91 places of the 2026-10-12 pilot for which both were fetched (compare_sources re-checks it on whatever is cached) — so the default is pages=("geo",), one request per place, and pages=("geo", "list") is there for a cross-check.

What the dates are — and are not

První zpráva is the first surviving report of theatre in the place, not a founding date. An ensemble's span is printed as (od 1873 do 1908); the years may be fuzzy (191x, 19xx) or the span open-ended ((od 1936)). A fuzzy year is kept as its decade or century with a precision flag and its printed form beside it — it is never coerced to a year (parse_year_token).

Politeness

The site is a small public-sector database behind Cloudflare; the client is built so that it cannot hurt it.

  • Sequential, one connection, never parallel.
  • At least one second between requests — delay below MIN_DELAY is refused, the default is 1.5 s — and the pause stretches with the server's own response time (twice the last response time, capped), so a slow server is given room.
  • Every response is cached on disk and never requested twice; a re-run costs only the canary.
  • Backs off on 429/5xx (honouring Retry-After), gives up after a run of consecutive failures (ServerUnhealthyError) rather than hammering a server that is down, and stops at once on a Cloudflare challenge (BlockedError) — bot protection is never worked around.
  • Rests batch_pause seconds every batch_size requests.
  • The User-Agent names this script and its version — a script, not a browser — and nothing about who runs it.
  • The site publishes no robots.txt (404 on 2026-10-12) and its pages carry &lt;meta name=&quot;robots&quot; content=&quot;ALL,FOLLOW&quot;&gt;.

    """Parse the map XML into one row per ``<location>``.

    The attributes give id, name, coordinates and type.  The higher units are in the
    ``<tab0>`` child, a CDATA block of HTML (the map's info window) of the shape ::

        [Nadřazený celek: <a …id=P>Obec</a><br>]<a …id=K>Kraj</a>, okres <a …id=O>Okres</a>

        okres_geo_id, kraj, kraj_geo_id, parent_obec, parent_obec_geo_id, active_count``.

    if isinstance(xml, str):
        xml = xml.encode("utf-8")
    root = ElementTree.fromstring(xml)
    rows: list[dict] = []
    for loc in root.iter("location"):
        info = loc.find("tab0")
        rows.append({
            "geo_id": _int_or_none(loc.get("id")),
            "name": _clean(loc.get("name")),
            "type": _clean(loc.get("typnazev")),
            "type_code": _int_or_none(loc.get("typ")),
            "lat": _float_or_none(loc.get("lat")),
            "lon": _float_or_none(loc.get("lng")),
            **_parse_map_info(info.text if info is not None and info.text else ""),
            "active_count": _int_or_none(loc.get("alive")),
        })
    return rows

def parse_year_token(token: str | None) -> tuple[int | None, str]:
    """Read one printed year: ``1873`` / ``191x`` / ``19xx``.

    A fuzzy year is **not** turned into a year.  ``191x`` comes back as ``(1910,
    "decade")`` — the first year of the decade it names, to be read as 1910–1919 — and
    ``19xx`` as ``(1900, "century")``.  Anything else is ``(None, "unparsed")`` so the
    caller can count it; an absent token is ``(None, "missing")``.

    Returns:
        ``(value, precision)`` with precision in
        ``{"year", "decade", "century", "missing", "unparsed"}``.
    """
    tok = (token or "").strip().rstrip(".,;")
    if not tok:
        return None, "missing"
    if _YEAR.match(tok):
        return int(tok), "year"
    if (m := _DECADE.match(tok)):
        return int(m.group(1)) * 10, "decade"
    if (m := _CENTURY.match(tok)):
        return int(m.group(1)) * 100, "century"
    return None, "unparsed"

def parse_span(text: str | None) -> dict:
    """Read an ensemble's printed span, e.g. ``(od 1873 do 1908)``.

    ``open_ended`` is True when a start is printed and no end — ``(od 1936)``.  That is
    what the page says and no more: it is how a still-active ensemble is printed, but also
    one whose end is simply not recorded, so it is not by itself evidence of survival.

    Returns:
        ``year_from, year_to`` (ints or None), ``year_from_precision,
        year_to_precision`` (see :func:`parse_year_token`), ``year_from_raw, year_to_raw``
        (as printed), ``open_ended`` and ``span_raw``.
    """
    raw = _clean(text)
    m = _SPAN.search(raw) if raw else None
    od = m.group("od") if m else None
    do = m.group("do") if m else None
    year_from, p_from = parse_year_token(od)
    year_to, p_to = parse_year_token(do)
    if raw and not (m and (od or do)):
        # something is printed that is not an od/do span — never guess at it
        p_from = p_to = "unparsed"
    return {
        "year_from": year_from, "year_to": year_to,
        "year_from_precision": p_from, "year_to_precision": p_to,
        "year_from_raw": od, "year_to_raw": do,
        "open_ended": bool(od) and not do,
        "span_raw": raw or None,
    }

    """Ensembles from the list page ``index.php?data=soubor&list=soubor11&id={geo_id}``.

    Each row is a link ``Name <span class="doplnek">(od YYYY do YYYY)</span>`` to
    ``index.php?data=soubor&id={ensemble_id}``; the link's class says whether the

        fields, and ``status``.  An empty list is a real answer — the place has no

    container = soup.find(id="searchResults")

        return rows

    for a in container.find_all("a", href=True):
        m = _ENSEMBLE_LINK.search(a["href"])
        if not m or int(m.group(1)) in seen:      # the source repeats a row now and then
            continue

            span_el.extract()

                     "name": _clean(a.get_text(" ")),
                     **parse_span(span_text), "status": _row_status(a)})
    return rows

def parse_first_record(text: str | None) -> dict:
    """Read ``První zpráva`` — the first surviving report of theatre in the place.

    Normally a bare year.  Where it is prose (``kolem 1850``, ``před 1848``) the first

    out["first_record_year"] = value
    out["first_record_precision"] = precision if value is not None else "unparsed"
    return out

    """One polite session against amaterskedivadlo.cz, with an on-disk cache.

    See *Politeness* in the module docstring for what the pacing guarantees.
    """

    FETCH_LOG_FIELDS = ["fetched_at", "kind", "key", "url", "status", "bytes", "elapsed_s"]

    def __init__(
        self,
        out_dir: str | Path = DEFAULT_OUT_DIR,
        *,
        delay: float = DEFAULT_DELAY,
        timeout: float = 60.0,
        retries: int = 4,
        max_requests: int | None = None,
        max_consecutive_failures: int = 5,
        batch_size: int = 200,
        batch_pause: float = 20.0,
    ) -> None:
        if delay < MIN_DELAY:
            raise ValueError(f"delay={delay} s is below the {MIN_DELAY} s floor — "
                             "this site is not to be requested faster than that")
        self.out_dir = Path(out_dir)
        self.cache_dir = self.out_dir / "cache"
        self.delay = float(delay)
        self.timeout = timeout
        self.retries = retries
        self.max_requests = max_requests
        self.max_consecutive_failures = max_consecutive_failures
        self.batch_size = batch_size
        self.batch_pause = batch_pause
        self.session = requests.Session()
        self.session.headers.update({"User-Agent": USER_AGENT,
                                     "Accept-Language": "cs,en;q=0.8"})
        self.n_requests = 0
        self._pause = self.delay
        self._last_done: float | None = None
        self._consecutive_failures = 0
        self._history_ready = False

    # -- cache --------------------------------------------------------------
    def cache_path(self, kind: str, geo_id: int | None = None) -> Path:
        if kind == "map":
            return self.cache_dir / "map.xml.gz"
        return self.cache_dir / kind / f"{int(geo_id)}.html.gz"

    def read_cache(self, kind: str, geo_id: int | None = None) -> bytes | None:
        path = self.cache_path(kind, geo_id)
        if path.exists() and path.stat().st_size > 0:
            return gzip.decompress(path.read_bytes())
        return None

    def _write_cache(self, kind: str, geo_id: int | None, content: bytes) -> None:
        path = self.cache_path(kind, geo_id)
        path.parent.mkdir(parents=True, exist_ok=True)
        tmp = path.with_suffix(path.suffix + ".tmp")
        tmp.write_bytes(gzip.compress(content))
        tmp.replace(path)          # atomic: an interrupted run leaves no half-written page

    def _log_fetch(self, kind: str, key, url: str, status, n_bytes: int, elapsed: float) -> None:
        self.out_dir.mkdir(parents=True, exist_ok=True)
        path = self.out_dir / "fetch_log.csv"
        new = not path.exists()
        with open(path, "a", newline="", encoding="utf-8") as fh:
            writer = csv.writer(fh)
            if new:
                writer.writerow(self.FETCH_LOG_FIELDS)
            writer.writerow([datetime.now(timezone.utc).isoformat(timespec="seconds"),
                             kind, key, url, status, n_bytes, f"{elapsed:.2f}"])

    # -- pacing -------------------------------------------------------------
    def _wait(self) -> None:
        """Sleep until at least ``_pause`` seconds have passed since the last response."""
        if self._last_done is not None:
            remaining = self._pause - (time.monotonic() - self._last_done)
            if remaining > 0:
                time.sleep(remaining)
        if self.batch_size and self.n_requests and self.n_requests % self.batch_size == 0:
            log.info("  %d requests this run — resting %.0f s", self.n_requests, self.batch_pause)
            time.sleep(self.batch_pause)

    def _get(self, url: str, *, kind: str, key=None) -> requests.Response | None:
        """One polite GET.  Returns the response (200 or 404) or ``None`` after retries.

        Raises:
            BlockedError: a bot challenge was served.
            ServerUnhealthyError: ``max_consecutive_failures`` URLs failed in a row.
            RequestBudgetExceeded: the ``max_requests`` cap was reached.
        """
        for attempt in range(1, self.retries + 1):
            if self.max_requests is not None and self.n_requests >= self.max_requests:
                raise RequestBudgetExceeded(f"stopped at max_requests={self.max_requests}")
            self._wait()
            started = time.monotonic()
            status: int | str
            try:
                response = self.session.get(url, timeout=self.timeout)
                status = response.status_code
            except requests.RequestException as exc:
                response, status = None, exc.__class__.__name__
            elapsed = time.monotonic() - started
            self.n_requests += 1
            self._last_done = time.monotonic()
            # give a slow server room: wait at least twice as long as it took to answer
            self._pause = max(self.delay, min(MAX_ADAPTIVE_DELAY, 2 * elapsed))
            self._log_fetch(kind, key, url, status,
                            len(response.content) if response is not None else 0, elapsed)

            if response is not None and _is_challenge(response):
                raise BlockedError(
                    f"{url} answered with a bot challenge (HTTP {status}). Stopping — "
                    "wait, and contact the database's operators rather than retrying.")
            if response is not None and status in (200, 404):
                self._consecutive_failures = 0
                return response

            wait = min(MAX_BACKOFF, self.delay * 4 ** attempt)
            if response is not None:
                retry_after = _float_or_none(response.headers.get("Retry-After"))
                if retry_after:
                    wait = min(MAX_BACKOFF, max(wait, retry_after))
            if response is not None and status not in RETRY_STATUS:
                log.warning("  HTTP %s on %s — not retried", status, url)
                break
            log.warning("  %s on %s — attempt %d/%d, waiting %.0f s",
                        status, url, attempt, self.retries, wait)
            if attempt < self.retries:
                time.sleep(wait)

        self._consecutive_failures += 1
        if self._consecutive_failures >= self.max_consecutive_failures:
            raise ServerUnhealthyError(
                f"{self._consecutive_failures} URLs in a row failed — the server looks "
                "unwell, so the run stops here. Everything fetched so far is cached; "
                "re-run later to resume.")
        return None

    # -- step A -------------------------------------------------------------
    def fetch_map(self, *, refresh: bool = False) -> bytes:

    def fetch_page(self, kind: str, geo_id: int, *, refresh: bool = False) -> tuple[str | None, bool]:

        A page is cached only if it was served in the historical, full view; one that was
        not triggers a single re-establishment of the session and a second try.

            ``(html, fetched)`` — ``html`` is None when the page could not be had (404 or
            repeated failure; it is then retried on the next run), ``fetched`` says whether
            the network was touched.

            if cached is not None:
                return cached.decode("utf-8", errors="replace"), False
        if not self._history_ready:
            self.enable_history()

        raise HistoryViewError(
            f"{kind} page of geo {geo_id} is still not in the historical view after the "
            "session was re-established. Stopping; nothing wrong was cached.")

    The info window's first link is the place's *parent unit*, which is the kraj for an
    ordinary obec but the city for a city district (``Ostrava``, ``Plzeň``), and the parts

    * a missing okres is inherited from the parent place's row;
    * a missing kraj is the kraj of the other places of the same okres.

    ``units_inferred`` marks the rows this touched.  Key ``geo_id``, asserted.

    places = pd.DataFrame(parse_map_xml(xml), columns=PLACE_COLUMNS)
    _assert_key(places, "geo_id", "places")

    not_kraj = places["kraj"].notna() & ~places["kraj"].fillna("").str.contains(_IS_KRAJ)
    move = not_kraj & places["parent_obec"].isna()
    places.loc[move, ["parent_obec", "parent_obec_geo_id"]] = (
        places.loc[move, ["kraj", "kraj_geo_id"]].to_numpy())
    places.loc[not_kraj, ["kraj", "kraj_geo_id"]] = None

    for _ in range(2):                     # a part of a part needs a second pass

        missing = places["okres"].isna() & places["parent_obec_geo_id"].notna()
        inherited = parent.reindex(places.loc[missing, "parent_obec_geo_id"])
        places.loc[missing, ["okres", "okres_geo_id"]] = inherited.to_numpy()

    known = places.dropna(subset=["kraj", "okres_geo_id"])
    okres_kraj = (known.groupby("okres_geo_id")[["kraj", "kraj_geo_id"]]
                  .agg(lambda s: s.mode().iloc[0]))
    missing = places["kraj"].isna() & places["okres_geo_id"].notna()
    filled = okres_kraj.reindex(places.loc[missing, "okres_geo_id"])
    places.loc[missing, ["kraj", "kraj_geo_id"]] = filled.to_numpy()

    places["units_inferred"] = (original["okres"].fillna("") != places["okres"].fillna("")) | (
        original["kraj"].fillna("") != places["kraj"].fillna(""))
    for col in set(_PLACE_INT_COLUMNS) & set(places.columns):
        places[col] = places[col].astype("Int64")
    return places

            and/or ``"list"`` (the ensemble list alone).  The default is the entry only:
            on the pilot sample the two named the same ensembles on every place compared,
            so the second request per place buys nothing (:func:`compare_sources`).
        client_kwargs: passed to :class:`TheatreClient` (``delay``, ``max_requests`` …).

    Returns:
        Counts: ``places, cached, fetched, failed, requests``.
    """
    unknown = set(pages) - set(PAGE_URLS)
    if unknown:
        raise ValueError(f"unknown page kind(s): {sorted(unknown)}")
    client = client or TheatreClient(out_dir, **client_kwargs)
    ids = sorted({int(g) for g in geo_ids})
    summary = {"places": len(ids), "cached": 0, "fetched": 0, "failed": 0, "requests": 0}
    failed: list[tuple[str, int]] = []

    bar = page_bar(len(ids), "amaterskedivadlo", enabled=progress, unit="place")
    with bar, redirect_logging():
        for i, geo_id in enumerate(ids, 1):
            for kind in pages:
                html, fetched = client.fetch_page(kind, geo_id)
                if html is None:
                    summary["failed"] += 1
                    failed.append((kind, geo_id))
                elif fetched:
                    summary["fetched"] += 1
                else:
                    summary["cached"] += 1
            bar.update(1)
            bar.set_postfix(fetched=summary["fetched"], failed=summary["failed"], refresh=False)
            if not getattr(bar, "live", False) and (i % 50 == 0 or i == len(ids)):
                log.info("  … %d/%d places (%d pages fetched this run)",
                         i, len(ids), summary["fetched"])

    summary["requests"] = client.n_requests
    if failed:
        log.warning("%d page(s) could not be fetched and will be retried on the next run: %s",
                    len(failed), failed[:10])
    log.info("Step B: %(places)d places — %(fetched)d pages fetched, %(cached)d from cache, "
             "%(failed)d failed, %(requests)d requests", summary)
    return summary

             len(places), int(places["page_cached"].sum()), len(ensembles),
             ensembles["geo_id"].nunique())

def compare_sources(out_dir: str | Path = DEFAULT_OUT_DIR) -> dict:
    """Do the list page and the place page name the same ensembles, with the same years?

    return {"places_compared": len(both), "places_identical": len(both) - len(differing),
            "differing": differing}

def estimate_full_run(out_dir: str | Path = DEFAULT_OUT_DIR, *, pages: tuple[str, ...] = ("geo",),
                      delay: float = DEFAULT_DELAY, batch_size: int = 200,
                      batch_pause: float = 20.0) -> dict:
    """Requests and hours the rest of step B would take, from what this cache has seen.

    The response time is the mean of the place pages already in ``fetch_log.csv``; the
    pause per request is the client's own rule (``max(delay, 2 × response time)``).

    Returns:
        ``places_total, pages_cached, requests_left, mean_response_s, hours``.
    """
    import pandas as pd

    out_dir = Path(out_dir)
    xml = TheatreClient(out_dir).read_cache("map")

    cached = sum(len(_cached_ids(out_dir, kind)) for kind in pages)
    requests_left = n_places * len(pages) - cached
    log_path = out_dir / "fetch_log.csv"
    mean_response = 0.0
    if log_path.exists():
        fetch_log = pd.read_csv(log_path)
        seen = fetch_log.loc[fetch_log["kind"].isin(PAGE_URLS), "elapsed_s"]
        mean_response = float(seen.mean()) if len(seen) else 0.0
    per_request = max(delay, 2 * mean_response) + mean_response

            "mean_response_s": round(mean_response, 2),
            "hours": round((requests_left * per_request + rests) / 3600, 1)}

    logging.basicConfig(level=logging.DEBUG if args.verbose else logging.INFO,
                        format="%(asctime)s %(message)s", datefmt="%H:%M:%S")
    client_kwargs = {"delay": args.delay, "max_requests": args.max_requests}
    try:
        if args.step == "map":
            fetch_places(args.out_dir, **client_kwargs)
        elif args.step == "places":
            places = fetch_places(args.out_dir, **client_kwargs)     # cached after step A
            ids = (places["geo_id"].astype(int).tolist() if args.all
                   else select_geo_ids(places, okresy=args.okres, geo_ids=args.geo_ids))

                return 2

                     result["differing"][:20])

#!/usr/bin/env python3
"""
amaterskedivadlo.cz scraper — importable module + CLI.  **Feasibility pilot.**

Reads the *Databáze českého amatérského divadla* (DbČAD), the encyclopedic database of
Czech amateur theatre kept by NIK – Národní institut pro kulturu (formerly NIPOS), for
one question: is the date at which amateur theatre is first documented in a place usable
as a settlement-level, dated measure of pre-1914 Czech associational life?

Two steps, deliberately separate because their cost differs by four orders of magnitude:

    A  the map XML      one request     every place in the database, with coordinates
    B  the place pages  1–2 per place   the ensembles of a place and their years

Step A — enumeration
--------------------
``ajax/map2.php?zoom=12&nex=…&ney=…&swx=…&swy=…`` returns one XML document of
``<location>`` elements (id, name, lat, lng, typ, typnazev, alive) whose CDATA body names
the kraj and the okres with their own geo ids.  Below zoom ~8 the endpoint returns kraj
aggregates instead, so the zoom is fixed high.  The XML carries **no dates**.

Step B — dates, and the view switch that decides what a page says
-----------------------------------------------------------------
By default the site shows only ensembles active *today* and shortened records.  The
historical view is a **PHP-session switch**: the page's own buttons call
``ajax/prepinac.php?co=rozsah&val=1`` (Historie) and ``…?co=delka&val=1`` (Úplné
záznamy) and reload.  A scraper that forgets this gets a well-formed page listing one
ensemble where there are thirteen — a silent error, not a loud one.  So:

* one session is kept for the whole run and both switches are set first;
* a **canary** is then fetched live: geo id 936, Uhlířské Janovice, must list
  ``Beseda (od 1873 do 1908)``, or the run stops (:class:`HistoryViewError`);
* **every** page is checked before it is cached — each carries the switch buttons with
  the active one marked, so a session that expired mid-run is caught on the page where
  it happened (:func:`view_state`), re-established once, and otherwise fatal.

Nothing is written to the cache unless it was served in the historical, full view.

Per place, two pages are available:

    main.php?data=geo&id={geo_id}                        the place entry: type, okres,
        'První zpráva', a chronicle, bibliography, archive citations — and, under
        'Související Soubory', the ensembles with their years
    index.php?data=soubor&list=soubor11&id={geo_id}      the ensemble list alone

The place page's block is a superset: it prints each ensemble as ``Place: Name (span)``
and also lists the ensembles filed under *other* places — a town's parts, a touring
group's other homes.  Only the rows filed under the page's own heading are this place's
(:func:`parse_place_ensembles`).  Read that way the two pages agree — on all 91 places of
the 2026-10-12 pilot for which both were fetched (:func:`compare_sources` re-checks it on
whatever is cached) — so the default is ``pages=("geo",)``, one request per place, and
``pages=("geo", "list")`` is there for a cross-check.

What the dates are — and are not
--------------------------------
``První zpráva`` is the **first surviving report** of theatre in the place, not a
founding date.  An ensemble's span is printed as ``(od 1873 do 1908)``; the years may be
fuzzy (``191x``, ``19xx``) or the span open-ended (``(od 1936)``).  A fuzzy year is kept
as its decade or century **with a precision flag** and its printed form beside it — it is
never coerced to a year (:func:`parse_year_token`).

Politeness
----------
The site is a small public-sector database behind Cloudflare; the client is built so that
it cannot hurt it.

* **Sequential, one connection**, never parallel.
* **At least one second between requests** — ``delay`` below :data:`MIN_DELAY` is
  refused, the default is 1.5 s — and the pause **stretches with the server's own
  response time** (twice the last response time, capped), so a slow server is given room.
* **Every response is cached on disk** and never requested twice; a re-run costs only the
  canary.
* **Backs off** on 429/5xx (honouring ``Retry-After``), **gives up** after a run of
  consecutive failures (:class:`ServerUnhealthyError`) rather than hammering a server that
  is down, and **stops at once** on a Cloudflare challenge (:class:`BlockedError`) —
  bot protection is never worked around.
* Rests ``batch_pause`` seconds every ``batch_size`` requests.
* The ``User-Agent`` names this script and its version — a script, not a browser — and
  nothing about who runs it.
* The site publishes no ``robots.txt`` (404 on 2026-10-12) and its pages carry
  ``<meta name="robots" content="ALL,FOLLOW">``.

Source and citation
-------------------
    Databáze českého amatérského divadla [online]. Praha: NIK – Národní institut pro
    kulturu (dříve NIPOS), 2005–2026. https://www.amaterskedivadlo.cz

Cite with the retrieval date written to ``SOURCE.txt`` in the output directory, and cite
an individual place as its heading plus ``main.php?data=geo&id={geo_id}``.  The database
grew out of *Místopis českého amatérského divadla* I–II (Praha: IPOS-ARTAMA, 2001–2002),
which its entries cite; that is the print source to cite beside it.  All rights reserved
by NIK (NIPOS); scraping rests on the same basis as the project's other sources — §90
zákon č. 121/2000 Sb. (scientific research).  The raw cache stays under the gitignored
``data/`` tree and is not redistributed; only facts (names, places, years) are extracted.

Jupyter usage
-------------
    >>> from utils.scraping import scraper_amaterskedivadlo as ad
    >>> places = ad.fetch_places()                       # step A, one request
    >>> ids = ad.select_geo_ids(places, okresy=["Kutná Hora", "Trutnov", "Přerov"])
    >>> ad.scrape_places(ids)                            # step B, resumable
    >>> places, ensembles = ad.build_tables()            # parse the cache, no network

CLI usage: see ``python utils/scraping/scraper_amaterskedivadlo.py --help``
    python utils/scraping/scraper_amaterskedivadlo.py --step map
    python utils/scraping/scraper_amaterskedivadlo.py --step places --okres "Kutná Hora" Trutnov
    python utils/scraping/scraper_amaterskedivadlo.py --step places --all

The coverage tabulation that reads the result is ``utils/reference_tools/places/run_amateur_theatre_pilot.py``.

_GEO_LINK = re.compile(r"data=geo&(?:amp;)?id=(\d+)")
_ENSEMBLE_LINK = re.compile(r"data=soubor&(?:amp;)?id=(\d+)")
_WS = re.compile(r"\s+")


def _clean(text: str | None) -> str:
    return _WS.sub(" ", text or "").strip()


def _int_or_none(value: str | None) -> int | None:
    try:
        return int(str(value).strip())
    except (TypeError, ValueError):
        return None


def _float_or_none(value: str | None) -> float | None:
    try:
        return float(str(value).strip().replace(",", "."))
    except (TypeError, ValueError):
        return None


def parse_map_xml(xml: bytes | str) -> list[dict]:
    """Parse the map XML into one row per ``<location>``.

    The attributes give id, name, coordinates and type.  The higher units are in the
    ``<tab0>`` child, a CDATA block of HTML (the map's info window) of the shape ::

        [Nadřazený celek: <a …id=P>Obec</a><br>]<a …id=K>Kraj</a>, okres <a …id=O>Okres</a>

    read by its labels, not by link position: the parent line is present only for a part
    of an obec, and a few places carry a kraj and no okres.  A handful of okres names are
    printed with a trailing ``, okres`` (``Chrudim, okres``), which is dropped.

    Returns:
        A list of dicts with ``geo_id, name, type, type_code, lat, lon, okres,
        okres_geo_id, kraj, kraj_geo_id, parent_obec, parent_obec_geo_id, active_count``.
    """
    if isinstance(xml, str):
        xml = xml.encode("utf-8")
    root = ElementTree.fromstring(xml)
    rows: list[dict] = []
    for loc in root.iter("location"):
        info = loc.find("tab0")
        rows.append({
            "geo_id": _int_or_none(loc.get("id")),
            "name": _clean(loc.get("name")),
            "type": _clean(loc.get("typnazev")),
            "type_code": _int_or_none(loc.get("typ")),
            "lat": _float_or_none(loc.get("lat")),
            "lon": _float_or_none(loc.get("lng")),
            **_parse_map_info(info.text if info is not None and info.text else ""),
            "active_count": _int_or_none(loc.get("alive")),
        })
    return rows


_MAP_LINK = re.compile(r'<a\s[^>]*?data=geo&(?:amp;)?id=(\d+)[^>]*>([^<]*)</a>', re.I)
_OKRES_SUFFIX = re.compile(r",\s*okres\s*$", re.I)


def _parse_map_info(info_html: str) -> dict:
    """Parent obec, kraj and okres (name + geo id each) from a location's info window."""
    out = dict.fromkeys(["okres", "okres_geo_id", "kraj", "kraj_geo_id",
                         "parent_obec", "parent_obec_geo_id"])

    def put(level: str, fragment: str) -> None:
        m = _MAP_LINK.search(fragment)
        if m:
            out[level] = _OKRES_SUFFIX.sub("", _clean(m.group(2)))
            out[f"{level}_geo_id"] = int(m.group(1))

    head, has_parent, units = info_html.partition("<br>")
    if not has_parent:
        head, units = "", info_html
    if "Nadřazený celek" in head:
        put("parent_obec", head)
    kraj_part, has_okres, okres_part = units.partition(", okres ")
    put("kraj", kraj_part)
    if has_okres:
        put("okres", okres_part)
    return out


# four digits from 1000 on: the oldest first reports are medieval (Brno 1348, Cheb 1442)
_YEAR = re.compile(r"^(1\d\d\d|20\d\d)$")
_DECADE = re.compile(r"^(1\d\d|20\d)[xX?]$")
_CENTURY = re.compile(r"^(1\d|20)[xX?]{2}$")


def parse_year_token(token: str | None) -> tuple[int | None, str]:
    """Read one printed year: ``1873`` / ``191x`` / ``19xx``.

    A fuzzy year is **not** turned into a year.  ``191x`` comes back as ``(1910,
    "decade")`` — the first year of the decade it names, to be read as 1910–1919 — and
    ``19xx`` as ``(1900, "century")``.  Anything else is ``(None, "unparsed")`` so the
    caller can count it; an absent token is ``(None, "missing")``.

    Returns:
        ``(value, precision)`` with precision in
        ``{"year", "decade", "century", "missing", "unparsed"}``.
    """
    tok = (token or "").strip().rstrip(".,;")
    if not tok:
        return None, "missing"
    if _YEAR.match(tok):
        return int(tok), "year"
    if (m := _DECADE.match(tok)):
        return int(m.group(1)) * 10, "decade"
    if (m := _CENTURY.match(tok)):
        return int(m.group(1)) * 100, "century"
    return None, "unparsed"


# "(od 1873 do 1908)" · "(od 1936)" · "(do 1950)" · "(od 191x do 195x)"
_SPAN = re.compile(r"\(\s*(?:od\s+(?P<od>[^\s()]+))?\s*(?:do\s+(?P<do>[^\s()]+))?\s*\)\s*$")


def parse_span(text: str | None) -> dict:
    """Read an ensemble's printed span, e.g. ``(od 1873 do 1908)``.

    ``open_ended`` is True when a start is printed and no end — ``(od 1936)``.  That is
    what the page says and no more: it is how a still-active ensemble is printed, but also
    one whose end is simply not recorded, so it is not by itself evidence of survival.

    Returns:
        ``year_from, year_to`` (ints or None), ``year_from_precision,
        year_to_precision`` (see :func:`parse_year_token`), ``year_from_raw, year_to_raw``
        (as printed), ``open_ended`` and ``span_raw``.
    """
    raw = _clean(text)
    m = _SPAN.search(raw) if raw else None
    od = m.group("od") if m else None
    do = m.group("do") if m else None
    year_from, p_from = parse_year_token(od)
    year_to, p_to = parse_year_token(do)
    if raw and not (m and (od or do)):
        # something is printed that is not an od/do span — never guess at it
        p_from = p_to = "unparsed"
    return {
        "year_from": year_from, "year_to": year_to,
        "year_from_precision": p_from, "year_to_precision": p_to,
        "year_from_raw": od, "year_to_raw": do,
        "open_ended": bool(od) and not do,
        "span_raw": raw or None,
    }


# trailing "(od …)" / "(do …)" of an ensemble printed as plain text on the place page
_TRAILING_SPAN = re.compile(r"\s*(\(\s*(?:od|do)\b[^()]*\))\s*$")
_ROW_CLASS = {"rowAlive": "alive", "rowHistory": "history", "rowEmpty": "unrevised"}


def _row_status(anchor) -> str | None:
    for cls in anchor.get("class") or []:
        if cls in _ROW_CLASS:
            return _ROW_CLASS[cls]
    return None


def parse_ensemble_list(html: str, geo_id: int) -> list[dict]:
    """Ensembles from the list page ``index.php?data=soubor&list=soubor11&id={geo_id}``.

    Each row is a link ``Name <span class="doplnek">(od YYYY do YYYY)</span>`` to
    ``index.php?data=soubor&id={ensemble_id}``; the link's class says whether the
    ensemble is active today (``alive``), historical, or not yet revised.

    Returns:
        One dict per ensemble: ``ensemble_id, geo_id, name``, the :func:`parse_span`
        fields, and ``status``.  An empty list is a real answer — the place has no
        ensemble on record.
    """
    soup = BeautifulSoup(html, "html.parser")
    container = soup.find(id="searchResults")
    rows: list[dict] = []
    if container is None:
        return rows
    seen: set[int] = set()
    for a in container.find_all("a", href=True):
        m = _ENSEMBLE_LINK.search(a["href"])
        if not m or int(m.group(1)) in seen:      # the source repeats a row now and then
            continue
        seen.add(int(m.group(1)))
        span_el = a.find("span", class_="doplnek")
        span_text = span_el.get_text(" ", strip=True) if span_el else ""
        if span_el is not None:
            span_el.extract()
        rows.append({"ensemble_id": int(m.group(1)), "geo_id": int(geo_id),
                     "name": _clean(a.get_text(" ")),
                     **parse_span(span_text), "status": _row_status(a)})
    return rows


def _field(soup: BeautifulSoup, element_id: str) -> tuple[str | None, int | None]:
    """A labelled field of the place page: its text (label dropped) and linked geo id."""
    el = soup.find(id=element_id)
    if el is None:
        return None, None
    label = el.find("span")
    if label is not None:
        label.extract()
    link = el.find("a", href=True)
    m = _GEO_LINK.search(link["href"]) if link else None
    return _clean(el.get_text(" ")) or None, (int(m.group(1)) if m else None)


def _block_text(soup: BeautifulSoup, element_id: str) -> str | None:
    """A free-text block of the place page, with its line structure kept.

    The chronicle, the bibliography and the archive citations are each a run of entries
    separated by ``<br>`` — one dated note, one title, one fond per line.  The breaks are
    kept as newlines (blank lines dropped, spaces collapsed within a line) so the entries
    can be told apart later; the block's bold label (``Bibliografie:``) is dropped.
    """
    el = soup.find(id=element_id)
    if el is None:
        return None
    label = el.find("span")
    if label is not None and label.find("b") is not None and _clean(label.get_text()).endswith(":"):
        label.extract()
    for br in el.find_all("br"):
        # unwrap, never replace: the parser sometimes nests the following text inside a
        # `<br />`, and replacing the tag would throw that text away
        br.insert_before("\n")
        br.unwrap()
    lines = (_clean(line) for line in el.get_text("").split("\n"))
    return "\n".join(line for line in lines if line) or None


_FIRST_RECORD_TOKEN = re.compile(r"\b(?:1\d\d\d|20\d\d|1\d\d[xX]|20\d[xX]|(?:1\d|20)[xX]{2})\b")


def parse_first_record(text: str | None) -> dict:
    """Read ``První zpráva`` — the first surviving report of theatre in the place.

    Normally a bare year.  Where it is prose (``kolem 1850``, ``před 1848``) the first
    year-like token is read and ``first_record_qualified`` set, so the bare-year cases can
    be separated from the hedged ones; with no year-like token at all the value is None
    and the precision ``unparsed``.
    """
    raw = _clean(text) or None
    out = {"first_record_raw": raw, "first_record_year": None,
           "first_record_precision": "missing", "first_record_qualified": False}
    if not raw:
        return out
    value, precision = parse_year_token(raw)
    if value is None:
        m = _FIRST_RECORD_TOKEN.search(raw)
        if m:
            value, precision = parse_year_token(m.group(0))
            out["first_record_qualified"] = True
    out["first_record_year"] = value
    out["first_record_precision"] = precision if value is not None else "unparsed"
    return out


def parse_place_page(html: str, geo_id: int) -> dict:
    """The place entry ``main.php?data=geo&id={geo_id}``.

    Besides the dated field, the three free-text blocks are kept whole — the chronicle,
    the bibliography and the archive citations (:func:`_block_text`, one entry per line) —
    with their lengths in characters as a crude measure of *how much* is documented about
    a place, which is what has to be compared across town sizes and across lands before
    ``first_record_year`` can be read as anything but an artefact of documentation.  The
    texts are the database's own prose: they stay under the gitignored ``data/`` tree.

    Returns:
        ``geo_id, page_name, page_type, page_okres, page_okres_geo_id, page_parent,
        page_parent_geo_id``, the :func:`parse_first_record` fields, ``n_child_places``,
        ``text_chars, bibliography_chars, archive_chars``, ``n_related_ensembles`` and
        ``chronicle_text, bibliography_text, archive_text``.
    """
    soup = BeautifulSoup(html, "html.parser")
    heading = soup.find(id="obsah")
    type_text, _ = _field(soup, "TypCelku_ID")
    okres, okres_id = _field(soup, "Okres_ID")
    parent, parent_id = _field(soup, "Parent_ID")
    first, _ = _field(soup, "PrvniZprava")

    chronicle = _block_text(soup, "Text")
    bibliography = _block_text(soup, "Bibliografie")
    archives = _block_text(soup, "Archivy")

    children = 0
    for h in soup.find_all("h4"):
        if "geografick" in h.get_text().lower():
            ul = h.find_next_sibling("ul")
            children = len(ul.find_all("a", href=_GEO_LINK)) if ul else 0
            break

    return {
        "geo_id": int(geo_id),
        "page_name": _clean(heading.get_text(" ")) if heading else None,
        "page_type": type_text,
        "page_okres": okres, "page_okres_geo_id": okres_id,
        "page_parent": parent, "page_parent_geo_id": parent_id,
        **parse_first_record(first),
        "n_child_places": children,
        "text_chars": len(chronicle or ""),
        "bibliography_chars": len(bibliography or ""),
        "archive_chars": len(archives or ""),
        "n_related_ensembles": len(parse_place_ensembles(html, geo_id)),
        "chronicle_text": chronicle,
        "bibliography_text": bibliography,
        "archive_text": archives,
    }


def parse_place_ensembles(html: str, geo_id: int, *, own_only: bool = True) -> list[dict]:
    """Ensembles from the place page's own 'Související Soubory' block.

    There an ensemble is printed as one string, ``Place: Name (od YYYY do YYYY)`` — and
    the place is **not always this place**.  A town's page also lists the ensembles filed
    under its parts (Přerov lists ``Čekyně: Svornost …``), and an ensemble tied to several
    places is listed once per place (``Praha, hlavní město: Láhor/Soundsystem`` on the
    page of Hranice).  So the prefix is read, kept as ``listed_under``, and by default only
    the rows filed under this page's own heading are returned.  The source also repeats a
    row now and then; exact repeats are dropped.

    Args:
        own_only: keep only ensembles filed under this place (the default).  With False,
            every row of the block comes back, each with its ``listed_under``.

    Returns:
        The :func:`parse_ensemble_list` fields plus ``listed_under``.
    """
    soup = BeautifulSoup(html, "html.parser")
    block = soup.find(id="ssoubor")
    rows: list[dict] = []
    if block is None:
        return rows
    heading_el = soup.find(id="obsah")
    heading = _clean(heading_el.get_text(" ")) if heading_el else None
    seen: set[tuple] = set()
    for a in block.find_all("a", href=True):
        m = _ENSEMBLE_LINK.search(a["href"])
        if not m:
            continue
        text = _clean(a.get_text(" "))
        span_match = _TRAILING_SPAN.search(text)
        span_text = span_match.group(1) if span_match else ""
        name = text[:span_match.start()] if span_match else text
        if heading and name.startswith(heading + ":"):
            listed_under, name = heading, name[len(heading) + 1:]
        else:
            # another place's ensemble: the place is what precedes the first ": "
            listed_under, sep, rest = name.partition(": ")
            listed_under, name = (listed_under, rest) if sep else (None, name)
        key = (int(m.group(1)), listed_under)
        if key in seen or (own_only and listed_under != heading):
            continue
        seen.add(key)
        rows.append({"ensemble_id": int(m.group(1)), "geo_id": int(geo_id),
                     "name": _clean(name), **parse_span(span_text),
                     "status": _row_status(a), "listed_under": listed_under})
    return rows


_SWITCH = re.compile(r"prepinac\('(\w+)','(\w+)'\)\"\s+class=\"active\"")


def view_state(html: str) -> dict:
    """Which view a page was served in, read off its own switch buttons.

    Every database page prints the four buttons with the active pair marked, e.g.
    ``{"rozsah": "historie", "delka": "full"}``.  An empty dict means the buttons are not
    there at all — an error page, not a database page.
    """
    return {co: value for co, value in _SWITCH.findall(html)}


def is_history_view(html: str) -> bool:
    """True when the page was served in the historical, full view."""
    return view_state(html) == HISTORY_VIEW


def _is_challenge(response: requests.Response) -> bool:
    """A Cloudflare bot challenge rather than the site's own answer."""
    if response.headers.get("cf-mitigated", "").lower() == "challenge":
        return True
    if response.status_code in (403, 503):
        head = response.text[:2000]
        return "Just a moment" in head or "cf-chl" in head or "challenge-platform" in head
    return False

USER_AGENT = f"scraper_amaterskedivadlo/{__version__}"   # the script, not who runs it


class TheatreClient:
    """One polite session against amaterskedivadlo.cz, with an on-disk cache.

    See *Politeness* in the module docstring for what the pacing guarantees.
    """

    FETCH_LOG_FIELDS = ["fetched_at", "kind", "key", "url", "status", "bytes", "elapsed_s"]

    def __init__(
        self,
        out_dir: str | Path = DEFAULT_OUT_DIR,
        *,
        delay: float = DEFAULT_DELAY,
        timeout: float = 60.0,
        retries: int = 4,
        max_requests: int | None = None,
        max_consecutive_failures: int = 5,
        batch_size: int = 200,
        batch_pause: float = 20.0,
    ) -> None:
        if delay < MIN_DELAY:
            raise ValueError(f"delay={delay} s is below the {MIN_DELAY} s floor — "
                             "this site is not to be requested faster than that")
        self.out_dir = Path(out_dir)
        self.cache_dir = self.out_dir / "cache"
        self.delay = float(delay)
        self.timeout = timeout
        self.retries = retries
        self.max_requests = max_requests
        self.max_consecutive_failures = max_consecutive_failures
        self.batch_size = batch_size
        self.batch_pause = batch_pause
        self.session = requests.Session()
        self.session.headers.update({"User-Agent": USER_AGENT,
                                     "Accept-Language": "cs,en;q=0.8"})
        self.n_requests = 0
        self._pause = self.delay
        self._last_done: float | None = None
        self._consecutive_failures = 0
        self._history_ready = False

    # -- cache --------------------------------------------------------------
    def cache_path(self, kind: str, geo_id: int | None = None) -> Path:
        if kind == "map":
            return self.cache_dir / "map.xml.gz"
        return self.cache_dir / kind / f"{int(geo_id)}.html.gz"

    def read_cache(self, kind: str, geo_id: int | None = None) -> bytes | None:
        path = self.cache_path(kind, geo_id)
        if path.exists() and path.stat().st_size > 0:
            return gzip.decompress(path.read_bytes())
        return None

    def _write_cache(self, kind: str, geo_id: int | None, content: bytes) -> None:
        path = self.cache_path(kind, geo_id)
        path.parent.mkdir(parents=True, exist_ok=True)
        tmp = path.with_suffix(path.suffix + ".tmp")
        tmp.write_bytes(gzip.compress(content))
        tmp.replace(path)          # atomic: an interrupted run leaves no half-written page

    def _log_fetch(self, kind: str, key, url: str, status, n_bytes: int, elapsed: float) -> None:
        self.out_dir.mkdir(parents=True, exist_ok=True)
        path = self.out_dir / "fetch_log.csv"
        new = not path.exists()
        with open(path, "a", newline="", encoding="utf-8") as fh:
            writer = csv.writer(fh)
            if new:
                writer.writerow(self.FETCH_LOG_FIELDS)
            writer.writerow([datetime.now(timezone.utc).isoformat(timespec="seconds"),
                             kind, key, url, status, n_bytes, f"{elapsed:.2f}"])

    # -- pacing -------------------------------------------------------------
    def _wait(self) -> None:
        """Sleep until at least ``_pause`` seconds have passed since the last response."""
        if self._last_done is not None:
            remaining = self._pause - (time.monotonic() - self._last_done)
            if remaining > 0:
                time.sleep(remaining)
        if self.batch_size and self.n_requests and self.n_requests % self.batch_size == 0:
            log.info("  %d requests this run — resting %.0f s", self.n_requests, self.batch_pause)
            time.sleep(self.batch_pause)

    def _get(self, url: str, *, kind: str, key=None) -> requests.Response | None:
        """One polite GET.  Returns the response (200 or 404) or ``None`` after retries.

        Raises:
            BlockedError: a bot challenge was served.
            ServerUnhealthyError: ``max_consecutive_failures`` URLs failed in a row.
            RequestBudgetExceeded: the ``max_requests`` cap was reached.
        """
        for attempt in range(1, self.retries + 1):
            if self.max_requests is not None and self.n_requests >= self.max_requests:
                raise RequestBudgetExceeded(f"stopped at max_requests={self.max_requests}")
            self._wait()
            started = time.monotonic()
            status: int | str
            try:
                response = self.session.get(url, timeout=self.timeout)
                status = response.status_code
            except requests.RequestException as exc:
                response, status = None, exc.__class__.__name__
            elapsed = time.monotonic() - started
            self.n_requests += 1
            self._last_done = time.monotonic()
            # give a slow server room: wait at least twice as long as it took to answer
            self._pause = max(self.delay, min(MAX_ADAPTIVE_DELAY, 2 * elapsed))
            self._log_fetch(kind, key, url, status,
                            len(response.content) if response is not None else 0, elapsed)

            if response is not None and _is_challenge(response):
                raise BlockedError(
                    f"{url} answered with a bot challenge (HTTP {status}). Stopping — "
                    "wait, and contact the database's operators rather than retrying.")
            if response is not None and status in (200, 404):
                self._consecutive_failures = 0
                return response

            wait = min(MAX_BACKOFF, self.delay * 4 ** attempt)
            if response is not None:
                retry_after = _float_or_none(response.headers.get("Retry-After"))
                if retry_after:
                    wait = min(MAX_BACKOFF, max(wait, retry_after))
            if response is not None and status not in RETRY_STATUS:
                log.warning("  HTTP %s on %s — not retried", status, url)
                break
            log.warning("  %s on %s — attempt %d/%d, waiting %.0f s",
                        status, url, attempt, self.retries, wait)
            if attempt < self.retries:
                time.sleep(wait)

        self._consecutive_failures += 1
        if self._consecutive_failures >= self.max_consecutive_failures:
            raise ServerUnhealthyError(
                f"{self._consecutive_failures} URLs in a row failed — the server looks "
                "unwell, so the run stops here. Everything fetched so far is cached; "
                "re-run later to resume.")
        return None

    # -- step A -------------------------------------------------------------
    def fetch_map(self, *, refresh: bool = False) -> bytes:
        """The map XML — one request, cached."""
        cached = None if refresh else self.read_cache("map")
        if cached is not None:
            return cached
        response = self._get(MAP_URL, kind="map", key="map")
        if response is None or response.status_code != 200:
            raise RuntimeError(f"could not fetch the map XML: {MAP_URL}")
        self._write_cache("map", None, response.content)
        write_source_note(self.out_dir)
        return response.content

    # -- step B -------------------------------------------------------------
    def enable_history(self) -> None:
        """Set both view switches on this session, then prove it on the canary.

        Raises:
            HistoryViewError: the canary page is not in the historical view, or does not
                list the ensemble it is known to list.
        """
        for co in HISTORY_VIEW:
            response = self._get(SWITCH_URL.format(co=co), kind="switch", key=co)
            if response is None or response.status_code != 200:
                raise HistoryViewError(f"could not set the '{co}' view switch")
        url = PAGE_URLS["list"].format(geo_id=CANARY_GEO_ID)
        response = self._get(url, kind="canary", key=CANARY_GEO_ID)
        if response is None or response.status_code != 200:
            raise HistoryViewError("could not fetch the canary page after setting the switches")
        html = response.content.decode("utf-8", errors="replace")
        state = view_state(html)
        ensembles = parse_ensemble_list(html, CANARY_GEO_ID)
        found = any(all(e[k] == v for k, v in CANARY_ENSEMBLE.items()) for e in ensembles)
        if state != HISTORY_VIEW or not found:
            raise HistoryViewError(
                f"historical view is NOT on: switches read {state or 'absent'}, canary "
                f"geo {CANARY_GEO_ID} lists {len(ensembles)} ensemble(s) and "
                f"{'does' if found else 'does not'} include "
                f"'{CANARY_ENSEMBLE['name']} (od {CANARY_ENSEMBLE['year_from']} do "
                f"{CANARY_ENSEMBLE['year_to']})'. Nothing was cached.")
        self._write_cache("list", CANARY_GEO_ID, response.content)
        self._history_ready = True
        log.info("Historical view confirmed on the canary (geo %d, %d ensembles).",
                 CANARY_GEO_ID, len(ensembles))

    def fetch_page(self, kind: str, geo_id: int, *, refresh: bool = False) -> tuple[str | None, bool]:
        """One place page (``kind`` = ``"geo"`` or ``"list"``), from cache or the site.

        A page is cached only if it was served in the historical, full view; one that was
        not triggers a single re-establishment of the session and a second try.

        Returns:
            ``(html, fetched)`` — ``html`` is None when the page could not be had (404 or
            repeated failure; it is then retried on the next run), ``fetched`` says whether
            the network was touched.
        """
        if not refresh:
            cached = self.read_cache(kind, geo_id)
            if cached is not None:
                return cached.decode("utf-8", errors="replace"), False
        if not self._history_ready:
            self.enable_history()
        url = PAGE_URLS[kind].format(geo_id=int(geo_id))
        for attempt in (1, 2):
            response = self._get(url, kind=kind, key=geo_id)
            if response is None or response.status_code != 200:
                return None, True
            html = response.content.decode("utf-8", errors="replace")
            state = view_state(html)
            if state == HISTORY_VIEW:
                self._write_cache(kind, geo_id, response.content)
                return html, True
            if not state:
                log.warning("  %s page of geo %s carries no view switches — not a "
                            "database page, not cached", kind, geo_id)
                return None, True
            if attempt == 1:
                log.warning("  %s page of geo %s came back in view %s — session lost; "
                            "re-establishing", kind, geo_id, state)
                self.enable_history()
        raise HistoryViewError(
            f"{kind} page of geo {geo_id} is still not in the historical view after the "
            "session was re-established. Stopping; nothing wrong was cached.")

_IS_KRAJ = re.compile(r"\bkraj\b|^Praha, hlavní město$", re.I)


def places_table(xml: bytes | str):
    """The step-A places table: :func:`parse_map_xml` plus the units the XML leaves implicit.

    The info window's first link is the place's *parent unit*, which is the kraj for an
    ordinary obec but the city for a city district (``Ostrava``, ``Plzeň``), and the parts
    of Prague and Plzeň carry no okres link at all.  So that every place has a kraj and an
    okres to be tabulated by:

    * a "kraj" that is not a kraj is moved to ``parent_obec``;
    * a missing okres is inherited from the parent place's row;
    * a missing kraj is the kraj of the other places of the same okres.

    ``units_inferred`` marks the rows this touched.  Key ``geo_id``, asserted.
    """
    import pandas as pd

    places = pd.DataFrame(parse_map_xml(xml), columns=PLACE_COLUMNS)
    _assert_key(places, "geo_id", "places")
    original = places[["okres", "kraj"]].copy()

    not_kraj = places["kraj"].notna() & ~places["kraj"].fillna("").str.contains(_IS_KRAJ)
    move = not_kraj & places["parent_obec"].isna()
    places.loc[move, ["parent_obec", "parent_obec_geo_id"]] = (
        places.loc[move, ["kraj", "kraj_geo_id"]].to_numpy())
    places.loc[not_kraj, ["kraj", "kraj_geo_id"]] = None

    for _ in range(2):                     # a part of a part needs a second pass
        parent = places.set_index("geo_id")[["okres", "okres_geo_id"]]
        missing = places["okres"].isna() & places["parent_obec_geo_id"].notna()
        inherited = parent.reindex(places.loc[missing, "parent_obec_geo_id"])
        places.loc[missing, ["okres", "okres_geo_id"]] = inherited.to_numpy()

    known = places.dropna(subset=["kraj", "okres_geo_id"])
    okres_kraj = (known.groupby("okres_geo_id")[["kraj", "kraj_geo_id"]]
                  .agg(lambda s: s.mode().iloc[0]))
    missing = places["kraj"].isna() & places["okres_geo_id"].notna()
    filled = okres_kraj.reindex(places.loc[missing, "okres_geo_id"])
    places.loc[missing, ["kraj", "kraj_geo_id"]] = filled.to_numpy()

    places["units_inferred"] = (original["okres"].fillna("") != places["okres"].fillna("")) | (
        original["kraj"].fillna("") != places["kraj"].fillna(""))
    for col in set(_PLACE_INT_COLUMNS) & set(places.columns):
        places[col] = places[col].astype("Int64")
    return places


def _assert_key(frame, key, name: str) -> None:
    keys = [key] if isinstance(key, str) else list(key)
    if frame[keys].isna().any().any():
        raise AssertionError(f"{name}: key {keys} has missing values")
    if frame.duplicated(keys).any():
        raise AssertionError(f"{name}: key {keys} is not unique "
                             f"({int(frame.duplicated(keys).sum())} duplicate rows)")


def select_geo_ids(places, *, okresy: Iterable[str] | None = None,
                   geo_ids: Iterable[int] | None = None) -> list[int]:
    """Geo ids to scrape: every place of the named okresy, and/or explicit ids."""
    chosen: list[int] = [int(g) for g in (geo_ids or [])]
    if okresy:
        wanted = {o.strip().casefold() for o in okresy}
        known = {str(o).casefold() for o in places["okres"].dropna().unique()}
        if wanted - known:
            raise ValueError(f"okres not in the places table: {sorted(wanted - known)}")
        mask = places["okres"].str.casefold().isin(wanted)
        chosen += places.loc[mask, "geo_id"].astype(int).tolist()
    return sorted(set(chosen))

def scrape_places(
    geo_ids: Iterable[int],
    out_dir: str | Path = DEFAULT_OUT_DIR,
    *,
    pages: tuple[str, ...] = ("geo",),
    client: TheatreClient | None = None,
    progress: bool = True,
    **client_kwargs,
) -> dict:
    """Step B: fetch the pages of each place into the cache.  Resumable.

    A page already in the cache is not requested again, so an interrupted run is resumed
    by calling this again with the same ids.  Nothing is parsed here — see
    :func:`build_tables`.

    Args:
        geo_ids: places to fetch (see :func:`select_geo_ids`).
        pages: which pages per place — ``"geo"`` (the entry; carries the ensembles too)
            and/or ``"list"`` (the ensemble list alone).  The default is the entry only:
            on the pilot sample the two named the same ensembles on every place compared,
            so the second request per place buys nothing (:func:`compare_sources`).
        client_kwargs: passed to :class:`TheatreClient` (``delay``, ``max_requests`` …).

    Returns:
        Counts: ``places, cached, fetched, failed, requests``.
    """
    unknown = set(pages) - set(PAGE_URLS)
    if unknown:
        raise ValueError(f"unknown page kind(s): {sorted(unknown)}")
    client = client or TheatreClient(out_dir, **client_kwargs)
    ids = sorted({int(g) for g in geo_ids})
    summary = {"places": len(ids), "cached": 0, "fetched": 0, "failed": 0, "requests": 0}
    failed: list[tuple[str, int]] = []

    bar = page_bar(len(ids), "amaterskedivadlo", enabled=progress, unit="place")
    with bar, redirect_logging():
        for i, geo_id in enumerate(ids, 1):
            for kind in pages:
                html, fetched = client.fetch_page(kind, geo_id)
                if html is None:
                    summary["failed"] += 1
                    failed.append((kind, geo_id))
                elif fetched:
                    summary["fetched"] += 1
                else:
                    summary["cached"] += 1
            bar.update(1)
            bar.set_postfix(fetched=summary["fetched"], failed=summary["failed"], refresh=False)
            if not getattr(bar, "live", False) and (i % 50 == 0 or i == len(ids)):
                log.info("  … %d/%d places (%d pages fetched this run)",
                         i, len(ids), summary["fetched"])

    summary["requests"] = client.n_requests
    if failed:
        log.warning("%d page(s) could not be fetched and will be retried on the next run: %s",
                    len(failed), failed[:10])
    log.info("Step B: %(places)d places — %(fetched)d pages fetched, %(cached)d from cache, "
             "%(failed)d failed, %(requests)d requests", summary)
    return summary


def _cached_ids(out_dir: Path, kind: str) -> list[int]:
    folder = out_dir / "cache" / kind
    return sorted(int(p.name.split(".")[0]) for p in folder.glob("*.html.gz")) if folder.exists() else []


def _read_page(out_dir: Path, kind: str, geo_id: int) -> str:
    raw = gzip.decompress((out_dir / "cache" / kind / f"{geo_id}.html.gz").read_bytes())
    return raw.decode("utf-8", errors="replace")


ENSEMBLE_COLUMNS = ["ensemble_id", "geo_id", "name", "year_from", "year_to",
                    "year_from_precision", "year_to_precision", "open_ended",
                    "year_from_raw", "year_to_raw", "span_raw", "status", "source_page"]


def build_tables(out_dir: str | Path = DEFAULT_OUT_DIR):
    """Parse the cache into the two tables.  No network.

    * ``places.csv`` — the step-A table (every place in the database) with the place-page
      fields joined on for the places whose page is cached; ``page_cached`` says which.
      Key ``geo_id``.
    * ``ensembles.csv`` — one row per ensemble **per place it is listed under**, key
      ``(ensemble_id, geo_id)``.  Read from the list page where that is cached, otherwise
      from the place page's own block; ``source_page`` says which.

    Returns:
        ``(places, ensembles)`` as DataFrames.
    """
    import pandas as pd

    out_dir = Path(out_dir)
    xml = TheatreClient(out_dir).read_cache("map")
    if xml is None:
        raise FileNotFoundError("no cached map XML — run step A (fetch_places) first")
    places = places_table(xml)

    geo_ids, list_ids = _cached_ids(out_dir, "geo"), _cached_ids(out_dir, "list")
    page_rows = [parse_place_page(_read_page(out_dir, "geo", g), g) for g in geo_ids]
    ensemble_rows: list[dict] = []
    for g in list_ids:
        ensemble_rows += [{**row, "source_page": "list"}
                          for row in parse_ensemble_list(_read_page(out_dir, "list", g), g)]
    for g in sorted(set(geo_ids) - set(list_ids)):
        ensemble_rows += [{**row, "source_page": "geo"}
                          for row in parse_place_ensembles(_read_page(out_dir, "geo", g), g)]

    n_before = len(places)
    if page_rows:
        pages = pd.DataFrame(page_rows)
        _assert_key(pages, "geo_id", "place pages")
        places = places.merge(pages, on="geo_id", how="left", validate="1:1", indicator=True)
        places["page_cached"] = places.pop("_merge").eq("both")
        orphans = set(pages["geo_id"]) - set(places["geo_id"])
        if orphans:
            log.warning("%d cached place page(s) are not in the map XML: %s",
                        len(orphans), sorted(orphans)[:10])
    else:
        places["page_cached"] = False
    assert len(places) == n_before, "the place-page merge changed the number of places"
    places["list_cached"] = places["geo_id"].isin(set(list_ids) | set(geo_ids))

    ensembles = pd.DataFrame(ensemble_rows, columns=ENSEMBLE_COLUMNS)
    if len(ensembles):
        _assert_key(ensembles, ["ensemble_id", "geo_id"], "ensembles")
    for col in ("year_from", "year_to"):
        ensembles[col] = ensembles[col].astype("Int64")
    for col in set(_PLACE_INT_COLUMNS) & set(places.columns):
        places[col] = places[col].astype("Int64")

    places.to_csv(out_dir / "places.csv", index=False, encoding="utf-8")
    ensembles.to_csv(out_dir / "ensembles.csv", index=False, encoding="utf-8")
    log.info("Tables: %d places (%d with a cached page), %d ensemble rows over %d places",
             len(places), int(places["page_cached"].sum()), len(ensembles),
             ensembles["geo_id"].nunique())
    return places, ensembles


def compare_sources(out_dir: str | Path = DEFAULT_OUT_DIR) -> dict:
    """Do the list page and the place page name the same ensembles, with the same years?

    Compared over every place for which both pages are cached.  If they agree, the full
    run needs only one page per place (``pages=("geo",)``) — half the requests.

    Returns:
        ``places_compared``, ``places_identical``, and ``differing`` (geo ids whose
        ``(ensemble_id, name, year_from_raw, year_to_raw)`` sets differ).
    """
    out_dir = Path(out_dir)
    both = sorted(set(_cached_ids(out_dir, "geo")) & set(_cached_ids(out_dir, "list")))

    def signature(rows: list[dict]) -> set:
        return {(r["ensemble_id"], r["name"], r["year_from_raw"], r["year_to_raw"]) for r in rows}

    differing = [g for g in both
                 if signature(parse_ensemble_list(_read_page(out_dir, "list", g), g))
                 != signature(parse_place_ensembles(_read_page(out_dir, "geo", g), g))]
    return {"places_compared": len(both), "places_identical": len(both) - len(differing),
            "differing": differing}


def estimate_full_run(out_dir: str | Path = DEFAULT_OUT_DIR, *, pages: tuple[str, ...] = ("geo",),
                      delay: float = DEFAULT_DELAY, batch_size: int = 200,
                      batch_pause: float = 20.0) -> dict:
    """Requests and hours the rest of step B would take, from what this cache has seen.

    The response time is the mean of the place pages already in ``fetch_log.csv``; the
    pause per request is the client's own rule (``max(delay, 2 × response time)``).

    Returns:
        ``places_total, pages_cached, requests_left, mean_response_s, hours``.
    """
    import pandas as pd

    out_dir = Path(out_dir)
    xml = TheatreClient(out_dir).read_cache("map")
    if xml is None:
        raise FileNotFoundError("no cached map XML — run step A (fetch_places) first")
    n_places = len(parse_map_xml(xml))
    cached = sum(len(_cached_ids(out_dir, kind)) for kind in pages)
    requests_left = n_places * len(pages) - cached
    log_path = out_dir / "fetch_log.csv"
    mean_response = 0.0
    if log_path.exists():
        fetch_log = pd.read_csv(log_path)
        seen = fetch_log.loc[fetch_log["kind"].isin(PAGE_URLS), "elapsed_s"]
        mean_response = float(seen.mean()) if len(seen) else 0.0
    per_request = max(delay, 2 * mean_response) + mean_response
    rests = (requests_left // batch_size) * batch_pause if batch_size else 0.0
    return {"places_total": n_places, "pages_cached": cached, "requests_left": requests_left,
            "mean_response_s": round(mean_response, 2),
            "hours": round((requests_left * per_request + rests) / 3600, 1)}

def build_parser() -> argparse.ArgumentParser:
    p = argparse.ArgumentParser(
        description="Scrape the Databáze českého amatérského divadla (feasibility pilot).",
        formatter_class=argparse.ArgumentDefaultsHelpFormatter,
    )
    p.add_argument("--step", choices=["map", "places", "tables", "compare"], required=True,
                   help="map = step A (one request); places = step B for the selected "
                        "places; tables = parse the cache; compare = list page vs place page")
    p.add_argument("--out-dir", default=str(DEFAULT_OUT_DIR))
    p.add_argument("--okres", nargs="+", metavar="NAME",
                   help="step B: every place of these okresy (names as in the map XML)")
    p.add_argument("--geo-ids", nargs="+", type=int, metavar="ID", help="step B: explicit ids")
    p.add_argument("--all", action="store_true",
                   help="step B: every place in the map XML (the full run — hours)")
    p.add_argument("--pages", nargs="+", choices=sorted(PAGE_URLS), default=["geo"],
                   help="step B: which pages to fetch per place (the place entry carries "
                        "the ensemble list too; add 'list' only to cross-check)")
    p.add_argument("--delay", type=float, default=DEFAULT_DELAY,
                   help=f"seconds between requests (floor {MIN_DELAY})")
    p.add_argument("--max-requests", type=int, default=None, help="stop after this many requests")
    p.add_argument("--no-progress", action="store_true")
    p.add_argument("-v", "--verbose", action="store_true")
    return p


def main(argv: list[str] | None = None) -> int:
    args = build_parser().parse_args(argv)
    logging.basicConfig(level=logging.DEBUG if args.verbose else logging.INFO,
                        format="%(asctime)s %(message)s", datefmt="%H:%M:%S")
    client_kwargs = {"delay": args.delay, "max_requests": args.max_requests}
    try:
        if args.step == "map":
            fetch_places(args.out_dir, **client_kwargs)
        elif args.step == "places":
            places = fetch_places(args.out_dir, **client_kwargs)     # cached after step A
            ids = (places["geo_id"].astype(int).tolist() if args.all
                   else select_geo_ids(places, okresy=args.okres, geo_ids=args.geo_ids))
            if not ids:
                log.error("no places selected — give --okres, --geo-ids or --all")
                return 2
            scrape_places(ids, args.out_dir, pages=tuple(args.pages),
                          progress=not args.no_progress, **client_kwargs)
            build_tables(args.out_dir)
        elif args.step == "tables":
            build_tables(args.out_dir)
        else:
            result = compare_sources(args.out_dir)
            log.info("list page vs place page: %d of %d places identical; differing: %s",
                     result["places_identical"], result["places_compared"],
                     result["differing"][:20])
    except (HistoryViewError, BlockedError, ServerUnhealthyError, RequestBudgetExceeded) as exc:
        log.error("STOPPED: %s", exc)
        return 1
    return 0
