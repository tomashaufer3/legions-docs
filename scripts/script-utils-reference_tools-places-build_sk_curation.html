TL;DR

Magyar → Slovak/Rusyn name curation for the 1910 Upper-Hungary (Felvidék) backbone (utils.parsing.districts_hu). Keyed by the Magyar unit name (name_hu) and Magyar county name so it survives id changes. 1910-era Slovak forms are used for sk (e.g. Liptovský Svätý Mikuláš, Turčiansky Svätý Martin) because the soldier records use period spellings; cs_modern carries today's name where the town was renamed.

How it works

Genuinely-Hungarian towns (Borsod / Heves counties, and border seats such as Szob, Sátoraljaújhely, Tokaj) are left blank — records never name them in Slovak. A few obscure Subcarpathian-Rusyn seats are left blank (flagged by districts_hu.jaras_report) pending review.

sk_alt carries two kinds of curated alias, both read by utils.parsing.lexikon_sk and utils.parsing.records_geo_hu: a high-frequency non-seat settlement that stands in for its containing járás (UNIT_SK_BY_ID), and an adjectival district name the Majo lexicón prints in place of a seat (DISTRICT_ADJ_SK).

def main() -> None:
    bb = dzh.build_jaras_backbone(SHP_DIR, curation_csv=None)
    rows = []
    for mid, sub in bb.drop_duplicates("megye_id").groupby("megye_id"):
        hu = sub.iloc[0]["megye_hu"]
        rows.append({"level": "megye", "key": mid, "hu": hu, "unit_type": "",
                     "sk": MEGYE_SK.get(hu, ""), "cs_modern": ""})
    for _, r in bb.iterrows():
        rows.append({"level": "jaras", "key": r["unit_id"], "hu": r["name_hu"],
                     "unit_type": r["unit_type"], "sk": SEAT_SK.get(r["name_hu"], ""),
                     "sk_alt": (UNIT_SK_BY_ID.get(r["unit_id"])
                                or DISTRICT_ADJ_SK.get(r["unit_id"], "")),
                     "cs_modern": MODERN.get(r["name_hu"], "")})
    import pandas as pd
    dd = pd.DataFrame(rows, columns=["level", "key", "hu", "unit_type", "sk", "sk_alt", "cs_modern"])
    dd.to_csv(OUT, index=False, encoding="utf-8")
    n_unit = (dd["level"] == "jaras").sum()
    n_named = ((dd["level"] == "jaras") & (dd["sk"] != "")).sum()
    print(f"wrote {OUT.relative_to(ROOT)}  ({len(dd)} rows; "
          f"{n_named}/{n_unit} units + {(dd['level']=='megye').sum()} counties Slovak-named)")

# Adjectival Slovak DISTRICT names — the form the Majo (2012) lexicón prints for three okres
# blocks, which names the district rather than its seat and so reaches the backbone through no
# other route. "Hradný" is Vári járás (seat Turdossin/Tvrdošín) — Orava castle, `vár` = castle,
# and _hu_adj_base("Vári") gives "Vár", which is not a chartered town and therefore not in the
# backbone's own Magyar→Slovak dictionary. Likewise "Pohronský" for Garamvölgyi (the upper Hron
# valley) and "Medzibodrocký" for Bodrogközi (the Bodrogköz). Written into `sk_alt`, which both
# lexikon_sk's district lookup and records_geo_hu's record lookup already read — so a soldier
# whose birth district is recorded as "Hradný" resolves too. DECISIONS D-21.

}
