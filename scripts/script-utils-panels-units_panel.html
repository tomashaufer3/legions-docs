How it works

================== =========================== ========================================== table key built by ================== =========================== ========================================== unit table unit_key build_unit_table from the person file unit panel unit_key × period build_unit_panel from a person-period spell frame (built by the spells module) ================== =========================== ==========================================

Both tables carry aggregates only: no person attribute is copied in. The unit a man is counted in is his unit at Legion entry (Jednotka v době zařazení); csol.cz does not date transfers, so the panel holds him in that unit for his whole spell (see ASSIGNMENT_RULE — a call for the author).

The Fidler (2025) authority is a check, never a source

reference/units/unit_authority.csv and unit_timeline.csv are read from Fidler's Encyklopedie československých legií and are validation only (CLAUDE.md). The unit table joins them as check columns — the theatres and formation dates the encyclopedia gives a regiment's name, whether the records' own theatre agrees, and how the records' entry dates sit against the name's tenure — and overwrites nothing with them.

The theatre check is weak by construction: pass 1 of theater.py reads the theatre off the same unit parenthetical that sets legion_army in unit_key (VALIDATION_FIDLER.md §2.7), so on a Czechoslovak-Legion key agreement largely restates the key, and it cannot test the imputed theatres. Its population also differs from data_checks._theatre_vs_fidler (which takes stř/p regiments only and counts an Unknown theatre as a conflict; this one adds jízd/děl regiments and leaves Unknown out), so the two rates are not one measure.

The lineage caveat (VALIDATION_FIDLER.md §2.6)

One regiment name has several Fidler headwords, and the transitions between them are of two kinds. Fidler records every one as renamed with the command (velitelství) carried over, so the encyclopedia itself does not say "a different body of men" anywhere:

  • a rename of the same body — the 1918 round-trip: the N. čs. střelecký pluk was renamed N. čs. pěší pluk on 20 Aug 1918 and back to N. čs. střelecký pluk [II]/[III] on 7 Oct 1918 (regiments 1–12). Entries dated in that window carry the pěší name, which is why a střelecký key shows entries "not in force" then;
  • a contraction and re-formation — regiments 1–3 after Zborov: [I] became a combined battalion (Sloučený prapor) on 23/24 Jul 1917, and [II] was formed from it on 30 Jul 1917. Only this kind could plausibly separate two bodies of men.

So a unit_key read off a record is one name, possibly several headwords. add_lineage_columns places every dated entry against the tenures of the name's headwords and flags the unit when its entries fall in more than one, or on a date the name was not in force. It merges and splits nothing: the flag, the counts and the kind of each transition are for the author to rule on. lineage_spans_variants is the informative flag; lineage_name_out_of_force fires on almost every regiment, mostly from entries dated before the regiment was formed (the record names the regiment a man served in, his enroll_date the day he joined the Legion), so lineage_flag (their OR) separates little. A key whose theatre contradicts Fidler's (e.g. 1.stř.pl. @ CS Legion (Italy)) is a source contradiction (VALIDATION_FIDLER.md §2.5), not a lineage finding: its lineage columns are &lt;NA&gt; and lineage_status says why.

def match_authority(unit_keys: pd.DataFrame, authority: pd.DataFrame) -> pd.DataFrame:
    """Long table: each Legion regiment ``unit_key`` × the Fidler headwords its name matches.

    Args:
        unit_keys: frame with ``unit_key``, ``regiment``, ``legion_army`` (one row per unit).
        authority: ``unit_authority.csv`` as read.

    Returns:
        ``unit_key, unit_cs, variant, authority_theatre, authority_formed, match_kind``;
        a unit with no headword has no row.
    """
    auth = authority[(authority["kind"] == "unit") & authority["number"].notna()].copy()
    auth["number"] = auth["number"].astype(int)
    rows = []
    legion = unit_keys["legion_army"].astype("string").str.startswith(LEGION_ARMY_PREFIX, na=False)
    for uk, reg in zip(unit_keys.loc[legion, UNIT_KEY], unit_keys.loc[legion, "regiment"]):
        for pattern, head in REGIMENT_HEADS:
            m = re.match(pattern, str(reg))
            if not m:
                continue
            n = int(m.group(1))
            hit = auth[(auth["number"] == n) & auth["unit_cs"].str.contains(
                rf"ČS\. {head}(?: \[[IVX]+\])?$", regex=True, na=False)]
            kind = "exact_type"
            abbrev = re.match(r"^\d+\.\s?(\w+)\.pl\.$", str(reg))
            if hit.empty and abbrev and abbrev.group(1) in INFANTRY_ABBREVS:
                alt = "|".join(INFANTRY_HEADS)
                hit = auth[(auth["number"] == n) & auth["unit_cs"].str.contains(
                    rf"ČS\. (?:{alt})(?: \[[IVX]+\])?$", regex=True, na=False)]
                kind = "number_infantry"
            for r in hit.itertuples(index=False):
                rows.append((uk, r.unit_cs, r.variant, r.theatre, r.formed, kind))
            break
    cols = [UNIT_KEY, "unit_cs", "variant", "authority_theatre", "authority_formed", "match_kind"]
    out = pd.DataFrame(rows, columns=cols)
    out["authority_formed"] = pd.to_datetime(out["authority_formed"], errors="coerce")
    return out

def add_authority_columns(units: pd.DataFrame, persons: pd.DataFrame,
                          matches: pd.DataFrame) -> pd.DataFrame:
    """Join the Fidler check columns onto the unit table (left, 1:1); nothing is overwritten.

    ``authority_theatre_agrees`` and ``authority_*_records_agree`` mostly re-read the unit
    parenthetical that also set ``legion_army`` (module docstring): a consistency check of the
    key against Fidler, not a test of the theatre imputation.
    """
    if matches.empty:
        agg = pd.DataFrame(columns=["authority_match", "authority_units", "authority_theatres",
                                    "authority_formed_first"]).rename_axis(UNIT_KEY)
    else:
        g = matches.groupby(UNIT_KEY)
        agg = pd.DataFrame({
            "authority_match": g["match_kind"].first(),
            "authority_units": g["unit_cs"].agg(lambda s: "; ".join(sorted(s))),
            "authority_theatres": g["authority_theatre"].agg(lambda s: ";".join(sorted(set(s)))),
            "authority_formed_first": g["authority_formed"].min(),
        })
    n0 = len(units)
    out = units.merge(agg, left_index=True, right_index=True, how="left", validate="1:1")
    assert len(out) == n0, "authority join changed the unit count"
    for col in ("authority_match", "authority_units", "authority_theatres"):
        out[col] = out[col].astype("string")
    out["authority_formed_first"] = pd.to_datetime(out["authority_formed_first"])
    tset = out["authority_theatres"].str.split(";")
    agree = [pd.NA if (not isinstance(ts, list) or pd.isna(m)) else (m in ts)
             for ts, m in zip(tset, out["theater_modal"])]
    out["authority_theatre_agrees"] = pd.array(agree, dtype="boolean")
    rec = persons.loc[persons[UNIT_KEY].notna(), [UNIT_KEY, THEATRE]]
    rec = rec[rec[THEATRE].notna() & (rec[THEATRE] != UNKNOWN_THEATRE)]
    n1 = len(rec)
    rec = rec.merge(out[["authority_theatres"]], left_on=UNIT_KEY, right_index=True,
                    how="inner", validate="m:1")
    assert len(rec) <= n1
    rec = rec[rec["authority_theatres"].notna()]
    rec["_agree"] = [t in s.split(";") for t, s in zip(rec[THEATRE], rec["authority_theatres"])]
    n_agree = rec.groupby(UNIT_KEY)["_agree"].sum()
    has = out["authority_match"].notna()
    out["authority_n_records_agree"] = (n_agree.reindex(out.index).fillna(0)
                                        .astype("Int64").where(has))
    out["authority_share_records_agree"] = (out["authority_n_records_agree"].astype("Float64")
                                            / out["n_theater_known"].astype("Float64")
                                            ).where(has & (out["n_theater_known"] > 0))
    return out

def classify_entries(entries: pd.DataFrame, variants: pd.DataFrame) -> pd.DataFrame:
    """Place each entry against its unit's name tenures.

    Args:
        entries:  ``entry, unit_key, lo, hi`` (the possible-date window of each entry).
        variants: ``unit_key, unit_cs, start, end`` (``end`` NaT = still in force).

    Returns:
        ``entry, unit_key, state``: the headword whose tenure holds the whole window; else
        ``before_name`` (window ends before the earliest tenure), ``not_in_force`` (touches no
        tenure otherwise) or ``ambiguous`` (touches a tenure without lying inside one).
    """
    x = entries.merge(variants, on=UNIT_KEY, how="inner", validate="m:m")
    open_end = x["end"].isna()
    x["inside"] = (x["lo"] >= x["start"]) & (open_end | (x["hi"] < x["end"]))
    x["touch"] = (x["hi"] >= x["start"]) & (open_end | (x["lo"] < x["end"]))
    g = x.groupby("entry")
    n_in, n_touch = g["inside"].sum(), g["touch"].sum()
    first_start = g["start"].min()
    hi = g["hi"].first()
    pick = x[x["inside"]].groupby("entry")["unit_cs"].first()
    state = pd.Series(STATE_AMBIGUOUS, index=n_in.index, dtype="object")
    state[(n_touch == 0) & (hi < first_start)] = STATE_BEFORE
    state[(n_touch == 0) & ~(hi < first_start)] = STATE_OUT
    one = n_in == 1
    state[one] = pick.reindex(state.index)[one]
    out = state.rename("state").reset_index()
    return out.merge(entries[["entry", UNIT_KEY]], on="entry", how="left", validate="1:1")

def calendar_period_check(spells: pd.DataFrame, period: str,
                          calendar_col: str | None = SPELLS_CALENDAR) -> None:
    """Refuse a period column that is not a calendar period.

    Under ``build_spells(clock="duration")`` ``period_index`` counts periods since each man's
    own entry, so one value is many calendar months: a unit × ``period_index`` panel would be a
    unit × tenure panel. The test: ``period`` must map to exactly one ``calendar_col`` value
    (``period_start``, the calendar start under either clock). A datetime period is calendar by
    construction; ``calendar_col=None`` skips the test (the caller vouches for the clock).
    """
    if period == calendar_col or pd.api.types.is_datetime64_any_dtype(spells[period]):
        return
    if calendar_col is None:
        return
    if calendar_col not in spells.columns:
        raise KeyError(f"spells lacks {calendar_col!r}, needed to prove {period!r} is calendar time")
    pairs = spells[[period, calendar_col]].drop_duplicates()
    if pairs[period].duplicated().any() or pairs[calendar_col].duplicated().any():
        raise ValueError(f"{period!r} is not one-to-one with {calendar_col!r}: a duration clock? "
                         f"Use period={calendar_col!r}, or build_spells(..., clock='calendar')")

"""
units_panel.py — the Legion unit table and the unit × period panel
===================================================================

Two tables for unit fixed effects, clustering and size denominators, both keyed on
``unit_key`` (``"regiment @ army"``, ``utils/parsing/units.py``): ``regiment`` alone is not a
unit, because every army numbered its own regiments (D-02; ``1.pl.`` is mostly the French
Foreign Legion's first regiment, not the Czechoslovak 1st Rifle).

==================  ===========================  ==========================================
table               key                          built by
==================  ===========================  ==========================================
unit table          ``unit_key``                 :func:`build_unit_table` from the person file
unit panel          ``unit_key`` × period        :func:`build_unit_panel` from a person-period
                                                 spell frame (built by the spells module)
==================  ===========================  ==========================================

Both tables carry **aggregates only**: no person attribute is copied in. The unit a man is
counted in is his unit *at Legion entry* (``Jednotka v době zařazení``); csol.cz does not date
transfers, so the panel holds him in that unit for his whole spell (see
:data:`ASSIGNMENT_RULE` — a call for the author).

The Fidler (2025) authority is a check, never a source
------------------------------------------------------
``reference/units/unit_authority.csv`` and ``unit_timeline.csv`` are read from Fidler's
*Encyklopedie československých legií* and are **validation only** (CLAUDE.md). The unit table
joins them as *check columns* — the theatres and formation dates the encyclopedia gives a
regiment's name, whether the records' own theatre agrees, and how the records' entry dates sit
against the name's tenure — and overwrites nothing with them.

The theatre check is weak by construction: pass 1 of ``theater.py`` reads the theatre off the
same unit parenthetical that sets ``legion_army`` in ``unit_key`` (VALIDATION_FIDLER.md §2.7),
so on a Czechoslovak-Legion key agreement largely restates the key, and it cannot test the
imputed theatres. Its population also differs from ``data_checks._theatre_vs_fidler`` (which
takes ``stř``/``p`` regiments only and counts an Unknown theatre as a conflict; this one adds
``jízd``/``děl`` regiments and leaves Unknown out), so the two rates are not one measure.

The lineage caveat (VALIDATION_FIDLER.md §2.6)
----------------------------------------------
One regiment name has several Fidler headwords, and the transitions between them are of two
kinds. Fidler records every one as ``renamed`` with the command (*velitelství*) carried over,
so the encyclopedia itself does not say "a different body of men" anywhere:

* **a rename of the same body** — the 1918 round-trip: the ``N. čs. střelecký pluk`` was
  renamed ``N. čs. pěší pluk`` on 20 Aug 1918 and back to ``N. čs. střelecký pluk [II]/[III]``
  on 7 Oct 1918 (regiments 1–12). Entries dated in that window carry the pěší name, which is
  why a ``střelecký`` key shows entries "not in force" then;
* **a contraction and re-formation** — regiments 1–3 after Zborov: ``[I]`` became a combined
  battalion (*Sloučený prapor*) on 23/24 Jul 1917, and ``[II]`` was formed from it on 30 Jul
  1917. Only this kind could plausibly separate two bodies of men.

So a ``unit_key`` read off a record is one name, possibly several headwords.
:func:`add_lineage_columns` places every dated entry against the tenures of the name's
headwords and flags the unit when its entries fall in more than one, or on a date the name was
not in force. It **merges and splits nothing**: the flag, the counts and the kind of each
transition are for the author to rule on. ``lineage_spans_variants`` is the informative flag;
``lineage_name_out_of_force`` fires on almost every regiment, mostly from entries dated before
the regiment was formed (the record names the regiment a man served in, his ``enroll_date`` the
day he joined the Legion), so ``lineage_flag`` (their OR) separates little. A key whose theatre contradicts Fidler's (e.g.
``1.stř.pl. @ CS Legion (Italy)``) is a source contradiction (VALIDATION_FIDLER.md §2.5), not
a lineage finding: its lineage columns are ``<NA>`` and ``lineage_status`` says why.

Usage
-----
    from utils.panels import units_panel as up
    from utils.panels.spells import build_spells
    persons = pd.read_parquet("data/final/persons/legionnaires_clean.parquet")
    units = up.build_unit_table(persons, *up.load_unit_references())
    _, periods = build_spells(persons)                    # either clock: the panel is calendar
    panel = up.build_unit_panel(periods, persons[["legion_id", "unit_key"]], unit_table=units)
    up.units_panel_report(units, panel)

Changelog
---------
0.3.0 (2026-11-18)  The second check's LOWs (D-260): every ``REGIMENT_HEADS`` pattern tolerates a
                    space after the number (``2. jízd.pl.`` now reaches its headword, as
                    ``2. leh.děl.pl.`` did); a nullable-string ``exit_codes`` is read as the
                    plain one (``<NA>`` no code); ``last_enroll_date_could_be_later`` says where a
                    month- or year-precise entry may fall after the stored latest entry date.
                    Built in notebook 04 on the ruled headline spells (``panels/unit_panel``).
0.2.0 (2026-11-18)  Fits the spells module's real ``spell_periods``: the ``"none"`` event is no
                    exit (``no_event``), events must be spells outcome labels (``allowed_events``),
                    the desertion event is ``"desertion"``, an ``<NA>`` at_risk is refused or
                    excluded and counted (``unknown_risk``), and the panel period is the calendar
                    ``period_start`` by default (an integer period must be a calendar clock, or
                    the build refuses it). Lineage verdicts withheld on a theatre contradiction
                    (``lineage_status``); first/last entry date precision; whitespace spelling
                    collisions of unit_key listed, not merged.
0.1.0 (2026-11-18)  First build: unit table with Fidler check columns and lineage flags; unit ×
                    period panel against the spells interface (person, period, at_risk, event).

def _exit_code_sets(codes: pd.Series) -> pd.Series:
    """``"DM;X"`` → ``{"DM", "X"}``; a missing or blank cell → ``None`` (no code recorded)."""
    def split(v):
        if v is None or (not isinstance(v, str) and pd.isna(v)) or not str(v).strip():
            return None
        return {c.strip() for c in str(v).split(";") if c.strip()}
    # astype(object): a nullable "string" column's map would skip <NA> and hand it back (0.3.0)
    return codes.astype(object).map(split)


# ═════════════════════════════════════════ unit table ═══════════════════════════════════
def _unit_aggregates(persons: pd.DataFrame, person_col: str) -> pd.DataFrame:
    """Counts, dates and desertion per ``unit_key`` (records with no unit are not a unit)."""
    p = persons[persons[UNIT_KEY].notna()].copy()
    for col in UNIT_ATTRS:                                    # a function of the key, or a bug
        n = p.groupby(UNIT_KEY)[col].nunique(dropna=False)
        if (n > 1).any():
            raise ValueError(f"{col} varies within unit_key: {list(n[n > 1].index[:5])}")
    codes = _exit_code_sets(p[EXIT_CODES])
    p["_exit_recorded"] = codes.map(lambda s: isinstance(s, set))
    p["_deserted"] = codes.map(lambda s: isinstance(s, set) and DESERTION_CODE in s)
    g = p.groupby(UNIT_KEY, sort=True)
    out = g[list(UNIT_ATTRS)].first()
    out["n_enrolled"] = g[person_col].nunique().astype("Int64")
    out["n_enroll_dated"] = g[ENTRY_DATE].count().astype("Int64")
    out["first_enroll_date"] = g[ENTRY_DATE].min()
    out["first_enroll_date_precision"] = _bound_precision(p, "min")
    out["last_enroll_date"] = g[ENTRY_DATE].max()
    out["last_enroll_date_precision"] = _bound_precision(p, "max")
    out["last_enroll_date_could_be_later"] = _could_be_later(p, out["last_enroll_date"])
    out["n_exit_recorded"] = g["_exit_recorded"].sum().astype("Int64")
    out["n_deserted"] = g["_deserted"].sum().astype("Int64")
    base = out["n_exit_recorded"].astype("Float64")
    out["desertion_rate"] = (out["n_deserted"] / base).where(base > 0)   # no base → <NA>
    return out


def _bound_precision(p: pd.DataFrame, how: str) -> pd.Series:
    """Precision of a unit's earliest (``how="min"``) or latest stored entry date.

    Several records can share the bound with different precisions (``1917-01-01`` as a day and
    as a year): the coarsest is given, since the bound is then only that precise. ``<NA>`` where
    a record at the bound has no known precision.
    """
    d = p.loc[p[ENTRY_DATE].notna(), [UNIT_KEY, ENTRY_DATE, ENTRY_PRECISION]]
    at = d[d[ENTRY_DATE] == d.groupby(UNIT_KEY)[ENTRY_DATE].transform(how)]
    rank = at[ENTRY_PRECISION].astype("string").map(
        {name: i for i, name in enumerate(PRECISION_ORDER)}).astype("Float64")
    g = rank.groupby(at[UNIT_KEY])
    coarsest = g.max().where(~rank.isna().groupby(at[UNIT_KEY]).any())
    labels = pd.Series(PRECISION_ORDER, dtype="string")
    return coarsest.map(lambda r: pd.NA if pd.isna(r) else labels[int(r)]).astype("string")


def _could_be_later(p: pd.DataFrame, last: pd.Series) -> pd.Series:
    """True where a month- or year-precise entry of the unit may fall after its stored latest
    entry date (a partial date is stored at its first day, so the max of stored dates can sit
    before the true last entry); ``<NA>`` where the unit has no dated entry."""
    d = p.loc[p[ENTRY_DATE].notna(), [UNIT_KEY, ENTRY_DATE, ENTRY_PRECISION]]
    none = pd.DateOffset(days=0)                  # an unknown precision is taken at face value
    upper = pd.Series([dt + PRECISION_SPAN.get(pr if isinstance(pr, str) else "", none)
                       for dt, pr in zip(d[ENTRY_DATE], d[ENTRY_PRECISION].astype(object))],
                      index=d.index)
    later = (upper > d[UNIT_KEY].map(last)).groupby(d[UNIT_KEY]).any()
    return later.reindex(last.index).astype("boolean")


def _theatre_mode(persons: pd.DataFrame) -> pd.DataFrame:
    """Modal theatre per unit over records with a theatre, its share, and whether it tied."""
    p = persons[persons[UNIT_KEY].notna()]
    known = p[THEATRE].notna() & (p[THEATRE] != UNKNOWN_THEATRE)
    cnt = (p[known].groupby([UNIT_KEY, THEATRE]).size().rename("n").reset_index()
           .sort_values([UNIT_KEY, "n", THEATRE], ascending=[True, False, True]))
    top = cnt.groupby(UNIT_KEY).head(2).copy()
    top["rank"] = top.groupby(UNIT_KEY).cumcount()
    first = top[top["rank"] == 0].set_index(UNIT_KEY)
    second = top[top["rank"] == 1].set_index(UNIT_KEY)["n"]
    out = pd.DataFrame(index=pd.Index(sorted(p[UNIT_KEY].unique()), name=UNIT_KEY))
    out["n_theater_known"] = cnt.groupby(UNIT_KEY)["n"].sum().reindex(out.index).fillna(0).astype("Int64")
    out["theater_modal"] = first[THEATRE].reindex(out.index).astype("string")
    out["theater_n_distinct"] = cnt.groupby(UNIT_KEY).size().reindex(out.index).fillna(0).astype("Int64")
    n_first = first["n"].reindex(out.index).astype("Float64")
    out["theater_modal_share"] = (n_first / out["n_theater_known"].astype("Float64")).where(n_first.notna())
    tied = second.reindex(out.index).astype("Float64") == n_first
    out["theater_modal_tied"] = tied.fillna(False).astype("boolean").where(n_first.notna())
    return out


def match_authority(unit_keys: pd.DataFrame, authority: pd.DataFrame) -> pd.DataFrame:
    """Long table: each Legion regiment ``unit_key`` × the Fidler headwords its name matches.

    Args:
        unit_keys: frame with ``unit_key``, ``regiment``, ``legion_army`` (one row per unit).
        authority: ``unit_authority.csv`` as read.

    Returns:
        ``unit_key, unit_cs, variant, authority_theatre, authority_formed, match_kind``;
        a unit with no headword has no row.
    """
    auth = authority[(authority["kind"] == "unit") & authority["number"].notna()].copy()
    auth["number"] = auth["number"].astype(int)
    rows = []
    legion = unit_keys["legion_army"].astype("string").str.startswith(LEGION_ARMY_PREFIX, na=False)
    for uk, reg in zip(unit_keys.loc[legion, UNIT_KEY], unit_keys.loc[legion, "regiment"]):
        for pattern, head in REGIMENT_HEADS:
            m = re.match(pattern, str(reg))
            if not m:
                continue
            n = int(m.group(1))
            hit = auth[(auth["number"] == n) & auth["unit_cs"].str.contains(
                rf"ČS\. {head}(?: \[[IVX]+\])?$", regex=True, na=False)]
            kind = "exact_type"
            abbrev = re.match(r"^\d+\.\s?(\w+)\.pl\.$", str(reg))
            if hit.empty and abbrev and abbrev.group(1) in INFANTRY_ABBREVS:
                alt = "|".join(INFANTRY_HEADS)
                hit = auth[(auth["number"] == n) & auth["unit_cs"].str.contains(
                    rf"ČS\. (?:{alt})(?: \[[IVX]+\])?$", regex=True, na=False)]
                kind = "number_infantry"
            for r in hit.itertuples(index=False):
                rows.append((uk, r.unit_cs, r.variant, r.theatre, r.formed, kind))
            break
    cols = [UNIT_KEY, "unit_cs", "variant", "authority_theatre", "authority_formed", "match_kind"]
    out = pd.DataFrame(rows, columns=cols)
    out["authority_formed"] = pd.to_datetime(out["authority_formed"], errors="coerce")
    return out


def add_authority_columns(units: pd.DataFrame, persons: pd.DataFrame,
                          matches: pd.DataFrame) -> pd.DataFrame:
    """Join the Fidler check columns onto the unit table (left, 1:1); nothing is overwritten.

    ``authority_theatre_agrees`` and ``authority_*_records_agree`` mostly re-read the unit
    parenthetical that also set ``legion_army`` (module docstring): a consistency check of the
    key against Fidler, not a test of the theatre imputation.
    """
    if matches.empty:
        agg = pd.DataFrame(columns=["authority_match", "authority_units", "authority_theatres",
                                    "authority_formed_first"]).rename_axis(UNIT_KEY)
    else:
        g = matches.groupby(UNIT_KEY)
        agg = pd.DataFrame({
            "authority_match": g["match_kind"].first(),
            "authority_units": g["unit_cs"].agg(lambda s: "; ".join(sorted(s))),
            "authority_theatres": g["authority_theatre"].agg(lambda s: ";".join(sorted(set(s)))),
            "authority_formed_first": g["authority_formed"].min(),
        })
    n0 = len(units)
    out = units.merge(agg, left_index=True, right_index=True, how="left", validate="1:1")
    assert len(out) == n0, "authority join changed the unit count"
    for col in ("authority_match", "authority_units", "authority_theatres"):
        out[col] = out[col].astype("string")
    out["authority_formed_first"] = pd.to_datetime(out["authority_formed_first"])
    tset = out["authority_theatres"].str.split(";")
    agree = [pd.NA if (not isinstance(ts, list) or pd.isna(m)) else (m in ts)
             for ts, m in zip(tset, out["theater_modal"])]
    out["authority_theatre_agrees"] = pd.array(agree, dtype="boolean")
    rec = persons.loc[persons[UNIT_KEY].notna(), [UNIT_KEY, THEATRE]]
    rec = rec[rec[THEATRE].notna() & (rec[THEATRE] != UNKNOWN_THEATRE)]
    n1 = len(rec)
    rec = rec.merge(out[["authority_theatres"]], left_on=UNIT_KEY, right_index=True,
                    how="inner", validate="m:1")
    assert len(rec) <= n1
    rec = rec[rec["authority_theatres"].notna()]
    rec["_agree"] = [t in s.split(";") for t, s in zip(rec[THEATRE], rec["authority_theatres"])]
    n_agree = rec.groupby(UNIT_KEY)["_agree"].sum()
    has = out["authority_match"].notna()
    out["authority_n_records_agree"] = (n_agree.reindex(out.index).fillna(0)
                                        .astype("Int64").where(has))
    out["authority_share_records_agree"] = (out["authority_n_records_agree"].astype("Float64")
                                            / out["n_theater_known"].astype("Float64")
                                            ).where(has & (out["n_theater_known"] > 0))
    return out


# ═════════════════════════════════════════ lineage ══════════════════════════════════════
def name_intervals(authority: pd.DataFrame, timeline: pd.DataFrame) -> pd.DataFrame:
    """Each Fidler headword's tenure: ``start`` (formed) to ``end`` (first rename/merge/disband).

    ``end`` is ``NaT`` when the encyclopedia ends no tenure (the unit kept the name to the end).
    Only the headword's own lifecycle rows count (not a sub-unit's), and rows the timeline flags
    ``date_suspect`` are left out.
    """
    lc = timeline[(timeline["kind"] == "lifecycle") & timeline["subunit"].isna()
                  & timeline["state"].isin(NAME_END_STATES)
                  & (pd.to_numeric(timeline["date_suspect"], errors="coerce").fillna(0) == 0)]
    end = (lc.assign(d=pd.to_datetime(lc["date_from"], errors="coerce"))
           .groupby("unit_cs")["d"].min())
    out = authority[["unit_cs"]].copy()
    out["start"] = pd.to_datetime(authority["formed"], errors="coerce")
    out["end"] = out["unit_cs"].map(end)
    out["end"] = pd.to_datetime(out["end"])
    return out.reset_index(drop=True)


def _entry_bounds(persons: pd.DataFrame) -> pd.DataFrame:
    """Each dated entry's earliest and latest possible date from its stated precision.

    An entry with no precision (or one not in :data:`PRECISION_SPAN`) is not placed.
    """
    p = persons.loc[persons[UNIT_KEY].notna() & persons[ENTRY_DATE].notna(),
                    [UNIT_KEY, ENTRY_DATE, ENTRY_PRECISION]].copy()
    prec = p[ENTRY_PRECISION].astype("string")
    p = p[prec.isin(list(PRECISION_SPAN))]
    p["lo"] = pd.to_datetime(p[ENTRY_DATE])
    hi = p["lo"].copy()
    for name, span in PRECISION_SPAN.items():
        sel = p[ENTRY_PRECISION].astype("string") == name
        hi[sel] = p.loc[sel, "lo"] + span
    p["hi"] = hi
    return p.reset_index(drop=True).rename_axis("entry").reset_index()[["entry", UNIT_KEY, "lo", "hi"]]


def classify_entries(entries: pd.DataFrame, variants: pd.DataFrame) -> pd.DataFrame:
    """Place each entry against its unit's name tenures.

    Args:
        entries:  ``entry, unit_key, lo, hi`` (the possible-date window of each entry).
        variants: ``unit_key, unit_cs, start, end`` (``end`` NaT = still in force).

    Returns:
        ``entry, unit_key, state``: the headword whose tenure holds the whole window; else
        ``before_name`` (window ends before the earliest tenure), ``not_in_force`` (touches no
        tenure otherwise) or ``ambiguous`` (touches a tenure without lying inside one).
    """
    x = entries.merge(variants, on=UNIT_KEY, how="inner", validate="m:m")
    open_end = x["end"].isna()
    x["inside"] = (x["lo"] >= x["start"]) & (open_end | (x["hi"] < x["end"]))
    x["touch"] = (x["hi"] >= x["start"]) & (open_end | (x["lo"] < x["end"]))
    g = x.groupby("entry")
    n_in, n_touch = g["inside"].sum(), g["touch"].sum()
    first_start = g["start"].min()
    hi = g["hi"].first()
    pick = x[x["inside"]].groupby("entry")["unit_cs"].first()
    state = pd.Series(STATE_AMBIGUOUS, index=n_in.index, dtype="object")
    state[(n_touch == 0) & (hi < first_start)] = STATE_BEFORE
    state[(n_touch == 0) & ~(hi < first_start)] = STATE_OUT
    one = n_in == 1
    state[one] = pick.reindex(state.index)[one]
    out = state.rename("state").reset_index()
    return out.merge(entries[["entry", UNIT_KEY]], on="entry", how="left", validate="1:1")


def _lineage_counts(units_index: pd.Index, states: pd.DataFrame,
                    variants: pd.DataFrame) -> pd.DataFrame:
    """Per-unit counts of entries by state and the two lineage flags."""
    special = {STATE_BEFORE, STATE_OUT, STATE_AMBIGUOUS}
    st = states.assign(is_variant=~states["state"].isin(special))
    g = st.groupby(UNIT_KEY)
    out = pd.DataFrame(index=units_index)
    out["lineage_n_name_variants"] = variants.groupby(UNIT_KEY)["unit_cs"].nunique()
    out["lineage_n_entries_placed"] = g.size()
    out["lineage_n_variants_hit"] = st[st["is_variant"]].groupby(UNIT_KEY)["state"].nunique()
    for col, s in (("lineage_n_before_name", STATE_BEFORE), ("lineage_n_not_in_force", STATE_OUT),
                   ("lineage_n_ambiguous", STATE_AMBIGUOUS)):
        out[col] = st[st["state"] == s].groupby(UNIT_KEY).size()
    has = out["lineage_n_name_variants"].notna()
    for col in out.columns:
        out[col] = out[col].fillna(0).astype("Int64").where(has)
    sc = st.groupby([UNIT_KEY, "state"]).size().reset_index(name="n")
    sc["txt"] = sc["state"].astype(str) + "=" + sc["n"].astype(str)
    out["lineage_state_counts"] = (sc.groupby(UNIT_KEY)["txt"].agg("; ".join)
                                   .reindex(units_index).astype("string"))
    spans = (out["lineage_n_variants_hit"] >= 2).astype("boolean")
    out_force = ((out["lineage_n_before_name"] + out["lineage_n_not_in_force"]) > 0).astype("boolean")
    out["lineage_spans_variants"] = spans.where(has)
    out["lineage_name_out_of_force"] = out_force.where(has)
    out["lineage_flag"] = (spans | out_force).where(has)
    return out


def lineage_status(units: pd.DataFrame, *, require_theatre_agreement: bool = True) -> pd.Series:
    """Why each unit's lineage columns hold a verdict (``checked``) or ``<NA>`` (the reason).

    With ``require_theatre_agreement`` (the conservative default) a headword whose Fidler
    theatre contradicts the unit's modal theatre, or a unit with no known theatre, gets no
    verdict: the headword is then probably not this unit's, so its tenures say nothing.
    """
    agrees = units["authority_theatre_agrees"]
    s = pd.Series(LINEAGE_CHECKED, index=units.index, dtype="string")
    s[units["lineage_n_name_variants"].isna()] = LINEAGE_NO_TENURE
    if require_theatre_agreement:
        s[agrees.isna()] = LINEAGE_THEATRE_UNKNOWN
        s[agrees.fillna(True) == False] = LINEAGE_CONTRADICTION          # noqa: E712
    s[units["authority_match"].isna()] = LINEAGE_NO_HEADWORD
    return s


def add_lineage_columns(units: pd.DataFrame, persons: pd.DataFrame, matches: pd.DataFrame,
                        intervals: pd.DataFrame, *,
                        require_theatre_agreement: bool = True) -> pd.DataFrame:
    """Lineage check columns: how a unit's dated entries sit against its name's Fidler tenures.

    A unit with no verdict (see :func:`lineage_status`) gets ``<NA>`` throughout — not *no
    lineage problem* — and ``lineage_status`` says why.
    """
    variants = (matches[[UNIT_KEY, "unit_cs"]]
                .merge(intervals, on="unit_cs", how="left", validate="m:1"))
    if len(variants) != len(matches):
        raise AssertionError("tenure join changed the match count")
    variants = variants[variants["start"].notna()]
    states = classify_entries(_entry_bounds(persons), variants)
    lin = _lineage_counts(units.index, states, variants)
    n0 = len(units)
    out = units.merge(lin, left_index=True, right_index=True, how="left", validate="1:1")
    assert len(out) == n0, "lineage join changed the unit count"
    out["lineage_status"] = lineage_status(out, require_theatre_agreement=require_theatre_agreement)
    withheld = out["lineage_status"] != LINEAGE_CHECKED
    for col in LINEAGE_COLS:
        out[col] = out[col].where(~withheld)
    return out


def build_unit_table(persons: pd.DataFrame, authority: pd.DataFrame | None = None,
                     timeline: pd.DataFrame | None = None, *,
                     person_col: str = PERSON_KEY,
                     require_theatre_agreement: bool = True) -> pd.DataFrame:
    """The static unit table, one row per ``unit_key`` (unique, never missing).

    Args:
        persons:    the legionnaire person file (``data/final/persons/legionnaires_clean``).
        authority:  ``unit_authority.csv``; ``None`` reads it from ``reference/units``.
        timeline:   ``unit_timeline.csv``; ``None`` reads it from ``reference/units``.
        person_col: the person key.
        require_theatre_agreement: withhold the lineage verdict where the unit's theatre
                    contradicts Fidler's (a call for the author; see :func:`lineage_status`).

    Returns:
        The unit table with ``unit_key`` as a column, sorted on it.
    """
    if not persons[person_col].is_unique:
        raise ValueError(f"{person_col} is not unique in the person file")
    if authority is None or timeline is None:
        a, t = load_unit_references()
        authority = a if authority is None else authority
        timeline = t if timeline is None else timeline
    units = _unit_aggregates(persons, person_col)
    theatre = _theatre_mode(persons)
    n0 = len(units)
    units = units.merge(theatre, left_index=True, right_index=True, how="left", validate="1:1")
    assert len(units) == n0
    matches = match_authority(units.reset_index(), authority)
    units = add_authority_columns(units, persons, matches)
    units = add_lineage_columns(units, persons, matches, name_intervals(authority, timeline),
                                require_theatre_agreement=require_theatre_agreement)
    out = units.reset_index()
    if out[UNIT_KEY].isna().any() or not out[UNIT_KEY].is_unique:
        raise AssertionError("unit_key must be unique and never missing")
    return out


# ═════════════════════════════════════════ spelling collisions ══════════════════════════
def key_spelling_collisions(units: pd.DataFrame) -> pd.DataFrame:
    """unit_keys that differ only by whitespace in the regiment label (listed, never merged).

    ``2. oms.poch.pr.`` and ``2.oms.poch.pr.`` are one unit spelled two ways in csol.cz;
    ``units.make_unit_key`` keeps the label as written, so they are two keys here. The fix
    belongs upstream (whitespace normalisation of the regiment label in units.py).

    Returns:
        ``spelling, unit_key, n_enrolled, n_keys, n_enrolled_group, is_modal`` for every key in
        a group of two or more; ``is_modal`` marks the group's largest key (ties: first by key).
    """
    u = units[[UNIT_KEY, "regiment", "legion_army", "n_enrolled"]].copy()
    army = u["legion_army"].astype("string").fillna("<NA>")
    u["spelling"] = u["regiment"].astype("string").str.replace(r"\s+", "", regex=True) + " @ " + army
    g = u.groupby("spelling")
    u["n_keys"] = g[UNIT_KEY].transform("size").astype("Int64")
    u["n_enrolled_group"] = g["n_enrolled"].transform("sum").astype("Int64")
    u = u[u["n_keys"] > 1].sort_values(["spelling", "n_enrolled", UNIT_KEY],
                                       ascending=[True, False, True])
    u["is_modal"] = ~u.duplicated("spelling")
    return u[["spelling", UNIT_KEY, "n_enrolled", "n_keys", "n_enrolled_group", "is_modal"]
             ].reset_index(drop=True)


# ═════════════════════════════════════════ unit × period panel ═══════════════════════════
def _attach_units(spells: pd.DataFrame, units: pd.DataFrame, *, person_col: str,
                  unit_col: str) -> tuple[pd.DataFrame, dict]:
    """Merge each spell row onto its person's unit (m:1); report and drop the unplaced."""
    assign = units[[person_col, unit_col]]
    if not assign[person_col].is_unique:
        raise ValueError(f"the unit assignment repeats {person_col}")
    n0 = len(spells)
    m = spells.merge(assign, on=person_col, how="left", validate="m:1", indicator=True)
    if len(m) != n0:
        raise AssertionError("unit merge changed the spell row count")
    report = {
        "spell_rows": n0,
        "spell_persons": int(spells[person_col].nunique()),
        "persons_no_assignment_row": int(m.loc[m["_merge"] == "left_only", person_col].nunique()),
        "persons_unit_missing": int(m.loc[(m["_merge"] == "both") & m[unit_col].isna(),
                                          person_col].nunique()),
    }
    kept = m[m[unit_col].notna()].drop(columns="_merge")
    report["persons_placed"] = int(kept[person_col].nunique())
    report["spell_rows_placed"] = len(kept)
    return kept, report


def _event_column(t) -> str:
    """``exits_<type>``; any character outside a word is folded to ``_``."""
    return "exits_" + re.sub(r"\W", "_", str(t))


def calendar_period_check(spells: pd.DataFrame, period: str,
                          calendar_col: str | None = SPELLS_CALENDAR) -> None:
    """Refuse a period column that is not a calendar period.

    Under ``build_spells(clock="duration")`` ``period_index`` counts periods since each man's
    own entry, so one value is many calendar months: a unit × ``period_index`` panel would be a
    unit × tenure panel. The test: ``period`` must map to exactly one ``calendar_col`` value
    (``period_start``, the calendar start under either clock). A datetime period is calendar by
    construction; ``calendar_col=None`` skips the test (the caller vouches for the clock).
    """
    if period == calendar_col or pd.api.types.is_datetime64_any_dtype(spells[period]):
        return
    if calendar_col is None:
        return
    if calendar_col not in spells.columns:
        raise KeyError(f"spells lacks {calendar_col!r}, needed to prove {period!r} is calendar time")
    pairs = spells[[period, calendar_col]].drop_duplicates()
    if pairs[period].duplicated().any() or pairs[calendar_col].duplicated().any():
        raise ValueError(f"{period!r} is not one-to-one with {calendar_col!r}: a duration clock? "
                         f"Use period={calendar_col!r}, or build_spells(..., clock='calendar')")


def _prepare_spells(spells: pd.DataFrame, *, person_col: str, period: str, at_risk_col: str,
                    event_col: str, no_event: tuple, allowed_events, desertion_event: str,
                    unknown_risk: str) -> tuple[pd.DataFrame, dict]:
    """Validate the spell frame; return ``person, period, _risk, _event`` (``<NA>`` = no event)."""
    need = {person_col, period, at_risk_col, event_col}
    if need - set(spells.columns):
        raise KeyError(f"spells lacks {sorted(need - set(spells.columns))}")
    if unknown_risk not in UNKNOWN_RISK_RULES:
        raise ValueError(f"unknown_risk must be one of {UNKNOWN_RISK_RULES}")
    if desertion_event in no_event:
        raise ValueError(f"desertion_event {desertion_event!r} is listed as a no-event value")
    if allowed_events is not None and desertion_event not in allowed_events:
        raise ValueError(f"desertion_event {desertion_event!r} is not an allowed event type")
    if spells.duplicated([person_col, period]).any():
        raise ValueError("spells must be unique on person × period")
    raw = spells[event_col].astype("string")
    if raw.isna().any():
        raise ValueError(f"{int(raw.isna().sum()):,} {event_col} missing: a survived period or an "
                         f"unrecorded exit? The spell file must say ({no_event!r} = survived)")
    event = raw.where(~raw.isin(list(no_event)))
    if allowed_events is not None:
        bad = sorted(set(event.dropna()) - set(allowed_events))
        if bad:
            raise ValueError(f"event types {bad} are neither no_event nor allowed_events")
    risk = spells[at_risk_col].astype("boolean")
    s = pd.DataFrame({person_col: spells[person_col], period: spells[period],
                      "_risk": risk, "_event": event})
    report = {"rows_risk_unknown": int(risk.isna().sum()),
              "events_on_risk_unknown": int((risk.isna() & event.notna()).sum())}
    if report["rows_risk_unknown"]:
        if unknown_risk == "refuse":
            raise ValueError(f"{report['rows_risk_unknown']:,} rows with {at_risk_col} <NA> "
                             "(inside an exit interval); pass unknown_risk='exclude' to drop them")
        s = s[s["_risk"].notna()]
    if (s["_event"].notna() & ~s["_risk"].astype(bool)).any():
        raise ValueError("an event in a period not at risk")
    return s.assign(_risk=s["_risk"].astype(bool)), report


def _aggregate(s: pd.DataFrame, *, keys: list[str], person_col: str, unit_col: str,
               period: str, desertion_event: str) -> pd.DataFrame:
    """Counts per unit × period over the rows at risk."""
    at = s[s["_risk"]]
    panel = at.groupby(keys).size().rename("n_at_risk").to_frame()
    first = at.groupby(person_col)[period].min().rename(period).reset_index()
    first = first.merge(s[[person_col, unit_col]].drop_duplicates(), on=person_col,
                        how="left", validate="1:1")
    panel["n_entries"] = first.groupby(keys).size()
    ev = at[at["_event"].notna()]
    types = sorted(set(ev["_event"]) | {desertion_event})
    for t in types:
        panel[_event_column(t)] = ev[ev["_event"] == t].groupby(keys).size()
    panel = panel.fillna(0).astype("int64").reset_index()
    panel.attrs["exit_cols"] = [_event_column(t) for t in types]
    return panel


def _complete_span(panel: pd.DataFrame, unit_col: str, period: str,
                   span_freq: str | None) -> pd.DataFrame:
    """Every period between a unit's first and last observed one, missing ones as zero rows."""
    kind = panel[period].dtype
    frames = []
    for uk, d in panel.groupby(unit_col, sort=False):
        lo, hi = d[period].min(), d[period].max()
        if isinstance(kind, pd.PeriodDtype):
            rng = pd.period_range(lo, hi, freq=kind.freq)
        elif pd.api.types.is_integer_dtype(kind):
            rng = range(int(lo), int(hi) + 1)
        elif pd.api.types.is_datetime64_any_dtype(kind) and span_freq:
            rng = pd.date_range(lo, hi, freq=span_freq)
        else:
            raise TypeError("fill='span' needs a Period, integer, or datetime period with span_freq")
        frames.append(pd.DataFrame({unit_col: uk, period: pd.Series(rng, dtype=kind)}))
    full = pd.concat(frames, ignore_index=True)
    out = full.merge(panel, on=[unit_col, period], how="left", validate="1:1")
    if int(out["n_at_risk"].notna().sum()) != len(panel):
        raise AssertionError(f"observed periods off the {span_freq!r} grid: wrong span_freq?")
    counts = [c for c in out.columns if c not in (unit_col, period)]
    out[counts] = out[counts].fillna(0)
    return out


def build_unit_panel(spells: pd.DataFrame, units: pd.DataFrame, *,
                     period: str = SPELLS_CALENDAR, person_col: str = PERSON_KEY,
                     at_risk_col: str = "at_risk", event_col: str = SPELLS_EVENT,
                     unit_col: str = UNIT_KEY, desertion_event: str = SPELLS_DESERTION,
                     no_event: tuple = (SPELLS_NO_EVENT,), allowed_events=SPELLS_EVENTS,
                     unknown_risk: str = "refuse", calendar_col: str | None = SPELLS_CALENDAR,
                     fill: str = "span", span_freq: str | None = SPAN_FREQ["month"],
                     unit_table: pd.DataFrame | None = None) -> pd.DataFrame:
    """Aggregate a person-period spell frame (``spells.spell_periods``) to ``unit_key`` × period.

    Args:
        spells:          one row per person × period: ``person_col``, ``period``,
                         ``at_risk_col`` and ``event_col`` (an exit type in the period it
                         happens, a ``no_event`` value otherwise; a missing value is refused).
        units:           the person → unit assignment (``person_col``, ``unit_col``), one row
                         per person; a person with no unit is dropped and counted.
        period:          the period column. The default ``period_start`` is calendar time under
                         either spells clock; an integer period must pass
                         :func:`calendar_period_check`.
        no_event:        event values that mean "survived the period" (spells: ``"none"``).
        allowed_events:  every other event value must be one of these (spells outcome labels);
                         ``None`` accepts any.
        desertion_event: the event value that is a desertion (the hazard's numerator).
        unknown_risk:    ``"refuse"`` an ``<NA>`` at_risk (spells' ``interval_rule="interval"``)
                         or ``"exclude"`` those rows, counting them and their events.
        fill / span_freq: ``"span"`` adds zero rows for a unit's periods between its first and
                         last observed one (a datetime period steps by ``span_freq``);
                         ``"observed"`` keeps observed rows only.
        unit_table:      when given, every panel unit must be one of its ``unit_key``.

    Returns:
        ``unit_key, <period>, n_at_risk, n_entries, n_exits, exits_<type>…, desertion_hazard``;
        the merge report is in ``.attrs["merge_report"]``.
    """
    s, risk_report = _prepare_spells(
        spells, person_col=person_col, period=period, at_risk_col=at_risk_col,
        event_col=event_col, no_event=tuple(no_event), allowed_events=allowed_events,
        desertion_event=desertion_event, unknown_risk=unknown_risk)
    calendar_period_check(spells, period, calendar_col)
    s, report = _attach_units(s, units, person_col=person_col, unit_col=unit_col)
    keys = [unit_col, period]
    panel = _aggregate(s, keys=keys, person_col=person_col, unit_col=unit_col, period=period,
                       desertion_event=desertion_event)
    exit_cols = panel.attrs["exit_cols"]
    if fill == "span":
        panel = _complete_span(panel, unit_col, period, span_freq)
    elif fill != "observed":
        raise ValueError("fill must be 'span' or 'observed'")
    panel[["n_at_risk", "n_entries"] + exit_cols] = (
        panel[["n_at_risk", "n_entries"] + exit_cols].astype("int64"))
    panel.insert(4, "n_exits", panel[exit_cols].sum(axis=1).astype("int64"))
    des = panel[_event_column(desertion_event)].astype("Float64")
    risk = panel["n_at_risk"].astype("Float64")
    panel["desertion_hazard"] = (des / risk).where(panel["n_at_risk"] > 0)
    panel = panel.sort_values(keys).reset_index(drop=True)
    _assert_panel(panel, keys, unit_table, unit_col)
    report.update(risk_report)
    report["events_placed"] = int(s.loc[s["_risk"], "_event"].notna().sum())
    panel.attrs = {"merge_report": report}
    return panel


def _assert_panel(panel: pd.DataFrame, keys: list[str], unit_table: pd.DataFrame | None,
                  unit_col: str) -> None:
    """The panel's own invariants: key unique and never missing, counts never negative."""
    if panel[keys].isna().any().any() or panel.duplicated(keys).any():
        raise AssertionError("unit × period key must be unique and never missing")
    counts = panel.select_dtypes("number").drop(columns="desertion_hazard", errors="ignore")
    if (counts < 0).any().any():
        raise AssertionError("a negative count in the unit panel")
    h = panel["desertion_hazard"].dropna()
    if ((h < 0) | (h > 1)).any():
        raise AssertionError("desertion hazard outside [0, 1]")
    if unit_table is not None:
        unknown = set(panel[unit_col]) - set(unit_table[unit_col])
        if unknown:
            raise AssertionError(f"{len(unknown)} panel unit(s) not in the unit table")

AUTHORITY_COLS = ("authority_units", "authority_theatres", "authority_formed_first",
                  "authority_theatre_agrees", "authority_n_records_agree",
                  "authority_share_records_agree")
LINEAGE_COLS = ("lineage_n_name_variants", "lineage_n_entries_placed", "lineage_n_variants_hit",
                "lineage_n_before_name", "lineage_n_not_in_force", "lineage_n_ambiguous",
                "lineage_state_counts", "lineage_spans_variants", "lineage_name_out_of_force",
                "lineage_flag")
# data_checks' own SOFT bar for the Fidler theatre check (_theatre_vs_fidler: rate >= 0.98).
THEATRE_AGREE_MIN = 0.98


def _unit_table_lineage_checks(units: pd.DataFrame) -> list[tuple[str, bool, str, bool]]:
    """The withheld-verdict and date-precision invariants of the unit table."""
    withheld = units["lineage_status"] != LINEAGE_CHECKED
    bad = [c for c in LINEAGE_COLS if units.loc[withheld, c].notna().any()]
    out = [("units: lineage_status never missing; no lineage verdict unless it is 'checked'",
            bool(units["lineage_status"].notna().all()) and not bad,
            f"verdict where withheld: {bad}", True)]
    ok = True
    for bound in ("first", "last"):
        date, prec = units[f"{bound}_enroll_date"], units[f"{bound}_enroll_date_precision"]
        ok &= bool(prec[date.notna()].isin(list(PRECISION_ORDER)).all()
                   and prec[date.isna()].isna().all())
    out.append(("units: entry-date bounds carry their precision (and only where dated)", ok,
                "a dated bound with no precision, or a precision with no date", True))
    return out


def unit_table_checks(units: pd.DataFrame,
                      persons: pd.DataFrame | None = None) -> list[tuple[str, bool, str, bool]]:
    """The unit table's invariants as ``(label, ok, detail_if_failed, hard)``."""
    k = units[UNIT_KEY]
    out = [("units: key unit_key unique and never missing", bool(k.notna().all() and k.is_unique),
            f"{int(k.isna().sum())} missing, {int(k.duplicated().sum())} duplicate", True)]
    order = ((units["n_deserted"] <= units["n_exit_recorded"])
             & (units["n_exit_recorded"] <= units["n_enrolled"])).all()
    out.append(("units: n_deserted <= n_exit_recorded <= n_enrolled", bool(order),
                "a unit with more deserters than recorded exits, or exits than men", True))
    rate, base = units["desertion_rate"], units["n_exit_recorded"]
    ok = bool((rate.isna() == (base == 0)).all() and rate.dropna().between(0, 1).all())
    out.append(("units: desertion_rate in [0,1], <NA> exactly where no exit is recorded", ok,
                "a rate on an empty base, or a missing rate on a recorded one", True))
    none = units["authority_match"].isna()
    bad = [c for c in AUTHORITY_COLS + LINEAGE_COLS if units.loc[none, c].notna().any()]
    out.append(("units: no Fidler check value on a unit with no Fidler headword", not bad,
                f"filled without a match: {bad}", True))
    out += _unit_table_lineage_checks(units)
    placed = units["lineage_n_entries_placed"].dropna()
    out.append(("units: lineage places no more entries than are dated",
                bool((placed <= units.loc[placed.index, "n_enroll_dated"]).all()),
                "more lineage-placed entries than dated entries", True))
    has = ~none
    rec_n, rec_d = units.loc[has, "authority_n_records_agree"].sum(), units.loc[has, "n_theater_known"].sum()
    share = float(rec_n / rec_d) if rec_d else 1.0
    out.append((f"units: records' theatre agrees with Fidler ({share:.2%} of {int(rec_d):,}; "
                "re-reads the unit parenthetical, SOFT)",
                share >= THEATRE_AGREE_MIN, f"agreement {share:.2%} below {THEATRE_AGREE_MIN:.0%}",
                False))
    if persons is not None:
        on = persons[UNIT_KEY].dropna()
        same = set(on) == set(k) and int(units["n_enrolled"].sum()) == len(on)
        out.append(("units: every person with a unit is counted once, in a unit of the table",
                    same, f"{len(on):,} persons with a unit vs {int(units['n_enrolled'].sum()):,} "
                    "counted", True))
    return out


def unit_panel_checks(panel: pd.DataFrame, units: pd.DataFrame, period: str = SPELLS_CALENDAR, *,
                      no_event: tuple = (SPELLS_NO_EVENT,),
                      desertion_event: str = SPELLS_DESERTION) -> list[tuple[str, bool, str, bool]]:
    """The unit × period panel's invariants as ``(label, ok, detail_if_failed, hard)``."""
    keys = [UNIT_KEY, period]
    na, dup = int(panel[keys].isna().any(axis=1).sum()), int(panel.duplicated(keys).sum())
    out = [(f"unit panel: key {keys} unique and never missing", na == 0 and dup == 0,
            f"{na} missing key(s), {dup} duplicate(s)", True)]
    exit_cols = [c for c in panel.columns if c.startswith("exits_")]
    named_none = [_event_column(v) for v in no_event if _event_column(v) in exit_cols]
    out.append(("unit panel: no exits_ column for a no-event value; the desertion column exists",
                not named_none and _event_column(desertion_event) in exit_cols,
                f"no-event columns {named_none}, or {_event_column(desertion_event)} absent", True))
    at_risk = panel["n_at_risk"] > 0
    out.append(("unit panel: survival observed (n_exits < n_at_risk somewhere)",
                bool(not at_risk.any() or (panel["n_exits"] < panel["n_at_risk"]).any()),
                "every man at risk exits every period: is a survived period counted as an exit?",
                True))
    counts = panel[["n_at_risk", "n_entries", "n_exits"] + exit_cols]
    out.append(("unit panel: no count negative", bool((counts >= 0).all().all()),
                "a negative count", True))
    ok = bool((panel["n_exits"] == panel[exit_cols].sum(axis=1)).all()
              and (panel["n_exits"] <= panel["n_at_risk"]).all()
              and (panel["n_entries"] <= panel["n_at_risk"]).all())
    out.append(("unit panel: exits sum by type; exits and entries within those at risk", ok,
                "n_exits differs from its types, or exceeds n_at_risk", True))
    h = panel["desertion_hazard"]
    ok = bool((h.isna() == ~at_risk).all() and h.dropna().between(0, 1).all())
    out.append(("unit panel: desertion_hazard in [0,1], <NA> exactly where none is at risk", ok,
                "a hazard on an empty risk set, or outside [0, 1]", True))
    unknown = set(panel[UNIT_KEY]) - set(units[UNIT_KEY])
    out.append(("unit panel: every unit_key is in the unit table", not unknown,
                f"{len(unknown)} unit(s) not in the table", True))
    entries = panel.groupby(UNIT_KEY)["n_entries"].sum()
    cap = units.set_index(UNIT_KEY)["n_enrolled"].reindex(entries.index)
    out.append(("unit panel: no unit enters more men than it enrolled",
                bool((entries <= cap).all()), "panel entries above the unit's n_enrolled", True))
    return out


# ═════════════════════════════════════════ report ═══════════════════════════════════════
def _lineage_report(units: pd.DataFrame) -> dict:
    """Lineage verdict counts, and the theatres the spanning units are in."""
    flag = units["lineage_flag"].fillna(False).astype(bool)
    spans = units["lineage_spans_variants"].fillna(False).astype(bool)
    r = {f"units_lineage_status_{k}": int(v)
         for k, v in units["lineage_status"].value_counts().sort_index().items()}
    r.update({
        "units_lineage_flag": int(flag.sum()),
        "units_lineage_spans_variants": int(spans.sum()),
        "units_lineage_name_out_of_force": int(units["lineage_name_out_of_force"].fillna(False)
                                               .astype(bool).sum()),
        "records_in_lineage_flagged_units": int(units.loc[flag, "n_enrolled"].sum()),
        "spans_by_theatre": "; ".join(f"{t}={n}" for t, n in units.loc[spans, "theater_modal"]
                                      .value_counts().sort_index().items()),
    })
    return r


def units_panel_report(units: pd.DataFrame, panel: pd.DataFrame | None = None) -> dict:
    """Print and return the headline counts of the unit table (and the panel, if given)."""
    has = units["authority_match"].notna()
    agree = units.loc[has, "authority_theatre_agrees"]
    rec_n = int(units.loc[has, "authority_n_records_agree"].sum())
    rec_d = int(units.loc[has, "n_theater_known"].sum())
    coll = key_spelling_collisions(units)
    r = {
        "units": len(units),
        "records_in_units": int(units["n_enrolled"].sum()),
        "units_first_enroll_not_day_precise": int(
            (units["first_enroll_date_precision"].dropna() != "day").sum()),
        "units_matched_fidler": int(has.sum()),
        "units_matched_exact_type": int((units["authority_match"] == "exact_type").sum()),
        "records_in_matched_units": int(units.loc[has, "n_enrolled"].sum()),
        "units_modal_theatre_agrees": int(agree.sum()),
        "units_modal_theatre_disagrees": int((agree == False).sum()),   # noqa: E712
        "records_theatre_known_in_matched_units": rec_d,
        "records_theatre_agree": rec_n,
        "records_theatre_conflict": rec_d - rec_n,
        "records_theatre_agree_share": float(rec_n / rec_d) if rec_d else np.nan,
        **_lineage_report(units),
        "spelling_collision_groups": int(coll["spelling"].nunique()),
        "spelling_collision_keys": len(coll),
        "records_in_non_modal_spelling": int(coll.loc[~coll["is_modal"], "n_enrolled"].sum()),
    }
    if panel is not None:
        r.update({"panel_rows": len(panel), "panel_units": int(panel[UNIT_KEY].nunique()),
                  "panel_person_periods_at_risk": int(panel["n_at_risk"].sum()),
                  "panel_entries": int(panel["n_entries"].sum()),
                  "panel_exits": int(panel["n_exits"].sum()),
                  **{f"merge_{k}": v for k, v in panel.attrs.get("merge_report", {}).items()}})
    for k, v in r.items():
        if isinstance(v, str):
            print(f"  {k:<40} {v}")
        else:
            print(f"  {k:<40} {v:,.4f}" if isinstance(v, float) else f"  {k:<40} {v:,}")
    return r
